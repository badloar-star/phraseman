## Outcome

Один документ `docs/phraseman-2.0/R1_TEST_CLEANUP.md`: для каждой разрешённой владельцем реальной отправки с тестового
гостя (заявка на публикацию, отклик, жалобы, обращение в поддержку, вызов ИИ, +1 добавление и лайк набору, удаление
аккаунта №3) — какая функция/коллекция пишет, по каким полям найти запись, какие счётчики меняются, чем откатить и кто
может это сделать. Успех: человек без контекста может после съёмки пройти по списку и убрать следы, не трогая прод наугад.

## Scope

In scope: чтение кода `functions/src/*`, `app/community_packs/*`, `firestore.rules`; один новый документ плана.

Out of scope: любые записи в прод, запуск скриптов уборки, правка продуктового кода, правка правил.

## Architecture

No architecture change — только документ. Пути и поля сверены с кодом (ссылки файл:строка в самом документе).

## Security and privacy

Записей в прод нет. В документе нет паролей, токенов и реальных uid; для uid гостя оставлены подстановки. Предложенные
действия уборки помечены «только после явного «да» владельца»; админ-действия — только через проверенные функции модерации.

## Technical debt

Pay now: найденные при чтении дыры уборки (удаление аккаунта не чистит лайк/добавление/отклик под чужими наборами;
счётчики `jarvis_quality_daily` не откатываются) вынесены в документ как «остаточный след» — продуктовую правку не делаем
(вне объёма), передаём координатору.

## Verification

Каждое утверждение документа сверено с кодом; что не проверено (индексы collectionGroup, TTL-политика сессий диалога,
поведение админки на удаление) помечено «не проверено». Evidence: ссылки файл:строка в документе.

## Rollback

Документ можно удалить без последствий; он ничего не меняет в системе.
