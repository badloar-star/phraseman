# Полноэкранный тур Пика — 1:1 по утверждённому макету (05.11.2026)

Governance-ID: TG-466C0900CB4D

## Outcome
Тур первого входа в Пик — полноэкранный, 3 страницы со свайпом, ровно по макету `docs/work/release/mockups/peak_tour_full_approved_2026-11-05.html` (коммит 81273d1c5), тёмная и светлая тема. Слово владельца: «реализовать ТОЧНО так же, как на макете».

## Scope
- Новый компонент `components/spire/peak/PeakTourFull.tsx` (рядом, без правок `PeakTour.tsx` и `use_peak_tour_gate` — их держит Ядро).
- Сторож-тест `tests/peak_tour_full_2026_11_05.test.ts`.
- Подключение на место `PeakTour` — отдельной одной правкой после коммита Ядра.

## Architecture
Горизонтальный постраничный `ScrollView` (свайп встроенный), каждая страница: «Пропустить», рисунок 340 dp, текст `peakTour1..3`, точки, «Далее»/«Начать». Рисунки: башня `SpireTowerDeferred` (как в прежнем `SpireTour`), пять строк «Игрок 1–5» с монетами ранга (`coinRankSourceForSize`), плашки «лига → лига / энергия ↑ / +1 000», окно башни `SpireTower` на 15 этаже. Цвета — только из `useSpirePalette`.

## Security and privacy
Данных не собирает и не хранит; тексты и цифры — иллюстрация правил, не данные пользователей.

## Technical debt
Старый `PeakTour` (окна поверх экрана) остаётся до подключения; после одобрения замены его можно удалить.

## Verification
Сторож-тест: 3 страницы, ровно тексты peakTour1..3, нет tour*Title, нет сырых цветов; кадры эмулятора (через координатора) в тёмной и светлой теме; лог `[PEAK-TOUR-FULL]`.

## Rollback
Вернуть подключение `PeakTour` в `PeakScreenV2`; новый файл можно удалить без последствий.
