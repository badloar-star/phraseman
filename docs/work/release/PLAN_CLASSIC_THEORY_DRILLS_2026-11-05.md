## 1. Как устроена английская теория (источник правды)

- Экран `app/hint.tsx` → `components/theory/TheoryLessonView.tsx` (946 строк): аккордеон разделов, шапка «Разделы n/m · задания k/N» (`app/theory_progress.ts`: `countCompletedTheoryDrills`, `theoryOverallProgressPct`, ключ прогресса по языку курса).
- Данные уроков: `app/theory_content_lessonNN.ts` (английский курс), форма `TheorySection { num, title, blocks[] }`, блоки: `body | formula | examples | fix | tip | note | drill`.
- Тип задания (`TheoryDrill.type`): `choice` (ThreeTileChoice), `word_bank` (WordBankBuilder), `spot_slip` (SpotTheSlip), `binary` (BinaryRecognition). Данные задания — `IntroChoiceInteraction | IntroBuildInteraction | IntroSpotInteraction | IntroBinaryInteraction` (`app/lesson_data_types.ts:285–330`).
- Теория Learning V2 уже использует тот же `TheoryLessonView` через адаптер (`app/lesson_theory_v2.tsx`) — готовый прецедент «чужие данные → родной экран».

## 2. Что есть в данных fr/es/de/it

Задания **уже написаны автором**, по 20 на каждый из 32 уроков в каждом языке (проверено скриптом):

| Язык | Поле | Виды заданий (по 128 штук на вид) |
|---|---|---|
| fr, it | `drills[]` | choice, spot, match, build, transfer |
| de | `lab[]` | choice, spot, match, build, transfer |
| es | `sharedActivities[]` | form, spot, match, build, transform |

Поля задания (fr/it/de): `id` (`fr:01:01:lab`), `chapter`, `item` (номер фразы урока), `kind`, `slot` (позиция слова во фразе), `bad` (типичная ошибка), `near` (номер соседней фразы-образца), `options[3]`. У es: `right`, `near`, `seq` (слова фразы), `feedback{9 локалей}`, `chapterActivities` (какие задания к какой главе).

Тексты-пояснения у es есть на 9 локалей (`feedback`); у fr/it/de пояснений нет — новые тексты с нуля **не нужны**, нужны только короткие подписи интерфейса («Найди неверное слово», «Выбери форму») — это строки UI, а не контент курса.

## 3. Можно ли собрать автоматически — да, без новых текстов курса

Сопоставление (чистая функция, без сети):

| Вид в данных | Экран | Как собирается |
|---|---|---|
| choice / form | `choice` | фраза `item` из `lessons-NN.json`, слово `slot` заменено пропуском; `options` и ответ (= плитка `slot`) |
| spot | `spot_slip` | слова фразы чипами, на `slot` подставлено `bad`; `answerIndex = slot-1`; «исправление» = верная фраза |
| match | `binary` | вариант A = верная фраза, B = с `bad` на `slot`; порядок по детерминированному хэшу id |
| build | `word_bank` | плитки фразы + дистракторы из `options`; перевод фразы на языке интерфейса — как условие |
| transfer / transform | `word_bank` (перенос на соседнюю фразу `near`) или пропуск на первом релизе | уточнить у Теории, что именно означает вид |

Главы привязываются по полю `chapter` (fr/it/de) или `chapterActivities` (es).
