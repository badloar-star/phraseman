## Outcome

10 готовых роликов формата «фраза → стоп → перевод» лежат в папке
`C:\Users\badlo\Desktop\Phraseman Clips` с понятными именами.

Успех: в папке 10 файлов .mp4 1080x1920, каждый со своим фрагментом интервью,
у каждого есть озвучка и переводы; ни один не дублирует другой по содержанию.

## Scope

In scope:
- `content/clipper/batch.py` — новый оркестратор: режет видео на N отрезков,
  прогоняет каждый через phrases -> перевод -> tts_seq -> render_seq,
  складывает результат в указанную папку.
- Переводы 10 отрезков (выполняет модель в диалоге).

Out of scope:
- Приложение Phraseman.
- Новые исходники: владелец выбрал делать всё из имеющегося интервью.
- Музыка, хук, караоке.

## Architecture

Текущая граница: конвейер обрабатывает ОДИН отрезок за запуск, границы
задаются руками, перевод кладётся в phrases.json вручную.

Целевая: batch.py принимает число роликов и папку назначения, сам вычисляет
непересекающиеся отрезки по длительности транскрипта, для каждого создаёт
свою рабочую подпапку (work/batch_NN), прогоняет шаги и копирует финал.
Шаг перевода остаётся ручным: скрипт останавливается и печатает, что нужно
перевести, если поле ru пустое.

Инвариант: каждый отрезок имеет свою work-папку, поэтому phrases.json,
озвучки и куски не смешиваются между роликами.

Решение: отрезки нарезаются последовательно по всей длине, а не выбираются
«самые интересные» — замер плотности речи показал равномерность
(94-156 слов в минуту на всех 13 минутах), выбирать не из чего.

## Security and privacy

Личных данных нет: вход — видео владельца, выход — файлы на его рабочем столе.
Firestore, аккаунты, детские данные не затронуты; privacy policy без изменений.

Секреты: ELEVENLABS_API_KEY из окружения, в репозиторий не пишется.

Запись ВНЕ проекта: скрипт пишет в `Desktop\Phraseman Clips` по явной просьбе
владельца. Путь передаётся аргументом, по умолчанию пишет в output проекта.
Существующие файлы не перезаписываются молча — при совпадении имени
добавляется суффикс.

Копирайт: исходник чужой, ролики содержат фрагменты интервью с собственным
разбором. Ответственность за права — на владельце (отмечено в README).

## Technical debt

- **Accept temporarily:** перевод по-прежнему делает модель в диалоге, а не
  автоматический вызов API. Владелец, пересмотр — когда формат устоится.
- **Accept temporarily:** расход квоты ElevenLabs ~5500 знаков за партию.
  Владелец подтвердил, что квоты достаточно.
- **Contain:** batch.py вызывает существующие шаги как подпроцессы, не
  дублируя их логику. Условие выхода: если шаги изменятся — batch не трогать.

- `python content/clipper/batch.py <видео> <папка> 10` завершается без ошибок.
- В папке ровно 10 файлов .mp4.
- ffprobe каждого: 1080x1920, есть аудиодорожка, длительность > 20с.
- Выборочно по кадрам: перевод соответствует прозвучавшей фразе.

## Rollback

Удаление папки на рабочем столе отменяет результат полностью. batch.py
изолирован, существующие шаги не менялись. Рабочие подпапки work/batch_NN
удаляются вместе с work. На приложение и сборку не влияет.
