# Teori · Yeni kursun 4. dersi — «There is, there are, some, any, in, on, under» (TR)

> «12 · ТЕОРИЯ» oturumu, 21.10.2026. Bölümler 01–14, İngilizce cümleler ve alıştırmalar
> `lesson_04_ru.md` ile aynı. Türkçe konuşanların tuzakları: «Burada bir eczane var» → «var» sonda,
> yer başta, İngilizcede ise There is başa gelir (Here is a pharmacy, Here pharmacy); «yok» tek kelime →
> There not / There is no; «-de/-da» hem in hem on için → in/on karışır; «arkasında» = behind,
> «yanında» = next to. Hitap: sen. Yayından önce ana dili Türkçe olan biri okumalı.

**Ekran başlığı:** Teori · Ne nerede var

---

## 01 · Neler söylemeyi öğreneceksin *(baştan açık)*

**body**
Bu derste neyin nerede olduğunu anlatmayı öğreniyorsun: «yakında eczane var», «buzdolabında süt var», «burada zil yok», «anahtar paspasın altında». Dersin ana kalıbı There is — Türkçede sadece «var».

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There is a pharmacy here. | Burada bir eczane var. | There is |
| There is some milk here. | Burada süt var. | some |
| Is there a toilet here? | Burada tuvalet var mı? | Is there |
| There isn't a doorbell. | Zil yok. | isn't |
| The key is under the doormat. | Anahtar paspasın altında. | under |

---

## 02 · There is — «var» *(baştan açık)*

**body**
Bir şeyin bir yerde olduğunu söylerken There is ile başla. Türkçede «Burada bir eczane var» deriz, «var» sonda durur. İngilizcede «var» başa gelir, yer sona gider: There is a pharmacy here.

**formula**
`There is` · `a + eşya` · `nerede`

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There is a pharmacy here. | Burada bir eczane var. | There is |
| There is a library nearby. | Yakında bir kütüphane var. | There is |
| There is a bakery here. | Burada bir fırın var. | There is |
| There is an office upstairs. | Üst katta bir ofis var. | There is |
| There is a clinic inside the building. | Binanın içinde bir klinik var. | There is |

**fix**
- ~~Here is a pharmacy.~~ *(«burada var» anlamında)* → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There burada «orada» demek değil. Sadece «var» cümlesinin başı. Bu yüzden There is a pharmacy here — «burada eczane var»; there ile here birbirine ters düşmez.

---

## 03 · There are — birkaç tane olunca

**body**
Birden fazla şey varsa is yerine are gelir, kelimeye de s eklenir: There are banks here. Türkçedeki «-ler/-lar» gibi düşün. 3. dersteki gibi, birkaç şeyin önüne a konmaz.

**formula**
`There are` · `eşya + s` · `nerede`

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There are banks here. | Burada bankalar var. | There are |
| There are museums nearby. | Yakında müzeler var. | There are |
| There are bridges nearby. | Yakında köprüler var. | There are |
| There are quiet streets here. | Burada sakin sokaklar var. | There are |
| There are parks nearby. | Yakında parklar var. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- cümle: `There ___ museums nearby.`
- seçenekler: `is` · `are` · `am`
- cevap: `are`
- neden: Müzeler birden fazla, bu yüzden There are.

---

## 04 · Yer — en sonda

**body**
Türkçede yer çoğu zaman başta durur: «Binanın arkasında bahçe var». İngilizcede önce There is ve eşya gelir, nerede olduğu en sonda: There is a garden behind the building. Önce ne var, sonra nerede.

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There is a garden behind the building. | Binanın arkasında bir bahçe var. | behind |
| There is a bench near the garden. | Bahçenin yakınında bir bank var. *(oturulan)* | near |
| There is a church behind the bank. | Bankanın arkasında bir kilise var. | behind |
| There is a market near the bridge. | Köprünün yakınında bir pazar var. | near |
| There is a lake behind the park. | Parkın arkasında bir göl var. | behind |

**drill · word_bank**
- görev: Arkadaşına söyle: «Parkın arkasında bir göl var».
- cevap: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- hücre etiketleri: yok (cümle uzun, hücre ipuçları sadece engel olur)
- fazla kartlar: `are` · `in`

## 05 · «Var mı?» diye sor, kısa cevap ver

**body**
Sormak için ilk iki kelimenin yerini değiştir: There is → Is there…? There are → Are there…? Kısa cevap: Yes, there is. No, there isn't. Yes, there are. No, there aren't. Türkçedeki «var mı?» burada başa gelir.

**formula**
`Is there` · `a + eşya` · `nerede` · `?` — `Are there` · `eşya + s` · `nerede` · `?`

**examples** 🔊
| en | tr | hi |
|---|---|---|
| Is there a dentist near here? | Buralarda bir diş hekimi var mı? | Is there |
| Is there a toilet here? | Burada tuvalet var mı? | Is there |
| Yes, there is. | Evet, var. | there is |
| No, there isn't. | Hayır, yok. | isn't |
| Are there trams near the bank? | Bankanın yakınında tramvay var mı? | Are there |
| Yes, there are. | Evet, var. | there are |
| No, there aren't. | Hayır, yok. | aren't |

**fix**
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

## 06 · Süt, ekmek, tereyağı — tane tane sayılmaz

**body**
Bazı şeyler sayılır: muz, iki muz. Bazıları sayılmaz: süt, ekmek, tereyağı, şeker. Bunların önüne a gelmez, sonuna s gelmez. «Biraz var» demek için some: There is some milk. Türkçede de «bir süt» demeyiz.

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There is some milk here. | Burada süt var. | some |
| There is some bread near the basket. | Sepetin yanında ekmek var. | some |
| There is some butter near the bowl. | Kasenin yanında tereyağı var. | some |
| There is some cheese here. | Burada peynir var. | some |
| There are some berries here. | Burada orman meyveleri var. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
Sayılmayan şeyle hep is: There is some milk. Türkçede «bir sürü süt» desek de are olmaz.

---

## 07 · some mı, any mi

**body**
some — bir şeyin olduğunu söylerken. any — var mı diye sorarken ya da yok derken. Türkçede any çoğu zaman «hiç» gibidir: «Hiç meyve suyu yok» — There isn't any juice. «Çorba var mı?» — Is there any soup?

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There is some milk here. | Burada süt var. | some |
| Is there any soup here? | Burada çorba var mı? | any |
| Are there any mushrooms here? | Burada mantar var mı? | any |
| There isn't any juice here. | Burada hiç meyve suyu yok. | any |
| There aren't any carrots here. | Burada hiç havuç yok. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.

**drill · choice**
- cümle: `Is there ___ rice near the pot?`
- seçenekler: `a` · `some` · `any`
- cevap: `any`
- neden: Pirinç var mı diye soruyorsun, bu yüzden any.

## 08 · «Yok»: There isn't, there aren't

**body**
Türkçede «yok» tek kelime, İngilizcede not eklenir: There is not → There isn't, There are not → There aren't. Tek şey için isn't a, birkaç şey için aren't any. There not ya da There is no demeyelim.

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There isn't a doorbell. | Zil yok. | isn't |
| There isn't an intercom. | Diyafon yok. | isn't |
| There aren't any handrails. | Hiç tırabzan yok. | aren't |
| There aren't any steps. | Hiç basamak yok. | aren't |
| There isn't a lawn behind the building. | Binanın arkasında çimenlik yok. | isn't |

**fix**
- ~~There not a doorbell.~~ → There isn't a doorbell.
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.

**drill · binary**
- soru: Kapıda zil yok. Nasıl söylersin?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- doğru: A
- açıklama: Zil tek, bu yüzden isn't.

## 09 · in, on, under — içinde, üstünde, altında

**body**
Türkçede «-de/-da» hem içi hem üstü söyler: lavaboda, tezgâhta. İngilizcede üç ayrı kelime. in — içinde: in the sink. on — üstünde: on the worktop. under — altında: under the doormat.

**examples** 🔊
| en | tr | hi |
|---|---|---|
| The lemon is in the sink. | Limon lavabonun içinde. | in |
| The bicycle is in the basement. | Bisiklet bodrumda. | in |
| The cups are on the worktop. | Fincanlar tezgâhın üstünde. | on |
| The plant is on the windowsill. | Çiçek pencere pervazında. | on |
| The key is under the doormat. | Anahtar paspasın altında. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

---

## 10 · next to, between … and, near, behind

**body**
next to — hemen yanında. near — yakınında. behind — arkasında. between … and — «… ile … arasında»; iki yer iki ayrı kelime: between the bank and the library. Araya virgül değil, and gelir.

**examples** 🔊
| en | tr | hi |
|---|---|---|
| The bench is next to the lamppost. | Bank lambanın yanında. *(oturulan)* | next to |
| The signpost is near the bridge. | Tabela köprünün yakınında. | near |
| The ladder is behind the shed. | Merdiven kulübenin arkasında. | behind |
| The bus stop is between the bank and the library. | Durak banka ile kütüphanenin arasında. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- cümle: `The bus stop is ___ the bank and the library.`
- seçenekler: `next to` · `behind` · `between`
- cevap: `between`
- neden: İki yer işareti var, durak ikisinin ortasında: between … and.

---

## 11 · There is mi, The … is mi

**body**
There is — bir şeyin var olduğunu haber verirken; karşındaki henüz bilmiyor. The … is — şey zaten tanıdıksa ve nerede olduğunu söylüyorsan. Türkçede de böyle: «Zil var» ile «Limon lavaboda».

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There is a car park near the hotel. | Otelin yakınında bir otopark var. | There is |
| The barrier is near the gate. | Bariyer kapının yanında. | The |
| There is a storeroom between the kitchen and the hall. | Mutfakla koridorun arasında bir kiler var. | There is |
| The coat rack is behind the door. | Askılık kapının arkasında. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- soru: Kız kardeşin ikinizin de bildiği limonu arıyor. Limon lavabonun içinde. Ne dersin?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- doğru: B
- açıklama: Limon zaten tanıdık, nerede olduğunu söylüyorsun: The lemon is in the sink.

## 12 · Kısa biçim: There's

**body**
Konuşurken There is hemen hemen hep There's olur: There's a cashpoint near the bank. There are böyle kısalmaz. «Yok» her zamanki gibi kısalır: isn't, aren't.

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There's a cashpoint near the bank. | Bankanın yanında bir bankamatik var. | There's |
| There's a postbox next to the gate. | Kapının yanında bir posta kutusu var. | There's |
| There's a vending machine in the hall. | Holde bir otomat var. | There's |

**tip**
Kısa «evet» kısalmaz: Yes, there is. Yes, there's değil.

## 13 · Neredeyse herkesin yaptığı hatalar

**fix**
- ~~Here is a pharmacy.~~ *(«burada var»)* → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
İki kontrol. Bir şeyin var olduğunu mu söylüyorsun, yoksa bildiğin bir şeyin yerini mi? «Var» — There is / There are. «Nerede» — The … is. İkincisi: tek mi, birkaç mı, yoksa tane tane sayılmayan bir şey mi?

## 14 · Alıştırmaya ne götürmelisin

**body**
«Var» — There is a… / There are… / There is some… «Var mı?» — Is there…? Are there any…? «Yok» — There isn't a… / There aren't any… Yer en sonda: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | tr | hi |
|---|---|---|
| There is a library nearby. | Yakında bir kütüphane var. | There is |
| Are there any mushrooms here? | Burada mantar var mı? | any |
| There aren't any steps. | Hiç basamak yok. | aren't |
| The cups are on the worktop. | Fincanlar tezgâhın üstünde. | on |
