# used_to_basic draft

Status: Jesse reworked.

Training id: `used_to_basic`
Category: `verb`
Priority: `44`

Single learner problem:
The learner sees "раньше / раніше" and chooses between `used to`, `before`, ordinary past, `didn't used to`, and `be used to` by surface memory instead of meaning.

Core contrast:
- `used to work` = old habit/state, different now.
- `didn't use to work` / `Did you use to work?` = after `did`, use `use to`.
- `am used to working` = accustomed now, not old habit.
- `I work now` = current habit, not `used to`.

What this training must not become:
- Not a broad Past Simple lesson.
- Not a full `would` vs `used to` lesson.
- Not a pronunciation or spelling lesson.
- Not the advanced accustomed-meaning lesson; `be used to` appears only as a contrast trap.

Learner-facing copy rule:
- RU/UK copy explains through meaning: `раньше, сейчас уже нет`, `раніше, зараз уже ні`, `я привык / я звик`.
- Avoid internal labels such as `subject`, `object`, `base verb`, `main verb`, `auxiliary`, and `modal`.
- Keep the live contrasts visible: `used to work`, `didn't use to work`, `Did you use to work?`, `am used to working`, `I work now`.

Required contract anchors:
- `used_to_easy_001`: wrong `use to` feedback mentions `used to`.
- `used_to_easy_002`: wrong `playing` feedback mentions `used to play`.
- `used_to_contrast_004`: wrong `used to` feedback mentions `didn't use to`.
- `used_to_mixed_003`: wrong `used to work` feedback mentions `work`.

Final learner outcome:
The learner can separate:
`I used to work` -> old habit, not true now
`I didn't use to work` -> negative after `did`
`Did you use to work?` -> question after `did`
`I am used to working` -> accustomed
`I work now` -> current habit
