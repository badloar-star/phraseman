## Дополнение 13.10: точность двух гейтов стор-экспорта (зона Ядра)

Первый настоящий стор-экспорт показал два ложных отказа:
- `[STORE-BUNDLE-DEV]`: «[DEV-STATE]» — общий префикс журналов в dev-ветках 58 боевых файлов; в .hbc остались 2 строки журналов
  (Карточки-сообщество, опрос настроек), сами dev-модули подменены заглушками. Правка: точная проверка по source map — настоящие
  модули из списка заглушек сборщика не должны быть среди источников бандла; карта обязательна (без неё — отказ с инструкцией).
  Байтовые маркеры `dev_vip_override`, `HUB-LIFECYCLE` остаются.
- `[DPK-GATE]`: экспорт кладёт в metadata.json только ресурсы из `assetPatternsToBeBundled` (app.config.js), поэтому «0 dpk»
  ничего не доказывает. Правка: в экспорте проверяется, что бандл регистрирует каждый пакет с хэшем текущего файла (md5 = hash
  registerAsset); встраивание в установочный файл — по-прежнему по манифесту релизной сборки.
Тесты: `node --test tests/store_bundle_dev_strings_gate.test.mjs tests/daily_phrase_dpk_assets_gate.test.mjs`.
