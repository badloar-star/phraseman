## 2. ЧТО СДЕЛАНО (с доказательствами)

### 2.1. Корневой баг «отвечаю только на первый вопрос» — ИСПРАВЛЕН
**Причина:** протухшее значение `secondsLeft = 0` переживало переход между
вопросами и ложно триггерило эффект таймаута, мгновенно «съедая» новый вопрос.

**Файл:** `app/tournament_round.tsx`
- В `goNext` добавлен сброс: `setSecondsLeft(null)`, `setPicked(null)`,
  `setFeedbackCorrect(null)`.
- В эффекте таймаута добавлена сверка с абсолютным дедлайном:
  `if (answerEndsAtMs !== undefined && tournamentNow() < answerEndsAtMs) return;`

**Доказательство:** живой лог на устройстве + контрактный тест
`«a stale zero on the task timer can never kill the next question»`.

### 2.2. Отсчёт 3-2-1 — ВОССТАНОВЛЕН

### 2.4. Кнопка «Готово» — УБРАНА
