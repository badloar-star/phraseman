# Английский · Урок 22 · Занятие 28 — Выбрать готовые продукты

**Ситуация.** Вы сравниваете продукты в магазине.

**Что вы освоите:** не повторять название вещи: this one, the red ones
**Новые слова:** ready-to-eat, freshly baked, pre-cooked, pre-sliced

## Интро 1

### Выбрать готовый салат

Продавец показывает салат, который ещё нужно приготовить, и готовый салат. Вы выбираете готовый. I want the ready-to-eat one — я хочу тот, который можно сразу есть. После I want ставим the, описание ready-to-eat и one. One заменяет salad: речь об одном салате. Описание перед one уточняет ваш выбор.

**Выберите фразу для этой ситуации.**

- ✅ **I want the ready-to-eat one.**
- ❌ I want the ready-to-eat ones. — *В этой ситуации название вещи заменяем one для одной вещи или ones для нескольких.*
- ❌ I want the ready-to-eat it. — *В этой ситуации название вещи заменяем one для одной вещи или ones для нескольких.*

## Интро 2

### Выбрать свежие булочки

В пекарне вы сравниваете вчерашние булочки со свежевыпеченными и говорите, какие вам нравятся. I like the freshly baked ones — мне нравятся свежевыпеченные. Сначала I like, затем the freshly baked ones. Ones заменяет buns в форме для нескольких. Freshly baked сохраняем перед ones, чтобы указать именно на свежие булочки.

**Выберите фразу для этой ситуации.**

- ✅ **I like the freshly baked ones.**
- ❌ I like the freshly baked one. — *В этой ситуации название вещи заменяем one для одной вещи или ones для нескольких.*
- ❌ I like the freshly baked them. — *В этой ситуации название вещи заменяем one для одной вещи или ones для нескольких.*

---

## Интро 3

### Выбрать нарезанную буханку

В магазине вам показывают целую и уже нарезанную буханку. Вы хотите нарезанную. I want the pre-sliced one — я хочу ту, которая уже нарезана. После I want ставим the pre-sliced one. One заменяет loaf — одну буханку, а pre-sliced описывает её. Здесь мы заменяем слово loaf, а не bread — хлеб не считают поштучно.

**Выберите фразу для этой ситуации.**

- ✅ **I want the pre-sliced one.**
- ❌ I want the pre-sliced ones. — *В этой ситуации название вещи заменяем one для одной вещи или ones для нескольких.*
- ❌ I want the pre-sliced it. — *В этой ситуации название вещи заменяем one для одной вещи или ones для нескольких.*
