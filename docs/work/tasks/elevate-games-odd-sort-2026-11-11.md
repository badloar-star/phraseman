# Task packet: перенос макетов Elevate — игры «Лишнее слово» и «Сортировка»

Governance-ID: TG-DC501950984C
Status: In progress
Owner: сессия макетов Elevate (владелец 11.11.2026: «самое главное — механики», «у тебя приоритет»)
Related epic/enabler: docs/work/tasks/elevate-game-flow-2026-11-11.md, D207

## Outcome

В приложении играются «Лишнее слово» и «Сортировка» по утверждённому макету
(`docs/design/v2-app/elevate-mechanics.app.js`, `cut()` и `sort()`): в первой игрок убирает лишнее слово из
фразы, видит перевод и объяснение, монета идёт по тропе; во второй смахивает фразу в одну из двух корзин.
Верный ответ даёт очки «Грамматики» по таблице навыков.

## Scope

In scope: новые `modules/games/odd_word_core.ts`, `modules/games/sort_core.ts`, их тесты, экраны
`app/game_odd_word.tsx`, `app/game_sort.tsx`.

Out of scope: наполнение игр по всем урокам и языкам; вход из разминки; общий экран итога.

## Architecture

Каждая игра — чистые правила плюс экран. Задания приходят в игру готовым списком (контракт `OddWordTask`,
`SortTask`), экран о происхождении заданий не знает — когда появится авторский банк по урокам, он подключается
без правки экранов.

## Security and privacy

Новых данных нет.

## Technical debt

- Accept temporarily: в играх лежат только утверждённые владельцем примеры из макета (4 и 6 заданий, английский,
  объяснения на русском). Владелец — эта сессия; выход — авторский банк заданий по урокам, отдельная задача с
  вычиткой текстов (правило владельца о дистракторах и «Библия текстов»); до него игры в разминку для других
  языков не включаются.

## Verification

`npm run test:one -- tests/game_odd_word_core.test.ts tests/game_sort_core.test.ts` через светофор; эмулятор и
склейка с макетом.

## Rollback

Удалить новые файлы; на игры никто не ссылается.

## Разминка на 4 минуты (11.11, тот же заход)

отметка «сыграно» по факту итога. Вход с Главной и из «Сегодня» — отдельным шагом после договорённости с сессией,
которая ведёт Главную. Architecture: состав и порядок игр — в одном модуле; сыгранное за день хранится в памяти
процесса. Technical debt (Accept temporarily, владелец — эта сессия, пересмотр при подключении входа с Главной):

ошибок за неделю» и плашки монет нет — пока разминка не собирается из ошибок и монет не даёт, экран этого не обещает.

## Подключение банка заданий к играм (11.11, вечер)

Governance-ID: TG-7971509D11F8

Outcome: игры берут задания урока, на котором сейчас человек, из банка `modules/games/bank/*` (английский, уроки
1–8, написан и вычитан сессией «Банк заданий для игр Elevate»); для языка, у которого заданий нет, игра в разминку

только его. Урок берётся из уже существующего снимка Главной в памяти (`peekHomeScreenHydration`), без диска и сети.
Security and privacy: новых данных нет.
Technical debt (Contain): для уроков старше восьмого берутся задания восьмого урока; для курсов, кроме английского,
доступен только «Поток». Выход — расширение банка.
Verification: `tests/game_task_source.test.ts`, узкая проверка типов. Rollback: вернуть экранам константы-примеры.

## Ответы владельца 11.11 (вечер): игры на всех языках, очки двух игр, место блока, строка на Главной

Governance-ID: TG-BC175D5DC85B

Решения: (1) «Собери диалог» к слуху не относится («слух тут при чём?») — обе игры на диалогах дают «Грамматику» +2;
(2) «оно должно работать на всех языках» — банк заданий нужен для каждого курса (en, es, de, fr, it), а не только для
английского; (3) блок «Навыки» в статистике — как в макете, после «Твоей недели»; (4) строка разминки на Главной —
да, после проверки на телефоне.
Scope этого шага: `modules/games/bank/index.ts` (реестр банков по языкам), `modules/games/task_source.ts` (берёт банк
языка обучения из реестра), `modules/skills/skill_points_table.ts` (две строки: `hunt_correct`, `order_correct` →
«Грамматика» +2), `modules/games/warmup_state.ts` (навык игры «Собери диалог»), экраны двух игр (начисление),
`app/streak_stats.tsx` (перенос одной вставки), тесты. Банки es/de/fr/it пишут отдельные сессии в
`modules/games/bank/*_<язык>.ts` и добавляют одну запись в реестр.
Architecture: реестр `GAME_BANKS[язык]` — единственное место, где язык связывается с заданиями; подбор и разминка
работают одинаково для любого языка. Security and privacy: новых данных нет.
Technical debt (Contain): подписи заданий («Что прозвучало?», названия корзин, объяснения) в банке написаны на русском —
для других языков интерфейса их нужно переводить; выход — отдельная задача переводов банка.
Verification: тесты подбора и банка, узкая проверка типов и оформления через светофор. Rollback: вернуть коммиты.
