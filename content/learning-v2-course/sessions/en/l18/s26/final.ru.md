# Английский · Урок 18 · Занятие 26 — Подобрать детали для дома

**Ситуация.** Вы проверяете, подходит ли вещь для конкретной задачи.

**Что вы освоите:** too + adjective; adjective + enough
**Новые слова:** door lock, window lock, window handle, spare part

## Интро 1

### Объяснить, почему замок не подходит

Вы принесли новый дверной замок, но его корпус не помещается в подготовленное отверстие. This door lock is too large — этот дверной замок слишком большой. После This door lock is поставьте too large. Too стоит перед large и показывает, что размер мешает установке. Вы говорите не просто о большом замке, а о превышении подходящего размера.

**Выберите фразу для этой ситуации.**

- ✅ **This door lock is too large.**
- ❌ This door lock is large too. — *Правильный порядок: too large.*
- ❌ This door lock is large enough. — *По ситуации требуется too large: условие либо мешает, либо выполнено.*

## Интро 2

### Передать оценку мастера

Мастер проверил оконный замок и сказал, что его прочности хватает для предусмотренной задачи. Вы пересказываете эту оценку: This window lock is strong enough — этот оконный замок достаточно прочный. Сначала This window lock is, затем strong enough. Enough после strong показывает, что нужная степень прочности достигнута.

**Выберите фразу для этой ситуации.**

- ✅ **This window lock is strong enough.**
- ❌ This window lock is enough strong. — *Правильный порядок: strong enough.*
- ❌ This window lock is too strong. — *По ситуации требуется strong enough: условие либо мешает, либо выполнено.*

## Интро 3

### Выбрать удобную ручку

Вы берётесь за оконную ручку: ладонь удобно помещается, длины ручки хватает. This window handle is long enough — эта оконная ручка достаточно длинная. Назовите ручку: This window handle, затем поставьте is. В конце long enough: сначала прилагательное long, после него enough. Так вы сообщаете, что ручка подходит по длине.

**Выберите фразу для этой ситуации.**

- ✅ **This window handle is long enough.**
- ❌ This window handle is enough long. — *Правильный порядок: long enough.*
- ❌ This window handle is too long. — *По ситуации требуется long enough: условие либо мешает, либо выполнено.*
