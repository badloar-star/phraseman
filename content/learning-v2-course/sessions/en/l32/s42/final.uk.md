# Урок 32 · Заняття 42 — Відчиняємо кімнату для гостей

**Ситуація.** Ви з Анною готуєте кімнату для гостя.

**Що ви опануєте:** пояснювати припущення, відкидати неможливий варіант і уточнювати предмет.
**Нові слова:** —
**Повторюємо знайомі слова:** window, bed, blanket, room

## Інтро 1

### Спостереження й можливість

На склі краплі води. Ви припускаєте, що скло холодне, але ще не торкалися його. The window is wet, so it might be cold. — Вікно мокре, тому воно, можливо, холодне. Складіть The window is wet + so + it might be cold. До so назвіть спостереження, після so — можливий висновок із might. Перед станом cold потрібна зв’язка be.

**Виберіть фразу для цієї ситуації.**

- ✅ **The window is wet, so it might be cold.**
- ❌ The window is wet, so it might is cold. — *Після might використовуємо be.*
- ❌ The window is wet, so it might to be cold. — *Після might не ставимо to.*

---

## Інтро 2

### Цей варіант виключений

Анна вважає, що на ліжку нічого немає, але ви бачите на ньому велику валізу. The bed can't be empty. — Ліжко не може бути порожнім. Складіть The bed + can’t + be + empty. Спостереження виключає названий стан. Can’t виражає цей висновок; перед empty тут потрібна зв’язка be.

**Виберіть фразу для цієї ситуації.**

- ✅ **The bed can't be empty.**
- ❌ The bed can't is empty. — *Після can’t використовуємо be.*
- ❌ The bed can't to be empty. — *Після can’t не ставимо to.*

---

## Інтро 3

### Уточнюємо предмет

Ви показуєте Анні предмет й уточнюєте свою дію з ним: The blanket I washed is dry. — Ковдра, яку ви випрали, суха. Складіть The blanket + I washed + is dry. Частина I washed уточнює blanket. That можна опустити: I вже називає того, хто виконав дію.

**Виберіть фразу для цієї ситуації.**

- ✅ **The blanket I washed is dry.**
- ❌ The blanket I washed it is dry. — *Не повторюємо названий предмет займенником it.*
- ❌ The blanket I washing is dry. — *Потрібна минула форма washed.*
