# Экран «Активность за год» как в макете (results-009, владелец 13.10, вопрос 17, до 16.10)

Governance-ID: TG-8310FD2F5782
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора от владельца)

## Outcome
Тап по маленькой полоске «Год» внутри «Серии и статистики» открывает отдельный экран `/year_activity` по образцу `docs/design/v2-app/results.html` (телефон 9/14, results-009): кнопка назад и заголовок «Активность за год», карточка «365 дней · Практика по календарю» с пилюлей года, большая сетка дней (13 колонок, квадратные клетки, как `.heatmap` макета), легенда «меньше … больше» и две строки «Фраз выучено» и «Время практики». Тап по клетке открывает прежнее окно месяца. Данные — те же, что рисует полоска (кэш `peekActivity365Analytics` и тот же `loadActivity365Analytics`), без новых запросов к базе. Логи `[YEAR-ACTIVITY]`.

## Scope
Новые: `app/year_activity.tsx` (экран), `app/year_activity_model.ts` (чистая модель сетки и итогов), тест `tests/year_activity_model.test.ts`. Правки: `components/ActivityHeatmap365.tsx` (тап по полоске → экран; экспорт `buildCanonicalYear`, `heatPalette`, `MonthExplorerModal`), `app/_layout.tsx` (одна строка `Stack.Screen`, только мой хунк через `--patch`), `app/product_analytics_screen_registry.ts` (имя экрана). Не трогаются: расчёт аналитики, облако, чужие экраны.

## Architecture
Модель: последние 365 дней, оканчивающиеся последним наблюдаемым днём (как у полоски), порядок «по строкам» по 13 в ряд; итоги — сумма `metrics.phrasesLearned` и `minutes`; год пилюли — год последнего дня. Экран: `ScreenGradient` + шапка с `ResultsGlassBackButton` + карточка «Тени» (`PlateFill`, без обводок), цвета клеток — `heatPalette` от акцента темы. Первый кадр из кэша (без спиннеров), затем тихое обновление тем же загрузчиком.

## Security and privacy
Только локальные агрегаты активности, уже показываемые полоской; новых данных и запросов нет, политика не меняется.

## Technical debt
Кнопка «назад» возвращает на «Серию и статистику» через `safeRouterBack`; карта месяцев (`MonthExplorerModal`) остаётся в файле полоски и импортируется экраном. Полоска за блоком Plus по-прежнему закрыта вуалью без Plus.

## Verification
Точечные тесты модели (13 колонок, 365 ячеек, итоги, год, форматирование времени) и контракта источника; проверка в эмуляторе по ссылке `/year_activity` и по тапу на полоске; Сверке — results-009 после коммита.
