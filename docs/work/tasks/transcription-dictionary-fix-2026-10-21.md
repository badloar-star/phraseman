## Outcome

Фразы из репортов показывают верную транскрипцию: In the driver's seat, Read between the lines,
Under the table, She uses apps. Слова, которые движок сейчас собирает по буквам неверно
(feet /fɪːt/, mouth /mæʊth/, than /thæn/, apps /æpps/, moon /mʊn/, calm /kælm/ и ещё ~60),
получают проверенную запись в словаре — словарь стоит раньше правил, поэтому неверная сборка
для них больше не срабатывает. Версия движка поднимается до 3, чтобы уже сохранённые карточки
с неверной записью перегенерировались один раз.

## Scope

In scope: только словарь `DICT` и число `TRANSCRIPTION_ENGINE_VERSION` в `app/transcription.ts`.

Out of scope: логика правил (`ruleBasedIPA`), код сохранения карточек, озвучка (битые mp3 —
отдельная задача координатора), полное пополнение словаря 572 словами.

## Architecture

No architecture change: только данные словаря и номер версии, предусмотренный файлом
(«Поднимай число при каждом изменении словаря или правил»).

## Security and privacy

Не применимо: новых данных не собираем.

## Technical debt

- Правила по буквам остаются и неверны для части слов вне словаря; полное решение — словарь из
  открытого произносительного словаря и отказ от правил. Передано координатору отдельно.
