# DEV_LINKS_P83 — кадры языка наборов на «Настройке» тренировки и «Из видео» (Дизайн, 12.10 ночь)

Документ ПИШЕТСЯ РУКАМИ (в отличие от `DEV_LINKS_R1.md`, который генерируется `scripts/dev_links_r1_generate.py`): здесь кадры, у которых нет отдельной строки реестра.
Строки с id реестра — `cards-027` (меню языка), `cards-080` («Из видео — Пока пусто»), `cards-030` («Из видео — ошибка»), `dialogs-005/017/018/036` — живут в генераторе (`scripts/dev_links_r1_steps_p83.py`) и в `DEV_LINKS_R1.md`.

Подмены **только в памяти процесса** (в стор-сборке заглушки, Firestore не трогается): `cardslangs=on|off` (`app/dev_fc_lang_state.ts` — списки наборов испанского [3: «Сохранённые» + 2 набора] и французского [2] рядом с английским из `cards=demo`) и `videopacks=empty|demo` (`app/dev_state_fixtures.ts` — ответ каталога роликов «Из видео»). Память живёт до перезапуска приложения — в КАЖДОЙ ссылке ставить `cardslangs=on|off` и `videopacks=…` явно, чтобы кадр не унаследовал прошлый. Карточки «чужих» наборов в хранилище не пишутся: сессия на языке наборов откроется с тем, что реально есть на устройстве; для кадра 5 важны маршрут (`?target=es`) и журнал `[FC-LANG-FILTER]`. Фикстуры `cards=demo` — только анонимный гость (правило 8 DEV_LINKS_R1).
Тема кадра: «Графит · Спокойно» (по умолчанию гостя); акцент мятный в образцах — это «Аврора · Максимум» (`theme=grad_aurora&level=1`, Темы 9f6d6220c).
