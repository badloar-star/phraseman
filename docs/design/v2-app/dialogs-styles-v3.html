Диалоги — пять стилей выбора

Владелец: «Лента не подходит — давай пять кардинально новых стилей». Здесь пять разных идей целиком, а не варианты карусели: Входящие (собеседники пишут тебе), Колода (одна карта за раз), Маршрут (путь по рангам темы), Афиша (сцены как плакаты), Город (темы — районы, диалоги — места). У каждого — первый взгляд → выбираю → начал.

Законы для всех: только цвета и оттенки текущей темы (переключатель — три темы приложения, цвета из их токенов), экран целиком без прокрутки на 390 × 844, «назад» слева сверху в одном месте, кнопки одного стиля V2, без текстур. Данные — из приложения: 76 диалогов (4 темы по 19), собеседники, цели, брифинги; пример — ранг 7, бесплатный тариф, 18 из 30 ответов.
