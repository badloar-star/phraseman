# Урок 27 · Заняття 24 — Пояснити самопочуття й домовитися про час

**Ситуація.** Ви описуєте відчуття, телефонуєте дізнатися час прийому й переносите зустріч із другом.

**Що ви опануєте:** сказати, що було б, якби…
**Нові слова:** groggy, dizziness, stiffness, numbness

## Інтро 1

### Якби був номер клініки

Ви хочете дізнатися години прийому в клініці, але не знаєте її номера. Поясніть другові: I would call the clinic if I had the number — я б зателефонував до клініки, якби мав номер. Would call — уявна дія; if I had the number — умова, яка зараз не виконується. Складаємо речення: I + would call + the clinic + if I had the number — хто, що зробив би, куди зателефонував би, за якої умови. Після would потрібна call; в умові ставимо had без would.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would call the clinic if I had the number.**
- ❌ I would called the clinic if I had the number. — *Після would потрібна форма call.*
- ❌ I would call the clinic if I would had the number. — *В умові тут had без would.*

---

## Інтро 2

### Чи є запис на сьогодні

Ви телефонуєте до клініки, щоб дізнатися, чи можна записатися на сьогодні. Запитайте: Is there an appointment today? — є запис на сьогодні? Is there починає запитання про наявність одного варіанта запису. Appointment починається з голосного звука, тому перед ним потрібне an. Складаємо речення: Is there + an appointment + today? — чи є, що саме, коли. Для одного appointment використовуємо is, а не are.

**Виберіть фразу для цієї ситуації.**

- ✅ **Is there an appointment today?**
- ❌ Are there an appointment today? — *Тут один час для запису: is there.*
- ❌ Is there a appointment today? — *Перед appointment потрібен an.*

---

## Інтро 3

### Коли телефонували до клініки

Друг запитує, коли ви телефонували до клініки. Це було вчора. Дайте відповідь: I called yesterday — я телефонував учора. Called — минула форма call із закінченням -ed. Yesterday називає завершений час, тому have не потрібне. Складаємо речення: I + called + yesterday — хто, дія в минулому, коли. Куди ви телефонували, уже зрозуміло із запитання.

**Виберіть фразу для цієї ситуації.**

- ✅ **I called yesterday.**
- ❌ I have called yesterday. — *Із yesterday тут called без have.*
- ❌ I call yesterday. — *Тут дія в минулому: called.*
