## Outcome

Решение координатора 18.10 по двум пробелам обхода Optimistic UI:
1. «Сохранить фразу» на экране ролика при лимите Free открывает окно оплаты, как у карточки из набора (закрытие окна закрывает только шторку, ролик остаётся). Тост лимита для Free убран; для Plus и прочих причин отказа тост остаётся.
2. Сохранённую фразу можно снять повторным тапом: закладка гаснет сразу, запись догоняет, при отказе закладка возвращается с тостом; один проход на фразу.

## Scope

In scope: `components/youtube/YoutubeVideoPhrases.tsx`, `components/SaveToCardsButton.tsx` (необязательный `onUnsave`), сторожа.
Out of scope: карточки из набора (уже сделано), серверная часть, перевод старого Диалога.

## Architecture

`SaveToCardsButton` получает необязательный `onUnsave`; без него поведение прежнее (сохранённая кнопка молчит). `YoutubeVideoPhrases.unsave`: оптимистично гасит закладку, ищет карточку `source: video_phrase` + `sourceId === phrase.id`, удаляет `removeFlashcard`, при сбое — откат + тост. Окно оплаты — тот же вход, что у карточки из набора: источник `video_card_save` (зарегистрирован в реестре), контекст `flashcard_limit`.

## Security and privacy

Новых данных не собирается; аналитика `paywall_shown` с тем же источником, что уже зарегистрирован.
