# Эталоны без системных текстов — аудит docs/design/v2-app (Макеты, 15.10)

Правило владельца 15.10: человеку не показываем технических фраз — провайдер, сервер, синхронизация, код ошибки,
«до ответа…», «нет соединения с сервером», английские идентификаторы. Поручение координатора: пройти все эталоны,
чистые замены в незапертых сделать, запертые — только в таблицу. Сверено с аудитом переводчика
`docs/work/tasks/no-system-texts-audit-2026-10-15.md`, чтобы код и эталон шли одинаково.

## Метод

- Все 105 страниц `docs/design/v2-app/*.html` отрендерены по очереди (один браузер). Текст взят только внутри телефонов:
  элементы размером с экран телефона. Подписи кадров и заметки для ревью вне телефона не считаются.
- Словарь: провайдер, сервер, синхрониз-, соединени-, код ошибки, токен, кеш/кэш, маркер, сборка, сервис, облако, сбой,
  «не удалось», «подождите», английские идентификаторы (snake_case, camelCase, `.tsx`, хеши), формы на «вы».
- 359 совпадений → разобраны вручную. Больше двух третей — подписи и заметки, попавшие в рамку колонки
  (`♪ v2/…`, `settings.tsx:1853`, «тост после отказа сервера»): игрок их не видит, не правились.

## E. Оставлено как есть

- «Не удалось связаться с магазином. Попробуй позже.» (пейвол) — магазин понятен; так же решил переводчик.
- «…ответ и правильная фраза отправятся на сервер — без имени…» (learn · 39) и согласие с OpenAI (settings-gaps · 16) —
  юридически обязательное раскрытие.
- «Не получилось сохранить его в облако…» (accounts-gaps · 4) — «облако» понятно; переводчик оставил так же.
- Журнал «Техническая диагностика» (settings-gaps · 38: `app_state · info`) — человек сам решает, прикладывать ли его в поддержку.
- «Не удалось загрузить / сохранить / отправить …» без технических слов — обычные человеческие ошибки.
- «demo_user_17» (overlays · 33) — пример ника в списке.
