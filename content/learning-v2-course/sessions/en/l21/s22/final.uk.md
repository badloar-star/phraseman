# Англійська · Урок 21 · Заняття 22 — Встигнути на зустріч

**Ситуація.** Ви готуєтеся до зустрічі й плануєте час на дорогу.

**Що ви опануєте:** verb + to-infinitive
**Нові слова:** run late, lose track of time, set an alarm, allow time

## Інтро 1

### Не запізнюватися

Run late — відставати від графіка, запізнюватися. У вас призначена зустріч, і ви не хочете затриматися. Часто можна почути I am running late — «Я запізнююся»; тут виражаємо небажання: I do not want to run late. Після want і need тут використовуємо to + початкову форму. I do not want to… виражає небажання, I need to… — необхідність. У сполученнях to run і to set не подвоюємо останньої літери: подвоєння є лише в running та setting.

**Виберіть фразу для цієї ситуації.**

- ✅ **I do not want to run late.**
- ❌ I do not want to running late. — *Тут після to потрібна початкова форма, без -ing.*
- ❌ I do not want to runs late. — *Після to не додаємо -s до дієслова.*

## Інтро 2

### Стежити за часом

Lose track of time — втратити відчуття часу, захопитися й не помітити, скільки часу минуло. Ви не хочете забути про зустріч за читанням. Set an alarm — поставити будильник, вибрати час сигналу. Після want і need тут використовуємо to + початкову форму. I do not want to… виражає небажання, I need to… — необхідність. У сполученнях to run і to set не подвоюємо останньої літери: подвоєння є лише в running та setting.

**Виберіть фразу для цієї ситуації.**

- ✅ **I do not want to lose track of time.**
- ❌ I do not want to losing track of time. — *Тут після to потрібна початкова форма, без -ing.*
- ❌ I do not want to loses track of time. — *Після to не додаємо -s до дієслова.*

## Інтро 3

### Урахувати дорогу

Allow time — передбачити час на щось. Ви плануєте зустріч і враховуєте, скільки триватиме дорога. Allow time for the journey означає залишити в плані достатньо часу на шлях. Після want і need тут використовуємо to + початкову форму. I do not want to… виражає небажання, I need to… — необхідність. У сполученнях to run і to set не подвоюємо останньої літери: подвоєння є лише в running та setting.

**Виберіть фразу для цієї ситуації.**

- ✅ **I need to allow time for the journey.**
- ❌ I need to allowing time for the journey. — *Тут після to потрібна початкова форма, без -ing.*
- ❌ I need to allows time for the journey. — *Після to не додаємо -s до дієслова.*
