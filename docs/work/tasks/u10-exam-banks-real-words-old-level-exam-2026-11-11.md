## Outcome

Три отдельных куска, три отдельных коммита.

- **А (пункт 5, «Заменить на настоящие слова»).** В зачёте урока (`app/exam.tsx`) и входном тесте (`app/diagnostic_test.tsx`)
  среди вариантов ответа нет выдуманных словоформ («wills», «haves», «cans», «should to»…). Вместо них — настоящее слово,
  неверное в этом слоте по правилу, либо в предложение добавлен контекст, который делает прежний настоящий вариант неверным.
  Мера успеха: в каждом задании ровно один подходящий вариант, дублей вариантов нет, id / порядок / число заданий прежние;
  новый сторож не пропускает несуществующую словоформу из найденного списка.
- **Б (пункт 4, «Удалить, если нигде не нужен»).** По коду доказано, есть ли хоть один живой путь на старый экран экзамена
  уровня (`app/level_exam.tsx`) и читает ли кто-то его банк. Нет — экран, банк и осиротевшие тесты удалены одним коммитом.
  Есть — ничего не удаляется, путь описан в отчёте.
- **В (пункт 1, «Да, перевести»).** Экзамен уровня английского собирает задания из фраз классического курса. Сначала разбор
  (источник фраз, уровни ↔ уроки, состав сохранённой попытки, число заданий с пропуском по уровням); правка — только если
  заданий хватает и сохранённые попытки совместимы, иначе цифры и варианты возвращаются владельцу.

## Scope

In scope:
- `app/exam.tsx`, `app/diagnostic_test.tsx` — только строки вариантов и, где нужно, текст вопроса (контекст);
- новый сторож `tests/u10_exam_banks_real_words_guard.test.ts`;
- `app/level_exam.tsx`, его банк и тесты — только после доказательства, что путей нет;
- `app/level_exam_blueprint.ts` и соседние чистые модули — для куска В, после разбора;
- отчёт и этот пакет.

Out of scope:
- поведение и вид экранов экзаменов (интерфейс не меняется);
- тексты фраз классических курсов (переозвучка не требуется);
- зачёты ES / DE / IT / FR и финальные экзамены — ими заняты другие сессии;
- файлы с чужими незакоммиченными изменениями: не трогаются, называются в отчёте.

## Architecture

А — правка данных в существующих банках, архитектура не меняется. Б — удаление мёртвого экрана вместе с его данными;
инвариант: ни один маршрут, диплинк, уведомление и восстановление попытки не ссылается на удаляемое. В — источник фраз
экзамена уровня меняется со старых данных урока на классический курс через существующий шов `app/classic_course_phrases.ts`;
инварианты: версия чертежа попытки повышается, чтобы начатые попытки пересобирались предсказуемо, а сданные результаты не
менялись; правило «ровно один доказуемо верный вариант» (`app/level_exam_gap_rules.ts`) остаётся единственным источником
заданий с пропуском.

## Security and privacy

Не затрагивается: учебные данные и локальная сборка заданий. Сбор, хранение и передача данных пользователя не меняются.

## Technical debt

- Contain: список выдуманных форм составляется просмотром всех вариантов двух банков; сторож закрепляет найденный список,
  но не умеет сам отличить выдуманное слово от настоящего — новый выдуманный вариант вне списка он не поймает.
- Contain (В): если на каком-то уровне классический курс даёт мало заданий с пропуском, правка не делается, решение за владельцем.
