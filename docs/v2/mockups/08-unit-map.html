Прогон состояний

Или руками: тап по пройденному узлу открывает лист с лучшим результатом, тап по текущему открывает превью с CTA «Начать», тап по приоткрытому следующему или по закрытому даёт мягкий отказ с подсказкой снизу. «Пройти сессию 7» = полный прогон: узел становится пройденным, звёзды летят в пилюлю юнита, золотая волна, узел 8 становится текущим, узел 9 впервые приоткрывается.

Спецификация для RN (Reanimated 4)

Вход узлов тропы: каскад40 мс · spring ui (d18 s280)
Пульс текущего узлаuse_runtime_active · freeze-контракт
Пресс узла (3D-кромка)120 мс · вибро
Отказ закрытого/следующего узла220 мс · scale 0.96, без тряски
Подсказка-отказ: слот снизу180 мс · fade + slide, высота зарезервирована
Нижний лист: раскрытие320 мс · spring (d22 s280)
Переход в пройденный + звёзды420 мс узел · 700 мс ×3 звезды · тик-хаптик
Золотая волна на завершении700 мс · перелив по экрану
Разблокировка следующего узла420 мс · поп-спринг после волны, на текущем и на новом next
Бамп пилюль юнитаspring micro · scale 1.16
Только transform / opacity (UI-тред). Направление пути читается плотностью тропы и контрастом состояний узлов (без соединительной линии, правка владельца). Скролл-зона: нативный overflow, скроллбар скрыт. Лист использует нативный bottom sheet на RN (переиспользуемый компонент), здесь - DOM-эквивалент для витрины. Reduced motion: пульс выключен, узлы появляются сразу.
