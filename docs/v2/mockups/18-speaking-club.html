Тема приложения

Прогон состояний

Или руками: на брифе тапни по заголовку карточки «Полезные фразы», чтобы свернуть/развернуть (место в ленте сохраняется). В чате тапни микрофон: начнётся запись (амплитуда + таймер), повторный тап останавливает запись и открывает транскрипт-превью. В превью «Отправить» уходит в ленту, «Ещё раз» запускает перезапись, «Изменить» открывает правку текста (тогда голосовая звезда за ход не идёт). Кнопки по бокам мика: «Фразы-опоры» разворачивает опорные фразы, «Текстом» открывает typed fallback (тоже без голосовой звезды).

Только transform / opacity (UI-тред). Reduced motion заменяет перелёты и «печатает» на мгновенную замену/статичное состояние; looping-пульсы выключены. Waveform скрыт от accessibility tree: вместо неё объявляется «Идёт запись, N секунд» (см. 04, Accessibility CaptureCard).

Политика звёзд SB-12 (04 · Star policy)

Звезда 1: ходы пройденызавершены нужные ходы, voice/text не важно
Звезда 2: цели достигнутыкоммуникативные цели выполнены
Звезда 3: голосом, без правокот двух уверенных неотредактированных voice-ходов
typed / learner_editedзакрывает цели, третью звезду не даёт
UNCERTAIN / шумнейтрально, бесплатный retry, без штрафа
В проде: ответ партнёра формируется как AI-генерация по тексту транскрипта пользователя (LLM), а не заготовленный скрипт. Распознавание речи выполняется только on-device (expo-speech-recognition), сопоставление цели работает через speaking_word_match локально. Аудио пользователя не покидает устройство ни на одном шаге; на сервер (если используется генерация ответа) уходит только текст распознанного транскрипта, никогда не сама запись. В этом макете партнёр отвечает по сценарию (заготовленные реплики): это допущение витрины, а не описание финальной архитектуры.
