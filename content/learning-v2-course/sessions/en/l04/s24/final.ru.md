# Английский · Урок 4 · Занятие 24 — Завтрак перед бассейном

**Ситуация.** Перед походом в бассейн вы с другом проверяете продукты: что есть к завтраку и что останется для супа на обед. Нужно спрашивать и о напитках, и об отдельных овощах.

**Что вы освоите:** спросить о йогурте и повторить some/any с продуктами из главы
**Новые слова:** yoghurt

---

## Интро 1

### Йогурт

`yoghurt` — «йогурт». Когда говорим о продукте вообще: `There is some yoghurt` — «Есть немного йогурта». Здесь не считаем баночки: начало — `There is`, перед `yoghurt` не нужно `a`. Даже большая миска не требует `are`. Ложка побольше, возможно, понадобится.

**Спросите «Здесь есть йогурт?» с `any`.**

- ✅ **Is there any yoghurt here?**
- ❌ Are there any yoghurt here? — *О йогурте как продукте спрашиваем `Is there`.*
- ❌ Is there a yoghurt here? — *Здесь не спрашивают об отдельной порции или баночке: нужно `any yoghurt`.*

---

## Интро 2

### Что осталось на кухне

`milk` — «молоко», `soup` — «суп», `juice` — «сок», `cheese` — «сыр». О продуктах, без подсчёта порций: `There is some milk` — «Есть немного молока». Вопрос: `Is there any cheese?` — «Есть ли сыр?» Напротив, `berry` — одна ягода, `berries` — несколько: `Are there any berries?` — «Есть ли ягоды?»

**Вы нашли немного супа. Сообщите об этом с `some`.**

- ✅ **There is some soup.**
- ❌ There are some soup. — *О супе как еде говорим `There is some soup`.*
- ❌ There is a soup. — *Здесь речь о продукте вообще: `some soup`.*

---

## Интро 3

### Овощи и планы

`mushroom` — «гриб», `mushrooms` — «грибы»; `carrot` — «морковка», `carrots` — «морковь, несколько морковок». `Are there any carrots?` — «Есть ли морковь?» Для супа нужно проверить продукты, а для прогулки — место: `swimming pool` — «бассейн». `Is there a swimming pool here?` — «Здесь есть бассейн?» Перед одним бассейном `a`, перед несколькими морковками — `any`.

**Спросите, есть ли здесь бассейн.**

- ✅ **Is there a swimming pool here?**
- ❌ Are there a swimming pool here? — *Один бассейн: `Is there a swimming pool here?`.*
- ❌ Is there swimming pool here? — *Перед одним бассейном нужно `a`.*
