## Outcome

Чистая функция learningV2UpcomingCoursePhrasesV1 отдаёт 3–4 пары { en, translation } из ближайших непройденных уроков курса
пользователя, начиная со следующего урока; только выпущенные уроки (манифест бандла), только локально (без сети и Firestore),
синхронно. Нечего показать (курс пройден, нет данных, язык интерфейса без перевода) → пустой массив, блок скрывается.
Журнал [PAYWALL-M-PHRASES]: откуда фразы, сколько, причина пустого ответа.

## Scope

modules/learning-v2/content/paywall_upcoming_phrases_v1.ts, тест tests/paywall_upcoming_phrases_v1.test.ts. Экраны не трогаю.

## Architecture

Источник пары — карточка «Скажи так» вступления занятия (learningV2IntroSayPartsForPageV1: phrase.text + phrase.meaning),
вступление читается ленивым require из манифеста (уже в бандле). По одной фразе из первого занятия каждого следующего урока;
если следующих уроков не хватает — из оставшихся непройденных занятий текущего урока. Перевод есть только ru/uk; другой язык
интерфейса — пусто (русский перевод испаноговорящему не показываем). Результат кешируется в памяти по (урок, занятие, язык).
