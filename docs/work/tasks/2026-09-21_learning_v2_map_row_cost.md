пустых мест нет. Подписи занятий под кружками убраны: остаётся чистая тропа

## Architecture
Корень найден по коду, а не по догадке: цена ОДНОЙ строки — 4
`useSharedValue`, 3 `useAnimatedStyle`, 2 эффекта с анимациями, SVG-дужка,
2 иконки и текстовый узел подписи. Всё это создаётся для КАЖДОГО узла, в том
числе для заблокированных, которые никогда не анимируются: гало нужно ровно
одному узлу из 2048, pop — только при смене состояния, нажатие — только
нажимаемым.

Две безопасные меры (решение владельца — «только безопасное»):
1. Узел создаёт анимации по потребности. Хуки нельзя вызывать условно,
   поэтому тяжёлую часть выносим в отдельный внутренний компонент, который
   монтируется только для узлов, которым он нужен. Неактивный узел остаётся
   статичной вёрсткой.
2. Подпись под кружком удаляется целиком. Минус текстовый узел на строку и
   минус 40px высоты строки (SESSION_LABEL_BLOCK) — на экран влезает больше
   строк при меньшей работе.

Осознанно НЕ делаем (владелец выбрал «только безопасное»): замену SVG-дужки
на слой фона и схлопывание кружка в один слой.
