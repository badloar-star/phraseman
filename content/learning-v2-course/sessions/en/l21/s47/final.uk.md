# Англійська · Урок 21 · Заняття 47 — Справи на кухні

**Ситуація.** Ви говорите про домашні справи до та після їжі.

**Що ви опануєте:** want / need + to-infinitive
**Нові слова:** set the table, do the washing-up, take out the rubbish, put the kettle on

## Інтро 1

### Накрити на стіл

Вечеря майже готова, але тарілки ще в шафі: I need to set the table — «мені потрібно накрити на стіл». Починаємо з I need, потім to set і the table. Після need дія приєднується через to; set залишається в початковій формі. Тут set the table означає підготувати стіл до їжі, тому вся фраза називає одну необхідну дію.

**Виберіть фразу для цієї ситуації.**

- ✅ **I need to set the table.**
- ❌ I need to setting the table. — *Після to у цій конструкції потрібна початкова форма.*
- ❌ I need for set the table. — *Після want або need перед дієсловом потрібне to, не for.*

---

## Інтро 2

### Помити посуд

Після вечері в мийці залишилися брудні тарілки: I need to do the washing-up — «мені потрібно помити посуд». Після I need ставимо to do. Саме do тут називає дію й залишається в початковій формі. The washing-up — назва домашньої справи, тому закінчення -ing усередині цього виразу зберігається: to do the washing-up, а не to doing the washing-up.

**Виберіть фразу для цієї ситуації.**

- ✅ **I need to do the washing-up.**
- ❌ I need to doing the washing-up. — *Після to у цій конструкції потрібна початкова форма.*
- ❌ I need for do the washing-up. — *Після want або need перед дієсловом потрібне to, не for.*

---

## Інтро 3

### Закип’ятити воду для чаю

До вас прийшов друг, і ви хочете приготувати чай: I want to put the kettle on — «я хочу поставити чайник». Після I want ставимо to put, потім the kettle та on. To пов’язує want із дією put, яка залишається без -ing. On наприкінці стосується ввімкнення нагрівання: йдеться про те, щоб закип’ятити воду.

**Виберіть фразу для цієї ситуації.**

- ✅ **I want to put the kettle on.**
- ❌ I want to putting the kettle on. — *Після to у цій конструкції потрібна початкова форма.*
- ❌ I want for put the kettle on. — *Після want або need перед дієсловом потрібне to, не for.*
