# Вопрос 18, вариант А — снять опросы осколков до выхода 2.0 (подготовлено Ядром 13.10, НЕ запускалось)

## Почему «снять сегодняшний» не работает
На боевом сервере ещё старый `getActiveShardSurvey` (без фильтра по языку — он придёт с 2.0, e4f45f8e3). Если выключить только
опрос дня из ротации, сервер уходит в старый режим `where('enabled','==',true)` и показывает любой другой включённый опрос — снова
по-русски. Поэтому вариант А = выключить **все** включённые опросы и вернуть их в день выхода. Цена: до выхода опрос с наградой
не видит никто (и ru/uk тоже).

Ротация на ближайшие дни (номера `survey_preset_NNN`): 13.10 — 48, 14.10 — 50, 15.10 — 53, 16.10 — 56, 17.10 — 58, 18.10 — 60,
19.10 — 61, 20.10 — 62.

## Команды (запускает владелец; читают `service-account.json`)

1. Просмотр, ничего не пишет: сколько опросов включено, у скольких нет es/en, сколько людей с испанским языком пушей.

```bash
node scripts/pause_shard_surveys_until_release.mjs
```

2. Снять (список сохраняется в `docs/phraseman-2.0/evidence/shard_survey_pause_list.json` ДО записи):

```bash
node scripts/pause_shard_surveys_until_release.mjs --write --confirm PAUSE_SHARD_SURVEYS_UNTIL_RELEASE
```

3. Вернуть — в день выхода, **после** выкладки функций опроса (шаг 13а плана):

```bash
node scripts/pause_shard_surveys_until_release.mjs --restore --confirm RESTORE_SHARD_SURVEYS_AFTER_RELEASE
```

Возврат включает только опросы из файла и только с пометкой `pausedForRelease`; тексты, ротация и `updatedAtMs` не меняются.

## Что видно без чтения ключей
Ничего о проде: число активных опросов и людей с испанским языком даёт только шаг 1 (его запускает владелец). По коду: в ротации 63
опроса; переводов es в черновике нет ни у одного (`shard_survey_translations_uk_en_draft.json` — только uk/en).
