# Статистика: тональная иерархия без обводок

## Цель

Вернуть читаемое разделение между экраном, основными карточками и внутренними плитками статистики, не возвращая декоративные рамки, blur или постоянную анимацию.

## Решение

Для статистики вводится отдельная палитра фона экрана по всем поддерживаемым темам. Она не меняет глобальные токены темы. Карточки по-прежнему используют существующий `bgCard`, но их тёмный scrim уменьшается только на экране статистики, чтобы оттенок карточки оставался видимым.

Иерархия: статичный фон страницы → более плотная основная карточка → существующие `bgSurface`-плитки. Для `businessLight` используется обратная, бумажная иерархия: слегка серый фон за белыми карточками.

## Границы

- Не меняются цвета других экранов и темы целиком.
- Не добавляются новые изображения, blur, анимации, тени или обводки карточек.
- Рамки состояний (выбор, фокус, ошибка) сохраняются.
- Аудит остальных декоративных обводок продолжается отдельными безопасными проходами по реестру.

## Проверка

Контракт проверяет наличие полной палитры на 10 тем, подключение палитры только к `streak_stats` и отсутствие декоративного `borderWidth` в обёртках карточек. Запускаются сфокусированные тесты статистики и строгий аудит обводок.
