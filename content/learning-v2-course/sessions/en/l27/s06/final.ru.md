# Урок 27 · Занятие 06 — Что будем есть

**Ситуация.** Вы выбираете обед, объясняете свои вкусы и обсуждаете ужин с другом.

**Что вы освоите:** if + past simple, would + base verb; past simple / present perfect
**Новые слова:** nutritious, appetizing, tasteless, sugary

## Интро 1

### Выбрать обед

Nutritious — питательный, содержащий полезные для организма вещества. I want a nutritious lunch — я хочу питательный обед. Appetizing — аппетитный, вызывающий желание поесть: That looks appetizing — это выглядит аппетитно. В британском написании встречается appetising; это то же слово. Вы бы готовили чаще, если бы было больше времени: I would cook more often if I had more time. Had после if обозначает воображаемое условие, would cook — результат.

**Выберите фразу для этой ситуации.**

- ✅ **I would cook more often if I had more time.**
- ❌ I would cooked more often if I had more time. — *После would нужно cook.*
- ❌ I would cook more often if I would had more time. — *В условии had без would.*

---

## Интро 2

### Рассказать о вкусе

Tasteless — безвкусный, почти без вкуса, когда речь о еде. This soup is tasteless — этот суп безвкусный. Это ваше впечатление о вкусе, а не сообщение о безопасности еды. Sugary — сладкий из-за сахара, с заметным количеством сахара. This drink is too sugary for me — этот напиток для меня слишком сладкий. For me показывает личное предпочтение. Друг предлагает лимон. I would add some lemon if I had one — я бы добавил немного лимона, если бы он у меня был. One здесь заменяет a lemon.

**Выберите фразу для этой ситуации.**

- ✅ **I would add some lemon if I had one.**
- ❌ I would adding some lemon if I had one. — *После would нужна форма add.*
- ❌ I would add some lemon if I would had one. — *После if здесь had без would.*

---

## Интро 3

### Кто сегодня готовит

I have made dinner — я приготовил ужин: сообщаем о результате сейчас. I made it yesterday — я приготовил это вчера: называем законченное время, поэтому made без have. Вы обсуждаете помощь на кухне: I would help you if I finished work earlier — я бы помог тебе, если бы заканчивал работу раньше. Finished здесь — воображаемое условие, а не обещание. Друг уже накрыл на стол. Это его любимая часть готовки: еда появляется, а кастрюли пока не его забота.

**Выберите фразу для этой ситуации.**

- ✅ **I made it yesterday.**
- ❌ I have made it yesterday. — *С yesterday здесь past simple.*
- ❌ I maked it yesterday. — *Прошедшая форма make — made.*
