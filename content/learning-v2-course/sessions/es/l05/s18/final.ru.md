# Испанский · Урок 5 · Занятие 18 — У неё есть книга

**Ситуация.** Обсуждаете с другом, какие вещи есть у Аны для поездки.
**Что вы освоите:** использовать ella tiene в рассказе о женщине.
**Новые слова:** —
**Повторяем знакомые слова:** ella, tener, libro, bolsa, llave.

## Интро 1

### Книга Аны

Вы уже говорите об Ане. Сообщите `Ella tiene un libro` — «У неё есть книга». Соберите `ella` + `tiene` + `un libro`. Ella означает «она». Для ella используем ту же форму tiene, что и для él: пол человека не меняет форму этого глагола.

**Речь об Ане. Скажите «У неё есть книга». Начните с Ella tiene.**

- ✅ **Ella tiene un libro.** — *Ella сочетается с tiene.*
- ❌ Ella tienes un libro. — *Tienes — для «ты»; с ella нужно tiene.*
- ❌ Ella tengo un libro. — *Tengo — для «я»; здесь ella tiene.*

## Интро 2

### Сумка Аны

Друг ищет сумку для покупок. Вы вспоминаете, что у Аны есть сумка, и говорите `Ella tiene una bolsa` — «У неё есть сумка». Соберите `ella` + `tiene` + `una bolsa`. Una выбираем по слову bolsa, а не потому, что владелец — женщина. С libro у той же Аны было un libro.

**Речь об Ане. Скажите «У неё есть сумка». Начните с Ella tiene и используйте bolsa.**

- ✅ **Ella tiene una bolsa.** — *Una согласуется с bolsa.*
- ❌ Ella tiene un bolsa. — *Bolsa женского рода: una.*
- ❌ Ella tengo una bolsa. — *С ella нужна форма tiene.*

## Интро 3

### Ключ Аны

Перед выходом друг спрашивает про ключ Аны. Скажите `Ella tiene una llave` — «У неё есть ключ». Соберите `ella` + `tiene` + `una llave`. Llave — женского рода в испанском, поэтому una. Порядок остаётся прежним: о ком говорим, затем tiene, затем название вещи с артиклем.

**Речь об Ане. Скажите «У неё есть ключ». Начните с Ella tiene.**

- ✅ **Ella tiene una llave.** — *Ella + tiene + una llave.*
- ❌ Ella tiene un llave. — *Llave женского рода: una.*
- ❌ Ella tienes una llave. — *С ella нужно tiene, без s.*

## Практика · 12 заданий

**1 · Послушайте и выберите слово**
🔊 *ella*
→ **ella** · él
- él — *Звучит ella — «она».*

`Ella ___ un libro.`
→ **tiene** · tienes · tengo
Полная фраза: **Ella tiene un libro.**
- tienes — *Для ella нужна форма tiene.*
- tengo — *Tengo относится к «я»; здесь ella tiene.*

Плитки: `libro` · `ella` · `un` · `tiene` · `tengo`.

*Плитка `tengo` лишняя: с ella нужно tiene.*
