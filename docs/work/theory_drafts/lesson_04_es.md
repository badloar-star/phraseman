# Teoría · Lección 4 del curso nuevo — «There is, there are, some, any, in, on, under» (ES)

> Sesión «12 · ТЕОРИЯ», 21.10.2026. Secciones 01–14, frases en inglés y ejercicios como en
> `lesson_04_ru.md`. Las trampas del español: «hay» sirve para una cosa y para muchas (→ There is
> banks); «Hay leche» no lleva some (→ There is milk); «¿Hay sopa?» → There is soup?; «hay» no es
> «es/está» (→ Is a pharmacy here); y «en la mesa» = on the table, no in (en = in y on). Tratamiento: tú,
> español neutro latinoamericano. Necesita revisión de un nativo.

**Título de la pantalla:** Teoría · Qué hay dónde

---

## 01 · Qué vas a aprender a decir *(abierta al inicio)*

**body**
En esta lección aprendes a contar qué hay dónde: «cerca hay una farmacia», «en el refrigerador hay leche», «no hay timbre», «la llave está debajo del felpudo». La frase nueva clave es There is: en español es el «hay».

**examples** 🔊
| en | es | hi |
|---|---|---|
| There is a pharmacy here. | Aquí hay una farmacia. | There is |
| There is some milk here. | Aquí hay leche. | some |
| Is there a toilet here? | ¿Hay un baño aquí? | Is there |
| There isn't a doorbell. | No hay timbre. | isn't |
| The key is under the doormat. | La llave está debajo del felpudo. | under |

---

## 02 · There is — «aquí hay» *(abierta al inicio)*

**body**
Para decir que algo existe en un lugar, empieza con There is. En español basta «hay», pero en inglés no se puede empezar con Is: Is a pharmacy here suena mal. Se dice There is a pharmacy here, y el lugar va al final.

**formula**
`There is` · `a + cosa` · `dónde`

**examples** 🔊
| en | es | hi |
|---|---|---|
| There is a pharmacy here. | Aquí hay una farmacia. | There is |
| There is a library nearby. | Cerca hay una biblioteca. | There is |
| There is a bakery here. | Aquí hay una panadería. | There is |
| There is an office upstairs. | Arriba hay una oficina. | There is |
| There is a clinic inside the building. | En el edificio hay una clínica. | There is |

**fix**
- ~~Is a pharmacy here.~~ → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There aquí no significa «allí». Es solo el comienzo de «hay». Por eso There is a pharmacy here es «aquí hay una farmacia», y there y here no se pelean.

---

## 03 · There are — cuando son varios

**body**
Si hay varias cosas, en vez de is se pone are, y la palabra lleva s: There are banks here. En español «hay» no cambia, en inglés sí. Y, como en la lección 3, con varias cosas no se pone a.

**formula**
`There are` · `cosas + s` · `dónde`

**examples** 🔊
| en | es | hi |
|---|---|---|
| There are banks here. | Aquí hay bancos. | There are |
| There are museums nearby. | Cerca hay museos. | There are |
| There are bridges nearby. | Cerca hay puentes. | There are |
| There are quiet streets here. | Aquí hay calles tranquilas. | There are |
| There are parks nearby. | Cerca hay parques. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- frase: `There ___ museums nearby.`
- opciones: `is` · `are` · `am`
- respuesta: `are`
- por qué: Son varios museos, así que There are.

---

## 04 · El lugar, al final

**body**
En español el lugar suele ir primero: «Detrás del edificio hay un jardín». En inglés va al revés: primero There is y la cosa, y al final dónde: There is a garden behind the building. Así dices primero qué hay y luego lo precisas.

**examples** 🔊
| en | es | hi |
|---|---|---|
| There is a garden behind the building. | Detrás del edificio hay un jardín. | behind |
| There is a bench near the garden. | Cerca del jardín hay una banca. | near |
| There is a church behind the bank. | Detrás del banco hay una iglesia. | behind |
| There is a market near the bridge. | Cerca del puente hay un mercado. | near |
| There is a lake behind the park. | Detrás del parque hay un lago. | behind |

**drill · word_bank**
- tarea: Dile a un amigo: «Detrás del parque hay un lago».
- respuesta: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- etiquetas: ninguna (la frase es larga y las pistas por ficha solo estorban)
- fichas de más: `are` · `in`

## 05 · Preguntar «¿hay?» y responder corto

**body**
Para preguntar si hay algo, cambia de lugar las dos primeras palabras: There is → Is there…? There are → Are there…? La respuesta corta: Yes, there is. No, there isn't. Yes, there are. No, there aren't.

**formula**
`Is there` · `a + cosa` · `dónde` · `?` — `Are there` · `cosas + s` · `dónde` · `?`

**examples** 🔊
| en | es | hi |
|---|---|---|
| Is there a dentist near here? | ¿Hay un dentista cerca de aquí? | Is there |
| Is there a toilet here? | ¿Hay un baño aquí? | Is there |
| Yes, there is. | Sí, hay. | there is |
| No, there isn't. | No, no hay. | isn't |
| Are there trams near the bank? | ¿Hay tranvías cerca del banco? | Are there |
| Yes, there are. | Sí, hay. | there are |
| No, there aren't. | No, no hay. | aren't |

**fix**
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

## 06 · Leche, pan, mantequilla: no se cuentan

**body**
Unas cosas se cuentan: un plátano, dos plátanos. Otras no: leche, pan, mantequilla, azúcar. Antes de ellas no va a, y al final no llevan s. Para decir «hay un poco» se pone some: There is some milk. En español «Hay leche» no necesita nada, en inglés sí.

**examples** 🔊
| en | es | hi |
|---|---|---|
| There is some milk here. | Aquí hay leche. | some |
| There is some bread near the basket. | Cerca de la canasta hay pan. | some |
| There is some butter near the bowl. | Cerca del tazón hay mantequilla. | some |
| There is some cheese here. | Aquí hay queso. | some |
| There are some berries here. | Aquí hay frutos rojos. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
Con lo que no se cuenta siempre va is, no are: There is some milk, aunque en español parezca que hay «mucha» leche.

## 07 · some o any

**body**
some se pone cuando dices que algo hay. any, cuando preguntas si hay o dices que no hay. En español casi nunca se traduce: «¿Hay sopa?» es Is there any soup? Y la pregunta no se arma con There is: There is soup? está mal.

**examples** 🔊
| en | es | hi |
|---|---|---|
| There is some milk here. | Aquí hay leche. | some |
| Is there any soup here? | ¿Hay sopa aquí? | any |
| Are there any mushrooms here? | ¿Hay hongos aquí? | any |
| There isn't any juice here. | Aquí no hay jugo. | any |
| There aren't any carrots here. | Aquí no hay zanahorias. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.
- ~~There is soup here?~~ → Is there any soup here?

**drill · choice**
- frase: `Is there ___ rice near the pot?`
- opciones: `a` · `some` · `any`
- respuesta: `any`
- por qué: Preguntas si hay arroz o no, así que any.

---

## 08 · «No hay»: There isn't, there aren't

**body**
Para decir que algo no hay, añade not: There is not → There isn't, There are not → There aren't. De una cosa — isn't a; de varias — aren't any. El «no hay» se arma con isn't o aren't, no con don't have.

**examples** 🔊
| en | es | hi |
|---|---|---|
| There isn't a doorbell. | No hay timbre. | isn't |
| There isn't an intercom. | No hay interfón. | isn't |
| There aren't any handrails. | No hay barandales. | aren't |
| There aren't any steps. | No hay escalones. | aren't |
| There isn't a lawn behind the building. | Detrás del edificio no hay césped. | isn't |

**fix**
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.

**drill · binary**
- pregunta: En la puerta no hay timbre. ¿Cómo lo dices?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- correcta: A
- explicación: El timbre es uno, así que isn't.

## 09 · in, on, under — en, sobre, debajo

**body**
in — dentro: in the sink, in the basement. on — encima, sobre una superficie: on the worktop, on the windowsill. under — debajo: under the doormat. Ojo: el español dice «en» para las dos. «En la mesa» es on the table, no in.

**examples** 🔊
| en | es | hi |
|---|---|---|
| The lemon is in the sink. | El limón está en el fregadero. | in |
| The bicycle is in the basement. | La bicicleta está en el sótano. | in |
| The cups are on the worktop. | Las tazas están en la mesada. | on |
| The plant is on the windowsill. | La planta está en el alféizar. | on |
| The key is under the doormat. | La llave está debajo del felpudo. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The cups are in the worktop.~~ → The cups are on the worktop.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

## 10 · next to, between … and, near, behind

**body**
next to — pegado, «junto a». near — cerca, «cerca de». behind — «detrás de». between … and — «entre … y …», son dos palabras para dos referencias.

**examples** 🔊
| en | es | hi |
|---|---|---|
| The bench is next to the lamppost. | La banca está junto al poste de luz. | next to |
| The signpost is near the bridge. | El letrero está cerca del puente. | near |
| The ladder is behind the shed. | La escalera está detrás del cobertizo. | behind |
| The bus stop is between the bank and the library. | La parada está entre el banco y la biblioteca. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- frase: `The bus stop is ___ the bank and the library.`
- opciones: `next to` · `behind` · `between`
- respuesta: `between`
- por qué: Hay dos referencias, el banco y la biblioteca, y la parada está en medio: between … and.

## 11 · There is o The … is

**body**
En español son dos palabras distintas: «hay» y «está». There is es «hay»: dices que algo existe y la otra persona aún no lo sabe. The … is es «está»: la cosa ya se conoce y dices dónde: The lemon is in the sink.

**examples** 🔊
| en | es | hi |
|---|---|---|
| There is a car park near the hotel. | Cerca del hotel hay un estacionamiento. | There is |
| The barrier is near the gate. | La barrera está cerca de la puerta. | The |
| There is a storeroom between the kitchen and the hall. | Entre la cocina y el pasillo hay una bodega. | There is |
| The coat rack is behind the door. | El perchero está detrás de la puerta. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- pregunta: Tu hermana busca el limón, del que las dos saben. Está en el fregadero. ¿Qué dices?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- correcta: B
- explicación: El limón ya se conoce y dices dónde está: The lemon is in the sink.

## 12 · La forma corta: There's

**body**
Al hablar, There is casi siempre se acorta a There's: There's a cashpoint near the bank. Con There are no se hace, y el «no hay» se acorta como siempre: isn't, aren't.

**examples** 🔊
| en | es | hi |
|---|---|---|
| There's a cashpoint near the bank. | Cerca del banco hay un cajero automático. | There's |
| There's a postbox next to the gate. | Junto a la puerta hay un buzón. | There's |
| There's a vending machine in the hall. | En el vestíbulo hay una máquina expendedora. | There's |

**tip**
El «sí» corto no se acorta: Yes, there is, no Yes, there's.

## 13 · Los errores que comete casi todo el mundo

**fix**
- ~~Is a pharmacy here.~~ → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
Dos preguntas. ¿Dices que algo hay o dónde está una cosa conocida? «Hay» — There is / There are. «Está» — The … is. Y la otra: ¿una cosa, varias, o algo que no se cuenta?

## 14 · Qué llevarte a la práctica

**body**
«Hay» — There is a… / There are… / There is some… «¿Hay?» — Is there…? Are there any…? «No hay» — There isn't a… / There aren't any… El lugar, al final: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | es | hi |
|---|---|---|
| There is a library nearby. | Cerca hay una biblioteca. | There is |
| Are there any mushrooms here? | ¿Hay hongos aquí? | any |
| There aren't any steps. | No hay escalones. | aren't |
| The cups are on the worktop. | Las tazas están en la mesada. | on |
