# Карточки эпизодов — разные оттенки темы (шаг по номеру эпизода)

Governance-ID: TG-19044DEC3BA6

## Outcome
Владелец утвердил хаб урока и сказал: «КАРТОЧКИ ДОЛЖНЫ БЫТЬ РАЗНЫХ ОТТЕНКОВ ТЕМЫ». Соседние карточки эпизодов теперь заметно различаются светлотой и насыщенностью при одном оттенке темы (шаг светлоты ≥ 0,05 между соседними номерами). Белый текст остаётся ≥ 4,5.

## Scope
In scope: `season_art.ts` (`SEASON_EPISODE_STEPS`, `seasonThemedArt`), тест `season_theme_colors_contract.test.ts`.
Out of scope: экран хаба урока (2 · ДИЗАЙН), веер.

## Architecture
Период 6 эпизодов: «темнее на» 0 / 0,05 / 0,10 / 0,03 / 0,08 / 0,13 и насыщенность ×1 / 0,82 / 1 / 0,68 / 0,92 / 0,76; плюс малая добавка главы (0,01×(глава%3)) и множитель насыщенности главы. Номер берётся по модулю, функция детерминирована и кэшируется по (оттенок, глава, шаг, тема). API для 2 · ДИЗАЙН: `seasonThemedArt(hexHue(g.accent), chapterOrdinal, sessionOrdinal, g.isLight ? 'light' : 'dark', exam?)` → `{ from, to, glow }`.
