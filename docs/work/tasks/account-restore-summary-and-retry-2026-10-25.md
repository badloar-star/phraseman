## Architecture

Определения цифр — те же, что у экрана готовности к экзамену (`app/exam_readiness.ts`): «урок» = первый из 32 уроков,
где верных меньше 45 (все сданы — 32); «фразы» = сумма ячеек correct/replay_correct по 32 урокам (≤50 на урок);
«серия» = `progress.streak_count`. Флаг выкл → окно байт-в-байт прежнее (сторож aa_release_registration_restore_prompt).
Старый клиент лишнее поле ответа игнорирует.

## Security and privacy

Сводка возвращается только владельцу (auth uid → job → stableUid), только во время grace. Новых данных не собираем —
читаем уже хранимый прогресс. Политика покрывает (прогресс хранится и возвращается при восстановлении).
