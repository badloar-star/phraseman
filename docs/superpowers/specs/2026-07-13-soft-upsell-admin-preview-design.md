# Локальное превью мягких пейволов в админ-панели

Дата: 2026-07-13  
Статус: утверждено пользователем

## Цель

Добавить в существующую dev-only админ-панель приложения отдельный раздел «Мягкие пейволы». Администратор должен одним нажатием открыть и вручную посмотреть каждый из шести вариантов без прохождения реального пользовательского сценария.

## Границы

- Изменяется только нативная QA/админ-панель приложения.
- `admin/index.html`, Admin v2, Firebase Hosting и production Remote Config не изменяются.
- Превью не пишет в Firestore или AsyncStorage, не меняет флаги, cooldown, milestone и лимиты.
- Превью не отправляет продуктовую аналитику.
- Лимит AI-диалогов остаётся равным двум за всё время.

## Интерфейс

В главе «Премиум» появляется аккордеон «Мягкие пейволы» с кратким пояснением «Локальное превью — ничего не публикует».

Внутри находятся шесть строк с иконкой, понятным названием и описанием контекста:

1. После первого урока.
2. После восьмого бесплатного урока.
3. После недельного обзора.
4. После второго AI-диалога.
5. После серии занятий: 7 дней.
6. После повторных тренировок.

Нажатие на строку открывает модальное локальное превью с реальным компонентом `SoftContextualUpsellCard`. Заголовок, пояснение, CTA и назначение соответствуют выбранному контексту. Кнопка закрытия закрывает превью. CTA показывает нейтральное подтверждение выбранного назначения и не выполняет навигацию или покупку.

## Архитектура

- Новый изолированный компонент секции живёт в `components/admin_panel/sections/SoftUpsellPreviewSection.tsx`.
- Секция импортируется только из `app/_admin_settings_testers.tsx`; production-gate в `app/settings_testers.tsx` остаётся неизменным.
- Типизированный каталог шести preview-сценариев находится в отдельном dev-only helper `components/admin_panel/soft_upsell_preview_catalog.ts`, чтобы тестировать тексты и маршруты без рендера экрана.
- В `components/admin_panel/ui.tsx` добавляется только метаданные поиска/категории для нового section id.
- Для визуальной точности переиспользуется production-компонент карточки; бизнес-хук `useSoftUpsellOpportunity` не вызывается.

## Состояния и безопасность

- Одновременно открыто не более одного превью.
- Закрытие возвращает в тот же раздел без изменения состояния приложения.
- Превью работает без сети.
- Все кнопки имеют минимум 44 px, текстовые accessibility labels и понятные подписи.
- На яркой акцентной CTA используется тёмный текст через существующий `correctText`.
- В превью явно написано, что это локальная проверка и пользователи её не увидят.

## Проверка

- Контрактный тест подтверждает наличие всех шести сценариев и точные trigger/context/destination.
- Компонентный тест открывает каждый вариант и проверяет реальную карточку, закрытие и безопасный CTA.
- Контракт production-gate подтверждает, что новый раздел достижим только через `_admin_settings_testers.tsx`.
- Проверяются существующие тесты карточки и soft-upsell core.
- Выполняются ESLint и `git diff --check` для изменённых файлов.
- Выполняется визуальная проверка компактной и широкой ширины без горизонтального переполнения.

## Критерии готовности

- Все шесть вариантов доступны независимо.
- Для просмотра не нужно воспроизводить реальные уроки, streak, review, диалоги или тренировки.
- Ни одно действие превью не влияет на production-конфигурацию или пользовательские ограничения.
- Раздел находится в категории «Премиум», находится через поиск и использует существующую дизайн-систему админ-панели.
