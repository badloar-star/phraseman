# Learning V2 — обязательная новая лексика во всех неконтрольных сессиях

**Дата:** 2026-08-30  
**Статус решения:** `OWNER-APPROVED DESIGN`  
**Область:** все target-language курсы Learning V2; первая реализация — English Full B1, 32 урока × 56 сессий  
**Приоритет:** прямое решение владельца; заменяет прежние исключения `retrieval-only` для voice, listening, repair и других неконтрольных сессий

## 1. Решение владельца

Каждая неконтрольная сессия Learning V2 обязана вводить полезную новую лексику. Контрольные сессии не вводят новую лексику и проверяют только ранее введённый материал.

В каждом уроке:

- 56 сессий;
- контрольные сессии: `8 / 16 / 24 / 32 / 40 / 48 / 56`;
- 49 неконтрольных сессий обязаны иметь непустой `newLexicalSenseIds`;
- 7 контрольных сессий обязаны иметь пустой `newLexicalSenseIds`;
- повторение знакомых слов обязательно, но не заменяет новую лексику в неконтрольной сессии.

## 2. Цель

Курс одновременно развивает грамматику и системно расширяет словарь. Ученик не проводит восемь сессий с двумя одинаковыми фразами и не получает псевдоразнообразие из перестановки одних и тех же слов.

Новая лексика подчиняется грамматике текущего exact packet:

- каждое новое слово естественно образует фразу с текущей grammar operation;
- слово не добавляется ради счётчика;
- неизвестная будущая грамматика не используется ради удобной фразы;
- если полезную лексику нельзя встроить без нарушения prerequisite boundary, план получает `HOLD` и исправляется на верхнем уровне.

## 3. Нагрузка по типам сессий

Обязательный минимум — один новый lexical sense в каждой неконтрольной сессии. Планировочная цель зависит от реальной учебной нагрузки:

| Тип сессии | Новые senses | Требование |
|---|---:|---|
| введение или расширение грамматики | 2–3 | полезные слова, необходимые для разнообразных естественных примеров |
| guided application | 2–3 | новые слова плюс changed-context retrieval знакомых |
| diagnostic repair | 1–2 | новая лексика не заслоняет диагностируемую грамматическую ошибку |
| listening retrieval | 1–2 | новые слова заранее введены word-first и имеют подготовленное аудио |
| spoken production | 1–2 | новые слова введены до оцениваемого произнесения; голосовая часть использует уже встреченную форму |
| checkpoint | 0 | только ранее введённые grammar operations и lexical senses |

Числа выше — диапазоны учебного проектирования, а не разрешение механически добивать квоту. Каждая новая единица проходит semantic/editor review.

## 4. Word-first и scored-use

Каждый новый sense до первого оцениваемого применения получает:

1. blocking-карточку знакомства;
2. точное значение и ручную locale-native дефиницию во всех восьми интерфейсных локалях;
3. готовое аудио до начала сессии;
4. отдельные контакты `recognize → retrieve meaning → build/use form`;
5. не меньше трёх осмысленных контактов до scored-use;
6. будущие retrieval edges в изменённых контекстах.

Voice/listening-сессия может вводить новую лексику только до профильного listening/speaking этапа. Ученик не должен впервые узнавать слово одновременно с проверкой слуха или произношения.

## 5. Повторение и уникальность

- `newLexicalSenseIds` содержит только senses, которые не вводились раньше в курсе.
- Повтор ранее введённого sense записывается только в `retrievalLexicalSenseIds`.
- Каждый важный sense получает несколько отложенных retrieval edges.
- Повтор обязан менять контекст, уровень поддержки, modality или output demand.
- Идентичное повторение prompt, target и activity family запрещено.
- Одна и та же пара `exact target + activity family` не повторяется внутри сессии.
- Canonical examples неконтрольной сессии обязаны покрывать новые senses и не могут циклически состоять из двух фраз на все восемь сессий главы.

## 6. Контрольные сессии

Контрольная сессия:

- не вводит grammar operation;
- не вводит lexical sense;
- использует только material, впервые введённый до неё;
- проверяет changed-context transfer, а не копирует тренировочные prompts;
- может выбирать репрезентативный набор лексики главы, но coverage всей главы обеспечивается совокупностью retrieval edges, а не одной перегруженной проверкой.

## 7. Первая глава английского курса

Первая глава сохраняет атомарную грамматику `I + am`, но расширяет полезные дополнения вместо циклического повторения `I am here` и `I am ready`.

План:

| Сессия | Новая лексика | Роль |
|---:|---|---|
| 1 | `here`, `ready`, `fine` | первый контакт с `I + am` |
| 2 | `happy`, `sad`, `tired` | состояния и контраст значений |
| 3 | `busy`, `free`, `late` | доступность и ситуация |
| 4 | `hungry`, `thirsty`, `sick` | физическое состояние |
| 5 | `cold`, `hot`, `warm` | ощущение температуры |
| 6 | `calm`, `nervous`, `excited` | эмоциональное состояние и listening retrieval |
| 7 | `angry`, `scared` | word-first введение, затем spoken production вместе со знакомыми словами |
| 8 | нет | независимый checkpoint по ранее введённым словам |

Итого первая глава вводит 20 полезных lexical senses. Сессия 8 не показывает новые карточки и не использует неизвестные слова в вариантах, аудио или feedback.

## 8. Канонические пакеты и генератор

Exact packet обязан явно хранить:

- непустой `newLexicalSenseIds` для каждого non-checkpoint packet;
- `retrievalLexicalSenseIds` с конкретными ранее введёнными senses;
- session-specific `canonicalExamples`, которые покрывают новые senses;
- `activityPlan`, не полученный слепым `examples[index % examples.length]` без проверки разнообразия;
- changed-context independent probe;
- точную причину и роль каждого повторения.

Генератор не имеет права автоматически назначать слово только потому, что оно встретилось в старом candidate pool. Каждая first-introduction позиция является частью owner-reviewable curriculum body и влияет на canonical fingerprint.

## 9. Машинные gates

Новый fail-closed gate проверяет весь English blueprint:

1. ровно 32 урока, по 56 сессий;
2. `newLexicalSenseIds.length > 0` во всех 1 568 неконтрольных packets;
3. `newLexicalSenseIds.length === 0` во всех 224 checkpoints;
4. каждый sense имеет ровно одну first-introduction позицию;
5. ни один sense не объявлен новым после своей first-introduction;
6. каждое новое слово присутствует в canonical example своей сессии;
7. canonical examples не используют будущую grammar operation;
8. каждое новое слово имеет forward retrieval edge;
9. ни одна глава не циклирует один и тот же малый набор canonical examples через все восемь сессий;
10. checkpoint использует только ранее введённые senses;
11. owner map и canonical body имеют один fingerprint;
12. после изменения blueprint owner map обязательно пересобран.

Отдельный course-start gate проверяет точную сетку первой главы и минимум 20 уникальных lexical senses до Session 8.

## 10. Изменение fingerprint и статуса

Это решение меняет canonical curriculum body. Текущий fingerprint `3a4ca1422a6125bb317121c312c0166fdb595ee90111f297c480c8a82b7716e4` после реализации станет `SUPERSEDED`.

Новая сборка обязана:

1. получить новый fingerprint;
2. перейти в `OWNER REVIEW REQUIRED`;
3. пересобрать полный кликабельный owner map;
4. пройти structural, prerequisite, semantic, lexical-density и map gates;
5. не разрешать learner-facing authoring до явного owner approval нового exact fingerprint.

## 11. Non-goals

В этот пакет не входят:

- массовое написание learner-facing интро, упражнений, дистракторов и feedback;
- массовая генерация восьми локализаций карточек;
- TTS, deploy, publish или Firebase writes;
- изменение runtime UI;
- ослабление grammar-first, prerequisite, word-first или checkpoint contracts.

## 12. Критерии приёмки

Дизайн считается реализованным только когда:

- новый gate сначала воспроизводит текущий дефект и падает;
- после изменения canonical modules gate проходит;
- все 1 568 non-checkpoint packets содержат полезную новую лексику;
- все 224 checkpoint packets содержат ноль новой лексики;
- первая глава показывает 20 разных senses и разнообразные canonical examples;
- owner map отражает новые words, retrieval edges и новый fingerprint;
- aggregate blueprint gate остаётся `HOLD` только из-за ожидаемого `approval_pass=false`;
- новый exact fingerprint показан владельцу для отдельного утверждения.
