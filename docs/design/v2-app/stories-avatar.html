Сторис по аватару — события недели и серии

Окно итога недели (m01 / m02 / m03) по-прежнему показывается один раз при первом входе после закрытия недели (D191), и тот же итог параллельно попадает в сторис. Сам по себе не всплывает только сторис-просмотр: когда есть непросмотренное событие, вокруг аватара-монеты в шапке Главной — красное кольцо, как у сторис в Instagram. Тап по аватару открывает все события подряд: только то, что реально произошло. Полосы прогресса сверху, тап справа — дальше, слева — назад, удержание — пауза, свайп вниз — закрыть. Всё просмотрено — кольцо исчезает. Событий нет — кольца нет, тап ведёт туда же, куда сейчас (профиль). Монета — только валюта и аватар ранга.
