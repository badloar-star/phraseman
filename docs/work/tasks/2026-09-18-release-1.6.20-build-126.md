## Architecture

Изменений в коде нет — только номера версии. Важные связи, проверенные перед
правкой:

1. `runtimeVersion` поднимается ВМЕСТЕ с version каждый релиз (проверено по
   истории: 1.6.17 → 1.6.18 → 1.6.19 менялись парой). Он определяет, какие
   OTA-обновления совместимы с этой сборкой: оставить старый — значит пустить
   на новый бинарник обновления, собранные для предыдущего нативного кода.
2. `autoIncrement: false` в eas.json — номера ведутся руками, EAS их не
   подкрутит. Значит все три места обязаны быть подняты явно, иначе Apple
   отвергнет сборку с уже занятым buildNumber.
3. Профиль production несёт `EXPO_PUBLIC_STORE_RELEASE=1` и реальную
   аттестацию App Check у RevenueCat/Firebase — сборка идёт как магазинная.

## Security and privacy

Правка номеров не затрагивает данные, разрешения и сторонние сервисы. Состав
собираемых данных с прошлого релиза не менялся — политика приватности
обновления не требует (проверено отдельной задачей 2026-09-17 по рунам).

Публикация в App Store — необратимое внешнее действие, выполняется по прямому
указанию владельца в этом же ходу. Android намеренно без автоотправки: решение
о публикации остаётся за владельцем.

## Technical debt

- Гейт `update_release_gate.mjs` падает крашем V8 из-за проверки типов без
  увеличенной памяти, из-за чего push идёт с `--no-verify`. Disposition:
  **Accept temporarily**, owner: владелец. Exit condition: добавить
  NODE_OPTIONS в скрипт. Impact ceiling: гейт не защищает push, но сборку EAS
  это не затрагивает — там свои проверки.
- `package.json` держит version 1.5.53, рассинхронизирован с app.json (1.6.20).
  Disposition: **Accept temporarily** — на сборку не влияет, Expo читает
  app.json. Exit condition: отдельная задача по синхронизации.

## Rollback

Номера версий откатываются `git revert` коммита. Уже запущенные сборки EAS
отменяются в панели EAS (`eas build:cancel`), пока не завершились. Сборка,
ушедшая в App Store Connect, из TestFlight удаляется вручную — но это не
публикация в магазин: релиз в продажу требует отдельного действия владельца,
поэтому необратимого шага автосабмит не делает.
