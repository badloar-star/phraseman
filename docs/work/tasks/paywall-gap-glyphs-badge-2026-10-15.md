# Пейвол Plus: значки по эталону, плашка «Выгоднее всего» в одну строку с «Год» (15.10)

Governance-ID: TG-703D12758940

## Outcome
По замеру Сверки (paywall-gap-001/007/009/010/011) три отличия на стороне кода Дизайна: (1) плашка «Выгоднее всего» стоит под словом «Год», в эталоне — в одну строку; (2) значки: «место закончилось»/«собери набор» — стопка слоёв, «добавь фразу» — «+», в «что входит» у AI две искры, у заморозки — снежинка-звёздочка из эталона; (3) кнопка «✕» крупнее эталона. Приводим (1) и (2); по (3) проверяем размеры по коду.

## Scope
`components/paywall/PaywallPlus.tsx` (отступ и поля плашки), `components/paywall/PaywallContextIcons.tsx` (контуры трёх контекстов), `components/paywall/PaywallBenefitComparison.tsx` (две иконки списка выгод рисуются SVG по контурам эталона). Тон шторки и ручку не трогаем (решение Макетов).

## Architecture
Только вид: те же компоненты, меняются числа отступов и пути значков. Иконки — `react-native-svg`, уже подключённый в проекте; цвет из токенов темы.

## Security and privacy
Данные не затрагиваются.

## Technical debt
Значки эталона нарисованы вручную по мотивам Ionicons — отличия от стока остаются осознанными; когда Макеты перейдут на стоковые контуры, вернуть Ionicons.
