# Стиль «Тень» — контейнеры без обводок (решение владельца 12.10.2026)

Владелец выбрал вариант 2 из `no-borders-variants.html`: «ВТОРОЙ ВАРИАНТ ДЕЛАЕМ!». Эталон — `shadow-style-etalon.html` (Главная, Настройки, Диалоги, Карточки · хаб, Обучение; тёмная «Аврора» и светлая).

## Правило
Ни одного контейнера с обводкой (ни `borderWidth`, ни внутренней кромки `inset … spreadDistance:1`, ни `glassEdge`/`hairline` вокруг плашки). Плашку отделяют тень и мягкий блик-градиент сверху. Выбранное/главное — приподнято.

## Числа (CSS макета → React Native `boxShadow`)
| Слой | Тёмная | Светлая |
|---|---|---|
| Плашка, заливка | градиент 180°: белый 8,5% → 4% | градиент 180°: `#FFFFFF` → `#F3F3F8` |
| Плашка, тень | `0 16 28 −14` чёрный 75% | `0 14 26 −14` `rgba(40,40,80,.34)` + `0 1 3` 6% |
| Вложенное (плитка-иконка, кнопка внутри плашки) | тень `0 6 12 −6` чёрный 60% | `0 5 10 −5` `rgba(40,40,80,.28)` |
| Выбранное/главное: заливка | градиент белый 15% → 7% | `#FFFFFF` → `#F8F8FC` |
| Выбранное: тень и сдвиг | `0 26 40 −14` чёрный 90%, `translateY −3` | `0 26 40 −14` `rgba(40,40,80,.46)` + `0 2 4` 8%, `translateY −3` |
| Строки внутри групповой плашки | без своей плашки; разделитель между строками — тон `rgba(255,255,255,.07)` / `rgba(20,20,40,.06)` | то же |
| Кнопка действия | цвет темы + цветная тень `0 14 24 −10` цвет темы 60% | то же |

Отступ между плашками ≥ 10 — тень должна «дышать». Нижнее меню — плашка 64 с той же тенью; активная вкладка — тон + малая тень.

## Где менять в приложении (для Дизайна)
- `KitSurface`/`Sheen` (`components/cards-grid/CardsKit.tsx`) — убрать внутреннюю кромку, добавить тень и градиент по таблице; `PackRow`, `SettingsGlassGroup/Row`, `GlassAlertDialog`, плитки Главной, строки «Сегодня», плашки Диалогов и Обучения берут оттуда.
- `constants/liquidGlassThemePalette.ts` — токены `glassEdge`/`hairline*` для контейнеров больше не нужны; добавить токены тени (`dropShadow` есть) для светлой и тёмной.
- Тесты-сторожа обводок (design-guard, tests `*_liquid_glass_source_contract*`) — пересмотреть: «обводка запрещена везде», а не «разрешена тонкая» (исключение 2.0 от 24.09 для контейнеров снимается).

## Оговорки
- Тени дороже по отрисовке на слабых Android: на списках длиннее экрана — `renderToHardwareTextureAndroid`/без тени у элементов вне экрана, замерить.
- Выбранное приподнято сдвигом: в списках не менять высоту ряда (сдвиг только transform).
- Правка касается всех экранов — делать поэтапно, сверка по `shadow-style-etalon.html`.
