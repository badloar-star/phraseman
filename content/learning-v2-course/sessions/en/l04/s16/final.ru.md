# Английский · Урок 4 · Занятие 16 — Район с бассейном

**Ситуация.** Вы выбираете район для поездки: рассматриваете жильё, транспорт и места для занятий спортом. Друг сверяет карту с фотографиями, а вы уточняете, что здесь есть.

**Что вы освоите:** спросить о бассейне и вспомнить места и транспорт из главы
**Новые слова:** swimming pool

---

## Интро 1

### Два слова — один бассейн

`swimming pool` — «бассейн», место для плавания. Одно место — `a swimming pool`, несколько — `swimming pools`: окончание меняется у последнего слова. `Is there a swimming pool here?` — «Здесь есть бассейн?» Два слова не означают два бассейна: второй купальник пока не нужен.

**Спросите «Здесь есть бассейн?»**

- ✅ **Is there a swimming pool here?**
- ❌ Are there a swimming pool here? — *Один бассейн: `Is there a swimming pool here?`.*
- ❌ Is there swimming pool here? — *Перед одним бассейном нужно `a`: `a swimming pool`.*

---

## Интро 2

### Что есть в районе

`neighbourhood` — «район», `hotel` — «отель», `dentist` — «стоматолог». `This is a neighbourhood` — «Это район». `There is a hotel here` — «Здесь есть отель». `Is there a dentist here?` — «Здесь есть стоматолог?» Ещё два знакомых места: `laundrette` — «прачечная самообслуживания», `gym` — «тренажёрный зал».

**На схеме района вы нашли отель. Сообщите «Здесь есть отель».**

- ✅ **There is a hotel here.**
- ❌ There are a hotel here. — *Один отель: `There is a hotel here`.*
- ❌ Is there a hotel here? — *Это вопрос. Вы уже нашли отель и сообщаете: `There is`.*

---

## Интро 3

### Добраться и потренироваться

`tram` — «трамвай», `taxi` — «такси», `platform` — «платформа». Друг показывает на трамвай вдали: `That is a tram` — «То — трамвай». Вопрос о зале: `Is there a gym?` — «Есть ли тренажёрный зал?» О нескольких прачечных: `Are there laundrettes here?` — «Здесь есть прачечные самообслуживания?» Перед несколькими местами `a` не ставим.

**Спросите, есть ли здесь несколько прачечных самообслуживания.**

- ✅ **Are there laundrettes here?**
- ❌ Is there laundrettes here? — *`laundrettes` — несколько мест: `Are there`.*
- ❌ Are there a laundrettes here? — *Перед несколькими местами не нужно `a`.*
