# Удаление мёртвого settingsSurfaces.ts и перевод таблицы cardPackPaywallTheme на токены Liquid Glass

Governance-ID: TG-E29CF9A18BDB
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (решения координатора: п.1 — удалить модуль и его проверки; п.2 — перевести таблицу темы окна покупки набора на токены, вид окна не менять)

## Outcome
1) `components/settings/settingsSurfaces.ts` (30 литералов по прежним id тем, никем не импортируется) удалён вместе с проверками этого модуля в tests/sage_porcelain_surface_chrome_contract.test.ts; остальное содержимое теста остаётся. 2) `app/flashcards/cardPackPaywallTheme.ts` (65 литералов, таблица по прежним id тем) отдаёт цвета окна покупки набора из токенов Liquid Glass: тёмное/светлое оформление и любой оттенок ползунка. Внешний вид окна для нынешних тем фиксируется тестом-отпечатком ДО замены и после замены не меняется для них.

## Scope
Удаление файла и правка одного теста (отдельный коммит). Таблица cardPackPaywallTheme.ts и тест-отпечаток; экраны Карточек (CardPackShardPaywallModal.tsx, useCollectionData.ts) не трогаются — если без их правки нельзя, список уйдёт Дизайну.

## Architecture
Сперва отпечаток: тест вычисляет значения таблицы для всех нынешних тем (то, что видит человек сегодня) и пинит их. Затем таблица строится функцией от токенов (`liquidGlassTokens`), которая для тем со старыми id возвращает ТЕ ЖЕ значения (через сопоставление ролей токенов), а для новых/градиентных тем и светлого оформления — значения из токенов. Если точного соответствия роль→литерал нет, значение остаётся и помечается в отчёте.

## Security and privacy
Только цвета окна; покупка и данные не затрагиваются.

## Technical debt
Литералы, которые не выражаются токеном без смены вида, остаются с пометкой и причиной в отчёте.

## Verification
Тест-отпечаток (до/после), тесты Карточек (flashcards_* контракты по одному файлу), срез типов, ратчет цветов.
