# Англійська · Урок 22 · Заняття 27 — Обрати речі для дому

**Ситуація.** Ви читаєте описи посуду, одягу й рушників.

**Що ви опануєте:** determiner|adjective + one|ones
**Нові слова:** dishwasher-safe, microwave-safe, machine-washable, absorbent

## Інтро 1

### Тарілки для посудомийки

Dishwasher-safe — придатний для миття в посудомийній машині. Це опис на пакованні посуду. У прикладі кілька тарілок, тому ones замінює plates. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I want the dishwasher-safe ones.**
- ❌ I want the dishwasher-safe one. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I want the dishwasher-safe them. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*

## Інтро 2

Microwave-safe — придатний для мікрохвильової печі. Machine-washable — придатний для машинного прання, наприклад светр. Це різні властивості: перше стосується посуду для розігрівання, друге — речей, які перуть. В обох прикладах обираємо одну річ. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

## Інтро 3

### Рушники

Absorbent — такий, що добре вбирає вологу. Так описують рушники, губки чи серветки. У прикладі йдеться про кілька рушників: towels → ones. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones.
