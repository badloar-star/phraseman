# Знание о бизнесе для Джарвиса

Файлы этой папки читает Джарвис перед тем, как делать выводы. Здесь то, что
**нельзя посчитать** запросом к базе: что для нас важно, что уже пробовали,
чего делать нельзя и почему.

## Зачем это существует

До сих пор Джарвис знал только числа: сколько пользователей, сколько платящих,
как изменилась метрика. Он мог сказать «возвратов больше обычного», но не мог
знать, что возвраты в первые сутки — это норма для подписки с пробным периодом,
а на второй месяц — уже сигнал.

Числа без контекста дают уверенные, но бессмысленные советы.

## Почему текстовые файлы, а не база

Проверено на практике проекта: тот же приём уже работает для контент-конвейеров
и памяти между сессиями. Преимущества перед базой или графом знаний:

- **человек может открыть и прочитать** — видно, что именно знает Джарвис;
- **правится в редакторе** за минуту, без миграций и админки;
- **история в git** — видно, когда и почему поменялось решение;
- **не тонет**: департамент читает только свой файл, а не всё сразу.

Формальный граф знаний и семантический слой для этого масштаба избыточны.

## Формат файла

Каждый файл — одна тема. Структура жёсткая, чтобы Джарвис не гадал:

```markdown
# Название темы

## Что сейчас верно
Короткие утверждения, каждое отдельной строкой. Это то, на что опирается
Джарвис прямо сейчас.

## Почему так
Причины решений. Без них через полгода никто не вспомнит, зачем это правило,
и его отменят «как устаревшее».

## Чего делать нельзя
Явные запреты. Джарвис не должен предлагать то, что уже отвергнуто.

## Когда пересмотреть
Дата или условие. Без этого файл превращается в вечную истину, которой он
не является.
```

## Правила

1. **Одна тема — один файл.** Файл длиннее двух экранов пора делить.
2. **Устаревшее удаляется, а не копится.** Неверное знание хуже отсутствующего:
   на него опираются с той же уверенностью.
3. **Утверждение без причины — не знание, а суеверие.** Если непонятно, почему
   так, — либо выясните, либо не пишите.
4. **Числа сюда не пишутся.** Они приходят из базы и меняются каждый день;
   записанное здесь число устареет к завтрашнему утру и начнёт врать.
