## Outcome
- Герой «Сцены» на Главной (160 dp ≈ 480 px на экране 3×) грузится и декодируется из копии 512×512 вместо оригинала 1024×1024:
  вчетверо меньше пикселей на первом кадре, меньше памяти под картинку.
- Оригиналы владельца в assets/images/v2art/{dark,light}/home_scene_<state>.webp не трогаются; копии лежат рядом —
  assets/images/v2art/hero512/{dark,light}/ — с манифестом (sha256 оригинала и копии, размеры).
- Нет копии (владелец положил новый арт и не пересобрал) — сцена берёт оригинал 1024 и пишет причину в журнал [HOME-HERO];
  сторож при этом красный и называет файл и команду пересборки.

## Команда пересборки
- node scripts/gen_home_hero_512.mjs — пересобрать копии 512, манифест и реестр components/home/v2/scene/home_scene_hero512.generated.ts
- node scripts/gen_home_hero_512.mjs --check — только проверить, что всё актуально (ничего не пишет; код выхода 1 при расхождении)
- Порядок, когда владелец кладёт новый 1024: сначала node scripts/gen_themed_art_assets.mjs (реестр оригиналов), затем команда выше.

## Scope
- scripts/gen_home_hero_512.mjs (sharp): все home_scene_*.webp (и .accent.webp, если появятся) из dark/light → resize fit inside
  512 (без увеличения), webp q90 alphaQuality 100 effort 5 (как import_art_style / crop_spire_tile); манифест manifest.json;
  generated-реестр с require (Metro подключает картинки только статическим require).
- components/home/v2/scene/home_scene_art.ts: после resolveThemedArt подменяет источник на копию 512 той же яркости, из которой
  взят оригинал (v2art → своя, v2art_other_brightness → другая); заглушки (placeholder) не трогает; поле px в результате.
- HomeScene.tsx: px в строке журнала [HOME-SCENE] art.
- Сторож tests/home_hero_512_2026_10_22.test.ts: для каждого оригинала home_scene_* есть копия; sha256 оригинала = манифест;
  sha256 копии = манифест; заголовок WebP копии ≤ 512; нет копий-сирот; реестр перечисляет ровно копии; выбор яркости — чистой функцией.

## Architecture
- Отдельная папка hero512 вне dark/light: генератор оригиналов (gen_themed_art_assets.mjs) и сторожа v2art читают только dark/light
  без рекурсии — копии не попадут в реестр оригиналов как новые имена. Без «@» в имени файла (Metro и имена ресурсов Android).
- Реестр оригиналов (themed_art_assets.generated.ts, автогенерация) не правится: 1024 остаются в сборке до решения об их исключении.

## Security and privacy
- Данные пользователя, сеть и хранилище не затронуты; только картинки в сборке. Политику конфиденциальности не меняет.

## Technical debt
- Оригиналы 1024 по-прежнему подключены реестром оригиналов и попадают в сборку (+ ~0,3 МБ на копии 512). Исключать 1024 из
  сборки — отдельное решение (генератор оригиналов общий, владелец кладёт туда новые файлы).
- Сторож сверяет хэш, а не перекодирует: другая версия sharp даст другие байты — тогда пересобрать командой выше.
