# Шпиль при английском интерфейсе: экран не открывается по прямому маршруту (п.76)

Owner: сессия «4 · ТЕМЫ 2.0» (разрешено координатором: «ДА, делай сам», Ядро занято английским)

## Outcome
Шпиль скрыт для интерфейса вне ru/uk не только вкладкой, но и самим экраном: прямой маршрут /spire при en и смена языка на открытом экране показывают SpireLockedState, а не английские подписи с русскими заданиями. Решение уже в коде (SPIRE_UI_LANGS, spireUiLangDecision) — экран лишь начинает ему подчиняться.

## Scope
components/spire/SpireHomeScreen.tsx: `unlocked` учитывает решение по языку интерфейса; ранний выход locked стоит до экрана загрузки; журнал [SPIRE-GATE] screen. Новый чистый помощник components/spire/spire_screen_lang_lock.ts и тест tests/spire_screen_lang_lock.test.ts. Логика игры, Optimistic UI и Ядро не меняются.

## Architecture
Помощник `spireScreenLangLock(lang)` оборачивает spireUiLangDecision и возвращает {locked, decision}; экран вызывает его на каждом рендере (дешёвая проверка по списку из двух языков), эффект пишет журнал только при смене решения. Запретный язык выключает `unlocked`, поэтому useSpireGame и чтение недели не стартуют (ноль сетевых чтений).

## Security and privacy
Данные не собираются и не уходят; журнал в консоль содержит только код языка и причину.

## Technical debt
