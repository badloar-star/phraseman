# Полная проверка до выхода — шаблон таблицы сверки (Макеты, 15.10)

Поручение владельца через координатора: проверить ВСЁ — каждый экран, раздел, кнопку, модал, путь. Список экранов собирает координатор;
Макеты сверяют кадры по этому шаблону. Одна строка таблицы = один кадр.

## Код состояния

Состояние пишется коротким кодом из трёх частей: `доступ · тема · язык обучения`.

| часть | значения | dev-параметр ссылки |
|---|---|---|
| доступ | `F` — Free, `P` — Plus | `plus=off` / `plus=on` |
| тема | `L` — светлая «Сумерки», `D` — тёмная «Океан» | `theme=ink` / `theme=marine` |
| язык обучения | `en`, `es`, `fr`, `de`, `it` | `studyTarget=en` и т. д. |

Пример: `F·L·en` — Free, светлая, английский. `P·D·de` — Plus, тёмная, немецкий.

## Сколько кадров на экран (чтобы не снимать 20 на каждый)

- **Базовый набор — каждый экран:** `F·L·en` и `P·D·en` (2 кадра). Покрывает обе темы и оба доступа.
- **+ Free/Plus в одной теме** — только там, где экран у Free и Plus разный (замки, лимиты, бейджи Plus, пейволы): добавить `P·L·en` и `F·D·en`.
- **+ языки ×5** — только там, где на экране контент языка обучения (уроки, курс V2, Карточки, диалоги, «Мои ошибки», фраза дня, видео, язык изучения): `F·L·es`, `F·L·fr`, `F·L·de`, `F·L·it`.
- **Модалы и шторки** — в той же паре тем, поверх своего экрана.
- **Длинные тексты / пусто / нет сети / загрузка** — отдельной строкой состояния, если у экрана они есть (см. колонку «вариант»).

## Колонки таблицы

| колонка | что писать |
|---|---|
| id | id экрана из списка координатора; если есть строка реестра — её id из registries/visual_parity.json |
| раздел | Главная / Обучение / Практика / Сообщество / Настройки / онбординг / пейвол / … |
| экран | название, как видит человек |
| вариант | обычный / пусто / нет сети / загрузка / длинный текст / ошибка / модал «…» |
| состояние | код `доступ·тема·язык` |
| эталон | файл макета и номер телефона (`learn.html №4`) или `нет эталона` |
| кадр | путь к кадру Сверки |
| вердикт | `совпадает` / `расходится` / `нет эталона` / `не снято` / `заблокировано` |
| что не так | одной фразой, по-человечески; для «совпадает» — пусто |
| кто | сессия-исполнитель |
| когда | `до сборки` / `после сборки` / `—` |

## Правила вердикта

- `совпадает` — состав, порядок, тексты, размеры и цвет темы как в эталоне; демо-данные могут отличаться.
- `расходится` — любое отличие вида или текста, которого нет в решениях владельца; в «что не так» — что именно и где.
- Если эталон устарел, а приложение сделано по более новому решению — `совпадает`, в «что не так» — «эталон устарел, Макеты обновят».
- `заблокировано` — кадр нельзя снять (нет пути, нужен сервер) — причина в «что не так».
- 🔴 (падение, пустой экран, потеря данных или денег, неправда о подписке) — сразу координатору, не ждать конца таблицы.
