# Все участники: визитка по нажатию

Запрос владельца 26.10.2026: нажатие на любого участника должно открывать визитку.

Причина: строки SpireAllMembers были View без обработчика. Теперь вся строка — V2Pressable, открывающая существующую SpirePlayerCard внутри полноэкранного окна списка. Передаются UID, имя, признак своей строки, монета, Plus и очки текущего режима. Закрытие визитки оставляет список открытым.

Проверка: tests/spire_all_members_profile.test.tsx — 2/2 проходят (ступени и монеты; другой участник, своя строка, синтетический участник; закрытие и повторное открытие). На копии исходного компонента оба теста падают из-за отсутствующей нажимаемой строки. Тест зарегистрирован в RNTL-конфигурации.
