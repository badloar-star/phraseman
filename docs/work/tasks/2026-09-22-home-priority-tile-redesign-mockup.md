## Architecture

**Текущая граница.** Плашка отрисована инлайн в `app/(tabs)/home.tsx`: `TouchableOpacity`
→ `LinearGradient(homeThemePanelGradient)` → `Reanimated.View` с `homePriorityCardFlipStyle`
→ три блока (арт 92×72 / название по центру / счётчик справа). Данные приходят из
`priorityCardTitle`, `priorityCardImage`, `priorityCardCounter`, `priorityCardShowsMistakes`
(вычисляются в рендере, ~строки 3908–3936).

**Намеченная граница.** На шаге макета — без изменений. На шаге реализации меняется ТОЛЬКО
внутренность `Reanimated.View` с `homePriorityCardFlipStyle`: состав и вёрстка визуальных
блоков. Контракт наружу сохраняется дословно:
- `testID="home-continue-lesson"` и `testID="home-continue-lesson-title"` остаются;
- `accessibilityLabel` / `accessibilityHint` / `onLongPress` / `delayLongPress={380}` остаются;
- обёртка держит размер, переворот живёт на внутреннем слое — иначе поедет layout stability.

**Инварианты, которые нельзя нарушить:**
1. Высота плашки фиксирована (решение владельца: держать компактно ~80–90 px). Первый кадр
   = финальная геометрия, соседи не дёргаются (`tests/layout_stability_contract.test.ts`).
2. Оба лица имеют ОДИНАКОВУЮ высоту — иначе переворот дёрнет layout.
3. Никаких `borderWidth`/`borderColor` вокруг блока (запрет владельца, ловится `design-guard.js`).
4. Никаких подписей-расшифровок мелким шрифтом под названием (запрет владельца).
5. Никакого `adjustsFontSizeToFit` (запрет владельца, известный класс бага).
6. Никаких вечных анимаций: всё, что движется, гасится по фокусу/AppState
   (`tests/perf_freeze_contract.test.ts`).

**Решение по вариантам.** Три макета отличаются способом подачи прогресса:
01 «Полоса пути» — линейный индикатор; 02 «Кольцо» — круговой; 03 «Сцена» — крупный арт
за правым краем. Все три держат одну высоту и работают в обеих темах.

## Security and privacy

Не применимо, и вот почему конкретно: правка чисто визуальная. Новых полей, коллекций,
сторонних сервисов, системных разрешений и передачи данных нет. Плашка показывает данные,
которые уже отображались на этом же экране (название урока, число пройденных заданий, число
активных ошибок) — источник и объём не меняются. Persona/PII наружу не уходит, сеть не
задействована, Firestore-чтений не добавляется. Privacy policy правки не требует.
