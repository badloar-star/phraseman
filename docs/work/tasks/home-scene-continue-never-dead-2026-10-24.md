# «Продолжить» на «Сцене» Главной никогда не мёртвая (Р3)

Governance-ID: TG-8D30FE9EBE87

## Outcome
Координатор 24.10, решение Р3 из чек-листа FLAGS_SCREEN_CHECKLIST: «„Продолжить" никогда не мёртвая — герой „newbie" или переход в
доступный раздел, с логом ветки». Сейчас у языка изучения без раздела «Уроки» и без метки диалога/карточек «Сцена» рисует героя
«continue» без названия, а кнопка молча ничего не делает.

## Scope
Новый чистый модуль components/home/v2/scene/home_scene_continue_target.ts (выбор раздела), его тест; в app/(tabs)/home.tsx —
вызов, название, герой и обработчик кнопки «Сцены». Старая Главная (без сцены) не меняется.

## Architecture
Если продолжать нечего (выбор «none», урок прочитан) и «Уроков» для языка нет — «Сцена» становится местом первого доступного
раздела: «Диалоги», иначе «Карточки». Герой «newbie» с названием раздела и «Начать» ведёт туда же, куда плитка раздела. Разделов
нет вовсе — герой «newbie» без перехода в скрытое, причина в журнале. Каждая ветка — строка [HOME-CONTINUE] scene_target.

## Security and privacy
Нет данных, чтений и сервисов.

## Technical debt
Новых долгов нет; герой «newbie» без перехода остаётся только у языка без всех трёх разделов (сейчас таких нет).

## Verification
Срез типов, тесты Главной, новый сторож выбора.
