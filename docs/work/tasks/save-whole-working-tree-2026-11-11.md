## Outcome

Несохранённая работа остановленных номерных сессий и соседних сессий записана в общую ветку одним коммитом и больше
не существует только на диске. Владелец 11.11: «сохрани!»; на «коммитить всё рабочее дерево целиком, включая
58 564 удаления?» — «Да, всё целиком»; на «включить файл Главной в общий коммит?» — «Да, вместе с Главной».

Мера успеха: коммит прошёл все сторожа pre-commit штатно, без обхода; `git status` после него показывает только
намеренно оставленное.

## Scope

In scope:
- `git add -A` всего рабочего дерева и один коммит;
- две точечные правки, без которых сторож SILENT-CATCH не пропускает запись (правило владельца «никаких немых catch»):
  `functions/src/explain/mistake_explain_structured.ts` (разбор ответа модели) и
  `modules/mistake-practice/correction_reward_receipt.ts` (разбор записи награды) — в `catch` добавлена запись причины;
- вторая волна того же сторожа, ещё пять мест: `app/lesson_word_progress_compat.ts` (чтение счётчиков слов),
  `app/premium_real_storage.ts` (три места: разбор записи подписки, разбор журнала, удаление отметки ожидания),
  `components/dev/DevPlusToggle.tsx` (отладочный переключатель Plus) — то же: только строка журнала с причиной.

Out of scope (в коммит не входят намеренно):
- `admin.zip` — тяжёлый архив в корне, содержимое не проверялось;
- `docs/work/support/prepared-replies-2026-10-24.snippet.js` — обрывок, не проходит сторож синтаксиса;
- `functions-admin/lib/` — результат сборки (у `functions/lib` и `functions-max/lib` такая папка в .gitignore);
  в ней 42 немых `catch` скомпилированного кода;
- проверка кода тестами и типами: сохраняется как есть;
- отправка наружу (push).

## Architecture

No architecture change: запись уже существующих правок. Две правки `catch` не меняют поведение — функции по-прежнему
бросают ту же ошибку (`invalid()` / `fail()`), добавлена только строка журнала.

## Security and privacy

Перед записью новые и изменённые файлы просканированы на ключи и секреты (приватные ключи, ключи Google, OpenAI,
Stripe, GitHub, Slack, AWS, `"private_key"`) — совпадений нет. В добавленных строках журнала нет личных данных:
пишется длина ответа модели и число ключей записи, не их содержимое.

## Technical debt

- Accept temporarily: код сохранён без прогона тестов и типов. Владелец — координатор и сессии-хозяева кусков; exit —
  их собственные проверки; потолок ущерба — красные тесты в ветке до починки, наружу не отправлено.
- Contain: `functions-admin/lib/` не в .gitignore и будет всплывать как «новая папка» у каждой сессии. Exit — добавить
  строку в .gitignore по слову владельца.
- Contain: файл-обрывок в заготовках поддержки останавливает сторож синтаксиса. Exit — переименовать в `.txt`.

## Verification

Вывод pre-commit: `[SYNTAX] ok`, `[TRACKED-IMPORTS] ok`, `[SILENT-CATCH] ok` и остальные сторожа; хэш коммита;
число несохранённых изменений после записи.

## Rollback

Коммит не отправлен наружу: откат — `git revert <хэш>` (или `git reset` к предыдущему HEAD, пока поверх нет чужих
коммитов). Страховочная копия правок — `backups/uncommitted-2026-11-11/`.
