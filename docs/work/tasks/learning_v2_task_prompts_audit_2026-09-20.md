## Outcome

Ученик не видит инструкций, которые (а) заранее объявляют диагностическую лишнюю
плитку и тем самым выдают ответ, (б) обещают «без подсказок», хотя подсказка стоит
в той же строке. Мера успеха: 0 совпадений запрещённых формул в
`content/learning-v2-course/release/en/**/learner.json` и в
`content/learning-v2-course/sessions/en/**/final.ru.md`, при этом
каждая переписанная инструкция описывает сцену/действие и сохраняет однозначность
верного ответа.

Повод — прямое указание владельца 2026-09-20: «среди плиток есть чужая скрепка»
такого текста быть не должно; «соберите фразу без подсказок», когда на экране
сразу в той же строчке идёт подсказка — фраза на русском.

## Scope

В scope:
- `content/learning-v2-course/release/en/l01..l03/*/learner.json` — поля `prompt`,
  `accessibilityLabel`, `modePayload.localizedMeaning.ru`, `.uk`.
- `content/learning-v2-course/sessions/en/l01..l03/*/final.ru.md` — исходники, из
  которых `build_release.mjs` пересобирает release.
- `content/learning-v2-course/exemplars/en/*.ru.md` — образцы, по которым автор
  пишет новые сессии (иначе класс бага воспроизводится).
- `content/learning-v2-course/pipeline/owner_quality.mjs` (+ тест) — сторож,
  блокирующий возврат запрещённых формул.

Вне scope: смысл заданий, целевые фразы, наборы плиток, дистракторы, аудио,
интро-страницы, локали кроме ru/uk, курсы fr/de, старая система
`modules/learning-v2/content/source`.

## Architecture

Границы не меняются. Данные идут `sessions/**/final.ru.md` → `build_release.mjs` →
`release/**/learner.json` → приложение. Инвариант, который ставится под охрану:
инструкция описывает действие и смысл фразы, но НЕ устройство теста и НЕ уровень
помощи. Диагностическая лишняя плитка остаётся в наборе без объявления.

Правка только текстовая: ни один `interactionId`, `targetPhrase`,
`orderedTokens`, `authoredDistractorTokens` не трогается, поэтому ответы,
аудио и прогресс не смещаются.

## Security and privacy

Не применимо: меняются только обучающие тексты курса. Персональных данных,
авторизации, секретов, сетевых вызовов и детских данных правка не касается.
Privacy policy обновления не требует — новых данных не собирается.
