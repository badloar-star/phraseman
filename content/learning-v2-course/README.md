# Learning V2 — рабочий процесс курса

Главный источник правил — `ЗАДАНИЕ_CODEX_2026-10-15.md`. Качество текста
задают `ГЛАВНОЕ_ТРЕБОВАНИЕ.md`, `КОНСТИТУЦИЯ.md`, три эталона и решения
владельца. Старые квитанции, хэши, цепочки допуска и повторные проверки
перенесены в `pipeline/_archive_2026-10-15/` и не участвуют в работе.

## Одно занятие

1. Возьми пакет занятия из одобренного плана d956 и посмотри старое занятие
   на ту же тему как сырьё.
2. Напиши `sessions/<язык>/lXX/sYY/final.ru.md`, затем
   `final.uk.md`. Канонический источник — эти два Markdown-файла; новые
   квитанции, реестры, `status.json` и `practice.atomic.json` не нужны.
3. Запусти одну проверку:

   ```powershell
   node content/learning-v2-course/pipeline/check.mjs en/l01/s17
   ```

   `FIX` означает, что перечисленное нужно исправить. `PASS` означает только
   прохождение машинных проверок. Неверный английский, ложные объяснения,
   естественность и признаки машинного текста проверяют два проверяющих:
   ученик и носитель, не больше двух кругов каждый.
4. Закончив восемь занятий главы, собери приватный релиз и макет. Явный
   `--out` обязателен, чтобы не менять набор D198 из 15 занятий:

   ```powershell
   node content/learning-v2-course/pipeline/build_release.mjs --session en/l01/s17 --locales ru,uk --out outputs/en-l01-c03/release --candidate-preview
   node content/learning-v2-course/pipeline/build_mockup.mjs --candidate-preview --release content/learning-v2-course/outputs/en-l01-c03/release --out content/learning-v2-course/outputs/en-l01-c03/index.html
   ```

   Повтори сборку релиза для всех восьми занятий в тот же приватный каталог,
   затем собери один макет главы. Отсутствие аудио проверяется только перед
   выпуском принятой главы.
5. Запиши путь к макету и итог главы в `ХОД_КУРСА.md`, закоммить готовую главу
   и переходи к следующей, не ожидая ответа владельца.

## Что проверяет команда

Команда читает Markdown напрямую и повторно использует оставленные парсеры и
проектор: заголовок и сцену, 1–5 новых слов и совпадение с пакетом d956,
три вводные страницы, ключи и варианты ответов, число/порядок/типы заданий,
одну английскую фразу на взаимодействие, а также одинаковую структуру RU/UK.
Она не обращается к API и не меняет файлы занятия, релиз или макет.

## Что осталось в `pipeline/`

- `check.mjs` — единственная команда проверки занятия;
- `build_release.mjs` и `build_mockup.mjs` — приватная сборка главы;
- `session_header.mjs`, `single_phrase_release.mjs`,
  `practice_explanations_v1.mjs`, `owner_quality.mjs`,
  `audit_actor_clarity.mjs`, `write_mockup_file.mjs` — используемые ими
  парсеры и проверки того, что видит ученик.
