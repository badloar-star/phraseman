# Англійська · Урок 26 · Заняття 42 — Плани у сніжний день

**Ситуація.** Ви описуєте ранок, перевіряєте автобус і змінюєте час зустрічі.

**Що ви опануєте:** сказати, що буде, якщо чи коли…, і що вже зроблено до моменту: If it rains, we’ll stay. I’ve already eaten.
**Нові слова:** snowy, misty, snowfall, windshield

## Інтро 1

### Якщо доріжка вільна

Після снігопаду ви вирішуєте з другом, чи можна пройти пішки. Скажіть: We can walk if the path is clear — ми можемо пройти пішки, якщо доріжка вільна. Складаємо: We + can walk + if the path is clear — хто, що може зробити, за якої умови. Після can потрібна walk без to. If задає умову вашого плану; у цій частині використовуємо is без will.

**Виберіть фразу для цієї ситуації.**

- ✅ **We can walk if the path is clear.**
- ❌ We can walk unless the path is clear. — *Unless змінює умову: якщо доріжка не вільна.*
- ❌ We can walk if the path will be clear. — *У цій умові після if потрібно is без will.*

---

## Інтро 2

### Розклад уже перевірено

Друг пропонує подивитися час автобуса, але ви вже зробили це. Дайте відповідь: I have already checked them — я вже перевірив розклад. Them замінює bus times — обговорювані години відправлення автобусів. Складаємо: I + have + already + checked + them — хто, have, уже, дія, що перевірив. Already ставимо між have і checked. Після have потрібна форма checked із -ed; have / has + done повідомляє про готовий результат зараз.

**Виберіть фразу для цієї ситуації.**

- ✅ **I have already checked them.**
- ❌ I have already check them. — *Після have потрібна форма checked.*
- ❌ I already checking them. — *Результат зараз виражається через have checked.*

---

## Інтро 3

### Сніг розтанув до зустрічі

Ви згадуєте вчорашню зустріч: до вашого приходу снігу вже не було. Скажіть: The snow had melted by the time we met — сніг розтанув до того часу, як ми зустрілися. Складаємо: The snow + had melted + by the time we met — що, що сталося раніше, до якого моменту в минулому. Had melted показує танення до зустрічі. Після had потрібна melted із -ed, а met називає пізнішу подію.

**Виберіть фразу для цієї ситуації.**

- ✅ **The snow had melted by the time we met.**
- ❌ The snow has melted by the time we met. — *Met задає минуле; раніша подія — had melted.*
- ❌ The snow had melt by the time we met. — *Після had потрібна форма melted.*
