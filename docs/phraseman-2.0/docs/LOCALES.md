# Контуры языков и данных

Разделить четыре понятия: UI locale, язык передней стороны, язык обратной стороны, изучаемый курс/сценарий. Карточки могут быть универсальными. Добавить язык в selector не означает перевести UI, создать курс и гарантировать голос на каждом телефоне.

Предлагаемая модель ключей: account namespace → domain → course/content version → learning direction. Для карточки own ID и явно заданные side locales. Направление EN→RU и RU→EN может быть отдельной настройкой практики, но не должно случайно раздвоить содержимое. Точное key format определить по существующему sync contract, не создавать параллельный storage.

Общие аккаунту: баланс монет, ранг монеты, Plus entitlement. XP не остаётся общим, потому что удалён. Статистика может иметь общий summary, но raw learning events имеют locale/source; ошибки всегда показывают конкретный язык. Switching во время сессии не переименовывает её сохранённые результаты.

Смена языка бесплатная. Онбординг должен уважать направление из ролика и не заставлять выбирать отсутствующий платный курс. Английский из S35 вернуть именно в том месте, где он реально пропал: current code audit прежде любого исправления.

Расширять locale registry с проверяемыми capabilities: карточки доступны, TTS available/unknown, диалоги готовы/нет, V1/V2 доступны/нет. Отсутствующий голос — понятное состояние, не silent wrong-language fallback. Нужны проверки диакритики, сортировки, больших текстов, RTL при заявленной поддержке и смешанного письма. Не вводить обещание «все языки» до тестов.

## Общий кошелёк, ранг и статистика по языкам (PM-121, ядро, 2026-10-02)
Баланс монет, `coinRank` и Plus не зависят от языка обучения (`coin_rank_v1:<owner>` без языка; в `target_storage_keys.ts` у них нет языкового ключа). XP не возвращён (D02). Сводка «За всё время» (`app/lifetime_profile_stats.ts`) раньше считала только `en`+`fr` и нигде не называла язык — испанский, немецкий и итальянский молча терялись. Теперь суммируются все языки курса (`LEARNING_LANGUAGE_TARGETS`), а в результате есть `byTarget` — слова/фразы/карточки по каждому языку, сумма равна итогу. Подпись на экране («по всем языкам» и разбивка) — зона «Дизайн».
