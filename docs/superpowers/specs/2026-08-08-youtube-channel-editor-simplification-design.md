# Упрощение редактора YouTube-каналов

Дата: 2026-08-08

## Цель

Сделать добавление и редактирование YouTube-канала одним коротким действием без технических настроек на экране.

## Интерфейс

Экран показывает:

- список сохранённых каналов;
- кнопку «Добавить канал»;
- поле «Ссылка на канал»;
- поле «Название»;
- поле «Язык»;
- кнопку «Сохранить канал»;
- понятные состояния загрузки, успешного сохранения и ошибки.

С экрана убираются статусные карточки, внутренний ID, порядок, переключатель включения, ручное назначение каналов по локалям, плейлисты, премьеры, предварительная проверка, причина изменения, отдельная кнопка публикации и история изменений.

## Автоматические значения

- Новый канал получает стабильный внутренний ID вида `channel-N`.
- Новый канал сразу включён.
- Порядок равен позиции канала в списке.
- Поле языка принимает один языковой тег, например `en`, `es` или `pt-BR`; в backend он сохраняется как массив из одного элемента.
- Для указанного языка канал автоматически становится каналом по умолчанию.
- Существующие технические данные канала, включая плейлисты и премьеры, сохраняются при редактировании и не удаляются только потому, что скрыты из интерфейса.
- Причина изменения формируется автоматически для audit log.

## Сохранение

Кнопка «Сохранить канал» валидирует только видимые обязательные данные и вызывает `adminPublishYoutubeCatalogConfig`.

- Ссылка должна содержать Channel ID `UC…`, `@handle` или URL вида `youtube.com/@handle`.
- Название обязательно.
- Язык обязан соответствовать языковому тегу.
- Во время запроса именно нажатая кнопка получает состояние «Сохраняем…».
- Ошибка показывается рядом с формой и не уводит пользователя к скрытому блоку.
- После успеха рабочая область перечитывается, а сохранённый канал остаётся выбранным.

## Границы изменения

- Рабочая поверхность остаётся в `admin/v2/legacy.html`.
- Backend-контракт и Firestore-схема не меняются.
- Проверка Firebase Admin claim и аудит публикации сохраняются.
- App Check для админки не включается.

## Проверка

- Контрактный тест подтверждает наличие ровно трёх полей редактора и отсутствие удалённых секций.
- Тест подтверждает автоматические ID, порядок, включение и locale defaults.
- Тест подтверждает, что кнопка сохранения использует видимое состояние загрузки и callable публикации.
- Выполняются focused-тесты админки и визуальная проверка production после точечного deploy hosting.
