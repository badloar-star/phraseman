## 1. ЧТО ПРОСИЛ ВЛАДЕЛЕЦ

Дословно, по смыслу:

1. Полный аудит всех анимаций, модалок, тостов, экранов и **всех возможных состояний**.
2. Полная переделка движения с нуля.
3. По **три разных дизайна** на каждую поверхность — радикально разных, без повторов и похожести.

5. Экран победы при завершении урока — **эталон, не трогать**.
6. Модалка повышения уровня — приоритет. Сейчас это отдельный экран, раньше был модал. Нужны варианты на выбор.
7. Макеты — так, чтобы анимации переносились **точно, а не примерно**.
8. **Никакой новой нагрузки** на устройства пользователей.
9. Мультиагентно, с обсуждением, какие стили лучше.
10. Позже: перенести всё в **DEV Hub** приложения отдельным разделом, чтобы каждую анимацию можно было запустить на телефоне. **Не применять к боевым экранам.** Это выполнено — см. раздел 5.

## 3. MOTION DNA — ЗАКОНЫ, ИЗВЛЕЧЁННЫЕ ИЗ ЭТАЛОНА

Это не пожелания, а описание того, что уже работает в `ResultsSequence.tsx`.
Любая новая поверхность обязана им соответствовать.

1. **Градуированный отскок.** Пружинит герой, свита — нет. Медаль
   `damping 10 / stiffness 150 / mass 0.7` → перерегулирование 17,3 %;
   звезда `11/170/1` → 23,2 %; XP `14/200/0.6` → 7,4 %; галка `12/180/0.55` → 9,3 %;
   CTA `14/130/1` → 8,7 %; пилюля `14/210/0.55` → 6,8 %.
   Правило: 1–2 элемента кадра имеют право на отскок >15 %, остальным 6–9 %.

2. **Ритм замедляется к кульминации.** Сетка 0 / 500 / 940 / 1500 / ~2100 / 2500 / 3000 мс.
   Стаггер звёзд неравномерный: сначала 440 мс, потом 560. **Ровный метроном запрещён.**

3. **CTA на 2500 мс, безусловная разблокировка на 3000 мс.** Ни одна поверхность
   не держит палец дольше трёх секунд.

4. **Между двумя наградными звуками минимум 100 мс тишины.** Следующий бит стартует
   по «конец предыдущего звука + GAP», а не по круглому числу. Арбитр звука однослотовый.

5. **Каждая веха = звук И хаптика одновременно.** `fk.milestone()` всегда несёт
   `haptics.success()`. Поверхность без хаптики — вне DNA.

6. **Числа считаются на UI-треде.** `AnimatedTextInput` + `useAnimatedProps`.
   Никаких `setState` в тик счётчика.

7. **Ширина числового слота фиксируется до старта:** `max(84, len*32+20)`.
   Цифры не двигают соседей на переходах 9→10 и 99→100.

8. **Высота будущих слотов резервируется заранее.** Появление награды не двигает макет.

9. **Празднование — состояние экрана, а не окно поверх него.** Фон — `ScreenGradient`
   самого маршрута, ноль бэкдропов. Если фон нужен — он обязан анимироваться
   ВМЕСТЕ со сценой, а не появляться отдельным кадром.

10. **Тап в любой момент = скип за 120–160 мс; второй тап закрывает.** Аудио-очередь глушится.

11. **Конфетти конечны и детерминированы:** ≤120 частиц, ровно 1200 мс,
    `Easing.out(cubic)`, фиксированный seed, автостоп. Бесконечных циклов в наградном слое нет.

12. **Reduce Motion — не «быстрее», а «сразу»:** всё в финальном состоянии одним кадром,
    таймеры не заводятся, вехи молчат, `confettiCount: 0`.

13. **Полный сброс + `cancelAnimation` на каждый ремаунт и unmount.**

14. **Типографическая иерархия кульминации 50/28/22/18/15.** Награда всегда крупнее заголовка.

15. **Выход обязателен и не длиннее входа.** Эталон `MotionModal`: 280 out-cubic / 180 in-cubic,
    панель держится смонтированной до конца. Запрещено: `animationType="none"` без exit,
    `onClose()` прямо из `onPress`, снятие `visible` родителем в тот же кадр,
    `if (!visible) return null` до проигрыша анимации.

16. **Затемнение — токен, зависящий от светлости темы.** Хардкод чёрного запрещён.

## 5. ТРИ НАПРАВЛЕНИЯ ДВИЖЕНИЯ

Радикально разные по физике, а не по цвету. Владелец ещё не выбрал.

### I · «ЧЕКАН» — материал и вес
Всё имеет массу: падает, ударяется, сплющивается, встаёт за один отскок.
Поверхность отвечает отдачей. Частицы подчиняются гравитации.

```
FALL      220 мс, Easing.bezier(0.6, 0, 0.95, 0.5)   // с ускорением
ANTICIP   180 мс, Easing.inOut                        // замах перед падением
SQUASH    stiffness 260, damping 5,  mass 1           // сплющивание тела
RECOIL    stiffness 180, damping 6,  mass 1           // отдача поверхности
PANEL     stiffness 165, damping 15, mass 0.9
ROW       stiffness 145, damping 12, mass 0.6
CHIP      stiffness 190, damping 10, mass 0.5
TOAST     stiffness 190, damping 12 | ошибка 240/11
EXIT      190 мс, Easing.bezier(0.4, 0, 1, 1)
BACKDROP  240 мс · OFFSET 130 px
LADDER    [0, 62, 146, 262, 410, 590]                 // каскад замедляется
```

### II · «СВЕТОВОД» — свет и глубина
Ничто не летит. Сначала загорается источник, потом из него выходит форма.
Движение по оси Z: масштаб, свечение, зажигание кромки. Ни одной пружины с отскоком.

```
BLOOM     420 мс   // источник света, всегда ПЕРВЫМ
RESOLVE   380 мс   // форма выходит из расфокуса
SETTLE    stiffness 150, damping 22, mass 1   // посадка БЕЗ отскока
RIM       620 мс   // свет обегает кромку
DEPTH     460 мс · EXIT 260 мс
SHIFT     16 px    // единственное перемещение направления
DEFOCUS   scale 1.06 → 1   // BlurView НЕ используется, это дорого на Android
LADDER    [0, 74, 172, 306, 478, 688]
```

### III · «МЕТРОНОМ» — ритм и цифры
Ни свечений, ни ударов, ни частиц. Числа досчитывают, линии прочерчиваются,
строки приходят в такт. Самое дешёвое направление.

```
BEAT      60 мс — базовый такт, все длительности кратны
LINE      360 мс (6 тактов)   // разделитель чертится слева направо
TEXT      240 мс (4 такта)
COUNT     720 мс (12 тактов)  // число досчитывает
OPEN      420 мс (7 тактов)   // панель раскрывается по вертикали
EXIT      180 мс (3 такта) · SHIFT 6 px
LADDER    [0, 60, 140, 260, 420, 620]
```

**Важно:** у всех трёх каскад **неравномерный** — это требование закона 2.
Первая версия «Метронома» была на ровном шаге и нарушала эталон; исправлено.

```js
// React Native внутри переводит tension/friction в stiffness/damping ровно так
// (Animated/SpringConfig.js → fromOrigamiTensionAndFriction)
stiffness = (tension - 30) * 3.62 + 194
damping   = (friction - 8) * 3 + 25
```

Поэтому цифры из макета переносятся в RN без пересчёта.

`_shared/bases.js` содержит **реальные токены 5 тем** приложения (dark, midnight,

## 10. ГРАБЛИ

- **Не начинай в `~/phraseman`.** См. раздел 0.
- **Не выдумывай дизайн.** Смотри `.dev-screens/` и токены тем.
- **Не ставь ровный стаггер** — нарушает закон 2.
- **Не анимируй `height`** — это layout на JS-потоке. Используй `scaleY` +
  компенсирующий `scaleY` на содержимом.
- **Не тащи `BlurView`** — в проекте его нет намеренно, Android-бюджетники.
- **Счётчики только через `AnimatedTextInput` + `useAnimatedProps`**, никогда `setState`.
- **Git в песочнице Cowork не может удалять файлы** — каждая операция оставляет
  `.git/index.lock`, следующая падает. Снимать через `mv`, не `rm`.
- **Скрипты в `package.json` написаны под PowerShell** и на маке не работают.
  Рабочие: `scripts/dev-mac-restart.sh`, `scripts/push-all-to-origin.sh`.
- **`tsc --noEmit` на всём проекте падает по OOM.** Проверяй точечно:
  `NODE_OPTIONS="--max-old-space-size=6144" npx tsc --noEmit --skipLibCheck --jsx react-jsx ... <файлы>`.
- **Линт проекта запрещает `numberOfLines`** (правило `text-integrity/no-unsafe-text-truncation`)
  и `Array<T>` вместо `T[]`.
