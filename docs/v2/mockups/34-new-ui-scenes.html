Выход с подтверждением
«Выйти» срабатывает мгновенно, а прямо под ним — «Удалить аккаунт». У человека без привязанной почты промах необратим. Подтверждение спрашивает не «точно?», а показывает чем он рискует.
развилка текст зависит от того, есть ли способ вернуться есть почта спокойный тон: «войдёшь снова по почте» нет почты предупреждение золотом + первая кнопка НЕ «выйти», а «привязать почту» (даём выход из ловушки, а не только предупреждаем) кнопки «Выйти» — вторичная, НЕ красная: выход не разрушение, не пугаем цветом развод «Удалить аккаунт» переезжает в отдельную группу ниже, с воздухом между ними
