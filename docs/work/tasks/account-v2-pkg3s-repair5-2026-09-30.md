## Architecture

GC по байтам вытесняет только tombstone с ревизией ≤ ревизии сущности на начало пакета (R0 выдан предыдущим пакетом, такой tombstone не «свежий»); если и так не помещается — окончательный `entity_state_too_large` (честно, без тихой потери свежей защиты).
