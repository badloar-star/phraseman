## Outcome

Ещё два окна при включённых историях приходят кадром (владелец 11.11: «никаких модальных окон совсем»,
на вопрос о порядке — «Продолжать партиями»):
- реферальное окно-приветствие «Тебя пригласили» — когда вводить код друга не нужно;
- окно «Первый разговор» в конце первого диалога с ИИ.

Оба кадра несут НАСТОЯЩИЙ текст окон, а не придуманный в макете: в макете приветствие обещало «7 дней Plus в подарок»
и награду другу — окно такого не говорило; у «Первого разговора» были выдуманные реплики и минуты, которых итог диалога
не знает.

## Scope

In scope:
- `modules/story_events/story_instead_sources.ts`, `components/stories/templates/story_instead_from_event.ts` — два вида;
- `components/ReferralWelcomeHost.tsx`, `components/dialog_moments/FirstDialogHost.tsx` — при включённых историях пишут факт;
- кадры, строки, примеры фотостудии, макет, тесты.

Out of scope:
- реферальное приветствие, когда код ещё нужно ввести: окно остаётся, потому что кнопке «У меня есть код приглашения»
  у кадра нет действия — общий файл действий кнопок правит соседняя сессия;
- кнопка окна «Первый разговор» «Следующий сценарий»: у кадра её нет, следующий сценарий человек выбирает на экране итога.

## Architecture

Тот же приём: решение хоста прежнее, меняется последний шаг. Отметка «видел» / «показано» ставится после успешной записи
события. «Первый разговор»: кадр берёт тексты прямо из `first_dialog_strings.ts` (заголовок с «по-английски» из
словаря изучаемых языков и строка «6 реплик · 5 заданий из 5») — своих копий строк нет.

## Security and privacy

Новых данных нет: в событие пишутся изучаемый язык, число реплик и заданий — то, что окно уже показывало.

  кадр наследует их как есть.

## Дополнение 18:50 — действие кнопки «У меня есть код приглашения»
