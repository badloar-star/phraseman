# m18 «Итог диалога — думает… → реакция»: новые строки

Источник — эталон `docs/design/v2-app/engagement-moments-v3-all.html`, блок `done3`. Код — `components/completion/dialogue_chain_strings.ts`.

Переводы на все языки, кроме RU, — черновики, носитель их не проверял (TODO-i18n).

**Ждёт решения владельца.** В эталоне реакция «Эмма довольна» — слово с родом. У персонажа в данных пола нет, а слова настроения в коде мужские («Доволен»). Поэтому реакция сформулирована без рода: «{name}: отлично!» — это вариант (б) из письма координатору. Если владелец выберет другой вариант, меняются только значения `pleased` и `neutral`.

| ключ | ru | en (черновик) | когда |
|---|---|---|---|
| thinking | {name} думает… | {name} is thinking… | пока итог идёт из сети, не короче 0,8 с |
| pleased | {name}: отлично! | {name}: great job! | настроение happy/smile, или разговор завершил собеседник и все цели закрыты |
| neutral | {name}: неплохо | {name}: not bad | все остальные исходы, без праздника |
| partner | Собеседник | Your partner | у сценария нет имени персоны |
| goalsOf | {met} из {total} | {met} of {total} | подпись «Закажи кофе · 3 из 3 целей» |

- `{name}` — имя персоны из `dialogueV2UiCopy(...).personas`, первая персона.
- Слово «целей» — уже существующая подпись `labels.goals` итога диалога.
