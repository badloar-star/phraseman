# Task packet: карточка экзамена в «Сезоне» сразу «сдан» после возврата с экзамена

Governance-ID: TG-DC1D37317E2A
Status: In progress
Owner: Learning V2 session; координатор 25.10 — вероятная причина жалобы №17

## Outcome

После сдачи экзамена главы и возврата на «Сезон» карточка экзамена сразу показывает «сдан» — без перезапуска приложения.
Раньше записи экзаменов читались только при смене урока, и карточка до перезапуска звала «Сдать экзамен».

## Scope

components/learning-v2/season/SeasonCourseConnected.tsx (эффект чтения записей экзаменов: ещё и при возврате фокуса экрана),
тест. Вид карточки не меняется.

## Architecture

Записи читаются из того же хранилища (память процесса, диск — если памяти нет); итог экзамена пишет запись в память сразу, поэтому
чтение после фокуса мгновенное. Новая ссылка на объект — только если записи изменились (иначе лишнего рендера нет).

## Security and privacy

Только локальное чтение результатов экзаменов этого аккаунта; сети и Firestore нет.

## Technical debt

Нет.

## Verification

Тест: экран в фокусе → запись экзамена «сдан» → потеря и возврат фокуса → карточка экзамена «done».
