## Architecture

№3: копия каталога хранится рядом с наборами в том же ключе `video_phrase_set_packs_cache_v2` необязательными полями `catalogVersion` и `catalog` (массивы строк, чтобы файл был компактным). Ключ не меняется: старая копия без полей просто даёт один полный проход. Версия сохраняется только если все каналы прочитаны без ошибок.
№5: `fetchFriendProfilesBatch(uids, { force, maxAgeMs })`; для записей с профилем срок берётся из `maxAgeMs`, пустые записи (сбой вызова) живут прежние 5 мин, чтобы сбой не прятал друзей на 30 мин. Очистка просроченного — по 30 мин.
