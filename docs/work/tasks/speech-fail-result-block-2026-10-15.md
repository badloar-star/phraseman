# Экран результата речи «не засчитано»: единый блок по эталону Макетов (15.10)

Governance-ID: TG-48EBA587A141

## Outcome
По поручению координатора (до сборки, цель 20:00): когда фраза не засчитана (строгая проверка речи, владелец 15.10), человек видит ФРАЗУ ЦЕЛИКОМ, пропущенные слова мягким красным токеном темы, строку «Не услышали слово «X» — скажи фразу целиком» (подсвечены все пропущенные, названо первое), главную кнопку «Ещё раз» и «Пропустить» текстом. Эталон: `docs/design/v2-app/speech-result-states.html` (91eee157a), разбор `speech-fail-ui-2026-10-15.md` (1af2808df). Один блок для урока, курса V2 и Карточек «Устно»; Диалоги не меняются. В V2 «Попробуйте ещё раз.» (на «вы») → «Попробуй ещё раз.» (приложение на «ты»). Янтарь неуверенных слов — после релиза.

## Scope
Новое: `app/speech_fail_view.ts` (чистые данные: какие слова подсветить, строка на 9 языках), `components/speech/SpeechFailBlock.tsx` (вид по токенам темы). Подключение: Карточки «Устно» (`app/flashcards_speaking_session.tsx` — блок результата), курс V2 (`app/learning_v2_direct_session_player_v1.tsx` — карточка «Ты сказал(а)»; `modules/learning-v2/modes/mode_feedback_v1.tsx` — «ты»), урок (`components/SpeakingPanel.tsx` — только после того, как «Сайт» и Ядро освободят файл; свой ханк через --patch). Логику строгой проверки (`pronunciation_scoring_core.ts`) не трогаю — это «Сайт».

## Architecture
Чистая функция `buildSpeechFailView(targetText, missingWords)` сопоставляет нормализованные пропущенные слова оценщика со словами фразы как написано (стяжения «you're» → «you are» — слово подсвечено, если пропущено любое из нормализованных; повторяющиеся слова считаются набором). Блок — плашка «Тень» без обводки (тень и тон), слова в строках с переносом, пропущенное слово — плашка `badSoft` с текстом `bad` (токены темы, не hex). Данные `missingWords` приходят из результата оценки; пока панель говорения отдаёт в `onScore` только `{score, passed, transcript}` — согласовано с «Сайтом» (сообщение 15.10), до их ответа хост вычисляет пропущенные слова из `targetText` + `transcript` тем же оценщиком.

## Security and privacy
Данные не покидают устройство; распознанная речь уже обрабатывается панелью, новых полей и сервисов нет — политика не меняется.

## Technical debt
Тексты строки — новые на 9 языках, отдаю Переводчику на проверку (в `speech_fail_view.ts`). Маска `t____` в уроке уходит вместе с блоком (после освобождения SpeakingPanel); анти-чит «эталон не читается с экрана» снят решением эталона Макетов.
