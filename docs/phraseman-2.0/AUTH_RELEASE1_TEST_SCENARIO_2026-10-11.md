# Первый выпуск: проверка входа, выхода, удаления и смены аккаунта

Версия 11.10.2026. **Прогон делает сессия на эмуляторе Pixel_8** (приказ владельца: «все проверки и прогоны делаются не мной, а на эмуляторе — сессия должна всё это проверить с моими 3 аккаунтами»). Старт — когда владелец разрешит эмулятор.

## Правила прогона сессией (обязательны)
1. **Пароли не вводятся никогда.** Google — только выбором аккаунта, который уже добавлен в Android на эмуляторе (Настройки Android → Аккаунты). Появилось поле пароля, код из SMS или «Войдите в аккаунт» — **СТОП**, ничего не вводить, сообщить координатору.
2. **Аккаунты.** A, B, C — три Google-аккаунта владельца, заранее добавленные в Android на эмуляторе. Перед прогоном сессия читает список: `adb shell dumpsys account` (только чтение) и записывает в отчёт, какие из трёх есть. Известен один: `badloar@gmail.com` (владелец, админ). Двух других сессия не знает — их называет владелец или они видны в списке аккаунтов эмулятора.
3. **Удаление.** Основные аккаунты владельца **не удаляются** без его прямого «да». Аккаунт `badloar@gmail.com` (claim `admin`) сервер удалить не даст вовсе — пломба 22.09; пробовать не надо. Раздел F — только на отдельном тестовом Google-аккаунте, добавленном в эмулятор владельцем, и только после его «да». Раздел G (гость) — можно всегда.
4. **Apple на Android** открывает веб-форму Apple ID с паролем → по правилу 1 сессия её **не проходит**. Проверяется: кнопка «Войти через Apple» видна, окно открывается, отмена (крестик) возвращает без ошибки (H4). Полный вход Apple (H1–H3) — владелец на iPhone, отдельно.
5. **Траты.** Кнопки, которые тратят монеты/покупают, сессия не жмёт без проверки обработчика (правило Сверки). В E1 «покупка за монеты» заменяется на проверяемое без трат: имя профиля, пройденный урок, «Мои ошибки».
6. Перед прогоном — `adb emu avd snapshot save` (НЕ load); после — снимок возвращает «Эмулятор» холодным стартом.
7. Отчёт: по каждому шагу «совпало / нет + строка журнала», снимки экрана в `docs/phraseman-2.0/evidence/auth/`.

**Как пользоваться.** Идите по шагам сверху вниз. В каждом шаге: **что сделать → что должно быть**. Не совпало — отметьте номер шага и пришлите строки журнала с метками ниже. Учётные данные никуда не записываются.

**Метки журнала:** `[ONBOARDING-AUTH]` `[AUTH-MODAL]` `[AUTH-SIGNIN]` `[ACC-MUT]` `[ACCOUNT-RESTORE]` `[AUTH-SWITCH-OFFER]` `[account-delete-local]` `[PRIVACY]` `[SETTINGS-LANG-STUDY]`.

**Способы входа в выпуске:** Google (Android и iPhone), Apple (iPhone; на Android — только если заданы переменные `EXPO_PUBLIC_APPLE_ANDROID_*`, они заданы), гость (кнопка «Позже»). **Входа по почте в приложении нет** — это не ошибка; почтовый вход есть только служебный, для эмулятора разработчика.

**Перед началом:** свежая dev-сборка на эмуляторе; `adb shell pm clear` пакета приложения (чистая установка); три аккаунта владельца добавлены в Android (правило 2); снимок сохранён (правило 6).

## A. Гость (≈3 мин)

| № | Что сделать | Что должно быть |
|---|---|---|
| A1 | Открыть приложение → «Начать», пройти вопросы онбординга | Экраны идут без пауз и спиннеров на весь экран |
| A2 | На экране «Твои данные — только твои» нажать «Позже» | Открывается Главная. Окна ошибки нет |
| A3 | Пройти 1 урок до конца | Монеты и серия выросли; запомните цифры |
| A4 | Настройки → карточка профиля | Подпись про прогресс на этом телефоне; строка «Аккаунт» без способа входа |
| A5 | Настройки → «Аккаунт» | Видна строка «Привязать аккаунт», строк «Email» и «Способ входа» нет |

## B. Гость → аккаунт Google (≈2 мин)

| № | Что сделать | Что должно быть |
|---|---|---|
| B1 | Настройки → «Аккаунт» → «Привязать аккаунт» → «Войти через Google» | Открывается ОДНО системное окно Google |
| B2 | Выбрать свой аккаунт | Окно закрывается сразу; на Главной — те же монеты и серия, что в A3 (прогресс не потерян) |
| B3 | Настройки → «Аккаунт» | «Способ входа · Google», есть email и «Скопировать»; «Привязать аккаунт» больше нет |
| B4 | «Скопировать» у email | Короткое «Скопировано» |

## C. Выход и повторный вход (≈2 мин)

| № | Что сделать | Что должно быть |
|---|---|---|
| C1 | Настройки → «Аккаунт» → «Выйти» | Окно «Выйти из аккаунта?» с кнопками «Выйти» и «Отмена» |
| C2 | «Отмена» | Окно закрылось, вы по-прежнему в аккаунте |
| C3 | Снова «Выйти» → «Выйти» | Коротко «Сохраняем прогресс», затем первый экран приложения |
| C4 | «У меня уже есть аккаунт» → Google, тот же аккаунт | Открывается Главная; монеты, серия, имя — как до выхода |
| C5 | Выйти без интернета (включить авиарежим) → «Выйти» | Выход не выполняется молча: показан понятный текст и «Повторить»; данные на месте. Выключить авиарежим, «Повторить» — выход проходит |

## D. Поведение кнопок входа (≈2 мин)

| № | Что сделать | Что должно быть |
|---|---|---|
| D1 | На экране входа быстро нажать «Войти через Google» два раза | Открывается ОДНО окно Google, ничего не «залипает» |
| D2 | Открыть окно Google и закрыть его крестиком / «Назад» | Никакого окна ошибки; кнопки снова нажимаются |
| D3 | Медленная сеть: нажать Google и подождать больше 8 секунд | Строка «Вход всё ещё выполняется. Кнопки останутся недоступны до ответа провайдера.»; «Назад» нажимается |
| D4 | Если вход после этого всё-таки завершился | Приложение пускает в аккаунт; анкета новичка не затирает имя и прогресс |

## E. Смена между тремя аккаунтами A → B → C → A (≈6 мин)

| № | Что сделать | Что должно быть |
|---|---|---|
| E1 | Войти аккаунтом A. Запомнить имя, монеты, серию; пройти 1 урок; открыть «Мои ошибки» | Урок засчитан сразу, цифры выросли |
| E2 | Настройки → сменить аккаунт → в окне выбора Google выбрать B | Окно «Сменить аккаунт?» с «Отмена»; после подтверждения — профиль B, ничего от A (имя, монеты, ошибки — свои) |
| E3 | Если на телефоне есть несохранённое (карточки, покупка в процессе) | Честное окно: «Прогресс не сохранён» / «Покупка ещё синхронизируется» / «Нужна проверка монет», кнопки «Остаться здесь» и «Сменить без сохранения» — выбрать «Остаться здесь» |
| E4 | Из B так же перейти на C | Профиль C, ничего от A и B |
| E5 | Из C вернуться на A | У A на месте имя, монеты, серия, урок из E1, «Мои ошибки» |
| E6 | Пропала сеть посреди смены (авиарежим эмулятора) | «Нужно завершить смену аккаунта» и «Повторить»; после перезапуска смена доводится сама, данные не теряются |

## F. Удаление аккаунта Google и восстановление (≈3 мин) — ТОЛЬКО тестовый аккаунт и только после «да» владельца

| № | Что сделать | Что должно быть |
|---|---|---|
| F1 | Настройки → «Аккаунт» → «Удалить аккаунт» | Окно «Удалить аккаунт?»: «Аккаунт удалится через 14 дней. Если передумаешь — просто войди снова тем же способом. Подписка в App Store или Google Play не отменится автоматически.» Поле «Введи «УДАЛИТЬ» для подтверждения:» |
| F2 | Ввести «УДАЛИТЬ» → «Удалить» | Первый экран приложения. **Никакого всплывающего уведомления об удалении** (решение владельца) |
| F3 | «У меня уже есть аккаунт» → тот же Google | Окно «Восстановить аккаунт?» с кнопками «Восстановить» и «Не восстанавливать» |
| F4 | «Восстановить» | «Аккаунт восстановлен. Войди ещё раз — весь прогресс на месте.» → после входа прогресс на месте |
| F5 | (по желанию) F1–F3, затем «Не восстанавливать» | Открывается новый пустой профиль; старые данные не возвращаются |
| F6 | Удаление без интернета | «Удаление не завершилось. Проверь интернет и попробуй ещё раз.» + «Повторить»; аккаунт не удалён наполовину |

## G. Удаление гостя (≈1 мин)

| № | Что сделать | Что должно быть |
|---|---|---|
| G1 | Новая установка → «Позже» → 1 урок → Настройки → «Аккаунт» → «Удалить аккаунт» | «Прогресс удалится безвозвратно. Подписка в App Store или Google Play не отменится автоматически.» (у гостя нет 14 дней — войти ему нечем) |
| G2 | «УДАЛИТЬ» → «Удалить» | Первый экран; приложение как новое. Без интернета: телефон стирается сразу, серверная часть дочищается при следующем запуске с сетью |

## H. Apple — на эмуляторе только H4 (веб-форма с паролем не проходится); H1–H3 — владелец на iPhone

| № | Что сделать | Что должно быть |
|---|---|---|
| H1 | Повторить B1–B3 через «Войти через Apple» | Одно окно Apple; после входа прогресс на месте, «Способ входа · Apple» |
| H2 | Повторить C3–C4 через Apple | Прогресс на месте |
| H3 | Повторить F1–F4 через Apple | «Восстановить аккаунт?» после повторного входа Apple |
| H4 | Отменить окно Apple | Без окна ошибки, кнопки активны; при отказе Apple — «Apple не подтвердил вход. Попробуй ещё раз.» |

## I. Приватность и язык (≈1 мин)

| № | Что сделать | Что должно быть |
|---|---|---|
| I1 | Настройки → «Приватность и данные» → «Память диалогов» | Открывается экран «что сохранено / очистить»; «Назад» — обратно в Приватность |
| I2 | Настройки → «Язык интерфейса» → выбрать другой язык | Интерфейс сразу на новом языке; вернуть русский |
| I3 | На том же экране строка «Язык изучения» | Открывается шторка выбора языка изучения (новые языки помечены замком — так решено) |

## Что НЕ является ошибкой
- Гость при удалении получает «безвозвратно» — так задумано.
- Окно «Не получилось / Повторить» при удалении — только при настоящем сбое (обычно нет сети).
- Входа по почте нет.
- После удаления не показывается уведомление «аккаунт удалён» — решение владельца.
