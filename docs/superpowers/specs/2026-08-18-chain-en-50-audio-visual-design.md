# CHAIN EN 50 — спецификация озвучки и визуалов

Дата: 2026-08-18  
Исходный пакет: CHAIN_EN_50_5_STEPS_EXPLANATIONS_CAPCUT_FULL_PACK.zip

## 1. Объём пакета

Исходный проект содержит 50 английских цепочек по 5 шагов:

- 250 английских фраз;
- 250 русских переводов;
- 50 русских объяснений;
- 50 визуалов — по одному на цепочку;
- готовая CapCut-структура с папками 1–6.

Финальный аудиопакет содержит 1050 файлов:

| Папка | Содержание | Количество |
|---|---|---:|
| 1 | русские переводы | 250 |
| 2 | английский голос 1 | 250 |
| 3 | английский голос 2 | 250 |
| 4 | английский голос 3 | 250 |
| 5 | русские объяснения | 50 |
| 6 | визуалы с альфа-каналом | 50 |

## 2. Распределение голосов

Используются четыре голоса Learning V2:

- nova — русский голос для всех 250 переводов и 50 объяснений. Подача приятная, мягкая, современная, без назидательного тона и без рекламной интонации.
- ash — английский голос 1: медленный учебный темп, чёткая артикуляция, естественный британский/нейтральный учебный ритм.
- onyx — английский голос 2: медленный темп, более глубокая и спокойная подача, без театральности.
- coral — английский голос 3: обычный разговорный темп, живой и естественный, но с ясным произношением.

Английские голоса различаются по тембру и подаче. Ни один голос не произносит номера файлов, названия шагов, кавычки или дополнительные комментарии.

## 3. Формат и качество аудио

- Основной мастер-формат: WAV без потерь.
- Для каждой папки используется один и тот же формат и одинаковые параметры экспорта.
- Один TXT/одна строка источника = один аудиофайл.
- В начале и конце не добавляется искусственная длинная тишина.
- Между словами не добавляются искусственные паузы.
- Пунктуация исходного текста сохраняется только там, где она помогает естественной интонации.
- Реальная длительность каждого WAV измеряется сборщиком CapCut; длительность не рассчитывается по числу символов.

## 4. Нумерация и расположение

Нумерация строго соответствует исходному TIMELINE_MAP.csv:

- 1/001.wav … 1/250.wav;
- 2/001.wav … 2/250.wav;
- 3/001.wav … 3/250.wav;
- 4/001.wav … 4/250.wav;
- 5/001.wav … 5/050.wav;
- 6/001.png … 6/050.png.

Финальный повтор пятого английского шага повторно использует файлы из папки 2, как предусмотрено исходным проектом. Новые аудиофайлы для повторов не создаются.

## 5. Визуальный стиль

Название стиля: Soft 3D Clay Educational.

Каждая иллюстрация строится как мягкая объёмная миниатюра из матового clay-материала:

- один постоянный главный герой на протяжении всех 50 цепочек;
- округлые формы, мягкие края, тактильная матовая поверхность;
- тёплый рассеянный свет;
- современная палитра: бирюзовый, кремовый, коралловый и горчичный;
- дружелюбное выражение лица без мультяшной чрезмерности;
- простая сцена, один главный визуальный смысл на цепочку;
- никаких надписей, букв, логотипов и читаемых слов внутри изображения;
- все объекты полностью помещены в безопасную область;
- запрещено обрезание персонажа, багажа, мебели, транспорта и любых других объектов;
- финальный файл должен иметь настоящий прозрачный альфа-канал, а не шахматный фон и не белую подложку;
- один PNG относится ко всей цепочке из пяти шагов.

Постоянный герой сохраняет узнаваемые черты, причёску, пропорции и общий костюм. Меняются только действие, предметы и окружение, необходимые для конкретной цепочки.

## 6. Сборка и контроль

Перед финальной сборкой выполняются проверки:

1. все 1050 аудиофайлов присутствуют и имеют правильную нумерацию;
2. каждый аудиофайл соответствует строке из ELEVENLABS_BATCH_MANIFEST.csv;
3. все 50 визуалов присутствуют;
4. каждый визуал имеет альфа-канал;
5. ни один объект не выходит за безопасные поля;
6. CapCut-сборщик измеряет реальную длительность WAV;
7. после пересчёта нет наложений аудио, текста и объяснений;
8. BUILD_REPORT.txt, VALIDATION_REPORT.txt и PACKAGE_QA_REPORT.txt заканчиваются RESULT: PASS.

## 7. Ограничения

В этот этап не входят изменение исходной механики CapCut, изменение текстов фраз, перестановка цепочек, изменение таймингов вручную и замена постоянного героя после утверждения первого визуального образца.
