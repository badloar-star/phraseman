## Режим А («как сейчас»)
- [ ] Старт занятия списывает 1 энергию; шапка: энергия + сердечки + монеты.
- [ ] Ошибка: сердечко пропадает, монеты сбрасываются; энергия не меняется.
- [ ] Энергия 0: старт нового занятия → шторка Plus-предложения.
- [ ] Plus: ничего не списывается, остановок нет.

## Режим Б («энергия за ошибки»)
- [ ] Старт занятия НЕ списывает энергию.
- [ ] Шапка: энергия, БЕЗ сердечек.
- [ ] Ошибка: −1 энергия; иконка трясётся (shake), «−1» улетает (запись экрана, сверка тайминга с макетом).
- [ ] Монеты за ошибку не сбрасываются.
- [ ] Ошибка на ПОСЛЕДНЕЙ энергии → занятие останавливается; шторка «продолжить с Plus сейчас».
- [ ] «Оформить Plus» из шторки → занятие продолжается с того же вопроса (в dev-Plus).
- [ ] Выход после остановки; новый старт без энергии → шторка Plus; с 1 восстановленной энергией → старт.
- [ ] Восстановление со временем (10 мин, максимум 5) — индикатор.
- [ ] Plus: энергию не тратит ни в одном режиме.
