## Architecture
`queuedMessageRef: string | null` вместо булева флага: в нём уже проверенный текст, пузырь показан при постановке. Эффект на
появление сессии отдаёт текст в `send(queued)`, который не перечитывает поле ввода и не дублирует пузырь. Проверка текста
при постановке — `parseDialogueV2FreeformSessionTurnShape` с пробными id нужного формата (общий контракт не меняется).
`startInFlightRef` (поколение старта в полёте) и `retryBusyRef` — синхронные защёлки до любого await.
