# Lingman Algorithm Upgrade 008 - Universal Clarity And Full Rewrite Control

Дата:

```text
2026-05-20
```

## Причина

```text
Пользователь указал, что предыдущая правка была недостаточно значительной.
Нужно не полировать старый сценарий, а полностью пересобирать текст, если сценарий ощущается тем же самым.
Также нужен контроль бессмысленного юмора, obscure facts и непонятных сравнений.
Текст должен быть понятен любому новичку, даже ребенку, но при этом оставаться плотным, интересным и удерживающим.
```

## Новый Контроль Понятности

```text
Перед сдачей сценария нужно проверять каждый абзац вопросом:
поймет ли это умный 10-летний новичок без грамматического бэкграунда?

Если нет, абзац переписывается.
```

## Контроль Юмора

```text
Юмор допустим только если он:
- понятен без культурного контекста;
- помогает объяснить мысль или характер ведущего;
- не выглядит как отдельная вставка "тут шутка";
- не построен на случайном образе, который отвлекает от урока.

Запрещено:
- obscure jokes;
- бессмысленные сравнения;
- мемы ради мемов;
- "ИИ-шутки", которые можно узнать по случайности и переигрыванию.
```

## Контроль Фактов

```text
Факт остается в сценарии только если он:
- помогает понять английский;
- усиливает доверие;
- объясняет боль зрителя;
- дает практический критерий для речи.

Факт удаляется, если он:
- технически верный, но скучный;
- требует дополнительного объяснения;
- нужен только для демонстрации ресерча;
- может выбить зрителя из потока.
```

## Контроль Плотности

```text
Не ужимать сильное объяснение ради хронометража.
Лучше длиннее, но понятнее и интереснее.
Главный страх не "слишком долго", а "слишком сжато и сухо".
```

## Триггер Полной Переписи

```text
Если пользователь говорит, что сценарий почти не изменился, следующая версия должна быть создана заново:
- новый хук;
- новая структура;
- новый порядок примеров;
- новый рекламный мост;
- новый финал;
- без использования старого текста как шаблона.
```
