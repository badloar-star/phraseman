# Task packet: утверждённые тексты пейвола (36 входов × 9 языков) и пилюля «что закончилось»

Governance-ID: TG-1142EAB573EF
Status: In progress
Owner: сессия «1 · Ядро» (координатор 19:05/19:40/22:20: владелец утвердил тексты сессии 3 — docs/design/v2-app/paywall-context-texts.md)

## Outcome
1. `app/paywall_context_texts.ts` — утверждённые ru-тексты (заголовок / подзаголовок ≤ ~90 знаков / первая выгода) по
   всем входам и переводы на en, uk, es, pt-BR, vi, id, tr, pl («ты»-формы, где они есть). `theme` и `arena_limit`
   сняты по решению владельца (темы бесплатны, Арены нет). Числа — из констант кода, не из текста.
2. Пилюля «что закончилось» (`pill`) — у входов, где что-то кончилось или закрыто: энергия, разбор, урок N, подходы,
   место для карточек, тренировки, серия N дней, ответы, голос, попытки, бесплатные уроки, доступы. Число урока и
   длина серии — из параметров входа; нет данных — пилюля без числа.
3. `paywallContextHeadline` берёт тексты из нового модуля; сторож: у каждого входа белого списка все 9 языков и все
   поля, без кириллицы в латинских языках.

## Scope
In: новый `app/paywall_context_texts.ts`, `app/paywall_context_headline.ts`, `components/paywall/PaywallPlusScreen.tsx`
(только передача фактов входа в контракт), тест-сторож. Out: вёрстка шторки (Дизайн), старые тексты `paywall_copy.ts`
(их читают другие экраны — не трогаем).

## Architecture
Чистые данные + чистая функция. Факты входа (`lessons_done`, `streak`) приходят параметрами маршрута, которые входы
уже передают; лимиты — `REVENUE_DAILY_LIMITS`, `REVENUE_MONTHLY_LIMITS`, `MONTHLY_TRAINING_SESSION_LIMIT`,
`FREE_SAVED_CARD_LIMIT`, `FREE_AI_MISTAKE_EXPLAINS_PER_DAY_DEFAULT`.

## Security and privacy
Новых данных нет.

## Technical debt
- Pay now: пять входов показывали одинаковое «Продолжим курс?», «серия» говорила про энергию, лимит карточек
  в старых текстах — «20 фраз», а в коде действует 50 (числа теперь из констант).
- Contain: вход `lesson_b1` не вызывается ни одним местом (все закрытые уроки идут как `course_after_lesson3`) —
  текст оставлен, гейта по B1 нет; решение — за владельцем.

## Verification
Сторож текстов (9 языков × все поля × все входы), тесты пейвола, точечный typecheck.

## Rollback
Отдельный коммит; без нового модуля контракт возвращается к paywall_copy.ts.
