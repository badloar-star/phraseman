## Outcome

Решение владельца 04.11 (через координатора): (1) новые пользователи и все, у кого нет хотя бы одного завершённого занятия V2
(порог V2_UNLOCK_MIN_COMPLETED_EPISODES = 1, ответ владельца), V2 не видят: «Уроки» открывает обычный курс; (2) у кого прогресс есть, рядом с кнопкой «комбинированный урок»
остаётся вход в V2; (3) для остальных V2 не индексируется и не прогревается при старте; (4) ошибки и жалобы из V2 не уходят владельцу в Telegram
(сейчас только клиентская часть). Контент V2 не трогаем.

## Scope

- Новый `app/learning_v2_progress_gate.ts`: одна дешёвая локальная проверка (один `AsyncStorage.multiGet`, без сети и Firestore), память + подписка.
- `app/learning_v2_visibility_switch.ts`: `LEARNING_V2_HIDDEN` становится живой привязкой (`export let`), по умолчанию скрыт; открывается проверкой прогресса.
- Константы уровня модуля, посчитанные при импорте (`lessons.tsx`, `learning_v2_home_continue_route.ts`, `today_tasks_view.ts`), переводятся на функции.
- `app/_layout.tsx`: проверка при активном аккаунте; планировщик досылки завершений ставится только при наличии V2-следа.
- Клиентские отчёты: `logAppError` и `submitClientReport` пропускают источник learning_v2 (Crashlytics остаётся).
- Тесты: сторож видимости (обновление под новое решение), тест проверки прогресса, тест отчётов.

Вне задачи: серверный фильтр Telegram (деплой функций по кнопке владельца), контент V2, языковые курсы Classic9.

## Architecture

`LEARNING_V2_HIDDEN` читают ~45 мест в телах функций: живая привязка делает их динамическими без правок. Перерисовку экранов даёт хук
`useLearningV2Visible()`. Правило: в объединённой маске выполненных занятий (маски, цепочка, локальный список; языки en и es) не меньше
V2_UNLOCK_MIN_COMPLETED_EPISODES (=1) бит.

## Security and privacy

Новых данных нет: читаются существующие локальные ключи прогресса, наружу ничего не уходит. Политику менять не нужно.

- Появление V2 после восстановления из облака на новом телефоне — при ближайшей проверке (смена аккаунта, следующий запуск).

прогрев и планировщик не создаются; пользователь с пройденным уроком — вход есть.
