## Outcome

Набор, добавленный из видео (или из сообщества), сразу виден в «Моих наборах» независимо от его языка. «Мои наборы» открываются на языке цели обучения (не на глобальном сохранённом языке); если из-за языка не видно ни одного набора — показываются все, а при частичном скрытии над списком строка «Скрыто N: другой язык · Показать все». Кэш «набора нет» (30 мин) сбрасывается на добавлении. Журналы `[MY-PACKS]` и `[PACK-LANG]` показывают язык каждого набора, откуда он взят и что скрыто.

## Scope

In scope: `app/flashcards_my_packs.tsx` (фильтр языка переехал из загрузки в клиентский вид; событие `community_pack_added`; язык по умолчанию — цель обучения), `app/flashcards/MyPacksV2.tsx` (строка «Скрыто N»), журнал языка набора при добавлении (`communityPackActions.ts`), плитка «Мои» в хабе (R28), тесты. Out of scope: серверное определение языка набора из видео (Ядро), удаление и кэш видео (R31, Ядро).

## Architecture

Загрузка отдаёт ВСЕ мои наборы (без фильтра по языку) — смена языка не перечитывает данные (дешевле и мгновенно); фильтр применяется в `useMemo` с правилом «если скрыто всё — показать всё». Журнал — чистая функция `pack_lang_trace`.

## Security and privacy

Данные не собираются и не передаются; журнал пишет id и языковые поля наборов только в локальную консоль.

## Technical debt

Язык набора из видео сервер определяет по фразам (сомнение → en) — решение Ядра; клиент теперь не теряет такой набор.

## Verification

Тесты: набор it при языке en виден; фильтр скрывает часть и показывает строку; пусто → показать все; сброс кэша на событие; язык по умолчанию — цель обучения. Затронутые контракты Карточек. Снимки — Сверке.
