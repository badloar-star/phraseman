# ✅ CHECKLIST — финальная проверка сценария перед отдачей автору

> Пройти ПЕРЕД тем, как вывести сценарий в чат. Если хоть один пункт «нет» — доработать.

## ФОРМАТ
- [ ] 3-4 цепочки (ситуации) за видео.
- [ ] В каждой цепочке есть наращивание (минимум 2-3 шага, где осмысленно).
- [ ] Каждый шаг прошёл по слоям: ситуация → фраза → разбор слов → этимология/факт → почему так → тон → повтор+проговор.
- [ ] Каждая фраза дана с русской транскрипцией («как звучит») + переводом.
- [ ] Каждая ключевая фраза повторяется в тексте минимум 2 раза.

## ГОЛОС (живость)
- [ ] Прочитал вслух — нигде не споткнулся, не стало скучно.
- [ ] НЕТ ИИ-маркеров («давайте погрузимся», «в этом видео мы рассмотрим», симметричные тройки, канцелярит).
- [ ] Есть конкретные картинки/ситуации, а не абстракции.
- [ ] Есть тёплый человеческий момент / улыбка (юмор не шаблонный).
- [ ] Обращение на «вы», уважительно, без снисходительности и без молодёжного сленга.
- [ ] Темп размеренный, короткие предложения, заложены паузы.

## ВКУС (STYLE_FUSION)
- [ ] Холодный старт через конкретику (слово/сценка/странность), а не «сегодня тема».
- [ ] Есть хотя бы одна открытая петля (обещание + задержка ответа, 15-20 сек).
- [ ] Есть метафора-мост или сочная история минимум для одной фразы.
- [ ] Хотя бы для одной фразы развёрнуто «микро-эссе» (6 тактов из STYLE_FUSION) — там, где этимология сочная.
- [ ] Эмоция раньше логики хотя бы раз («как удобно!/вот это да» → потом разбор).
- [ ] Контраст темпа: плотные куски чередуются с лёгкими/паузами.
- [ ] Финал — послевкусие с возвратом к началу, а не «итак, запомните».
- [ ] Настроение СВЕТЛОЕ (любопытство/восхищение). НЕТ чужого мрака/тяжести/грусти/эзотерики.
- [ ] Бережность: ошибаться не стыдно, автор «на стороне» зрителя.

## АУДИТОРИЯ 40+/50+
- [ ] Где уместно — снят страх «поздно/память не та» (хотя бы лёгким штрихом).
- [ ] Маленькие порции, одна грам-мысль за раз, без перегруза.
- [ ] Заложены повторы и проговор вслух.

## РЕСЁРЧ (честность)
- [ ] Этимология/факты проверены, не выдуманы. Спорное — помечено «(уточнить)» или убрано.
- [ ] Указана типичная ошибка русскоязычных там, где она есть.

## PHRASEMAN
- [ ] 2-3 лёгких нативных касания (польза/факт/«проверь себя»), НЕ реклама.
- [ ] 1 полноценная интеграция (обычно цепочка №3).
- [ ] Нет запрещённого: «спонсор», «купите/цена/подписка» в лоб, обещаний несуществующих фич.
- [ ] Формулировки касаний не дублируют прошлые видео.

## СЕРИЙНОСТЬ
- [ ] 2 отсылки назад (на разобранное из PHRASES_LOG.md).
- [ ] 1 крючок вперёд (open loop) — занесён в SERIES_STATE.md.
- [ ] 1 мостик для новичка (зашедший на середину серии не чувствует себя потерянным).
- [ ] Лёгкое ощущение прогресса/нумерации.

## ПАМЯТЬ (шаг 6 — без этого урок не засчитан)
- [ ] Сценарий сохранён в `scripts/ГГГГ-ММ-ДД_NNN_название.md`.
- [ ] `memory/PHRASES_LOG.md` дополнен новыми фразами/словами.
- [ ] `memory/CURRICULUM.md` — урок отмечен снятым, план скорректирован.
- [ ] `memory/SERIES_STATE.md` — крючки/линии обновлены.
