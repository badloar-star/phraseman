# Вкладки «Уроки | V2» вверху списка уроков, как в макете (learn-007/008/011, владелец 13.10, вопрос 18, до 16.10)

Governance-ID: TG-8310FD2F5782
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора от владельца)

## Outcome
Вверху списка уроков стоит переключатель «Уроки | V2» (макет `docs/design/v2-app/learn.html`, `.lvtabs`). Вкладка «V2» ведёт в существующий вход Learning V2 (`LearningV2ChaptersCourse`, экраны V2 не меняются). Выбранная вкладка хранится локально: при следующем входе список открывается сразу на ней, переключение мгновенное, без ожидания сети. Логи `[LESSONS-TABS]`.

## Scope
Правка `app/(tabs)/lessons.tsx`: сам переключатель (подчёркнутые вкладки «Уроки», «V2» и «Диалоги» при включённом доступе) уже есть в шапке; добавляется память выбранной вкладки (ключ `lessons_tab_page_v1`), стартовая вкладка из неё и логи. Тест источника `tests/lessons_tabs_memory.test.ts`. Не трогаются: экраны и модули Learning V2, Диалоги, расчёты уроков.

## Architecture
Модульная переменная в памяти процесса читается синхронно в первом кадре; AsyncStorage читается один раз при загрузке модуля и подставляет вкладку тихо, если человек ещё не тапнул. Запись — только по тапу на «Уроки»/«V2» (Диалоги не запоминаются). «V2» запоминается и восстанавливается только если курс доступен (`LEARNING_V2_COURSE_CAN_BE_OPENED_MANUALLY`).

## Security and privacy
Хранится одно слово («lessons»/«v2») на устройстве; в облако не уходит, политика не меняется.

## Technical debt
Раньше вход всегда открывал «Уроки» безусловно (решение 20.09). Теперь вход открывает последнюю выбранную вкладку по решению владельца 13.10; при желании вернуть прежнее — убрать вызов `startLessonsPage`.
