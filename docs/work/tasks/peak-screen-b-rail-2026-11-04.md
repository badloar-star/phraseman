## Architecture

Новый презентационный компонент PeakScreenV2 получает уже вычисленные данные из SpireHomeScreen (участники, этаж, подписи) и ничего не читает сам. Включается константой флага; без флага поведение прежнее. Модель — чистые функции, зоны по тому же рубильнику rankBy, что и итог недели.

## Security and privacy

Новых данных не собирается и не передаётся; используются поля комнаты, уже читаемые экраном (имена, монеты). Политика конфиденциальности не затрагивается.
