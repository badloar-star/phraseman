# Урок 27 · Заняття 20 — Інший план поїздки

**Ситуація.** Потрібний автобус не ходить. Ви шукаєте інший шлях, уточнюєте час і пояснюєте, що вас не влаштовує.

**Що ви опануєте:** сказати, що було б, якби…, і дати пораду «на вашому місці я б…»
**Нові слова:** unfortunate, roadside, unwise, dissatisfied

## Інтро 1

### Якби поїздка могла тривати довше

Ви з другом хочете затриматися в місці відпочинку, але сьогодні потрібно повертатися. Поясніть: We would stay longer if we had more time — ми б залишилися довше, якби мали більше часу. Would stay — уявний результат. If we had more time — умова, якої зараз немає. Складаємо речення: We + would stay + longer + if we had more time — хто, що зробив би, наскільки довше, за якої умови. Після would потрібна stay; в умові had без would.

**Виберіть фразу для цієї ситуації.**

- ✅ **We would stay longer if we had more time.**
- ❌ We would stayed longer if we had more time. — *Після would потрібна форма stay.*
- ❌ We would stay longer if we would had more time. — *В умові потрібне had без would.*

## Інтро 2

### Порадити раніший автобус

Друг вибирає автобус і побоюється запізнитися до місця зустрічі. Ви вважаєте, що краще виїхати раніше. Порадьте: If I were you, I would take the earlier bus — на твоєму місці я б сів на раніший автобус. If I were you вводить пораду. Складаємо речення: If I were you, + I would + take + the earlier bus — на твоєму місці, я б, яка дія, який автобус. Після умови ставимо кому; після would — take без to.

**Виберіть фразу для цієї ситуації.**

- ✅ **If I were you, I would take the earlier bus.**
- ❌ If I were you, I would took the earlier bus. — *Після would потрібна форма take.*
- ❌ If I were you, I would to take the earlier bus. — *Після would не ставимо to.*

## Інтро 3

### Коли перевірили розклад

Зараз вечір. Друг запитує, коли ви перевіряли розклад, і ви відповідаєте про ранок, який уже закінчився: I checked it this morning — я перевірив його сьогодні вранці. It замінює the timetable. Checked — минула форма check. У цій ситуації ранок завершився, тому потрібен Past Simple без have. Складаємо речення: I + checked + it + this morning — хто, дія в минулому, що перевірив, коли.

**Виберіть фразу для цієї ситуації.**

- ✅ **I checked it this morning.**
- ❌ I have checked it this morning. — *У цій вечірній сцені ранок завершився: checked без have.*
- ❌ I check it this morning. — *Тут ідеться про минуле: checked.*
