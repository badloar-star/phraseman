## Outcome

Тесты, которые проверяют поведение уже удалённых механик (и потому падают), убраны. Действующие проверки (покупки, синхронизация, безопасность, права Plus, идемпотентность актуальных функций) остаются. Успех: затронутые наборы проходят целиком; число оставшихся тестов не падает ниже числа действующих; список удалённого записан в PROGRESS.md по названиям.

## Scope

In scope: тесты, которые сейчас падают ИЗ-ЗА ретайра: `functions/src/community_packs.test.ts` (32 случая official/level-gift/Spin/league grant), `functions/src/friend_activity_likes.test.ts` (5, если причина — лиги), `functions/src/admin_final_sensitive_writes.test.ts` (3 про admin_league_controls), `tests/economy_constitution_contract.test.ts` (3 про удалённые модули).
Out of scope: любые тесты, падающие по другой причине; тесты безопасности, прав и идемпотентности актуальных функций; тесты Арены; чужие рабочие изменения других сессий.

## Architecture

Без изменений кода приложения. Тест удаляется только если (а) он проверен чтением и его падение доказано ссылкой на удалённый символ, файл или поведение, (б) поведение удалено по решению владельца.

## Security and privacy

Тесты безопасности актуальных путей (auth, права admin, идемпотентность, защита от двойной выдачи) НЕ удаляются. Каждый удаляемый тест перед удалением сверяется с этим правилом; сомнительные остаются.

## Technical debt

Pay now: устаревшие ожидания убираются. Contain: пробы-ратчеты (retired_*, *_retirement) уже защищают отсутствие удалённого; список удалённых тестов фиксируется в PROGRESS.

## Verification

Точечный прогон каждого затронутого набора до и после (для tests/ — `npm run test:one`, для functions — с поднятой кучей); ожидание — 0 падений; счёт pass до/после записать в PROGRESS.

## Rollback

Файлы не закоммичены: восстановление удалённых тестов — из git (`git show HEAD:<путь>`), копированием нужных блоков. Данные не затрагиваются.
