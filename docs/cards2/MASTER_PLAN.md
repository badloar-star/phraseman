# Мастер-план Cards 2.0 — «Колода» (ФИНАЛ)

Финальная версия: драфт + правки ревью (`CRITIQUE.md`), сверено с кодом 2026-08-10.
Уже исправленное в коде вычеркнуто из бэклога, недостающие пункты критики добавлены и назначены этапам.

**Рамочные принципы (обязательны для каждого решения):**
1. Одна модель сессии везде: конечная сессия N карточек → сегмент-прогресс → экран результата 0–3★. Никаких бесконечных очередей.
2. ≤2 тапа до любой тренировки с любого экрана раздела. Достигается «быстрым стартом»: тап по режиму запускает сессию с последним пресетом (набор+размер), `DeckPickerSheet` открывается по long-press / иконке настройки — НЕ обязателен на пути к старту.
3. Анимации = только `transform` + `opacity` на UI-потоке (Reanimated 4). Бюджет-устройство: **Helio G35 / 3GB RAM / 60fps**. ≤8 живых анимаций одновременно, ≤3 смонтированных полноразмерных карточек, ноль блюров. **Не ставим** Lottie/Skia/Moti/Rive.
4. Данные не ломаем. Реальные существующие ключи (сверено с `app/cloud_sync.ts` и `hooks/use-flashcards.ts`): `flashcards_v1` (сохранённые карточки), `custom_flashcards_v2` (юзерская библиотека; ключа «flashcards_custom» НЕ существует), `flashcards_progress_v1`, `flashcards_owned_packs_v1`, `trainer_store_v1`, `active_recall_items`. Все — неприкосновенны; правила `docs/FLASHCARDS_RULES.md` и языковые инварианты handleSave — тоже. Новые фичи — только новые ключи. **Все записи `custom_flashcards_v2` — через одну очередь записи (functional-update, по образцу mutex-очереди `app/trainer_store.ts:91`)** — иначе undo-паттерн «запись после таймаута» теряет данные.
5. Деградация на слабых устройствах: `lowPowerMode` = авто (`expo-device` **totalMemory строго < 3GB**) ИЛИ тумблер «Упрощённые эффекты» + существующий reduceMotion. Эталон Helio G35 / ровно 3GB под порог НЕ попадает → **на эталоне принимается полный 3D-флип 60fps**, не кроссфейд. Все декоративные эффекты обязаны иметь ветку деградации.
6. Локали ru/uk (+es): все новые строки — через существующий triLang-механизм, ни одной хардкод-строки.
7. **Web-совместимость обязательна**: смоук-тесты гоняются через expo web + Playwright (сценарии в `/home/claude/shots/flows`). Каждая новая фича обязана иметь ветку `Platform.OS === 'web'` там, где нативное API недоступно (жесты → дублирующие кнопки, 3D-флип → кроссфейд, InteractionManager → прямой вызов — паттерн уже практикуется, см. `flashcards_collection.tsx:754`).

**Метрики успеха:** D7 retention раздела; сессий/день; доля perfect sessions; claim rate сундуков; доля пользователей слушания; 60fps UI-потока при свайпе/флипе на эталоне (проверка `useFrameCallback`-счётчиком при искусственном JS-фризе).

## 2. Дизайн-язык

**Метафора: физическая колода в руках.** Карточка — один тактильный предмет с одним видом, одним флипом, одним звуком, одной хаптикой во всех местах, где она карточка (колода, words-сессия, слушание).

**Карточка (`PhraseCard`):**
- Скругление 24; градиент лица из темы пака (`getCardPackPaywallTheme`), акцент — через контраст-чек с осветлением на тёмных темах (7 существующих тем из `constants/theme.ts`, новых цветов не вводим).
- Лицо: EN-фраза + транскрипция + динамик (единая позиция справа везде — убрать `voiceSpeakOnRight`); рубашка: перевод + пример.
- «Толстая» нижняя грань 4px в цвет акцента; при нажатии карточка сдвигается вниз на 2px, грань сжимается (Duolingo-press). Тот же приём — на всех CTA сессий.
- Высота в списке — адаптивная по контенту (min 120), убить фикс CARD_H 224. Плотность списка **~×1.9–2** от текущей (не «×3» — при min 120 против 224 больше физически не выходит).
- Индикатор силы слова: точка Weak/Medium/Strong (интервалы SRS 1–3 → Weak, 7–14 → Medium, 30 → Strong; цвета из темы) — на карточке и в строке списка.
- Бейдж источника: «Урок 1» локализованно вместо «ГЛАГОЛ LESSON1».

**Типографика:** системные шрифты (не меняем); EN — крупный semibold, транскрипция — secondary, перевод — regular.

**Движение — `constants/flashcards_motion.ts`:**
```ts
export const FC_SPRING = {
  press:  { damping: 16, stiffness: 420 },        // вынесено из HubTileShell
  flip:   { duration: 450, dampingRatio: 0.8 },
  return: { duration: 350, dampingRatio: 0.7 },
  ring:   { duration: 800, dampingRatio: 1 },
};
export const FC_TIMING = { fast: 150, base: 250, enter: 300, flyStar: 600 };
export const FC_STAGGER = { step: 60, cap: 8 };   // delay = min(i, 8) * 60
```
Всё уважает reduceMotion/lowPowerMode/web: флип → кроссфейд 150мс, частицы → scale-пульс + хаптика, параллакс/стагер → off.

### 3.3 Карточка `PhraseCard` — флип и жесты
**3D-флип (замена scaleX):**
```
transform: [{perspective: 1200}, {rotateY: 0↔180}]  // perspective ПЕРВЫМ
withSpring(FC_SPRING.flip)
backfaceVisibility: 'hidden' + фолбэк-переключение opacity на 90° внутри useAnimatedStyle
   (официальный паттерн доков Reanimated — чинит старые Android и web)
параллельно scale: withSequence(1→1.04 за 120мс, →1 за 180мс)
useAnimatedReaction на пересечении 90° → runOnJS: impactAsync(Light) + SFX flip
```
Web — фолбэк на кроссфейд (обязателен: Playwright-смоук флипает карточку). reduceMotion/lowPower — кроссфейд 150мс. Автоозвучка EN при флипе (настройка «Автопроизношение», дефолт on).

**Свайп-оценка (в сессиях):** `Gesture.Pan` с `activeOffsetX([-10,10])`; порог = 35% ширины ИЛИ velocityX > 800; rotateZ ±12°; overlay «Знаю» (зелёный) / «Учу» (оранжевый), opacity = interpolate(tx); `selectionAsync` один раз на пересечении порога (флаг в SharedValue). Улёт — withTiming 250мс; возврат — spring 350/0.7. **Undo обязателен**: «↩» 3с + swipeBack. Дублирующие кнопки ✓/✕ внизу — одноручный режим, доступность и **единственный способ оценки на web** (смоуки жмут кнопки).

## 4. Система звёзд (экономика C — гибрид)

**Роль:** звёзды = метрика качества сессии, НЕ кошелёк (кошелёк — осколки). Не покупаются. Выплаты — через `shards_system.ts`. Ноль новых валют, weekly reset. Все числа — в `app/flashcards/stars_config.ts`.

**Заработок за сессию**, пороги видны до старта:
- ★ — accuracy ≥ 70%
- ★★ — accuracy ≥ 90%
- ★★★ — 100% + среднее время ответа ≤ порога **пер-режимно**: свайп/выбор 5с, письменный ввод 12с, fill_gap 10с.
- Слушание: фикс 1★ за сессию ≥10 карточек.
- Режим «Колода» (просмотр) звёзд **не даёт** — нет механики оценки.

**Таблица «режим × дневной free-лимит × звёзды» (п.13–14 критики, единственный источник правды — дублируется константами в `stars_config.ts`):**

| Режим | Free-лимит (день) | Звёзды | Дневной кэп ★ с источника |
|---|---|---|---|
| Тренер words/phrases/arena | 1 бесплатная сессия (`trainer_session.ts`), премиум — безлимит | 0–3★ | 3★ |
| «Тренировать эту колоду» (custom deck через тренер) | входит в тот же лимит тренера | 0–3★, анти-фарм ниже | 3★ (общий с тренером) |
| Review (SRS) | безлимит — core loop | 0–3★ за сессию | 6★ |
| Слушание | безлимит | 1★ за сессию ≥10 карточек | 2★ |
| Блиц | безлимит | 0–3★ | 3★ |
| Колода (просмотр) | безлимит | — | — |

Free-юзер собирает 21★/нед при ~3★/день из смеси review+слушание+блиц — лимит тренера недельный трек НЕ ломает (проверяется юнит-тестом «неделя free-юзера»).

**Анти-фарм кастомных колод (п.13):** сессия по кастомной колоде даёт звёзды, только если содержит ≥10 карточек, из них ≥10 **уникальных, не тренированных сегодня** (учёт id в `fc_stars_v1.customTrainedToday`). Колода из «a→a» ×10 фармится максимум один раз в день на 3★ — в пределах кэпа тренера, экономика не течёт.

**Недельный трек 21★**, reset по **ISO-week UTC** (`weekKey: "2026-W33"`; НЕ «понедельник 00:00 локали» — см. merge в §1). Сундуки-чекпоинты (клейм тапом на хабе): 7★ → 20–40 осколков, 14★ → 40–80, 21★ → 100–200 + косметика (рубашка колоды). Ролл 70/25/5 (джекпот ×2). Эмиссия ≤ ~320 осколков/нед. Стрик ≥7 дней → порог идеальной недели 18★. Perfect session → буст XP ×1.5 на 15 минут.
**Защита от двойного клейма чекпоинтов с двух устройств:** merge `checkpointsClaimed = union` (клейм — идемпотентное множество), а сама выплата осколков за чекпоинт `{weekKey}:{checkpoint}` дополнительно регистрируется в **`shards_one_time_events`** (уже в SYNC_KEYS, `cloud_sync.ts:172`; готовый механизм `shards_system.ts:74`) — второй девайс увидит событие и не выплатит повторно.

**Долгосрочный хук:** best-рейтинг колод 0–3★ в `fc_deck_best_stars_v1` (+SYNC_KEYS, merge max); «тускнение» через 7 дней без тренировки; milestone-сундуки за суммарные best-звёзды: 10★ → 50 осколков, 25★ → 150 + рамка, 50★ → 400.
**Дюп-защита milestone (п.11 критики):** флаги клейма — ТОЛЬКО в `shards_one_time_events` (ключи `fc_milestone_10|25|50`), не в локальном ключе. Переустановка → best-звёзды восстановятся из синка, а даже при потере — one-time события не дадут повторной эмиссии.

**Хранение и оптимистик:** начисление оптимистичное — звезда летит в счётчик мгновенно, AsyncStorage-запись после анимации; то же для клейма и удаления карточек (всегда через соответствующую очередь записи). Клейм чекпоинта: тряска сундука 3×80мс → burst 12–16 частиц (lowPower — пульс+хаптика).

## 5. Звук и хаптика

`SoundService` (**на `expo-audio`** с E1): пул плееров на 9 SFX, `seekTo(0)` перед play. Файлы: Kenney UI Audio / uisfx (CC0), одно тембровое семейство, нормализация −16 LUFS, пики −6 dBFS, mp3 mono ≤30KB (бандл +~250KB); существующие 7 mp3 в `assets/sounds` ревизовать под семейство.
**⚠ Производство аудио — отдельная задача вне бюджета строк кода (п.19 критики):** «маримба C5→E5», пре-рендер комбо-питчей +2/+4/+6 и сведение к −16 LUFS не существуют в Kenney готовыми — это ручная звукорежиссура (ffmpeg/sox pitch-shift + loudnorm, скрипт в `scripts/audio_pipeline.sh`). Закладывается как подготовительная подзадача этапа E9 с фолбэком: до готовности семейства — 3 временных CC0-звука (correct/incorrect/flip), карта событий уже работает.

Тумблеры «Звуковые эффекты» и «Автопроизношение» в настройках раздела. Правило очереди: SFX (≤400мс) → пауза 120мс → TTS, никогда одновременно. Хаптика дублирует каждый звук; из worklet — только runOnJS.
**Платформенный маппинг хаптики (п.23, явно):** iOS — полный набор (`notificationAsync` Success/Error, impact Light/Medium); **Android — любые notification*/Medium деградируют до `impactAsync(Light)`, порог свайпа — `selectionAsync`**; web — хаптики нет, no-op. Единая обёртка `fcHaptic(event)` внутри SoundService.

| Событие | Звук | Vol | Хаптика (iOS / Android) |
|---|---|---|---|
| Флип карточки | бумажный flick 80–150мс | 0.3 | Light / Light — на 90° |
| Свайп «знаю» | восходящий whoosh+tick 150мс | 0.3 | Success / Light |
| Свайп «учу» | нисходящий whoosh 150мс | 0.3 | Light / Light — не наказываем |
| Пересечение порога свайпа | — | — | selection / selection, 1 раз (флаг в SharedValue) |
| Верный ответ | 2 ноты вверх C5→E5, маримба, 300мс | 0.55 | Success / Light |
| Неверный ответ | мягкий thud вниз 200мс, **без buzzer** | 0.4 | Error / Light |
| Комбо ×3/×5/×10 | тот же мотив, питч +2/+4/+6 (пре-рендер) | 0.6 | 2×Light шаг 100мс |
| Звезда / сундук | sparkle 400мс | 0.5 | Medium / Light |
| Финал сессии | арпеджио 3–5 нот, ≤900мс | 0.7 | 3×Light по 100мс |
| Открытие пака (церемония) | riser 600мс + sparkle на reveal | 0.6 | Medium / Light |
| Смена карточки в слушании | тихий tick 30мс | 0.2 | — |
| Кнопки | без звука | — | selection только на сегментах/табах |

Аудио-политика: `mixWithOthers` глобально, `duckOthers` только в слушании; `playsInSilentMode: true` до первого TTS.
