# Урок 27 · Заняття 01 — Якби було інакше

**Ситуація.** Ви обговорюєте поїздку, уявляєте будинок із садом та обираєте відповідне житло.

**Що ви опануєте:** if + past simple, would + base verb
**Нові слова:** possibly, naturally, obviously, frankly

## Інтро 1

### Якби було більше часу

У вас мало вільного часу, але ви уявляєте інше життя: If I had more time, I would travel — якби в мене було більше часу, я б подорожував. Had тут не розповідь про минуле: це уявна ситуація зараз або в майбутньому. Після if ставимо past simple, а в результаті — would і початкову форму: would travel. Possibly — можливо. I would possibly take a train — можливо, я б поїхав потягом. Так ви залишаєте вибір відкритим.

**Виберіть фразу для цієї ситуації.**

- ✅ **If I had more time, I would travel.**
- ❌ If I would have more time, I would travel. — *В умові потрібно had, без would.*
- ❌ If I had more time, I would travelled. — *Після would потрібна початкова форма travel.*

## Інтро 2

### Будинок із садом

Друг показує невеликий будинок. Naturally — природним чином, без втручання людини. These flowers grow naturally here — ці квіти ростуть тут самі по собі. Ви уявляєте свій сад: We would grow vegetables if we had a garden — ми б вирощували овочі, якби в нас був сад. Результат можна поставити першим; перед if у такому порядку кома зазвичай не потрібна. Сад поки існує лише в розмові, а список овочів уже зайняв цілу сторінку.

**Виберіть фразу для цієї ситуації.**

- ✅ **We would grow vegetables if we had a garden.**
- ❌ We would growing vegetables if we had a garden. — *Після would потрібно grow.*
- ❌ We would grow vegetables if we would had a garden. — *В умові потрібно had без would.*

## Інтро 3

### Висловити свою думку

Ви оглядаєте кімнату вдвох. Obviously — очевидно: It is obviously too small — вона явно замала. Frankly — відверто кажучи: Frankly, I need a break — відверто кажучи, мені потрібна перерва. Це слово робить думку прямою; з незнайомою людиною воно іноді звучить різко. Друг запитує про можливий переїзд. I would move if I found a job — я б переїхав, якби знайшов роботу. Found — форма find; тут ви уявляєте умову, а не повідомляєте, що вже знайшли роботу.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would move if I found a job.**
- ❌ I would to move if I found a job. — *Після would не ставимо to.*
- ❌ I would move if I finded a job. — *Минула форма find — found.*
