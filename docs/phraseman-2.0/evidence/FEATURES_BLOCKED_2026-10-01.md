## 4. Вопросы координатору (нет в 03_DECISIONS.md)

1. **Голос собеседников в Диалогах V2 (`voiceMode`).** В одобренном контенте поля нет; во
   встроенном выпуске стоит `text_only` (готовой озвучки реплик нет, `optional_prepared_voice`
   заставил бы сервер искать несуществующие клипы). Варианты: (а) оставить `text_only`
   (рекомендую до появления озвучки); (б) `optional_prepared_voice` для всех после
   озвучки реплик. Смена = правка константы в генераторе + перегенерация.
2. **`groupReplyPolicy`.** Вывел из контракта: `maxDirectReplies 1`, `silenceAllowed true`,
   `maxUsefulFollowUps` = 1 только для сцен с 2+ собеседниками (24 сцены), иначе 0.
   Подтвердить или задать иначе.
