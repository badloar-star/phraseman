# Звёзды оценки на карточках эпизодов — цвета в оттенках темы

Governance-ID: TG-3908D1010FB0

## Outcome
Координатор (владелец просит оценку на пройденных карточках): токены цвета звёзд «заполненная / пустая» в оттенках текущей темы, без жёлтого и золотого. Отдать 2 · ДИЗАЙН для хаба урока.

## Scope
In scope: новый `components/learning-v2/season/season_star_tones.ts`, тест `tests/season_star_tones.test.ts`.
Out of scope: сама разметка звёзд и данные оценки (2 · ДИЗАЙН и Learning V2).

## Architecture
`seasonStarTones(themeHue)` → `{ filled, empty }`, где `themeHue = hexHue(g.accent)`: заполненная — почти белая с лёгкой тонировкой оттенка темы (OKLCH L 0,98, C 0,03), пустая — светлее фона, но заметно тусклее (L 0,84, C 0,05). Лежат на градиенте карточки `seasonThemedArt`. Кэш по округлённому оттенку.
