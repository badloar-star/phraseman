# Два режима энергии — отображение и анимации (Дизайн)

Governance-ID: TG-778093E55379
Governance-ID: TG-8DC1A581DEB0

## Outcome
По ТЗ владельца (docs/phraseman-2.0/ENERGY_MODES_OWNER_BRIEF_2026-10-11.md): режим Б — энергия снимается за ошибки (по 1), сердечек нет; анимация снятия (shake иконки + «−1»); остановка занятия при ошибке на последней энергии с предложением «Продолжить с Plus сейчас»; шторка «Нужна энергия» при попытке начать без энергии. Режим А (по умолчанию) — как сегодня. Места: уроки, слова, неправильные глаголы, Learning V2, «Карточки: тренировка». В диалогах и «Фразе дня» без изменений.

## Scope
`components/energy/EnergyMistakeHud.tsx` (новый), `components/session_attempts/SessionAttemptsHud.tsx` (переключение по режиму), экран остановки и шторка «Нужна энергия» (новые компоненты), тесты. Логика режима, списания и остановки — у Ядра (`app/energy_mode.ts`, `useSessionAttempts`, `useEnergySessionIntent`).

## Architecture
Все десять экранов с сердечками рисуют их через один `SessionAttemptsHud`; в режиме Б он вместо сердечек показывает `EnergyMistakeHud`, который сам следит за падением энергии (`useEnergy`) — экраны не правятся. Анимации на нативном драйвере; «уменьшить движение» — без shake, «−1» только растворяется.

## Security and privacy
Данные не затрагиваются.

## Technical debt
Не добавляется; новые компоненты изолированы, сторожа обновляются вместе с кодом.

## Verification
Типы, юнит-тесты компонента (падение энергии → shake и «−1», reduce motion, режим А без изменений), сторожа раскладки и типографики, кадры Эмулятора по макетам сессии 3.

## Rollback
Откатить коммиты; режим по умолчанию А не меняет прежнее поведение.
