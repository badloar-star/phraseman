## Этап 1 — ВАУ-слой: анимации + звук (1–2 дня)

> Всё по Performance Bible: только `transform`/`opacity` c native driver,
> никаких незащищённых лупов, не ломать `tests/perf_freeze_contract.test.ts`.

1. **Переходы между шагами.** Общий shell остаётся (как в Duolingo), контент шага —
   fade+slide (выход 120мс влево, вход 200мс справа, мягкий easing). Прогресс-бар —
   анимированная ширина со spring-довеском.
2. **Welcome-сцена:** лого scale-in с overshoot + лёгкое «дыхание» (пульс 1.0→1.03,
   guarded loop), заголовок «От первых слов до свободной речи.» **печатается**
   (typewriter ~35мс/символ, мигающий курсор), CTA появляется fade-up после допечатки.
3. **Реакции Компаса печатаются.** Реализовать bubble-реакции из спека (§4–6: на уровень,
   цель, минуты) c typewriter-эффектом — это и вау, и «приложение тебя услышало».
   Один переиспользуемый компонент `TypewriterText` (интервал, onDone, skip по тапу).
4. **Карточки вариантов:** staggered-каскад появления (40–60мс сдвиг), при выборе —
   scale 0.97→1 + заливка/чек с fade.
5. **Звук:** подключить готовый `useOnboardingSounds` —
   `playDemoCorrect` (успех mini-aha), `playPlanReady` («Маршрут готов»),
   `playPurchaseSuccess` (оплата). Рядом `hapticSuccess`; на ошибку в mini-aha —
   `hapticWarning`. Уважать глобальный флаг звука.
6. **Конфетти/glow на пиках:** успех mini-aha и «Маршрут готов» — короткий burst
   (не дольше 1200мс, native driver).

## Этап 2 — Новые экраны и порядок (2–3 дня) — главные рычаги конверсии

1. **Mini-Aha (спек §7) — реализовать.** 3 микродействия по выбранной цели:
   послушай живую фразу → выбери естественный ответ → собери реплику из chips.
   Контент-таблица уже в спеке (кафе/встреча/сериал/small talk/бытовая/база).
   Успех = звук + конфетти + hapticSuccess + мост: «Это фраза из твоего маршрута.
   Дальше — ещё сотни таких». *Reciprocity: первая победа бесплатно.*
2. **«Собираем твой маршрут» (plan building).** 1.5–2.5с анимированный чек-лист,
   зеркалящий ответы: «Цель: путешествия ✓ · Старт: с нуля ✓ · Темп: 10 мин/день ✓ →
   Подбираем фразы…». Финал — пик «Маршрут готов» + `playPlanReady`. *IKEA-эффект +
   peak-end перед продажей.*
3. **Персональный результат маршрута.** Карта недель: 1-я открыта (темы видны),
   остальные с замками и названиями тем. *Loss aversion: видно, ЧТО заблокировано.*
   Единственная CTA «Открыть мой маршрут» → startMode. Никаких «продолжить без плана».
4. **Новый порядок:**
   `welcome → intro → level → goal → minutes → mini-aha → building → result →
   notifications → promise(3 мес) → startMode → plusBenefits → paywall → name → age/legal`
   - **source («как узнал») — убрать из начала**: в конец (после name) или на день 2.
     Спек сам флагует его как первого кандидата на вылет (строка 110).
   - notifications ПОСЛЕ mini-aha/победы (спек, строка 239) — сейчас стоит до какой-либо
     ценности.

## Этап 3 — Тексты: переписать под продажу трансформации (1 день)

Принципы (эмоции → логика; продаём трансформацию, не продукт; «ты/твой»; зацепить быстро;
возражения сразу; конкретика):

1. **Welcome:** вместо описания продукта — результат:
   «Заговори по-английски. Не когда-нибудь — этой осенью.» (или текущий слоган спека,
   но с печатающимся эффектом). Подзаголовок: «Живые фразы · короткие сессии · твой маршрут».
2. **Promise (3 месяца):** оставить 3 блока спека, усилить конкретикой ситуаций
   («кафе, дорога, встреча»), без числовых клеймов.
3. **plusBenefits:** заголовок «Plus открывает твой маршрут полностью» + 5 анимированных
   пунктов из спека (появляются по одному с чеком и haptic-tick).
4. **Пейвол:** блок-витрина «{N} недель · 350+ живых фраз · разбор твоих ошибок»,
   строка-отличие «Не зубрёжка слов — разговор и разбор ошибок под твою цель»,
   соц-доказательство (реальное число учеников), снятие риска: «Платить сейчас не нужно —
   напомним, отменишь за день до конца, спишется 0».
5. Все реакции Компаса — из таблиц спека (§4–6), голос по канону Компаса
   (от первого лица, без пафоса и слоганов).

## Этап 4 — Пейвол онбординга: продавать по-взрослому (1–2 дня)

Довести `onboardingPaywall` до уровня лучших паттернов основной пейвол-системы
(`components/paywall/*` — переиспользовать, не писать с нуля; спек §12 это прямо требует):

1. **Годовой предвыбран** + бейдж «−XX%» (реальный расчёт из storePrices) + «≈ X/мес»
   + зачёркнутый якорь 12×месяц. *Anchoring + default bias.*
2. **Sticky CTA** «Открыть 3 дня бесплатно» (если trial есть) — всегда видна.
3. **Trial-таймлайн доверия:** Сегодня — полный доступ · День 2 — напоминание ·
   День 3 — списание. Снимает главный страх «забуду отменить».
4. **PaywallGreetingLine / персонализация:** зеркалить цель и темп
   («Твой маршрут: путешествия · 10 мин/день — Plus открывает его целиком»).
   Имя спрашивается после пейвола — значит зеркалим ЦЕЛЬ, не имя.
5. **Соц-доказательство + mini-FAQ:** переиспользовать `FaqCard`/`PercentileCard`/
   `PaywallProofCards` из paywall C. Возражения («смогу ли я?», «а если не зайдёт?»)
   закрываются прямо на экране.
6. **Exit-intent:** при «Продолжить бесплатно» — один тёплый оффер
   (механика `shouldShowExitTrialOffer` в `app/paywall_purchase.ts` уже написана,
   один раз на устройство).
7. **Celebration после покупки** (был в старом онбординге, коммит 8abd36129) —
   перенести: конфетти + `playPurchaseSuccess` + `hapticSuccess`.
