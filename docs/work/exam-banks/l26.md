# Экзамены глав урока 26 — задания на чтение

Семь глав, по 8 эпизодов. В каждой попытке приложение берёт 10 заданий из списка: каждая тема попадает хотя бы раз, остальные идут в запас для пересдачи. Сдал — 8 из 10.

Как читать: слева то, что видит человек, справа ожидаемый ответ. Через «/» — другие ответы, которые тоже засчитываются. Сокращения (I've, haven't) засчитываются всегда.

Правила, по которым написано:
- Только слова и формы из эпизодов этого урока до экзамена. Это проверяет автоматический сторож.
- Ситуация и ответ сходятся по смыслу.
- На каждую тему не меньше трёх заданий.
- Вопросы — там, где глава их учит (How long have you had…? / Have you … yet?).
- Пометка: если у задания показан один ответ, а в нём есть «a», другие формулировки пока не добавлены — сторож слов ошибочно не пропускает «a» в запасных ответах (Learning V2 чинит).

Банки подключены в обнову 2.0.3 (ваше слово 26.10 «банки для всех уроков и глав»). Нашли неудачное задание — его правят точечно.
