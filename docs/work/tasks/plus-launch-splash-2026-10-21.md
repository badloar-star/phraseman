# Task packet: полноэкранная заставка Plus при запуске (№35), раз в 14 дней

Governance-ID: TG-80529DEFA507
Status: Planned
Owner: сессия «2 · ДИЗАЙН»
Related epic/enabler: решение владельца 21.10 (№35), эталон `docs/design/v2-app/plus-launch-etalon.html` (коммит 512150a0e), поручение координатора

## Outcome

При запуске приложения человек без Plus раз в 14 дней видит полноэкранную заставку «Больше практики — без стопов» с кнопкой, которая ведёт в пейвол с выбранным годовым пакетом. Цена и срок пробного берутся из магазина (RevenueCat offerings из кэша SDK), а не написаны в коде; закрытие мгновенное; решение показать / не показать пишется в журнал `[PLUS-SPLASH]` с причиной. Успех: правила эталона выполняются (14 дней; не в первые 3 дня; после 3× «Не сейчас» — раз в 30 дней; не при Plus, пробном и 30 дней после отмены; не при `billing_unavailable`), заставка не мешает другим окнам старта.

## Scope

In scope: чистая политика показа (`app/plus_splash_policy.ts`) и локальное хранилище состояния (`app/plus_splash_state.ts`, AsyncStorage на устройстве); хук решения при запуске; компонент заставки по эталону (стиль 2.0, движение по emil-design-eng); тексты на 9 языках; запись в журнал `[PLUS-SPLASH]`; тесты; встраивание через `OverlayArbiter` (правка `app/_layout.tsx` только если файл свободен от чужих правок).

Out of scope: изменение самого пейвола и логики покупки, серверные правила, изменение расчёта подписки, новая аналитика-воронка.

## Architecture

Новый слой поверх существующего: политика — чистая функция от (премиум-состояние, время установки, локальный счётчик, причина недоступности магазина); состояние — один ключ AsyncStorage (последний показ, число отказов подряд); цена и пробный — существующие `getTrialInfo` и фразы пейвола `ctaStartTrial` / `ctaBuyYear` / `COPY.*`. Показ идёт через арбитр окон, чтобы не пересекаться с другими окнами запуска. Инвариант: ни одного нового чтения или записи Firebase.

## Security and privacy

Новых персональных данных нет: на устройстве хранятся только метка времени последнего показа и счётчик отказов. Платёжных данных не касаемся: покупка идёт через существующий пейвол и системный шит магазина. Привязка к Plus-статусу — только чтение. Privacy Policy не затрагивается.

## Technical debt

Pay now: политика и состояние — чистые модули с тестами, без размазывания по экранам. Contain: если `app/_layout.tsx` занят чужими правками, встраивание идёт через `OverlayArbiter` без его правки, остаточная привязка фиксируется комментарием с условием выхода.

## Verification

- Юнит-тесты политики на все правила эталона (граничные случаи по датам).
- Тест состояния (чтение/запись, битый JSON, счётчик отказов).
- Тест компонента: состояния цены (пробный / без пробного / цена грузится / магазин не ответил), закрытие мгновенное.
- `tsc`, проверка синтаксиса, ручной просмотр в эмуляторе «Сверкой» (склейка с эталоном, обе темы).

## Rollback

Удаление встраивания в арбитр отключает заставку; сохранённое локальное состояние безвредно и ничего не ломает. Данные пользователя и подписки не затрагиваются.
