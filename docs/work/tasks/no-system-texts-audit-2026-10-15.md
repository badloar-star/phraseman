# Task packet: аудит системных и технических текстов в интерфейсе (9 языков)

Governance-ID: TG-95458B19CF14
Status: In progress
Owner: сессия «Специалист по переводам» (поручение координатора 15.10, правило владельца)
Related epic/enabler: релиз PhraseMan 2.0 (сборка 16.10)

## Outcome

Человек не видит ни одного системного текста: ни провайдера, ни сервера, ни синхронизации, ни токенов, кэша, кодов ошибок,
«до ответа», id и названий сервисов (Firebase, RevenueCat, Google Play Services). Каждая такая строка либо заменена
человеческой («Не получилось. Попробуй ещё раз», «Нет интернета»), либо убрана в пользу индикатора, а подпись остаётся
только в accessibilityLabel. Мерило — таблица ниже: у каждой найденной строки есть файл:строка, текст и решение.

## Scope

In scope: видимые строки в app/, components/, modules/, constants/, hooks/ — ru и те же ключи на uk/en/es/pt-BR/vi/id/tr/pl.
Чистые замены текста в строковых таблицах переводчик делает сам: на этот класс у владельца есть общее правило, ru менять разрешено.
Out of scope: онбординг (Темы) и RegistrationPromptModal (Авторизация) — уже в работе у них. Удаление элементов из вёрстки —
только список координатору. Логи, трассировки, dev-экраны и админка — не видны игроку.

## Architecture

No architecture change: меняются значения строк. Элементы, которые нужно убрать из вёрстки, отдаются владельцам экранов.

## Security and privacy

Плюс к приватности: уходят упоминания внутренних сервисов и кодов, которые раскрывали устройство бэкенда. Данные не затрагиваются.

## Technical debt

- Строки, которые требуют правки вёрстки, — Contain: список у координатора, раздаётся владельцам экранов; выход — пустой список.
- Сторожа на этот класс текстов нет — Accept temporarily: предложение сторожа (словарь запрещённых слов в ru-строках) — в отчёте ниже.

## Verification

Сканер видимых ru-строк по словарю технических слов + ручной разбор каждой находки; сторожа i18n
(i18n_missing_en_fallback, ru_strings_no_ukrainian_letters, english_ui_enable_preflight, untranslated_ui_positional) и тесты файлов,
где правились строки, — через slot.sh.
