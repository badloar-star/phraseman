текущем коде до правки), сторож-контракт редактора зелёный.

## Scope

историй в приложении, серверные функции, данные в Firestore (старые черновики не удаляются, только скрываются), выкладка
на хостинг, рабочий процесс GitHub выкладки, push.

## Architecture

Источник шаблонов — `TPL` страницы предпросмотра; галерея админки строится из него, а редактор держит запасной список
`FALLBACK_DESIGNS`. Граница: галерея админки берёт `TPL` без `poll` (`ADMIN_TEMPLATES`), макет-страница — весь `TPL`.
`knownDesign` редактора опирается на `FALLBACK_DESIGNS`, поэтому опрос перестаёт быть допустимым шаблоном и при открытии,
и при сохранении. Инвариант: число шаблонов в галерее, запасном списке и проверке готовности галереи совпадает (35).
