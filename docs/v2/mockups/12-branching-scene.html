Тема приложения

Прогон состояний

Хотспоты — широкие строки списком (exploration по 04, без координат-тапов по картинке — картинок нет вообще). Тап по хотспоту: нарративная карточка сдвигается (переход как карточки эталона PB), появляется реплика персонажа и варианты. Верно: цель в мини-чеклисте шапки отмечается SVG-галочкой с поп-анимацией + звезда. Неверно: contextual repair по 04 — персонаж уточняет, БЕЗ красного экрана. «Выйти и вернуться» эмулирует resume: сцена восстанавливается на текущем узле, без потери прогресса по целям.

Contextual repair (без confirm)реплика-уточнение, без тряски/красного экрана
Resume (выйти/вернуться)мгновенное восстановление узла, без re-intro
Авто-«Дальше» на итоге1400 мс · тап = сразу
Только transform / opacity (UI-тред). Reduced motion: переходы карточки и полёты заменяются кроссфейдом; success haptic только на завершении цели (по 04). Exploration не зависит от координат: список хотспотов повторяет все действия сцены — это единственный способ взаимодействия в этом макете (без скрытых зон на картинке, картинок нет).
