# Крупный шрифт ×1,3 и узкий экран 360 dp на экранах R1 (R1_BACKLOG №4, поручение координатора 13.10)

Governance-ID: TG-136FC9D9AF6E
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0»

## Outcome
Экраны R1 (Главная, Уроки/итог урока, Шпиль, Диалоги, Карточки, Настройки, Пэйволы) выдерживают системный шрифт ×1,3 и ширину 360 dp: текст переносится, не обрезается и не наезжает на соседние элементы. Найденное в моей зоне чинится сразу вёрсткой (перенос, `flexWrap`, `minHeight` вместо `height`), чужое отдаётся владельцам списком. `adjustsFontSizeToFit` не используется.

## Scope
Аудит по коду (жёсткие `height`/`width` у блоков с текстом, `numberOfLines` без переноса, ряды без `flexWrap`, `minWidth`) и пачка проверочных кадров FS1 у Сверки (font_scale 1.3, плотность под 360 dp). Правки — только в файлах моей зоны (темы, токены, общие компоненты тем); экраны других сессий — строкой владельцу. Отчёт: `docs/phraseman-2.0/R1_LARGE_FONT_360_AUDIT_2026-10-13.md`.

## Architecture
Метод: статический скан кандидатов по списку экранов, затем ручная проверка каждого кандидата на «текст внутри жёсткого размера». Исправления локальные и не меняют логику; при необходимости общая причина (токен кегля, общий компонент) чинится в одном месте.

## Security and privacy
Только вёрстка; данных и разрешений не касается.

## Technical debt
Автоматического снимка при ×1,3/360 dp в тестах нет — только кадры Сверки; полноценный сторож вёрстки (по кадрам) — отдельная задача.

## Verification
Отчёт со списком кандидатов и решений; точечные тесты источников на правленые файлы; кадры FS1 у Сверки.
