# Визитка, ранговая подпись и sharing

Визитка остаётся облегчённой: идентичность пользователя, монета-аватар и согласованная короткая подпись. Энергия, бонусы ёмкости, пять косметических уровней и старый редактор аватара удаляются. Точные полезные поля определить по текущему экрану и визуальному макету.

Ранняя идея «базовая + одна Pro-визитка за 20–30k» теперь пересекается с 15–30 рангами монеты. Нельзя реализовать обе системы автоматически и снова получить витрину. D23 фиксирует обсуждение; рекомендация — сначала простая визитка, покупку улучшения отложить до оценки пользы.

Знак создателю десяти наборов — предметное поощрение вклада. Требуется различить «создал для себя» и «опубликовал полезное для других». Предложение: считать одобренные публичные наборы и не выдавать знак за пустые дубликаты. Не называть это новым XP/достижением с тостом. Отдельно решить, как знак сосуществует с ранговой подписью.

Sharing на главной открывает штатный механизм. Два обсуждаемых содержания: простая визитка или учебный итог. Старый опыт/level не экспортируется. Личные ошибки, email, internal UID, покупки и сырые данные не попадают в публичную картинку/link. Ссылка работает для получателя без аккаунта или честно ведёт к приложению; поведение требуется проверить, не объявить готовым.
