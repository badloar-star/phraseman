# Моменты вовлечения — исследование конкурентов и аудит приложения (13.10.2026)

Заказ владельца: «нарисуй на макетах модалы/моменты для всех потенциальных состояний, которых сейчас нет и которые реально поднимут актив, вовлечение и деньги; досмотри всех конкурентов; по несколько вариантов каждого». ## 2. Что берём (механики → наши моменты)

1. **Праздники только на вехах** (Duolingo) → рубежи серии 7/30/100 с нарастанием; обычный урок — тихо, идеальный — золото.
2. **Подарок на каждой вехе** → 7: заморозка; 30: ранг монеты бесплатно; 100: Plus на 7 дней + рамка монеты.
3. **Тихая заморозка + «спасла»** → момент «Заморозка спасла серию» + строка про Plus (авто-восстановление).
4. **Пуш/тост «от цели», конкретика** → «Серия сгорит в полночь — одна ступень, 2 минуты».
5. **Полноэкранный итог недели с подиумом** (Duolingo League Results) → «Итог недели»: подиум комнаты + сторис «Твоя неделя» + повышение/удержание/понижение как отдельные церемонии.
6. **«X занял твоё место»** → тост/модал «Ира обошла тебя — 3 ступени, 6 минут».
7. **Понижение без стыда + платная защита** (Demotion Zone, League Repair, trophy gates) → «Передышка» / «Реванш» + «Щит лиги» в Plus (предложение).
8. **Пейвол под контекст, первая строка выгод под точку входа** → энергия кончилась: таймер + «∞ без ожидания»; после идеальной серии — «Ты в ударе»; микро-покупка энергии за монеты.
9. **Сундук / переворот карты** (Clash Royale) → повышение лиги как «карта лиги», ранг монеты как «полка коллекции».
10. **Каскадный финал** (Sugar Crush) → итог ступени «Чисто!» с лесенкой ступеней, каскад целей в итоге диалога.
11. **Комбо с множителем** (Candy Crush, Duolingo combo bonus) → «Молния» 3/5/10 подряд: бейдж → разряд → множитель монет ×2/×3.
12. **Аватар говорит до старта** (Praktika/Speak) → брифинг-переписка: собеседник печатает превью реплик, цель между ними.
13. **Кольца активности** (Apple Watch) → «кольца дня»: 3 образа, закрытие с хаптиком, неделя 7 мини-колец, «Полный день».
14. **Recap ценности перед концом пробного** (Headspace, Superwall) → «Что дал Plus за 5 дней».
15. **Welcome back без вины + лёгкий первый шаг** → «Ничего не сгорело» + «разминка в 3 шага».

## 3. Аудит приложения — что есть, чего нет (по коду app/, components/, modules/)

**Есть и хорошо:** церемония ранга монеты «Монетный двор» (`components/level_up/LevelUpMintCeremony.tsx`, запускается только при платном повышении), результат урока `ResultsSequence`/`V2DoneScreen` (конфетти на любой результат), `CoinRewardFlight` (монеты летят в баланс), `EnergyMistakeHud`, `EnergyNeededSheet`/`EnergyStopSheet`/`SpireClimbDock` (энергия → Plus), `PaywallPlus` с контекстами, `PremiumCelebrationModal`, `IntroFullAccessModal` (72 ч), `StreakRiskToastHost` (вечерний тост), заморозка в `streak_stats`, `SpireWeekResultCard` (карточка «Итог недели» с одним pop), `SpireResultPanel` (ступень/этаж/вершина — статичная панель), `DialogueV2BriefingScreen` (статичный брифинг), `dialogue_v2_completion` (спокойный итог), `DialogVerdictScreen` (старый поток, с реакцией персонажа), `ActionToast`.

**Нет (или заглушка):**
- Церемония повышения/удержания/понижения лиги — только карточка и пуш `spire_week_result`.
- Комбо правильных ответов — эффект удалён 03.08.2026, остался `ComboRing` в старых уроках; в Пике и курсе — ничего.
- Брифинг с печатающимся собеседником — нет; typewriter есть только в онбординге.
- Рубежи серии 7/30/100 — ачивки в каталоге, открываются молча (PM-053).
- «Серия под угрозой» как шторка/карточка — нет (только тост и пейвол); `streak_revive_offer` без слушателя.
- Идеальный урок как отдельный момент — нет (только звук 3-й звезды).
- Обгон друга — нет (`RankChangeBanner` не смонтирован).
- Возвращение после перерыва — нет (только winback-пейвол после 7+ дней).
- Дневная цель выполнена / кольца дня — «Сегодня» платит монеты молча; `components/home/DayRings.tsx` никем не импортируется.
- Первый диалог пройден — нет.
- Подиум «Итог недели» — нет (recap только пушем).
- Пробный Plus: нет момента «включён» и рекапа в середине.
- Мёртвые триггеры: `home_level_up_celebrated` никто не эмитит; ключи арбитра `levelUp`, `friendGift`, `compassBriefing` без хостов.

## 5. Кольца дня — одно или три?

Рекомендация: **три кольца**, где первое («Урок») закрывается за 3–5 минут. Лёгкая ежедневная победа (как Move у Apple для большинства) + два «растягивающих» кольца, которые тянут на вторую сессию. Одно кольцо проще объяснить, но теряет эффект «почти закрыл ещё одно» и не даёт дифференцировать Plus-бонус («×2 за полный день»). Образ — кольца вокруг монеты ранга (монета уже «я»), место — шапка Главной над «Продолжить».

## 6. Новые механики, предложенные дизайном (в продукте нет — решение владельца)

- «Щит лиги» (Plus): одно понижение в месяц не считается.
- Множитель монет за серию ответов ×2 (с 5-го) / ×3 (с 10-го).
- Бонус ×1,5 за идеальный урок; 5 идеальных подряд → ранг монеты бесплатно.
- Бонус за «полный день» (все кольца) +100 монет; серия полных дней.
- Заморозка за 200 монет; в Plus — авто-восстановление еженедельно.
- Подарки на рубежах серии: 7 — заморозка; 30 — ранг; 100 — Plus 7 дней + рамка монеты.
- Микро-покупка энергии за 100 монет.
- «Разминка после паузы» с +150 монет и ×2 на 3 дня.

Текст «без вины», короткие кнопки, все модалы без обводок (стиль «Тень»).
