# ⛔ АРЕНА: НЕ ОТКАТЫВАТЬ И НЕ ПЕРЕЗАПИСЫВАТЬ

**Это распоряжение владельца, а не пожелание.** Файл лежит в корне, чтобы его
видел любой процесс, который откроет репозиторий.

Раздел «Арена» переписывается по прямому заданию владельца. Работа уже дважды
терялась из-за чужих операций с деревом: коммит `Revert` и переключение веток
снесли готовые файлы, и их приходилось восстанавливать поштучно.

## Что запрещено делать с файлами Арены

- `git revert` коммитов, содержащих файлы Арены;
- `git checkout` / `git restore` чужой версии поверх них;
- перезапись их из своего буфера, если вы их не читали в текущем состоянии;
- «уборка» и переформатирование заодно с другой задачей.

## Если ваша задача ТРЕБУЕТ тронуть эти файлы

1. Не откатывайте. Внесите изменение поверх текущего состояния.
2. Прогоните тесты Арены: 36 наборов должны остаться зелёными.
3. Опишите изменение в `docs/arena/OWNER_DECISIONS.md` — это журнал владельца.

## Резервная копия

Полный слепок Арены лежит ВНЕ репозитория:
`~/Documents/phraseman-wip-backups/arena-snapshot/arena-latest.tgz`

Восстановление после случайного отката:

```bash
cd ~/Documents/phraseman
tar xzf ~/Documents/phraseman-wip-backups/arena-snapshot/arena-latest.tgz
```

Если слепок старше вашей правки — ищите нужный коммит:
`git log --oneline -5 -- app/arena_match.tsx`, затем
`git show <commit>:<путь> > <путь>`.
