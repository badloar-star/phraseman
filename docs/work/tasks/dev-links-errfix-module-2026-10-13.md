## Outcome
Для id из списка ошибок шагов робота, где причина — сами шаги или ссылка, новый модуль `scripts/dev_links_r1_steps_errfix.py` заменяет запись так, чтобы робот дошёл до нужного состояния. Для остальных id (исправлено кодом приложения, нужна живая съёмка, нужна новая подмена) в отчёте указана причина и владелец.

## Scope
Только новый файл `scripts/dev_links_r1_steps_errfix.py` (подключение в генератор делает Авторизация последним, после p84) и этот пакет. Экраны, чужие модули шагов, `parity_steps.mjs` не меняются.

## Architecture
Модуль, как p84, меняет словарь `ENTRIES` из `dev_links_r1_steps`: заменяет шаги или параметры записи (идемпотентно; записи нет — понятная ошибка). Причины найдены по кадрам ошибок и журналам в `docs/phraseman-2.0/evidence/parity/_runs/*` и коду: бесконечная анимация мешает дампу uiautomator (спиннер), робот застревает на экране предыдущей ссылки (прокрутка Главной), ссылка ведёт на другое состояние (комната вместо главного экрана Шпиля).

## Security and privacy
Только dev-ссылки и шаги для сборки разработчика, пользовательские данные не затрагиваются.
