# Урок 27 · Занятие 17 — Если бы вышли сейчас

**Ситуация.** Вы обсуждаете дорогу, время пересадки и короткую поездку с друзьями.

**Что вы освоите:** сказать, что было бы, если бы…: If I had time, I would help
**Новые слова:** aboard, layover, backpacker, getaway

## Интро 1

### Если бы вышли сейчас

Вы ещё дома и обсуждаете с другом, когда выйти. Представьте результат немедленного выхода: We would arrive early if we left now — мы бы приехали рано, если бы вышли сейчас. В этом воображаемом условии would относится к результату arrive, а после if ставим форму прошлого left без would. Left здесь не означает, что вы уже вышли. Собираем предложение: We + would arrive + early + if we left now — кто, возможный результат, насколько рано, при каком условии. После would нужна начальная форма arrive.

**Выберите фразу для этой ситуации.**

- ✅ **We would arrive early if we left now.**
- ❌ We would arrived early if we left now. — *После would нужна начальная форма arrive.*
- ❌ We would arrive early if we would left now. — *В этом условии left без would.*

## Интро 2

### Если бы хватало времени

Друг зовёт вас присоединиться к прогулке, но у вас мало времени. Ответьте: I would join you if I had more time — я бы присоединился к тебе, если бы у меня было больше времени. Would join — воображаемый результат; had после if — условие сейчас, а не рассказ о прошлом. Собираем предложение: I + would join + you + if I had more time — кто, что сделал бы, к кому, при каком условии. Would ставим только в части с результатом, перед join.

**Выберите фразу для этой ситуации.**

- ✅ **I would join you if I had more time.**
- ❌ I would joined you if I had more time. — *После would нужно join.*
- ❌ I would join you if I would had more time. — *В условии had без would.*

---

## Интро 3

### Если бы друзья знали

Вы предполагаете, что друзья приехали бы на встречу, но они о ней пока не знают. Скажите: They would come if they knew — они бы приехали, если бы знали. Would come — предполагаемый результат, if they knew — условие. Knew — форма know для этого воображаемого условия. Собираем предложение: They + would come + if they knew — кто, что сделал бы, при каком условии. Не переносим would в часть после if и не заменяем come на came после would.

**Выберите фразу для этой ситуации.**

- ✅ **They would come if they knew.**
- ❌ They would came if they knew. — *После would нужна начальная форма come.*
- ❌ They would come if they would knew. — *В условии knew без would.*
