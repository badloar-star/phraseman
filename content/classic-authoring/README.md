# PhraseMan · Мастерская классических курсов

**Команда владельца:** `Пиши следующий урок испанского.` Не спрашивать снова, сколько уроков или фраз. Это исходники содержания классики, не Learning V2, не Firebase и не действующая сборка. Ветка `work/classic-authoring-es-pilot`, база `feature/referral-roulette`. Не смешивать с PR №35. Обновляем учебную ветку, не активируем продукт.

## Откуда продолжить в любом чате

1. Прочитать этот файл на рабочей ветке (после слияния — на согласованной базе), `es/course.psv`, `es/senses.psv`, папку последнего урока. Получить актуальный HEAD. Прочитать `NEXT.json` из последнего успешного прогона или собрать его заново. Не принимать старый файл из чата за источник истины. Два автора не должны параллельно менять одну пару уроков; если HEAD сменился, перечитать изменения.
2. `ordinal` — первый ещё не написанный номер после непрерывной последовательности папок. Сверить контрольную сумму пакета и `handoff.next`. При уже существующем номере продолжать черновик или проверять его, не перезаписывать готовый урок. Просьба `Пиши урок N` не даёт права пропускать незаконченные предыдущие словари.
3. Создать `es/lessons/NN/phrases.psv` и `guide.json` по рабочему примеру `01`; расширять общий `senses.psv`, не клонировать его. В любом другом языке начинать отдельный каталог и программу, а не переводить испанские списки. До появления собственного профиля считать новый язык неподдержанным для выпуска.

## Одна редакционная операция

**Паспорт.** Прочитать строку программы; определить, что ученик сделает сам в финале. Зафиксировать собеседника, регистр, региональные варианты, основные новые значения и 3–6 ключей для возврата из предыдущих уроков. Не объявлять 32 урока полным освоением A1–C2. Для ES используется системный голос `es-ES` как QA-профиль, а не утверждение, что выражение обязательно одинаково во всех странах.

**Отбор.** Написать больше кандидатов, чем требуется. Удалить искусственные переводы, механическую замену имён, пятидесятую вариацию одной просьбы и фразы вне ситуации. Собрать пять связанных сцен по 10 реплик; это деление внутри урока, не новый тип упражнения. Чередовать реплики ученика и то, что он услышит в ответ. На старте предпочитать 2–5 слов; живое однословное «Igualmente» лучше искусственно растянутой реплики. Не включать фразу «Я из Украины» и её переводные эквиваленты. Исходные фразы создавать самостоятельно, справочники использовать для проверки, не копирования готового курса.

**Строка фразы.** `локальный ID | испанский текст для показа и системного TTS | естественный RU | естественный UK | ключи смысловых отрезков по порядку | дополнительные верные ответы через ; или — | контекст RU | контекст UK`. ID составляется в виде `es:02:01`. Знаки ¿/¡, тильды и ударения сохранять. Контекст объясняет, кому и зачем говорят. Добавочные формы — допустимые варианты перевода, а не обязательные повторы и не исчерпывающий список для наказания за свободный ответ. Проверять регистр и смысл каждого варианта. Для дословного аудиозадания отдельно задан эталон.

**Словарь.** Ключ относится к языку и значению. Например, `llamarse` покрывает целые отрезки `me llamo`, `te llamas`, `se llama`. Два смысла `ser` могут иметь общую словарную форму. Два омографа не склеивать. Новизна считается по первому реальному употреблению в основных фразах и порядку уроков, а не по моменту генерации. Переводы, имена в пояснениях и ложные варианты не вводят новую карточку. `core` — активный минимум; `recognize` — достаточно понять; `support` — служебные слова и конструкции; `name` — имена, не словарь для заучивания. Рабочий ориентир пилота: 8–16 основных единиц, не механическая квота. При перекосе проверить сложность и скорректировать фразы. Не выдавать все имена и служебные слова за «выученные». Чтение реплики и компиляция урока не меняют FSRS пользователя.

**Теория, практика и контроль.** Для каждой теоретической заметки — ситуация, пример из строк, ошибка или контраст, обратная связь. Справочник показывает формы из текущего материала, а не таблицу всех времён. Заполнить пять сцен, теорию, языковой справочник, связанные диалоги, мини-проверки с объяснениями, источники и передачу следующему автору. Для каждой фразы собираются токены и пять альтернативных плиток на токен для воспроизведения эталона. Проверить их уместность; машинная подборка не доказывает педагогического качества. Экзамены, их проходной балл, награды и правила подписки не меняются.

**Инструкция независимому рецензенту** (отдельный проход или модель, не самооценка автора): «Прочитай цель, сцену, ES, RU/UK и теорию. Сформулируй свой перевод до просмотра авторских вариантов; найди случаи с двумя приемлемыми ответами, неестественную вежливость, неверное согласование, мнимую уникальность и неправильное первое введение. Для каждого дефекта верни ID фразы, тяжесть, причину и исправление. Не ставь PASS без проверки обеих локалей и всех 50 фраз. Не считай техническую сборку лингвистической проверкой». Исправить только затронутые записи и повторить проверку. Отдельно произнести целевые фразы на устройствах. Ручная экспертная выборка желательна на пилоте, но не является кнопкой публикации каждого урока.

## Как собрать

Из корня репозитория: `python3 -B -m unittest discover -s content/classic-authoring -p test_build.py -v` и `python3 -B content/classic-authoring/build.py --target es --out /tmp/phraseman-classic-es`. Windows: `py -3 content/classic-authoring/build.py --target es --out .\build\classic-es`. Выходной каталог должен быть отдельным. Без API-ключей и платной озвучки. В PR отдельная проверка `Classic course authoring preview` сохраняет ZIP: исходники, `ES-01.html` (открыть в браузере, перевод скрыт, RU/UA переключаются), `bundle.json`, `ledger.json`, `NEXT.json`, `receipt.json`.

**Границы.** Результат — `author_draft / STRUCTURE_PASS_ONLY`, не автоматически одобренный релиз. Это авторская разметка с компьютером для проверки соответствий, не универсальный морфологический анализатор и не замена русскоязычному/украиноязычному редактору. Пакет не соответствует напрямую мобильному `LessonData`: там исторически есть `english` и разные роли `spanish`; запрещено записывать испанский текст в поле английского ради типа. Отдельны: адаптер данных классики, независимый языковой допуск, проверка настоящих экранов, TTS на iOS/Android и разрешённый канал публикации. Ничего из этого данный скрипт не инициирует.
