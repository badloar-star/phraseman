# Единый языковой контур обучения — спецификация

**Статус:** одобрено владельцем как направление, 20.09.2026  
**Целевые языки:** English (`en`), Spanish (`es`), French (`fr`), German (`de`)

## 1. Простое правило продукта

У пользователя есть один выбранный **язык обучения**. После его смены вся
учебная часть приложения открывает материал только этого языка:

- обычные уроки и Learning V2;
- диалоги и AI-сценарии;
- фраза дня и её задание;
- тренировки, диагностика и экзамены;
- Арена;
- видео и фразы, сохранённые из видео;
- карточки, включая системные, сохранённые, наборы и тренировки.

Язык интерфейса — отдельная настройка. Например, ученик может учить немецкий
при русском интерфейсе; это не превращает немецкий контент в русский или
английский.

## 2. Что остаётся общим для аккаунта

Не зависят от языка обучения:

- баланс валюты и все операции с валютой;
- XP, уровень, Plus и профиль;
- общая история аккаунта и покупки;
- глобальные достижения, если их условие не описывает конкретный учебный
  материал.

Зависят от языка обучения:

- прохождение уроков, сессий, экзаменов и тренировок;
- изученные слова, SRS/повторы, ошибки и подсказки;
- сохранённые карточки и доступ к языковым наборам;
- фраза дня, её кэш, сохранение и задание;
- контент и история диалогов, Арены и видео-фраз.

Получение XP за действие на любом языке увеличивает один общий XP-счётчик. Но
само завершение урока Spanish не открывает урок French и не подмешивает
испанский материал в немецкую тренировку.

## 3. Единственный контракт языка

Создаётся один общий immutable-реестр `LearningLanguageContour` с точными
кодами `en | es | fr | de`. Он является единственным источником для:

- имени, флага и speech locale языка;
- допустимых source/interface locales;
- ключей учебного состояния;
- статуса готовности каждого учебного раздела;
- проверки, можно ли показать язык в обычном переключателе;
- маршрутизации контента и аудио.

Локальные реестры Arena, Dialogues, карточек и Learning V2 не хранят второй
список языков. Они получают язык из общего контракта и добавляют только
специфичные для себя данные: например, режимы Арены или fingerprint набора
диалогов.

`studyTarget`, `targetLanguage`, `packLanguage` и аналогичные поля на границе
раздела должны иметь одно и то же значение. Разные названия допустимы лишь там,
где требует старый wire-format; преобразование выполняется в одном адаптере и
проверяется тестом.

## 4. Полнота важнее выбора

Обычный пользователь всегда видит в переключателе все четыре языка. Готовность
каждой поверхности подтверждается target-specific manifest/receipt и не
определяет, можно ли выбрать язык целиком.

Если хотя бы один обязательный пакет отсутствует, повреждён, не прошёл review
или имеет другой target:

1. выбранный язык сохраняется и остаётся активным во всём приложении;
2. прямой deep link или устаревшее локальное значение не открывают английский;
3. только отсутствующий раздел показывает нейтральное состояние «контент для
   этого языка готовится» либо возвращает
   на выбор языка без начислений, сетевых вызовов и записи учебного прогресса.

Spanish Learning V2 остаётся отдельным будущим контуром: его уроки и
authoring/fingerprint registry не меняются этой реформой. До появления
проверенного Spanish release соответствующий раздел показывает unavailable
state, но Spanish остаётся доступен для выбора и для других готовых разделов.

## 5. Карточки и видео

Карточки и видео не являются самостоятельными языковыми режимами.

- Вход в карточки использует активный язык обучения и показывает только его
  системные, сохранённые, community и official-наборы.
- Существующий ручной picker языка наборов не может увести обычного ученика в
  другой контур; его либо заменяет информативный индикатор активного языка,
  либо он доступен только в явно обозначенном QA/creator-контексте.
- Канал видео выбирается по активному языку. Отсутствующий native channel
  означает unavailable state, не английский канал.
- Сохранённая из видео карточка получает тот же target, что и канал. Она не
  меняет язык обучения и не появляется в чужом карточном контуре.

## 6. Правила безопасности данных и поведения

- Никакая функция доступности не использует lossy-нормализацию вида
  «всё неизвестное = English». Для content lookup неизвестный язык возвращает
  `null`/`unavailable`.
- Английские исторические ключи читаются только в английском контуре. Данные
  French/Spanish/German никогда не читают и не перезаписывают их.
- Все target-scoped ключи используют канонический код из общего реестра.
- Аудио, ASR/TTS, кэши, release manifests, локальный прогресс и серверные
  запросы содержат target в identity и сверяют его перед отображением.
- Смена языка отменяет in-flight загрузки старого языка и сбрасывает только
  отображаемый учебный state. Она не отменяет локально подтверждённую награду,
  не меняет баланс и не делает сетевой rollback.
- В Learning V2 ни один путь восстановления или запуска сессии не может
  зашивать `en`/`ru`; он получает exact target и source locale из активного
  контура.

## 7. Публикация языка

Язык проходит четыре состояния: `draft`, `qa`, `ready_for_release`,
`production_enabled`.

Переход в `production_enabled` делает отдельная release-проверка, которая
доказывает, что для конкретного target готовы все обязательные поверхности,
их content/voice manifests совпадают с target, а все контурные тесты зелёные.
Один готовый раздел не может включить язык целиком.

Создание/редактирование learner-facing контента Learning V2 остаётся под его
существующими owner rules, preauthoring guardian и фабричными gates. Эта
спецификация меняет только платформенную маршрутизацию и не разрешает
автоматически переводить или публиковать новый материал.

## 8. Выявленные расхождения, которые надо устранить

1. App-level контракт содержит `en/fr`, dev-контракт добавляет `es`, policy
   Learning V2 содержит `en/de`, authoring Learning V2 — `en/es`, а Arena и
   Dialogues — все четыре языка.
2. Learning V2 отправляет English через direct player, а другой target — через
   legacy player; в legacy local progress есть жёстко заданные `en/ru` scopes.
3. Общая key helper нормализует большинство `es/de` вызовов к английскому
   namespace; отдельная защита есть лишь в отдельных новых surface gates.
4. Карточки уже знают четыре pack languages, но их ручной picker независим от
   активного target. Видео выбирают channel language, а не гарантированно
   канонический language contour.
5. Несколько существующих Learning V2 gates сами разошлись с текущим registry
   и npm script. Их нельзя игнорировать или ослаблять: ожидания нужно привести
   к действующему owner-approved состоянию отдельной проверяемой правкой.

## 9. Проверяемые критерии приёмки

Для каждого из `en/es/fr/de` в release matrix доказывается:

1. выбор языка меняет все обязательные учебные entry points;
2. каждый entry point передаёт exact target в content, audio, storage и network
   boundaries;
3. чужой target payload не рендерится и не получает награду;
4. отсутствие собственного пакета не показывает English content;
5. карточки и видео открывают только активный target;
6. баланс, XP, уровень и Plus до/после смены языка не меняются;
7. начисление XP в любом контуре увеличивает общий XP один раз;
8. учебный прогресс одного языка не открывает и не перезаписывает другой;
9. legacy English data остаются доступны только после выбора English;
10. production picker всегда показывает четыре языка, а readiness управляет
    только доступностью конкретного раздела.

## 10. Границы работы

В эту реформу входят единый контракт, маршрутизация, ключи состояния,
fail-closed availability, migration, тестовая matrix и release checklist.

В неё не входит написание, машинный перевод или публикация учебного контента
для Spanish/French/German. Подготовка native content и его owner/reviewer
receipts выполняется отдельными потоками; до их завершения язык остаётся
скрытым от production-переключателя.
