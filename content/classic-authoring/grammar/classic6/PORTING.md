# PhraseMan Classic · Español · ES-01—06

Откройте **START.html** в обычном браузере. Он содержит весь материал без сети: шесть уроков, 300 упражнений, переключатель RU / UK, отдельные вкладки «Вступление», «Практика», «Разбор», «Словарь», «Глаголы и формы», «Теория», «Все 50 фраз». Каждый урок можно выбрать вверху. Для чтения без тренажёра откройте **THEORY.html**. Прогресс браузерной копии локальный, это не вход в аккаунт приложения. Системный голос работает только при наличии подходящего голоса на устройстве.

## Что является эталоном
Ревизия приложения: `badloar-star/phraseman@7bf2258cdc5d2647bea7a6f9ed9115035ee2d581`. Эталоны: `app/lesson_data_1_8.ts`, `app/lesson_intro_screens_lesson1_v2.ts` (суффикс в имени — ревизия данных классики), `app/lesson_intro_screens.tsx`, `app/lesson_data_types.ts`, `components/lesson_intro_rich.tsx`. Для отдельной справки — `app/lesson_help.tsx`, `app/lesson_help_theory_registry.ts`, `components/lesson_help_theory_ui.tsx`.

Новый формат заменяет старые трёхстраничные HTML-прототипы партий 01–03/04–06. Каждый урок начинает один читаемый блок, по нажатию следующий **добавляется** под ним, предыдущий не исчезает. Темп задаёт ученик. Формулы, короткие примеры с переводом, типичные ошибки с исправлением, разбор сборки. В последнем блоке — «Начать тренировку». Нет трёх оцениваемых вопросов, звёзд или дополнительных заданий в интро. В отдельной «Теории» семь глав на урок, разборы на реальных примерах, сопоставление ошибки с верным вариантом и таблицы форм. Пример с ошибкой — контрпример для чтения, никогда не ответ для тренировки. В тренировке только 50 переводов-конструкторов на каждый урок.

## Что переносить
- `lessons/ES-01…06.json`: полные данные. `phrases[].id`, displayOrder, подсказки, контекст (род/обращение/ситуация), варианты, разбор, словарные ID, ссылочные таблицы сохраняются. Не переносите один массив ответов без его контекстов.
- `classic-intro/ES-NN.intro.json`: реальные поля существующего типа `LessonIntroScreen[]`: screenId, lessonId, order, kind, titleRU/UK, subtitleRU/UK, textRU/UK, linesRU/UK с типами и размеченными частями. Подключить в `getLessonIntroScreens(lessonId, studyTarget)` отдельную ветку **ES**. Монтировать существующий `LessonIntroScreens` с этим массивом, а не `LearningV2SessionIntro`; событие onComplete только начинает обычную практику. Не включать старые ES seed-данные поверх этого пакета. Подзаголовок должен приходить из испанского каталога, не из перевода названия английской темы.
- `classic-theory/ES-NN.theory.json` + `TheoryClassicES.tsx`: готовый адаптер для `TheoryContent`. Скопировать их рядом в `components/classic-es/`. Из старого маршрута справки выбрать `getSpanishClassicTheory(id)` при studyTarget=es и языке объяснения ru/uk; английский реестр не заменять. Функция возвращает отдельный React-рендер на старых Section/Body/Example/Tip/Warn/Table. Проверить порядок приоритетов маршрутов и не подменять отдельную теорию коротким intro. Не подставлять русский, английский или тексты V2 для неподдерживаемой локали.
- `classic-adapter/ES-NN.phrases.json`: 50 записей на урок, совместимых по полям с LessonPhrase; использовать ES `spanish`, `words`, `alternativesEs`, а не `english` или состав чужого урока. Пунктуация восстанавливается автоматически. `ledger.json` — общий словарь первых появлений по курсу; `vocabulary.new`, `vocabulary.seenBefore`, `verbs`/`verbTables`, `grammarTables` относятся к активному уроку. Сохранять старые идентификаторы карточек, прогресс, SRS и раздельное пространство языка.
- `ALL-300.tsv`: единый банк с RU/UK, ES и разборами. `programme.json` содержит план 32 тем, не 32 готовых урока. Следующий ещё не написанный — ES-07. `qa/` — отчёт браузерной проверки и отпечатки упражнений.

## Граница проверки
Открыть каждый урок с установленным ru и uk. Вначале одна карточка, нет контролов ответов и списания попытки; два последовательных нажатия дают две, затем три видимые карточки. Последняя кнопка начинает первое практическое задание. В открытой справке пример, перевод и пометка ошибки различимы без цвета. Вернувшись из теории, пользователь не теряет выбранные слова. Отдельно проверить перенос на iOS/Android со штатной темой, шрифтами, озвучкой, возвратом, списанием энергии и действующим доступом к курсу. В браузере нет попытки имитировать работу экономики или реального аккаунта. Пакет не подключает приложение и не публикует изменения.

## Воспроизведение
В актуальном PR: `cd content/classic-authoring/grammar/classic6`. В распакованном комплекте: `cd source/classic6`. Выберите пустой **внешний** каталог для результатов. Выполнить `python3 -B build.py /tmp/es-six` и `python3 -B verify.py /tmp/es-six`. Для браузерной проверки нужен Chrome/Chromium; рендеру на телефоне нужен отдельный прогон после интеграции. Для продолжения авторской работы сначала прочтите NEXT.json и реестр слов, а не старые указатели в предыдущих прототипах.
