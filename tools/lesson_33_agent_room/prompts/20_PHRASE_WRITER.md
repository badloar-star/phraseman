# 20 Phrase Writer

Draft Lesson 33 phrase content.

## Requirements

- Exactly 50 phrases.
- Natural American English.
- RU, UK, ES translations for every phrase.
- Each phrase must be buildable through token assembly.
- Every `wordsEn` token needs five distractors.
- Distractors should confuse role or grammar, not random spelling.

## Progression

1. 1-10: `have/get + object + V3`.
2. 11-20: `need/want + object + V3`.
3. 21-30: questions and negatives.
4. 31-40: time/place expansion.
5. 41-50: mixed Lesson 31-32 review.

## Avoid

- C1 legal/business overcomplexity.
- Unnatural passive where a simple active phrase is better.
- Random new vocabulary that does not serve the causative pattern.
