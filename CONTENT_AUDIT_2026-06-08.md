## ВЫСОКИЕ ПРИОРИТЕТЫ

### 🟠 H1. Сломанный UTF-8 символ во вьетнамском тексте
**Файл:** `trainer_smart_session.tsx`, строка 202  
```ts
vi: "t?",   // должно быть "từ" (слово)
```
Вьетнамский пользователь видит бессмысленный `"t?"`.

### 🟠 H2. Дубликаты фраз между уроками
- `lesson10_phrase_8` = `lesson18_phrase_31` → "Can you help me?" / "Ты можешь помочь мне?"
- `lesson19_phrase_16` = `lesson20_phrase_33` → "Is the phone on the table?" / "Телефон на столе?"  
- В уроке 1: слово `calm` — 4 вхождения, `ready` — 5, `tired` — 3

### 🟠 H3. Пропущено слово "на" в массиве `words`
**Файл:** `lesson_data_17_24.ts`, `lesson20_phrase_33`, строка ~3803  
Русская фраза "Телефон **на** столе?" — предлог "на" отсутствует в `words`. Пользователь не может собрать полное предложение.

### 🟠 H4. `I fear dogs` засчитывается как ошибка — методически неверно
**Файл:** `quiz_data.ts`, строка 376  
Фраза грамматически корректна. Вариант 0 должен принимать либо `correct: [0, 1]`, либо объяснение должно явно указывать на стилистическое различие без пенальти.

### 🟠 H5. Дистракторы некорректной части речи в уроках
**Файлы:** `lesson_data_1_8_phrases_source.ts`  
- phrase_7: `important` — дистракторы `import, improve, imagine, impact` (глаголы вместо прилагательных)  
- phrase_2: `You` — дистракторы `yew, yoke` (дерево, ярмо — не местоимения)  
- phrase_3: `busy` — дистрактор `bus` (существительное)

### 🟠 H6. Серийный бонус в Арене не сбрасывается при таймауте вопроса
**Файл:** `arena_game.tsx`  
`correctStreakRef` не обнуляется при таймауте — серия сохраняется через пропущенные вопросы. Результат: нечестный бонус.

### 🟠 H7. Двойное начисление бонусов за скорость в Арене
**Файл:** `arena_game.tsx`, строки 551–562  
При ответе быстрее 2 сек начисляются и `speedBonus` (+50) и `outspeedBonus` (+15) одновременно. Итого до 165 очков за 1 ответ — не задокументировано, вероятно баг.

### 🟠 H8. Лемматизатор: мёртвый код и некорректные результаты
**Файл:** `smart_distractors.ts`, строки 175–178  
```ts
return stem.endsWith('e') ? stem : stem;  // обе ветки одинаковые
```
`making` → лемма `"mak"` вместо `"make"`. Формы одного глагола (make/making/made) получают разные леммы и попадают в дистракторы как "разные слова".

### 🟠 H9. Диагностические тренинги: `es`-поля содержат английский текст
**Файлы:**
- `diagnosis_training_verb_past_simple_regular_irregular.ts:453` → `es: 'Yes. Yesterday shows the past. Work -> worked.'`
- `diagnosis_training_verb_present_simple_statement.ts` → `whatUserMustLearn.es` массив на английском
- `diagnosis_training_pronoun_case.ts` — аналогично
- `diagnosis_training_modal_can_could_ability_request.ts:465` → `es: 'Yes. Ability now uses can.'`

При этом `supportedLocales: ['ru','uk','es']` объявлен. Испаноязычный пользователь получает объяснения на английском.

### 🟠 H10. Полные дубликаты в квизах
