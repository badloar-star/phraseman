# AI-проверка: язык определяется по тексту, перестановка полей — отдельная правка

Governance-ID: TG-CE4E1DA8C3F1
Дата: 2026-09-21
Запрос владельца (дословно): «ПОЛЕ НЕ ИМЕЕТ ЗНАЧЕНИЯ ПРОВЕРЯЕТСЯ НЕ ПОЛЕ»,
«ПРОСТО ПОЛЕ МОЖНО ИЗМЕНИТЬ И ВСЕ, ИИ ДОЛЖНА УМЕТЬ ЭТО СДЕЛАТЬ».

## Что сломалось

Первая версия промпта объявляла эталоном ИМЯ ПОЛЯ:
«Learners study English; their native side is Russian» + «grammar — mistakes
in the `en` text». Модель приняла это как аксиому.

В боевых заявках раскладка обратная: в `en` лежит русский, в `ru` — английский.
Это НЕ порча данных: так во всех 6 заявках, и `normalizePackCardTexts`
(`app/flashcards/pack_languages.ts`) читает `targetText ?? en` и
`translationText ?? ru` — имена полей взаимозаменяемы.

Следствие на экране владельца:

```
БЫЛО:  Wake up in the morning   ← правильный английский
СТАЛО: Sprinkle in the morning  ← ИИ перевёл опечатку «посыпайся» (посыпать→sprinkle)

БЫЛО:  The plane takes off      ← правильно
СТАЛО: The plane took off       ← сломал, подгоняя под русское «взлетел»
```

ИИ не ошибся — он выполнил инструкцию на данных, где инструкция неверна.
Кнопка предлагала «Применить 16 правок», то есть испортить весь набор.

## Outcome

1. Язык куска текста определяется ПО СОДЕРЖИМОМУ, а не по имени поля.
2. Перестановка полей местами — отдельный вид правки (`category: "swapped"`),
   который ИИ обязан предложить вместо перевода опечаток.
3. Модель не считает ни одно поле эталоном заранее: сначала решает, где какой
   язык, потом проверяет.

## Scope

### Правится
- `functions/src/admin_community_pack_qa.ts` — `buildPrompt`: язык по тексту,
  новая категория `swapped`, запрет «чинить» правильный текст под кривой;
  `CATEGORY_LABEL` — метка «Перепутаны поля».

### Не трогается
- `community_pack_qa_apply.ts` — перестановка выражается двумя обычными
  правками полей, новый механизм не нужен. Проверка `before` защищает так же.
- Клиент `legacy.html` — показ «было → стало» уже универсален.

## Architecture

Перестановка = две правки одной карточки: `en` получает значение `ru`, `ru`
получает значение `en`. `applyQaFixesToPayload` применяет их независимо, каждая
со своей сверкой `before` — то есть существующая защита от гонки работает без
изменений. Отдельный тип операции не вводится намеренно: меньше кода, меньше
мест, где можно ошибиться.

## Security and privacy

Изменяется только текст промпта. В OpenAI по-прежнему уходит лишь содержимое
карточек и заголовки; `authorStableId`/uid/email не отправляются — проверено на
всех 6 боевых заявках и закреплено тестом. Privacy policy правок не требует.

## Technical debt

## Rollback

`git revert` коммита. Изменение локализовано в одной функции `buildPrompt`;
контракт ответа расширен совместимо (новая категория, старые продолжают
работать), клиент и применение правок не менялись.
