# Англійська · Урок 16 · Заняття 52 — Вибрати дорогу для прогулянки

**Ситуація.** Ви розрізняєте прогнози, наміри й узгоджені майбутні справи.

**Що ви опануєте:** will / going to / Present Continuous: future form contrast
**Нові слова:** uneven, shaded, paved, unpaved

## Інтро 1

### Думка про майбутнє

Will підходить для думки-прогнозу, going to підкреслює намір, Present Continuous — уже організовану майбутню справу. Форми можуть перетинатися; тут вибираємо форму за вказаним змістом, а не оголошуємо іншу завжди неправильною. uneven — нерівний — про поверхню. Ви ще не гуляли цією доріжкою й припускаєте, що поверхня буде нерівною. I think the path will be uneven. — Думаю, доріжка буде нерівною. Передайте думку-прогноз через will.

**Виберіть фразу для цієї ситуації.**

- ✅ **I think the path will be uneven.**
- ❌ I think the path is going to be uneven. — *Ця форма можлива в іншому контексті; тут тренуємо вказану. Передайте думку-прогноз через will.*
- ❌ I think the path will to be uneven. — *Порушено побудову форми.*
