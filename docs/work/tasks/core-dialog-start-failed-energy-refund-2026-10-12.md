## Outcome
Если старт серверной сессии диалога провалился все 5 тихих попыток (`serverSessionState === 'unavailable'`) и энергия за
вход ещё не закреплена первым ответом — энергия возвращается один раз, человек видит тост «Энергия возвращена».
Повтор («Повторить») после возврата не списывает энергию снова; поздний успешный первый ход не закрепляет и не возвращает
повторно.

## Scope
In: `app/dialogue_v2_session.tsx` (вызов возврата на «сессия не стартовала», одноразовое решение через новый модуль),
`app/dialogue_v2_energy_settle.ts` (новый: одноразовое решение acknowledge/refund на попытку), `components/EnergyContext.tsx`
(только строка лога `[ENERGY-REFUND]` в `refundActivityStart` — до/после, статус; логика не меняется),
тест `tests/dialogue_v2_energy_settle.test.ts`. Out: сервер, журнал энергии (`app/energy_session_operation_ledger.ts`),
свободный разговор `dialogue_v2_freeform.tsx`, `readNotificationLang` в EnergyContext (зона Авторизации).

## Architecture
Ключ идемпотентности — `energyOp` (id операции списания, приходит параметром маршрута с брифинга). Два уровня защиты:
1) экран: одноразовый «расчёт» на попытку — первое решение (acknowledge или refund) забирает id синхронно, до любого await,
   поэтому двойной вызов и гонка «возврат ↔ первый ответ» дают ровно одно действие; при сбое записи возврата id
   возвращается для следующей попытки;
2) локальный журнал энергии: возврат по `<op>:refund` идемпотентен (`already-applied`), возврат после подтверждения
   отклоняется, подтверждение после возврата отклоняется (уже покрыто `tests/energy_session_start_status.test.ts`).
Энергия локальная (AsyncStorage) — сервер не нужен, выкладки нет.

## Security and privacy
Новых данных нет; в лог идут id операции, причина и числа энергии — без uid и текста диалога.

## Technical debt
После возврата «Повторить» может открыть диалог без списания (так же, как сегодня после `service`-сбоя) — осознанное решение
координатора «человек ничего не получил»; если владелец захочет списывать на повторе, это отдельное изменение входа.
Свободный разговор (`dialogue_v2_freeform.tsx`) этим проходом не проверен — в отчёте координатору.
