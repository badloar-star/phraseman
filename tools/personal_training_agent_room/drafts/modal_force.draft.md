# modal_force

Jesse rework pass for choosing force across can/could/should/must/have to/may/might.

## Scope

- One microdiagnosis only: `modal_force`.
- Replace mojibake-heavy legacy file.
- Keep the training focused on meaning strength, not the shape after the word.

## Teaching Point

The learner should choose the force first:

1. `can` = allowed / able
2. `could` = polite request / was able before
3. `should` = advice
4. `must` / `have to` = required
5. `mustn't` = forbidden
6. `don't have to` = not required
7. `may` / `might` = possible

## Copy Rules

- Visible RU/UK copy uses ASCII transliteration.
- Avoid learner-facing raw label `modal`.
- Keep the dangerous pair explicit: `mustn't` vs `don't have to`.

## Structure

- Easy: permission, advice, rule, prohibition.
- Contrast: no obligation, polite request, uncertainty, past ability.
- Mixed: outside requirement, formal permission, strong conclusion, negative advice.
