# Англійська · Урок 16 · Заняття 40 — Зручні речі для кухні й дому

**Ситуація.** Ви розрізняєте прогнози, наміри й узгоджені майбутні справи.

**Що ви опануєте:** will / going to / Present Continuous: future form contrast
**Нові слова:** airtight, leakproof, non-stick, foldable

## Інтро 1

### Думка про майбутнє

Will підходить для думки-прогнозу, going to підкреслює намір, Present Continuous — уже організовану майбутню справу. Форми можуть перетинатися; тут вибираємо форму за вказаним змістом, а не оголошуємо іншу завжди неправильною. airtight — герметичний, що не пропускає повітря. Ви припускаєте, що новий контейнер щільно закриватиметься й не пропускатиме повітря. I think the container will be airtight. — Думаю, контейнер буде герметичним. Передайте думку-прогноз через will.

**Виберіть фразу для цієї ситуації.**

- ✅ **I think the container will be airtight.**
- ❌ I think the container is going to be airtight. — *Ця форма можлива в іншому контексті; тут тренуємо вказану. Передайте думку-прогноз через will.*
- ❌ I think the container will to be airtight. — *Порушено побудову форми.*
