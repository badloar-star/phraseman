# adjective_vs_adverb

Jesse rewrite for `adjective_vs_adverb`.

## Scope

- Keep the MVP contract: `good/well`, `-ly` words, and linking-verb traps.
- Replace grammar-label teaching with meaning-first copy.
- One learner problem only: the learner chooses by Russian translation, but English chooses by what the word describes.

## Lesson shape

- Person/thing/state: `good teacher`, `quick answer`, `careful driver`, `It sounds strange`.
- Action: `teaches well`, `answered quickly`, `drive carefully`, `looked strangely`.
- Main trap: `good` does not become `goodly`; for action use `well`.

## Required anchors

- `adj_adv_easy_001`: wrong `well` feedback must contain `good`.
- `adj_adv_contrast_005`: wrong `careful` feedback must contain `carefully`.
- `adj_adv_mixed_001`: wrong `strangely` feedback must contain `strange`.
