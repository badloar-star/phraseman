## Architecture
Корень: id сохранённой карточки = `${lang}_${source}_${en с _ вместо пробелов}_${ts}` (hooks/use-flashcards.ts) —
апострофы, запятые, «?», «!» не проходят `ID_RE` в компактном manifest → `invalid_input`. Блиц/«Вспомни»/«Устно»
с 03.10 кладут отпечатки (`app/flashcards/training_manifest_ids.ts`), свайп остался на сырых `trainingKey`.
Для «Верно/Неверно» обход (fail-open) запрещён политикой → красная строка. Решение: свайп кладёт
`cardManifestId(trainingKey)` в orderedCardIds/promptRecipe/initialCardId и `manifestSeed` в seed; восстановление
ищет по отпечатку, затем по сырому ключу (старые записи журнала с чистыми id). Коллизия отпечатков — явная ошибка.

## Security and privacy
В журнал обращений уходят только закрытые значения: режим, вид источника, размер (0–999), итог-перечисление,
длительность. Ни текста карточек, ни id, ни uid. Новых полей/сервисов нет — политику не трогает.
