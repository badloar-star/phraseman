# Task packet: перенос макетов Elevate — игра «Поток»

Status: In progress
Owner: сессия макетов Elevate (владелец 11.11.2026: «у тебя приоритет», «самое главное — механики»)
Related epic/enabler: docs/work/tasks/elevate-skills-into-app-2026-11-11.md (D207)

## Outcome

В приложении играется «Поток» ровно как в утверждённом макете (`docs/design/v2-app/elevate-mechanics.app.js`,
`flow()`): экран с правилом и кнопкой «Начать», отсчёт 3-2-1, фраза появляется по одному слову и исчезает,
затем три варианта перевода; верный ответ поднимает темп, промах опускает; перед следующей фразой сигнал
«Следующая фраза». Верный быстрый ответ даёт очки «Скорости» по таблице навыков. Успех — склейка
«макет | эмулятор» и запись экрана рядом с записью макета.

## Scope

In scope: новые файлы `modules/games/flow_core.ts` (правила без React), `tests/game_flow_core.test.ts`,
`app/game_flow.tsx` (экран), `components/games/*` по мере надобности.

Out of scope: вход в игру из разминки и тренировки карточек (этап «Разминка»); экран итога игры (общий итог
из макета — отдельный шаг); остальные игры.

## Architecture

Правила игры — чистые функции: таблица темпа, сбор раундов из набора «фраза + перевод», расписание появления
слов. Экран только исполняет расписание и сообщает ответы в `modules/skills`. Фразы берутся из уже загруженных
в приложение уроков (`app/classic_course_phrases.ts`), сети нет — экран открывается мгновенно.

## Security and privacy

Новых данных нет: игра ничего не собирает и не передаёт; очки навыков — уже описанный прогресс на устройстве.

## Technical debt

- Contain: неверные варианты ответа берутся из переводов других фраз того же урока, а в макете они отличаются
  от верного одним словом (время/лицо). Авторских «близких» вариантов в данных нет. Выход — решение владельца:
  либо достаточно, либо отдельная вычитка вариантов.
- Contain: в макете промах отправляет фразу в «Ошибки»; раздел ошибок ведёт другая сессия, вызов добавляется
  после договорённости с ней. До этого подпись про «Ошибки» на экране не показывается.

## Verification

`npm run test:one -- tests/game_flow_core.test.ts` через светофор; открытие экрана на эмуляторе, склейка с макетом.

## Rollback

Удалить перечисленные новые файлы; на игру никто не ссылается.
