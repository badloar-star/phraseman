# DEV_LINKS_LANG_PASS — ключевые экраны на 7 языках интерфейса (Темы 13.10)

Файл генерируется: `python scripts/dev_links_lang_pass.py`. Руками не править.

**Условие:** `dev_state?uiLang` сейчас принимает только `en|off`. Для es / pt-BR / tr / pl / vi / id / uk ссылки заработают после расширения параметра у Ядра (`app/dev_state_fixtures.ts`, `app/dev_ui_lang.ts`): значение = код языка из ворот интерфейсных языков; до этого параметр попадёт в `rejected`.

**Как проходить:** языки идут блоками по 15 экранов; внутри блока `force-stop` не нужен (проверка смены языка без перезапуска), между блоками — `uiLang=off`. Кадр целиком на языке блока: русская или английская строка на нём = прилипшая строка (журнал `[LANG-SWITCH]`, `[I18N-FALLBACK]`). Смотреть длинные слова: переносы, обрезка, перекрытие (кнопки, плашки, заголовки).
