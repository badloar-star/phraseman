## Outcome

Когда Codex положит предметы в `assets/images/v2art/{dark,light}/<name>.webp` + `<name>.accent.webp`, любой экран сможет показать предмет одной строкой `<ThemedArt name="lessons" size={96} />`: тёмный или светлый комплект по оформлению темы, цветная деталь — в цвет акцента темы. Пока картинок нет — показывается нынешняя картинка этого места, без падений и пустых мест.

## Architecture

Metro подключает картинки только статическим `require` — несуществующий файл нельзя указать заранее (сборка упадёт). Поэтому: запасные картинки (`fallback`) указаны в реестре сейчас, слоты новых файлов живут в generated-файле, который скрипт пересобирает по папке. Разрешение `resolveThemedArt(name, brightness)` кэшируется по `name|brightness` в памяти модуля → при смене темы/движении ползунка объекты источников не создаются заново. Цвет детали — `accentBright` из уже кэшированной палитры темы (`liquidGlassTokens`), `tintColor` на втором `Image` поверх основы (expo-image, как остальная графика).

Порядок источника: новый файл нужной яркости → новый файл другой яркости (лучше, чем старая картинка) → нынешняя картинка → пустое место ЗАДАННОГО размера (геометрия первого кадра не прыгает) + лог `[THEMED-ART]`.
