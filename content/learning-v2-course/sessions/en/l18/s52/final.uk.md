# Англійська · Урок 18 · Заняття 52 — Плюси, мінуси й різниця

**Ситуація.** Ви ділитеся сильним враженням і підкреслюєте якість.

**Що ви опануєте:** so + adjective; such + noun phrase
**Нові слова:** benefit, advantage, disadvantage, difference

## Інтро 1

### Сильне враження

benefit — користь, корисний результат. So підсилює прикметник: so kind. Such підсилює групу з іменником: such a kind person. Для одного злічуваного предмета потрібне a або an після such; із множиною й незлічуваними його немає: such kind people, such good news.

**Виберіть фразу для цієї ситуації.**

- ✅ **This benefit is so important.**
- ❌ This benefit is such important. — *Після пропуску прикметник без іменника: so.*
- ❌ This benefit is much important. — *Перед звичайним прикметником тут потрібне so, не much.*

## Інтро 2

### Коли називаємо людину або річ

advantage — перевага. So підсилює прикметник: so kind. Such підсилює групу з іменником: such a kind person. Для одного злічуваного предмета потрібне a або an після such; із множиною й незлічуваними його немає: such kind people, such good news.

**Виберіть фразу для цієї ситуації.**

- ✅ **This is such a big advantage.**
- ❌ This is so a big advantage. — *Після пропуску група з іменником: such. Перед злічуваним в однині зберігаємо a/an.*
- ❌ This is a such big advantage. — *Порядок: such a/an, не a/an such.*

### Підкреслити враження

disadvantage — недолік, невигідний бік. difference — різниця, відмінність. So підсилює прикметник: so kind. Such підсилює групу з іменником: such a kind person. Для одного злічуваного предмета потрібне a або an після such; із множиною й незлічуваними його немає: such kind people, such good news.
