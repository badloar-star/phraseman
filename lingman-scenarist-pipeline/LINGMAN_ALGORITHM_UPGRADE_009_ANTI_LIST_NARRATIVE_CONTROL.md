# Lingman Algorithm Upgrade 009 - Anti-List Narrative Control

Дата:

```text
2026-05-20
```

## Причина

```text
Пользователь указал, что сценарий стал длиннее, но плотность снова была сделана через перечисление примеров.
Нужны рассказы, наблюдения, факты, сцены и объяснения, а не учебный лист с большим количеством фраз.
```

## Главное Правило

```text
Плотность сценария не равна количеству примеров.
Пример должен доказывать мысль, а не заменять мысль.
```

## Лимит Примеров

```text
По умолчанию не больше 2 примеров подряд.

Больше 2 можно только если это:
- короткий drill;
- диагностика;
- финальный recap;
- намеренный ритмичный момент.

Даже в этих случаях блок должен быть коротким и оправданным.
```

## Что Делать Вместо Списков

```text
Если сценарист видит цепочку примеров, он обязан заменить ее на один из вариантов:
- бытовая сцена;
- маленькая история ошибки;
- интересный факт, который объясняет механизм;
- возражение зрителя;
- подробный разбор одного примера;
- переход к следующей идее;
- мост в практику Фрейзмена.
```

## Контроль Каждого Примера

```text
Каждый пример должен отвечать хотя бы на один вопрос:
- почему русскоязычный зритель так скажет;
- что именно хочет английский;
- что зритель должен заметить в следующий раз;
- как это связано с живой речью.
```

## Запрещено

```text
- длинные цепочки фраз;
- перевод за переводом;
- механический ритм таблицы;
- блоки correct / wrong;
- примеры как наполнитель;
- "учебный лист", растянутый до сценария.
```
