## 6. Full Teleprompter Script

### Hook

If you say:

```text
I very like it.
```

I know exactly what happened.

Your Russian brain saw:

```text
очень
```

grabbed:

```text
very
```

and walked into English like it owned the building.

Very confident.

Very logical.

Very wrong.

The natural sentence is:

```text
I really like it.
```

Not:

```text
I very like it.
```

Today I will show you the tiny rule that fixes this mistake, and I will give you better phrases than just "I like it."

### Promise Receipt

Look:

```text
It is very good.
```

Correct.

Why?

Because:

```text
good
```

is an adjective.

Now:

```text
I very like it.
```

Wrong.

Why?

Because:

```text
like
```

is a verb.

In English, "very" usually modifies adjectives and adverbs.

```text
very good
very interesting
very quickly
```

But with verbs, use:

```text
really
```

So:

```text
I really like it.
I really need it.
I really want it.
I really miss you.
```

That is the receipt.

You clicked for "I very like it."

The fix is:

```text
really + verb
```

### The Russian Trap

Russian gives you one very useful word:

```text
очень
```

And you can say:

```text
очень хороший
очень быстро
очень хочу
очень люблю
```

So your brain thinks:

"Beautiful. One word. One solution. English will respect efficiency."

English does not respect efficiency.

English asks:

```text
What kind of word comes next?
```

If the next word is an adjective:

```text
very good
very tired
very important
```

If the next word is an adverb:

```text
very quickly
very slowly
```

But if the next word is a verb:

```text
like
want
need
miss
enjoy
```

use:

```text
really
```

Professor Lingman verdict:

```text
Very is not your universal "очень" button. It has a job description.
```

### Word Function Check

Use this check.

Ask:

```text
What comes after the intensifier?
```

If it is an adjective:

```text
very good
very nice
very strange
very useful
```

If it is a verb:

```text
really like
really want
really need
really miss
really enjoy
```

So:

```text
I very like this song.
```

becomes:

```text
I really like this song.
```

```text
I very want coffee.
```

becomes:

```text
I really want coffee.
```

```text
I very need help.
```

becomes:

```text
I really need help.
```

This is not advanced grammar.

This is word traffic control.

Very goes in one lane.

Really goes in another lane.

### Before/After Speaking Upgrade

Before:

```text
I very like this movie.
```

After:

```text
I really like this movie.
```

Stronger:

```text
I love this movie.
```

More natural:

```text
I'm really into this movie.
```

More expressive:

```text
This movie is exactly my thing.
```

Very strong:

```text
I absolutely love this movie.
```

Notice the upgrade.

We are not only fixing a mistake.

We are giving your English more range.

Because "I really like it" is correct.

But sometimes you need:

```text
I'm really into it.
I love it.
I'm a big fan of it.
It's exactly my thing.
```

That is how you stop sounding translated.

### Micro-Test

Quick test.

Which sentences are natural?

```text
A. It is very good.
B. I very like it.
C. I really like it.
D. I like it very much.
E. I very need this.
F. I really need this.
```

Answers:

```text
A. It is very good.
C. I really like it.
D. I like it very much.
F. I really need this.
```

B is wrong because "like" is a verb.

E is wrong because "need" is a verb.

D is correct because "very much" works as a phrase after the verb.

This is the little edge case.

English says:

```text
I really like it.
I like it very much.
```

But not:

```text
I very like it.
```

Because apparently English enjoys giving you two doors and hiding one handle.

### Edge Case Without Confusion

Now the important edge case.

You can say:

```text
I like it very much.
```

That is correct.

But:

```text
I very like it.
```

is not natural.

So do not think:

"Very is impossible with like."

Think:

```text
very much
```

can come after the verb.

```text
really
```

can come before the verb.

Like this:

```text
I really like it.
I like it very much.
```

Both correct.

But in normal speech:

```text
I really like it.
```

is usually more natural and flexible.

## 9. Description

Stop saying "I very like it" and learn the simple reason it sounds wrong.

Russian "очень" often tempts learners to use "very" everywhere, but English does not work like that. In English, "very" usually modifies adjectives and adverbs, while "really" can modify verbs.

In this lesson, Professor Lingman explains:

```text
why "I very like it" is wrong;
why "I really like it" is natural;
when to use "very";
when to use "really";
why "I like it very much" is correct;
better phrases like "I'm really into it" and "I absolutely love it."
```

After watching, practice natural intensifier chunks in Phraseman so the correct phrase comes out automatically.
