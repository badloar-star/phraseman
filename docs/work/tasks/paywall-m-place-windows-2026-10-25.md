## Outcome

По месту входа сначала короткая панель про человека: «Энергия закончилась» (подождать или Plus), «Серия» (неделя с закрытым пропуском), «Замок урока» (следующий урок и полоса «N из 32»). По тапу — общий экран М с шапкой этого места. «Не сейчас» всегда видно.

## Scope

In scope: панели energy / streak / lock в `components/paywall/m/`, выбор панели по существующему контексту входа, роли цветов по карте Тем (молния — ink плана; кружки недели — ctaFill/ctaFillInk).
Out of scope: окна «Разговор с ИИ» и «Мастерская фраз» (нет данных места во входе: минуты/фразы разговора, номер урока и число фраз — нужны от экранов-источников; пока ведут сразу на общий экран с общей шапкой), «Не видим твой Plus» (остаётся на своём доке 39d9916b3), любые новые `context`/`source`.

## Architecture

`PaywallMSheet` получает `placeKind`; если для места есть панель (`paywallMPanelKindFor`) — первым кадром рисует панель, по кнопке переключает состояние на общий экран (локально, мгновенно, без сети). Данные: снимок прогресса (серия, даты занятий, пройденные уроки), таймер энергии из `useEnergyCountdown`, цены/пробный — те же значения магазина, что у общего экрана.

## Security and privacy

Данных не собираем и не отправляем: числа считаются на телефоне и показываются только человеку.
