# Task packet: не показывать объявления о новинках новичку (онбординг завершён < суток назад)

Governance-ID: TG-41E5419C977C
Status: In progress
Owner: сессия «2 · ДИЗАЙН» по поручению координатора (12.10; находка Сверки 20:5x)
Related epic/enabler: app/app_messages.ts, app/_layout.tsx (очередь модальных объявлений)

## Outcome

Новичок сразу после онбординга видел поверх Главной объявление «Замочки ушли в отпуск!» (что нового) — хотя «старого» он ничего не видел. Результат: модальные объявления (`message`/`poll` с показом при входе) не появляются, если онбординг завершён в этом же запуске или менее суток назад; в журнал пишется `[APP-MESSAGE] skip reason=fresh_install`. Мера успеха: тест на правило «меньше суток / старше / нет отметки / часы вперёд», в журнале видна причина пропуска; уже зарегистрированные пользователи без отметки видят объявления как раньше.

## Scope

In scope: новый чистый модуль `app/fresh_install_gate.ts` (ключ локального хранилища с временем завершения онбординга, вердикт, фильтр очереди); запись отметки в `components/CleanOnboarding.tsx` в момент завершения онбординга (вместе с `onboarding_done`); подключение фильтра к очереди модальных объявлений в `app/_layout.tsx` (один блок); тест `tests/fresh_install_announcement_gate.test.ts`.

Out of scope: личные сообщения администратора (`personal_admin_message`, показ при следующем входе) — они адресованы человеку, не «что нового»; сам список сообщений во входящих центра уведомлений (остаётся, пропускается только всплывающее окно); серверная логика рассылки.

## Architecture

Источник «свежести» — локальная отметка времени завершения онбординга (одна запись в AsyncStorage, без сети и Firestore). Нет отметки (все прежние пользователи, восстановленные аккаунты) → не новичок, объявления показываются как раньше. Часы устройства ушли вперёд больше чем на 5 минут → отметка считается недостоверной и новичком не считаем (иначе объявления скрылись бы навсегда). Фильтр применяется только к очереди модальных объявлений.

## Security and privacy

Новое локальное поле (время завершения онбординга) хранится только на устройстве, не отправляется никуда, персональных данных не содержит; политика конфиденциальности не меняется.

## Technical debt

Pay now: правило и тест. Accept temporarily: переустановка приложения прежним пользователем с онбордингом заново скроет объявления на сутки — допустимо, владелец/координатор решают при желании.

## Verification

`npm run -s test:one -- tests/fresh_install_announcement_gate.test.ts` и соседние тесты сообщений/онбординга; срез типов по затронутым файлам; журнал `[APP-MESSAGE] skip reason=fresh_install` на эмуляторе при свежем онбординге (Сверка).

## Rollback

Откат коммитов; запись отметки безвредна, фильтр без неё не срабатывает.
