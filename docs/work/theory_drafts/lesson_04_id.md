# Teori · Pelajaran 4 kursus baru — «There is, there are, some, any, in, on, under» (ID)

> Sesi «12 · ТЕОРИЯ», 21.10.2026. Bagian 01–14, kalimat bahasa Inggris, dan latihan sama dengan
> `lesson_04_ru.md`. Jebakan penutur bahasa Indonesia: «Di sini ada apotek» — «ada» dipindah jadi
> Here is/have a pharmacy, There is pharmacy (tanpa a); «tidak ada» → There not a; «di» satu kata
> untuk in / on / at → bingung; «di atas» = on, «di bawah» = under, «di samping» = next to.
> Sapaan: kamu. Perlu dibaca ulang oleh penutur asli.

**Judul layar:** Teori · Apa ada di mana

## 01 · Apa yang akan kamu pelajari *(terbuka sejak awal)*

**body**
Di pelajaran ini kamu belajar menyebut apa yang ada di mana: «di dekat sini ada apotek», «di kulkas ada susu», «di sini tidak ada bel», «kunci ada di bawah keset». Pola utamanya There is — dalam bahasa Indonesia cukup «ada».

**examples** 🔊
| en | id | hi |
|---|---|---|
| There is a pharmacy here. | Di sini ada apotek. | There is |
| There is some milk here. | Di sini ada susu. | some |
| Is there a toilet here? | Di sini ada toilet? | Is there |
| There isn't a doorbell. | Tidak ada bel pintu. | isn't |
| The key is under the doormat. | Kuncinya ada di bawah keset. | under |

---

## 02 · There is — «ada» *(terbuka sejak awal)*

**body**
Kalau mau bilang ada sesuatu di suatu tempat, mulai dengan There is. Jangan bilang Here is a pharmacy. Tempat ditaruh di akhir, dan di depan benda ada a: There is a pharmacy here, bukan There is pharmacy.

**formula**
`There is` · `a + benda` · `di mana`

**examples** 🔊
| en | id | hi |
|---|---|---|
| There is a pharmacy here. | Di sini ada apotek. | There is |
| There is a library nearby. | Di dekat sini ada perpustakaan. | There is |
| There is a bakery here. | Di sini ada toko roti. | There is |
| There is an office upstairs. | Di lantai atas ada kantor. | There is |
| There is a clinic inside the building. | Di dalam gedung ada klinik. | There is |

**fix**
- ~~Here is a pharmacy.~~ *(maksudnya «di sini ada»)* → There is a pharmacy here.
- ~~Here have a pharmacy.~~ → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There di sini bukan «di sana». Itu hanya awal kalimat «ada». Jadi There is a pharmacy here — «di sini ada apotek», dan there dengan here tidak bertengkar.

---

## 03 · There are — kalau jumlahnya banyak

**body**
Kalau bendanya banyak, is diganti are, dan katanya diberi s: There are banks here. Di bahasa Indonesia «ada bank» atau «ada bank-bank» sama saja, di bahasa Inggris harus ada s. Seperti pelajaran 3, a tidak dipakai.

**formula**
`There are` · `benda + s` · `di mana`

**examples** 🔊
| en | id | hi |
|---|---|---|
| There are banks here. | Di sini ada bank-bank. | There are |
| There are museums nearby. | Di dekat sini ada museum-museum. | There are |
| There are bridges nearby. | Di dekat sini ada jembatan-jembatan. | There are |
| There are quiet streets here. | Di sini ada jalan-jalan yang sepi. | There are |
| There are parks nearby. | Di dekat sini ada taman-taman. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- kalimat: `There ___ museums nearby.`
- pilihan: `is` · `are` · `am`
- jawaban: `are`
- kenapa: Museumnya banyak, jadi There are.

## 04 · Tempat — di akhir

**body**
Dalam bahasa Indonesia tempat sering di depan: «Di belakang gedung ada taman». Dalam bahasa Inggris kebalikannya: dulu There is dan benda, tempat di akhir — There is a garden behind the building. Dulu apa yang ada, baru di mana.

**examples** 🔊
| en | id | hi |
|---|---|---|
| There is a garden behind the building. | Di belakang gedung ada taman. | behind |
| There is a bench near the garden. | Di dekat taman ada bangku. | near |
| There is a church behind the bank. | Di belakang bank ada gereja. | behind |
| There is a market near the bridge. | Di dekat jembatan ada pasar. | near |
| There is a lake behind the park. | Di belakang taman ada danau. | behind |

**drill · word_bank**
- tugas: Katakan pada temanmu: «Di belakang taman ada danau».
- jawaban: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- label kotak: tidak ada (kalimatnya panjang, petunjuk per kotak malah mengganggu)
- kartu lebih: `are` · `in`

## 05 · Bertanya «ada?» dan jawab singkat

**body**
Untuk bertanya, tukar dua kata pertama: There is → Is there…? There are → Are there…? Jawaban singkat: Yes, there is. No, there isn't. Yes, there are. No, there aren't. Bahasa Indonesia tidak menukar urutan, jadi ini perlu dilatih.

**formula**
`Is there` · `a + benda` · `di mana` · `?` — `Are there` · `benda + s` · `di mana` · `?`

**examples** 🔊
| en | id | hi |
|---|---|---|
| Is there a dentist near here? | Di dekat sini ada dokter gigi? | Is there |
| Is there a toilet here? | Di sini ada toilet? | Is there |
| Yes, there is. | Ada. | there is |
| No, there isn't. | Tidak ada. | isn't |
| Are there trams near the bank? | Di dekat bank ada trem? | Are there |
| Yes, there are. | Ada. | there are |
| No, there aren't. | Tidak ada. | aren't |

**fix**
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~Yes, have.~~ → Yes, there is.
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

## 06 · Susu, roti, mentega — tidak dihitung satuan

**body**
Ada benda yang dihitung: pisang, dua pisang. Ada yang tidak: susu, roti, mentega, gula. Di depannya tidak ada a, dan di akhirnya tidak ada s. Untuk «ada sedikit» pakai some: There is some milk.

**examples** 🔊
| en | id | hi |
|---|---|---|
| There is some milk here. | Di sini ada susu. | some |
| There is some bread near the basket. | Di dekat keranjang ada roti. | some |
| There is some butter near the bowl. | Di dekat mangkuk ada mentega. | some |
| There is some cheese here. | Di sini ada keju. | some |
| There are some berries here. | Di sini ada beberapa buah beri. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
Untuk benda yang tidak dihitung, selalu is, bukan are: There is some milk, walaupun susunya terasa «banyak».

---

## 07 · some atau any

**body**
some — saat bilang bahwa ada. any — saat bertanya ada atau tidak, atau bilang tidak ada. Bahasa Indonesia sering tidak menerjemahkan keduanya: «Ada sup?» — Is there any soup? «Tidak ada jus» — There isn't any juice.

**examples** 🔊
| en | id | hi |
|---|---|---|
| There is some milk here. | Di sini ada susu. | some |
| Is there any soup here? | Di sini ada sup? | any |
| Are there any mushrooms here? | Di sini ada jamur? | any |
| There isn't any juice here. | Di sini tidak ada jus. | any |
| There aren't any carrots here. | Di sini tidak ada wortel. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.

**drill · choice**
- kalimat: `Is there ___ rice near the pot?`
- pilihan: `a` · `some` · `any`
- jawaban: `any`
- kenapa: Kamu bertanya ada nasi atau tidak, jadi any.

## 08 · «Tidak ada»: There isn't, there aren't

**body**
Di bahasa Indonesia «tidak ada» sudah satu paket. Di bahasa Inggris tambahkan not: There is not → There isn't, There are not → There aren't. Satu benda — isn't a, banyak — aren't any. Bukan There not.

**examples** 🔊
| en | id | hi |
|---|---|---|
| There isn't a doorbell. | Tidak ada bel pintu. | isn't |
| There isn't an intercom. | Tidak ada interkom. | isn't |
| There aren't any handrails. | Tidak ada pegangan tangga. | aren't |
| There aren't any steps. | Tidak ada anak tangga. | aren't |
| There isn't a lawn behind the building. | Di belakang gedung tidak ada halaman rumput. | isn't |

**fix**
- ~~There not a doorbell.~~ → There isn't a doorbell.
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.

**drill · binary**
- pertanyaan: Di pintu tidak ada bel. Bagaimana mengatakannya?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- benar: A
- penjelasan: Belnya satu, jadi isn't.

## 09 · in, on, under — di dalam, di atas, di bawah

**body**
Bahasa Indonesia memakai «di» untuk semuanya, bahasa Inggris memilih. in — di dalam: in the sink. on — di atas, menempel di permukaan: on the worktop. under — di bawah: under the doormat.

**examples** 🔊
| en | id | hi |
|---|---|---|
| The lemon is in the sink. | Lemonnya di dalam wastafel. | in |
| The bicycle is in the basement. | Sepedanya di ruang bawah tanah. | in |
| The cups are on the worktop. | Cangkir-cangkirnya di atas meja dapur. | on |
| The plant is on the windowsill. | Tanamannya di ambang jendela. | on |
| The key is under the doormat. | Kuncinya di bawah keset. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

---

## 10 · next to, between … and, near, behind

**body**
next to — tepat di samping. near — di dekat. behind — di belakang. between … and — «di antara … dan …», dua penanda berarti dua kata: between the bank and the library. Pakai and, bukan koma.

**examples** 🔊
| en | id | hi |
|---|---|---|
| The bench is next to the lamppost. | Bangkunya di samping tiang lampu. | next to |
| The signpost is near the bridge. | Papan penunjuk jalan di dekat jembatan. | near |
| The ladder is behind the shed. | Tangganya di belakang gudang kecil. | behind |
| The bus stop is between the bank and the library. | Halte ada di antara bank dan perpustakaan. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- kalimat: `The bus stop is ___ the bank and the library.`
- pilihan: `next to` · `behind` · `between`
- jawaban: `between`
- kenapa: Ada dua penanda — bank dan perpustakaan, halte di tengahnya: between … and.

## 11 · There is atau The … is

**body**
There is — saat memberi tahu bahwa ada sesuatu, lawan bicara belum tahu. The … is — saat bendanya sudah dikenal dan kamu bilang di mana. Mirip akhiran «-nya» dalam «Lemonnya di wastafel». Pertama ada, lalu di mana.

**examples** 🔊
| en | id | hi |
|---|---|---|
| There is a car park near the hotel. | Di dekat hotel ada tempat parkir. | There is |
| The barrier is near the gate. | Palangnya di dekat gerbang. | The |
| There is a storeroom between the kitchen and the hall. | Di antara dapur dan aula ada gudang kecil. | There is |
| The coat rack is behind the door. | Gantungan bajunya di belakang pintu. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- pertanyaan: Adikmu mencari lemon yang kalian berdua tahu. Lemonnya di wastafel. Kamu bilang apa?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- benar: B
- penjelasan: Lemonnya sudah dikenal, kamu bilang di mana: The lemon is in the sink.

## 12 · Bentuk pendek: There's

**body**
Dalam percakapan, There is hampir selalu jadi There's: There's a cashpoint near the bank. There are tidak dipendekkan, dan «tidak» dipendekkan seperti biasa: isn't, aren't.

**examples** 🔊
| en | id | hi |
|---|---|---|
| There's a cashpoint near the bank. | Di dekat bank ada ATM. | There's |
| There's a postbox next to the gate. | Di samping gerbang ada kotak pos. | There's |
| There's a vending machine in the hall. | Di aula ada mesin penjual otomatis. | There's |

**tip**
Jawaban «ya» yang pendek tidak dipendekkan: Yes, there is, bukan Yes, there's.

## 13 · Kesalahan yang dibuat hampir semua orang

**fix**
- ~~Here is a pharmacy.~~ *(«di sini ada»)* → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
Dua pemeriksaan. Kamu memberi tahu bahwa ada sesuatu, atau bilang di mana benda yang sudah dikenal? «Ada» — There is / There are. «Di mana» — The … is. Lalu: satu, banyak, atau benda yang tidak dihitung satuan?

## 14 · Bekal untuk latihan

**body**
«Ada» — There is a… / There are… / There is some… «Ada?» — Is there…? Are there any…? «Tidak ada» — There isn't a… / There aren't any… Tempat di akhir: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | id | hi |
|---|---|---|
| There is a library nearby. | Di dekat sini ada perpustakaan. | There is |
| Are there any mushrooms here? | Di sini ada jamur? | any |
| There aren't any steps. | Tidak ada anak tangga. | aren't |
| The cups are on the worktop. | Cangkir-cangkirnya di atas meja dapur. | on |
