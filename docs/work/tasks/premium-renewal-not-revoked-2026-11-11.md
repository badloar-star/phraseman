## Architecture
Условие отключения проверяется заново ВНУТРИ записи (в колбэке `updateRealPremiumSnapshotForGeneration`, под замком
перехода аккаунта) по актуальному снимку; если он уже даёт доступ — запись не делается, проверка отвечает по нему.
`invalidatePremiumCache()` увеличивает счётчик; вычисление, начатое до сброса, результат вызвавшему отдаёт, но в кэш не кладёт.
Правило «доступ есть» вынесено в одну функцию и используется и для решения, и для перепроверки.

## Security and privacy

прочитанному под замком, с тем же правилом, что и раньше. Новая строка журнала не содержит идентификаторов человека.
