# Phraseman — макеты отработки ошибок

Режим: redesign / preserve. Пользователь 09.09.2026 утвердил предложение показать полный макет и уточнил: ошибки сохраняют один общий слот с последним уроком; постоянной отдельной карточки нет.

Источник палитры: constants/theme.ts DARK. Фон #030604, карточка #101710, поверхность #17241A, акцент #47C870, текст на акценте #042010. Ошибки показываются мягким красным на тёмной подложке. Светлая версия — дополнительная демонстрационная адаптация, не точная копия всей темы приложения.

Шрифт: существующие assets/fonts/Inter-Regular.ttf и Inter-Bold.ttf. Реальный знак: assets/images/icon.webp. Иллюстрации — существующие home_mistakes/home-mistakes-dark.webp и home_menu/home-forest-{lessons,cards}.webp.

Сетка 4/8 px; поля 24 px; кнопки 54 px; скругления 12–22 px. Контраст, единый главный CTA и постепенное раскрытие деталей. Motion 180 ms, отключается при reduced motion. Dials: visual variance 3, motion 2, density 4, assets 7, brand fidelity 8.

Защищённые границы: общий слот; доступ к последнему уроку; Plus; энергия только за старт; скрытие/отмена; report; сохранение состояния. Макет ничего не покупает и не отправляет. Продолжение урока и переход к оплате обозначают границу прототипа.

Предлагаемые, ещё не реализованные решения: явные переключатели внутри общего слота; короткая сессия 3 с вариантами 5/10/15/Все; конкретный feedback; 3 этапа прогресса; resume Home; дневная пауза. Порог автоматического показа на Home не изменён в примере (12 ошибок). Focus с одной ошибкой показан отдельно.

30 состояний: Home errors/lesson; setup; recap; choice wrong/correct; build/feedback; listening/feedback; typing/feedback; finish; due/check/mastered; speech/technical error; pause/resume; one-error/empty/cooldown/loading/load-error/Plus/energy/hide/report.

Учебные данные и даты — демонстрационные. Синтез речи использует браузер, без OpenAI API. Микрофон не запрашивается; speech-ветка симулируется. Награды иллюстративны и не начисляются. Внешних JS/CDN зависимостей нет.
