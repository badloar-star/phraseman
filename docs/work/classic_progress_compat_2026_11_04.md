# Классические курсы: сводка «урок → число фраз старое/новое» (совместимость прогресса)

Старое = данные приложения до внесения (app/lesson_data_*.ts: EN-база, ES — только уроки 1–16 в *_phrases_es.gen.ts). Новое = modules/classic-courses.
Позиция = номер фразы в уроке (старый id `lessonN_phrase_M` ↔ новая M-я фраза урока N). «Тот же текст» — совпадение цели на той же позиции без учёта регистра и знаков.

FR: в приложении нет одобренных французских уроков (APPROVED_FRENCH_LESSON_SEEDS пуст). DE и IT: старого курса нет. Прогресса не теряется, сводка «старое» не применима.
