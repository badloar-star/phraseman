## Outcome

Движение в перенесённых играх совпадает с утверждённым макетом по длительности, кривой и порядку. Числа берутся из
`docs/design/v2-app/elevate-mechanics.css`, `kit.css` и сценариев макета, а не подбираются на глаз. Успех по каждой
игре — запись экрана телефона рядом с записью макета без видимых расхождений.

## Таблица движения (источник — макет)

| Что | Значение в макете |
|---|---|
| Нажатие (`.t`) | вдавливание 90 мс до scale .97 и opacity .86; отпускание 240 мс cubic-bezier(.3,1.4,.5,1), opacity 160 мс |
| Подъём элемента (`rise`) | 520 мс cubic-bezier(.2,1,.3,1), из opacity 0 и translateY 18; задержка лесенкой |
| Дрожь промаха (`shake`) | 380 мс: −7 на 20 %, +6 на 45 %, −3 на 70 %, 0 в конце |
| Исход плитки ответа (`.at.ok/.no`) | фон и цвет текста 260 мс; остальные плитки гаснут до .34 за 300 мс |
| Деление прогресса (`.segs i`) | заполнение scaleX 800 мс cubic-bezier(.2,.8,.2,1) слева направо |
| Подскок числа (`numup`) | 650 мс cubic-bezier(.3,1.4,.5,1): на 35 % translateY −5 и scale 1.22, затем обратно |
| Слово «Потока» (`.line span`) | появление: opacity 0→1, blur 8→0, translateY 8→0 за 0,55 времени слова; opacity и blur — ease-out, сдвиг — cubic-bezier(.2,1,.3,1); уход: opacity →0, blur →10, translateY →−8 за то же время; после ответа фраза возвращается за 300 мс |
| Полоса под фразой (`.beam i`) | scaleX 0→1 линейно за всё время показа, задержка 350 мс; исчезает за 300 мс |
| Подпись под фразой (`.fade`) | opacity 320 мс |
| Столбики темпа (`.tempo i`) | смена фона 300 мс |

## Scope

In scope: новые `components/games/GameAnswerTile.tsx`, `components/games/GameSegments.tsx`, `constants/gameMotion.ts`;
правки своих экранов игр, начиная с `app/game_flow.tsx`, затем `app/game_quiz.tsx`, остальные игры и разминка.

Out of scope: экраны других сессий; новые механики.

## Architecture

Числа движения лежат в одном файле `constants/gameMotion.ts` с указанием строки макета — экраны берут их оттуда.
Плитка ответа и деления прогресса — общие детали: одна реализация движения на все игры.

## Security and privacy

Не затронуто.

## Technical debt

- Contain: размытие слов требует поддержки фильтра размытия на устройстве; если анимируемое размытие на телефоне
  недоступно, слово появляется без него, а расхождение выносится владельцу с записью экрана.

`adb screenrecord`, запись кладётся рядом с записью макета.
