# Стайлгайд карточек «Сокровищницы»

Единые правила для текстов и иллюстраций всех 330 карточек (300 + 30 секретных).
Эталоны: сеты `set01_animals` и `set02_food` в `catalog_seed.json`, иллюстрации — в
`docs/reports/COLLECTIBLES_CARDS_MOCKUP_2026-06-10.html`.

## 1. Тексты (поля карточки)

| Поле | Правило | Лимит |
|---|---|---|
| `en` | Фраза как её реально говорят (с артиклем, если нужен: "A night owl") | — |
| `ipa` | Британская транскрипция, без слешей | — |
| `ru` | Литературный эквивалент, НЕ дословный («Когда рак на горе свистнет», не «когда свиньи полетят») | 60 |
| `literalRu` | Дословный перевод с маленькой буквы — даёт «вау, вот как они говорят» | 80 |
| `meaningRu` | Значение одним простым предложением, «как для детей» | 140 |
| `exampleEn` | Живой бытовой пример: кухня, друзья, работа, телефон. Фраза внутри звучит естественно | 110 |
| `exampleRu` | Перевод примера, разговорный | 130 |
| `originRu` | История происхождения 1–2 предложения, ОБЯЗАТЕЛЬНО с интересным фактом. Если происхождение спорно — «по одной из версий» | 240 |

Тон: дружелюбный тренер. Запрещено: канцелярит, «данное выражение», лекционность.
Если есть русская поговорка-двойник — использовать её в `ru` (это любимый момент пользователей).
Где уместно — факты, цепляющие русскоязычных (пример-эталон: «слон в комнате» — из басни Крылова).

## 2. Редкость = сочность фразы

- **common (150)** — частые и сразу полезные в речи: «hold your horses», «piece of cake»;
- **rare (90)** — образные, со вкусом: «let the cat out of the bag»;
- **epic (45)** — яркие, культурно богатые: «the elephant in the room»;
- **legendary (15)** — самые сочные/культовые/смешные: «the bee's knees», «cool as a cucumber».

Секретная карточка сета — сленг/мем по теме («Top dog», «Food coma», «Touch grass»): награда-сюрприз за полный сет.

## 3. SVG-иллюстрации (целевой арт)

- `viewBox="0 0 200 160"`, прозрачный фон (подложку по редкости даёт приложение);
- плоский «детская книжка»-стиль: 3–6 крупных скруглённых объектов, без мелких деталей;
- сцена иллюстрирует БУКВАЛЬНЫЙ смысл фразы, смешно и узнаваемо (pigs fly = свинка с крыльями в облаках);
- тень под главным объектом: `<ellipse ... fill="rgba(0,0,0,.25)"/>`;
- живые пастельные цвета; текст внутри SVG запрещён; `role="img"` + `aria-label` с фразой;
- ≤ 60 строк на SVG; запрещены `<image>`, `<filter>`, `<script>`, внешние ссылки;
- маскот Тео может появляться в сценах (вопрос продукту — пока опционально).

Плейсхолдеры до готовности арта генерирует `generate.mjs placeholders` (уникальный паттерн+монограмма
по hash от id, цвета редкости) — сет можно выпускать с плейсхолдерами и подменять арт позже.

## 4. Локализация (после русской версии)

Поля `ru/literalRu/meaningRu/exampleRu/originRu` переводятся на uk/es/pt-BR/vi/id/tr/pl
через heisenberg-пайплайн (как контент планов). `en/ipa/exampleEn` общие для всех локалей.

## 5. Аудио

`en` и `exampleEn` озвучиваются OpenAI TTS (существующий пайплайн фраз приложения), файлы кладутся
рядом с ассетами уроков; в карточке кнопка «Прослушать» играет фразу, длинный тап — пример.
