# Урок 32 · Заняття 52 — Упорядковуємо сад

**Ситуація.** Ви з Анною оглядаєте сад після дощу.

**Що ви опануєте:** пояснювати припущення, відкидати неможливий варіант і уточнювати предмет.
**Нові слова:** —
**Повторюємо знайомі слова:** path, bucket, plant, soil

## Інтро 1

### Спостереження й можливість

Ви бачите мокру садову доріжку й припускаєте, що на ній можна посковзнутися. The path is wet, so it might be slippery. — Доріжка мокра, тому вона, можливо, слизька. Складіть The path is wet + so + it might be slippery. До so назвіть спостереження, після so — можливий висновок із might. Перед станом slippery потрібна зв’язка be.

**Виберіть фразу для цієї ситуації.**

- ✅ **The path is wet, so it might be slippery.**
- ❌ The path is wet, so it might is slippery. — *Після might використовуємо be.*
- ❌ The path is wet, so it might to be slippery. — *Після might не ставимо to.*

## Інтро 2

### Цей варіант виключений

У відкритому відрі видно дощову воду. Анна вважала, що воно порожнє. The bucket can't be empty. — Відро не може бути порожнім. Складіть The bucket + can’t + be + empty. Спостереження виключає названий стан. Can’t виражає цей висновок; перед empty тут потрібна зв’язка be.

**Виберіть фразу для цієї ситуації.**

- ✅ **The bucket can't be empty.**
- ❌ The bucket can't is empty. — *Після can’t використовуємо be.*
- ❌ The bucket can't to be empty. — *Після can’t не ставимо to.*

---

## Інтро 3

### Уточнюємо предмет

Ви показуєте Анні предмет й уточнюєте свою дію з ним: The plant I bought is small. — Рослина, яку я купив, маленька. Складіть The plant + I bought + is small. Частина I bought уточнює plant. That можна опустити: I вже називає того, хто виконав дію.

**Виберіть фразу для цієї ситуації.**

- ✅ **The plant I bought is small.**
- ❌ The plant I bought it is small. — *Не повторюємо названий предмет займенником it.*
- ❌ The plant I buying is small. — *Потрібна минула форма bought.*
