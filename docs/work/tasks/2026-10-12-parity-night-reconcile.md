## Outcome

По каждому свежему кадру `evidence/parity/<id>.png` (склейка «образец | приложение»): совпало всё → `match` с evidence и sha256; образец устарел относительно кода (код — эталон) → образец правится под приложение, затем `match`; дефект кода → `diff` и строка в списке дефектов координатору. Страницы под замком владельца (cards-section и т. п.) не правятся. Мера успеха: растёт число `match` в реестре без потери строк.

## Scope

In scope: docs/design/v2-app/*.html (кроме страниц под замком), docs/design/v2-app/assets (копии ресурсов приложения для образцов), registries/visual_parity.json (статусы, diffs, evidence), R1_SHOT_LIST.md (сводка).

Out of scope: код приложения, гейт `release:precheck`, замки владельца (`cards-section.lock.json`).

## Architecture

## Security and privacy

Данных пользователей нет; кадры берутся из эмулятора с тестовыми аккаунтами.
