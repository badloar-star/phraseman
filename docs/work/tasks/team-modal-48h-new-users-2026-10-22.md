# Task packet: окна «от команды» на Главной — только тем, кто в приложении ≥ 48 ч

Governance-ID: TG-2B333D385DB3
Status: В работе
Owner: 5 · ВХОД И АККАУНТ (правило владельца 22.10 через координатора, приоритет)

## Outcome

Владелец 22.10: «Уведомления инбокс на Главной как модал показываются юзерам только которые уже 2 дня в приложении — чтобы модал
уведомления от команды не показывался тем, кто только скачал приложение».
- окно от команды — только если человеку в приложении ≥ 48 ч; до этого сообщение тихо лежит во «Входящих»/колокольчике;
- рассылки, созданные ДО первого входа человека, окном не всплывают никогда (иначе на третий день — пачка старых объявлений);
- ответы на его обращения (report_reply) — исключение, окно можно.

## Scope

Окна на Главной из «Входящих» и рассылок (факты по коду 22.10):
1. Объявления app_messages (kind message/poll, showOnNextLoginModal) → AppMessageAnnouncementModal. Ворота: граница версии
   (announcement_version_floor; с целевой версией — без границы) + «свежая установка» 24 ч (fresh_install_gate).
2. Личные сообщения команды (personal_admin_message, deliveryMode next_login_modal) → окно личного сообщения. Ворот новичка НЕТ.
3. Рассылки с наградой (global_broadcasts через globalBroadcastListActive) → окно рассылки. Ворота: «свежая установка» 24 ч;
   «создана до первого входа» — нет.
4. Ответы на обращения (report_reply) окном не всплывают нигде — только колокольчик/«Входящие»; путь уже отдельный
   (kind report_reply), правило их не касается.

Правка: app/fresh_install_gate.ts (48 ч, первый вход, чистые решения с логом [INBOX-MODAL]), app/_layout.tsx (личное окно,
очередь объявлений, рассылка), app/global_broadcast_modal.ts (кандидат, созданный до первого входа, не выбирается).

## Architecture

Первый вход = локальная отметка завершения онбординга (onboarding_completed_at_ms_v1, пишется один раз в CleanOnboarding) —
без новых чтений. Нет отметки (прежние пользователи 1.6/2.0 до отметки) → не новичок. Часы ушли вперёд → отметке не верим.
Окно новичка 48 ч (было 24). «Создано до первого входа» — для объявлений (включая с целевой версией) и рассылок; для личных —
только 48 ч (личное пишется конкретному человеку, «пачки старых» нет). Скрытое окно не помечается прочитанным: сообщение
остаётся во «Входящих» и всплывёт окном после 48 ч (кроме созданных до первого входа).
