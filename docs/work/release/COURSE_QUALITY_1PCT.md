# Качество курсов: измеритель «не более 1% ошибок на фулл-курс» (Ревизор, 05.11.2026)

Требование владельца: все курсы — теория, интро, уроки, фразы, словари, доп. разделы — проверены, **не более 1% ошибок на фулл-курс**. Измеритель независим от авторов (Теория, Переводчик, Learning V2).

## 1. Что считается ошибкой (по разделам)
| Раздел | Единица счёта | Ошибка |
|---|---|---|
| Фразы (1600/курс) | фраза | перевод ru/uk/другой локали неверен или калька; нет перевода/копия английского; плитки ≠ цель; нет верного в accepted; дубль цели; неестественный ru/uk; подсказка допускает другой естественный порядок, которого нет в alternatives; мусор в alternatives; заглушка |
| Соблазны (1600/курс) | фраза | соблазн = верной плитке; дубли соблазнов; <3; одиночная или парная подстановка даёт принимаемую фразу; соблазн «подходит по смыслу»/выдаёт себя (смысловой — аудит моделью) |
| Словарь (лемм/курс) | слово | нет/неверный перевод ru/uk; грамматика вместо перевода («определённый артикль»); повтор слова между уроками; перевод противоречит теории |
| Охват словаря (1600/курс) | фраза | фраза не связана ни с одним словом словаря; слово задания отсутствует в списке урока |
| Теория | текст ru/uk | запрещённые термины; мета-фраза; нет кириллицы; английская копия в не-en локали; упоминание русского в чужой локали; непонятно новичку (агент) |
| Интро | экран ru/uk | шаблон «Представь ситуацию»; запрещённые термины; мета-фраза; повтор чужого урока; непонятно новичку (агент) |
| Задания | задание | нет образца; слова не из теории; противоречат тексту (fr L2 «là») |
| Заглушки | экран | любой текст «пока готовится/скрыто/скоро откроется» |

Правило 1%: `ошибочных единиц / всех единиц ≤ 1%` **по каждому курсу и каждому разделу**; сумма по курсу тоже ≤ 1%.

## 2. Метод (полный проход, не выборка)
1. **Механический проход по ВСЕМУ корпусу** — `node scripts/course_quality_measure.cjs [--json out.json]`: считает детерминированные классы по 5 курсам × 6 разделам. Запускается после каждой порции правок за секунды.
2. **Смысловой проход по ВСЕМУ корпусу** — аудит моделью: пакеты `docs/work/course_quality_1pct/pass1/chunk_<курс>_NN.json` (100 фраз, 16 на курс, 80 всего) + `INSTRUCTIONS.md`. Начинаю с en и es (32 чанка) по просьбе координатора; пилот на 2 чанках для калибровки доли ошибок и стоимости, затем веер (до 10 параллельно). fr/de/it — после правок Теории/Переводчика.
3. **Контрольная доля** — 5% чанков повторно другим агентом: расхождение >20% по числу замечаний → весь курс перепрогоняется.
4. **Понятность новичку** — `scripts/classic_beginner_qa.cjs` по всем 32 урокам курса (сейчас прогнаны уроки 1–3).
5. **Повтор** после каждой пачки правок до ≤1% по КАЖДОМУ курсу; ошибки передаются пачками: данные курса → Теория, ru/uk и локали → Переводчик, тексты вступлений → Темы.

Главный класс (~90% замечаний): «соблазн выдаёт себя» — слово совсем другой части речи/темы на позиции (вопросительное слово среди имён «Cuándo»; существительные и артикли вместо форм глагола; «выход»/«остановка» среди профессий; `we` вместо `off`). Реже: соблазн даёт принимаемую фразу (es «Сколько стоит билет?»), подсказка ru/uk — калька или смысл не тот («есть ли паспорт» вместо «взяла ли с собой»), лишний/недостающий вариант в alternatives. Агент es 05 отметил: явно лишних соблазнов в корпусе «очень много, общий подход составителей», он записал не все — реальная доля выше.
Следствие: **пороговые 1% по фразам в en/es не достигнуты**; нужна массовая перегенерация соблазнов по правилу «та же часть речи/форма, правдоподобная ошибка» с последующим ПОЛНЫМ перепрогоном (дешёвый префильтр: механическая проверка части речи по тегу + запрет вопросительных слов на не-вопросительных позициях).

## 7. Словарь и неправильные глаголы en (Learning V2, 05.11)
- Словарь `modules/classic-courses/en/glossary.json`: слов заданий без записи было 380, стало 2 (имена Tom/Anna); лемм 853 → 910 (+57: служебные слова, формы неправильных глаголов привязаны к основам); 34 перевода многозначных слов выровнены с теорией. Измеритель: en glossary 0/910, coverage 0/1600.
- Приложение берёт слова en из этого словаря (en включён в `ClassicWordsLang`); прежний прогресс переносится по тексту слова (`app/en_words_switch.ts`, лог `[EN-WORDS-SWITCH]`), ничего не удаляется.
- Неправильные глаголы en (`app/irregular_verbs_data.ts`): 71 глагол, каждый ровно в одном уроке — там, где его формы впервые встречаются в заданиях; +21 новый глагол (ru/uk + 6 локалей); hit/shake/sing/strike в заданиях нет — ни в один урок не назначены. Прогресс глаголов хранится одним общим ключом по основе, перенос между уроками его не сбрасывает.
- Ревизору: перемерить словарь/глаголы en (`node scripts/course_quality_measure.cjs`); `manifest.json` en по glossary.json расходился с файлом ещё до правки — пересобирает владелец манифеста.
