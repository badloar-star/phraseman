# Optimistic UI смены темы: повтор записи, откат при ошибке, защита от гонок, лог [THEMES-SWITCH]

Governance-ID: TG-C3E1A274B99B
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора: аудит Optimistic UI экрана тем)

## Outcome
Смена темы, оформления и насыщенности по-прежнему мгновенна (локальное состояние), запись на диск идёт фоном. Добавлено то, чего не было: один повтор записи при сбое, откат к последнему сохранённому значению при повторном сбое (только если с тех пор не было нового выбора), понятное сообщение человеку, лог [THEMES-SWITCH] по каждому шагу. Двойной тап и быстрая серия не ломают: поздний сбой старой записи не откатывает новый выбор.

## Scope
app/theme_persist.ts (новый чистый модуль), components/ThemeContext.tsx (три setter-а используют его), тест. Вид экрана тем и расчёт токенов не меняются.

## Architecture
createThemePersister: последовательный номер на вид выбора (тема / оформление / насыщенность), карта последних сохранённых значений, одна повторная попытка через 700 мс, откат и тост только при совпадении номера. ThemeContext держит один экземпляр в ref; setState-функции стабильны, зависимости колбэков не растут.

## Security and privacy
Данные темы локальные, в облако не уходят; сообщение не содержит персональных данных.

## Technical debt
Перерисовка всех подписчиков useTheme при смене темы — замер в отчёте; разделение контекста — отдельное решение, не в этой задаче.

## Verification
Тест модуля (успех, повтор, откат, гонка, двойной тап); тесты темы; срез типов.
