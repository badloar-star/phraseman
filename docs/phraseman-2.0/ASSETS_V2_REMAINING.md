## 0. Общие правила — ОДИНАКОВО ДЛЯ ВСЕХ (как у уже принятых картинок Главной)

**Стиль.** Настоящие предметы из настоящих материалов: кожа, плотная бумага, картон, керамика, камень,
матовый металл, дерево. Уровень — премиальные 3D-иконки Apple. Эталон: уже готовые
`assets/images/v2art/dark/lessons.webp` (стопка книг) и `cards.webp` (карточки) — сравнивай с ними каждую новую картинку.

**ЗАПРЕЩЕНО ВЕЗДЕ:** стекло, прозрачность, хрусталь, акрил, линзы, зеркала, хром, блестящее золото, неон, свечение,
пластик-игрушка, пластилин, мультяшность, плоский вектор, чистый белый, цветной корпус предмета, текст, буквы,
цифры, логотипы, фон, пол, тарелка-подставка, рамка, обводка, несколько ракурсов, обрезанный предмет, люди, руки, лица.
Разрешено только как выпуклая пиктограмма: галочка, крестик, звезда, «?», «▶», молния, кавычки, стрелка.

**Два комплекта — один и тот же предмет, разные тона материалов.**
- ТЁМНЫЙ (`dark`, для всех тёмных и градиентных тем, фон ≈ #0B0B0D…#1A1A22):
  основной материал графит — кожа #2B2B30, матовый чёрный картон #26262A, тёмная керамика #303036;
  светлые детали — бумага слоновой кости #E9E3D6, кремовые листы #DDD5C5;
  холодный мягкий блик по верхним кромкам; самая светлая крупная часть минимум на 40 % светлее фона.
- СВЕТЛЫЙ (`light`, для всех светлых тем, фон ≈ #F4F2EE…#EDE7F3): НЕ БЕЛЫЙ.
  основной материал — средний тёплый тон: камень #9C958A, кожа #8A7F74, тёмно-серый картон #6E6A66;
  светлые детали — бумага #E4DDCF; тени внутри предмета заметные #5E5850; ни одна крупная плоскость не светлее #E6E0D4.

**Цвет.** Сам предмет только нейтральный. Цвет даёт ОДНА маленькая деталь (ленточка, ярлычок, кнопка, огонёк),
и она рисуется ОТДЕЛЬНЫМ слоем `.accent` (см. §0.1). В основной картинке эта деталь — нейтральная, тоном светлее корпуса.

**Камера и свет.** Три четверти сверху: камера спереди-справа, наклон 30°, поворот 30–35°, объектив 85 мм.
Ключевой свет — большой мягкий сверху-слева; заполняющий — слабый справа; контровой — тонкая светлая кромка сверху.
Тень — мягкая контактная, плотность 25–35 %, короткая, вниз-вправо, рисуется вместе с предметом.

**Холст.** 1024×1024, прозрачный фон. Предмет — в квадрате 800×800 по центру, нижняя точка на 80 % высоты.
Читается в 96×96 px: крупные формы, 1–2 детали. WebP с альфой, качество 85, вес ≤ 120 КБ.
Исключения по холсту указаны у предмета.

### 0.1 Слой акцента `<name>.accent.webp` — как делать
- Тот же холст, тот же размер, та же позиция — слой накладывается на основную картинку ТОЧНО поверх.
- Видна ТОЛЬКО цветная деталь: чистый белый #FFFFFF, её объём — оттенками серого (свет/тень), всё остальное
  полностью прозрачное. Код красит слой в цвет темы (мятный, лавандовый, розовый и т. д.).
- Делать НЕ генерацией заново, а маской из готовой основной картинки: выделить деталь → перевести в оттенки серого
  → поднять уровни так, чтобы самая светлая точка была белой. Так совпадение гарантировано.
- У dark и light — свой слой (вырезан из своей основной картинки).
- Вес ≤ 30 КБ.

### 0.2 Имена и папки
`<папка на рабочем столе>/<name>-dark.webp`, `<name>-light.webp`, `<name>.accent-dark.webp`, `<name>.accent-light.webp`
— точно как в прошлой выдаче окон первого входа. Координатор сам разложит в
`assets/images/v2art/{dark,light}/`. Имена `<name>` — строго из этого документа.
