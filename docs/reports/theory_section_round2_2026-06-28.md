# Раздел «Теория» — раунд 2: интерактивная теория (2026-06-28)

**Паттернов исследовано:** 38, **оставлено после верификации:** 22

## Резюме

Раунд 2 превращает теорию из read-only лекции в интерактивный тренажёр-в-теории, оставаясь безопасным для 40+/50+. По сравнению с раундом 1 (где фиксировались только структурные проблемы — раздвоение заголовков, спрятанный контент, низкий контраст) теперь добавлено четыре новых семейства интерактивных блоков, прошедших жёсткую адверсариальную проверку: главный флагман — Word-Bank Builder (сборка фразы из кнопок-слов прямо в теории, опт-ин, 1 на экран, без XP), плюс Choose-the-form для уроков с agreement, Spot-the-Slip для пар wrong/correct и Binary Recognition как финал-чек темы. Подтверждены 14 идей и отвергнуты 17 — прежде всего drag-and-drop, скрытые жесты (long-press), микрофон в теории, slot-fill с клавиатурой, прогрессивный фейдинг подсказок и любые механики с XP/штрафами внутри теории. Введён обязательный «Контракт обратной связи» — протокол без модалок, без shake, без хаптик-error, с тёплым тоном бренда («промахи», не «ошибки»). Цветовая палитра доведена до AAA (7:1) с разделением семантики success/danger и accent темы. Под спеку готов кликабельный HTML-макет на 3 темах с встроенными работающими интерактивами.

## Принципы

- Интерактив — ОПТ-ИН, не авто-вставка. На concept-экранах никогда не разрывать дидактический пик 'вот так сломано → вот так правильно'. Интерактив только под кнопкой 'Попробуй' или в kind='practice'.
- Только ТАП, никакого drag-and-drop. Drag убивает аудиторию 50+ (тремор, мелкая моторика). Тап-зоны ≥48dp, кнопки ответа ≥56pt × ≥80pt, gap ≥12pt.
- Один интерактивный блок на экран — максимум. На уроке 1-2 интерактива всего. Иначе теория превратится в череду микро-тестов и убьёт чтение.
- БЕЗ XP, БЕЗ streak, БЕЗ сердец внутри теории. Теория — безопасная песочница. Награда — только визуальная анимация. XP живёт в упражнении урока.
- Контракт обратной связи: без модалок, без shake всего блока (только неверный слот), без haptic-error по умолчанию. Промах = цветовая подсветка + ✕ для дальтоников + накопительная тёплая подсказка. На «промахи», не «ошибки».
- Подсказка-перевод и формула ВСЕГДА видимы во время интерактива. Sticky к верху аккордеона. Рабочая память 60+ хрупкая — нельзя заставлять держать контекст в голове.
- Контраст AAA (7:1) — не AA. Аудитория с дальнозоркостью. Семантика success/danger ОТДЕЛЬНО от accent темы (защита от слияния на янтарных уроках).
- Тестирование на FONT_SCALE 1.30 обязательно — без этого кнопки и формула ломают раскладку (подтверждено Large Font Clipping Audit 2026-06-28).
- Recognition < recall по нагрузке. 3-Tile Choice (узнать форму из 3) — для уроков с agreement. Word-Bank Builder (продуктивная сборка) — флагман для практики, но всегда с переводом и формулой над слотами.
- Никогда не дублировать упражнение урока 1-в-1. Теория-сборка отличается: формула sticky, перевод видим, дистракторы только из той же темы, БЕЗ XP, одна короткая фраза (3 слова max в MVP), а не 5-7.
- Bridge-связки с пройденным («помнишь was/were?») — самая дешёвая и ценная фича. Снижают страх «новой страны» для уроков 23-32 и для повторов.
- Тон бренда на «ты», тёплый, без жаргона. Не «попробуй ещё» — а «почти, попробуй ещё раз». Не «правильно/неправильно» — а «узнал правило руками». Это решает страх двоек у 50+.
- Включать активный интерактив (Spot-the-Slip) только со ВТОРОГО захода в тему. Первый проход — спокойное чтение, чтобы не перегрузить новичка.
- Никакой генерации новых фраз. Реюзать существующие type='example'/'correct'/'wrong' из linesRU — иначе нарушим developerNotes.forbiddenContent.

## Типы блоков

### [static] Шапка темы (Topic Header) (по умолчанию открыт)
- **Цель:** Закрывает CRITICAL «раздвоение теории». Берёт titleRU/subtitleRU первого concept-экрана (helper getTopicHeader) и показывает как 'Урок N · <реальный title>'. Под ним — sticky-чипы оглавления (зачем / как / примеры — максимум 4, без чипа «собери», чтобы не обещать дубль упражнения). Тап по чипу — раскрывает соответствующий аккордеон in-place и плавно скроллит. Помогает 40+/50+ сразу понять, о чём тема, и не теряться.
- **Вид:** Цвет темы в фоне (синий To Be / фиолетовый Do-Does / янтарный модальные), заголовок 22-24sp semibold, подзаголовок 16sp muted (2 строки + ellipsis), чипы 44pt высотой, sticky сверху при скролле, активный чип залит accent-цветом темы.

### [static] Guidebook-экран (kind:concept) (по умолчанию открыт)
- **Цель:** Первый экран каждой темы — ВСЕГДА статичный, без кнопок и проверок. Цель: «понял правило за 20 секунд, не успев испугаться». Только чтение wrong → correct → tip. Это безопасный заход, защита от паники для 50+. Никакого интерактива, чтобы не разрывать дидактический пик «вот так сломано → вот так правильно».
- **Вид:** Размер шрифта на ступень крупнее, чем на интерактивных экранах. Контраст AAA (7:1). Цвет темы только в акцентах (tone='accent' токены), фон нейтральный. Внизу кнопка «Готов» (не «Далее») — психологический сигнал контроля. Линии wrong с tone='danger' приглушённо-красные, correct с tone='success' насыщенно-зелёные, tip в отдельной мягкой плашке.

### [static] Живая формула (Sticky Formula) (по умолчанию открыт)
- **Цель:** На экранах kind='formula' формула остаётся sticky над интерактивом во время сборки. Решает педагогическую проблему: 40+/50+ не связывают «правило в учебнике» и «фразу, которую сами говорят». Слоты формулы («кто», «связка», «описание») окрашиваются в цвет темы. При сборке соответствующий слот пульсирует success/danger — формула становится живой обратной связью.
- **Вид:** Горизонтальная плашка с 3 цветными пилюлями ролей. Пилюли крупные (≥56pt), padding 14pt, разделители-плюсы между ними. Sticky к верху аккордеона. Анимация подсветки 150-200ms ease-out, без скачков масштаба. Цвет пилюль = цвет темы урока (НЕ глобальный accent).

### [interactive] Собери фразу (Word-Bank Builder) (по умолчанию свёрнут)
- **Цель:** ГЛАВНЫЙ ответ на запрос владельца — сборка фразы прямо в теории. Закрывает CRITICAL «теория пассивна». Запускается опт-ин по тапу на свёрнутую карточку «Попробуй собрать фразу руками», НЕ автоматически (не ломает чтение). 1 builder на экран, только на kind='practice' или kind='formula' после tip-строки. НЕ на concept.
- **Вид:** Кнопки слов 56dp высотой, ≥80pt шириной, flex-wrap на 2 ряда, 12pt gap, шрифт 18-20sp. Слот-строка с 3 пилюлями того же размера, цветной обводкой ролей. Подсказка-перевод 22sp над слотами, sticky. Кнопка «Проверить» disabled серая до заполнения. Success: зелёная заливка + чек-иконка + лёгкий glow. Промах: красная вспышка 400ms ТОЛЬКО на неверном слоте + ✕-иконка (для дальтоников). Тестировать на FONT_SCALE 1.30 (Large Font Clipping).
- **Взаимодействие:** Подсказка на родном языке сверху ('Она готова'). Под ней — слот-строка с 3 пустыми пилюлями ролей. Снизу — банк из 4-6 кнопок-слов (3-5 верных + 1-2 дистрактора из той же категории). Тап по слову — автозаполнение в первый пустой слот (250ms fade+slide). Тап по слову в слоте — возврат в банк. Кнопка «Проверить» активна с 1-го заполненного слота. На верном: вся фраза зелёная пульсация 1с + формула выше пульсирует success + автопроигрывание TTS + микро-фраза «Узнал правило руками» + +0.5 искры (визуально, без записи в XP). На промахе: трясётся только неверный слот (без shake всего экрана), под фразой плашка «Сравни с формулой: ‘кто’ = he, а he просит is» — объяснение опирается на цвета формулы. После 2 промахов — автоподсветка правильного слова в банке зелёной рамкой + кнопка «Понятно». Никаких сердец/XP/таймера.

### [interactive] Выбери форму (3-Tile Choice) (по умолчанию свёрнут)
- **Цель:** Единственный жанр для уроков с agreement (1, 2, 4, 5, 7, 9). recognition < recall — самая щадящая нагрузка для 50+. Закрывает находку «формы даются текстом, без активной развилки». НЕ для модальных (semantic choice — отдельная фича).
- **Вид:** Кнопки минимум 56pt × 96pt, gap 12pt, шрифт 22sp+. Карточка отделена от текста теории мягким accent-soft фоном, подпись «Можно пропустить, это не оценивается». Прогресс — нейтральные точки-следы (●○○○), НЕ счётчик «1/4». Контраст 7:1.
- **Взаимодействие:** Свёрнутая CTA-карточка «Попробуй выбрать форму — 4 коротких вопроса» под formula-строкой. Раскрывается по тапу. Внутри: 1-2 фразы с одним пропуском ('She ___ ready'), под каждой банк из 3 кнопок одинакового размера (am/is/are — ВСЕ ТРИ, не 2). Над пропуском — родной чип-скаффолд («она → ?»). Тап → мгновенный фидбэк: верная кнопка плавно зеленеет с галочкой, неверная — мягко пульсирует danger-tint 600ms (БЕЗ shake, БЕЗ haptic-error, БЕЗ блокировки). Объяснение ВСЕГДА (и при верном, и при неверном) одной строкой: «I всегда с am». Кнопка «почему?» отдельной ссылкой под пропуском раскрывает 1-строчную микро-подсказку. После всех ходов — тёплая текстовая реплика «Молодец, форма понятна — пошли тренировать в уроке».

### [interactive] Найди промах (Spot-The-Slip) (по умолчанию свёрнут)
- **Цель:** Превращает пассивный показ 'wrong/correct' в активный noticing. Лечит CQ-01 (нет «образ+почему+что делать»). Самый простой ввод: 1 тап по 1 из 3-5 крупных чипов. Не дублирует упражнение (там продуктивная сборка с нуля, тут — рецептивное распознавание).
- **Вид:** Чипы-слова ≥48dp, gap ≥8pt. Зелёная подсветка из СЕМАНТИКИ (success-tint), а не accent темы (защита от COLOR-01). После фикса — крупная correct-фраза 24sp + микро-tip 1 строкой. accessibilityRole='button' с label слова на target-языке.
- **Взаимодействие:** Wrong-фраза показана как ряд тап-кнопок-чипов. Подпись «Тут лишнее слово» / «Тут не та форма» (вариативность копирайта). Тап по правильному чипу: для diff='вставка лишнего слова' — чип зачёркивается красным и ИСЧЕЗАЕТ через 300ms, correct-форма пульсирует крупно 1.5с. Для diff='замена формы' — two-tap choice: чип подсвечен, под фразой 2 чипа замены (do/does), тап по правильному. Промах: красная вспышка 400ms БЕЗ потери прогресса, можно тапать снова. Жёсткий тайминг: wrong-форма видна ≤3 сек до первого тапа, после фикса wrong-токен мгновенно исчезает (защита от negative transfer — в долгую память уходит только correct). Включать со ВТОРОГО захода в тему (review-режим), не на первом проходе.

### [static] Карта артиклей (Article Flowchart) (по умолчанию свёрнут)
- **Цель:** СПЕЦИАЛЬНЫЙ блок ТОЛЬКО для урока L20 (a/an/the/∅). Артикли — топ-1 боль RU/UK 40+, аудитория годами читала техкарты, дерево-флоучарт у них считывается быстрее текста. ДОБАВЛЯЕТСЯ как 5-й экран (kind='practice') ПОСЛЕ существующих 4 экранов L20, не заменяет их.
- **Вид:** Статичный SVG/Skia флоучарт целиком (никакого branching-интерактива). Узлы: 'Начинается со ЗВУКА гласной?' (исправлено с 'звук гласной'), под ним 2 живых примера (an hour vs a university). Узел 'упомянули раньше / единственный в мире / в принципе' разложен в 3 подсказки-карточки type='example'. Внизу 4 финальные карточки a/an/the/∅ как обычные IntroLine. Никакого 'собери фразу' — только deeplink «Попробуй в уроке →».

### [static] Двухветочная схема If→Then (Branch) (по умолчанию свёрнут)
- **Цель:** Для L26/L31 (conditionals). Двухветочная цветовая разводка 'если' (синяя ветка) — 'то' (фиолетовая ветка) со стрелкой между ними. Статично, без drag/tap. Решает: плоский текст conditionals читается в 3 раза дольше визуальной развилки.
- **Вид:** Новый IntroLine.type='branch'. Две колонки рядом с цветными метками, стрелка-коннектор. Статичные подписи + 1-2 примера в каждой ветке.

### [static] Параллельные колонки (Active↔Passive, Time-Shift) (по умолчанию свёрнут)
- **Цель:** Для L23 (passive), L27 (reported speech). ДВЕ колонки рядом, обе фразы видны одновременно, подсвечен объект-который-становится-подлежащим. Заменяет рискованный flip-card паттерн (для 40+/50+ непонятно что тапать, теряется контекст).
- **Вид:** Новый IntroLine.type='parallel'. 2 колонки, между ними стрелка-трансформации. Подсветка перемещаемого токена. Статика.

### [static] Мостик к пройденному (Bridge) (по умолчанию открыт)
- **Цель:** Карточка «помнишь was/were? пассив строится так же» для L23-32. Самое ценное в идее раздела продвинутых тем — связка с уже изученным снижает страх «новой страны». Можно начать ставить даже в L1-L10 на повторах.
- **Вид:** Новый IntroLine.type='bridge'. Тёплая плашка с иконкой-связкой, мини-цитата из старого урока + 1 строка про текущий. Цвет — нейтральный, не темы.

### [interactive] Аккордеоны concept→formula(→A/B)→practice (по умолчанию свёрнут)
- **Цель:** Структура темы. Для уроков с раздваивающимся правилом (L7, L11, L15, L17-21) — 4 блока concept → formula-A → formula-B → practice. В шапке экрана с 4 блоками — крупная подпись «Правило раздваивается» с двумя иконками веток. Прогресс через счётчик «Шаг 2 из 4» в шапке + заполненная полоса под чипами-якорями (НЕ через градиент насыщенности — защита от провала контраста).
- **Вид:** Заголовки аккордеонов 18sp semibold, превью 14sp muted, счётчик в правом углу. Цвет темы единой интенсивности (без градиента). Полоса прогресса под чипами — 4pt высота, цвет темы.
- **Взаимодействие:** Первая секция (concept) РАСКРЫТА по умолчанию, остальные свёрнуты с превью первой строки и счётчиком («Формула · 3 примера», «Практика · собрать 4 фразы»). Тап по заголовку = сворачивает/раскрывает (единое поведение на всех уроках). Состояние запоминается в AsyncStorage по lessonId+screenId.

### [interactive] Финал-чек: один выбор (Binary Recognition) (по умолчанию свёрнут)
- **Цель:** Лёгкий финал-чек темы. Реюзает готовые wrong+correct пары из linesRU. НЕ на каждом экране — макс 1 на 3-4 экрана теории, иначе превратит теорию в 83 теста подряд. Включать только в kind='practice' или последнем экране подтемы.
- **Вид:** Кнопки минимум 56pt высотой, на всю ширину (минус padding 16pt), gap 12pt. Шрифт body+2 (учитывая FONT_SCALE 1.30). Контраст 7:1 (WCAG AAA — дальнозоркость аудитории). Тёплый бренд-копирайтинг на «ты».
- **Взаимодействие:** В самом конце экрана practice ИЛИ финального экрана подтемы — спокойная плашка «Какой здесь главный сигнал?» и 2 крупные кнопки на всю ширину (например 'I can helps' / 'I can help'). БЕЗ таймера. Тап по верной: галочка + короткий tip-почему 1 строкой («Да! После can — голый глагол, потому что can сам несёт смысл модальности») + озвучка фразы целиком из phrase_audio_url_map. Тап по неверной: кнопка с промахом приглушается серым + зачёркивание, правильная слегка зеленеет + контраст «помни: не helps — а help» + озвучка ПРАВИЛЬНОЙ фразы тёплым тоном. Можно тапнуть ещё раз. Никаких штрафов/вибрации.

### [static] Контракт обратной связи (Feedback Contract) (по умолчанию открыт)
- **Цель:** Не UI-блок, а ПРОТОКОЛ для всех интерактивов. Без него любой интерактив провалится для 40+/50+.
- **Вид:** Правила: (а) НЕТ drag-and-drop, только тап. Тап-зоны ≥48dp, ≥56dp для кнопок ответа. (б) НЕТ модалок, НЕТ полноэкранных оверлеев. (в) НЕТ XP/streak/искр внутри теории (только визуальная анимация-награда). (г) Промах: только цветовая подсветка + дублирующая иконка ✕ для дальтоников, БЕЗ shake всего блока, БЕЗ haptic-error. Hapic — только iOS lightSelection, по умолчанию OFF на Android, тумблер в настройках. (д) Накопительная подсказка тёплая: 1-й промах «почти, попробуй ещё раз», 2-й «они — это про многих, поэтому Do», 3-й — автопоказ правильного ответа зелёным + пояснение, БЕЗ «провала». (е) Бренд: «промахи», не «ошибки». Тон на «ты». (ж) Промах не сбрасывает прогресс/слоты — рабочая память 60+ хрупкая.

## Цвет и контраст

ИТОГОВАЯ ПАЛИТРА. Сохраняем уникальные цвета по темам из раунда 1, но УСИЛИВАЕМ контраст до AAA (7:1) для аудитории 50+ с дальнозоркостью.

To Be (синий): primary #1E5BBF (текст AAA на белом), accent #3B7DDB для активных пилюль формулы, soft-фон #E8F0FC для CTA-карточек интерактива, success #137333, danger #B3261E (мягкий, не алый — защита от стресса 50+).

Do/Does (фиолетовый): primary #5E2D9E, accent #7C3FBF, soft #F0E8FC, success/danger — единая семантика.

Модальные (янтарный): primary #B45309, accent #D97706, soft #FEF3E0. Янтарный — самый рискованный по AA, поэтому фон карточек на янтаре всегда нейтральный (белый/серый), цвет идёт только в обводки, пилюли, акцентные токены.

ЕДИНАЯ СЕМАНТИКА (не зависит от темы): success #137333, danger #B3261E, warning #B45309. Никогда не использовать accent темы для «правильно/неправильно» — иначе на янтарных уроках correct сольётся с темой (защита от COLOR-01/02 из раунда 1).

ОТКАЗ ОТ ГРАДИЕНТА НАСЫЩЕННОСТИ по секциям: на 4-блочных схемах прогресс через счётчик «Шаг 2 из 4» + полоса, а не через бледный→насыщенный (бледные тона провалят AAA-контраст).

КОНТРАСТ интерактивных кнопок: текст на кнопке 7:1 к фону кнопки. Серый «disabled» — не ниже 4.5:1 (иначе 50+ не видят кнопку «Проверить»). Подсказки/перевод — minimum 6:1, не ниже.

ТАКТИЛЬНЫЙ ОТКЛИК: визуальная подсветка работает БЕЗ хаптика самостоятельно (многие 60+ выключают вибрации).

## Покрытие по темам

To Be (L1, L2): полное покрытие макета — Guidebook + Sticky Formula + 3-Tile Choice (am/is/are) + Word-Bank Builder. ОСНОВНОЙ пилот.

Do/Does (L4, L5): Guidebook + Sticky Formula + 3-Tile Choice (2 кнопки Do/Does) + Spot-the-Slip (лишнее -s) + Word-Bank Builder.

Have/Has (L7): 4-блочная схема concept → formula-A (I/you/we/they → have) → formula-B (he/she/it → has) → practice. 3-Tile Choice с банком [have/has].

Артикли (L20): СПЕЦИАЛЬНЫЙ статичный SVG-флоучарт как 5-й экран. Без branching-интерактива. Deeplink в упражнение урока.

Модальные (L10): Guidebook + Bridge-плашка + Sticky Formula + Spot-the-Slip (лишнее to, лишнее -s) + Word-Bank Builder + Финал-чек Binary Recognition. НЕТ 3-Tile Choice (semantic choice, отложено).

Времена прошлые/будущие (L11-L13, L17, L24, L25, L29): аккордеоны + Bridge-плашки («помнишь was/were?»). НЕТ оси времени (отвергнута). Простое противопоставление двух примеров side-by-side через type='example'.

Conditionals (L26, L31): новый IntroLine.type='branch' — двухветочная схема If→Then. Статика, без интерактива.

Passive (L23), Reported Speech (L27): новый IntroLine.type='parallel' — две колонки рядом с подсвеченным трансформируемым токеном. Без flip-карточек.

Неправильные глаголы (L12): аккордеоны с существующими formula-заголовками групп («Покупать/пить/находить») усилены как новый IntroLine.type='group_header' (без collapse). НЕТ под-аккордеонов 2-го уровня (отвергнуто). Одна общая интерактивная сборка в конце экрана с примерами из ВСЕХ групп вперемешку.

Короткие 3-экранные уроки (L3, L6): стандартная схема concept→formula→practice с раскрытым concept и счётчиком прогресса. Аккордеоны не убираем (единое поведение на всех уроках).

## Бриф на макет

МАКЕТ — 3 экрана-вкладки (To Be / Do-Does / модальные), переключаемые табами сверху. Размер 380×800 (мобильный viewport, под iPhone SE с FONT_SCALE 1.30 проверка обязательна). Всё на русском, тон на «ты».

===== ГЛОБАЛЬНАЯ СТРУКТУРА КАЖДОГО ЭКРАНА =====

1) ТАБ-БАР сверху (3 цветных таба с цветом темы — синий/фиолетовый/янтарный). Активный таб с заливкой, неактивные — обводка.

2) ШАПКА ТЕМЫ (sticky):
   - To Be: «Урок 1 · Слово, без которого фраза не звучит» / подзаголовок «Маленькое слово am/is/are склеивает кто-ты и какой-ты».
   - Do-Does: «Урок 5 · Как спросить про действие» / «Если вопрос про действие, английский начинает его с Do или Does».
   - Модальные: «Урок 10 · Слово перед действием» / «can, should и must ставятся перед действием и меняют его смысл».
   Заголовок 22sp semibold, подзаголовок 16sp muted (2 строки).

3) ЧИПЫ-ОГЛАВЛЕНИЕ (sticky под шапкой, горизонтальная лента, 44pt каждый): «зачем» / «как это работает» / «примеры». БЕЗ чипа «собери» (не обещаем дубль упражнения). Тап по чипу = плавный scrollTo + раскрытие аккордеона.

4) АККОРДЕОНЫ concept → formula → practice. Первый (concept) развёрнут по умолчанию, остальные свёрнуты с превью первой строки и счётчиком «Формула · 3 примера», «Практика · собрать 1 фразу». Прогресс «Шаг 1 из 3» в шапке секции + полоса 4pt под чипами.

===== ЭКРАН 1: TO BE (СИНИЙ) =====

CONCEPT (раскрыт, Guidebook-режим, БЕЗ интерактива):
- Строка wrong (приглушённо-красная): «I here / He busy / It important»
- Строка correct (насыщенно-зелёная с подсветкой am/is/are синим accent): «I AM here / He IS busy / It IS important»
- tip-плашка soft-blue: «Без am/is/are фраза не «склеивается». Это связка кто+какой.»
- Кнопка «Готов» (синяя обводка, 56pt) — психологический сигнал контроля.

FORMULA (свёрнут, превью «кто + am/is/are + описание · 3 примера»):
При раскрытии:
- STICKY FORMULA сверху аккордеона: 3 синие пилюли [кто] + [am/is/are] + [описание]
- 3 example-строки с подсветкой am/is/are.
- НИЖЕ — карточка-CTA «Попробуй выбрать форму — 1 короткий вопрос» (3-Tile Choice):
  - Скаффолд «она → ?»
  - Фраза «She ___ ready» (24sp, пропуск пульсирует синим)
  - 3 кнопки в ряд: [am][is][are] (по 96pt × 56pt, gap 12pt)
  - Под кнопками — ссылка «почему?» (мелкая, разворачивает 1-строчную подсказку)
  - При верном тапе: 'is' зеленеет с галочкой + 1 строка «She — это he/she/it, поэтому is».
  - При неверном: 'am' мягко пульсирует danger 600ms (БЕЗ shake, БЕЗ блокировки). Подсказка та же.
  - Прогресс — 3 нейтральные точки внизу.

PRACTICE (свёрнут, превью «собрать 1 фразу»):
При раскрытии:
- STICKY FORMULA остаётся синяя.
- Карточка-CTA «Попробуй собрать фразу руками» (свёрнутая, на тап раскрывается):
  - WORD-BANK BUILDER:
    - Подсказка-перевод 22sp: «Она готова»
    - Слот-строка: 3 пустых пилюли с цветной обводкой ролей [кто][связка][описание]
    - Банк кнопок-слов (flex-wrap, 2 ряда, 56dp × ≥80pt, gap 12pt): [She][is][ready][He][am][busy] (3 верных + 3 дистрактора темы)
    - Кнопка «Проверить» (disabled серая 4.5:1, активная синяя 7:1 после заполнения)
    - Тап по слову: автозалёт в первый пустой слот (250ms fade+slide). Тап по слову в слоте: возврат.
    - Верно: вся фраза зелёная пульсация 1с + формула выше пульсирует success + автопроигрывание TTS (иконка-динамик) + микро-фраза «Узнал правило руками» + лёгкий glow. БЕЗ XP.
    - Промах (например She+am+ready): трясётся ТОЛЬКО слот [связка] (не весь блок) + плашка под фразой «Сравни с формулой: ‘связка’ — это is, потому что she/he/it идут с is».
    - После 2 промахов: правильное слово в банке подсвечивается зелёной рамкой + кнопка «Понятно».

===== ЭКРАН 2: DO-DOES (ФИОЛЕТОВЫЙ) =====

ЧИПЫ: «зачем спрашивать через Do» / «формула вопроса» / «попробуй».

CONCEPT (раскрыт):
- wrong: «He live here? / She likes tea?»
- correct: «DOES he live here? / DOES she like tea?» (DOES — фиолетовый accent)
- tip: «В вопросе про действие английский ставит Do/Does ПЕРЕД лицом. После Does — глагол без -s.»
- Кнопка «Готов».

FORMULA:
- STICKY FORMULA: [Do/Does] + [кто] + [действие]
- 3 примера: «Do you drink coffee? / Does he live here? / Do they know you?»
- 3-Tile Choice (CTA «Попробуй — 3 вопроса»):
  - «___ you drink coffee?» → [Do][Does] (банк 2 кнопок для Do/Does достаточно)
  - «___ he live here?» → [Do][Does]
  - «___ they know you?» → [Do][Does]
  - Прогресс точки ●○○ → ●●○ → ●●●. Никакого счётчика «1/3».

PRACTICE:
- STICKY FORMULA фиолетовая.
- SPOT-THE-SLIP (для diff='лишнее -s'):
  - Подпись «Тут лишнее окончание»
  - Чипы-слова: [Does][he][lives][here]
  - Тап по 'lives' → 'lives' зачёркивается красным и исчезает через 300ms → крупно «Does he live here?» 24sp пульсирует 1.5с + tip «После Does — голый глагол, без -s».
- Ниже — CTA WORD-BANK BUILDER «Собери вопрос»:
  - Подсказка: «Она любит чай?»
  - Слоты: [Do/Does][кто][действие][дополнение]
  - Банк: [Does][Do][she][like][likes][tea] (3 дистрактора темы)
  - Логика как на To Be.

===== ЭКРАН 3: МОДАЛЬНЫЕ (ЯНТАРНЫЙ) =====

ЧИПЫ: «зачем нужны can/should/must» / «как ставить» / «когда что выбрать».

CONCEPT (раскрыт):
- wrong: «I can helps you / I must to go now»
- correct: «I CAN help you / I MUST go now» (CAN, MUST — янтарный accent на белом фоне)
- tip-плашка: «После can/should/must — голый глагол. Без -s, без to.»
- BRIDGE-плашка (нейтральная): «Помнишь, как мы говорили I help / he helps в Present Simple? С can/should/must -s исчезает — модал сам несёт смысл.»

FORMULA:
- STICKY FORMULA: [кто] + [can/should/must] + [действие]
- 3 примера с разными модалами.
- ВАЖНО: для модальных НЕТ 3-Tile Choice (semantic choice — отдельная фича, не agreement).
- Вместо этого SPOT-THE-SLIP two-tap-choice:
  - Подпись «Тут не та форма»
  - Чипы: [I][must][to][go][now]
  - Тап по 'to' → 'to' зачёркивается красным и исчезает → крупно «I must go now» + tip «После must — без to».

PRACTICE:
- STICKY FORMULA янтарная.
- WORD-BANK BUILDER:
  - Подсказка: «Я могу помочь тебе»
  - Слоты: [кто][модал][действие][дополнение]
  - Банк: [I][can][help][you][should][helps] (с дистракторами темы)
  - Тап-сборка → проверка → озвучка фразы.
- ФИНАЛ-ЧЕК (Binary Recognition) внизу экрана — спокойная плашка на всю ширину:
  - «Какой здесь главный сигнал?»
  - 2 кнопки 64pt на всю ширину: «I can helps» / «I can help»
  - Тап по верной: галочка + tip «Да! После can — голый глагол, потому что can сам несёт смысл модальности» + озвучка.
  - Тап по неверной: «I can helps» приглушается серым + зачёркивание, «I can help» зеленеет + «помни: не helps — а help» + озвучка ПРАВИЛЬНОЙ фразы.

===== ИНТЕРАКТИВНЫЕ ДЕТАЛИ ДЛЯ HTML-МАКЕТА =====

JS-логика (vanilla, без фреймворков):
- Аккордеоны: click по заголовку → toggle class 'open' с CSS-анимацией высоты 250ms.
- 3-Tile Choice: data-correct атрибут на кнопке, click → проверка → добавление class 'correct'/'wrong', через 600ms reset класса 'wrong'.
- Word-Bank Builder:
  - Массив slots (изначально пустой), массив bank.
  - Click по слову в банке → push в первый пустой slot, удалить из bank (DOM-перенос с CSS-transition).
  - Click по слову в слоте → вернуть в bank.
  - Click «Проверить» → сравнить slots с correctAnswer.
  - Верно: добавить class 'success' слотам + проиграть TTS (или placeholder beep), показать success-плашку.
  - Промах: добавить class 'shake' только неверному слоту, показать explanation.
- Spot-the-Slip: click по чипу → если data-extra='true' → fadeOut(300ms) → showCorrect(); иначе shake 400ms.
- Binary Recognition: click по кнопке → проверка → правильную зеленить, неверную серить + зачёркивать. Без блокировки.

CSS:
- CSS-переменные на каждую тему: --topic-primary, --topic-accent, --topic-soft.
- Sticky formula: position:sticky; top: <высота шапки + чипов>;
- Кнопки-слова: min-width: 80pt, min-height: 56pt, padding: 14pt, font-size: 18pt, border-radius: 12pt.
- Transition: transform 250ms ease-out для перелёта слов.
- Animation 'shake': translateX ±4pt 3 цикла за 400ms.
- Animation 'success-glow': box-shadow с зелёным glow, 1s.
- @media для FONT_SCALE 1.30: уменьшить количество кнопок в ряду до 2, увеличить вертикальный gap.

ACCESSIBILITY:
- Все кнопки: role='button', aria-label с русским описанием.
- Спикер-иконки: aria-label='Озвучить фразу'.
- Цвет НЕ единственный канал: добавить ✓ / ✕ иконки на success/error.

## Отвергнутые идеи

- Quick-recall плашка в начале следующего экрана — ломает поток чтения, spaced retrieval на интервале 60 секунд не работает, требует 664 новых блока контента.
- Прогрессивное снятие подсказок (scaffolding fading) от экрана к экрану — линейный рамп без mastery-based fading создаёт выученную беспомощность, дублирует упражнение урока на последнем уровне.
- Mini-build внутри tip-строки — open-ended генератор переводов даёт semantic garbage ('I must rest'), ломает закрывающую функцию tip.
- Микрофон в теории (Cake-паттерн повторения, ELSA фонемы) — аудитория 50+ боится мика даже с щадящей оценкой, требует TTS-пайплайн на 500+ строк, дублирует речевой режим урока.
- Slot-fill с клавиатурой и подсказкой первых букв — английская раскладка на телефоне для 50+ катастрофа, барьер выхода из теории.
- Reveal-on-tap с анимацией залетающих слов и автохайлайтом через 5 сек — вестибулярный шум + давление по времени, рациональный юзер всегда тапает «показать» и теория превращается в комикс.
- Шкала «слабее → сильнее» для модальных (can/should/must на одной оси) — методически некорректна (can про возможность, should/must про обязанность), вводит в заблуждение.
- Ось времени для прошлого/будущего/перфекта — пассивная визуализация, конфликтует с цветовой системой тем, требует нового типа блока + переписки 7 уроков × 8 локалей.
- Парные карточки для двух колонок (my/mine, do/does) с drag-and-drop — drag антипаттерн для 50+, дублирует упражнение урока, не подходит для уроков с 3 группами местоимений.
- Группы-папки 2-го уровня для длинных списков irregular verbs — вложенные аккордеоны ухудшают находку «контент спрятан за тапами», требуют миграции типов и контента.
- Чипы-оглавление с горизонтальной лентой 5-6 чипов — горизонтальный скролл системно пропускается аудиторией 60+ (NN/g 65% slip-rate), чип «собери» создаёт ложное обещание дубля упражнения.
- Аккордеоны не нужны для коротких 3-экранных уроков — гипотеза построена на цифре из воздуха (у L1 8 экранов, не 3), ломает единое поведение, убирает карту прогресса.
- Зебра-сопоставление (Pair-matching местоимений и форм) — другая когнитивная операция (matching), не отвечает на бриф «сборка фраз», изолирует пары от живой фразы, не масштабируется (3 урока из 22).
- Шкала силы Strength Scale с двухшаговым тапом ячейка→слово — два решения подряд + рабочая память «какую ячейку я тапнул», категории «мягко/совет/жёстко» абстрактны для новичка.
- Tone Swap «мягче/жёстче» с переключателями — смешивает разные смыслы модалов (возможность/совет/обязательство), методически неверно, иконки облако/молния не считываются.
- Любые механики с XP/streak/сердцами внутри теории — обесценивают основное упражнение, превращают безопасную песочницу в экзамен.
- Long-press как «tap to learn how» — скрытый жест с discovery rate <10% у 50+, тач-зона на отдельном слове 60-80px нарушает WCAG 2.5.5.
