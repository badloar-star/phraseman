# Английский · Урок 15 · Занятие 13 — Погода меняется

**Ситуация.** Вы смотрите в окно и по заметным признакам предполагаете, какой станет погода.

**Что вы освоите:** review: going to predictions from present evidence
**Новые слова:** downpour, gale, gust, slush

## Интро 1

### Признак уже виден

downpour — сильный ливень. Небо почти чёрное; уже падают первые крупные капли. There is going to be a downpour. — Сейчас будет ливень. По видимому признаку делаем прогноз: be going to + начальная форма глагола.

**Выберите фразу для этой ситуации.**

- ✅ **There is going to be a downpour.**
- ❌ There is going be a downpour. — *После going нужна to.*
- ❌ There are going to be a downpour. — *Здесь один предмет: нужна is.*

---

## Интро 2

### Ещё два изменения

gale — очень сильный ветер; gust — внезапный порыв ветра. Ветер быстро усиливается; большие ветви уже сильно качаются. There is going to be a gale. — Похоже, будет очень сильный ветер. Выберите прогноз.

**Выберите фразу для этой ситуации.**

- ✅ **There is going to be a gale.**
- ❌ There is going be a gale. — *После going нужна to.*
- ❌ There are going to be a gale. — *Здесь один предмет: нужна is.*

---

## Интро 3

### Основание для прогноза

slush — мокрая снежная каша. Снег на дороге уже тает; воздух становится теплее. There is going to be slush on the road. — На дороге будет снежная каша. После going to форма глагола не меняется.

**Выберите фразу для этой ситуации.**

- ✅ **There is going to be slush on the road.**
- ❌ There is going be slush on the road. — *После going нужна to.*
- ❌ There are going to be slush on the road. — *Здесь один предмет: нужна is.*
