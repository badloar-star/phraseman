## Сторож

`theme_hardcoded_colors_ratchet` считает только `.tsx` вне `components/home/**`, `app/_*`, онбординга, админки и палитр; строка с `theme-exempt:` не считается. Дыры: `.ts`-файлы токенов (там сидят `wordCardGradient`, `tower_skins`, `home_scene_tokens`), Главная (`components/home/**` пропущена), причина в `theme-exempt` не проверяется.
Ужесточение (в этом заходе): сторож `v2_screens_no_new_color_literals` — для списка v2-экранов (сцена Главной, «Сегодня», Сезон, экзамен главы, Диалоги, Пик, дуэль) число цветовых литералов НЕ растёт по файлам, `theme-exempt` допускается только с причиной из словаря (`scrim`, `shadow`, `ink-on-media`, `metal`, `illustration`).
