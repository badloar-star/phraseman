# Урок 31 · Заняття 45 — Де чашки?

**Ситуація.** Після переїзду ви розбираєте коробки й допомагаєте Анні знайти посуд.

**Що ви опануєте:** пояснювати, навіщо ви відкрили й підписали коробку, та називати того, хто її спакував.
**Нові слова:** —
**Повторюємо знайомі слова:** box, cups, label, shelf

## Інтро 1

### Відкрив коробку, щоб знайти чашки

Після переїзду ви шукаєте чашки: I opened the box to find the cups — я відкрив коробку, щоб знайти чашки. Складіть I opened the box + to + find the cups. Відкрив — дія, to find — її мета. Після to використовуємо find, а не found.

**Виберіть фразу для цієї ситуації.**

- ✅ **I opened the box to find the cups.**
- ❌ I opened the box to found the cups. — *Після to потрібна форма find.*
- ❌ I opened the box for find the cups. — *Перед find для мети потрібне to.*

---

## Інтро 2

### Підписав коробку для Анни

Щоб Анна згодом знайшла чашки, ви підписали коробку: I labelled the box so that Anna could find the cups — я підписав коробку, щоб Анна могла знайти чашки. Складіть I labelled the box + so that + Anna could find the cups. Підписали ви; після so that називаємо Анну та її дію.

**Виберіть фразу для цієї ситуації.**

- ✅ **I labelled the box so that Anna could find the cups.**
- ❌ I labelled the box to Anna find the cups. — *Для частини з Anna потрібна сполука so that.*
- ❌ I labelled the box so that Anna could found the cups. — *Після could потрібна форма find.*

---

## Інтро 3

### Коробку спакував Бен

Анна запитує, хто спакував коробку. Почніть відповідь із коробки: The box was packed by Ben — коробку спакував Бен. Складіть The box + was packed + by Ben. Was packed повідомляє, що зробили з коробкою; by Ben називає того, хто це зробив.

**Виберіть фразу для цієї ситуації.**

- ✅ **The box was packed by Ben.**
- ❌ The box was pack by Ben. — *Після was потрібна форма packed.*
- ❌ The box were packed by Ben. — *Одна box потребує was.*
