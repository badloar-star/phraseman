3. Сканер непереведённого: строка со значением ru (`messageRu:`, `textRu:`, `ru:`) не считается находкой, если внутри того же
   литерала-объекта или вызова есть непустой en-вариант; тест на «есть en» и «en пустой/нет»; база вниз по чистому срезу.

## Architecture
Поля сценария заполняются вручную (одна правка на сценарий через скрипт вставки после строки `nextStepHintRu`/`titleRu` по id —
текст задаётся явной таблицей id → {title, hint}, без генерации). Сканер: окно объекта — от открывающей `{`/`(` до парной,
считается по строкам с учётом вложенности.
