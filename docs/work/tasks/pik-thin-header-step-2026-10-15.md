# Пик: «тонкая шапка» как первая ступень ужатия — подготовлена, выключена флагом (координатор 15.10)

Governance-ID: TG-564311DBEDE5
Governance-ID: TG-B51099BCDF82

## Outcome
Если на реальных кадрах iPhone 390×844 при шрифте 1.0 Пик уходит в режим прокрутки — это слишком частый телефон. Первый кандидат — более тонкая шапка страницы Пика. Ветка готовится заранее и не включается: флаг `SPIRE_THIN_HEADER_ENABLED = false`, решает координатор по кадрам. Башню над подиум не поднимаем (решение владельца 13.10).

## Scope
`components/spire/spire_tower_window.ts` (лестница ступеней обобщена: шапка 22 → подиум 40 → строка этажа 32 → режим прокрутки; при выключенном флаге поведение прежнее), `use_spire_tower_budget.ts` (приведение верха окна к «полному» по сумме применённых ступеней выше башни), `SpireHomeScreen.tsx` (вид тонкой шапки: заголовок 24/30 вместо 34/40, отступы 6→0), тесты `spire_tower_window_height`, `spire_dock_always_above_pill`.

## Architecture
Ступени применяются по порядку; ступень i включается при rawFit + сумма экономий предыдущих < 180, режим прокрутки — при rawFit + сумма всех < 120; гистерезис 16 dp. Для включённой шапки: 180 / 158 / 118 / 26; для выключенной (по умолчанию) прежние 180 / 140 / 48. Шапка и подиум лежат выше башни — их экономия прибавляется к измеренному верху окна башни, строка этажа ниже башни и в верх не входит.

## Security and privacy
