## Outcome

Подсветка «силы слова» на карточках и персональная аналитика ошибок считаются по
журналу ТЕКУЩЕГО изучаемого языка, а не всегда по английскому. Пользователь,
изучающий испанский/французский/немецкий, видит свою реальную статистику, а не
пустоту.

Измеримо: при изучении не-английского языка `loadWordStrengthMap` читает ключ
журнала своего языка; сегодня он всегда читает английский и возвращает пустую
карту, из-за чего подсветка слов просто не появляется.

## Scope

In scope:
- `app/flashcards/word_strength.ts` — `loadWordStrengthMap()` принимает язык;
- `app/flashcards_collection.tsx` — единственный вызов передаёт свой `studyTarget`;
- `app/phrase_analytics.ts` — `computePhraseAnalytics()` получает язык;
- логи причин в местах, где ошибка сейчас глотается немым `catch`.

Out of scope:
- `app/community_packs/localAuthorPacks.ts` — **файл редактируется другой
  сессией прямо сейчас** (незакоммиченная правка типа `studyTarget`). Починка
  перебора языков `['en','fr']` ждёт освобождения файла;
- `app/study_target_server_prefetch.ts` — мёртвый код, ни одного импорта;
- `app/statsCache.ts`, `flashcards_swipe.tsx`, `useCollectionData.ts` — там
  ошибки чисто структурные (присвоение `StudyTarget` в узкий тип), поведение
  корректное.

## Architecture

No architecture change: функции получают уже существующее значение явным
параметром вместо чтения глобального умолчания.

Инвариант: **всё, что читает журнал ошибок, обязано знать язык**. Журнал
разложен по языковым ключам (`scopedOrLegacyKey`, `target_storage_keys.ts:157`),
поэтому вызов `storageStudyTarget()` без аргумента молча означает «английский», а
не «текущий». Это не опечатка одного места: тот же паттерн был в двух файлах.

Сигнатура остаётся обратно совместимой (параметр необязательный) — вызовы без
аргумента продолжают работать как раньше, что важно для чужих мест, которые я не
вижу.

## Security and privacy

Не применимо: читается локальный журнал ошибок самого пользователя, объём и
состав читаемых данных не меняется — меняется только ключ языка. Новых данных не
собирается, наружу ничего не уходит. Privacy Policy не затрагивается.

## Technical debt

- **Pay now** — оба вызова получают язык; немые `catch` начинают называть причину
  (правило владельца «сперва логи»: запрет немого `catch {}`).
- **Contain** — нет сторожа на «чтение журнала без языка». Граница: логи теперь
  печатают, каким языком прочитан журнал, — расхождение станет видно в трассе.
  Exit: тест-контракт «loadWordStrengthMap(es) читает ключ es».
- **Accept temporarily** — `app/study_target_server_prefetch.ts` остаётся мёртвым
  кодом с 5 ошибками типов. Владелец: владелец проекта. Потолок ущерба: нулевой,
  функции не импортируются. Exit: удалить или подключить.

## Verification

- проверка типов с `--max-old-space-size=8192` до и после: ошибки в затронутых
  файлах не добавляются (исходные 415 не должны вырасти);
- чтение кода: единственный вызов `loadWordStrengthMap` —
  [flashcards_collection.tsx:505](app/flashcards_collection.tsx), там
  `studyTarget` доступен со строки 163;
- логи: при открытии коллекции трасса называет прочитанный язык и число записей,
  а прежде немой `catch` — причину отказа.

Ограничение: подтвердить «пользователь видит подсветку» можно только на
устройстве с не-английским языком и непустым журналом ошибок. До такой проверки
заявляю починку чтения журнала, а не факт появления подсветки.

## Rollback

`git revert <commit>` возвращает прежнее поведение (всегда английский журнал).
Пользовательских данных не затрагивает: правка только читающая, журналы не
переписываются и не мигрируют. Откат безопасен в любой момент.
