Составлено чтением кода (без запуска приложения). Тексты — точные русские строки из `triLang`/`STR`. Стили/цвета/отступы не описываются — только структура, тексты и условная логика.

Пометка **[2.0: убирается]** — всё, что относится к XP/опыту, жемчугу, рунам, осколкам, подаркам (по программе упрощения 2.0).

## 1. Хаб «Карточки» (`FlashcardsHubScreen.tsx`)

**Шапка:** ← «Назад» (на главную) · заголовок «Карточки» · справа круглая кнопка «+» → создать набор.

**Блок «Лучшее у сообществе»** (`SavedTopCommunityPacks`, горизонтальный скролл, до 10 плиток):
- обложка набора (PNG-«веер» или иконка категории), бейдж числа карточек, галочка «уже добавлен» если владею;
- название, ник автора, соцбар (лайки/добавления — обычные счётчики популярности, НЕ валюта);
- загрузка — 3 плейсхолдера со спиннером в среднем; пусто/ошибка — «Наборы сообщества пока недоступны» + «Повторить»;
- тап → открывает набор в предпросмотре (`/flashcards_collection?pack=&preview=1&from=hub`).

**Заголовок «Ваши карточки»** и список из 4 строк (иконка · название · подпись · шеврон):
1. «Сохранённые» — «Личная коллекция» → `/flashcards_collection?cat=saved&from=hub`
2. «Из видео» — «Наборы с роликов» → `/flashcards_video_packs`
3. «Мои наборы» — «Созданные и добавленные» → `/flashcards_my_packs`
4. «Наборы пользователей» — «Открыть каталог» → `/flashcards_packs`

**Кнопка «Тренироваться с карточками»** (низ экрана, акцентная):
- под подписью — точки остатка дневных попыток (`SpeakingQuotaDots`, скрыты от скринридера, но остаток озвучен в accessibilityLabel);
- если лимит исчерпан — бейдж Plus на кнопке, тап → пейволл (`/premium_modal`, context `flashcard_training`);
- иначе тап → открывает шторку выбора режима.

**Шторка выбора режима** (`FlashcardsTrainingModeSheet`) — 4 строки (иконка · название · описание · шеврон), режим «Устно» скрывается, если голосовые функции выключены удалённым флагом:
- «Блиц» — «За 60 секунд находи верные переводы и вспоминай быстрее.»
- «Устно» — «Произноси фразы вслух и практикуй разговорную речь. Можно остановиться и попробовать ещё раз.» (может быть заблокирован бейджем Plus, если лимит исчерпан)
- «Правда / ложь» — «Сверяй фразу с переводом и сразу проверяй память.»
- «Вспомни и напиши» — «Вводи фразу на изучаемом языке целиком по памяти.»
- Тап по строке → закрывает шторку и переходит на `/flashcards_training_setup?mode=<mode>`.

Ничего из XP/рун/жемчуга на хабе нет.

## 2. «Сохранённые» / коллекция (`flashcards_collection.tsx` + компоненты)

### Шапка (`CollectionHeader`)
- ← Назад · заголовок (название категории или открытого набора) ·
- на «Сохранённые»: пикер языка набора + кнопка «⋯» (меню: «Вид» список/стопка, «Отметить», «Удалить выбранные»);
- на прочих вкладках/наборе: переключатель Список/Стопка + кнопка «Фильтр» с текущим значением.
- Режим выделения: слева «Отмена», по центру «Отметить», справа счётчик «N / M».
- На открытом наборе — ник автора; для своей неопубликованной коллекции — «Отправить в сообщество» (при отправке — спиннер); для своего опубликованного — «Править набор».
- Поиск (только «Сохранённые», не в открытом наборе): плейсхолдер «Поиск по карточкам», крестик очистки.
- Сегмент-контрол (только «Сохранённые»): «Все · N» / «Слова · N» / «Фразы · N».

### Список (`CollectionListView`)
- «Добавить карточку» (только вкладка «Мои карточки»).
- Разовая подсказка (5 сек, автозакрытие): «Зажмите карточку чтобы удалить её».
- Строка карточки — см. ниже.
- Свайп влево → красная зона «Удалить»; долгое нажатие → затемнение с кнопкой «Удалить».
- Снекбар после удаления: «Карточка удалена» + «Вернуть» (undo, 5 сек).
- **Лимит free** (подвал списка, если часть скрыта): иконка замка, «+N карточек скрыто», «Бесплатно доступны первые 20 сохранённых карточек», кнопка «Открыть все с Премиум».
- Режим выделения: «Создать набор» (или подсказка «Выбери ещё N карточек»), «Удалить выбранные» (красным), строка выбора = чекбокс + текст + перевод + источник.

### Стопка (`CollectionDeckView`)
- Счётчик «N/M» слева, справа «К списку».
- Стек из до 3 карточек внахлёст; тап = переворот, свайп = следующая/предыдущая (на web — кнопки «‹»/«›»).

### Карточка (`FlashcardListItem` + `FlashcardDetailsBody`)
- Лицо: фраза, транскрипция курсивом, кнопка озвучки, точки «сила слова» (визуальный индикатор прогресса — НЕ валюта), шеврон-подсказка на первой карточке списка.
- Рубашка: перевод (при противопоставлении «≠» — верный вариант зелёным, неверный зачёркнут красным), кнопка озвучки.
- Раскрытые детали: «Дословно:» + буквальный перевод, описание/примечание курсивом, кнопка репорта ошибки (флажок); для своих карточек — «Редактировать»/«Удалить».

### Пустое состояние
- Иконка (лупа при пустом поиске / закладка иначе);
- «Нет карточек» / «Ничего не найдено»;
- ссылка «Наборы сообщества» (не при пустом поиске);
- при ошибке — «Повторить загрузку».

### Фильтры (`FlashcardsFilterDropdown`)
- Выпадающее меню: пункт «Все» + сгруппированные варианты (заголовок группы капсом, галочка у активного).

### Экран набора — доп. блоки
- Если набор собран из видео — сверху широкое превью ролика (`PackVideoHero`).
- Для набора сообщества (UGC) — социальная строка (см. §5) + тихая ссылка «Пожаловаться на набор».
- Модалка подтверждения массового удаления: «Удалить N карточек?» / «Карточки исчезнут из «Сохранённых». Исходные уроки и видео не изменятся.» / «Отмена» · «Удалить».

## 3. «Мои наборы» (`flashcards_my_packs.tsx`)

**Шапка:** ← Назад · пикер языка набора справа.
**Заголовок:** «Мои наборы» + подсказка «Всё, что ты добавил или создал сам — открой набор и начни тренировку.»
**Панель инструментов** (если есть наборы): поиск «Поиск по названию»; переключатель сортировки «Сначала новые» ⇄ «По алфавиту».

**Два раздела** (пустой не рендерится): «Добавленные из сообщества», «Созданные мной» — у каждого счётчик количества.

**Плитка набора** (сетка 3 в ряд): обложка/иконка, бейдж числа карточек, флаг языка, название (до 2 строк, без подписи-расшифровки). Для «Созданные мной»: иконка-карандаш «Редактировать набор» и иконка-корзина «Удалить набор» прямо на плитке. Во время открытия — спиннер поверх плитки.

**Тап** → мгновенный звук, стейджинг карточек, переход на `/flashcards_collection?pack=<id>&from=mine`; при неудаче сети — тост «Не удалось загрузить набор. Проверьте интернет и попробуйте ещё раз.»

**Удаление:** модалка «Удалить набор» / «<название> — набор будет убран из твоих наборов.» / «Отмена» · «Удалить набор» (деструктивная). Успех — тост «Набор удалён.»

**Пустое состояние:** «Выбери готовый набор из сообщества или создай свой кнопкой «+» внизу.» + «Открыть наборы сообщества». Пустой поиск: «Ничего не найдено.»

**Плавающая кнопка «+»** внизу → создание набора. Явных free/Plus лимитов на число наборов не найдено.

## 4. Каталог наборов пользователей (`flashcards_packs.tsx` + `FlashcardsCategoryHub.tsx`)

**Шапка:** ← Назад (скрыта во встроенном режиме) · «Наборы сообщества» · пикер языка · круглая лупа (раскрывает поле поиска «Поиск набора» с крестиком закрытия).

**Нижняя плавающая панель из 3 кнопок:** «Новые» (сортировка по свежести) · крупная «+» по центру (создать набор) · «Топ» (сортировка по лайкам→добавлениям→свежести).

**Описание подраздела:** «Готовые наборы от других пользователей — добавь себе и тренируйся.»

**Незавершённый черновик:** плашка «Продолжить создание набора» (если есть локальный черновик).

**Плитка набора сообщества** (сетка 3 в ряд):
- обложка/иконка категории;
- бейдж числа карточек (правый нижний угол);
- бейдж «в топе» (значок тренда, левый верхний) для самых залайканных;
- галочка «уже добавлен» (правый верхний), если владею;
- флаг языка набора (левый нижний);
- название (до 2 строк);
- **строка автора и цены**: «‹автор›» ИЛИ, если набор платный, «‹автор› · ᚱ N» — **[2.0: убирается]** (цена и знак рун ᚱ);
- соцбар (лайк/добавления/комментарии, вариант «tile»).
- Долгий тап по чужому набору → строка действий: «Пожаловаться на набор» / «Не показывать мне».
- Кнопка-карандаш «Редактировать» — только на своих опубликованных UGC-наборах.

**Тап:** свой набор → сразу открывает (`/flashcards_collection?pack=<id>&from=community`); чужой → открывает в режиме предпросмотра (`?preview=1`).

**Пустое состояние:** «Здесь появятся наборы после публикации.» (каталог пуст) или «Ничего не найдено.» (пустой поиск/фильтр).

**Загрузка:** без спиннера на весь экран — тёплый кэш рисует список сразу, сеть подменяет бесшовно.

**Free/Plus:** явных ограничений на доступ к каталогу не найдено — сам каталог позиционируется как открытый; платность — на уровне отдельных наборов (руны, см. выше — убирается).

## 5. Экран одного набора — соцблок и модалки

Маршрут — тот же `/flashcards_collection?pack=<id>` (см. §2), но с доп. блоками:

**`CommunityPackSocialBar`** (вариант "screen"):
- Лайк — доступен только ПОСЛЕ добавления набора себе; до этого приглушён, тап → тост «Сначала добавьте набор себе — потом можно поставить лайк.»; после добавления — подпись «Нравится · N».
- Счётчик «добавили» (иконка людей + число).
- Счётчик комментариев (💬 N, виден всегда, даже при 0) → открывает шторку комментариев.
- Кнопка «Добавить себе» / «В моих наборах» — компактная иконка без текста.
- Платный набор — тап на «Добавить» открывает `CardPackShardPaywallModal` **[2.0: убирается]**.
- Optimistic UI: лайк и добавление меняются мгновенно, с откатом и тостом об ошибке при отказе сервера.

**`PackCommentsSheet`** — шторка «Отклик» (+ «· N»):
- Комментарии одноуровневые, закреплённый — сверху; у каждого: аватар, имя, бейджи «автор»/«закреплено», время, текст, реакции 👍/🔥 со счётчиками, «Ответить» (подставляет «@ник »), меню «···».
- Композер виден только добавившим набор или автору: плейсхолдер «Написать автору…», счётчик «N осталось».
- Пустое состояние: «Пока тихо» / «Скажи автору, что было полезно — он увидит первым».
- Меню «···»: автору — «Закрепить/Открепить», «Скрыть у всех» (мягкое скрытие чужого); себе — «Удалить»; чужому — «Пожаловаться».
- Optimistic UI отправки: комментарий появляется мгновенно (статус `sending`), при неудаче — «Повторить»/«Удалить».

**`ReportCommentModal`:** «Пожаловаться на комментарий», цитата «Автор: «текст»», причины: «Спам или реклама», «Оскорбление», «Не по теме набора», «Другое», необязательный комментарий (до 500), «Отправить жалобу» → успех «Жалоба отправлена» / «Автор набора решит, что делать. Комментарий пока останется виден остальным.» Троттлинг 30 сек.

**`ReportPackModal`** (жалоба на набор): 6 причин («Образа / ненависть», «Откровенный контент», «Спам / бессмыслица», «Авторское право», «Неправильный перевод», «Другое»), комментарий до 500, «Отмена»/«Отправить жалобу», успех + «Не показывать мне этот набор» (скрытие на устройстве).

**`CardPackShardPaywallModal`** — **[2.0: убирается целиком]**:
- Режим `confirm`: цена в жемчуге/рунах, «Открыть за N жемчужин/рун», «Отмена».
- Режим `insufficient`: «Недостаточно жемчуга»/«Не хватает рун», «Пополнить жемчуг»/«Как заработать руны».
- Режим `voucher`: «Набор в подарок» — **[2.0: убирается]**, «Использовать подарок?», предупреждение об одноразовости.

## 6. Редактор карточки (`flashcards_card_editor.tsx`)

**Роуты:** создание (`?create=1&cat=custom`) / редактирование (`?id=`).
**Шапка:** × закрыть слева · «Новая карточка» / «Редактировать карточку» · пустой отступ справа.

**Гейт Plus — только для создания** (не для правки): пока подписка не резолвлена — скелет формы; при отказе — редирект на `/premium_modal`.

**Поля:**
1. «Передняя сторона» (макс. 80 симв.) — кнопка звука рядом с лейблом (если поле не пусто); под полем — серая курсивная авто-транскрипция; жёлтая плашка «Карточка «X» уже есть в коллекции.» при дубликате.
2. «Задняя сторона» (макс. 80 симв., перевод на языке интерфейса) — под полем плашка-подсказка перевода «Подсказка: <текст>» (тап подставляет).
3. «+ Добавить заметку» (раскрывается, макс. 220 симв., счётчик «N/220»).

**Кнопка удаления карточки на этом экране отсутствует** (тексты `delete`/`deleteConfirm: 'Удалить карточку?'` есть в словаре, но не используются — удаление живёт на экране коллекции).

**Валидация:** кнопка «Сохранить» неактивна, пока EN и перевод не заполнены (или пока не резолвлен гейт/идёт сохранение).
**Ошибки:** «Не удалось сохранить карточку.»; «Карточка не найдена.» (для несуществующего id при правке).
**Успех:** тост «Карточка обновлена.» / «Карточка сохранена.»
**Подвал:** «Карточка появится во вкладке «Свои» и будет доступна в тренировках.»

## 7. Создание/публикация набора (`community_pack_create.tsx`)

**Роуты:** создание / `?packId=` (правка своего) / `?stage=` (перенос выбранных сохранённых карточек).
**Шапка:** ← назад · «Новый набор» / «Редактировать набор» (при ошибке загрузки правки — «Редактирование» + «Набор недоступен для редактирования»).

**Гейт Plus — только для создания НОВОГО набора**, правка своего уже опубликованного не гейтится.

**Поля:**
- «Название набора» *, «Кратко о наборе» * (описание).
- «Язык набора» + пояснение «Карточки будут показаны в выбранном разделе языка.»
- Переключатель «Публичный набор» / «Только для меня»: вкл (новый) → «Набор появится в каталоге после проверки.»; вкл (правка) → «Изменения станут видны всем сразу после сохранения.»; выкл → «Он сохранится только у тебя.»
- «Оформление» (свёрнуто): «Цвет карточек» (палитра тем) и «Иконка набора» (листалка стрелками влево/вправо + лента миниатюр).

**Цена в рунах/жемчуге — уже отсутствует в интерфейсе** (комментарий в коде: владелец лично запретил делать наборы платными, `priceRunes: 0` зашито в payload). Это **уже соответствует состоянию 2.0**, менять не нужно.

**Список карточек:** «+ Добавить карточку» (открывает панель: «Передняя сторона», «Задняя сторона», «Подсказка (необязательно)», «Отмена»/«Сохранить»); лимит 50 карточек блокирует добавление; тап по карточке в списке — редактирование, есть удаление.

**Минимум/максимум:** 10–50 карточек для сохранения; при нарушении — тост «Минимум N карточек.» / «Не более N карточек.»

**Другие ошибки:** «Укажите название и описание набора.»; «У каждой карточки должны быть EN и перевод.»; «Community-наборы для French закрыты до отдельной проверки источников.»; «Проверь название, описание и все карточки.»; «Добавь хотя бы одну карточку.»

**Кнопка «Сохранить»** — единственная (нет отдельной «Опубликовать» — публичность определяет переключатель выше).

**Успех/ошибка:** «Набор сохранён.» (+ переход на экран набора); офлайн — «Набор сохранён на устройстве. Публикация не завершена — нажмите «Сохранить» ещё раз при подключении.»; ошибка — текст ошибки или «Не удалось сохранить набор.»

**Прочее:** «Очистить черновик» (модалка «Очистить черновик?»/«Локальные данные этого набора будут удалены.»/«Отмена»·«Очистить»); кнопка «Сообщить об ошибке».

## 8. Наборы из видео (`flashcards_video_packs.tsx` + `VideoPackRow.tsx`)

**Шапка:** ← назад · пикер языка · заголовок «Из видео».
**Поиск и сортировка:** «Поиск по наборам»; переключатели «Популярные»/«Новые».

**Строка набора (`VideoPackRow`):** превью кадра ролика 16:9 с плей-бейджем и меткой длительности (напр. «12:34»); во время открытия — крутилка поверх кадра. Справа — название (до 2 строк) + соцбар (лайк/добавить).
- Тап по кадру → открывает видео во внешнем приложении/браузере (при неудаче — тост «Видео сейчас не открывается. Карточки набора доступны как обычно.»).
- Тап по остальной строке → предпросмотр набора (`?preview=1&from=video`).

**Пустые/ошибочные состояния:**
- «Пока пусто» / «Наборы из роликов появятся здесь, как только выйдут.»
- «Ничего не нашли» / «Попробуйте другое слово.» + «Показать все».
- «Не удалось загрузить» / «Проверьте связь и попробуйте снова.» + «Повторить».
- Загрузка — 7 строк-скелетонов.

## 9. Подготовка тренировки (`flashcards_training_setup.tsx`, `DeckPickerSheet.tsx`, `PackLanguagePicker.tsx`)

**Заголовок экрана** = название режима: «Блиц» / «Устная тренировка» / «Вспомни и напиши» / «Правда / ложь» (невалидный режим — «Режим недоступен»).

**Сводка:** «Отметь один или несколько наборов для тренировки.» / «Загружаем наборы…» / «Выбрано N · M карточек».

**Выбор наборов:** сетка плиток прямо на экране (не через шторку). Шторка `DeckPickerSheet` (используется в других местах хаба) устроена так: заголовок по режиму («Что говорим?» / «Что в блице?» / «Что тренируем?»), счётчик выбора, столбец строк-наборов с чекбоксами (мультивыбор), для не-блица — «Карточек в сессии» с чипами 10/15/20, кнопка старта («Начать тренировку» / «Начать говорить» / «В блиц!»), крестик закрытия.

**Пикер языка набора (`PackLanguagePicker`):** флаг + код языка, при открытии — карточка-меню со списком языков (флаг, название, галочка у выбранного).

**Пустое состояние (наборов нет):** «Добавьте первый набор» + ряд до 3 лучших чужих наборов.

**Ошибки:** «Этот режим сейчас недоступен. Вернитесь и выберите другой режим.»; «Не удалось загрузить наборы. Проверьте интернет и попробуйте ещё раз.» + «Повторить»; «Пока нет карточек для тренировки. Сохрани карточки или добавь набор из сообщества.»; для блица — «Для блица нужно минимум 4 карточки.» (красным, кнопка старта неактивна).

**Кнопка «Начать»** — единый текст на всех режимах; неактивна при: нет выбора, идёт загрузка, лимит free исчерпан (см. ниже), для блица — мало карточек.

**Free-лимит:** не показан текстом на этом экране — при исчерпанной квоте пользователя автоматически перекидывает на `/premium_modal` (пейволл).

## 10. Итог тренировки (`SessionResultScreen.tsx`)

**Заголовок:** «Тренировка завершена».
**Пилюля счёта** (только блиц): «Счёт: N».

**Статистика (3 колонки):** число верных ответов + «верно»; число ошибок + «ошибок»; процент + «точность».

**Начисления:**
- **XP** (`XpGainBadge`) — показывается при `xpGained > 0`. **[2.0: убирается]**
- **Руны** (`ResultRuneAward`) — при `runesGained > 0`, анимация «+N» с «полётом» руны к счётчику. **[2.0: убирается]**
- Жемчуга/осколков на этом экране нет.
- Ценник «энергии» над кнопками уже убран ранее (не относится к XP/рунам, отдельная мелочь, уже сделано).

**Обратная связь (опционально, не чаще раза в неделю):** звёзды «Слова того стоили?» + поле «Каких слов не хватило? Какие лишние?» + «Отправить».

**Кнопки:** «Добить: Ещё учу (N)» (вторичная, если есть ошибочные карточки) · «Готово» (основная, всегда).
Призыва к Plus на этом экране нет — пейволл срабатывает раньше, на экране подготовки тренировки.
