## Outcome

Экран «Минута знаний» из утверждённого макета (`docs/design/v2-app/elevate-games.js`, `minute()`) существует в
приложении как отдельный маршрут: правило в двух строках, до двух примеров с переводом, полоса времени на
20 секунд, кнопка «Понятно». Материал — объяснения банка заданий языка обучения по текущему уроку.
Мера успеха: правила подбора покрыты тестом, типы и линтер чистые. Экран НИКУДА не подключён — подключает
ведущая сессия после проверки (в 23:59 сборки уходят в сторы).

## Scope

In scope (только новые файлы): `modules/games/minute_core.ts`, `modules/games/minute_motion.ts`,
`app/game_minute.tsx`, `tests/game_minute_core.test.ts`.

Out of scope: `constants/gameMotion.ts`, остальные экраны игр, разминка, `WARMUP_POOL`, `navigation_back.ts`,
банки заданий, показ экрана «после ошибки в игре» (вызов из других игр), монеты в шапке.

## Architecture

Правила без React — в `minute_core.ts`: карточка теории собирается из задания «Точного слова» (фраза с
верным словом + пояснение) или «Охоты на ошибку» (исправленная реплика + объяснение); примеры — фразы того же
урока с переводом, в которых есть выделенное слово. Экран берёт задания через `task_source` (язык обучения,
текущий урок) и только рисует. Чужой язык не подставляется: нет материала — пустой итог.
Числа движения — в `minute_motion.ts`, с номерами строк макета.

## Security and privacy

Не применимо: статические учебные тексты, нет ввода, сети, хранения и личных данных. Озвучка примера —
голос телефона через общий `useAudio`, как в «На слух».

## Technical debt

- Contain: монет в шапке нет (в макете справа пилюля с балансом) — у экранов игр нет общего источника
  баланса; выход — решение ведущей сессии при подключении.
- Contain: примеры подбираются по совпадению слова, а не по авторской связке «правило — примеры»; если
  подходящих фраз нет, карточка показывается без примеров. Выход — авторские примеры в банке.
- Contain: тексты экрана на ru/uk/es/en, пояснения банка только на русском (как во всех играх).
