# Task packet: экзамен v2 засчитывает главу так же, как прежний (жалоба №17)

Governance-ID: TG-DC1D37317E2A
Status: In progress
Owner: Learning V2 session; координатор 25.10 — жалоба №17 «главу 1 прошла без ошибок, но дальше не пустили, урок 8 не засчитан»

## Outcome

Цепочка «экзамен сдан → глава засчитана → открыт следующий эпизод» проверена для экзамена v2 (главы 1–3 урока 1) и прежнего
(глава 4) на ветках: первая сдача, сдача после пересдачи, без сети, второе устройство. После сдачи журнал [EXAM-V2-CREDIT]
перечитывает прогресс и пишет, стал ли первый эпизод следующей главы доступным (текущий или открытый): жалобу можно проверить
по фактам. «Эпизод 8 не засчитан» — по правилу владельца «открыто ≠ пройдено»: экзамен открывает, но не засчитывает.

## Scope

app/learning_v2_chapter_exam_v1.ts (общий итог: признак движка, журнал с проверкой после записи), app/learning_v2_chapter_exam_v2.ts
(передаёт движок v2), тест tests/learning_v2_exam_chapter_credit_parity.test.ts.

## Architecture

Обе ветки идут через finishLearningV2ChapterExamWithResultV1 → placeStart: открыть первый эпизод главы (если не пройден), точка
старта — первый эпизод следующей главы, прежний текущий эпизод открывается. Проверка после записи — чтение локального прогресса
(диск, без сети).

## Security and privacy

Журнал без uid: ключ экзамена, номера эпизодов, движок. Сети и Firestore нет.

## Technical debt

Карта «Сезона» читает записи экзаменов только при смене урока — после сдачи карточка экзамена может до перезапуска показывать
«Сдать экзамен» (доступ к эпизодам от этого не зависит). Сообщено координатору, файл Сезона не мой.

## Verification

Тест: v2 глава 1 и прежний экзамен глава 4 — одинаковый итог (текущий — первый эпизод следующей главы, восьмой открыт, ничего не
засчитано); пересдача; второе устройство через облачные копии масок и экзамена.

## Rollback

Revert коммита (журнал и признак движка безвредны).
