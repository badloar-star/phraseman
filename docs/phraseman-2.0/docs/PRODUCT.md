# Продуктовый контракт

Владелец описал не нехватку фич, а усталость от их последствий: «новые баги целая классы багов», тормоза на устройствах пользователей, навязчивые награды и ощущение детского продукта. Это мотивация работы, а не доказательство всех причин снижения продаж. Не сводить проект к перекраске кнопок и не использовать очистку как повод написать новую платформу.

## Ценность и границы
Основной продукт — практика фраз/карточек, связанных с роликами каналов владельца. Его процесс уже существует: видео → документ для Telegram → набор через админку. Сохранить связность и облегчить доступ. Универсальные наборы могут содержать неязыковые знания, например деталь автомобиля и описание; это использование того же движка, не запуск отдельной «академии всего».

Остаются карточки, полезные тренировочные режимы, видео, текущий V1, диалоги, фактическая статистика и ошибки, простые друзья/активность. Настройки остаются утилитарными. Новая монетная идентичность не должна оттеснить обучение.

Существующим пользователям обещаны не новые правила задним числом, а понятный переход: сохранить данные и законные права, дать согласованную компенсацию исчезающих покупок, не заставить начинать обучение заново. Приоритет прав определяется фактическим ledger, не воспоминанием о числе продаж.

## Нельзя подменять понятия
Ранг монеты — не знание языка. Учебные звёзды — не XP. Остаток монет — не недельная активность. Статистика всех языков — не право смешивать ошибки разных языков. Удаление геймификации — не удаление обратной связи об ошибке. TTS — не распознавание речи. Скрытый экран — не исключённый из bundle экран. Маленький репозиторий — не быстрое приложение.

## Модель прогресса без XP (PM-013)
Четыре независимых величины, ни одна не выводится из другой и не заменяет её:
1. **Баланс монет** — накопленная внутриигровая валюта (остаток). Тратится и пополняется; не показывает уровень знаний и не влияет на ранг.
2. **Ранг монеты** — визуальная ступень, читается через `useMyCoinRank`; единый идентификатор ранга (PM-070). Не знание языка.
3. **Прогресс курса** — локальный учебный прогресс Learning V2 (`course_local_progress_v1`); считает пройденные сессии, а не очки.
4. **Недельный результат** — активность недели (`weekDone`/`weekPoints`) и итог Шпиля; обнуляется по календарю недели.
XP и старые уровни в модели отсутствуют (владелец 2026-09-27: экран прогресса сохраняет структуру, но без XP). Старые XP-данные только читаются и закрываются заменой `shards_6`.

## Проверка результата
Один сценарий во всех ревью: новый человек после конкретного ролика понимает, где его фразы, видит связанный набор, начинает тренировку и слышит правильный язык. Повторный пользователь возвращается к тому же набору без потери фильтра/прогресса. Free понимает ограничения; Plus получает свои права без отдельного лабиринта. На слабом устройстве путь измерен в release build.

Статусы гипотез и решений — в `03_DECISIONS.md`; спорное не реализовать как будто уже принято. Все подробные задачи — E02 и связанные доменные эпики.
