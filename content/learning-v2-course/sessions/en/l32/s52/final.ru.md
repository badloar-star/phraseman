# Урок 32 · Занятие 52 — Приводим в порядок сад

**Ситуация.** Вы с Анной осматриваете сад после дождя.

**Что вы освоите:** объяснять предположение, отвергать невозможный вариант и уточнять предмет.
**Новые слова:** —
**Повторяем знакомые слова:** path, bucket, plant, soil

## Интро 1

### Наблюдение и возможность

Вы видите мокрую садовую дорожку и допускаете, что на ней можно поскользнуться. The path is wet, so it might be slippery. — Дорожка мокрая, поэтому она, возможно, скользкая. Соберите The path is wet + so + it might be slippery. До so назовите наблюдение, после so — возможный вывод с might. Перед состоянием slippery нужна связка be.

**Выберите фразу для этой ситуации.**

- ✅ **The path is wet, so it might be slippery.**
- ❌ The path is wet, so it might is slippery. — *После might используем be.*
- ❌ The path is wet, so it might to be slippery. — *После might не ставим to.*

## Интро 2

### Этот вариант исключён

В открытом ведре видна дождевая вода. Анна считала, что оно пустое. The bucket can't be empty. — Ведро не может быть пустым. Соберите The bucket + can’t + be + empty. Наблюдение исключает названное состояние. Can’t выражает этот вывод; перед empty здесь нужна связка be.

**Выберите фразу для этой ситуации.**

- ✅ **The bucket can't be empty.**
- ❌ The bucket can't is empty. — *После can’t используем be.*
- ❌ The bucket can't to be empty. — *После can’t не ставим to.*

## Интро 3

### Уточняем предмет

Вы показываете Анне предмет и уточняете своё действие с ним: The plant I bought is small. — Растение, которое я купил, маленькое. Соберите The plant + I bought + is small. Часть I bought уточняет plant. That можно опустить: I уже называет того, кто выполнил действие.

**Выберите фразу для этой ситуации.**

- ✅ **The plant I bought is small.**
- ❌ The plant I bought it is small. — *Не повторяем названный предмет местоимением it.*
- ❌ The plant I buying is small. — *Нужна прошедшая форма bought.*
