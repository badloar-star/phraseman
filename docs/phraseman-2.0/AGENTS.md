# PhraseMan 2.0 — блок для включения в существующие правила

Это предложенный блок, а не разрешение заменить существующий AGENTS.md.
Постоянные инструкции: `01_BIBLE.md` внутри этого пакета. При размещении документации в репозитории поправить путь на `docs/phraseman-2.0/01_BIBLE.md` и проверить фактическую иерархию AGENTS.

Перед работой прочитай BIBLE, CURRENT_STATE, DECISIONS, конкретную задачу и её спецификацию. Требования берутся из файлов, не из сжатого контекста. До правок установи фактический HEAD и покажи impact по Firestore/Functions/AI, устройству, очередям и логированию. Не добавляй новые расходы/фоновые jobs/SDK/декор без явного решения.

XP и старый уровень удаляются. Энергия 5/1/10 минут, Plus без расхода. Монета становится кошельком и аватаром; таблица рангов требует утверждения. Макс и генераторы арены сохраняются вне release. V1 не удалять. «Графит» отклонён, новый дизайн не утверждён.

Удаление — по карте зависимостей и миграций, не grep-delete. Покупки/auth/account deletion/локальные данные и безопасность сохраняются. Production и ветки не менять без плана/подтверждения. Один write-исполнитель; ревьюеры read-only. Модель/effort выбираются по карточке задачи, не всегда максимальные.

Доказательства и прогресс: `registries/tasks.json` и append-only `registries/worklog.jsonl`; пересоздать производные представления `python tools/render_views.py`. Нельзя объявить done без тестов/доказательств и SHA там, где нужен код. Исходники `sources/` не публиковать автоматически в публичный репозиторий.
