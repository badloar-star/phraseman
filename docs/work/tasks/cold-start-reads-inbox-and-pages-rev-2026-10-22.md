## Architecture

Счётчик — `FieldValue.increment(1)` в той же транзакции, что и запись сообщения: строго монотонен, без совпадений
по миллисекундам. Клиент сравнивает на равенство, значение для него непрозрачно.
Триггер `usersWriteRouter` (functions/src/users_write_router.ts) срабатывает на каждую запись `users/{uid}`. Поэтому
`inboxRev` кладётся в ту же запись `userRef`, если она уже есть в транзакции; иначе — одна запись на личное сообщение
(они редки: ответы на репорты, личные сообщения админа, клеймы наград).

## Security and privacy
