# Англійська · Урок 18 · Заняття 56 — Спілкування й стосунки

**Ситуація.** Ви обговорюєте з другом стосунки між людьми: як спокійно поговорити, обговорити проблему й не довести розмову до сварки.

**Що ви опануєте:** сказати «так / такий» з почуттям: so cold, such a cold day
**Нові слова:** communication, relationship, discussion, argument

## Інтро 1

### Важливість розмови

Ви з другом спокійно поговорили й зрозуміли, що ображалися одне на одного через непорозуміння. Communication — спілкування. Good communication is so important. — Добре спілкування таке важливе. Спочатку називаємо тему Good communication, потім is та оцінку so important. So стоїть прямо перед прикметником important і підсилює його; після important тут немає іменника, тому such не підходить.

**Виберіть фразу для цієї ситуації.**

- ✅ **Good communication is so important.**
- ❌ Good communication is such important. — *Після пропуску прикметник без іменника: so.*
- ❌ Good communication is much important. — *Перед звичайним прикметником тут потрібне so, не much.*

---

## Інтро 2

### Добрі стосунки

Ви із сестрою завжди можете спокійно обговорити труднощі й допомогти одне одному. Relationship — стосунки між людьми. We have such a good relationship. — У нас такі добрі стосунки. Після We have йде ціла група such a good relationship. В англійській relationship тут у формі для одного: це один зв’язок між вами. Тому порядок такий: such + a + good + relationship; a ставимо після such.

**Виберіть фразу для цієї ситуації.**

- ✅ **We have such a good relationship.**
- ❌ We have so a good relationship. — *Після пропуску група з іменником: such. Перед одним предметом, який можна порахувати, зберігаємо a/an.*
- ❌ We have a such good relationship. — *Порядок: such a/an, не a/an such.*

---

## Інтро 3

### Серйозна сварка

Двоє друзів сильно посварилися й тепер не розмовляють. Argument тут — сварка. This argument is so serious. — Ця сварка така серйозна. This argument називає конкретну сварку, is пов’язує її з оцінкою, а so підсилює serious. Складаємо: This argument + is + so + serious. Після so йде прикметник без іменника, тому a тут не потрібен.

**Виберіть фразу для цієї ситуації.**

- ✅ **This argument is so serious.**
- ❌ This argument is such serious. — *Після пропуску прикметник без іменника: so.*
- ❌ This argument is much serious. — *Перед звичайним прикметником тут потрібне so, не much.*
