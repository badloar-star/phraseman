# Стандарт «объясняем как ребёнку» — теория, вступления, задания (слово владельца, 05.11.2026)

Слова владельца: «Теория и интро перед уроками должны объяснять настолько доступно и понятно, чтобы это было понятно трёхлетнему ребёнку. Не надо писать техничку, что заучивать, что не заучивать. Не надо делать задания, которые без основательного контекста не понять. Каждый юзер — ребёнок, которому надо всё разжевать. Я прочитал чуть-чуть теории первого урока испанского и ничего не понял как человек, который не знает испанского. Мы должны рассчитывать, что человек, который начинает с первого урока, не знает языка».

## Читатель
Взрослый, который НЕ знает изучаемого языка и НЕ знает грамматических слов. Урок 1 начинается с нуля.

## Правила (обязательны для ВСЕХ языков курса: en, es, fr, de, it; тексты ru, uk, затем остальные локали)
1. **Простые слова.** Короткие предложения (до ~12 слов). Никаких грамматических терминов: подлежащее, сказуемое, спряжение, вспомогательный глагол, артикль, падеж, инфинитив, причастие, согласование, форма… Если без слова нельзя — объяснить его одной картинкой-примером и не повторять термин.
2. **Одна мысль на главу.** Сначала ПОКАЗАТЬ, потом объяснить: 2–3 примера «фраза на языке курса → перевод → (как читается русскими буквами, где это нужно)», затем одна-две фразы объяснения обычными словами.
3. **Никаких мета-блоков.** Нет разделов «что заучивать / что не заучивать», «типичная ошибка» с абстрактным правилом, «выбор формы», «нюансы», «стратегия». Только то, что человек делает и видит.
4. **Опора на уже виденное.** Объяснение использует только слова, которые человек уже встретил в этом или прошлых уроках. Новые слова — переводить сразу рядом.
5. **Вступление перед уроком** (intro): 3–5 коротких строк — что мы сегодня учим, обычными словами, плюс 3 примера «фраза → перевод». Без «Представь ситуацию».
6. **Задания.** Каждое начинается одной понятной командой («Выбери, как сказать: «Я дома»»), у первого в разделе показан образец готового ответа. В задании только слова и правила, которые уже были в теории. Никаких «найди ошибку в форме», «трансформируй», «перенеси», пока человек этого не видел на примере.
7. **Обращение «вы»** (решение владельца), везде одинаково.
8. **Без мелких подписей-расшифровок** под названиями (правило дизайна).

## Проверка «пятилетнего читателя» (обязательна перед принятием)
Независимая модель получает ТОЛЬКО текст (глава или вступление + задания) в роли взрослого без знания языка и грамматики и отвечает письменно: (а) что я сейчас узнал, (б) что мне делать в задании, (в) какое слово/фраза мне непонятны. Любой непонятный термин, пропущенный шаг, «слово из воздуха» — брак. Допуск: 0 непонятных терминов в главе; 100% заданий понятны без пояснений.

## Порядок работ
1. Теория (12): переписать все главы теории классики для fr/es/de/it/en (160 уроков) по этому стандарту (ru/uk/en), начиная с урока 1 каждого языка; примеры — только фразы курса.
2. Темы (4): вступления перед уроками (intro) по этому стандарту.
3. Learning V2: формулировки заданий — одна понятная команда + образец; убрать/заменить непонятные типы заданий; «Часть N» → понятные названия разделов.
4. Переводчик: остальные локали + единый список простых слов вместо терминов.
5. Ревизор: «проверка пятилетнего читателя» независимыми агентами по выборке и по каждому уроку 1–3 каждого языка.

## Дополнение владельца (05.11, 09:05): роль «Новичок-проверяющий» и состав разделов
Слова владельца: нужна сессия, которая открывает раздел теории КАЖДОГО урока КАЖДОГО курса и проверяет его как новичок/ученик/читатель («вот это я не понимаю — значит подправить»). Всё должно быть полностью разжёвано. То же — для интро перед уроками. ОБРАЗЕЦ — СТАРЫЙ КУРС АНГЛИЙСКОГО: там интро и теория были прекрасными, нравились пользователям, понятные, без технического языка.

Проверяются все разделы урока:
1. **Интро перед уроком** и **Теория**: понятно ли новичку (см. выше).
2. **Слова (словарь)** по образцу старого английского: в уроке N показываются ТОЛЬКО новые слова, которые встречаются в этом уроке; слова прошлых уроков не повторяются (человек при желании возвращается в тот урок и повторяет). Каждое слово изучается ровно в одном уроке.
3. **Неправильные глаголы / их аналог**: для английского — неправильные глаголы; для остальных языков — то, что у языка играет такую же роль (например, глаголы с неправильными формами, а если такого раздела нет — другой понятный отдельный раздел, нужный новичку). Те же правила: только новые в этом уроке, без повторов, понятные примеры.
4. **Задания** теории — понятная команда + образец.
