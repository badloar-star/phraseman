# Проверка «пятилетнего читателя» — как повторять

Стандарт: docs/work/classic_plain_explanation_standard_2026-11-05.md. Принимает Ревизор.

1. Свежие входные файлы (после правок Теории/Тем): `node scripts/classic_plain_reader_extract.cjs` — модуль; сборка входов — `node scripts/classic_child_reader_build_inputs.cjs ru 1,2,3`. Результат: `input/<курс>_lessons_1_2_3_ru.md` (вступление + теория + первые 6 заданий уроков 1–3).
2. На каждый курс — отдельный независимый агент БЕЗ доступа к остальному репозиторию: читает только свой входной файл и отвечает по каждому уроку (а) что узнал, (б) что делать в заданиях, (в) непонятные места цитатой + число, (г) оценка 0–3. Отчёт: `report_<курс>_<метка>.md`.
3. Принято, когда у каждого курса вердикт ПРОЙДЕНО, оценки уроков ≥2, непонятных терминов ≤2 на урок.
4. Механическая часть — `tests/classic_plain_terms_guard.test.ts` (запрещённые термины, «Представь ситуацию»).
