# Центр стратегических решений Agent Office

В Admin v2 откройте **Обзор → Стратегические решения** (`#agent-office`). Экран показывает только серверную проекцию Agent Office: дела, их статус, объяснение уверенности, свежесть источников, рекомендации и безопасный журнал.

## Что делает экран

- Читает данные только через `agentOfficeListCases`, `agentOfficeGetCase`, `agentOfficeListRecommendations` и `agentOfficeListAuditEvents`.
- Не читает и не записывает Firestore из браузера, не показывает исходные документы или секреты.
- Явно показывает состояния загрузки, отсутствия данных, ошибки и отсутствия права `briefing.read`.
- Владелец может одобрить или отклонить только текущую рекомендацию. Перед отправкой обязательны причина и системное подтверждение.

## Граница решения

В запрос `agentOfficeDecideRecommendation` входят идентификаторы дела и рекомендации, ожидаемая ревизия дела, ревизия и content hash рекомендации, решение, причина и новый idempotency key. Сервер повторно проверяет эти условия и роль владельца.

Каждое решение имеет область `prepare_only`: оно создаёт неизменяемую запись решения и аудит, но **не запускает задачу, Telegram, внешний API или изменение данных приложения**.

## Telegram

Веб‑экран не управляет Telegram и не видит его токены. Если W6 включает Telegram‑подтверждения, они используют отдельный серверный выпуск одноразового токена и остаются независимыми от этого интерфейса.
