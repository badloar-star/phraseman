## Outcome

Решение владельца 14.10 (D193): вместо пейвола по возвращении — окно «С возвращением» по образцу m21 из engagement-moments-v3-all.html.

Логика (по слову координатора):
- цифры только настоящие, из локальных данных, без сети: дни отсутствия, число фраз, ранг монеты, энергия;
- серию не упоминать, если она сгорела;
- заголовок нейтральный по роду — «С возвращением»;
- главная кнопка:
  - есть карточки на повтор по сроку → «N карточек — 1 минута» (N ≤ 5);
  - иначе есть сохранённые карточки → «N карточек — 1 минута» по последним сохранённым (N ≤ 5, настоящее число);
  - карточек нет → «Продолжить урок →»;
- вторая кнопка «На Главную» закрывает;
- окно 1 раз на возвращение, порог дней тот же, что у winback (`WINBACK_INACTIVITY_MS`).

Часть 1 — чистая модель без React, интерфейса и чтения данных: `modules/welcome_back/welcome_back_model.ts`, тесты `tests/welcome_back_model.test.ts`.
