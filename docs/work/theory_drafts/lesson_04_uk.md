# Теорія · Урок 4 нового курсу — «There is, there are, some, any, in, on, under» (UK)

> Сесія «12 · ТЕОРИЯ», 21.10.2026. Розділи 01–14, англійські фрази й завдання — як у
> `lesson_04_ru.md`. Опори — на українську: «є» — одне слово і для одного, і для багатьох, тож
> «тут є аптека» легко стає Here is a pharmacy; місце ми ставимо на початок («За будинком є сад»),
> а англійською воно в кінці; «на підвіконні» = on, «у» = in. Звертання на «ви». Потрібна вичитка носієм.

**Заголовок екрана:** Теорія · Що де є

---

## 01 · Що ви навчитеся казати *(відкрито одразу)*

**body**
У цьому уроці ви вчитеся розповідати, що де є: «поруч є аптека», «у холодильнику є молоко», «тут немає дзвінка», «ключ під килимком». Головна нова фраза уроку — There is: українською це просто «є».

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There is a pharmacy here. | Тут є аптека. | There is |
| There is some milk here. | Тут є молоко. | some |
| Is there a toilet here? | Тут є туалет? | Is there |
| There isn't a doorbell. | Дзвінка немає. | isn't |
| The key is under the doormat. | Ключ під килимком. | under |

---

## 02 · There is — «тут є» *(відкрито одразу)*

**body**
Коли повідомляєте, що десь щось є, починайте з There is. Українською «Тут є аптека», а в англійській порядок інший: There is a pharmacy here. Не Here is: Here is — це «ось», а не «тут є». Місце йде в кінець.

**formula**
`There is` · `a + річ` · `де`

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There is a pharmacy here. | Тут є аптека. | There is |
| There is a library nearby. | Поруч є бібліотека. | There is |
| There is a bakery here. | Тут є пекарня. | There is |
| There is an office upstairs. | Нагорі є офіс. | There is |
| There is a clinic inside the building. | У будівлі є поліклініка. | There is |

**fix**
- ~~Here is a pharmacy.~~ *(у значенні «тут є»)* → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There тут не значить «там». Це просто початок фрази «є». Тому There is a pharmacy here — «тут є аптека», і there з here не сперечаються.

---

## 03 · There are — коли їх кілька

**body**
Якщо речей кілька, замість is ставлять are, а в слова з'являється s: There are banks here. Як і в уроці 3, a перед кількома речами не ставлять.

**formula**
`There are` · `речі + s` · `де`

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There are banks here. | Тут є банки. | There are |
| There are museums nearby. | Поруч є музеї. | There are |
| There are bridges nearby. | Поруч є мости. | There are |
| There are quiet streets here. | Тут є тихі вулиці. | There are |
| There are parks nearby. | Поруч є парки. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- фраза: `There ___ museums nearby.`
- варіанти: `is` · `are` · `am`
- відповідь: `are`
- чому: Музеїв кілька, тому There are.

## 04 · Місце — в кінці

**body**
Українською місце часто стоїть на початку: «За будинком є сад». В англійській спершу There is і річ, а де — в самому кінці: There is a garden behind the building. Так легше: спершу кажете, що є, потім уточнюєте де.

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There is a garden behind the building. | За будинком є сад. | behind |
| There is a bench near the garden. | Біля саду є лавка. | near |
| There is a church behind the bank. | За банком є церква. | behind |
| There is a market near the bridge. | Біля мосту є ринок. | near |
| There is a lake behind the park. | За парком є озеро. | behind |

**drill · word_bank**
- завдання: Скажіть другові: «За парком є озеро».
- відповідь: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- підписи комірок: немає (фраза довга, підказки по комірках тільки заважають)
- зайві фішки: `are` · `in`

---

## 05 · Спитати «є?» і відповісти коротко

**body**
Щоб спитати, чи щось є, поміняйте два перші слова місцями: There is → Is there…? There are → Are there…? Коротко відповідають так: Yes, there is. No, there isn't. Yes, there are. No, there aren't.

**formula**
`Is there` · `a + річ` · `де` · `?` — `Are there` · `речі + s` · `де` · `?`

**examples** 🔊
| en | uk | hi |
|---|---|---|
| Is there a dentist near here? | Тут поблизу є стоматолог? | Is there |
| Is there a toilet here? | Тут є туалет? | Is there |
| Yes, there is. | Так, є. | there is |
| No, there isn't. | Ні. | isn't |
| Are there trams near the bank? | Біля банку ходять трамваї? | Are there |
| Yes, there are. | Так, є. | there are |
| No, there aren't. | Ні. | aren't |

**fix**
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

---

## 06 · Молоко, хліб, масло — їх не рахують штуками

**body**
Одні речі рахують: банан, два банани. Інші — ні: молоко, хліб, масло, цукор. Перед такими словами не ставлять a, і s у кінці в них не буває. Щоб сказати «є трохи», ставлять some: There is some milk.

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There is some milk here. | Тут є молоко. | some |
| There is some bread near the basket. | Біля кошика є хліб. | some |
| There is some butter near the bowl. | Біля миски є масло. | some |
| There is some cheese here. | Тут є сир. | some |
| There are some berries here. | Тут є ягоди. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
З тим, що не рахують штуками, завжди is, а не are: There is some milk, хоча українською здається, що молока «багато».

## 07 · some чи any

**body**
some ставлять, коли кажете, що щось є. any — коли питаєте, чи є взагалі, або кажете, що немає. Українською обидва часто не перекладаються: «Суп є?» — Is there any soup?

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There is some milk here. | Тут є молоко. | some |
| Is there any soup here? | Тут є суп? | any |
| Are there any mushrooms here? | Тут є гриби? | any |
| There isn't any juice here. | Тут немає соку. | any |
| There aren't any carrots here. | Тут немає моркви. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.

**drill · choice**
- фраза: `Is there ___ rice near the pot?`
- варіанти: `a` · `some` · `any`
- відповідь: `any`
- чому: Ви питаєте, чи є рис взагалі, тому any.

---

## 08 · «Немає»: There isn't, there aren't

**body**
Щоб сказати, що чогось немає, додайте not: There is not → There isn't, There are not → There aren't. Про одну річ — isn't a, про кілька — aren't any. Українське «немає» окремо не перекладайте: no тут не потрібне.

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There isn't a doorbell. | Дзвінка немає. | isn't |
| There isn't an intercom. | Домофона немає. | isn't |
| There aren't any handrails. | Поручнів немає. | aren't |
| There aren't any steps. | Сходинок немає. | aren't |
| There isn't a lawn behind the building. | За будинком немає газону. | isn't |

**fix**
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.

**drill · binary**
- питання: На дверях немає дзвінка. Як сказати?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- правильно: A
- розбір: Дзвінок один, тому isn't.

## 09 · in, on, under — у, на, під

**body**
in — всередині: in the sink, in the basement. on — зверху, на поверхні: on the worktop, on the windowsill. under — під: under the doormat. Українське «на» зазвичай on, «у» — in.

**examples** 🔊
| en | uk | hi |
|---|---|---|
| The lemon is in the sink. | Лимон у раковині. | in |
| The bicycle is in the basement. | Велосипед у підвалі. | in |
| The cups are on the worktop. | Чашки на стільниці. | on |
| The plant is on the windowsill. | Квітка на підвіконні. | on |
| The key is under the doormat. | Ключ під килимком. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

---

## 10 · next to, between … and, near, behind

**body**
next to — упритул поруч, «біля». near — неподалік, «поблизу». behind — «за», позаду. between … and — «між … і …», це два слова на два орієнтири.

**examples** 🔊
| en | uk | hi |
|---|---|---|
| The bench is next to the lamppost. | Лавка біля ліхтаря. | next to |
| The signpost is near the bridge. | Покажчик поблизу мосту. | near |
| The ladder is behind the shed. | Драбина за сараєм. | behind |
| The bus stop is between the bank and the library. | Зупинка між банком і бібліотекою. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- фраза: `The bus stop is ___ the bank and the library.`
- варіанти: `next to` · `behind` · `between`
- відповідь: `between`
- чому: Два орієнтири — банк і бібліотека, зупинка посередині: between … and.

## 11 · There is чи The … is

**body**
There is — коли повідомляєте, що щось є: співрозмовник про нього ще не знає. The … is — коли річ уже знайома, а ви кажете, де вона: The lemon is in the sink. Спершу «є», потім «де воно».

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There is a car park near the hotel. | Біля готелю є парковка. | There is |
| The barrier is near the gate. | Шлагбаум біля воріт. | The |
| There is a storeroom between the kitchen and the hall. | Між кухнею й передпокоєм є комора. | There is |
| The coat rack is behind the door. | Вішак за дверима. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- питання: Сестра шукає лимон, про який ви обидві знаєте. Він у раковині. Що сказати?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- правильно: B
- розбір: Лимон уже знайомий, ви кажете, де він: The lemon is in the sink.

---

## 12 · Коротка форма: There's

**body**
У розмові There is майже завжди скорочують до There's: There's a cashpoint near the bank. З There are так не роблять, а «немає» скорочується як зазвичай: isn't, aren't.

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There's a cashpoint near the bank. | Біля банку є банкомат. | There's |
| There's a postbox next to the gate. | Біля воріт є поштова скринька. | There's |
| There's a vending machine in the hall. | У холі є торговий автомат. | There's |

**tip**
Коротку відповідь «так» не скорочують: Yes, there is, а не Yes, there's.

## 13 · Помилки, яких припускаються майже всі

**fix**
- ~~Here is a pharmacy.~~ *(«тут є»)* → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
Дві перевірки. Ви повідомляєте, що щось є, чи кажете, де знайома річ? «Є» — There is / There are. «Де» — The … is. І друге: одна річ, кілька чи така, що штуками не рахують?

## 14 · Що взяти з собою в практику

**body**
«Є» — There is a… / There are… / There is some… «Є?» — Is there…? Are there any…? «Немає» — There isn't a… / There aren't any… Місце — в кінці: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | uk | hi |
|---|---|---|
| There is a library nearby. | Поруч є бібліотека. | There is |
| Are there any mushrooms here? | Тут є гриби? | any |
| There aren't any steps. | Сходинок немає. | aren't |
| The cups are on the worktop. | Чашки на стільниці. | on |
