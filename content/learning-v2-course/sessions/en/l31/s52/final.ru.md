# Урок 31 · Занятие 52 — Ждём столик

**Ситуация.** Вы пришли с Анной в кафе и ждёте свободный столик.

**Что вы освоите:** объяснять ожидание и следующий шаг через so и therefore.
**Новые слова:** —
**Повторяем знакомые слова:** cafe, table, menu, window

## Интро 1

### Кафе заполнено — мы подождали

Вы пришли в кафе, но свободных мест нет: The cafe was full, so we waited — кафе было заполнено, поэтому мы подождали. Соберите The cafe was full + so + we waited. Перед so называем причину, после него — результат. В прошедшем времени wait получает окончание ed: waited.

**Выберите фразу для этой ситуации.**

- ✅ **The cafe was full, so we waited.**
- ❌ The cafe was full, so we waiting. — *Нужна полная часть we waited.*
- ❌ The cafe was full, so we waits. — *Для прошлого действия используем waited.*

---

## Интро 2

### Столик свободен — мы сели

В письменном рассказе вы объясняете следующий шаг: The table was free and therefore we sat down — столик был свободен, и поэтому мы сели. Соберите The table was free + and therefore + we sat down. Therefore показывает результат; sat — прошедшая форма sit.

**Выберите фразу для этой ситуации.**

- ✅ **The table was free and therefore we sat down.**
- ❌ The table was free and therefore we sitting down. — *Для прошлого действия нужна форма sat.*
- ❌ The table was free and therefore we sits down. — *После we и в прошлом используем sat.*

---

## Интро 3

### Вежливо уточняем, свободен ли столик

Вы видите пустой столик и спрашиваете официанта: Could you tell me if this table is free? — не могли бы вы сказать, свободен ли этот столик? Соберите Could you tell me + if + this table is free. If здесь значит «ли»; внутри сохраняем порядок this table is без вопросительной перестановки.

**Выберите фразу для этой ситуации.**

- ✅ **Could you tell me if this table is free?**
- ❌ Could you tell me if is this table free? — *После if порядок this table is free.*
- ❌ Could you tell me if this table are free? — *Один table требует is.*
