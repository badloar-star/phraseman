## Architecture

Лесенка — чистая функция от снимка приглашений (`ladder` из `referralListMyInvites`, который экран и так читает и кэширует на 15 минут) и числа ключей; компонент — презентационный, без своих запросов. Флаг читается реактивно, как `referral_roulette_enabled`. Выключен флаг — экран остаётся прежним, включён — на месте дуги призов стоит лесенка, дуга и кнопка «Получить приз» — только при `availableCreditCount > 0`. Без поля `ladder` в ответе сервера клиент показывает 0 ступеней, но ничего не выдумывает и не смешивает «покупку Plus» со «первым уроком».

## Security and privacy

Награды выдаёт только сервер; клиент ничего не пишет в монеты/Plus. Новых данных не собираем: имя друга уже есть в списке приглашений. Политика конфиденциальности не меняется (проверить для этапа 2: «цель недели» читает дни друга из уже загруженного снимка «Вместе»). В журнал — только числа и этапы, без идентификаторов.

Pay now: никаких копий формулы прогресса в UI — одна модель с тестом. Contain: флаг выключен по умолчанию; тест фиксирует, что при выключенном флаге экран рендерится как раньше.
