# Learning V2 — карта открывается в то же мгновение, что и тап

Governance-ID: TG-A2CE5028ACFE

## Outcome
Тап по входу в раздел Learning V2 показывает карту в ТОМ ЖЕ кадре. Никакой
паузы на чтение диска, никакого второго появления карты после прихода
прогресса, никаких морганий. Владелец: «должно открываться в ту же
миллисекунду, в то же мгновение когда мы нажимаем на кнопку», «и оно всё
равно моргает».

## Scope
- `app/(tabs)/lessons.tsx` — прогрев прогресса и каталога, гейт warmup.
- `modules/learning-v2/progress/course_local_progress_v1.ts` — синхронный
  peek прочитанного прогресса.
- `components/learning-v2/LearningV2PulseCourse.tsx` — построение 2048 строк
  и layout при монтировании.
- `modules/learning-v2/map/course_accordion_map_model_v1.ts` — кэш проекции.

## Architecture
Первый шаг — трассировка `[V2-OPEN]`, показывающая фактические тайминги:
тап → монтирование карты → построение модели (hit/miss кэша) → layout →
приход прогресса с диска → повторное построение. Диагноз ставится по логам
владельца, а не по догадке.

Гипотеза, которую логи обязаны подтвердить или опровергнуть: прогрев
гейтится `page === "v2"`, то есть диск читается ТОЛЬКО после тапа; приход
прогресса создаёт новый preparedProgress, кэш проекции промахивается и
2048 строк строятся заново — карта появляется дважды.

## Security and privacy
Логи не печатают персональные данные: только количества, ординалы, длины
и тайминги. accountScopeHash не выводится. Privacy policy не затрагивается.

## Technical debt
Комментарий о прогреве «пока человек смотрит на список уроков» расходится
с кодом (условие `page === "v2"` его отменяет) — расхождение устраняется.
