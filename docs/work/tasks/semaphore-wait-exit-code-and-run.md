## Outcome

`.claude/semaphore/slot.sh`: при WAIT выход строго ненулевой и слово WAIT в первой строке (так было и раньше — это фиксируется тестом), добавлены `acquire --wait[=сек]` (ждать до GO с таймаутом), `renew` (продлить слот) и `run "зачем" -- команда…` (взять слот, держать его живым на время команды, отдать, вернуть код команды). Длинные прогоны (36 мин) больше не теряют слот на TTL 15 минут.

## Scope

In scope: `.claude/semaphore/slot.sh`, `.claude/semaphore/README.md`; проверка совместимости со всеми вызывающими (`C:/Temp/claude/work/*.sh`, `scripts/gustav_*`, хук `~/.claude/hooks/heavy-process-traffic-light.js` читает только папки `slot.*.d`).

Out of scope: хук светофора, лимит слотов, TTL как значение, `.claude/session-locks/*`.

## Architecture

Те же папки `slot.<id>.d` с файлами `born`/`why`; новые команды лишь обновляют `born`. Формат вывода `GO …` / `WAIT …` одной строкой сохранён — вызывающие, которые читают `grep -q '^GO'` или `tail -1`, не ломаются.

## Security and privacy

Только локальный скрипт; секретов и пользовательских данных нет.

## Technical debt

Contain: ошибка ID сессии (`ppid-$PPID` меняется между вызовами инструмента) остаётся; `run` держит слот внутри одного процесса, поэтому не страдает.
