# Смена языка в первом выпуске: интерфейс и изучаемый язык без перезапуска (11.10)

Governance-ID: TG-D05ECF98529A

## Outcome
При переключении в Настройках языка интерфейса и изучаемого языка все разделы первого выпуска (Диалоги, Карточки, Шпиль, Настройки, пейволы) сразу показывают новый язык, без перезапуска; кэши не держат старое значение. Логи `[LANG-SWITCH]`. Поручение координатора 11.10 (`docs/phraseman-2.0/R1_WORK_SPLIT_2026-10-11.md`), срок 13.10.

## Scope
Мои файлы: `components/LangContext.tsx`, `app/*language*.ts(x)` (кроме онбординга — заморожен), `app/account_*`, `app/auth_*`, `app/privacy_settings.tsx`. Правки в чужих разделах (Карточки — Дизайн, сервер — Ядро, Шпиль/Диалоги — их хозяева) — только сообщением хозяину с точным местом.

## Architecture
- Шаг 1 (логи прежде починки): `[LANG-SWITCH]` в `LangContext.setLang` и на пути смены изучаемого языка (вход, значение до/после, источник, длительность записи, каждый ранний выход и catch).
- Шаг 2: карта мест, где язык интерфейса / изучаемый язык читаются вне React-контекста или кэшируются модулем без ключа языка (аудит, только чтение).
- Шаг 3: в моих файлах — мгновенная смена (сначала состояние, запись фоном, откат при ошибке), событие смены языка интерфейса для модульных кэшей; в чужих — адресные сообщения хозяевам.

## Security and privacy
Не затрагивается: язык — локальная настройка, новых данных не собирается.

## Technical debt
Кэши в чужих разделах закрываются их хозяевами; список и статус — в этом пакете.

## Verification
Точечные тесты LangContext / study target / settings_language; сторожа layout/perf; прогон сценария I2–I3 (AUTH_RELEASE1_TEST_SCENARIO) на эмуляторе, когда его разрешат; ревью до APPROVE.
