## SFX Note

This animatic uses 29 local temp-SFX events across different sound families: air, blip, magnetic click, riser, pulse, tick, chime, and hit.

Pixabay Sound Effects pages were blocked by a browser/Cloudflare flow when accessed via raw HTTP, and the official Pixabay API documentation covers images/videos rather than sound effects. For final polish, replace temp-SFX with unique downloaded Pixabay Sound Effects files according to `english_chains_intro_premium_animatic_v3_1.sourcing_manifest.json`.
