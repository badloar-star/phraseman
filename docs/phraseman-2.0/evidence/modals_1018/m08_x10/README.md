# m08 ×10 — НЕ СНЯТО (СВЕРКА, 18.10 04:43–04:45)
Урок 1 при запуске с shortLesson=10 продолжился с 6/10 (прошлые зелёные задания сохранены), поэтому серия 10 в этом заходе недостижима; кадры p1/p2 — запутанный набор («It was already»). Для 10 подряд нужен чистый урок (без прогресса) и ~25 шагов с чтением каждого экрана; прервано из-за лимита использования сессии.
Для следующей попытки: сначала сбросить прогресс урока 1 (завершить текущий урок до итога и открыть заново ссылкой с shortLesson=10&m08hold=3), затем 10 верных подряд, кадры на 5-м и 10-м.
