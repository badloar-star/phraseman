# Ручная проверка банка арены с ИИ

## Как запустить экспорт батчей

Из корня репозитория:

```bash
node scripts/export_arena_llm_review.mjs
```

По умолчанию выгружаются **все** уровни (**A1 + A2 + B1**), по **15** карточек в файл, папка **`review/arena_llm/`**.

Примеры:

```bash
node scripts/export_arena_llm_review.mjs --level a2 --batch 20
node scripts/export_arena_llm_review.mjs --level b1 --batch 10 --out review/b1_only
```

Открой любой сгенерированный `.md`, скопируй блоки вопросов и вставь в чат вместе с промптом ниже.

---

## Промпт для вставки в ИИ (скопируй целиком)

Ты — редактор тестов по английскому для уровней A1–B1 и переводчик RU/UK (литературная украинская). На входе — карточки арены: вопрос, 4 варианта, какой ответ сейчас помечен верным в банке, поле rule, тип задания.

**Обязательно:**

1. Укажи по **каждому id** вердикт: **OK** / **ПЛОХО: причина**.
2. Если **ПЛОХО**: что именно не так (грамматика EN, неверный ключ, двусмысленность, калька или плохой RU/UK, для find_error — неверно выбрано «ошибочное» предложение).
3. Если нужно исправить: дай **готовую замену** — полные поля `question`, `options` (массив из 4 строк), `correct`, `rule` (RU · UK через среднюю точку · как в проекте). Тип задания не меняй без необходимости.
4. Не придумывай спорных правил: один однозначно верный вариант.
5. Для заданий с пропуском `___` верный ответ должен быть **одним из четырёх вариантов** как в игре (сравнение строк).

Формат ответа в конце для правок (если есть):

```json
[
  {
    "id": "a2_042",
    "question": "...",
    "options": ["...", "...", "...", "..."],
    "correct": "...",
    "rule": "RU · UK"
  }
]
```

Если для id всё хорошо — в JSON его не включай.

---

## После ответа ИИ

Правки из JSON нужно **вручную** внести в `scripts/a2_seed.json` / источник A1 / `scripts/b1_seed.json` (в зависимости от уровня) и пересобрать JSON в `assets/` скриптами `build_arena_a2.mjs` / `build_arena_b1.mjs` (для A1 — правка `assets/arena_questions_a1.json` или цепочки, из которой он собирается).

Перед релизом прогон: `npm test` (в т.ч. `tests/arena_questions_assets.test.ts`).
