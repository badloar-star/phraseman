# Новичок-проверяющий: испанский (es), уроки 1–4. Исходное состояние (baseline), 05.11.2026

Роль: взрослый, который не знает испанского и не знает грамматических слов. Только чтение, ничего не правилось.
Стандарт: `docs/work/classic_plain_explanation_standard_2026-11-05.md`.

Что реально видит пользователь (по коду `app/classic_theory_view.ts`, `app/lesson_help.tsx`):
- Теория: название урока, затем 7 глав (название главы, текст `body`, до 6 примеров «фраза — перевод») и задания внутри глав. Поля `note`, `formula`, `story`, `use`, `choose`, `nuance`, `wrong/right`, `strategy`, таблица форм на экран НЕ выводятся (но лежат в данных, и главы на них ссылаются, см. ниже).
- Задания: из 20 заданий урока показываются 3 вида (выбрать пропущенное слово, выбрать верную фразу, собрать фразу); «найди ошибку», «перенос», «преобразование» скрыты. Команды: «Выберите, как сказать: «…»», «Какая фраза значит «…»?», «Соберите фразу: «…»». У первого задания раздела подпись «Пример: фраза — перевод» (это первый пример главы, не образец именно этого задания).
- Вступление: 3 экрана перед уроком («Правило», «Как строится», «Типичные ошибки и примеры»).
- Слова: слова урока N = леммы с `firstLesson == N` в `glossary.json`.

Блоки на урок: вступление 3 экрана + 7 глав теории + 3 первых задания + словарь = 14. Уроков 4, всего 56 блоков.
«Первые 3 задания» = первые три, которые реально появятся на экране при чтении сверху вниз (порядок воспроизведён по коду).
