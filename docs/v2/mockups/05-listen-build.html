Тема приложения

Прогон состояний

Play-кнопка эмулирует TTS: кольцо заполняется 1.5 c, слово подсвечивается в подписи. Целевой EN-текст нигде не написан заранее — узнать его можно только на слух или через клавиатурный fallback. «Медленнее» повторно эмулирует ту же фразу с удвоенной длительностью кольца. Клавиатура в углу банка — заглушка (в RN: реальный текстовый ввод + распознавание).

Только transform / opacity (UI-тред). Кольцо прогресса — stroke-dashoffset на UI-треде через Reanimated, не JS-таймер. Строка ответа, полоса раскрытия перевода и полоса фидбека с зарезервированной высотой: первый кадр = финальная геометрия. Reduced motion: перелёты заменяются мгновенной перестановкой с коротким кроссфейдом; кольцо всё равно заполняется (несёт смысл, не декоративно).
