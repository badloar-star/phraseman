# Task packet: словарь идиом не грузится на старте ради «завтрашней» фразы

Governance-ID: TG-AD6D29BEB409
Status: In progress
Owner: Ядро (сессия 1)
Related epic/enabler: замер Сверки f0d559796 (getIdiomsSync ← rememberPeekPhrases, 50–60 мс в окне +5…+12 с), координатор 13.10

## Outcome

После первого кадра запуск не поднимает каталог идиом (610 КБ JS) ради снимка завтрашней фразы: сегодняшняя фраза
сохраняется сразу, завтрашняя берётся из прошлого снимка или считается отложенно (после взаимодействий + пауза).
Первый показ фразы дня не меняется (сегодняшняя не зависит от каталога, если есть remote/кэш/сохранённая).

## Scope

In scope: `app/daily_phrase_system.ts` (rememberPeekPhrases, память прочитанного снимка), `app/idioms_lazy.ts`
(`isIdiomsCatalogLoaded`), тест. Out of scope: экраны, каталог идиом.

## Architecture

No architecture change: тот же снимок `DAILY_PHRASE_PEEK_KEY` {сегодня, завтра}; меняется только когда считается «завтра».

## Security and privacy

Не касается.

## Technical debt

- Contain: отложенное вычисление может не успеть до выхода из приложения — тогда завтрашний холодный старт возьмёт
  фразу из remote/кэша или поднимет каталог, как раньше (лог `[DAILY-PHRASE-PEEK] miss`).

## Verification

Тест: при наличии завтрашней фразы в прочитанном снимке каталог не грузится; без неё — грузится только после отложенного
шага; сегодняшняя фраза записана сразу. Лог `[IDIOMS-LAZY]`.
