## Architecture
Каждый гейт из `scripts/release_precheck.mjs` (GATES) запускается отдельным `node scripts/<gate>.mjs` с теми же переменными,
что даёт precheck; вывод — в scratchpad `gates/*.log`. Тяжёлый гейт озвучки (внутри раннер тестов) — только со слотом
светофора. Полный typecheck — только при ≥4 ГБ свободной памяти и без другого процесса проверки типов; иначе пропуск с причиной.

заглушками-префиксами `appl_`/`goog_` для хвоста проверки. Пользовательские данные не затрагиваются.
