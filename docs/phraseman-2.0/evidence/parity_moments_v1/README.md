## Пик — Дизайн (components/spire/moments)

**m01 «Повышение лиги — три акта» (вариант A)**
1. Через 14 с приложение стоит на экране «ТОП-5 КОМНАТЫ / 5 место. Поднимаешься» с крупной монетой — такого экрана в эталоне нет.
   Эталон за 10 с: акт 1 «ИТОГ НЕДЕЛИ · ГРАНИТ» + «Считаем монеты недели…» + таблица 6 строк (место · монета ранга · имя · монеты);
   акт 2 «Граница топ-5 — под тобой», строка «Ты» подсвечена, линия «топ-5» под 5-м местом;
   акт 3 (финал) башня целиком со шпилем и «НАД ОБЛАКАМИ», шкала этажей 1–15 слева, монета-аватар на этаже 1 + плашка «Этаж 1»,
   название новой лиги «Базальт», «+100 монет за повышение», кнопка «Играть» со стрелкой у правого края.
2. «Пропустить» в эталоне есть только в актах 1–2; в финале её нет. В приложении она остаётся в финале.
