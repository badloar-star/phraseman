# Англійська · Урок 22 · Заняття 25 — Обрати ту або ті

**Ситуація.** Ви порівнюєте речі й обираєте відповідні.

**Що ви опануєте:** determiner|adjective + one|ones
**Нові слова:** hooded, patterned, loose-fitting, tight-fitting

## Інтро 1

### Куртка з капюшоном

Hooded — із капюшоном. Ви обираєте одну куртку й хочете саме куртку з капюшоном: the hooded one. One замінює jacket. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I want the hooded one.**
- ❌ I want the hooded ones. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I want the hooded it. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*

## Інтро 2

### Візерунок і вільний крій

Patterned — із візерунком, не однотонний. Візерунок може бути різним; striped — смугастий — уже знайомий окремий випадок. Ви обираєте штори, тобто кілька предметів: the patterned ones. Loose-fitting — вільного крою: сорочка не облягає тіло. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I like the patterned ones.**
- ❌ I like the patterned one. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I like the patterned them. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*

## Інтро 3

### Обтислі джинси

Tight-fitting — обтислий, такий, що щільно облягає фігуру. Це опис крою, а не обов’язково помилка розміру. Jeans — слово у множині, тому кажемо the tight-fitting ones, навіть коли обираємо одну пару джинсів. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I do not want the tight-fitting ones.**
- ❌ I do not want the tight-fitting one. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I do not want the tight-fitting them. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
