# Урок 31 · Заняття 52 — Чекаємо на столик

**Ситуація.** Ви прийшли з Анною до кафе й чекаєте на вільний столик.

**Що ви опануєте:** пояснювати очікування й наступний крок через so і therefore.
**Нові слова:** —
**Повторюємо знайомі слова:** cafe, table, menu, window

## Інтро 1

### Кафе заповнене — ми зачекали

Ви прийшли до кафе, але вільних місць немає: The cafe was full, so we waited — кафе було заповнене, тому ми зачекали. Складіть The cafe was full + so + we waited. Перед so називаємо причину, після нього — результат. У минулому часі wait отримує закінчення ed: waited.

**Виберіть фразу для цієї ситуації.**

- ✅ **The cafe was full, so we waited.**
- ❌ The cafe was full, so we waiting. — *Потрібна повна частина we waited.*
- ❌ The cafe was full, so we waits. — *Для минулої дії використовуємо waited.*

---

## Інтро 2

### Столик вільний — ми сіли

У письмовій розповіді ви пояснюєте наступний крок: The table was free and therefore we sat down — столик був вільний, і тому ми сіли. Складіть The table was free + and therefore + we sat down. Therefore показує результат; sat — минула форма sit.

**Виберіть фразу для цієї ситуації.**

- ✅ **The table was free and therefore we sat down.**
- ❌ The table was free and therefore we sitting down. — *Для минулої дії потрібна форма sat.*
- ❌ The table was free and therefore we sits down. — *Після we й у минулому використовуємо sat.*

---

## Інтро 3

### Ввічливо уточнюємо, чи вільний столик

Ви бачите порожній столик і запитуєте офіціанта: Could you tell me if this table is free? — чи не могли б ви сказати, чи вільний цей столик? Складіть Could you tell me + if + this table is free. If тут означає «чи»; усередині зберігаємо порядок this table is без питальної перестановки.

**Виберіть фразу для цієї ситуації.**

- ✅ **Could you tell me if this table is free?**
- ❌ Could you tell me if is this table free? — *Після if порядок this table is free.*
- ❌ Could you tell me if this table are free? — *Один table потребує is.*
