# Phraseman — Аудит наград и опыта (XP)

**Дата:** 2026-06-14
**Метод:** прямое чтение кода (5 параллельных карт-агентов) + независимая верификация ключевых находок по file:line.
**Что покрыто:** весь цикл наград — XP, Осколки 💎, Энергия, VIP-дни, косметика, коллекционные карточки. Источник истины по XP — серверный `functions/src/progress_events.ts` (доверяет `xpDelta` клиента, кап на тип события, лимит 500 событий/сутки).

---

## 0. Три валюты (как устроено)

- **XP** — `registerXP(amount, source, ...)` в `app/xp_manager.ts:170`. Мультипликаторы (клуб, цепочка, comeback, сложность урока, подарок, лиги, league-chest) применяются только к «заработанным» источникам (`xp_manager.ts:198`). `amount === 0` → ранний выход (никогда не начисляем за неправильный ответ).
- **Осколки 💎** — `addShards(source)` / `addShardsRaw` / `awardOneTime` в `app/shards_system.ts`. Каталог сумм — `SHARD_REWARDS` (`shards_system.ts:53-75`).
- **Энергия** — `spendEnergy/addEnergy` в `app/energy_system.ts`. Гейтит уроки для бесплатных; премиум и тестеры не тратят.

## КРИТИЧЕСКИЕ НАХОДКИ (верифицировано лично)

### 🔴 C1. «Умная тренировка» (Smart Session) НЕ даёт НИ XP, НИ осколков
- **Экран:** `app/trainer_smart_session.tsx` — **0 вызовов** `registerXP` / `addShards` (проверено grep'ом: 0 совпадений).
- **Это реальный, заметный экран**, не заглушка. Точки входа:
  - `app/trainer.tsx:623` — режим `smart_mix` (общий «Тренер»).
  - **Все диагностические тренировки** ведут сюда (`diagnosis_training_*.ts` → `smartTrainerRoute: '/trainer_smart_session?mode=weak...'`). То есть пользователь выявил свои слабые места и пришёл их отрабатывать — и не получает ничего.
  - `app/personal_plan_navigation.ts:163`.
- **Нюанс:** когда тот же движок достигается через *задачу плана* — идёт через `personal_plan_exercise.tsx` и даёт `plan_task_complete` (+6 XP). Но **отдельная сессия тренажёра не платит ничего.** Косвенно двигает прогресс дневных заданий, но прямого XP/осколка нет.
- **Вывод:** самая «честная учёба» (отработка собственных ошибок) — нулевая награда. Главный кандидат на фикс.

### 🔴 C2. Зачёт уровня (level exam) даёт 0 XP — `xpDelta` захардкожен в 0
- `app/level_exam.tsx:772` — `xpDelta: 0` в `submitProgressEvent`. `registerXP` в файле отсутствует.
- Что есть: `addShards('lesson_quiz_passed')` +1 (`:750`, только при `passed`) и `awardOneTime('exam_excellent')` +3 при ≥90% (пожизненно один раз, `:752`).
- **Провал зачёта (pct < порог) → 0 XP и 0 осколков.** Никакой награды за участие.
- `lesson_quiz_passed` +1 **без ключа дедупликации** на уровень — повторная сдача уже пройденного уровня может выдавать +1 каждый раз (мелкий фарм; контраст с дедупом в других местах).
- **Вывод:** полноценный экзамен на разблокировку CEFR-уровня = почти нулевой XP. Должен давать ощутимый XP.

### 🔴 C3. «Сундук дня» (Daily Treasure Chest) — ПОЛНОСТЬЮ МЁРТВЫЙ КОД
- В `variable_reward_system.ts` весь аппарат сундука (`openTreasureChest`, `getTreasureChestState`, `prepareTreasureChestOpen`, `commitTreasureChestOpen`, `getTreasureStats`, премиум-открытия `premiumChestsUsed` до 2/день) имеет **0 ссылок** во всём приложении (проверено grep'ом).
- Единственный живой потребитель — `calculateRewardWithBonus()`:
  - `app/lesson_complete.tsx:600` (после урока, на базу `BONUS`),
  - `app/(tabs)/quizzes.tsx:1559` (после квиза ≥70%, на `score`).
- `calculateRandomBonus()` (`variable_reward_system.ts:55`): **82% → 0 бонуса**, 10% → 0-10, 5% → 10-20, 3% → 20-30. Средний бонус ≈ **1.95 XP** за раз.
- **Двойная проблема:** (а) обещанная механика «открой сундук» не существует в UI — мёртвый код; (б) то, что осталось, в 82% случаев молча даёт 0 поверх базы — невидимая и почти бессмысленная «переменная награда».
- **Вывод:** либо реализовать настоящий ежедневный сундук как отдельное действие, либо выкинуть мёртвый код и переосмыслить бонус (гарантировать минимум, поднять шансы).

### 🔴 C4. Награда за баг-репорт (+1 осколок) — МЁРТВЫЙ КОД
- `bug_report: 1` объявлен в `SHARD_REWARDS` (`shards_system.ts:74`), но **ни одного вызова** `addShards('bug_report')` нигде (ни клиент, ни сервер; проверено grep'ом, включая динамические строки → 0).
- Серверный `functions/src/client_reports.ts` (приём репортов) вообще не упоминает осколки/XP.
- **Вывод:** пользователь шлёт баг-репорт и не получает обещанный осколок. Либо подключить начисление (на сервере, идемпотентно, с антифармом), либо убрать из каталога.

### 🔴 C5. Награды за место в лиге (1-е/2-е/3-е) — МЁРТВЫЙ КОД
- `league_1st:3`, `league_2nd:2`, `league_3rd:1` объявлены (`shards_system.ts:65-67`), но **нет ни одного** `addShards('league_1st'|'league_2nd'|'league_3rd')` во всём коде (проверено grep'ом → только определение).
- Недельная лига выдаёт награды через **league_chest** (`functions/src/league_chest.ts`: база 15-35 осколков + бонусы + косметика), а призовые за топ-3 в каталоге — висят неподключённые.
- **Вывод:** либо это намеренно заменено сундуком лиги (тогда убрать мёртвые источники), либо топ-3 должны получать эти осколки и сейчас не получают.

## ⚠️ ОБРАТНЫЙ РИСК: повторяемый XP-фарм (тоже баг)

### 🟠 R1. Повтор урока 1 начисляет XP за каждый правильный ответ БЕЗ ограничения
- `app/lesson1.tsx:2577` — `registerXP(xpAmount, 'lesson_answer', ...)` внутри `if (isRight)` (`:2541`), **без гарда `isReplayRef`**. Более того, в payload честно стоит `replay: overridePhraseCell !== null` — код ЗНАЕТ, что это повтор, но всё равно платит.
- При повторе генерируется свежий `serverAttemptIdRef` (`:2673`) и сбрасывается `sessionAnswerCount` (`:2676`) → `answerEventId` каждый раз новый → серверный дедуп по `eventId` НЕ ловит → XP реально начисляется снова. Ограничение только серверным капом **500 событий/сутки** (`progress_events.ts:554`).
- Контраст: ветка неправильного ответа (`:2614`) гард `if (!isReplayRef.current)` имеет; словарь и неправильные глаголы на повторе корректно дают 0.
- **То же у финального экзамена:** `exam.tsx` начисляет 10000 XP за ≥90% без дедупа → повторная сдача = снова 10000.
- **Вывод:** ассиметрия. «Честная» учёба (тренажёр, зачёт) = 0, а повтор урока 1 и пересдача экзамена = фарм. Нужен гард повтора на `lesson_answer` (как в else-ветке) и дедуп на экзамене.

## Соревновательные режимы: проигравший и ничья

(значения XP — серверные, `functions/src/arena_bot_match.ts:18,45`: win=50, draw=`DRAW_XP=30`, loss=15)

| Исход | XP | Осколки | Ранг |
|---|---|---|---|
| Победа (ранкед/бот) | +50 (×мультипликаторы) | +1 (`arena_win`) +1/10 побед +1 на рост ранга при серии | +1 звезда |
| **Поражение** | +15 | **0** | −1 звезда (если последний) |
| **Ничья** | +30 | **0** | без изменений |
| Сдача/форфейт | 0 | 0 | без изменений; ставка всё равно списывается |
| Дружеская комната / гост-челлендж | 0 | 0 | без изменений |

- **Проигравший и ничья — без осколков.** Это, скорее всего, by design (мотивация), но стоит решить осознанно: ничья (ровный счёт — достижимый исход) не даёт ни осколка и **сбрасывает серию побед** (`arena_results.tsx`).
- Ставочные исходы используют `addShardsRaw(stake×2, 'arena_match_wager_win')` / `spendShards(..., 'arena_match_wager_loss')` — это **не баг**, просто эти reason'ы вне каталога `SHARD_REWARDS` (произвольная сумма ставки), что корректно.

## Что работает хорошо (подтверждено)

- **Достижения:** ~109 шт., все дают XP (`achievement_reward`, кап 5000 на сервере) + по +1 осколку через ручной клейм (`claimAchievementShardReward`, `achievements.ts:3185`). Нет «пустых» достижений без XP.
- **Ежедневный вход:** `registerXP(bonusXP, 'daily_login_bonus', ...)` подключён (`_layout.tsx:438`), эскалация 20→750 XP по дням цикла.
- **Comeback:** ×2 на день при возврате после 7+ дней (`_layout.tsx:493`, мультипликатор в `xp_manager.ts:211`). Нюанс: это множитель, не флэт — без активности в этот день даёт 0.
- **Дневные задания:** индивидуальный клейм (`daily_task_reward`) + бандл «все 3» (+1 осколок, `claimDailyTasksAllShardsReward`, идемпотентно через Firestore-транзакцию).
- **Фраза дня:** +50 XP один раз/день (`daily_phrase_quest.ts:126`).
- **Цепочка:** +3 осколка на 7/14/21…, +5 на 30/60/90… (`shards_system.ts:794-798`). Промежуточные дни (5, 50, 100) — без осколков.
- **Подарок за уровень:** есть на каждый уровень, пулы F2P/премиум, гарантии на вехах (10/20/30/40/50/70). Косметика, XP-банк, осколки.
- **Коллекционные карточки:** серверные дропы (урок 28%, квиз 18%, экзамен 40%, арена 10%), pity-гарантии, +15 осколков за полный сет. Сами по себе XP/осколков не дают (косметика) — спорно, но скорее by design.
- **VIP-опрос:** +30 дней VIP (один раз, `vip_survey.ts`). **Рефералка:** +7 дней рефери / +7×N рефереру, за флагом `referral_enabled` (дефолт true), антифрод 72ч. **Friend quest:** +1000 XP и +10 осколков обоим при 3000 XP за 24ч.
