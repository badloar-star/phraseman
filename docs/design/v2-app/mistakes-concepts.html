Мои ошибки — три концепции

Все три нарочно непохожи на «Карточки»: нет стопки-героя, плиток 2×2, сетки карточек и переворота карточки. Общее с приложением — только цвет темы (аврора, акцентная кнопка). В каждой по четыре ключевых экрана: хаб, ошибка, вопрос отработки, неверный ответ. Выберите одну — построю весь раздел в этом языке.
