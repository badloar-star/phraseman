# Plus / Ultra — уровень подписки по продукту (шаг 2, слово владельца 06.11: «МАКЕТ ПО УЛЬТРА И ПЛЮС ОДОБРЯЮ!»)

## Outcome

Месячная подписка показывается как «Plus» (как сейчас), ГОДОВАЯ — как «Ultra»: другой цвет и другая форма значка. Уровень определяет ОДНА функция по продукту магазина (годовой → ultra, месячный → plus; пожизненная/VIP/подарок → plus), из уже загруженных данных (память плана + локальное хранилище), без новых сетевых запросов. Права доступа не меняются: Ultra = все права Plus.

## Scope

Часть A: `app/subscription_tier.ts` (чистая `tierFromPlan`/`tierFromProductId` + журнал `[SUB-TIER]`), `components/plus/plus_ring_spec.ts` (палитра Ultra рядом с Plus, ОДНА константа выбора варианта: по умолчанию «Рубин»), `components/plus/use_subscription_tier.ts` (хук), тесты. Следующие части: B — кольцо/значок/метки/пилюли; C — профиль, Настройки, шапка Главной, пейволы и тексты; D — публичная проекция (Ядро) для друзей/Пика.

## Architecture

Источник уровня для себя: `peekPremiumPlan()` (память, первый кадр) → AsyncStorage `premium_plan` (локально) → по событиям `premium_activated/deactivated/access_changed`. Неизвестный план при активной подписке = Plus (никогда не показываем Ultra по догадке). Для других людей уровень приходит публичным полем (часть D), по умолчанию Plus. Палитра Ultra — константа `ULTRA_VARIANT_IN_USE`; смена на Изумруд/Платину — одна строка.

## Security and privacy

Уровень для других — тот же класс данных, что и признак Plus (публичная проекция), отдельных разрешений нет; политика уже описывает подписку. Новых сторонних сервисов нет.
