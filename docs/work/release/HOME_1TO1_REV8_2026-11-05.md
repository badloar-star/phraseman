## Цвет Главной: фиолет / зелёный против графита эталона (вопрос Сверки, 423c12635)
**Вердикт: не регресс дефолтной темы.**
- Дефолт для нового пользователя в коде — одна светлая тема «Сумерки» (`ink`, насыщенность 1): `app/theme_first_run_default.ts`, `pickSystemDefaultTheme` отдаёт `NEW_USER_SYSTEM_PAIR.light` при ЛЮБОМ системном режиме. Это ЗАМОК ВЛАДЕЛЬЦА 24.10 («из онбординга убрать тёмную тему, и стандартная тема только одна — светлая», коммит 16b3a3ed9). Фиолетовый кадр новичка `ru_frames/02_home_newbie_free.png` = «Сумерки» — как и должно быть.
- Зелёный кадр (`home-r3-free__default.png`, «Нефрит») — выбранная/подставленная dev-тема эмулятора (`devThemeChoice` / dev_state `theme=`), не дефолт.
- Графит и тёмный фон эталонов rev6–rev8 — макеты Codex в тёмной теме; встроенный дефолт кода (`BUILTIN_DEFAULT_THEME`) — `graphite`, но для НОВЫХ пользователей он перекрыт замком 24.10.
- Что решает владелец: если эталон надо сравнивать в дефолте приложения, нужен кадр в тёмной теме «Графит» (dev_state `theme=graphite&appearance=dark`) — склейка по составу и раскладке (цвет темы не расхождение). Менять дефолт на графит нельзя без слова владельца (замок 24.10); тема-ползунки 05.11 (флаг theme_sliders_v1) стандартный вид для «остальных» пока не определили.

## Анимации Главной (`approved-rev8/motion.js`)
Просмотрен весь файл (8 КБ). Он описывает ТОЛЬКО две хореографии: **приветствие** (выход героя, набор текста, монета в слове «монет…») и **истории «Открытие раздела»** (искры, орбы, свет, полоса). Обе — зона «Моментов» (по слову координатора не трогаю). У самой Главной в утверждённом макете движения нет: `approved-rev8/*.css` не содержит ни одной анимации (только `animation: none` для reduce-motion). Пульс плиток новых разделов — конечный, по `OWNER-STATE-MAPPING.md` («pulses finite; 0 = no pulse; reduced motion never scales icons») — сверка по коду отдельным пунктом ниже.
- **Расхождений по анимациям Главной: нет** (в макете их нет), кроме пульса плиток — проверить кадрами/записью: плитка нового раздела пульсирует конечное число раз, при Reduce Motion не масштабируется, после захода «Новое» снимается.
