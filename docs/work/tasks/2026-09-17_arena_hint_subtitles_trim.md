## Outcome

Владелец прямым сообщением попросил сократить подтексты режимов в шторке
выбора режима Арены:
- рейтинговый — убрать «· только игроки», оставить только про ранг;
- быстрый матч — убрать «· соперник по уровню», оставить только
  «(не влияет на ранг)»;
- дуэль с другом — подтекст убрать целиком (сейчас пусто).

Наблюдаемый результат: в шторке выбора режима у «Рейтинг» подпись «Победа
двигает ранг», у «Быстрый матч» — «(не влияет на ранг)», у «Дуэль с другом»
подписи нет вообще.

## Architecture

Чисто презентационная правка словаря копирайта и пропуска одного поля в уже
существующей мапе `modeHint`. Компонент `ArenaModeSheet` уже поддерживает
пустой `body` (`body?: string`, рендерится условно) — новой логики не нужно.

## Security and privacy

Нет влияния. Только текстовые строки интерфейса, без новых полей/сервисов/
разрешений.
