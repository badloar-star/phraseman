## Outcome

В клиенте и на сервере не остаётся кода, который начисляет, хранит как активную механику, синхронизирует или показывает XP/опыт. Историю (старые квитанции/операции) читать можно только в compat-файлах. Успех: скан по токенам XP даёт только allowlist compat-файлов; проверка типов не растёт; связанные пробы и тесты зелёные.

## Scope

In scope: активные producers/consumers XP в app/components/modules/hooks/functions/src (по результату скана), синхронизация progress-событий (`grant_xp`), копирайты; новые пробы.
Out of scope: deploy, удаление облачных данных, чужие тесты (удалять нельзя), Learning V2 контент, MAX-пломба, App Check.

## Architecture

XP не существует как понятие; compat-чтение старых данных изолировано в перечисленных файлах. Изменения удаляют код, не добавляют путей. Старые операции и поля читаются и игнорируются, не бросают исключений.

## Security and privacy

Новых данных нет; удаляется хранение и синхронизация XP-полей. Правка политики конфиденциальности не нужна, упомянуть при релизе. Секреты не читаются.

## Technical debt

Contain: compat-файлы перечислены в пробе-ратчете; неразобранное — в PROGRESS как BLOCKED со следующим шагом.

## Verification

Скан токенов XP до и после; `npx tsx` пробы; `npm run typecheck` (число ошибок не растёт); точечный `npm run test:one`; факты в PROGRESS.md.

## Rollback

Правки локальные, не закоммичены; откат — обратная правка конкретного файла (без reset/checkout). Данные пользователей не затрагиваются.
