# Learning V2 — прокрутка карты: мягкая, без ощущения ограничения

Governance-ID: TG-54906AC63197

## Outcome
Карту нельзя «зашвырнуть» одним резким взмахом на десятки экранов. После
отпускания пальца она проезжает короткую дистанцию и плавно замирает.
Владелец: «нельзя было вот так пальцем очень быстро скроллить, но при том
чтобы не ощущалось что есть ограничение — он плавный, мягкий и приятный».

Явное решение владельца (21.09): гасим ТОЛЬКО инерцию после отпускания.
Скорость движения ПОД пальцем не трогаем — карта идёт за пальцем один в
один, иначе экран читается как «тормозит».

## Scope
- `components/learning-v2/LearningV2PulseCourse.tsx` — props прокрутки
  карты (FlatList `learning-v2-pulse-map`).

## Architecture
Одна настройка поведения, без собственной физики и без перехвата жестов:
`decelerationRate` переводится на «быстрое» затухание (принятый в проекте
приём, уже используется в ~десятке экранов). Нативная инерция сохраняется
целиком — меняется только коэффициент затухания, поэтому движение остаётся
плавным и не имеет видимой границы.

Дополнительно включается `alwaysBounceVertical`, чтобы край карты отвечал
мягким пружинным откликом, а не жёстким стопом — это снимает ощущение
упора в стену.

Осознанно НЕ делаем: snapToInterval (карта вставала бы по сетке — владелец
выбрал вариант без этого), ограничение скорости под пальцем, кастомный
PanResponder.

## Security and privacy
Данных не касается: правятся только свойства прокрутки. Privacy policy
изменений не требует.

## Technical debt

настройки `decelerationRate`, тогда как остальные экраны её задают.
