## Outcome

Политика §5 обещает убрать запись человека из рейтингов при удалении аккаунта. Сейчас 3ed0dcf5f пишет в итог недели каждого
участника комнаты снимок лестницы (ник, ранг монеты, место, монеты), и он хранится бессрочно. Ник удалённого остаётся у соседей.

После правки:
- при удалении аккаунта в итогах соседей по комнатам, где человек был, его строка лестницы теряет ник (нейтральное имя) и ранг монеты;
- место и монеты остаются, иначе лестница соседа развалится;
- чужие строки не трогаются; повтор безопасен.

Всё в том же пакете выкладки 17.10. Текст политики не меняется (вариант Б координатора).

## Scope

In scope:
- `functions/src/spire_finalize_core.ts`: у строки лестницы ключ участника `memberKey` = sha256(`groupId:stableUid`), первые 16 hex-символов, без uid;
- `functions/src/account_delete.ts`: перед снятием членства в `spire_groups` для каждой комнаты читаются итоги соседей `{weekId}_{lang}` (getAll, ≤ 30 на комнату), строки с этим ключом обезличиваются; журнал `[D189-LADDER-SCRUB]`;
- клиент `app/spire/spire_week_result_client.ts`: строка с пометкой `removed` получает пустое имя, вид подставляет нейтральное «Игрок» на языке интерфейса;
- тесты сервера и клиента.

Out of scope:
- старые итоги без лестницы (до выкладки 17.10 лестниц в проде нет — 3ed0dcf5f не выложен);
- текст политики;
- групповой рейтинг вне Пика.

## Architecture

1. Ключ строки — хеш от `groupId` и stableUid.
   - Сосед видит только непрозрачную строку, и она разная в разных комнатах: человека нельзя связать между неделями.
   - Сервер при удалении знает и `groupId`, и stableUid, поэтому пересчитывает тот же ключ.
2. Обезличивание идёт по комнатам из того же запроса `members.<uid> != null`, которым сейчас снимается членство.
   - Порядок: сначала итоги соседей, потом снятие членства.
   - Иначе список соседей пропадёт вместе с членством.
3. Записи — батчами, только изменённые документы.
4. Строка после обезличивания: `name: ''`, `coinRank: null`, `removed: true`; place и coins прежние.

## Security and privacy

Правка закрывает разрыв с политикой §5: имя удалённого больше не живёт в чужих документах. Новых персональных данных нет. Ключ — хеш с солью комнаты, без uid. Итог по-прежнему читает только владелец; запись клиенту запрещена правилами. Детских данных правка не касается.

## Technical debt

- Contain: обезличивание ищет соседей по `members` комнаты. Если комната уже удалена кроном до удаления аккаунта, итоги её соседей не найдутся.
  - Сейчас комнаты не удаляются: проверено, в кроне финализации нет удаления `spire_groups`.
  - Если появится чистка комнат, она должна идти после обезличивания или вместе с ним.
