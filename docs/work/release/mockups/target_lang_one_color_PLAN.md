# Изучаемый язык одним цветом — план реализации

Решение владельца 05.11 (окончательное, заменяет «части речи цветом»): «делаем 1 цвет для слов фраз изучаемого языка».
Макет: `pos_colors.html` (рядом). Код приложения до «да» владельца не трогаем. В сборку 150 — только английский курс.

## Схема
| Что | Цвет | Жирность |
|---|---|---|
| Текст на языке интерфейса | обычный цвет экрана, как сейчас (вступление — `text`, теория — `secondary`) | как сейчас |
| Все слова и фразы на изучаемом языке | ОДИН цвет из оттенка темы (`lang`) | 700 |
| Строка «Читается» (теория и вступление, под каждым примером) | приглушённый тон темы (`say`), курсив | 400 |
| Заголовки карточек («Добавьте ed») | обычный цвет, не красим | как сейчас |
| Неправильный пример | значок ✗ в сером кружке, без красного; верный — без зелёного | как сейчас |

Частей речи, отдельной подсветки частиц/артиклей/окончаний и подложки `accentSoft` больше нет. Разметка частей речи не нужна.

## Как считается цвет (на телефоне, без сети)
- Оттенок H — оттенок темы (сейчас — акцент темы на «Максимуме», как уже делает `introTextRolesForTokens`; с ползунками — H из `tune:<H>:<S>`).
- `lang` = OKLCH(H, C 0,15, L 0,80 тёмная / 0,40 светлая), `say` = OKLCH(H, C 0,07, L 0,70 / 0,53). Насыщенность ползунка: C × k, k = S/35
  (как `themeTuneChromaScale` в `constants/theme_tune.ts`); при S = 0 оба цвета серые и отличаются светлотой, жирностью и курсивом.
- Светлота доводится до контраста ≥ 4,6 на всех подложках: карточка вступления, стекло на фоне, плашка теории сверху и снизу, шторка,
  подсказка (`selected`). Готовая функция уже есть: `toContrast(hue, chroma, L, dir, MIN, surfaces)` в `constants/liquidGlassPaletteRoles.ts`,
  кэш по токенам — в `constants/liquidGlassIntroTextRoles.ts`.

Контраст (макет, худшая подложка): `lang` тёмная 6,85–7,46, светлая 5,97–6,63; `say` тёмная 4,86–5,09, светлая 4,61–4,73 (синий 245°,
фиолетовый 300°, бирюзовый 180°, оранжевый 40°). Обычный текст 11,85–12,81.

Где изучаемый язык при интерфейсе на латинице. Для RU/UK интерфейса правило «латиница = изучаемый язык» работает на телефоне (дёшево,
кэш по строке). Для интерфейсов en, es, pt-BR, vi, id, tr, pl (у английского курса — всё на латинице) по буквам не отличить. Решение — при сборке:
скрипт размечает в intro.json/theory.json отрезки изучаемого языка (совпадение с фразами урока из `lessons-NN.json`, рамки «The word X means»,
бэктики, которые уже есть в fr/de/it), телефон только красит готовые отрезки. Для 150: RU/UK — полностью; латинские интерфейсы — красим
примеры (они точно на изучаемом языке), абзацы — без цвета, пока нет разметки (честно, без ошибок). Разметку абзацев — следующим шагом.

  для остальных интерфейсов чтения нет нигде).

## Сторожа
1. Контраст `lang` и `say` ≥ 4,5 на всех подложках: все темы × светлая/тёмная + сетка ползунков H 0…355 шаг 5 × S 0…100 шаг 10.
2. Различимость: `lang` ≠ обычный текст, `say` ≠ `lang` и ≠ `secondary` (OKLab ΔE ≥ 0,04 + курсив/жирность).
3. Каждый пример вступления английского курса имеет «Читается» для ru и uk (217/217).
4. На экранах вступления и теории нет цветов `t.wrong`/`t.correct` и подложки частицы.
5. Замок в `docs/work/OWNER_LOCKS.md`: «изучаемый язык — один цвет из оттенка темы; частей речи нет».

## Риски
- Латинские интерфейсы: без разметки при сборке абзацы окрашивать нельзя — покрасится и пояснение. Для 150 красим только примеры.
- Изменение `splitIntroTextRoles` ломает тесты Learning V2 про частицы — переписать тесты вместе с правкой.
- `say` в светлой теме близок к обычному тексту теории (ΔE ≈ 0,045) — отличие держат курсив и оттенок; проверить на телефоне глазами.
- Вес: копия `say` во вступления — около 217 строк × 2 языка, единицы КБ.
