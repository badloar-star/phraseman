# Идеи для улучшения онбординга

## Social proof — варианты реализации

### Где показывать
На экране `streak` (шаг 5) — заменить пустое "Дай слово!" на экран с реальной ценностью + social proof.

### Варианты

**A — Счётчик учеников (рекомендовано для старта)**
```
🌍 Уже 14 200+ человек учат английский с Phraseman
```
Статичная цифра, обновляется вручную раз в месяц. Минимальные усилия, работает сразу.

**B — App Store рейтинг**
```
★★★★★ 4.8 · 340 отзывов
```
Подключить после накопления реальных отзывов в сторе.

**C — Живые имена из leaderboard**
Брать 3-4 имени из AsyncStorage `leaderboard` и показывать:
```
Вместе с тобой учатся: Алексей, Катерина, Omar...
```
Данные реальные, выглядит живо. Реализовать через `AsyncStorage.getItem('leaderboard')`.

**D — Прогресс других пользователей**
```
Пользователи Phraseman выучивают в среднем 12 фраз за неделю
```
Доверие через конкретику. Статичная цифра.

**E — Мини-цитата бета-тестера**
Одна короткая цитата от реального бета-тестера + имя + счётчик учеников.
Пример:
```
"Наконец-то понял разницу между look up и look for!" — Дмитрий, Киев
```

### Рекомендация для первого релиза
Комбо A + E: счётчик учеников + одна цитата бета-тестера прямо на экране `streak`.
Позже заменить E на реальные отзывы из App Store/Google Play.
