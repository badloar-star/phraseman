# Адаптация коротких и узких экранов — 9 сентября 2026

## Результат и принцип

Исправлены обнаруженные ограничения высоты в общих оболочках, заданиях Арены,
тренировках карточек, старых экранах персонального плана и ряде модальных окон.
Текст и цели нажатия не масштабируются целиком вниз: сначала сокращаются отступы,
затем включается ограниченная прокрутка. В крайне низком окне Арены прокручивается
вся страница задания. Длинные ответы больше не заменяются многоточием.

Это отчёт об исправлениях исходников и ограниченной проверке, **не сертификат
работы каждого состояния приложения на каждом физическом устройстве**.

## Обнаруженные причины и изменения

| Поверхность | Причина | Исправление |
| --- | --- | --- |
| ArenaQuestion: варианты, сборка, пары | Неограниченная flex-высота; подсказка вне прокрутки; обрезание ответов | Ограниченный viewport, прокручиваемые подсказка/ответы, кнопка отдельно, компактные отступы |
| ArenaScreen: бой, задание дня, поиск | HUD и действия не помещались в очень низкую высоту | Прокрутка всей страницы по явному opt-in; виртуализированные списки сохраняют собственный viewport |
| Поворот во время ответа | Смена View на ScrollView перемонтировала задание | Постоянный родитель; переключается только scrollEnabled, выбор сохраняется |
| Блиц, слушание, говорение | Центральное содержимое не могло прокручиваться | Ограниченная прокрутка; транспорт/удержание микрофона остаются отдельно; перенос настроек |
| PhraseCard | Высота абсолютных сторон определялась только лицом | PhraseCardSizer измеряет обе стороны при текущей ширине, включая внутренние отступы |
| Названия наборов и длинные фразы | Жёсткий numberOfLines скрывал текст | Ответы и карточки показываются полностью; название набора прокручивается горизонтально в ограниченной шапке |
| HybridAlertShell | Высокое содержимое упиралось в край окна | Прокрутка обычных диалогов, safe area и keyboard inset; явное исключение для форм со своей прокруткой |
| SeasonGiftModal | Одна фаза содержала вложенный список, другие не имели прокрутки | Один FlatList владеет всей карточкой: заголовок, друзья, кнопки; все фазы сохранены |
| ReportErrorButton | Минимальная высота 360 и снимок Dimensions не учитывали оставшееся место с клавиатурой | Ограничение относительно KeyboardAvoidingView и прокрутка всех состояний формы |
| Награды, сообщения, обновление, восстановление | Карточки и текст превышали высоту окна | Полная прокрутка содержимого/страницы; общий ResponsiveModalScrollView учитывает safe area |
| PremiumCelebrationModal | Абсолютные сцены перекрывались в коротком окне | Достаточная высота сцены с прокруткой, горизонтальные safe area, отсутствие overscroll |
| Старый персональный план | Статические экраны результата/перехода/вопроса | Прокрутка с сохранением всех действий |

Наградные и информационные поверхности включают BoonActivated/BoonChest (оба
варианта), ReferralFriendRewardHybrid, FriendLevelUp, WelcomeGift, LevelSpinReward,
PersonalAdminMessage, GlobalBroadcast, ReferralWelcome, RewardCardV2,
LeagueBonusAvailable, LeagueChestTeaser, StatsLearningInsights и окно завершения
реферального доступа. Обработчики начислений, отправки и восстановления не менялись.

Три исключения UpdateModal удалены из text-integrity baseline через штатный
shrink-only API после удаления соответствующего обрезания. Новых исключений нет.

## Ширина аудита и ограничения

Статическая инвентаризация нашла 142 корневых route-кандидата (включая `(tabs)`)
и 99 вхождений Modal. Эти числа включают вспомогательные модули, перенаправления
и пересечения; их нельзя складывать или называть числом проверенных экранов.
Для общего обзора проверены scroll-контейнеры, фиксированные размеры и делегирование
в дочерние экраны. Наличие ScrollView само по себе не считается PASS.

Уже существующие решения в onboarding, Learning V2 PracticeViewport,
TheoryLessonView, DialogsTabContent и BouncyScrollView сохранены. Учебный контент,
авторские реестры Learning V2 и испанского курса не изменялись.
Декоративные сцены, редиректы, служебные модули и отладочные страницы отделены
от пользовательских форм; общий принудительный ScrollView на всё приложение
не добавлялся, поскольку он нарушил бы списки и жесты.

Не выполнен сплошной runtime-обход всех маршрутов, локалей и состояний.
Не проверены на физических Android/iOS: клавиатура во всех формах, удержание
микрофона, вложенные жесты, VoiceOver/TalkBack, все варианты системной навигации.
Полная нативная сборка и общий tsc не запускались. Это остаётся обязательной
проверкой перед заявлением «работает на всех устройствах».
