## Outcome

Владелец: «Из видео должна быть кнопка „Сохранить“ на КАЖДОЙ отдельной карточке … можно сохранить себе только те карточки, которые сам хочешь, а не весь набор»; и «если текст длиннее — размер текста уменьшается соответственно, чтобы весь текст поместился». Мера: у каждой карточки набора из видео своя закладка (мгновенно, откат, без двойных тапов), сохранённая попадает в «Сохранённые» (фильтр «Из видео»); длинная фраза на карточке уменьшается до 14 по расчёту и не обрезается.

## Scope

In scope: `app/flashcards/use_video_card_save.ts` (+ чистое `video_card_save_core.ts`), `components/cards-grid/VideoCardSaveButton.tsx`, `VideoSetView.tsx` (кнопка на строке), `FlashcardListItem.tsx` (кнопка через контекст + расчёт кегля), `flashcards_collection.tsx` (провайдер для наборов из видео), `fit_phrase_font.ts`, тесты.
Out of scope: тренировка (`flashcards_swipe.tsx` правится другой сессией — размер текста в тренировке остаётся за ней), экран ролика (там своя кнопка уже есть), серверная часть.

## Architecture

Сохранение — существующий `addFlashcard` (локально-первое, дубль по английскому тексту, лимит Free/Plus), облако — прежний cloud_sync; отдельной записи на тап нет. Контекст `VideoCardSaveContext` кладёт сохранение в список карточек набора из видео. Кегль: чистая функция по длине и ширине (перенос по словам, шаг вниз до 14), без adjustsFontSizeToFit.

## Security and privacy

Новых данных не собирается: сохранённая карточка — обычная сохранённая карточка пользователя (уже покрыто политикой). Новых серверных правил нет.
