# condition_zero_first

Jesse rework pass for zero/first conditional training.

## Scope

- One microdiagnosis only: `condition_zero_first`.
- Keep the MVP contract: category `syntax`, priority `50`, locales `ru/uk`, 6+ examples, 12+ steps, guided recovery, mastery, Smart Trainer, and distractor-specific feedback.
- Preserve contract anchors:
  - `cond_zero_first_easy_001`: wrong `will boil` feedback mentions `boils`.
  - `cond_zero_first_contrast_004`: wrong `If it will rain tomorrow...` feedback mentions `If it rains`.
  - `cond_zero_first_contrast_006`: wrong `will finish` feedback mentions `if I finish`.
  - `cond_zero_first_mixed_002`: wrong `will get` feedback mentions `when I get`.

## Teaching Point

The learner should separate meaning first:

1. general rule: `If you heat water, it boils`
2. real future option: `If it rains, I will stay`
3. time/condition words: `when I get`, `unless you hurry`

## Copy Rules

- Visible RU/UK copy uses ASCII transliteration.
- Avoid learner-facing grammar labels such as `base verb`.
- Keep tested English anchors exactly.
- Contrast set and Smart Trainer keep the contract labels.

## Structure

- Easy: rules and habits.
- Contrast: future result with `will`, no `will` after `if`.
- Mixed: `unless`, `when`, set repair, full sentence repair.
