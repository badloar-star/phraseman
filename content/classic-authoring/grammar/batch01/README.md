# PhraseMan Classic · Español • Первая партия 01–03

Откройте `START.html` в браузере. Внутри три урока на одном экране, переключатель Русский / Українська, интро, Практика, Разбор, Словарь, Глагол: estar, Теория, Все 50 фраз. Установка и интернет для просмотра не нужны. Предпросмотр не требует аккаунта, не начисляет награды и не отправляет результаты на сервер. Для озвучки нужен установленный испанский системный голос; при его отсутствии сохраняется текстовая практика. Фразы можно слушать после ответа. Изменения языка и прогресс хранятся, когда браузер разрешает локальное хранение; это не облачный прогресс приложения.

## Содержание

| Урок | Что умеет ученик | Пример |
|---|---|---|
| ES-01. Местонахождение | Назвать человека или предмет и место. Выбрать форму estar по подлежащему. | Estoy en casa. / Las llaves están en la mochila. |
| ES-02. Отрицание | Опровергнуть предположение, поставив no непосредственно перед формой estar в изучаемых конструкциях. | No estoy en casa. / Las llaves no están en el bolso. |
| ES-03. Общий вопрос | Уточнить предполагаемое место, задав прямой вопрос с ответом «да» или «нет». | ¿Estás en casa? / ¿Están las llaves en la mochila? |

По 50 переводов с конструктором каждого слова. Другие виды заданий отсутствуют. Примеры, справочные сравнения, таблицы и разборы — читаемый материал, не отдельные задания. Все 50 канонических строк и ID первого урока сохранены, как и порядок, интро и теория согласованной версии. Уроки 2 и 3 имеют собственные банки и объяснения. Полоса прогресса считает завершённые фразы, не открытые объяснения; повтор не прибавляет второе завершение.

## Что получает мобильная команда

1. `manifest.json` — схема пакета, допустимый целевой язык, языки пояснений, перечень уроков, количественные итоги и SHA-256 экспортированных файлов. `lessons/ES-01.json` … `ES-03.json` — самостоятельные уроки с ID, целью, порядком показа, текстами, словарными ссылками и словесными плитками. Для раскрытия словаря нужен общий `ledger.json`. `phrase-audit.tsv` — построчная проверка без разработки. `programme.json` содержит также будущие темы, **не показывать их как выпущенные**. `NEXT.json` — следующее авторское задание.
2. Сохраните отдельный ключ `аккаунт × classic × es × lessonId/phraseId`; порядок `displayOrder` не идентифицирует фразу. Карточка для повторения определяется стабильной парой `es + senseId`, а не поверхностной формой или языком пояснений. `no` — отдельная запись, а no está — не новый глагол. Поля первого появления и примеры пересчитываются в порядке обучения. Внутри урока `new` и `seenBefore` не пересекаются; переключение RU/UK записей не создаёт. `formsSeen` в общем реестре показаны по всей партии; внутри урока показывайте только формы из доступных ученику фраз, как делает просмотрщик.
3. `classic-adapter/ES-XX.phrases.json` — уже подготовленные строки для типа `LessonPhrase`: `id`, `russian`, `ukrainian`, `spanish`, `alternativesEs`, `words` с `text/correct`, пятью `distractors`, категорией и `teachingNote`. Поле `english` заполнено вспомогательным переводом ради совместимости типа; это **не** английский учебный банк. Не регистрировать его для `en` и не показывать вместо испанского. В старом `app/phrase_target_utils.ts` есть условие на ES. Подключить адаптер к испанской классике явно; не включать глобальный dev-флаг ради обхода и не посылать данные в Learning V2.
4. Банки адаптера не заменяют полный урок: контекст обращения обязателен. До выбора первого слова передайте `context[uiLocale]` отдельной строкой (или присоедините к RU/UK подсказке, если экран пока не умеет показывать контекст отдельно). В частности, три одинаковых перевода «Вы дома?» требуют разных адресатов. Значения `acceptedExamples` и `alternativesEs` — перечень поддержанных естественных вариантов, не исчерпывающий каталог всех возможных переводов. Каноническая сборка тренирует один образец; не считать иные корректные порядки грамматическими ошибками. На шагах не предлагать как отвлекающий тот следующий токен, который продолжает один из зарегистрированных правильных вариантов.
5. Словесные плитки не содержат знаков «¿», «?» и «.». В начале используйте `punctuation.before`, в конце — `punctuation.after` без лишнего пробела. Для итоговой строки, TTS и проверки отображения — `targetText` с пунктуацией и ударениями. При нажатии «Почему так?» сохранить ID фразы и индекс слова и восстановить оба при возврате. Не засчитывать ошибку и не списывать попытку за справку или недоступный голос.
6. До практики показать `intro` (3 экрана, ссылки на реальные примеры). `theory` отображать отдельно без необходимости завершить интро. В `verbs` — полная таблица шести личных форм с примерами именно из текущего урока и применением в утверждении, отрицании или вопросе. Разбор фразы состоит из согласования, изучаемой операции и места; у каждого слова — собственное пояснение на RU/UK. Идентификаторы в `intro`, `theory`, `verbs`, словаре и шаблонах перехода указывают на одни и те же фразы.
7. Системная озвучка испанского на устройстве; не требовать облачных MP3. В приложении переиспользовать его настройки скорости и повтора, доступ, действующую экономику и синхронизацию прогресса. Предпросмотр — не реализация этих мобильных механизмов. JSON можно включить в тестовую сборку без сторонних ключей. Не изменять продакшн-флаги, английские данные или покупки при импорте.

## Приёмка при переносе

Проверить на iOS и Android: RU/UK; 50 фраз на экран урока; первая/последняя фразы; возвращение из Теории к тому же слову; два знака вопроса в ES-03 без лишней точки; отсутствие выдачи ответа в вопросе; группы на usted/ustedes/vosotros; уже сохранённая карточка estar без дубля; отказ в TTS не блокирует практику. 150 фраз — содержание партии, **не доказательство достижения уровня A1 и не гарантия оптимального порядка для каждого ученика**. Независимая вычитка преподавателем и пользовательский пилот не выполнены в составе программных тестов.

## Воспроизведение и продолжение

Из корня актуального репозитория: `python3 -B content/classic-authoring/grammar/batch01/compile_batch.py --out /tmp/phraseman-batch-new` (новая пустая папка). В архиве те же исходники лежат под `source/grammar/`: `python3 -B source/grammar/batch01/compile_batch.py --out preview-new`. Необходим Python 3.10+. Тесты: в `batch01/` выполнить `python3 -B -m unittest -v test_package`, а затем `python3 -B smoke.py /путь/к/START.html` при установленном Chrome/Chromium. Команды не публикуют файлы, не обращаются в Firebase и не меняют приложение. Для учебного материала использовать `batch01` поверх принятой базы ES-01: старый экспорт только одного урока и прототип-разговорник не являются текущей партией. Следующий урок — **ES-04: утвердительный ser для имени, профессии и роли**. Не вводить заново существующие леммы, использовать ledger этой партии. Для ES-04 требуется новый валидатор грамматики, а не расширение проверки estar на все глаголы.
