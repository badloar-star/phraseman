## Architecture

- Начисление — только сервер. Значения берутся из серверных полей:
  - опыт — `progressServerState.totalXp`;
  - жемчуг — `users.shards`;
  - вращения — `levelSpinServerState.balance`.
- Операции идут через `commitStarOperations` с opId `legacy_bonus:v1:<валюта>:<id>`.
- Метка на документе — в той же транзакции.
- Уровень онбординга:
  - callable пишет один ответ на stableId, идемпотентный ключ;
  - дневной документ-агрегат увеличивается через `FieldValue.increment`;
  - админка читает дни, а не пользователей.
