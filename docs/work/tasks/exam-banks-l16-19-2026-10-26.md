## Outcome

## Scope
Файлы modules/learning-v2/exam/banks/chapter_exam_v2_lNN_cC.ts (28 штук), читабельные docs/work/exam-banks/lNN.md, строки в docs/work/exam-banks/PROGRESS.md. Общие файлы (список BANKS, тесты) не трогаем: авто-подключение из папки делает Learning V2.

## Architecture
Тип ChapterExamV2Bank из modules/learning-v2/exam/chapter_exam_v2.ts, образцы chapter_exam_v2_l01_c1..c3.ts. Банки пишутся из компактного описания скриптом-генератором (вне репозитория), результат — обычные файлы TypeScript без логики. Проверка слов — по выпуску курса content/learning-v2-course/release/en.

## Security and privacy
Данных пользователя нет: только учебные фразы. Политику не меняет.

## Technical debt
Новых долгов нет. Известное ограничение: проверочный тест запрещает знак вопроса в репликах и ответах, поэтому вопросительные формы глав («Shall I...») в экзамен не входят — их смысл проверяется предложениями с I will и I am going to. Когда Learning V2 снимет запрет, банки можно дополнить вопросами отдельным коммитом.
