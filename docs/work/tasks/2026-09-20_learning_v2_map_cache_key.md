даёт промах кэша и заново строит 2048 строк с ~4200 строковыми аллокациями —

Мера успеха: замер — поле `expanded` не используется ни в одном потребителе;

## Architecture

Замер (grep по всем потребителям): `row.expanded` и `.expanded` **не читаются
нигде** — ни в карте, ни в экране уроков, ни в Horizons. Поле осталось от
отменённого 20.09 аккордеона, где оно решало, показывать ли занятия урока.

При этом `expandedLessonOrdinal` входит в ключ `projectionCache`
(строка 197), поэтому смена значения = промах кэша = полная пересборка:
2048 `Object.freeze`, 1792 вызова `learningV2CourseSessionIdV1` со сборкой
строк, 1792 поиска в Set, 1792 вызова `learningV2CourseSessionRoleV1`.

Решение: убрать поле `expanded` из строки `lesson` и `expandedLessonOrdinal`
из ключа кэша и из входных типов. Тем, кому понадобится «какой урок в
фокусе», вычислят это в компоненте сравнением `row.lessonOrdinal`.

Инвариант: при неизменном прогрессе и scope модель строится ровно один раз
за сеанс, независимо от навигации по карте.
