# Сторож арта 2.0: не пускать в сборку тяжёлые картинки и картинки без настоящей прозрачности

Governance-ID: TG-EA267FED84D7
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (задача координатора: Codex положил spire_tile/cards_* по 1,7 МБ с нарисованной шахматкой вместо альфы; владелец отверг)

## Outcome
Генератор реестра арта (scripts/gen_themed_art_assets.mjs) отказывается регистрировать файл из assets/images/v2art/{dark,light}/, если он больше 400 КБ или у него непрозрачные углы (нет настоящей альфы), и пишет причину `[THEMED-ART-GUARD]`. В themed_art_assets.generated попадают только годные файлы; режим --check падает при отвергнутом файле. Тест сторожит и сами файлы в репозитории.

## Scope
scripts/gen_themed_art_assets.mjs (функция guard, фильтр в scan), tests/themed_art_guard.test.ts (новый). Код реестра и экранов не меняется; слот spire_tile и переход плиток на resolveThemedArt остаются.

## Architecture
Проверка размера по stat; прозрачность — sharp: углы 4×4 пикселя во всех четырёх углах, максимальная альфа ≤ 16 из 255. Сторож — отдельная async-функция checkArtFile; scan принимает множество исключённых файлов.

## Security and privacy
Локальный скрипт сборки, данных пользователя нет.

## Technical debt
Порог 400 КБ — по поручению координатора; текущие файлы ≤ 159 КБ. Проверка «углы прозрачны» не ловит арт с непрозрачным фоном при прозрачных углах — достаточно для шахматки.

## Verification
Новый тест на синтетических картинках (годная; тяжёлая; без альфы; шахматка) и на всех v2art в репозитории; node scripts/gen_themed_art_assets.mjs --check.
