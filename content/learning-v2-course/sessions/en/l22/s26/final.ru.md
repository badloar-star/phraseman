# Английский · Урок 22 · Занятие 26 — Удобные вещи на каждый день

**Ситуация.** Вы выбираете вещи для тепла и удобства.

**Что вы освоите:** determiner|adjective + one|ones
**Новые слова:** thermal, padded, non-slip, cushioned

## Интро 1

### Тёплые носки

Thermal в описании одежды — сохраняющий тепло, например thermal socks для холодной погоды. Выбираем носки: socks стоит во множественном числе, поэтому the thermal ones. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I want the thermal ones.**
- ❌ I want the thermal one. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I want the thermal them. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 2

### Мягкая куртка и коврик

Padded — с мягкой набивкой, например куртка с утепляющим слоем. Non-slip — нескользящий, например коврик с поверхностью, которая меньше скользит. В примерах куртка и коврик по одному: one. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ❌ I prefer the padded it. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 3

### Мягкая подкладка

Cushioned — с мягкой подкладкой или слоем, который смягчает давление. В примере выбираем обувь с мягкой опорой для стопы. Shoes — множественное число, поэтому the cushioned ones. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.
