## Architecture

- `isRepeatPromotion = promoted && prevTier ≥ 1`. Лига стартует с 0, данные — из того же документа итога недели: 0 чтений, без истории.
- Допущение «вылетел на 0 и снова поднялся = первое» принято координатором.
- Поле в типе необязательное: тестовые заготовки Дизайна собирают решение руками, а гейт задаёт поле всегда.

## Security and privacy
