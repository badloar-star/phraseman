Прогон состояний

Тап по ЛЮБОЙ точке телефона мгновенно завершает всю церемонию (финальное состояние без анимаций). Тап по пустой (незажжённой) звезде показывает условие в зарезервированной полосе под звёздами: это единственный интерактив после завершения церемонии, кроме кнопок дока.
