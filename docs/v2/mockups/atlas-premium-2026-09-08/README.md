# Learning V2 — Горизонты

## Ревизия 2: миры и заработанные руны

Текущий вариант — `standalone.html`. Вход заменён на «Горизонты»: один крупный мир, соседние направления, перелистывание жестом/стрелками, быстрый список всех 32 уроков и отдельное продолжение текущей сессии. Исходный каталог сохранён по кнопке «Сравнить с первым вариантом». Словарь, история пути, маршруты, начало занятия и отдельный checkpoint сохраняются.

Выбор среди «Библиотеки миров», «Экспедиции» и «Горизонтов»: у последнего нет метафоры хранения или тяжёлой игры. Каждый урок обозначает доступное умение. Один объект в фокусе снижает визуальную конкуренцию, быстрый список устраняет необходимость листать весь курс. Объём создают обод, свет, глубина рельефа и ступени. Семь палитр используют общие роли цвета; цвет не заменяет подписи состояния. Светлые CTA имеют тёмный текст.

Переход в мир длится 1450 мс: короткая фиксация портала, движение камеры внутрь, раскрытие маршрута. Переключение мира — 650 мс. Руны собираются в счётчик; после задержки 220 мс сумма растёт 1050 мс с замедлением. Повтор обоими способами воспроизводит тот же результат. Смена сцены отменяет переход, уход со вкладки завершает счётчик, reduced motion сразу показывает итог. Фокус сохраняется при перелистывании клавиатурой.

- `components/LearningV2CheckpointOutcome.tsx`: отдельные «Закрепилось» и «Стоит повторить», без потери предыдущего прогресса.

Числа 54 / 43 / 0 — демонстрационные результаты, а не пользовательские данные. Для каждого проверена сумма рун и качество в звёздах. Не добавлены неподтверждённые выдачи XP, spin, gifts или множителей. Реального баланса и сетевых операций в макете нет. Кнопка повтора анимации принадлежит демонстрации.

1. Коллекция 32 карт с четырьмя диапазонами курса, видимыми названиями грамматических тем и отдельной художественной идентичностью.
2. Карта урока: 7 глав × 8 узлов, завершённый / текущий / будущий / закрытый; разные маршруты глав, словарь, возврат, продолжение.
3. Обычный старт: подъём нижней карточки 480 мс. Checkpoint: центральные ворота, створки 760 мс. Итоги: знак + последовательное появление метрик; новая глава и завершение урока имеют свои сцены.
4. Проверить браузером взаимодействия, узкий экран, клавиатуру, отсутствие переполнения и reduced motion. Никаких production вызовов или настоящего начисления наград.

## Дизайн

Выбран атмосферный атлас вместо стеклянной панели или обычной сетки карточек. Семь палитр: нефрит, прилив, терракота, ирис, янтарь, ледник, розовый кварц. В каждой есть тёмная подложка, три уровня рельефа, светлый акцент и читаемые нейтральные тексты. Тёмные надписи на светлых кнопках. Номер, форма, подпись и состояние дублируют цветовую семантику.

Карта сохраняет последовательную учебную зависимость. Разные изгибы огибают острова; они не предлагают ложных альтернатив в учебном плане. Контрольные узлы — арки вместо круглых кнопок. Рельеф — авторский SVG с несколькими слоями, без тяжёлых изображений и WebGL. Типографика — локальный Inter с системным fallback; выразительность достигается масштабом, ритмом, пространством и материалами.

## Перенос в приложение

| Макет | Нативная реализация |
|---|---|
| Палитры | Семантические токены темы |
| SVG-острова и маршруты | react-native-svg, фиксированный viewBox |
| Свет, дыхание, press | Reanimated, UI thread; transform/opacity |
| Карточка старта | Modal/существующий sheet, spring |
| Створки checkpoint | Два SVG/View слоя с translateX |
| Сборка знака | SVG-группы + stagger transform/opacity |
| Атлас | FlatList, виртуализация; одна открытая глава |
| Фоновое движение | Только видимый экран + активное приложение |

Нативную производительность этот HTML не доказывает. Перед интеграцией нужны измерения на Android, безопасные отступы, восемь локалей и сверка с существующими правилами доступа/результатов. Веб-анимация штриха маршрута при переносе может быть заменена коротким reveal-mask; фоновые тени не анимируются. Нажимаемые области фиксированы. Reduced motion сразу показывает финальную геометрию; скрытая вкладка останавливает движение.
