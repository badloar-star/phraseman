## Вопросы владельцу

1. **Шпиль — только в ru и uk.** Он виден только при интерфейсе ru/uk (4b5162622), поэтому в остальных 7 языках его нет. Согласен?
2. **«Интерфейс теперь и на английском».** Для ru/uk/es и других это новость-«плюс», а не главное. Можно убрать, если текст покажется длинным.
3. **Голос в Диалогах.** Упомянут без лимита. У Free 3 голосовые попытки в день (D165) — в «Что нового» лимиты обычно не пишут.
4. **Термины** совпадают с приложением: vi «bộ thẻ», pl «zestaw», pt-BR «pacote», tr/id «paket», es «pack». Переводы vi/id/tr/pl/pt-BR носителем не проверены.
