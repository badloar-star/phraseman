# Пейвол v3 «Атриум» — большой ресёрч, аудит v1/v2 и план самого конвертящего пейвола
**Дата:** 2026-06-11 · **Статус:** ресёрч + концепция + план (код не написан)
**Макеты:** `docs/design/paywall_v3_mockups_2026-06-11.html` (открыть в браузере)

---

## 0. TL;DR

1. **Сейчас живут два пейвола**: v1 (прод, длинный скролл, 4 966 строк, 26 контекстов, 8 языков) и v2 (компакт без скролла, RU-only, A/B ~50%). A/B между ними **методологически сломан** и ответа «скролл vs не скролл» не даст (§3).
2. **Ресёрч (40+ источников, 4 параллельных агента)** говорит: побеждает не «скролл» и не «компакт», а **гибрид** — всё решающее в первом экране, доказательства ниже фолда, CTA закреплён поверх скролла (§5–6).
3. Самые подтверждённые рычаги конверсии 2024–2026: **таймлайн триала** (Blinkist: +23% к стартам триала, жалобы −55%), **годовой план по умолчанию + цена/день** (+15–20%), **специфичное соцдоказательство** (точные числа, рейтинг 4.2–4.5 правдоподобнее 5.0), **локализация** (62% побед в тестах — выше всех категорий). Toggle-триал Блинкиста **мёртв: Apple отклоняет с 01.2026** (Guideline 3.1.2).
4. **Комплаенс-чистка обязательна до любого редизайна**: фейковая «удвоенная цена» в urgency, хардкод «47 000+ учеников» и неверифицированный отзыв в v2 — прямой риск ревью (2.3.1/3.1.2/5.1.1) и доверия (§2.4, §7).
5. **Дизайн v3 «Атриум»**: один экран-«атриум» (контекст-герой → 2 плана с таймлайном → CTA) + «галерея доказательств» под фолдом + sticky-CTA. Дорогой вид достигается сдержанностью: уголь + шампань, один акцент, воздух, микро-движение вместо ярмарки (§6).
6. **План — 8 фаз** от комплаенс-чистки и честного A/B-фундамента до полировки и метрик (§8).

### 1.2 Скрытая механика v1

- **Exit-офер** (`requestPaywallClose`): при закрытии без покупки — модалка «возьми триал» (для избранных контекстов). Деликатный второй шанс.
- **Manage-режим** для подписчиков (план, дата, отмена с опросом причин).
- **8 языков** через `LP()` (ru/uk/es/pt-BR/vi/id/tr/pl).
- Полная воронка событий: `paywall_shown → plan_select → cta_click → purchase_started → completed/failed/cancelled` + legacy `logPaywall*`.

### 1.3 Диагноз v1

**Сильное:** контекстность (26 входов), персонализация (теги, зеркало, перцентиль), честные сторовские цены, exit-офер, i18n, аналитика.
**Слабое:**
- **Слишком длинно**: 10+ секций до карточек планов; цена и CTA глубоко под фолдом. На 360×800 пользователь должен проскроллить ~3 экрана до цены.
- Визуальный шум: 5 типов карточек с разными рамками, 3 уровня бейджей, эмодзи везде → «ярмарка», не «бутик».
- Сравнительная таблица — 9 строк мелкого текста 10px (нечитаемо, давит).
- Рейтинг «4.8 · 10 000+ оценок» — хардкод, источник не указан.
- Монолит на 5к строк — править страшно, A/B-вариации внутри файла невозможны.

## 2. Аудит v2 — `app/premium_modal_v2.tsx` (A/B ~50%, «компакт»)

### 2.1 Порядок блоков

Headline («Заговори. Не останавливайся.») → персональные теги → соцкарта (★4.9 + «47 000+ учеников» + отзыв) → urgency-полоса (таймер + «персональная цена») → **2 плана** (Год pre-selected, «ХИТ», −N% из реальных цен, цена/мес крупно; Месяц как якорь) → 4 бенефита-результата → CTA («Начать бесплатно»/«Открыть полный доступ») → «Отмена в любой момент» → футер (Условия · Конфиденциальность · Восстановить).

### 2.2 Что v2 делает правильно

- Цена и CTA **видны без скролла** почти на любом экране.
- Годовой по умолчанию + якорь месячной цены + реальный «−N%» из цен стора (T-21/T-01/T-35).
- CTA честный: «Начать бесплатно» только если стор реально отдал intro phase.
- Бенефиты как результаты, а не фичи («Занимайся в самолёте и метро — без интернета»).
- Аккуратный тёмный стиль с тема-конфигом `paywallThemeConfig` (7 тем).

### 2.3 Чего v2 лишился (и что, вероятно, режет его конверсию)

| Потеря vs v1 | Последствие |
|---|---|
| Контекстные заголовки/герои (26 → 1 generic) | боль юзера не отражена: пришёл за энергией — видит «Заговори» |
| **Только русский** (LP() нет) | uk/es/pt-BR/vi/id/tr/pl видят русский текст; локализация — категория №1 по победам в A/B (62%) |
| Exit-офер при закрытии | теряется «второй шанс» — у v1 он есть, у v2 нет → сам A/B нечестный |
| Зеркало прогресса, перцентиль, сравнение Free/Premium | нет endowment и рациональных доказательств |
| Trial ribbon + «затем …₽/год» возле CTA | у CTA «Начать бесплатно» не видно, что будет после триала (слабее по доверию и по 3.1.2-гигиене) |
| Manage-режим | ок (роутится в v1), но это значит: v2 — только покупка |

### 2.4 Красные флаги обоих (комплаенс/честность) — чинить ДО редизайна

1. **Фейковая «удвоенная цена»** (`getDoubledPrice` ×2 → зачёркнутая) в v1 и v2: вымышленная «старая цена» = классический dark pattern; риск App Review 2.3.1/2.3.2 + FTC/EU; доверие падает. Ресёрч: подтверждённого прироста у фейк-таймеров НЕТ (§4.5).
2. **«47 000+ учеников» и «★4.9»** в v2 — хардкод без источника, противоречит v1 («4.8 · 10 000+»).
3. **Отзыв в v2 захардкожен** («За месяц поняла первый сериал…») — это **черновик** из `paywall_testimonials.ts` с `verified:false` и DRAFT-маркером: анти-фейк гард обойдён копипастой. В v1 такой отзыв в прод не попал бы.
4. Таймер «Персональная цена — истекает через…» при том, что цена после «истечения» не меняется — манипуляция, которую юзер проверит за день.

## 3. Почему текущий A/B (v1 vs v2) не отвечает ни на один вопрос

1. **Двойной `paywall_shown`**: v1 на маунте синхронно шлёт `paywall_shown(paywall:'v1')`, и только потом асинхронный `AsyncStorage.getItem('paywall_variant')` делает `router.replace('/premium_modal_v2')`, где летит второй `paywall_shown(paywall:'v2')`. Все v2-юзеры засчитаны и как v1-показы → знаменатель v1 раздут, его конверсия занижена.
2. **`Math.random` на устройстве** (premium_modal.tsx:1679), а не хэш stableId: переустановка/новое устройство = новый вариант; в аналитике один юзер мешает обе ветки. (Уже флагалось в аудите экономики.)
3. **v2 до недавнего фикса вообще не слал событий** — окно A/B до фикса невосстановимо.
4. **Неравные условия**: v2 без exit-офера, без локализации, без контекстных копирайтов — сравниваются не «скролл vs компакт», а «полный набор оружия vs усечённый».
5. Нет kill-switch и нет фиксации варианта в профиле → нельзя ни выключить, ни сегментировать ретроспективно.

**Вывод:** результаты текущего A/B читать нельзя. v3 начинается с честного фундамента эксперимента (§8, Фаза 1).

Легальная замена = таймлайн триала + явный CTA ([RevenueCat «RIP toggle paywall»](https://www.revenuecat.com/blog/growth/rip-toggle-paywall/)).

### 4.2 Кейсы топов (что реально стоит на их экранах)

- **Duolingo Super/Max** — компактный пейвол 1–2 экрана, перед ним многоэкранная карусель ценности; всего 2 плана (Individual + **Family как якорь**); «Start my free week»; маскот-анимация; **без таймеров, без таблиц сравнения**. Подписки = 85% выручки Q2 2025.

- **Calm** — дорогая минималистика, эмоция; дорогой месячный показан первым, чтобы годовой казался дешёвым, «SAVE 85%».

- **Speak ($2.8M/мес)** — соцдоказательство как двигатель: «5 million users», «4.8 ★ (140k reviews)» прямо на пейволе; квиз → персональный план → пейвол.

- **CapCut** — клип-демо на каждую фичу; **FitOn** — видео для новичков, простая карусель для вернувшихся.
- Паттерн победителей: **инвестиция юзера до пейвола → годовой первым → прозрачный триал → соцдоказательство на самом экране → пост-покупочный праздник**. Таймеры — нет.

## 5. ВЕРДИКТ: скролл с большей инфой или без скролла?

**Прямого победителя в индустрии нет — есть правило и матрица.**

Данные с двух сторон:
- За длинный: кейс OMENA — лендинг-пейвол (отзывы+фото+FAQ+история фаундера) **удвоил старты триала**; длинный выигрывает на холодном трафике, дорогой годовой цене, сложном продукте ([Airbridge](https://www.airbridge.io/en/blog/paywall-conversion-structural-decisions), [Apphud](https://apphud.com/blog/design-high-converting-subscription-app-paywalls)).
- За компакт: чек-лист Adapty-2026 прямо содержит пункт «влезает ли в один экран»; задокументирован тест, где одностраничник побил многостраничник; **layout-тесты — самая слабая категория (34.6% win-rate)** — структура (цена/триал/момент показа) важнее длины ([Adapty 2026](https://adapty.io/blog/high-performing-paywall-2026/)).
- Несокрушимое правило (0 противоречий во всех источниках): **цена и CTA видны без скролла — всегда**; для длинных — sticky-CTA (в e-commerce sticky-бар даёт +31% конверсий, 58M сессий).
- % скроллящих пейвол: публичной агрегированной цифры нет; Adapty советует мерить scroll-depth у себя (если медиана 25% — всё важное должно жить выше).

**Решение для Phraseman — гибрид «Атриум», и вот почему по матрице:**

| Фактор Phraseman | Что советует матрица |
|---|---|
| Трафик тёплый: пейвол открывается из 26 in-app триггеров ПОСЛЕ ценности (нет холодных ad-лендингов) | → компактное ядро |
| Покупка обдуманная: годовой ~half выручки, education, цена ≈ $45/год | → доказательства должны существовать |
| `intro_ended` (главный момент конверсии) = юзер 72ч видел всё | → ядро решает, но возражения («а вдруг забуду отменить») снимает таймлайн+FAQ |
| Соцдоказательств верифицированных пока 0 | → длинный «лендинг» строить не из чего; копим (Фаза 6) |

**Формула v3:** первый экран полностью самодостаточен (никто не ОБЯЗАН скроллить) + «галерея доказательств» ниже фолда для сомневающихся + sticky-CTA при скролле. Это снимает спор v1-vs-v2: компакт и глубина перестают быть взаимоисключающими. A/B потом честно измерит, сколько добавляет галерея (§8, Фаза 7).

## 6. Дизайн v3 «Атриум» — самый дорогой и конвертящий

> Дорого ≠ больше золота. Дорого = меньше, но точнее: один акцент, воздух, тонкие линии, медленный свет. Ярмарочные бейджи и пляшущие таймеры выглядят дёшево и снижают доверие — а доверие и есть конверсия (Blinkist доказал: снятие страха > перечисление фич).

### 6.1 Первый экран (атриум — без скролла самодостаточен)

```
┌─────────────────────────────────┐
│ ✕                        (44px) │
│  [глиф контекста в капсуле]     │ ← компактный hero: глиф + аврора-свечение,
│  Энергия не должна              │   ЗАГОЛОВОК ПО КОНТЕКСТУ (26 копирайтов v1)
│  заканчиваться                  │   28–30px / -1.5ls / weight 800
│  Ты занимался 6 дней подряд —   │ ← 1 строка ЛИЧНОЙ правды (теги v1, max 1)
│  Premium не даст остановиться   │
│                                 │
│  ── Таймлайн триала ──          │ ← ЭЛЕМЕНТ №1 ПО ДАННЫМ:
│  ● Сегодня — полный доступ      │   3 шага, вертикально, иконки SVG
│  ○ День 2 — напомним пушем      │   (рендер только при реальном introPhase)
│  ○ День 3 — спишется 299 ₽/мес  │
│                                 │
│  ┌───────────────────────────┐  │
│  │ ГОД  −62%   249 ₽/мес     │  │ ← выбран; цена/мес крупно, под ней
│  │ 2 990 ₽ раз в год · 8₽/день│  │   полная цена года + цена/день
│  └───────────────────────────┘  │
│  ┌───────────────────────────┐  │
│  │ Месяц        649 ₽/мес    │  │ ← якорь, визуально тише
│  └───────────────────────────┘  │
│                                 │
│  [ Попробовать 3 дня бесплатно ]│ ← CTA cream→champagne, тёмный текст,
│   затем 2 990 ₽/год · отмена    │   медленный shine 3с; под ним честный
│   в любой момент                │   сабтекст с ценой (3.1.2-гигиена)
│  Восстановить · Условия · Конф. │
│  Продолжить бесплатно (ghost)   │
└─────────────────────────────────┘
   ↓ ниже фолда — для сомневающихся
```

### 6.2 Галерея доказательств (ниже фолда, опциональный скролл)

Порядок — от личного к рациональному (endowment → proof → objection):
1. **«Уже твоё»** — зеркало прогресса (фразы/XP/серия) + «Premium держит этот темп» (из v1).
2. **Перцентиль** «Ты упорнее 88% учеников» — честное соцдоказательство из СВОИХ данных (пока нет verified-отзывов — никаких «47 000+»).
3. **Сравнение Free → Premium, сжатое до 5 строк** (уроки/энергия/квизы/карточки/серия), шрифт ≥12px.
4. **Отзывы** — рендер ТОЛЬКО `verified:true` (анти-фейк гард уже есть); до их появления секция не существует.
5. **FAQ — 3 вопроса**: «Что будет после триала?» / «Как отменить?» (с шагами!) / «Что входит?» — прямая монетизация инсайта Blinkist про страх.
6. Повторный CTA + футер.
**Sticky-CTA**-бар (цена + кнопка) появляется, как только главный CTA уходит за экран.

### 6.3 Язык дорогого (дизайн-токены)

| Токен | Значение | Зачем |
|---|---|---|
| Фон | вертикальный уголь `#0B0904 → #141008` + золотая аврора 8% сверху + зерно 3% | глубина OLED, тепло Компаса |
| Акцент | ОДИН: cream `#FFE7B6` / champagne `#F2C48D` (COMPASS_RICH); всё прочее — монохром | моноакцент = люкс; пёстрое = ярмарка |
| Линии | hairline 1px `rgba(248,215,163,.14/.23)` | тонкость = цена |
| Карточки | `#202022` raised, радиус 16, выбранная — champagne-рамка + wash 10% | как в paywallThemeConfig.compass |
| Типографика | Inter: H 28–30/800/-1.5ls; цены tabular-nums; body 15/1.5 | системная скорость, дорогая плотность |
| Иконки | только SVG-глифы 1.5px stroke (без эмодзи в v3-хроме) | эмодзи удешевляют |
| Движение | вход stagger 500–600мс cubic; glow «дыхание» 4с; shine CTA раз в 3с; всё под `prefers-reduced-motion` | медленно = дорого; быстро = базар |
| Касания | все цели ≥44px; haptic на план/CTA | стандарт |

### 6.4 Что из v1/v2 берём, что хороним

| Берём | Откуда |
|---|---|
| 26 контекстных копирайтов + LP() 8 языков | v1 |
| Персональные теги (1 шт. в hero), зеркало, перцентиль | v1 |
| Exit-офер с реальным триалом | v1 |
| Годовой default + реальный −N% + якорь месяца + цена/день | v2/v1 |
| Честный CTA («бесплатно» только при introPhase) + цена под CTA | v2+v1 |
| Тема-конфиг 7 тем (`paywallThemeConfig`) | v2 |
| **Хороним** | фейковая удвоенная цена и «персональная цена истекает»; хардкод «47 000+ / 4.9»; DRAFT-отзыв; 9-строчная таблица 10px; эмодзи-зоопарк; 3 уровня бейджей |

## 7. Комплаенс-чеклист v3 (после ресёрча — обязательный)

- [ ] Никаких выдуманных «старых» зачёркнутых цен (EU Omnibus: «was»-цена = минимум за 30 дней; FTC: до $50 120 за нарушение; фейк-таймеры — в топ-10 dark patterns FTC).
- [ ] Таймер — только если есть РЕАЛЬНЫЙ intro-offer с реальным сроком из стора.
- [ ] Никакого toggle-триала (Apple reject с 01–02.2026).
- [ ] Цена/период/автопродление — крупно, не в сноске (3.1.2); «Try Free» в метаданных без честного триала — reject (2.3).
- [ ] Restore + Terms + Privacy на экране (есть в v1/v2 — сохранить).
- [ ] Отзывы — только реальные (`verified:true`), числа юзеров — только подтверждаемые.

## 8. БОЛЬШОЙ ПЛАН внедрения (8 фаз)

> Принцип очерёдности: сначала честность и измеримость (Ф0–Ф1), потом самый подтверждённый элемент (Ф2), потом каркас и мясо (Ф3–Ф6), потом честный эксперимент (Ф7) и фронтир (Ф8). Каждая фаза — отдельный коммит(ы) в master, без веток.

### Фаза 0 — Комплаенс-чистка (немедленно, 0.5 дня)
- Убрать из v1+v2: `getDoubledPrice`-зачёркивания, «Персональная цена — истекает», «🔒 Зафиксировали старую цену».
- v2: убрать «47 000+ учеников», «4.9», захардкоженный DRAFT-отзыв (рендерить из `pickTestimonials(verified-only)` → т.е. пока ничего).
- v1: рейтинг «4.8 · 10 000+ оценок» — либо реальная цифра стора, либо убрать.
- Файлы: `app/premium_modal.tsx`, `app/premium_modal_v2.tsx`, `app/paywall_urgency.ts` (оставить только функции таймера для будущих РЕАЛЬНЫХ офферов).
- Верификация: grep по `getDoubledPrice` = 0 вызовов в рендере; тесты paywall_* зелёные.

### Фаза 1 — Честный фундамент эксперимента (1 день)
- Вынести выбор варианта в `app/paywall_variant.ts`: детерминированный хэш `stableId` + override из Remote Config (`paywall_variant_override`: off/v1/v2/v3 + проценты) + kill-switch.
- Резолвить вариант ДО навигации (в `premium_guard.ts`/точках входа) — **убрать двойной `paywall_shown`** (v1 не должен маунтиться для v2-юзеров).
- `paywall` (variant) во ВСЕ события воронки; записать вариант в профиль (`users/{id}.paywall_variant`) для сегментации.
- Тест: `tests/paywall_variant.test.ts` (стабильность хэша, отсутствие двойных событий).

### Фаза 2 — Таймлайн триала + честные пуши (1–1.5 дня)
- Компонент `components/paywall/TrialTimeline.tsx`: 3 шага из РЕАЛЬНОГО `introPrice` (длительность из стора, не хардкод «3 дня»).
- Локальный пуш «напомним за день до списания» — реально планировать при `trial_started` (expo-notifications уже в проекте: notifications.ts). Это даёт и opt-in пушей (Blinkist: 6%→74%).
- Включить таймлайн в v1 и v2 СРАЗУ (до v3) — самый дешёвый подтверждённый прирост.
- Тест: таймлайн не рендерится без introPhase; даты считаются от длительности intro.

### Фаза 3 — Каркас v3 «Атриум»: первый экран (2–3 дня)
- Новая структура: `app/premium_modal_v3.tsx` (<800 строк) + `components/paywall/`: `PaywallHero`, `PlanCards`, `TrialTimeline`, `PaywallCta`, `PaywallFooter`, `paywallCopy.ts` (26 контекстов, LP()).
- Дизайн-токены из §6.3 поверх `paywallThemeConfig` (расширить конфиг: aurora, hairline, grain).
- Без скролла самодостаточен на 360×800; e2e-скрин на iPhone SE габарите.
- События: `paywall_shown{paywall:'v3'}` и вся воронка с первого дня.

### Фаза 4 — Галерея доказательств + sticky CTA (1–2 дня)
- `ProofGallery`: зеркало («Уже твоё»), перцентиль, сравнение 5 строк, FAQ (3 вопроса), повторный CTA.
- Sticky-CTA бар по onScroll (появление после ухода главного CTA), c ценой выбранного плана.
- События скролла: `paywall_scroll_depth` (25/50/75/100) — наконец узнаем, сколько наших юзеров вообще скроллит.

### Фаза 5 — Контекст и язык (1–2 дня)
- Перенести 26 копирайтов v1 + до-писать по Библии стиля («заниматься», без self-blame), 1 личный тег в hero.
- LP() на все строки v3 (8 языков) — локализация = категория №1 по win-rate.
- Exit-офер v1 подключить к v3 (тот же `paywall_trial_offer.ts`).

### Фаза 6 — Реальное соцдоказательство (фоном, 2–4 недели календарно)
- Сбор verified-отзывов: in-app промпт после сильных моментов (экзамен сдан, серия 30) с согласием на публикацию → админка-модерация → `verified:true`.
- Реальный рейтинг стора (если ≥4.2) — подтянуть и показать с источником.
- До появления — секции отзывов в v3 просто нет (правило «не выдумывать»).

### Фаза 7 — Честный A/B v3 vs v1 vs v2 (запуск после Ф3–Ф5)
- Сплит 34/33/33 по хэшу stableId; min 2 недели или N покупок на ветку (рассчитать по текущему трафику пейвола из PostHog).
- Главная метрика: paywall_view → trial_start и → purchase D7; guardrails: refund rate, close-rate, жалобы.
- Через RC можно мгновенно перекинуть 100% на победителя.

### Фаза 8 — Фронтир (по очереди, каждый — отдельный A/B)
1. Анимированный hero (Reanimated-глиф/линза, НЕ Lottie — стек проекта) — кандидат «+80%» с одним источником.
2. Длина триала 3 vs 7 дней (бенчмарк: длиннее = выше trial→paid, но смотреть экономику).
3. Weekly-план третьим (education weekly = 52% выручки категории — но ретеншн 10%@12мес: только тест).
4. Apple win-back offers (iOS 18) + «пауза вместо отмены» в manage-режиме (75% пауз возвращаются).
5. Видео-отзыв/демо-клипы фич (CapCut-паттерн).
6. Pre-paywall карусель ценности (Duolingo-паттерн) для `course_after_lesson3`.

### Definition of Done v3
- [ ] 0 хардкод-цен, 0 фейк-скидок, 0 неверифицированных чисел
- [ ] Первый экран: цена+CTA видны на 360×800 без скролла во всех 7 темах
- [ ] Полная воронка событий с variant + scroll_depth
- [ ] tsc/тесты зелёные, e2e-скрины 3 габаритов
- [ ] A/B запущен с kill-switch

## 9. Метрики успеха (что считаем победой)

| Метрика | Бейслайн | Цель v3 |
|---|---|---|
| paywall_view → trial_start | измерить после Ф1 (сейчас данные грязные) | +25–40% к чистому бейслайну (эффект таймлайна+структуры) |
| trial_start → paid | сравнить с медианой education 25.6% | ≥ медианы; топ-квартиль 60% как звезда |
| paywall_view → purchase (без триала) | измерить | + к бейслайну при не-росте refund |
| Refund/жалобы | текущий | не выше; ожидаем снижение (честность) |
| Push opt-in после триал-пуша | текущий | кратный рост (Blinkist: 6%→74%) |
| Доля скроллящих галерею | неизвестна (впервые замерим) | инсайт для итераций |
