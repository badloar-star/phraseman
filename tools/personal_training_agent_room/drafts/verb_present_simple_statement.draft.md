# verb_present_simple_statement

Jesse rework pass for basic positive Present Simple: `I work`, `she works`, schedules, facts, and habits.

## Scope

- One microdiagnosis only: `verb_present_simple_statement`.
- Preserve the existing MVP contract ids and contrast set.
- Replace English-heavy learner copy with RU/UK ASCII transliteration.

## Teaching Point

The learner should stop adding `am/is/are` or `-ing` to habits:

1. `I work every day`
2. `They live in Dublin`
3. `She works every day`
4. `The shop opens at 9`
5. `Water freezes at 0C`

## Copy Rules

- Visible RU/UK copy uses ASCII transliteration.
- Avoid learner-facing raw labels like `base verb`, `subject`, or `main verb`.
- Contract contrast labels remain unchanged because tests assert them.

## Structure

- Easy: I/they/we without `-s`.
- Contrast: he/she/it with `-s` or `-es`, no `am/is/are`.
- Mixed: schedule, fact, stable attitude, pair correction.
