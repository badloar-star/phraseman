# Lingman Agent Upgrade 001

Date:

```text
2026-05-20
```

Upgrade theme:

```text
Agent accountability, ownership, blocker rights, handoff quality, and anti-vague-feedback discipline.
```

## Problem

The office had many strong agents, but the next risk was agent softness.

Soft agents create:

```text
vague comments;
duplicate opinions;
unclear ownership;
missing handoffs;
slow loopbacks;
too many taste-based decisions presented as certainty.
```

## Upgrade Applied

Added:

```text
Universal Agent Operating Contract.
Agent Report Template.
Agent Power Levels.
Agent Quality Score.
Agent Anti-Bloat Rule.
Agent Accountability Auditor.
Agent Accountability Layer.
Agent accountability field in QA.
PRIMARY OWNER AGENT and BLOCKING AGENTS in the One-Page Brief.
Agent Work Standard in the master prompt.
Agent accountability backfill in test runs 001-006.
```

## New Agent Behavior

Every important agent now must answer:

```text
What layer do I own?
What did I decide?
What evidence supports it?
What artifact did I produce?
What risk did I find?
What repair did I apply?
Who receives the handoff?
Am I blocking the package?
```

## New Blocker Logic

Blockers are now explicit:

```text
Algorithm Control Director blocks wrong routing.
Pedagogy QA blocks incorrect or overbroad teaching.
False Promise Auditor blocks misleading title/thumbnail/intro/payoff.
Conversion Guard blocks forced or trust-damaging ads.
Teleprompter Polish blocks unreadable scripts.
Agent Accountability Auditor blocks vague or missing agent outputs.
Final Director resolves and approves.
```

## New Rule

```text
No vague feedback.
Every critique must point to a line, beat, field, title, thumbnail, ad point, example, or QA item.
```
