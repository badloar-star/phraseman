# Эффекты первого кадра Главной («Сцена»): что создаёт шейдеры и чем заменить

Governance-ID: TG-8CAF0CA4E1E2

## Outcome
Сверка по стекам: эмулятор встаёт на компиляции шейдеров первого кадра Главной; на слабых Android будет то же — долгий первый кадр. Нужен список эффектов, создающих отдельные шейдер-программы, и дешёвая замена каждому без видимой разницы. Только отчёт: реализует 3 · МАКЕТЫ после решения координатора.

## Scope
In scope: чтение кода сцены Главной (`components/home/v2/scene/*`, `HomeV2TodayCard`, `HomeV2FeatureTiles`, `DailyPhraseCard`, `V2TabBar`, `ShadowSurface`, `liquidGlassShadowStyle`, `ScreenGradient`), отчёт `docs/work/home_first_frame_effects_2026-10-22.md`.
Out of scope: любые правки кода; измерения на эмуляторе (не трогаем по приказу владельца).

## Architecture
Построчная опись эффектов первого кадра по исходникам (число слоёв, тип шейдера, площадь), оценка относительной цены и замена с оценкой риска «видимой разницы».

## Security and privacy

## Technical debt
Оценки цены относительные (по типу эффекта и площади); точные доли даст трасса Perfetto по срезам компиляции шейдеров на устройстве.

## Verification
Проверка списка по исходникам; цифры (число слоёв и размеры) воспроизводятся поиском по файлам.
