# 🎓 LINGMAN — контент-цех обучающего канала «Professor Lingman»

Со-сценарист обучающего YouTube-канала про английский (≈59к подписчиков, аудитория 40+/50+).
Формат — **цепочки английских фраз**: ситуация → фраза → разбор → наращивание. Голос — **Professor Lingman**.
Постоянная память между сессиями и между разными ИИ (всё в файлах этой папки).

> ⚠️ Это НЕ MASON. MASON (`../MASON.md`) — другой канал (за кадром про разработку, Shorts, стиль Кларксона).
> LINGMAN — обучающий канал, длинные видео, тёплый наставник. Не путать.

## ⭐ Точка входа
**[LINGMAN.md](./LINGMAN.md)** — главный файл. Любой ИИ читает его первым и получает пошаговые инструкции.

## Файлы
- [LINGMAN.md](./LINGMAN.md) — пайплайн, запуск, команды. **Читать первым.**
- [VOICE_LINGMAN.md](./VOICE_LINGMAN.md) — голос и тон автора (как звучать живо, не как ИИ).
- [STYLE_FUSION.md](./STYLE_FUSION.md) — «двигатель вкуса»: приёмы лучших рассказчиков + шаблон микро-эссе про фразу.
- [AUDIENCE.md](./AUDIENCE.md) — кто наша аудитория 40+/50+, что любит/отталкивает.
- [FORMAT_CHAIN.md](./FORMAT_CHAIN.md) — анатомия цепочки фраз + структура видео + ресёрч-чек.
- [PHRASEMAN_INTEGRATION.md](./PHRASEMAN_INTEGRATION.md) — нативные упоминания приложения (не реклама).
- [RESEARCH_NICHE.md](./RESEARCH_NICHE.md) — сводный ресёрч ниши, форматов, удержания, монтажа.
- [CHECKLIST.md](./CHECKLIST.md) — финальная проверка перед отдачей сценария.
- [memory/](./memory/) — память: учебный план, реестр фраз, состояние серий.
- [scripts/](./scripts/) — готовые сценарии по датам.

## Как пользоваться (автору)
0. В любой сессии любого ИИ скажи **«LINGMAN»** или **«пишем новый урок»** — пайплайн поднимется сам.
1. Накидываешь тему/ситуацию дня (или говоришь «покажи план» и выбираешь из плана).
2. ИИ читает память + ресёрч → выдаёт **готовый сплошной текст для телесуфлёра**.
3. Текст сохраняется в `scripts/`, а память (`memory/`) обновляется автоматически.

## Команды-триггеры
- **«пишем новый урок [тема]»** / **«следующее видео»** — новый сценарий (полный цикл).
- **«покажи план»** — что прошли, что дальше.
- **«что уже разбирали про …»** — поиск по реестру фраз.
- **«перепиши живее / проще / короче / с бóльшим юмором»** — правка последнего сценария.
- **«сделай интеграцию мягче / сильнее»** — настройка упоминаний приложения.

## Стоп-факты (не путать)
- Канал ОБУЧАЮЩИЙ, повествование на русском, изучаемый язык — английский.
- Голос = Professor Lingman. Аудитория 40+/50+ — тёпло, уважительно, без сленга и снисхождения.
- Длина видео — ориентир 10-12 мин. Формат — цепочки фраз. Phraseman — нативно, не реклама.
