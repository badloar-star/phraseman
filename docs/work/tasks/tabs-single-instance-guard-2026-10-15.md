## Outcome

Диагноз r7k (docs/work/tasks/tabs-idx-rollback-logs-stall-authfetch-2026-10-15.md): `router.replace('/(tabs)/…')` с экрана поверх
вкладок кладёт в корневой стек НОВЫЙ маршрут `(tabs)`, старый остаётся под ним. Скрытый экземпляр догоняет каждую смену маршрута
и перерисовывает всё дерево вкладок впустую — 0,3–0,7 с JS на тап + память; «назад» с Главной уводит в старую копию/урок.
Цель: в корневом стеке всегда ровно один `(tabs)`; лишние маршруты ниже последнего `(tabs)` снимаются без анимации.

Почему не `dangerouslySingular`/`getId`: в expo-router 6.0.24 singular обрабатывается только для PUSH/NAVIGATE
(layouts/StackClient.js), а `router.replace` в стеке — REPLACE и идёт в обычный StackRouter; свой `UNSTABLE_router` Stack expo-router
не принимает (жёстко подставляет stackRouterOverride).

## Scope

In scope:
- новый `app/tabs_single_instance.ts` — чистая `dedupeTabsRoutes(state)` + хук `useTabsSingleInstanceGuard(containerRef)`;
- `app/_layout.tsx` — одна строка вызова хука (свой ханк, файл общий);
- тест чистой функции и хука (условия координатора 1–5).
Out of scope: lesson_complete / exam / diagnostic / paywall / notifications (их `replace` остаётся), dev_state.

## Architecture

Условия координатора 15.10:
1. Применение — только после r7l (inst=2 на боевом пути «урок → На главную»).
2. Reset — ПОСЛЕ перехода: слушатель `state` контейнера → `InteractionManager.runAfterInteractions` → повторная проверка живого
   состояния → reset; не посреди анимации.
3. Идемпотентность: срабатывает только при ≥2 `(tabs)` в одном стеке; после reset ровно один; повторный вызов без дублей — no-op с логом.
4. Маршруты от последнего `(tabs)` и выше сохраняются как есть (тот же key/params/state) — пейвол/модалка поверх вкладок не мигают и
   не перемонтируются; reset адресован ключу именно этого стека (`target`).
5. Аварийный выключатель: Remote Config `tabs_single_guard` — по умолчанию ВКЛ; выключен только явным `false` в кэше RC.
6. Android «назад» на Главной после сторожа = как на свежем старте (глобальный обработчик Главную не перехватывает; двойного нажатия
   для выхода в коде нет) — проверить на эмуляторе.
7. Логи [TABS-SINGLE] на каждом раннем выходе — навсегда.
