# Англійська · Урок 17 · Заняття 41 — Документи для пошуку роботи

**Ситуація.** Ви обговорюєте відгуки на вакансії й умови майбутньої роботи.

**Що ви опануєте:** some / any + plural count noun or non-count noun
**Нові слова:** reference, cover letter, job security, flexible working

## Інтро 1

### Повідомити про наявність

reference — рекомендація про працівника від попереднього роботодавця або іншого рекомендувача. Для заявки потрібні кілька рекомендацій про роботу людини. Reference → references. Some ставимо перед злічуваним у множині або незлічуваним, коли повідомляємо про певну кількість.

**Виберіть фразу для цієї ситуації.**

- ✅ **We need some references.**
- ❌ We need any references. — *У стверджувальному повідомленні про певну кількість використовуємо some.*
- ❌ We need a references. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 2

### Повністю заперечити наявність

cover letter — супровідний лист до відгуку на вакансію. У папці немає жодного супровідного листа. Повністю заперечте наявність. Cover letter → cover letters. job security — упевненість у збереженні роботи, стабільність зайнятості. Some використовується з множиною злічуваних та з незлічуваними. У запереченні зі значенням «жодного» зазвичай вибираємо any.

**Виберіть фразу для цієї ситуації.**

- ✅ **We don't have any cover letters.**
- ❌ We don't have some cover letters. — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ We don't have a cover letters. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 3

### Запитати без припущення

flexible working — робота з гнучким графіком або умовами вибору місця роботи. Ви не знаєте умов роботодавця. Запитайте нейтрально, без очікування відповіді «так». У нейтральному запитанні зазвичай any. Some теж трапляється в запитаннях: наприклад, у пропозиції Would you like some tea? або коли очікують «так». Тому враховуйте ситуацію, а не лише знак питання.

**Виберіть фразу для цієї ситуації.**

- ✅ **Do you offer any flexible working?**
- ❌ Do you offer some flexible working? — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ Do you offer a flexible working? — *A не ставиться перед незлічуваним або множиною.*
