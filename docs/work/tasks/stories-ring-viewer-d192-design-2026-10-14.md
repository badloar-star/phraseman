## Outcome

На Главной вокруг аватара-монеты в шапке — красное кольцо, пока есть непросмотренное событие; тап открывает полноэкранный просмотр: полосы прогресса, по 2,4 с на событие, тап справа/слева — дальше/назад, удержание — пауза, свайп вниз или ✕ — закрыть; после последнего просмотр закрывается сам, кольцо исчезает. Событий нет или флаг `stories_v1` выключен — аватар работает как раньше (тап ведёт в профиль). Слайды: итог недели Шпиля (башня новой лиги целиком, свой этаж с монетой), рубеж серии (огонь с цифрой на тёмной плашке), ранг монеты (старая → новая), ачивка.

## Scope

In scope: новые файлы `components/stories/` (`story_strings.ts`, `StoryRing.tsx`, `StorySlides.tsx`, `StoryViewer.tsx`, `StoryAvatarSlot.tsx`), тест `tests/stories_ring_viewer_contract.test.tsx`; одна точечная замена в `app/(tabs)/home.tsx` (кнопка аватара → `StoryAvatarSlot`, прежняя разметка переезжает внутрь компонента без изменений).
Out of scope: источник событий и его запись (Ядро); звуки V2 берутся готовыми (`story`, `sheet_close`); монета — только валюта/аватар ранга (закон владельца 14.10).

## Architecture

`StoryAvatarSlot` читает `useStoryEvents()`: при `!enabled || unseenCount === 0` возвращает ровно прежнюю кнопку профиля (те же testID, тот же обработчик) — поведение флаг-выкл неизменно. Иначе — кольцо (SVG-градиент 45°, 3 dp + зазор 2 dp цветом фона, «дышит» 1 → 1,06 за 1,8 с на UI-треде под `useRuntimeActive`) и тап открывает `StoryViewer`. Просмотр — прозрачный `Modal` с собственной анимацией раскрытия из аватара (380 мс, кривая .32,.72,0,1), все таймеры полос и жесты — Reanimated/Gesture Handler на UI-треде; каждый просмотренный слайд — `markSeen(id)` (мгновенно в памяти, диск догоняет фоном). Данные не запрашиваются: всё из снапшота памяти (первый кадр без ожидания).
