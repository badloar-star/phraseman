# Task packet: №43 — английские слова в плитках итальянского

## Outcome
В плитках курсов любого языка, кроме английского, испанского и французского, больше нет английских слов (fires, finish, favorite). Соблазны берутся только из курса. Сначала добавлен журнал `[TILE-SOURCE]` (откуда взяты соблазны), затем исправление.

## Scope
- `app/lesson1_smart_options.ts`, функция `getPerWordDistracts`: журнал и отключение английских пулов для языков, отличных от en/es/fr.
- Тест `tests/tile_source_no_english_pools_2026_11_05.test.ts`.
- Курс английского, испанского и французского не меняется.

## Architecture
Корень найден «Теорией»: когда у слова мало соблазнов в курсе, функция добирает их из английских пулов приложения (`WORD_POOLS_L1`, существительные/глаголы/прилагательные) через `globalFallbackPool` и `sameLanguageCategoryPool`. Для es и fr есть свои пулы, а для остальных языков оставались английские. Фикс: флаг `isOtherTarget`, при нём общий пул пуст, пул категории пуст, закрытые классы и английские защиты отключены. Если соблазнов в курсе меньше, плиток на экране меньше, но язык не смешивается.

## Security and privacy
Данные не собираются и не передаются. Журнал содержит только счётчики и слово, без идентификаторов пользователя.

## Technical debt
Журнал `[TILE-SOURCE]` пишется на каждое слово; в релизной сборке `console.log` вырезается, поэтому нагрузки нет. Если курсу не хватает соблазнов, это надо чинить в самом курсе (фабрика), а не добирать из приложения.

## Verification
Тест с итальянским, немецким и португальским классическими фразами: ни одного слова из английских пулов, журнал показывает `englishPoolsAllowed:false`, курс английского даёт прежний набор. Проверка на устройстве: урок итальянского, снимок плиток.

## Rollback
`git revert` коммита; поведение вернётся к прежнему (с английскими пулами).
