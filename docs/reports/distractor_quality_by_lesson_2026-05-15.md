# Аудит качества дистракторов по урокам (2026-05-15)

Источник: `app/lesson_data_all.ts` и подключаемые файлы `app/lesson_data_1_8.ts`, `app/lesson_data_9_16.ts`, `app/lesson_data_17_24.ts`, `app/lesson_data_25_32.ts`.

Проверены оба набора токенов, где они есть: `words` (испанские ответы) и `wordsEn` (английские ответы). Пунктуационные слоты не штрафовались за формат дистракторов, потому что для них нормален отдельный набор знаков.

## Методика оценки

Оценка ставилась по совокупности признаков:

- структурные ошибки: правильный ответ внутри `distractors`, дубли внутри массива, пустой/слишком короткий пул;
- покрытие: для обычных слов ожидается 5 дистракторов;
- педагогические риски: дистрактор совпадает с другим токеном той же фразы, много близких форм типа `work/works`;
- словарность: отдельный аудит `scripts/audit_fake_distractors.mjs` не нашёл выдуманных английских дистракторов.

Шкала:

- `A` - хорошее качество, можно оставлять;
- `B` - есть мелкие замечания, не блокирует;
- `C` - рабочее, но желательно усилить пулы;
- `D` - слабое качество, нужна доработка перед релизом;
- `E` - критично: пустые или массово короткие пулы.

## Общий вывод

Главный риск не в выдуманных словах и не в дубликатах: fake-аудит дал 0 проблем по всем 32 урокам. Главный провал качества - уроки 22 и 23, где много пустых пулов. Второй слой риска - уроки 24-30 и 32: они в целом рабочие, но не дотягивают до стандарта 5 дистракторов на обычный токен.

Приоритет исправлений:

1. Урок 23: заполнить пустые пулы и довести все обычные токены до 5 дистракторов.
2. Урок 22: заполнить 110 пустых пулов и расширить остальные до 5.
3. Уроки 24-30 и 32: массово расширить пулы с 3-4 до 5.
4. Точечно исправить структурные мелочи: `lesson8_phrase_13`, `lesson12_phrase_34`, 7 случаев в уроке 25, 1 дубль в уроке 24. Статус: исправлено в исходных данных.

## Обновление после первого прохода

Сделан защитный слой в генераторе options:

- правильный `correct` принудительно остаётся среди вариантов;
- если два соседних токена можно собрать сокращением (`do not` → `don't`), сокращение остаётся доступным для выбора;
- если canonical-токен уже сокращение (`don't`), первый раскрытый токен (`do`) остаётся доступным и запускает режим добора второго токена (`not`);
- короткие пулы добираются сначала из ручных дистракторов и категорийных пулов, общий fallback используется только последним;
- добавлен регрессионный тест по всем 32 урокам на наличие correct и contraction-вариантов.

Проверка после исправлений: в обычных непунктуационных слотах больше нет `correct` внутри `distractors` и дублей внутри массива.

Минус остается только как зона дальнейшего ручного QA: часть добавленных вариантов является category-aware fallback, поэтому их можно постепенно улучшать семантически под конкретные фразы.

Оставшийся счетчик `INFLECTED` в `audit_distractor_quality` не считается ошибкой автоматически: он ловит пары вроде `work/works`, `go/going`, `used/use`, которые часто являются полезными грамматическими ловушками. Такие случаи требуют не удаления, а выборочного просмотра по теме урока.

## Semantic-pass для уроков 22 и 23

Отдельно проверены самые слабые до ремонта уроки:

- урок 22: Gerundio / форма `-ing`;
- урок 23: Voz pasiva / passive voice.

Найденный паттерн: часть английских `wordsEn` была формально валидна, но добрана слишком общими местоимениями `I/you/he/she/we` для неместоименных correct вроде `every`, `day`, `room`, `online`, `sold`, `not`. Это ухудшало качество упражнения: варианты были слишком очевидными и не тренировали тему.

Исправление:

- для времени добавлены time-ловушки: `day/night/morning/week/month/time`;
- для места добавлены place-ловушки: `here/there/inside/outside/online/offline`;
- для пассивных participles добавлены формы, проверяющие passive vs active/tense: `cleaned -> clean/cleans/cleaning`, `sold -> sell/sells/selling`, `sent -> send/sends/sending`;
- для отрицания `not` добавлены adverb/negation distractors: `never/always/also/still/already`;
- для местоимений уточнены классы: object pronouns к object pronouns, possessives к possessives.

Результат targeted-аудита `scripts/audit_lesson22_23_semantic_distractors.mjs`: 0 неместоименных строк, где generic pronoun filler используется как добор.

- 26: Conditionals;
- 27: Reported speech;

До ремонта targeted-аудит нашел 965 неместоименных английских строк, где в distractors оставались generic pronoun fillers. Больше всего проблем было в уроках 24, 26, 27, 29 и 30; урок 32 уже был чистым по этому признаку.

Исправление:

- Present Perfect: `have/has/had`, `just/already/yet/ever/never`, participle/base/ing ловушки;
- Conditionals: `if/when/unless/because/although/whether`, modal traps `will/would/could/should`;
- Reported speech: `said/told/asked/says/tell`;
- Reflexive pronouns: уточнены reflexive/object/possessive классы;
- Used to: `used/use/using/would/did`;
- Relative clauses: `who/which/that/whose/where/when/why/how`;
- time/place/noun/adverb slots получили тематические candidate pools вместо случайных местоимений.

Результат targeted-аудита `scripts/audit_lesson24_32_semantic_distractors.mjs`: 0 неместоименных строк с generic pronoun filler в уроках 24-30 и 32.
