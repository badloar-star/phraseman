# Англійська · Урок 26 · Заняття 54 — Вечеря й невелика зміна планів

**Ситуація.** Ви куштуєте суп, згадуєте про хліб, ділите справи й вирішуєте, де поїсти.

**Що ви опануєте:** when, if, unless; just, already, yet; by the time
**Нові слова:** slightly, totally, meanwhile, besides

## Інтро 1

### Коли купите хліб

Удома закінчився хліб. Ви збираєтеся вийти й обіцяєте: I will get some when I go out — я куплю трохи, коли вийду. Some замінює трохи хліба. Складаємо: I + will get + some + when I go out — хто, що зробить, що купить, коли. У головній частині майбутнє передає will get. Після when, яке задає час цієї майбутньої дії, використовуємо теперішню форму go, без will.

**Виберіть фразу для цієї ситуації.**

- ✅ **I will get some when I go out.**
- ❌ I will get some when I will go out. — *Після when тут go без will.*
- ❌ I will get some when I goes out. — *З I потрібно go без -s.*

## Інтро 2

### Стіл був накритий до приходу гостей

Ви розповідаєте про вчорашню вечерю: гості прийшли до вже накритого столу. Скажіть: I had set the table by the time they arrived — я накрив на стіл до того часу, як вони прийшли. Складаємо: I + had set + the table + by the time they arrived — хто, що зробив раніше, що підготував, до якого моменту в минулому. Had set позначає ранішу дію, arrived — пізнішу. Після had потрібна третя форма set; вона пишеться так само, не setted.

**Виберіть фразу для цієї ситуації.**

- ✅ **I had set the table by the time they arrived.**
- ❌ I have set the table by the time they arrived. — *Arrived задає минуле; раніша дія — had set.*
- ❌ I had setted the table by the time they arrived. — *Форма set не змінюється; setted тут неправильно.*

## Інтро 3

### Запропонувати суп голодному другові

Друг прийшов до вас, і ви не знаєте, чи встиг він поїсти. Запропонуйте: Have some soup if you are hungry — поїж супу, якщо ти голодний. Складаємо: Have + some soup + if you are hungry — пропозиція щось зробити, що поїсти, за якої умови. Початкова форма Have без you робить цю частину пропозицією або спонуканням. If означає якщо; в умові з you використовуємо are.

**Виберіть фразу для цієї ситуації.**

- ✅ **Have some soup if you are hungry.**
- ❌ Have some soup unless you are hungry. — *Unless змінює умову: якщо ти не голодний.*
- ❌ Have some soup if you is hungry. — *З you потрібно are.*
