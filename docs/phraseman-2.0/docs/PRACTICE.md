# Режимы практики

Blitz, Устно, Напиши, Вспомни и напиши, Правда/неправда — сохраняемые возможности с новым интерфейсом. Общие boundaries: набор/локаль → подготовка → session start (энергия) → попытки → результат/ошибки → возврат. UI компонентов меньше, но проверка ответа, история и аудио не переписываются без причины.

Удалить кнопки, не поддерживающие действие пользователя. Сохранить выход, повтор нужного аудио, понятную проверку и необходимые доступные controls. После клавиатуры/микрофона действия остаются видны. Стандартные ошибки — короткие и конкретные, не замаскированы удалением всех тостов.

Устно использует текущий работоспособный механизм. Permission denied, нет речи, timeout, звонок/наушники, audio focus и background проверяются. Облачный движок сейчас не добавляется. Распознанный текст не доказывает правильность произношения; статистика не должна выдавать такие диагнозы.

«Разбор промаха» и «Объяснить проще» сохраняются при реальной пользе. Audit обязан показать prompt/input/output, согласие, отправляемые данные, кеш, rate limit, стоимость, timeout и fallback. Запрос по явному действию; не делать сетевой вызов на каждый просмотр ошибки. Полезное объяснение не означает неограниченный бесплатный AI.

Общий итог: что получилось, какие конкретные ошибки можно повторить, дальнейшее действие. Нет XP, подарков, случайных наград и парада анимаций. Списание энергии не привязано к каждому вопросу, если цена заявлена за сессию.
