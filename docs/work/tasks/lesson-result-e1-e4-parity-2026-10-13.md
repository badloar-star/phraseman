## Outcome

1. Звёзды на итоге урока считаются по D121/D36 (≥85 % — 3★, 60–84 % — 2★, ниже — 1★) через `app/lesson_star_scale.ts`, а не по медали (50/90/100 %): кнопки «Повторить урок / Следующий урок» и подсказка «нужно 2★» совпадают с порогом открытия следующего урока.
2. Счёт верно/ошибок приходит в итог из навигации экрана урока, если ключа прогресса в хранилище нет (запасной источник), а не пропадает.
3. Вторая строка под главной кнопкой — «Добить: Ещё учу (N)» (решение владельца): запускает повтор ошибок этого прохода в «Моих ошибках» (`mistakeIds`); кнопка «Повторить ошибки» внутри карточки «Ошибки» — то же действие.

## Scope

In scope: `app/lesson_complete.tsx`, `app/lesson1.tsx` (параметры маршрута, сбор id ошибок), `app/lesson_run_errors_memory.ts`, тесты и сторож.

Out of scope: начисление монет за диалог и предлоги (Ядро), сама логика «Моих ошибок», тексты курса.

## Architecture

Память процесса (не durable) хранит строки списка и id записанных ошибок прохода; экран итога читает их при показе. Звёзды — чистая функция от процента верных ответов. Маршрут урока → итог несёт `resultCorrect`/`resultTotal`.

## Security and privacy

Новых данных пользователя нет, наружу ничего не уходит; id ошибок уже существуют в локальном журнале «Моих ошибок».

## Technical debt

Contain: медаль (бронза/серебро/золото) остаётся прежней для достижений и уведомлений; звёзды итога и медаль теперь считаются по разным порогам — расхождение записано в комментарии у `resultStars`.
