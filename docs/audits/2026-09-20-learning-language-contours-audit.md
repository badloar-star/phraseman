# Аудит языковых контуров — 2026-09-20

## Решение владельца

Один выбранный изучаемый язык: `en`, `es`, `fr`, `de`.

Он должен определять учебный контент в уроках, Learning V2, фразе дня,
диалогах, Арене, видео, карточках, диагностике и экзаменах. У валют, XP,
уровня, Plus и профиля общего контура нет переключения по языку.

Если конкретный раздел для выбранного языка не готов, он обязан показать
состояние подготовки. Английский контент не может быть подстановкой.

Испанские материалы Learning V2 не проверялись и не изменялись этим аудитом.

| Диагностика и экзамены | небезопасно | риск P1 | `exam_target_gate.ts` знает только en/fr; после нормализации es/de возвращает английский банк. Нужен fail-closed для es/de и target-specific copy |

## Порядок исправления

1. Добавить единый экранный gate `ready/preparing` для уроков и Learning V2.
   Spanish lessons не менять; при отсутствии разрешения показывать только
   «готовится».
2. Закрыть ES/DE в `exam_target_gate.ts` и проверить все диагностические входы.
3. Сделать видео строго target-driven: ручной канал другого языка не допускается,
   отсутствующий канал даёт «готовится».
4. Убрать независимый выбор языка из карточек; он остаётся только служебным
   инструментом редактора, если такой понадобится.
5. Пройти все вызовы Arena readiness и добавить сквозные проверки: при каждом
   из четырёх target ни один раздел не показывает английский контент без target
   `en`.
