# Тема по умолчанию для новых: «Сумерки» / «Океан» по системному режиму (владелец 13.10 10:05, вопрос 3)

Governance-ID: TG-0194F603C83D
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора от владельца)

## Outcome
Новый человек (метка первого запуска) видит тему «как на телефоне»: системный светлый → «Сумерки» (ink), системный тёмный → «Океан» (marine), насыщенность 1. При смене системного режима пара переключается ink↔marine сразу, без мигания и перезапуска. Как только человек сам выбрал тему, оформление или насыщенность, текущая пара замораживается и записывается — его выбор навсегда. Старые пользователи не затрагиваются. Логи `[DEFAULT-THEME]`: первый запуск?, системный режим, выбранная тема, откуда (по умолчанию / выбор человека).

## Scope
`app/theme_first_run_default.ts` (пара, метка `theme_default_follow_system_v1`, `pickSystemDefaultTheme`, решение «новичок по метке»), `components/ThemeContext.tsx` (следование за `useColorScheme`, заморозка при первом выборе, метка вместо записи темы новичку), тесты `tests/theme_first_run_default.test.ts` (обновление) и сторож в нём же. Не трогаются: палитры тем, экран выбора тем, оформление старых пользователей, `app.json`. Прежние патчи DEFAULT_THEME_AURORA_* не применяются.

## Architecture
Новичку тема не пишется в хранилище: пишется только метка «следует за системой». Эффективные тема/оформление/насыщенность вычисляются в провайдере из `useColorScheme()` (мгновенно, без записи). Первый вызов любого из трёх commit-ов вызывает `freezeFollowSystem`: фиксирует то, что человек видит сейчас, пишет все ключи одним `multiSet` и снимает метку; дальше действует прежний путь выбора с откатом. Сплеш по-прежнему ждёт гидратацию, так что первый кадр сразу в нужной теме.

## Security and privacy
Хранится только тема и метка на устройстве, в облако ничего не уходит; политика не меняется.

## Technical debt
Новичок без сохранённых ключей считается «следующим за системой» только пока метка равна 1; пользователи, прошедшие онбординг до этого релиза, остаются на прежнем поведении. Метку можно убрать, если когда-нибудь потребуется единая тема.

## Verification
Тесты чистого решения (метка, пара по режиму, старые пользователи) и источник-контракт на ThemeContext; на эмуляторе — смена системного режима у нового профиля и выбор темы вручную; Сверке — Главная/Уроки в обоих режимах.

## Rollback
