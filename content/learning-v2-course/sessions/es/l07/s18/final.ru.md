# Испанский · Урок 7 · Занятие 18 — Двадцать пять, двадцать шесть, двадцать семь

**Ситуация.** Считаете книги для разных групп.
**Что вы освоите:** называть числа 25–27 одним словом.
**Новые слова:** veinticinco, veintiséis, veintisiete
**Повторяем знакомые слова:** haber, libro, aquí.

## Интро 1

### Двадцать пять книг

Для первой группы вы насчитали двадцать пять книг. Сообщите `Hay veinticinco libros` — «Есть двадцать пять книг». Соберите `Hay` + `veinticinco` + `libros`. Veinticinco — двадцать пять: одно слово без знака ударения. Произнесите с ударением на cin: veinticinco. Libros остаётся во множественном числе.

**Сообщите «Есть двадцать пять книг». Начните с Hay, число поставьте перед libros.**

- ✅ **Hay veinticinco libros.** — *Hay + veinticinco + libros.*
- ❌ Hay veinticinco libro. — *Книг несколько: libros.*
- ❌ Hay veinte libros. — *Veinte — двадцать, а нужно двадцать пять.*

## Интро 2

### Двадцать шесть здесь

В другой группе подготовлены двадцать шесть книг. Вы показываете их и говорите `Hay veintiséis libros aquí` — «Здесь есть двадцать шесть книг». Соберите `Hay` + `veintiséis libros` + `aquí`. Veintiséis тоже одно слово; нужен знак é на последнем слоге. Место ставим в конце.

**Сообщите «Здесь есть двадцать шесть книг». Начните с Hay, число поставьте перед libros, место — в конце.**

- ✅ **Hay veintiséis libros aquí.** — *Hay + veintiséis libros + aquí.*
- ❌ Hay veintiséis libro aquí. — *После veintiséis нужно libros.*
- ❌ Hay veinticinco libros aquí. — *В этой группе двадцать шесть: veintiséis.*

## Интро 3

### Двадцать семь для встречи

В следующей группе двадцать семь участников. Уточните `¿Hay veintisiete libros?` — «Есть двадцать семь книг?» Соберите `¿Hay` + `veintisiete` + `libros?`. Veintisiete — одно слово без знака ударения. Число по-прежнему стоит перед предметами. Сначала уточните количество, затем раздавайте книги.

**Спросите «Есть двадцать семь книг?». Начните с ¿Hay, число поставьте перед libros.**

- ✅ **¿Hay veintisiete libros?** — *¿Hay + veintisiete + libros?*
- ❌ ¿Hay veintisiete libro? — *Книг несколько: libros.*
- ❌ ¿Hay veintiséis libros? — *Нужно двадцать семь: veintisiete.*
