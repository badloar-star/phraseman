# Task packet: чистка старых замков git и вердикт по удалению гостей (05.11)

## Outcome
Старые временные индексы git с мёртвыми владельцами удалены; дан доказанный вердикт «удаляются ли гости сразу» со ссылками на строки.

## Scope
Файлы только внутри `.git` вида `aa_part_*`, `core_tmp_index_*`, `next-index-*.lock`, `safe_commit_index_*.lock` с мёртвым PID. Чтение `functions/src/account_delete.ts`. Код не меняется.

## Architecture
Номер процесса берётся из имени файла и сверяется со списками живых процессов Windows и Git Bash. Удаляются только файлы, у которых владелец мёртв и возраст больше часа. Живые замки (`safe_commit_index_160358*`, `index.lock`, общий замок коммита) не трогаются.

## Security and privacy
Удаляются временные индексы без пользовательских данных. Идентификаторов в отчёте нет.

## Technical debt
Скрипты, создающие эти файлы, не чистят их при падении; нужна очистка в `finally`/trap либо периодическая уборка.
