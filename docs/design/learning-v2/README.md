# Атлас: дизайн раздела Learning V2 (макеты со всеми состояниями)

Дата: 2026-09-05. Заказ владельца: полный дизайн раздела Learning V2, HTML-макеты
с анимациями в премиальном стиле, все вероятные состояния, новые модалы,
эффектный старт раздела на релизе, при этом быстродействие.

## Что это

Восемь интерактивных макетов телефона (390×844) с панелью состояний, замедлением
4×, reduced motion и тремя темами хрома приложения. Открывать `index.html`.

| Файл | Экран | Состояний |
|---|---|---|
| `01-premiere.html` | Премьера раздела (первый вход после релиза) | 4 |
| `02-atlas.html` | Атлас: колода из 32 карт уроков, карта → карта урока | 7 |
| `03-map.html` | Карта урока: 7 районов, 7 форм пути, хореографии | 11 |
| `04-session-start.html` | Билет занятия (модал старта) и ирис в занятие | 7 |
| `05-checkpoint-start.html` | Печать главы и врата экзамена, открытие как сейф | 6 |
| `06-session-complete.html` | Финал занятия | 6 |
| `07-checkpoint-result.html` | Результат проверки, печать, урок пройден | 4 |
| `08-states.html` | Системные состояния (подготовка, ошибка, выход, разбор…) | 7 |

Состояние открывается ссылкой: `03-map.html#return-complete`.

## Как смотреть

Локально (относительные пути к `shared/` работают и с диска, и с сервера):

```bash
python -m http.server 8848 --directory docs/design/learning-v2
```

В приложении Claude есть конфиг превью `learning-v2-mockups` (порт 8848).

Автономные копии (общие модули вклеены, один файл на экран):

```bash
node docs/design/learning-v2/build.mjs
```

Результат в `dist/`. Шрифт Inter подтягивается с Google Fonts; без сети
используется системный.

## Устройство

- `shared/tokens.css` — темы хрома (Лес, Золото, Коралл) и свет семи глав.
- `shared/phone.css` — рама, статус-бар, чипы, 3D-клавиша, шторка, вуаль, тост,
  скелетон, ирис.
- `shared/map.css` + `shared/map.js` — карта урока: районы, улица, фонари, печати,
  врата, туман, хореографии (`MapKit`).
- `shared/atlas.css` + `shared/atlas.js` — колода карт уроков (`AtlasKit`).
- `shared/course.js` — 32 урока, 7 глав и 56 сессий урока 1 из плана курса.
- `shared/routes.js` — геометрия семи маршрутов и построение SVG-пути.
- `shared/showcase.js` — панель витрины.
- `shared/icons.js` — SVG-спрайт (без эмодзи и растра).

## Что не решено и ждёт владельца

- Название раздела «Атлас» и слово «фонарь» для узла: предложение, не решение.
- Награды за занятие (+15 рун, +40 опыта, +5 за повтор, +40 за главу, +120 за
  урок): цифры для макета, экономику считает сервер.
- Открытие сцены печати для закрытой печати (вместо тоста): предложение UX.
- Текст клавиши экзамена «Начать экзамен» вместо общего «Начать проверку».
