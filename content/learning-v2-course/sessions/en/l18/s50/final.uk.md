# Англійська · Урок 18 · Заняття 50 — Повага й самостійність

**Ситуація.** Ви ділитеся сильним враженням і підкреслюєте якість.

**Що ви опануєте:** so + adjective; such + noun phrase
**Нові слова:** respect, freedom, independence, responsibility

## Інтро 1

### Вислухати одне одного

Ви із сусідом по квартирі по-різному уявляєте порядок удома, але спокійно вислуховуєте одне одного. Respect — повага; mutual respect — взаємна повага. Mutual respect is so important. — Взаємна повага така важлива. Mutual respect називає те, що ви цінуєте, is пов’язує це з оцінкою. So ставимо перед important, щоб підсилити прикметник: is + so + important.

**Виберіть фразу для цієї ситуації.**

- ✅ **Mutual respect is so important.**
- ❌ Mutual respect is such important. — *Після пропуску прикметник без іменника: so.*
- ❌ Mutual respect is much important. — *Перед звичайним прикметником тут потрібне so, не much.*

---

## Інтро 2

### Самому вибирати плани

Друг намагається вирішувати за вас, як проводити вихідні, а ви пояснюєте, чому хочете вибирати самі. Freedom — свобода. Freedom is so important. — Свобода така важлива. Спочатку Freedom — тема висловлювання, потім is та оцінка so important. Після so йде прикметник important без іменника, тому such тут не підходить. Freedom як загальне поняття вживаємо без a.

**Виберіть фразу для цієї ситуації.**

- ✅ **Freedom is so important.**
- ❌ Freedom is such important. — *Після пропуску прикметник без іменника: so.*
- ❌ Freedom is much important. — *Перед звичайним прикметником тут потрібне so, не much.*

---

## Інтро 3

### Відповідати за чужого улюбленця

Сусід їде й просить вас тиждень доглядати його собаку. Responsibility — відповідальність, обов’язок. This is such a big responsibility. — Це така велика відповідальність. This указує на догляд за собакою, потім is і група such a big responsibility. Тут responsibility означає конкретний обов’язок, тому потрібен a. Порядок: such + a + big + responsibility.

**Виберіть фразу для цієї ситуації.**

- ✅ **This is such a big responsibility.**
- ❌ This is so a big responsibility. — *Після пропуску група з іменником: such. Перед злічуваним в однині зберігаємо a/an.*
- ❌ This is a such big responsibility. — *Порядок: such a/an, не a/an such.*
