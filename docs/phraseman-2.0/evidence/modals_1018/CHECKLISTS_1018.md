# Чек-листы сверки 18.10 — вход, карта V2, карточки из видео

> зачем (координатор 18.10): вердикт по кадру за минуты — идём по строкам сверху вниз, у каждой строки «что / где / размер / цвет».
> Любое расхождение = ❌ со ссылкой на номер строки. «Почти» = расхождение (правило владельца: каждый элемент, цвет тоже).
> Размеры в dp. Эмулятор Pixel 8: **1 dp = 2,625 px** (420 dpi). Цвета: тёмная (графит) / светлая («Сумерки»).

Как мерить по кадру:
- dp = px ÷ 2,625. Высота кнопки 54 dp = 142 px, плитка 55 = 144 px, плитка 46 = 121 px.
- Кегль текста — по шагу строк (базовая линия → базовая линия) ÷ межстрочный, или по высоте заглавной (≈ 0,73 кегля для Inter).
- Цвет — пипеткой в середине заливки, не на краю (край сглажен).

## (в) Карточки из видео с длинной фразой — очередь пересъёмок №21 (4d65c8be5 + eb6f98f9f + 72674b014)

Условия съёмки: тёмная тема; шрифт 1,0 и 1,3; набор из видео; карточка с **самой длинной** фразой набора и рядом — с короткой (для сравнения).
Кадры: (1) список карточек набора — лицевая и обратная сторона; (2) VideoSetView; (3) тренировка-свайп.

Нижняя граница кегля 14 по кадру (шаг строк = кегль × 1,3 × масштаб шрифта × 2,625 px):
- шрифт 1,0 → шаг строк фразы **≥ 48 px**;
- шрифт 1,3 → **≥ 62 px** (в списке масштаб ограничен 1,35).
