# Главная и маршруты
Главная перестраивается, не ремонтируется косметически. Primary action — связанная с запросом человека практика. Карточки легко найти; видео и курс доступны без конкурирующих призов. Точное число/порядок вкладок определяется после route audit и выбора макета; не навязывать новый таббар без решения.

Убрать арена-tab и все её входы, спины/подарки, колокольчик, старый XP, строку «Продолжение скоро» и декоративные reward hosts. Энергия у Free живёт в согласованном header. Sharing использует стандартное понятное действие. Профиль использует монету и визитку, не редактор старого аватара. Баланс монет и действие апгрейда компактны и не захватывают экран.

Огонь серии заменяет перо: дизайн стадий 0–10 дней и дальше по утверждённой шкале. Это отображение состояния, не новая экономика и не восстановление ускорителей энергии. Сброс/границы дня согласованы с существующей streak-логикой, без cron на анимацию.

Для каждого retired route перечислить deeplink, push destination, admin message destination, back stack и shared URL. Известный старый link ведёт в понятное безопасное состояние, не crash/бесконечную навигацию. Общие section sheets удаляются только после проверки оставшихся экранов. Кеш и scroll position сохраняются там, где помогают вернуться к набору, а не сохраняют старые призовые модалки.

Сделать checklist всех размеров текста, горизонтальных отступов и controls на главной. Уменьшение визуального блока не означает уменьшить область нажатия до пиктограммы.
