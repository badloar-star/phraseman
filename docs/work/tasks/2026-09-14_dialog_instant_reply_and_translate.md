## Outcome

Пользователь в ИИ-диалоге видит первые слова ответа собеседника через ~0.5–1 с после отправки
(время первого токена модели), а не через 3–6 с (полная генерация + постпроверка). Нажатие
«Показать перевод» открывает перевод мгновенно для уже пришедших реплик (перевод подтягивается
заранее в фоне и лежит в локальном кэше экрана), а холодный старт функции перевода снимается
прогревом при входе на экран.

Мера успеха: в логах `[DIALOG-LAT]` (клиент и сервер) `firstDeltaMs` ≈ TTFT модели
(≤ ~1200 мс на тёплом инстансе), `translate tap→shown` ≈ 0 мс для предзагруженных реплик.

## Architecture

Текущая граница: сервер буферизовал весь ответ провайдера, прогонял анти-повтор/язык/советы и только
потом нарезал готовый текст на SSE-дельты — «стрим» был декоративным. Перед вызовом модели шли
7–8 последовательных обращений к Firestore (личность → подписка → транзакции лимитов).

Новая граница: дельты провайдера публикуются клиенту по мере прихода (монотонный хвост поля reply
для игрового JSON-конверта). Инварианты сохранены: квота списывается ДО генерации; `done` несёт
авторитетный текст, которым клиент заменяет черновик; отвергнутый анти-повтором черновик убирается
кадром `reset` перед второй попыткой; языковой гард и фильтр регулируемых советов по-прежнему
применяются к полному тексту перед `done`. Личность (stableUid) и подписка кэшируются в памяти
инстанса на 60 с по authUid — экономия 4–6 round-trip на реплику и чтений Firestore.

Решение: принято осознанно, что при редкой регенерации пользователь увидит, как первый черновик
исчезает и печатается новый (кадр `reset`). Это цена мгновенного первого токена, которую требует
владелец.

## Security and privacy

Аутентификация — без изменений (bearer ID-token / callable auth). Авторизация — те же гейты
(Plus, дневная квота, rate-limit) выполняются до вызова провайдера; кэш личности 60 с не
расширяет доступ: истёкшая подписка действует не дольше 60 с на том же инстансе, и только на
диалог. Персональные данные новые не собираются; в логах `[DIALOG-LAT]` — только длительности и
коды, без текста реплик и без uid. Предзагрузка перевода отправляет на сервер текст реплики
СОБЕСЕДНИКА (сгенерированный ИИ), не текст пользователя. Privacy policy правок не требует.

## Rollback

Клиент: флаг `DIALOG_TRANSLATE_PREFETCH_ENABLED=false` отключает предзагрузку; кадр `reset`
игнорируется старыми клиентами (неизвестный тип кадра пропускается). Сервер: откат коммита
возвращает буферизованный стрим — протокол `started/delta/done/error` совместим в обе стороны.
Данные пользователей не мигрируются; сущностей в Firestore не добавляется.
