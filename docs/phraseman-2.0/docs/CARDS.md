# Карточки — главный сценарий 2.0

Каталог превращается в спокойный компактный список. Наборы из видео отличаются небольшой миниатюрой и отдельным play-действием, а не цветной рубашкой. Название, язык/предмет, число карточек и основное действие читаемы. Сортировка и поиск по своим наборам позволяют вернуться к нужному материалу. После тренировки сохранять фильтр и позицию.

## Создание
«Лицевая сторона» и «Обратная сторона» — нейтральные названия. Язык стороны/озвучки выбирается отдельно с разумным наследованием от набора. Предметный набор может не быть языковым: описание ↔ деталь машины не требует искусственно выбирать английский курс. Убираются рубашки, цвета и декоративные assets выбора. Не добавлять сложный предметный классификатор: он не нужен для этой возможности.

Лимиты 3 собственных набора и 50 карточек — незавершённое бизнес-решение. Рекомендация: активные собственные данные, а не пожизненный счётчик любого действия; 50 суммарно, официальные материалы отдельно. Согласовать существующие сверхлимитные аккаунты, импорт, дубликаты, публикацию, удаление и Plus expiry. Нет платы за удаление. Для защиты расходов использовать размеры payload, ограничение массового создания/публикации и серверную валидацию. Не включать эти новые ограничения без impact и approval.

## Тренировка и выбор
Общий selector наборов для Blitz/Устно/Напиши/Вспомни/Правда–неправда. Отмеченные строки явно выделены, итог выбора понятен, пустой выбор не стартует. Play открывает видео, не снимает selection. Нет отдельного многократно скопированного picker для каждого режима.

Открытый набор: переворот, предыдущая/следующая, начало практики и нужные действия без декоративной панели статистики. Поиск не обязан читать Firestore на каждую букву; сначала оценить локальные данные и объём каталога. Частичная загрузка не должна выдавать ложное «ничего нет» при неполной базе.

## Тексты и жалобы
Одна краткая полезная строка у самого раздела и каждого реального подраздела — прямое требование S64, а не запрещённая «болтовня». Иконка флага вместо длинной кнопки жалобы; accessibility label, feedback и рабочая доставка в админку сохраняются. В публичных наборах проверить авторские права, приватность, report moderation и ограничения спама. Не расширять приложение до социальной сети.

## Контроль существующих данных
Appearance поля перестают использоваться, содержимое сохраняется. «Удалить карточки за жемчуг» означает удалить товарный механизм и решить купленные права, а не уничтожить тексты людей. Язык интерфейса не определяет язык набора после создания. Общий wallet/rank не смешивает результаты разных локалей.
