## Outcome
1. Раздела «Умная очередь» нет нигде в интерфейсе (журнал владельца, строка 12): без блока, шторки, заголовка-героя и строк на 9 языках; механика подбора карточек остаётся, но пользователю не названа.
2. Кнопки таб-бара целиком помещаются (журнал, строка 3): причина измерена по логам `[TABBAR]`, исправлена, есть сторож расчёта ширин.
3. Пейволы контекстные (журнал, строки 10–11): у каждого входа свой заголовок, подзаголовок и подсвеченная первая выгода; пустые плашки предложений заменены состоянием «Цена недоступна — повторить».
4. Шпиль — после (отдельный пакет `spire-design-layer-2026-10-11.md`).

## Scope
1: `app/flashcards_swipe.tsx` (строки и использование `smartQueue`), поиск по коду, i18n, тестам и документам. 2: `components/v2/V2TabBar.tsx`, `app/(tabs)/_layout.tsx`. 3: `components/paywall/PaywallPlus.tsx`, `PaywallPlusScreen.tsx`, `PaywallPlusCopy.ts` (контракт context-ключей и тексты — совместно с Ядром, передача контекста — Ядро).

## Architecture
1: удаление пользовательского слоя, не логики очереди. 2: расчёт ширин в одном месте, один источник отступов, сторож-тест «сумма ширин не превышает контейнер». 3: набор context-ключей → верх экрана через таблицу `PaywallPlusCopy`, единая раскладка.

## Security and privacy
Данные не затрагиваются; пейволы только показывают уже существующие тексты и цены.

## Technical debt
Не добавляется; снятые тексты удаляются целиком из всех языков.

## Verification
Типы и точечные тесты в слоте светофора, контрактные тесты достижимости и устойчивости, сторожа по каждому пункту, пересъёмка Сверкой.
