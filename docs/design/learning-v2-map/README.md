# Карта курса Learning V2 — макеты

Дата: 2026-09-20. Заказ владельца: «при открытии раздела Learning V2 открывалась
карта… эта карта длится вниз вниз вниз вниз, после 56 сессий идёт красивая плашка
с названием следующей темы и сессии продолжаются снова с 1 до 56… в футере кнопка,
которая открывает список всех уроков… каждая сессия должна быть названа».
И главное требование: **«ничего не должно лагать!!!!!»**

## Как смотреть

```bash
python -m http.server 8851 --directory docs/design/learning-v2-map
```

В приложении Claude есть конфиг превью `learning-v2-map` (порт 8851).

На странице три телефона:

| Телефон | Что показывает |
|---|---|
| Карта | Непрерывный путь от урока 1 до урока 32, плашки уроков, подписи под кружками |
| Список уроков | Шторка снизу, 32 строки, тап — прыжок к уроку |
| Высота плашки | Нынешние 108px против 72px как в Learning V1 |

Панель сверху переключает тему (Лес / Золото / Коралл), прогресс и
«меньше движения». Справа — счётчик кадров и число живых узлов в DOM.

## Что решено

- **Карта вместо аккордеона.** Сейчас `app/learning-v2/course.tsx` рендерит
  `LessonsTab` с горизонтальным рядом из 32 плиток; тап раскрывает 56 сессий
  внутри плитки. В макете карта сплошная, а список уроков переехал в шторку и
  работает как навигация, а не как раскрытие.
- **Плашка урока на пол-экрана** (380px при экране 844): номер, название
  системы, арка урока, статус. Разделена световой нитью, а не обводкой.
- **Видно весь курс.** Закрытое приглушено, но путь виден до горизонта —
  выбор владельца из трёх вариантов.
- **Имена только настоящие.** 168 имён занятий взяты из колонки «Момент сцены»
  в `content/learning-v2-course/curriculum/en/ПЛАН_КУРСА.md` (уроки 1–3 —
  ровно те, что написаны). Где текста нет, кружок подписан номером занятия.
  Владелец: «только для тех которые есть, остальные ещё пишутся, их не трогаем».

## Почему это не лагает

1792 кружка в DOM — гарантированный лаг. Движок (`mapkit.js`) построен на трёх
законах:

1. **Геометрия — числа, не DOM.** Позиция узла — чистая функция от индекса
   (`nodeAt(i)`). Полная высота полотна (282 752px) известна до первой
   отрисовки: скроллбар честный сразу, контент не «дорастает».
2. **Окно и пул.** В DOM живут только узлы видимого диапазона плюс запас;
   элементы переиспользуются из пула, а не создаются и удаляются.
   Замер: **9–16 узлов вместо 1792**, то есть в ~200 раз меньше работы на кадр.
   На экране это 120 fps.
3. **Кадр без layout.** Обработчик `scroll` только просит `rAF`; внутри кадра
   только `transform`/`opacity` и текст. Никаких `offsetTop` и
   `getBoundingClientRect` — это принудительный reflow и главный источник рывков.

Плюс: бесконечная анимация на карте ровно одна — дыхание текущего узла
(он на экране один). Это сознательно, после находки 20.09, что
`QuestTaskCard` крутил native-loop на Главной без гейта.

Проверка числами, без браузера:

```bash
node docs/design/learning-v2-map/check.mjs
```

18 проверок: высота полотна, уникальность позиций, ≤40 узлов в окне при любом
скролле, зазор между подписью и следующим кружком, размер плашки, честность
имён, высота строки урока, отсутствие массовых анимаций.

## Что нашлось при проверке в браузере

Каждое — настоящий дефект, найденный замером, а не на глаз:

- **Подписи лезли на соседний кружок.** При шаге 118px между подписью и
  следующим кружком оставалось 12px. Шаг увеличен до 138px (зазор 32px), и
  это закреплено проверкой в `check.mjs`.
- **Шапка показывала обрезанную арку.** «Первая неделя в Дублине: но…» —
  арка длинная. Теперь в шапке сцена главы: короткая и точнее говорит, где
  человек сейчас.
- **`d.chapters` — массив, а не словарь.** Поиск главы по ключу `"1:5"`
  молча давал `undefined`, и шапка писала «Глава 5» вместо «Обед с командой».
- **Плавный прыжок не доезжал.** `scrollTo({behavior:"smooth"})` на 29 000px
  не сдвигает `scrollTop` вообще — тап по уроку выглядел бы мёртвой кнопкой.
  Далеко прыгаем мгновенно, плавно — только рядом.
- **Разметка плана доезжала до экрана.** В именах занятий встречались
  `обратные кавычки` из markdown.
- **«ГЛАВА 6 / Глава 6».** У ненаписанных уроков сцены нет, и заголовок
  повторял сам себя. Теперь там диапазон занятий.

## Высота плашки урока

Владелец 20.09: плашки в списке уроков должны быть как в Learning V1, а не
такими высокими; круговой индикатор остаётся.

Причина высоты найдена точно, три слагаемых:

| Что | Сейчас в V2 | В макете |
|---|---|---|
| `minHeight` (`app/(tabs)/lessons.tsx:870`) | 108 | 72 (`BOOK_H` из V1) |
| Кольцо прогресса | 48×48 | 44×44 |
| Заголовок урока | без `numberOfLines`, до 3 строк | одна строка |

Третий пункт и есть главный: «Существительные, a/an/the, this/that/these/those»
разливается на три строки и тянет плашку вверх независимо от `minHeight`.

## Что ещё не решено и ждёт владельца

- Имена занятий для уроков 4–32 появятся, когда фабрика начнёт писать имя
  занятия в релиз. До тех пор карта показывает номера — это сознательно.
- Слово «Занятие» против «Сессия» в подписях: в макете «Занятие», потому что
  на карте это читается человечнее. Термин не менял, спрашиваю.
- Реализация в приложении не начата: это макеты. Пакет задачи —
  `docs/work/tasks/2026-09-20_learning_v2_continuous_map.md`.
