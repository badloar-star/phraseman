     Не брать карточки слов, `listen_*`, `speed_match`, `scripted_repeat_compare`, `phrase_builder`.
  2. Все варианты — формы темы ЭТОГО урока: урок 1 — am / is / are (и isn't / aren't, 'm / 're / 's); урок 2 — начало вопроса
     Am / Is / Are / Who / What / Where (с заглавной); урок 3 — a / an / the, this / that / these / those или одно слово в
     единственном / множественном числе (labels / label). Если хоть один вариант — другое слово по смыслу, задание не берём.

  5. Три вопроса одного урока — на разные части темы (урок 1: am, is, are; урок 2: Is, Are, вопросительное слово;
     урок 3: a / an, число, the), чтобы «2 из 3» не засчитывалось одной и той же формой.
