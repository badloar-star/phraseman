## Architecture

Шаг 2м: история только для варианта «подписка». Теперь — для всех: кадр показывает уровень, а не вариант окна. Уровень
берётся из памяти плана (`peekPremiumPlan`): продукт точнее плана; плана нет — Plus (Ultra по догадке не показываем).
Ожидающее поздравление (и для VIP) гасится только после записи истории, как в шаге 2м.
