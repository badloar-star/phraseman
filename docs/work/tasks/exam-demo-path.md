## Что включено в dev без правок данных

- `SEASON_CHAPTER_EXAM_ENABLED` — в dev включён: карта экзамена в карусели «Сезона» видна.
- `SEASON_CHAPTER_EXAM_START_ENABLED = false` — кнопки «Сдать экзамен» / «Открыть экзаменом главы» на карте ещё не ведут
  на экран (включит координатор после ✅). Поэтому экран открывается **прямой ссылкой** (шаг 2).
- Данные экзамена — встроенный выпуск курса (урок 1, глава 1 = эпизоды 1–7), сеть не нужна.

## Маршрут

1. **Состояние** (Free, энергия есть):
   `adb shell am start -W -a android.intent.action.VIEW -d "phraseman://dev_state?energy=5&plus=off&onboarding=done"`
   — дождаться «DEV-STATE OK». Для Plus: `plus=on`.
2. **Экран экзамена** (урок 1, глава 1):
   `adb shell am start -W -a android.intent.action.VIEW -d "phraseman://learning-v2/chapter-exam?lessonOrdinal=1&chapterOrdinal=1&source=exam_card"`
3. **Вопросы**: шапка «Экзамен · 1 / 12», прогресс; 12 вопросов (сборка фразы, вставь слово, послушай и выбери,
   диктант). Энергия −1 при первом вопросе (Free), Plus — без списания.
   - После ответа — только «Верно / Неверно» (без разбора — так задумано, разбор в итоге), кнопка «Дальше».
4. **Не сдан**: ответить неверно ≥ 3 раз → итог «X из 12» (без кубка), «Почти получилось», 12 точек, фраза
   «Чтобы сдать, нужно 10. Разберём K ошибок, и через час можно пересдать.», кнопки «Разбор ошибок» + «К главе 1».
5. **Разбор**: «Разбор ошибок», подзаголовок «Экзамен главы 1 · K ошибок», карточки: «Вопрос i · задание», ситуация,
   «Твой ответ: ~~…~~» (цвет ошибки темы), правильный ответ (зелёный темы), объяснение, «Повторить эпизод N».
6. **Пауза час**: снова открыть ссылку из шага 2 → «Экзамен главы 1» + «Пересдать через 59 мин» (вопросов нет).
   Лог: `[CHAPTER-EXAM] prepare:cooldown`.
7. **Сдан** (на другой главе, чтобы не мешала пауза: `chapterOrdinal=2`): ответить верно ≥ 10 → кубок, «X из 12»,
   «Экзамен сдан», плашка «Глава 3 открыта» с обложкой и сценой (+ «Эпизоды a–b главы 2 тоже открыты», если экзамен
   засчитал непройденные эпизоды), кнопки «К главе 3» + «Разбор ошибки · K» (если были ошибки).
   - Плашка «+40» встаёт **сразу** вместе с итогом (aadfc39e5, закон владельца: монеты выдаёт телефон, сервер сохраняет).
     Баланс на телефоне растёт тут же; сохранение на сервере — фоном (`[COIN-WALLET] chapter_exam:synced`). Нет плашки —
     дефект: смотреть `[COIN-WALLET] chapter_exam:result` / `chapter_exam:failed` (причина сбоя записи на телефоне).
8. **Шторка перед стартом** (вариант классической карты, `chapter-exam-flow.html` `.xsh`) в «Сезоне» не используется:
   в Сезоне окно перед стартом — увеличенная карта 4 · ТЕМЫ (`SeasonExpandedCard`).

Журнал всего маршрута: `grep "\[CHAPTER-EXAM\]\|\[COIN-WALLET\] chapter_exam" .expo/metro-console.log`.
