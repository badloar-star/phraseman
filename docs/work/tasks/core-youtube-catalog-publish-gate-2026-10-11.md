# Task packet: каталог YouTube — не публиковать неизменившийся снимок (находка K)

## Outcome

Плановый синк каталога YouTube (`youtubeCatalogSyncCron`) не пишет новый снимок, если содержимое не изменилось.

Сейчас каждая публикация:
- пишет весь снимок (канал, видео, плейлисты, страницы);
- тут же перечитывает его для проверки;
- через 7 дней удаляет.

Это раз в 15 минут, а в эфир — каждую минуту.

Решение:
- изменения, которые видит человек (новые ролики, эфир, названия, плейлисты), публикуются сразу, как раньше;
- изменившееся только число просмотров (приложение его показывает: карточка видео, экран просмотра) —
  не чаще раза в 6 ч, по значению в том же округлении, что на экране.

## Scope

In scope:
- новый чистый модуль `functions/src/youtube_catalog_publish_gate.ts`: отпечатки и решение;
- `youtube_catalog.ts`: ветка «без публикации»;
- `youtube_catalog_store.ts`:
  - хранение отпечатков в `sync_state`;
  - снятие блокировки без публикации;
  - сброс отпечатков при откате;
- тесты, `DEPLOY_NOW.md`.

Out of scope:
- форма манифеста и снимка — не меняется, старые клиенты (1.6.24) не затронуты;
- ручное обновление из админки (`adminRefreshYoutubeCatalog`) публикует всегда, как раньше.

## Architecture

Отпечатки — sha256 от стабильной сериализации снимка без `version`, `activeVersion`, `generatedAt`,
`sourceRefreshedAt`:
- «структура» — без `viewCount`;
- «экран» — с `viewCount`, округлённым как `components/video/formatViewCount.ts`.

Хранятся только в серверном документе `youtube_catalog/sync_state`.

## Security and privacy

Не затрагиваются: публичный каталог, без персональных данных.

## Technical debt

- Contain: округление просмотров на сервере дублирует клиентский форматтер. Расхождение даст лишь лишнюю или
  пропущенную публикацию, которую закроет потолок 6 ч. Отмечено в коде.

## Verification

Тесты:
- совпало → ни записи снимка, ни чтения проверки, ни удаления; блокировка снята, `nextRunAtMs` сдвинут;
- изменилась структура → публикуем;
- изменились только просмотры:
  - < 6 ч → не публикуем;
  - ≥ 6 ч → публикуем;
- эфир (меняются только просмотры) → не публикуем;
- ручной запуск → публикуем всегда;
- откат версии сбрасывает отпечатки.

Плюс точечная проверка типов.

## Rollback

Откат коммита и повторная выкладка `youtubeCatalogSyncCron`, `adminRefreshYoutubeCatalog`. Данные не мигрируются.
