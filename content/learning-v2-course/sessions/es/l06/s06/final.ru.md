# Испанский · Урок 6 · Занятие 6 — Есть два стула

**Ситуация.** Готовите место для небольшой встречи и считаете мебель.
**Что вы освоите:** после hay назвать точное количество предметов.
**Новые слова:** —
**Повторяем знакомые слова:** haber, dos, tres, silla, mesa, libro.

## Интро 1

### Посчитать места

На встречу пришли двое, и вы нашли два стула. Сообщите `Hay dos sillas` — «Есть два стула». Соберите `Hay` + `dos` + `sillas`. Число ставим перед предметом, без una. После dos нужно sillas с s. Hay остаётся прежним — считать стулья умеем мы, ему менять форму не нужно.

**Сообщите «Есть два стула». Начните с Hay, число поставьте перед предметом.**

- ✅ **Hay dos sillas.** — *Hay + dos + sillas.*
- ❌ Hay dos silla. — *После dos нужно множественное sillas.*
- ❌ Hay una dos sillas. — *Перед dos здесь нет una.*

## Интро 2

### Посчитать столы

В комнате для занятия стоят три стола. Скажите `Hay tres mesas` — «Есть три стола». Соберите `Hay` + `tres` + `mesas`. После tres называем несколько столов: mesas. Между hay и tres артикль не добавляем.

**Сообщите «Есть три стола». Начните с Hay, число поставьте перед предметом.**

- ✅ **Hay tres mesas.** — *Hay + tres + mesas.*
- ❌ Hay tres mesa. — *Столов три: mesas.*
- ❌ Hay una tres mesas. — *Перед числом не нужна una.*

## Интро 3

### Проверить книги для чтения

Для совместного чтения вы нашли две книги. Сообщите `Hay dos libros` — «Есть две книги». Соберите `Hay` + `dos` + `libros`. Dos не меняется из-за рода предмета: dos sillas и dos libros. А у названия нескольких книг сохраняется s.

**Сообщите «Есть две книги». Начните с Hay, число поставьте перед предметом.**

- ✅ **Hay dos libros.** — *Hay + dos + libros.*
- ❌ Hay dos libro. — *Книг две: libros.*
- ❌ Hay un dos libros. — *Перед dos не нужен un.*
