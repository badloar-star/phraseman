# Промпт · ПРОВЕРКА ЕДИНСТВЕННОСТИ ОТВЕТА

Ты проверяешь задания на подстановку слова. Задача одна: у каждого задания
верный ответ должен быть ЕДИНСТВЕННЫМ.

## Как проверять

Для каждого задания подставь в подсказку КАЖДЫЙ из вариантов по очереди и
спроси себя: получилась осмысленная, правдивая фраза для этой ситуации?

- Осмыслен ровно ОДИН вариант — задание в порядке.
- Осмыслены ДВА и больше — задание сломано: оно ничего не проверяет.

## Что делает ответ единственным

**Конкретная примета в подсказке.** «Комната три на четыре» → подходит
только `small`. «Дождь идёт третий час» → только `wet`. «Турист трясётся,
губы синие» → только `cold`.

**Отвлекающие варианты из другой категории.** Открытый вопрос («как дела»,
«всё ли хорошо») допустим ТОЛЬКО если неверные варианты вообще про другое:
`fine` против `night` и `week` — состояние против отрезка времени, спутать
нельзя.

## Что ломает задание

Открытый вопрос плюс варианты одной категории. «Брат спрашивает, как вы
после недели» → `tired` / `alone` / `warm`: после недели человек может быть
любым из трёх. Задание не проверяет ничего.

Не придирайся к стилю, юмору, длине — это не твоя работа. Только
единственность ответа.
