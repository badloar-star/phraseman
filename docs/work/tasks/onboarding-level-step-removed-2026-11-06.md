## Outcome

Онбординг не содержит шага уровня: ни экрана, ни тестов-текстов, ни флага, ни ключа шага, ни веток навигации. Счётчик/полоска шагов считаются без него, «Далее»/«Назад» работают. Уровень по умолчанию — A2 (как при пропуске раньше). Журнал `[ONBOARDING] steps:[…]` на старте. Замок владельца и сторож «шага уровня нет навсегда».

## Scope

In scope: `components/CleanOnboarding.tsx` (тип шага, флаг, порядок, восстановление шага, render, переходы, выбор уровня, статистика ответа), `components/onboarding/clean_onboarding_options.ts` и `clean_onboarding_copy_core.ts` (тексты уровня), `app/onboarding_flow.ts` (id шага, каталог админки), пины в `tests/`, строка в `docs/work/OWNER_LOCKS.md`, новый сторож.
Out of scope: серверные функции статистики уровня (остаются как есть, клиент их больше не зовёт); экзамен/диагностика уровня внутри приложения.

## Architecture

No architecture change: удаление ветки. Сохранённый шаг 'level' у тех, кто остановился на нём в прошлой сессии, безусловно уводит на соседний «notifications». Список включённых шагов из удалённого конфига с 'level' игнорируется (фильтр по каталогу).

## Security and privacy

Сбор данных уменьшается: ответ «уровень» больше не спрашивается и не отправляется (политика остаётся верной). Новых данных нет.

## Technical debt

Pay now: тексты, флаг, ветки, каталог админки. Contain: сторож в тестах; серверная статистика уровня — сирота, вынесена в отчёт.
