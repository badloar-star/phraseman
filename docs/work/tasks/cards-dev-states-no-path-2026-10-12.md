# Task packet: dev-состояния Карточек для съёмки — снять «нет пути» (hold / fail / speech / train_gate / moderation / demo_published / notranslation)

Governance-ID: TG-B6946C649397
Status: In progress
Owner: сессия «2 · ДИЗАЙН» по поручению координатора (12.10; docs/phraseman-2.0/R1_SHOT_LIST.md «Остаётся нет пути», детали — R1_SHOT_LIST_CARDS.md Н-1…Н-12)
Related epic/enabler: R1 робот-съёмка (Maestro), app/dev_state_fixtures.ts

## Outcome

Робот снимает состояния Карточек, которые штатно не воспроизвести: загрузки (скелеты), ошибки чтения и записи, отказ слоя отложенной выдачи тренировки, ввод распознанной речи в «Устно», окна решений модерации набора, опубликованный набор автора, карточки без перевода. Результат: одна ссылка `dev_state?…` выставляет нужное состояние, снимок совпадает с макетом. Мера успеха: все строки из списка «нет пути» по Карточкам имеют параметр; в стор-сборке параметры ничего не делают (тест).

## Scope

In scope: новый модуль флагов `app/dev_cards_state.ts` (в памяти процесса, как `app/dev_dialog_state.ts`); разбор параметров `hold=`, `fail=`, `speech=`, `train_gate=`, `moderation=`, `cards=demo_published|notranslation` в `app/dev_state_fixtures.ts` (+ фикстуры в `app/dev_state_cards_demo.ts`); точечные dev-точки внедрения в экранах/хуках Карточек (скелеты загрузки, сбой чтения/записи, шторка тренировки, голосовой пикер, «Устно», окно модерации); тесты; обновление «нет пути» в R1_SHOT_LIST.md.

Out of scope: изменение поведения для пользователей; вид экранов; серверные вызовы и запись в Firestore (всё локально, без сети); внешний вид обводок (Темы), правки FlashcardsHubScreen по макетам (Макеты) — при пересечении только мои строки отдельным коммитом из чистой копии HEAD.

## Architecture

No architecture change: флаги в памяти процесса, геттеры возвращают «выключено» вне `__DEV__ && !IS_STORE_RELEASE`; точка внедрения — одна строка-условие у существующего места (скелет/catch/результат). Данные пользователя не пишутся; фикстуры карточек — только локальные ключи устройства, как `cards=demo`.

## Security and privacy

Новых данных, разрешений и сторонних сервисов нет. Сеть и Firestore не используются; в стор-сборке маршрут `dev_state` вырезан, а геттеры гасят флаги. Распознанный «транскрипт» `speech=` — фиксированная тестовая фраза, не пользовательская.

## Technical debt

Contain: тест «в стор-сборке не действует» на каждый флаг; логи `[DEV-STATE]` на каждой ветке. Accept temporarily: точки внедрения остаются в продуктовом коде до конца R1 (владелец — координатор Сверки), после — удалить вместе со списком «нет пути».
