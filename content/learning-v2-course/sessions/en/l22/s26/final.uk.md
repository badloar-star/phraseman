# Англійська · Урок 22 · Заняття 26 — Зручні речі на щодень

**Ситуація.** Ви обираєте речі для тепла й зручності.

**Що ви опануєте:** determiner|adjective + one|ones
**Нові слова:** thermal, padded, non-slip, cushioned

## Інтро 1

### Теплі шкарпетки

Thermal в описі одягу — такий, що зберігає тепло, наприклад thermal socks для холодної погоди. Обираємо шкарпетки: socks стоїть у множині, тому the thermal ones. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I want the thermal ones.**
- ❌ I want the thermal one. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I want the thermal them. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*

## Інтро 2

### М’яка куртка й килимок

Padded — із м’якою набивкою, наприклад куртка з утеплювальним шаром. Non-slip — нековзний, наприклад килимок із поверхнею, яка менше ковзає. У прикладах куртка й килимок по одному: one. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I prefer the padded one.**
- ❌ I prefer the padded ones. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I prefer the padded it. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*

## Інтро 3

### М’яка підкладка

Cushioned — із м’якою підкладкою або шаром, який пом’якшує тиск. У прикладі обираємо взуття з м’якою опорою для стопи. Shoes — множина, тому the cushioned ones. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ❌ I like the cushioned them. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
