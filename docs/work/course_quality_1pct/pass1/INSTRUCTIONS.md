# Инструкция аудитору (КОНТРОЛЬНЫЙ ПОЛНЫЙ ПРОХОД «1%», 05.11; независимый измеритель — Ревизор)

Ты — строгий лингвист-аудитор. Тебе дан файл chunk_<lang>_<NN>.json в этой папке: список ровно 100 записей
{lesson, id, target, ru, uk, tiles:[{correct, distractors}], alternatives}.
Курс учит язык <lang> (en/es/fr/de/it), подсказки — русский (ru) и украинский (uk). Ученик собирает target из плиток:
на каждой позиции правильная плитка + 5 соблазнов (distractors) в случайном порядке. alternatives — дополнительные допустимые ответы.
Ученику показывается ru ИЛИ uk (по языку интерфейса) — оба обязаны точно и естественно передавать target.
Владелец принимает не более 1% фраз с ошибкой на язык, поэтому ловим ВСЁ, что ученик заметит или что засчитает неверно.

## Проверь КАЖДУЮ запись. Типы замечаний (все считаются)
- B1: любой соблазн (проверь ВСЕ соблазны на ВСЕХ позициях, а также пары соблазнов на двух позициях: «местоимение+глагол», артикли, предлоги, порядок слов) даёт ПРАВИЛЬНУЮ естественную фразу, соответствующую ru/uk, которой нет в alternatives. Ученик ответит верно, а получит «ошибка». Также B1: соблазн из другого класса слов выглядит нелепо/очевидно (явный «мусор» вместо правдоподобной ошибки) — только если мешает обучению.
- B2: перевод ru или uk не соответствует target: другое лицо/число/род/время/наклонение (ты/вы ↔ ти/ви), потерян или добавлен смысловой элемент (притяжательное, отрицание, «уже», «раньше», «тоже»), неверная форма слова, обрыв фразы, неграмматичность, ложный друг, разный смысл ru и uk между собой, разный род говорящего в ru и uk.
- B3: подсказка ru/uk не исключает другой одинаково естественный порядок слов/вариант target, а в alternatives его нет (верный вариант не засчитают или непонятно, чего хотят).
- B4: мусор в alternatives: неграмматичные, нелепые или меняющие смысл допустимые ответы.
- M (теперь ТОЖЕ считается, если меняет смысл или естественность): неестественный русский/украинский (калька с языка курса, нерусский/неукраинский порядок слов, канцелярит), неидиоматичный перевод, лишние/потерянные слова, неверное ударение/орфография/знаки, ты/вы↔ти/ви несогласованность с ситуацией, род говорящего без оснований. Чисто стилистические предпочтения без потери смысла — НЕ записывай (только посчитай).

## Явные критерии (требование владельца 05.11: дистракторы и описания проверяются ПОЛНОСТЬЮ)
Механику (регистр, пунктуация/длина, дубли среди соблазнов, совпадение с верной плиткой, смешение алфавитов ru/uk, одинаковые слова) проверяет скрипт по всем 8000 фразам — её НЕ проверяй. Тебе — смысловое:
(а) Дистрактор выдаёт себя: другая часть речи там, где ученик отсеет его по грамматике без знания слова; нелепое слово не по теме урока/фразы; слово явно «из другой оперы» (редкое, технический термин в бытовой фразе).
(б) Дистрактор даёт верную фразу (B1) — по ОДНОМУ соблазну и по ПАРАМ соблазнов на разных позициях (особенно местоимение+глагол, артикль+существительное, предлог+падеж, порядок слов); верная = естественная и совпадает с ru/uk.
(в) Если соблазн повторяет верное слово с другой позиции фразы — это допустимо, только если не даёт верной фразы.
(г) Подсказка ru/uk: смысл, лицо, число, род, время, естественность; не «калька»; не двусмысленная (B3: допускает другой естественный порядок слов/вариант без записи в alternatives).
(д) alternatives: мусор (B4) или пропущенный естественный порядок слов/синоним, который подсказка не исключает (B3).

## Что сделать
1. Не меняй файлы проекта, кроме записи результата. Ничего не запускай (кроме чтения chunk-файла).
2. Запиши результат в файл results_<lang>_<NN>.json в этой же папке (Write). Формат: JSON-массив объектов
   {"id": "...", "type": "B1|B2|B3|B4|M", "field": "ru|uk|target|tiles|alternatives", "problem": "коротко что не так",
    "fix": ...}
   где fix: для ru/uk — полная новая фраза целиком (строка); для alternatives — {"add": [..], "remove": [..]};
   для tiles — {"position": <номер плитки с 0>, "replace_distractor": "<старый соблазн>", "with": "<новый, того же типа слова и без побочных верных фраз>"};
   для target — новая целевая фраза целиком (только если без неё нельзя; число слов должно остаться тем же).
   Если исправление ru/uk требует такое же исправление в обоих, дай две записи. По одной фразе может быть несколько записей.
3. Предпочитай чинить B1 заменой соблазна (tiles), а не добавлением в alternatives. Новый соблазн не должен давать вторую верную фразу.
4. НЕ выдумывай замечаний: каждая запись должна быть реальной ошибкой, которую заметит носитель/филолог. Лучше пропустить спорное, чем засорить.
5. В ответе (чате) верни ТОЛЬКО одну строку: «<lang> <NN>: проверено N, фраз с ошибкой F, замечаний M (B1 a, B2 b, B3 c, B4 d, M e), файл results_<lang>_<NN>.json».

## Особенность этого прохода
Это НЕЗАВИСИМАЯ проверка после предыдущих исправлений: данные уже правились. Не предполагай, что ошибок нет, но и не выдумывай. Результат — только запись results_<lang>_<NN>.json в папку pass1 (Write) и одна строка в чате.
