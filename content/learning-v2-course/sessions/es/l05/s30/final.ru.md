# Испанский · Урок 5 · Занятие 30 — У них нет машины

**Ситуация.** Объясняете, чего нет у друзей перед общей поездкой.
**Что вы освоите:** поставить no между ellos или ellas и tienen.
**Новые слова:** —
**Повторяем знакомые слова:** ellos, ellas, no, tener, carro, tiempo, llave.

## Интро 1

### Друзей нужно подвезти

Два друга просят подвезти их. Объясните водителю `Ellos no tienen carro` — «У них нет машины». Соберите `Ellos` + `no` + `tienen` + `carro`. Сначала называем людей, затем ставим no прямо перед tienen. Людей несколько, поэтому tienen с n. В этой фразе об отсутствии машины используем carro без артикля.

**Скажите «У них нет машины». Начните с Ellos no tienen, используйте carro без артикля.**

- ✅ **Ellos no tienen carro.** — *Ellos + no tienen + carro.*
- ❌ Ellos tienen no carro. — *No ставим перед tienen.*
- ❌ Ellos no tiene carro. — *С ellos нужно tienen.*

## Интро 2

### Друзья спешат

Друзья не могут задержаться для разговора. Сообщите `Ellos no tienen tiempo` — «У них нет времени». Соберите `Ellos` + `no tienen` + `tiempo`. Сохраняем отрицание перед tienen, затем называем то, чего нет. Tiempo в этой фразе без артикля.

**Скажите «У них нет времени». Начните с Ellos no tienen.**

- ✅ **Ellos no tienen tiempo.** — *Ellos + no tienen + tiempo.*
- ❌ Ellos tienen no tiempo. — *No должно стоять перед tienen.*
- ❌ Ellos no tenemos tiempo. — *Tenemos — «мы»; о них нужно tienen.*

## Интро 3

### Подруги забыли ключ

Две подруги ждут у двери. Поясните соседу `Ellas no tienen llave` — «У них нет ключа». Соберите `Ellas` + `no` + `tienen` + `llave`. О женщинах используем ellas, но отрицание no tienen остаётся таким же. Для этой фразы об отсутствии ключа используем llave без артикля.

**Скажите о подругах «У них нет ключа». Начните с Ellas no tienen, используйте llave без артикля.**

- ✅ **Ellas no tienen llave.** — *Ellas + no tienen + llave.*
- ❌ Ellas tienen no llave. — *No ставим перед tienen.*
- ❌ Ellas no tiene llave. — *С ellas нужно tienen.*
