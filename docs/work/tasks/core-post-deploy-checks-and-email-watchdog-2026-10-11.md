## Architecture
Проба ключа остаётся одним GET без отправки писем. Ответ 401 с признаком ключа «только для отправки» (`restricted_api_key`
/ «restricted to only send emails») трактуется как живой ключ: значит, ключ принят сервисом, ему лишь закрыто чтение
списка ключей. Любой другой 401/403 — по-прежнему мёртвый ключ.
