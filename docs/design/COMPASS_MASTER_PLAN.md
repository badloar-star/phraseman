# Компас — большой план: глобальная обучающая нервная система Phraseman

> Статус: ДИЗАЙН-ПЛАН (код не написан). Версия 2.0 — 2026-06-20.
> Амбиция (зафиксирована с пользователем): ГИБРИД (правила-скелет + ИИ-голос сверху),
> охват ПОЛНЫЙ (учёба + экономика + мотивация + статистика/админка),
> связь фич = «читает и зовёт» + единая «карта памяти» (читает всё, пишет только свою карту —
> прогресс каждой фичи остаётся раздельным).
> Все пользовательские тексты — строго по `PHRASEMAN_BIBLE.md` + `docs/personal-plans-copy-style.md`.

## 0. Манифест: что мы на самом деле строим

Не «ещё одну карточку на главной». Мы строим **нервную систему приложения** — единый слой,
который чувствует весь путь ученика по всем ~26 частям и осмысленно дирижирует им: что учить,
как наградить, когда вернуть, что показать в результатах.

Сегодня в приложении 26 отличных фич, но они **не разговаривают друг с другом**. Урок не знает
про план, план не знает про ошибки, награды перекошены, статистика разрознена. Компас — это
**мозг, который связывает всё**, не ломая ни одну часть.

Три закона Компаса (нерушимы):
1. **Читает и зовёт, не захватывает.** Компас читает сигналы всех фич и зовёт в нужную. Прогресс
   каждой фичи остаётся её собственным. Единственное, что Компас пишет — свою «карту тем».
2. **Дёшево по умолчанию.** Решения (что показать, как наградить) — детерминированные правила,
   0 токенов. ИИ — тонкий слой сверху: тёплый текст и лёгкая подкрутка, кэш один на весь продукт.
3. **Говорит как человек.** Каждое слово — по Библии Phraseman. Тёплый Тренер, «ты», gain-framing.

## 1. Архитектура: 5 слоёв (фундамент → ядро → 4 крыла → оболочка)

```
┌──────────────────────── ОБОЛОЧКА (UI + Админка) ────────────────────────┐
│  Брифинг дня · плашка-зов · блок «Твой Компас» · раздел в админке         │
├──────────── 4 КРЫЛА (учёба · экономика · мотивация · память) ────────────┤
│  что учить  │  как наградить  │  когда вернуть  │  карта тем (зеркало)    │
├──────────────────────── ЯДРО (мозг Компаса) ────────────────────────────┤
│  собирает «День» из сигналов · выбирает тип дня · решает правилами        │
│  + тонкий ИИ-голос (gpt-4.1-nano, кэш 1-на-продукт, kill-switch)          │
├──────────────────── ФУНДАМЕНТ (шина сигналов) ──────────────────────────┤
│  единый ридер всех сигналов: ошибки · SRS · мастерство · план · стрик     │
│  + премиум-гейт (чинит дыру) + флаги/конфиг (живые рычаги)                │
└──────────────────────────────────────────────────────────────────────────┘
        ↑ читает готовые системы (mistake_log, trainer_store, pos, plan_state, xp)
```

### 1.1 ФУНДАМЕНТ — Шина сигналов (Signal Bus)
Единая точка, через которую Компас читает ВСЁ приложение. Без неё каждое крыло лезло бы в 6 сторов.

`app/compass/signal_bus.ts` (НОВЫЙ) — один объект `CompassSnapshot`, собранный из готового:
| Поле снимка | Источник (готовый, читаем) | Тип сигнала |
|---|---|---|
| `mistakes` | `mistake_log.ts` getTopMistakePhraseDetails / getMistakeCountByLesson | где спотыкается |
| `srsDue` | `trainer_store.ts` getTrainerCounts / getTrainerDashboard | что пора повторить |
| `posMastery` | `pos_workout_engine.ts` getPosMasterySnapshot (15 тем) | сила тем |
| `planDay` | `personal_plan_state.ts` PersonalPlanHomeSnapshot | где в плане |
| `planWeak` | `personal_plan_weak_spot_reader.ts` readPlanWeakSpotView | слабые места плана |
| `passedLessons` | `plan_day_lesson_recommendation.ts` readPassedLessonIds | что пройдено |
| `streak` / `energy` | `xp_manager.ts` / energy_system | темп, ресурс |
| `lastSeenAt` | xp daily_stats | пауза/возврат |
| `premium` | `PremiumContext.tsx` hasPremiumAccess | гейт |

Плюс в фундаменте:
- **Премиум-гейт (чинит дыру).** Одна точка `compass_access.ts`: гейт перед `activatePersonalPlan`
  (`personal_plan_setup.tsx:298`) и в брифинге. Free видит превью Компаса, не функцию.
- **Конфиг/флаги.** `compass_flags.ts` читает remote_config (тумблеры всех фич Компаса + тексты),
  как Пульт. Всё включается/гасится без релиза.

### 1.2 ЯДРО — Мозг (гибрид: правила + ИИ-голос)
`app/compass/compass_brain.ts` (НОВЫЙ) — чистая функция `CompassSnapshot → CompassDay`. 0 ИИ.

Гибрид работает так:
- **Скелет дня = правила (детерминированно, дёшево).** Мозг выбирает ТИП дня и 3–5 задач
  сортировкой по готовым числам важности (priorityScore, mistakeCount, srsDue, posMastery).
- **ИИ-голос сверху (тонко, кэшировано).** ИИ получает briefing-числа + allowlist тем и:
  (а) пишет тёплый комментарий дня по Библии; (б) может слегка переупорядочить/выбрать тему
  ИЗ allowlist (как weekly_review parseAndGuardResult). ИИ НЕ видит сырых логов, НЕ создаёт контент.
- **Fallback.** ИИ выкл/бюджет исчёрпан → шаблон Библии. День всё равно собран. ИИ — украшение.

`functions/src/compass.ts` (НОВЫЙ) — CF `compassGenerate`, клон `explain_choice.ts`:
auth → AppCheck → `resolveJobConfig(db,'compass')` → cache-first → budget → lock →
`gpt-4.1-nano` → judge → cache. Кэш `compass_briefings` по `compassHashFor(signature, lang)`.

### 1.3 ЧЕТЫРЕ КРЫЛА

Каждое крыло — отдельный модуль, читает снимок, отвечает за свою грань. Это и есть «оживление».

#### Крыло A — УЧЁБА (что делать сегодня) — `compass_learn.ts`
- Собирает задачи дня из всех фич: сессия-погружение, разбор фраз, повтор карточек, голос, квиз,
  диалог (premium), вызов арены (для азартных).
- 4 типа дня: 🟢 лёгкий · 📖 погружение · 🩹 ремонт · 🔁 возврат (выбор правилами по снимку).
- **Зов в фичу** (главная связь): рабочая кнопка «Открыть сессию» там, где сейчас мёртвый текст
  (`personal_plan.tsx:627`). Распространяется на ВСЕ режимы: ошибся 2× на теме → плашка-зов.

#### Крыло B — ЭКОНОМИКА (как наградить) — `compass_economy.ts`
- **Чинит перекос наград.** Сейчас: урок = XP+сундук+медали+осколки; задание плана = плоско 6 XP;
  день плана = +2 осколка. Компас вводит **единый «вес дня»**: закрытый день Компаса = достойная
  награда (переменная, как сундук урока — `variable_reward_system.ts`), чтобы день плана не
  чувствовался дешевле сессии.
- **«Печать дня»** — за закрытый день Компаса осколки + бонус-XP, идемпотентно (как
  personal_plan_day_reward, но богаче и единообразно по всем типам дня).
- **Анти-фарм.** Компас знает, что одна тема пройдена в уроке И в плане — не задваивает награду
  за один смысл (читает passedLessons + mistake-resolved). Награда честная.
- Тексты наград — Игра+Тренер по Библии («7 фраз за 4 минуты. Серия: 5 дней 🔥»).

#### Крыло C — МОТИВАЦИЯ (когда вернуть) — `compass_retention.ts`
- **Умный возврат.** Пауза → день-возврат: «Ты вернулся. Хорошо. Начнём с трёх фраз.» (Библия).
  Не carryover-затык (как сейчас), а тёплый короткий день из почти забытых фраз.
- **Защита серии.** Компас бережёт стрик: подсказывает «5 минут — и серия цела» (Библия,
  loss-framing ТОЛЬКО для активных 7+ дней — правило Библии).
- **Умные пуши.** Компас формирует push-текст по Библии и по снимку («В твоей теме — новые фразы»),
  через существующий re_engage_push. Без запугивания, без фальшивой срочности (запрет Библии).
- **Близкие вехи.** Подсвечивает достижение в одном шаге (achievement_nearest).

#### Крыло D — ПАМЯТЬ (карта тем) — `compass_memory.ts`
- Единая **карта тем** (Приветствия / Прошедшее / Артикли / Present Perfect…). Читает posMastery +
  mistake_log + passedLessons. Растёт от ЛЮБОЙ активности любой фичи.
- ЭТО единственное, что Компас ПИШЕТ (своя коллекция `compass_topic_map`). Прогресс фич не трогает.
- Карта = и топливо мозга («веди в слабую тему»), и зеркало для ученика (см. крыло-оболочку).

### 1.4 ОБОЛОЧКА — UI + Админка
- **Брифинг дня** `compass_briefing_modal.tsx` — модал входа (тексты Библии).
- **Плашка-зов** `compass_lesson_invite.tsx` — во всех режимах упражнений.
- **Блок «Твой Компас»** в существующий `streak_stats.tsx` (карта тем + серия + дней закрыто).

## 2. Дёшево: точная экономика ИИ

| Что | Решение | Стоимость |
|---|---|---|
| Выбор типа дня и задач | правила по готовым числам | 0 токенов |
| Карта тем | детерминированный агрегат | 0 токенов |
| Награды/возврат/пуш-выбор | правила | 0 токенов |
| Тёплый текст дня | ИИ gpt-4.1-nano, кэш по подписи дня | ~центы/день на продукт |
| Подкрутка темы из allowlist | в том же 1 вызове | включено |

Почему дёшево: подписей дня мало и они повторяются («новичок, слаб в артиклях, день-ремонт» —
одна на тысячи учеников). Кэш 1-на-продукт (как explainChoice) → 90%+ показов = 0 токенов.
Бюджет user+global + kill-switch = жёсткий потолок расходов. Fallback = всё работает и без ИИ.

## 4. Раздел «Компас» в админке (`admin/index.html`)

Новая вкладка `compass`, три под-секции (переиспользует инфру Пульта + Explain cache).

### Аналитика
- брифингов/день, **% cache-hit** (видна дешевизна), расход ИИ, уник. подписей дня.
- распределение типов дня (лёгкий/погружение/ремонт/возврат).
- топ тем, куда Компас ведёт всех (агрегат карты тем) — продуктовый инсайт.

### Статистика
- сколько получают Компас, средняя серия с Компасом, % дней закрыто.
- conversion: free увидел запертый Компас → Premium.
- эффект на удержание (D1/D7) до/после Компаса.

### Управление (живые рычаги)
- kill-switch job `compass` (мгновенно гасит ИИ, остаётся fallback).
- модель (`gpt-4.1-nano`/`gpt-4o-mini`) + капы user/global (openAiJobsConfig).
- тумблеры крыльев: дни-погружения, плашка-зов, единый вес наград, умный возврат, умные пуши, карта тем.
- редактор fallback-текстов (remote_config texts-слой).
- удаление кэша брифингов → регенерация (как Explain cache).

## 5. Волны внедрения (не 7 косметических шагов — 5 волн настоящей системы)

Каждая волна — самостоятельная ценность. Внутри волны — атомарные коммиты.

### ВОЛНА 1 — ФУНДАМЕНТ (без ИИ, чинит дыры)
1. Премиум-гейт: закрыть течь (`compass_access.ts` перед activatePersonalPlan).
2. Шина сигналов `signal_bus.ts` — единый снимок из всех готовых стора.
3. Флаги/конфиг `compass_flags.ts` (тумблеры + тексты из remote_config).
> Результат: фундамент стоит, дыра закрыта, всё за тумблерами.

### ВОЛНА 2 — ЯДРО + УЧЁБА (без ИИ, виден Компас)
4. Мозг `compass_brain.ts` (типы дня + задачи, правилами).
5. `compass_copy.ts` + брифинг-модал (тексты Библии, fallback).
6. Крыло A: плашка-зов во всех режимах + рабочая кнопка в сессию.
> Результат: ученик видит один осмысленный день. Уроки приходят на помощь. ИИ ещё не нужен.

### ВОЛНА 3 — ЭКОНОМИКА + МОТИВАЦИЯ (без ИИ, оживление)
7. Крыло B: единый вес дня, печать дня, анти-фарм.
8. Крыло C: умный возврат, защита серии, умные пуши (тексты Библии).
> Результат: награды честные и ровные, удержание оживает. Это «оживление приложения».

### ВОЛНА 4 — ПАМЯТЬ + СТАТИСТИКА (без ИИ)
9. Крыло D: карта тем (`compass_topic_map`, читает всё, пишет только себя).
10. Блок «Твой Компас» в общий стат-хаб.
> Результат: единое зеркало прогресса, мозг ведёт в слабые темы.

### ВОЛНА 5 — ИИ-ГОЛОС + АДМИНКА (ИИ за выключателем)
11. CF `compassGenerate` + кэш + бюджет + job `compass` (дешёвый живой голос).
12. Раздел «Компас» в админке: Аналитика · Статистика · Управление.
> Результат: тёплый адаптивный голос; полный контроль и видимая дешевизна.

**Итого: 5 волн, 12 крупных блоков.** 4 волны из 5 работают вообще без ИИ (бесплатно).
ИИ — только Волна 5, сразу за kill-switch.

## 7. Чеклист Библии (для каждого текста Компаса)
1. Глагол в кнопке. 2. Gain-framing. 3. Нет «урок/ошибка/статистика/цена/купить» (замены).
4. ≤10 слов, одна мысль — строка. 5. Звучит как живой Тренер.
Запрещено: запугивание, фальшивая срочность, «вы», тех-коды, слова-паразиты, унижение за ошибку.
