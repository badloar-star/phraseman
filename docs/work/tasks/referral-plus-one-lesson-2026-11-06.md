# Task packet: Plus за друга — достаточно одного пройденного урока любого курса

## Outcome
Слово владельца (06.11, через координатора): «Награда за друга» — для Plus другу нужно просто пройти 1 урок (обычный, «старый» курс); условие «заниматься в новом курсе» убрать. Сейчас Plus за друзей требует итоги Learning V2 в 2 разных серверных дня, V2 скрыт у большинства, поэтому Plus за друзей почти недостижим. Результат: друг засчитывается для Plus при ≥1 уроке любого курса по серверному источнику монет (`contestLessonsCompleted`); друзья, ждавшие второго дня (`waiting` / `days_missing`), пересчитываются.

## Scope
- `functions/src/referral_ladder_plus.ts`: решение `decideLadderPlusEligibility` по числу уроков вместо двух серверных дней; новые причины `lesson_missing`, `lesson_device_different`, `lesson_device_unknown`.
- `functions/src/referral_ladder_server.ts`: передача числа уроков из `contestLessonsCompleted`, журнал `[REFERRAL-PLUS]` на каждом решении, пересчёт `waiting`-друзей в повторе пригласившего (до 5 за заход).
- Тесты `functions/src/referral_ladder_plus.test.ts` и новые на пересчёт.
- Деплой только затронутых функций поимённо, логи ERROR 20 минут.
- Вне объёма: текст в приложении (Дизайн), защита от накрутки сверх монетной, клиент.

## Architecture
Единый источник «пройденный урок» — тот же, что для монет. Решение остаётся чистой функцией, Firestore-обвязка в `referral_ladder_server.ts` не меняется, кроме пересчёта ожидающих.

## Security and privacy
Защита от накрутки: серверный счётчик уроков (как у монет) + проверка того же устройства (хэш push-токена) + кулдаун 30 дней на пригласившего. В журнал идут только хэши идентификаторов.
