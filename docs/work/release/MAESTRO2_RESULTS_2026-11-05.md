## Находки по способу запуска
- При `newbie=on` приложение сразу уходит в вступление урока 1, экран DEV-STATE может не успеть показаться: не ждать его жёстко.
- Составная ссылка `set=a:b,c:d` на этом эмуляторе экран DEV-STATE не открыла; рабочая форма `a=b&c=d`.
- `uiLang` и `coinRank` живут только в памяти: применять после запуска, без перезапуска приложения.
- После перезапуска adb нужно заново `adb -s emulator-5562 reverse tcp:8081 tcp:8081`, иначе «Unable to load script».
- Ссылки с `(tabs)` через `adb shell am start` ломаются на скобках; в Maestro `openLink` работает.
- Урок 11 без подписки — окно «Rest is in Ultra»; после подписки открывается экран «Открытие раздела» (PHRASEMAN PLUS), он перекрывает меню урока.
