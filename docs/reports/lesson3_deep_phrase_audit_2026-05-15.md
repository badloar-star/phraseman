# Углубленный аудит фраз урока 3

Дата: 2026-05-15

Источник активных фраз: `app/lesson_data_1_8_phrases_es.gen.ts`, импортируется через `app/lesson_data_1_8.ts`.

## Итог

Урок 3 можно считать безопасным для текущего RU/UK релиза. В активном английском режиме 50 фраз совпадают со слотами `wordsEn[]`, правильные ответы присутствуют, автоматический аудит переводов не нашел проблем.

Тема урока выдержана: Present Simple, утверждения. Покрыты `I/you/we/they + base verb`, `he/she/it + verb-s`, объектные местоимения, простые дополнения и частотные/оценочные слова.

- `npm run audit:lesson-drill-quality`: OK, 0 warnings.
- `npm run audit:lesson-words`: OK, строгий live source без stale vocabulary refs.
- `npm run audit:lesson-sections`: урок 3 = OK. Общий скрипт падает на других уроках, не на уроке 3.
- Ручная структурная проверка Lesson 3: 50 фраз, `wordsEn[]` vs `english` = 0 расхождений.

## Что проверено вручную

- Все EN-фразы являются утверждениями Present Simple, без отрицаний/вопросов из следующих уроков.
- Для `he/she/it` в английском используется форма с `-s`: `lives`, `helps`, `eats`, `speaks`, `costs`, `writes`, `washes`, `cooks`, `works`, `needs`, `knows`, `takes`, `sounds`, `remembers`.
- Для `I/you/we/they` используется базовая форма: `work`, `understand`, `drink`, `watch`, `know`, `help`, `buy`, `live`, `read`, `listen`, `drive`, `travel`, `need`, `trust`, `order`.
- RU/UK переводы сохраняют лицо, число и объект.
- В словах ответа нет расхождений с отображаемой английской фразой.

## Замечания

- `vocab_repeat` ожидаем: местоимения и `here` повторяются из ранних уроков.
- `lesson3_phrase_50`: `You help friends` переведено как `Вы помогаете друзьям / Ви допомагаєте друзям`, тогда как многие другие `you` в уроке 3 переведены через `ты/ти`. Это не ошибка, но перед релизом нужно убедиться, что курс сознательно чередует значения `you`.
- `lesson3_phrase_46`: `They come late` = `Они приходят поздно / Вони приходять пізно`. Смысл сохранен; в некоторых контекстах естественнее `опаздывают`, но для тренировки `come` вариант допустим.
- `lesson3_phrase_24`: `I feel tired` = `Я чувствую усталость / Я відчуваю втому`. Семантически верно; более разговорно было бы `Я устал / Я втомився`, но текущий вариант лучше показывает глагол `feel`.
- Скрытый нерелизный риск: Spanish study пока отсутствует в приложении, но в данных урока 3 есть 32 расхождения `spanish` vs `words[]`. Не влияет на RU/UK релиз, пока испанский режим недоступен.

## Релизный чеклист

- [ ] Открыть урок 3 в RU-интерфейсе и пройти все 50 фраз.
