# Пейвол Plus: карта цветов на токенах тем (заранее, до макетов)

Для: 3 · МАКЕТЫ (контекстные пейволы по `docs/work/research/paywall-research-2026-10-25.md`), 2 · ДИЗАЙН, сессии пейвола. Подготовил: 4 · ТЕМЫ, 25.10.2026. Код пейвола не менялся.

**Поверхности — те же, что у текущего `PaywallPlus`:** лист `paywallSheetBg` (`opaqueSheet`), плашки планов и таймлайна `paywallPlateBg` (светлая: `opaqueControl`, тёмная: `sheetPlateFillFrom`), выбранный план `planRowSelectedPaint` (градиент `accent` 30 % → плашка 90 %; подписи доводятся `legibleOn` до 4,55). Новый пейвол на этих поверхностях наследует проверенные цифры ниже; другая поверхность — пересчитать.

**Правило сторов (исследование, раздел 5):** реальная сумма списания не может быть тише триала. Поэтому в карте сумма списания — обычный текст (`text` / `planRowSelectedPaint.ink`), а не приглушённый, а строка триала не ярче её. «Не сейчас» и «Восстановить покупки» — `secondary` (≥ 4,5 во всех темах): прятать выход тусклым цветом — тёмный паттерн, сторы за это отклоняют.

**Как проверено:** 29 тем × светлая/тёмная × Спокойно/Акцент/Максимум = 174 сочетания × 22 роли = 3828 пар. Для выбранного плана берётся худшая точка его градиента. Порог: текст 4,5, графика (рамка, галочка, точки таймлайна, кнопка на листе) 3,0. **Итог по карте: 0 нарушений.** Скрипт: `scripts/paywall_contrast_measure.ts` (`npx tsx scripts/paywall_contrast_measure.ts`). Он сверяет свою копию функций поверхностей с исходником и падает, если исходник изменился.

## Заметки для макетов

- **Запас тонкий** у четырёх ролей (минимум 4,51–4,56): подпись кнопки покупки (`ctaFillInk` на `ctaFill`, «Оливковая» светлая), подписи выбранного плана (доводятся ровно до 4,55), акцент таймлайна `accentTextSafe`. Цвета этих ролей на макете не «подкрашивать» и не делать прозрачными — запаса нет.
- **Не использовать прозрачность для «вторичного»** («Не сейчас», мелкие условия): берите `secondary` / `mutedText`, а не текст с opacity — прозрачность роняет контраст ниже порога.
- **Бейдж скидки** — смысловое золото `#FFD27A` / `#3A2700` (исключение из правила тем, уже утверждено в `PaywallPlanRows.tsx`), 10,0.
- **Без рамок:** план выделяется градиентом и тонкой подсветкой `accentGraphic`, не обводкой; плашки — тоном (`paywallPlateBg`).
- **Когда Макеты выпустят пейвол:** прогнать этот же скрипт по ролям из макета; если появится новая поверхность (фото, иллюстрация под текстом, тёмная полоса) — добавить её роль в скрипт.
