# Два неприменённых патча «тема по умолчанию для новых — Аврора» (вопрос 3 владельца)

Governance-ID: TG-8A12317D000D

Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора: ответ владельца на вопрос 3 должен стать одной командой)

## Outcome
В `docs/phraseman-2.0/patches/` лежат два готовых патча, не применённых к коду: `DEFAULT_THEME_AURORA_L1_2026-10-13.diff` (Аврора, уровень 1) и `DEFAULT_THEME_AURORA_L05_2026-10-13.diff` (Аврора, уровень 0,5). Каждый меняет одну константу `NEW_USER_DEFAULT_THEME` и обновляет тест. Оба проходят `git apply --check`.

## Scope
Только новые файлы-патчи и временный скрипт сборки вне репозитория. Код приложения и тесты в рабочем дереве НЕ меняются; применяет патч владелец командой `git apply`.

## Architecture
Используется готовый механизм метки первого запуска (`decideFirstRunTheme`, коммит ce69facd8): новичок (нет ключей темы и онбординг не пройден) получает тему из константы, существующий без ключей остаётся прежним, сохранённый выбор пользователя всегда сильнее. Патч меняет только константу и ожидания теста.

## Security and privacy
Данные не собираются и не передаются: меняется только локальная тема по умолчанию.

## Technical debt
После применения патча первый кейс старого теста («конфиг равен встроенному дефолту») заменяется новым ожиданием; строку решения надо записать в `03_DECISIONS.md`, а правку кода коммитить в окне :00–:05 или :30–:35.

## Verification
`git apply --check` для обоих патчей на текущем дереве; точечный прогон `tests/theme_first_run_default.test.ts` после применения — только по слоту светофора.

## Rollback
Удалить файлы патчей; если патч применён — `git revert` его коммита.
