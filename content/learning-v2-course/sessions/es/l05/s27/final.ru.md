# Испанский · Урок 5 · Занятие 27 — У них есть книга

**Ситуация.** Рассказываете о вещах двух друзей, которые едут с вами.
**Что вы освоите:** соединить ellos с tienen, когда говорите о нескольких других людях.
**Новые слова:** —
**Повторяем знакомые слова:** ellos, tener, libro, carro, llave.

## Интро 1

### Книга у друзей

Два друга взяли книгу в дорогу. Расскажите о них `Ellos tienen un libro` — «У них есть книга». Соберите `Ellos` + `tienen` + `un libro`. Ellos обозначает нескольких мужчин или смешанную группу; с ним нужна форма tienen с n на конце. Tiene относится к одному человеку, tienen — к нескольким. Здесь книга одна, хотя людей двое.

**Скажите «У них есть книга». Начните с Ellos tienen.**

- ✅ **Ellos tienen un libro.** — *Ellos + tienen + un libro.*
- ❌ Ellos tiene un libro. — *Людей несколько: tienen с n.*
- ❌ Ellos tenemos un libro. — *Tenemos — «у нас»; о них нужно tienen.*

## Интро 2

### Их машина

Друг и подруга едут вместе на машине. Сообщите `Ellos tienen un carro` — «У них есть машина». Соберите `Ellos` + `tienen` + `un carro`. О смешанной группе здесь говорим ellos, а глагол ставим в форме tienen. Число машин не определяет форму глагола: людей несколько, машина одна.

**Скажите «У них есть машина». Начните с Ellos tienen, используйте carro.**

- ✅ **Ellos tienen un carro.** — *Ellos + tienen + un carro.*
- ❌ Ellos tiene un carro. — *После ellos нужно tienen.*
- ❌ Ellos tienen una carro. — *Carro мужского рода: un.*

## Интро 3

### Ключ у друзей

Уточняете для соседа, что у двух друзей есть ключ: `Ellos tienen una llave` — «У них есть ключ». Соберите `Ellos` + `tienen` + `una llave`. Начало ellos tienen сохраняется, затем называем вещь. Llave женского рода, поэтому una. Род вещи не меняет форму tienen.

**Скажите «У них есть ключ». Начните с Ellos tienen.**

- ✅ **Ellos tienen una llave.** — *Ellos + tienen + una llave.*
- ❌ Ellos tenemos una llave. — *Говорите о них, не о вас: tienen.*
- ❌ Ellos tienen un llave. — *Llave женского рода: una.*
