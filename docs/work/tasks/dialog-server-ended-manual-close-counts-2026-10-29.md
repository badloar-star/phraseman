# Диалог, законченный сервером и закрытый через «Ещё → Завершить», засчитывается в тему (жалоба Надежды, 29.10)

Governance-ID: TG-C833BE22BF23

## Outcome

Жалоба Надежды: диалог «Спросить совет» пройден 6 из 6, засчитан в серии и в заданиях дня, а счётчик темы «Повседневное» показывает 0.
Причина видна прямо из кода: отметка «пройден» ставится только при `endedBy === 'bot'`. Если собеседник уже закончил разговор (`coaching.ended`),
а человек закрыл итог через меню «Ещё → Завершить», уходит `endedBy = 'manual'`, и тема не засчитывается.
Координатор (слово владельца) велел чинить сразу, вместе с логами [DIALOG-THEME-PROGRESS].

Результат: если сервер закончил разговор, любой путь к итогу считается завершением собеседником (`bot`). Тема засчитывается, а итог
называется «Диалог пройден».

## Scope

- `app/dialogue_v2_session.tsx` — в `openSummary` ручное закрытие после `coaching.ended` нормализуется в `bot`; журнал пишет и запрошенный, и итоговый путь.
- `app/dialog_theme_progress_diagnostics.ts`, `app/dialogue_v2_done_store.ts`, `components/dialogs/scene/use_dialogs_scene_hub.ts` — логи (уже сделаны).
- Тесты: `tests/dialog_theme_progress_diagnostics.test.ts` и новый сценарий в `tests/dialogue_v2_session_route.test.ts`
  (сервер завершил → onComplete → итог `bot`, тема отмечена).

Вне задачи: остановка вручную ДО конца разговора и остановка по лимиту по-прежнему не засчитываются.

## Architecture

Нормализация в одном месте, на входе `openSummary`, поэтому отметка, переход и экран итога видят одно значение. Условие отметки
`endedBy === 'bot' && learnerTurns > 0 && supportedTarget(studyTarget)` остаётся дословным: его сверяют сторожа
`dialogue_v2_done_status` и `dialogue_v2_day_mark`. Переход для `bot` — push поверх переписки, как при обычной кнопке «Итоги».

## Security and privacy

Новых данных нет. Журнал обращений получает только закрытые значения: путь, флаги, числа, id сценария из общего каталога.
Политику менять не нужно.

## Technical debt

Отметка «пройден» по-прежнему только локальная (на телефоне), в облако не синхронизируется: это прежнее решение dialogs-003, вне задачи.
После переустановки счётчик тем обнулится. Записано как известное ограничение.
