## Architecture

**Двойное открытие.** Карта рендерится с `key={learningV2ProjectionScopeKey}`,
а ключ собирается как `${captureAccountGeneration().generation}:${studyTarget}:${epoch}`.
`generation` читается ВНУТРИ `useMemo`, но его нет в зависимостях: при
пересчёте мемо ключ может получить новое значение. Смена `key` заставляет
React уничтожить и заново смонтировать весь компонент — это и есть
«потушение экрана, а затем снова». Трассировка `[V2-REMOUNT]` поставлена,
чтобы подтвердить фактом, а не догадкой.

**Таббар.** Раздел открывается внутри вкладки (`setPage("v2")`), таббар —
часть layout вкладок. Готового механизма скрытия нет. Вводится контекст со
СЧЁТЧИКОМ запросов (не булевым флагом): если скрытия попросят два экрана,
таббар вернётся только когда отпустят оба, и размонтирование одного экрана не
покажет таббар поверх другого.

Инвариант: экран, запросивший скрытие, обязан отпустить его при
размонтировании — иначе таббар «залипнет» скрытым на всё приложение.
