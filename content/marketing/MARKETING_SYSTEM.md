# PHRASEMAN MARKETING SYSTEM — система продвижения через соцсети

> **Пайплайн называется VIRAL.** Точка входа для любого ИИ — `VIRAL.md` (процедура по шагам).
> Триггеры: «VIRAL», «вирал», «пишем рилс», «пишем карусель», «контент-план».
> Плейбуки: видео → `VIRAL_VIDEO_PLAYBOOK.md`, карусели → `CAROUSEL_PLAYBOOK.md`.
> Подключение оплаты/аналитики воронки → `PAYMENTS_SETUP.md`. Готовые примеры → `scripts/`.
> Система самодостаточна: любая сессия продолжает отсюда.

---

## 1. Цель и стратегия

**Цель — не просмотры. Цель — платящие подписчики Phraseman.**

Активы: Instagram ~70k, TikTok ~70k, Facebook ~124k (суммарно ~264k).
Аудитория: русско- и украиноязычные, учат английский, много 30+.

Воронка:

```
Ролик/карусель (охват)
   → профиль → ссылка в био / стикер в сторис / ссылка в FB-посте
      → knowlyapps.com/start/  (квиз «подбери план за 2 минуты»)
         → персональный результат → пейвол (карта / PayPal / RU→Telegram)
            → оплата → активация Premium → приложение
```

**Два типа контента, оба обязательны:**

| Тип | Доля | Задача | Пример |
|---|---|---|---|
| MAGNET (полезность) | ~60% | охват, подписки, сохранения | «5 фраз, которые говорят вместо How are you» |
| DEMO (продукт) | ~40% | клики, установки, оплаты | скринкаст: ИИ-диалог исправляет твою ошибку |

MAGNET собирает толпу, DEMO продаёт. Только MAGNET = толпа халявщиков.
Только DEMO = никто не смотрит. Чередовать.

## 2. Каденс (минимум, стабильно, без героизма)

- **3 видео в неделю** (пн/ср/пт): 2 MAGNET + 1 DEMO. Один ролик → сразу на TikTok, IG Reels, FB Reels, YouTube Shorts.
- **1 карусель в неделю** (вс) в IG + дублировать в FB как фотопост со ссылкой.
- **Сторис ежедневно**: 1–3 фрейма. Каждый день хотя бы одна сторис со стикером-ссылкой на /start/.
- FB: к каждому видео — текстовый пост со ссылкой прямо в тексте (единственная площадка, где ссылка живёт в посте).

## 3. Ссылки и UTM (иначе не поймём, что работает)

Единый шаблон ссылки:

```
https://knowlyapps.com/start/?utm_source={tiktok|instagram|facebook}&utm_medium={bio|story|post|reel}&utm_campaign={код_ролика}
```

Код ролика = дата+тема, например `0705_fillerwords`. Квиз сам сохраняет UTM и
прикрепляет к заказу — в Firestore видно, какой ролик принёс оплату.

- TikTok: ссылка в био (только одна — всегда на /start/).
- Instagram: ссылка в био + КАЖДЫЙ день сторис со стикером-ссылкой.
- Facebook: ссылка в первом абзаце поста.

## 4. Метрики недели (смотреть каждое воскресенье)

1. Просмотры → плохо/хорошо для формата (внутри площадки).
2. Переходы на /start/ по UTM (Firestore `site_stats`).
3. Старт квиза → завершение квиза (`quiz_start` / `quiz_complete`).
4. Показы пейвола → клики оплаты (`paywall_view` / `checkout_click`).
5. Оплаты (`web_premium_orders`, статус paid).

Правило: формат, который дал оплату — повторить в 3 вариациях на следующей неделе.
Формат, который дал охват, но 0 кликов — оставить как MAGNET, но добавить в него DEMO-вставку.

## 5. Ретаргетинг (второй этаж системы, включить после запуска воронки)

264k подписчиков = готовая тёплая аудитория для Meta Ads:
1. В Meta Ads Manager собрать аудитории: «взаимодействовали с аккаунтом IG/FB за 90 дней», «смотрели ≥50% видео».
2. Кампания на конверсии → лендинг /start/ (Pixel уже стоит в квизе — см. site-config.js, поле metaPixelId).
3. Бюджет для старта: $10–20/день. Lookalike 1–3% от покупателей — после первых ~50 оплат.

## 6. Правила бренда в контенте

- Тон: как объяснил бы друг. Без пафоса, без «уникальная методика», без обещаний
  «выучишь за 30 дней». (См. канон голоса Компаса — от первого лица, без слоганов.)
- Грамматику сверять с Cambridge/Oxford — ошибка в обучающем ролике = смерть доверия.
- Цвета бренда: чёрный #0a0a0e + золото #e8c566 (градиент #f7de8b→#c2902e), шрифт Inter.
- CTA всегда один и тот же: «Подбери свой план за 2 минуты — ссылка в профиле».
- Не копировать чужие ролики 1-в-1 — брать МЕХАНИКУ формата, наполнять своим.

