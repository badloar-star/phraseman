## Architecture
Окно рисует итог только из ответа сервера (coins.total). Счётчик итога растёт от 0 по мере «сгорания» строк; страховка
(f92bdcb90) к концу сценария ставит точный итог. Плашка с пересчётом рисуется только при total > 0 и хотя бы одной строке.

## Security and privacy
Журналы сервера читаются с короткими префиксами uid; данные пользователей не печатаются.
