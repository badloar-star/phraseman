> Документ составлен на основе анализа исходного кода. Достаточен для понимания приложения без доступа к коду.

## ОБЩЕЕ ОПИСАНИЕ ПРИЛОЖЕНИЯ

**PhraseMan** — мобильное приложение для изучения английского языка. Платформа: React Native + Expo, TypeScript. Целевая аудитория: русско- и украиноязычные пользователи уровней A1–B2.

Приложение использует несколько систем одновременно:
- Прогрессивные уроки (32 урока, 50 фраз каждый)
- Геймификацию (XP, уровни 1-50, стрики, медали, достижения)
- Интервальное повторение SRS (алгоритм SM-2)
- Соревновательные механики (клубы, лидерборд)
- Систему ограничения активности (энергия)
- Монетизацию через подписку (RevenueCat)

Всё состояние пользователя хранится локально в **AsyncStorage** (ключ-значение хранилище React Native). Сетевого бэкенда нет — данные лидерборда частично симулируются NPC-игроками.

Интерфейс полностью двуязычный: **русский / украинский**, переключается в настройках в любой момент. Язык по умолчанию определяется из device locale при первом запуске (если `uk` — украинский, иначе русский).

Приложение использует React Context API:

## БЛОК 2 — ОНБОРДИНГ (ПЕРВЫЙ ЗАПУСК)

Файл: `components/onboarding.tsx`

При первом запуске проверяется AsyncStorage ключ `onboarding_done`. Если `!= 1` — показывается онбординг.

### Шаги онбординга (последовательно):

**Шаг 1 — Выбор языка**
- Автоопределение из device locale
- Если `uk` → украинский, иначе → русский
- Пользователь может переключить вручную

**Шаг 2 — Демо-квиз #1**
- Интерактивный пример задания
- Анимированный конструктор фраз (drag-and-drop слов)
- Показывает механику до начала обучения

**Шаг 3 — Демо-квиз #2**
- Второй пример с другим типом взаимодействия
- Анимация правильного ответа

**Шаг 4 — Ввод имени**
- Текстовое поле, 2-20 символов
- Фильтрация нецензурных слов (встроенный список)
- Сохраняется в AsyncStorage: `user_name`

**Шаг 5 — Предложение пройти диагностику**
- Кнопка "Пройти тест" → переход на `diagnostic_test`
- Кнопка "Пропустить" → переход к следующему шагу

**Шаг 6 — Выбор времени уведомлений**
- 5 вариантов: 08:00, 12:00, 18:00, 20:00, 22:00
- Сохраняется, используется для планирования push-уведомлений

**Шаг 7 — Реферальный код**
- Показывается персональный код пользователя
- Можно поделиться

**Шаг 8 — Завершение**
- Запись в AsyncStorage: `onboarding_done = 1`
- Навигация на главный экран или диагностический тест

**Дефолтные значения после онбординга:**
- `goal: 'hobby'`
- `minutes_per_day: 15`
- `current_level: 'A1'`
- `target_level: 'A2'`

## БЛОК 4 — СИСТЕМА УРОКОВ

### Общая структура
- **Всего уроков:** 32
- **Фраз в каждом уроке:** 50
- **Группировка по CEFR:**
  - A1: уроки 1-8 (зелёная тема)
  - A2: уроки 9-16 (синяя тема)
  - B1: уроки 17-24 (золотая тема)
  - B2: уроки 25-32 (оранжевая тема)

### Экран меню урока (`lesson_menu.tsx`)
Перед входом в урок показывается карточка с:
- Название урока
- Текущая медаль (Bronze/Silver/Gold или нет)
- Прогресс-бар из 50 клеток (каждая = 1 фраза, цвет = статус)
- Числовая оценка (0.0 - 5.0)
- Кнопки: Основной урок / Словарь / Неправильные глаголы (если доступны)
- Если урок заблокирован — модалка с условием разблокировки

### Система разблокировки уроков
- Урок 1 всегда доступен (для всех)
- Уроки 2-32: разблокируются когда предыдущий урок получил оценку ≥ 2.5 (Бронза)
- Логика хранится в `lesson{N}_score` в AsyncStorage

### Основной экран урока (`lesson1.tsx`)
Единый файл для всех 32 уроков — номер урока передаётся как параметр маршрута.

#### Механика вопроса (стандартный режим)
1. Показывается фраза на русском/украинском
2. Под ней пустые слоты — по одному на каждое слово ответа
3. Снизу — кнопки-слова (4-6 штук), перемешанные
4. Пользователь нажимает слова по одному в нужном порядке
5. Каждое нажатое слово перемещается в слот
6. После заполнения всех слотов — автоматическая проверка

#### Hard Mode (клавиатура)
- Вместо кнопок-слов показывается клавиатура
- Пользователь набирает ответ полностью
- Применяется нормализация контракций (I'm = I am, don't = do not)
- Включается в настройках (`settings_edu.tsx`)

#### Статусы фразы (сохраняются в `lesson{N}_progress`)
- `empty` — не начата
- `wrong` — была ошибка
- `correct` — правильно с первой попытки
- `replay_correct` — правильно после ошибки

#### Система дистракторов (неправильные варианты)
На каждое слово генерируется 5 дистракторов:
1. **Фонетический** — похожее по звучанию слово
2. **Морфологический** — другая форма того же слова (goes/going/went)
3. **Синтаксический** — слово той же грамматической роли
4. **Семантический** — синоним или близкое по значению
5. **Категориальный** — слово из той же тематической группы

#### Трёхуровневая система объяснения ошибок
При неправильном ответе показывается подсказка. Источник: `/error_traps/` (разбит по диапазонам уроков, загружается лениво).

- **Уровень 1 (Per-word trap):** Подсказка для конкретной позиции слова — "На этом месте ошибаются с предлогами in/on/at"
- **Уровень 2 (Trigger trap):** Паттерн-ошибка — если пользователь выбрал конкретное неправильное слово, объясняется почему оно неверно
- **Уровень 3 (General rule):** Общее правило урока — "В Present Simple с he/she/it глагол получает -s"

#### Оценка (score) урока
Оценка по шкале 0.0–5.0, хранится в `lesson{N}_score`:
- Зависит от соотношения `correct` vs `wrong` фраз
- Пересчитывается после каждого прохождения
- Берётся лучший результат из всех прохождений

#### Медали
| Медаль | Порог оценки | Эффект |
|--------|-------------|--------|
| Бронза | ≥ 2.5 | Разблокирует следующий урок |
| Серебро | ≥ 4.5 | Засчитывается в сертификат уровня |
| Золото | 5.0 | Идеальное прохождение |

#### Счётчик прохождений
`lesson{N}_pass_count` — сколько раз пройден урок. Используется для системы Гемов (см. Блок 7).

### Словарный раздел (`lesson_words.tsx`)
Доступен в некоторых уроках (кнопка в меню урока).
- Показывает слова из урока
- Механика: flip-карточки (лицевая — английский, оборот — перевод)
- За каждое "выученное" слово (просмотрено ≥ 3 раза) начисляется **25 XP**
- Прогресс хранится в `lesson{N}_words` (объект word → count)
- Слово считается выученным при count ≥ 3

### Раздел неправильных глаголов (`lesson_irregular_verbs.tsx`)
Доступен в 20 из 32 уроков.

**Две вкладки:**

**Вкладка "Учить":**
- Каждый глагол показывается в трёх формах: V1 (зелёный), V2 (синий), V3 (фиолетовый)
- Пользователь последовательно изучает каждую форму
- Форма считается выученной после подтверждения

**Вкладка "Тест":**
- Показывается V1, нужно ввести V2 и V3
- Или: показывается одна форма, нужно угадать остальные
- **XP:** 3 XP за каждую правильную форму
- Прогресс хранится глобально: `irregular_verbs_global`

### Раздел теории (`lesson_help.tsx`)
- Грамматические объяснения, характерные для урока
- Примеры предложений
- **XP:** 25 XP за просмотр (начисляется однократно через `verb_learned` task)

### Итоговый экзамен (`exam.tsx`)
- **Открывается:** когда все 32 урока имеют оценку ≥ 4.5 И получены все 4 сертификата уровней
- **Вопросов:** 160+, охватывают все 32 урока
- **Типы:** заполнение пробелов, множественный выбор (4 варианта), исправление ошибок
- **Длительность:** 60 минут
- **Проходной балл:** 70%

### Сертификаты уровней (Level Exams)
Для каждого CEFR-уровня (A1/A2/B1/B2) — свой мини-экзамен.
Открывается после получения Серебра во всех 8 уроках уровня.

## БЛОК 5 — СИСТЕМА XP И УРОВНЕЙ

### Источники XP

| Действие | XP | Условия |
|----------|-----|---------|
| Правильный ответ в уроке | 5 × комбо-множитель × сложность урока | Базовая ставка |
| Изучение слова (словарь) | 25 | Однократно за слово |
| Правильная форма глагола | 3 | За каждую форму V1/V2/V3 |
| Ежедневное задание | 10-100 | Зависит от типа задания |
| Бонус входа (login bonus) | 5-50 | 7-дневный цикл |
| Бонус возвращения | x2 множитель | После 3+ дней отсутствия |
| Бонус-сундук | 0-30 | Случайно: 10% → 0-10, 5% → 10-20, 3% → 20-30 |
| Диалог (хорошая концовка) | 50/25/5 | Зависит от итогового счёта |

### Комбо-множитель (внутри урока)
Считает серию правильных ответов подряд в рамках одной сессии:

| Серия правильных | Множитель |
|-----------------|-----------|
| 1-4 | 1.0x |
| 5-9 | 1.5x |
| 10-14 | 2.0x |
| 15-24 | 2.5x |
| 25+ | 3.0x |

### Множитель стрика (дневного)
Применяется ко всем очкам, включая квизы:

| Длина стрика | Множитель |
|-------------|-----------|
| 1-2 дня | 1.0x |
| 3-6 дней | 1.2x |
| 7-13 дней | 1.4x |
| 14-29 дней | 1.6x |
| 30+ дней | 1.8x |

### Множитель сложности урока
Каждый урок имеет повышающий коэффициент:
- Урок 1: 1.0x
- Каждый следующий урок: +5%
- Урок 32: 2.55x

### Уровни (1–50)
Файл: `constants/theme.ts`, функция `getLevelFromXP()`

**Формула роста:**
- Уровень 1 требует: 100 XP
- Уровень N требует: XP_предыдущего × (1 + (30% - (N-2) × 1%))
- Минимальный прирост с уровня 27: 5% за уровень
- Максимальный уровень: 50

**CEFR-соответствие:**

|--------|------|
| 1-10 | A1 — Beginner |
| 11-20 | A2 — Elementary |
| 21-35 | B1 — Intermediate |
| 36-50 | B2 — Upper-Intermediate |

## БЛОК 6 — СИСТЕМА ЭНЕРГИИ

Файл: `app/energy_system.ts`, контекст: `EnergyContext`

### Параметры
- **Максимум:** 5 единиц
- **Стоимость:** 1 энергия за **неправильный** ответ в уроке (правильные — бесплатно)
- **Восстановление:** 1 единица каждые **30 минут**
- **Полное восстановление:** 0 → 5 за **150 минут (2.5 часа)**

### Хранение
- `energy_count` — текущее значение (0-5)
- `energy_last_update` — timestamp последнего обновления
- При открытии приложения: пересчитывается сколько восстановилось за время отсутствия

### При 0 энергии
- Показывается модальное окно "Недостаточно энергии"
- Кнопки: "Подождать" (показывает таймер до +1 единицы) / "Купить Премиум"
- Нельзя продолжать урок без энергии

### Премиум-пользователи
- Энергия не тратится совсем
- Индикатор энергии меняет цвет на синий (#4FC3F7)

### Tester Mode
- В `settings_testers.tsx` есть режим разработчика
- В нём энергия не тратится независимо от статуса

## БЛОК 7 — СИСТЕМА СТРИКОВ

Файлы: `app/hall_of_fame_utils.ts`, `app/streak_repair.ts`

### Как начисляется стрик
- При любом действии, дающем XP (урок, квиз, задание) — проверяется дата
- Если последняя активность была **вчера** → стрик +1
- Если **сегодня** → стрик не меняется
- Если пропущен 1 день без защиты → стрик = 1 (сброс)
- Если пропущено 2+ дней → стрик = 1

### Хранение
- `streak_count` — текущий стрик
- `last_active_date` — дата последней активности (YYYY-MM-DD)
- `week_days_done` — boolean[7] — какие дни недели активны
- `week_days_week_key` — ключ текущей недели (YYYY-WXX)

### Визуализация
На главном экране: горизонтальный ряд из 7 иконок дней. Выполненные дни подсвечены.

### Заморозка стрика (Streak Freeze)
- **Доступно:** только Премиум-пользователям
- **Механика:** если пользователь пропустил ровно 1 день, а у него активна заморозка — стрик сохраняется
- Заморозка **одноразовая** — после использования нужна новая
- Хранится: `streak_freeze` (boolean)

### Ремонт стрика (Streak Repair)
- **Доступно:** бесплатно
- **Условие:** пропущен ровно 1 день
- **Требование:** пройти **2 урока** в текущий день
- **Результат:** стрик восстанавливается, день пропуска "закрывается"
- Файл: `app/streak_repair.ts`, функции: `isRepairEligible()`, `getRepairProgress()`

### Статистика стриков (`streak_stats.tsx`)
- График по дням
- История лучших серий
- Кнопка запуска ремонта

## БЛОК 8 — ЕЖЕДНЕВНЫЕ ЗАДАНИЯ

Файл: `app/daily_tasks.ts`

### Структура
- **Всего заданий в пуле:** 90
- **Каждый день:** 3 задания (выбираются по индексу дня: `dayIndex % 30 * 3`)
- **Хранение прогресса:** `daily_tasks_YYYY-MM-DD` (сбрасывается каждый день)

### Типы заданий и награды

### SRS / Active Recall (интервальное повторение)
Файл: `app/active_recall.ts`

**Алгоритм:** SM-2 (SuperMemo 2)

**Параметры SM-2:**
- `easeFactor`: от 1.3 до 2.5 (начальное значение 2.5)
- Интервалы: 1 день → 3 дня → `easeFactor × предыдущий интервал`
- Фраза считается "выученной" после **5+ правильных ответов подряд**

**Сессия повторения:**
- Лимит: **7 карточек** за сессию
- Функция `getDueItems(limit)` возвращает просроченные карточки
- Максимум в хранилище: **300 элементов**
- Автоудаление: карточки, не повторявшиеся **60+ дней**

**Оценки пользователя (кнопки в сессии):**
- Again — не вспомнил, интервал сбрасывается
- Hard — вспомнил с трудом, easeFactor снижается
- Good — вспомнил нормально
- Easy — вспомнил легко, easeFactor растёт

**Связь с главным экраном:**
На главной показывается число "Повторить сегодня" = `getDueItems().length`
После сессии: возврат на главную → обновление счётчика.
