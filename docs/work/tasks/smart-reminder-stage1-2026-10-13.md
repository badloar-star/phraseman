## Outcome

Телефон сам подбирает время ежедневного напоминания.
- **Сбор.** Минуты начала уроков и сессий копятся только локально, 28 дней.
- **Расчёт.** Пик привычки с затуханием, напоминание за 45 минут до пика, коридор 09:00–19:45.
- **Новички.** Меньше 5 дней данных — 20:00, как в образце настроек (решение координатора).
- **Ручное время** человека не трогаем никогда.
- **Пересчёт** только при запуске, перепланировка только при смене времени.

Шаг 0 (правило владельца «сперва логи»): журнал `[SMART-REMINDER]` по двум подозрениям.
1. **Окно «включить напоминания».** Нажатие ничего не планирует: без включённых дней недели вызывается отключённая `scheduleDailyReminder`.
   Ту же отключённую функцию зовут онбординг (`CleanOnboarding`) и Настройки.
2. **Серверный крон возвратов.** Работает в 10:00 UTC и не доходит до поясов UTC−2…−12 и +12…+14.
   По коду `functions/` только чтение, вывод координатору, сервер не выкладываем.

## Architecture

- **Расчёт.** Чистая функция `computeSmartReminderTime(events, now, opts)`: веса (урок 2, сессия 1, по пушу 0), затухание вдвое за 10 дней,
  48 получасовых корзин по кругу, сглаживание, порог уверенности, цель −45 мин, коридор 09:00–19:45, шаг 5 мин,
  гистерезис 30 мин / 3 дня / ≤ 60 мин.
- **Хранение.** Только AsyncStorage одного ключа, ≤ 60 записей. Без Firestore и без синхронизации.

## Security and privacy

- Минуты занятий — только на телефоне, никуда не уходят.
- В политику §12 — одна фраза (решение владельца через координатора).
- Ключ хранилища удаляется вместе с локальными данными.
