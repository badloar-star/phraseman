# Светлые темы на всех экранах первого выпуска: никаких тёмных клякс на белых плашках

Related epic/enabler: home-translucent-plates-light-smoke-2026-10-14.md

## Outcome
Во всех светлых темах на экранах первого выпуска (Карточки, Диалоги, Шпиль, Настройки, пейволы, уроки): блик и дымка внутри плашки только светлее неё (белые, без усиления), тень — только снаружи и снизу. Тёмные темы без изменений. Прозрачность 50 % — только Главная (остальные экраны по прозрачности не трогаем). Лог `[PLATE-TONE]` один раз на сочетание тема/оформление/уровень/насыщенность, контракт-тест.

## Scope
`components/v2/plateTone.ts` (новое правило), `components/v2/V2Glass.tsx` (V2GlassSheen с условием isLight), `components/v2/ThemeGlassSmoke.tsx` (в светлых темах не рисуется: цветная дымка «Максимума» на белом — серо-голубое пятно), тесты. Палитра светлых тем уже исправлена в `9ffbfb41a`; здесь — страховка в компоненте и покрытие второго источника (ThemeGlassSmoke: Настройки, Друзья, Уроки).

## Architecture
Чистая функция `plateToneFor(g, palette)`: светлая → дымка `#FFFFFF`, усиление 1; тёмная → как в палитре. Её используют V2GlassSheen и тест; `ThemeGlassSmoke` возвращает null при `glass.isLight`.

## Security and privacy
Не применимо.

## Technical debt
Цветная дымка уровня «Максимум» в светлых темах отключена целиком (любой оттенок темнее белой плашки). Если владелец захочет цветную дымку в светлом «Максимуме» — нужен отдельный рецепт (светлее плашки невозможно на белой заливке).
