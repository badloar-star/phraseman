## Architecture

Скелет — чистая вёрстка на тоне стиля «Тень» (заливка и тень, без обводок), без анимации-петли (перф-бюджет: бесконечные анимации запрещены/заморожены, `freezeOnBlur`). Размеры резервируют итоговую геометрию (первый кадр = финальная геометрия, без прыжка), шапка и карточки повторяют форму меню урока. Таймер длительности проверки — ref момента первого кадра; лог пишется один раз при снятии скелета (по уже существующему сигналу «решение получено»).

## Security and privacy
