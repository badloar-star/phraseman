## Outcome

Экзамен главы работает в дев-сборке: карта экзамена последней в карусели Сезона, 12 вопросов из готовых заданий главы,
сдал при 10/12 → следующая глава открыта, пропущенные эпизоды засчитаны без звёзд, строка «Экзамен сдан · X из 12».
Провал → разбор ошибок, новая попытка через час, сердечки не тратятся. Энергия: экзамен 1 для бесплатных, Plus бесплатно;
входной тест бесплатно. В выпуске выключен (SEASON_CHAPTER_EXAM_ENABLED = IS_DEV) до Сверки.

## Scope

In scope: модель и движок экзамена (подбор 12 из заданий главы, порог, таймер повтора, открытие главы, энергия),
локальное хранение результата, включение карты экзамена в Сезоне за флагом, логи [CHAPTER-EXAM], тесты.
Out of scope: новый контент (Codex не нужен), серверная авторитетность результата (позже, отдельно), сам вид экранов —
эталон chapter-exam-season.html / chapter-exam-flow.html, переносит дизайн.

## Architecture

Чистый движок (modules/learning-v2) без сети: подбор вопросов детерминирован от главы и номера попытки, проверка ответа —
по готовым заданиям выбора (single_choice). Результат и время следующей попытки — в AsyncStorage по аккаунту.
Открытие главы и зачёт эпизодов — через локальный прогресс курса. Энергия — через общий модуль энергии.

## Security and privacy

Новых данных нет: результат экзамена хранится локально, как прогресс курса. Сетевых вызовов нет.
