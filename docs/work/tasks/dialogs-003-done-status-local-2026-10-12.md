## Outcome

Хаб «Диалоги» показывает «пройдено ✓» у пройденных сценариев и «пройдено N / всего M» в категории. Источник — только устройство: новая локальная запись пройденных сценариев (account-scoped, стирается при выходе/смене аккаунта вместе с локальной копией памяти диалогов); без новых чтений и записей Firestore. Облачная синхронизация — после R1.

Находка: dialogue_v2_session_outcome_store держит итоги ТОЛЬКО в памяти процесса (последние 4 сессии, ключ sessionId, «не durable намеренно») — по нему «пройдено» на хабе восстановить нельзя. Поэтому добавляется отдельное маленькое хранилище id пройденных сценариев; старое не меняется.

Правило «пройден»: диалог закончен самим собеседником (endedBy = bot) — то же условие, что даёт заголовок «Диалог пройден» на экране итога — и в нём была хотя бы одна реплика ученика.

## Scope

In scope: новое хранилище, подключение в проекции и контейнере хаба, запись в момент открытия итога, чистка при выходе, логи [DIALOG-DONE], тесты.
Out of scope: серверные данные, облако, вид строк (рисует DialogueV2CatalogueSection уже сейчас).

## Architecture

Одно новое небольшое хранилище (память + AsyncStorage, ключ с областью аккаунта) по образцу локальной копии памяти диалогов; проекция получает необязательное множество пройденных id.

## Security and privacy

Хранится только id сценария (общий каталог), без реплик и без идентификаторов третьим лицам; остаётся на устройстве, не передаётся; стирается при выходе/смене аккаунта. Политика конфиденциальности (локальные данные прогресса на устройстве) не меняется — проверить формулировку при выпуске.
