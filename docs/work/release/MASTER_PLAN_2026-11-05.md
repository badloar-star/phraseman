## 0. Правила для ВСЕХ сессий (действуют сразу)
1. **Сборок и отправок в сторы нет**, пока владелец лично не скажет «собирай» после доклада с доказательствами (`RELEASE_GATE_100.md`, ведёт Ревизор).
2. **Закрытие задачи = доказательство**: коммит + тест/кадр. Слово сессии «готово» не считается.
3. **Визуал — по кадрам с устройства/эмулятора, а не по коду.** Макет побеждает приложение; «так лучше» — не довод, довод только слово владельца в чате.
4. **Заглушек нет.** Ни «пока готовится / скрыто / скоро откроется» в классике. Нет данных → пункт скрыт либо данные делаются; текст-заглушка запрещён.
5. **Язык курса ≠ английский → ничего английского** в слове/теории/глаголах/подсказках.
6. **Статус-файл**: каждая сессия раз в 30 минут пишет 3–6 строк в `docs/work/release/status/<номер>_<имя>.md` (сделано / коммиты / блокеры / следующее). Координатор и Макеты читают файлы, а не гоняют сообщения → экономия токенов.
7. **Дерево общее и грязное**: `git add` только свои файлы (`git add <путь>` / `--patch`), коммит атомарно, без stash/worktree/веток. Чужое WIP (`app/lesson_complete.tsx`, audio, `firestore.indexes.json`) не трогать.
8. **Простоя нет.** Нечего делать — взять следующий пункт своей очереди; очередь кончилась — написать координатору, получить новую.
9. **Дешёвое — локальным моделям** (Ollama/LM Studio): префильтр, черновики, массовые проверки. Они не принимают решений, решения и итог — Sonnet/Opus. Рой не должен простаивать.
10. **Логи прежде починки** (правило владельца): ошибка → подробная трассировка → диагноз → фикс.

## 3. Лучший способ (как организована работа)
- **Один реестр + статус-файлы**, а не поток сообщений: координатор читает `status/*.md` и `git log` раз в 30 минут, пинает отстающих.
- **Конвейер для курсов**: локальная модель (префильтр) → Opus (аудит порциями ≤10 агентов) → правка в слое/генераторе → сторож-тест → контрольная выборка Ревизора → цифра ≤1%.
- **Конвейер для экранов**: эталон (макет) → кадр «сейчас» (Сверка/Эмулятор) → склейка (Макеты) → правка (исполнитель) → кадр «после» → вердикт. Без кадра «после» строка не закрывается.
- **Конвейер E2E**: сценарий Maestro на чистом эмуляторе → красный = баг → фикс → повтор; результаты в `E2E_RESULTS`.
- **Аудиты координатора (идут сейчас)**: (1) все заглушки/«скоро»/пустые состояния в видимых строках приложения; (2) флаги/гейты: что видно на ранге 0 и что закрыто флагом, не совпадающее с макетом.
