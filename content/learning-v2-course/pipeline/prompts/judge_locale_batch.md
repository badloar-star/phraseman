> В одном задании разрешена ровно одна фраза целевого языка: одна целевая фраза, один audio-target, одна сборка, один диктант, один voice-повтор или одна фраза с пропусками. Нельзя просить сказать, услышать, собрать или заполнить две-три фразы подряд на одном экране. Последовательность сохраняется без потерь как отдельные interaction с собственными ID, ответами, аудио и feedback; локали сохраняют тот же порядок. Правило действует для всех семейств, включая финал. Найденное объединение даёт BLOCK. Источник: `judgements/owner/2026-10-03_single_phrase_per_interaction.md`.
> В `context_gap_grammar` виден ровно один `___` и выбирается один естественный фрагмент целевого языка без точек с запятой или пакетной записи; несколько разнесённых пропусков в одном предложении дают BLOCK.
> В assessed target/audio/voice строке, любом видимом responseOption и selectable localized meaning один вариант может содержать ровно одно слово, одну фразу или одно значение. Пакеты через `;`, `；`, `|`, переносы строк, маркеры списка, повторные пары `word — meaning` либо три target-слова подряд дают BLOCK независимо от грамматики. Многострочное объяснение разрешено только в отдельной non-selectable word-card, которая не является вариантом ответа. Markdown и atomic source обязаны совпадать по learner-facing target, options и audio; расхождение даёт BLOCK. Правило применяется к любому целевому языку. У каждой проверяемой interaction обязателен непустой конкретный `correctText` из её собственного контракта. В диктанте скрытая целевая фраза точно совпадает с `referenceAudio.transcript`; несовпадение даёт BLOCK.

Для КАЖДОЙ локали проверь:
1. **Структура совпадает с мастером**: те же номера и количество заданий,
   те же английские целевые слова и фразы, тот же блок «Для сборщика».
2. **Чистота языка**: нет русских или английских фрагментов в

3. **Своя опора**: контраст идёт с родным языком локали, а не пересказ

4. **Ловушки уместны** для носителей этого языка.
5. **Живой юмор сохраняется в локали.** Для новой и исправляемой серии Codex L2/S33+ редакторская цель — хотя бы один естественный уместный юмористический ход на сессию, а не обязательная шутка на каждой странице. Он объясняет язык, понятен с первого чтения и не является приклеенной концовкой. Проверяй по конкретной цитате из текущей локали. ## Ответ — СТРОГО JSON

Ключи в `locales` — только коды присланных локалей, ничего не добавляй:

```json
{
  "locales": {
    "<код присланной локали>": {"verdict": "PASS|REVISE|BLOCK", "problems": [{"where": "…", "quote": "…", "why": "…", "fix": "…"}]}
  },
  "verdict": "PASS|REVISE|BLOCK",
  "verdict_reason": "одно предложение про худшую локаль"
}
```

BLOCK локали: структура или английские цели разошлись с мастером, чужой
язык в тексте, пропуски внутри присланной локали. REVISE: машинный запах,
русская опора вместо своей, нетипичные ловушки, потерянный или натужный юмор в указанной серии. Отсутствие шутки на отдельной странице само по себе не дефект. PASS:
носитель не заметил бы, что это версия, а не оригинал. Общий `verdict` —
худший из присланных. Отсутствие непрошенной локали в вердикт не входит.

## ЯЗЫК ЛОКАЛИ — ЖИВОЙ И КРАСИВЫЙ, А НЕ ВЫДУМАННЫЙ

Владелец: «переводы на украинский должны быть красивые, красивый украинский
должен быть, а не выдуманный».

Локаль — не подстановка слов по словарю, а текст, который носитель читает
как написанный носителем. Запрещено:
- калька с русского («не тільки про мову» вместо «про те, як говорять»:
  `мова` для украинца прежде всего «язык», смысл заголовка менялся);
- слова, которых в живой речи нет, придуманные ради «украинскости»;
- русское слово с украинским окончанием («Молчання» вместо `Мовчання`);
- непереведённые куски: заголовки, подписи, служебные строки.

Проверка одна: прочитал бы это носитель вслух и не споткнулся?
