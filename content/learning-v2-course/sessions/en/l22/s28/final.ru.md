# Английский · Урок 22 · Занятие 28 — Выбрать готовые продукты

**Ситуация.** Вы сравниваете продукты в магазине.

**Что вы освоите:** determiner|adjective + one|ones
**Новые слова:** ready-to-eat, freshly baked, pre-cooked, pre-sliced

## Интро 1

### Салат можно есть

Ready-to-eat — готовый к употреблению: продукт не нужно готовить перед едой. В примере выбираем один готовый салат: one заменяет salad. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I want the ready-to-eat one.**
- ❌ I want the ready-to-eat ones. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I want the ready-to-eat it. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 2

### Свежая выпечка и готовые сосиски

Freshly baked — свежевыпеченный, только что или недавно испечённый. Pre-cooked — предварительно приготовленный: приготовление уже происходило до покупки. Это не обязательно значит ready-to-eat: способ подачи зависит от продукта и указаний на упаковке. Сейчас вы выбираете несколько свежевыпеченных булочек: buns → ones. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I like the freshly baked ones.**
- ❌ I like the freshly baked one. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I like the freshly baked them. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 3

### Нарезанная буханка

Pre-sliced — заранее нарезанный ломтиками. Выбираем одну буханку: the pre-sliced one заменяет the pre-sliced loaf. One относится к loaf, а не к неисчисляемому bread. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones.
