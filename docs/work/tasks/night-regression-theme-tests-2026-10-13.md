## Outcome
Установлен факт по каждому красному тесту и тест приведён к текущему коду с пояснением «зачем», либо указана ошибка кода. Установлено: `theme_intensity_slider` красный из-за ложного сравнения (в эталон попадали значения уровня calm производных токенов accentGraphic/accentTextSafe), сами токены верны (тёмный: оба равны accent уровня); `olive_phase1_surface_contract` и `sage_porcelain_real_device_visibility_contract` проверяют устаревшую форму кода (таблица оболочек по id тем; светлая карточка только по режиму темы), код изменён намеренно на токены.

## Scope
Только три файла тестов в `tests/`. Код приложения и токены не меняются.

## Architecture
В slider-тесте производные токены исключаются из сравнения «формула трёх уровней на опорных точках» так же, как уже исключены токены поверхностей и палитры ролей; их корректность стережёт `accent_graphic_token`. В остальных двух тестах ожидания заменены на текущий смысл кода (оболочка из `cardPackPaywallShellFromTokens`; `isSagePorcelainCard` и `lockedCardHasLightFill` учитывают `lightCard`).

## Security and privacy
Только тесты.

## Technical debt
Тесты по-прежнему сверяют подстроки исходников, а не поведение; перевод на проверку поведения — отдельным шагом.

## Verification
Три теста точечно по слоту светофора, затем `accent_graphic_token` для проверки, что тёмный вид токенов прежний.
