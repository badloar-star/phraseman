## Architecture

**Офлайн-плашка.** Источник состояния — существующий `subscribeNetStatus`
(`app/net_status.ts:278`), тот же, что кормит глобальный `OfflineBanner`.
Второго детектора сети не заводим. Глобальный баннер говорит «нет соединения»
вообще; плашка на экране говорит КОНКРЕТНО: «эти цифры от 14:20». Разные
сообщения, один источник.

**Поиск.** Фильтрация локальная, по уже загруженному списку уроков: 0 чтений
Firestore, без дебаунса (список в памяти, фильтруем в кадре ввода). Лупа —
член существующего ряда чипов (владелец 17.09: «это один ряд весь»), поле
раскрывается в отдельном слоте НАД рядом, поэтому ряд не сдвигается.

**Pull-to-refresh.** Только на экранах с локальными данными. `mistakes_hub`
читает журнал ошибок с устройства → жест пересчитывает кэш и в сеть не идёт.

**Разбор ошибок.** Ответ ученика в журнале сейчас НЕ хранится (находка аудита
15.09) — это первое звено цепочки. Поле добавляется как необязательное,
пишется ЛОКАЛЬНО, в Firestore не уходит. Старые записи без него читаются
как раньше.

**Инварианты:** без обводок · без подписей-расшифровок · без
`adjustsFontSizeToFit` · анимации только transform/opacity · логи на каждом
раннем выходе и в catch · Optimistic UI с откатом.
