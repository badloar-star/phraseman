# Пик: блокировка страницы при касании окна башни снимается при размонтировании окна (Ревизор по 690a67f59, 🟡)

Governance-ID: TG-88B9E65C8D56

## Outcome
Палец на окне башни + уход экрана (замок языка, «Все участники», смена вкладки) оставляли `locked=true`: страница Пика не прокручивалась и не обновлялась потягиванием, пока человек снова не коснётся окна. Теперь при размонтировании башни блокировка снимается.

## Scope
`components/spire/SpireTower.tsx` (эффект очистки), `tests/spire_tower_window_height.test.ts`.

## Architecture
`useEffect(() => () => onTouchActive?.(false), [onTouchActive])` — колбэк стабилен (useCallback в хуке), очистка срабатывает только при размонтировании.
