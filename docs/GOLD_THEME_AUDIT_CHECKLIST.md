# Gold Theme Audit Checklist

Дата аудита: 2026-05-17

## Цель

Создать тему Gold как отдельный премиальный визуальный слой: черная база, шампанское золото, тонкие рамки, сдержанные тени, металлические CTA и минимум случайных coral/navy остатков.

## Проверено и изменено

- [x] Сохранить ключ темы `gold`, чтобы не ломать AsyncStorage, premium gate и существующие настройки пользователей.
- [x] Заменить старую Coral/Finance палитру в `constants/theme.ts` на Black Gold.
- [x] Проверить контраст текста на карточках, фоне, CTA и золотой заливке.
- [x] Перекрасить фон `ScreenGradient` для `gold`: убрать coral/blue настроение, оставить черный и приглушенный золотой свет.
- [x] Уменьшить радиусы и сделать тени более плотными через `ThemeContext.ds` для `gold`.
- [x] Обновить `PremiumCard`: тонкие hairline-рамки, более строгий default radius, дополнительный внутренний rim для Gold.
- [x] Обновить `PrimaryButton`: для Gold использовать металлический градиент вместо плоской заливки.
- [x] Обновить `ThemedInput`: тонкая золотая рамка в Gold.
- [x] Переименовать тему в UI с Coral на Gold/Oro/Золото.
- [x] Добавить цветовой preview-свотч в экран выбора тем.
- [x] Убрать coral-настроение из Gold-ассетов на Home/Daily Phrase/Energy/Diagnostic, временно перевести на нейтральный fog-набор.
- [x] Обновить Gold-палитры карточек quiz-уровней на black/gold варианты.
- [x] Обновить shell flashcards paywall с coral/navy на black/gold.
- [x] Проверить прямые вхождения `Coral`, `Корал`, `coral` в theme-related коде.

## Остаточные наблюдения

- [ ] В проекте нет отдельного набора bitmap-ассетов `gold` для всех плиток главного меню. Сейчас Gold использует нейтральный `fog`-набор, чтобы не светить coral. Идеальный следующий шаг: нарисовать/сгенерировать отдельные `lesson gold.webp`, `cards gold.webp`, `shop gold.webp` и т.д.
- [ ] Некоторые achievements используют coral-картинки как собственные иконки достижений, не как theme mapping. Я их не трогал, чтобы не менять смысл наград.
- [ ] В коде есть много inline-стилей с фиксированными радиусами `16/20`; Gold теперь влияет на общие компоненты и `ds`, но не на каждый единичный inline-card.
- [ ] Полный визуальный аудит лучше завершить скриншотами на Home, Lessons, Quiz, Settings, Paywall, Flashcards после запуска Metro.

## Критерии приемки

- [x] В настройках тема называется Gold/Oro/Золото, а не Coral.
- [x] Основной фон Gold воспринимается черным, не navy/purple.
- [x] Главный акцент Gold воспринимается золотым, не coral/red.
- [x] Общие карточки/кнопки/поля получили более тонкую и премиальную обработку.
- [x] Тема остается совместимой с существующим `ThemeMode = 'gold'`.
