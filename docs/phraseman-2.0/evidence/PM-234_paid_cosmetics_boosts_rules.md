# PM-234 — правила для оплаченной косметики и бустов (evidence, 2026-10-01)

Источник фактов: реестр PM-233 (`PM-233_purchase_ledger.md`, 39 продуктов, сторож `scripts/pm233_purchase_ledger_dry_run.mjs --check`) и решения владельца в `03_DECISIONS.md`. Новых решений этот документ не принимает — только сводит принятые.

## PM-234-A1: «жемчуг 1:10» НЕ заменяет компенсацию всех покупок — выполнено

Правило «жемчуг → ×10 монет» (D15/D45/D53) **отменено** (D15 → SUPERSEDED, D70, D84, D103): жемчуг удаляется без компенсации, в коде `app/gifts_to_coins_table_v1.ts:33` даёт 0. Каждая категория покупок имеет СВОЮ строку судьбы, универсальной конвертации нет:

| Категория (строка реестра PM-233) | Судьба в 2.0 | Решения |
|---|---|---|
| Жемчуг (баланс, в т.ч. купленный за деньги) | Сгорает без компенсации; приём покупок жемчуга удалён | D70, D84, D103, D139 |
| Косметика: образы/ауры (за жемчуг и руны) | Удаляется целиком, включая купленное; без возврата | D102, D108, D138 |
| Диалоги, купленные за руны | Не учитываются (доступ по рангу монеты), без возврата | D124, D05, D138 |
| «+10 ответов за 300 монет» | Покупка убрана; квота Free 30/мес остаётся | D111, D139 |
| Заморозки серии (купленные) | Не переносятся; бесплатная заморозка Plus остаётся | D101, D107, OD7 |
| Бусты, Season Pass, щит цепочки | Удаляются с XP и лигой; незабранные награды Season Pass — монетами по таблице подарков | D09, D53, D58, D70, D103 |
| Украшения за звёзды Арены | Чистятся вместе с данными Арены после релиза | D90, D140 |
| Подарочные наборы (ваучеры) | Код удалён, непогашенные ваучеры аннулированы, полученные наборы остаются | D09, D68, D140 |
| Квесты, коллекции | Убраны; выданные дни Plus сохраняются | D140 |
| Минуты/подписка MAX | Денежный код удалён, без возврата | D136 |
| Plus (подписка/пожизненный/веб) | Сохраняется; отклонённые чеки — выдать Plus (по команде владельца) | D137, D139 |

## PM-234-A2: grandfathering / refund / альтернатива согласованы — выполнено

Согласовано владельцем 2026-10-01 (ответы в сессии Account V2, записаны D136–D140):
- **refund:** нет ни для одной внутриигровой покупки (D138, D103, D136);
- **grandfathering:** только Plus и уже полученные наборы/дни Plus (D137, D140);
- **альтернатива:** незабранные подарки/награды Season Pass — монетами по таблице `gifts_to_coins` (D53/D57), всё остальное — без замены.
