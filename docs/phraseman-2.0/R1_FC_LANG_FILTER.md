# R1 · Кнопка языка на настройке тренировки Карточек: фильтр наборов по языку (cards-027, решение владельца п.83)

Статус: **ПЛАН на подтверждение координатора** — кода по этому плану ещё нет. Автор: сессия «2 · ДИЗАЙН», 12.10 (вечер).
Решение владельца: «Кнопка языка отфильтровывает наборы карточек по языкам». Чип из коммита 6d54b8f5b (read-only) становится кнопкой фильтра.
Ограничения координатора: studyTarget приложения НЕ меняется (D129/D130), без новых чтений Firestore, список меняется мгновенно, выбор помнится на время экрана, лог `[FC-LANG-FILTER]`, тесты.

**Подтверждено координатором 12.10 (вечер).** Вопрос (б): наборов других языков нет — остаётся read-only чип (да). Два условия:
1. `?target` в маршруте ВАЛИДИРУЕТСЯ в `useTrainingStudyTarget` — принимаются только языки, где «Карточки» `ready`; иначе откат на `studyTarget` приложения + лог причины (`[FC-LANG-FILTER] target_rejected`), чтобы ссылкой нельзя было запустить неподготовленный язык.
2. Гейты энергии / Plus / квоты тренировки работают для чужого языка так же (не обходятся сменой `target`) — отдельный тест.

## 1. Что проверено в коде (факты, не догадки)

1. **Наборы строго по языку.** `loadFcDeckOptions(mode, lang, studyTarget)` (`app/flashcards/deck_options.ts:305`) собирает 7 источников и КАЖДОМУ отдаёт `studyTarget` (`loadDeckCards({kind:'saved'|'custom'|'pack'}, cl, studyTarget)`, `loadAccessiblePackIds`, `loadCommunityOwnedPackIds`, `loadLocalAuthorPacks`, `peek/loadPublishedCommunityMarketPacks`, `peekVideoMarketPacks`, `bundledPacksForOwned`); пакеты других языков отбрасываются (`storageStudyTarget(pack.studyTarget) !== target → continue`, строка 131). Кэш и «тёплый» снимок — по ключу «аккаунт + цель + язык интерфейса + режим» (`deckOptionsCacheKey`). То есть **списка наборов «всех языков» сейчас нет нигде** — его надо собрать из пяти вызовов по языкам.
2. **Идентификаторы наборов не несут язык.** `FcDeckId = 'weak' | 'saved' | 'custom' | 'pack:<id>'` (`deck_selection.ts`). `saved` и `custom` — ХРАНИЛИЩА по языку (один и тот же id означает «сохранённые на английском» или «на испанском» в зависимости от цели). Поэтому **выбор наборов может быть только внутри одного языка**: смешать «saved EN» и «saved ES» нельзя.
3. **Запуск тренировки читает язык из контекста приложения.** Маршрут `buildCardsTrainingRoute` (`training_entry.ts`) несёт только `deck`, `size`, `sec`, `dir`. Сессии берут `const { studyTarget } = useStudyTarget()` и от него считают: `contentLang = flashcardContentLang(lang, studyTarget)` (язык озвучки и проверки), загрузку карточек (`loadDeckCardsMulti(refs, contentLang, { studyTarget })`, `loadAllFcDeckRefs(studyTarget)`), выбор набора внутри сессии (`loadFcDeckOptions(..., studyTarget)`), ошибки (`isMistakeStudyTargetValue(studyTarget)`), `sessionId`, подписи сторон карточки `langChip(studyTarget)`. Файлы: `flashcards_blitz_session.tsx` (16 упоминаний), `flashcards_speaking_session.tsx` (14), `flashcards_recall_session.tsx` (9), `flashcards_swipe.tsx` (тренировка «верно/неверно» — `flashcards_truefalse_session.tsx` — это обёртка на него).
4. **Какие языки вообще можно показывать.** Раздел «Карточки» открыт у всех пяти (`en, es, fr, de, it`), клетки `flashcards` таблицы `learning_language_surface_readiness.ts` — `ready` (D129/D130). Таблицу не меняем.
5. **Последний выбор наборов** (`setLastPreset(mode, { deckIds })`) хранится по режиму, без языка — после выбора набора другого языка его нельзя восстанавливать под языком приложения.
6. **Сеть.** Источники пакетов в `loadFcDeckOptions` для цели X запускают фоновую подгрузку каталога этой цели (`loadPublishedCommunityMarketPacks(X)`, кэш 6 ч). Для «чужих» языков это были бы НОВЫЕ чтения — их надо выключить режимом «только локально» (см. §3).

## 2. Решение по дизайну

- **Чип → кнопка.** В верхнем ряду справа остаётся «EN» рядом с пилюлей остатка; если у пользователя есть наборы более чем одного языка — рядом шеврон и тап открывает меню (`PackLanguagePicker`, без «Без языка»), в пунктах — язык и **число наборов**; если язык один — чип остаётся без стрелки и не нажимается (как сейчас).
- **По умолчанию** выбран текущий `studyTarget`. Выбор живёт в `useState` экрана (без записи в профиль).
- **Мгновенно.** Для выбранного языка список строится из уже собранных данных (тёплые снимки по языку); если этого языка ещё нет — показывается скелетон ТОЛЬКО на месте списка наборов, шапка и чип уже на месте; результат кэшируется (повторный выбор — 0 мс).
- **Смена языка сбрасывает выбор наборов** (они из другого хранилища), кнопка «Начать» блокируется до нового выбора.
- **Меню языков строится лениво:** язык текущей цели известен сразу; остальные четыре считаются фоном после первого кадра (один проход, по одному, под `InteractionManager`), по мере готовности пункты появляются в меню. Языки без наборов в меню не попадают.
- **Пустой язык** (набранный вручную/по ссылке, наборов нет): понятная строка вместо пустого экрана (существующий `KitEmpty` в режиме `empty`).
- **Запуск.** Маршрут получает параметр `target=<язык выбранных наборов>` (только если он ≠ `studyTarget` приложения; для текущего языка маршрут не меняется, значит и все прежние ссылки/тесты живы). Сессии берут язык не из контекста напрямую, а через **один общий хук** `useTrainingStudyTarget()`: проверенный параметр `target` маршрута (должен входить в языки с `flashcards: ready`), иначе `studyTarget` приложения. В каждой сессии это замена ОДНОЙ строки `const { studyTarget } = useStudyTarget()` → `const studyTarget = useTrainingStudyTarget()` — всё остальное (озвучка, проверка ответа, загрузка, ошибки, `sessionId`, подписи сторон) следует автоматически. Контекст приложения не меняется.
- **Пресет** `setLastPreset` для набора чужого языка НЕ записываем (пропускаем с логом), чтобы не подсунуть его под другим языком.

|---|---|---|
| `app/flashcards/fc_lang_filter.ts` (новый, чистый) | Дизайн | языки-кандидаты (`flashcards: ready`, текущий первым), фильтрация/подсчёт, валидация параметра `target`, сборка параметра маршрута; без react-native — тестируется в node |
| `app/flashcards/use_training_study_target.ts` (новый хук) | Дизайн | `useTrainingStudyTarget()`: `useLocalSearchParams().target` → валидация → иначе контекст |

| `app/flashcards_training_setup.tsx` | Дизайн | состояние выбранного языка, загрузка наборов выбранного языка, сброс выбора, параметр `target` в маршруте, пропуск пресета, журнал `[FC-LANG-FILTER]` |

| `app/flashcards/deck_options.ts` | **Ядро** | режим `localOnly` (без фоновой подгрузки каталогов по сети) + экспорт «только пик/локальная сборка по целям»; ключ кэша уже включает цель |

Порядок: (1) Дизайн кладёт чистый модуль + хук + `training_entry` (не ломая ничего) и пишет тесты; (2) Ядро делает `localOnly` и подключает хук в 4 сессиях; (3) Дизайн включает кнопку и меню, когда оба готовы. Файлы не пересекаются.

## 4. Риски и открытые вопросы

1. **Сессии в 4 файлах** — единственная чувствительная часть (деньги: энергия/руны, ошибки и очереди). Поэтому — Ядро и общий хук вместо точечных правок.
2. **Скорость экрана.** Пять локальных сборок наборов за раз дороги; решение — лениво и по одной после первого кадра, кэш по ключу «аккаунт+цель+язык интерфейса+режим» уже есть.
3. **Купленные наборы чужого языка** показываем из локальных списков владения (без сети); наборы маркета чужого языка — только то, что уже в тёплом кэше каталога (peek), без запроса.
4. **Быстрый старт с хаба Карточек** (`buildCardsTrainingRoute(mode, [deck.deckId])` по плитке) остаётся без `target` — хаб показывает наборы текущего языка.
5. **Вопрос координатору:** если у пользователя наборов других языков нет вообще (самый частый случай), кнопка остаётся read-only чипом — подтверждаешь?

## 5. Тесты

- чистый модуль: языки-кандидаты (текущий первым, только `flashcards: ready`), счётчики, фильтр, пустой язык, валидация `target` (мусор, чужой регистр, язык без раздела);
- `buildCardsTrainingRoute`: без `target` — маршрут как раньше (все существующие ожидания); с `target` — параметр есть;
- хук: параметр → язык набора, мусор/нет параметра → язык приложения (без рендерера — на чистой функции выбора);
- экран настройки: источник-контракт (смена языка сбрасывает выбор, пресет не пишется для чужого языка, журнал `[FC-LANG-FILTER]`); «Начать» блокируется после смены языка;
- сессии (Ядро): `target=es` при `studyTarget=en` → `contentLang`, загрузка, ошибки и `sessionId` идут по `es`.

## 6. Firebase / стоимость

0 новых чтений: только локальные хранилища и уже лежащие в памяти снимки каталогов. Режим `localOnly` в `deck_options` запрещает фоновую подгрузку каталога для не-текущих языков. Лог `[FC-LANG-FILTER] {language, decks, source: warm|local|none, ms}` покажет, откуда список и сколько занял.
