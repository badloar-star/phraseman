# Task packet: меню платного урока не висит на заготовке дольше 12 секунд

Governance-ID: TG-EA3878D78D0D
Status: In progress
Owner: сессия аудита загрузок 11.11
Related epic/enabler: аудит загрузок 11.11, ошибка № 2; D158 «тихо — не значит бесконечно»

## Outcome

Решение владельца 11.11 на вопрос «Что делать с платным уроком, если подписка не подтвердилась
за 12 секунд?» — дословно: «Пускать в меню».

Результат: при входе в платный урок (с 4-го) с ещё не подтверждённой подпиской заготовка меню
держится не дольше `LOAD_GATE_TOTAL_MS` (12 с). Затем показывается само меню. Запуск урока при этом
остаётся закрытым до настоящего решения о доступе — человек видит меню, но начать платный урок без
подтверждённой подписки не может. Когда подписка подтверждается, проверка проходит заново и меню
либо открывает запуск, либо закрывается по обычным правилам.

Мера успеха: в журнале `[LESSON-MENU] lock:pending_ceiling` вместо бесконечного скелета.

## Scope

In scope: `app/lesson_menu.tsx` — потолок ожидания ветки `access_pending`.

Out of scope: правила платного доступа (кому какой урок открыт), охранник `lesson1`, замок
дополнительного языка (`language_lock`), список уроков.

## Architecture

No architecture change. Используется существующее состояние `lockRevalidating` («экран виден,
запуск закрыт»), которое уже применяется при тихой перепроверке на возврате фокуса. Добавлены:
ref ключа, для которого потолок сработал, и один таймер.

Инварианты (сторож `tests/lesson_menu_access_fail_closed_contract.test.ts`) сохранены:
- `isLessonLocked` стартует `true`;
- `lessonLaunchBlocked = !lockStateLoaded || isLessonLocked || lockRevalidating` не меняется;
- неподтверждённая проверка остаётся launch-blocking; ветка ошибки остаётся закрытой.

## Security and privacy

Платный доступ не расширяется: после потолка открывается только ВИД меню, все обработчики запуска
по-прежнему выходят по `lessonLaunchBlocked`. Охранник `lesson1` не тронут. Новых данных нет.

## Technical debt
