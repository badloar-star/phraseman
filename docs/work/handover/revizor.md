## 8. Грабли среды (Windows)

- jest: больше ~250 путей в одной команде — «command line is too long» → `--shard=i/N` или пачки; functions jest одним процессом — OOM →
  `--maxWorkers=1 --workerIdleMemoryLimit=900MB`.
- tsc приложения: `NODE_OPTIONS=--max-old-space-size=6144` (без — exit 134).
- Обратные кавычки внутри `node -e` в bash съедаются — писать скрипт в файл .cjs.
- Пути для node — в виде `C:/…` (`cygpath -m`), не `/c/…`.
- Связки node_modules (`mklink /J`) снимать `cmd //c rmdir` ДО `rm -rf` копии — иначе удалится настоящий node_modules.
- Коммиты часто ждут из-за чужих (HEAD двигается каждые секунды) — `safe_commit.sh` в цикле с паузой 5 с.
