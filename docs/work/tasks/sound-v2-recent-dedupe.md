# Task packet: звук Пика без задержки и без двоения — «недавно сыграно» вместо паузы и реестра

Governance-ID: TG-48D46189A918
Status: In progress
Owner: сессия «4 · ТЕМЫ 2.0»
Related epic/enabler: поручения координатора 14.10 — тишина Пика по факту показа момента, затем «пауза 120 мс — регресс мгновенности»

## Outcome

Отклик игры (ступень / этаж / вершина в `use_spire_game`) звучит СРАЗУ, без паузы, как раньше. Мост отмечает «событие сыграно». Момент Пика при показе зовёт `playUnlessRecentlyPlayed(event)`: молчит и пишет причину, если такое же событие звучало последние ~400 мс; иначе играет. Нет задержки, нет двойного звука, нет регистрации моментов.

## Scope

In scope: `modules/sound_v2/legacy_bridge.ts` (отметка, `playUnlessRecentlyPlayed`), `app/spire/use_spire_game.ts` (звук сразу), тесты.

Out of scope: сами моменты Дизайна — им одна строка: вместо `playEvent('floor')` вызывать `playUnlessRecentlyPlayed('floor', 'SpireFloorMoment')`.

## Architecture

Карта «событие → время последнего воспроизведения» в мосте; все пути моста отмечают сами. Окно 400 мс. Флаг выключен — мост ничего не играет и не отмечает.

## Security and privacy

Только звук; данные не затрагиваются.

## Technical debt

Contain: пока моменты Дизайна зовут `playEvent` напрямую, их звук не гасится; одна строка на момент закрывает.

## Verification

Тест трёх случаев: шаг без момента — звук сразу (синхронно); шаг + момент — один звук и причина в журнале; момент без шага — звук; плюс окно, другое событие, флаг выключен, ручная отметка. Строгий прогон: «N passed», без «failed to run».
