# Оттенок карточек Сезона равен оттенку темы (без сдвига тона)

Governance-ID: TG-20634D6C8A37

## Outcome
Координатор (слово владельца «строго оттенки темы»): сдвиг тона главы ±24° убрать; hue = hue темы. Главы и эпизоды различаются только светлотой и насыщенностью внутри палитры текущей темы. Функция общая для старого и нового экрана урока.

## Scope
In scope: `season_art.ts` (`seasonThemedArt`, параметр насыщенности), тест `season_theme_colors_contract.test.ts` (допуск оттенка 8°).
Out of scope: веер «Вся глава» (отменён), экран урока по новым макетам (8 · МОМЕНТЫ).

## Architecture
`seasonThemedArt(themeHue, chapter, episode, theme, exam)`: оттенок = оттенок акцента темы; светлота темнее на `0.015*(глава%4) + 0.004*(эпизод%8)`; насыщенность ×1 / 0,88 / 0,76 по главам; экзамен — темнее на 0,12 и ×0,8. Белый текст держит ≥ 4,5, потому что светлота только падает.
