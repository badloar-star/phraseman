## Outcome

Ученик, отвечая на опрос, сразу видит «+1 жемчужина» в строке ответа, жемчужина
улетает в чип баланса в шапке шторки, число докручивается, затем без лишнего
тапа открывается панель «Спасибо! +1 жемчужина уже на счету». Плашка опроса на
Главной показывает весь заголовок без «…», растёт по тексту, шрифт на 20% меньше,
плашка мягко пульсирует, пока опрос активен. Успех: владелец видит поведение
1-в-1 с макетом A на устройстве.

## Scope

In scope: components/survey/SurveySheetModal.tsx, SurveyRewardPanel.tsx, новые
SurveyPearlChip.tsx и SurveyPearlFlight.tsx, components/SurveyTaskCard.tsx,

Firestore, другие экраны с жемчугом.

## Architecture

Граница прежняя: useSurveyFlowController владеет состоянием ответов и отправкой;
шторка добавляет ТОЛЬКО презентационный слой: локальную optimistic-дельту баланса
(+1 после перелёта, сброс при retryable-error или confirmedReward=0, схлопывание
когда родительский баланс вырос), автопереход goNext после хореографии,
overlay перелёта (transform/opacity на UI-потоке Reanimated, без withRepeat).
Пульс плашки на Главной: withRepeat под гардом useRuntimeActive + reduceMotion,
только в фазе active. Инвариант: награду начисляет только сервер; клиент лишь
показывает.

## Security and privacy

Персональные данные не добавляются, сеть не меняется. Баланс жемчуга читается из
уже существующего локального состояния Главной.
