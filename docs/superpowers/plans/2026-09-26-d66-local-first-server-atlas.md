# D66 Local-First Server Atlas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every discovered server connection visibly and testably classified against the owner’s D66 local-first policy before any runtime connection is removed or replaced.

**Architecture:** The existing Server Decision Atlas remains a read-only static inventory. A small policy module will attach a conservative D66 status to each record: explicitly allowed service, must retire/replace, or requires manual review. The classifier must never claim that an unknown route is safe; only a narrow source-and-route allowlist receives an allowed status. The interactive HTML will display the status and the existing browser/contract suite will make policy omissions visible.

**Tech Stack:** Node.js ESM, `node:assert/strict`, existing static source scanner, HTML generated by `scripts/server_decision_atlas/render.mjs`, Playwright browser smoke test.

---

## Scope and boundaries

This plan implements only the audit guard. It does not change Firestore listeners, Cloud Functions, Firestore Rules, `cloud_sync`, authentication, purchases, account lifecycle, migrations, or production configuration. Those are separate work packages after the atlas identifies one bounded route at a time.

The owner’s current D66 rule is exact: normal learning and progression decisions happen locally; the server is limited to durable progress sync/storage, subscriptions and purchases, content/video/updates, notifications, and technical authentication needed to reach synchronization. Account deletion and competitive integrity remain security-sensitive contracts and stay `manual-review` unless the account owner supplies their API boundary.

## Files and responsibilities

- Create: `scripts/server_decision_atlas/d66_policy.mjs` — pure, deterministic classification of one scanned record.
- Modify: `scripts/server_decision_atlas/catalog.mjs` — imports the policy module, adds `d66` to each record and summary counts to metrics.
- Modify: `scripts/server_decision_atlas/render.mjs` — renders the D66 status and explanation without changing any user decision or source snippet.
- Modify: `tests/server_decision_atlas_contract.mjs` — verifies exact policy classification and atlas wiring.

- Modify: `docs/phraseman-2.0/tasks/PM-225.md` — link the audit result and retain `in_progress` until a non-allowed listener is actually replaced.

- [ ] **Step 3: Create the policy module**

Create `scripts/server_decision_atlas/d66_policy.mjs` with this complete pure classifier:

```js
const REALTIME_EXCEPTIONS = new Map([
  ['components/PremiumContext.tsx', {
    service: 'subscription',
    reason: 'Это проекция права на подписку; D66 допускает её получение с сервера.',
  }],
  ['app/app_messages.ts', {
    service: 'notification',
    reason: 'Это доставка уведомлений; D66 допускает серверный канал уведомлений.',
  }],
  ['app/remote_account_deletion_monitor.ts', {
    service: 'technical-authentication',
    reason: 'Это технический защитный контур аккаунта, необходимый для безопасного доступа к синхронизации.',
  }],
]);

export function classifyD66(record) {
  if (record.routeType === 'client-firestore' && record.name === 'onSnapshot') {
    const exception = REALTIME_EXCEPTIONS.get(record.sourcePath);
    if (exception) return { kind: 'allowed-service', ...exception };
    if (record.sourcePath === 'app/firestore_friend_requests.ts') {
      return {
        kind: 'retire-or-replace',
        service: null,
        reason: 'Постоянная лента друзей не относится к разрешённым сервисам D66; заменить чтением по фокусу с TTL и локальным SWR-кешем.',
      };
    }
    if (record.sourcePath === 'app/league_group_boosts.ts') {
      return {
        kind: 'retire-or-replace',
        service: null,
        reason: 'Постоянное состояние группы не относится к разрешённым сервисам D66; удалить вместе с устаревшей механикой либо заменить локальным состоянием.',
      };
    }
    return {
      kind: 'retire-or-replace',
      service: null,
      reason: 'Постоянное Firestore-соединение не входит в явный allowlist D66; нужен отдельный безопасный путь замены.',
    };
  }

  if (record.routeType === 'client-firestore' || record.routeType === 'client-callable' || record.routeType === 'client-http') {
    return {
      kind: 'manual-review',
      service: null,
      reason: 'Статический разбор нашёл связь, но не доказывает её назначение. Сверить с D66 до изменения поведения.',
    };
  }

  return {
    kind: 'manual-review',
    service: null,
    reason: 'Серверный маршрут требует отдельного анализа: atlas не делает предположений о праве сервера принимать решение.',
  };
}
```
