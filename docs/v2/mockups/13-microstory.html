Тема приложения

Прогон состояний

Обложка: тап «Слушать» открывает плеер. Тап по любой строке ленты ставит на паузу и раскрывает деталь-панель (перевод + повтор фрагмента + сохранить). Тап по активной пилюле «1×» переключает 0.75×. Полоса прогресса истории: только индикатор, тап по ней в макете не перематывает.

Спецификация для RN (Reanimated 4)

Переход обложка → плеер240 мс · fade + slide 10px
Подсветка активной строкиcrossfade 240 мс · только transform
Кегль активной строкиtransform:scale(1.08), НЕ font-size
Автоскролл ленты к строке320 мс · slide, scrollTo
Раскрытие деталь-панели320 мс · maxHeight outquint
Сохранение фразы: закладкаспринг micro + полёт в шапку 620 мс
Comprehension: верноokPop 340 мс + звезда + продолжение
Comprehension: невернотонировка 180 мс, без тряски
Загрузка эпизода1500 мс · линейная заливка CTA
Финал: бейдж420 мс · spring, ряды фраз 320 мс стаггер
В RN: phrase_audio_player: единый движок таймкодов; подсветка строки управляется его onProgress. Скролл ленты: через Reanimated scrollTo на shared value, не JS-скролл. Кегль активной реплики: исключительно transform (UI-тред), font-size остаётся неизменным во всех состояниях, геометрия строки не пересчитывается.
