# Кнопка перехода в старую админку

Дата: 2026-07-14

## Цель

Добавить в Admin 2 постоянный и заметный переход к старой админке для функций, которые ещё не перенесены. Переход не должен выглядеть как главное действие текущего экрана.

## Размещение и поведение

- Разместить ссылку-кнопку `Старая админка` в правой части верхней панели `admin/v2/index.html`.
- Вести на публичный путь `/legacy.html`. Путь `/index.html` не подходит, потому что перенаправляет обратно в Admin 2.
- Открывать старую админку в новой вкладке через `target="_blank"` и `rel="noopener"`, чтобы сохранить текущий экран Admin 2 и изолировать контекст новой вкладки.
- Использовать видимую текстовую подпись и SVG-иконку внешнего перехода. Emoji не использовать.
- Добавить доступную подсказку: `Открыть старую админку в новой вкладке — для функций, которых ещё нет в Admin 2`.

## Внешний вид

- Использовать отдельный secondary-стиль, а не `.primary`, чтобы не создавать второй главный CTA.
- Применить спокойный warning-фон и заметную рамку из существующей палитры Admin 2.
- Сохранить тёмный текст, минимальную высоту 44 px, стабильный hover без изменения геометрии и существующий видимый `focus-visible`.
- На ширине до 760 px оставить кнопку видимой, несмотря на общее правило скрытия ссылок верхней панели. Скрыть только текстовую подпись, оставив квадратную SVG-кнопку с `aria-label` и подсказкой.

## Затрагиваемые файлы

- `admin/v2/index.html` — ссылка, подпись, SVG-иконка и доступные атрибуты.
- `admin/v2/styles/admin.css` — desktop, hover и mobile-оформление.
- Новый узкий контрактный тест — проверка пути, новой вкладки, `noopener`, текста и доступной подсказки.

Изменение не затрагивает авторизацию, Firebase, данные, маршрутизацию Admin 2 и содержимое старой админки.

## Ошибки и ограничения

- Ссылка является обычной статической навигацией и не требует состояния загрузки.
- Если `/legacy.html` недоступен, браузер покажет стандартную ошибку загрузки; Admin 2 останется открытой в исходной вкладке.
- Кнопка не должна перехватывать hash-маршруты и не должна использовать `admin/index.html`, чтобы избежать возврата в Admin 2.

## Проверка

- Узкий Jest-контракт для HTML и CSS кнопки.
- `node scripts/admin-v2-smoke.mjs`.
- `node scripts/admin-v2-control-plane-smoke.mjs`.
- `node scripts/admin-v2-tooltip-audit.mjs`.
- `node scripts/admin-v2-language-audit.mjs`.
- Проверка отображения на 375, 768, 1024 и 1440 px, включая клавиатурный фокус, отсутствие горизонтального скролла и видимость кнопки в светлой и тёмной темах.

## Критерии приёмки

1. Кнопка видна на каждой странице Admin 2.
2. На desktop отображаются иконка и текст `Старая админка`; на узком экране остаётся доступная иконка.
3. Нажатие открывает `/legacy.html` в новой вкладке.
4. Кнопка имеет понятную подсказку и доступна с клавиатуры.
5. Она заметна, но визуально не конкурирует с главным действием страницы.
6. Существующие маршруты, авторизация и функции обеих админок не меняются.
