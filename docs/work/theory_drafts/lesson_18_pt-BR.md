# Teoria · Lição 18 do curso novo — «cheaper than, the cheapest, as … as, too / enough, so / such» (PT-BR)

> Sessão «12 · ТЕОРИЯ», 22.10.2026. Seções 01–08, frases em inglês e exercícios como em
> `lesson_18_ru.md`. Armadilhas de um brasileiro: «mais barato que» (→ more cheaper / cheaper
> that), «o mais barato» (→ the most cheapest), «tão … quanto» (→ so … as / as … than), «tão» e
> «tal» se misturam (→ so a helpful person). Tratamento: você. Precisa de revisão de um falante
> nativo.

**Título da tela:** Teoria · Comparando

---

## 01 · O que você vai aprender a dizer *(aberta de início)*

**body**
Esta lição é para comparar: «este quarto é mais barato que o nosso», «esta loja tem a entrega mais rápida», «este café é tão forte quanto o seu», «a mala é grande demais», «a gente tem uma relação tão boa». Quase tudo são pequenos acréscimos à palavra.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| This hotel room is cheaper than ours. | Este quarto de hotel é mais barato que o nosso. | cheaper than |
| This shop has the shortest delivery time. | Esta loja tem a entrega mais rápida. | the shortest |
| This instant coffee is as strong as yours. | Este café solúvel é tão forte quanto o seu. | as strong as |
| This cabin bag is too big. | Esta mala de mão é grande demais. | too big |
| We have such a good relationship. | A gente tem uma relação tão boa. | such a |

---

## 02 · -er than — «mais barato que» *(aberta de início)*

**body**
Para «mais barato», «mais silencioso», «mais longo» se põe -er na palavra, e «que» é than: cheaper than ours. O «mais» já está no -er, então não vai more: nunca more cheaper. E esse «que» não é that.

**formula**
`o quê` · `is` · `palavra + er` · `than` · `com o quê`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| This hotel room is cheaper than ours. | Este quarto de hotel é mais barato que o nosso. | cheaper than |
| The shared bathroom is cleaner than before. | O banheiro compartilhado está mais limpo que antes. | cleaner than |
| The train journey is shorter than ours. | A viagem de trem é mais curta que a nossa. | shorter than |
| The airport bus is slower than a taxi. | O ônibus do aeroporto é mais lento que um táxi. | slower than |
| These leather shoes are softer than that pair. | Estes sapatos de couro são mais macios que aquele par. | softer than |

**fix**
- ~~This hotel room is more cheaper than ours.~~ → This hotel room is cheaper than ours.
- ~~The shared bathroom is cleaner that before.~~ → The shared bathroom is cleaner than before.
- ~~This hotel room is cheap than ours.~~ → This hotel room is cheaper than ours.

**drill · choice**
- frase: `The top floor is ___ than this floor.`
- opções: `quieter` · `more quieter` · `quiet`
- resposta: `quieter`
- por quê: «Mais silencioso que» é palavra + -er, sem more.

## 03 · the -est — «o mais…»

**body**
Se você escolhe um entre todos — «o mais barato», «o mais perto» —, põe -est e na frente the: the shortest delivery time, the nearest shop. O «mais» já está no -est: nada de the most cheapest. -er compara dois; the -est, um com todos.

**formula**
`the` · `palavra + est` · `(coisa)`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| This shop has the shortest delivery time. | Esta loja tem a entrega mais rápida. | the shortest |
| This clinic has the longest waiting time. | Nesta clínica a espera é a mais longa. | the longest |
| This local shop is the nearest. | Esta lojinha do bairro é a mais perto. | the nearest |
| The plain yoghurt is the cheapest option. | O iogurte natural é a opção mais barata. | the cheapest |
| We booked the earliest home visit. | Marcamos a visita domiciliar mais cedo. | the earliest |

**fix**
- ~~This shop has the most shortest delivery time.~~ → This shop has the shortest delivery time.
- ~~This shop has shortest delivery time.~~ → This shop has the shortest delivery time.
- ~~This shop has the shorter delivery time.~~ *(de todas)* → This shop has the shortest delivery time.

**drill · binary**
- pergunta: Você está vendo três lojas. Esta é a maior. O que você diz?
- A: `This chain store is the larger.`
- B: `This chain store is the largest.`
- certa: B
- explicação: Uma entre todas: the + -est.

## 04 · as … as — «tão … quanto»

**body**
Se não há diferença — «tão forte quanto o seu» —, a palavra fica entre dois as: as strong as yours. «Tão … quanto» puxa para so … as, mas em inglês são os dois as, e a palavra fica sem -er.

**formula**
`o quê` · `is` · `as` · `palavra` · `as` · `com o quê`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| This instant coffee is as strong as yours. | Este café solúvel é tão forte quanto o seu. | as strong as |
| This green tea is as cheap as that one. | Este chá verde é tão barato quanto aquele. | as cheap as |
| These reading glasses are as light as mine. | Estes óculos de leitura são tão leves quanto os meus. | as light as |
| This electric kettle is as fast as ours. | Esta chaleira elétrica é tão rápida quanto a nossa. | as fast as |

**fix**
- ~~This instant coffee is so strong as yours.~~ → This instant coffee is as strong as yours.
- ~~This instant coffee is as strong than yours.~~ → This instant coffee is as strong as yours.
- ~~This instant coffee is as stronger as yours.~~ → This instant coffee is as strong as yours.

---

## 05 · too e enough — «demais» e «o suficiente»

**body**
too — «demais», atrapalha: This cabin bag is too big. enough — «o suficiente», serve: This checked bag is light enough. Aqui o inglês é como o português: «leve o suficiente» — enough depois da palavra. Já too vem antes.

**formula**
`atrapalha: too + palavra` · `serve: palavra + enough`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| This cabin bag is too big. | Esta mala de mão é grande demais. | too big |
| This checked bag is light enough. | Esta mala despachada é leve o suficiente. | light enough |
| The monthly rent is too high. | O aluguel mensal é alto demais. | too high |
| The rental deposit is low enough. | A caução do aluguel é baixa o suficiente. | low enough |
| This driveway is too narrow. | Esta entrada da garagem é estreita demais. | too narrow |

**fix**
- ~~This cabin bag is big too.~~ → This cabin bag is too big.
- ~~This checked bag is enough light.~~ → This checked bag is light enough.

**drill · choice**
- frase: `This window lock is strong ___.` *(a trava serve, não precisa trocar)*
- opções: `enough` · `too` · `so`
- resposta: `enough`
- por quê: «O suficiente» é enough, e vem depois da palavra.

---

## 06 · so e such — «tão» e «tal»

**body**
Sem coisa depois — so: My close friend is so kind («tão gentil»). Se depois vem uma coisa — such: such a helpful person («uma pessoa tão prestativa»), such hard work. A ordem é such a, não a such.

**formula**
`sem coisa: so + palavra` · `com coisa: such a + palavra + coisa`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| My close friend is so kind. | Meu amigo próximo é tão gentil. | so |
| Our mutual friend is such a helpful person. | Nosso amigo em comum é uma pessoa tão prestativa. | such a |
| This is such hard work. | Isso é um trabalho tão pesado. | such |
| The live music is so loud. | A música ao vivo está tão alta. | so |
| You have such a good memory. | Você tem uma memória tão boa. | such a |

**fix**
- ~~Our mutual friend is so a helpful person.~~ → Our mutual friend is such a helpful person.
- ~~My close friend is such kind.~~ → My close friend is so kind.
- ~~Our mutual friend is a such helpful person.~~ → Our mutual friend is such a helpful person.

**drill · word_bank**
- tarefa: Diga: «A gente tem uma relação tão boa».
- resposta: `We` · `have` · `such` · `a` · `good` · `relationship`
- rótulos das casas: não (frase longa)
- fichas a mais: `so` · `much`

## 07 · Os erros que quase todo mundo comete

**fix**
- ~~This hotel room is more cheaper than ours.~~ → This hotel room is cheaper than ours.
- ~~This shop has the most shortest delivery time.~~ → This shop has the shortest delivery time.
- ~~This instant coffee is so strong as yours.~~ → This instant coffee is as strong as yours.
- ~~This cabin bag is big too.~~ → This cabin bag is too big.
- ~~Our mutual friend is so a helpful person.~~ → Our mutual friend is such a helpful person.

**tip**
Duas coisas: -er than. Uma entre todas: the -est. Igual: as … as. Atrapalha: too antes; serve: enough depois. Sem coisa: so; com coisa: such a.

## 08 · O que levar para a prática

**body**
-er than para comparar dois. the -est para escolher um entre todos. as … as para dizer «igual». too / enough: «demais» e «o suficiente». so / such: so sem coisa, such com coisa.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| The sale price is lower than before. | O preço da promoção está mais baixo que antes. | lower than |
| This dining table is the widest. | Esta mesa de jantar é a mais larga. | the widest |
| This is such a big improvement. | É uma melhora tão grande. | such a |
