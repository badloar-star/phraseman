# Learning V2 — выход без «Сессия недоступна», прокрутка и верхний край

Governance-ID: TG-54906AC63197

## Outcome
1. Закрытие сессии НИКОГДА не показывает экран «Сессия недоступна».
   Владелец 21.09: «вышел из сессии (закрыл её) и написано этой сессии
   больше недоступна — такого экрана не должно быть никогда».
2. Быстрая продолжительная прокрутка карты не разгоняется до скорости,
   на которой строки не успевают отрисоваться.
3. Анимация первого кружка при открытии карты не обрезается верхним краем.

## Scope
- `app/learning_v2_direct_session_player_v1.tsx` — ветка «unavailable»
  при выходе.
- `components/learning-v2/LearningV2PulseCourse.tsx` — затухание
  прокрутки, верхний отступ карты.

## Architecture
1. **Выход.** `exitLearningV2Session` ставит `sessionExitRequestedRef` и
   вызывает `router.replace`. Между этим вызовом и размонтированием React
   успевает отрендерить компонент ещё раз, а параметры маршрута уже пусты
   → `routeCoordinates === null` → ветка «Сессия недоступна». Ветка
   получает предохранитель: при запрошенном выходе она не рисует ошибку,
   а отдаёт пустой фон под цвет темы. Это НЕ прячет настоящую ошибку:
   она остаётся для случая, когда экран открыт с битым маршрутом.
2. **Прокрутка.** decelerationRate 0.985 гасит инерцию, но на длинном
   быстром жесте скорость набирается самим жестом. Снижаем до 0.97 и
   поднимаем плотность отрисовки при быстром движении.
3. **Верхний край.** Кружок текущего занятия имеет гало и тень за
   границами своей строки; при `padding`, равном высоте шага, верх
   анимации уходит под край. Добавляем запас сверху.
