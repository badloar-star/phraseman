## Урок 15 — новые задания не нужны: убрать подсказку из условия (6 примеров, всего таких 128)

Задания уже проверяют главное («решил сам» → going to, «договорился, есть время» → -ing), но последняя фраза условия называет
ответ («Передайте намерение через going to»). Для входного теста достаточно **условия без последней фразы** — выбор тогда делает
