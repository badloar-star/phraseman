# Спек: «Разговорный клуб» — режим устной практики (Loora-style) v1.0

Дата: 2026-07-04. Статус: концепт согласован по итогам разбора Loora (loora.com support, App Store/GP, обзоры) и разведки кодовой базы. Макеты: артефакт «speaking-club-concept» (5 экранов).

## 1. Суть

Отдельный режим обучения: **32 голосовые миссии — по одной на каждый урок курса**. Живой разговор с ИИ-собеседником (hold-to-talk), который заставляет использовать вслух фразы только что пройденного урока. Механика Loora (подсветка ошибок в чате, разбор по тапу, один Key Takeaway после сессии, Practice Zone), но встроенная в наш курс, экономику осколков и прогрессию уроков.

**Главный дифференциатор от Loora:** разговор — четвёртое касание фразы (урок → флешкарты → диалог → применил вслух). У Loora разговор ни к чему не привязан — это её главная слабость по отзывам («поговорил и забыл», «статистика без цели»).

## 2. Структура: 32 миссии, 4 акта по CEFR-уровням курса

Миссия N открыта ⇔ урок N пройден (`lesson_lock_system` наследуется; пограничные 9/19/29 автоматически требуют зачёт уровня).

| Акт | Миссии | Уровень | Формат | Особенности |
|---|---|---|---|---|
| I «Разминка» | 1–8 | A1 | управляемый Q&A: эхо фразы урока + свой ответ | подсказка-ответ всегда видна, реплики ИИ короткие |
| II «Сценки» | 9–18 | A2 | ролевые миссии с целью (кафе, дорога, отель…) | персонаж с голосом/характером, цели-чеклист |
| III «Истории» | 19–28 | B1 | мини-текст/ситуация → обсуждение мнений (Read&Talk) | вопросы «почему», оценка беглости строже |
| IV «Свободный полёт» | 29–32 | B2 | дебаты, собеседование, спонтанный разговор | подсказки выключены (вкл. за осколки); миссия 32 — «выпускной разговор» с профессором Лингманом |

Параметры миссии: 10–14 обменов репликами, 5–10 минут, без таймера, оценка до 3 звёзд. Цели миссии: цель сценария + использовать 3–4 фразы урока N (чек-лист виден в разговоре).

## 3. Экран разговора

- Чат-транскрипт. В репликах ЮЗЕРА подсвечиваются: **красным** — ошибки (грамматика/произношение), **жёлтым** — «можно естественнее». Собеседник вслух НЕ исправляет и не перебивает (как Loora: максимум 2–3 устных подсказки за сессию, остальное — визуально).
- Тап по подсвеченному слову → шторка разбора: «Ты сказал … / Носитель сказал бы …» + почему + пословная оценка произношения (зелёный/жёлтый/красный) + кнопка «🎙️ Сказать ещё раз» (переговаривать до идеала — любимая фича юзеров Loora).
- Инструменты (низ экрана): 💡 Подсказка ответа (free — за осколки, Plus — бесплатно) · 🛟 «Как сказать?» (пишешь на родном → перевод, проговори его) · 📖 Фразы урока (шпаргалка целевых фраз) · под репликой ИИ: 🔄 перевод · 🐌 медленнее · 🔁 ещё раз.
- Тап по любому слову ИИ → в словарик. Полезные фразы ИИ подсвечиваются (движок уже делает `[[...]]`).
- Ввод: hold-to-talk (основной), тумблер hands-free (тап-старт/тап-стоп), fallback-клавиатура ⌨️ (доступность/шум).
- Чек-лист целей миссии сверху, отмечается на лету (движок диалогов уже возвращает `objectivesMet`).

## 4. Итог миссии

- Балл беседы (0–100) → звёзды; 4 оси: беглость, произношение, грамматика, словарь.
- **Ровно ОДИН «Главный вывод»** (Key Takeaway, как у Loora): самая важная ошибка → мини-упражнение (правило+примеры / звук / естественная лексика). Сохраняется в копилку выводов, повторяется в следующих миссиях.
- Чек «фразы урока использованы 3/3».
- Награды в ОБЩУЮ экономику: осколки (+25 базово), серия дня (миссия засчитывается в стрик), XP.
- Кнопка «В Клуб» (см. п.5).

## 5. «Клуб» (аналог Practice Zone)

Открывается после миссии дня: свободная болтовня на любую тему, темы из интересов профиля, свои сценарии, дебаты. Free: одна короткая сессия (~5 мин). Plus: безлимит. Здесь же: копилка выводов, словарик, тренажёр произношения слова (переиспользуем word drill).

## 6. Отличия-козыри (что делаем лучше Loora)

1. Привязка к урокам курса (см. выше).
2. **Память собеседника**: Firestore-профиль (имя, работа, интересы, прошлые темы, старые ошибки) → «В прошлый раз ты путал since/for — проверим?». У Loora «память золотой рыбки» — жалоба №1.
3. **Ролевые персонажи с разными голосами** (бариста/интервьюер/попутчик) вместо одной персоны.
4. Адаптивная сложность от честной оценки уровня (скучно для C1 — жалоба №2 на Loora).
5. Никакой новой валюты: осколки (у Loora отдельные «гемы»).
6. Free-день даёт ПОЛНУЮ миссию (а не 10-минутный обрубок с 24ч локаутом — главный негатив Loora).

## 7. Монетизация

- Free: 1 миссия/день целиком; 2-я миссия — за осколки по нарастающей (аналог гемов Loora 15→20→25); Клуб — 5 минут.
- Plus: миссии безлимит, Клуб безлимит, подсказки бесплатно, пооценочное произношение + мини-уроки звуков, постоянная память собеседника, свои сценарии.
- Новый `FeatureGate` `speaking_club` в `app/feature_gates.ts` + remote-флаг `gate_speaking_club_premium` (дефолт true), гейт через `useFeatureAccess('speaking_club')`, пейвол `router.push('/premium_modal', {context:'speaking_club'})`.

## 8. Техреализация (переиспользование)

- **STT**: `app/speaking_recognition_options.ts` c `holdToTalk:true` (continuous под палец); 7-сек watchdog (паттерн `SpeakingPanel`/`SpeechBeat`); Android-фолбэк PCM→whisper (`speaking_hold_recorder` + `speaking_neural_judge`) там, где поддержан.
- **Скоринг произношения**: для целевых фраз урока — существующее ядро (`personal_plan_pronunciation_scoring_core` + честная оценка `speaking_honesty_check` + `speaking_phoneme_diff`). Для свободной речи — новый режим: скоринг по финальному транскрипту против «эталона» = собственная реплика юзера, нормализованная ИИ (волна 2).
- **Диалоговый движок**: новая cloud function `speakingClubSend` по образцу `functions/src/premium_dialog.ts` (scenario-режим + gameBlock с objectives; companion-режим для Клуба). Обязательно: `GLOBAL_RULES`-паттерн, CEFR-reinjection, language lock (`assertDialogReplyMatchesTarget`-аналог), модерация `ai_safety.ts`. Новое: в JSON-конверт добавить `corrections[]` (спан в реплике юзера, тип error|upgrade, объяснение, native-вариант) — для подсветки без второго вызова.
- **Разбор после миссии**: паттерн `premiumDialogReview`; перевод — паттерн `premiumDialogTranslate`.
- **Квоты**: зеркальный паттерн `premium_dialog` (rate limit 60/час, дневная квота free/premium, транзакции, billing-лог, App Check). Константы клиент↔сервер зеркалить (ловушка из диалогов).
- **TTS**: `useAudio().speak()` (динамический текст → системный TTS; замедление с питч-коррекцией уже есть). Голоса персонажей: voice override expo-speech (волна 2), опционально OpenAI TTS стрим позже.
- **Языки**: принимать `interfaceLang` (9 языков) + `studyTarget` (en|fr); новый литерал `AiLanguageFeature` `'speaking_club'` в `functions/src/ai_language_contract.ts`; промпт через `studyTargetName()`.
- **Навигация**: route `app/speaking_club_home.tsx` + `app/speaking_club_session.tsx`, регистрация в `app/_layout.tsx`, плитка в `quickItems`/`activityQuickItems` (`app/(tabs)/home.tsx`).
- **Контент миссий**: `app/speaking_club_missions.ts` — 32 записи `{lessonId, актType, сценарий, роль ИИ, цель, objectives[], targetPhrases (из фраз урока), персонаж/голос, темы}`; фразы берём из `getLessonData(id)`.
- **Стриминга в бэкенде нет** — короткие реплики через onCall приемлемы (у Loora ответ 1.5–2 с — норм для юзеров); стриминг не проектируем в v1.

## 9. Волны запуска

1. **MVP**: 8 миссий Акта I на готовом движке диалогов (objectives уже поддержаны), экран разговора с hold-to-talk, итог через review-паттерн, плитка+гейт, квоты. Без подсветки ошибок в реплике (только финальный разбор).
2. Все 32 миссии, `corrections[]`-подсветка + шторка разбора + «сказать ещё раз», пооценочный скоринг, Клуб для Plus, подсказки за осколки, голоса персонажей.
3. Память собеседника, свои сценарии, дебаты, мини-уроки звуков, hands-free, «выпускной» с Лингманом.

## 10. Не делаем (осознанно)

- Перебивание ИИ голосом (barge-in) — turn-based, как у Loora; архитектурно проще, юзеры не жалуются.
- Стриминг ответа — не в v1.
- Отдельную валюту/лиги для режима — всё в общую экономику.
- Расширение числа уроков >32 — режим живёт поверх существующей прогрессии.
