# Англійська · Урок 17 · Заняття 48 — Покупки й повернення товару

**Ситуація.** Ви порівнюєте умови магазинів, документи доставки й курси валют перед купівлею за кордоном.

**Що ви опануєте:** some / any + plural count noun or non-count noun
**Нові слова:** refund policy, return label, exchange rate, delivery note

## Інтро 1

### Повідомити про наявність

refund policy — правила повернення грошей. Ви порівняли умови повернення в кількох магазинах. Refund policy → refund policies. Some ставимо перед злічуваним у множині або незлічуваним, коли повідомляємо про певну кількість.

**Виберіть фразу для цієї ситуації.**

- ✅ **We compared some refund policies.**
- ❌ We compared any refund policies. — *У стверджувальному повідомленні про певну кількість використовуємо some.*
- ❌ We compared a refund policies. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 2

### Повністю заперечити наявність

return label — поштова етикетка для зворотного відправлення товару. Для жодної посилки етикетки немає. Повністю заперечте наявність. Return label → return labels. exchange rate — обмінний курс валюти. Some використовується з множиною злічуваних та з незлічуваними. У запереченні зі значенням «жодного» зазвичай вибираємо any.

**Виберіть фразу для цієї ситуації.**

- ✅ **We don't have any return labels.**
- ❌ We don't have some return labels. — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ We don't have a return labels. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 3

### Запитати без припущення

delivery note — документ зі списком доставлених товарів. Ви не знаєте, чи збереглися документи з посилок. Запитайте нейтрально. Delivery note → delivery notes. У нейтральному запитанні зазвичай any. Some теж трапляється в запитаннях: наприклад, у пропозиції Would you like some tea? або коли очікують «так». Тому враховуйте ситуацію, а не лише знак питання.

**Виберіть фразу для цієї ситуації.**

- ✅ **Do you have any delivery notes?**
- ❌ Do you have some delivery notes? — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ Do you have a delivery notes? — *A не ставиться перед незлічуваним або множиною.*
