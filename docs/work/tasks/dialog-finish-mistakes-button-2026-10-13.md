# Task packet: «Добить: Ещё учу (N)» на итоге диалога

Governance-ID: TG-583CFCED2650
Status: In progress
Owner: сессия «2 · ДИЗАЙН» по решению владельца 13.10 («Да, пусть ошибки диалога попадают в Мои ошибки») и после коммита Ядра (запись ошибок диалога)

## Outcome

На итоге диалога при наличии ошибок под «Готово» вместо «Ещё раз» — «Добить: Ещё учу (N)» (макет dialogs.html D2: `.quiet`); нажатие запускает отработку ошибок этого диалога (`dialogMistakes.openPractice`); а кнопка «Повторить ошибки» в карточке «Ошибки» делает то же. Без ошибок остаётся «Ещё раз».

## Scope

In scope: `app/dialogue_v2_completion.tsx` (подпись и действие нижней тихой кнопки, кнопка в карточке «Ошибки»), сторож.

Out of scope: запись ошибок диалога в журнал и сам хук (`hooks/useDialogueV2MistakeCapture.ts`, Ядро).

## Architecture

Экран берёт из хука `status`, `mistakeIds.length` (N) и `openPractice`; кнопка показывается при `status === 'ready'` и N > 0. Подпись на 9 языках по образцу итога урока.

## Security and privacy

Новых данных нет: ошибки диалога пишет хук Ядра; экран только показывает счётчик и открывает отработку.

## Technical debt

Contain: в dev-подмене итога хук отдаёт заглушки id и не открывает отработку (по решению Ядра).

## Verification
