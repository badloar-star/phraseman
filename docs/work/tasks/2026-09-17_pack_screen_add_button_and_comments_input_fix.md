## Outcome

Владелец протестировал фичу вживую и нашёл два дефекта: (1) кнопка «Добавить
себе» / «В моих наборах» на экране набора — большая текстовая плашка, владелец
хочет компактную иконку (плюсик до добавления, простая галочка после);
(2) поле ввода комментария физически отсутствует на экране — «писать
комментарий невозможно, там нет поля ввода». Задача — исправить оба.

## Scope

In scope:
- `app/community_packs/CommunityPackSocialBar.tsx` (variant="screen"): заменить
  текстовую кнопку «Добавить себе»/«В моих наборах» на компактную
  иконку-кнопку (плюс/галочка), сохранив hit-area ≥44pt и все существующие
  accessibility-атрибуты, optimistic UI, анимацию лайка.
- `app/community_packs/PackCommentsSheet.tsx`: диагностировать, почему поле
  ввода не появляется (canWrite остаётся false, либо загрузка бесконечна,
  либо иная причина) — СНАЧАЛА логи (правило проекта), потом починка. Добавить
  видимую причину пользователю вместо молчаливой пустоты, когда canWrite=false.

Out of scope:
- Полная переработка визуального языка экрана набора за пределами этих двух
  элементов.
- Изменение самого правила «писать может только добавивший набор или автор» —
  это уже подтверждённое владельцем поведение, чинится ТОЛЬКО отображение
  причины/сам баг, не правило.
