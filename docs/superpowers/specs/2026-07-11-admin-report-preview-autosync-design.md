# Автосинхронизация ответов на репорты в превью админки

## Цель

После подготовки и dry-run нового `replies.json` черновики без дополнительного согласования добавляются в `PREPARED_REPORT_REPLIES`, проверяются и публикуются через Firebase Hosting `admin`.

## Граница безопасности

- Автоматизируется только статический предпросмотр в админке.
- Firestore, уведомления пользователей, статусы репортов и осколки не изменяются.
- `sendAllPreparedReplies()` и индивидуальная отправка остаются ручными действиями администратора с подтверждением.
- CLI с `--send` из Codex не запускается.

## Поток

1. Подготовить `replies.json` с `resolution` и `rewardGroup`.
2. Выполнить `node scripts/reply_to_reports.mjs replies.json --dry-run`.
3. Идемпотентно добавить записи по `reportId` в `PREPARED_REPORT_REPLIES`.
4. Проверить совпадение заголовка, текста, награды и метаданных.
5. Задеплоить только `hosting:admin`.
6. Проверить опубликованный HTML, не нажимая кнопки отправки.

## Критерии готовности

- Все строки текущего `replies.json` присутствуют в превью ровно один раз.
- Ручная отправка и confirmation-диалог сохранены.
- Встроенная LLM-инструкция и `AGENTS.md` требуют автопубликацию превью.
- Успешно выполнены узкие тесты, dry-run и деплой `hosting:admin`.
