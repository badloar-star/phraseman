## Outcome
Тестер: «Собери фразу», ситуация «Брат высокий.», а крупная инструкция — «Подпишите его портрет.».
Источник: строки «Соберите фразу — брат высокий; подпишите его портрет» (uk «Складіть фразу — брат високий; підпишіть
його портрет») в learner.json/learner.uk.json урока en/l01/s09. Приложение режет текст по «;» и показывает хвост
как инструкцию. Нужно: простая инструкция без сюжетного хвоста («Соберите фразу: брат высокий.»), и тот же дефект —
во всех уроках и языках.

## Scope
Только тексты заданий (prompt / accessibilityLabel / localizedMeaning / testedDimension) с «;»-хвостом в
generated_release и в источнике фабрики (content/learning-v2-course: sessions/*/practice.atomic.json, final.*.md,
release/*). Генерируемые файлы (манифест, отпечатки) — только штатной пересборкой, не руками. Код приложения не трогаю.

## Architecture
Сначала поиск [PROMPT-TAIL] (только чтение) по всем learner*.json → список строк. Затем правка источника и
штатная пересборка релиза курса (сборщик Learning V2). Если меняется голова курса — новая голова в
LADDER_TRUSTED_COURSE_HEADS_V1 (сторож referral_ladder_course_heads_guard) и проверка release_changed.

## Security and privacy
Данных пользователей нет.

## Technical debt

## Verification
