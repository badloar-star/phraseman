## 01 · Что вы научитесь говорить *(открыт сразу)*

**body**
В этом уроке вы учитесь рассказывать, что где есть: «рядом есть аптека», «в холодильнике есть молоко», «здесь нет звонка», «ключ под ковриком». Главная новая фраза урока — There is: по-русски это просто «есть».

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There is a pharmacy here. | Здесь есть аптека. | There is |
| There is some milk here. | Здесь есть молоко. | some |
| Is there a toilet here? | Здесь есть туалет? | Is there |
| There isn't a doorbell. | Звонка нет. | isn't |
| The key is under the doormat. | Ключ под ковриком. | under |

---

## 02 · There is — «здесь есть» *(открыт сразу)*

**body**
Когда сообщаете, что где-то что-то есть, начинайте с There is. По-русски «Здесь есть аптека», а в английском порядок другой: There is a pharmacy here. Место уходит в конец.

**formula**
`There is` · `a + вещь` · `где`

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There is a pharmacy here. | Здесь есть аптека. | There is |
| There is a library nearby. | Рядом есть библиотека. | There is |
| There is a bakery here. | Здесь есть пекарня. | There is |
| There is an office upstairs. | Наверху есть офис. | There is |
| There is a clinic inside the building. | В здании есть поликлиника. | There is |

**fix**
- ~~Here is a pharmacy.~~ *(в смысле «здесь есть»)* → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There здесь не значит «там». Это просто начало фразы «есть». Поэтому There is a pharmacy here — «здесь есть аптека», и there с here не спорят.

---

## 03 · There are — когда их несколько

**body**
Если вещей несколько, вместо is ставят are, а у слова появляется s: There are banks here. Как и в уроке 3, a с несколькими вещами не ставят.

**formula**
`There are` · `вещи + s` · `где`

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There are banks here. | Здесь есть банки. | There are |
| There are museums nearby. | Рядом есть музеи. | There are |
| There are bridges nearby. | Рядом есть мосты. | There are |
| There are quiet streets here. | Здесь есть тихие улицы. | There are |
| There are parks nearby. | Рядом есть парки. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- фраза: `There ___ museums nearby.`
- варианты: `is` · `are` · `am`
- ответ: `are`
- почему: Музеев несколько, поэтому There are.

---

## 04 · Место — в конце

**body**
По-русски место часто стоит в начале: «За зданием есть сад». В английском сначала There is и вещь, а где — в самом конце: There is a garden behind the building. Так легче: сначала вы говорите, что есть, потом уточняете где.

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There is a garden behind the building. | За зданием есть сад. | behind |
| There is a bench near the garden. | Возле сада есть скамейка. | near |
| There is a church behind the bank. | За банком есть церковь. | behind |
| There is a market near the bridge. | Возле моста есть рынок. | near |
| There is a lake behind the park. | За парком есть озеро. | behind |

**drill · word_bank**
- задание: Скажите другу: «За парком есть озеро».
- ответ: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- подписи ячеек: нет (фраза длинная, подсказки по ячейкам только мешают)
- лишние фишки: `are` · `in`

---

## 05 · Спросить «есть?» и ответить коротко

**body**
Чтобы спросить, есть ли что-то, поменяйте два первых слова местами: There is → Is there…? There are → Are there…? Коротко отвечают так: Yes, there is. No, there isn't. Yes, there are. No, there aren't.

**formula**
`Is there` · `a + вещь` · `где` · `?` — `Are there` · `вещи + s` · `где` · `?`

**examples** 🔊
| en | ru | hi |
|---|---|---|
| Is there a dentist near here? | Здесь поблизости есть стоматолог? | Is there |
| Is there a toilet here? | Здесь есть туалет? | Is there |
| Yes, there is. | Да, есть. | there is |
| No, there isn't. | Нет. | isn't |
| Are there trams near the bank? | У банка ходят трамваи? | Are there |
| Yes, there are. | Да, есть. | there are |
| No, there aren't. | Нет. | aren't |

**fix**
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

---

## 06 · Молоко, хлеб, масло — их не считают штуками

**body**
Одни вещи считают: банан, два банана. Другие — нет: молоко, хлеб, масло, сахар. Перед такими словами не ставят a, и s в конце у них не бывает. Чтобы сказать «есть немного», ставят some: There is some milk.

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There is some milk here. | Здесь есть молоко. | some |
| There is some bread near the basket. | Возле корзины есть хлеб. | some |
| There is some butter near the bowl. | Возле миски есть масло. | some |
| There is some cheese here. | Здесь есть сыр. | some |
| There are some berries here. | Здесь есть ягоды. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
С тем, что не считают штуками, всегда is, а не are: There is some milk, хотя по-русски кажется, что молока «много».

---

## 07 · some или any

**body**
some ставят, когда говорите, что что-то есть. any — когда спрашиваете, есть ли вообще, или говорите, что нет. По-русски оба часто не переводятся: «Суп есть?» — Is there any soup?

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There is some milk here. | Здесь есть молоко. | some |
| Is there any soup here? | Здесь есть суп? | any |
| Are there any mushrooms here? | Здесь есть грибы? | any |
| There isn't any juice here. | Здесь нет сока. | any |
| There aren't any carrots here. | Здесь нет моркови. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.

**drill · choice**
- фраза: `Is there ___ rice near the pot?`
- варианты: `a` · `some` · `any`
- ответ: `any`
- почему: Вы спрашиваете, есть ли рис вообще, поэтому any.

---

## 08 · «Нет»: There isn't, there aren't

**body**
Чтобы сказать, что чего-то нет, добавьте not: There is not → There isn't, There are not → There aren't. Про одну вещь — isn't a, про несколько — aren't any.

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There isn't a doorbell. | Звонка нет. | isn't |
| There isn't an intercom. | Домофона нет. | isn't |
| There aren't any handrails. | Перил нет. | aren't |
| There aren't any steps. | Ступенек нет. | aren't |
| There isn't a lawn behind the building. | За зданием нет газона. | isn't |

**fix**
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.

**drill · binary**
- вопрос: На двери нет звонка. Как сказать?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- верно: A
- разбор: Звонок один, поэтому isn't.

## 09 · in, on, under — в, на, под

**body**
in — внутри: in the sink, in the basement. on — сверху, на поверхности: on the worktop, on the windowsill. under — под: under the doormat. Русское «на» обычно on, «в» — in.

**examples** 🔊
| en | ru | hi |
|---|---|---|
| The lemon is in the sink. | Лимон в раковине. | in |
| The bicycle is in the basement. | Велосипед в подвале. | in |
| The cups are on the worktop. | Чашки на столешнице. | on |
| The plant is on the windowsill. | Цветок на подоконнике. | on |
| The key is under the doormat. | Ключ под ковриком. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

---

## 10 · next to, between … and, near, behind

**body**
next to — вплотную рядом, «у». near — неподалёку, «возле». behind — «за», сзади. between … and — «между … и …», это два слова на два ориентира.

**examples** 🔊
| en | ru | hi |
|---|---|---|
| The bench is next to the lamppost. | Скамейка у фонаря. | next to |
| The signpost is near the bridge. | Указатель возле моста. | near |
| The ladder is behind the shed. | Лестница за сараем. | behind |
| The bus stop is between the bank and the library. | Остановка между банком и библиотекой. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- фраза: `The bus stop is ___ the bank and the library.`
- варианты: `next to` · `behind` · `between`
- ответ: `between`
- почему: Два ориентира — банк и библиотека, остановка посередине: between … and.

## 11 · There is или The … is

**body**
There is — когда сообщаете, что что-то есть: собеседник ещё не знает о нём. The … is — когда вещь уже знакома, а вы говорите, где она: The lemon is in the sink. Сначала «есть», потом «где он».

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There is a car park near the hotel. | Возле отеля есть парковка. | There is |
| The barrier is near the gate. | Шлагбаум у ворот. | The |
| There is a storeroom between the kitchen and the hall. | Между кухней и прихожей есть кладовка. | There is |
| The coat rack is behind the door. | Вешалка за дверью. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- вопрос: Сестра ищет лимон, о котором вы обе знаете. Он в раковине. Что сказать?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- верно: B
- разбор: Лимон уже знаком, вы говорите, где он: The lemon is in the sink.

---

## 12 · Короткая форма: There's

**body**
В разговоре There is почти всегда сокращают до There's: There's a cashpoint near the bank. С There are так не делают, а «нет» сокращается как обычно: isn't, aren't.

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There's a cashpoint near the bank. | У банка есть банкомат. | There's |
| There's a postbox next to the gate. | У ворот есть почтовый ящик. | There's |
| There's a vending machine in the hall. | В холле есть торговый автомат. | There's |

**tip**
Короткое «да» не сокращают: Yes, there is, а не Yes, there's.

---

## 13 · Ошибки, которые делают почти все

**fix**
- ~~Here is a pharmacy.~~ *(«здесь есть»)* → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
Две проверки. Вы сообщаете, что что-то есть, или говорите, где знакомая вещь? «Есть» — There is / There are. «Где» — The … is. И второе: одна вещь, несколько или такая, что штуками не считают?

---

## 14 · Что взять с собой в практику

**body**
«Есть» — There is a… / There are… / There is some… «Есть?» — Is there…? Are there any…? «Нет» — There isn't a… / There aren't any… Место — в конце: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | ru | hi |
|---|---|---|
| There is a library nearby. | Рядом есть библиотека. | There is |
| Are there any mushrooms here? | Здесь есть грибы? | any |
| There aren't any steps. | Ступенек нет. | aren't |
| The cups are on the worktop. | Чашки на столешнице. | on |
