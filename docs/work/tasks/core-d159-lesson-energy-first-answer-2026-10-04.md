# Task packet: D159 — энергия урока/«Словаря»/«Глаголов»: окончательно после первого ответа + бесплатный повторный вход 10 мин

Governance-ID: TG-098403732E10
Status: Done — решения владельца 04.10 через координатора
Owner: Ядро

## Outcome
По logcat эмулятора (09:13–09:16): каждый вход в урок, «Словарь» или «Глаголы» брал 1 энергию при показе экрана и не возвращал её, даже если человек вышел, не ответив ни на один вопрос (5 → 1 за три минуты просмотра). Решения владельца:
1) «Словарь» и «Глаголы» тратят энергию — как есть.
2) Вошёл и вышел без единого ответа → энергия возвращается; окончательное списание — после первого ответа.
3) Повторный вход в тот же раздел того же урока в течение 10 минут после выхода — бесплатно.

## Scope
- app/energy_contract.ts — `ENERGY_FREE_REENTRY_WINDOW_MS` (10 мин, единственное место).
- app/energy_first_question_gate.ts — режим `finalizeOn: 'first_answer'` (показ не финализирует; `markFirstAnswerGiven` подтверждает старт и снимает запись журнала); бесплатный повторный вход по ключу «раздел + урок»; запись времени выхода; логи [ENERGY-GATE] refund reason=no_answer, free_reentry window_left_ms.
- hooks/useFirstQuestionEnergyGate.ts — опция `finalizeOn`, метод `markAnswered`, запись выхода при размонтировании.
- app/lesson1.tsx, app/lesson_words.tsx, app/lesson_irregular_verbs.tsx — режим first_answer и вызов `markAnswered` на первом ответе.
- docs/phraseman-2.0/03_DECISIONS.md — D159.
- tests/energy_first_answer_reentry.test.ts.

## Architecture
Остальные занятия (экзамены, диалоги, Learning V2, предлоги) — без изменений (режим по умолчанию 'shown'). Возврат — тот же путь гейта: реестр в памяти + журнал AsyncStorage, идемпотентно по operationId (ровно один раз; падение до ответа → возврат при следующем старте). Бесплатное окно открывает только сессия, за которую энергия осталась списанной (был ответ) или сама бесплатная; сессия с возвратом окно не открывает — иначе «вошёл-вышел» давал бы бесконечные бесплатные входы.

## Security and privacy
Новый локальный ключ AsyncStorage со временем выхода из раздела урока (без контента); на сервер не уходит.

## Technical debt
Окно бесплатного входа хранится локально на устройстве: при смене телефона не переносится (осознанно — 10 минут). Другие занятия (экзамены, диалоги) остаются на правиле D72 — при желании владельца распространить D159 и на них.
