## ПРОМПТ

```
Сделай 3 РАЗНЫХ варианта анимации «повышение уровня» для мобильного приложения PhraseMan,
каждый — отдельный самодостаточный HTML-файл (один файл, без сборки, без внешних
зависимостей кроме разрешённых CDN), который открывается в браузере и выглядит как экран
телефона 390×844 по центру страницы. Плюс index.html со ссылками на три варианта.
Сохрани в docs/design/level-up-animation/ (variant-a.html, variant-b.html, variant-c.html,
index.html). Код приложения НЕ трогай.

ЧТО ПРОИСХОДИТ (сценарий владельца, обязателен во всех вариантах):
Человек накопил монеты и нажал «Повысить уровень». Экран уходит в темноту (fade в почти
чёрный). В темноте есть ПОЛ — тёмная глянцевая/каменная поверхность, уходящая в
перспективу, с мягким пятном света сверху (как сцена/подиум в студии). Снизу из-за края пола
ПОДНИМАЕТСЯ текущая монета (текущий уровень), зависает над полом, отражаясь в нём.
Затем монета ПЕРЕВОРАЧИВАЕТСЯ (флип вокруг вертикальной оси, видно толщину ребра с
насечкой) — и на обороте проявляется НОВАЯ монета (новый уровень). Новая монета
«встаёт на место» с тяжёлым, дорогим ощущением, под ней появляется название нового уровня
и строка «Уровень N». Затем кнопка «Продолжить». Всё должно выглядеть НЕ дёшево —
так, чтобы захватывало дух: кинематографичный свет, отражения, глубина, тайминги.

УРОВНИ ДЛЯ ДЕМО: переход «Уровень 8 · Мастер (монета Электрум)» →
«Уровень 9 · Эрудит (монета Золото)». Добавь в углу маленький выбор пары уровней
(например 0→1 «Стажёр→Кадет», 8→9, 19→20 «Титан→Оракул»), чтобы увидеть,
как анимация смотрится с разными металлами. Кнопка «Повторить».

МОНЕТЫ (ассетов ещё нет): нарисуй монеты сам процедурно — SVG/CSS/Canvas или WebGL:
круглая монета анфас, металл градиентами (медь, электрум, золото, платина+золото для
«Эталона»), рельеф центрального знака — минималистичный пузырь речи из двух
перекрывающихся полуокружностей, поясок, гурт с насечкой на ребре. Сделай так, чтобы
картинку монеты потом можно было заменить на PNG одной переменной (coinSrc).

ЗВУК (анимация ОЗВУЧЕННАЯ, обязательно): синтезируй звук через Web Audio API прямо в
файле (без внешних аудиофайлов), чтобы работало офлайн. Звуковые события:
 1) затемнение — низкий мягкий «воздушный» свип/саб-дроп;
 2) подъём монеты — нарастающий металлический шорох/райзер;
 3) флип — короткий звон металла + «вжух» вращения (синхронно с моментом ребра);
 4) проявление новой монеты — глубокий «тяжёлый» удар + чистый колокольный тон
    (аккорд, не писк);
 5) появление названия — тихий мягкий «шиммер».
Громкость сдержанная, без казино-звуков и фанфар. Звук стартует по первому тапу (политика
автоплея браузера) — сделай стартовый экран «Нажми, чтобы повысить уровень». Переключатель
«Звук вкл/выкл».

ТРИ НАПРАВЛЕНИЯ (варианты должны реально отличаться):
 A) «Студия» — чёрный зеркальный пол, один конусный прожектор сверху, строгая Apple-подача,
    медленный флип ~1.1 с, блик пробегает по монете после проявления.
 B) «Монетный двор» — пол из тёмного камня/металла, монета поднимается из щели в полу
    (как из пресса), флип быстрее и тяжелее, вспышка тёплого света в момент чеканки,
    лёгкая пыль/искры металла (сдержанно, не салют).
 C) «Глубина» — 3D-сцена (можно three.js с cdn.jsdelivr.net), настоящая 3D-монета с
    толщиной и отражением, камера слегка облетает монету во время флипа, мягкий объёмный
    свет (god rays), лёгкий параллакс от движения мыши/гироскопа.

ТАЙМЛАЙН-ОРИЕНТИР (подгоняй под вариант, общая длина 4–6 с до кнопки):
 0.0–0.5 с затемнение → 0.5–1.4 подъём монеты с лёгким перелётом и оседанием →
 1.4–1.9 пауза-«вдох» (монета чуть покачивается) → 1.9–3.1 флип с проявлением новой →
 3.1–3.6 «посадка» новой монеты + свет → 3.6–4.4 название и «Уровень N» → 4.6 кнопка.
Easing — пружины/кастомные кривые, без линейных движений. Тап в любой момент —
досмотреть ускоренно до финала (скип).

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ:
- 60 fps: анимировать только transform/opacity (или WebGL), без layout-анимаций.
- prefers-reduced-motion: короткая версия (затемнение → смена монеты кроссфейдом → название).
- Типографика: одна семья (Inter / SF Pro-подобная из Google Fonts), название уровня
  крупно (~32–36 px, weight 700), «Уровень N» мельче и тише. Никаких эмодзи.
- Цвета: фон почти чёрный (#050507…#0B0B0F), металл — единственный яркий элемент.
- Код анимации должен быть понятен для переноса в React Native (Reanimated/Skia):
  вынеси тайминги, кривые и последовательность шагов в один объект-конфиг в начале файла
  и прокомментируй каждый шаг.
- Никаких обводок-рамок вокруг экрана/карточек, кроме тонкой рамки телефона.

Готовность: открой каждый файл в браузере, проверь, что анимация проходит до кнопки,
звук играет после первого тапа, «Повторить» и выбор пары уровней работают, нет ошибок
в консоли. Пришли владельцу ссылки/файлы и 1–2 фразы, чем отличается каждый вариант.
```

## Для реализации в приложении позже (PM-077, программа 2.0)
- Анимация разовая, празднование не durable (правило «празднование не ставится в
  durable-очередь»): показ только сразу после подтверждённого апгрейда, пропуск ничего не стоит.
- Сначала локальное списание монет и смена аватара (optimistic), сервер догоняет;
  анимация не ждёт сети.
- Звуки — в общий звуковой движок проекта, уважать настройку звука.
