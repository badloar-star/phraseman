Обозначения:
- `{n}`, `{price}`, `{days}`, `{monthly}`, `{limit}`, `{min}`, `{pace}`, `{lesson}`, `{total}`, `{done}`, `{week}`, `{topic}`, `{day}` — подстановки как в ru.
- `[форма1|форма2|форма3]` после числа — формы по числу: для uk/pl — один|несколько(2–4)|много(5+); для en/es/pt-BR — один|много.
  vi, id, tr форм не имеют. Подставляет код (как `ruPl`/`plPl`/`en` в home_scene_special_copy.ts).
- Термины как в приложении: фраза = uk «вислів», tr «ifade», pl «zwrot»; серия = Streak / Racha / Sequência / Chuỗi /
  Rangkaian / Seri / Seria; «Восстановить покупки» и «Энергия 0» — существующие строки.
- Род не угадывается: «твій вислів», «tus frases»; в pl без прошедшего времени с родом.

## ⚠ Замечания к русскому исходнику (решать Макетам/координатору, переводы сделаны по ru как есть)

1. `m.chart.note.voice` — «ограничен тремя попытками в день»: слово «попытки» владелец убрал из интерфейса как «кухню»
   (сторож `no_dev_jargon_visible_copy_2026_10_25`). Предлагаю ru: «Бесплатно — три фразы вслух в день.» — переводы этого
   варианта даны в строке `m.chart.note.voice (вариант без «попыток»)`.
2. `m.fine.trial` — «Сегодня 0 €»: валюта жёстко в строке; в рублях/гривнах/лирах будет неверно. Нужна подстановка
   `{zero}` из магазина (форматированный ноль в валюте) — в переводах так и сделано.
3. `mc.refused.nf.body.ios` — Apple в 2024 переименовала «Apple ID» в «Аккаунт Apple». Переводы по исходнику («Apple ID»);
   если решите на новое имя — заменить разом во всех языках.
