# Theory · Lesson 4 of the new course — «There is, there are, some, any, in, on, under» (EN)

> Session «12 · ТЕОРИЯ», 21.10.2026. Same sections (01–14), English phrases and drills as
> `lesson_04_ru.md`. Plain English for learners whose own language is not in the app. Traps are
> the most common ones: Here is a pharmacy instead of There is, There is banks, There are some milk,
> There isn't some juice, and in/on mix-ups. The second column explains the meaning instead of
> translating. Needs a native speaker's read-through.

**Screen title:** Theory · What is where

---

## 01 · What you will learn to say *(open at start)*

**body**
In this lesson you learn to say what is where: «there's a pharmacy nearby», «there's milk in the fridge», «there's no bell here», «the key is under the mat». The main new phrase is There is — it means «something exists here».

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There is a pharmacy here. | A pharmacy exists here. | There is |
| There is some milk here. | You can find some milk here. | some |
| Is there a toilet here? | You ask if a toilet exists here. | Is there |
| There isn't a doorbell. | The door has no bell. | isn't |
| The key is under the doormat. | The key is below the mat. | under |

---

## 02 · There is: «something exists here» *(open at start)*

**body**
To say something is somewhere, start with There is. Don't start with Here is: that is for handing something over. Then comes a and the thing, and the place goes last: There is a pharmacy here.

**formula**
`There is` · `a + thing` · `where`

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There is a pharmacy here. | A pharmacy exists here. | There is |
| There is a library nearby. | A library is close to here. | There is |
| There is a bakery here. | A bakery is here. | There is |
| There is an office upstairs. | An office is on the floor above. | There is |
| There is a clinic inside the building. | A clinic is in this building. | There is |

**fix**
- ~~Here is a pharmacy.~~ *(meaning «there is one here»)* → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There here does not mean «over there». It is just the start of the phrase «something exists». So There is a pharmacy here is fine: there and here don't fight.

---

## 03 · There are: when there are several

**body**
For more than one thing, use are instead of is and add s to the word: There are banks here. As in lesson 3, you don't put a before several things.

**formula**
`There are` · `things + s` · `where`

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There are banks here. | More than one bank is here. | There are |
| There are museums nearby. | More than one museum is close. | There are |
| There are bridges nearby. | More than one bridge is close. | There are |
| There are quiet streets here. | Some quiet streets are here. | There are |
| There are parks nearby. | More than one park is close. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- sentence: `There ___ museums nearby.`
- options: `is` · `are` · `am`
- answer: `are`
- why: There is more than one museum, so There are.

## 04 · The place goes last

**body**
First say what exists, then say where. Start with There is and the thing, and put the place at the very end: There is a garden behind the building. It's easier: first the news, then the details.

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There is a garden behind the building. | The garden is at the back of the building. | behind |
| There is a bench near the garden. | A seat is close to the garden. | near |
| There is a church behind the bank. | The church is at the back of the bank. | behind |
| There is a market near the bridge. | A market is close to the bridge. | near |
| There is a lake behind the park. | The lake is past the park. | behind |

**drill · word_bank**
- task: Tell a friend: there is a lake behind the park.
- answer: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- slot labels: none (the phrase is long, hints for each slot only get in the way)
- extra tiles: `are` · `in`

## 05 · Asking «is there…?» and answering short

**body**
To ask, swap the first two words: There is → Is there…? There are → Are there…? Short answers: Yes, there is. No, there isn't. Yes, there are. No, there aren't. Don't ask with the normal order: not There is a toilet here?

**formula**
`Is there` · `a + thing` · `where` · `?` — `Are there` · `things + s` · `where` · `?`

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| Is there a dentist near here? | You ask if a dentist is close. | Is there |
| Is there a toilet here? | You ask if a toilet is here. | Is there |
| Yes, there is. | One does exist. | there is |
| No, there isn't. | None exists. | isn't |
| Are there trams near the bank? | You ask if trams run near the bank. | Are there |
| Yes, there are. | Several exist. | there are |
| No, there aren't. | None exist. | aren't |

**fix**
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

## 06 · Milk, bread, butter: you don't count them

**body**
Some things you count: one banana, two bananas. Others you don't: milk, bread, butter, sugar. They have no a in front and no s at the end. To say «there is a bit», use some: There is some milk.

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There is some milk here. | You can find milk here. | some |
| There is some bread near the basket. | Bread is close to the basket. | some |
| There is some butter near the bowl. | Butter is close to the bowl. | some |
| There is some cheese here. | You can find cheese here. | some |
| There are some berries here. | You can find a few berries here. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
With things you don't count, always is, never are: There is some milk, even if it feels like «a lot» of milk.

## 07 · some or any

**body**
some — when you say that something is there. any — when you ask if there is any at all, or say there is none. Often both are left out in other languages: «Is there soup?» — Is there any soup?

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There is some milk here. | Milk is here. | some |
| Is there any soup here? | You ask if soup is here. | any |
| Are there any mushrooms here? | You ask if mushrooms are here. | any |
| There isn't any juice here. | No juice is here. | any |
| There aren't any carrots here. | No carrots are here. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.

**drill · choice**
- sentence: `Is there ___ rice near the pot?`
- options: `a` · `some` · `any`
- answer: `any`
- why: You ask if there is any rice at all, so any.

---

## 08 · «No»: There isn't, there aren't

**body**
To say something isn't there, add not: There is not → There isn't, There are not → There aren't. For one thing — isn't a. For several — aren't any.

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There isn't a doorbell. | The door has no bell. | isn't |
| There isn't an intercom. | No speaker at the door. | isn't |
| There aren't any handrails. | No rails to hold. | aren't |
| There aren't any steps. | No steps at all. | aren't |
| There isn't a lawn behind the building. | No grass at the back. | isn't |

**fix**
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.

**drill · binary**
- question: The door has no bell. How do you say it?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- correct: A
- explanation: There is one bell, so isn't.

## 09 · in, on, under

**body**
in — inside something: in the sink, in the basement. on — on top, touching the surface: on the worktop, on the windowsill. under — below: under the doormat. Careful: a windowsill is on, not in.

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| The lemon is in the sink. | Inside the sink. | in |
| The bicycle is in the basement. | Inside the room under the house. | in |
| The cups are on the worktop. | On top of the kitchen counter. | on |
| The plant is on the windowsill. | On the shelf under the window. | on |
| The key is under the doormat. | Below the mat. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

---

## 10 · next to, between … and, near, behind

**body**
next to — right beside. near — close, but not touching. behind — at the back. between … and — in the middle of two things: two things, two words: between the bank and the library. Use and, not a comma.

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| The bench is next to the lamppost. | Right beside the lamppost. | next to |
| The signpost is near the bridge. | Close to the bridge. | near |
| The ladder is behind the shed. | At the back of the shed. | behind |
| The bus stop is between the bank and the library. | The bank on one side, the library on the other. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- sentence: `The bus stop is ___ the bank and the library.`
- options: `next to` · `behind` · `between`
- answer: `between`
- why: There are two places, and the stop is in the middle: between … and.

## 11 · There is or The … is

**body**
There is — when you tell someone that something exists; they don't know about it yet. The … is — when you both know the thing and you say where it is: The lemon is in the sink. First «it exists», then «where it is».

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There is a car park near the hotel. | News: a car park exists. | There is |
| The barrier is near the gate. | We both know the barrier. | The |
| There is a storeroom between the kitchen and the hall. | News: a storeroom exists. | There is |
| The coat rack is behind the door. | We both know the coat rack. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- question: Your sister is looking for the lemon you both know about. It is in the sink. What do you say?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- correct: B
- explanation: The lemon is known, you say where it is: The lemon is in the sink.

---

## 12 · The short form: There's

**body**
In speech, There is almost always becomes There's: There's a cashpoint near the bank. There are is not shortened. And «not» is shortened as usual: isn't, aren't.

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There's a cashpoint near the bank. | A cash machine is near the bank. | There's |
| There's a postbox next to the gate. | A post box is by the gate. | There's |
| There's a vending machine in the hall. | A snack machine is in the hall. | There's |

**tip**
A short «yes» is not shortened: Yes, there is, not Yes, there's.

## 13 · Mistakes almost everyone makes

**fix**
- ~~Here is a pharmacy.~~ *(meaning «there is one here»)* → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
Two checks. Are you telling someone that something exists, or saying where a thing you both know is? «Exists» — There is / There are. «Where» — The … is. Second: one thing, several, or something you don't count?

## 14 · What to take into practice

**body**
«It exists» — There is a… / There are… / There is some… «Is there?» — Is there…? Are there any…? «There isn't» — There isn't a… / There aren't any… The place goes last: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | meaning | hi |
|---|---|---|
| There is a library nearby. | A library is close. | There is |
| Are there any mushrooms here? | You ask if mushrooms are here. | any |
| There aren't any steps. | No steps at all. | aren't |
| The cups are on the worktop. | On top of the kitchen counter. | on |
