# Понятный язык и подсказки в аналитике Admin v2

## Область

Изменения относятся ко всем шести модулям новой аналитики Admin v2 и их секциям в основном admin shell. Старые legacy-разделы не меняются.

## Язык

- Основной видимый текст — русский и понятный без знания Firebase, BigQuery или внутренних названий событий.
- `app instance` называется «установка приложения» с подсказкой, что это не обязательно уникальный человек.
- `P50` называется «у половины», `P90` — «у 90%»; техническое обозначение можно оставить только в подсказке.
- `coverage` называется «доля данных с новой детализацией» или конкретнее по смыслу.
- `impression` называется «показ экрана оплаты».
- `CTA` называется «нажатие главной кнопки».
- `store start` называется «открытие окна магазина».
- Нельзя писать «удалил приложение», «экран вызвал уход» или «нажал заблокированную кнопку», если источник этого не доказывает.

## Подсказки

- Каждый KPI, заголовок таблицы, статус и фильтр получает короткое объяснение.
- Подсказка доступна через hover и keyboard focus.
- Для нативных таблиц используется общий helper, который создаёт `title`, `tabindex="0"` и `aria-label`.
- Подсказка объясняет определение, знаменатель и главное ограничение показателя.

## Структура

- Общий модуль `admin/v2/analytics-language.js` хранит словарь экранов, контекстов, источников, планов, причин и helper для подписей/подсказок.
- Остальные модули используют общий helper и не дублируют определения.
- Технические значения из API никогда не вставляются как основная подпись без безопасного перевода; неизвестное значение показывается как «Не определено».

## Состояния

Loading, empty, partial и error состояния описываются по-русски и объясняют, что делать дальше. Сырые сообщения Cloud Function не становятся основным текстом.

## Контроль качества

- Языковой аудит читает фактический `admin/index.html` и `admin/v2/*.js`.
- Контракт запрещает ключевые английские заголовки в видимом интерфейсе.
- Все модули проходят `node --check`, Admin smoke и focused Jest.
