# Логика уроков и квизов — как должно работать

## Уроки (lesson1.tsx)

### Структура
- **50 фраз** на урок (`TOTAL = 50`)
- Каждая фраза — отдельная ячейка в прогресс-баре

### Как идут вопросы
- Фразы идут **строго по порядку**, бесконечно по кругу: 1 → 2 → ... → 50 → 1 → 2 → ...
- **Никакого отдельного режима повтора ошибок**
- Если ошибся на фразе — ячейка становится красной
- Исправить красную ячейку можно только когда цикл дойдёт до этой фразы снова по порядку
- Ответил правильно → ячейка становится зелёной (`replay_correct`)

### Завершение урока
Урок завершается только когда выполнены оба условия одновременно:
1. **Все 50 ячеек зелёные** (нет ни одной красной)
2. Пользователь ответил **минимум 50 раз** в текущей сессии

После завершения → экран `lesson_complete`

### Индикаторы прогресса
- **Серый** = ещё не отвечено
- **Зелёный** = правильный ответ
- **Красный** = неправильный ответ (можно исправить при следующем прохождении)
- **Светлый** = текущая фраза

---

## Квизы (quizzes.tsx)

### Структура
- **10 случайных фраз** за сессию (загружаются через `getQuizPhrases`)
- Уровни: Easy / Medium / Hard

### Как идут вопросы
- Вопросы идут **строго по порядку**: 1 → 2 → ... → 10
- **Никакого отдельного режима повтора ошибок**
- После последнего (10-го) вопроса → сразу результат (`done`)

### Завершение квиза
После 10-го вопроса → экран результата с итоговым счётом и XP

### Индикаторы прогресса
- 10 полосок в верхней части
- **Серые** = не отвечены
- **Зелёные** = правильно
- **Красные** = неправильно
- **Текущая** = светлее остальных

---

## Что НЕ должно быть

- ❌ Никакого `reviewing` режима (не добавлять)
- ❌ Никакого автоматического повтора ошибок после окончания набора вопросов
- ❌ Никакого зависания счётчика на одной цифре
- ❌ Никакого "исправь ошибки" экрана между вопросами
