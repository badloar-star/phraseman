Related epic/enabler: D191, решение координатора 14.10 (пункт 3)

## Outcome

Кнопка «Напомнить вечером» в окне понижения (m03) ставит одно локальное напоминание сегодня в 19:00 по местному времени.
Только через существующую инфраструктуру уведомлений приложения (app/notifications.ts), только если разрешение УЖЕ дано,
включён общий тумблер и категория «Шпиль». Новый запрос разрешения из окна не делаем, политику не трогаем.
Нет разрешения / категория выключена / уже позже 18:30 — кнопку не показываем. Тап по напоминанию — раздел Шпиля (как пуши
spire_week_result), при замке Шпиля — Главная.

## Scope

In scope: `app/notifications.ts` (тип spire_week_remind, категория spire, низкоуровневая постановка без запроса разрешения),
`app/notification_tap_handler.ts` (маршрут), `app/spire/spire_week_remind.ts` (доступность + постановка + тексты ru/uk),
`app/spire/use_spire_week_moment.ts` (remind в результате хука), тест `tests/spire_week_remind.test.ts`.
Out of scope: вид кнопки (Дизайн), серверные пуши.

## Architecture

Доступность считается при решении показать окно (асинхронно, без ожидания в первом кадре). Повтор нажатия — одно напоминание
(id прежнего хранится, повтор отменяет и ставит заново). Лог [D191-REMIND] на каждом решении и раннем выходе.

## Security and privacy

Новых данных и разрешений нет; категория «Шпиль» уже в настройках уведомлений. Политика не меняется.

## Technical debt

Contain: время 19:00 — константа; при необходимости вынести в конфиг.

## Verification

Тесты: 18:00 + разрешение → доступно, триггер сегодня 19:00 местного; 18:31 → нет; нет разрешения → нет (и запроса нет);
категория выкл → нет; постановка зовёт планировщик один раз, повтор заменяет прежнее.

## Rollback

Убрать кнопку из хука (remind.available=false) — окно работает как без неё.
