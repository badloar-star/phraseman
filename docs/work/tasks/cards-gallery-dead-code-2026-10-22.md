# Task packet: «Карточки» — убрать мёртвый код галереи после ухода ползунка и щипка

Governance-ID: TG-C647F0C145E1
Status: В работе
Owner: 2 · ДИЗАЙН (поручение координатора 22.10: «мёртвый код CardsGallery — статичную ветку перетекания и геометрию шагов 1–3 — убирай уже сейчас; отдельным коммитом, тесты галереи и замок макета зелёные»)

## Outcome

Галерея карточек больше не несёт того, что нужно было только ползунку и щипку: перетекание плиток, четыре раскладки (1/2/3/5 колонок), пересчёт сеток на каждый шаг, опора щипка и докрутка. Остаётся единственный нормальный вид (шаг 0): одна горизонтальная карточка на строку,
высота 118, радиус 16. Вид карточек (лицо плитки, градиент, блик, кегль, точки силы слова, перевод) не меняется — замок макета и тесты посадки текста остаются зелёными. Побочная выгода: сетки считаются один раз вместо четырёх (быстрее на длинных наборах).

## Scope

- components/cards-grid/cardsGalleryLayout.ts — таблица шагов из одной строки; удалены функции раскладки/опоры щипка и константы перетекания.
- components/cards-grid/cardsGalleryFit.ts — таблицы лица плитки из одной строки.
- components/cards-grid/cardsGalleryGrid.ts — сетки только шага 0; удалены опора щипка и докрутка.
- components/cards-grid/useGalleryGrids.ts — без изменений по смыслу (считает единственную сетку).
- components/cards-grid/CardsGallery.tsx — статичные плитки без анимации перетекания и без веток шагов 1–3.
- components/cards-grid/useFixedGalleryStep.ts — удалить (шаг и «перетекание» больше не передаются).
- app/flashcards/CollectionGalleryView.tsx, CommunityPackPreview.tsx — без step/morph.
- tests: cards_gallery_layout, saved_cards_fit, cards_gallery_mini_words, cards_fixed_step_contract (и r1_diff_one_fix_group1_contract при необходимости).

## Architecture

API с параметром step остаётся (step всегда 0): так не ломаются места, где шаг входит в ключ поправки кегля (`${id}|${step}`) и в журналы. Таблицы данных (шаги, лицо плитки, минимальная высота, пол кегля) сводятся к одной строке; всё, что работало только на смену шага, удаляется.
Сброс сохранённого шага (gallery_step_prefs, [CARDS-GRID] old=… → 0) подключается из двух экранов (CollectionGalleryView, CommunityPackPreview): сама галерея хранилище не тянет.

## Security and privacy

Не затрагивается: данных не собираем.

## Technical debt

Параметр step в API сеток остаётся как константа 0; его полное удаление затронет ключи поправок и журналы и не нужно для пользователя. Уйдёт при следующей переработке галереи.

## Verification

Типы, тесты галереи (cards_gallery_layout, saved_cards_fit, cards_gallery_mini_words, cards_fixed_step_contract, r1_diff_one_fix_group1_contract), замок макета cards_section_locked, перф/вёрстка-храповики, кадры Сверки «Сохранённые» (вид шага 0 без отличий).

## Rollback

git revert коммита: вернутся четыре раскладки и перетекание (ползунка и щипка это не вернёт — они удалены раньше).
