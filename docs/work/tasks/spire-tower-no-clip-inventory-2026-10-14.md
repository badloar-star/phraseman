## Architecture

Единая «внешняя граница» башни считается из геометрии, а не из магических чисел: верх = `min(острие, навершие, древко флага, верх ореола)`, где ореол = `cy − r` круга `spireGlow` (cy = apex − 14, r = glowR, у вершины-премиума ×2.6). Контейнер (viewBox/запас/окно) обязан содержать эту границу + запас. Если не помещается — масштаб ниже, обрезки нет. Правило сторожа: «bounds башни ⊂ viewBox/контейнер» по числам для всех 12 лиг и обоих состояний (обычное и вершина).

## Инвентарь мест, где башня может обрезаться

Числа: `top` = верх 15-го этажа = 300 (TOP_PAD); кровля: барабан 34 + конус 168 → `apex` = 98; ореол: круг с центром `apex − 14` = 84 и радиусом `glowR` (34…52 по лигам; вершина-премиум ×2.6 ⇒ до 135); древко флага: `poleTop = apex − 34` (с флажком) = 64; навершие: до ≈ `apex − 16 − 20·1.25` ≈ 57.

1. **`SpireWeekResultCard` → `SpireTowerSvg variant="weekTop"`** (ЭТО СКРИН ВЛАДЕЛЬЦА). `viewBox` верх = `geom.top − 236` = 64, то есть только 34 над острием. Навершие (≈57), древко (64) и весь ореол (верх 84 − 52 = 32, а у «вершины недели» 84 − 135 = −51) лежат выше верха viewBox ⇒ режутся краем SVG. Сверху ещё радиальная маска затемняет край. НАРУШЕНИЕ. Правка: верх viewBox = верх границы башни + запас (≈ −55 − 12), больше высота, масштаб карточки ↓ (мини-башня остаётся 103 dp по высоте, ширина уменьшается), маска не заходит на острие.
2. **`SpireTowerSvg variant="tower"`** (Пик на вкладке, Главная Пика через `SpireTower`; превью и окна). `viewBox` = `0 0 390 height`: верх контента y = 0. У вершины-премиума ореол (верх = 84 − glowR·2.6, до −51) выходит выше y = 0 ⇒ режется. НАРУШЕНИЕ (только состояние «вершина», премиум-лиги, 5+ из 12). Правка: запас сверху ≥ 135 + 14 + 12 над острием по расчёту границы (поднять TOP_PAD с 300 до расчётного значения, все координаты считаются из геометрии) либо ограничить радиус ореола доступным запасом — решение после замера.
3. **`SpireTower` окно (`overflow: hidden`, прокручиваемое)**: окно — прокручиваемая область, поэтому «режет» только то, что вне прокрутки; но `spireWindowScrollY` допускает срез навершия `SPIRE_FINIAL_SLACK = 12` ради этажа и `SPIRE_CROWN_RISE` берёт запас 36 (не ×2.6 ореола). НАРУШЕНИЕ ЗАКОНА. Правка: запас = граница башни из п. Architecture, срез 0; если этаж и навершие не влезают вместе — высота окна растёт (в пределах [260,400]) либо масштаб.
4. **`SpireTour` (`towerClip`, `overflow: hidden`, высота 340, `marginTop: −32`)**: башня сдвинута вверх на 32 dp и подрезана — ореол (верх ≈ 84 − 52 = 32 ед. = 20 dp) и навершие над краем. НАРУШЕНИЕ. Правка: убрать подрезку сверху (offset ≥ 0), масштаб ↓ под высоту 340.
5. **Главная (`home.tsx`)**: плитка Пика — картинка (`spire_tile`, арт Codex), не SVG — не относится. Превью лиг/окна лиг — тоже через `SpireWeekResultCard`/`SpireTower` (п. 1–2); отдельных мест с `SpireTowerSvg` нет (проверено поиском по `app/`, `components/`, `modules/`).
