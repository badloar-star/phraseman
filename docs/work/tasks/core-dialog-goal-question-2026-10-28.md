# Ядро · цель «Задать вопрос» в Диалогах засчитывается (координатор 28.10)

Governance-ID: TG-9762BA8BBD0D
Status: In progress
Owner: 1 · ЯДРО

## Outcome
Цель вида «Ask one simple question / Hacer una pregunta / Poser une question / Eine Frage stellen» (и другие «Ask…»-цели)
засчитывается, когда ученик задал вопрос: со знаком «?»/«¿» или без него, в начале или в середине реплики. Сейчас
прогресс целей целиком решает модель (`activeObjectiveId` на ходе, `objectiveResults` в итоге), а прошлые ответы модели в
истории урезаны до `{"replies":…}` — модель не помнит, на какой цели стояла, и вопрос ученика не засчитывает.

## Scope
In scope: новый `functions/src/dialogue_v2_goal_progress.ts` (распознавание вопроса и «вопросной» цели на en/es/fr/de),
`functions/src/dialogue_v2_turn_coaching.ts` (сдвиг указателя цели на ходе + строка промпта), `functions/src/dialogue_v2_turn_callable.ts`
(передача целей в разбор + журнал `[DIALOG-GOAL]`), `functions/src/dialogue_v2_completion_server.ts` (итог: «вопросная» цель met,
если среди реплик ученика есть вопрос), тесты.
Out of scope: `functions/src/dialogue_v2_turn_production_callable.ts` (чужая незакоммиченная правка 18.10 — диагностика отказов
модели, не трогаю), клиент (null «все цели выполнены» клиент пропускает — отдельная находка координатору), выкладка.

## Architecture
Чистые функции без сети. На ходе: модель назвала активной «вопросную» цель, а реплика — вопрос → указатель на следующую цель
(последнюю не сдвигаем: конец диалога тогда принимается как «last_objective»). В итоге: «вопросная» цель not_met → met с
доказательством — id реплики-вопроса. Новых чтений/записей нет.

## Security and privacy
Текст ученика в журнал сервера не пишется (правило модуля): только длина, есть ли «?», имя сработавшего правила, id целей.

## Technical debt
Распознавание вопроса — эвристика (слова и порядок слов); редкие ложные срабатывания («What a day») допустимы — они только
засчитывают «спросить», ничего не списывают.

## Verification
Тесты: «Can I ask you something?», «Where is the station?», вопрос без «?», вопрос в середине реплики — засчитаны на 4 языках;
утверждения — нет; сдвиг указателя и итог. functions: проверка типов и тесты затронутых файлов.

## Rollback
