## Outcome

После прохождения всех 56 занятий урока V2 у строки урока появляется «Мастерская фраз»: фразы этого урока в старом режиме (сборка из плиток, 50/50, «Устно», теория). Только Plus; монеты и серия как за практику; никакого зачёта старого курса (разблокировки, «задание дня», ачивки, первый бонус урока); энергии и сердец нет. Всё за флагом, JS-only OTA.

## Scope

In scope (этот шаг): флаг, чистая модель состояния входа (нет входа / копится / Plus-замок / открыто, порог банка ≥ 20), адаптер «банк фраз → LessonPhrase», тесты. Дальше отдельными коммитами: кнопка в строке урока, подключение источника в `lesson1.tsx` (по прецеденту комбо-урока), Plus-замок и награды.
Out of scope: серверный код, новые активности наград (используем существующую `lesson`), правки старого курса вне нужных точек.

## Architecture

Прецедент — комбо-урок: экран `lesson1.tsx` остаётся тем же, меняются источник фраз и ключи хранилища (`lessonStorageId`). Для мастерской источник — локальный банк (`app/learning_v2_lesson_phrase_bank_v1.ts`) через чистый адаптер `app/phrase_workshop_adapter_v1.ts`; ключи прогресса — отдельное пространство `workshop_<N>`; в завершении не вызываются разблокировка/«задание дня»/ачивки/бонус. Состояние входа — одна чистая функция `phraseWorkshopEntryState`, которую читают и кнопка, и гейт экрана.

## Security and privacy

Данных об ученике не собирается; банк — учебный контент, уже показанный ему. Политика приватности не меняется. Plus-проверка fail-closed (как в комбо-гейте).

## Technical debt

`lesson1.tsx` растёт на несколько хунков с флагом режима; песочница-изоляция держится сторожами-тестами. Чистка банка при удалении аккаунта — отдельный шаг с координатором.

## Verification

Тесты модели и адаптера (чистые), сторож «режим не вызывает зачёты старого курса», `npm run typecheck`, эмулятор: прохождение мастерской на накопленном банке, Free → пейвол, «копится» → тост; склейка «макет | эмулятор» по свежим снимкам Сверки.
