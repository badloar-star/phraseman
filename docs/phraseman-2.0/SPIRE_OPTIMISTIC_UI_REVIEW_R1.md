## Короткий список для Ядра / Тем

1. Если пакета недели нет локально, «Подняться» не даёт видимого отклика до ответа сети — открывать экран ступени сразу («Готовим…») и догружать пакет внутри.
2. `canAnswer()` в раннере читает `feedback` из замыкания; для полной защиты от двойного тапа после ВЕРНОГО ответа проверять ref (не state).
3. Жалоба: добавить тост «Отправим позже» при сетевой ошибке, если кнопка к этому моменту размонтирована; проверить поведение `ReportErrorButton` при `failed` после снятия задания.
4. Запись ошибки в «Мои ошибки» (`mistakeSaved=false`) — сообщить человеку тихой строкой, а не только в журнал.
