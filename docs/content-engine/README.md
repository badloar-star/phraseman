# Phraseman Content Engine

Эта папка хранит редакционную систему для Reels, carousels и длинных Instagram captions.

## Файлы

- `VOICE_SPEC.md` - авторский голос, ритм, структура, анти-ИИ правила и продуктовые мосты.
- `CONTENT_PASSES.md` - пять отдельных проходов: pattern break, hooks, multiplication, retention и authority.
- `EDITORIAL_WORKFLOW.md` - процесс от исследования конкурентов до A/B теста.
- `RESEARCH_QUEUE_2026-07.md` - актуальные исследования и готовые углы для громких материалов.
- `SAMPLE_CAPTIONS_V1.md` - первая серия переписанных статей и hooks.
- `APPLIED_EXAMPLE_RETENTION_V2.md` - первый демонстрационный материал с hooks, оценками, тремя голосовыми версиями и тремя форматами.
- `PIPELINE_RUN_CHATBOT_ROLEPLAY_2026-07.md` - полный пятиступенчатый прогон исследования о ролевых AI-диалогах: source card, семь паттернов, десять концепций, 20 hooks с оценками, три формата, retention map, Elegant, Direct и Premium версии, A/B/C тест и fact check.
- `VISUAL_SEARCH_QUERIES_V1.md` - визуальные направления и English search queries для Pexels и Pixabay по десяти готовым сценариям.
- `WRITING_PROMPT.md` - рабочий промпт для производства новых материалов, включая обязательную визуальную связь hook с первым кадром и stock search queries.

## Главный принцип

Reel создаёт личный сбой. Caption объясняет механизм. Phraseman возвращает этот сбой позже без подсказки.

Продукт не прерывает статью рекламой. Он закрывает психологический цикл, который статья уже открыла.

Hook и видео должны усиливать один конфликт. Stock-ролик не является случайным красивым фоном.

## Порядок работы

1. Проверить источник и заполнить research card.
2. Посмотреть свежий контент конкурентов и назвать заезженные паттерны.
3. Найти содержательный pattern break.
4. Прогнать hooks через оценку, включая визуальную совместимость.
5. Написать и отредактировать caption на удержание.
6. Сделать Elegant, Direct и Premium версии.
7. Перевести победившую идею в Text Reel, carousel и quiet visual post.
8. Для Text Reel определить тип визуальной связи, первый кадр, композицию, loop и 6-10 поисковых запросов для Pexels и Pixabay.
9. Проверить факт, продуктовый мост, отсутствие длинных тире и отсутствие визуального противоречия между hook и роликом.
