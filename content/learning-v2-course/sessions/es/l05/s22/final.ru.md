# Испанский · Урок 5 · Занятие 22 — У вас есть время?

**Ситуация.** Вежливо обращаетесь к одному человеку, с которым не знакомы близко.
**Что вы освоите:** соединить usted с tiene в вопросе.
**Новые слова:** —
**Повторяем знакомые слова:** usted, tener, tiempo, llave, libro.

## Интро 1

### Минута для разговора

Хотите поговорить с новым соседом и обращаетесь к нему на «вы»: `¿Usted tiene tiempo?` — «У вас есть время?» Соберите `¿Usted` + `tiene` + `tiempo?`. Usted — вежливое обращение к одному человеку. Хотя вопрос адресован собеседнику, с usted нужна форма tiene, без s. Здесь не tienes, которое сочетается с tú.

**Вежливо спросите одного человека «У вас есть время?» Начните с ¿Usted.**

- ✅ **¿Usted tiene tiempo?** — *Usted + tiene + tiempo.*
- ❌ ¿Usted tienes tiempo? — *С usted нужна форма tiene.*
- ❌ ¿Usted tengo tiempo? — *Tengo — о себе; с usted нужно tiene.*

## Интро 2

### Ключ у соседа

Стоите с соседом у общей двери и вежливо спрашиваете `¿Usted tiene una llave?` — «У вас есть ключ?» Соберите `¿Usted` + `tiene` + `una llave?`. Сохраняем начало usted tiene и добавляем нужную вещь. Llave женского рода, поэтому una llave. Вопрос адресован одному человеку.

**Вежливо спросите «У вас есть ключ?» Начните с ¿Usted tiene.**

- ✅ **¿Usted tiene una llave?** — *Вежливое обращение usted + tiene + una llave.*
- ❌ ¿Usted tiene un llave? — *Перед llave нужно una.*
- ❌ ¿Usted tener una llave? — *Нужна личная форма tiene.*

## Интро 3

### Книга для чтения

Обращаетесь к одному новому знакомому на «вы» и уточняете, есть ли у него книга: `¿Usted tiene un libro?` — «У вас есть книга?» Соберите `¿Usted` + `tiene` + `un libro?`. После usted tiene называем предмет: un libro. В этой форме обращения пол собеседника ничего не меняет.

**Вежливо спросите «У вас есть книга?» Начните с ¿Usted tiene.**

- ✅ **¿Usted tiene un libro?** — *Usted + tiene + un libro.*
- ❌ ¿Usted tienes un libro? — *После usted — tiene без s.*
- ❌ ¿Usted tiene una libro? — *Libro мужского рода: un.*
