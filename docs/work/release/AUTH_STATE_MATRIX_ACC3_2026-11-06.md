## 2. Сценарии для Эмулятора на аккаунте №3 (по порядку; каждый шаг — «ожидание» и «стоп»)

Условия: AVD с Google-аккаунтом №3, сборка ≥ `812ac51f1` (после A9, A11, A5). Между сценариями приложение не переустанавливать, если не сказано.

**S1. Гость → №3 (существующий).** Чистая установка, онбординг, на Главной нажать вход Google, выбрать №3. Ждём: прогресс №3 на экране, ни одного окна. Стоп: окно ошибки или чужие данные.

**S2. Выход.** Аккаунт → «Выйти». Ждём: «Сохраняем прогресс…», затем шторка входа; в журнале `ui_done`. Стоп: «Не удалось выйти» (тогда журнал `ui_recovery_done ok:false` — прислать координатору).

**S3. Повторный вход тем же.** Шторка входа → Google №3. Ждём: вход за секунды, прогресс тот же.

**S4. Смена A → B.** (нужен второй аккаунт, №2) Выйти из №3, войти в №2, выйти, войти в №3. Ждём: прямой переход без «Сменить аккаунт?»; прогресс каждого свой.

**S5. Удаление и возврат (A9→A10).** Настройки → «Удалить аккаунт» → подтвердить. Ждём: новый гость, без окон. Подождать 1–3 мин. Вход Google №3 → «Восстановить аккаунт?» → «Восстановить». Ждём: прогресс вернулся (серия, монеты, уроки). Стоп: прогресс не вернулся.

**S6. Вход в окончательно удалённый (A11)** — только когда Ядро подтвердит окончание удаления №3 (Q26). Вход Google №3. Ждём: чистый новичок, без окна «Аккаунт удалён». Журнал `[AUTH-RETIRED]`/`created_new`.

**S7. Нет сети.** Авиарежим → вход Google. Ждём: ровно «Связь пропала. Попробуй ещё раз.» Включить сеть — повторить вход, всё работает.

№3 — тестовый аккаунт по решению координатора; S5 возвращает его прогресс (A10), S6 — единственный сценарий, после которого прогресс №3 не вернуть, поэтому запускать его только по слову Ядра.
