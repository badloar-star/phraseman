# Логи «сперва логи» для четырёх жалоб и проверка Optimistic UI / скорости по зонам Дизайна (26.10)

Governance-ID: TG-0F39153C5826
Governance-ID: TG-3168913C4656

## Outcome
Утром владелец один раз воспроизводит жалобы (окно эпизода на iOS, подпись под капсулой таб-бара, дёрганый скролл, напоминание «Видео») и получает факты в журнале. Параллельно проверены Карточки, Настройки и пейвол: что ждёт сеть без нужды, где спиннер на весь экран, двойной тап, лишние перерисовки, списки без виртуализации.

## Scope
`app/home_scroll_probe.ts` (промежутки между кадрами JS в окне прокрутки), проверка полноты журналов `[EPISODE-MODAL]`, `[SEASON-LAYOUT]`, `[VIDEO-REMINDER]`; чтение кода Карточек/Настроек/пейвола; дешёвые безопасные правки отдельными коммитами с тестом; остальное в `docs/work/design-optimistic-perf-2026-10-25.md`.

## Architecture
Только JS, без новых зависимостей. Журнал скролла печатает числа раз в секунду, пока открыто окно прокрутки (вне прокрутки нулевая стоимость). Имена префиксов сохраняются прежние, чтобы владелец не искал новые.

## Security and privacy
Только числа и размеры; текстов пользователя и фраз в журнал не пишем.

## Technical debt
Нет новых. Префикс `[HOME-SCROLL]` остаётся, а не переименовывается в `[SCROLL-JANK]`.

## Verification
Точечные тесты одного файла под слотом светофора; проверка типов; чтение кода по каждой зоне.

## Rollback
Откат коммита с журналом; остальные правки откатываются по хэшам.
