## Откуда рост и почему это важно

1. **Контент курса Codex влит в JS — подтверждено.** `factory_native_manifest_v1.generated.ts` — сгенерированные данные всех занятий
   (10,3 МБ, каждая строка — строка в байткоде). Растёт с каждым выпуском уроков Codex: +3,8 МБ за 22–24.10.
2. **Ленивая загрузка в сторе выключена.** `metro.config.js:56` — `inlineRequires` включается только при `PHRASEMAN_INLINE_REQUIRES=1`;
   иначе все статические `import` исполняются при загрузке модуля. Манифест импортируется статически из `factory_native_course_v1.ts`,
   а тот — статически из `learning_session_rune_reward_composite_v1.ts`, `lesson1_release_parity_v1.ts` и
   `learning_v2_course_released_session_client_v3.ts`. Если хоть одна из этих цепочек доходит до корня приложения, 10 МБ данных
   разбираются на холодном старте (не проверено запуском — нужен замер `[BOOT]` на устройстве).
3. **Hermes отображает байткод в память**, поэтому размер файла сам по себе старт не тормозит; тормозит исполнение модулей
   и объектов данных при импорте, и память (OOM эмулятора — dev-бандл без Hermes держит 236 МБ текста).
