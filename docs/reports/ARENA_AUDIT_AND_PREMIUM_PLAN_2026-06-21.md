### Внутри матча

### Результаты
- Победа/поражение/ничья, счёт, разбор ответов, реванш (PvP), полёт наград (XP/осколки/звёзды).
- **Конфетти/Lottie НЕТ.** Есть только `RankChangeModal`. Наград мало: +1 осколок за победу, XP, иногда дроп карточки.

### Монетизация (перепроверено лично)

- Сам геймплей, темы, реванш, статистика, рейтинг — **премиумом НЕ гейтятся**.
- **Вывод: монетизация 5–6/10. Деньги лежат на столе — премиум не даёт ничего, кроме снятия лимита.**

## 2. Корневой диагноз

Арена технически сильная, визуально красивая, но **эмоционально плоская и не даёт повода платить**:
1. **Матч без драмы** — не чувствуешь живого соперника, нет пиков напряжения, нет момента победы.
2. **Прогрессия без вкуса** — 24 ранга = долгий грайнд; осколки некуда тратить «по-понтовому»; сезоны/SR живы только для топ-1% (Legend III).
3. **Соперник анонимен** — сыграл и забыл, нет вирального следа.
4. **Премиум = просто снятие лимита** — нет ни статуса, ни эксклюзива, ни драйва.

## 3. План «разъёба» (выбранные векторы: драма + прогрессия + социалка)

### Вектор A — ДРАМА МАТЧА (вау-момент)
Цель: матч ощущается как живой бой. Файлы: `arena_game.tsx`, `arena_results.tsx`, `ArenaDuelFlyingEmoji.tsx`.

A1. **Индикатор «соперник ответил»** — пульс/галочка на аватаре соперника в табло, когда он сдал ответ (даже для бота — имитировать реалистичную задержку 2–8 сек вместо 4–30). Это №1 по влиянию на «живость».
A2. **Reveal-эффект** — задержка 300–500 мс перед раскрытием + scale/shimmer правильного варианта, вспышка-частицы на верный, лёгкая тряска на неверный.
A3. **Реакция счёта** — когда счёт соперника растёт, число пульсирует/краснеет; когда мой — золотая вспышка. Reanimated scale-pulse.
A4. **Last-question drama** — на 10-м вопросе при разнице ≤2 очка: затемнение фона, надпись «Решающий вопрос», ускоренный пульс таймера, особый звук.
A5. **Финальный экран матча** — перед прыжком в результаты: 0.8–1.2 сек большого счёта «X : Y» с исходом (победа = золото+конфетти, поражение = серый), затем переход.
A6. **Звук поражения** + отдельный «wrong» звук (сейчас на неправильный — тишина).
A7. **Countdown-анимация** — 3-2-1 с bounce/swoosh, а не статичный текст.
A8. **Конфетти/Lottie на победе** в результатах + анимированный счётчик наград.

→ Премиум-крючок: **премиум-победная анимация/аура** (эксклюзивное конфетти, особый финальный экран, кинематографичный rank-up). Статус виден сопернику.

### Вектор B — ПРОГРЕССИЯ И КОЛЛЕКЦИЯ
Цель: долгосрочная цель = причина платить. Файлы: `arena_season_math.ts`, `arena_results.tsx`, `arena_lobby.tsx`, новый battle-pass модуль.

B1. **Сезонный рейтинг (SR) для ВСЕХ, а не только Legend III** — +N SR за каждую победу, видимый сезонный прогресс-бар на лобби. Сейчас SR мёртв для 99%.
B2. **Боевой пропуск арены (Arena Battle Pass)** — сезонный, 2 трека: бесплатный + **премиум**. Уровни за победы/задания. Награды: арена-скины, ауры, рамки, звания, осколки. Это ГЛАВНЫЙ премиум-драйвер.
B3. **Видимый прогресс ранга на лобби** — бар «до повышения N звёзд», анимация звезды при входе, а не только на результатах.
B4. **Осколки → «понты»** — арена-скины фона матча, ауры аватара в бою, звания у имени («Король недели», «Гроза ботов»). Сейчас осколки тратить по-крутому негде.
B5. **Трон дня → Трон недели/сезона + награда** — персистентность, +10 осколков королю дня, бейдж «Король сезона» (виден везде).
B6. **Гарантированный дроп карточки за серию побед** (например 3 подряд) — связать арену с коллекцией collectibles.

→ Премиум-крючок: **премиум-трек батл-пасса** (эксклюзивные скины/ауры/звания), ускоренный прогресс, +2x→4x по ставкам.

### Вектор C — СОЦИАЛКА И ВИРАЛЬНОСТЬ
Цель: арена приводит новых и удерживает. Файлы: `arena_results.tsx`, `arena_lobby.tsx`, `arena_duel_share.ts`, `arena_pulse.ts`.

C1. **Профиль соперника после матча + «Добавить в друзья» / «Реванш»** — самый высокий ROI по виралу. Сейчас соперник анонимен.
C2. **Видимый рейтинг/ранг соперника** в матче и результатах («я побил Diamond!»).
C3. **Live-лента «кто играет сейчас»** на лобби (использовать `arena_pulse`) — ощущение онлайн-движухи, кликабельно → вызов.
C4. **Шеринг результата в соцсети** — красивая карточка «Я выиграл 15:2» + реф-код. Сейчас шеринг только при создании комнаты.
C5. **Вызовы друзей / еженедельный дружеский турнир** за звёзды/осколки.
C6. **Премиум-рамка/аура в лидерборде и профиле соперника** — статус, который видят другие = социальное давление купить премиум.

→ Премиум-крючок: **видимый премиум-статус** (рамка, аура, звание) — единственное, что реально продаёт в соц-играх. Люди платят за то, что видят другие.

## 4. Откуда берётся премиум (следствие, не самоцель)

| Вектор | Что бесплатно | Что за премиум (повод платить) |
|---|---|---|
| Драма | базовые анимации боя | эксклюзивная победная анимация/аура/финальный экран |
| Прогрессия | бесплатный трек батл-пасса, базовый SR | премиум-трек (скины/ауры/звания), ускорение, 4x ставки |
| Социалка | профиль соперника, добавить в друзья | премиум-рамка/аура/звание видны ВСЕМ в лидерборде и бою |
| Лимиты | 5 матчей/день | ∞ (как сейчас) |

Ключ: премиум перестаёт быть «снятием стены» и становится **статусом + эксклюзивом + драйвом**, которые видят другие игроки.
