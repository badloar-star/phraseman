## Scope

По шагам, каждый — отдельный коммит после замера «до/после»:

1. Финальная копия: сборка страницы сейчас на КАЖДУЮ пару заново сериализует и хеширует всю страницу (чистый JS SHA-256)
   и считает её UTF-8 через массив чисел — O(пар × размер страницы). Заменить на точный инкрементальный подсчёт размера
   (база страницы + длина каждой пары): страницы и отпечатки байт в байт те же, хеш — один раз на страницу (как и сейчас
   в writePage). Файл: app/cloud_sync.ts saveAccountSwitchEmergencyBackup. Доказательство — стенд
   (scratchpad backup_bench.ts): старый и новый алгоритм дают одинаковые страницы, время до/после.
2. Пропуск записи документа, если все отправляемые поля совпадают со снимком последней синхронизации ЭТОГО же
   владельца — только по слову координатора (граница данных).
3. Дальше по фактам: стирание (1,3 с), новый анонимный вход параллельно с не зависящими шагами — только после разбора
   порядка маркеров (охраняет восстановление после обрыва).
