# Модалка энергии: текст обязан соответствовать разделу

Governance-ID: TG-BE5789A43993

## Outcome

Окно «Недостаточно энергии» называет то занятие, из которого человек в него
попал. Владелец дословно: «когда в диалоге закончилась энергия, модал говорит
недостаточно энергии и экзамен требует 20! какого хуй экзамен!!!??! исправь все
тексты на модалах чтобы они все соответствовали разделу».

Корень (найден в коде, не предположение): `components/NoEnergyModal.tsx` выбирал
строку **случайно** из двух вариантов на язык, и первый вариант жёстко говорил
про экзамен. Плюс запасная строка бралась всегда нулевой, то есть тоже
экзаменной. Активность (`activity`) в окно уже приходила и использовалась для
ЦЕНЫ, но не для ТЕКСТА.

После правки: в диалоге — про диалог, в карточках — про карточки, в арене — про
матч, на экзамене — про экзамен. Случайного выбора текста нет.

## Scope

- `components/NoEnergyModal.tsx` — текст строится по `activity`, рулетка удалена.
- Тест-сторож на соответствие текста разделу.

НЕ в scope: цена энергии (она уже берётся из общего контракта и верна), верстка
окна, пейвол Plus, другие модалки.

## Architecture

Название занятия выводится из `EnergyActivityKey`, который экран уже передаёт —
новых пропов не заводим и новых источников правды не создаём. Ключей немного,
и они перечислимы, поэтому соответствие «ключ → название занятия» описывается
как полная карта: добавили активность — TypeScript заставит дописать название.

Вариант «оставить один нейтральный текст на всё» отвергнут: владелец просил
соответствие разделу, а не обезличивание.

## Security and privacy

Текстовая правка. Новых данных не собираем, разрешений не добавляем, наружу
ничего не уходит. Privacy policy правок не требует.

## Technical debt

- Pay now: случайный выбор текста убран полностью — он и был дефектом.
- Contain: карта названий закрыта типом, «забыть» новую активность нельзя.
- Accept temporarily: ничего.

## Verification

- Точечный `tsc` по затронутым файлам под слотом светофора.
- Новый тест: для каждой активности строка содержит своё название занятия и НЕ
  содержит чужого (в частности, диалог не упоминает экзамен).
- Проверка владельцем на устройстве: исчерпать энергию в диалоге.

## Rollback

Одна правка, один коммит; revert возвращает прежний текст. Данных не трогаем,
контракт пропов не меняем.
