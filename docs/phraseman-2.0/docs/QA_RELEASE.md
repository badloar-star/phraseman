# Приёмка, тексты, право и выпуск

## Тестовая матрица
Новый/существующий пользователь, анонимный/связанный аккаунт; Free/активный Plus/истёкший/restore/refund; до/после миграции; один/два устройства; offline/reconnect/timeout; weak Android/iOS; разные локали, длинные тексты, большой шрифт, screen reader, reduce motion. Главные сценарии: открыть набор из ролика, перевернуть/озвучить, выбрать наборы, начать занятие, сохранить результат, вернуться, добавить видео в избранное, повысить ранг, открыть диалог, проверить права курса.

Negative тесты: duplicate command, поздний ответ другого аккаунта, старый deeplink, старый notification, старый appearance ID, неизвестная locale, нет голоса TTS, failed purchase callback, очистка кеша офлайн, повтор миграции. Release graph не содержит retired scopes; deployed jobs сверены отдельно. Собственный набор и обучение не исчезают при очистке/выходе/апдейте.

## Судьи
UX/редактор проверяет новый экран, краткость без потери смысла, отсутствие AI-канцелярита/фанфар и соответствие утверждённому дизайну. Технический reviewer проверяет корректность, shared dependencies, data rights, очередь, расходы и end-to-end diagnostics. Доказательство — screenshot/trace/test command/file:line, не «мне кажется нормально».

## Paywall
Сравнение только на сопоставимых exposure/cohorts: platform, locale, source, pricing, eligibility trial, даты, cohort maturity. Смотреть не только клики/trials, но и paid starts/restore/errors/refunds там, где данные доступны. Маленькая выборка — неопределённость, не «победитель». Упростить экран до ценности и существенных условий. Цена, период, переход trial к списанию, восстановление/управление и ссылки на terms/privacy не удаляются ради минимализма. Проверить текущие требования платформы [W8–W9].

## Политики и тексты
Privacy/Terms обновляются по реально реализованным потокам и SDK. Нужны контролёр/контакты, типы данных, цели/основания, получатели/передачи, сроки, права и удаления, дети/возраст, AI/voice по факту. Полный юридический документ до фактического аудита будет выдуманным, поэтому в данном пакете — техническое задание и checklist, не «готовая действующая Privacy». Финальную правовую проверку выделить отдельно [W10].

Минимальный текст не означает скрыть существенные условия или ошибку. Не нужно доказывать пользователю происхождение кода: нужны нормальные осмысленные короткие строки. Юмор только осознанный; не добавлять служебные абзацы «для дружелюбия». Опросы переписать отдельно. Сохранить запрошенные короткие описания карточек.

## Релиз
Сначала подготовка и одна вертикальная цепочка, затем все экраны/домены, upgrade rehearsal и ограниченный beta rollout. Поэтапное распространение после comparable baseline: crashes, старт/отклик, lost progress, purchases, Firestore cost. Порог стопа согласован заранее. Не выпускать монетную миграцию только потому, что получился красивый ассет. Не ждать будущую V2 для выпускного упрощения.

Приветствие «PhraseMan 2.0» — спокойное короткое объяснение изменений, не возвращение блокирующих фанфар. Старые покупатели понимают, что сохранено/компенсировано. Подтверждение улучшения конверсии возможно только после данных, не при выдаче документации.
