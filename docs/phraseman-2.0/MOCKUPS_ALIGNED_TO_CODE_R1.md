# Образцы, приведённые к коду (R1, ночь 11→12.10)

Зачем документ: за ночь сверка паритета (Макеты по поручению координатора) приводила **образцы** к коду там, где код — эталон для текстов, состава и состояний. Чтобы паритет не «совпал» молча за счёт сдвинутого образца, здесь по одной строке на каждое изменение: **что было в образце → что стало (как в коде) → почему**. Строки реестра правились только по id, число строк не уменьшалось.

Правило, по которому правили: образец менялся к коду только для текстов, состава экрана и состояний; цвет и «тон» задаёт тема, различия данных тестового аккаунта образцом не «лечатся». Страницы под замком владельца (`cards-section.html`, `cards-gallery.html`, `mistakes-panel.html`, `packs-simple.html`) **не менялись** ни в одной строке.

Хэши — коммиты в репозитории (для старых коммитов 11.10 колонка «было» собрана по сообщению коммита — точный diff: `git show <хэш> -- docs/design/v2-app/<страница>`). «Решение координатора» = поручение координатора ночью (владелец спит); «по коду» = источник — текущий код приложения.
