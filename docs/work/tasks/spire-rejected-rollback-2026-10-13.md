# Task packet: Шпиль — откат локального маркера при отказе сервера по ступени (rejected)

## Outcome

Когда сервер отверг пройденную ступень (`verdict: rejected`, причины: malformed, stale_week, clock_ahead, pack_unknown, pack_mismatch, tier_mismatch), локальный маркер этажа возвращается на честное значение, человек видит понятную строку, а в журнале есть вся цепочка `[SPIRE-REJECT]`: id ступени, причина, маркер до и после, источник. Поздний или повторный отказ не откатывает лишнего.

## Scope

In scope: `modules/spire/report_queue.ts` (чистый откат маркера, `rolledBack` в результате досылки), `modules/spire/report_store.ts` (журнал `[SPIRE-REJECT]`, `rolledBack` в исходе), `app/spire/use_spire_game.ts` (применение отката к экрану, строка-уведомление), `components/spire/SpireHomeScreen.tsx` (плашка), существующий тест `tests/spire_report_queue.test.ts` (старое поведение «маркер не трогаем» заменяется), новый тест отката.

Out of scope: текст сообщения на 9 языков от Ядра (пока используется существующая строка «Ступень не сохранилась. Попробуй ещё раз»), пауза таймера на форме жалобы (решено: не делать), серверная часть.

## Architecture

Откат — чистая функция над `SpireWeekLocal`: из пройденных отвергнутых строк, которые ещё лежали в очереди (`pending`) и относятся к той же неделе, считается новое число ступеней; этаж и ступень внутри этажа пересчитываются по лестнице 5,6,7,8,9,10; не опускаемся ниже подтверждённого сервером числа. Повторная досылка уже снятых строк ничего не откатывает (идемпотентно: откат только для строк, которые были в очереди в момент ответа). Экран применяет ту же функцию к своей текущей неделе (не заменяет её снимком с диска), поэтому ступень, пройденная за время запроса, не теряется.
