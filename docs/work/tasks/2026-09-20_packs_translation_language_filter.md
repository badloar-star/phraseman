# Task packet: фильтр наборов карточек по языку перевода

Governance-ID: TG-290ACF3B48E0
Status: Planned (enabler, не начат)
Owner: не назначен
Related epic/enabler: репорт #18 (Ева, 2026-09-17)

## Outcome

Человек с русским интерфейсом видит на витрине наборов только те, перевод
в которых он понимает, и больше не проваливает карточки из-за украинского
перевода. Решение владельца 2026-09-20: «сделай фильтр наборов по языку».

Успех: на витрине и в «Добавить набор» есть переключатель языка перевода,
по умолчанию — язык интерфейса; наборы с непонятным переводом не попадают
в тренировку молча.

## Scope

В scope: `app/flashcards/pack_languages.ts`, `app/flashcards/marketplace.ts`,
`app/flashcards_packs.tsx`, `app/flashcards/deck_options.ts`, запись языка
перевода при публикации набора в `community_packs`.

Вне scope: автоперевод чужих наборов, правка чужого контента, смена языка
уже добавленных наборов.

## Architecture

ВАЖНО, почему это не правка на ходу: существующий `PackLanguage`
('en' | 'fr' | 'de' | 'es') описывает ИЗУЧАЕМЫЙ язык набора. Языка ПЕРЕВОДА
(на каком языке написана обратная сторона карточки) в модели нет вообще.

Значит нужно: новое поле у набора, его заполнение при публикации, обратная
совместимость для уже опубликованных наборов (определять по `sourceLocales`
или помечать «язык не указан»), и только потом фильтр в UI.

Инвариант: уже добавленные человеком наборы не должны исчезнуть из его
тренировки после ввода фильтра.

## Security and privacy

Новое поле — язык контента набора, не персональные данные. Политика
приватности правки не требует. Чужой контент не редактируется.

## Technical debt

- Accept temporarily: до появления поля наборы сообщества остаются
  смешанными по языку перевода. Владелец, review при взятии задачи,
  потолок воздействия — неудобство выбора, потери данных нет.

## Verification

- Набор без указанного языка перевода не пропадает с витрины.
- Переключатель языка меняет список, уже добавленные наборы остаются.
- `npx jest tests/flashcards_*.test.ts --runInBand --watchman=false`.

## Rollback

Фильтр выключается одним флагом: витрина возвращается к показу всех наборов.
Новое поле остаётся в данных и ничего не ломает.
