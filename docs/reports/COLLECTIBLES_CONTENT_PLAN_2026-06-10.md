## 2. Структура карточки (схема данных)

```
id, en, ipa, ru (литературный эквивалент), literalRu (дословно),
meaningRu (значение «как для детей»), exampleEn + exampleRu (живой пример),
originRu (история с фактом), rarity, art, status: seed→texts_done→art_done→ready
```
Формат совместим по духу с «Фразой дня» (`DailyPhrase`: english/literal/meaning/text) — деталка карточки = расширенная фраза дня.

## 3. Про изображения — честно

Растровые картинки уровня DALL·E я генерировать не могу. Стратегия трёх уровней:

1. **Сейчас (уже есть):** уникальные SVG-плейсхолдеры на каждую карточку — паттерн из 6 семейств + монограмма + кольцо, детерминированно от id, цвета редкости. Сет можно выпускать сразу.
2. **Целевой арт (основной путь):** уникальные SVG-сцены, иллюстрирующие буквальный смысл фразы (как 10 «Животных»), — рисуются LLM-батчами по 10 через `prompts <setId>` по стайлгайду, ревью человеком. SVG легче PNG, масштабируются, тонируются под редкость.
3. **Опционально позже:** DALL·E-пайплайн (в проекте уже описан для аватаров/сундуков: `docs/LEVEL_GIFT_*`, `PREMIUM_CUSTOM_AVATAR_*`) — для «премиального» обновления артов отдельных сетов. Замена арта не требует изменения данных.

## 4. Конвейер производства одного сета (~1–1.5 часа)

```
prompts <setId> ──► ПРОМПТ 1 (тексты) ──► JSON 11 объектов ──► вставка в catalog_seed.json
      │                                                            │
      └──► ПРОМПТ 2 (10 SVG-сцен) ──► ассеты + art:…               ▼
                                                          node generate.mjs validate
                                                                   ▼
                                              ревью человеком (STYLE_GUIDE чек-лист, факты в originRu!)
                                                                   ▼
                                                          node generate.mjs build
```

Дальше отдельными проходами по готовым сетам: **локализация** (uk/es/pt-BR/vi/id/tr/pl — heisenberg-пайплайн, переводятся только ru-поля) и **аудио** (OpenAI TTS: en + exampleEn, существующий пайплайн).

## 6. Контроль качества

- **Механика:** `validate` ловит дубли фраз (по всему каталогу, включая секретки), битые редкости (строго 5/3/2 или 5/3/1/1 на сет), пропуски полей по статусу, превышение лимитов длины.
- **Человек:** чек-лист STYLE_GUIDE — главное `originRu` (факты не выдуманы), `ru` (русский эквивалент-поговорка где есть), пример звучит живо.
- **Интеграционный замок (при имплементации фичи):** unit-тест на каталог — counts 300/30, уникальность id/en, наличие текстов у выпускаемых сетов (по образцу контент-контрактных тестов планов).
