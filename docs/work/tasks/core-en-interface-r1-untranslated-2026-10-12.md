## Architecture
Переводы — тем же `triLang(lang, {…})`, что используют соседние строки; источник языка — тот, что уже есть в компоненте
(`useLang`/параметр). Формат времени — функция с подписями единиц по языку (ч/м/с → h/m/s и т.д.), без новых зависимостей.
Поиск находок с номерами строк — копия логики сканера в scratchpad (только чтение).
