# Task packet: живая страница очереди светофора для владельца

Governance-ID: TG-707A56F4C8BC

Дата: 2026-11-11. Исполнитель: сессия-координатор.

## Outcome

Владелец 11.11: «что там по очереди, сделай макет, покажи, какая очередь, кто идёт, и
проверяй, обновляй мне макет регулярно, чтобы я видел». Результат — локальная страница,
которая сама раз в 5 секунд показывает: кто держит слот светофора и что делает, кто ждёт
и сколько, кто недавно прошёл, сколько свободной памяти и процессов на ПК. Обновляется без
участия сессий и без расхода токенов.

## Scope

- Новый файл `docs/work/mockups/queue-board-2026-11-11/serve.cjs` — маленький локальный
  сервер без зависимостей, отдаёт страницу и данные.
- Одна новая запись `queue-board` в `.claude/launch.json` (порт 4790), по образцу соседних.
- Этот пакет задачи.
- НЕ трогаются: `.claude/semaphore/slot.sh`, хук светофора, файлы слотов и очереди (страница
  их только читает), код приложения, сервер, тесты.

## Architecture

- Источник правды — папка `.claude/semaphore`: `slot.<id>.d` (кто держит слот: файлы `born`,
  `why`), `run.<id>.d` (кто ждёт: файл `born`), `slot_events.log` (кто недавно получил и отдал
  слот). Только чтение.
- Названия сессий и описание того, что ждущая сессия поставила на проверку, берутся из
  журналов сессий в домашней папке (`~/.claude/projects/**/<id>.jsonl`): читается только
  хвост файла, результат кэшируется по id и времени постановки — чтобы опрос раз в 5 секунд
  не грузил диск.
- Записи очереди старше 3 часов помечаются как «мёртвые» (процесса давно нет): страница их
  показывает отдельно и ничего с ними не делает.
- Число процессов node/claude считается через `tasklist` не чаще раза в 30 секунд.
- Сервер слушает только `127.0.0.1`, ничего не пишет на диск и ничего не запускает из
  тяжёлого; сам занимает порядка 30–40 МБ памяти. Тяжёлой командой по правилам светофора
  не является (не jest, не tsc, не сборка).
- Порядок выдачи слота в `slot.sh` не строго по очереди, поэтому страница сортирует ждущих по
  времени ожидания и прямо пишет, что это не гарантированный порядок.

## Security and privacy

- Сервер доступен только с этого компьютера (`127.0.0.1`).
- На страницу попадают названия сессий и короткие описания команд из локальных журналов;
  содержимое переписки, ключи и данные пользователей не читаются и не показываются.
- Наружу ничего не отправляется.

## Technical debt

- Страница — служебный инструмент владельца, не часть приложения; тестов у неё нет.
- Описание ждущей задачи восстанавливается из журнала сессии, потому что сам светофор его не
  хранит. Правильное лечение — научить `slot.sh` писать `why` и для ждущих; это правка сторожа
  и отдельное решение владельца.

## Verification

- Страница открывается в панели браузера, показывает держателя слота и ждущих, совпадающих с
  `bash .claude/semaphore/slot.sh status`.
- Отметка «обновлено» на странице меняется сама без перезагрузки.
- В консоли браузера нет ошибок.

## Rollback

Остановить сервер, удалить папку `docs/work/mockups/queue-board-2026-11-11/` и запись
`queue-board` из `.claude/launch.json`. На светофор и приложение не влияет.
