# Урок 28 · Занятие 25 — Вещи могут пригодиться снова

**Ситуация.** Вы разбираете ненужные вещи и уточняете в пункте приёма, что с ними можно сделать.

**Что вы освоите:** действие над предметом после can, must, should: модальный глагол + be + третья форма.
**Новые слова:** aluminium, ceramic, porcelain, landfill

## Интро 1

### Можно использовать снова

Вы принесли чистую стеклянную банку и спрашиваете, пригодится ли она ещё. Сотрудник отвечает: This jar can be reused — эту банку можно использовать снова. Соберите This jar + can + be + reused. Can означает возможность. Be reused показывает действие над банкой. После can нужна начальная форма be, а после неё reused — форма reuse с окончанием -d.

**Выберите фразу для этой ситуации.**

- ✅ **This jar can be reused.**
- ❌ This jar can reused. — *Между can и reused нужно be.*
- ❌ This jar can be reuse. — *Здесь нужна reused.*

## Интро 2

### Правило этого пункта

В этом пункте приёма посетителей просят сортировать вещи до сдачи. Сотрудник объясняет обязательное правило: Items must be sorted first — вещи необходимо сначала рассортировать. Соберите Items + must + be + sorted + first. Must выражает требование, а be sorted — действие над вещами. После must используем be даже для нескольких предметов.

**Выберите фразу для этой ситуации.**

- ✅ **Items must be sorted first.**
- ❌ Items must are sorted first. — *После must нужна be, не are.*
- ❌ Items must be sort first. — *Здесь нужна sorted.*

---

## Интро 3

### Совет перед дарением

Вы хотите отдать кому-нибудь запылившуюся чашку. Друг советует сначала её вымыть: The cup should be washed first — чашку стоит сначала вымыть. Соберите The cup + should + be + washed + first. Should выражает совет, а be washed — действие над чашкой. После should нужна be, затем washed. First показывает порядок действий.

**Выберите фразу для этой ситуации.**

- ✅ **The cup should be washed first.**
- ❌ The cup should washed first. — *После should нужно be.*
- ❌ The cup should be wash first. — *Здесь нужна washed.*
