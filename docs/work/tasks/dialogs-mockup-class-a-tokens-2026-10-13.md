## Outcome
Макет `docs/design/v2-app/dialogs.html` рисует кнопки «Включить / Остаться / Получить Plus / К урокам / Закрыть / Открыть Plus» мятой (`--acc`/`--on` Авроры ＠1) и фон телефонов со свечением темы, как приложение на `theme=grad_aurora&level=1` и как остальные страницы класса A. Разметка и тексты не меняются.

## Scope
Только CSS в `dialogs.html` (переопределение цвета основной кнопки и фона `.ph` через `--g1/--g2/--acc/--on`); рендер «до/после» для проверки; пометка «пересклейка» у затронутых строк `dialogs-*` в реестре visual_parity.json (только свои строки) либо список Макетам.

## Architecture
На странице уже задаются `--acc/--on` и (из чипов тем) `--g1/--g2` у `.ph`. Добавляется правило для основной кнопки `.cta:not(.dis):not(.gh)` (мята) и фон `.ph` как радиальные свечения `--g1/--g2` поверх базового фона; значения берутся из замеров кадров приложения на Авроре ＠1, а не придумываются.
