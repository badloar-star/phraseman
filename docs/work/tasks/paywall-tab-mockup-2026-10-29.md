## Outcome
Интерактивный макет (новый артефакт) на настоящих кадрах: (1) нижняя панель с новым табом сразу после «Сообщества» — только значок
(бриллиант Plus из бейджа аватарки), без подписи; (2) по тапу — полноэкранная страница-пейвол с панелью внизу (таб подсвечен):
заголовок, преимущества, тарифы, кнопка покупки, «закрыть» и «восстановить покупки»; (3) переключатели: тема (графит + 2),
тёмное/светлое, «Для Free» (таб есть) / «Для Plus» (таба нет).
## Scope
docs/design/v2-app/paywall-tab.{app.js,css,make.cjs,html}; кадры — assets/real (Главная по темам) и кадр окна подписки, если есть.

## Architecture
Движок реальных кадров (real-frame.js): телефон = кадр, панель внизу — HTML-слой поверх полосы таббара кадра (6 табов для Free, 5 для
Plus), страница-пейвол — HTML-слой на фоне темы по токенам, содержимое — из кадра/описи пейвола приложения.
