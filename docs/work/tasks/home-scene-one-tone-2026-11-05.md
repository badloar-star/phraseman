## Scope

In scope: `components/scene/SceneBlockShadow.tsx` (флаг `flat`: без тени под низом); `components/home/v2/scene/HomeSceneStage.tsx` и `components/home/v2/today_scene/TodaySceneView.tsx` (рамка сцены — фон = цвет сцены, без тени); градиент сцены «Сегодня» (`TodaySceneView.tsx`) — один цвет `tokens.sceneTop`.

## Architecture

`SceneBlockShadow` — общая рамка сцен: фон рамки = `tone`, тень под низом. Новый флаг `flat` отключает тень и задаёт фон рамки цветом сцены. Инвариант: по умолчанию поведение прежнее (тень есть) — другие сцены не меняются.

## Security and privacy

Не применимо: визуальные цвета и тени, персональных данных и сети нет.
