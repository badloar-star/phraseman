1. «Пары»: причина — размытие копиями текста оставляло буквы различимыми. Теперь на месте перевода мягкое пятно
   размером с текст (полосы, раздутые на 0–12 с убывающей плотностью): букв нет совсем — не читается ни на Android, ни на iOS.

2. «Охота»: причина — «сканер» макета в светлой теме тёмно-синий (elevate-light.css:59), а у нас был белым; в кадре

   сканера, она движется (2,6 с по кругу), так в макете.
3. «Глаголы»: журнал [QUIZ-ROUND] показал, что эффект нового задания запускается через 346 мс после смены раунда
   (на нагруженном телефоне до 1,4 с) — всё это время плашки стояли невидимыми. Подъём переведён на анимацию входа
   (components/games/gameRiseEntering.ts) — на записи после правки пустой кадр один (~50 мс), дальше плашки поднимаются.
   По ходу найдено и исправлено: длинные формы («schreiben · schrieb») обрезались по краям экрана — третья ячейка теперь
   переносится на следующую строку. Временный журнал убран.
