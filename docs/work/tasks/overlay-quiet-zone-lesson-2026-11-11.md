# Task packet: тишина в уроке — служебные окна не всплывают поверх занятия

Related epic/enabler: none

## Outcome

Игрок, который проходит урок, экзамен, тренировку карточек или разговор с ИИ, не получает поверх занятия
служебные окна («Доступно обновление», напоминание про уведомления, рассылки, сообщения команды, личные
сообщения, восстановление входа, приветствие по реферальной ссылке, переход на экран оплаты после истёкшей
подписки). Эти окна не теряются: они остаются в очереди и показываются, когда игрок вышел с занятия.

Мера успеха: в журнале `[OVERLAY-QUIET]` на экране занятия видно `deferred=[…]`, а в `[OVERLAY-STACK] show`
ни одного из отложенных ключей, пока путь экрана — занятие.

## Scope

In scope:
- `components/overlay_quiet_zone.ts` (новый) — чистые правила: какие пути «тихие», какие ключи откладываются.
- `components/OverlayArbiter.tsx` — провайдер читает текущий путь и выбирает следующего владельца слота
  по отфильтрованному списку желающих.
- `tests/overlay_quiet_zone.test.ts` (новый).

Out of scope (осознанно):
- `components/overlay_arbiter_core.ts`, `tests/overlay_arbiter.test.ts`, `app/_layout.tsx` — в них есть чужие
  незакоммиченные правки другой сессии; не трогаем.
- Окна мимо очереди (ForceUpdateGate, MaintenanceGate, PhoneStateRecoveryScreen, NoEnergyModal) — блокирующие
  по замыслу либо часть самого занятия.
- Ступени Пика: играются внутри вкладки без собственного пути, правилом по пути не покрываются.
- Лимит «не больше N окон за запуск» и поломки очереди на экране итога урока — отдельные задачи аудита.

## Architecture

Сейчас: `OverlayArbiterProvider` выбирает владельца слота по `wantsMap` и приоритету, не зная экрана.
Станет: провайдер получает путь через `usePathname()` (он смонтирован внутри корневого layout expo-router,
там же путь уже читает `EntitlementExpiredHost`), считает `quiet = isQuietRoute(pathname)` и подаёт в
`resolveNextOverlay` список желающих после `filterWantsForQuietZone`.

Инварианты:
- Очередь остаётся невытесняющей: окно, которое уже держит слот, не снимается при входе в тихую зону.
- Отложенное окно не теряет свою просьбу: `wantsMap` не меняется, фильтруется только выбор следующего.
- Окна самого занятия (`themedAlert`, итог урока, тосты, праздники экранов) не откладываются.
- При выходе из тихой зоны эффект выбора перезапускается и отдаёт слот по обычному приоритету.

## Security and privacy

Не затрагивает: вход, права, сеть, хранилище, личные данные. В журнал пишутся только путь экрана и имена
ключей окон, без содержимого сообщений и без идентификаторов игрока. Обязательное обновление
(ForceUpdateGate) и техработы идут мимо очереди и этой правкой не ослабляются.
