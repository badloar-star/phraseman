# Gate MIGRATION_AND_ROLLBACK_APPROVED_BEFORE_DESTRUCTIVE_CHANGE — пакет (2026-10-01)

Решение координатора §37 (Q85/Q83): gate подтверждается пакетом, если по КАЖДОЙ миграции есть
ссылка на решение владельца, проверка с выводом, шаг отката, судьба данных при откате и правило
«прод — только владелец». Пакет проверяет независимый агент-ревьюер, затем подписывает координатор.
Без шага отката gate не подтверждается.

Задачи, на которые распространяется: PM-046, PM-055, PM-078, PM-079, PM-084, PM-085, PM-089, PM-090.
Все прогоны — 2026-10-01 на HEAD ветки feature/referral-roulette, под светофором, без устройства и без прода.

**Общее правило для всех миграций: прод — только владелец.** Ни одна миграция ниже не запускается
серверным скриптом по базе; всё выполняется на телефоне человека при обновлении приложения или за
рубильником Remote Config, который включает владелец. Ядро и исполнители прод не трогают.
