Тема приложения

Прогон состояний

«Показать гейт» — лист въезжает снизу (spring), сцена карты гаснет скримом. «Открыть Plus» — тап по CTA: лист сменяется заглушкой «Экран подписки приложения» (в реальном приложении — existing paywall stack). «Вернуться завтра» — лист уезжает вниз, скрим гаснет, карта оживает (лёгкое дыхание узла). Никакого дарк-паттерна: вторичная кнопка — полноценная плитка, а не серый микротекст «нет, спасибо».

Спецификация для RN (Reanimated 4)

Лист: въезд снизу320 мс · spring (d22 s280)

Таймер до сброса лимитатик раз/с · tabular-nums, без layout jump
CTA Plus: бегущий блик-переливраз в 3с · 3D-кромка, глушится reduced
Пресс CTA/вторичной (3D-кромка)120 мс · вибро
Переход лист → заглушка paywall320 мс · slide-up spring, лист остаётся под ней
Возврат «Позже»: лист уезжает280 мс · slide-down outQuint
Карта оживает после закрытиядыхание текущего узла возобновляется
Только transform / opacity (UI-тред). Лист использует нативный bottom sheet на RN (переиспользуемый компонент из 08-unit-map.html), здесь — DOM-эквивалент для витрины. Reduced motion: въезд/выезд листа и переход к заглушке заменяются мгновенной сменой состояния с коротким кроссфейдом; бегущий блик CTA выключен.
