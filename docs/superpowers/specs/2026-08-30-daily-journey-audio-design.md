# Саунд-дизайн ежедневного путешествия: пять вариантов

Дата: 2026-08-30
Статус: дизайн утверждён владельцем; разрешена платная генерация ElevenLabs Sound Effects.

## 1. Цель

Добавить к существующему HTML-прототипу ежедневных подарков пять полноценных вариантов безречевого саунд-дизайна. В сцене нет диктора, речи, TTS, вокала и произнесённого текста. Каждый вариант сопровождает один и тот же визуальный таймлайн продолжительностью 6,2 секунды и позволяет сравнить характер звука без изменения интерфейса или анимации.

## 2. Пять направлений

| Вариант | Характер | Звуковые материалы |
|---|---|---|
| 1. Кристалл | чистый, светлый, точный | стеклянные импульсы, воздушный подъём, кристальный удар, мягкое сияющее послезвучие |
| 2. Руны | древний, материальный, магический | каменный резонанс, сухое чернильное потрескивание, низкий гул, рунический удар |
| 3. Игра | быстрый, упругий, наградной | короткие синтезаторные импульсы, аркадный подъём, плотный reward-pop, монетное мерцание без буквального звона кассы |
| 4. Кино | широкий, дорогой, кульминационный | приглушённый саб-пульс, кинематографичный riser, контролируемый impact, длинный световой хвост |
| 5. Тактильность | минимальный, физичный, спокойный | магнитные клики, мягкий воздушный whoosh, короткий чистый удар, быстрое затухание |

Варианты не содержат пугающих, агрессивных, тревожных или казино-подобных звуков. Кульминация заметна, но не превосходит по громкости безопасный мобильный интерфейсный уровень.

## 3. Генерируемые элементы

Для каждого направления ElevenLabs Sound Effects создаёт четыре независимых элемента:

1. `intro` — атмосферное открытие длительностью 2,6 секунды;
2. `pulse` — один короткий импульс длительностью 0,5 секунды, переиспользуемый три раза;
3. `reveal` — переход, подъём, impact и хвост длительностью 2,1 секунды;
4. `tap` — тактильный интерфейсный отклик длительностью 0,5 секунды.

Итого: 20 платных генераций, четыре элемента × пять направлений. Для каждой генерации фиксируются вариант, назначение, prompt, длительность, модель, HTTP request id, reported character cost, размер файла и SHA-256. API-ключ читается только из локального секрета и никогда не записывается в HTML, manifest, prompt или лог.

## 4. Синхронизация

| Время | Визуальное событие | Звуковое событие |
|---:|---|---|
| `0,00 с` | проявление модала | начало `intro` |
| `2,80 с` | первый пульс подарка | `pulse` с gain `0,72` |
| `3,23 с` | второй пульс | `pulse` с gain `0,86` |
| `3,66 с` | третий пульс | `pulse` с gain `1,00` |
| `4,10 с` | растворение календаря | начало `reveal` |
| `4,70 с` | увеличение подарка и лучи | подъём внутри `reveal` |
| `5,18 с` | удар раскрытия | кульминация внутри `reveal` |
| `5,60 с` | появление описания | световой хвост `reveal` |
| `6,20 с` | финальный модал | тишина; модал остаётся на экране |

`intro`, три экземпляра `pulse` и `reveal` сводятся офлайн в один мастер длиной ровно 6,2 секунды. Сведение использует равные таймкоды для всех вариантов, короткие fade-in/fade-out, peak не выше `-1 dBFS` и loudness, согласованный между пятью мастерами. В мастере нет бесконечного ambience-loop: после кульминации звук естественно заканчивается.

## 5. Управление воспроизведением

- Старт или «Повторить» запускает визуальную сцену и выбранный мастер от `0,00 с`.
- Пауза останавливает и анимацию, и звук на одной позиции.
- Продолжение восстанавливает оба потока с той же позиции.
- Перемотка устанавливает одинаковый `currentTime` для анимации и аудио.
- Смена варианта останавливает текущий мастер и при следующем повторе запускает выбранный.
- «Пропустить» немедленно отменяет мастер и все ожидающие звуки, показывает финальный модал и не проигрывает reveal/impact задним числом.
- «Применить» и «Позже» используют короткий `tap` выбранного варианта перед закрытием модала.
- Закрытие крестиком останавливает мастер без дополнительной кульминации.

## 6. HTML-прототип

В существующую внешнюю панель управления добавляется переключатель пяти звуковых вариантов и кнопка включения звука. Внутри мобильного модала не появляется новых подписей, бейджей или технических элементов.

Браузер может блокировать звук до первого жеста. Поэтому HTML-предпросмотр начинает визуальную сцену автоматически, а после первого нажатия на кнопку звука синхронно повторяет её уже со звуком. Это ограничение относится только к браузерному прототипу; production-приложение использует нативную аудиосессию.

Пять master-файлов и пять tap-файлов хранятся рядом с прототипом как локальные MP3. Для visual companion они встраиваются в автономную копию HTML как data URI. Внешних запросов из HTML нет.

## 7. Генерация и расходы

- Используется ElevenLabs Sound Effects, не Text to Speech.
- Модель: `eleven_text_to_sound_v2`.
- Формат исходных генераций: MP3 достаточного качества для последующего сведения.
- `prompt_influence` задаётся одинаково для сравнимости вариантов.
- Каждый prompt прямо запрещает speech, voice, words, vocals и music melody.
- Генератор не повторяет успешный запрос при повторном запуске: существующий файл с валидным manifest и SHA-256 пропускается.
- Ошибка одного элемента останавливает соответствующий вариант; генератор не делает неограниченных повторов.
- Полный stdout/stderr остаётся в игнорируемом рабочем каталоге, в чат выводится только краткая сводка.

## 8. Проверка

Для каждого master автоматически проверяется:

- файл декодируется;
- длительность равна 6,2 секунды с допуском 50 мс;
- нет цифрового clipping;
- peak не выше `-1 dBFS`;
- после `6,2 с` нет звука;
- HTML не содержит API-ключей и сетевых вызовов;
- play, pause, seek, replay и skip сохраняют синхронизацию;
- при skip финальный модал остаётся открыт, а звук остановлен;
- все пять вариантов доступны в браузерном предпросмотре.

## 9. Граница этапа

Этот этап создаёт только звуковые файлы, manifest, локальное сведение и HTML-предпросмотр. Он не подключает ежедневные награды к production-хранилищу, не меняет экономику, не активирует энергию, не выдаёт реальные ресурсы и не добавляет голосовую озвучку.
