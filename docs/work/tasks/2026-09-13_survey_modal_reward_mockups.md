# Task packet: макеты модалки опроса с наградой «+1 жемчужина за ответ»

Governance-ID: TG-F6A1BD74EAC7
Status: Planned
Owner: сессия Claude (Fable 5.1), владелец badloar@gmail.com
Related epic/enabler: опросы (components/survey/*), экономика жемчуга (app/shards_system.ts)

## Outcome

Владелец получает страницу с четырьмя живыми макетами новой модалки опроса
(тема «Индиго»), где каждый ответ мгновенно показывает «+1 жемчужина» и жемчужина
улетает в счётчик. Он выбирает направление для внедрения. Успех: выбран один
вариант (или гибрид) и есть список решений для реализации в SurveySheetModal.

## Scope

In scope: `docs/design/survey-modal/SURVEY_MODAL_VARIANTS_2026-09-13.html`
(автономный HTML, без зависимостей кроме Google Fonts), этот пакет.

Out of scope: правки `components/survey/**`, `app/shards_system.ts`, серверной
функции `submitShardSurvey`, правил Firestore. Внедрение — отдельная задача
после выбора владельца.

## Architecture

No architecture change: документ дизайна. Зафиксированное расхождение: сейчас
награда +1 выдаётся сервером один раз за ВЕСЬ опрос (идемпотентно), макеты по
запросу владельца показывают +1 за КАЖДЫЙ ответ. Внедрение потребует решения:
серверная выдача per-answer (новый контракт) или клиентская «дробная» анимация
одной награды.

## Security and privacy

Персональных данных нет; страница статична, ничего не отправляет. Публикуется
как приватный Artifact владельца.

## Technical debt

Contain: макет живёт в docs/design, не в коде приложения; выход — при внедрении
перенести мотив в Reanimated и удалить дублирующий текст копий из макета.
