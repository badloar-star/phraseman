# Англійська · Урок 13 · Заняття 34 — Дорогою до друзів

**Ситуація.** Уточніть у друга порядок учорашніх подій у дорозі.

**Що ви опануєте:** review: past event sequence
**Нові слова:** set off, stop off, drop off, run into

## Інтро 1

### Вирушити в дорогу

Set off — вирушити в дорогу. First of all, we set off at eight — насамперед ми вирушили о восьмій. Did you set off early? — Ти вирушив рано? Виберіть запитання.

**Виберіть фразу для цієї ситуації.**

- ✅ **Did you set off early?**
- ❌ You set off early. — *Це повідомлення, не запитання.*
- ❌ Do you set off early every day? — *Це запитання про звичку.*

---

## Інтро 2

### Зупинитися дорогою

Stop off — ненадовго зупинитися дорогою. Then we stopped off at a café — потім ми ненадовго зупинилися в кафе. Виберіть зупинку дорогою.

**Виберіть фразу для цієї ситуації.**

- ✅ **Then we stopped off at a café.**
- ❌ First of all, we set off at eight. — *Це відправлення, а потрібно зупинитися дорогою.*
- ❌ Then we stop off at a café yesterday. — *Для минулого потрібна stopped.*

---

## Інтро 3

### Завезти й випадково зустріти

Drop off тут — завезти й залишити річ або людину в потрібному місці. Run into тут — випадково зустріти знайомого. Did you run into your neighbour? — Ти випадково зустрів сусіда? Виберіть зустріч.

**Виберіть фразу для цієї ситуації.**

- ✅ **Did you run into your neighbour?**
- ❌ Did you drop off the parcel? — *Це доставляння посилки.*
- ❌ Did you ran into your neighbour? — *Після did потрібна run.*
