# E2E «новичок»: онбординг → welcome B-3 → первый урок классики → +500 (для Сверки, 05.11)

Пакет: `docs/work/tasks/e2e-newbie-steps-2026-11-05.md`. Составлено по коду (не по памяти); числа и ключи ниже — из исходников.

## 0. Условия (без них шаги 4–8 «ожидаемо пустые»)

- **Момент среза.** «Новый» = аккаунт Firebase создан не раньше `RANK_GATES_NEW_USERS_SINCE_MS` (`app/rank_gates_new_user.ts`). Пока там `Number.MAX_SAFE_INTEGER`, «новых» нет: приветствие B-3, бонус +500 и замки НЕ работают (это нормально до команды «ставь» ~02:15). Проверять шаги 4–8 на сборке ПОСЛЕ подстановки метки среза; метка должна быть РАНЬШЕ момента создания тестового аккаунта.
- **Флаги (решение координатора 05.11).** В первой версии 2.1.0 `rank_gates_enabled` и `section_openings_enabled` ВЫКЛ по умолчанию (включает Пульт в момент «сборка в сторе»). Приветствие B-3 и бонус +500 от этих флагов НЕ зависят: приветствие и бонус работают при выключенных гейтах.
- **Проверка гейтов (замки по рангу, окна «Открытие разделов») — только с принудительным включением флага в dev**, без записи в боевой Пульт: собрать dev-сборку с `EXPO_PUBLIC_DEV_FORCE_FLAGS=rank_gates_enabled,section_openings_enabled` (в релизе и стор-сборке переменная игнорируется). Без неё замки и окна «Открытие разделов» не появляются — это ожидаемо.
- **Журнал.** В релизной сборке `console.log` вырезается (остаются `warn`/`error`). Строки `[WELCOME-B3]`, `[RANK-GATE]` видны только в dev-сборке (Metro, `.expo/metro-console.log`). В релизной сборке проверять по экрану: приветствие, число монет, окно результата.
- **Чистая установка:** удалить приложение, поставить заново (очистка данных недостаточна: Auth хранится в системе). Новый аккаунт — не тот, что использовался раньше.

## 1. Онбординг (первый запуск)

1. Запуск → экран выбора языка/приветствия языка (`language_welcome`): три шага «приветствие → цель → уровень».
2. Нажатия на кнопки и карточки: лёгкое вдавливание (нажатие кита), галочка выбора «ставится» пружиной; при системном «Уменьшить движение» — без пружины, галочка есть.
3. «Продолжить» не активна, пока нет выбора; «назад» возвращает на предыдущий шаг.
4. После завершения онбординга в хранилище появляется метка `onboarding_completed_at_ms_v1` (строка `[RANK-GATE] verdict` в dev-журнале содержит `completedAtMs`).
- Ожидание: нет двух окон одновременно; никакого системного окна уведомлений поверх нашего приветствия не обещано (порядок задаёт ОС, см. `docs/work/tasks/first-run-risks-2026-11-05.md`).

## 2. Welcome B-3 (после онбординга, на Главной)

1. Должно появиться приветствие `ApprovedWelcome` ОДИН раз (через арбитр окон, ключ `onboardingWelcome`, первым).
2. Dev-журнал, ожидаемая цепочка:
   - `[RANK-GATE] verdict {"isNew":true,"reason":"new", ... "accountCreatedAtMs":<мс>, "sinceMs":<метка среза>}`
   - `[WELCOME-B3] {"show":true,"isNew":true,"reason":"new","alreadyShown":false,"attempt":0,"retryInMs":null}`
3. Если сразу после установки время создания аккаунта ещё неизвестно: `reason":"account_age_unknown"`, `"retryInMs":3000`, затем 8000 и 20000 (максимум 3 повтора, отметка «не новый» НЕ записывается). Приветствие должно появиться при первом успешном повторе.
4. Закрыть («Пропустить» или «Начать») → `[WELCOME-B3] {"event":"skip"|"start","slot":"released"}`; в хранилище ключ `story_events_v1:welcome_b3:<uid>`. «Начать» ведёт в `/(tabs)/lessons`.
5. Перезапуск приложения: приветствие НЕ повторяется (`alreadyShown:true`).

## 3. Первый урок КЛАССИКИ и бонус +500

1. «Уроки» → первый урок обычного курса (не V2: вкладка V2 скрыта до первого завершённого занятия; «Начать урок 1» и «Продолжить» ведут в классику).
2. Пройти урок до экрана результата (`lesson_complete`).
3. Ожидаемо:
   - монеты +500 сверх обычной награды за урок (бонус `FIRST_LESSON_BONUS_COINS = 500`, подарок `stars_500`); в окне результата — строка подтверждения «+500 монет за первое занятие» (хук `use_first_lesson_bonus_note`);
   - dev-журнал: `[RANK-GATE] first_lesson_bonus granted {"coins":500}`;
   - флаг: ключ `story_events_v1:first_lesson_bonus_granted:<uid>` = `1`.
4. Повторы: второй урок / повторное прохождение / перезапуск — бонус НЕ начисляется (`first_lesson_bonus skip reason=already_granted`); счёт монет не меняется сверх обычных наград.
5. Ключ операции один на владельца (`dailyjourney_<32 символа>_1`): даже если окно «+500» покажется повторно, монеты не задваиваются.
