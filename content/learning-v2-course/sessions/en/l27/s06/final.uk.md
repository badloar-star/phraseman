# Урок 27 · Заняття 06 — Що будемо їсти

**Ситуація.** Ви обираєте обід, пояснюєте свої смаки й обговорюєте вечерю з другом.

**Що ви опануєте:** if + past simple, would + base verb; past simple / present perfect
**Нові слова:** nutritious, appetizing, tasteless, sugary

## Інтро 1

### Якби вистачало часу готувати

Друг запитує, чому ви рідко готуєте вдома. Поясніть: I would cook more often if I had more time — я б готував частіше, якби мав більше часу. Складаємо: I + would cook + more often + if I had more time — хто, що робив би, як часто, за якої умови. Would cook показує уявну дію; cook після would не змінюється. В умові використовуємо had без would: вільного часу зараз мало.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would cook more often if I had more time.**
- ❌ I would cooked more often if I had more time. — *Після would потрібно cook.*
- ❌ I would cook more often if I would had more time. — *В умові had без would.*

---

## Інтро 2

### Якби був лимон

Ви куштуєте суп і хочете додати лимон, але його немає. Скажіть: I would add some lemon if I had one — я б додав трохи лимона, якби мав лимон. Складаємо: I + would add + some lemon + if I had one — хто, що зробив би, що додав би, за якої умови. Після would потрібна add. One замінює цілий лимон, щоб не повторювати a lemon; had описує уявну умову зараз.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would add some lemon if I had one.**
- ❌ I would adding some lemon if I had one. — *Після would потрібна форма add.*
- ❌ I would add some lemon if I would had one. — *Після if тут had без would.*

---

## Інтро 3

### Коли приготували вечерю

Друг запитує, коли ви приготували вечерю, яку зараз розігріваєте. Дайте відповідь: I made it yesterday — я приготував її вчора. Складаємо: I + made + it + yesterday — хто, дія в минулому, що приготував, коли. Made — минула форма make, не maked. It замінює вечерю. Yesterday називає завершений час, тому тут made без have.

**Виберіть фразу для цієї ситуації.**

- ✅ **I made it yesterday.**
- ❌ I have made it yesterday. — *Із yesterday тут past simple.*
- ❌ I maked it yesterday. — *Минула форма make — made.*
