# Англійська · Урок 19 · Заняття 37 — Пояснити, що не підходить

**Ситуація.** Ви пояснюєте, чому час не підходить, називаєте відповідь нечесною й оцінюєте звичку та ймовірність результату.

**Що ви опануєте:** so + adjective; such + noun phrase
**Нові слова:** inconvenient, dishonest, unhealthy, unlikely

## Інтро 1

### Сильне враження

inconvenient — незручний за часом або обставинами. So підсилює прикметник: so kind. Such підсилює групу з іменником: such a kind person. Для одного злічуваного предмета потрібне a або an після such; із множиною й незлічуваними його немає: such kind people, such good news.

**Виберіть фразу для цієї ситуації.**

- ✅ **This time is so inconvenient.**
- ❌ This time is such inconvenient. — *Після пропуску прикметник без іменника: so.*
- ❌ This time is much inconvenient. — *Перед звичайним прикметником тут потрібне so, не much.*

dishonest — нечесний. So підсилює прикметник: so kind. Such підсилює групу з іменником: such a kind person. Для одного злічуваного предмета потрібне a або an після such; із множиною й незлічуваними його немає: such kind people, such good news.
