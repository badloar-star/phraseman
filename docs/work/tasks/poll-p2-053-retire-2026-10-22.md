## Outcome

Набор p2-053 (q1 «Do you use the card size slider?» + q2 «Which card layout do you like?») не показывается людям: в его день карточки опроса нет, как у «битого» набора. Расписание, нумерация наборов, тексты в home_polls_v2.json (приложение и content/polls),
форма набора на сервере (id вопросов и вариантов) и собранные ответы не меняются.

## Scope

- app/home_polls/home_polls_v2_model.ts — список снятых наборов HOME_POLL_V2_RETIRED_SET_IDS = ['p2-053']; parseHomePollV2Catalog даёт для него null (индексы остальных наборов не сдвигаются — так уже устроен «битый набор»).
- tests/home_poll_v2_contract.test.ts — контракт: в файлах по-прежнему 100 наборов и 230 вопросов, зеркало content/polls = app совпадает; в показе 99 наборов, снят ровно p2-053; тест самого механизма.
- Файлы home_polls_v2.json (оба) НЕ меняются, см. Architecture.

## Architecture

Вопрос из JSON выкинуть нельзя: модель требует 2–3 вопроса на набор (набор с одним q2 станет «битым»), сторож требует ровно 100 наборов и 230 вопросов и зеркало app ↔ content/polls, а сидер scripts/polls_v2/seed_home_polls_v2.mjs сверяет форму наборов с уже созданными документами на сервере.
Поэтому снятие — на уровне показа: единственная точка в модели, обратимая одной строкой. Набор p2-053 по расписанию придёт не раньше середины 2027 (один набор в ~4 дня, сейчас p2-002), ответов на него быть не могло; отложенные голоса (очередь) для него не появятся.
В журнале клиента день снятого набора пишется как load:no_set reason=set_broken_in_bundle — файл клиента сейчас правит другая сессия, поэтому его не трогаем; уточнение причины можно добавить отдельно.
