## 1. ГЛАВНОЕ ТРЕБОВАНИЕ ВЛАДЕЛЬЦА (дословно)

> «перенос с макетов строжайше не маппинг а точный перенос именно сверка по
> макету а не написание по коду, именно визуально и тактильно и все остальное
> точно как по макетам»

> «Открыть каждый макет, разобрать: структуру DOM → CSS каждого состояния →
> каждый keyframe → тайминг и кривую. Перенести в React Native один в один:
> land → Reanimated-анимация позиции, playPulse → пульс на кнопке звука,
> matchPop → схлопывание пары. Потом запустить приложение, открыть макет рядом
> и сравнить кадр за кадром. Это не «дополировать» — это переписать четыре
> экрана заново с макетов.»

> «задания не создать новую структуру а сделать так чтобы сессии учитывали
> словари и неправильные глаголы (отдельные режимы для отработки) и учитывали
> фразы все 32 урока и все фразы уроков и всю структуру, а также интро и
> теорию, просто в новом дополненном дизайне но это все весь контент должен
> быть сохранен просто переиспользован в новом формате»

**Расшифровка:** контент 32 уроков НЕ создаётся заново. Он переиспользуется в
новой оболочке. Макеты — источник истины для внешнего вида и ощущения, код
приложения — источник истины для контента и механики проверки.

## 2. РЕШЕНИЯ ВЛАДЕЛЬЦА — ЗАКОН, НЕ ПЕРЕСПРАШИВАТЬ

### Законы дизайна (G27–G39, из предыдущего хендовера, все в силе)

- **G27.** Никаких графических/визуальных режимов. Режим `visual_discovery`
  вычеркнут полностью.
- **G28.** НИКАКИХ эмодзи и картинок в контенте и UI. Весь контент —
  типографика + аудио. Иконки только векторные (SVG/Ionicons).
- **G29.** Эталон премиальности: ТИПОГРАФИКА-ГЕРОЙ (фраза — центр композиции,
  чёткая лестница кеглей) + глубокие градиенты и деликатные переливы тона.
- **G30.** Волну открывает Сборка фразы (Phrase Builder).
- **G31.** СТРИК ВНУТРИ СЕССИИ: пилюля серии с ярусами накала (2/4/6+, на
  максимуме бегущий блик) + «золотая волна» через экран на вехах 3/5/7 + искры.
  За серию сразу больше звёзд: ×3 = +1 бонусная, ×5 = +2 (летят от пилюли серии).
  Ошибка гасит серию ДЕЛИКАТНО, без наказания.
- **G32.** Премиальность на ВСЁМ: не только кнопки, но фоны (виньетка глубины),
  счётчики-пилюли, полосы фидбека, базовые линии (градиентная нить вместо
  жёсткой черты), градиент по тексту героя.
- **G33.** В шапке НЕ дублировать динамик: справа «настройки урока», озвучка —
  одна кнопка у фразы.
- **G34.** Индикатор прогресса — СПЛОШНАЯ полоса, не сегменты.
- **G35.** Карта: БЕЗ полоски-дорожки между узлами, плотно (шаг 96px).
- **G36.** КРИТЕРИЙ РЕЖИМА: режим живёт ТОЛЬКО если есть (а) однозначно верный
  ответ, (б) честная проверка «верно/неверно» БЕЗ ИИ, (в) звёзды за результат
  и серия. Нет проверки и вердикта — это упражнение, а не режим.
- **G37.** ВЫДЕЛЕНИЕ ВЫБРАННОГО читается мгновенно и БЕЗ обводок: ощутимо
  светлее градиент фона, подъём translateY(-2px) с усиленной тенью, акцентный
  SVG-бейдж, текст выбранного самый яркий, невыбранные притухают (opacity 0.82).
- **G38.** ВСЁ ПОМЕЩАЕТСЯ БЕЗ СКРОЛЛА в раме 390×800 в КАЖДОМ состоянии; CTA
  внизу виден всегда. Исключение — карты и ленты чата (там скролл — механика).
- **G39.** РЕАЛЬНОЕ АУДИО в макетах через `new Audio()` с graceful fallback.

### Решения после research (H1–H6)

- **H1. СТРИКИ ОСТАЮТСЯ, И ДНЕВНЫЕ ТОЖЕ.** Владелец ознакомлен с research
  (аудитория 40+/50+ хуже переносит стрик-давление; 45% негатива Duolingo на
  энергию) и подтвердил решение. Цифры за: Streak Freeze +48% удержания
  (17.19 против 11.62 дней на 7-й день), 43M пользователей Duolingo с
  7-дневным стриком. **Реализовать МЯГКО:** заморозки, без чувства вины, без
  давящих уведомлений.
- **H2. ЭНЕРГИЯ УБИРАЕТСЯ ПОЛНОСТЬЮ.** Вместо неё — вход в сессию за ЗВЁЗДЫ.
  Осколки уже заменены на жемчужины.
- **H3. УРОК = 12 СЕССИЙ ПО 8 КАРТОЧЕК.** Каждый из 32 уроков становится юнитом
  из 12 коротких сессий (3–4 минуты). Весь контент урока сохраняется и
  раскладывается по сессиям.
- **H4.** Формат опроса владельца: блоками по 4 вопроса подряд, каждый с
  подробным объяснением простым языком.
- **H5.** Отдельные режимы отработки словаря и неправильных глаголов
  сохраняются.
- **H6.** Перенос с макетов — строжайше точный, сверка кадр за кадром.

### Ранее принятые решения (§3 старого хендовера, все в силе)

1. Цикл состояний «как у Duolingo»: ответ → Проверить → inline-обработка →
   вердикт → авто-дальше. Никаких служебных панелей переключения состояний.
2. Микрофон НАСТОЯЩИЙ, распознавание ТОЛЬКО на устройстве, аудио не
   сохраняется. Экраны с обещанием СЕТЕВОЙ обработки голоса — не показывать.
3. Дистракторы: каждый неверный вариант грамматически НЕВОЗМОЖЕН в контексте.
   Допустимый вариант = второй правильный ответ = запрещено.
4. Тема: режимы перенимают цвета приложения через `useTheme`, не хардкод.
5. Запреты дизайна: без обводок контейнеров, без подписей-расшифровок мелким
   шрифтом, без `adjustsFontSizeToFit`. Клик-звук только на управляющих
   кнопках; плитки — хаптика.
6. Показ работы: макеты в браузере → одобрение → перенос в RN.

## 3. RESEARCH КОНКУРЕНТОВ — ВЫЖИМКА С ЦИФРАМИ

### 3.1 Отменённые режимы и почему

Владелец отменил 7 из 14 режимов по критерию G36. Файлы удалены, не возвращать:
`11-scripted-dialogue`, `12-branching-scene`, `13-microstory` (сценарные),
`15-quick-response` (свободная речь требует ИИ), `16-sound-lab`, `17-shadowing`
(нет вердикта, не игровые), `18-speaking-club` (ответы партнёра требуют ИИ).

**Осталось 7 режимов:** Сборка фразы (эталон), Выбор на слух, Пары звуков,
Диктант, Контекстный пропуск, Пары на скорость, Повтор за моделью.

### 3.2 Duolingo (главный ориентир по механике)

- Структура: Section → Unit → Level → Lesson. 4–9 секций на курс.
- Сессия: 5–10 минут, «дюжина» упражнений. Дневная цель: Casual 5 мин/10 XP,
  Regular 10/20, Serious 15/30, Intense 20/50.
- Типы заданий: диктант, выбор на слух, перевод, дополнение перевода,
  пары на скорость (Match Madness), сборка из банка слов, произношение,
  истории, легендарные уровни.
- Обратная связь: звук «Ding-dilin», маскот, красный баннер «Incorrect»,
  **«Explain My Answer» (GPT-4) теперь бесплатно для всех**.
- Экономика 2025: **энергия заменила жизни** — 25 единиц/день, тратится на
  КАЖДЫЙ вопрос независимо от правильности, восстановление до 18 часов.
  **45% всего негатива в отзывах — про энергию.** Тред «So Now We're Punished
  for Using the App?» — 3000 апвоутов.
- Стрики: Streak Society на 7/30/100/365 дней. Заморозка 200 гемов.
  **Данные удержания: с заморозкой 17.19 дней на стрике против 11.62 без неё
  (+48%); на 14-й день 30.63 против 18.87.**
- Достижения: выполнившие хотя бы одно в первый день удерживаются 33.42%
  против 20.36%. Сложные достижения — до 74.17%.
- Лиги: 10 тиров по 30 человек, недельный сброс. Bronze продвигает топ-67%,
  Diamond — не продвигает.
- Монетизация: Super $13.99/мес, $95.99/год. Max $29.99/мес. **Reverse-trial:
  14 дней Super бесплатно новым пользователям.** Пейволл после ПЕРВОГО урока.
  300+ экспериментов в квартал, конверсия выросла с ~3% до 8.9%.
- Финансы FY2025: 52.7M DAU (+36%), 133M MAU, 12.2M подписчиков, выручка $1.04B.

### 3.3 Что говорят исследования про аудиторию 40+/50+ (КРИТИЧНО)

- Средний пользователь Babbel в США — **45 лет и старше**. В исследовании
  Йельского университета (117 человек) **75% участников были старше 40**.
  Мотивация: путешествия 74%, работа 15%.
- Прямая рекомендация профильного обзора для 50+: **избегать сильно
  геймифицированных приложений со «стрик-тревогой»**. Цитата: «Стрики, XP,
  сердечки, короны и лиги — это механики из мобильных игр, которые почти не
  имеют отношения к тому, как взрослые учат языки».
- Что нужно этой аудитории: спокойный интерфейс, читаемая типографика, **явные
  объяснения грамматики** (не «догадайся сам»), возможность замедлить аудио,
  путь к реальному разговору.
- Научное подтверждение: взрослые учащиеся выигрывают БОЛЬШЕ от явного
  объяснения грамматики, чем от неявного погружения (Cambridge SLA) — они
  сознательно сравнивают с родным языком.
- Мотивационный крючок с доказательной базой: изучение языка в возрасте —
  подтверждённая нейропластичная защита от возрастного когнитивного снижения
  (несколько исследований PMC). Это честный аргумент, не маркетинг.
- Duolingo не сегментирует 40+ в публичных отчётах (60% DAU — 16–34 года) —
  **сегмент недоисследован, там есть место**.
- **Владелец знает про это и всё равно решил оставить стрики (H1).** Причина:
  цифры удержания реальны. Задача — сделать мягко, без вины.

### 3.4 LingoDeer — ближайший идеологический сосед

- **НЕТ жизней/сердечек/энергии вообще.** Ошибся — вопрос просто вернётся позже.
- Грамматика — главное отличие: «Learning Tips» / «Knowledge Cards» с
  объяснениями «как в учебнике» ПЕРЕД упражнениями.
- Прямая цитата из обзоров: подходит **взрослым, которые не поняли объяснений
  грамматики в Duolingo**; «значительно быстрее для взрослых, которые учили
  второй язык в школе с грамматикой».
- Ответ не отправляется, пока не нажал «Check» — «ошибаться это нормально».
- Отзыв о статусах слов: New → Weak → Good → Perfect.
- Цена: $14.99/мес, $95.99/год.

### 3.5 Babbel — «курс, а не игра»

- Позиционирование прямо анти-Duolingo: «Babbel ощущается как настоящий курс,
  а не игра», «намеренно избегает геймификации вроде мультяшных персонажей,
  выпрашивающих стрик».
- Юнит = 3–5 занятий + повторение. Сессия 10–15 минут.
- **Интервальное повторение с точными интервалами:** правильно с первого раза →
  повтор через 1 день → 4 дня → 7 → 14 → 60 → 6 месяцев. Ошибся → завтра.
  Шесть уровней знания слова.
- Стрики есть, но с **2 заморозками в неделю**, обновляются в понедельник.
- Грамматика: короткие всплывающие подсказки прямо в потоке упражнений +
  отдельный Grammar Guide (определение → таблица → примеры).
- Пейволл: 17 шагов онбординга, вопрос о времени в день (5–60 мин) ДО пейволла,
  показ пейволла после «психологического обязательства». Отказ → 7 дней
  бесплатно; ещё отказ → скидка 55%.
- Цена: $14.99/мес, ~$95.88/год, пожизненно $599 (часто $299).

### 3.6 Memrise, ELSA, Rosetta, Lingvist, Speak — коротко

- **Memrise:** интервалы 4ч → 12ч → 24ч → 6 дней → 12 → 48 → 96 → 6 месяцев;
  ошибка сбрасывает на 4 часа. Метафора «цветок растёт». Главная жалоба —
  слабая грамматика. Видео с живыми носителями вместо робоголоса.
- **ELSA Speak:** пофонемная цветная подсветка (зелёный/жёлтый/красный),
  процент близости к носителю, пентаграмма из 5 осей (произношение, беглость,
  интонация, грамматика, словарь). Это эталон визуализации оценки речи.
- **Rosetta Stone:** сессии 20–30 минут, TruAccent, геймификация почти
  отсутствует, позиционируется как «традиционная, спокойная альтернатива».
- **Lingvist:** заполнение пропуска в реальном предложении + ИИ-модель
  забывания. Минимум геймификации.
- **Speak:** $1B оценка, OpenAI Realtime API, ролевые сценарии с целями.

### 3.7 Топ практик к переносу

1. Короткие сессии 5–10 минут (все 6 конкурентов).
2. Явная грамматика для взрослых (LingoDeer, Babbel) — у нас уже есть теория
   32 уроков, это преимущество.
3. Ответ проверяется по кнопке, не автоматически (LingoDeer).
4. Интервальное повторение с явными интервалами (Babbel/Memrise).
5. Заморозки стрика (Duolingo/Babbel) — обязательно при H1.
6. Объяснение ПОЧЕМУ ответ неверен (Duolingo «Explain My Answer»).
7. Пейволл после первой ценности, не до неё.
8. Замедленное аудио отдельной записью, не playbackRate.

### 3.8 Антипаттерны — чего НЕ делать

1. Трата ресурса за правильные ответы (энергия Duolingo 2025) — 45% негатива.
2. Давящие уведомления с чувством вины.
3. Потеря длинного стрика без возможности восстановить.
4. Однообразие после среднего уровня (жалоба на Babbel).
5. Раздражающий звук успеха (жалоба на Babbel в наушниках).
6. Лишние кнопки «Продолжить», замедляющие поток.
7. Скрытые условия подписки, сложная отмена.

## 4. АУДИТ КОДА ПРИЛОЖЕНИЯ — ЧТО ЕСТЬ СЕЙЧАС

### 4.1 Движок уроков

- **`app/lesson1.tsx` (3998 строк)** — универсальный движок для ВСЕХ 32 уроков,
  несмотря на имя. Экспортирует `LessonScreen()`.
- Внутри: `LessonContent` (презентационный, ~70 пропсов), `LessonCycleEndModal`,
  `LessonPressable`.
- **Два режима ввода** (не типы заданий!): сборка из плиток (по умолчанию) и
  печать текста (`settings.hardMode`). Это настройка пользователя.
- Цикл: `getPhraseForCell` → `handleWordPress` / `handleTypedSubmit` →
  `checkAnswer` (строка 2843, ключевая) → `setStatus('result')` → `goNext`.
- Порядок фраз: Фишер-Йетс шаффл при старте, сохраняется в AsyncStorage.
- **Немедленный повтор ошибок:** ошибка → очередь `errorQueueRef` → всплывает
  через `ERROR_REPLAY_DELAY_ANSWERS = 2` ответа. Урок не завершится, пока
  очередь не пуста.
- Проверка ответа: `isCorrectAnswer` из `constants/contractions.ts` —
  нормализация (NFKC, кириллические двойники, апострофы, раскрытие сокращений,
  британский→американский), затем ТОЧНОЕ сравнение. Никакого Левенштейна.
- Энергия тратится по 1 на каждый ответ (правильный и нет), блокирует ответ
  при нуле, но не выкидывает из урока.

### 4.2 Дистракторы

- **Боевой путь:** `app/lesson1_smart_options.ts` (3097 строк) →
  `getPerWordDistracts` → `app/smart_distractors.ts` (480 строк) →
  `rankSmartDistractors`.
- `app/lesson1_distractor_logic.ts` (698 строк) — **мёртвый legacy**, не
  импортируется.
- Пайплайн: ручные дистракторы из данных → guard против false-negative
  (it/this/that как взаимозаменяемые; can/could) → guard закрытого класса
  (служебное слово → дистракторы только из того же класса) → категория →
  соседнее слово → глобальный пул → ранжирование.
- Ранжирование: +130 за совпадение закрытого класса, −120 за несовпадение,
  +55/−95 за часть речи, +34 за грамматическую ловушку, +120 за куратора,
  −50 за generic-глагол. Отсечение при score < −50.
- Всегда 6 вариантов: 1 правильный + 5 дистракторов. Позиция на экране —
  честный шаффл (`layoutOptionShuffle`), чтобы не запоминали позицию.

## 7. ЛОВУШКИ И ПРАВИЛА РЕПОЗИТОРИЯ

7. **Windows-консоль:** python print кириллицы падает (cp1252) — писать файлами
   или через node.
8. **Хуки:** tsc-каскад после каждой записи, `layout_stability_hook.mjs`
