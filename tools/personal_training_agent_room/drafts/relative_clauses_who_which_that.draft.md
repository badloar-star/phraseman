# relative_clauses_who_which_that

Jesse rework pass for choosing `who`, `which`, `that`, and `whose`.

## Scope

- One microdiagnosis only: `relative_clauses_who_which_that`.
- Preserve the existing MVP contract ids and contrast sets.
- Replace English-only learner copy with RU/UK ASCII transliteration.

## Teaching Point

The learner should first look at the word before the gap:

1. Person -> `who` or `that`
2. Thing / idea -> `which` or `that`
3. Possession -> `whose`
4. Avoid extra `he` / `it` when the sentence already connects cleanly.

## Copy Rules

- Visible RU/UK copy uses ASCII transliteration.
- Avoid learner-facing raw labels like `noun`, `subject`, or `object`.
- Contract contrast labels remain unchanged because tests assert them.

## Structure

- Easy: `who` for people.
- Contrast: `which` for things/ideas, `that` for defining details.
- Mixed: duplicate `he/it`, omission, `whose`, comma + `who`.
