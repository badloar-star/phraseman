# Новое начало дизайна — не рестайлинг «Графита»
Предыдущий макет отклонён владельцем как устаревший, похожий на интернет-приложение 2000-х. Не повторять его композицию и не считать низкую насыщенность цвета достаточной премиальностью.

Прочитать docs/DESIGN.md и последние требования. Сначала согласовать состав пяти экранов. Предложение: главная, каталог карточек, практика, видео, активность. Подготовить несколько действительно разных современных мобильных направлений на одном контенте и размере телефона. Никаких фальшивых данных о продуктивности и новых разделов. Не выдавать HTML-доску документации за UI приложения.

Показать полный мобильный экран, состояние, типографику, отступы, действия. После owner selection зафиксировать конкретные макеты. Не начинать production UI до утверждения. Изображение-концепт не доказывает производительность или техническую реализуемость; после выбора нужен реальный компонентный прототип.
