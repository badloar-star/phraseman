## Outcome

В Пике задание тем легче, чем ниже башня (шпиль) и этаж: первый этаж первой башни получает самые лёгкие фразы пула, вершина
последней башни — самые трудные. Сложность берётся из оценки автора для КАЖДОЙ фразы (поле `target` Кодекса, 21,75…49),
а не из вида механики. Мера успеха: на шпиле 0, этаже 1 в накладке стоят только задания из самой лёгкой части пула языка;
средняя оценка заданий растёт с этажом и со шпилем.

## Scope

In scope:
- `content/spire-expanded/{lang}/tasks.jsonl` — к каждой строке дописывается `level.target` и `level.floor` автора
  (из его исходных файлов по `candidateId`); остальное в строке не меняется (правки вычитки сохраняются).
- `scripts/attach_peak_expanded_levels.mjs` — это дописывание, повторяемо; `scripts/import_peak_expanded_pool.mjs` —
  впредь тоже переносит `target`/`floor`.
- `functions/src/spire_expanded_task.ts` — оценка фразы попадает в задание пула (`rank`).
- `functions/src/spire_expanded_overlay.ts` — выбор задания для места в наборе по «трудности места» (та же формула
  `spireHardness(шпиль, этаж)`, по которой собирается сам набор недели): трудность места → доля пула, отсортированного по
  оценке фразы; задание берётся из окна вокруг этой доли.
- `functions/src/spire_pack_build.ts` — накладка, собранная по старому правилу, считается устаревшей и пересобирается
  (пакет недели при этом не меняется).
- `content/spire-quality` — трудность принятых заданий старых видов: не ниже метки автора (D1/D2), а по оценке автора
  самые трудные поднимаются выше.
- Тесты в `tests/spire_expanded_overlay_parity.test.ts`.

Out of scope:
- Нынешний пул Арены (4 000 заданий на язык) — он уже раскладывается по этажам формулой трудности набора; не меняется.
- Независимая калибровка сложности на игроках — оценка автора редакторская (`empiricallyCalibrated: false`).

## Architecture

Сейчас: накладка делит пул на три корзины по «неделе» автора (1–4, 5–8, 9+) и берёт задание из корзины, совпадающей с
трудностью заменяемого задания. Корзина 1 охватывает половину пула, поэтому на первом этаже встречаются фразы уровня B1–B2.
Станет: пул языка сортируется по оценке фразы; для места в наборе считается `h = spireHardness(tier, floor)` ∈ [0,1];
центр окна — `h·(n−1)`, ширина окна — max(48, 15 % пула); внутри окна порядок перемешан детерминированно (по неделе, языку,
шпилю, этажу и ступени), при нехватке окно расширяется к ближайшим по оценке. Инварианты прежние: пакет недели и его отпечаток
не меняются, повтора внутри ступени нет, снятые по жалобе задания не попадают, сборка детерминирована.
