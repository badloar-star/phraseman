# Окно «Встречайте PhraseMan 2.0»: старые бонусы стали монетами (15.10)

Governance-ID: TG-A6A2AD5951BA
Status: Planned
Owner: сессия «2 · Дизайн» (экран), «1 · Ядро» (сервер и клиентский хук)
Related epic/enabler: D195 (все старые бонусы в монеты по курсам «Средне»)

## Outcome
Человек, у которого сервер реально начислил монеты за старые опыт, жемчуг и вращения колеса, один раз видит на Главной шторку «Встречайте PhraseMan 2.0»: строки «что во что превратилось», счётчик монеты растёт до итога, кнопка «Понятно». Монеты уже на балансе; окно — только рассказ о факте. Макет: артефакт Q9jqpBbjwJEFV1DpdEGx2h (утверждён Ядром/владельцем).

## Scope
In scope: `modules/legacy_bonus/legacy_bonus_strings.ts` (9 языков) и `legacy_bonus_view.ts` (строки окна из ответа сервера, форматирование); `components/legacy_bonus/*` (шторка, счётчик, летящие монеты); `hooks/use_legacy_bonus_welcome_moment.ts` (слот в очереди окон, ленивый вызов после первого кадра Главной); ключ `legacyBonusWelcome` в `components/overlay_arbiter_core.ts`; подключение в `app/(tabs)/home.tsx`; тесты.
Out of scope: сам начисляющий вызов и `app/legacy_bonus_client.ts` (Ядро), начисление на сервере, пересчёт курсов.

## Architecture
Клиентский контракт Ядра: `useLegacyBonusWelcome(): { kind: 'none' | 'show'; result?: LegacyBonusResult }` и `dismissLegacyBonusWelcome()`. `show` — только при status `converted` и не закрытом окне; иначе ничего не рисуем и не ждём. Показ — через OverlayArbiter (свой ключ, после окна «С возвращением»), шторка HybridSheetShell (тот же материал, что у «Что нового»). Поздравление не durable (правило 01.09): монеты на балансе, окно не хранит долг на показ. Строки — только там, где монет больше нуля; потолок (`cappedBy`) не объясняется.

## Security and privacy
Новых данных не собираем и не отправляем: окно читает ответ, который клиент уже получил. Ожидания нет — индикатор без текста; ошибки окна нет (вызов не прошёл — окно не появляется). Системных слов («сервер», «синхронизация», «конвертация») в тексте нет.

## Technical debt
Тексты 7 языков кроме ru/uk написаны Дизайном и ждут проверки переводчика (docs/work/tasks/translations-from-design-2026-10-15.md, раздел для окна). Исчерпанные курсы и потолки живут на сервере; клиент ничего не считает сам.

## Verification
Контрактные тесты: строки только для монет > 0, итог = coins.total, нет запрещённых слов, ключ в арбитре, `kind none` ничего не рисует; съёмка по макету с dev-подменой `legacybonus=demo` (Ядро); сверка «макет | эмулятор» Сверкой.

## Rollback
Откат коммита; ключ арбитра и подключение на Главной убираются одной правкой, данных окно не пишет.
