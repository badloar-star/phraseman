# Главная в.2 — довести до бита по склейкам Сверки home4 (за флагом сцены)

Governance-ID: TG-AE62E746CD1C

## Outcome
Главная со «Сценой» совпадает со scenes-compact в.2: строки «Сегодня» (логи, почему строки урока нет), шапка карточки без серого круглого чипа ›, плитки с подписью ВНУТРИ плитки по CSS макета, «Фраза дня» одним рядом без перевода и целиком над нижней панелью без прокрутки, нижняя панель с подписями вкладок. Всё за `HOME_SCENE_V2_ENABLED`; без флага выпуск не меняется.

## Scope
In scope: `components/home/v2/HomeV2FeatureTiles.tsx` (плитки в режиме сцены), `components/home/v2/HomeV2TodayCard.tsx` (шапка нажимается целиком), `components/DailyPhraseCard.tsx` (без перевода со сценой), `components/home/v2/scene/home_scene_fit.ts` (высота сцены), `components/v2/V2TabBar.tsx` (подписи вкладок со сценой), `app/(tabs)/home.tsx` (журнал набора дня), тесты.
Out of scope: правило набора дня (D49 «3 типа из пула»), релизный флаг, «Сегодня»-экран и Пик.

## Architecture
Строка урока: набор дня — 3 типа из 6, детерминированно от (владелец, день) (`selectTodayTaskKinds`), поэтому урока в наборе может не быть — это правило D49, а не сбой; на Главной видео убрано, значит строк 2 и счётчик «0 из 2». Решение о составе набора — за владельцем (через координатора). Остальное — стили/раскладка под флагом.
