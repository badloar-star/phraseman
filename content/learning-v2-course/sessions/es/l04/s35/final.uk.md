# Іспанська · Урок 4 · Заняття 35 — Ця книжка велика

**Ситуація.** Показуєте другові книжку поруч із вами.
**Що ви опануєте:** ставити este перед назвою одного предмета чоловічого роду.
**Нові слова:** —
**Повторюємо знайомі слова:** este, libro, es, grande, nuevo, muy.

## Інтро 1

### Книжка перед вами

Показуєте другові велику книжку на столі. Скажіть `Este libro es grande` — «Ця книжка велика». Складіть `este libro` + `es` + `grande`. Тут este стоїть безпосередньо перед libro: разом вони означають «ця книжка». Іспанське libro чоловічого роду, тому потрібне este, хоча українське «книжка» жіночого роду.

**Скажіть про книжку поруч: «Ця книжка велика». Почніть з Este libro.**

- ✅ **Este libro es grande.** — *Este узгоджується з чоловічим libro.*
- ❌ Esta libro es grande. — *Libro чоловічого роду: este.*
- ❌ Este libro son grande. — *Книжка одна: es.*

## Інтро 2

### Нова книжка

Друг помічає вашу нову книжку. Скажіть `Este libro es nuevo` — «Ця книжка нова». Складіть `este libro` + `es` + `nuevo`. Замість grande поставте nuevo. Закінчення -o стосується чоловічого libro; українське «нова» не підказує іспанського закінчення.

**Скажіть про книжку поруч: «Ця книжка нова». Почніть з Este libro.**

- ✅ **Este libro es nuevo.** — *Чоловіче libro: nuevo.*
- ❌ Este libro es nueva. — *Nueva — жіноча форма; тут libro.*
- ❌ Esta libro es nuevo. — *Перед чоловічим libro потрібне este.*

## Інтро 3

### Дуже велика

Книжка поруч із вами ледве вміщується в сумку. Підкресліть розмір: `Este libro es muy grande` — «Ця книжка дуже велика». Складіть `este libro` + `es` + `muy grande`. Muy ставте безпосередньо перед grande: воно підсилює ознаку й означає «дуже».

**Підкресліть розмір книжки поруч: «Ця книжка дуже велика». Почніть з Este libro.**

- ✅ **Este libro es muy grande.** — *Muy стоїть перед grande.*
- ❌ Este libro es grande muy. — *Muy ставиться перед ознакою.*
- ❌ Este libro muy es grande. — *Поєднайте muy з grande після es.*

## Практика · 12 завдань

**1 · Послухайте та виберіть слово**
🔊 *este*
→ **este** · esta
- esta — *Звучить кінцеве e: este.*

**2 · Вставте слово — ця книжка поруч велика**
`___ libro es grande.`
→ **Este** · Esta · Estas
Повна фраза: **Este libro es grande.**
- Esta — *Libro чоловічого роду: este.*
- Estas — *Тут один предмет чоловічого роду: este.*

**3 · Зберіть фразу — ця книжка поруч велика; почніть з Este libro**
Плитки: `grande` · `libro` · `es` · `este` · `el`.
→ **Este libro es grande.**
*Плитка `el` зайва: перед libro вже стоїть este.*

**4 · Вставте слово — ця книжка поруч нова**
`Este libro es ___.`
→ **nuevo** · nueva · nuevos
Повна фраза: **Este libro es nuevo.**
- nueva — *Libro чоловічого роду: nuevo.*
- nuevos — *Книжка одна: nuevo.*

**5 · Зберіть фразу — ця книжка поруч нова; почніть з Este libro**
Плитки: `nuevo` · `libro` · `es` · `este` · `nueva`.
→ **Este libro es nuevo.**
*Плитка `nueva` зайва: libro чоловічого роду.*

**6 · Зберіть фразу — ця книжка поруч дуже велика; почніть з Este libro**
Плитки: `grande` · `muy` · `libro` · `es` · `este` · `son`.
→ **Este libro es muy grande.**

→ **Este libro es nuevo.**
*Плитка `esta` зайва: звучить este.*

→ **es** · son · soy

- son — *Книжка одна: es.*
