# Teoria · Lição 4 do curso novo — «There is, there are, some, any, in, on, under» (PT-BR)

> Sessão «12 · ТЕОРИЯ», 21.10.2026. Seções 01–14, frases em inglês e exercícios como em
> `lesson_04_ru.md`. As armadilhas do português: «Tem uma farmácia aqui» vira It has a pharmacy /
> Have a pharmacy here (o erro mais comum!); «Tem leite?» → Have milk?; «tem» serve para uma e para
> várias coisas (→ There is banks); «Tem leite» sem some; e «em/no/na» = in e on ao mesmo tempo
> (→ in the windowsill). Tratamento: você. Precisa de revisão de um falante nativo.

**Título da tela:** Teoria · O que tem onde

---

## 01 · O que você vai aprender a dizer *(aberta de início)*

**body**
Nesta lição você aprende a contar o que tem onde: «tem uma farmácia por perto», «tem leite na geladeira», «não tem campainha», «a chave está embaixo do capacho». A frase nova mais importante é There is: em português, é o «tem».

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There is a pharmacy here. | Tem uma farmácia aqui. | There is |
| There is some milk here. | Tem leite aqui. | some |
| Is there a toilet here? | Tem banheiro aqui? | Is there |
| There isn't a doorbell. | Não tem campainha. | isn't |
| The key is under the doormat. | A chave está embaixo do capacho. | under |

---

## 02 · There is — «aqui tem» *(aberta de início)*

**body**
Para dizer que algo existe num lugar, comece com There is. Em português é «tem», mas em inglês have não serve: Have a pharmacy here e It has a pharmacy estão errados. Diga There is a pharmacy here, e o lugar vai para o fim.

**formula**
`There is` · `a + coisa` · `onde`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There is a pharmacy here. | Tem uma farmácia aqui. | There is |
| There is a library nearby. | Tem uma biblioteca por perto. | There is |
| There is a bakery here. | Tem uma padaria aqui. | There is |
| There is an office upstairs. | Tem um escritório lá em cima. | There is |
| There is a clinic inside the building. | Tem uma clínica dentro do prédio. | There is |

**fix**
- ~~Have a pharmacy here.~~ → There is a pharmacy here.
- ~~It has a pharmacy here.~~ → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There aqui não quer dizer «lá». É só o começo de «tem». Por isso There is a pharmacy here é «tem uma farmácia aqui», e there e here não brigam.

---

## 03 · There are — quando são vários

**body**
Se são várias coisas, no lugar de is vai are, e a palavra ganha s: There are banks here. Em português «tem» não muda, em inglês muda. E, como na lição 3, com várias coisas não se usa a.

**formula**
`There are` · `coisas + s` · `onde`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There are banks here. | Tem bancos aqui. | There are |
| There are museums nearby. | Tem museus por perto. | There are |
| There are bridges nearby. | Tem pontes por perto. | There are |
| There are quiet streets here. | Tem ruas tranquilas aqui. | There are |
| There are parks nearby. | Tem parques por perto. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- frase: `There ___ museums nearby.`
- opções: `is` · `are` · `am`
- resposta: `are`
- por quê: São vários museus, então There are.

---

## 04 · O lugar vai no fim

**body**
Em português o lugar costuma vir primeiro: «Atrás do prédio tem um jardim». Em inglês é o contrário: primeiro There is e a coisa, e no fim onde: There is a garden behind the building. Assim você diz o que tem e depois explica onde.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There is a garden behind the building. | Atrás do prédio tem um jardim. | behind |
| There is a bench near the garden. | Perto do jardim tem um banco. | near |
| There is a church behind the bank. | Atrás do banco tem uma igreja. | behind |
| There is a market near the bridge. | Perto da ponte tem um mercado. | near |
| There is a lake behind the park. | Atrás do parque tem um lago. | behind |

**drill · word_bank**
- tarefa: Diga a um amigo: «Atrás do parque tem um lago».
- resposta: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- rótulos: nenhum (a frase é longa e dicas por ficha só atrapalham)
- fichas a mais: `are` · `in`

## 05 · Perguntar «tem?» e responder curto

**body**
Para perguntar se tem algo, troque as duas primeiras palavras de lugar: There is → Is there…? There are → Are there…? Resposta curta: Yes, there is. No, there isn't. Yes, there are. No, there aren't. Não use have: Have a toilet here? está errado.

**formula**
`Is there` · `a + coisa` · `onde` · `?` — `Are there` · `coisas + s` · `onde` · `?`

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| Is there a dentist near here? | Tem um dentista aqui perto? | Is there |
| Is there a toilet here? | Tem banheiro aqui? | Is there |
| Yes, there is. | Sim, tem. | there is |
| No, there isn't. | Não, não tem. | isn't |
| Are there trams near the bank? | Tem VLT perto do banco? | Are there |
| Yes, there are. | Sim, tem. | there are |
| No, there aren't. | Não, não tem. | aren't |

**fix**
- ~~Have a toilet here?~~ → Is there a toilet here?
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

## 06 · Leite, pão, manteiga: não se contam

**body**
Algumas coisas se contam: uma banana, duas bananas. Outras não: leite, pão, manteiga, açúcar. Antes delas não vai a, e no fim não tem s. Para dizer «tem um pouco», usa-se some: There is some milk. Em português «Tem leite» não pede nada, em inglês pede.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There is some milk here. | Tem leite aqui. | some |
| There is some bread near the basket. | Perto da cesta tem pão. | some |
| There is some butter near the bowl. | Perto da tigela tem manteiga. | some |
| There is some cheese here. | Tem queijo aqui. | some |
| There are some berries here. | Tem frutinhas vermelhas aqui. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
Com o que não se conta é sempre is, e não are: There is some milk, mesmo que em português pareça que tem «muito» leite.

## 07 · some ou any

**body**
some se usa quando você diz que algo tem. any, quando pergunta se tem ou diz que não tem. Em português quase nunca se traduz: «Tem sopa?» é Is there any soup? E nada de Have soup?: a pergunta se faz com Is there.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There is some milk here. | Tem leite aqui. | some |
| Is there any soup here? | Tem sopa aqui? | any |
| Are there any mushrooms here? | Tem cogumelos aqui? | any |
| There isn't any juice here. | Não tem suco aqui. | any |
| There aren't any carrots here. | Não tem cenouras aqui. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.
- ~~Have milk here?~~ → Is there any milk here?

**drill · choice**
- frase: `Is there ___ rice near the pot?`
- opções: `a` · `some` · `any`
- resposta: `any`
- por quê: Você pergunta se tem arroz ou não, então any.

## 08 · «Não tem»: There isn't, there aren't

**body**
Para dizer que algo não tem, acrescente not: There is not → There isn't, There are not → There aren't. De uma coisa — isn't a; de várias — aren't any. O «não tem» se faz com isn't ou aren't, e não com don't have.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There isn't a doorbell. | Não tem campainha. | isn't |
| There isn't an intercom. | Não tem interfone. | isn't |
| There aren't any handrails. | Não tem corrimão. | aren't |
| There aren't any steps. | Não tem degraus. | aren't |
| There isn't a lawn behind the building. | Atrás do prédio não tem gramado. | isn't |

**fix**
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.

**drill · binary**
- pergunta: Na porta não tem campainha. Como você diz?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- certa: A
- explicação: A campainha é uma só, então isn't.

## 09 · in, on, under — em, sobre, embaixo

**body**
in — dentro: in the sink, in the basement. on — em cima, numa superfície: on the worktop, on the windowsill. under — embaixo: under the doormat. Cuidado: o português usa «em» (no, na) para os dois. «Na mesa» é on the table, e não in.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| The lemon is in the sink. | O limão está na pia. | in |
| The bicycle is in the basement. | A bicicleta está no porão. | in |
| The cups are on the worktop. | As xícaras estão na bancada. | on |
| The plant is on the windowsill. | A planta está no parapeito. | on |
| The key is under the doormat. | A chave está embaixo do capacho. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The cups are in the worktop.~~ → The cups are on the worktop.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

## 10 · next to, between … and, near, behind

**body**
next to — colado, «ao lado de». near — perto, «perto de». behind — «atrás de». between … and — «entre … e …», são duas palavras para dois pontos de referência.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| The bench is next to the lamppost. | O banco está ao lado do poste. | next to |
| The signpost is near the bridge. | A placa está perto da ponte. | near |
| The ladder is behind the shed. | A escada está atrás do galpão. | behind |
| The bus stop is between the bank and the library. | O ponto de ônibus fica entre o banco e a biblioteca. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- frase: `The bus stop is ___ the bank and the library.`
- opções: `next to` · `behind` · `between`
- resposta: `between`
- por quê: São dois pontos de referência, o banco e a biblioteca, e o ponto fica no meio: between … and.

## 11 · There is ou The … is

**body**
There is é o «tem»: você diz que algo existe e a outra pessoa ainda não sabe. The … is é o «está»: a coisa já é conhecida e você diz onde ela fica: The lemon is in the sink. Primeiro o «tem», depois o «onde está».

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There is a car park near the hotel. | Tem um estacionamento perto do hotel. | There is |
| The barrier is near the gate. | A cancela está perto do portão. | The |
| There is a storeroom between the kitchen and the hall. | Entre a cozinha e o corredor tem um depósito. | There is |
| The coat rack is behind the door. | O cabideiro está atrás da porta. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- pergunta: Sua irmã procura o limão, que vocês duas conhecem. Ele está na pia. O que você diz?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- certa: B
- explicação: O limão já é conhecido e você diz onde está: The lemon is in the sink.

## 12 · A forma curta: There's

**body**
Na conversa, There is quase sempre vira There's: There's a cashpoint near the bank. Com There are não se faz isso, e o «não tem» encurta como sempre: isn't, aren't.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There's a cashpoint near the bank. | Tem um caixa eletrônico perto do banco. | There's |
| There's a postbox next to the gate. | Tem uma caixa de correio ao lado do portão. | There's |
| There's a vending machine in the hall. | Tem uma máquina de venda automática no saguão. | There's |

**tip**
O «sim» curto não se encurta: Yes, there is, e não Yes, there's.

## 13 · Os erros que quase todo mundo comete

**fix**
- ~~Have a pharmacy here.~~ → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~Have a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
Duas perguntas. Você diz que algo tem ou onde está uma coisa conhecida? «Tem» — There is / There are. «Está» — The … is. E a outra: uma coisa, várias, ou algo que não se conta?

## 14 · O que levar para a prática

**body**
«Tem» — There is a… / There are… / There is some… «Tem?» — Is there…? Are there any…? «Não tem» — There isn't a… / There aren't any… O lugar vai no fim: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | pt-BR | hi |
|---|---|---|
| There is a library nearby. | Tem uma biblioteca por perto. | There is |
| Are there any mushrooms here? | Tem cogumelos aqui? | any |
| There aren't any steps. | Não tem degraus. | aren't |
| The cups are on the worktop. | As xícaras estão na bancada. | on |
