**Владелец держит 10+ сессий ИИ одновременно на одной машине.** Из этого
следуют три жёстких правила:

1. **Перед тяжёлой работой возьми слот светофора.** Тяжёлое — субагенты,
   тесты, сборка, конвейер, массовый поиск по репозиторию.
   ```
   bash .claude/semaphore/slot.sh acquire "что делаю"
   ```
   Ответ `GO` — работай. `WAIT` — займись лёгким. Закончил — сразу
   `bash .claude/semaphore/slot.sh release`. Слотов всего 3.
2. **Не создавай ветки и worktree.** Все сессии пишут в одну ветку. Владелец
   не хочет мержить. Команда `git worktree add` заблокирована хуком.
3. **Git-индекс общий.** Коммить одной командой с явными путями:
   `git add -- content/learning-v2-course && git commit -- content/learning-v2-course`.
   Если индекс занят другой сессией — подожди и повтори, не ломай замок.

**Коммить часто, атомарно, в рабочую ветку.** Пуш не делай — владелец сам.

## 1. Почему предыдущая попытка провалилась

Прочитай `фабрика/ДИАГНОЗ_2026-09-03.md` целиком. Коротко: за 6 недель
накопили 3,2 МБ правил и 417 автопроверок — и не написали ни одного курса.
Тексты вышли сухими **именно из-за правил**.

**Вывод, на котором построена фабрика:** запреты дают сухой текст. Качество
задают **образцы** и **вердикты владельца**. Поэтому здесь пять страниц
правил вместо трёх мегабайт. Не возвращай старую систему, не добавляй новых
гейтов «на всякий случай».

## 3. Проверь свои модели. Не пропускай — результат неочевиден

У тебя другие модели, чем у нас. Повтори наши три проверки на своих.

**Автор.** Дай трём своим моделям написать одну сессию по
`фабрика/pipeline/prompts/author.md`. Сравни с эталоном. У нас слабая
модель стабильно проваливала юмор и ловушки, сильная — нет. Автором ставь
только ту, что держит планку.

**Судья вкуса — здесь ловушка, в которую мы попали.** Мы попробовали
сэкономить и поставили судьёй вкуса модель послабее. Она оказалась
**строже**: ставила «доработать» там, где сильная давала «принято». Это не
экономия, а лишние круги правки. Судья вкуса — только сильная модель.

**Ученик и педагог.** Работают на модели подешевле без потерь: первый
честно проходит урок, второй сверяет с машинными фактами, которые считает
скрипт.

Свои результаты запиши в `фабрика/judgements/` — следующая модель не будет
повторять твои опыты.

## 4. Пиши сессии

Одна сессия:
```
node pipeline/run.mjs full --session en/l01/s09
```
Несколько подряд (переживает лимиты и ночь):
```
node pipeline/run_batch.mjs --from en/l01/s09 --count 8
```

Что происходит внутри — читай `run.mjs`, там всё прокомментировано:

1. Три автора пишут три черновика с разными характерами.
2. Скрипт считает машинные факты (касания слов, объём, механики) и
   отсеивает слабейший черновик **бесплатно**, без модели.
3. Судья вкуса сравнивает оставшихся с эталоном парно.
4. Полный суд лучшего: ученик-новичок, редактор вкуса, педагог.
5. Редактор правит по трём вердиктам, суд повторяется (до 2 кругов).
6. **BLOCK любого судьи останавливает работу** — сессия не локализуется.
7. Локали одним пакетом, один судья на все.

Бэкенды: `--backend claude` (headless CLI), `api` (Anthropic API), `mock`
(без модели, проверить логику). Свой бэкенд добавь в функцию `callModel`.

**Промпты читаются с диска при каждом вызове** — правь `prompts/*.md` прямо
во время работы пакета, следующая сессия подхватит изменения. Перезапускать
пакет ради этого не нужно.

**Готовые черновики и вердикты не переписываются** при перезапуске: они
берутся с диска. Это экономит деньги, но если ты изменил правила и хочешь
переписать сессию с нуля — удали её папку в `sessions/`.

**Локали:** сейчас пишем только `ru` и `uk`. Остальные шесть дописываются
позже одним вызовом. Причина: локаль — чистая функция от мастера, а
написанная заранее выбрасывается при любой правке мастера.

## 7. Правила, которые нельзя нарушать

| Правило | Почему |
|---|---|
| Интро 220–260 знаков | Владелец: «есть риск переутомлять текстами» |
| Шутка на каждой странице интро | Страница без шутки — дефект, даже короткая |
| Английский в обратных кавычках | Красится цветом, чтобы отличался от объяснения |
| Одна сквозная сцена на сессию | Ученик должен понимать, зачем говорит фразу |
| Никаких «вчера / сегодня / вы уже учили» | Человек проходит сколько угодно сессий подряд |
| Ловушки — реалистичные ошибки | `I is fine` можно (так ошибаются), `Fine I am` нельзя |
| Только 8 механик приложения | Новых режимов нет: диалог, печать, «найди ошибку» отложены |
| Заданий 12–20, ориентир 17 | |
| Возвращаемое слово ≥2 касаний | И хотя бы раз правильным ответом |
| Без грамматических терминов | «слово-скрепка», а не «глагол-связка» |

Полный список — в Конституции. Если правило кажется странным, ищи причину в
`judgements/owner/`: почти каждое выросло из конкретного разбора.

## 9. Как отчитываться владельцу

- Всегда по-русски.
- В конце каждого ответа — короткий итог простым языком, списком, без
  технических терминов. Без него ответ не считается законченным.
- Не отчитывайся «готово», не проверив. Если тест не прогнан — так и скажи.
- Нашёл проблему — сначала логи в это место, потом починка по фактам.
  Гадать и «чинить похожее место» запрещено: так уже терялись круги работы.

## 11. Что мы выучили дорогой ценой

- **Контекст дороже письма.** Одна сессия стоила $8.70, и почти всё — это
  повторное чтение одних и тех же правил в каждом вызове: 704 тысячи
  токенов из кэша против 52 новых. Сжали контекст и объединили вызовы —
  стало вдвое дешевле. Всегда смотри, что читает каждый вызов.
- **Судьи ловят то, чего не видит автор.** Три независимых судьи нашли
  смысловую ошибку, которую автор пропустил: задание просило сказать «я не
  прав», а верным считался ответ с обратным смыслом.
- **Свежая память обязательна.** Судья, видевший, как писался черновик,
  судит предвзято. Каждый судья — отдельный вызов, ничего не знающий об
  авторе.
- **Считай машинно то, что можно посчитать.** Касания слов, число заданий,
  разрешённые механики считает скрипт — судьям остаётся смысл.
- **Пустой экран — всегда чья-то ошибка.** Не списывай на среду: ставь
  логи и доводи до причины. Мы один раз списали и потеряли время.
