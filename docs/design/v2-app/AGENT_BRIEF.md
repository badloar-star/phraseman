## Жёсткие правила
- Цвет: графит, белый, серый. НИКАКОГО жёлтого/золотого/тёплого/оранжевого. Главная кнопка — белая `.cta`.
- Шрифт: только Inter (уже в kit.css). Никаких засечек, никаких других шрифтов, никаких Google Fonts.
- Размеры, радиусы, плашки, строки, пилюли, шторки — как в etalon.html. Новое рисуй в той же манере.
- Телефон 430×932 (`K.phone`). Ничего не налезает, ничего не обрезается краем экрана, текст влезает,
  нижние элементы выше полоски «домой». Кнопка звука не сдвигает центр текста.
- Монеты — только файлы `assets/coin_rank_00..19.webp` через `K.coinImg(rank, size)` / `K.coins(n)`
  (круглые, без подложек). Энергия — `K.energy(n)`, максимум 5.
- Опыта (XP) нет. Подарков, спинов, сундуков, жемчуга, Арены, аур — нет.
- Язык — везде одна кнопка выбора с флагом.
- Не рисовать состояний, которых нет в продукте. Не менять Главную (её не трогаем вообще).
- Каждая кнопка — класс `.t` (живое нажатие). Шторки — `K.sheet(id, html, open)` + `data-open` / `data-close`.
- Тексты по-русски, коротко, человеческим языком.
