## Architecture

No architecture change: только числа и анимации внутри существующих компонентов. Бесконечная анимация
волны работает только при `useRuntimeActive()` (экран в фокусе и приложение активно) и уважает
«уменьшить движение». Кривые создаются на уровне модуля. Панель навыков общая для итогов игр и карточек —
правка меняет все эти итоги одинаково.

Не применимо: только анимации, нет данных, сети и ввода.
