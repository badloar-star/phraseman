# Запечённые ассеты сцены Главной: фон сцены и маски теней плит

Governance-ID: TG-8CAF0CA4E1E2

## Outcome
Владелец одобрил план ускорения первого кадра Главной. Моя часть (координатор): скрипт, который из токенов тем запекает (а) фон сцены WebP — 23 темы × 2 оформления × день/вечер, (б) маски теней плит в обеих яркостях; вывод в `assets/`, таблица «тема → файл», сторож «каждый файл есть и совпадает с токенами», цель — совпадение с нынешним рендером (в пределах 8-битной точности). Подключение в Главную и авто-Lite — 3 · МАКЕТЫ.

## Scope
In scope: `scripts/lib/scene_backdrop_math.ts`, `scripts/gen_scene_assets.mts`, `assets/images/v2scene/*`, `components/home/v2/scene/home_scene_baked_assets.generated.ts`, сторож `tests/home_scene_baked_assets.test.ts`.
Out of scope: правки `HomeSceneStage`/плит/`V2TabBar` (3 · МАКЕТЫ), авто-Lite.

## Architecture
Фон сцены = нормализованная функция от размеров (диагональный градиент `start(0.22,0) → end(0.78,1)` + радиальный свет `sceneLight`), поэтому маленький растр 232×225 (пропорции между типичными сценами 411×425 и 390×358: диагональный градиент считается в пикселях и не инвариантен к растяжению) растягивается на любую сцену без потери вида. Отдельно запекаются обобщённые детали: `scene_halo` (белый ореол 22 %), `scene_ember` (угли вечера), `scene_scrim` (затемнение низа 0→40 %). Тени плит — белые маски альфы (пик 1,0) трёх классов (плитка 86×92 r20, «Сегодня» 358×209 r28, «Фраза дня» 358×80 r18) для слоёв темы: тёмная (16,28,−14), светлая (14,26,−14) и светлая мягкая (1,3,0); цвет и прозрачность даёт tintColor из токенов `plateShadow` / `plateShadowSoft`.

## Security and privacy
Данных не касается; ассеты генерируются из токенов тем.

## Technical debt
Маски растягиваются целиком (без 9-slice) на ±15 % — на размытой тени незаметно; если появятся плиты сильно другого размера, добавить класс в скрипт.

## Verification
Сторож: файл существует для каждого ключа, растянутый растр совпадает с аналитическим расчётом по токенам в пределах 4/255 на размерах 360×320, 390×358, 411×425, а сохранённый файл совпадает с пересчитанным в пределах 1/255.
