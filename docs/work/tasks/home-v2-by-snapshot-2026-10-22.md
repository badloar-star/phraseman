# Главная по снимку Сверки home3 против scenes-compact, вариант 2

Governance-ID: TG-D21B613CF41C

## Outcome
Главная (со «Сценой») совпадает с макетом scenes-compact.html в.2: белая карточка «Сегодня · N из M» (радиус 28, наезд на сцену 22) с крупным тёмным заголовком внутри, три строки без «Посмотреть видео» (анкета — 4-й строкой только при активной кампании из админки, Poll V2 на Главной не показываем), плитки по порядку Уроки · Карточки · Диалоги · Пик, «Фраза дня» карточкой с картинкой слева и шевроном. Обе темы. Решение владельца 22.10, поручение координатора; 3 · МАКЕТЫ подтвердил, что в Главной не работает.

## Scope
In scope: `components/home/v2/HomeV2TodayCard.tsx` (режим «сцена»), `app/(tabs)/home.tsx` (передача режима, три строки, порядок плиток, без Poll V2), `components/DailyPhraseCard.tsx` (карточка homeV2), `components/home/v2/today_scene/today_scene_copy.ts` (экспорт «N из M»), сторож `tests/daily_phrase_v2_text_integrity_source_contract.test.mjs`.
Out of scope: сцена Главной (скругление 32 уже в c1d6870a7), чужие строки анкет в home.tsx (коммитятся владельцем), релизный флаг сцены.

## Architecture
Режим «сцена» включается пропом `scene` (только при `HOME_SCENE_V2_ENABLED`); без него карточка рисуется прежней. Заливка карточки — `opaqueCard` темы, тень — общая «Тень». Строки — те же, что были, без плашек, разделитель — тонкая линия сверху. Порядок плиток — сортировка по ключам при включённой сцене.
