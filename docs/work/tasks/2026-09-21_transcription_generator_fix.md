# Task packet: карточки перестают показывать выдуманную транскрипцию

Status: In progress
Owner: сессия Claude (21.09.2026)
Related epic/enabler: none

## Outcome

Пользователь написал в поддержку: на карточке `Where do we meet guests?` транскрипция
`guests` показана как `/gdʒʌːsts/`, хотя правильно `/ɡests/`. Замечание верное.

Наблюдаемый результат после задачи: на карточках сохранённых фраз не появляется
транскрипция, выдуманная правилами. Либо показывается корректная (словарь или
надёжное правило), либо не показывается ничего. Мера успеха — слова из
контрольного списка (`guests`, `girl`, `school`, `ghost`, `two`, `know`, `heart`,
`debt`, `question`, `picture`) либо транскрибируются верно, либо отсутствуют.

## Scope

In scope:
- `app/transcription.ts` — словарь, правила, порог доверия, версия генератора.
- `app/flashcards/useCollectionData.ts` — перегенерация транскрипции у уже
  сохранённых карточек, где лежит мусор от старой версии.
- тест-сторож на контрольный список слов.

Out of scope:
- транскрипция в Learning V2 и в наборах сообщества (там тексты авторские,
  не генерируются этим модулем);
- переход на полноценный словарь CMUdict/онлайн-сервис — это отдельная задача,
  здесь только чистка вранья.

## Architecture

Текущая граница: `getTranscription(text)` обязан вернуть непустую строку для
любого ввода («Guarantees a result for every non-empty English string») — отсюда
и вранье: неизвестное слово прогоняется через `ruleBasedIPA`, который
для английской орфографии заведомо неадекватен (замер: 40+ мусорных выдач
на списке из 70 частотных слов).

Интендед: гарантия меняется с «всегда что-то» на «всегда правда либо ничего».
`getTranscription` возвращает пустую строку, когда уверенности нет. Потребители
уже готовы к пустому значению (`useCollectionData` проверяет `if (tr)`,
`widget_bridge` — `firstNonEmpty`, редактор кладёт `|| existing?.transcription`).

Инвариант: транскрипция сохраняется в документ карточки, поэтому у генератора
появляется версия `TRANSCRIPTION_ENGINE_VERSION`; карточка, записанная старой
версией, перегенерируется один раз при следующем открытии коллекции.

## Security and privacy

Не применимо: модуль полностью офлайновый, работает со строкой английской
фразы, не обращается в сеть, не читает и не пишет персональные данные, не
требует разрешений. Политику приватности менять не нужно.

## Technical debt

- Pay now: немой `u` после `g`, `kn-/wr-/gh`, `-tion/-ture/-sion`, мягкая `g`,
  `ea/ear/ear`, удвоенные согласные — чинятся в этой задаче.
- Contain: правило-генератор остаётся приблизительным. Граница — порог доверия
  плюс сторож со списком слов; выход — замена на нормальный словарь произношений.
  Ratchet: список контрольных слов может только расти.
- Accept temporarily: словарь покрывает A1–B2 и системные карточки, редкие слова
  останутся без транскрипции. Владелец, ревью при следующем репорте от
  пользователей. Потолок влияния — отсутствие подсказки, а не ложная подсказка.

## Verification

- `npx jest tests/transcription_no_invented_ipa.test.ts --runInBand --watchman=false`
  — контрольный список: каждое слово либо даёт ожидаемую транскрипцию, либо пусто;
  ни одно не даёт мусорную последовательность.
- `npx tsc --noEmit` точечно по затронутым файлам.
- Ручная проверка: открыть «Сохранённые», убедиться, что `guests` показывает
  `/ɡests/`, а карточки без уверенной транскрипции показывают только текст.

## Rollback

Изменение чисто клиентское и не мигрирует данные деструктивно: перегенерация
только заполняет поле `transcription` заново. Откат — вернуть предыдущую версию
файла; уже перезаписанные карточки останутся с корректной транскрипцией, потери
пользовательских данных нет. Ни одна выданная покупка/подписка не затрагивается.
