# modifier_very_really_quite

Jesse rewrite for `modifier_very_really_quite`.

## Scope

- Category: `modifier`
- Status: `active`
- Priority: `35`
- Locales: `ru`, `uk`
- Main contrast: `very useful` vs `really tired` vs `quite good` vs `too hot`

## Learner problem

The learner treats `very`, `really`, `quite`, and `too` as one generic "very" bucket. The training now separates tone:

- `very` = neutral strength
- `really` = more conversational and stronger
- `quite` = softer / moderate positive evaluation
- `too` = excessive, already a problem

## Contract anchors

- `modifier_vrq_easy_001`: wrong `very much` feedback contains `very useful`.
- `modifier_vrq_contrast_001`: wrong `really much` feedback contains `really tired`.
- `modifier_vrq_contrast_004`: wrong `too` feedback contains `quite good`.
- `modifier_vrq_mixed_001`: wrong `too` feedback contains `very hot`.
- `modifier_vrq_mixed_006`: wrong long sentence feedback contains `really useful / quite difficult`.
