# B3A target-scoped immutable-attempt authority amendment

`ATTEMPT_NAMESPACE_ONLY / ACCEPTANCE_HOLD / TARGET_DE_ONLY`

This amendment supersedes the prior immutable-attempt authority only where it
described English Learning V2 paths as snapshot inputs. A B3A attempt is a
German-target acceptance procedure. Its snapshot, guardian, P, reviews, F and
immutable-anchor proof bind exactly the German B3A closure named by the
immutable-attempt gate.

English paths are not attempt inputs. Any English path presented in an attempt
snapshot or closure is rejected before that path is read. The gate neither
hashes, baselines, stages, cleans, changes nor attributes English content.
Existing English work therefore remains untouched and outside B3A authority.

All remaining constraints are unchanged: there is no attempt directory or
acceptance claim in this amendment; B3 remains not established; rows remain
zero; Task 7, learner authoring, mockup, audio, runtime and release remain
HOLD; and no production action, API-key use, deletion, reset or staging is
authorized.
