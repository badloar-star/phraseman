# Локальные инструменты документации
Python 3.10+. Зависимости — только стандартная библиотека. Нет сетевых запросов, API, ключей, Git-операций или изменения приложения.

## Команды
`python tools/make_prompt.py PM-001` — напечатать промпт одной задачи с выбранной моделью. Не запускает Codex.

`python tools/render_views.py` — пересоздать tasks/*.md, epics/*.md, 06_TRACEABILITY.md, 02_MASTER_PLAN.md и board.html из реестров. Производные файлы перезаписываются; свои заметки хранить в tasks.json/notes, worklog или отдельном evidence, а не только в Markdown-карточке.

`python tools/validate.py` — проверить IDs, взаимные связи, источник/выдержку, файлы спецификаций, DAG, модели и правила accepted/done. Никаких тестов приложения не запускает.

`python tools/validate.py --manifest` — дополнительно проверить hashes исходной выдачи. После разрешённых правок документации MANIFEST выдачи закономерно перестаёт совпадать: сохранить его как историю и создать новый version manifest, а не считать любое изменение порчей.

## Как менять статус
В `registries/tasks.json` выбрать точный id. Указать owner, audit_sha, actual_model, actual_reasoning, notes. Статус in_progress не означает принятые критерии. Для каждого принятого критерия записать evidence и accepted=true; оставшиеся остаются false. Историю добавлять в `registries/worklog.jsonl`, не стирать старые строки.

Done допускается только после всех принятых критериев, общего evidence, reviewer, review_verdict=PASS, фактических model/effort и gate_evidence для каждого применимого gate. Перед завершением классифицировать kind: code / audit / documentation / design / decision. Для code нужен result_sha; некоммитированный diff может быть review, но не done. Если gate неприменим после аудита, явно изменить его с мотивировкой и review, а не оставить пустое значение.

Evidence — пути к реальным отчётам/скриншотам/trace/коммитам либо точное решение владельца. Валидатор проверяет наличие записей и структуру, но не способен доказать правдивость произвольного текста отчёта. Это задача независимого reviewer.

При read-only роли не сохранять изменения. Вернуть предложенный JSON-diff владельцу записи. Примеры Codex отдельно и не активируются этими скриптами.
