## 0. Подготовка (один раз)

Ссылки открываются так (dev-сборка, эмулятор `emulator-5554`):

```bash
adb -s emulator-5554 shell am start -W -a android.intent.action.VIEW -d "phraseman://dev_state?moments=v3&next=/(tabs)/home" app.phraseman
```

- `moments=v3` — dev-переключатель (только `__DEV__`, ключ `dev_moments_v3_override`). С 4f8a07461 флаг и так включён, но переключатель
  убирает зависимость от кэша конфига. `moments=off` — проверка, что всё прячется; `moments=inherit` — снять подмену.
- Журнал: `.expo/metro-console.log` (или `adb logcat -s ReactNativeJS`). Ищем по префиксам из таблицы.

  `[MOMENTS-V3-FLAG] {"source":"screens","remote":"absent","cache":"есть",...,"effective":true}`. Ворота окон Главной пишут то же
  со своим `source`: `spire_week`, `coin_rank_enough`, `welcome_back`.
