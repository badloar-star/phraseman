## Решение 1 — «Входящие» без inboxRev

peekInboxRev отдаёт 0, когда документ прочитан, а поля нет (личных сообщений от сервера не было). Раньше 0 = «версии нет»:
копия не сохранялась, каждые 6 ч перечитывались user_messages и app_message_states (до 80). Теперь 0 — настоящая версия,
но копия с версией 0 живёт не дольше суток (страховка, пока Ядро не выложило счётчик на сервер: личное сообщение старого
сервера дойдёт ≤ 24 ч); после выкладки любая запись поднимает версию → перечит сразу.
