## 2. ЧТО НЕ РАБОТАЕТ

### P1.1 — `club_boost_free` («Буст клуба бесплатно») ПОЛНОСТЬЮ СЛОМАН ❌

Подарок (rare, weight 6 — выпадает часто) обещает «следующая активация буста в клубе без осколков». Фактически:

- Выдача пишет флаг `club_gift_free_boost_v1` (`app/club_boosts.ts:522`, вызов из `level_gift_system.ts:1295` и `global_broadcast_modal.ts:323`).
- Флаг читается ТОЛЬКО для отображения чипа в инвентаре (`app/level_gift_active_inventory.ts:151`).
- `hasClubGiftFreeBoostFromLevel()` (`club_boosts.ts:514`) — **ни одного вызова в коде**.
- `clearClubGiftFreeBoostFromLevel()` (`club_boosts.ts:528`) — **ни одного вызова в коде**.
- Экран клуба всегда списывает полную цену `LEAGUE_GROUP_BOOST_COST_SHARDS` (`app/club_screen.tsx:1007-1018`), флаг не проверяется.

Итог: юзер получает подарок, видит вечный чип «бесплатный буст» в инвентаре, платит полную цену. Эффект не потребляется и не сгорает никогда.

**Фикс:** в `club_screen.tsx` перед списанием проверить `hasClubGiftFreeBoostFromLevel()` → пропустить списание → `clearClubGiftFreeBoostFromLevel()`. Учесть, что активация идёт через CF `leagueActivateGroupBoost` (там серверное списание из аудита экономики) — серверу нужен признак ваучера, иначе фикс только клиентский.

### P1.2 — `hint_1` / `hint_3` не доходят до урока на французском курсе ❌ (для fr)

- Запись: `applyGift` пишет в `lessonBonusHintsKey(today, opts?.studyTarget)` (`level_gift_system.ts:1217`), модалки передают активный target (`LevelGiftDualModal.tsx:427`). Для fr ключ неймспейсится (`target_storage_keys.ts:249-252`: fr → `targetKey(...)`, иначе legacy).
- Чтение: единственное место — `lesson1.tsx:2277` `getBonusHintsToday()` **без аргумента** → всегда legacy-ключ (en).

Для en всё совпадает; для французского курса (voyazh) подарок записан, но урок его никогда не видит. Фикс — однострочник: передать активный studyTarget в `getBonusHintsToday(...)` в `lesson1.tsx`.

### P2.1 — Реферальный подарок (7 дней VIP) мёртв в проде ⚠️ (известно)

Код клейма цел и безопасен (`referral.ts:422-555`, транзакция, идемпотентно, кап 30/мес), но `referral_enabled` в Remote Config дефолт `false` (`app/remote_flags.ts:60`) — весь UI скрыт. Включается в админке + деплой invite-страницы (см. memory).

### P2.2 — Push о подарке друга только на русском ⚠️

`friend_gifts.ts:424-431`: заголовок «🎁 Подарок от друга!» и `giftLabelRu` захардкожены по-русски для всех локалей получателя.

### P3 — мелочи

- `firestore.rules:126-131`: владелец может **сам создать** запись в своём `shard_rewards` с `reason:'friend_gift'` → фейковые «подарки от друзей» в своём инбоксе (информационный обман, денег не даёт).
- `friend_gifts.ts:183-231`: legacy edge — для аккаунтов без `firebaseAuthUid` проверка отправителя опирается на `senderStableId === auth.uid`; self-gift через две identity одного юзера технически возможен. `enforceAppCheck: false` (как и везде — App Check глобально не энфорсится).
- `level_premium_pack_unlock_gifts_v1` (анти-повтор pack-unlock подарков) не в `SYNC_KEYS` `cloud_sync.ts` → при смене устройства премиум может получить тот же набор повторно (не критично, `addOwnedPackId` идемпотентна).
- Непринятые подарки `unclaimed_level_gifts*` и `energy_gift_bonus` не синкаются между устройствами (похоже на замысел — задокументировать).
- Тесты milestone-подарков не покрывают уровни 10, 30, 50 (`tests/level_gift_milestones.test.ts`).
- Сундук лиги хардкодит `packId:'league_bonus_voucher'` (`league_chest.ts:337`) против случайного на клиенте — на доступ не влияет, чисто косметика истории.
- Milestone-подарки определены только до 50 уровня — дальше только рандом, юзер теряет «вехи».

## 3. Что работает (проверено)

- 35 из 37 level-подарков работают полностью end-to-end (эффект реально потребляется): энергия, XP, осколки, XP-банк ×2, фокус-множители, ×2 на 24/48ч, заморозка стрика, арена +5, скидка пари (одноразовая, сгорает при ставке — `streak_wager.ts:136,251`), аватары/ауры, ваучеры 48ч, pack-unlock навсегда, выбор из 3.
- Сундук лиги: ролл серверный, сид детерминирован, клейм идемпотентен (`league_chest_claims`), клиент не может выдать себе награду.
- Подарки друзьям: баланс и списание серверные в транзакции, лимиты 3/день и 1/другу/день, самодарение заблокировано, эффекты атомарны, двойного начисления нет, push после коммита.
- Ежедневные задания: клейм идемпотентен, двойной тап защищён.
- Ваучер набора: одноразовый, реально сгорает при активации (`cardPackShardPurchase.ts:97`).
