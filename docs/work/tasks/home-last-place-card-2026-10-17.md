# Task packet: Главная — карточка «последнее место» (урок / V2 / диалог / карточки)

Governance-ID: TG-77E0023EAB5B
Status: In progress
Owner: сессия «2 · ДИЗАЙН»
Related epic/enabler: R09 (карточка «Продолжить» V2), P23 (метки продолжения)

## Outcome
Слово владельца 17.10 (через координатора): над плитками «Уроки / Карточки / Диалоги» стоит карточка места, где человек был последним: занятие V2, урок классического курса, диалог или набор карточек; тап — сразу туда. Нет ни одной записи — «Начать урок 1» (новые уроки). Запись устарела — тихий откат с логом `[HOME-CONTINUE]`.

## Scope
In scope: `app/home_continue_mark.ts` (метки «диалог» и «карточки», выбор самого свежего из четырёх, проверка на устаревание, подписи), `app/(tabs)/home.tsx` (карточка), `components/home/v2/HomeV2ContinueCard.tsx` (вид без полосы прогресса), точки входа: `app/ai_dialog_session.tsx` (старт диалога), `app/flashcards_training_setup.tsx` (старт тренировки карточек), новый сторож `tests/home_continue_places_contract.test.ts`.
Out of scope: Firestore (ничего не читаем и не пишем), новые экраны, макет (заказан у Макетов координатором), смена существующих меток урока и V2.

## Architecture
Расширение существующего «Продолжить», а не вторая карточка: к меткам `v2` и `legacyAtMs` добавлены `dialog` и `cards` — `{id, title, subtitle, route, atMs}`, AsyncStorage + память процесса, чистятся при смене аккаунта. `pickHomeContinue` выбирает самое свежее из четырёх (при равенстве V2 > диалог > карточки > старый урок). Главная получает уже проверенные метки из `resolveHomeContinuePlaces` (раздел виден для языка; сценарий диалога существует; название диалога — по текущему языку, каталог сценариев грузится лениво только при наличии метки). Тап: диалог → `/ai_dialog_briefing?scenarioId` (свои проверки доступа), карточки → `/flashcards_training_setup?mode=` (предвыбор последнего набора и проверка квоты, прямой запуск сессии её обошёл бы), «Начать урок 1» → карта V2 (при рубильнике — меню урока 1). Первый кадр — из памяти, без сети; прежняя ветка урока/V2 с заглушкой и закреплёнными строками сторожей оставлена нетронутой, новая карточка стоит отдельным блоком с той же геометрией.

## Security and privacy
Данные только локальные, на устройстве (id сценария, названия наборов карточек пользователя, время). Ничего не уходит в сеть и не попадает в аналитику. Названия наборов — пользовательские данные: чистятся при смене аккаунта (как метки V2). Политика приватности не меняется.

## Technical debt
Contain: метка карточек хранит выбор наборов одной строкой и название первого набора; если набор удалён, тап ведёт на экран выбора (он сам предвыберет доступное). Нужен макет карточки для диалога/карточек/«Начать» (Макеты). Тексты на 9 языках (плашки «Диалог»/«Карточки», «Начать урок 1») — мой черновик, нужна сверка Переводчика.
