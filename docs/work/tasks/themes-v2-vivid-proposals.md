# Task packet: яркие («атмосферные») двойники тем 2.0 — макеты на выбор владельцу

Governance-ID: TG-95609037839A
Status: In progress
Owner: дизайн-сессия тем (Claude), 2026-09-30
Related epic/enabler: PhraseMan 2.0 — темы (THEMES_DESIGN.md, решение «все темы бесплатны» 30.09)

## Outcome

Владелец видит HTML-макеты, где тема заметно меняет интерфейс, а не только оттенок фона.
Решения владельца 30.09:
- сила — «атмосферная»;
- красятся кнопки и выбор, таббар и навигация, прогресс и кольца, фон и иконки плиток, огонь серии и молния;
- монеты и «верно / ошибка» не красятся;
- у каждой из 13 тем есть яркий двойник со своим характером: камень, природа, металл или ночь;
- на экране «Темы» сверху переключатель «Тонко / Ярко»;
- одна светлая тема на пробу.

Успех: владелец выбирает или правит вариант, а до / после видно на одних и тех же экранах 2.0.

## Scope

In scope: новые файлы в папке макетов Codex (вне git):
- themes-v2-proposals.html/.css/.js;
- копии иллюстраций приложения в v2p/.

Экраны: Главная, урок, карточки, Шпиль (ступень), пейвол, «Темы».

Out of scope:
- код приложения;
- одобренные макеты и темы (kit.*, theme-tokens.js, themes.*, liquid-glass.*, страницы каталога) — не меняются;
- названия ярких тем — только рабочие, выбор за владельцем.

## Architecture

No architecture change: только макет. Яркая тема — CSS-слой в обёртке .vv[data-vivid] поверх общего kit, одобренные токены не трогаются. «До» рисуется через штатный data-fixed-theme.

## Security and privacy

Нет сети, аккаунта и персональных данных. Параметры URL (v, only) проходят проверку по белому списку.

## Technical debt

Accept temporarily: перенос в liquidGlassThemePalette.ts и в компоненты — отдельная задача после одобрения. Владелец — сессия переноса. Условие выхода — одобренный вариант.

## Verification

Headless-скриншоты Chrome каждого состояния (по одному процессу, через светофор), просмотр глазами до выдачи. Контраст текста на кнопках не ниже 4.5:1.

## Rollback

Удалить новые файлы из папки макетов; одобренные файлы не изменялись.
