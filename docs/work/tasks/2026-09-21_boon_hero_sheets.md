## Outcome

Пять «тихих» бонусов дня (`streak_saver`, `energy_free_window`, `turbo_regen`,
`flashcard_friday`, `speaking_saturday`) открываются модалом того же класса, что
вчерашний `DoubleRewardSheet` для Супервоскресенья: объёмный SVG-герой с
металлическим градиентом и 3D-разворотом, орбита, блик, каскадное появление
текста, строка из двух фактов.

Наблюдаемый результат: человек, которому сегодня выпал щит серии или окно без
энергии, видит такое же дорогое празднование, как в воскресенье, а не серую
иконку-заглушку `RetiredRasterFallback`.

Мера успеха: ни один из пяти бонусов не рендерит `RetiredRasterFallback`;
у каждого свой узнаваемый символ; тесты на контракт зелёные.

## Scope

В scope:
- новый `components/boon_hero/BoonHeroEmblem.tsx` — пять SVG-символов на общем
  движке градиента (щит, молния, двойная шевронная стрелка, стопка карточек,
  звуковая волна);
- новый `components/BoonHeroSheet.tsx` — каркас модала (герой + кикер +
  заголовок + описание + две графы фактов + CTA), построенный на уже
  существующем `HybridSheetShell`;
- `app/boons/boon_facts_copy.ts` — две графы фактов на бонус, 9 языков;
- `components/BoonActivatedSheet.tsx` — маршрутизация пяти id на новый модал;
- `tests/boon_hero_sheet.test.tsx` — контракт.

Вне scope:
- сундуки (`mystery_monday`, `perfect_week`, comeback, подарок за уровень) —
  у них свой утверждённый язык объёмного сундука, он уже дорогой;
- `DoubleRewardSheet` — эталон, не трогаем;
- экономика бонусов: движки решают, что активно и на сколько. Модал только
  показывает.

## Architecture

Текущая граница: `BoonActivatedSheet` — развилка. `double_xp` уходит в
`DoubleRewardSheet`, остальные шесть — в локальный `OtherBoonActivatedSheet`
с иконкой-заглушкой.

Целевая граница: развилка расширяется. Пять id уходят в `BoonHeroSheet`,
`double_xp` остаётся в `DoubleRewardSheet`, `mystery_monday` сохраняет прежний
путь (он в норме сюда и не попадает — его показывает `MysteryMondayHost` через
сундук), но fallback остаётся рабочим, чтобы ни один id не остался без экрана.

Инвариант, который нельзя нарушить: модал — **чистая презентация**. Он не
начисляет, не списывает и не гасит право на награду. Бонус активен ДО монтажа
поверхности; закрытие только отпускает владение оверлеем. Это прямо записано в
шапке существующего `BoonActivatedSheet` и сохраняется дословно.

Второй инвариант — правило владельца «празднование не ставится в durable-очередь»:
новый модал ничего не пишет в AsyncStorage и не заводит долг на показ.

Решение по архитектуре: общий движок градиента и анимации вынесен один раз,
различается только `Path` символа. Пять копий анимации были бы долгом.

## Security and privacy

Не применяется, и вот почему: изменение целиком в слое отрисовки. Нет сети, нет
Firestore, нет новых полей профиля, нет разрешений устройства, нет сторонних
сервисов, нет персональных данных, нет данных детей. Privacy policy не
затрагивается — новых категорий данных не появляется.

## Technical debt

- **Pay now.** `RetiredRasterFallback kind="boon"` уходит из пути пяти бонусов
  вместе с заглушкой — это и был долг («ретированный растр»).
- **Contain.** `OtherBoonActivatedSheet` остаётся как fallback для любого id вне
  пятёрки. Граница: тест перечисляет пять id и ловит появление шестого.
  Условие выхода: когда `mystery_monday` окончательно закрепится за сундуком,
  fallback можно снести целиком.
- **Accept temporarily** — нет.

## Verification

1. `npx jest tests/boon_hero_sheet.test.tsx --runInBand --watchman=false` —
   каждый из пяти id рендерит свой символ (testID эмблемы), две графы фактов
   непусты, CTA закрывает шторку ровно один раз.
2. `npx jest tests/double_reward_sheet.test.tsx --runInBand --watchman=false` —
   эталон Супервоскресенья не задет.
3. `npx tsc --noEmit` точечно по затронутым файлам.
4. Доступность: герой декоративный (`importantForAccessibility="no-hide-descendants"`),
   заголовок несёт `accessibilityRole="header"`, у CTA есть label и hint,
   `maxFontSizeMultiplier={2}` на каждом тексте.
5. Reduce motion: при включённом системном «меньше движения» блик не рендерится,
   прогресс сразу равен 1, контент виден целиком (та же ветка, что в эталоне).
6. Ручной проход: DEV Hub → сцена празднований, по одному на каждый бонус.

Артефакт: вывод jest по двум файлам.

## Rollback

Откат — одна строка: вернуть в `BoonActivatedSheet` безусловный
`OtherBoonActivatedSheet` для всех id, кроме `double_xp`. Новые файлы остаются
на диске и никого не ломают.

Пользовательских данных изменение не касается, права на награду не выдаёт и не
отзывает, поэтому откат не может ни потерять прогресс, ни отобрать уже
начисленный бонус.
