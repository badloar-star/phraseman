# Диалоги: аудит раздела и макеты редизайна (2026-09-14)

Заказ владельца: полный аудит раздела «Диалоги» глазами пользователя, макеты
нового раздела (каждый экран, каждая шторка, по три варианта), разговорный
клуб с наградами за удачные диалоги и особый «Диалог с тутором» на обучающем
каркасе MAX без голоса и без realtime.

Макет: `index.html` (одна страница, обычный скролл, телефоны реального
размера 390×844 с прокруткой внутри; по одному выбранному варианту на экран,
кроме урока в процессе, где три варианта ждут решения).

**Решения владельца по экранам (2026-09-14, второй круг):**
- Экран разговора: вариант Б; у реплики собеседника три обязательные круглые
  кнопки на кромке пузыря (озвучить, перевести, «почему так»); микрофон слева,
  поле в центре, отправить справа.
- «Почему так»: шторка снизу вверх; содержимое (объяснение, перевод,
  рекомендации как ответить) мгновенно, без ожидания генерации: приходит
  вместе с репликой.
- Помощник: вариант А, показывается только после трёх неадекватных реплик
  подряд.
- Разбор: вариант А + оценка диалога числом + полный разбор каждой фразы
  ученика; Free видит одну фразу, остальные в Plus; оценка разговора звёздами.
- Урок с Максом: вариант Б, Макс предлагает настоящие темы из каталога целей
  (по языкам); ситуации не разыгрывает, а учит, уточняет, объясняет, приводит
  примеры. Итог урока: вариант А. Клуб: не делаем. Стена Free: вариант А.
- Всё отцентровано, реальные размеры экранов.

**Решения владельца 2026-09-14 (после первой версии):**
- Хаб = вариант Б, но афиша ведёт не в сценарий, а сразу в урок с **Максом**;
  слово «Миры» не используется; ниже список групп разговоров, каждая
  раскрывается вниз, без стрелок вправо; звание маленьким кольцом в правом
  верхнем углу с пульсирующей прозрачностью.
- Макс не роль и не собеседник по сценарию, а отдельная сущность: учит, как
  учил MAX, сам решает, что учить сегодня, или спрашивает; никогда не молчит и
  всегда говорит первым. Роли остаются в обычных диалогах.
- Один цвет темы на всё (без света сцен), компактные действия внутри пузыря,
  настоящие ассеты приложения (орб Макса из `assets/images/home_menu/max`).
Локально: `python -m http.server 8849 --directory docs/design/dialogs`
(в приложении Claude есть конфиг превью `dialogs-mockups`).

Правила макета: цвета только из тем приложения (Полночь, Уголь, Лес, Золото),
один акцент темы на всё, золото только у наград и Plus; иконки разделов,
недельной цели и опыта взяты из `assets/images` самого приложения; всё крупно,
как в «Статистике»; действия внутри пузыря одной строкой иконок, без плашек.

## 1. Что есть сейчас (факты из кода)

### Хаб (`components/DialogsTabContent.tsx`, `app/ai_dialog_home.tsx`)
- Бейдж квоты Free над всем экраном, hero «Продолжить» (первый незакрытый
  сценарий по порядку массива), четыре свёрнутые карточки-мира с «X из N»,
  апселл Plus внизу.
- **Прогресса нет**: ни звания, ни недели, ни серии, ни истории прошлых
  диалогов, ни агрегированной статистики. Единственный след: галочка
  «Пройдено» на 136 сценариях (`app/dialogs_progress.ts`, AsyncStorage).
- Два входа в один контент: плитка на Главной и вкладка внутри «Уроков».

### Сценарии (`app/ai_dialog_scenarios.ts`)
- 136 активных: 117 курсовых (everyday 20, travel 12, social 24; CEFR A1-B2)
  и 19 «Ситуаций» по уровню аккаунта 5…60.
- Поля: роль, сеттинг, персона, цель, objectives (чек-лист), temperament
  (терпение/теплота), nextStepHint. Полей «объяснение/подсказка/тутор» нет.

### Путь до первого сообщения (сейчас)
Главная → плитка (1) → сценарий, часто с разворотом мира (2-3) → брифинг при
первом заходе (4) → согласие на ИИ при самом первом диалоге (5) → чат.
Повторный сценарий: 2 тапа, брифинг пропускается.

### Экран разговора (`app/ai_dialog_session.tsx`, 2575 строк)
- Шапка: назад, иконка сцены, смайл настроения, «Завершить», «Сообщить об
  ошибке». Индикатор целей убран владельцем; цели видны только в финале.
- Реплика собеседника: текст, ключевые фразы `[[...]]` подсвечены и
  озвучиваются по тапу системным TTS, кнопка «Показать перевод» (с
  предзагрузкой, `DIALOG_TRANSLATE_PREFETCH_ENABLED`).
- **Объяснения «почему так» нет.** Сервер возвращает за ход только
  `assistantMessage`, `remainingQuota`, `turnState {mood, objectivesMet,
  outcome}`; `characterReaction`/`coachTips` приходят только на последнем ходе
  (`app/ai_dialog_client.ts:90-104`, `functions/src/premium_dialog_stream.ts:495`).
- **Поправок по ходу нет.** Модель «вплетает» верную форму в свой ответ
  (`GENTLE CORRECTION`, `premium_dialog.ts:327`), UI этого не показывает.
  Все исправления собраны в финальном `premiumDialogReview` (до 8 штук),
  и только для Plus.
- **Помощника нет.** Есть статичная пилюля «Что сделать дальше» из каталога,
  появляется после трёх ходов без новой цели (`stuckTurnsRef`), без сети.
  Нет готовых ответов, нет «как сказать», нет банка фраз.
- Ввод: текст + зажать микрофон (системный STT, `expo-speech-recognition`).
- Конец: `success | lost_patience | stalled`, ручное «Завершить», мягкий
  потолок 8 обменов.

### Разбор (`components/DialogVerdictScreen.tsx`)
Исход, смайл, +XP (только первое прохождение сцены), реакция персонажа,
чек-лист целей, 1-2 совета, «Разбор твоих фраз» (praise + corrections + tip).
Free видит вместо разбора закрытый тизер. Салют только при честном success.

### Награды (`app/dialog_outcome.ts`, `app/config.ts:273`)
XP 10 × (1 / 0.6 / 0.4), один раз на сценарий. Рун нет, стрика диалогов нет,
клуба/лиги нет. Диалог стоит энергию.

### Сервер (`functions/src/premium_dialog*.ts`)
Стрим SSE с 2026-09-14 живой; модель `gpt-4o-mini` по умолчанию, перевод
`gpt-4.1-nano`; история 8 ходов × 300 симв., выход 200/400 токенов, кэш
префикса, rate-limit 60/час, дневная квота Free 10 реплик, Plus 200.

## 3. «Урок с Максом» на каркасе MAX (план, код не трогали)

Вход: клавиша «Начать урок» на афише хаба → сразу чат, первым пишет Макс
(предлагает тему из памяти/каталога целей или спрашивает). Экрана-билета нет.

Что берём у MAX как чистые модули (без голоса):
- каталог целей can-do (78 целей A1-B2) `functions/src/max_voice_can_do_goals*.ts`,
  клиентская витрина `app/max_lesson_catalog.ts`;
- 12 инструментов тутора и их клиентский исполнитель `app/max_call_tutor_tools.ts`
  (`show_tutor_board`, `start_scene`, `mark_phrase_result`, `mark_goal_progress`,
  `assign_homework`, `set_next_topic`, `remember_learner`, `flag_safety`…);
- редьюсер доски `app/max_tutor_live_board_state.ts`, `MaxTutorGoalStrip`,
  `MaxLessonMissionPlaque`, `MaxTutorTopicNotice`;
- память тутора `functions/src/max_voice_tutor_memory.ts` (тот же документ
  `voice_tutor_memory/{id}`: имя, цель, повторяющиеся ошибки, домашка,
  очередь фраз, мастерство целей);
- домашка → карточки `app/max_homework_trainer_ingest.ts`;
- разбор: `maxVoiceReviewSystemPrompt` + `mergeTutorMemory` из
  `max_voice_finalize.ts`, проекция `app/max_voice_review_projection.ts`;
- фильтр безопасности `max_voice_safety.ts`.

Что НЕ берём: WebRTC, mint, минуты, watchdog, reconnect, hint-timer тишины,
XP по аудио-токенам.

Новое (всё вне запломбированного namespace, без префикса `maxVoice*`):
- `functions/src/tutor_text_prompt.ts`: префикс из `VOICE_TUTOR_PREFIX` без
  голосовых абзацев («speak slowly», «under 15 seconds»), лимит «2-4
  предложения», бюджет урока в репликах вместо секунд;
- callable `tutorTextTurn` (история + реплика → ответ + tool calls; чтение
  памяти при старте), стрим по тому же пути, что `premiumDialogStream`;
- callable `tutorTextFinalize` (разбор + транзакционное обновление памяти +
  XP по подтверждённым репликам ученика);
- клиент `app/ai_dialog_tutor_session.tsx` на базе текущего чата + раннер
  tool-calls (тот же паттерн, что в `max_text_qa.ts`);
- независимый флаг видимости (например `gate_ai_text_tutor`), не
  `isMaxVoiceEntryVisible`.

Стоимость сессии: 14 ходов × (кэшируемый префикс 3-5 тыс. токенов + ≤300
выход) на mini-модели ≈ 1-2 цента, плюс один вызов разбора; Firestore: 1
чтение памяти при старте, 1 запись в конце. Голосовая минута MAX стоила на
порядок больше и требовала watchdog каждые 10 минут.

Пломба MAX не задевается: `max_voice_flags.ts`, `functions-max/index.ts` и
сторож `tests/max_section_sealed_contract.test.ts` не меняются.

## 4. Что нужно от сервера для нового экрана разговора

Один вызов на ход, лимит вывода 200 → 320 токенов, в JSON-конверте:
- `note`: почему так сказано, 1-2 предложения без грамматических терминов;
- `userFix {corrected, note}`: только если у ученика была ошибка;
- `suggestions[2]`: готовые ответы под CEFR (с переводом для варианта «Сцена»);
- «как сказать»: nano-модель, тот же путь и лимит, что перевод.

Награды считает сервер идемпотентно; клиент показывает по факту
(закон: празднуем фактом, а не записью).
