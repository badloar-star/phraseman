Повышение уровня — три прототипа

Сценарий один: экран уходит в темноту, из-за края пола поднимается текущая монета, переворачивается — на обороте новая монета нового уровня, затем название, «Уровень N» и «Продолжить». Тап в любой момент — досмотреть ускоренно.

Вариант A
Студия
Чёрный зеркальный пол, один конусный прожектор. Полтора оборота с наездом, ударная волна и золотая пыль на посадке, блик пробегает по новой монете. CSS 3D.
Вариант B · выбран владельцем 24.09
Монетный двор
Тёмный камень, монета выходит из светящейся щели пресса. Один быстрый тяжёлый оборот, тёплая вспышка чеканки, удар камеры, искры металла. CSS 3D.
Вариант C
Глубина
Настоящая 3D-сцена: монета с толщиной и гуртом, зеркальный пол, объёмный луч, камера облетает монету во время флипа, параллакс от мыши. three.js.

Общее для всех. Тайминги, кривые и последовательность шагов вынесены в объект TIMELINE в начале каждого файла и прокомментированы — по нему переносить в Reanimated/Skia. В углу телефона — выбор пары уровней (0→1, 8→9, 19→20) и после финала кнопка «Повторить». Монеты нарисованы процедурно; когда появятся PNG, подставить в coinSrc[n].

Звук. По решению владельца озвучка не синтезируется: в таймлайне есть метки sounds и пустой обработчик onSoundCue(name) — точки для будущих звуков (drop, riser, flip, mint, shimmer).

Доступность. При prefers-reduced-motion играет короткая версия: затемнение → кроссфейд монеты → название.
