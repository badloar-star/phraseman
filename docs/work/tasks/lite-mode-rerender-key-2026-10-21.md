# Task packet: «Лёгкий режим» — перерисовка открытых экранов при переключении

Governance-ID: TG-865096F7E81C
Status: In progress
Owner: 6 · СВЕРКА (замечание Ревизора к c0bfb85b7, через координатора, 21.10)

## Outcome
После переключения «Лёгкого режима» в Настройках тени сразу пропадают/возвращаются на всех открытых экранах (а не только на новых). Мера успеха: смена флага меняет ключ корня вкладок, дерево перерисовывается; подписи «после перезапуска» не добавляются.

## Scope
In: `app/(tabs)/_layout.tsx` — подписка на `useLiteMode()` и ключ у корня вкладок. Out: подъём `initLiteMode()` выше (заставка/онбординг) — мелочь на будущее, файл `app/_layout.tsx` правят другие сессии.

## Architecture
Тени читают плоский флаг `constants/lite_mode_flag.ts` при рендере, но компоненты на него не подписаны. Корень вкладок получает `key`, зависящий от флага: смена флага пересоздаёт дерево вкладок, все плашки перечитывают тени. Переключатель редкий, потеря локального состояния вкладок при нём допустима. Состояние переключателя берётся из того же хука (мгновенно).

## Security and privacy
Данных не собирается и не передаётся; политику менять не нужно.

## Technical debt
Remount дерева при переключении — Contain (редкое действие); полная подписка каждого экрана на флаг дороже и не нужна.

## Verification
Тест `tests/lite_mode.test.ts` остаётся зелёным; проверка типов через слот; вид — снимок эмулятора после перезапуска (по слову координатора).

## Rollback
Убрать `key` и вызов `useLiteMode()` — поведение возвращается к c0bfb85b7.
