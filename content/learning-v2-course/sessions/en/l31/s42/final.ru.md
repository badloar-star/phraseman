# Урок 31 · Занятие 42 — Ключ и записка

**Ситуация.** Вы убираете запасной ключ и оставляете Анне записку.

**Что вы освоите:** объяснять цель своих действий и называть другого участника после so that.
**Новые слова:** —
**Повторяем знакомые слова:** key, box, note, drawer

## Интро 1

### Убрал ключ, чтобы сохранить его

Вы положили запасной ключ в коробку, где он не потеряется: I put the key in the box to keep it safe — я положил ключ в коробку, чтобы сохранить его в безопасности. Соберите I put the key in the box + to + keep it safe. После to называем цель: keep it safe. Кладёте и хотите сохранить ключ вы.

**Выберите фразу для этой ситуации.**

- ✅ **I put the key in the box to keep it safe.**
- ❌ I put the key in the box to kept it safe. — *После to нужна начальная форма keep.*
- ❌ I put the key in the box for keep it safe. — *Перед keep для этой цели нужно to.*

---

## Интро 2

### Записка поможет Анне найти ключ

Анна придёт позже. Вы написали ей записку о том, где лежит ключ: I wrote a note so that Anna could find the key — я написал записку, чтобы Анна могла найти ключ. Соберите I wrote a note + so that + Anna could find the key. Пишете вы, а найти должна Анна: после so that явно называем её.

**Выберите фразу для этой ситуации.**

- ✅ **I wrote a note so that Anna could find the key.**
- ❌ I wrote a note to Anna find the key. — *Для отдельного участника Anna нужна целая часть после so that.*
- ❌ I wrote a note so that Anna could found the key. — *После could нужна форма find.*

---

## Интро 3

### Я знаю, где коробка

Друг ищет коробку с ключом. Вы помните её место: I know where the box is — я знаю, где коробка. Соберите I know + where + the box + is. После where сохраняем порядок the box is, без вопросительной перестановки.

**Выберите фразу для этой ситуации.**

- ✅ **I know where the box is.**
- ❌ I know where is the box. — *После where порядок the box is.*
- ❌ I know where the box are. — *Одна box требует is.*
