# Урок 32 · Заняття 07 — Шукаємо вихід

**Ситуація.** Ви з Беном шукаєте вихід із великої будівлі за планом.

**Що ви опануєте:** робити висновок із поведінки людини й уточнювати знайдені підказки.
**Нові слова:** —
**Повторюємо знайомі слова:** map, exit, stairs, floor

## Інтро 1

### Напевно, потрібна допомога

Бен кілька разів дивиться на план будівлі й повертається до тих самих дверей. Ви припускаєте: He must need help — йому, напевно, потрібна допомога. Складіть He + must + need + help. Після must одразу ставимо початкову форму need без s. Must тут виражає висновок із поведінки Бена.

**Виберіть фразу для цієї ситуації.**

- ✅ **He must need help.**
- ❌ He must needs help. — *Після must використовуємо need без s.*
- ❌ He must be need help. — *Перед дієсловом need додаткове be не потрібне.*

---

## Інтро 2

### План, який я знайшов

Ви знайшли план будівлі біля входу й показуєте його Бену: The map I found is useful — план, який я знайшов, корисний. Складіть The map + I found + is useful. Частина I found уточнює map. That можна опустити: усередині уточнення вже є I, той, хто знайшов план.

**Виберіть фразу для цієї ситуації.**

- ✅ **The map I found is useful.**
- ❌ The map I found it is useful. — *Map уже названо: it після found не потрібне.*
- ❌ The map I find yesterday is useful. — *Для завершеної минулої дії потрібна форма found.*

---

## Інтро 3

### Вихід зачинений — повернулися

Ви з Беном дійшли до зачиненого виходу: The exit was closed, so we went back — вихід був зачинений, тому ми повернулися. Складіть The exit was closed + so + we went back. Після so називаємо результат. Went back означає «повернулися».

**Виберіть фразу для цієї ситуації.**

- ✅ **The exit was closed, so we went back.**
- ❌ The exit was closed, so we gone back. — *Потрібна минула форма went.*
- ❌ The exit was closed, so we going back. — *Потрібна повна частина we went back.*
