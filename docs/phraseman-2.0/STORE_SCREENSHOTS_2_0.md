# Скриншоты магазинов PhraseMan 2.0 (App Store, Google Play)

Запас R1 №6, сессия «Макеты», 13.10.2026. Страница рамок: `docs/design/v2-app/store-screenshots.html` (9 языков × 2 магазина, переключатели сверху). Данные кадров и подписей: `docs/design/v2-app/store/captions.js`; этот файл генерируется из них.

Заменяет «Часть 4. Скриншоты» в `content/marketing/ASO_STORE_LISTING.md` (сценарий 01.08 для версии 1.x): лиги и турниры убраны (их заменил Шпиль), Premium → Plus, добавлены диалоги, карточки и Шпиль.

## Правила кадра

- Подпись сверху говорит о результате, а не о названии экрана; 2–3 строки, страница сама предупреждает, если на каком-то языке вышло больше трёх.
- Экран снизу; у Google Play (9 : 16) телефон уходит за нижний край — так принято в витринах.
- Фон — глубокие тона темы «Аврора» под каждый кадр, без обводок, без мелких подписей под заголовком.
- Первыми идут бесплатные функции. Пейвола, цен и «Plus»-стен на кадрах нет.
- Пометка «Plus» не нужна: все семь функций доступны бесплатно (часть — с лимитом). Если владелец переведёт функцию за Plus целиком — кадру нужна спокойная пометка «Plus» в углу подписи, иначе витрина обещает бесплатное.
- Ничего сверх правды: в подписях нет чисел пользователей, рейтингов и сроков «заговоришь за месяц».

## Съёмка (Сверка, эмулятор)

1. Интерфейс на языке витрины (9 проходов: ru, uk, en, es, pt-BR, vi, id, tr, pl), тема «Аврора», тёмная, размер шрифта средний.
2. Строка состояния чистая: демо-режим Android (часы 9:41, полная батарея, Wi-Fi без значков отладки). Никаких «(dev)», «Dev Hub», отладочных баннеров.
3. Данные — «живой» пользователь без нулей: серия ≥ 2 дней, монеты, урок в процессе, друзья в Шпиле. Реплики собеседника — настоящие, не заглушка.
4. Снимок экрана целиком без рамки телефона, PNG, в `docs/design/v2-app/store/shots/<язык>/<№ с нулём>.png` (например `shots/en/03.png`). Страница рамок подхватит его вместо образца сама.
5. Готовые кадры выгружаются со страницы режимом экспорта: `store-screenshots.html?export=1&lang=en&store=ios&n=3` — снимок окна в пикселях магазина.
