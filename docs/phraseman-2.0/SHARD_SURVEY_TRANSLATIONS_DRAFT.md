# Опросы осколков — переводы uk / en (черновик для владельца)

Сессия «1 · Ядро», 12.10. Код — e4f45f8e3 (без деплоя).

## Зачем

На украинском интерфейсе в «Сегодня» Главной стоит русская строка опроса — «Зовёшь друга заниматься…» (пресет 47).
У живых опросов есть только русский текст, и сервер молча подставлял его для любого языка. На английском интерфейсе —
то же самое.

После выкладки e4f45f8e3 сервер **не предлагает** опрос, если у него нет текста на языке человека (лог
`[SHARD-SURVEY] reason=no_locale`). То есть без переводов опрос на uk/en/es/… просто исчезнет — и появится обратно,
как только перевод будет вписан.

## Что готово

- `docs/phraseman-2.0/shard_survey_translations_uk_en_draft.json` — украинский и английский для всех **54** опросов
  библиотеки + общий финальный экран («Дякуємо!» / «Thank you!»). Переведено вручную, тон сохранён (шутка в последнем
  варианте). В украинском — «вислів» вместо «фраза» (указание владельца 12.10). Сверено автоматически: у каждого опроса
  то же число вариантов и те же кнопки действий, что у русского.
- `scripts/apply_shard_survey_translations.mjs` — вписывает переводы в живые документы за один проход (руками в
  админке это 54 × 2 × ~7 полей).

## Как применить (только владелец — запись в прод)

```bash
node scripts/apply_shard_survey_translations.mjs
```

Это **только план**: по каждому `survey_preset_NNN` — сколько строк будет вписано или почему пропуск. Если план устраивает:

```bash
node scripts/apply_shard_survey_translations.mjs --write --confirm APPLY_SURVEY_TRANSLATIONS_UK_EN
```

Безопасность: пишутся только языки, которых в документе нет (уже вписанный перевод не перезаписывается); опрос, у которого
число вариантов или кнопки разошлись с черновиком (правили в админке), пропускается; ru и остальные поля не трогаются.

**Порядок:** сначала выложить функции опроса (e4f45f8e3 — шаг 3 плана дня релиза), потом скрипт. Старый сервер при
чтении отбрасывает ключ `en` (его нет в старом списке языков), поэтому английский заработает только с новым сервером;
украинский виден и старому серверу сразу.

## Чего нет

- **9 из 63 живых опросов** в коде отсутствуют (библиотека в коде — 54 пресета). Скрипт покажет их строкой
  «нет в черновике (presetId=…)» — эти 9 перевести вручную в админке («Опросы») или прислать мне их русский текст.
- **es, pt-BR, vi, id, tr, pl** — не переведены. До перевода опросы на этих языках интерфейса после выкладки сервера
  скрыты. Предлагаю машинный перевод тем же путём, что сообщения в админке (`adminTranslateMessage`), с вычиткой — отдельной
  задачей.
- Тексты библиотеки упоминают удалённые разделы (пресет 1 — «Идеи», 63 — руны и «соревнования»). Это вопрос содержания
  опросов, не перевода; переведено как есть.
