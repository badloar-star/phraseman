## Удалено в 2.0 — только пометка, не рисуем
- XP: тост «+N XP» в уроке, «+25 XP» за теорию, «+N опыта» в диагностике → нет.
- Руны/жемчуг: пилюля рун в шапке списка, «Разблокировать · 100» в окне замка, «Восстановить за N жемчужин» в окне энергии, празднование «Урок открыт — теперь твой навсегда».
- Подарки: спасение сердец подарком (gift rescue) в шапке урока.
- Медали (бронза/серебро/золото), тост медали, «★ 4.5» → звёзды 1–3 (D36).
- Пороги «2.5+», «4.5+» → «2★».
- Вкладки «Маршрут», «Диалоги», «V2» и чип «Новые уроки» в шапке списка (Диалоги — свой раздел; Learning V2 — отдельная страница).
- Dev-кнопки (язык обучения, разблокировка сессий).
- «Куплено» на карточке урока (жемчужная покупка урока).
