# Урок 27 · Заняття 05 — Пояснити й попросити допомогу

**Ситуація.** Ви уточнюєте напис у магазині, описуєте невелику проблему й домовляєтеся про прийом.

**Що ви опануєте:** сказати, що було б, якби…, і не плутати «вже зроблено» з «було тоді»: I have a rash.
**Нові слова:** oily, chapped, splinter, rash

## Інтро 1

### Якби окуляри були із собою

Ви не можете прочитати дрібний напис на етикетці: окуляри залишилися вдома. Поясніть: I would read the label if I had my glasses — я б прочитав етикетку, якби мав окуляри. Складаємо: I + would read + the label + if I had my glasses — хто, що зробив би, що прочитав би, за якої умови. Після would потрібна read без to. Had після if описує відсутню зараз умову; would туди не ставимо.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would read the label if I had my glasses.**
- ❌ I would reading the label if I had my glasses. — *Після would потрібна початкова форма read.*
- ❌ I would read the label if I would had my glasses. — *В умові had без would.*

---

## Інтро 2

### Якби був телефон

Ви домовляєтеся з другом про зустріч, але телефона із собою немає. Скажіть: I would call you if I had my phone — я б зателефонував тобі, якби мав телефон. Складаємо: I + would call + you + if I had my phone — хто, що зробив би, кому, за якої умови. Call після would залишається без закінчення. Had позначає уявну наявність телефона зараз; це не розповідь про вчорашній дзвінок.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would call you if I had my phone.**
- ❌ I would called you if I had my phone. — *Після would потрібно call.*
- ❌ I would call you if I would had my phone. — *Після if тут had без would.*

---

## Інтро 3

### Коли записалися на прийом

Адміністратор запитує, коли ви записалися на прийом. Дайте відповідь: I booked it yesterday — я записався вчора. It замінює вже названий прийом. Складаємо: I + booked + it + yesterday — хто, дія в минулому, що забронював, коли. До book додаємо -ed. Yesterday указує завершений час, тому використовуємо booked без have.

**Виберіть фразу для цієї ситуації.**

- ✅ **I booked it yesterday.**
- ❌ I have booked it yesterday. — *Із завершеним yesterday тут форма минулого.*
- ❌ I booking it yesterday. — *Для минулої події потрібна форма booked.*
