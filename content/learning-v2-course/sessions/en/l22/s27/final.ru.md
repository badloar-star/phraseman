# Английский · Урок 22 · Занятие 27 — Выбрать вещи для дома

**Ситуация.** Вы читаете описания посуды, одежды и полотенец.

**Что вы освоите:** determiner|adjective + one|ones
**Новые слова:** dishwasher-safe, microwave-safe, machine-washable, absorbent

## Интро 1

### Тарелки для посудомойки

Dishwasher-safe — пригодный для мытья в посудомоечной машине. Это описание на упаковке посуды. В примере несколько тарелок, поэтому ones заменяет plates. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I want the dishwasher-safe ones.**
- ❌ I want the dishwasher-safe one. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I want the dishwasher-safe them. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 2

### Миска и свитер

Microwave-safe — пригодный для микроволновой печи. Machine-washable — пригодный для машинной стирки, например свитер. Это разные свойства: первое относится к посуде для разогрева, второе — к вещам, которые стирают. В обоих примерах выбираем одну вещь. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I prefer the microwave-safe one.**
- ❌ I prefer the microwave-safe ones. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I prefer the microwave-safe it. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 3

### Полотенца

Absorbent — хорошо впитывающий влагу. Так описывают полотенца, губки или салфетки. В примере речь о нескольких полотенцах: towels → ones. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.
