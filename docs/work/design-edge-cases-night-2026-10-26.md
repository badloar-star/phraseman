# Крайние случаи ночных экранов — 360 dp, шрифт ×1,3, самая длинная строка из 9 языков (26.10, по коду)

Проверял чтением кода и оценкой по строкам (устройство и кадры не использовались). Что искал: фиксированная высота у текста и кнопок, обрезка и `numberOfLines` без переноса, наезд на круг «назад» 48, блоки, растущие за край. `adjustsFontSizeToFit` не добавлялся нигде (правило владельца): везде перенос и `minHeight`.

## Что нашёл и поправил

| экран | что было | что сделано |
|---|---|---|
| Окна М — все панели (энергия, серия, замок, Мастерская, «Разговор с ИИ», «Не видим Plus») | панель лежала в шторке с `maxHeight` и `overflow: hidden` **без прокрутки**: на 360×640 при шрифте ×1,3 и длинном переводе низ с кнопкой и «Не сейчас» обрезался | общий каркас `PanelFrame` — `ScrollView` с высотой по содержимому; прокрутка включается только когда панель выше шторки |
| Кнопки панелей и «дока» М | `height: 56` при `overflow: hidden` — подпись из двух-трёх строк режется | `minHeight: 56` + вертикальный отступ: кнопка растёт, текст переносится |
| Панель энергии: плитки «Подождать» / «Plus» | две плитки в ряд оставляли слову ~120 dp: «продолжить», «Подождать» рвались посреди слова уже на 360 dp | в «тесной» раскладке (окно < 380 dp или шрифт > ×1,15) плитки друг под другом |
| Общий экран М: тарифы | два тарифа в ряд оставляли цене ~119 dp при 28 pt: «R$ 199,90», «3 999,00 ₽» рвались посреди числа | в «тесной» раскладке тарифы друг под другом |
| Сравнение «Бесплатно и Plus» | колонки 92 + 112 dp оставляли названию строки ~96 dp на 360 dp | в «тесной» раскладке колонки 76 + 96 dp |
| Неделя серии | подпись дня и «пропуск» — `numberOfLines={1}` в колонке ~40 dp, «sin práctica» и «dia perdido» уходили в многоточие | подпись переносится по словам |
| Шапка общего экрана М | подпись плитки показателя — `numberOfLines={2}` (многоточие вместо слова) | перенос без ограничения |
| Блок Мастерской | русская фраза — `numberOfLines={2}`, слова-плитки — `numberOfLines={1}` | перенос без ограничения |
| «Восстановить аккаунт?» (`AccountRestoreSummaryDialog`) | значения и подписи ячеек сводки — `numberOfLines={1}` (в ячейке ~78 dp), подпись кнопки — `numberOfLines={2}` | подписи и кнопки переносятся |
| Окно удаления, подпись кнопки рядом с индикатором | текст в строке `row` без `flexShrink` — длинная подпись выходит за край кнопки | `flexShrink: 1` |
| Строка награды «+N монет» без плашки (`CoinAward`, итог урока V2) | `height: 54` — число и подпись при ×1,3 режутся | `minHeight: 54` + перенос |

Правило «тесной раскладки» — одна функция `paywallMCompactLayout(width, fontScale)` (`components/paywall/m/paywall_m_panels.ts`), пороги 380 dp и ×1,15.

## Что проверил и оставил как есть

| экран | вывод |
|---|---|
| Окно удаления, строка «Не получилось» (`FailureNote`) | без `numberOfLines`, высота от размера шрифта (`lineHeight = size × 1,35`), центр; кнопки `minHeight: 52`; окно прокручивается своим скроллом шелла |
| Плашка «+30 монет» (`CoinAward plaque`) | текст `flex: 1` без ограничения строк, плашка растёт по содержимому |
| Шапки Диалогов с кругом 48 (briefing, freeform, session, completion, Hub) | везде `ScreenBackSlot` резервирует 48 слева, заголовок `flex: 1, minWidth: 0`, наезда на круг нет. Название сцены в шапке сессии намеренно в одну строку с многоточием (образец `dialogs.html .ti { white-space: nowrap; text-overflow: ellipsis }`, решение 13.10) и с `maxFontSizeMultiplier: 1.3`; подпись настроения — так же по решению dialogs-023 |
| Настройки «Обучение» | подписи без ограничения строк; строки `minHeight: 64`; строка «Голос озвучки (EN)» — колонка сжимается, значение `maxWidth: 120`; при ×1,3 название переносится на вторую строку, это допустимо |
| Окно «Изменить имя» | кнопка `minHeight: 48`, текст без сжатия (комментарий в коде) |

## Самая длинная строка из 9 языков (оценка: знак ≈ 0,6 кегля, ×1,3, окно 360 dp)

Тест `tests/design_edge_cases_night_2026_10_26.test.ts` считает худший случай по всей таблице текстов М:

| что | худший случай | строк | бюджет |
|---|---|---|---|
| подписи кнопок | es · `m.cta.noTrial` «Suscribirse por 99 al año» | 2 | 3 |
| заголовки панелей и шапок (24 pt) | en · `mc.dialog.title` «99 min of conversation and 99 of your phrases» | 4 | 5 |
| абзацы панелей | id · `mc.dialog.body` | 5 | 9 |

Оценка не заменяет кадры Сверки (на 360 dp и ×1,3): она ловит случай, когда в кнопку или заголовок кладут абзац.

## Не проверено / ждёт кадров
- Реальный вид панелей М на 360×640 с ×1,3 — нужны кадры Сверки (прокрутка панели, стопка плиток и тарифов).
- Окно «Восстановить аккаунт?» с тремя ячейками на узком экране — визуально не смотрел.
