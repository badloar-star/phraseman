# mitap — тематическая арка плана (112 дней / 16 недель)

Каркас для генерации authored-контента рабочего/делового английского. Аудитория —
носители русского/украинского/испанского, учат английский для **рабочих созвонов,
видеовстреч и удалёнки**. Цель плана: **понимать созвоны и отвечать коротко**
(standup, дедлайны, блокеры, письма, митинги, remote work).

**Принцип арки (главное).** Хук — это **ситуация дня**, а не сам английский.
Английский всегда остаётся на уровне дня. Меняется то, КАКАЯ ситуация. Каждый день —
один конкретный, узнаваемый, смешной или high-stakes момент удалённой работы,
который каждый, кто работает на видеосозвонах, узнаёт и над которым ржёт. 112 разных
запоминающихся моментов с естественной эскалацией. Никаких сухих «дать статус по
задаче» — только живые провалы, эмоция, «это прям про меня».

**Прогрессия.** Грамматический gate растёт до дня ~35 (A1→B1): дни 1–35 опираются
только на грамматику, доступную к этому дню — поэтому ранние хуки выражаются простыми
словами, но всё равно цепляют. Дни 36–112 — вся грамматика открыта (passive,
conditionals, reported-speech, relative-clauses, complex-object), ситуации
становятся глубже и острее (B1→B2→C1-lite). Каждый 7-й день — review, собирающий
провалы недели. Ни одна ситуация не повторяется за 112 дней.
