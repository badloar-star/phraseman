# Task packet: PhraseMan 2.0 «Диалоги» — статичная страница макетов

Related epic/enabler: docs/phraseman-2.0 (E06/E07, редизайн 2.0), design track docs/design/v2-app

## Outcome

Одна статичная HTML-страница `docs/design/v2-app/dialogs.html` с телефонами-макетами
раздела «Диалоги» 2.0 (хаб, категория, брифинг, согласие на ИИ, выбор режима, сам диалог
во всех состояниях, шторки, лимиты, завершение) — по образцу `home.html` и брифу
`docs/design/v2-app/AGENT_BRIEF.md`. Успех: владелец открывает файл в браузере и видит
все экраны/состояния из задания без обрезаний и лишней возни, стиль совпадает с
референсами ref_18/19/20, контент (названия категорий/сценариев) соответствует
`app/ai_dialog_scenarios.ts` и `docs/design/v2-app/RULES.md`.

## Scope

In scope: только новый файл `docs/design/v2-app/dialogs.html` (HTML/CSS/JS инлайн,
использует общие `kit.css`/`kit.js`/`nav.js`). Никакого кода приложения, никаких
git-команд, никаких других файлов в `docs/design/v2-app/`.

Out of scope: правка `app/ai_dialog_*`, компонентов `components/dialogs/*`, экономики
рун/Plus, любых других страниц макетов (`home.html` и т.д.), запуск тестов/сборки.

## Architecture

Чистый статичный макет без рантайма приложения — архитектурных изменений нет и быть
не может (это не код продукта, а иллюстрация для дизайн-ревью). No architecture change:
файл ничего не импортирует из `app/`/`functions/` и не может повлиять на прод.

## Security and privacy

Не применимо: страница не собирает данные, не обращается к сети/Firestore, не хранит
персональные данные. Никакого нового стороннего сервиса или разрешения не вводится.

## Technical debt

Долга не создаётся: страница разовая, независимая, без зависимостей от неё у другого
кода. Accept temporarily: реальные тексты сценариев могут разойтись с каталогом
(`app/ai_dialog_scenarios.ts`) при будущих правках контента — владелец/дизайн-сессия
актуализирует макет по необходимости, отдельного мониторинга не требуется.
