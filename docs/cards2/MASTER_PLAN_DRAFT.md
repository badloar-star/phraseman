# Мастер-план Cards 2.0 — «Колода»

Синтез трёх концепций (premium-visual / ux-flow / perf-engineer) с учётом вердиктов судей. Проверено против кода: `flashcards_v1` **уже добавлен** в SYNC_KEYS (`app/cloud_sync.ts:105`, комментарий `FIX(cards-2.0)`) — из бэклога багов вычеркнут. Установлен `expo-av ~16.0.8`; `expo-audio`, `expo-keep-awake`, `expo-device` — отсутствуют, ставятся по этапам (§7).

**Рамочные принципы (обязательны для каждого решения):**
1. Одна модель сессии везде: конечная сессия N карточек → сегмент-прогресс → экран результата 0–3★. Никаких бесконечных очередей.
2. ≤2 тапа до любой тренировки с любого экрана раздела.
3. Анимации = только `transform` + `opacity` на UI-потоке (Reanimated 4). Бюджет-устройство: **Helio G35 / 3GB RAM / 60fps**. ≤8 живых анимаций одновременно, ≤3 смонтированных полноразмерных карточек, ноль блюров. **Не ставим** Lottie/Skia/Moti/Rive.
4. Данные не ломаем: все существующие AsyncStorage-ключи (`flashcards_custom`, `flashcards_v1`, ключи trainer_store/review), правила `docs/FLASHCARDS_RULES.md`, языковые инварианты handleSave — неприкосновенны. Новые фичи — только новые ключи.
5. Деградация на слабых устройствах: `lowPowerMode` = авто (`expo-device` totalMemory < 3GB) ИЛИ тумблер «Упрощённые эффекты» + существующий reduceMotion. Все декоративные эффекты обязаны иметь ветку деградации.
6. Локали ru/uk (+es): все новые строки — через существующий triLang-механизм, ни одной хардкод-строки.

**Метрики успеха (критерии приёмки продукта):** D7 retention раздела; сессий/день на пользователя; доля perfect sessions; claim rate сундуков; доля пользователей режима слушания; 60fps UI-потока при свайпе/флипе на бюджет-устройстве (проверка `useFrameCallback`-счётчиком при искусственном JS-фризе).

## 2. Дизайн-язык

**Метафора: физическая колода в руках.** Карточка — один тактильный предмет с одним видом, одним флипом, одним звуком, одной хаптикой во всех местах, где она карточка (колода, words-сессия, слушание).

**Карточка (`PhraseCard`):**
- Скругление 24; градиент лица из темы пака (`getCardPackPaywallTheme`), акцент — через контраст-чек с осветлением на тёмных темах (7 существующих тем из `constants/theme.ts`, новых цветов не вводим).
- Лицо: EN-фраза + транскрипция + динамик (единая позиция справа везде — убрать `voiceSpeakOnRight`); рубашка: перевод + пример.
- «Толстая» нижняя грань 4px в цвет акцента; при нажатии карточка сдвигается вниз на 2px, грань сжимается (Duolingo-press). Тот же приём — на всех CTA сессий.
- Высота в списке — адаптивная по контенту (min 120), убить фикс CARD_H 224 (сейчас 60–70% пустоты).
- Индикатор силы слова: точка Weak/Medium/Strong (интервалы SRS 1–3 → Weak, 7–14 → Medium, 30 → Strong; цвета из темы) — на карточке и в строке списка.
- Бейдж источника: «Урок 1» локализованно вместо «ГЛАГОЛ LESSON1».

**Типографика:** системные шрифты (не меняем), иерархия: EN — крупный semibold, транскрипция — secondary, перевод — regular. Плотность списка ×3 от текущей.

**Движение — `constants/flashcards_motion.ts`:**
```ts
export const FC_SPRING = {
  press:  { damping: 16, stiffness: 420 },        // вынесено из HubTileShell
  flip:   { duration: 450, dampingRatio: 0.8 },
  return: { duration: 350, dampingRatio: 0.7 },
  ring:   { duration: 800, dampingRatio: 1 },
};
export const FC_TIMING = { fast: 150, base: 250, enter: 300, flyStar: 600 };
export const FC_STAGGER = { step: 60, cap: 8 };   // delay = min(i, 8) * 60
```
Всё уважает reduceMotion/lowPowerMode: флип → кроссфейд 150мс, частицы → scale-пульс + хаптика, параллакс/стагер → off.

## 3. Поэкранные ТЗ

### 3.1 Хаб-дашборд (`FlashcardsCategoryHub.tsx`)
Обычный ScrollView (<20 элементов), секции сверху вниз, вход — `FadeInDown.duration(300).delay(min(i,8)*60).springify().damping(14)` (Reanimated entering, хедер и сегменты тоже анимируются):

1. **Хедер**: «Карточки»; справа — баланс осколков (уже грузится, `flashcards.tsx:46`) + счётчик звёзд недели `N/21★`. Тап по осколкам → `shards_shop`, по звёздам → раскрытие недельного трека. Кнопка «⋯» (overflow): сообщить о баге, настройки звука/голоса.

5. **«Режимы практики»**: 4 карточки — Тренер / Повторение / **Слушание (NEW)** / **Блиц (NEW)** — со счётчиком доступного контента. Тап → `DeckPickerSheet`.

Параллакс орбов ScreenGradient: `translateY = interpolate(scrollY, ±20px)` — один worklet-стиль, за reduceMotion.

Шапка: поиск (debounce 200мс, по загруженному массиву) + фильтр **на всех вкладках, включая custom и паки**; переключатель «Список / Колода»; закреплённая нижняя панель «Тренировать / Слушать / Повторить (N)».

Кнопка «Развернуть все» удаляется целиком (перевод и так виден — вместе с ней исчезает баг десинхрона `cardFlippedState`). Swipe-влево = удалить (ReanimatedSwipeable из gesture-handler) + undo-снекбар 5с: оптимистично из стейта сразу, запись в AsyncStorage после таймаута; longpress и пункт в деталях — как альтернативы. Пункт «Редактировать» в раскрытых деталях → `flashcards_card_editor`.

Tap = флип, свайп L/R = навигация, свайп вниз/шеврон = детали (существующее Reanimated-раскрытие сохранить). Смонтировано максимум 3 карточки — весь дорогой визуал живёт только здесь.

### 3.3 Карточка `PhraseCard` — флип и жесты
**3D-флип (замена scaleX):**
```
transform: [{perspective: 1200}, {rotateY: 0↔180}]  // perspective ПЕРВЫМ
withSpring(FC_SPRING.flip)  // 450мс, dampingRatio 0.8
backfaceVisibility: 'hidden' + фолбэк-переключение opacity на 90° внутри useAnimatedStyle
   (официальный паттерн доков Reanimated — чинит старые Android и web)
параллельно scale: withSequence(1→1.04 за 120мс, →1 за 180мс)
useAnimatedReaction на пересечении 90° → runOnJS: impactAsync(Light) + SFX flip
```
Web — фолбэк на кроссфейд. reduceMotion/lowPower — кроссфейд 150мс. Автоозвучка EN при флипе (настройка «Автопроизношение», дефолт on).

**Свайп-оценка (в сессиях):** `Gesture.Pan` с `activeOffsetX([-10,10])`; порог = 35% ширины ИЛИ velocityX > 800; rotateZ ±12° интерполяцией от tx; overlay «Знаю» (зелёный) / «Учу» (оранжевый), opacity = interpolate(tx); `selectionAsync` один раз на пересечении порога (флаг в SharedValue). Улёт — withTiming 250мс Easing.out(quad); возврат — spring 350/0.7. **Undo обязателен**: кнопка «↩» 3с + swipeBack-анимация. Дублирующие кнопки ✓/✕ внизу (одноручный режим, доступность).

## 4. Система звёзд (экономика C — гибрид)

**Роль:** звёзды = метрика качества сессии, НЕ кошелёк (кошелёк — существующие осколки). Не покупаются ни за что. Выплаты — через готовый шаблон `shards_system.ts`. Ноль новых валют, ноль инфляции (weekly reset). Все числа — в `app/flashcards/stars_config.ts` (один модуль, задел под remote config).

**Заработок за сессию** (тренер, review, блиц, колода ≥10 карточек), пороги видны до старта:
- ★ — accuracy ≥ 70%
- ★★ — accuracy ≥ 90%
- ★★★ — 100% + среднее время ответа ≤ порога **пер-режимно**: свайп/выбор 5с, письменный ввод 12с, fill_gap 10с (единый порог 5с фрустрирует в письменных режимах — замечание судей).
- Слушание: фикс 1★ за сессию ≥10 карточек, кэп 2★/день.

**Недельный трек 21★**, reset понедельник 00:00 локали. Сундуки-чекпоинты (клейм тапом на хабе): 7★ → 20–40 осколков, 14★ → 40–80, 21★ («идеальная неделя») → 100–200 + косметика (рубашка колоды). Ролл 70% низ / 25% середина / 5% джекпот ×2. Эмиссия ≤ ~320 осколков/нед — ограничена по построению. Стрик ≥7 дней → порог идеальной недели 18★. Perfect session → буст XP ×1.5 на 15 минут (стимул второй сессии, без эмиссии).

**Долгосрочный хук (P1, не P2 — вердикт судей):** best-рейтинг колод 0–3★ в `fc_deck_best_stars_v1` (перезапись лучшим, показ на плитке хаба); «тускнение» через 7 дней без тренировки (визуальный isFaded — мягкий daily-триггер); одноразовые milestone-сундуки за суммарные best-звёзды: 10★ → 50 осколков, 25★ → 150 + рамка, 50★ → 400.

**Хранение и оптимистик:** `fc_stars_v1` (+SYNC_KEYS). Начисление оптимистичное: звезда летит в счётчик и стейт мгновенно, AsyncStorage-запись — после анимации; то же для клейма сундука и удаления карточек. Клейм чекпоинта: тряска сундука 3×80мс (translateY spring) → burst 12–16 частиц (lowPower — пульс+хаптика).

## 5. Звук и хаптика

`SoundService`: пул плееров на 9 SFX, `seekTo(0)` перед play. Файлы: Kenney UI Audio / uisfx (CC0), одно тембровое семейство, нормализация −16 LUFS, пики −6 dBFS, mp3 mono ≤30KB (бандл +~250KB); существующие 7 mp3 в `assets/sounds` ревизовать под семейство. Тумблеры «Звуковые эффекты» и «Автопроизношение» в настройках раздела. Правило очереди: SFX (≤400мс) → пауза 120мс → TTS, никогда одновременно. Хаптика дублирует каждый звук (фидбек при mute); из worklet — только через runOnJS; Android — только Light/selection.

| Событие | Звук | Vol | Хаптика |
|---|---|---|---|
| Флип карточки | бумажный flick 80–150мс | 0.3 | impactAsync(Light) на 90° |
| Свайп «знаю» | восходящий whoosh+tick 150мс | 0.3 | notificationAsync(Success) |
| Свайп «учу» | нисходящий whoosh 150мс | 0.3 | impactAsync(Light) — не наказываем |
| Пересечение порога свайпа | — | — | selectionAsync, 1 раз (флаг в SharedValue) |
| Верный ответ | 2 ноты вверх C5→E5, маримба, 300мс | 0.55 | Success |
| Неверный ответ | мягкий thud вниз 200мс, **без buzzer** | 0.4 | notificationAsync(Error) |
| Комбо ×3/×5/×10 | тот же мотив, питч +2/+4/+6 полутонов (пре-рендеренные файлы) | 0.6 | 2×Light с шагом 100мс |
| Звезда / сундук | sparkle 400мс | 0.5 | impactMedium |
| Финал сессии | арпеджио 3–5 нот, ≤900мс | 0.7 | 3×Light по 100мс |
| Смена карточки в слушании | тихий tick 30мс | 0.2 | — |
| Кнопки | без звука | — | selectionAsync только на сегментах/табах |

Аудио-политика: `mixWithOthers` глобально, `duckOthers` только в слушании; `playsInSilentMode: true` до первого TTS.
