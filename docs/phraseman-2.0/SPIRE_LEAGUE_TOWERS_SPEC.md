## Модель (общая для всех лиг)

Одна модель этажей — `components/spire/spire_tower_model.ts`: 15 этажей, Страж каждые 5 (5, 10, 15), вершина — 15-й; состояния этажа `mine / passed / ahead` + «вершина недели»; маркер игрока справа от своего этажа (x = x0 + w + 34), соперники слева (x0 − 26); номер этажа и подпись СТРАЖ / ВЕРШИНА слева на полях. Лига (`spireTiers.<lang>`, 0 = Гранит … 11 = Алмаз, `modules/spire/tier_names.ts`) выбирает **архетип** башни.

Эталон — чёрная башня приложения (`SpireTowerSvg.tsx`) закреплена за лигой **Оникс (7)**: в образце это дословный порт `towerSvg` из `spire.html` (те же градиенты cyl/cylG/cylCorn/cone/under, кладка рядами 11 px, окна по окружности, зубцы, конус с навершием). Остальные 11 архетипов написаны в той же манере: реальная архитектура (кладка / ярусы / окна / навершие), объём светотенью (свет слева, тень справа), встроенные в архитектуру Стражи и навершие.

## Интерфейс архетипа (как это переносится в react-native-svg)

Каждый архетип — объект с одинаковым набором методов поверх общей модели этажей; страница собирает башню одной функцией `towerSvg(league, opts)`:

- `pal` — палитра: `sky[3]`, `accent` (маркер, подпись вершины), `num / numDim / lab` (номера и подписи), `win { lit, past, dark, glow }` (окна: мой этаж / пройден / впереди / свечение) + свои цвета материала.
- `geom()` → `{ floors[{ f, y, h, w, x0, … }], H, base, top }` — геометрия 15 этажей в viewBox 390 × H (своя ширина основания, сужение, высота этажа/Стража, запас сверху под навершие).
- `defs(p)` — градиенты и фильтры с префиксом `p` (несколько башен на экране). В RN фильтры blur (свечение окон, дымка) заменить статичными радиальными градиентами.
- `floor(fl, state, opts, p)` — один этаж: корпус с материалом, окна по состоянию (`lit / past / dark`), карниз/уступ, гало и усиление на «моём» этаже, вуаль неба (α .3) на «впереди», рамка выбранного этажа, зона тапа во всю ширину.
- `after(G, opts, p)` — то, что лежит поверх этажей: парапеты/террасы/пояса Стражей, контрфорсы, крыши пагоды.
- `crown(G, opts, p)` — навершие вершины; при «вершине недели» свечение ×2.5 и подпись «ВЕРШИНА НЕДЕЛИ».
- `scene(G, opts, p)` — небо (звёзды, облака/туман/сияние), земля и основание.

Опции: `myFloor`, `summit`, `selected`, `noMarker`, `clean` (без подписей), `crop: 'top' | 'base'` (крупные планы viewBox-ом). Узлов на башню: 490–1 400 (тяжелее всех Аметист — россыпь кристаллов, и Алмаз — огранённая кладка); для RN россыпи можно проредить вдвое без потери характера.

Состояния читаются одинаково во всех архетипах: **мой** — окна `win.lit` + размытое свечение `win.glow` + гало `litfloor` + маркер + рамка; **пройден** — `win.past`; **впереди** — `win.dark` + вуаль неба; **вершина недели** — 15-й этаж как «мой», навершие разгорается, подпись.

## Прогрессия

Основание и высота растут к старшим лигам не линейно, а архитектурой: Гранит — приземистый донжон (232 → 222), Оникс — цилиндр 196 → 126 с конусом, Алмаз — самый высокий и стройный силуэт (176 → 127, этаж 48 / 62, шпиль 232 + навершие). Светлые лиги (Мрамор, Кварц, Опал) и тёмные (Базальт, Обсидиан, Аметист) чередуются, чтобы лестница читалась как ряд разных построек, а не градиент одного цвета.

## Значки рангов

В образце нарисованы значки трёх лиг (Гранит — гранитный щит, Оникс — огранённый чёрный камень, Алмаз — бриллиант); остальные — заглушки с номером. Значки остальных девяти — отдельной задачей в материале башни (см. v1 этой спеки в истории git за список идей).
