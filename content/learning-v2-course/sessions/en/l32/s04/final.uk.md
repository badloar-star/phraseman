# Урок 32 · Заняття 04 — Не та адреса

**Ситуація.** Ви з Беном шукаєте будинок Анни й помічаєте помилку в записаній адресі.

**Що ви опануєте:** робити висновок за невідповідністю й уточнювати адресу знайомою частиною без that.
**Нові слова:** —
**Повторюємо знайомі слова:** address, door, street, number

## Інтро 1

### Напевно, не той будинок

Номер на дверях не збігається з адресою Анни. Ви робите висновок: This must be the wrong house — це, напевно, не той будинок. Складіть This + must + be + the wrong house. Must виражає впевнений висновок за знайденою невідповідністю; перед назвою предмета the wrong house потрібна зв’язка be.

**Виберіть фразу для цієї ситуації.**

- ✅ **This must be the wrong house.**
- ❌ This must the wrong house. — *Перед the wrong house потрібна зв’язка be.*
- ❌ This must is the wrong house. — *Після must тут потрібна форма be.*

---

## Інтро 2

### Адреса, яку написав Бен

У вас дві записки. Уточніть адресу на записці Бена: The address Ben wrote is wrong — адреса, яку написав Бен, неправильна. Складіть The address + Ben wrote + is wrong. Частина Ben wrote уточнює address. That можна опустити: Бен написав адресу, і Ben вже названий усередині уточнення.

**Виберіть фразу для цієї ситуації.**

- ✅ **The address Ben wrote is wrong.**
- ❌ The address Ben wrote it is wrong. — *Address уже названо: it після wrote не потрібне.*
- ❌ The address Ben written is wrong. — *Потрібна минула форма wrote.*

---

## Інтро 3

### Двері замкнені — зачекали

Ви з Беном дійшли до потрібного будинку, але двері були замкнені: The door was locked, so we waited — двері були замкнені, тому ми зачекали. Складіть The door was locked + so + we waited. Перед so — причина, після нього — результат вашого рішення.

**Виберіть фразу для цієї ситуації.**

- ✅ **The door was locked, so we waited.**
- ❌ The door was locked, so we waiting. — *Потрібна повна частина we waited.*
- ❌ The door was locked, so we waits. — *Для минулої дії використовуємо waited.*
