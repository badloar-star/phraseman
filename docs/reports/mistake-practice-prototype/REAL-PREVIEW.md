# Интерактивный макет на данных приложения

Открыть `real.html`. Предыдущая версия `index.html` сохранена; добавлена ссылка на новую.

22 задания, 11 форматов взаимодействия, 50 доступных из галереи экранов. Главный слот общий с последним уроком. Доступны галерея, тренировка 3/5/10 заданий, просмотр отдельных заданий, проверка ответа, разбор, история текущей демо-сессии, пауза/возобновление, скрытие/отмена, технические состояния, светлая тема и отключение движения.

Данные:
- `real-data.js`: 17 примеров из существующего authored Learning V2 EN lesson 1/session 1, exam, diagnostic, lesson_words и irregular_verbs_data. Извлечение — `extract-real-data.cjs`.
- `extra-data.js`: 4 формата из штатного `buildLevelExamBlueprint` (A1/RU, фиксированный seed) и вопрос `getPersonalPlanQuiz('voyazh_day_1_quiz')`. Экспорт выполнен `.codex-tmp/mistake-source-audit/export-extra.cjs`/`.ts`; RN-зависимые переключатели языка заменены на фиксированный английский, генератор и данные не менялись.
- Варианты карточек/словарной практики демонстрационно составлены из реальных слов; это явно указано в инспекторе. История ошибок и действия пользователя относятся только к макету.
- Для Арены и Max показаны состояния отсутствующего исходного разбора. Личные записи/диалоги не загружались. Содержимое матчей и разговоров не придумано.

Это UI-прототип, не подключение всех адаптеров к приложению. Проверка текстовых ответов в макете упрощённая; она не заменяет production evaluator. Авторские пояснения не редактировались и не прошли новый лингвистический аудит. Отдельный банк объяснений не создан.

Голос браузера читает существующий transcript; это не опубликованная аудиодорожка курса. Микрофон запрашивается только после нажатия записи. Запись остаётся локальной, её можно прослушать и самостоятельно сравнить; автоматической оценки нет. Внешние API не вызываются. Результаты голосовой проверки доступны как отдельные явно демонстрационные состояния.

Design / preserve: прежние локальные Inter, реальные иконка и иллюстрации, palette из существующего brand-spec. Каталог ui-ux-pro-max рассмотрен, произвольная indigo-палитра не применена: узнаваемость приложения важнее общего шаблона. Крупные цели 44–54 px, один главный CTA, раскрытие ответа после попытки, 180–320 ms transform/opacity, reduced-motion. Галерея хранит исходный масштаб экрана, просмотр кликом открывает рабочую версию.

Проверки: `verification.json`, `session-verification.json`. Выполнялись в headless Microsoft Edge через Playwright, 375/768/1440 px; voice capture — с браузерным fake device. Это не проверка физического микрофона, качества озвучки или production-приложения.

Source приложения, контракты хранения и экономические правила не изменены. Созданы только файлы макета, извлечённые публичные учебные примеры и временные проверки.
