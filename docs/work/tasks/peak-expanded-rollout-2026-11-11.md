## Outcome

Игрок на сборке с кодом новых механик видит в Пике задания двенадцати новых механик на всех местах набора, где стоит
задание вида «выбор». Мера успеха: в хранилище рядом с пакетом текущей недели лежит файл накладки
`spire_packs/{lang}/{tier}/{weekId}.expanded.json` для каждого языка и шпиля, привязанный к отпечатку пакета; жалоба на
такое задание принимается сервером.

## Scope

In scope:
- `functions/src/spire_expanded_overlay.ts` — число подменяемых заданий в наборе: с 2 до «все места вида выбор».
- `tests/spire_expanded_overlay_parity.test.ts` — проверка нового поведения (в наборе не остаётся «выбора», пока пул не исчерпан).
- Выкладка одной пачкой: `spirePackWeeklyCron`, `adminSpirePackBuild`, `submitClientReport`, функции `admin_spire_task_flag`
  (`adminSpireTaskFlagList/Add/Remove`, `adminSpireTaskReportList`, `adminSpireTaskIncidentStates/SetState`) и центр жалоб админки.
- Дописывание накладок к уже опубликованным пакетам текущей недели (сам пакет не пересобирается, `force` не используется).

Out of scope:
- Независимая языковая приёмка 1 550 заданий — отдельная сессия «Проверка непроверенных заданий Пика».
- Перенос 1 750 принятых заданий старых видов — следующий шаг этой же сессии, отдельным пакетом.
- Обновление приложения в магазине: владелец смотрит на сборке с этого компьютера.

## Architecture

Сейчас: накладка заменяет не больше двух заданий «выбор» в наборе. Станет: заменяет все задания «выбор» набора.
Инварианты не меняются: пакет недели и его отпечаток прежние (старые сборки ничего не замечают, отчёты ступеней и
монеты не затронуты); в одной ступени задание не повторяется; порядок детерминирован; задания, снятые по жалобе, в
накладку не попадают. Пул языка — 300–350 заданий, в ступени заданий заметно меньше, поэтому запрет повтора в ступени
выполним; при исчерпании корзины трудности берётся соседняя.

## Security and privacy

Новых данных о человеке не собирается. Файл накладки читается по уже действующему правилу хранилища для вошедшего
пользователя; правила не меняются. Ручной пересбор остаётся за админским claim. Секретов нет. App Check не используется.

  увидят больше. Страховка: жалоба снимает задание; вычитку ведёт отдельная сессия. Владелец решение принял 11.11.

  после сборки, клиентский таймаут загрузки 12 с.

## Rollback

Выключить новые задания без выкладки: удалить файлы `*.expanded.json` текущей недели — приложение играет прежним
пакетом. Вернуть плотность: константа `SPIRE_EXPANDED_OVERLAY_PER_SET = 2` и перевыкладка сборщика.
