## Architecture

Карточка сбоя `SignInFailureCard` получает необязательные `title` и `body`: если заданы — показываются вместо текстов по виду сбоя; без `onRetry` кнопки повтора нет. Окно входа переводит все отказы в одно состояние «карточка сбоя» (вид + необязательный свой текст), красный `inlineError` остаётся только для служебных ошибок восстановления. Строка с данными и строка статуса делят одно место: пока идёт вход в фазе calm/long, видна строка статуса.
