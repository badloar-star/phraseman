Минимум ненужных элементов — на утверждение

Правило владельца: на экране только то, что нужно в этот момент — одна мысль, одно главное действие, максимум одно вторичное. Слева — экран как сейчас в приложении (образец повторяет код), справа — тот же экран без лишнего. Ничего не перерисовано: справа элементы просто убраны. Утверждаете по пунктам; код правится после R1, кроме уже сделанного.
