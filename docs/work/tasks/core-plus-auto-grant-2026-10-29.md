## Outcome
- Общий модуль `functions/src/plus_grant.ts`: Plus тем же механизмом, что Telegram (`vip_active/vip_plan/vip_until`,
  проекция доступа), срок = max(текущий конец любого Plus, сейчас) + N (месяцы календарные / дни), идемпотентно
  по ключу в журнале `plus_grant_ledger/{key}`; логи `[PLUS-GRANT]` на каждом шаге и в каждом catch.
- Подсчёт конкурса: «любой урок» учитывает и маску пройденных занятий V2; тесты «только V2 → засчитан» и границы суток
  для месяцев 28/29/30/31 дня.
- Передача: финализация 1-го числа → Plus 3/2/1 месяца местам 1/2/3 автоматически (ключ `{yyyy-mm}:place{n}`), поле
  для истории победителя, крайние случаи (ничья, 0 голосов, удалённый набор, удалённый аккаунт) — на решение;
  лесенка приглашений 14 дней через тот же модуль.
- Тест клиента: Plus из `vip_*` открывает всё (правило PLUS_OPENS_ALL_LESSONS).

## Scope
In scope: новые файлы `functions/src/plus_grant.ts` + тест, `functions/src/community_month_tally.ts` + тест (мои),

## Architecture
Чистое ядро `buildPlusGrantPatch` (тестируется без Firestore) + транзакция `grantPlusOnce` (журнал → профиль → проекция).

## Security and privacy
Пишется только сервером; журнал выдачи содержит uid — при удалении аккаунта стирать (account_delete), отмечено в передаче.
Новых данных о человеке нет, политику не меняет (Plus-выдача уже описана как промо/рефералка).
