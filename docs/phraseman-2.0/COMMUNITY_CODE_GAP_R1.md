# Сообщество: где код отличается от утверждённого образца `community.html` (R1, 12.10)

Для Дизайна. Основание: приказ владельца 29.09 «вкладка «Друзья» 1 в 1 по макету community.html» (комментарий в `app/(tabs)/friends.tsx`, `components/friends/FriendsGlassKit.tsx`). По указанию координатора 12.10 образец `docs/design/v2-app/community.html` возвращён к состоянию до `daad65a97` (сверено: тот же blob `84de2af0a`), расхождения — **дефект кода**, пока владелец не скажет иначе.

## ⚠ Сначала решить: два утверждённых образца спорят друг с другом

- `community.html` (приказ 29.09): у вкладки «Сообщество» **свой заголовок** («Сообщество», «Друзья») с подписью, стрелкой «назад» и **сегмент-пилюлей** «Шпиль / Друзья / Наборы»; каталог — крупные карточки с обложкой.
- `packs-simple.html` (**04.10**, под замком, «один простой вариант … одобрен — да»): сверху **текстовые вкладки «Шпиль · Друзья · Наборы» с полосой под активной**, справа поиск и «EN ⌄», заголовок «Наборы сообщества», плотные строки, док «Новые · + · Топ».
- Код `app/(tabs)/community.tsx` прямо ссылается на второе: «решение владельца 04.10 — одна шапка на всю вкладку, без заголовка «Сообщество»» (`packs-simple.html` кадр 1, `.tabs3`).

То есть код следует **более позднему** утверждённому образцу. Если владелец утром скажет «побеждает community.html 29.09» — правки ниже обязательны; если «побеждает packs-simple.html 04.10» — правим уже `community.html` (журнал `MOCKUPS_ALIGNED_TO_CODE_R1.md`, блок A, строка `community.html`; версия образца «по коду» — коммит `daad65a97`, откат делается `git checkout daad65a97 -- docs/design/v2-app/community.html`).
