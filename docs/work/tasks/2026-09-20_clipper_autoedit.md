## Outcome

Владелец кладёт папку видео в `content/clipper/input/` и одной командой получает
в `content/clipper/output/` готовые вертикальные ролики формата:
фрагмент оригинала → стоп-кадр в момент конца английской фразы → кадр обесцвечен →
поверх текст фразы и перевод → озвучка объяснения (ElevenLabs) → возврат к видео.

Успех измеряется так: на прототипном ролике получен .mp4 9:16, где пауза стоит
ровно на конце выбранной фразы (±0.3с), текст читаем, озвучка совпадает по длине
с паузой. Без ручного монтажа.

## Scope

In scope:
- `content/clipper/` — новый изолированный модуль: скрипты, конфиг, вход/выход.
- Транскрипция: локальный faster-whisper (установлен), таймкоды по словам.
- Отбор фразы: вызов модели, оценка качества, порог отсечения перед платной озвучкой.
- Озвучка: адаптер поверх ElevenLabs с возможностью смены провайдера.
- Монтаж: ffmpeg (установлен, v8.1).

Out of scope:
- Приложение Phraseman: НИ ОДИН файл приложения не меняется.
- Публикация в TikTok/IG — ролики только складываются в папку.
- Скачивание видео с чужих каналов — вход это готовая папка владельца.

## Architecture

Текущая граница: отсутствует, модуля нет.

Целевая: `content/clipper/` полностью автономен, как `content/marketing` и
`content/lingman`. Не импортируется приложением и не импортирует его.
Поток: input → transcribe → select (модель + порог) → tts → render → output.
Каждый шаг пишет промежуточный артефакт в `work/`, поэтому падение на шаге N
не заставляет переделывать шаги 1..N-1.

Инвариант: озвучка заказывается ТОЛЬКО после прохождения порога качества —
платный вызов не делается для отбракованного момента.

Решение: провайдер TTS вынесен за интерфейс. Повод — подписка ElevenLabs
стоит на отмене 27.09.2026 (`pending_change: cancellation`), конвейер не должен
умереть вместе с ней.

## Security and privacy

Личных данных не обрабатывает: на входе публичные видео владельца, на выходе файлы
на его же диске. Firestore, аккаунты пользователей, детские данные не затронуты —
приложение не касается вовсе, поэтому privacy policy обновления НЕ требует.

Секреты: `ELEVENLABS_API_KEY` читается из окружения, в репозиторий не пишется.
`content/clipper/input/`, `work/`, `output/` уходят в .gitignore — чужие видео
не должны попасть в git (вес + копирайт).

Копирайт: конвейер добавляет разбор поверх фрагмента (transformative use), но
ответственность за права на исходники остаётся на владельце. Отмечено в README модуля.

## Technical debt

- **Accept temporarily:** автоотбор фразы моделью даёт ~1 из 5 слабых выборов.
  Владелец сознательно выбрал «рендерить всё подряд» без ручной проверки.
  Смягчение: порог качества в конфиге (`min_score`), отсекает худшее до оплаты.
  Владелец, пересмотр — после первой партии из 10+ роликов.
- **Contain:** зависимость от ElevenLabs. Граница — адаптер `tts.py`.
  Условие выхода: подписка отменяется 27.09 — до этой даты либо продление,
  либо переключение адаптера на другой провайдер.
- **Pay now:** локальная транскрипция вместо ElevenLabs STT — квота символов
  исчерпана на 92%, тратить её на распознавание нельзя.

## Verification

- `python content/clipper/run.py --one <видео>` даёт .mp4 в `output/`.
- ffprobe готового файла: разрешение 1080x1920, есть аудиодорожка.
- Глазами: пауза совпадает с концом фразы, текст не обрезан по краям,
  озвучка не наезжает на речь спикера.
- Логи с единым префиксом `[CLIPPER]` по правилу владельца: вход, каждое
  ветвление со значением, длительность вызовов, каждый ранний выход и catch,
  финальный результат. Артефакт — `work/<видео>/trace.log`.
