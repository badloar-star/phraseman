## Outcome

Сцена «Диалогов» получает два недостающих входа: (1) строка «голосом N раза в день» в состоянии «лимит» берётся из лимита Free (FREE_DIALOG_VOICE_DAILY_LIMIT), при неизвестном доступе — без числа;
(2) состояние day_done («Сегодня разговор засчитан») включается по локальной отметке, которая пишется при засчитанном завершении диалога (диалог закончил собеседник и у ученика была реплика — то же условие, что у «пройдено ✓»).

## Scope

- app/dialogue_v2_day_mark.ts — отметка «сегодня диалог засчитан»: AsyncStorage, ключ по области аккаунта (поколение + stableId), значение — локальная дата; память мгновенно, диск фоном; подписка для экрана.
- app/dialogue_v2_session.tsx — одна строка: рядом с markDialogueV2Done звать markDialogueV2DoneToday при засчитанном завершении.
- app/cloud_sync.ts — префикс dialogue_v2_day_done_v1: в ACCOUNT_LOCAL_KEY_PREFIXES (стирание, перенос и проверка остатка вместе с аккаунтом).
- components/dialogs/scene/use_dialogs_scene_hub.ts — dayDone из отметки; voicePerDay из лимита/доступа.
- tests/dialogue_v2_day_mark.test.ts.

## Architecture

Отметка независима от хранилища «пройденных» (dialogue_v2_done_store): тот хранит набор id по языкам, этот — одну дату на аккаунт; ключи не пересекаются, прежние тесты хранилища не затронуты.
Источником правды остаётся условие засчёта из dialogue_v2_session.tsx. Серверу ничего не отправляется, Firestore не читается и не пишется. Новый день — по локальной дате телефона (app/local_date).
Стирание на диске — только общим списком ACCOUNT_LOCAL_KEY_PREFIXES (отдельного multiRemove нет — иначе ломается fail-closed стирание аккаунта); память отделена по области аккаунта, чужой аккаунт отметку не прочтёт.

## Security and privacy

Хранится только дата (YYYY-MM-DD) и факт «засчитан»; без текста диалога, id сценария и данных собеседника. Новых сторонних сервисов нет. Политика приватности не меняется (локальный флаг в составе прогресса аккаунта).

## Technical debt

Полночь при открытом хабе не перерисовывает сцену до следующего входа на экран.
