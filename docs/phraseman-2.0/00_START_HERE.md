# PhraseMan 2.0 — начать здесь
Версия 1.0 · 23 сентября 2026

Это рабочий пакет документации, а не готовый новый релиз. Внутри 257 задач в 24 эпиках, полные текстовые исходники и шесть скриншотов, решения, спецификации, модели/effort, правила приёмки и передачи работы. Предыдущий макет «Графит» отклонён и не является утверждённым дизайном.

## Что открыть владельцу
`05_OWNER_GUIDE.pdf` — путеводитель по пакету; редактируемая копия — DOCX.
`02_MASTER_PLAN.md` — последовательность, эпики, приоритеты и точки решения.
`board.html` — автономная доска с поиском по всем задачам, критериями и моделями. Это доска документации, НЕ макет приложения.
`03_DECISIONS.md` — финальные указания, предложения и открытые конфликты отдельно.

## Что давать каждой новой сессии
`01_BIBLE.md`, `04_CURRENT_STATE.md`, `03_DECISIONS.md` и одну карточку `tasks/PM-NNN.md` со своей спецификацией. Для первой сессии уже есть `prompts/01_START_READONLY.md`. Не передавать весь архив в контекст каждого агента; точные исходные выдержки находятся в карточке и реестре требований.

## Два способа пользоваться
Без программирования: распаковать ZIP, открыть PDF/board.html, выбрать Task ID, передать указанные файлы в Codex. Обновления статуса вносить в `registries/tasks.json` и журнал, затем пересоздать представления.

С Python 3.10+ из корня распакованного пакета:
```sh
python tools/validate.py
python tools/make_prompt.py PM-001
python tools/render_views.py
```
Скрипты работают локально, без сторонних Python-библиотек, ключей, API, Git-записи или доступа к Firebase. Они не запускают Codex и не меняют приложение. Для DOCX/PDF генераторы не нужны — финальные файлы уже входят в комплект.

## Где находится правда о прогрессе
Реестр `tasks.json` — единственный изменяемый источник статусов и acceptance. Карточки, мастер-план и board.html генерируются из него. Принятые критерии имеют evidence, а done дополнительно требует рецензента и подтверждённые gates. Нельзя выдумать 10% по впечатлению: процент — принятые критерии / все критерии задачи. Создание документации не означает, что соответствующая фича реализована.

## Сохранность и приватность
Raw текст сохраняет настроение и формулировки владельца. Скриншоты — исходные файлы. `source_manifest.json` фиксирует их hashes. Реестр источников допускает точные цитаты и нормализованную расшифровку скриншотов с разной маркировкой. На момент выдачи исходники проекта прочитаны выборочно; полного построчного аудита и текущего биллинга нет.

Исходный текст/скриншоты предназначены для владельца и доверенных рабочих сессий. Не коммитить их автоматически в публичный GitHub. Существующий AGENTS.md проекта не перезаписывать: архивный AGENTS — предлагаемый блок правил для слияния. Никакие ветки не удалены, агенты не запущены, конфигурация Codex не установлена.
