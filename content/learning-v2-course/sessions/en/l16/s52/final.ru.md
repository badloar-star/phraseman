# Английский · Урок 16 · Занятие 52 — Выбрать дорогу для прогулки

**Ситуация.** Вы различаете прогнозы, намерения и согласованные будущие дела.

**Что вы освоите:** will / going to / Present Continuous: future form contrast
**Новые слова:** uneven, shaded, paved, unpaved

## Интро 1

### Мнение о будущем

Will подходит для мнения-прогноза, going to подчёркивает намерение, Present Continuous — уже устроенное будущее дело. Формы могут пересекаться; здесь выбираем форму по указанному смыслу, а не объявляем другую всегда неверной. uneven — неровный — о поверхности. Вы ещё не гуляли по этой дорожке и предполагаете, что поверхность будет неровной. I think the path will be uneven. — Думаю, дорожка будет неровной. Передайте мнение-прогноз через will.

**Выберите фразу для этой ситуации.**

- ✅ **I think the path will be uneven.**
- ❌ I think the path is going to be uneven. — *Эта форма возможна в другом контексте; здесь тренируем указанную. Передайте мнение-прогноз через will.*
- ❌ I think the path will to be uneven. — *Нарушено построение формы.*
