# Экзамены глав урока 23 — задания на чтение

Семь глав урока. В каждой попытке приложение берёт 10 заданий из списка: каждая тема попадает хотя бы раз, остальные идут в запас для пересдачи. Сдал — 8 из 10.

Как читать: слева то, что видит человек, справа ожидаемый ответ. Через «/» — другие ответы, которые тоже засчитываются. Сокращения (I'm, it's, don't) засчитываются всегда и здесь не повторяются.

Правила: только слова и формы из эпизодов до экзамена (проверяет автоматический сторож); ситуация и ответ сходятся по смыслу; на каждую тему не меньше трёх заданий; вопросов нет — общий сторож пока запрещает знак вопроса.

Банки написаны, но в приложении не включены: подключает Learning V2.
