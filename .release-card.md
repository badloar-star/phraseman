# Release card

## Type

fix

## Goal

Release the integrated fixes for friend lookup/navigation, Google sign-in, rapid lesson taps, Premium/AI access, purchases, energy and free limits, account-safe multi-device sync, and iOS App Check attestation.

## Allowed changes

- Narrow React Native fixes and focused regression tests for the reported user flows.
- Server-side friend lookup and Premium entitlement resolver fixes.
- AI error-state recovery, the existing three critical AI warm-instance settings, iOS App Attest production entitlement, and current app release metadata.
- Canonical RevenueCat entitlement checks, post-purchase lesson continuation, account-scoped persistence, energy restoration, and the approved monetization limits/copy.
- Zero-extra-read exam-medal hydration and safe cloud progress merging.
- Exact affected Firebase Functions/Rules deployment and an iOS production build submitted to TestFlight.

## Forbidden changes

- No unrelated Hosting/admin deployment, destructive production-data mutation, or broad all-functions deployment.
- No unrelated account-deletion/backend changes and no removal or replacement of existing app functionality.
- No model/API calls from the local Codex session.

## Risk level

high — the integrated release touches identity, paid access, purchases, cloud restore, AI callable configuration, Firestore Rules, and native App Check metadata; deployment is limited to the reviewed surfaces and uses a new TestFlight build.

## Manual tests

- Smoke: search an existing friend by exact nickname, open/leave Friends, enter an AI dialogue with admin Plus, and verify the Google button remains visible.
- Regression area: friend code search, friend live lists, normal paid/free paywall behavior, lesson word selection, and account-linked Premium.
- Trigger AI explanation failures and verify they are shown as honest retryable errors, never as fabricated successful explanations.
- Verify the iOS archive contains `com.apple.developer.devicecheck.appattest-environment=production`.
- Upgrade from previous version: after explicit authorization, verify the chosen TestFlight/OTA release path after a complete restart.
- User type(s): existing admin-VIP, existing paid, existing free, and provider-linked accounts.
- Platform-specific checks: verify the OTA update group contains both iOS and Android manifests; iOS TestFlight is the primary reported path.
- Performance check: switch away from Friends immediately and confirm tabs remain responsive while auth/network work is pending.
- Multi-device regression: verify a newer local streak is not reduced by an older cloud snapshot and exam medals hydrate without an added Firestore read.

## Diff review

- Every changed file maps to one reported failure or its focused regression coverage.
- Main risks are false entitlement inheritance and unguarded Firestore listeners; both have ownership/revoke and subscription-gate tests.
- The existing AI warm-instance settings are preserved only for the three already-designated critical AI functions; friend lookup receives no `minInstances` increase.
- Local validation does not invoke paid AI generation.
