# Аудит приложения: чего не хватает на экранах (2026-09-21)

Аудит «пробелов интерфейса», а не багов. Читался код 144 экранов и ~200 компонентов.
Метод: JSX каждого экрана — какие кнопки реально отрисованы, какие состояния
(loading / empty / error) обработаны, куда можно уйти с экрана.

---

## 0. СКВОЗНЫЕ ПРОБЕЛЫ (бьют по всему приложению)

Это не «на одном экране», а системные дыры — чинятся один раз, улучшают всё.

| Что | Замер | Почему важно |
|---|---|---|
| **Pull-to-refresh** | `RefreshControl` есть в **3 файлах из 144** (club_screen, lingman_videos, referrals) | Жест «потянуть вниз» — рефлекс. Его отсутствие на Главной, в Статистике, в Достижениях читается как «зависло» |
| **Поиск** | Поиск есть в **2 экранах** (flashcards_collection, flashcards_packs) | Нет поиска: по 32 урокам, по настройкам (15+ пунктов), по участникам лиги (~30), по списку ошибок, по друзьям |
| **История транзакций валют** | Экрана **нет ни одного** (внутренние леджеры есть: `personal_plan_xp_ledger`, `energy_session_operation_ledger`, `daily_journey_freeze_ledger`) | Руны/жемчуг/осколки тратятся, но человек не может посмотреть, куда ушли. Первая причина обращений «у меня пропали руны» |
| ~~**Списки без пустого состояния**~~ | ~~18 файлов~~ | ❌ **ОПРОВЕРГНУТО владельцем 21.09.** Grep не отличал списки, которые физически не бывают пустыми. ## 1. ГЛАВНЫЙ ЭКРАН

- **Нет pull-to-refresh.** Единственное обновление — баннер при полном отказе загрузки. `app/(tabs)/home.tsx:4156`
- **Крестик на карточке-подсказке гасит ВСЕ подсказки навсегда** (`completeHomeFeatureTips()`), а не текущую. Один случайный тап — и человек больше не увидит ни одного совета. `home.tsx:4766`
- **Карточка-подсказка без счётчика** «2 из 5» и без точек-пагинации — непонятно, сколько ещё свайпать. `home.tsx:4723-4814`
- **Заморозка серии списывает жемчужины одним тапом, без подтверждения.** `home.tsx:3295-3327`
- **Шторка «ошибок пока нет» — тупик:** только кнопка «Понятно», нет перехода в уроки, где ошибки появятся. `components/home/HomeMistakesLockedSheet.tsx:43-53`
- **Кнопка «Обновить» в баннере ошибки не показывает загрузку** — прячет баннер и молча перезапрашивает; при втором отказе баннер моргает. `home.tsx:5115-5126`
- **Тост ошибки заморозки серии без кнопки «Повторить»** — «проверь связь и попробуй ещё раз», но тянуться надо заново. `home.tsx:3341-3351`
- **Карточка YouTube при сбое сети молча исчезает** — не placeholder, а `null`. Человек не узнает, что раздел существует. `components/home/HomeYoutubeFeatureCard.tsx:129-146`
- **Частичный отказ загрузки не индицируется вовсе** — баннер только при `loadFailedNoData` (полный провал на первом запуске).
- **НОВИЧОК ВИДИТ ПУСТОЙ ГЛАВНЫЙ СЛОТ.** Карточка «Продолжить урок» рисуется только при `lastLesson !== null` (`home.tsx:3583, 4653`) — у человека без единого пройденного урока главный слот экрана пуст, и нет CTA «Начать урок 1». Первое впечатление о приложении — пустота.
- **Карточка «Цель лиги» исчезает без объяснения**, когда лиги нет: `if (homeLeagueChest) {...}` без `else` (`home.tsx:4913`). Раздел «Сегодня» молча укорачивается — читается как баг.
- **Плитки «Уроки / Диалоги / Карточки» без счётчиков-бейджей** — непонятно, где скопились дела, пока не зайдёшь.
- **Тултип энергии не даёт перехода «пополнить»** — при нуле энергии путь к покупке надо искать отдельно. `home.tsx:4450`
- **Профильная кнопка и аватар героя — два похожих круга с разным поведением** (модалка профиля vs `/avatar_select`), различие только в `accessibilityLabel`.

## 2. ОБУЧЕНИЕ (Learning V2 + старые уроки)

### Карта курса и вход в занятие
- **Нет поиска/перехода к уроку по номеру** — 32 урока × 56 сессий листаются руками.
- **Нет общего прогресса курса** в шапке (X из 32 уроков / % курса) — только прогресс внутри урока.
- **Подготовка занятия без индикатора** — кнопка тускнеет (`actionsDisabled`), но нет спиннера/«Готовим занятие». `components/LearningV2SessionOutcomeSheet.tsx:230-243`
- **Ошибка подготовки сессии не показывается пользователю** — только `DebugLogger.error`.
- **Нет экрана «весь курс пройден»** — карта просто заканчивается.

### Внутри сессии
- **Нет паузы и выхода с сохранением.** Уход в фон дольше короткого промежутка = `restartInterruptedRun`, прогресс сессии теряется. Предупреждения нет. `app/learning_v2_direct_session_player_v1.tsx:1493-1514`
- **Нет «пропустить задание»** — только тратить попытки до `attempts_exhausted`.
- **Медленная озвучка зависит от типа задания** — `playPracticeSlowReferenceAudio` подключён только в части режимов, а не в общем футере.
- **Разбор ошибки только со второй ошибки и никогда на проверках глав** (`wrongCount >= 2 && !isCheckpoint`) — на checkpoint человек ошибается вслепую.

### Итог сессии
- **Нет кнопки «Начать следующее занятие»** — хотя подпись обещает «Следующая сессия уже открыта». Только «Продолжить» → назад на карту.
- **Нет «Повторить занятие»** при результате 0–1 звезда.
- **Нет разбора ошибок** — только агрегаты (точность, время), без «вот что ты не угадал» и без ссылки в «Мои ошибки».
- **Завершение всего курса выглядит как завершение одной сессии** — нет отдельного праздника/сертификата/шаринга.

### Старые уроки
- **Нет «замедлить озвучку»** в lesson1, lesson_words, lesson_irregular_verbs, preposition_drill — скорость только глобальная из настроек.
- **«Объясни проще» доступно только ПОСЛЕ ответа** — когда непонятно ДО попытки, помощи нет. `lesson1.tsx:1658`
- **Нет «пропустить фразу»** в lesson1.
- **Теория с интерактивными блоками только для урока 1** (`hasNewTheory = lessonId === 1`) — остальные 31 урок получают простыню текста без проверки понимания. `lesson_theory_v2.tsx`
- **Нет оглавления/якорей в теории** — длинные грамматические темы листаются вручную. `lesson_help.tsx`
- **lesson_complete не показывает, на каких фразах ошибся** — данные есть в прогрессе, разбора нет.
- **«Добавить в карточки» есть в lesson1, но отсутствует** в preposition_drill и lesson_irregular_verbs — нельзя сохранить трудную форму с места ошибки.
- **Заблокированный V2-курс сообщает «в разработке» без срока** — тупик без понимания, когда вернуться.

## 3. КАРТОЧКИ (Flashcards)

### Тренировки — самый большой пробел раздела
- **Ни в одном из 4 режимов нет паузы** (swipe / recall / speaking / blitz). В блице пауза есть только как технический механизм при потере фокуса, кнопки для человека нет.
- **Выход из тренировки молча теряет прогресс, без подтверждения.** `leave` → `safeRouterBack` сразу. `flashcards_recall_session.tsx:186-205`, `flashcards_blitz_session.tsx:526-528`. `ThemedConfirmModal` в проекте уже есть — применён к удалению, но не к выходу из сессии.
- **Нет «Не знаю» / «Пропустить карточку»** в recall — только угадывать или показывать ответ и ставить себе оценку.
- **Нет отмены последнего ответа** («ошибся пальцем») — `answerLockedRef` необратим.
- **Нет «замедлить озвучку» в тренировке «Говорить»** — эталон всегда с системной скоростью (`speak(c.en, undefined, ...)`), хотя в `flashcards_voice_picker` есть три пресета. Чтобы замедлить — надо прервать тренировку, зайти в настройки голоса, вернуться.
- **Нет «озвучить ещё раз» по запросу** в recall/blitz — если не расслышал в блице, повторить нельзя.
- **Нет продолжения с того же места** — весь прогресс сессии в `useRef`, обнуляется при закрытии.

### Итог тренировки
- **Не показывает, какие именно слова оказались слабыми** — только «верно / ошибок / точность %». «Добить: Ещё учу (N)» — чёрный ящик, непонятно, что попадёт в повтор.
- **Нет «что дальше»** — ни «попробуй эти же слова устно», ни «вернись через 3 часа».

### Коллекция и наборы
- **Нет поиска по каталогу наборов сообщества** (ни по названию, ни по автору) и **нет поиска по «Моим наборам»**.
- **Нет сортировки** нигде: ни карточек в коллекции, ни наборов (по дате / алфавиту / силе слова).
- **Нет фильтра «только трудные»** — хотя `WordStrength` уже посчитан и рисуется точками на каждой карточке. Дешёвая фича на готовых данных, без новых чтений Firestore.
- **Удаление набора без undo** — хотя для отдельной карточки undo есть (`UndoDeleteSnackbar`). Непоследовательно.
- **Undo-снэкбар без таймера** — непонятно, сколько осталось на отмену.
- **Нет «поделиться набором»** — есть «пожаловаться», «опубликовать», «редактировать», но виральной кнопки нет у UGC-контента.
- **Нет импорта/экспорта карточек** — только ручной ввод по одной.
- **В редакторе карточки нет удаления и дублирования** — удалять надо возвращаться в коллекцию.
- **Массовое выделение только для создания набора и удаления** — нельзя массово переместить в категорию.

## 3b. ЭКЗАМЕНЫ И ТЕСТЫ

- **Финальный экзамен (50 вопросов / 60 минут) не переживает закрытия приложения.** Нет resume: `phase` сбрасывается в `intro`, час работы теряется. Подтверждение есть только на Android hardware-back; на iOS пути выхода с предупреждением нет вовсе. `app/exam.tsx:430-464`
  *Контраст:* `LevelExamV2` (зачёт по уровню, англ.) это уже умеет — `restoreLevelExamAttempt`, `pauseAndExit`, exit-confirm. Образец под рукой.
- **Экзамен при пустом списке вопросов падает в пустой экран** — `if (!q) return null;` без текста и без «назад». `app/exam.tsx:907-908`
- **Кнопка «Начать тест» молча не работает**, пока грузятся вопросы (фр. контент) — не дизейблится, спиннера нет. `app/exam.tsx:696-708`
- **Ни один из трёх тестов не показывает разбор неверных ответов** — только список тем с галочками (exam), медаль/XP (level_exam), уровень A1–C2 (diagnostic). Обучающая ценность экрана результата близка к нулю.
- **Диагностика не предупреждает про 30 секунд на вопрос** — человек узнаёт, когда таймер уже побежал. `diagnostic_test.tsx:59, 1561-1736`
- **В `LevelExamV2` нельзя ни вернуться назад, ни пропустить вопрос** — `Continue` задизейблена без ответа. В `exam.tsx` skip есть. Разный UX в двух экзаменах.

## 4. АРЕНА

- **С экрана результата нельзя открыть профиль соперника и добавить в друзья** — самый азартный момент не конвертируется в социальную связь. `arena_results.tsx`
- **Нет «поделиться результатом»** в overflow-меню Арены.
- **Нет реванша с тем же соперником** после дуэли с другом — только новый случайный поиск.
- **Жалоба доступна только с экрана результата** — из истории матчей пожаловаться постфактум нельзя. `arena_history.tsx`
- **Поиск соперника без ориентира «обычно 10–20 сек»** — на 30-й секунде непонятно, норма это или зависло.
- **Нет «сыграть с ботом» после долгого ожидания** (фолбэк в коде есть, пользователю не предлагается).
- **История матчей без фильтра** по режиму (`row.mode` есть в данных) и по периоду.
- **`arena_invite.tsx` захардкожен на русском** — единственный экран Арены без `triLang`. Для non-RU выглядит как баг.
- **Нет «отменить отправленный вызов»** у отправителя.
- **arena_tops при одиноком списке не предлагает пригласить друга** — идеальный контекст («не с кем сравнивать») пропадает.

## 5. ДРУЗЬЯ

- **Нет статуса «онлайн / был недавно»** — в модели `FriendProfile` его нет вовсе.
- **Нет свайп-действий и долгого тапа на строке друга** — подарок/зов только через шторку деталей.
- **Нет импорта контактов** и предложения «найти в контактах».
- **Пустой список друзей не предлагает поделиться своим кодом** — хотя `Share.share` уже работает в referrals.
- **Нет отдельного экрана входящих вызовов** — дуэли теряются среди списка друзей.
- **В карточке найденного пользователя нет состояния «заявка отправлена»** — только тост ниже.

## 6. ЛИГИ / КЛУБ

- **Нет счётчика «до зоны повышения осталось N рун»** у своей строки — есть общая формула и гонка, но считать приходится самому.
- **Правило понижения нигде не проговорено текстом** — только цветовая зона. (Учитывая инцидент 17.08 с неработающим понижением — это ещё и вопрос доверия.)
- **Нет поиска/перехода к участнику** — только «прыгнуть к себе».
- **Нет истории прошлых недель** — динамику повышений/понижений посмотреть негде.
- **Нет списка, кто поблагодарил за буст лиги** — только счётчик сердец.

## 7. РЕФЕРАЛЫ

- **Карточки приглашённых друзей не кликабельны** — нельзя открыть профиль.
- **Нет истории выигранных призов рулетки** — только разовая модалка.
- **Нет «скопировать ссылку»** отдельно от системного шаринга.
- **Срок жизни ключей виден только в режиме сворачивания программы** — в обычном режиме не проговорён.

## 8. РАБОТА НАД ОШИБКАМИ

- **Карта слабых мест не кликабельна** — тап по «артикли» должен фильтровать список, но `View` неинтерактивен. `mistakes_hub.tsx:207-222`
- **«Откуда приходят» тоже не кликабельно** — тап по «Арена» ничего не фильтрует. `mistakes_hub.tsx:235-248`
- **Кнопки «скрыть ошибку» нет, хотя механизм есть в данных** (`hidden`/`restored` в таймлайне `mistake_detail.tsx`) — классический для этого проекта случай «механизм есть, интерфейса нет».
- **Нет поиска и фильтра по дате** в списке ошибок — при 30+ только скролл.
- **Нет удаления записи об ошибке** (опечатка по невнимательности живёт вечно).
- **Нет экспорта** списка ошибок.

## 10. НАСТРОЙКИ

- **Нет поиска по настройкам** — 6 секций, 15+ пунктов и растёт.
- **Покупка темы за жемчуг без экрана подтверждения** — тап «Открыть за N» сразу списывает. `settings_themes.tsx:318-348`

- **Нет «включить/выключить всё»** для 10 тумблеров уведомлений — «оставить только важное» = 8-9 тапов.
- **Ряд «Время» тускнеет, но не объясняет почему** — надо сначала включить ежедневное напоминание. `settings_notifications.tsx:353-368`
