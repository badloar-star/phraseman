## Outcome

Разбор причины и журнал `[HOME-VIDEO-LANG]`; условие «лента только для интерфейсов, на языке которых есть ролики» подготовлено и ВЫКЛЮЧЕНО. Включать решает владелец.

## Разбор по коду

- Лента Главной выбирается по ЯЗЫКУ ИЗУЧЕНИЯ (`studyTarget`), не по языку интерфейса. `homeVideosVisible = isLearningSurfaceReady(studyTarget, 'videos')` (все языки ready по D132/D130); для `es/fr/de/it` — канал каталога YouTube по тегу языка (`resolveVideoChannelForStudyTarget`, `home_video_rail_source.ts`), канала нет → лента скрыта (`homeV2VideoNoChannel`); для `en` — RSS канала Professor Lingman (`lingman_youtube.ts`, активный канал из настроек/каталога), он русскоязычный.
- Фильтра по языку интерфейса нет нигде: ни в `home_video_rail_source.ts`, ни в `lingman_youtube.ts`, ни в `video_language_contour.ts` (теги канала — языки изучения). Поэтому испанский интерфейс + изучение английского = русские обложки Professor Lingman.
- `localeDefaults` каталога — по тегам языков изучения, к языку интерфейса отношения не имеет.

## Scope

In scope: `app/home_video_language_gate.ts` (чистая функция, константа-флаг `HOME_VIDEO_RAIL_LANG_FILTER_ENABLED = false`, журнал `[HOME-VIDEO-LANG]`), подключение в `app/(tabs)/home.tsx` (условие показа ленты и эффект журнала), тест.

Out of scope: смена каналов, метаданные «язык роликов» в каталоге (потребуют серверной схемы), вкладка «Видео».

## Architecture

Условие включено только при `HOME_VIDEO_RAIL_LANG_FILTER_ENABLED === true`: лента скрывается, если интерфейс не на кириллице (всё, кроме ru/uk) и ≥ 50 % названий загруженных роликов — кириллица. Это узкий признак наблюдаемого дефекта; канал с латинскими названиями, но русским закадровым текстом он не поймает (нужны метаданные языка в каталоге — предложение Ядру). Пока флаг выключен, поведение не меняется (условие всегда ложно).

## Security and privacy

Данные пользователя не затрагиваются; в журнал идут язык интерфейса, язык изучения, канал, число роликов и доля кириллических названий.
