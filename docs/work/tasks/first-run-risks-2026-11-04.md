## Architecture

Сторож читает исходник `app/rank_gates_new_user.ts` и при `RELEASE_CUT=1` (или `STORE_RELEASE=1`) падает, если значение — `MAX_SAFE_INTEGER` или не число-метка после 2026-01-01; без переменной — проходит и печатает напоминание. Включается в проверку среза сборки.
Офлайн: `judgeRankGateUser` с `accountCreatedAtMs=null` → `account_age_unknown`, входит в `UNSTABLE_REASONS` — отметка когорты не пишется; бонус пропущен без флага; на следующем завершении занятия при известном времени аккаунта выдаётся.
