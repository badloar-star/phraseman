Башни лиг Шпиля · v2

Двенадцать лиг-камней (Гранит … Алмаз). У каждой лиги — своя архитектура со своей геометрией: силуэт, материал, свет, атмосфера. Эталон качества — чёрная башня приложения, она закреплена за лигой «Оникс». Первый круг: Гранит (крепостной донжон), Оникс (эталон), Алмаз (ледяная игла с парящим бриллиантом). Остальные девять — после утверждения. Всё — SVG кодом, без картинок; каждая башня — параметры и набор форм поверх модели этажей (15 этажей, Страж каждые 5).

Лестница прогрессии

Башни в одном масштабе, основания на одной линии. Тап по башне — переключить лигу.

Крупный план

Слева — навершие и верхние этажи, справа — основание и нижние этажи.

Итог недели — повышение

Старая башня остаётся позади, новая — в полный рост.

Параметры (для переноса в код)

Каждая лига = архетип (своя геометрия и набор форм) + палитра. Общая модель этажей — spire_tower_model.ts: 15 этажей, Страж каждые 5, состояния «пройден / мой / впереди / вершина недели».
