# Концепция: Phraseman Flashcards 2.0 — «Колода»

Единая метафора раздела: **физическая колода карт в руках**. Всё — хаб, коллекция, тренировки, слушание — работает с одним визуальным объектом «карточка», у которого один вид, один флип, один звук, одна хаптика. Премиальность достигается не количеством эффектов, а тем, что карточка везде ощущается как один и тот же тактильный предмет.

Технический фундамент (P0, до любых фич): миграция домена на Reanimated-паттерны (transform+opacity only), `expo-audio` вместо expo-av, пул SFX-плееров, флаг `lowPowerMode` (авто по `expo-device` totalMemory < 3GB или тумблер) — все декоративные эффекты деградируют по нему. Существующие AsyncStorage-ключи и правила FLASHCARDS_RULES.md не трогаем; `flashcards_v1` добавить в SYNC_KEYS.

## 1. Структура раздела и навигация

### 1.1 Хаб = дашборд (P0)
Полная пересборка `FlashcardsCategoryHub` в скролл из секций (обычный ScrollView, элементов < 20):

1. **Хедер**: заголовок «Карточки», справа — баланс осколков (уже грузится в flashcards.tsx:46) и место под звёзды недели (см. §4). Тап по балансу → shards_shop. «Сообщить о баге» → в overflow-меню «…» хедера.
2. **Hero-CTA** (карточка на всю ширину, главный элемент экрана):
   - Есть SRS-очередь → «Повторить сегодня · N карточек» → review.tsx (закрывает баг недоступности review).
   - Очередь пуста → «Тренировка» → trainer.
   - Внутри hero — мини-прогресс дня: сегменты 3 звёзд сессии (см. §4) и стрик.
3. **«Продолжить»**: resume-плитка последней открытой колоды (данные из writeFlashcardsProgress — уже есть).
4. **«Мои колоды»**: Сохранённые (с бейджем количества и точкой «N к повторению» — данные из primeCustomFlashcardsCache), Мои карточки, owned-паки с кольцом прогресса «изучено X из Y».
5. **«Режимы практики»**: 4 горизонтальные карточки — Тренер / Повторение / Слушание (новый) / Блиц (новый, P1) — с счётчиком доступного контента.
6. **«Магазин наборов»**: горизонтальная лента unowned официальных паков с ценниками (убрать фильтр `mineTabPacksOnlyOwned` — вернуть витрину). Сегмент «Мои/Сообщество» понижается до таба внутри этой зоны.
7. Empty-state новичка: если нет ничего — иллюстрация + «Создай первую карточку или открой стартовый набор».

FAB «+» (создать карточку) вместо плитки «Создать». Long-press-жалобу на UGC заменить кнопкой «…» на плитке.

### 1.2 Коллекция: два режима просмотра (P1)
Переключатель в шапке:
- **«Список»** — компактные адаптивные строки (EN + перевод видны сразу + мини-динамик + индикатор силы слова Weak/Medium/Strong цветной точкой), поиск (debounce 200 мс, по загруженному массиву), фильтр везде (включая custom и паки). Плотность ×3 от текущей.
- **«Колода»** — полноэкранная карточка со стеком (peek 2 карточек под ней), свайпы листания, тап = флип. Тяжёлые анимации живут только здесь (смонтированы 3 карточки).

Разбить монолит `flashcards_collection.tsx` (P0-рефакторинг): create/edit → отдельный роут `flashcards_card_editor.tsx`; practice-режим удалить (недостижим, его роль — у тренера); view → компонент. Цель ≤ 600 строк на файл.

### 1.3 Точки входа в практику
Из любой колоды — нижняя закреплённая панель: «Тренировать» / «Слушать» / «Повторить (N)». Сессия всегда запускается с контекстом конкретной колоды или «всё к повторению».

## 2. Карточка: единый компонент `<PhraseCard>` (P0)

Один компонент для коллекции-колоды, review, тренера, слушания. Пропы: size (full/row), face-контент, тема пака.

**Вид**: скругление 24, градиент лица из темы пака (уже есть в getCardPackPaywallTheme, но акцент прогонять через контраст-чек и осветлять на тёмных темах), сверху EN + транскрипция + динамик, «толстая» нижняя грань 4px в цвет акцента (Duolingo-press: при нажатии карточка сдвигается вниз на 2px, грань сжимается).

**Флип (P0, замена scaleX)**: настоящий 3D — Reanimated, `perspective: 1200` первым в transform, `rotateY` 0→180, `backfaceVisibility: 'hidden'` + фолбэк-переключение opacity на 90° (официальный паттерн из доков Reanimated — заодно чинит старые Android и web). Spring `{duration: 500, dampingRatio: 0.8}`, параллельный подскок scale 1→1.05→1 (120/180 мс). На 90° — `hapticLightImpact` + SFX `flip` через useAnimatedReaction/runOnJS. При `reduceMotion`/`lowPowerMode` — кроссфейд 150 мс.

**Жесты** (в режимах сессий): Pan с `activeOffsetX([-10,10])`, порог 35% ширины или velocityX > 800; rotateZ ±12° по интерполяции; overlay «Знаю/Учу» с opacity = interpolate(tx); хаптика-«тик» один раз на пересечении порога (флаг в sharedValue). Возврат — spring dampingRatio 0.7. Обязателен undo (swipeBack) — кнопка «↩» 3 секунды после свайпа.

**Звук карточки**: тап по динамику и авто-озвучка при флипе (настройка «Автопроизношение», по умолчанию on). Единая позиция кнопки динамика во всех вкладках (убрать `voiceSpeakOnRight`).

## 3. Режимы тренировки

### 3.0 Общий каркас сессии (P0)
Любая сессия: **фиксированные 10–20 карточек** (дефолт 15, настройка 10/15/20), сегментированный прогресс-бар сверху (как Duolingo), никаких бесконечных очередей. Финал: экран результата (точность, время, серия, звёзды 0–3, XP) с празднованием. Цикл «добить Ещё учу (N)» вторым раундом. Прогресс сессии переживает выход (сохранение в store).

### 3.1 Существующие режимы — точечно
- **Words (тиндер-свайп)**: привести к каркасу §3.0 + §2 (общий стек, undo, оверлеи). **Багфикс P0**: ложный перевод для uk-локали.
- **Phrases (word_bank/fill_gap)** и **Arena**: без структурных изменений; добавить SFX/хаптику по карте §5 и звёзды §4. Arena уже имеет готовые StarSlot/StarDisplay — переиспользовать.
- **Review (SRS)**: добавить CTA с хаба (P0); свайп-пейджер выбора фразы заменить явными табами-точками; в перспективе (P2) — миграция SM-2 → ts-fsrs (бинарный свайп маппится Again/Good, retention 0.9), с миграцией существующих интервалов.
- **Тренировка своих карточек**: вместо мёртвого practice-режима — свои карточки попадают в общий тренер/review как источник (custom deck). Fuzzy-сравнение при вводе: нормализация ё/е, і/ї, пунктуации, split по «;» на варианты, Левенштейн ≤ 1 = «почти верно»; кнопка «Показать ответ» обязательна.
- **Награды тренера (P0)**: сессии тренера дают XP и звёзды наравне с review; подключить дневной лимит trainer_session; write-lock в trainer_store (mutex-очередь записи).

### 3.2 НОВЫЙ режим «Слушание» (P0 — ключевая фича)
Вход: с хаба, из колоды («Слушать»), из плеера-мини на экране коллекции.

**MVP (foreground, keep-awake)**:
- State machine на `onDone` expo-speech: `speak(EN, en-voice)` → пауза «подумать» 1.2–2 c (настройка 1/2/3/5) → тихий tick → `speak(перевод, ru-RU Milena / uk-UA Lesya)` → пауза 0.8 c → следующая. Отмена: `Speech.stop()` + очистка таймеров при любом жесте/выходе.
- Режимы порядка: EN→RU, RU→EN (recall: перевод, пауза 3 c, слово), EN×2 (второй раз rate 0.8).
- UI-плеер: крупная карточка автофлипается в такт речи (тот же 3D-флип), внизу — play/pause, next/prev, скорость, shuffle. Экран не гаснет (`expo-keep-awake`).
- Перед первым speak: `setAudioModeAsync({ playsInSilentMode: true, interruptionMode: 'duckOthers' })` — чинит молчание expo-speech в silent mode (expo issue #8235) и дакает Spotify.
- В слушании SFX correct/incorrect выключены — только речь и tick.

**P2**: фоновое воспроизведение (UIBackgroundModes audio + серверные/кэшированные mp3 через плеер-очередь, live-TTS только foreground), lock-screen controls.

**Выбор голоса (P1)**: экран «Голос»: `getAvailableVoicesAsync()`, фильтр en-US, приоритет Enhanced, фолбэк-цепочка сохранённый → Enhanced → `compact.en-US.Samantha` → `language:'en-US'`; исключить eloquence/novelty; превью-кнопка; подсказка на ru/uk как скачать улучшенный голос. Не хардкодить identifier.

### 3.3 НОВЫЙ режим «Блиц» (P1)
Speed Review по образцу Memrise: 60 секунд, multiple-choice 4 варианта, 3 жизни, растущий комбо-множитель со звуком-питчем вверх. Дешёвый в разработке (механика арены уже есть), даёт «быструю дофаминовую» сессию на 1 минуту.

## 4. Система звёзд (экономика C из ресерча — гибрид)

**Роль**: звёзды = метрика КАЧЕСТВА сессии. Не кошелёк (кошелёк уже есть — осколки). Не покупаются ни за что.

**Заработок** — каждая сессия (тренер, review, блиц, коллекция-колода ≥ 10 карточек) оценивается 0–3★, пороги видны до старта:
- ★ — accuracy ≥ 70%
- ★★ — ≥ 90%
- ★★★ — 100% + среднее время ответа ≤ 5 с

Слушание даёт фикс ★ за прослушанную колоду ≥ 10 карточек (без оценки качества), кэп 2★/день с этого источника.

**Недельный трек**: бар на 21★, reset в понедельник. Чекпоинты-сундуки: 7★ → 20–40 осколков, 14★ → 40–80, 21★ («идеальная неделя») → 100–200 + косметика (рубашка колоды). Ролл: 70% низ, 25% середина, 5% джекпот ×2. Стрик ≥ 7 дней снижает порог perfect week до 18★. Эмиссия осколков ограничена сверху (~320/нед) — инфляции нет по построению, новых кошельков нет: звёзды кормят существующий `shards_system.ts` (готовый шаблон).

**Хранение**: ключ `flashcards_stars_week_v1` (stars, checkpoints claimed, resetsAt), плюс `deck_best_stars_v1` (лучший результат по колодам — задел под гейтинг P2). Оптимистичное начисление: звезда летит в счётчик сразу, запись в AsyncStorage — после анимации.

**Анимации звёзд**: на экране результата — переиспользовать готовые StarSlot/StarDisplay из arena_results (последовательное появление 0/150/300 мс, spring scale 0→1.2→1, звук `star` с питчем +2 полутона на каждую). Полёт звезды из карточки в счётчик хедера: 2 transform (translate по bezier-подобной интерполяции + scale), 600 мс — дёшево. Сундук чекпоинта: тряска 3×80 мс → открытие с burst 14 частиц (§6).

**XP**: perfect session даёт буст ×1.5 XP на 15 минут (связка без эмиссии валют). Тренер начинает давать XP как review (+5/ответ) — P0.

## 5. Звук и хаптика: карта событий (P0)

`SoundService` (новый, на `expo-audio`): пул `createAudioPlayer` на каждый SFX при входе в раздел, `seekTo(0)` перед play. Пак 9 файлов (Kenney CC0/uisfx как база, нормализация −16 LUFS, пики −6 dBFS), одно «семейство» тембра. Тумблеры в настройках: «Звуковые эффекты», «Автопроизношение». Существующие 7 mp3 в assets/sounds ревизовать под это семейство. Правило очереди: SFX (≤400 мс) → пауза 120 мс → TTS, никогда одновременно.

| Событие | Звук | Vol | Хаптика |
|---|---|---|---|
| Флип карточки | бумажный flick 80–150 мс | 0.3 | impactAsync(Light) на 90° |
| Свайп «знаю» | восходящий whoosh+tick 150 мс | 0.3 | notificationAsync(Success) |
| Свайп «учу» | нисходящий whoosh 150 мс | 0.3 | impactAsync(Light) — не наказываем |
| Верный ответ | 2 ноты вверх C5→E5, маримба, 300 мс | 0.55 | Success |
| Неверный | мягкий thud вниз, 200 мс, БЕЗ buzzer | 0.4 | notificationAsync(Error) |
| Комбо ×3/×5/×10 | тот же мотив, питч +2/+4/+6 полутонов (заранее отрендеренные файлы) | 0.6 | 2×Light с шагом 100 мс |
| Звезда/чекпоинт | sparkle 400 мс | 0.5 | Success |
| Финал сессии | арпеджио 3–5 нот, 900 мс | 0.7 | 3×Light по 100 мс |
| Пересечение порога свайпа | — | — | selectionAsync (1 раз, флаг в sharedValue) |
| Кнопки | без звука | — | selectionAsync только на сегментах/табах |

Хаптика дублирует каждый звук — фидбек живёт при выключенном звуке. Android: только Light/selection.

# Концепция переработки раздела «Карточки» Phraseman — ТЗ

## 0. Принципы (рамка для всех решений)

1. **Одна модель сессии везде.** Любая практика (тренер, review, практика колоды, слушание) — это «сессия из N карточек» с сегментированным прогресс-баром, экраном результата и оценкой 0–3 звезды. Никаких бесконечных очередей.
2. **≤2 тапа до тренировки** с любого экрана раздела.
3. **Анимации = transform + opacity на UI-потоке (Reanimated 4).** Не ставить lottie/skia — всё выразимо через Reanimated + react-native-svg. Миграция с RN Animated (83 файла) — постепенная, только в переписываемых экранах.
4. **Не трогать данные:** ключи `flashcards_custom`, `flashcards_v1`, правила FLASHCARDS_RULES.md, поле-язык-инвариант из handleSave. Новые фичи — новые ключи (`flashcards_stars_v1`, `flashcards_listening_prefs_v1`). Добавить `flashcards_v1` в SYNC_KEYS (P0, известный баг).
5. **Слабые телефоны:** ≤8–10 анимируемых вью одновременно, колода рендерит 3 карточки, деградация эффектов через существующий reduceMotion + тумблер «упрощённые эффекты».

## 1. Структура раздела и навигация

## 4. Система звёзд (экономика C — «рейтинг + недельный трек»)

Новая валюта НЕ вводится как кошелёк — звёзды кормят существующие shards. Ноль инфляции (weekly reset), готово к Learning V2.

### 4.1 Заработок (P0)
Сессия оценивается 0–3★, пороги видимы до старта:
- ★ — accuracy ≥ 70%
- ★★ — accuracy ≥ 90%
- ★★★ — perfect: 100% + среднее время ответа ≤ 5с

Звёзды капают в **недельный трек 21★** (reset понедельник 00:00 локали). Чекпоинты-сундуки: 7★ → 20–40 shards (ролл 70/25/5% нижняя/середина/джекпот), 14★ → 40–80, 21★ → 100–200 + косметика. Клейм — тап по сундуку на хабе с shake-анимацией. Perfect session дополнительно: xpMultiplier 1.5 на 15 минут. Стрик ≥7 дней снижает порог perfect week до 18★.

Хранение: `flashcards_stars_v1` (+ в SYNC_KEYS), конфиг порогов — remote config. Начисление оптимистично: результат пишется в стейт мгновенно, AsyncStorage — после.

### 4.2 Постоянный рейтинг колод (P1)
Каждая колода имеет best-рейтинг 0–3★ (перезаписывается лучшим) — показывается на плитке хаба. Через 7 дней без тренировки звёзды «тускнеют» (isFaded, визуально) — мягкий daily-триггер. Milestone-сундуки за суммарные best-звёзды: 10★→50 shards, 25★→150+рамка, 50★→400 (одноразовые).

## 2. Дизайн карточки

### 2.1 Настоящий 3D-флип (P0)
Заменить scaleX-«схлопывание»:
```
transform: [{perspective: 1200}, {rotateY}] — perspective ПЕРВЫМ
withSpring(0↔180, {duration: 450, dampingRatio: 0.8})
```

### 2.2 Вид (P0)
- Высота адаптивная по контенту (min 120), не фикс 224 — убить 60-70% пустоты.
- Лицо: фраза EN + транскрипция + динамик (единая позиция **справа** на всех вкладках — убить `voiceSpeakOnRight`); рубашка: перевод + пример. Индикатор силы слова — 3 точки (Weak/Medium/Strong, цвет темы) в углу.
- Бейдж источника: человекочитаемое «Урок 1» вместо «ГЛАГОЛ LESSON1» (маппинг sourceId → номер + triLang).
- Пак-темы: прогонять borderAccent через контраст-проверку (осветление в тёмной теме).
- Автоозвучка EN при флипе (настройка on/off, дефолт on).

### 2.3 Жесты (P0 в режимах, P1 в коллекции)
- Tap = флип. В сессиях: свайп вправо = знаю (зелёный overlay), влево = не знаю (оранжевый) — порог 35% ширины ИЛИ velocityX > 800; overlay opacity = interpolate от tx, rotate ±12°; **undo-кнопка обязательна** (swipeBack). Дублирующие кнопки ✓/✕ внизу.

## 4. Система звёзд (Learning V2)

Принята **экономика C (гибрид)** из ресерча — ноль новых кошельков, ноль инфляции:

### 4.1 Правила (P0)
- Любая сессия (тренер/review/блиц; слушание — только «★ за завершение», без качества) оценивается 0–3★: ★ ≥70% точности, ★★ ≥90%, ★★★ = 100% + среднее время ≤5с/карточка. Пороги видны до старта.
- Звёзды заполняют **недельный трек 21★** (reset понедельник 00:00 локали). Чекпоинты-сундуки: 7★ → 20–40 осколков, 14★ → 40–80, 21★ («идеальная неделя») → 100–200 + косметика. Ролл 70/25/5 (низ/середина/джекпот ×2). Эмиссия осколков ≤ ~320/нед — предсказуемо.
- Perfect session → буст XP ×1.5 на 15 минут. Стрик тренировок ≥7 дней → порог идеальной недели 18★.
- Звёзды не покупаются ни за что. Хранение: `fc_stars_v1` {weekStart, stars, checkpoints[], streak}; выплаты через готовый шаблон shards_system.ts.
- P2: постоянный рейтинг колод 0–3★ (перезапись лучшим) + «тускнение» через 7 дней без тренировки — replayability.

### 4.2 Анимации звёзд (P0)
- **Реюз StarSlot/StarDisplay из arena_results** — анимации готовы. На экране результата: звёзды влетают по одной (scale 0→1.2→1 spring, stagger 250ms) + haptic Medium + SFX star на каждую.
- Полёт звезды к счётчику в хедере: 1 View, translateX/Y + scale по timing 600ms — 2 transform-свойства, копейки.
- Сундук чекпоинта: подпрыгивание (translateY spring) → «взрыв» 12–16 View-частиц (по withTiming 900–1400ms по предрассчитанным траекториям, размонтирование контейнера) — паттерн Shopify-конфетти, без Skia. На low-end (детект `expo-device` totalMemory <3GB) — деградация до scale-пульса + haptic Success.

### 4.3 Сила слова (P1)
Weak/Medium/Strong по интервалам SRS (1-3 → Weak, 7-14 → Medium, 30 → Strong) — точки на карточке и в списке, mastery % на плитке колоды. Использует существующие данные trainer_store/SM-2, ничего не мигрируем.
