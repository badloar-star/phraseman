# Заставка при запуске цветом сохранённой темы (лог и план)

Governance-ID: TG-C0C7377524C0

## Outcome
Сверка 25.10: в светлой теме на холодном старте нативная заставка тёмная #101214 (по системной тёмной схеме) ~7 с, потом JS-заставка 240 мс уходит на светлый #E9EFF6 — секунды тёмного экрана перед светлой темой. Координатор: заставка с первого нативного кадра — цвет сохранённой темы; сначала лог, какой цвет решила заставка и откуда; если нужна нативная сборка — подготовить в 2.0.3 и написать.

## Scope
In scope: лог [BOOTSPLASH] native-splash в `app/splash_hold_early.ts` (системная схема → цвет нативной заставки из app.json, сохранённое оформление `liquid_glass_appearance`, расхождение). План нативной части.
Out of scope: нативный модуль/плагин — после согласования (нужна нативная сборка).

## Architecture
Нативная заставка (expo-splash-screen, app.json) выбирает фон только по системной схеме: светлая #EDF0F4, тёмная #101214 — сохранённую тему приложения она не знает. JS до неё не успевает (заставку рисует система до старта процесса). Починка — Android 12+ UiModeManager.setApplicationNightMode (системно хранит ночной режим приложения, его видит стартовое окно) при выборе оформления; iOS — LaunchScreen статичный, только системная схема.

## Security and privacy
Не касается: в лог идут только схема и цвет.
