# Чек-лист токенов для раздела «Соцсети» (делает владелец)

Дата: 2026-07-06. Всё, что здесь — это шаги, которые нужно пройти руками в кабинетах площадок,
потому что это твои аккаунты и подтверждения. Каждый выданный токен кладём в Firebase secrets
командой (я подскажу точное имя секрета на этапе кода):

```
firebase functions:secrets:set ИМЯ_СЕКРЕТА
```

Порядок специально такой: сверху — самое быстрое, снизу — самое долгое (TikTok ждёт ревью).

---

## 1. YouTube (делаем первым — самый простой)

1. Зайти в Google Cloud Console → выбрать/создать проект (можно тот же, где уже живёт проект
   Firebase phraseman).
2. APIs & Services → включить **YouTube Data API v3** и **YouTube Analytics API**.
3. Credentials → создать OAuth client (тип Desktop) ИЛИ использовать service-account с доступом
   к каналу.
4. Один раз пройти OAuth-согласие своим Google-аккаунтом, у которого есть канал → получить
   refresh token (я дам маленький скрипт для этого шага).
5. Отдать мне: client_id, client_secret, refresh token. Кладём в secrets.

Что получим: просмотры, лайки, комменты, **удержание аудитории**, подписки с видео.

---

## 2. Meta: Instagram + Facebook (один флоу на обе площадки)

Требование: Instagram должен быть **бизнес- или creator-аккаунтом** и **привязан к
Facebook-странице**. Если сейчас это личный IG — сначала переключить в настройках IG.

1. developers.facebook.com → создать **Meta App** (тип Business).
2. Добавить продукты: Instagram Graph API, Facebook Login.
3. Выдать приложению разрешения: `instagram_basic`, `instagram_manage_insights`,
   `pages_read_engagement`, `pages_show_list`.
4. Получить **долгоживущий Page Access Token** (живёт ~60 дней, потом обновляется; я сделаю
   авто-обновление на бэке).
5. Узнать ID Instagram Business Account и ID FB-страницы.
6. Отдать мне: App ID, App Secret, долгоживущий токен, IG business account id, FB page id.

Что получим: охват, показы, вовлечённость, сохранения, репосты (по обеим площадкам).

---

## 3. Threads (через тот же Meta-аккаунт)

1. В том же Meta App включить **Threads API**.
2. Выдать разрешения на чтение инсайтов Threads.
3. Получить токен доступа к Threads (тот же OAuth-флоу Meta).
4. Отдать мне токен + Threads user id.

Что получим: просмотры, лайки, ответы, репосты, цитаты (метрики беднее, чем у остальных, но
официальные).

---

## 4. TikTok (делаем ПОСЛЕДНИМ — нужен ревью, может занять недели)

1. developers.tiktok.com → создать app.
2. Подключить **Login Kit** + запросить scope на чтение аналитики видео
   (Content Posting / Display API, video list + insights).
3. **Подать приложение на ревью TikTok** — доступ к аналитике постов выдают только после
   одобрения. Это самый долгий шаг, закладывай недели ожидания.
4. После одобрения — пройти OAuth, получить access + refresh token.
5. Отдать мне: client_key, client_secret, refresh token.

Что получим: просмотры, лайки, шеры, комменты, досматриваемость.

---

## Пока ждём токены — что уже можно делать без них

Фундамент связки (маркер-тег `#pmv_<shortId>` в описании + реестр публикаций в Firestore) и
каркас раздела админки **не требуют ни одного токена**. Их можно построить сразу, а площадки
подключать по мере получения доступов. YouTube-токен нужен только на этапе реального сбора.

---

## Правила безопасности (важно)

- Токены НИКОГДА не в коде и не в git — только `firebase functions:secrets:set`.
- Если токен где-то засветился — сразу отозвать и выпустить новый (правило security.md).
- Доступ к разделу «Соцсети» и коллекциям `social_*` — только админам.
