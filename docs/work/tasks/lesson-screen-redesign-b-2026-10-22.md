## Outcome

docs/design/v2-app/lesson-screen-redesign-b.html: два пронумерованных варианта экрана урока в рамке телефона 390 × 844, у каждого три кадра «первый взгляд → выбор главы → выбор эпизода». Одна главная кнопка, понятно «где я / что дальше», выбор главы и эпизода без веера «Вся глава» и без чипов глав, эпизоды — не вертикальные квадраты, кнопки «Слова» и «Теория», один общий «назад», все кнопки одного стиля, цвета только оттенки текущей темы (переключатель тёмная/светлая), без текстур, названия эпизодов не длиннее двух слов. Данные — урок 2 (7 глав по 8 эпизодов). Мера успеха: владелец выбирает вариант кнопкой.

## Scope

In scope: один новый HTML-макет в docs/design/v2-app; реальные названия глав и арка урока из modules/learning-v2/content/session_titles_v1.generated.ts; названия эпизодов в две слова — черновик автора макета.

Out of scope: код приложения; шторка выбора главы в приложении; «Слова» в Сезоне (сделано, 0eb910479); эмулятор.

## Architecture

Самодостаточный HTML, как scenes-compact.html и peak-pedestal-left.html: свои классы с префиксом ls-, телефон .ph, шрифты Inter и IoniconsApp из соседних папок, токены тем .ph.dk / .ph.lt из scenes-compact. Кадры собираются скриптом из встроенных данных урока 2.

## Security and privacy
