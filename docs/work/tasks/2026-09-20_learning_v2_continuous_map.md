# Task packet: сплошная карта курса Learning V2 (макеты)

Governance-ID: TG-EB1DAA886B6E
Status: Planned
Owner: Claude (сессия 20.09.2026), заказ владельца
Related epic/enabler: Learning V2 · «Атлас» (docs/design/learning-v2)

## Outcome

Владелец нажимает «Новые уроки» и сразу попадает на КАРТУ (а не на аккордеон из
32 плиток). Карта непрерывна: 56 сессий урока, затем плашка на пол-экрана с
номером и аркой следующего урока, затем снова сессии 1..56 — и так до конца
курса. Каждый кружок подписан. В футере — кнопка, открывающая шторку со списком
всех 32 уроков с прыжком к выбранному.

Мера успеха (требование владельца дословно: «ничего не должно лагать!!!!!»):
- скролл держит 60 fps на быстром флике через весь курс;
- в DOM/дереве одновременно живёт ≤ ~40 узлов, а не 1792;
- открытие раздела рисует первый кадр сразу, без спиннера на весь экран.

Отдельным пунктом (владелец, 20.09): плашки в списке «все уроки» обязаны быть
такой же высоты, как в Learning V1 (72px), а не 108px+ — круговой индикатор
прогресса при этом остаётся.

## Scope

In scope (этот пакет — ТОЛЬКО макеты, кода приложения не трогаем):
- `docs/design/learning-v2-map/` — новые HTML-макеты: сплошная карта, шторка
  списка уроков, сравнение высоты плашек V1/V2;
- `docs/design/learning-v2-map/course-data.json` — выгрузка РЕАЛЬНЫХ данных из
  `content/learning-v2-course/curriculum/en/ПЛАН_КУРСА.md` (168 имён сессий
  уроков 1–3, 21 глава, 32 арки уроков). Ничего не выдумано.

Out of scope (ЯВНО не делаем в этом пакете):
- правка `app/(tabs)/lessons.tsx` (5854 строки, аккордеон, живой экран);
- правка `modules/learning-v2/map/course_accordion_map_model_v1.ts`;
- экспорт имён сессий в релиз (`sessionTitle` в фабрике курса) — отдельная
  задача, без неё имена есть только у уроков 1–3;
- любые изменения Firestore, экономики, прогресса.

## Architecture

Текущая граница: `app/learning-v2/course.tsx` → `LessonsTab` с
`initialPage="v2"`. Горизонтальный ряд из 32 плиток; тап разворачивает 56 сессий
ИНЛАЙНОМ внутри той же плитки (аккордеон). Модель строк —
`buildLearningV2CourseAccordionMapV1`, строки трёх видов: `lesson` / `chapter` /
`session`. Развёрнут всегда РОВНО ОДИН урок.

Намеренная граница (что показывают макеты): один непрерывный вертикальный
список от урока 1 сессии 1 до урока 32 сессии 56. Разделитель между уроками —
не плитка, а плашка на пол-экрана. Аккордеон как понятие исчезает; список
уроков переезжает в шторку и работает как навигация (прыжок), а не как
раскрытие.

**Как это НЕ лагает — архитектура, а не пожелание.** Три закона макета:

1. **Геометрия считается числами, а не DOM.** Позиция каждого из 1792 узлов —
   чистая функция от его индекса (`y = f(index)`), плюс префиксные суммы высот
   уроков. Полная высота полотна известна сразу; скроллбар честный с первого
   кадра, без дорисовки и без «прыжка» контента.
2. **Виртуализация окна.** В DOM живут только узлы, попавшие в
   `[scrollTop - overscan, scrollTop + h + overscan]`. Узлы переиспользуются из
   пула: при скролле меняются координаты и текст, элементы не создаются и не
   удаляются. Поэтому стоимость кадра не зависит от длины курса.
3. **Скролл не вызывает layout.** Обработчик `scroll` только пишет индексы и
   просит `requestAnimationFrame`; вся работа — `transform: translate3d` и смена
   текста. Никаких `offsetTop`/`getBoundingClientRect` внутри кадра (это
   принудительный reflow — главный источник лагов в длинных списках).

Инварианты:
- высота полотна и позиция узла не зависят от того, что отрисовано;
- пул узлов не растёт при скролле (размер = видимое окно + overscan);
- бесконечных анимаций ровно столько, сколько видно: дышит ТОЛЬКО текущий узел.
  Это прямо перекликается с найденной 20.09 пробоиной `QuestTaskCard`
  (native-loop на Главной без гейта) — карта не должна повторить эту ошибку.

Решение о данных: имена сессий берём только там, где они есть (уроки 1–3,
написаны). Для ненаписанного показываем номер сессии. Владелец: «только для тех
которые есть потому что остальные еще пишутся их мы не трогаем пока».

## Security and privacy

Не применимо. Макеты — статический HTML/CSS/JS в `docs/`, в бандл приложения не
попадают. Персональных данных нет: единственные данные — учебный план курса,
уже лежащий в репозитории. Нет сети, нет хранилища, нет разрешений, нет
сторонних сервисов, нет данных детей. Privacy policy правки не требует.

## Technical debt

- **Contain — имена сессий есть только у уроков 1–3.** Макет честно показывает
  номер там, где имени нет, и не притворяется, что данные полные. Условие
  выхода: фабрика курса начинает писать имя сессии в релиз; до тех пор карта
  обязана работать с частичными именами и не ломаться.
- **Accept temporarily — макет и приложение расходятся.** Макет описывает
  экран, которого в коде ещё нет. Владелец: макеты сейчас, реализация после
  утверждения. Владелец — заказчик; потолок вреда нулевой (docs/ не в бандле);
  дата пересмотра — момент утверждения макета.
- **Pay now — высота плашки урока.** Причина найдена точно:
  `app/(tabs)/lessons.tsx:870` даёт V2 `minHeight: 108` против `BOOK_H = 72`
  у V1, кольцо 48×48 распирает строку, а заголовок урока рендерится без
  `numberOfLines` и разливается на 3 строки. Макет фиксирует правильную
  геометрию (72px, кольцо 44, заголовок в одну строку) — чтобы реализация
  чинила причину, а не подгоняла числа.

## Verification

Детерминированные проверки на макете:
1. `node docs/design/learning-v2-map/check.mjs` — считает геометрию без браузера:
   полная высота полотна, что окно при любом `scrollTop` даёт ≤ 40 узлов, что
   у каждого узла ровно одна позиция, что имена подставлены только для уроков
   1–3, что номера сессий идут 1..56 в каждом уроке.
2. Ручной прогон в браузере: флик от начала до конца курса — карта не белеет,
   плашки уроков приходят на своих местах, подписи под кружками не прыгают.
3. Проверка высоты: экран сравнения показывает плашку V1 (72) и нынешнюю V2
   (108) рядом — расхождение видно глазом и подписано числами.
4. Доступность: `prefers-reduced-motion` гасит дыхание текущего узла и анимацию
   шторки; контраст подписей проверен на тёмном фоне.

Артефакт: сами макеты в `docs/design/learning-v2-map/` + вывод `check.mjs`.

## Rollback

Полностью обратимо: удалить каталог `docs/design/learning-v2-map/`. Кода
приложения пакет не трогает, миграций нет, пользовательских данных нет,
выданных прав нет. Живой экран Learning V2 продолжает работать как раньше.
