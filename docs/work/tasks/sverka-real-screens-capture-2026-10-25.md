## Outcome
Настоящие снимки приложения (1080 px шириной, без рамки эмулятора) для построения макетов: Главная / Сезон / Пик в шести тёмных темах; окно экзамена главы; этапы вступления занятия.

## Scope
Эмулятор Pixel_8, служебные ссылки dev_state (тема, appearance, уровень «Максимум»). Папки `C:/Temp/claude/png/real/{dark_themes,exam_modal,intro}`. Скрипт `C:/Temp/claude/real_themes.sh` лежит вне репозитория.

## Architecture
Скрипт: ссылка с темой → Главная → вход в Сезон → возврат → вкладка «Пик» → кадр на каждом шаге. Закрывает отладочные плашки, чтобы они не перехватывали нажатия. К «Удалить аккаунт» не прикасается.
