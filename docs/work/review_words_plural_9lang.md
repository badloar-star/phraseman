# «Повторить N слов · M мин» — формы слов по числу (9 языков)

Плейсхолдеры: {n} — число слов, {m} — число минут. Выбор формы по числу, как в строках udobstv (ab1325f47).

| язык | слово при {n} | минуты при {m} |
|---|---|---|
| ru | 1 → слово; 2–4 → слова; 5+ и 11–14 → слов | 1 → минуту; 2–4 → минуты; 5+ → минут |
| uk | 1 → слово; 2–4 → слова; 5+ → слів | 1 → хвилину; 2–4 → хвилини; 5+ → хвилин |
| en | 1 → word; иначе → words | min (без изменений) |
| es | 1 → palabra; иначе → palabras | min (без изменений) |
| pt-BR | 1 → palavra; иначе → palavras | min (без изменений) |
| vi | từ (без изменений) | phút (без изменений) |
| id | kata (без изменений) | menit (без изменений) |
| tr | kelime (без изменений после числа) | dk (без изменений) |
| pl | 1 → słowo; 2–4 → słowa; 5+ → słów | 1 → minutę; 2–4 → minuty; 5+ → minut |

Пример ru: «Повторить 21 слово · 2 минуты», «Повторить 5 слов · 1 минуту».
