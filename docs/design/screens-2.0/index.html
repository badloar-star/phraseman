Экраны 2.0 — макеты

Восемь экранов, по три варианта раскладки. Содержимое снято с текущего кода — ничего не добавлено. Цвет один на всех (графит и тёплая кромка), варианты отличаются раскладкой.

А — каждая строка своей стеклянной карточкой · Б — строки собраны в группы с тонкими разделителями · В — крупные плитки и акцент на главном.
