## 1. Установка (НЕ запускать без решения владельца — это нативный ребилд)

```bash
# core + Expo resource-fetcher + файловые зависимости
npm i react-native-executorch react-native-executorch-expo-resource-fetcher
npm i expo-file-system expo-asset

# пересобрать dev-client (нативный модуль — Expo Go не подойдёт):
npx expo prebuild        # обновит android/ (ios/ нет — добавится при необходимости)
npx expo run:android     # или eas build --profile development
```

**Почему не запускаю сам:** добавление нативного модуля = пересборка APK (минуты-десятки минут, Gradle). По правилам сессии и из-за грабель проекта (несколько параллельных сессий, OOM Metro) — это шаг владельца. Экран-прототип `app/spike_voice.tsx` уже написан и **скомпилируется**, но Kokoro заработает только после установки выше; до установки экран честно покажет «Kokoro не установлен — озвучка через сток-`expo-speech`».

## 2. Kokoro TTS — API (проверено по докам swmansion, 2026)

```ts
import { useTextToSpeech, models } from 'react-native-executorch';

const tts = useTextToSpeech(models.text_to_speech.kokoro.en_us.heart()); // голос "heart"
// ...после загрузки модели:
const waveform = await tts.forward({ text: 'Hi! How are you today?', speed: 1.0 });
// waveform → проигрывается через аудио-API (expo-audio/executorch audio util)
```

- ⚠️ **Только английский.** Модель называется `kokoro.en_us.*` (есть `en_gb`). **Русского нет** → русские объяснения/оракул Фила озвучивать НЕ через Kokoro (для них — облачный TTS позже; правило проекта «no paid cloud» = про STT, не TTS).
- Поддержка стриминга (`stream` / `streamFromPhonemes`) есть — но для Спайка 0 не нужна, меряем простой `forward`.
- Первая генерация = разовая загрузка модели (~80–300 МБ) → мерить и это (время до первого звука «вхолодную»).

## 3. Что меряем — гейт-критерий

Заполняется в [spike0_voice_measurements_2026-06-10.md](./spike0_voice_measurements_2026-06-10.md) на 4 устройствах:
1. флагман iOS, 2. iOS постарше (SFSpeechRecognizer/60с-лимит), 3. флагман Android, 4. **бюджетный Android** (Redmi/Samsung A — это диаспора ЦА/Кавказ).

**Метрики:** воспринимаемый roundtrip (зажал→услышал ответ), WER on-device ASR на 5 русско-акцентных тестерах, нагрев/батарея за 10-мин сессию, качество голоса (слепой A/B Kokoro vs облако vs сток).

**Гейт:** если на бюджетном Android UX «мёртвый» (roundtrip > ~3–4 с или нагрев/лаги) ИЛИ Kokoro звучит как робот без облака → **меняется ВСЯ стратегия** (либо облачный TTS обязателен, либо аудитория сужается до флагманов). Лучше узнать за 2 недели.

### Итог простыми словами
- Хорошая новость: твоё приложение по технике уже готово принять «умный» голос Kokoro — версии и настройки совпадают, ничего ломать не надо.
- Нужна одна разовая пересборка приложения (несколько минут) — её запускаешь ты, потому что это твоё устройство и параллельные сессии не должны мешать.
- Kokoro отлично говорит по-английски (это 90% речи Фила), но по-русски не умеет — русские пояснения озвучим отдельно позже.
- Экран-прототип уже готов: пока Kokoro не поставлен — он озвучивает старым голосом, после установки — новым.
- Главная проверка: на дешёвом телефоне — быстро ли отвечает и не греется ли; и вслепую сравнить, какой голос приятнее. От этого зависит, каким путём идём дальше.
