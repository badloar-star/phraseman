# Phraseman — приложение в движении

Одобренное направление: премиальные интерактивные макеты всех поверхностей из `APP_DESIGN_MOTION_OPPORTUNITIES_2026-09-08.ru.md`, кроме отключённого Max. Production-код не меняется.

1. Создать автономную галерею: главная, профиль, библиотека, тренировка, результат, кошелёк, клуб, миры диалогов, разговор, сокровищница, магазин, онбординг, настройки, набор карточек.
2. Связать основные переходы; реализовать переключаемые состояния, раскрытия, счётчики, переворот, свайп, сообщения, фильтры и демонстрационный чек.
3. Использовать существующие изображения приложения, локальный шрифт, контрастные подписи, клавиатурное управление и reduced motion.
4. Проверить в браузере широкую и узкую компоновки, ключевые взаимодействия и автономность. Отдельно отметить границы демонстрации.

Критерии: 14 доступных экранов, отсутствие Max, нулевые внешние запросы в автономном HTML, функциональные основные CTA, все награды и покупки только локальные демонстрационные данные. Онбординг сохраняет действующий порядок этапов; скрытые language/level не включаются самовольно.
