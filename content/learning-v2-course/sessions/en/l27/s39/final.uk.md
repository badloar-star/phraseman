# Урок 27 · Заняття 39 — Подивитися малюнки друга

**Ситуація.** Ви розглядаєте малюнки, запитуєте про практику й підтримуєте друга.

**Що ви опануєте:** wish + past; if I were; unreal condition; present perfect / past simple
**Нові слова:** curiosity, affection, admiration, empathy

## Інтро 1

### Хотілося б більше часу на малювання

Ви любите малювати, але зараз рідко знаходите на це час. Скажіть другові: I wish I had more time to practise — хотілося б мати більше часу на практику. Після wish використовуємо had для бажання щодо теперішнього: часу поки бракує. To practise пояснює, для чого він потрібен. Складаємо речення: I wish + I + had + more time + to practise — бажання, хто, had, чого хочеться більше, для чого.

**Виберіть фразу для цієї ситуації.**

- ✅ **I wish I had more time to practise.**
- ❌ I wish I have more time to practise. — *Після wish тут had.*
- ❌ I wish I having more time to practise. — *Потрібна форма had.*

---

## Інтро 2

### Коли спробували намалювати собаку

Друг запитує, коли ви спробували намалювати свого собаку. Це було вчора. Дайте відповідь: I tried it yesterday — я спробував це вчора. It замінює дію «намалювати собаку». У минулій формі try літера y після приголосної змінюється на i перед -ed: tried. Yesterday називає завершений час, тому have не потрібне. Складаємо речення: I + tried + it + yesterday — хто, дія в минулому, що спробував, коли.

**Виберіть фразу для цієї ситуації.**

- ✅ **I tried it yesterday.**
- ❌ I have tried it yesterday. — *Із yesterday тут tried без have.*
- ❌ I tryed it yesterday. — *Минула форма try — tried.*

---

## Інтро 3

### Практикуватися разом

Наодинці ви рідко сідаєте малювати. Ви припускаєте, що спільні заняття допомогли б. Скажіть: I would practise more if we did it together — я б більше практикувався, якби ми займалися разом. Would practise — уявний результат; if we did it together — умова. Did стосується уявної ситуації, а не вчорашнього заняття. Складаємо речення: I + would practise + more + if we did it together — хто, що робив би, наскільки більше, за якої умови. Після would ставимо practise без to.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would practise more if we did it together.**
- ❌ I would practised more if we did it together. — *Після would потрібна practise.*
- ❌ I would to practise more if we did it together. — *Після would немає to.*
