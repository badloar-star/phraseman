Тема приложения

Прогон состояний

Или просто играй руками: тап по карточке, «Проверить», после вердикта «Дальше» уходит сам (заливка-таймер). Ошибка даёт вторую попытку, после второй попытки раскрывается связь сцена → фраза.

Спецификация для RN (Reanimated 4)

Вход вариантов: стаггер46 мс · spring ui (d20 s300)
Выбор карточки120 мс · easeOutQuint + haptic light
«Проверить»: пресс кромки120 мс · клик-звук (кнопка)
Radial-wipe от точки тапа420 мс · slide bezier
Галочка (stroke-draw)320 мс · задержка 140 мс
Фраза: blur-in240 мс · haptic success
Полёт звезды по дуге + трейл700 мс · slide · тик-хаптик
Бамп счётчикаspring micro · scale 1.28
Комбо-поп (серия)900 мс · streakPop 1.28
Ошибка: тонировка + оседание180 мс · без тряски и хаптика
Токен ошибки → счётчик600 мс · slide
Авто-«Дальше»1400 мс · тап = сразу
Переход карточек240 мс · сдвиг + поворот 4°
Все полёты и заливки: только transform / opacity / clip-path (UI-тред). Высоты полос фраз и фидбека зарезервированы: контент не прыгает (layout stability). Reduced motion: полёты и конфетти выключаются, остаются короткие кроссфейды. Конфетти: только на серии ×3 и финале сессии, не на каждый ответ.

Контракт состояний (04 · SB-01)

prompt → activeвыбор = тон + подъём + бейдж
processing160 мс лок, геометрия на месте
successзаливка + фраза + звезда
needs_workподсказка, ответ не раскрыт
retry №2показ связи сцена → фраза
asset failтекст + аудио, без штрафа
Дистракторы: смысловые сцены, ровно один правильный ответ. Звёзды и ошибки в шапке: прогресс текущей сессии, не глобальный баланс (по 04). Никаких обводок: выбор и вердикт кодируются тоном, тенью, бейджем и текстом.
