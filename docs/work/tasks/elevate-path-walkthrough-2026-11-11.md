## Outcome

Владелец открывает одну страницу, выбирает маршрут (разминка с Главной, тренировка карточек, урок, ошибки,
ступень Пика, диалоги, наборы, навыки и друзья) и проходит его на одном телефоне: на каждом шаге подсвечено,
куда нажать, игры можно сыграть самому, справа — что на этом шаге нового. К каждому шагу есть оценка и поле
комментария; одна кнопка копирует все комментарии текстом, чтобы вставить их в чат. Успех — владелец отдаёт
все замечания одним сообщением.

## Scope

In scope: новые файлы макетов `docs/design/v2-app/elevate-path.html`, `elevate-path.js`, `elevate-path.css`;
строка навигации в `elevate-core.js`.

Out of scope: код приложения; новые экраны (маршруты собраны из уже нарисованных); отправка комментариев куда-либо.

## Architecture

No architecture change: страница-предложение. Экраны берутся из уже собранных разделов `window.ELS`, чтобы
прохождение показывало ровно те же макеты, что и остальные страницы.

## Security and privacy

Комментарии хранятся только в браузере владельца (localStorage этой страницы) и никуда не отправляются;
копирование — в буфер обмена по нажатию кнопки. Личных данных и секретов нет.

## Technical debt

- Accept temporarily: шаг игры завершается кнопкой «Дальше», а не по факту выигрыша; владелец — эта сессия,
  пересмотр — если владелец попросит автопереход, потолок влияния — только макет.

## Verification

`node --check`; снимки в реальном времени с проходом каждого маршрута скриптом (все шаги открываются, ошибок
в журнале нет); проверка текста, который выдаёт кнопка копирования.

## Rollback

Удалить три файла `elevate-path.*` и строку навигации; приложение не затронуто.

## Правки по комментариям владельца (11.11, первый проход)

- «Поток»: перед игрой экран с правилом и кнопкой «Начать», затем отсчёт; перед каждой следующей фразой сигнал.
- Навыки: звезда возвращена на тёмное поле со свечением.
- Навык «Общение» переименован в «Социальный» (тема диалогов «Общение» не тронута).
- Комментарий про экран между играми владелец отозвал — не учитывается.

## Правки по комментариям владельца (11.11, второй проход)

- Навыки и статистика возвращены к тёмному варианту из первых макетов — именно те экраны, что владелец показал на снимках
  (экран «Навыки» с индексом и приростом за неделю; «Статистика» с блоками «Подтянуть», «Неделя», «Рекорды игр», «Год»,
  кривая сравнения). Остальные экраны остаются в светлом виде приложения.
- Визитка: в светлом виде карточка стала белой с белым текстом, замок не виден — вернуть тёмную карточку, как в приложении.
- Блиц: игра молча обрывалась после шести ответов — вопросы идут по кругу, в конце явное «Минута вышла».
- Таблица «какой навык что качает» — точная, с очками за действие; одна на все экраны.
