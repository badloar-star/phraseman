# Словарь Learning V2 — вариант A (план сессии Learning V2, 22.10 ночь)

Эталон: `docs/design/v2-app/dictionary-v2.html` (7f3cff3f7), вариант **A · Список с уроками** + галочки уроков из B.
Заказ владельца 21.10 через координатора: тренировать прямо в словаре (отметить уроки/слова, режим как в «Карточках»),
сохранять слова в «Карточки» одним тапом с «Отменить», без новых чтений Firebase, журнал `[V2-DICT]`.

## Что есть сейчас

- `components/learning-v2/LearningV2LessonDictionaryOverlayV1.tsx` — модалка словаря (поиск, озвучка, `AddToFlashcard`).
  **В ней чужие незакоммиченные правки** (озвучка через `learning_v2_preview_speech_watchdog_v1`, с 12:30) — не трогаю.
- Открывается из `app/(tabs)/lessons.tsx` — **чужая незакоммиченная работа** — не трогаю.
- Тренировки «Карточек» берут колоду из `?deck=` (`app/flashcards/deck_sources.ts`: `saved | custom | pack:<id>`).

## Решение (без чужих файлов)

1. **Колода «слова словаря»** — новый токен `lv2:<id>` в `deck_sources.ts`/`deck_selection.ts`.
   Слова передаются через реестр в памяти `app/learning_v2_dictionary_training_deck_v1.ts`
   (+ копия на телефоне, чтобы «Ещё раз» пережил перезапуск). Сеть не нужна: слова уже в бандле курса.
   Ошибки тренировки уходят с источником `lesson`. Блиц/Устно/Правда-ложь/Напиши — существующие экраны «Карточек» без копий.
2. **Новый экран** `components/learning-v2/LearningV2DictionaryV2.tsx` (+ `learning_v2_dictionary_v2_copy.ts`, 9 языков):
   список по урокам, чипы «Все уроки / Урок N» + лист «Уроки» с галочками нескольких, поиск, «Выбрать» → галочки слов,
   «Выбрать все N», «Тренировать · N» → лист режимов (`FlashcardsTrainingModeSheet`) → экран старта «Карточек»,
   закладка у слова → сразу «в карточках» + плашка «Отменить» (optimistic, откат при ошибке), пакетом из выбора,
   пусто / длинное слово / нет сети («отправим позже»).
3. **Подключение**: одна строка в `lessons.tsx` (заменить модалку на новый экран) — когда файл освободится,
   либо сделает владелец этой работы. До этого новый экран доступен из dev-маршрута для сверки «Сверкой».
