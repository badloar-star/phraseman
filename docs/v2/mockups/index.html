Законы витрины

  • Без эмодзи и картинок: только типографика и SVG-глифы.
  • Без обводок контейнеров: разделение тоном, тенью и скруглением.
  • Типографика-герой: крупный градиентный заголовок, чёткая иерархия.
  • Премиальные градиенты везде: глубокая заливка, а не плоский цвет.
  • Сплошная полоса прогресса: без сегментов, заливка растёт непрерывно.
  • Стрик золотой волной: растущая серия даёт перелив по экрану и бонус-звёзды.
  • Ошибка без тряски: тонировка и объяснение, никакой вибрации макета.
  • Голос только on-device: распознавание и синтез речи без внешних серверов.
  • Критерий режима: однозначно верный ответ, честная проверка без ИИ, звёзды и серия. Нет вердикта - не режим.
  • Всё помещается без скролла: рама 390 на 800, кнопка действия видна всегда.
  • Выбранное видно сразу: светлее градиент, подъём и бейдж, без обводок.
