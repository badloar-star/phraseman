# Онбординг: выключенные в админке экраны не показываются в релизе — диагноз по [ONB-FLAGS] и сторож (вопрос владельца 06.11)

## Outcome

Владелец выключил экраны онбординга в админке, а они показываются. Находим причину по журналу `[ONB-FLAGS]`: (1) dev-режим `EXPO_PUBLIC_FORCE_ONBOARDING_QA=1` показывает весь каталог; (2) в опубликованном списке нет метки `catalog_2026_08_17` → пять шагов включаются по умолчанию. Сторож фиксирует: выключенный с меткой шаг не показывается, QA-режим недостижим в релизе, админка всегда сохраняет метку.
