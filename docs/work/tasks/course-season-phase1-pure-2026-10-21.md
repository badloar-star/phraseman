## Outcome

Готовы и проверены без эмулятора три чистых модуля, на которых строятся компоненты фазы 2: (1) перевод цветов OKLCH эталона в hex для градиентных обложек глав в обеих темах, (2) математика карусели — положение, масштаб, поворот, прозрачность и порядок карты по её смещению от центра (формулы эталона: сдвиг 116, глубина 80 при перспективе 900, поворот 26°, дальние карты .5), (3) модель карт эпизодов главы из текущего прогресса курса (карта эпизода: состояние «пройден / текущий / закрыт», экзамен последней картой, карты следующей главы). Успех: тесты через `tsx`, лёгкие, без React Native.

## Scope

In scope: новые файлы `components/learning-v2/season/season_art.ts`, `season_carousel_layout.ts`, `season_course_model.ts`, тесты в `tests/`.

Out of scope: компоненты и анимации (фаза 2), раскрытая карта, веер, экзамен, выбор главы (фаза 3), подключение в экран «Обучение» (фаза 4, решает координатор утром), файлы `content/learning-v2-course/**`, `modules/learning-v2/content/**`, `app/(tabs)/lessons.tsx`.

## Architecture

Чистые функции без React и React Native: можно тестировать `tsx` и вызывать из worklet-ов Reanimated (формулы помечены `'worklet'`). Модель читает только существующий снимок прогресса (`completedSessionIds`, `currentSessionId`, топология курса), новых источников данных и чтений Firebase нет.

## Security and privacy

Новых данных и разрешений нет; Privacy Policy не затрагивается.
