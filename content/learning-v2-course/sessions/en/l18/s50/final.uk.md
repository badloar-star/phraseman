# Англійська · Урок 18 · Заняття 50 — Повага й самостійність

**Ситуація.** Ви ділитеся сильним враженням і підкреслюєте якість.

**Що ви опануєте:** so + adjective; such + noun phrase
**Нові слова:** respect, freedom, independence, responsibility

## Інтро 1

### Сильне враження

respect — повага. So підсилює прикметник: so kind. Such підсилює групу з іменником: such a kind person. Для одного злічуваного предмета потрібне a або an після such; із множиною й незлічуваними його немає: such kind people, such good news.

**Виберіть фразу для цієї ситуації.**

- ✅ **Mutual respect is so important.**
- ❌ Mutual respect is such important. — *Після пропуску прикметник без іменника: so.*
- ❌ Mutual respect is much important. — *Перед звичайним прикметником тут потрібне so, не much.*

## Інтро 3

### Підкреслити враження

independence — незалежність, самостійність. responsibility — відповідальність, обов’язок. So підсилює прикметник: so kind. Such підсилює групу з іменником: such a kind person. Для одного злічуваного предмета потрібне a або an після such; із множиною й незлічуваними його немає: such kind people, such good news.

**Виберіть фразу для цієї ситуації.**

- ✅ **This is such a big responsibility.**
- ❌ This is so a big responsibility. — *Після пропуску група з іменником: such. Перед злічуваним в однині зберігаємо a/an.*
- ❌ This is a such big responsibility. — *Порядок: such a/an, не a/an such.*
