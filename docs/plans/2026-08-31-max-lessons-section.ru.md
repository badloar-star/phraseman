**Движок уроков был написан и полностью скрыт от пользователя.** Сервер давно
ведёт ученика по 78 речевым целям CEFR, считает прогресс и строит план на пять

| Навигация | Плитка Главной ведёт в раздел, а не в звонок |
| Доступ к урокам | Все открыты сразу, есть «рекомендуемый» |

| Целей в уроке | Одна цель = один урок |
| Незачёт | Слова «не сдал» нет вообще, только достигнутый прогресс |
| Вид каталога | Список секциями по уровням |
| Темы | Поездка, работа, быт, общение (+ основы) — видны внутри раскрытой карточки; чипы-фильтры удалены по решению владельца 2026-09-01 |
| Статистика | Время речи, словарный запас, чистые фразы, длиннейшая реплика |
| Уровень CEFR | Торжественно только при повышении |
| Полный новичок | Урока-ноль НЕ делаем — MAX и так подстраивается |
| 12 целей без сцены | Дописать 12 сцен-интервью |
| Больная тема | MAX сам отступает, не спрашивая |
| Экран звонка | Показывать цель и живой прогресс по ней |
| Название | «Уроки с МАКСом» |

## 3. Что уже сделано (этап 1)

### Сервер

- `functions/src/max_voice_tutor_preview.ts` — превью отдаёт **карту звёзд всех
  уроков** (`catalogMastery`, только ненулевые) и прогресс (`progress`).
  Firestore-чтений это НЕ добавляет: память ученика уже прочитана вызывающим.
- `functions/src/max_voice_mint.ts` — принимает `requestedGoalId`: человек
  выбрал урок в каталоге, MAX ведёт **именно его**. Неизвестный id молча падает
  в обычный порядок (диплинк — недоверенный ввод), причина пишется в лог.
  То же поле принимает и `maxVoicePreflight`, иначе экран подготовки обещал бы
  один урок, а звонок вёл другой.

### Клиент

- `app/max_lesson_catalog.ts` — витрина 78 уроков: id, уровень, тема. Названия
  НЕ дублируются (они уже локализованы на сервере на 9 языков) — правило
  бандл-диеты. Плюс `recommendedMaxLessonId` — та же логика, что у сервера.
- `app/max_lessons.tsx` — экран раздела («Циферблат»): кольцо минут, секции по
  уровням, звёзды. `FlatList` вместо `ScrollView` (78 строк), первый кадр из
  peek-кэша без спиннера, догрузка в фоне.
- `app/max_tutor_preview.ts` — разбор новых полей с валидацией недоверенного
  ввода; `goalId` добавлен в ключ кэша.
- `app/max_call_premint.ts` — `goalId` в ключе заготовки: связь, прогретая под
  один урок, не подставится в другой.
- `app/(tabs)/home.tsx` — плитка ведёт в раздел; **прогрев связи убран**
  намеренно (заготовка держит резерв минут, а заход в каталог ≠ намерение звонить).

### Логи (правило «сперва логи»)

- `[MAX-PRESTART]` — ветка рендера, состояние подготовки, кошелёк, превью,
  причина отказа. Два немых `catch` заменены на логирующие.
- `[MAX-LESSONS]` — источник звёзд (кэш/сеть), каждый ранний выход, открытие урока.

### Сторожа

- `tests/max_lesson_catalog_contract.test.ts` — витрина совпадает с сервером
  (id, порядок, уровни), ни одна тема не съедает половину каталога.
- `functions/src/max_voice_requested_goal.test.ts` — выбранный урок побеждает
  порядок, неизвестный id не ломает звонок, нули не передаются.
- `tests/max_call_home_entry_contract.test.ts` — обновлён под новое поведение
  входа (прежний контракт отменён владельцем, это не регрессия).

## 5. Пайплайн авторства курсов (переносимый на другие языки)

Стадия → вход → работа → выход → **гейт**. Следующая не начинается, пока гейт
предыдущей не закрыт.

### Инварианты (нарушение = остановка, не предупреждение)

| # | Инвариант |
|---|---|
| I1 | Урок = ровно одна коммуникативная цель CEFR |
| I2 | Урок на 12–15 минут; зачёт по целям, таймера-минимума нет |
| I3 | У каждой цели есть минимум одна сцена проверки |
| I4 | Название урока — на языке интерфейса, все 9 локалей |
| I5 | Целевые фразы — на языке курса, английский каталог не переносится |
| I6 | Урок содержательно независим (свободный выбор порядка) |
| I7 | Ученик говорит ≥70 % времени |
| I8 | Тема проверена на чувствительность |
| I9 | Мастери растёт максимум на 1 ступень за звонок |
| I10 | Автор не утверждает собственный материал |
| I11 | Никакой публикации без разрешения владельца |

### Стадии

**S0 · Приём материала.** Владелец задаёт язык, уровень, список целей.
Гейт: язык указан, у каждой цели формулировка «могу …», отпечаток посчитан.

**S1 · Развёртка каталога.** Цели по уровням и темам, порядок по умолчанию.
Гейт: каждая цель в одном уровне и минимум в одной теме; ни одна не требует другой.

**S2 · Материал урока.** 4 опорные фразы, грамматика, 2–3 сцены.
Гейт: фразы на языке курса и уровню соответствуют; **сцена есть**.

**S3 · Локализация витрины.** Название и описание на 9 языках.
Гейт: нет пустых локалей, нет грамматических терминов, кодировка цела.

**S4 · Программа для промпта.** Блок `syllabusBlock` до 1600 знаков.
Гейт: влезает; **стабилен байт-в-байт** для пары (цель, уровень) — иначе рушится
кэш префикса OpenAI и растёт цена минуты; не перебивает SAFETY.

**S5 · Прогон на моделях учеников.** Новичок, тревожный, с акцентом, молчун,
болтун, провокатор.
Гейт: ученик говорит ≥70 %; цель достижима за 15 минут; при трёх неудачах есть
подсказка; провокация обработана; тема нейтральна.

**S6 · Приёмка владельцем.** Автор не утверждает сам.

**S7 · Релиз.** Сторожа зелёные, Джарвис обновлён, правила Firestore закрыты,
Privacy Policy сверена, отдельное разрешение владельца.

### Перенос на другой язык

Меняется только контент S0–S3. Код не меняется: `CanDoGoal` языко-независим,
`renderCanDoGoalBlock` умеет «курс на языке X — подбери фразы на X», локалей 9.

## 5.1. Как деплоить функции MAX

Функции MAX живут в **отдельной кодовой базе `max`** (папка `functions-max`,
реэкспорт из `functions/src/*`). Обычная команда с именем функции падает:

```
Error: No function matches the filter: default:maxVoicePreflight
```

Правильная форма — с именем кодовой базы:

```
npx firebase deploy --only "functions:max:maxVoicePreflight,functions:max:maxVoiceMint" --project phraseman-ea0b3
```

Проверено 2026-09-01: без деплоя раздел показывает технические id вместо
названий, и логи говорят об этом прямым текстом
(`[MAX-TITLES] net: сервер не прислал catalogTitles (старая версия функций?)`).
