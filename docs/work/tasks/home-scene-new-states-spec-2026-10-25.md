# Новые состояния сцены Главной — правила показа (25.10)

Governance-ID: TG-60C4CBC95EBA

Заказ владельца 25.10 («добавить ещё новых состояний экранов на Главной… все экраны анимированы»), живой макет на настоящих снимках: docs/design/v2-app/home-new-states.html. Всё — из данных телефона, без новых чтений Firestore. Особая сцена — не чаще одной в день, одна и та же — не два дня подряд; срочные (newbie, streak_risk, no_energy, welcome_back, streak_lost, exam_ready) всегда главнее. Журнал показов — локально (AsyncStorage), на сервер не уходит. Анимации — один раз при показе, ease-out 180–320 мс, «Уменьшить движение» — без сдвигов.

Порядок (предложение): newbie → streak_risk → no_energy → welcome_back → streak_lost → exam_ready → milestone → holiday → all_done → mistakes_pile → words_due → peak_overtaken → friend_nudge → mistake_poke → phrase_of_day_unseen → personal_best → mistake_mastered → weekly_recap → fun_stats → day_done → offline → continue (time_of_day — тон у continue).
