# Тема по умолчанию для R1 — варианты для владельца (Ядро, 12.10 ночь; код НЕ менялся)

**Вопрос.** Новый человек сейчас видит «Графит» на «Спокойно» (ползунок 0: серо-белая кнопка, без цвета). Все макеты 2.0 нарисованы
в «Авроре» на «Максимуме» (`grad_aurora`, ползунок 1: мятно-фиолетовое свечение фона, цветная дымка в карточках). Что показывать новым?
Старых пользователей НЕ трогаем ни в одном варианте.

## Как сейчас устроено (по коду)

- Выбор темы хранится **только на телефоне**: `AsyncStorage` ключи `liquid_glass_theme`, `liquid_glass_intensity` (+ старый
  `liquid_glass_color_level`), `liquid_glass_appearance` (`components/ThemeContext.tsx:295–300`). В облако не уходит — новый телефон
  = выбор по умолчанию.
- Нет ключа → `resolveLiquidGlassTheme(null)` = `'graphite'` (`constants/liquidGlassThemePalette.ts:243`); нет ползунка →
  `migrateStoredLiquidGlassIntensity` = 0 (`constants/liquidGlassThemeIntensity.ts:76`; `DEFAULT_LIQUID_GLASS_VARIANT` = calm/dark/0).
- Ключи пишутся **только когда человек сам что-то поменял**. Значит, у большинства старых пользователей ключей НЕТ — они на «Графите»
  по умолчанию, ровно как новый человек.
- Сплеш ждёт чтения темы (`THEME_HYDRATION_CEILING_MS`), поэтому смена дефолта не даёт мигания первого кадра.

**Следствие:** «одна константа» (`'graphite'` → `'grad_aurora'`, intensity 0 → 1) перекрасит ВСЕХ старых, кто тему не трогал. Чтобы
изменить только новых, нужна **метка первого запуска**: при первом чтении темы, если ключей темы нет И онбординг не пройден
(`onboarding_done !== '1'` — тот же один `multiGet`, без лишних чтений), записать новичку новую тему; если ключей нет, но онбординг
пройден — это старый человек: ничего не менять (по желанию — записать ему явный «Графит/0», чтобы будущие смены дефолта его не задели).

## Варианты

| | (а) Оставить «Графит / Спокойно» | (б) «Аврора / Максимум» для новых | (в) «Аврора» на середине (0,5 — «Акцент») для новых |
|---|---|---|---|
| Что видит новичок | серо-белый интерфейс, цвет только по желанию в Настройках | как на всех макетах и в материалах для магазина: свечение фона, цветная дымка в карточках | фон и карточки как у «Графита», цвет «Авроры» только на кнопках, выборе, таббаре, прогрессе, значках |
| Код | ничего | метка первого запуска в `ThemeContext` (~20 строк в чтении темы) + константа `NEW_USER_DEFAULT_THEME` + тест | то же, другое значение ползунка |
| Старые пользователи | не затронуты | не затронуты (метка смотрит на `onboarding_done`) | не затронуты |
| Брошенный онбординг | — | человек без пройденного онбординга считается новым → получит «Аврору» (он приложением ещё не пользовался) | то же |
| Новый телефон старого человека | «Графит» | «Аврора» (тема не синхронизируется — так и сейчас для любого выбора) | «Аврора» на 0,5 |
| Контраст | проверен | Темы проверяли все темы × ступени ≥ 4,5 (`tests/theme_contrast_report.test.ts`, правила text/secondary на карточке/плашке/шторке/фоне) — для `grad_aurora` на 1 нужно подтвердить прогоном (тяжёлый тест — в окне памяти) | то же, ступень 0,5 |
| Скорость | самая лёгкая | «Максимум» рисует свечение фона и дымку в карточках — на слабых Android проверить кадры на Главной/Уроках (Сверка, `[PERF-R1]`) | без свечения и дымки — как «Графит» по нагрузке |
| Риск | первое впечатление «серое», расходится с макетами и стор-скриншотами | яркость может утомлять; человек меняет в Настройках | минимальный: цвет есть, фон спокойный |
| Сверка «приложение = макет» | не влияет (кадры снимаются с `theme=`/`level=` подменой) | не влияет | не влияет |

## Рекомендация Ядра

**(б) «Аврора / Максимум» для новых, через метку первого запуска** — тогда новый человек видит ровно то, что на макетах и скриншотах
магазина («приложение = макет»), а старые не замечают ничего. Условие: до сборки подтвердить два пункта — контраст `grad_aurora` на 1
(прогон `theme_contrast_report`) и кадры «Максимума» на Главной/Уроках на эмуляторе (Сверка). Если хоть один не проходит —
**(в)** как безопасный запасной: цвет «Авроры» без свечения.

## Если владелец выберет (б) или (в) — что сделать (Ядро, ~1 час)

1. `constants/liquidGlassThemeVariants.ts` (или рядом): `NEW_USER_DEFAULT_THEME = { themeId: 'grad_aurora', intensity: 1 }` (для (в) — 0.5).
2. `components/ThemeContext.tsx`, чтение темы: в тот же `multiGet` добавить `onboarding_done`; если `liquid_glass_theme`, `…_intensity`,
   `…_color_level` пусты и онбординг не пройден → применить и записать новую тему (один `multiSet`), лог `[THEME-DEFAULT] new_user`;
   иначе лог `[THEME-DEFAULT] existing_user_kept` с причиной.
3. Тест: новичок → Аврора/1 и запись; старый без ключей (онбординг пройден) → Графит/0 и никаких записей; человек с выбранной темой — без
   изменений; сбой чтения → прежний дефолт.
4. Строка решения в `03_DECISIONS.md`.

Firebase: 0 чтений и записей (только локальное хранилище, тот же один `multiGet`).
