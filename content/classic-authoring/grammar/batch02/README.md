# PhraseMan Classic · ES-04–06

Учебные материалы по методике классического английского курса, не Learning V2. Второй пакет добавляет 150 переводов, не заменяет ES-01–03 и не переписывает прогресс. Используется испанский для Испании (es-ES) с RU и UK как отдельными языками объяснений. Внутри урока нет разговорного теста или отдельного задания по грамматике: все 50 упражнений — сборка перевода по одному слову.

## С чего начать

Откройте `START.html` локально. Первый экран — вступление. Уроки 4, 5 и 6 доступны сверху. Переключение RU/UK не меняет язык ответа и не сбрасывает выбранные плитки. «Все 50 фраз» — авторский обзор, где ответ открыт. В «Практике» он скрыт до завершения. «Почему так? Теория» возвращает к той же позиции. `ALL-150.html` — единая читаемая версия двух переводов и разборов; `phrase-audit.tsv` — редакторский экспорт.

| № | Один новый навык | Справочник |
|---|---|---|
| 04 | Представиться и назвать профессию или конкретного человека с ser | Настоящее время ser, все 6 форм в заданиях; профессия без артикля и указание на конкретную роль |
| 05 | Спросить о месте, человеке или вещи вместо ответа «да/нет» | Dónde, quién/quiénes, qué; две таблицы ser и estar. Формы без упражнения явно помечены как справочные |
| 06 | Подобрать el/la/los/las к известному существительному | Четыре формы артикля со своими примерами; отдельно — отсылка к уже знакомым формам estar |

Проверяйте голос на устройстве отдельно: используется системный es-ES с локальным испанским запасным голосом и скоростями 0,75/1/1,25. Аудиофайлов либо обращений к облачному TTS нет. Результаты HTML сохраняются только в этом браузере; это не синхронизация аккаунта.

## Перенос в приложение

1. Сначала установить ES-01–03 и выбрать именно сочетание `course=classic, studyTarget=es`. Прочитать `manifest.json`, проверить контрольные суммы. Не открывать английский курс как запасной вариант при отсутствии испанского пакета. Не менять экономику, требования к открытию уроков и Learning V2.
2. Подать `classic-adapter/ES-04.phrases.json` и файлы 05/06 в существующий путь `LessonPhrase[]`. Для ES целевой текст — `spanish`, сборка — `words`, а `english` — корректный служебный перевод, но НЕ запасной ответ ученика. В этой версии `app/phrase_target_utils.ts` содержит отдельные проверки активации испанского: не считать наличие JSON активацией функции. Для ES не включать слова английского `wordsEn`.
3. По неизменяемому `id` присоединить запись `lessons/ES-XX.json`. `prompt[ru/uk]` показывает сам перевод, **`context[ru/uk]` надо показывать до первого выбора**, даже если строка перевода совпадает в двух упражнениях. Например, ES-04:03/04 (пол врача) и :26/27 (формальное/неформальное обращение к группе). Источник истины — объединённая запись, а не изолированная строка адаптера. При наличии контекста, но отсутствии места для его вывода не выпускать такой экран.
4. `practiceWords[j]` — одна позиция; `choices` содержит шесть слов, `correct` и `distractors` — состав банка. Отклонение не продвигает позицию. Вариант отклика: «Для этого образца нужно другое слово» + `explanation[lang]`. Образец не объявляется единственно возможным переводом. `acceptedExamples` — проверенные дополнительные полные образцы, не исчерпывающий список свободных переводов; не показывать заранее. Вопросительные знаки из `punctuation` добавляет интерфейс. Не тратить их на отдельные плитки.
5. Сохранить показ трёх вводных экранов до практики. `theory` — семь самостоятельных глав; `analysis` — объяснение фразы; ссылки `examples` указывают на её ID. Для вопроса проверять, что не потеряны начальный ¿, конечный ? и ударения в dónde/quién/qué; у él ударение, у артикля el его нет.
6. Справочники: в 04 рендерить `verbTables[0]`; в 05 ОБЕ таблицы `verbTables`; в 06 сперва `grammarTables` с артиклями, затем `verbTables`. Поле `verbs` оставлено для обратной совместимости, но само по себе недостаточно. Для форм без примеров оставлять пометку «для справки», а не ссылку на постороннюю фразу.
7. `ledger.json` кумулятивен для 01–06: стабильные `id`, `firstLesson`, `firstPhrase` сохраняются. Расширять данные существующей карточки и ссылки на фразы, не создавать карточку из формы, не переустанавливать состояние FSRS и не переносить результаты между языками. Старые `examples` ведут в первую поставку: при интеграции разрешать их через объединённый каталог, не считать их удалёнными. Показ словаря: сначала `vocabulary.new`, затем `seenBefore` с пояснением «уже встречались».
8. Проверить на настоящих устройствах: с новым профилем пройти из 03 в 04; на RU и UK сверить контекст и гласные с ударением, TTS, фокус/крупный шрифт, офлайн-старт, переход в теорию из середины и возврат без потери слова; прогресс 01–03 и экономика не меняются. Автотест HTML не проверяет React Native и не заменяет независимую вычитку преподавателем.

## Воспроизведение и продолжение

В рабочей ветке читать `content/classic-authoring/grammar/batch02/`. В скачанном пакете тот же каталог — `source/batch02/`; соседний `batch01/` — его зависимость. Из `batch02/`: `python3 -B compile.py /tmp/pm-es0406` (пустой каталог), `python3 -B qa.py /tmp/pm-es0406`, `python3 -B smoke.py /tmp/pm-es0406/START.html`. Python 3.10+, для последнего шага нужен Chromium. Строки `04.psv`–`06.psv` — авторские источники, `editorial.psv` — окончательные изменения по ID, `*.teach` — вступления и отдельная теория на двух языках. Уроки не генерируются заново при запуске приложения. Контрольный материал курса — исходники классического EN и таблица `../es/programme.psv`.

Грамматические ориентиры: [Instituto Cervantes, PCIC A1–A2: грамматика](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/niveles/02_gramatica_inventario_a1-a2.htm), [орфография](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/niveles/04_ortografia_inventario_a1-a2.htm). Фразы и объяснения авторские. Сопоставление с программой не равно сертификации уровня.

Дальше — **ES-07: hay, наличие предмета**, затем ES-08 mi/tu/su и ES-09 настоящее время глаголов на -ar. Взять кумулятивный словарь этой партии, не считать уже изученные глаголы и артикли новыми. Сборка и публикация мобильного приложения в этот пакет не входят.
