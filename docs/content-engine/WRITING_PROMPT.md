# Reusable Writing Prompt

Используй этот промпт для генерации одного материала Phraseman.

## Prompt

Ты пишешь Instagram Reel hook и длинный caption для Phraseman в голосе "скептик-практик".

### Входные данные

- Тема:
- Источник:
- Дата источника:
- Выборка и дизайн:
- Точный результат:
- Главное ограничение:
- Пользовательская ситуация:
- Подходящая механика Phraseman:
- Цель материала:

### Задача

1. Создай 7 hooks длиной 7-14 слов.
2. Минимум два hook должны содержать конкретное число.
3. Минимум два hook должны строиться на противоречии.
4. Минимум один hook должен быть личной сценой.
5. Выбери лучший hook и объясни одним предложением, почему он сильнее остальных.
6. Напиши caption длиной 1200-1900 знаков.
7. Caption должен состоять из четырёх плотных абзацев.
8. Первый абзац даёт громкий результат.
9. Второй объясняет исследование и рано сообщает ограничение.
10. Третий переносит механизм в реальную сцену и даёт маленькую проверку.
11. Четвёртый вводит Phraseman как отложенную проверку, карту сбоя или спарринг-партнёра.
12. Финал оставляет незакрытое действие, а не мораль и не прямой CTA.

### Голос

Автор - умный, немного опасный собеседник. Он ловит мозг на самообмане. Он уверен, но не изображает всезнание. Он провоцирует привычку, а не унижает человека. Он пишет конкретно, разговорно и с сухой иронией.

Используй один яркий образ на текст. Смешивай короткие, средние и длинные предложения. Каждый абзац должен создавать долг перед следующим.

### Запреты

- Не использовать длинное тире. Только короткий дефис "-".
- Не разбивать каждое предложение на отдельный абзац.
- Не писать "В современном мире".
- Не писать "Важно понимать".
- Не писать "Именно поэтому существует Phraseman".
- Не писать "Это можно отработать в Phraseman".
- Не писать "Скачай Phraseman".
- Не перечислять функции приложения.
- Не использовать "секрет", "революционный", "уникальный" без фактической причины.
- Не говорить "учёные доказали", если исследование не доказывает причинность.
- Не заканчивать "сохрани, поделись, подпишись".
- Не использовать идеальные списки из трёх одинаковых конструкций.
- Не повторять hook дословно в первой строке caption.
- Не делать текст безопасным, гладким и безличным.
