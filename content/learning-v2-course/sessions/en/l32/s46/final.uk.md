# Урок 32 · Заняття 46 — Шукаємо кота вдома

**Ситуація.** Ви допомагаєте Анні знайти її кота вдома.

**Що ви опануєте:** пояснювати припущення, відкидати неможливий варіант і уточнювати предмет.
**Нові слова:** —
**Повторюємо знайомі слова:** cat, door, toy, bowl

## Інтро 1

### Спостереження й можливість

Кіт зазвичай нявкає біля кухні, але зараз його не чути. Ви припускаєте, що він спить. The cat is quiet, so it might be asleep. — Кіт не видає звуків, тому він, можливо, спить. Складіть The cat is quiet + so + it might be asleep. До so назвіть спостереження, після so — можливий висновок із might. Перед станом asleep потрібна зв’язка be.

**Виберіть фразу для цієї ситуації.**

- ✅ **The cat is quiet, so it might be asleep.**
- ❌ The cat is quiet, so it might is asleep. — *Після might використовуємо be.*
- ❌ The cat is quiet, so it might to be asleep. — *Після might не ставимо to.*

---

## Інтро 2

### Цей варіант виключений

Анна припускає, що двері відчинені, але ви бачите, що вони щільно зачинені. The door can't be open. — Двері не можуть бути відчиненими. Складіть The door + can’t + be + open. Спостереження виключає названий стан. Can’t виражає цей висновок; перед open тут потрібна зв’язка be.

**Виберіть фразу для цієї ситуації.**

- ✅ **The door can't be open.**
- ❌ The door can't is open. — *Після can’t використовуємо be.*
- ❌ The door can't to be open. — *Після can’t не ставимо to.*

---

## Інтро 3

### Уточнюємо предмет

Ви показуєте Анні предмет й уточнюєте свою дію з ним: The toy I found is small. — Іграшка, яку я знайшов, маленька. Складіть The toy + I found + is small. Частина I found уточнює toy. That можна опустити: I вже називає того, хто виконав дію.

**Виберіть фразу для цієї ситуації.**

- ✅ **The toy I found is small.**
- ❌ The toy I found it is small. — *Не повторюємо названий предмет займенником it.*
- ❌ The toy I finding is small. — *Потрібна минула форма found.*
