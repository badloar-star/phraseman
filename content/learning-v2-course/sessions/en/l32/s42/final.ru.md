# Урок 32 · Занятие 42 — Открываем комнату для гостей

**Ситуация.** Вы с Анной готовите комнату для гостя.

**Что вы освоите:** объяснять предположение, отвергать невозможный вариант и уточнять предмет.
**Новые слова:** —
**Повторяем знакомые слова:** window, bed, blanket, room

## Интро 1

### Наблюдение и возможность

На стекле капли воды. Вы предполагаете, что стекло холодное, но ещё не касались его. The window is wet, so it might be cold. — Окно мокрое, поэтому оно, возможно, холодное. Соберите The window is wet + so + it might be cold. До so назовите наблюдение, после so — возможный вывод с might. Перед состоянием cold нужна связка be.

**Выберите фразу для этой ситуации.**

- ✅ **The window is wet, so it might be cold.**
- ❌ The window is wet, so it might is cold. — *После might используем be.*
- ❌ The window is wet, so it might to be cold. — *После might не ставим to.*

---

## Интро 2

### Этот вариант исключён

Анна считает, что на кровати ничего нет, но вы видите на ней большой чемодан. The bed can't be empty. — Кровать не может быть пустой. Соберите The bed + can’t + be + empty. Наблюдение исключает названное состояние. Can’t выражает этот вывод; перед empty здесь нужна связка be.

**Выберите фразу для этой ситуации.**

- ✅ **The bed can't be empty.**
- ❌ The bed can't is empty. — *После can’t используем be.*
- ❌ The bed can't to be empty. — *После can’t не ставим to.*

---

## Интро 3

### Уточняем предмет

Вы показываете Анне предмет и уточняете своё действие с ним: The blanket I washed is dry. — Одеяло, которое я постирал, сухое. Соберите The blanket + I washed + is dry. Часть I washed уточняет blanket. That можно опустить: I уже называет того, кто выполнил действие.

**Выберите фразу для этой ситуации.**

- ✅ **The blanket I washed is dry.**
- ❌ The blanket I washed it is dry. — *Не повторяем названный предмет местоимением it.*
- ❌ The blanket I washing is dry. — *Нужна прошедшая форма washed.*
