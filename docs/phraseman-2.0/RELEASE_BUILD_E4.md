# E4 — как собрать релиз 2.0.0 (короткая инструкция, без секретов)

Для владельца. Ключи, пароли и файлы сервисных аккаунтов здесь не приводятся: они живут в секретах EAS и в локальном
файле `service-account.json`, который уже настроен в `eas.json`. Команды запускаются в терминале из корня проекта.

## 0. Перед сборкой — одна проверка

```bash
npm run release:precheck
```

- Номера версий: `2.0.0`, сборка `131` (`app.json`) — синхронны.
- Если пишет «номера разошлись», выполните:

```bash
npm run release:precheck -- --bump
```

- Сейчас эта проверка **красная** — 3 ворот (подробно в `INBOX_COORDINATOR_FROM_CORE.md`, §CORE-GATES):
  1. «приложение = макет»;
  2. «исходник = выпуск Learning V2»;
  3. «озвучка Learning V2».
- Пока ворота красные, сборку **не запускать**: те же ворота стоят в `eas-build-post-install` и уронят сборку на
  сервере уже после загрузки архива — платная сборка сгорит.

## 0а. Рычаги ворот (Ядро, 11.10)

- **Ворота Learning V2.** В стор-сборке (`EXPO_PUBLIC_STORE_RELEASE=1`, профиль production ставит его сам) ворота
  «озвучка Learning V2» печатают «пропущено: не входит в стор-сборку» и не красные. Ворота «исходник = выпуск
  Learning V2» ещё не закоммичены их владельцем (Codex); тот же пропуск подключается к ним тремя строками
  из `scripts/store_release_surface.mjs` (см. INBOX §CORE-LEVERS).
  - Работает только если `router.ctx.js` вырезает все маршруты `*learning[_-]v2*`.
  - Локальная проверка с тем же режимом:

```bash
EXPO_PUBLIC_STORE_RELEASE=1 npm run release:precheck
```

- **Ворота паритета макетов** по умолчанию СТРОГИЕ. Обойти их может только владелец, своим решением: переменная
  окружения EAS с датой и причиной. При ней сборка печатает громкое «ВОРОТА ПАРИТЕТА ОБОЙДЕНЫ ВЛАДЕЛЬЦЕМ: строк не
  принято N из M» и не падает. Включить (дату и причину поставить свои):

```bash
eas env:create --environment production --name PARITY_GATE_WAIVER --value "owner-2026-10-11:релиз 2.0.0 до полной сверки" --visibility plaintext
```

  - После релиза удалить переменную:

```bash
eas env:delete --variable-name PARITY_GATE_WAIVER --variable-environment production
```

  - Если флаги команды в вашей версии eas-cli другие — проверьте `eas env:create --help`.
  - Кривое значение (не `owner-ГГГГ-ММ-ДД:причина`) обход НЕ включает — ворота остаются строгими.

## 1. Сборка в облаке EAS (профиль production)

```bash
eas build --platform android --profile production
```

```bash
eas build --platform ios --profile production
```

- Профиль `production` сам ставит `EXPO_PUBLIC_STORE_RELEASE=1`, канал `production`, окружение `production`.
- Ключи RevenueCat и Google берутся из секретов EAS — локально их не нужно.
- `eas.json` требует чистого коммита (`requireCommit: true`): перед сборкой всё должно быть закоммичено
  и отправлено (`git push`).

## 2. Отправка в магазины

```bash
eas submit --platform android --profile production
```

```bash
eas submit --platform ios --profile production
```

- Android уходит во внутренний трек (`track: internal`); дальше выкатка — в Play Console.
- iOS уходит в App Store Connect (`ascAppId 6764800879`); дальше TestFlight и отправка на ревью.
- Можно запустить «дождаться iOS-сборки и отправить»:

```bash
npm run eas:submit-ios-wait
```

## 3. Если что-то пошло не так

- **Упала команда `eas`, а сборка на сервере идёт.** Падение локальной команды не отменяет ни сборку, ни отправку —
  они живут на сервере Expo. Смотрите статус на expo.dev, не запускайте вторую сборку.
- **Сборка упала на шаге упаковки с кодом 128.** Это хук веток, который мешает `git clone` на сервере EAS
  (известный случай). Проверьте, что ветка отправлена и коммит существует на сервере.
- **Магазинная сборка открылась без картинок и звуков.** Это протухший манифест обновлений; лечится пересборкой
  ресурсов. Касается только локальной Gradle-сборки, не облачной EAS.

## 4. Что выкладывает владелец отдельно (не сборка)

- **Серверные функции** — по списку в `DEPLOY_NOW.md`. Выкладывает только владелец.
- **OTA-обновление** (без новой сборки):

```bash
npm run eas:update:production
```

- Внутри — проверка `update:gate` и замок выкладки.
