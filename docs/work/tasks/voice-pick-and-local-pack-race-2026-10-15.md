# Выбор голоса: сбой записи не молчит + гонка правок локального набора + хаптик Приватности (15.10)

Governance-ID: TG-2CA7D7CA026E

## Outcome
По решению координатора до сборки: (1) экран выбора голоса (Карточки) при сбое записи пишет `[VOICE-PICK]` с причиной, откатывает выбор и показывает короткий тост; (2) две быстрые правки одного локального набора («удалить/вернуть/добавить карточку») не затирают друг друга — риск потери правки пользователя; (3) мелочь от Авторизации про хаптик на переключателях Приватности — проверить и привести к виду остальных переключателей.

## Scope
`app/flashcards/voice_prefs.ts` (`setEnVoiceId` возвращает `Promise<boolean>`), `app/flashcards_voice_picker.tsx`; новый `app/community_packs/local_pack_lock.ts`, `localPackCardOps.ts`, `localPackCardAdd.ts`; тесты. Хаптик Приватности: `app/privacy_settings.tsx` — только свой ханк (в файле чужие правки Тем).

## Architecture
Выбор голоса: локальное состояние меняется в кадре тапа, диск — фоном; результат записи — boolean; номер выбора защищает от позднего ответа. Гонка наборов: очередь по id набора (`createSerialPerKey`) вокруг цикла «прочитать → изменить → записать»; запись по-прежнему идёт через `saveLocalAuthorPack` (своя общая очередь), взаимной блокировки нет — очереди разные и вложены в одну сторону.

## Security and privacy
Данные не затрагиваются (локальные настройки голоса и локальные наборы).

## Technical debt
Редактор набора (`community_pack_create`) пишет набор целиком в обход очереди по id: одновременно с «Удалить карточку» из каталога не бывает (разные экраны), в долг не записываю.

## Verification
Тесты: «две правки подряд — обе сохранены» для удаления/добавления; выбор голоса — откат и тост при сбое записи; существующие `fc_voice_prefs`, `local_pack_card_add`.
