## Outcome

Ученик после неверного ответа получает разбор, в котором ИИ явно назвал: какое слово не то, какое
нужно, правило одной строкой, пояснение в 1–2 предложениях и пару коротких примеров из тех же слов.
Экран получает эти части отдельными полями и может выделить промах в самой фразе.

Мера успеха: (1) ни одного ответа с ложной фразой «в русском нет артиклей» у интерфейсов с
артиклями; (2) правильная фраза не дублируется в тексте разбора; (3) случай «ошибки нет»
приходит явным признаком; (4) старые сборки приложения продолжают получать обычный текст.

## Architecture

Сейчас: модель возвращает два текста между маркерами `<PHRASEMAN_FULL_V1>` / `<PHRASEMAN_ELI5_V1>`;
сервер кладёт в кэш `full` и `eli5`; экран показывает `full` одним абзацем.

Станет: модель возвращает JSON по строгой схеме (`verdict`, `wrong`, `right`, `rule`, `why`,
`you_said`, `pair`, `also`, `simple`). Сервер проверяет его (форма, длины, язык, фрагменты
действительно взяты из двух предложений), собирает из полей `full` и `eli5` для старых сборок и
кладёт в кэш всё вместе с `breakdown`. Ответ функции дополняется необязательным `breakdown`.

Инварианты: один платный вызов на уникальную ошибку; не более трёх попыток генерации; в кэш не
попадают сырые ответы ученика (поля `wrong`/`right`/`pair` — слова из учебной фразы, как и в
прежнем тексте разбора); старый клиент без знания о `breakdown` работает без изменений.

## Security and privacy

Набор данных, уходящих в OpenAI, не меняется (те же фразы урока и ответ ученика, согласие уже
спрашивается). Новых полей профиля, коллекций, сервисов и разрешений нет — политика
конфиденциальности не затрагивается. Авторизация вызова, лимиты, дневной потолок расходов и
блокировки не меняются. Ответ модели считается недоверенным вводом: проверяется по схеме, длинам и
языку до записи в кэш. App Check не трогается (запломбирован).

Откат коммитов возвращает прежний формат. Записи кэша версии 7 при откате перестанут читаться
(версия ниже текущей не принимается только в сторону роста, поэтому при откате константу вернуть
