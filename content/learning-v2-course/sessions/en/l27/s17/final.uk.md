# Урок 27 · Заняття 17 — Якби вийшли зараз

**Ситуація.** Ви обговорюєте дорогу, час пересадки й коротку поїздку з друзями.

**Що ви опануєте:** if-clause without would; result with would
**Нові слова:** aboard, layover, backpacker, getaway

## Інтро 1

### Вийти раніше

Aboard — на борту або на транспортному засобі, наприклад у потязі. Welcome aboard — ласкаво просимо на борт. Ви обговорюєте час виходу: If we left now, we would arrive early — якби ми вийшли зараз, ми б приїхали рано. У цьому типі уявної умови після if ставимо past simple: left. Would стоїть у результаті: would arrive. Left тут не повідомлення, що ми вже вийшли. Можна змінити порядок: We would arrive early if we left now.

**Виберіть фразу для цієї ситуації.**

- ✅ **We would arrive early if we left now.**
- ❌ We would arrived early if we left now. — *Після would потрібна початкова форма arrive.*
- ❌ We would arrive early if we would left now. — *У цій умові left без would.*

---

## Інтро 2

### Пересадка й попутник

Layover — зупинка між частинами поїздки, часто очікування наступного рейсу під час пересадки. We have a two-hour layover — у нас двогодинна пересадка. Backpacker — мандрівник із рюкзаком, зазвичай той, хто пересувається з ним між місцями. She is a backpacker — вона мандрує з рюкзаком. У вас мало часу: I would join you if I had more time — я б приєднався, якби мав більше часу. Had — умова, would join — результат; порядок частин не змінює цього розподілу.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would join you if I had more time.**
- ❌ I would joined you if I had more time. — *Після would потрібно join.*
- ❌ I would join you if I would had more time. — *В умові had без would.*

---

## Інтро 3

### Невелика поїздка

Getaway — коротка поїздка для відпочинку, розмовне слово. We need a weekend getaway — нам потрібна поїздка кудись на вихідні. Друзі ще не знають про плани: They would come if they knew — вони б приїхали, якби знали. Knew — форма know; would come — результат. Це не впевнена обіцянка за друзів, а припущення про іншу ситуацію. Ви планували їхати без зайвих речей. Рюкзак поки один, але список того, що «точно знадобиться», уже на двох сторінках.

**Виберіть фразу для цієї ситуації.**

- ✅ **They would come if they knew.**
- ❌ They would came if they knew. — *Після would потрібна початкова форма come.*
- ❌ They would come if they would knew. — *В умові knew без would.*
