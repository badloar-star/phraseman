# Англійська · Урок 22 · Заняття 29 — Обрати взуття та одяг

**Ситуація.** Ви обираєте речі для тепла й зручності.

**Що ви опануєте:** determiner|adjective + one|ones
**Нові слова:** lace-up, slip-on, pull-on, fleece-lined

## Інтро 1

### Обрати черевики на шнурках

Продавець показує вам черевики з блискавкою та на шнурках. Ви обираєте другі. I prefer the lace-up ones — я віддаю перевагу тим, що на шнурках. Після I prefer ставимо the, опис lace-up і ones. Ones замінює вже назване boots: черевики у формі для кількох. Опис зберігаємо перед ones, щоб було зрозуміло, які черевики ви обрали.

**Виберіть фразу для цієї ситуації.**

- ✅ **I prefer the lace-up ones.**
- ❌ I prefer the lace-up one. — *У цій ситуації назву речі замінюємо one для однієї речі або ones для кількох.*
- ❌ I prefer the lace-up them. — *У цій ситуації назву речі замінюємо one для однієї речі або ones для кількох.*

## Інтро 2

### Обрати туфлі без застібок

Ви розглядаєте туфлі й обираєте модель без шнурків та застібок. I want the slip-on ones — я хочу ті, що взуваються без застібок. Спочатку I want, потім the slip-on ones. Shoes уже назване й стоїть у формі для кількох, тому замінюємо його на ones. Slip-on залишається перед ones і відрізняє обрані туфлі від решти.

**Виберіть фразу для цієї ситуації.**

- ✅ **I want the slip-on ones.**
- ❌ I want the slip-on one. — *У цій ситуації назву речі замінюємо one для однієї речі або ones для кількох.*
- ❌ I want the slip-on them. — *У цій ситуації назву речі замінюємо one для однієї речі або ones для кількох.*

## Інтро 3

### Обрати куртку з підкладкою

Продавець показує дві куртки, і ви вказуєте на одну з флісовою підкладкою. I want the fleece-lined one — я хочу ту, що з флісовою підкладкою. Після I want ставимо the, опис fleece-lined і one. One замінює jacket: ви обираєте одну куртку. Опис перед one допомагає зрозуміти, яку саме.

**Виберіть фразу для цієї ситуації.**

- ✅ **I want the fleece-lined one.**
- ❌ I want the fleece-lined ones. — *У цій ситуації назву речі замінюємо one для однієї речі або ones для кількох.*
- ❌ I want the fleece-lined it. — *У цій ситуації назву речі замінюємо one для однієї речі або ones для кількох.*
