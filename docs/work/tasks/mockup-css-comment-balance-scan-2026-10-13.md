## Outcome
Известно, нет ли в `docs/design/v2-app/*.html` других незакрытых CSS-комментариев (особенно в страницах, правленных ночью моей сессией), и каждая находка исправлена или передана владельцу страницы.

## Scope
Разовый скрипт-сканер вне репозитория по блокам `<style>`; правки только в тех страницах, где виноват мой коммит и в файле нет чужих незакоммиченных правок; отчёт координатору.

## Architecture
Для каждого `<style>` сравнивается число `/*` и `*/` и ищется комментарий, открытый без закрытия до конца блока. Страницы, правленные мной за ночь, перечисляются по `git log --author` и по содержимому коммитов.

## Security and privacy
Только чтение макетов, данных нет.

## Technical debt
Сканер не заменяет рендер: правка образца не считается сделанной без рендера, при отсутствии слота рендер просим у Макетов до отчёта.

## Verification
Запуск сканера по всем страницам; рендер правленных мной страниц (dialogs.html после 86f88556a) средствами Макетов.

## Rollback
Нет изменений в репозитории, если находок нет; при находках — git revert соответствующей правки.
