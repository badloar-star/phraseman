# Аудит графики на сыром accent в светлой теме (светлая «Аврора»/«Максимум» и другие градиентные темы)

Governance-ID: TG-7BE44171CB3A
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора 12.10 по находке контраста «Авроры»: сырой accent на светлом фоне 1,0–1,8)

## Outcome
Таблица «файл:строка → элемент → на что заменить» в `docs/phraseman-2.0/LIGHT_ACCENT_GRAPHICS_AUDIT_2026-10-13.md`: все места в `app/` и `components/` (R1; Learning V2 Codex — отдельным списком без правок), где ГРАФИКА (кольца, полосы, контуры состояний, точки, ползунки, значки-заливки) и попутно текст/значки красятся сырым `accent` вместо `accentBorder`/`progressGradient`/`accentText`. Тест-сторож с храповиком (число таких мест не растёт). Сами экраны НЕ правятся: список отдаётся Дизайну координатором.

## Scope
Новый скрипт `scripts/light_accent_graphics_scan.mjs` (статический обход, без исполнения экранов), документ-аудит, тест `tests/light_accent_graphics_ratchet.test.ts` и базовая линия `config/light-accent-graphics-baseline.json`. Файлы экранов и компонентов не меняются.

## Architecture
Регулярный разбор строк `<объект>.accent` с окном контекста ±4 строки: классы text / icon / svg / border / fill-graphic / gradient-graphic / switch / other считаются «к исправлению»; вуали (`accent + '1F'`, alpha(...)), тени, заливки под текстом с `accentInk`, кнопки и артовые слоты (`lessons.accent` и т. п.) в учёт не входят. Пометка `light-accent-ok: причина` в строке — осознанное исключение. Базовая линия хранит число мест по файлам и может только уменьшаться.

## Security and privacy
Только статический разбор исходников и документация; данные пользователей не затрагиваются.

## Technical debt
Эвристика классификации может ошибаться на нетиповых местах (класс `other` — на ручную проверку); подтверждение кадром светлой «Авроры» 1 — через Сверку после правок Дизайна.

## Verification
Ручная выборка классификации по коду, тест-храповик через `npm run test:one` (по слоту светофора, `--runInBand`), срез типов не нужен (скрипт `.mjs` и тест без новых зависимостей, тест проверяется прогоном).

## Rollback
