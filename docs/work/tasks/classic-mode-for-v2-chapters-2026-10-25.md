# Task packet: «классический режим» главы Learning V2 — изучение (без кода)

Governance-ID: TG-83110AE755C3
Status: Research report (код не менялся)
Owner: 2 · ДИЗАЙН (по заданию 0 · КООРДИНАТОР, идея владельца 25.10)
Related epic/enabler: Learning V2 (`modules/learning-v2/**`), классический курс (`app/lesson1.tsx`)

## Outcome

Ответ на вопрос владельца: можно ли после главы (или урока) Learning V2 открывать «классический режим» — сборка фразы из плиток слов, 50/50, теория, «Устно» — как в старом курсе, и какой вариант дешевле, безопаснее и влезает в один JS-OTA для 2.0.2.

**Короткий ответ.**
- Старый движок целиком живёт в `app/lesson1.tsx` (4243 строки) и умеет ровно один тип задания: «собери фразу из плиток» (+ режим печати «hardMode» и «Устно» поверх той же фразы). Это именно то, что любят поклонники.
- Движок **нельзя** честно скормить фразами V2 «как есть»: он жёстко привязан к урокам 1–32 старого курса (`getLessonData(lessonId)`), к их ключам прогресса, к разблокировке следующего старого урока, к энергии и к экрану итога.
- Контента V2 для такого режима **на устройстве нет**: занятия V2 приходят с сервера и лежат в локальном кэше всего на 6 занятий (LRU). Значит, любой вариант на «фразах главы V2» требует нового локального хранилища, пишущегося при прохождении занятия. Новых чтений Firestore при этом не нужно.
- Самый дешёвый и безопасный вариант — **Г (новый, см. ниже): после главы V2 открывать уже существующий старый урок с той же темой** (кнопка «Классический курс» на карте уже есть). Ноль нового контента, ноль новых записей, ~1 день. Минус: фразы не те же, что в главе.
- Если владелец хочет именно **фразы главы** — вариант **А** (после главы): ~4–6 дней, укладывается в JS-OTA, но только при условии «режим-песочница без наград и без прогресса старого курса» (иначе двойной зачёт).

## 1. Инвентаризация старого движка

### 1.1 Точка входа и маршруты
- Экран: `app/lesson1.tsx`, маршрут `/lesson1`, параметры `id` (номер урока 1–32), `from`, `serverAttemptId`, combo-параметры.
- Входы: `app/lesson_menu.tsx` (кнопки «Начать»/«Продолжить», `router.push('/lesson1')`), `app/combined_lesson_pick.tsx` (комбо-урок из нескольких тем), `app/lesson_complete.tsx` (повтор: `router.replace('/lesson1')`).
- В 2.0 старый курс **достижим**: вкладка «Обучение» открывает карту V2, а старый список — кнопкой «Классический курс» на карте (`app/(tabs)/lessons.tsx` ~1379, 4205, 5250; логи `[V2-MAP] classic_course:tap`). Если интерфейс не ru/uk или V2 скрыт рубильником — вкладка открывает старый курс сразу.
- Ширина старого курса: 32 урока × 50 фраз (`FULL_LESSON_TOTAL = 50`), данные `app/lesson_data_1_8.ts … 25_32.ts`, собираются `getLessonData(lessonId)` в `app/lesson_data_all.ts`.

### 1.3 Откуда берутся данные (формат)
- `LessonPhrase` (`app/lesson_data_types.ts`): `english`, `alternatives?`, `russian`, `ukrainian`, `spanish?`, `sourceLocales?`, `words: LessonWord[]`, `wordsEn?`.
- `LessonWord`: `text`, `correct`, `distractors: string[]` (**5 заготовленных неверных на каждое слово**), `category`, `teachingNote?`.
- Плитки строит `lesson1_smart_options.ts` (3097 строк: пулы слов по темам, `buildSmartPhraseOptions`) и `lesson1_distractor_logic.ts` (698 строк, структуры фраз урока 1). Проверка ответа — `isCorrectAnswer` + `phraseCanonicalAnswer`/`phraseAnswerAlternatives`, плюс стяжения (don't/do not).
- Фразы фильтруются: нужны `words.length > 0`; число ячеек — `min(фраз, 50)`.
- Озвучка: `useAudio` + `prefetchPhraseAudio` по тексту фразы (клипы старого курса), с фолбэком на речь устройства.

### 1.4 Что движок пишет (прогресс / награды / Firestore)
Локально (AsyncStorage), всё с ключом `lessonId` + `studyTarget`:
- прогресс по ячейкам `lessonProgressKey`, позиция `CELL_KEY`, порядок `ORDER_KEY`, очередь повторов ошибок, `SERVER_ATTEMPT_KEY`; лучшая оценка, счётчик проходов (`target_storage_keys.ts`);
- дневной счётчик 50/50 (`fiftyFiftyUsageKey`), флаги «интро показано», `lastOpenedLessonKey`;
- «Мои ошибки» (`lesson_run_errors_memory`, запись через `getStableId()` — **серверная/облачная**, сопоставление ошибок по `phraseId`);
- статистика ответов `trackAnswer` (локально + позже `syncToCloud`).

По завершении прохода (`runLessonCompletionNavigation`, `lesson1.tsx` ~3440–3570):
- `tryUnlockNextLesson` — **открывает следующий старый урок** (`lesson_lock_system.ts`), для урока 1 — `syncToCloud({forceNow})`;
- аналитика `logLessonComplete`, `trackFeatureSuccess`, `bumpStatsDaily('lessons_completed')`;
- переход на `lesson_complete` с `resultCorrect/Total`, `passed`, `runeCompletionOrdinal`.

На `lesson_complete.tsx`: `markLessonFinishedOnce`, `grantLessonFirstCompleteBonus` (отметка первого прохождения, жемчуга нет — D70), `recordTodayTaskActivity({kind:'lesson'})` (**засчитывает задание дня «Сегодня»**), `checkAchievements` (число завершённых уроков, «идеально»), мягкий апселл, отзыв-оценка, D+1-пуш после урока 1.

Награды по ходу: «руны»/монеты за правильный ответ (`usePracticeRunes` → `CoinRewardFlight`), серия правильных (combo), энергия (`lesson1_energy.ts`: вход в урок списывает 20⚡, внутри не тратится).

Прямых `setDoc/updateDoc` в `lesson1.tsx` нет: в облако уходит только через `cloud_sync` (общая синхронизация), `getStableId()`-записи ошибок и серверные леджеры наград.

## 2. Можно ли скормить фразы главы V2

### 2.1 Что есть в V2
- Структура: 32 урока × 7 глав × 8 занятий = 56 занятий на урок (`course_topology_v1.ts`), в занятии 14–22 взаимодействий.
- Задание-сборка V2 (`phrase_builder`, `modules/learning-v2/modes/phrase_builder_mode_v1.tsx`) получает `modePayload`: `targetPhrase` (английский), `localizedMeaning` (перевод по локали), `orderedTokens` (**разбивка на слова**), `authoredDistractorTokens` (**плоский список лишних слов на фразу**, не по 5 на слово), `explanationV1` (разбор ошибки). То есть английский + перевод + разбивка есть.
- Ошибочные варианты для «50/50»: у V2 нет понятия «слот → 5 неверных»; есть общий список `authoredDistractorTokens`. Для затемнения плиток этого достаточно (движок 50/50 работает на банке плиток, а не на слотах), но «умные» подсказки старого движка (`getDistractorsForWord`) не заработают.
- Теория: у V2 свои вступления занятий (3 страницы с вопросами) и `modules/learning-v2/theory/learning_v2_theory_v1.ts` (130 строк, справочник). Теория старого курса (`THEORY[lessonId]`) соответствует старому уроку, не главе V2.
- Урок 1 — особый случай: V2-источник собран из старых фраз (`legacy_lesson_payload.ts`, `legacy_lesson_adapter.ts` из `LESSON_1_PHRASES`). Для остальных уроков V2 пишет **новый** текст фабрикой (`content/learning-v2-course`).

### 2.2 Где эти данные лежат у ученика
- Занятия V2 **не вшиты в приложение**: приходят callable-вызовом (`learning_v2_course_released_session_client_v3.ts`, `httpsCallable`) и кэшируются в `learning_v2_course_released_session_cache_v4` — **максимум 6 записей**, LRU. Для 8 занятий главы кэша не хватит.
- Уже есть локальный образец нужного приёма: `app/learning_v2_unlocked_lesson_words_v1.ts` — при встрече слова в занятии оно пишется в локальное хранилище по аккаунту и уроку (без сети). По тому же образцу можно хранить **банк фраз**.

### 2.3 Вывод по совместимости
- Фразу V2 можно превратить в `LessonPhrase`: `english`←`targetPhrase`, `russian/ukrainian/…`←`localizedMeaning`, `words[i]={text,correct,distractors}`←`orderedTokens` + общий список лишних слов.
- Но **напрямую в `lesson1.tsx` подать нельзя**: экран берёт фразы строго из `getLessonData(lessonId)`; единственная «чужая» дверь — combo-урок (`combinedLessonPlan`). Нужно либо расширить экран параметром «внешний пул», либо сделать тонкий экран-обёртку.

## 3. Варианты

Общее для всех вариантов: режим должен быть **песочницей** — без записи в прогресс старого курса, без `tryUnlockNextLesson`, без «задания дня», без ачивок за «уроки», без руны→монеты. Иначе двойной зачёт (см. раздел 4).

### А. Открывать после каждой главы (7 глав на урок, ~56 фраз сборки на главу)
- Что переиспользуется: механика сборки плиток и проверка ответа, плитки/анимации, 50/50 (дневной счётчик общий), «Устно» (гейт 3/день), печать. Теория — ссылка на разбор занятия V2 или теория старого урока той же темы.
- Что нужно написать: (1) локальный банк фраз V2 — запись при завершении занятия, по аккаунту+уроку+занятию (образец `learning_v2_unlocked_lesson_words_v1.ts`); (2) адаптер `V2 payload → LessonPhrase`; (3) вход в `lesson1.tsx` с внешним пулом без записи прогресса — либо флаг `sandbox` в экране (4243 строки, высокий риск), либо новый облегчённый экран на тех же компонентах; (4) кнопка на карточке «глава пройдена».
- Что пишется: только локальный банк фраз (при прохождении занятия), собственный ключ «классика главы пройдена N раз» (по желанию). Прогресс/монеты/XP старого курса — **не пишутся**.
- Усилие: 4–6 дней (банк+адаптер 1.5, экран-песочница 2–3, вход+состояния+9 языков 1, тесты 1).
- JS-OTA: да — без нативных модулей, без `package.json`/`app.json`. Условие: банк фраз пополняется только прохождением, начиная со следующего занятия; **уже пройденные занятия в банк не попадут**, пока ученик не откроет их повторно (кэш 6 занятий).
- Firestore: 0 новых чтений (всё из локального банка), 0 новых записей, если не вводить новый облачный счётчик.

### Б. Открывать после всего урока (32 урока, 7 глав)
- То же, что А, но порог выше и пул больше (~390 фраз): нужны выборка/лимит (например, 50 случайных, как в старом курсе — `FULL_LESSON_TOTAL`).
- Дополнительно: банк на 7 глав × 8 занятий — больше места в AsyncStorage (нужен лимит и сжатие; фраза ~200 байт → ~80 КБ на урок, терпимо).
- Усилие: 5–7 дней (то же + выборка и хранение по уроку). Поклонникам «долго ждать»: для первого урока V2 (курс идёт долго) награда далеко.
- JS-OTA: да. Firestore: 0 новых чтений.
- Плюс: законченный объём (как «урок» в старом курсе), понятная метка «пройден урок». Минус: дальше от желания «хочу сейчас, после главы».

### В. Отдельный режим «Собери фразы» из всего пройденного
- Входит в общий раздел (например, «Практика»/«Повторение»): случайные 20 фраз из банка всех пройденных занятий. Не привязан к главе или уроку.
- Переиспользование как у А, но выше ценность и риск: режим становится повторением (вес «Ошибки»/«Карточки»), а значит пересекается с уже существующими «Мои ошибки» и «Карточки слов».
- Усилие: 6–8 дней (то же + выборка по давности, интеграция с повторением, пустые состояния).
- JS-OTA: да. Firestore: 0 новых чтений.

### Г (новый, самый дешёвый). После главы/урока V2 открывать **существующий старый урок** той же темы
- Старый урок N по теме совпадает с уроком N V2 (уроки 1–32 — те же темы). Уже есть кнопка «Классический курс» (`classic_course:tap`).
- Что нужно: подпись «Классика этого урока» на карточке пройденной главы → `router.push('/lesson_menu', {id: N})`. Всё остальное — 100% готовая старая механика: теория, 50/50, «Устно», озвучка, ошибки.
- Что пишется: то, что и в старом курсе пишет (прогресс, разблокировка, задание дня). Для владельца это **плюс** — это и есть «как в старом курсе».
- Усилие: 0.5–1 день (метка + переход + журнал).
- JS-OTA: да. Firestore: 0 новых чтений.
- Минус: фразы не из главы V2, а из старого урока — другой список (кроме урока 1, где источник общий).

### Сводка
| | A: после главы | Б: после урока | В: общий режим | Г: старый урок |
|---|---|---|---|---|
| Фразы главы V2 | да | да | да | нет |
| Новый код | банк + адаптер + экран-песочница | то же + выборка | то же + выборка + интеграция | кнопка |
| Усилие | 4–6 дн | 5–7 дн | 6–8 дн | 0.5–1 дн |
| Пишет в прогресс старого | нет (песочница) | нет | нет | да (штатно) |
| JS-OTA | да | да | да | да |
| Новых чтений Firestore | 0 | 0 | 0 | 0 |
| Риск двойного зачёта | средний, если забыть песочницу | то же | то же | нет — это штатный старый курс |

**Рекомендация.** Для 2.0.2 (один OTA, лимит) — вариант **Г** сразу. Если владелец настаивает на фразах главы — отдельная задача **А** в 2.0.3 с условием «песочница без наград»; Б/В — только после результатов А.

## 4. Риски

1. **Двойной счёт прогресса и монет.** `lesson1.tsx` при завершении сам открывает следующий старый урок, пишет «задание дня», ачивки «N уроков», бонус первого прохождения и выдаёт монеты/руны. Если подать фразы V2 через `lessonId` старого урока, ученик получит награды дважды (за V2 и за «старый» урок) и «откроет» старые уроки, которых не проходил. Лечится только режимом-песочницей (отдельный `lessonId`-пространство `classic_v2_chapter_*`, без `tryUnlockNextLesson`, `recordTodayTaskActivity`, `checkAchievements`, `grantLessonFirstCompleteBonus`, `practiceRunes`).
2. **Путаница с классическим курсом.** В 2.0 уже есть кнопка «Классический курс» и у людей в голове — старый курс 32×50. Новая кнопка «Классика главы» обязана называться иначе (например, «Собрать фразы главы») и показывать, что прогресс старого курса не меняется. Иначе — жалобы «почему не засчитался урок».
3. **Нет контента на устройстве.** Кэш V2 — 6 занятий; уже пройденных 56 занятий не восстановить без новых запросов. Банк фраз пополняется только вперёд; для прошлых занятий нужна одноразовая подкачка (сервер, затраты) — **нельзя в этом OTA**.
4. **Сеть/Firestore.** Цель «0 новых чтений» достижима: банк локальный, запись при прохождении занятия. Нельзя: фоновая подкачка пройденных занятий, облачный счётчик «классика пройдена» (новые записи, правила Firestore, Джарвис — по правилу «тронул данные — обнови Джарвиса»). Если счётчик всё же нужен — только локально.
5. **Размер и производительность.** `lesson1.tsx` (4243 строки) тяжёлый; добавление режима «песочницы» флагом увеличит риск регрессий в основном потоке уроков. Безопаснее — отдельный экран на общих компонентах плиток. Банк фраз — отдельный ключ AsyncStorage с лимитом (≤ 200 КБ).
6. **Озвучка.** Классика играет клипы по тексту фразы (`prefetchPhraseAudio`), у V2 фраз озвучка другая (аудио занятий с сервера). Для режима песочницы — использовать аудио V2 из банка или речь устройства; иначе у фраз главы будет тишина.
7. **Языки.** Старый движок поддерживает 9 интерфейсных языков; V2 `localizedMeaning` приходит только для языков, на которых есть пояснения курса (ru/uk). При других языках режим А/Б/В недоступен — нужен фолбэк (скрыть вход).
8. **Макеты и гейты.** Любой новый экран/кнопка попадает под ворота «приложение = макет» (`docs/design/v2-app/*.html`): сначала макет и одобрение владельца, потом код. Для Г — только подпись на карточке главы.
9. **Приватность.** Новых данных об ученике не собираем (банк фраз — контент, который он и так видел). Политика не меняется. Если появится облачный счётчик — пересмотреть.
10. **Каскад на OTA.** Любая правка `lesson1.tsx` / `lessons.tsx` на горячем пути требует тестов по `lesson1_*` и ворот Сверки — риск не уложиться в окно OTA.

## Scope

In scope: чтение кода (`app/lesson1.tsx`, `lesson_complete.tsx`, `lesson_data_*`, `lesson1_smart_options.ts`, V2 `modules/learning-v2/**`), этот отчёт.
