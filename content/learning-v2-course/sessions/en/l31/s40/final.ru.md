# Урок 31 · Занятие 40 — Возвращаем книгу

**Ситуация.** Вы обсуждаете прочитанную книгу и собираетесь в библиотеку.

**Что вы освоите:** рассказывать о чтении, уточнять время и называть того, кто вернул книгу.
**Новые слова:** —
**Повторяем знакомые слова:** book, library, bag, card

## Интро 1

### Прочитал, хотя книга длинная

В книге оказалось много страниц, но вы дочитали её. Скажите: I read the book although it was long — я прочитал книгу, хотя она была длинной. Соберите I read the book + although + it was long. Although вводит обстоятельство, которое не помешало чтению; read здесь относится к прошлому.

**Выберите фразу для этой ситуации.**

- ✅ **I read the book although it was long.**
- ❌ I read the book although of it was long. — *После although не добавляем of.*
- ❌ I read the book although it were long. — *С it нужна форма was.*

## Интро 2

### Я знаю время закрытия библиотеки

Друг торопится вернуть книгу, а вы уже посмотрели часы работы: I know when the library closes — я знаю, когда закрывается библиотека. Соберите I know + when + the library + closes. После when сохраняем порядок the library closes; вопросительное does не добавляем.

**Выберите фразу для этой ситуации.**

- ✅ **I know when the library closes.**
- ❌ I know when does the library close. — *Внутри сообщения не ставим вопрос с does.*
- ❌ I know when the library close. — *С одной library нужна форма closes.*

---

## Интро 3

### Кто вернул книгу

Анна уже отнесла книгу в библиотеку. Расскажите об этом, начав с книги: The book was returned by Anna — книгу вернула Анна. Соберите The book + was + returned + by Anna. Was returned показывает, что сделали с книгой; by Anna называет исполнителя.

**Выберите фразу для этой ситуации.**

- ✅ **The book was returned by Anna.**
- ❌ The book were returned by Anna. — *Одна book требует was.*
- ❌ The book was return by Anna. — *Здесь нужна форма returned.*
