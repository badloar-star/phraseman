## Outcome
Новый интерактивный файл `docs/design/v2-app/theme-picker-live.html`: ключевые экраны ТЕКУЩЕГО приложения (Главная, Уроки, Урок, Урок пройден, Карточки, Диалоги, Шпиль, Ошибки, Монеты/Профиль, Настройки, Пейвол Plus) перекрашиваются кнопками тем, ползунком насыщенности 0…1 и переключателем «тёмная/светлая». Цвета — НАСТОЯЩИЕ токены приложения: в страницу встроена собранная esbuild копия `constants/liquidGlassThemePalette.ts` (та же формула, что в приложении), поэтому выбранное владельцем совпадает с приложением до оттенка. Внизу строка «Выбрано: <тема> · <насыщенность> · <тёмная/светлая>».

## Scope
Один новый HTML-файл (и временный скрипт сборки вне репозитория). Код приложения, токены и реестры не меняются. Первая версия — Главная, Уроки, Итог урока; остальные экраны догружаются следом.

## Architecture
`esbuild --bundle --format=iife` собирает модуль токенов (`liquidGlassTokens(id, {appearance, intensity})`, `LIQUID_GLASS_THEME_IDS`) в строку, вставляемую в страницу; экраны — статичная HTML-вёрстка по кадрам и коду экранов, цвета берутся из объекта токенов в CSS-переменных (`--bg`, `--text`, `--accent`, плашки `plateFillFrom/To`, `opaqueSheet` и т.д.). Стиль «Тень»: контейнеры без обводок, тени и блик вместо кромок.

## Security and privacy
Статичный локальный файл без сети и данных пользователей.

## Technical debt
Экраны — вёрстка по кадрам и коду, а не запуск приложения; мелкие расхождения с живым видом возможны, поэтому первые версии сверяются кадрами `evidence/parity`. Иллюстрации (3D-значки) в первой версии заменяются простыми заглушками тона темы, если файл тяжёлый.
