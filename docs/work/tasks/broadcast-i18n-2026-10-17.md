# Глобальная рассылка на английском — что нужно (для владельца, утро 18.10)

Составил переводчик 17.10 по поручению координатора. Это описание; ничего из этого не сделано — нужна команда владельца.

## Что сейчас

- Приложение (коммит 31fa965f7) уже умеет показывать английскую рассылку: читает `titleEn`, `messageEn`, `reviewCtaEn`.
- Сервер эти поля пока не пишет. Поэтому человек с английским интерфейсом видит нейтральную английскую рамку:
  - «A message from the team»;
  - «Thanks for being with us.»;
  - кнопка «Rate the app».
- Сам текст рассылки и награда английскому интерфейсу не видны. Русский текст он больше не видит.

## Что нужно, чтобы шёл настоящий английский текст

| Где | Файл | Что поменять |
|---|---|---|
| сервер, запись рассылки | `functions/src/admin_global_broadcast.ts` | `LANGUAGE_KEYS` + `'en'`, `LANGUAGE_SUFFIXES.en = 'En'`. Тогда `titleEn` / `messageEn` пишутся в документ `global_broadcast_modals/{id}` так же, как остальные 8 языков |
| сервер, разрешённые поля | `functions/src/global_broadcast_public_schema.ts` | `PUBLIC_GLOBAL_BROADCAST_FIELDS` + `titleEn`, `messageEn`, `reviewCtaEn`. Иначе чтение рассылки отбросит их как лишние |
| сервер, отпечатки | `GLOBAL_BROADCAST_SOURCE_ARTIFACT_HASHES` в `admin_global_broadcast.ts` | пересчитать `globalBroadcastPublicSourceSha256` после правки схемы — его сверяет проверка приватности рассылки |
| админка | `admin/v2/legacy.html` (форма «Глобальная рассылка», поля `gb-title-*` / `gb-message-*`) | поле «Заголовок EN» и «Текст EN»; авто-перевод (`admin_translate.ts`) уже умеет En без подстановки русского |
| кнопка отзыва | там же | поле `reviewCtaEn` (сейчас по умолчанию «Rate the app») |

## Порядок выкладки

1. Сервер (функции) — новые поля опциональны, старые рассылки не ломаются.
2. Админка.
3. Приложение уже готово, новой сборки не нужно.

## Деньги и нагрузка

Новых чтений нет: те же документы, только на 3 поля больше.
