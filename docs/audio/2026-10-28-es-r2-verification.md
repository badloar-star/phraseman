Проверена актуальная логика приложения на реальных опубликованных файлах, с моделируемыми транспортом и файловой системой:

- Все 3 323 ссылки на записи из 127 испанских занятий разрешаются после перезапуска runtime без сети.
- При продвижении 0 → 1 → 8 → 16 → 56 → 112 завершённых занятий суммарно требуются 7 пакетов, 3 каталога и 1 указатель версии: 11 объектов. Это один первоначальный проход, не месячный прогноз.

## Что пока не готово к общему выпуску

- Испанский Learning V2 скрыт отдельной таблицей готовности языка: learning_v2 = hidden('D129'). Глобальный флаг Learning V2 не выключен; интерфейс разрешён для русского и украинского языка объяснений. Правила доступности не менялись. Аудиотранспорт проверен, но обычный пользовательский путь испанского курса этим не подтверждён.
- Английская озвучка ещё не сгенерирована и не загружена. Тесты испанского набора не подтверждают наличие английских записей.
- Большие пакеты предзагружаются по Wi-Fi. На мобильной сети автоматически допускается только необходимый пакет до 1 МиБ; без сохранённой записи остаётся штатная резервная озвучка.
- Физический телефон, iOS, субъективное качество голоса и полный пользовательский путь всех упражнений не проверены.
