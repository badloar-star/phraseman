# Task packet: Диалоги пишут «всё открытое пройдено» при 0 пройденных — журнал [DIALOG-UNLOCK] и честный текст

## Outcome

Обход экранов 12.11: хаб «Диалоги» показывает «Пока всё открытое пройдено / Следующие диалоги откроются с новым
рангом» при «0 из 19» в каждой теме и «0 из 76». Текст утверждает, что человек всё прошёл, хотя он не прошёл ничего.

## Scope

Разбор по коду:
- текст выбирается в `buildDialogsSceneCopy`, когда у сцены нет следующего открытого диалога (`dialog === null`),
  без учёта того, сколько пройдено;
- диалог открыт, если ранг монеты ≥ ранга открытия (таблица `DIALOGUE_V2_UNLOCK_RANK_TABLE`, у новых +1) или есть Plus;
  неизвестный ранг (`null`) закрывает все диалоги;
- значит «0 открыто, 0 пройдено» бывает: (а) новый пользователь с рангом 0 (решение координатора 30.10: «ранг 0 у
  новых — диалогов нет»); (б) ранг ещё не известен для этого аккаунта. Какой случай у аккаунта обхода — покажет журнал.

In scope:
- `components/dialogs/scene/use_dialogs_scene_hub.ts` — журнал `[DIALOG-UNLOCK]`: ранг, Plus, сдвиг для новых,
  сколько открыто/пройдено/закрыто, ближайший ранг открытия и причина пустой сцены;
- `components/dialogs/scene/dialogs_scene_copy.ts` — при 0 пройденных текст «Диалоги откроются с новым рангом»
  вместо «всё открытое пройдено»;
- тест `tests/dialogs_scene_none_open_copy.test.ts`.

Out of scope: `DialogsScene*.tsx` (правятся в другой сессии), `hooks/use_today_tasks.ts` (правится в другой сессии;
задание дня уже снимает «Заверши диалог», когда ранг известен и раздел закрыт).
