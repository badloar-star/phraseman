# Урок 27 · Занятие 04 — Комната для гостей

**Ситуация.** Вы выбираете кровать, обсуждаете визит близких и заканчиваете подготовку комнаты.

**Что вы освоите:** сказать, что было бы, если бы…, и не путать «уже сделано» с «было тогда»
**Новые слова:** wisely, eagerly, deeply, practically

## Интро 1

### Если бы хватало денег

Вы выбираете кровать для гостей, но денег на понравившуюся модель не хватает. Объясните: I would buy a better bed if I had enough money — я бы купил кровать получше, если бы у меня было достаточно денег. Собираем: I + would buy + a better bed + if I had enough money — кто, что сделал бы, что купил бы, при каком условии. После would нужна buy, не bought. В условии используем had без would: нужной суммы сейчас нет.

**Выберите фразу для этой ситуации.**

- ✅ **I would buy a better bed if I had enough money.**
- ❌ I would bought a better bed if I had enough money. — *После would нужна форма buy.*
- ❌ I would buy a better bed if I would had enough money. — *В условии had без would.*

---

## Интро 2

### Если бы работали рядом

Вы редко видитесь с близкими, потому что работаете далеко от них. Объясните: I would see them more often if I worked nearby — я бы чаще с ними виделся, если бы работал рядом. Собираем: I + would see + them + more often + if I worked nearby — кто, что делал бы, с кем, как часто, при каком условии. Them заменяет близких. После would нужна see; worked после if представляет другое положение сейчас.

**Выберите фразу для этой ситуации.**

- ✅ **I would see them more often if I worked nearby.**
- ❌ I would seeing them more often if I worked nearby. — *После would нужно see.*
- ❌ I would see them more often if I would worked nearby. — *В условии worked без would.*

---

## Интро 3

### Когда собрали кровать

Гость замечает новую кровать и спрашивает, когда вы её собрали. Ответьте: We built it yesterday — мы собрали её вчера. Собираем: We + built + it + yesterday — кто, действие в прошлом, что собрали, когда. Built — прошедшая форма build, не builded. It заменяет кровать. Yesterday указывает законченное время, поэтому здесь built без have.

**Выберите фразу для этой ситуации.**

- ✅ **We built it yesterday.**
- ❌ We have built it yesterday. — *При законченном yesterday здесь past simple.*
- ❌ We builded it yesterday. — *Прошедшая форма build — built.*
