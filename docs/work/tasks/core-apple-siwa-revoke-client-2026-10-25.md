Governance-ID: TG-170828AF6944

## Outcome
Координатор 25.10: подготовить отзыв Sign in with Apple (требование Apple 5.1.1(v)) — клиент и сервер, за флагом, по умолчанию
ВЫКЛ, без выкладки; ключ Apple владелец добавит позже в консоли Firebase. План: docs/work/tasks/core-apple-siwa-revoke-plan-2026-10-25.md.

## Scope
- app/apple_signin_revoke.ts (новый): `revokeAppleSignInForDeletion(reason)` — флаг `apple_signin_revoke_enabled` → только iOS →
  только если у текущего пользователя есть провайдер apple.com → окно Apple (`signInAsync` без scopes) → свежий
  authorizationCode → `auth().revokeToken(code)` (RN Firebase 21.14, нативно) с потолком времени. Никогда не бросает и не
  блокирует удаление; результат — в журнал [APPLE-REVOKE].
- app/auth_provider.ts → `deleteAccountAndWipe`: один вызов перед `beginAccountDeletion` (общий путь и для удаления с grace, и для
  «Удалить навсегда сейчас», если «5 · ВХОД» поведёт кнопку через ту же функцию; иначе — ей вызвать этот же модуль).
- app/remote_flags.ts — ключ флага (только свои хунки, патчем от HEAD).
- тест модуля.
Сервер: НЕ делаю. Отзыв на сервере в конце grace требует refresh token Apple (сейчас нигде не хранится — нужно было бы менять
код авторизации на токен при каждом входе и хранить его) и собственного ключа .p8 в секретах (его нет). Firebase `revokeToken`
делает ровно этот вызов Apple с ключом из консоли — дублировать на сервере значит заводить новые чувствительные данные без пользы.

## Architecture
Отзыв — до постановки удаления: человек в этот момент на экране и подтверждает удаление; окно Apple — то же «подтверди личность».
Вариант Б удаления (пользователь Auth живёт до конца grace) не ломается: после отзыва повторный вход Apple даёт того же sub →
того же пользователя Firebase → «Восстановить аккаунт?».

## Security and privacy
Код авторизации живёт в памяти секунды, уходит только в Firebase; не логируется и не сохраняется. В журнал — стадия, код
ошибки, миллисекунды. Политика: добавить фразу об отзыве доступа Sign in with Apple при удалении (до включения флага).
