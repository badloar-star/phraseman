# Ассет спина

Сюда кладётся **один** файл: `spin_ticket.webp` — значок самого спина (права
крутнуть рулетку), общий для всех поверхностей приложения.

Требования к файлу: 512×512, RGBA WebP, качество 70–78, прозрачный фон,
непрозрачные пиксели не касаются краёв.

Промпт для генерации и полный чек-лист приёмки:
`docs/SPIN_TICKET_ASSET_DALLE_PROMPT.md`.

Пока файла нет, интерфейс сам показывает прежний запасной значок подарка —
ничего не ломается, ошибок сборки не возникает.
