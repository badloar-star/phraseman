## Вывод
Не-dev лучше, но ненамного: janky 9,4 % → 6,0 %, 99-й перцентиль 350 → 200 мс; медиана и 90-й почти те же (28–29 / 38–40 мс — это базовая скорость эмулятора без GPU). То есть долгие кадры при возврате (200–350 мс на 99-м) остаются и в сборке без dev — рывок НЕ только артефакт dev-режима. Окно измерения включает весь отрезок ≈ 20–25 с (с простоями между тапами), поэтому доля janky размыта; сами рывки возврата видны в 99-м перцентиле. Разница dev/не-dev по 99-му: −43 %.
Оговорки: эмулятор без GPU-ускорения; в не-dev бандл собран сборщиком в режиме dev=false, но без minify (JS Minify был выключен) — на релизной сборке (minify + байткод Hermes) будет чуть лучше.
