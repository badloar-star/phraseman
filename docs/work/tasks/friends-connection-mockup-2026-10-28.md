## Outcome

Один живой HTML-макет `docs/design/v2-app/friends-connection.html` (+ `.css`, `.app.js`, `.make.cjs` рядом) на движке «Сцены»
(peak-scene-v2, 23 темы × светлое/тёмное), где владелец видит, как связь с друзьями проходит через все разделы: 1) блоки
«друг сделал» на сценах Уроков, Пика, Видео, Карточек (как на Главной); 2) приглашение друга — очевидно, с наградой; 3) команда
(клан): создать, вступить, общая цель недели, рейтинг команд — минимум экранов; 4) «Друзья смотрят» в Видео; 5) «Избранное»
для видео. Каждый блок строится поверх существующего (друзья, профиль-карточки, зовы, лента, видео, реферальная награда) и
снабжён для координатора подписью стоимости Firebase: что читаем и как кэшируем (кэш при входе, без опроса). Мера успеха:
владелец выбирает блоки и экраны; headless — 0 JS-ошибок, 0 404, значки целы; тексты по VOICE.md, без мелких подписей.

## Architecture

Текущая граница: друзья — `friends/{uid}` + заявки, события друзей (`friend_social_events`), лайки активности, недельная карта
друга (FriendWeek*), зовы (FriendCallPill / FriendLessonInviteSheet / дуэли), реферальный код и награда, сторис-кольца; видео —
YouTube-карточки, избранное локально (`use_video_favorites`). Предлагаемая граница в макете: один блок «друг сделал» (`FriendEventMarker`
как источник) переиспользуется на 4 сценах; команда — новый контракт `teams/{teamId}` (имя, участники ≤ 10, цель недели, очки) с
чтением одного документа при входе и рейтингом команд из одного агрегата недели (функция раз в N часов), без подписок; «Друзья
смотрят» — агрегат `friend_video_watch/{uid}` (последние 3 видео, минуты) обновляется батчем с телефона раз в день; избранное —
локальный список + одна запись в профиль при входе. Инварианты: ни одного нового чтения на первом кадре, всё с кэша/снимка при
входе; ответы сети догоняют фоном; prefers-reduced-motion. Решение: только макет, код — отдельной задачей.

## Security and privacy

Макет статический, данных нет. Для будущего кода: «друзья смотрят» и «друг сделал» раскрывают активность пользователя друзьям —
нужна видимость только для подтверждённых друзей и выключатель в настройках приватности; команды — имена участников видны
команде; детские данные не затрагиваются; при переносе в код — проверить privacy policy (раздел «друзья/активность») до релиза.
