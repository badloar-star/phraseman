# Англійська · Урок 22 · Заняття 28 — Обрати готові продукти

**Ситуація.** Ви порівнюєте продукти в магазині.

**Що ви опануєте:** determiner|adjective + one|ones
**Нові слова:** ready-to-eat, freshly baked, pre-cooked, pre-sliced

## Інтро 1

### Салат можна їсти

Ready-to-eat — готовий до споживання: продукт не потрібно готувати перед їжею. У прикладі обираємо один готовий салат: one замінює salad. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I want the ready-to-eat one.**
- ❌ I want the ready-to-eat ones. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I want the ready-to-eat it. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*

## Інтро 2

### Свіжа випічка й готові сосиски

Freshly baked — щойно або нещодавно спечений. Pre-cooked — попередньо приготований: приготування вже відбулося до купівлі. Це не обов’язково означає ready-to-eat: спосіб подавання залежить від продукту й указівок на пакованні. Зараз ви обираєте кілька щойно спечених булочок: buns → ones. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones. Тут one означає не лічбу «один», а замінює назву речі.

**Виберіть фразу для цієї ситуації.**

- ✅ **I like the freshly baked ones.**
- ❌ I like the freshly baked one. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*
- ❌ I like the freshly baked them. — *У цій ситуації назву речі замінюємо one для однини або ones для множини.*

## Інтро 3

### Нарізана хлібина

Pre-sliced — заздалегідь нарізаний скибками. Обираємо одну хлібину: the pre-sliced one замінює the pre-sliced loaf. One стосується loaf, а не незлічуваного bread. One замінює вже названий злічуваний іменник в однині, ones — у множині: the red shirt → the red one; the red shirts → the red ones. Зберігаємо опис речі перед one / ones.
