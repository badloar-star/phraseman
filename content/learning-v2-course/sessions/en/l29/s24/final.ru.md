# Урок 29 · Занятие 24 — Помочь выбрать одежду

**Ситуация.** Вы с подругой рассматриваете одежду в магазине и примеряете подходящие вещи.

**Что вы освоите:** как назвать одежду, уточнить понравившуюся вещь и объяснить условие покупки.
**Новые слова:** headscarf, turtleneck, pinafore, playsuit

## Интро 1

### Где примерить одежду

Вы показываете подруге место для примерки в магазине. Скажите: This is the room where you can try it on — это комната, где можно это примерить. Соберите This is the room + where + you can try it on. Where связывает примерку с комнатой. После него поставьте обычный порядок you can try it on, без вопросительной перестановки can и you.

**Выберите фразу для этой ситуации.**

- ✅ **This is the room where you can try it on.**
- ❌ This is the room where can you try it on. — *В уточнении нужен порядок you can try.*
- ❌ This is the room who you can try it on. — *Для места здесь нужно where.*

---

## Интро 2

### Вещь с карманами

Подруга спрашивает, какое платье вам нравится, и вы выбираете платье с карманами. Скажите: I like the dress that has pockets — мне нравится платье, у которого есть карманы. Соберите I like the dress + that + has pockets. That обозначает платье внутри уточнения. После that сразу ставим has pockets, без it.

**Выберите фразу для этой ситуации.**

- ✅ **I like the dress that has pockets.**
- ❌ I like the dress that it has pockets. — *That уже обозначает платье, it лишнее.*
- ❌ I like the dress who has pockets. — *Для платья здесь используем that.*

---

## Интро 3

### Если размер подойдёт

Перед примеркой вы решаете купить вещь, только если она подойдёт по размеру. Скажите: I will buy it if it fits — я куплю это, если подойдёт по размеру. Соберите I will buy it + if it fits. Сначала поставьте решение с will buy. В условии после if используйте fits без will. Условие стоит в конце, поэтому запятая не нужна.

**Выберите фразу для этой ситуации.**

- ✅ **I will buy it if it fits.**
- ❌ I will buy it if it will fit. — *После if здесь нужно fits без will.*
- ❌ I will buy it if it fit. — *С it в этом условии используем fits.*
