## Outcome

Владелец получает на СВОЕЙ машине (`C:\ComfyUI`, RTX 5070 Ti Laptop 12 ГБ VRAM,
31 ГБ RAM) два рабочих конвейера для производства роликов:

1. **Картинки.** Персонажи в стиле 3D-Pixar/Disney **с чистым альфа-каналом**
   (RGBA PNG), пригодные для вставки в видеомонтаж без ручного вырезания.
   Два пути на сравнение владельцем: Flux + Pixar-LoRA + вырезание (RMBG)
   и Qwen-Image-Layered с НАТИВНОЙ послойной альфой.
2. **Озвучка.** Локальная замена ElevenLabs: список из 300–500 фраз на входе →
   пронумерованные аудиофайлы в одной папке на выходе, ОДНИМ И ТЕМ ЖЕ
   сохранённым голосом, на шести языках (RU/EN/DE/ES/FR/IT).

Мера успеха: владелец скармливает `phrases.txt` и получает `001.wav … 500.wav`
без ручной работы; голос между запусками не меняется; картинка открывается в
монтажке с прозрачным фоном.

Вне приложения Phraseman: это производственный инструментарий для контента, а
не код продукта. Репозиторий `C:\appsprojects\phraseman` НЕ затрагивается,
кроме этого пакета и скрипта озвучки в `tools/`.

## Architecture

Текущая граница: ComfyUI v0.33.1 (13.08.2026) с 7 кастомными нодами; моделей
Qwen нет; TTS-нод нет.

Целевая граница: ComfyUI v0.37.0 + две кастомные ноды (ComfyUI-RMBG,
TTS-Audio-Suite). Конвейеры независимы друг от друга и от приложения.

Поток данных (картинки, путь А — Flux):
промпт → Flux.1-dev + Canopus-Pixar-3D-LoRA → RGB-картинка → RMBG (BEN2 /
BiRefNet / Lucida) → RGBA PNG.

Поток данных (картинки, путь Б — Qwen-Layered):
промпт → `EmptyQwenImageLayeredLatentImage(layers=N)` → KSampler →
`LatentCut` / `LatentCutToBatch` → VAEDecode → RGBA-слои.
Латент имеет форму `[batch, 16, layers+1, h/8, w/8]` — прозрачность рождается
в генерации, а не вырезается постфактум.

Поток данных (озвучка):
`phrases.txt` → батч-скрипт → ComfyUI HTTP API (`/prompt`, `/history`) →
TTS-движок с зафиксированным голосом (`voices/Имя.wav` + `Имя.reference.txt`) →
`out/001.wav … NNN.wav`.

Инвариант озвучки: **голос задаётся парой файлов на диске**, а не случайным
seed. Один и тот же образец → один и тот же голос в любом запуске. Это прямое
требование владельца («голоса постоянные»).

Архитектурное решение: батч реализуется ПОВЕРХ ComfyUI через его HTTP API, а не
как форк движка. Причина: движок владелец выбирает на слух после теста, и
скрипт не должен переписываться при смене движка — меняется только имя ноды в
шаблоне задания.

## Security and privacy

- **Персональные данные.** Образец голоса — биометрия. Хранится ТОЛЬКО локально
  в `C:\ComfyUI\ComfyUI\models\voices\`, никуда не отправляется. Клонировать
  разрешено лишь собственный голос владельца или голос с явного согласия
  носителя; чужие голоса из интернета не использовать.
- **Приватность приложения.** Конвейеры не читают и не пишут данные
  пользователей Phraseman, не касаются Firestore. Privacy Policy приложения
  обновления НЕ требует: сбор данных пользователей не меняется, это
  производственный инструмент владельца на его машине.
- **Лицензии (риск для коммерческого использования).** Ролики продвигают платный
  продукт, поэтому лицензия движка озвучки существенна:
  - ChatterBox 23L — MIT, ограничений нет.
  - OmniVoice — Apache-2.0, ограничений нет.
  - **Higgs Audio v3 — Research and Non-Commercial: для продвигающих продукт
    роликов НЕ применять.**
  - Fish Audio S2 — собственная Research License, проверять перед коммерцией.
  - Flux.1-dev — некоммерческая лицензия FLUX; Qwen-Image — Apache-2.0.
- **Секреты.** Не требуются. Civitai требует авторизацию для скачивания — ключ
  владельца НЕ запрашивался и НЕ сохранялся; вместо Civitai взят эквивалент с
  HuggingFace (публичный доступ).
- **Сеть.** Скрипт ходит только на `127.0.0.1` (локальный ComfyUI). Наружу — лишь
  разовые скачивания моделей.

## Technical debt

- **Contain — хук `block-git-worktree.js` режет `git clone` на всей машине.**
  Из-за него сорвалась установка трёх pip-пакетов из GitHub и клонирование
  кастомных нод; обошёл скачиванием zip. Граница: ноды ставятся zip-методом,
  задокументировано здесь. Условие выхода: хук научить отличать `git clone` от
  `git worktree add` ЛИБО ограничить его каталогом Phraseman. Владелец решает
  отдельно — трогать защитный хук внутри чужой задачи запрещено правилами.
- **Accept temporarily — `protobuf` откатился 7.35.1 → 5.29.6** при установке
  ComfyUI-RMBG. Владелец: эта сессия. Ревизия: при первой ошибке импорта
  protobuf. Потолок влияния: ComfyUI стартует без ошибок (проверено), затронут
  только `C:\ComfyUI`, приложение Phraseman не задето.
- **Accept temporarily — VibeVoice и Dots TTS не установлены** (git clone
  заблокирован). Влияния нет: VibeVoice русского не поддерживает и отозван
  Microsoft, Dots TTS — запасной вариант. Ревизия: если ни один из четырёх
  кандидатов не устроит по звуку.
- **Accept temporarily — WeTextProcessing не собран** (требует ручной сборки
  wheel на Windows). Влияет только на нормализацию КИТАЙСКОГО текста в
  IndexTTS-2, который по языкам всё равно не подходит. Ревизия: не требуется.
- **Pay now — проверка целостности скачанного.** Каждый файл модели проверяется
  на валидность заголовка safetensors/размер сразу после скачивания. Причина:
  в этой же сессии HuggingFace дважды отдал 404-заглушку (15 байт) и Civitai —
  ошибку авторизации (106 байт) ВМЕСТО модели; без проверки владелец искал бы
  причину уже внутри ComfyUI.
