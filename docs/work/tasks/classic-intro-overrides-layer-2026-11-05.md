# Task packet: слой оверрайдов интро в пакете классических курсов

Governance-ID: TG-8A3674E816C9
Status: In progress
Owner: сессия «Темы» (интро классики)
Related epic/enabler: TG-D01D9A1F84C3 (переписывание интро классики)

## Outcome

Пересборка пакета `scripts/classic_course_pack.mjs` перестаёт откатывать вручную переписанные интро. Пользователь выигрывает: переписанные интро классики (без «Представь ситуацию») переживают любую пересборку из архивов. Мерка: после правки оверрайдов `node scripts/classic_course_pack.mjs` собирает `modules/classic-courses/en/intro.json` с нашими текстами, а сторож Ревизора `tests/classic_intro_no_template_start.test.ts` краснеет только на ещё не переписанных местах.

## Scope

In scope: загрузка двух файлов оверрайдов в `introText`/сборке интро пакета: `docs/work/classic_intro_overrides.json` (ru и прочие языки, пишет сессия «Темы») и `docs/work/classic_intro_overrides_uk.json` (uk-поля, пишет Переводчик). Ключ — `screenId` вида `<lang>:<LL>:intro:<N>`, значение — объект с полями `titleXX` / `textXX` / `linesXX`. Приоритет над архивом.
Out of scope: генератор дистракторов (правит Теория — тот же скрипт, отдельный коммит); сами интро-тексты (следующий шаг); слой правок Переводчика `classic_translation_fixes_*.json`; сторож Ревизора.

## Architecture

Граница: архив Classic → `classic_course_pack.mjs` → `modules/classic-courses/<lang>/intro.json`. Новый слой между архивом и сборкой: оверрайды, ключ — screenId. Инварианты: id экранов и порядок не меняются; число карточек на урок (3) не меняется; отсутствующий файл оверрайдов — не ошибка (пустой слой); неиспользованный ключ оверрайда — предупреждение в логе (опечатка видна).

## Security and privacy

Не применимо: локальные JSON-файлы репозитория и сборка, персональных данных и сети нет.

## Technical debt

- Pay now: слой оверрайдов интро — здесь.
- Contain: uk-оверрайды пишет Переводчик в отдельный файл — два писателя не в одном JSON.
- Accept temporarily: генератор дистракторов в том же скрипте правит Теория; конфликт снимаем ребейзом, мой коммит — отдельный и маленький.

## Verification

- Прогон сборки на одном языке (`node scripts/classic_course_pack.mjs en --check` или эквивалент пакета) без ошибок.
- Тест-страж Ревизора на собранном intro.json — итог по строке `Tests:`.
- Ручная проверка: один оверрайд на тестовом screenId меняет итог и только его.

## Rollback

Удалить блок загрузки оверрайдов из скрипта и файлы слоя — пакет вернётся к архиву; данные пользователей не затрагиваются (интро — статичный контент).
