# Контекстные пейволлы — тексты для согласования (ru, «ты»)

Для владельца: **нужно ваше «да» до коммита кода.** Макет: `paywall-context-redesign.html` (три варианта окна, 10 состояний).

Правила текста: на «ты»; заголовок до 5–6 слов; подзаголовок — одна короткая фраза; первая выгода — как в приложении сейчас. Числа (50 фраз, 30 тренировок и ответов, 3 попытки, 1 подход, 29 уроков) взяты из текущих текстов и констант кода, ничего не выдумано. Столбец «Сейчас» — заголовок, который человек видит в приложении сегодня.

## Что видно из таблицы

- Пять входов (закрытый урок, B1, повышение уровня, итог бесплатных уроков, пуш) сегодня показывают ОДИНАКОВЫЙ заголовок «Продолжим курс?» — контекста не видно. В предложении у каждого свой.
- Вход «Серия / заморозка» сегодня обещает «занятия без ожидания энергии» — не про серию. В предложении — про защиту серии.
- Входа «Видео» (просмотр роликов, фразы по таймкодам) в списке контекстов НЕТ: видео сейчас без пейволла. Если он нужен — это новый контекст, решение владельца.
- «Умная очередь» удалена — текстов нет.
