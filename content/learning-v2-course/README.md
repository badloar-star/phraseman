# Learning V2 — Фабрика курса

> Решение владельца 2026-09-03: производство курса живёт ЗДЕСЬ, вне бандла
> приложения. Приложение не импортирует ничего из этой папки. В приложение
> попадает только собранный релиз (`release/<lang>/<version>/*.json`) и только
> по явной команде владельца «выпустить».

## Почему эта папка, а не `modules/learning-v2/content`

Корневая `content/` уже вне сборки приложения (здесь живут MASON, LINGMAN,
VIRAL). Metro, tsc и jest её не видят. Черновик сессии физически не может
уронить приложение, потому что приложение о нём не знает.

Что было раньше и почему не работало — `ДИАГНОЗ_2026-09-03.md`.

## Устройство

```
content/learning-v2-course/
├── README.md                 ← этот файл
├── ДИАГНОЗ_2026-09-03.md      ← почему старая система не написала ни одного курса
├── КОНСТИТУЦИЯ.md            ← ЕДИНСТВЕННЫЙ документ правил (≤ 5 страниц)
├── ЧИСТКА_ПЛАН.md            ← что и как убрать из старой системы
├── exemplars/                ← золотые сессии, одобренные владельцем
│   └── en/l01_s01.ru.md
├── curriculum/               ← план курса на язык: 32 урока × 7 глав × 8 сессий
├── sessions/<lang>/<lesson>/ ← черновики и готовые сессии (YAML, ru-first)
├── judgements/               ← вердикты судей и владельца (калибровка вкуса)
├── pipeline/                 ← скрипт-конвейер (план → черновики → судьи → правка → локали → сборка)
└── release/                  ← собранные JSON, единственное, что читает приложение
```

## Принцип одной фразой

**Образцы вместо запретов.** Правил — пять страниц. Всё остальное качество
задают золотые сессии и вердикты владельца, на которых калибруются судьи.

## Как сессия становится готовой

1. `plan` — операция грамматики, новые слова, **сцена** (зачем это говорить).
2. `draft ×3` — три черновика на русском разными «авторами».
3. `judge` — три судьи: ученик-новичок (что понял, где споткнулся),
   редактор вкуса (парное сравнение с эталонами), педагог-контролёр
   (только пройденное, одна операция).
4. `revise` — правка по критике, повтор до схождения (обычно 1–2 круга).
5. `localize` — 7 локалей редакторами-носителями, судья на каждую локаль.
6. `build` — JSON для рантайма + `learner_view.md` (как видит ученик).
7. `release` — только по команде владельца.

Конвейер умеет два бэкенда: `claude` (headless `claude -p`, подписка, запуск
прямо из Claude Code) и `api` (Anthropic API, параллельно и без присмотра).
Одни и те же промпты, переключатель — флаг.
