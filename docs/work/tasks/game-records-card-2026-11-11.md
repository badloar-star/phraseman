## Outcome

В приложении есть готовые к подключению части блока «Рекорды игр» из утверждённого макета статистики: хранилище лучшего
результата по каждой игре на устройстве и карточка с четырьмя ячейками. Блок никуда не вставлен и рекорды никем не
пишутся — подключает координатор после проверки (сегодня выпуск, экраны не трогаем).

Мера успеха: тест хранилища зелёный, типы и стиль чистые, новые файлы ничем не импортируются.

## Scope

In scope (ТОЛЬКО новые файлы):
- `modules/games/game_records.ts` — лучший результат по игре, AsyncStorage, ключ на владельца аккаунта.
- `components/games/GameRecordsCard.tsx` — блок: заголовок и сетка 2 × 2 ячеек «число — название».
- `tests/game_records.test.ts`.

Out of scope: вставка блока в `app/streak_stats.tsx` и экраны игр, запись рекорда из игр, панель «Гонка с собой»
(`P.record`), синхронизация с сервером, любые существующие файлы.

## Architecture

- Образец — `modules/skills/skill_store.ts`: состояние в памяти процесса (`peekGameRecords` для первого кадра), диск
  читается один раз, изменения идут через одну очередь, подписка для `useSyncExternalStore`, сброс памяти при смене
  владельца (`onAccountOwnerChanged`).
- Ключ: `game_records_v1:<stableId | anon>`. Запись: `{ v: 1, best: { <игра>: число } }`.
- Реестр игр — четыре строки макета: Блиц (верных за минуту, больше — лучше), Поток (темп, больше — лучше),
  Лишнее слово (серия, больше — лучше), Смахни (секунд на ответ, меньше — лучше). Формат числа — как в макете:
  `26`, `×1,9`, `14`, `0,8 с`.
- Рекорд только улучшается: худший результат запись не меняет и на диск не идёт.
- `noteGameResult` никогда не бросает; сбой записи — `console.warn` с префиксом `[GAME-RECORDS]`, значение остаётся в
  памяти и дописывается при следующем событии или `refreshGameRecords`.
- Карточка рисуется сразу из памяти, спиннеров нет; пока нет ни одного рекорда — возвращает `null` (блок не показывается).
  Размеры из макета (`elevate-extra.css` `.recs`, `elevate-light.css` `.pan`): сетка 2 колонки, шаг 10, отступ 12 от
  заголовка; ячейка — радиус 16, поля 12 · 14; число 24/800, трекинг −0,4, табличные цифры; подпись 13.
  Движения у блока в макете нет — карточка статична.

Решения по спорному в макете (приняты по умолчанию, сообщены координатору):
- «Без подписей-расшифровок»: под числом только название игры («Блиц»), хвост «· верных за минуту» убран.
- Метки «новое» нет (как у соседнего блока «Навыки»).
- Стрелка в заголовке рисуется только когда блоку передан `onPress` — стрелка на ненажимаемом блоке обманывала бы.

## Security and privacy

Данные только на устройстве: лучший результат игры, без текста ответов и без времени занятий. В сеть ничего не уходит,
политика конфиденциальности не затрагивается. Ключ привязан к владельцу аккаунта; память сбрасывается при смене владельца.
Содержимое диска разбирается строго: не число, не конечное, отрицательное или неизвестная игра — отбрасывается.
