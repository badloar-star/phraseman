# Англійська · Урок 26 · Заняття 25 — Якщо тільки не

**Ситуація.** Ви готуєте частування й обговорюєте плани, умови та винятки.

**Що ви опануєте:** if, when, unless + present clause
**Нові слова:** unless, moist, gooey, grubby

## Інтро 1

### Якщо не станеться виняток

Unless — якщо не, якщо тільки не. We will eat outside unless it rains — ми поїмо надворі, якщо не піде дощ. Звичайний план — їсти надворі; дощ — виняток, який його змінює. Це можна передати як We will eat outside if it does not rain. Після unless тут rains: форма work / works без will і без додаткового not. Слово unless уже містить значення «якщо не».

**Виберіть фразу для цієї ситуації.**

- ✅ **We will eat outside unless it rains.**
- ❌ We will eat outside unless it will rain. — *Після unless у цій майбутній умові потрібна форма work / works: rains.*
- ❌ We will eat outside unless it does not rain. — *Додаткове not змінює зміст: вийде виняток, коли дощу немає.*

## Інтро 2

### Спробувати не надто солодкий пиріг

Друг пропонує пиріг. Ви згодні спробувати, але не любите надто солодке: I will try it unless it is too sweet — я спробую, якщо він не надто солодкий. Складаємо: I + will try + it + unless it is too sweet — хто, що зробить, що спробує, який виняток змінить рішення. It замінює пиріг. Unless уже означає якщо не, тому в його частині потрібна ствердна форма is too sweet. Not після is перевернуло б умову.

**Виберіть фразу для цієї ситуації.**

- ✅ **I will try it unless it is too sweet.**
- ❌ I will try it unless it will be too sweet. — *Після unless тут is без will.*
- ❌ I will try it unless it is not too sweet. — *Not після unless тут переверне умову: надто солодкий пиріг стане допустимим.*

## Інтро 3

### Не починати без готовності всіх

Ви збираєтеся почати спільну гру, але спершу кожен має приготуватися. Скажіть: We will not start unless everyone is ready — ми не почнемо, якщо не всі готові. Складаємо: We + will not start + unless everyone is ready — хто, чого не зробить, без якої обов’язкової умови. Will not start означає не почнемо. Unless everyone is ready дозволяє почати лише за готовності всіх. Після unless використовуємо ствердне is ready без will і без not; everyone потребує is.

**Виберіть фразу для цієї ситуації.**

- ✅ **We will not start unless everyone is ready.**
- ❌ We will not start unless everyone will be ready. — *Після unless у цій умові is без will.*
- ❌ We will not start unless everyone is not ready. — *Додаткове not змінює обов’язкову умову на протилежну.*
