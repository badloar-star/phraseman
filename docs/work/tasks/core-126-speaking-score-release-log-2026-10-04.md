## Outcome
Каждая оценённая попытка в SpeakingPanel пишет в релизе одну строку [SPEAK-SCORE]: цель, распознанный текст, «смещённый» балл (распознавание с подсказкой цели), контрольный балл (нейтральный движок, без подсказки), честный итог, порог, флаг, passed и признак, применилась ли поправка честности. Раньше это было только в micTrace (console.log), который babel вырезает в релизе.

## Scope
components/SpeakingPanel.tsx — одна строка лога.

## Architecture
Гипотеза для проверки по логам: фразовое распознавание запускается с contextualStrings из целевой фразы (app/speaking_recognition_options.ts:122), движок «дотягивает» до цели; контрольный прогон (whisper/системный без подсказки) должен понизить балл, но при control=null поправка не применяется.

## Security and privacy
В лог идёт распознанный текст попытки (не более 120 знаков) — это произнесённая учебная фраза; журнал локальный (консоль устройства / отчёт об ошибке по запросу), в Firestore не уходит.

## Technical debt
Правка порога/поправки — после диагноза. Huawei без Google Services: распознавание недоступно — отдельный путь (whisper на устройстве).
