Атлас: дизайн раздела Learning V2

Идея одной фразой: английский по картам. Уроки лежат колодой, каждая карта раскрывается в город, который ты зажигаешь: семь районов со своим светом и своей формой пути, фонари вместо кнопок, печать в конце главы и врата экзамена. Занятие открывается билетом и ирисом из клавиши, проверка — печатью, которая раскалывается как сейф. Всё живёт, всё за доли секунды, ноль растровых ассетов.

Токены

Законы

  • Световод + акценты Чекана. База: свет и глубина без отскоков. Удар и вес только на печати главы и вратах.
  • Из точки действия. Ирис начинается там, где нажали; фонарь летит в билет; карта растёт из своего места.
  • Спокойный отказ. Никакой тряски: прожим 4 % и точная причина в тосте.
  • Reduced motion всегда. Вечные циклы стоят на живом кадре, ирисы мгновенны, каскады 1 мс.
  • Празднование не durable. Награда считается локально и сверяется с фактом; пропущенная анимация ничего не должна.

Быстродействие: контракт для React Native

  • Только transform и opacity в рантайме; свечения — статичные радиальные градиенты, blur не анимируется.
  • Один вечный цикл на экран (дыхание текущего фонаря) с гейтом видимости и AppState; следующий фонарь греется тем же драйвером.
  • Улица = один Path на главу, свет через strokeDashoffset в animatedProps на UI-треде; искра по getPointAtLength предвычисленной таблицей.
  • Районы — секции виртуализированного списка с фиксированной высотой доски (ROUTES.h): первый кадр = финальная геометрия, скелетон без прыжков.
  • Ноль растровых ассетов: фонари, печати, врата, сигилы и руны — вектор и системный шрифт (старший футарк).
  • Тап отвечает до сети: билет, шторки, счётчики и награды — из локального состояния; сервер подтверждает фоном, отказ откатывает с тостом.
  • Переходы без чёрного кадра: ирис и FLIP рисуются поверх уже смонтированного экрана; тяжёлая подготовка (аудио) идёт под полосой света, не под спиннером.
  • Логи на ранних выходах с префиксом [ATLAS-*]; экран показывает человеческую причину, reason уходит в лог.
