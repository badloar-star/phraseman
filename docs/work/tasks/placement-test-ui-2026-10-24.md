## Architecture
Чистая модель вида (`placement_view_model.ts`) считает по состоянию движка: подпись «урок n из N», точки попыток (`ok`/`no`/`cur`/пусто), плашку «ещё 2», строки итога. Экраны — тонкие компоненты без своей логики. Источник вопросов и применение результата приходят через пропсы/мост (`placement_bridge.ts`), поставляет Learning V2.
