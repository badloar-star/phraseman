# too_enough

Jesse rewrite for `too_enough`.

## Scope

- Keep supported locales as `ru`, `uk`.
- Keep the full MVP contrast set, including `too ... to`.
- Teach through chunks, not grammar labels.

## Learner problem

The learner mixes two questions:

- Meaning: too = excessive/problem, enough = sufficient.
- Position: `too hot`, but `good enough`; `enough time`, not `time enough`.

## Required anchors

- `too_enough_easy_001`: wrong `enough` feedback contains `too hot`.
- `too_enough_contrast_001`: wrong `enough good` feedback contains `good enough`.
- `too_enough_contrast_004`: wrong `time enough` feedback contains `enough time`.
- `too_enough_mixed_001`: wrong `too much` feedback contains `too many people`.
- `too_enough_mixed_006`: wrong long sentence feedback contains `too small / enough chairs`.

## Step ladder

1. `too hot`
2. `too expensive`
3. `too fast`
4. `good enough`
5. `old enough`
6. `fast enough`
7. `enough time`
8. `enough money`
9. `not good enough`
10. `too many people`
11. `too much noise`
12. `too tired to work`
13. `too expensive / good enough`
14. `old enough / enough money`
15. final sentence correction
