## Architecture

Источник итога — тот же загрузчик `spireLoadWeekResult` в режиме «только посмотреть» (кэш 'found' от пробы D191 → 0 чтений;
иначе один документ по id). Отметка «показано» — локально `spire_week_moment_shown_v1:<uid>:<lang>` = weekId, ставится, когда
окно реально получило слот в очереди окон (не при решении) — не показанное окно не теряется. Неделя — по UTC (как у сервера),
поэтому часовой пояс устройства на решение не влияет. Порядок: ключ `spireWeekMoment` сразу после системных
(onboardingWelcome, update, authRecovery) и раньше всех окон Главной.
