# Lingman Algorithm Upgrade 010 - Direct Viewer Address

Дата:


## Причина

```text
Пользователь заметил, что в публичном сценарии появилось слово "зритель".
Это мета-язык брифа, а не речь ведущего.
В сценарии ведущий должен говорить напрямую с человеком.
```

## Правило

```text
В публичном сценарии использовать прямое обращение:
- вы;
- у вас;
- ваш мозг;
- вы замечаете;
- вы открываете;
- если вы учите английский.
```

## Запрещено В Публичном Сценарии

```text
Не использовать как обычный способ обращения:
- зритель;
- ученик;
- новичок;
- аудитория.

Эти слова допустимы в брифе, QA, стратегии, описании аудитории и внутренних заметках.
```
