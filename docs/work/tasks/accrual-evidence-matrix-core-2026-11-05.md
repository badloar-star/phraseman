# Task packet: доказательства по каждому начислению (E2E, часть «Ядра»)

## Outcome
Для каждого начисления есть проверяемое доказательство: что видит человек, что лежит на телефоне, что записал сервер. Таблица — чек-лист для «Эмулятора» и «Ревизора»; пустая клетка = начисление не принято.

## Scope
Только чтение и проверка. Код не меняется. Начисления: монеты 3/2/1 за правильный ответ, +500 за видео, XP, осколки, энергия (включая подарок), награда за экзамен главы, «Урок вместе».

## Architecture
Источники правды: телефон решает, сервер хранит (замок владельца 22.10). Для каждой строки: (а) действие на устройстве, (б) метка локального журнала, (в) серверный след, (г) готово, когда.

| Начисление | Действие на устройстве | Локальный след | Серверный след | Готово, когда |
|---|---|---|---|---|
| Монеты 3/2/1 (урок, словарь, глаголы) | пройти сессию 1-й, 2-й, 3-й раз; на каждом проходе 3 правильных ответа | `practice_runes:answer_skipped` НЕ появляется для новых ячеек; шапка монет растёт на 3, затем 2, затем 1 за ответ | `practice_rune_grant` приняла операции, структурный максимум, без отказов `amount_over_limit` | прирост шапки совпал с таблицей на всех трёх проходах, после перезапуска число то же |
| +500 за видео (70 %) | досмотреть видео до 70 % (без перемотки), затем открыть повторно и досмотреть снова | журнал `video_full:{videoId}`: ровно одна запись; повтор — no-op с причиной | `[COIN-WALLET] credited ... source=video_full amount=500`, второй раз `replay ... credited=0` | +500 один раз, повтор 0, пометка `[VIDEO-REWARD] limits_flag` только при >10 наград за сутки |
| XP | завершить урок | локальный счётчик XP вырос сразу, без ожидания сети | запись в документе пользователя после синхронизации | число XP до/после синхронизации не «прыгает» |
| Осколки | действие с наградой осколков (по макету) | локальный баланс обновился сразу, поздний ответ сервера не затёр его | квитанция операции в `stars_ledger` | баланс устройства = баланс сервера после синхронизации |
| Энергия: трата и возврат | начать занятие, оборвать вход | один `operationId` в журнале энергии, возврат разворачивает записанный split | нет серверной записи (энергия локальная) | запас не вышел за потолок 16 |
| Энергия: подарок (флаг OFF) | при включённом флаге: отправить/принять подарок | `[ENERGY-GIFT]` на каждой ветке | `energyGiftSend`/`energyGiftClaim`: коды `not_friends_24h`, `quota_*`, `plus_receiver`, `self` | включается только вместе с серверной частью; по умолчанию OFF |
| Экзамен главы 40 | сдать часть 1, затем 2 | две операции `chapterexam_…_1/_2` по 20 | `credited` дважды, потолок 120 в сутки | 40 за главу, воскресного ×2 нет |
| «Урок вместе» +2 | пройти урок с другом | `lessontogether_…` | `credited amount=2` | +2 один раз на пару и день |
| Награда за жалобу | отправить жалобу (по макету) | `report_reward_…` | `credited`, потолок 1000 на жалобу | сумма из таблицы |

## Security and privacy
Доказательства собираются на тестовых аккаунтах (№3, не №1). Идентификаторы пользователей в отчёты и чат не пишутся; в серверных логах они уже обрезаны. Серверный `videoId` награды — данные активности, абзац политики конфиденциальности обязателен до релиза.

## Technical debt
Нет отдельного места, где собраны метки логов по всем начислениям. Предложение: единый поиск по префиксам `[COIN-WALLET]`, `[VIDEO-REWARD]`, `[ENERGY-GIFT]`, `[COMPLETION-JOURNAL]`.

## Verification
Серверные следы читаются командой чтения логов Cloud Run по имени функции за окно времени прогона. Телефонные следы берёт «Эмулятор» из `.expo/metro-console.log`. Каждая строка таблицы закрывается ссылкой на снимок и фрагмент лога в `docs/phraseman-2.0/evidence/`.
