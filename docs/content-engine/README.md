# Phraseman Content Engine

Эта папка хранит редакционную систему для Reels, carousels и длинных Instagram captions.

## Файлы

- `VOICE_SPEC.md` - авторский голос, ритм, структура, анти-ИИ правила и продуктовые мосты.
- `CONTENT_PASSES.md` - пять отдельных проходов: pattern break, hooks, multiplication, retention и authority.
- `EDITORIAL_WORKFLOW.md` - процесс от исследования конкурентов до A/B теста.
- `RESEARCH_QUEUE_2026-07.md` - актуальные исследования и готовые углы для громких материалов.
- `SAMPLE_CAPTIONS_V1.md` - первая серия переписанных статей и hooks.
- `APPLIED_EXAMPLE_RETENTION_V2.md` - один материал, полностью проведённый через новую систему с hooks, оценками, тремя голосовыми версиями и тремя форматами.
- `WRITING_PROMPT.md` - рабочий промпт для производства новых материалов в том же голосе.

## Главный принцип

Reel создаёт личный сбой. Caption объясняет механизм. Phraseman возвращает этот сбой позже без подсказки.

Продукт не прерывает статью рекламой. Он закрывает психологический цикл, который статья уже открыла.

## Порядок работы

1. Проверить источник и заполнить research card.
2. Посмотреть свежий контент конкурентов и назвать заезженные паттерны.
3. Найти содержательный pattern break.
4. Прогнать hooks через оценку.
5. Написать и отредактировать caption на удержание.
6. Сделать Elegant, Direct и Premium версии.
7. Перевести победившую идею в Text Reel, carousel и quiet visual post.
8. Проверить факт, продуктовый мост и отсутствие длинных тире.
