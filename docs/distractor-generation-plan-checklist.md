# План и чеклист: качественные дистракторы для уроков

Цель: заменить случайные дистракторы на осмысленные варианты, которые тренируют правило урока, выглядят правдоподобно и не создают нечестных вопросов.

## Главный принцип

Дистрактор должен быть не случайным словом, а вероятной ошибкой ученика.

Хороший дистрактор:

- похож на правильный ответ по грамматической роли;
- связан с темой урока;
- выглядит правдоподобно в этом месте фразы;
- однозначно неправильный;
- помогает проверить конкретное правило, а не память на случайный набор слов.

Плохой дистрактор:

- случайное слово из другой категории;
- выдуманное слово;
- правильный ответ или его допустимый вариант;
- слово, которое тоже подходит в фразу;
- слишком очевидно неправильный вариант.

## Целевой стандарт для каждого слова

Для каждого обычного токена в `words` / `wordsEn`:

- минимум 5 дистракторов;
- без дублей;
- без `correct` внутри `distractors`;
- минимум 3 дистрактора из той же грамматической категории;
- минимум 2 дистрактора должны проверять именно тему урока;
- не больше 1 слишком простой "визуальной" ловушки, если она не является целью урока.

Пунктуация может иметь отдельный стандарт:

```ts
correct: ".",
distractors: [",", "?", "!", ";", ":"]
```

## Типовая структура пула из 5 дистракторов

Идеальный пул:

1. Ошибка по главному правилу урока.
2. Вторая ошибка по тому же правилу или близкому подправилу.
3. Морфологически близкая форма.
4. Семантически близкое слово той же части речи.
5. Частотная ошибка русско-/украиноязычного ученика или похожая форма.

Пример для Present Simple:

```ts
correct: "works",
distractors: ["work", "working", "worked", "does work", "is working"]
```

Пример для предлогов:

```ts
correct: "at",
distractors: ["in", "on", "to", "by", "for"]
```

Пример для Past Simple irregular:

```ts
correct: "went",
distractors: ["go", "goed", "gone", "goes", "was going"]
```

## Матрица правил по типам слов

| Тип correct | Какие дистракторы нужны | Чего избегать |
| --- | --- | --- |
| Pronoun | другие местоимения того же набора: `he/she/they`, `him/her/them` | существительные, глаголы, имена людей без причины |
| To be | формы `am/is/are/was/were/be/been/being` | случайные глаголы вроде `take`, `buy` |
| Regular verb | другая форма того же глагола + близкие глаголы | существительные и прилагательные |
| Irregular verb | base/past/participle ошибки: `go/went/gone/goed` | варианты, которые тоже грамматически подходят |
| Modal | другие модальные + ошибка `to + verb` | обычные лексические глаголы как основной пул |
| Article | `a/an/the/-/this/that` | любые слова не из системы determiners |
| Preposition | близкие предлоги той же зоны: time/place/direction | предлоги другой темы, если они не являются типичной ошибкой |
| Noun | существительные той же semantic field | глаголы, случайные абстрактные слова |
| Adjective | близкие прилагательные, comparative/superlative формы | наречия, если урок не про adj/adverb contrast |
| Adverb | близкие наречия и позиционные ошибки | прилагательные без учебной причины |
| Phrasal verb particle | частицы `up/out/off/in/on/away/back` | полные глаголы вместо particles |
| Question word | `what/where/when/why/how/who/which` | обычные наречия как основной пул |

## Правила по типам уроков

### Уроки про форму глагола

Дистракторы должны проверять форму:

```ts
correct: "is working",
distractors: ["works", "worked", "was working", "are working", "is work"]
```

Важно: если урок про Present Continuous, варианты `works` и `worked` хороши, потому что они проверяют отличие времён.

### Уроки про порядок слов

Дистракторы должны быть не случайными словами, а словами из этой же фразы или близкой структуры:

```ts
correct: "does",
distractors: ["do", "is", "has", "did", "-"]
```

### Уроки про предлоги

Дистракторы должны быть из того же поддомена:

- time: `in/on/at/by/during/for/since`;
- place: `in/on/at/under/behind/between/near`;
- direction: `to/into/from/through/toward/onto`.

Не смешивать без причины `during` с `under`, если урок про место.

### Уроки про лексику

Дистракторы должны быть из той же ситуации:

```ts
correct: "ticket",
distractors: ["passport", "receipt", "card", "document", "map"]
```

Это лучше, чем:

```ts
distractors: ["green", "slowly", "sleep", "because", "under"]
```

## План внедрения

### Этап 1. Зафиксировать спецификацию

- Принять стандарт: 5 дистракторов для каждого обычного токена.
- Отдельно разрешить пунктуационные пулы.
- Зафиксировать, что `correct` не может входить в `distractors`.
- Зафиксировать, что дистракторы должны быть той же категории или явной учебной ловушкой.

Готовность этапа: есть документ с правилами и чеклистом ревью.

### Этап 2. Разметить каждый токен

Для каждого `word` / `wordsEn` хранить или вычислять:

- `category`;
- часть речи;
- тему урока;
- грамматическую роль;
- lemma/base form, если это глагол;
- допустимые формы, которые тоже могут быть правильными.

Готовность этапа: можно программно понять, какой тип дистракторов нужен для каждого correct.

### Этап 3. Создать генераторы по категориям

Нужны не один общий генератор, а набор маленьких генераторов:

- `buildPronounDistractors`;
- `buildToBeDistractors`;
- `buildVerbTenseDistractors`;
- `buildArticleDistractors`;
- `buildPrepositionDistractors`;
- `buildNounDistractors`;
- `buildAdjectiveDistractors`;
- `buildQuestionWordDistractors`;
- `buildPhrasalParticleDistractors`;
- `buildPunctuationDistractors`.

Каждый генератор должен возвращать 5 вариантов и объяснение, почему они подходят.

Готовность этапа: для каждого типа correct есть предсказуемый способ получить пул.

### Этап 4. Добавить словари кандидатов

Нужны curated-пулы:

- местоимения;
- формы `to be`;
- модальные;
- артикли/determiners;
- предлоги по подтипам;
- вопросительные слова;
- частотные глаголы;
- тематические существительные;
- пары irregular verbs;
- пары adjective/adverb;
- частицы phrasal verbs.

Готовность этапа: генераторы не берут слова случайно из всего словаря.

### Этап 5. Добавить валидатор

Валидатор должен блокировать:

- `distractors.length < 5` для обычных токенов;
- дубли внутри массива;
- `correct` внутри массива;
- пустые строки;
- выдуманные английские слова;
- дистракторы из неправильной категории без разрешённой причины;
- варианты, которые тоже могут быть правильным ответом;
- одинаковый пул, переиспользованный в нерелевантном контексте.

Готовность этапа: плохой пул не проходит CI/аудит.

### Этап 6. Автоматически чинить слабые уроки

Приоритет:

1. Урок 23: заполнить пустые пулы.
2. Урок 22: заполнить пустые и короткие пулы.
3. Уроки 24-30 и 32: расширить пулы до 5.
4. Точечно исправить дубли и correct-in-distractors в уроках 8, 12, 24, 25.

Готовность этапа: все 32 урока имеют минимум `C+`, а целевой уровень - `A/B`.

### Этап 7. Сделать ручной QA

Для каждого урока проверить 10-15 случайных фраз:

- дистракторы выглядят правдоподобно;
- вопрос не превращается в угадайку;
- нет двух правильных ответов;
- нет слишком очевидных вариантов;
- ловушки соответствуют теме урока.

Готовность этапа: ревьюер может пройти урок и подтвердить, что ошибки обучающие, а не шумные.

## Чеклист для ревью одного слова

Для каждого `correct`:

- [ ] Есть 5 дистракторов.
- [ ] Нет дублей.
- [ ] Нет правильного ответа внутри `distractors`.
- [ ] Все варианты являются реальными словами или допустимыми учебными ошибками.
- [ ] Минимум 3 варианта из той же грамматической категории.
- [ ] Минимум 2 варианта проверяют тему урока.
- [ ] Ни один дистрактор не является вторым правильным ответом.
- [ ] Нет случайного слова из другой темы.
- [ ] Нет слишком лёгкого набора, где ответ очевиден сразу.
- [ ] Для глагола есть формы, релевантные времени/аспекту урока.
- [ ] Для предлога дистракторы из той же группы: time/place/direction.
- [ ] Для артикля используются только article/determiner варианты.
- [ ] Для существительного дистракторы из той же ситуации.
- [ ] Для местоимения дистракторы из той же системы лиц/числа/падежа.

## Чеклист для ревью урока

- [ ] 100% обычных токенов имеют 5 дистракторов.
- [ ] 0 пустых пулов.
- [ ] 0 correct-in-distractors.
- [ ] 0 дублей внутри массивов.
- [ ] Нет выдуманных слов.
- [ ] Нет массового повторения одного и того же пула для разных типов correct.
- [ ] В уроке есть баланс: не только визуально похожие слова, но и грамматические ловушки.
- [ ] Дистракторы соответствуют теме урока.
- [ ] Уровень сложности растёт: ранние уроки проще, поздние уроки тоньше.
- [ ] Минимум 10 фраз пройдены вручную.

## Что автоматизировать в первую очередь

Минимальный полезный набор:

1. Скрипт, который находит все `distractors.length < 5`.
2. Скрипт, который находит `correct` внутри `distractors`.
3. Скрипт, который находит дубли.
4. Скрипт, который группирует проблемы по урокам.
5. Генератор, который дополняет короткие пулы до 5 по категории.

После этого можно улучшать качество:

1. Проверять грамматическую совместимость.
2. Проверять, что дистракторы относятся к теме урока.
3. Хранить объяснение для каждого дистрактора.
4. Делать отчёт качества по урокам после каждой генерации.

## Рекомендуемая модель данных

Сейчас:

```ts
{
  text: "works",
  correct: "works",
  distractors: ["work", "working", "worked", "does", "is"]
}
```

Лучше:

```ts
{
  text: "works",
  correct: "works",
  category: "verb_present_simple_3sg",
  distractors: ["work", "working", "worked", "does work", "is working"],
  distractorMeta: [
    { value: "work", reason: "base form instead of 3rd person singular" },
    { value: "working", reason: "continuous form instead of present simple" },
    { value: "worked", reason: "past simple instead of present simple" },
    { value: "does work", reason: "auxiliary phrase instead of lexical verb slot" },
    { value: "is working", reason: "present continuous contrast" }
  ]
}
```

`distractorMeta` не обязательно показывать пользователю, но он полезен для QA и автопроверки.

## Критерий готовности всей системы

Система считается готовой, когда:

- все уроки 1-32 имеют 5 дистракторов на обычный токен;
- отчёт показывает 0 пустых пулов;
- отчёт показывает 0 `correct` внутри `distractors`;
- fake-аудит показывает 0 выдуманных слов;
- каждый урок получает оценку минимум `B`;
- уроки 22, 23, 24-30 и 32 подняты с текущего уровня до стандарта.
