Прогон состояний

«Пауза и выход» — оверлей паузы, «Выйти» возвращает на карточку готовности с пилюлей «Продолжить с 4 из 9» (04: pause/resume без потери прогресса). «Шумный ответ» — нейтральная полоса неуверенности, карточка сменяется другим заданием, счётчик НЕ увеличивается как ошибка (04: UNCERTAIN — эквивалентная попытка, не WRONG). «Результат с повторением» — один навык получает пилюлю «повторим», не крест. «Идеальный результат» — все четыре can-do зелёные, 3 звезды, золотая волна, конфетти, замок расщёлкивается.

Спецификация для RN (Reanimated 4)

Переход сцен (готовность → ход)240 мс · fade+slide, без полноэкранного спиннера
Оверлей паузы: раскрытие240 мс · scale spring, scrim opacity
Полоса неуверенности: раскрытие320 мс · max-height + fade
Смена карточки после неуверенности240 мс · crossfade, без штрафа
Мини-задание: слот/чипыFLIP-перелёт 280 мс, как в 06-context-gap
Can-do строки результата: каскад70 мс/строка · spring 360 мс
Зажигание звезды: сквош-поп420 мс · как в 09-session-finale
Золотая волна + конфеттитолько на идеальном результате
Расщёлкивание замка420 мс · поворот дужки, spring
Пресс CTA/вторичной (3D-кромка)120 мс · вибро
Только transform / opacity / clip-path (UI-тред). Reduced motion: каскады и звёзды получают финальные значения мгновенно; полоса неуверенности и оверлей паузы теряют анимацию раскрытия, но не смысл.
