# Задание фабрике курса: банки экзамена глав (экзамен v2)

Передаёт владелец. Формат утверждён на главах 1–3 урока 1 (25.10, «Да, включать и делать дальше»).

## Что сделать

Для каждой главы курса (урок N, глава C; в главе 8 эпизодов, экзамен идёт после эпизода C × 8) написать банк экзамена v2 —
файл `modules/learning-v2/exam/banks/chapter_exam_v2_lNN_cC.ts` с типом `ChapterExamV2Bank`
(`modules/learning-v2/exam/chapter_exam_v2.ts`). Начать с урока 1, главы 4–7; дальше — по урокам.

Образцы, которые нужно повторить по устройству: `chapter_exam_v2_l01_c1.ts`, `_c2.ts`, `_c3.ts`. Читабельный вид —
`docs/work/exam-banks-for-owner-2026-10-25.md`.

## Правила (все обязательны)

1. **Только слова и формы из эпизодов до экзамена.** Каждое английское слово реплики собеседника, фразы с ошибкой и ВСЕХ
   принятых ответов уже встречалось в эпизодах 1…C × 8 этого урока (выпуск `content/learning-v2-course/release/en/lNN/sNN`).
   Эталон (первый в `accepted`) — в той же форме, что в эпизодах: полной, без сокращений, если сокращения не показывали.
   Грамматику, которую ещё не вводили (например, вопросы или «we / they» раньше их эпизода), не использовать.
2. **Ситуация и ответ сходятся по смыслу**, как в живом разговоре. Плохой пример: «коллега спрашивает, готов ли отчёт» →
   «I'm not ready» (спросили про отчёт — ответили про себя).
3. **Несколько верных ответов**: короткая и полная форма, «No, …», если «no» уже было, синонимы из эпизодов.
4. **Состав**: 2–4 темы главы с 2–3 эпизодами для повторения у каждой; 14–16 заданий ≈ 6 «скажи по-английски» (ситуация),
   6 «ответь собеседнику» (реплика + что сделать), 4 «найди и исправь ошибку»; не меньше 3 заданий на тему.
5. **Тексты ситуаций — на русском и украинском**, короткие, без грамматических терминов, по Библии текстов Learning V2.

## Как проверить (банк не выпускается, пока красно)

- `tests/owner_locks_exam_episode_words_2026_10_25.test.ts` — незнакомые слова, с перечнем;
- `tests/learning_v2_chapter_exam_v2_banks_rules.test.ts` — состав, темы, уникальность, без вопросов, ru/uk.
  В тесте есть строка «банков три» — её надо обновить списком новых глав.

Исключения из правила 1 (имена собственные, интернациональные слова) — только явным списком в стороже, с причиной.

## Чего не делать

- Не подключать банк в приложении: строку в `BANKS` (`app/learning_v2_chapter_exam_v2.ts`) добавляет Learning V2 после
  вычитки владельцем.
- Не менять движок экзамена и экран: `modules/learning-v2/exam/chapter_exam_v2.ts`, `components/learning-v2/exam_v2/*`.
- Не трогать готовые банки глав 1–3 урока 1.

## Что вернуть

Файлы банков, зелёные оба теста и читабельный файл по образцу `docs/work/exam-banks-for-owner-2026-10-25.md`
(«ситуация → ожидаемый ответ / что ещё засчитывается») для вычитки владельцем.
