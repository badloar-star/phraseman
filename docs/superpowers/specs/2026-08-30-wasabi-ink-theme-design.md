# «Васаби и тушь» — дизайн темы

## Решение владельца

Добавить одну новую платную светлую тему `wasabiInk` с названием «Васаби и тушь». Это не пастельная перекраска: основа — тёплая японская бумага, рабочий акцент — почти чёрная зелёная тушь, а светлый васаби используется только как живой декоративный и иллюстративный тон. Стоимость — 200 жемчужин, как у существующих shard-тем; Plus тему не открывает.

## Палитра и семантика

| Токен | Значение | Назначение |
| --- | --- | --- |
| `bgPrimary` | `#EEEED5` | Матовая бумага, основной фон |
| `bgCard` | `#FFFEF7` | Карты и модальные поверхности |
| `bgSurface` / `bgSurface2` | `#E4E5CA` / `#D9DBC0` | Вложенные поверхности и треки |
| `textPrimary` | `#20291D` | Основной текст |
| `textSecond` / `textMuted` / `textGhost` | `#394B3B` / `#5D6952` / `#56614B` | Вторичный текст, без серого «мыла» |
| `accent` | `#34453A` | CTA, выбранные элементы, активные вкладки |
| `accentBg` | `#E0E8CD` | Мягкая акцентная подложка |
| `correct` / `wrong` | `#2F6E4C` / `#A6443B` | Состояния ответа |
| `gold` / `goldBg` | `#8F6626` / `#F0E5C9` | Награды, валюта и премиальные детали |
| `wasabiArt` | `#BDCD55` | Только иллюстрации, изображения плиток и фоновые детали; не UI-текст и не CTA |

Во всех интерактивных заливках текст остаётся белым только на тёмных `accent`, `correct`, `wrong` и `gold`. Светлый `wasabiArt` не используется как кнопка/плашка с белым текстом.

## Поведение

- Тема добавляется в `ThemeMode`, `THEME_MAP`, селектор и цикл доступных тем.
- `isLightThemeMode` возвращает `true` для `wasabiInk`; все уже централизованные светлые ветки используют эти токены.
- Доступ определяется только `theme_access_policy`: `wasabiInk` имеет tier `shards` и цену 200; запись покупки использует существующую атомарную операцию `theme_purchase` с `subjectId: 'wasabiInk'`.
- На экране тем плитка демонстрирует настоящую палитру и получает цену/замок через существующий механизм.
- Карты, progress, статус ошибок/успеха, paywall и модальные поверхности получают отдельные явные ключи `wasabiInk`; не допускается тёмный fallback.
- Все тематические asset-карты получают явный ключ. В первой поставке повторно используются существующие статические ассеты лишь там, где исходная карта уже допускает fallback; новый asset добавляется только при наличии статического `require()` и проверенной точки потребления.

## Границы

- Не меняются правила других тем, цены, Plus-полка и экономика покупки.
- Не создаются новые удалённые/динамические asset-загрузки и не используется project OpenAI API.
- Не редактируются текущие чужие незакоммиченные изменения в `app/(tabs)/settings.tsx` и `app/(tabs)/lessons.tsx`; перед каждой правкой проверяется пересечение diff.

## Критерии приёмки

1. Тема доступна в «Темах», предпросматривается и покупается ровно за 200 жемчужин; покупка не доступна через Plus.
2. Сохранённый режим `wasabiInk` восстанавливается `ThemeContext` и все центральные light-mode ветки считают его светлым.
3. Семантические токены и интерактивный текст соответствуют WCAG AA ≥4.5:1.
4. Каждый runtime theme map имеет явный ключ `wasabiInk` или доказуемо построен от семантических токенов; ни один экран не получает dark default.
5. Новые регрессионные тесты проходят вместе с затронутыми существующими theme-contract тестами.
