## Outcome

Все экраны с решением keep/redesign в `docs/phraseman-2.0/registries/screen_inventory.json`
выглядят как 8 референсов владельца от 24.09: тёмный фон, карточки с тонкой полупрозрачной обводкой,
подписи под названиями, крупная типографика. Главная совпадает с референсом один в один. Таббар:
Главная · Обучение · Видео (центр) · Сообщество (Друзья + Лига) · Настройки. Проверка — на эмуляторе Android
рядом с референсом.

## Scope

In scope: общие токены стиля (цвета, радиусы, отступы, кегли), общие UI-компоненты, таббар,
вёрстка экранов keep/redesign. Темы — только тёмные, отличаются акцентом.

Out of scope: логика и удаления (сессия «PhraseMan 2.0 разработка», D40); экраны remove/conserve/unknown;
ассеты (оставляем заглушки, рисует Codex); файлы, заблокированные соседней сессией до её коммита.

## Architecture

Существующая система тем сохраняется (D38). Добавляется единый набор токенов нового стиля, от которого
зависят все экраны; темы подменяют только акцентные цвета. Данные, навигационные маршруты и контракты
экранов не меняются, кроме состава вкладок таббара.

## Security and privacy

Не затрагивает: правка только внешнего вида, новых данных, сервисов и разрешений нет.

## Technical debt

- Contain: старые декоративные стили экранов, ещё не переведённых на токены, — выход: экран переведён.
- Accept temporarily: заглушки ассетов — владелец, до поставки ассетов от Codex.

## Verification

Эмулятор Android: скриншот каждого переделанного экрана рядом с референсом. Сторожа
`tests/layout_stability_contract.test.ts`, `tests/perf_freeze_contract.test.ts` точечно через `npm run test:one`.
Точечный tsc по затронутым файлам.

## Rollback

Каждый экран коммитится отдельно, откат — `git revert` конкретного коммита; данные пользователей не затрагиваются.
