## Метод

1. Выписаны все имена callable из `legacy.html` (`httpsCallable(…,'name')` и обёртки
   `getAdminUserOperationCallable`, `getAdminSensitiveControlCallable`, `supportCallable`,
   `qFn`, `tnFn`, `pmV5Callable`, `createAdminAuthCallable`, `call`).
2. Каждое имя сверено с живыми экспортами развёртываемых кодовых баз из `firebase.json`:
   `functions/src/index.ts` (default), `functions-max/index.ts` (max), `functions-content/index.ts`
   (content), `functions-english-test/index.js` (english-test). Закомментированный экспорт = мёртвый.
   `functions-admin/` в `firebase.json` не значится — его экспорты живыми не считались.
3. Отдельно проверены разделы, которые зовут ЖИВЫЕ функции, но управляют фичей, удалённой решением
   владельца (D-номер).
