## Architecture
Скрипт читает версии реестра из `git show <commit>:<путь>` по каждому коммиту за ночь, фиксирует множество id строк r1 по
текущему HEAD и считает по каждой версии число строк в match / pending / diff / blocked. Текущая разбивка — функцией
`evaluateRegistry` гейта (`--release=r1 --json`), чтобы цифры совпадали с гейтом.

## Security and privacy

## Technical debt
Темп считается по коммитам реестра, а не по фактическому времени съёмки: коммиты пачками дают ступенчатую кривую, прогноз —
линейная оценка с явной оговоркой. Незакоммиченные правки реестра другой сессии в расчёт не входят (указывается в документе).

## Verification
