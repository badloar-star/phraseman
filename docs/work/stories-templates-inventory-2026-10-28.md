## Как внедряю (порядок)

1. **Кадры** — новые файлы `components/stories/templates/*`: общий каркас (фон с пятнами света темы, обзор/заголовок «лесенкой» по 50 мс,
   счётчики ≤ 1,2 с, «Уменьшить движение» → сразу конечное состояние) и 23 кадра. Цвета — только `GlassTokens`; тёмное и светлое.
2. **Фотостудия** — режим `state=stories` в уже вырезанном из стора `app/dev_moments_preview.tsx` (мой файл; `router.ctx.js` не трогаю):
   все 23 кадра с примерными данными макета, переключатель темы/оформления, плеер с полосами/тапом/удержанием/свайпом — для снимков Сверки.
3. **Показ в приложении** — точка подключения кадров по типу события. `StorySlides.tsx` и `story_events_core.ts` у Codex → точный патч
   координатору (новые типы, ключи повтора, ветка `switch` на новый кадр).
4. **События** — новые переходники в `story_event_sources.ts` (одна строка `void record…`), источники в чужих файлах — патчами.
   Логи `[STORY-TPL]`: запись (тип, ключ, откуда данные), показ кадра (тип, тема, оформление, уменьшение движения).
5. **Тексты** — 9 языков через Переводчика.
6. **Праздник** — новый шаблон объявления затрагивает серверный контракт объявлений и редактор админки → отдельно, после 1–5.

Сознательные отличия от макета (данные важнее пикселя):

- **Твоя неделя**: столбики — доля от самого длинного дня. В CSS макета столбики 80, 90 и 100 % из-за сжатия flex выходили одной высоты (93 px).
- **Отметка монет**: монеты падают, как в описании движения. В макете у монет дождя инлайн `width:0;height:0` — в браузере их не видно.
- **Новая тема**: круг — цвета самой открытой темы из каталога (в макете — иллюстративные #DDE1E8 / #5E6570, их нет в токенах).
- **Итог недели**: пьедестал — только если событие несёт тройку недели (`p1Name…`); сейчас событие её не несёт → своя монета без соседей.
- **Без обрезки текста**: имена, карточки, строка ошибок, подпись кнопки переносятся, а не режутся многоточием (правило text-integrity).
