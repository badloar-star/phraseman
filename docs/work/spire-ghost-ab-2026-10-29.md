# Проба «призрак друга» на ступени Пика — 2 недели, 50/50 (владелец 29.10 ~09:30)

## Как включается
- Флаг «Пульта» **`ghost_friend_ab`** (`admin/v2/legacy.html` → «Пик: призрак друга (проба 50/50)»). По умолчанию **ВЫКЛ**: призрака не видит никто, ступень как в 2.0.3. **Включает только владелец кнопкой.** В коде флаг `false` (`app/remote_flags.ts`, снимок релиза `ota_flag_baseline_2026-10-25.json`).
- Флаг приходит с `remote_config`, который приложение и так читает на старте: **новых чтений нет**. Пока конфиг не приехал, действует дефолт (выкл).
- Константа `SPIRE_GHOST_ENABLED = false` остаётся рубильником «показать ВСЕМ» на случай, если после пробы решат включить для всех одной строкой.

## Корзина
Корзину считает `spireGhostBucket(stableId)` в `components/spire/spire_ghost_flag.ts`: **FNV-1a, 32 бита, от строки `ghost_friend_ab:v1:<stableId>`; чётный хеш → корзина `a` (призрак показывается), нечётный → `b` (не показывается).** Детерминирована: один и тот же аккаунт всегда в одной корзине, делится ≈ 50/50 (тест на 10 000 id: 47–53 %).

Пересчитать корзину любого uid в аналитике:
```js
function bucket(stableId) {
  let h = 0x811c9dc5;
  for (const ch of `ghost_friend_ab:v1:${stableId}`) { h ^= ch.charCodeAt(0); h = Math.imul(h, 0x01000193) >>> 0; }
  return h % 2 === 0 ? 'a' : 'b';
}
```
(`charCodeAt` по UTF-16, как в приложении; uid — ASCII.)

## Журнал
Событие журнала обращений (`recordSupportDiagnostic`): `feature_action`, экран `/spire`, действие **`spire:ghost:<shown|hidden>:<a|b>`**. Пишется только когда проба идёт (флаг включён и у человека есть id), один раз за процесс на действие. Белый список сервера проходит (тест). Идентификаторов в событии нет.

## Метрики сравнения — только существующие события, новых записей нет
1. **Возврат на следующий день** — доля людей группы, у которых на следующий календарный день была активность (существующая дневная активность профиля / `app:state_change`).
2. **Число ступеней** — число отправленных `spireReportSteps` на человека за проб­ный период (существующая коллекция отчётов Шпиля).
Группа каждого человека восстанавливается формулой выше из его uid — отдельное поле «корзина» писать не нужно. Если для расчёта понадобится новое событие, это будет отдельный запрос.
