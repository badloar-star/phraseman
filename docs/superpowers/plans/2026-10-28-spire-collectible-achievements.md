# Достижения Пика: одна статуэтка на башню

**Goal:** 12 постоянных достижений: вершина открывает, подтверждённое повышение из этой башни улучшает ту же награду. История показывает оба факта, повторы не создают дубликатов.

**Architecture:** общий каталог и хранилище achievements_v1, существующая очередь с защитой поколения аккаунта. Чистый редьюсер фактов Пика; факт повышения сохраняется даже до вершины. Алмаз не имеет перехода выше. Слияние облака объединяет подтверждения, а не заменяет их старым снимком. Истории используют прежний тип achievement с отдельным ключом стадии и исходной датой.

**Tech Stack:** TypeScript, React Native, AsyncStorage, Jest; существующий механизм синхронизации.

- [x] RED: правила вершины/повышения, порядок событий, дубликаты, границы 0–11, финальная башня, облачное слияние.
- [x] Каталог, локализованные условия, 12 сжатых изображений с существующими референсами; один id на башню.
- [x] Выдача через общий защищённый путь достижений, повторяемая доставка в историю с исходными датами.
- [x] Подключение к сохранённому результату ступени и подтверждённому итогу недели; восстановление пропущенных фактов.
- [x] Коллекция/карточка/история различают открыто и улучшено; награды не дают валюту.
- [x] GREEN: 155 focused integration/restore/history/catalog tests + 1 Jarvis guard; ревью без оставшихся замечаний; 0 диагностик типов в затронутых исходниках.
- [x] Отчёт отличает проверенное тестами от непроверенного на устройстве; без запуска эмулятора или деплоя.

Полная финальная проверка типов не зелёная: 22 ошибки в двух не изменявшихся здесь файлах `modules/learning-v2/audio/progressive_audio_contract.ts` и `progressive_audio_runtime.ts`. Итоговый лог `.codex-tmp/peak-complete-typecheck.log`. ESLint затронутых исходников: 0 ошибок. Проверка на телефоне не выполнялась.

**Acceptance:** вершина только после завершения последнего этажа; сохранение результата обязательно; повышение только при promoted=true, demoted=false и newTier=prevTier+1; повышение само не открывает статуэтку; повтор/понижение/смена недели не стирают прогресс; события аккаунта A не пишутся аккаунту B; восстановление облака сохраняет обе даты; история открытия и улучшения различима и не омолаживается на повторном входе.
