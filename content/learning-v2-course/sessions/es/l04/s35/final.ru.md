# Испанский · Урок 4 · Занятие 35 — Эта книга большая

**Ситуация.** Показываете другу книгу рядом с вами.
**Что вы освоите:** ставить este перед названием одного предмета мужского рода.
**Новые слова:** —
**Повторяем знакомые слова:** este, libro, es, grande, nuevo, muy.

## Интро 1

### Книга перед вами

Показываете другу большую книгу на столе. Скажите `Este libro es grande` — «Эта книга большая». Соберите `este libro` + `es` + `grande`. Здесь este стоит прямо перед libro: вместе они означают «эта книга». Испанское libro мужского рода, поэтому нужно este, хотя русское «книга» женского рода.

**Скажите о книге рядом: «Эта книга большая». Начните с Este libro.**

- ✅ **Este libro es grande.** — *Este согласуется с мужским libro.*
- ❌ Esta libro es grande. — *Libro мужского рода: este.*
- ❌ Este libro son grande. — *Книга одна: es.*

## Интро 2

### Новая книга

Друг замечает вашу новую книгу. Скажите `Este libro es nuevo` — «Эта книга новая». Соберите `este libro` + `es` + `nuevo`. Вместо grande поставьте nuevo. Окончание -o относится к мужскому libro; русское «новая» не подсказывает испанское окончание.

**Скажите о книге рядом: «Эта книга новая». Начните с Este libro.**

- ✅ **Este libro es nuevo.** — *Мужское libro: nuevo.*
- ❌ Este libro es nueva. — *Nueva — женская форма; здесь libro.*
- ❌ Esta libro es nuevo. — *Перед мужским libro нужно este.*

## Интро 3

### Очень большая

Книга рядом с вами едва помещается в сумку. Подчеркните размер: `Este libro es muy grande` — «Эта книга очень большая». Соберите `este libro` + `es` + `muy grande`. Muy ставьте непосредственно перед grande: оно усиливает признак и означает «очень».

**Подчеркните размер книги рядом: «Эта книга очень большая». Начните с Este libro.**

- ✅ **Este libro es muy grande.** — *Muy стоит перед grande.*
- ❌ Este libro es grande muy. — *Muy ставится перед признаком.*
- ❌ Este libro muy es grande. — *Соедините muy с grande после es.*

## Практика · 12 заданий

**1 · Послушайте и выберите слово**
🔊 *este*
→ **este** · esta
- esta — *Звучит конечное e: este.*

**2 · Вставьте слово — эта книга рядом большая**
`___ libro es grande.`
→ **Este** · Esta · Estas
Полная фраза: **Este libro es grande.**
- Esta — *Libro мужского рода: este.*
- Estas — *Здесь один предмет мужского рода: este.*

**3 · Соберите фразу — эта книга рядом большая; начните с Este libro**
Плитки: `grande` · `libro` · `es` · `este` · `el`.
→ **Este libro es grande.**
*Плитка `el` лишняя: перед libro уже стоит este.*

**4 · Вставьте слово — эта книга рядом новая**
`Este libro es ___.`
→ **nuevo** · nueva · nuevos
Полная фраза: **Este libro es nuevo.**
- nueva — *Libro мужского рода: nuevo.*
- nuevos — *Книга одна: nuevo.*

**5 · Соберите фразу — эта книга рядом новая; начните с Este libro**
Плитки: `nuevo` · `libro` · `es` · `este` · `nueva`.
→ **Este libro es nuevo.**
*Плитка `nueva` лишняя: libro мужского рода.*
