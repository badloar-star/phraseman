# Lingman Algorithm Upgrade 004 - Series Format Selection Gate

Date:

```text
2026-05-20
```

## Problem

```text
The office created a series format bible too early.
For large repeatable formats, the user needs to shape the format before the office locks the concept.
```

## New Rule

```text
For repeatable formats, courses, seasons, or long lesson series:

1. Ask a substantial user brief first.
2. Research the learning path, YouTube packaging/retention, and Phraseman product fit.
3. Offer multiple named format options.
4. Compare them by clickability, teaching value, continuity, conversion, and risk.
5. Recommend the best 2 options.
6. Wait for user approval before writing a final format bible, season map, or first episode script.
```

## Required Format Option Fields

```text
Format name:
what the audience sees.

Public promise:
what the viewer gets emotionally and practically.

Show engine:
what repeats every episode.

Episode structure:
how a 10-minute episode works.

Title style:
how clickbait and trust are balanced.

Phraseman conversion fit:
why the app appears naturally.

Series potential:
how many episodes the format can carry.

Risks:
what can make the format boring, fake, too negative, or too school-like.

Sample titles:
3 Russian clickable titles.
```
