# Видимые тексты занятия Learning V2 и экзамена главы — для волны живого голоса

Для: 10 · ПЕРЕВОДЧИК. Собрал Learning V2 25.10 по поручению координатора. Голос — docs/work/VOICE.md (утверждён владельцем).

Как читать:
- Ключ — имя строки в файле; RU и UK — то, что видит человек сейчас.
- `(3)` у ключа — шаблон с подстановкой; в таблице подставлено число 3, `{N}` — второе значение шаблона.
- Остальные 7 языков лежат в тех же файлах, кроме экзамена главы v2: у него только ru/uk, потому что курс V2 открыт только этим языкам интерфейса.

Как вернуть: тем же списком «ключ → новый текст (ru / uk)». Если меняется и смысл, то и на 7 других языков. Правку внесу я.

Тексты оценки ответа — честно, по просьбе координатора: человек должен понять, что ошибся и что делать дальше.
- Вердикт ответа (CORRECT / WRONG_VERDICT_BY_LOCALE) — общий для всех режимов занятия.
- В экзамене главы попытка одна, поэтому вместо «Попробуй ещё раз» там «Неверно.» + «Правильно: …».
- Если «Неверно.» станет мягче, оно всё равно не должно звучать как «верно».

Чего здесь нет: тексты самих заданий (ситуации, вступления, разборы) — это контент курса. Их пишет фабрика по Библии текстов, не интерфейс.
