## Architecture

**1. SVG на каждой строке (третья по тяжести).**
`react-native-svg` монтирует отдельную нативную поверхность (`RNSVGSvgView`)
на каждый `<Svg>`; при windowSize 11 их ~62 одновременно — ради декоративной
дужки прозрачностью 0.35. Форма детерминирована индексом строки и имеет всего
6 вариантов (`pulseMapOffsetX` = `sin(index·π/3)`, период 6).
Решение: заменить на обычный `View` — повёрнутый прямоугольник с скруглением.
Это снимает ~62 нативные поверхности. Анимированный вариант остаётся только
рядом с текущим занятием (там SVG допустим: строк мало).

**2. Нет React.memo на плашках урока и главы.**
Каждая вызывает `useTheme()` внутри, поэтому любой тик контекста темы
перерисовывает их все. Решение: обернуть в `React.memo` и передавать
примитивы.

**3. Плашка урока гоняет 56 итераций со сборкой строк-ключей.**
`learningV2CourseSessionIdV1` строит строку `lesson-NN:session:NN` — 56
аллокаций + 56 поисков в Set на каждый рендер плашки. Решение: один проход по
`completedSessionIds` в `useMemo` → `Map<lessonOrdinal, count>`, в плашку
приходит готовое число.

**4. Инлайновые пропы на месте вызова.**
`isSessionMaterialAvailable`, `onUnavailableLessonPress`,
`onLockedLessonPress`, `navigationControl` создаются заново каждый рендер и
срывают мемоизацию внутри карты. Решение: `useCallback` / `useMemo`.

Инвариант: число нативных SVG-поверхностей на экране не зависит от числа
видимых строк.
