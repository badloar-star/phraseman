Лесенка приглашений вместо рулетки Plus — на настоящем экране

Основа телефона — кадр вкладки «Друзья» текущей сборки («Затмение» тёмное); экран приглашений ждёт кадра Сверки. Понятные ступени вместо скрытой рулетки: за друга, прошедшего первый урок, — 500 монет обоим; за трёх друзей — N дней Plus. N — вариантами 3 / 7 / 14, владелец выберет.
