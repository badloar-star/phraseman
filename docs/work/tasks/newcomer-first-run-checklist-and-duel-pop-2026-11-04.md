## Чек-лист для Сверки (чистая установка, новый аккаунт)

Условие: «новый» включается только когда координатор подставит момент релиза в `RANK_GATES_NEW_USERS_SINCE_MS`; до этого пункты 4–7 ожидаемо «нет приветствия/замков/бонуса».

1. Онбординг: кнопки и карточки вдавливаются (нажатие кита), выбор варианта ставит галочку пружиной; при «Уменьшить движение» — без пружины, но с галочкой.
2. Выбор языка (language_welcome): три шага, кнопка «Продолжить» блокируется до выбора, «назад» работает.
3. Первый запуск не показывает два окна сразу: приветствие B-3 идёт через арбитр окон (`onboardingWelcome`), поверх праздников/опроса его нет.
4. Welcome B-3 показывается один раз на аккаунт; после выхода и входа в ДРУГОЙ новый аккаунт на том же телефоне — снова (своё состояние).
5. Первое завершённое занятие: +500 монет один раз; второе занятие и повторный вход не добавляют; второй новый аккаунт на том же телефоне получает свои +500 один раз.
6. Ярлыки на значке (expo-quick-actions) не мешают онбордингу: пока онбординг не пройден, ярлык «Продолжить урок» не открывает урок мимо онбординга.
7. Переустановка и вход в СТАРЫЙ аккаунт: не «новый» — нет приветствия, замков, бонуса; V2 виден только при ≥1 завершённом занятии.
8. «Сегодня»: выполненная задача ставит галочку пружиной ТОЛЬКО в момент выполнения на этом экране, не при каждом открытии Главной.
9. Промокод принят — значок «поп» и хаптик; отказ — без поп-эффекта. «Обращение отправлено» и итог диагностического теста — «поп».
