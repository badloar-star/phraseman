# Task packet: глянец главной кнопки `.cta` макета — один слой темы для всех главных кнопок

Governance-ID: TG-5DA4D81A607F
Status: In progress
Owner: сессия «4 · ТЕМЫ 2.0» (контур: слой темы главной кнопки)
Related epic/enabler: гейт «приложение = макет», сверка learning-v2-010 (координатор 05.10, предложение Дизайна)

## Outcome

Главные кнопки в «Спокойно-тёмном» плоские, а в макете `.cta` — «жидкий» глянец (kit.css:197: градиент #FFFFFF → --cta 48 % → #E3E2E8, блик 1px по верху, тёмная кромка снизу, мягкая тень). Константы `KIT_CTA_GRADIENT`/`KIT_CTA_SHADOW` в `components/v2/KitLiquidGlass.tsx` нигде не подключены. Делаем один слой `KitCtaGloss` и подключаем его через общий `ThemeAccentFill` (в «Спокойно-тёмном»), чтобы все главные кнопки китов получили глянец разом и одинаково.

## Scope

In scope:
- `components/v2/KitLiquidGlass.tsx` — компонент `KitCtaGloss` (градиент + блик/кромка + тень), цвета от `cta` темы: для `#F2F1F6` — ровно константы макета, для тонированных — та же форма от их `cta`.
- `components/v2/ThemeAccentFill.tsx` — в «Спокойно-тёмном» рисует `KitCtaGloss` вместо «ничего».
- Подключение к главным кнопкам, которые сейчас идут мимо слоя: окно занятия Learn «Начать» (`components/LearningV2SessionOutcomeSheet.tsx`, learning-v2-010), `PracticeCta` (`components/practice/PracticeStates.tsx`, всегда цвет `cta`), «Друзья» (`components/friends/FriendsGlassKit.tsx` — свой самодельный градиент заменяется общим слоем, без разнобоя).
Out of scope: `V2Button` (4 места, палитра V2 без уровня темы — отдельно), десятки экранов с самодельной заливкой `accent`, «Акцент»/«Максимум»/светлое (там уже фактура темы `accentGradient` — не меняется).

## Architecture

Один источник: `ThemeAccentFill` (уже стоит в китах Карточек, Диалогов, Друзей, Learning V2) + `KitCtaGloss`. Слой — первым ребёнком кнопки, `pointerEvents="none"`, статичен (ноль работы после кадра). Внутренние блики — отдельным видом поверх градиента (иначе градиент их перекроет); наружная тень — на внешнем виде слоя (обрезается, если у кнопки `overflow: hidden` — тогда только без тени).
