# Task packet: журнал [LESSON-COINS] — монеты после урока (№80/№72)

## Outcome
Единая цепочка журнала `[LESSON-COINS]` по завершению урока: вход, откуда взят номер прохождения, решение «+3/+2/+1», локальное начисление до/после, отправка на сервер, время гидратации (где уходят «10 секунд»), все ранние выходы и ошибки, что показал экран итога. По журналу можно сказать, почему на итоге 0 монет и где ожидание.

## Scope
- Новый `app/lesson_coins_log.ts` (одна функция записи в консоль и в `DebugLogger`).
- Точечные вставки журнала в `hooks/usePracticeRunes.ts` (гидратация, решение, зачёт) и `app/lesson_complete.tsx` (вход, показ). Логика начисления не меняется.
- Тест-сторож `tests/lesson_coins_3_2_1_2026_11_05.test.ts` на функцию решения 3/2/1 и на наличие журнала на всех ранних выходах.

## Architecture
`practiceRuneAwardForPass(passNumber)` уже решает 1→3, 2→2, 3+→1. Журнал показывает три источника номера прохода (маркер зачёта, журнал экономики, накопитель) и победителя. Префикс `[LESSON-COINS]` для поиска одним запросом; релизная сборка вырезает `console.log`, поэтому запись дублируется в `DebugLogger` (переживает релиз).

## Security and privacy
В журнал попадают идентификатор урока, номера, суммы и время; идентификатор пользователя не пишется, ключ сессии обрезается.

## Technical debt
