## Outcome

При DIALOGS_SCENE_V2_ENABLED список диалогов под сценой — карточки ДИАЛОГОВ (мир, название, «N целей · первая: …», собеседник внутри, ✓ у пройденных, замок и «Откроется на ранге N» у закрытых) и фильтр миров («Все» + миры).
Список берётся из той же проекции каталога, что у контейнера хаба — новых чтений нет. Без флага список прежний (DialogueV2CatalogueSection).
Следующий диалог на сцене — первый ОТКРЫТЫЙ непройденный; если открытых нет (всё пройденное или закрыто по рангу) — сцена без кнопки «Начать» с честным текстом.

## Scope

- components/dialogs/scene/dialogs_scene_hub_model.ts — сборка карточек из строк каталога и снимка текстов.
- components/dialogs/scene/DialogsScenePanel.tsx — карточка «закрыто», кнопка «Показать ещё», режим внутри списка (без наезда на сцену).
- components/dialogs/scene/DialogsSceneCatalogue.tsx — панель на данных каталога: фильтр миров, постраничный показ (по 8) — список не рисуется целиком.
- components/dialogs/scene/dialogs_scene_copy.ts, DialogsSceneStage.tsx — тексты «Все», «Показать ещё», «Пока всё открытое пройдено»; кнопка может отсутствовать.
- components/dialogs/DialogueV2CatalogueContainer.tsx, components/DialogsTabContent.tsx, app/ai_dialog_home.tsx — один проп sceneCatalogue (под флагом), в остальном контейнер не меняется.
- tests/dialogs_scene_catalogue.test.ts.

## Architecture

Контейнер хаба уже держит проекцию каталога (items со статусом available/done/locked, миры); при sceneCatalogue он отдаёт её в DialogsSceneCatalogue вместо секции. Тап по карточке — тот же onPressItem (замер, прогрев, брифинг).
Без нового чтения каталога и без новых запросов. Список постраничный (8 карточек + «Показать ещё»), фильтр миров — локальное состояние, мгновенно.
