## Outcome

## Scope

In scope: новый сторож `tests/classic_translation_layer_qa.test.ts` (чтение JSON, без записи в слой); отчёт `docs/work/release/COURSE_LAYER_QA_2026-11-05.md`; сообщения Переводчику.
Out of scope: правка самого слоя (его правит только Переводчик — одновременная правка ломает коммиты); правка курсов и кода приложения; переводы сами по себе.

## Architecture

Граница: слой JSON (только чтение) → сторож. Формат ключа: `<lang>:<LL>.<PP>` (LL — урок, PP — фраза). Служебный ключ `_note` исключён. Новые зависимости не добавляются.

## Security and privacy

Не применимо: читаются локальные файлы репозитория, персональных данных и сетевых вызовов нет.

## Technical debt

- Contain: 365 записей без ru и 171 без uk — сторож фиксирует их как известное состояние (список-ratchet), новые пропуски ломают сборку. Владелец: Переводчик; выход — Переводчик подтверждает, что частичные записи намеренны (консьюмер сливает с базой), или дописывает недостающий язык.
- Accept temporarily: ru==uk в одной записи (en:23.49) — оба варианта корректны по смыслу, не блокирует.
