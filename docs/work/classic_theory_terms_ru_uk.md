## Правила для проверки глав (на вычитке)

1. Обращение — «вы» / «ви» везде, где адресат; «ты» / «ти» только в примерах, где говорит персонаж в диалоге.
2. Калькуры: «первая вспомогательная» вместо «первое вспомогательное» — писать «перше допоміжне дієслово» (uk) и «первый вспомогательный глагол» (ru).
3. Не оставлять U+200B (нулевой пробел) и оборванные предложения.
4. Не смешивать «подлежащее» и «субъект», «дополнение» и «объект» — только первые слова из таблицы.
5. Если в uk стоит не-термин из столбца «не писать» — правка по этой таблице.
