# PM-223 — стоимость до и после 2.0 по операциям (оценка по коду)

Дата: 2026-10-01. Решение владельца R8: оценка **только по коду**, прод-цифр (Billing, Cloud Monitoring,
OpenAI Usage) эта оценка не содержит. «До» — клиент 1.6.x и сервер на `0b9b33a4e`/облачный список
PM-007; «после» — эта ветка (`feature/referral-roulette`). Денежные цены — параметры: OpenAI берётся
из таблицы в коде (`functions/src/openai_budget_dashboard.ts`, `OPENAI_MODEL_PRICES`, $ за 1 млн
токенов), TTS — `CARD_TTS_USD_PER_1K_CHARS = 0.015` (`card_tts_core.ts`). Цены Firestore / Functions /
Storage / egress подставляются из прайса Google на дату расчёта — в коде их нет, выдумывать не будем.

**Ноль евро не обещается (A3).** Даже при нуле пользователей 2.0 платит за: ~20 живых кронов
(Cloud Scheduler + вызовы + чтения пустых выборок), хранение данных и индексов Firestore, хранение
сборок функций, озвучку карточек при одобрении наборов, алерты и Jarvis (OpenAI раз в сутки).

## 1. Операции: до → после (A1)

Обозначения: R — чтения документов Firestore (пустой запрос = 1 чтение), W — записи, D — удаления,
IX — записи индексов (каждая W/D трогает индексы своих полей), ST — хранение, EG — исходящий трафик,
FN — вызовы функций, AI — платные запросы OpenAI. «unknown» — по коду не определить без замера.

## 3. Что нужно владельцу для реальных цифр (вне кода, R8)

- Billing → отчёт по сервисам за месяц до релиза и за месяц после: Firestore (R/W/D, хранение),
  Cloud Functions (вызовы, CPU/память), Cloud Scheduler, Storage, сеть.
- OpenAI Usage по проекту и модели; сверить с `openAiBudgetDashboard` (billing-коллекции по операциям).
- Число документов в коллекциях лиг/Арены/подарков/XP — из пробного прогона D90.
- Число знаков всех карточек для D128 — до запуска массовой озвучки.

## 4. Статус критериев

- **A1** — операции перечислены по всем категориям (R/W/D/IX/ST/EG/FN/AI) с направлением изменения и
  источником в коде; где по коду нельзя — честное unknown.
- **A2** — миграции вынесены отдельной таблицей §2.
- **A3** — «ноль евро» явно не обещан (вступление и §1: фоновые кроны стоят денег при нуле пользователей).
