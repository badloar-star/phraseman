# Покрытие объяснений первого входа

Это финальная карта решения владельца: где одноразовое объяснение действительно
помогает первому действию, а где его не нужно добавлять поверх уже понятного
экрана, конкретной инструкции или существующего контекстного состояния.

## Встроены в приложение

| Раздел | Когда показывается | Формат |
| --- | --- | --- |
| Карточки | первый вход в хаб карточек | невесомость |
| Статистика | первый вход в статистику | невесомость |
| Фраза дня | первое открытие карточки дня | невесомость |
| Видео | первый вход в видео | кино-премьера |
| Друзья | первый вход в раздел друзей | невесомость |
| Арена | первый вход в Арену | кино-премьера, заменяет прежнее знакомство |
| Лига | первый вход в Лигу | короткая кино-премьера; подробные правила остаются по запросу |
| Свайп карточек | перед первым режимом свайпа | невесомость |
| Аудирование | перед первым выбором набора | невесомость |
| Устная тренировка | перед первым выбором набора | невесомость |
| Блиц | перед первым выбором набора | невесомость |
| ИИ-диалоги | перед первым разговором | мини-комикс внутри существующего согласия |
| Работа над ошибками | в существующем окне выбора объёма | кино-премьера |

## Намеренно без нового авто-приветствия

Эти сценарии уже объясняются в момент действия, имеют собственную задачу или
сохранены как `keep` в утверждённом UX-аудите. Новый авто-модал здесь ухудшил бы
первый вход, дублировал бы текст или затронул бы неутверждённую механику.

| Сценарий | Решение |
| --- | --- |
| Уроки и теория | сохраняем контекстные подписи и текущую структуру урока; не перекрываем обучение приветствием |
| Достижения и мои наборы | понятные пустые состояния и существующие действия вместо отдельной заставки |
| Сезон, подарки, ранги Арены | сохраняем существующие инструкции и результаты, чтобы не подменить правила соревнования |
| Экзамен уровня | сохраняем существующую инструкцию экзамена |
| Магазин жемчужин и платный доступ | не меняем: пейволы, цены и доступ вне утверждённого объёма |
| Промокод, аватар, опрос | оставляем их собственные формы и контекстные подсказки; нет безопасного универсального первого действия для общей заставки |

## Проверяемая граница

Карта основана на [утверждённом внедрении](APPROVED_UX_IMPLEMENTATION_2026-09-08.md)
и на исходном списке сцен `.superpowers/brainstorm/feature-intros/ux-review/scenes.cjs`.
Это не означает, что остальные пользовательские модалы должны стать одноразовыми
интро: для них остаются контекстный текст или действующее окно.
