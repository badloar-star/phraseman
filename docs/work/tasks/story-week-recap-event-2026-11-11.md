## Outcome

Участник Пика в начале новой недели получает личную историю «Твоя неделя»: минуты по дням, уроки, минуты и дни серии
— из уже посчитанной на телефоне активности, монеты — из итога недели Пика. Бесплатному аккаунту следом идёт кадр
«Итог недели на одной странице» с кнопкой «Посмотреть Plus».

Кто в Пике не участвовал, истории недели НЕ получает: честного числа монет за неделю у него нет (решение владельца —
монеты Пика), а кадр «Твоя неделя» без плитки монет — это изменение утверждённого кадра, ему нужен макет.

## Scope

In scope:
- новый `modules/story_events/week_recap_story.ts` — сбор данных недели и запись события;
- `modules/story_events/story_events_core.ts` — тип `week_recap` (сохраняемый), ключ `week_recap:<понедельник>`;
- `modules/story_events/story_event_sources.ts` — одна строка в `recordSpireWeekStory` (новых мест вызова нет);
- `modules/story_events/plus_offer_stories.ts`, `components/stories/templates/story_plus_offer_from_event.ts` — кадр недели;
- тесты `tests/story_week_recap_event_2026_11_11.test.ts`, правки двух тестов историй-предложений.

Out of scope: кадр «Твоя неделя» (шаблон не менялся); истории недели для тех, кто не в Пике; серверная часть Пика.

## Architecture

Момент записи — когда приложение получило итог прошлой недели Пика (`recordSpireWeekStory`, уже зовётся из трёх мест):
там есть и факт «неделя закрыта», и монеты недели. Активность читается из локальной аналитики (`loadActivity365Analytics`,
только AsyncStorage) лениво и один раз за запуск на неделю. Неделя — та же, что у Пика: понедельник–воскресенье по UTC.
Пустая неделя (ни минут, ни уроков) истории не даёт. Кадр-предложение по-прежнему не хранится — выводится из события.

## Security and privacy

Новых данных нет: в событие ложатся числа активности, которые телефон уже считает, и монеты недели Пика из уже
прочитанного итога. Новых чтений Firestore нет. На сервер ничего не уходит.

## Technical debt

- Accept temporarily: дни активности на телефоне ведутся по местной дате, а неделя Пика — по UTC; у часовых поясов,
  далёких от UTC, крайний день недели может сместиться на один. Владелец — эта сессия; exit — если заметят расхождение.
- Accept temporarily: не участвующие в Пике истории недели не получают. Exit — решение владельца о кадре без монет.
