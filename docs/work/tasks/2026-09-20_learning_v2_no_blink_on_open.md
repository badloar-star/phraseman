# Learning V2 — раздел не моргает при открытии

Governance-ID: TG-EB23829F2B10
Governance-ID: TG-A2CE5028ACFE

## Outcome
Открытие раздела Learning V2 показывает карту ОДИН раз, с единственной
анимацией входа, которая была прописана для входа в раздел. Никаких
потушений, пустых кадров и повторного проигрывания вступления. Модал
«Founder Pass» появляется ОДИН раз на пользователя и показывается ПОВЕРХ
уже открытого и отрисованного раздела, ничего не пряча и не вызывая
повторного открытия.

## Scope
- `app/(tabs)/lessons.tsx` — гейт рендера карты, сброс чека по focusTick,
  дев-счётчики входа.
- `app/learning_v2_release_intro_receipt_v1.ts` — поле `revealCourse`.
- `components/learning-v2/LearningV2PulseCourse.tsx` — анимация входа.
- `tests/learning_v2_founder_pass_contract.test.ts` — контракт гейта.

## Architecture
Модал перестаёт быть условием показа курса. `revealCourse` всегда `true`
при активном разделе: карта монтируется сразу при `page === "v2"` и больше
не размонтируется, пока раздел открыт. Чек о показе модала читается, не
сбрасывая уже показанную карту — сброс `receipt` в `null` на каждый фокус
удаляется, вместо него сравнение по accountScopeHash. Дев-счётчики входа
удаляются целиком: они дважды давали баг «модал вернулся после закрытия».

## Security and privacy
Данных не добавляет и не передаёт. Чек показа модала остаётся локальным
(AsyncStorage), ключ по-прежнему скоупится хэшем аккаунта. Смена аккаунта
по-прежнему не переиспользует чужой чек — сравнение идёт по
accountScopeHash. Privacy policy правок не требует.

## Technical debt
Убирает `revealCourse` как условие показа и пустую заглушку
`learning-v2-founder-pass-gate`. Снимает дев-ветку счётчиков входа.
Контрактный тест перестаёт требовать сокрытие курса — он сторожил ровно ту
ложь, которая вызывала моргание.
