# Англійська · Урок 8 · Заняття 15 — Прання й прибирання вдома

**Ситуація.** Знайдіть потрібні речі для прання й миття посуду.

**Що ви опануєте:** can, whose
**Нові слова:** clothes airer, tumble dryer, laundry bag, dishwasher tablet

## Інтро 1

### Висушити білизну

Clothes airer — сушарка-стійка для білизни, без мотора; tumble dryer — сушильна машина. I can use the clothes airer — я можу скористатися сушаркою-стійкою. Виберіть стійку.

**Виберіть фразу для цієї ситуації.**

- ✅ **I can use the clothes airer.**
- ❌ I can use the tumble dryer. — *Тут інший зміст або неправильне питальне слово. Потрібно: I can use the clothes airer.*
- ❌ I can uses the clothes airer. — *Після can дієслово без to й s.*

---

## Інтро 2

### Чий мішок?

Laundry bag — мішок для білизни. Whose laundry bag is this? — Чий це мішок для білизни? Повторюємо whose: запитуємо про власника.

**Виберіть фразу для цієї ситуації.**

- ✅ **Whose laundry bag is this?**
- ❌ Who laundry bag is this? — *Тут інший зміст або неправильне питальне слово. Потрібно: Whose laundry bag is this?*
- ❌ Whose laundry bag are this? — *Один мішок: is this.*

---

## Інтро 3

### Помити посуд

Dishwasher tablet — таблетка для посудомийної машини. I can find a dishwasher tablet — я можу знайти таблетку для посудомийної машини. Виберіть цю фразу.

**Виберіть фразу для цієї ситуації.**

- ✅ **I can find a dishwasher tablet.**
- ❌ I can’t find a dishwasher tablet. — *Тут інший зміст або неправильне питальне слово. Потрібно: I can find a dishwasher tablet.*
- ❌ I can to find a dishwasher tablet. — *Після can дієслово без to й s.*
