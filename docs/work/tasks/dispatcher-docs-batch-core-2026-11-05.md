# Task packet: пакет документов «Ядра» по поручению диспетчера (05.11)

## Outcome
Четыре справочных документа, без кода, без деплоя, без удаления: (1) сквозной сценарий удаления аккаунта №3 для «Эмулятора»; (2) отчёт «где Firebase тратит больше всего и как срезать»; (3) список удаления «Памяти диалогов» и «Умной очереди»; (4) опись «старые функции к удалению».

## Scope
Только новые файлы в `docs/work/release/`. Чтение кода и конфигурации. Никаких изменений в `functions/`, `app/`, правилах и индексах.

## Architecture
Документы собираются из кода: этапы `accountDelete*` (`functions/src/account_delete.ts`), список экспортов `functions/src/index.ts`, места чтений/записей Firestore и плановые функции. Каждая цифра отчёта указывает файл и строку.

## Security and privacy
В документы не попадают идентификаторы реальных пользователей, ключи и токены. Тестовый аккаунт №3 называется только номером.

## Technical debt
Отчёт о стоимости основан на коде, а не на счёте Google Cloud (доступ к Cloud Monitoring у «Ядра» закрыт, см. бэклог). Цифры читаемые из кода (частоты cron, размеры пачек) — оценки сверху.

## Verification
Каждый список проверен поиском по репозиторию (кто вызывает, кто экспортирует). Документы закоммичены отдельным коммитом; хэш сообщается диспетчеру.

## Rollback
Удалить файлы документов; на работу приложения они не влияют.
