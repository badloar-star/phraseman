# Гейт «готово» — СТРОГО (владелец, 04.10.2026)

Дословно: «СТРОЖАЙШЕ ЗАПРЕЩЕНО ГОВОРИТЬ СДЕЛАНО, пока я не получу сравнение КАЖДОГО экрана с макетом, доведённого до точнейшего соответствия».

## Правило для любой сессии, переносящей экран в приложение
1. Слова «готово», «сделано», «готов к склейке» по экрану запрещены, пока не выполнено ВСЁ ниже.
2. На эмуляторе сделан снимок экрана приложения и положен рядом со снимком макета (одна картинка слева-справа), оба в одном размере.
3. Различия найдены глазами и исправлены; снимок переснят после последней правки кода.
4. В `docs/phraseman-2.0/registries/visual_parity.json` у строки заполнены `code`, `evidence` (путь к картинке сравнения), `evidence_at`, `evidence_sha256`.
5. `node scripts/port_ready_gate.mjs <id строки>` возвращает код 0. Если не 0 — докладывать «готово» нельзя.
6. Владельцу показывается сама картинка сравнения. Без неё отчёт «сделано» недействителен.

Финальное решение «match» остаётся за координатором и релиз-гейтом (`scripts/visual_parity_gate.mjs`); этот гейт лишь запрещает докладывать о готовности раньше времени.
