## Outcome

На карте V2 у каждого урока (1–8) и каждой главы (1–7) своя рисованная иконка. Плашка главы — со своим лёгким узором и оттенком. Состояния главы: открыта; пройдена (галочка в углу); закрыта (приглушена + замок в углу). Тёмные и светлые темы читаются, прокрутка карты не тормозит.

## Scope

В объёме (новые файлы): components/learning-v2/icons/learningV2IconData.generated.ts (фигуры иконок и узоров из макета), components/learning-v2/icons/learningV2IconHue.ts (оттенки OKLCH→sRGB по теме), components/learning-v2/icons/LearningV2Glyph.tsx, LearningV2ChapterTile.tsx, LearningV2ChapterPattern.tsx; scripts/gen_learning_v2_icons.mjs (генератор); tests/learning_v2_icons_contract.test.ts (сторож покрытия).
Правка чужого файла: components/learning-v2/LearningV2ChaptersCourse.tsx — только плитка главы, слой узора в карточке главы, иконка урока в строке темы (по согласованию с Дизайном).
Вне объёма: уроки 9–32 (фолбэк: прежний значок), узлы занятий, классический курс, контент курса.

## Architecture

Источник правды рисунков — макет learning-v2-icons.html. Генератор переводит строки SVG в структуры для react-native-svg, без разбора разметки на телефоне. Узор — Pattern + Mask с линейным градиентом (тает к тексту), один Svg на карточку, без изображений. Компоненты memo по (урок, глава, состояние, цвета). Оттенок: тон по номеру главы/урока, светлота и насыщенность — по тёмной/светлой теме палитры. Фолбэк: нет данных урока → прежняя плитка Ionicons.
