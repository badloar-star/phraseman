# Урок 27 · Заняття 12 — Пояснити самопочуття

**Ситуація.** Ви називаєте відчуття, розповідаєте про час і домовляєтеся про прийом.

**Що ви опануєте:** сказати, що було б, якби…: I have nausea.
**Нові слова:** nausea, heartburn, nosebleed, insomnia

## Інтро 1

### Якби був запис на сьогодні

Ви можете прийти до клініки сьогодні, але запису поки немає. Поясніть: I would come today if I had an appointment — я б прийшов сьогодні, якби мав запис на прийом. Would come — уявний результат; if I had an appointment — умова зараз. Складаємо речення: I + would come + today + if I had an appointment — хто, що зробив би, коли, за якої умови. Після would потрібна come; в умові had без would.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would come today if I had an appointment.**
- ❌ I would came today if I had an appointment. — *Після would потрібна початкова форма come.*
- ❌ I would come today if I would had an appointment. — *В умові had без would.*

---

## Інтро 2

### Коли записали час

Ви записали час кількох подій, і співрозмовник запитує, коли зробили ці нотатки. Дайте відповідь: I wrote them down yesterday — я записав їх учора. Wrote — минула форма write. Them замінює the times і стоїть між wrote та down. Yesterday називає завершений час; have не потрібне. Складаємо речення: I + wrote + them + down + yesterday — хто, wrote, що записав, down, коли.

**Виберіть фразу для цієї ситуації.**

- ✅ **I wrote them down yesterday.**
- ❌ I have written them down yesterday. — *Із yesterday тут форма минулого.*
- ❌ I writed them down yesterday. — *Минула форма write — wrote.*

---

## Інтро 3

### Порадити поставити нагадування

Друг боїться забути час прийому. Порадьте: If I were you, I would set a reminder — на твоєму місці я б поставив нагадування. If I were you вводить пораду; set a reminder — поставити нагадування. Складаємо речення: If I were you, + I would + set + a reminder — на твоєму місці, я б, дія, що поставити. Після умови ставимо кому. Після would потрібна set без to й без -ing.

**Виберіть фразу для цієї ситуації.**

- ✅ **If I were you, I would set a reminder.**
- ❌ If I were you, I would setting a reminder. — *Після would потрібна початкова форма set.*
- ❌ If I were you, I would to set a reminder. — *Після would не ставимо to.*
