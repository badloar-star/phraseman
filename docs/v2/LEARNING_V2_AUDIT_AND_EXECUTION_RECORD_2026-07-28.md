# Learning V2 — точный аудит и запись для продолжения

**Статус на 28 июля 2026:** аудит завершён; код приложения намеренно не менялся. Этот документ — самостоятельная точка продолжения: он фиксирует факты репозитория, уже принятые решения владельца, противоречия, порядок работ и вопросы, которые ещё нельзя угадывать.

## 1. Что должно получиться

Learning V2 — не новый курс и не набор «красивых экранов». Это новый способ проходить **существующие 32 урока**. Он обязан сохранить и переиспользовать:

- все 32 урока, 1 600 фраз (по 50 в уроке), переводы и локали;
- интро и теорию каждого урока;
- лексику, словари, неправильные глаголы и их отдельные тренировки;
- все фразы уроков, ошибки, повторение и активное воспроизведение;
- личные планы, включая их дополнительные задания на карте сессий;
- генератор администратора: он должен создавать данные для обязательных сессий и дополнительных заданий личного плана — фразы, отвлекающие ответы, объяснения, аудио-цели и связи с контентом.

Нельзя заменить это демонстрационными данными, сократить уроки или сделать V2 параллельной «игрушечной» веткой. Новая форма должна работать поверх реального контента и сохранять учебный смысл.

## 2. Решения владельца, уже принятые

| Тема | Решение |
|---|---|
| Энергия | Полностью убрать. Не скрыть, не обнулить на экране — удалить механику после отдельного плана миграции и регрессионной проверки. |
| Первая сессия | Бесплатна. |
| Последующие сессии | Открываются за звёзды; цена растёт по заранее видимой лестнице. Правило точных 80% отменено: цена одного и того же идеального задания не меняется от сессии к сессии. |
| Базовая награда за идеальную сессию | В сессии 12 заданий; каждое идеальное задание даёт 3 звезды. Итого идеальная сессия даёт 36 базовых звёзд. |
| Как добирать звёзды | Серия, повторная практика, а также доступные платному пользователю задания личного плана, турниры и другие утверждённые активности; не таймер и не энергия. Бонусы идут сверх честной награды за задания. |
| Ограничение роста цены | После 5–6 сессий за день кривая упирается в потолок. |
| Если звёзд не хватает | Повторять завершённые сессии без таймера. |
| Размер сессии | 12 заданий/карточек; старое правило 7–9 карточек устарело. |
| Награда за качество | За конкретное задание: 3 — с первой попытки без подсказки; 2 — со второй; 1 — с подсказкой или после ошибки; 0 — пропуск. |
| Прозрачность закрытой сессии | На закрытой карточке видны цена и тренируемое умение; число звёзд за идеальное прохождение заранее не показывается. |
| Стартовый баланс | 0 звёзд: первая сессия бесплатна, дальнейшие звёзды нужно честно заработать. |
| Источники недостающих 20% | Серия и качество, повторная практика, а для платного пользователя также доступные дополнительные активности: задания личного плана, турниры и другие утверждённые активности. Все источники должны быть видны и объяснены. |
| Ошибки и цена | Ошибка не увеличивает цену следующей сессии: меняется только полученная награда. |
| Идеальное прохождение | Все 12 заданий с первого раза и без подсказок; технически неопределённый результат микрофона не объявляется ошибкой пользователя. |
| Звёзды за одно задание | 3 — с первой попытки без подсказки; 2 — со второй попытки; 1 — с подсказкой или после ошибки; 0 — пропуск. |
| Бонусы серии | Есть два независимых, отдельно показанных бонуса: за идеальную серию заданий в сессии и за серию дней обучения. |
| Лестница цен | Цена растёт по заранее видимой лестнице: 0 → 45 → 50 → 55 → 60 → 65, затем не растёт. Пауза на несколько дней ничего не сбрасывает; лестница не сбрасывается и между уроками, а продолжается по всему курсу. |
| Остаток | Заработанные сверх текущей цены звёзды не сгорают: остаются в едином балансе для будущих сессий или активностей. |
| Дополнительные активности | Карточка личного плана, турнира или иной утверждённой активности заранее показывает цену в звёздах, награду и учебную пользу. Она не заменяет обязательную сессию. |
| Первая сессия | 6 коротких знакомств с новыми фразами (смысл, перевод, звук, пример), затем 6 очень лёгких проверок узнавания. |
| Вторая сессия | Сборка фразы из слов и короткий выбор услышанной фразы: сначала увидеть конструкцию, затем услышать её. |
| Первый голосовой режим | Repeat & Compare появляется после двух сессий, где те же фразы уже увидены, собраны и услышаны. |
| Карта личного плана | Задания активного плана — отдельные боковые карточки между обязательными сессиями; видны сразу и не перекрывают основную дорожку. |
| Слова и неправильные глаголы | Отдельные необязательные боковые тренировки, связанные с уроком и фразами; дают звёзды, но не закрывают обязательные сессии. |
| Третья сессия | Основной голосовой режим Repeat & Compare: образец → произношение → бережная обратная связь. |
| Speed Match | Появляется только после того, как фразы уже увидены, услышаны и проговорены; это быстрая тренировка различения, не знакомство. |
| Ошибка в фразе | Возвращается через 2–3 других задания сначала в облегчённой форме, затем в исходной; после сессии уходит в «Мою практику» по правилам приложения. |
| Повторяющаяся ошибка | После второй ошибки — короткое объяснение, образец и облегчённая версия; переход не блокируется. |
| Голосовой ответ | Технически нераспознанная запись не является ошибкой. Уверенно распознанное неверное произношение — ошибка и идёт в обычное мягкое повторение. |
| Теория и интро | Теория появляется только перед первым нуждающимся в ней заданием; используется точный формат существующего удачного интро: компактно, с раскрытием подробности. |
| После голоса | После Repeat & Compare идёт Context Gap: знакомая фраза применяется в понятной жизненной ситуации. |
| Объяснение ошибки | Одно короткое человеческое объяснение, почему вариант не подходит и почему правильный естественен; допустима лёгкая добрая ирония, но без насмешки и грамматического перегруза. |
| «Моя практика» | Начинается с облегчённого узнавания/выбора, затем возвращает к сборке или голосовому формату — по месту исходной ошибки. |
| Карточка личного плана | Сразу показывает цель, цену в звёздах, возможную награду и тренируемое умение. Открывается только после появления нужных учебных предусловий. |
| Турниры | Вне области этой переделки: у турниров свой генератор и отдельный пул фраз. Турнирные задания не появляются на карте урока и не используют её контентную логику. Честно заработанные в турнире звёзды можно использовать для открытия уроков. |
| Карта урока и план | На карте одна основная дорожка обязательных сессий с дополнительными заданиями личного плана. Турниры на эту карту не выводятся. |
| Нет активного плана | На карте нет пустого места, заглушки или рекламной карточки: остаётся чистая основная дорожка урока. |
| План и словари | План может дать задание на неправильные глаголы или словарь, если оно связано с целью плана, текущим уроком или ошибками; карточка объясняет связь. |
| Текст карточки плана | Человеческая причина и польза, а не техническое название режима: например, «Закрепим фразы для встречи». |
| Дополнительные задания плана | Открываются за звёзды: до открытия видны цена, награда и учебная польза. На одной карте одновременно максимум две такие карточки. |
| Открытое задание плана | Остаётся доступным без срока, пока не пройдено или не заменено более важным заданием до открытия. |
| Неподходящее задание плана | Не показывается, пока не пройдены нужные слова и фразы. |
| Источник фраз для плана | Сначала — фразы из цели плана и уже пройденных уроков, затем — ошибки и актуальное повторение. |
| Генератор плановых заданий | Создаёт задания один раз для каждого языка как выстроенную, проверяемую учебную систему; это не случайная генерация для каждого человека. Личный план только выбирает подходящие карточки из утверждённого языкового пула. |
| Недопустимое дублирование | Генератор личного плана не создаёт задание на фразу, которая уже есть в основной цепочке сессий урока. Это жёсткий контентный запрет, который обязан проверяться до выпуска. |
| Основа планового пула | Отдельный пул строится от конкретной цели плана: работа, переезд, путешествия, собеседования и т. п.; он не является копией основной 32-урочной цепочки. |
| Смена цели плана на карте | Плановые кружочки и карточки старой цели исчезают с карты: она полностью перестраивается под новую цель с нуля. История планов хранится отдельно. |
| Новая плановая карточка на карте урока | Может стоять боковой карточкой рядом с подходящей сессией, если человек уже готов к её отдельному материалу; связь объясняется человеческим текстом. |
| Уже открытое старое задание | После смены плана не отбирается: остаётся доступным с пометкой прежней цели, так как за него уже потрачены звёзды. |
| История нескольких планов | Каждый план — отдельная активная/завершённая дорожка с датами, результатами и фразами; разные цели не склеиваются в один процент. |
| Старые ошибки плана | После смены цели остаются в «Моей практике», но не возвращаются на карту нового активного плана. |
| Объём задания плана | 3–5 новых фраз как маленькая тематическая сцена; сначала знакомство со всеми, затем подходящие режимы — слух, сборка, контекст, при необходимости голос. |
| Прерывание задания плана | Незавершённая попытка начинается заново; уже открытый за звёзды узел остаётся доступным без новой оплаты. |
| Финал задания плана | Короткий результат, звёзды и одна понятная фраза о пользе для цели; без большой церемонии урока. |
| Связь с основным уроком | Известное слово или конструкция из урока может быть опорой, но главная фраза и учебная задача задания плана должны быть из отдельного планового пула. |
| Объём карточки плана | Может включать несколько новых плановых фраз и их отработку в нескольких уместных режимах; это отдельная учебная единица, не копия одного задания основной цепочки. |
| Неполные данные | Если нет качественных отвлекающих вариантов или объяснения, карточка не выпускается: генератор помечает недостающее для администратора. |
| Режимы для одной фразы | В основном пути фраза получает одно основное подходящее задание, а не обязательное повторение во всех режимах. Повторные форматы назначаются только по ошибкам и расписанию повторения. |
| Предпросмотр администратора | До публикации видны: урок, фраза, режим, правильный ответ, отвлекающие варианты, объяснение, аудио/произношение и связь с личным планом. |
| Голосовая непригодность | Если фраза не подходит для голосового режима, карточка голоса для неё не создаётся; выбирается подходящий режим, без выдумывания цели произношения и без удаления фразы из урока. |
| Исправление контента | Исправление фразы, перевода или объяснения выпускается новой версией языкового пула; путь уже начавшего человека не ломается и получает понятное обновление. |
| Выбор плановой карточки | Цель плана → уже пройденный материал → ошибка/слабое место → актуальное повторение → доступность по звёздам. |
| Ритм одной сессии | У сессии один главный режим; максимум 2–3 задания могут быть поддерживающими, только если они готовят к главному. |
| Пятая сессия | Возвращает знакомые фразы через другой, немного более сложный контекст, а не добавляет сразу много новых. |
| Ввод фраз | Небольшими волнами: первая группа в сессиях 1–4, следующая — после закрепления первой, затем смешанное повторение. |
| Старые ошибки в обязательной сессии | Могут появляться только как дополнительные слоты, если поддерживают текущую цель. Они никогда не заменяют 12 обязательных заданий текущего урока; иначе остаются в «Моей практике». |
| После двенадцатой сессии | Короткая понятная финальная проверка и церемония результата; незакреплённое уходит в «Мою практику», урок остаётся доступен для улучшения. |
| Дополнительные слоты ошибок | После 12 обязательных заданий можно добавить максимум два слота старых ошибок. Они не влияют на идеальность текущей сессии, могут дать отдельные звёзды и не мешают пройти основной путь. |
| Пройденная карточка карты | Остаётся на основной дорожке с лучшим результатом, заработанными звёздами и действием «улучшить». |
| Повтор сессии | Допустим без лимита. Награда за каждое повторное идеальное полное прохождение не превышает 20% цены следующей сессии; «Моя практика» для этого не используется и на карте не показывается. |
| Где добирать звёзды | Не на карте урока: доступные способы находятся в отдельном разделе/экране баланса. |
| Доступ к плановым заданиям | Только у платного пользователя; ежедневного лимита нет. |
| Идеальное задание плана | Даёт свои звёзды и усиливает серию, но никогда не повышает лучший результат обязательной сессии. |
| Награда повторной сессии | Идеально — 20% цены следующей сессии; хорошо — 12%; с ошибками — 5%; с пропусками — 0%. |
| Идеальный повтор | Все 12 обязательных заданий текущей версии сессии с первой попытки и без подсказок; дополнительные слоты не снижают результат. |
| Кошелёк звёзд | Показывает текущий баланс и статистику **только начислений**: урок, повтор, план, словарь, неправильные глаголы, турнир. Траты в кошельке не ведутся, ближайшая цена не показывается. |
| Подписка и план | При окончании подписки карточки плана остаются видимыми, но недоступными до возврата подписки; прогресс и результаты сохраняются. |
| Ошибка в задании плана | Та же мягкая логика: объяснение, облегчённое возвращение, затем «Моя практика» по правилам приложения; звёзды считаются только по качеству этого задания. |
| Баланс звёзд | Один общий баланс на аккаунт для всех изучаемых языков. |
| Карта 12 сессий | Три главы по четыре сессии: «Понять», «Применить», «Закрепить». Ярко выделены текущая и следующая; дальние карточки видны, но приглушены. |
| Визуальная форма карты | Не прямоугольные карточки, а объёмные анимированные кружочки-узлы на пути, по ощущению как у Duolingo. Основные сессии, дополнительные задания и личные планы показаны такими узлами на одной дорожке; различаются смыслом и состоянием. |
| Пройденный узел | Заполненный объёмный кружок с маленькими звёздами результата; открывает просмотр и действие «улучшить». |
| Текущий узел | Мягко «дышит» и слегка приподнимается без яркого мигания. |
| Закрытый узел | Объёмный, но приглушённый; видны смысл сессии и цена. |
| Узел личного плана | Та же объёмная форма с отдельным аккуратным знаком и короткой подписью цели рядом. |
| Главы карты | Границы «Понять / Применить / Закрепить» обозначены небольшой надписью и сменой ритма пути, без тяжёлых рамок. |
| Геометрия пути | Вертикальная дорожка с лёгкими изгибами между узлами. |
| Нажатие на пройденный узел | Короткий нижний лист: результат, чему учились, действие «улучшить». |
| Нажатие на текущий узел | Короткий нижний лист: название, смысл и действие «начать». |
| Позиция карты | Запоминается между возвратами; после результата карта один раз мягко переходит к новому текущему узлу. |
| Обычное касание | Лёгкое уменьшение, короткий тактильный отклик и возврат в объёмную форму. |
| Открытие следующего узла | Звёзды мягко перелетают к нему, путь подсвечивается, узел раскрывается пружинящей анимацией. |
| Reduced motion | Полёты и пружины заменяются коротким спокойным появлением без скачков. |
| Звук карты | Очень короткий мягкий звук при открытии/прохождении; выключается общей настройкой звука. |
| Завершение узла плана | Спокойный микро-финал и отметка на пути, без большой церемонии урока. |
| Офлайн-карта | Показывает сохранённую карту и открытые офлайн-сессии; рядом спокойный статус отложенного обновления. |

## 3. Реальный нынешний продукт

### Уроки и учебный контент

- `app/lesson_data_all.ts` загружает все 32 урока частями 1–8, 9–16, 17–24, 25–32.
- `tests/lesson_phrases_regression.test.ts` закрепляет 32 × 50 = **1 600** фраз. Проверено: тесты уроков, локалей и grammar map прошли, 25 проверок.
- `app/lesson_grammar_map.ts` хранит грамматические цели и зависимости A1–B2.
- Интро и теория существуют в 32 наборах; типы поддерживают вводные блоки, объяснения, ловушки и интерактивные фрагменты.
- `app/lesson_words.tsx` — отдельный тренажёр слов и ошибок. Неправильные глаголы живут в `app/irregular_verbs_data.ts`, связаны с уроками через `LESSON_IRREGULAR_BASES`, имеют отдельный экран и SRS.
- `app/active_recall.ts` — долговременное повторение: до 300 элементов, SM-2, ошибки из уроков.
- `app/personal_practice_lesson_router.ts` направляет слабое место в подходящую тренировку, учитывая цели и предусловия.

Полный список уроков: To Be; отрицания и вопросы; Present Simple; There is/are; модальные; Past Simple регулярные и неправильные; Future; сравнения; possessives; phrasal verbs; Continuous; imperative; prepositions; articles; indefinite pronouns; gerund; passive; Present Perfect; Past Continuous; conditionals; reported speech; reflexive; used to; relative clauses; Complex Object; финальное повторение. Уроки 25–32 — испанские по текущей регрессии.

### Текущий экран урока и энергия

`app/lesson1.tsx` (около 3 800 строк) — текущий универсальный движок урока. В нём есть интро, теория, озвучка, речь, возврат ошибок и награды. Энергия интегрирована не только в шапку: экран использует `useEnergy`, `LessonEnergyLightning`, проверку перед действиями и ряд соседних систем. Удалять её можно только отдельным целевым изменением с инвентарём всех потребителей и миграцией состояния — не «вырезанием одной полоски».

## 4. Что действительно есть в Learning V2

V2 пока **не подключён к пользователю**. Во вкладке уроков `app/(tabs)/lessons.tsx` он показывается только при `ENABLE_DEV_TOOLS` и это текстовая лабораторная заглушка `components/learning-v2-lab/LearningV2ModesLab.tsx`. Реальные мобильные экраны, хранение прогресса и подключение к 32 урокам ещё не сделаны.

Вокруг заглушки уже существует серьёзный контрактный фундамент:

- `modules/learning-v2/content/session_compiler.ts` — детерминированно собирает 12 сессий;
- `modules/learning-v2/contracts/activity.ts`, `content_item.ts`, `session.ts` — строгие форматы заданий и трассировка каждого задания к реальному контенту;
- `modules/learning-v2/contracts/stars.ts`, `progress/gate_policy.ts` — звёзды, доступ, контрольные точки;
- `modules/learning-v2/contracts/optional_practice.ts` — дополнительные тренировки;
- `modules/learning-v2/authoring/season_draft.ts` и `policies/decision_registry.ts` — неизменяемо зафиксированные решения и выпуск сезона.

### Критические противоречия, которые нужно исправлять только по плану

1. Компилятор и QA требуют 7–9 карточек и 3–4 семейства на сессию, а владелец выбрал 12 заданий. Это нужно заменить в типах, генераторе, тестах и в сценарии нагрузки — не только в интерфейсе.
2. В перечислениях всё ещё есть неутверждённые режимы (`visual_discovery`, `quick_spoken_response`, `shadowing_prosody`, `scripted_dialogue` и другие). В handover они исключены. Их нельзя случайно сгенерировать или открыть.
3. Старый доступ считает накопленные звёзды по эпизодам, предусматривает платный «boost» за shards и серверную котировку. Новая экономика сессий — другой контракт. Покупки/доступ — чувствительная зона: её нельзя менять без отдельного решения владельца, строгого сервера и проверки безопасности.
4. Существующий V2 сезон строит 4 главы по 8 эпизодов, а текущий мок карты показывает 12 сессий внутри юнита. Нужно определить, как 32 урока становятся 32 эпизодами и как сессии, личный план и контрольные точки соотносятся, не смешивая учебное доказательство со звёздами.

### Что обязано остаться неприкасаемым в логике

- Звёзды за результат, дополнительные тренировки и покупной доступ сейчас отделены от доказательства освоения. Нельзя дать повтору или покупке «нарисовать» знание.
- Дополнительная практика может давать доступ, но не заменяет обязательные петли, локальный минимум и контрольную точку.
- Данные V2 и решения о выпуске привязаны к версии, хешу и неизменяемой записи. Генератор обязан выпускать воспроизводимый результат.
- Ошибка в речи «не уверен» не равна ошибке учащегося; режимы голоса обязаны иметь честный путь восстановления.

Макеты — не вдохновение, а измеряемый источник истины. Всего разобраны 16 HTML-макетов: `02`–`10`, `14`, `19`–`24`, включая `24-missing-states.html`. Для каждого разобраны структура элементов, состояния, CSS, ключевые кадры, длительности и кривые. В исходных макетах повсеместно используются:

- вход: `cubic-bezier(.33,.52,.25,.99)`;
- «быстрый выход»: `cubic-bezier(.23,1,.32,1)`;
- пружина: `cubic-bezier(.38,.70,.125,1)`;
- обязательная ветка reduced motion.

### Перенос должен быть один в один

| Макет | Что переносится в React Native |
|---|---|
| 02 Phrase Builder | банк слов → ответ через FLIP-анимацию 320 мс; `land` 300 мс; поэтапный вердикт 70 мс; ошибочный возврат через 900 мс; автопереход 1 400 мс. |
| 03 Listen & Choose | обязательное прослушивание; кольцо 1 500 мс; медленное аудио 0,75×/2 000 мс; `playPulse` 1 100 мс; радиальное раскрытие 360 мс; blur транскрипта 320 мс; вторая попытка через 1 000 мс. |

| 05 Listen & Build | та же физика сборки фразы, но аудио является основным вводом. |

| 19–24 | входной барьер, бесплатный лимит, checkpoint, сезонная карта, листы/тосты/скелетоны и все пустые/offline/busy/retry состояния. |

### Важные визуальные инварианты

- Никаких растровых иллюстраций и emoji в V2 (G28): только типографика, звук и SVG.
- Только `useTheme`; не зашивать цвета.
- Основная фраза — герой экрана; серия — мягкий сигнал, не наказание.
- Первый кадр не прыгает: известное состояние синхронно, неизвестное — скелетон точно той же геометрии.
- Перенос анимаций: позиция/масштаб/прозрачность — Reanimated, звук — отдельный контроллер; таймеры и бесконечные циклы только пока экран видим и приложение активно.
- После реализации каждый экран открывается рядом с макетом и сравнивается кадр за кадром: покой, касание, processing, correct, wrong/recovery, переход, reduced motion, offline и повторный вход.

## 6. Личные планы — не побочная ветка

Текущая логика хранится в `app/personal_plan_catalog.ts`, `personal_plan_mode_profiles.ts`, `personal_plan_state.ts`, `personal_plan_engine_contracts.ts`, `personal_plan_exercise.tsx`, `plan_week_mode_progression.ts`.

У плана уже есть задания: пропуск слова, выбор естественной фразы, listen choose/build, повтор произношения, recall, связанный урок, quiz, личная практика, слабое место, flashcards, active recall. `trainer_weak_spot` — существующее «Разобрать ошибки маршрута». Текущий порядок плана: знакомство с фразой → профильный хвост задания; у разных планов он разный.

Целевая интеграция:

- карта урока показывает обязательные сессии и отдельные карточки активного плана;
- карта честно показывает стоимость разблокировки, ожидаемую награду и связь с целью плана;
- дополнительные задания получают звёзды, но не подменяют обязательное знание и контрольные точки;
- генератор выпускает задания плана из тех же реальных фраз/слов/целей, а не случайный внешний набор;
- «Моя практика» продолжает быть умным повторением, а не отдельным забытым списком.

## 8. Исследование практик конкурентов

Изучены первичные материалы шести конкурентов. Переносим не их интерфейс, а проверенные принципы:

- **Duolingo:** структурированный путь плюс отдельные виды практики; ошибки возвращаются раньше, а повторение выбирается по точности и времени. [Spaced repetition](https://blog.duolingo.com/spaced-repetition-for-learning/), [Practice Hub](https://blog.duolingo.com/guide-to-duolingo-practice-hub/).
- **Babbel:** короткие практические занятия, речь и интервальное возвращение материала. [How Babbel works](https://www.babbel.com/how-babbel-works), [Spaced repetition](https://www.babbel.com/spaced-repetition-language-learning).
- **LingoDeer:** грамматическое объяснение и заметки перед применением — подходит решению «теория прямо перед нужным действием». [Справка](https://support.lingodeer.com/en/support/solutions/articles/61000194372-how-is-lingodeer-different-from-other-apps-).
- **Memrise:** логичная дуга Learn → Hear/Immerse → Use/Communicate и свобода вернуться к словам. [Прогресс](https://www.memrise.com/blog/new-progress-tracking-for-language-learning), [новый опыт](https://www.memrise.com/blog/team-update-full-walkthrough).
- **Speak:** Learn → Practice → Apply; паттерны повторяются перед разговорным применением, обратная связь идёт сразу. [Продукт](https://www.speak.com/?lang=en), [Tutor lessons](https://help.speak.com/en/articles/11966855-what-are-tutor-lessons).
- **ELSA Speak:** обратная связь по произношению должна быть конкретной, но неопределённое распознавание нельзя выдавать за ошибку ученика. [Как работает feedback](https://elsaspeak.com/en/faqs/how-does-elsas-pronunciation-feedback-work).

Вывод для Phraseman: лучше всего подходит последовательность «увидел и понял → услышал → собрал → применил → проговорил → вернул в контексте», но её нельзя окончательно зафиксировать, пока владелец не выберет точный ритм 12 сессий и роль повторения.

## 15. Протокол работы несколькими ИИ и компьютерами

Этот документ — единственный общий журнал решений для Learning V2. Каждый исполнитель обязан прочитать его полностью до предложения или изменения кода.

### Правила, чтобы не мешать друг другу

1. **Один владелец файла.** Перед правкой исполнитель записывает в раздел «Активные пакеты» ниже, какие файлы и какую ответственность он берёт. Два исполнителя не редактируют один файл одновременно.
2. **Сначала факты, потом код.** Нельзя угадывать правило, если оно не записано. Неясность добавляется в «Открытые решения», а не решается молча.
3. **После каждого изменения** исполнитель обновляет: что сделал, какие файлы трогал, какие проверки запустил, что осталось и какие риски увидел.
4. **Не перетирать чужую работу.** Рабочее дерево может быть грязным; запрещены reset, массовый checkout, перезапись несвоих изменений и «почистить всё».
5. **Только малые независимые пакеты.** Один пакет = одна понятная цель, ограниченный список файлов, тесты и критерий готовности.
6. **Деньги, доступ, подписки, звёзды, покупки, миграции, приватность и серверные правила** — отдельный критический пакет с одним исполнителем и независимой проверкой. Их нельзя менять параллельно с обычным UI.
7. **Визуальный код не принимается по описанию.** Для каждого режима нужны запись экрана, сверка с соответствующим макетом покадрово и перечень состояний, которые были проверены.
