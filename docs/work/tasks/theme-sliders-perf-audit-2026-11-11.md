## Architecture

No architecture change: добавляется только наблюдение. Трассировка живёт в экране, под `__DEV__`, не меняет порядок
обновлений и не пишет в хранилище. Поток данных прежний: палец → бегунок на потоке отрисовки (shared value) →
смена целого шага → JS → локальный черновик экрана (не чаще кадра) → ThemeDraftScope → запись один раз при отпускании.

## Security and privacy

Не затрагивается: нет новых данных, сети, прав, секретов. В журнал уходят только числа (мс, счётчики) и идентификатор
темы `tune:H:S`; личных данных нет. В боевой сборке `console.log` вырезается, трассировка под `__DEV__`.
