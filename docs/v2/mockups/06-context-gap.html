Тема приложения

Прогон состояний

Тап по чипу-варианту — FLIP-перелёт в слот внутри предложения, слот заполняется. Тап по заполненному слоту возвращает чип на место в ряду вариантов (гнездо-ghost, ряд не прыгает). «Проверить»: success — слот и всё предложение заливаются ok-градиентом слева направо (clip-path wipe); ошибка — тонировка слота без тряски, конкретная подсказка, вторая попытка, автозаполнение верным + связь.

Спецификация для RN (Reanimated 4)

Только transform / opacity / clip-path (UI-тред). Слот, полоса раскрытия связи и полоса фидбека с зарезервированной высотой: первый кадр = финальная геометрия, ширина слота фиксирована по самому длинному варианту заранее (measure-once). Reduced motion: wipe и перелёты заменяются мгновенной сменой состояния с коротким кроссфейдом.
