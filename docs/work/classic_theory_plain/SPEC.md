# Спецификация: теория урока «как для ребёнка» (для писателей)

Обязателен к прочтению ЦЕЛИКОМ: `docs/work/classic_plain_explanation_standard_2026-11-05.md` (слово владельца) и этот файл.
Читатель — взрослый, который не знает изучаемого языка и не знает слов «подлежащее, глагол, артикль, форма, время». Он открывает урок 1 впервые в жизни.

## Вход
`docs/work/classic_theory_plain/input/<lang>_lesson_NN.json`: `phrases` (все фразы урока: id, target, ru, uk), `newWords` (слова, впервые встреченные в этом уроке), `knownWords` (слова прошлых уроков), `previousTopics`, `oldTheoryRu` (старый текст — ТОЛЬКО чтобы понять тему; не копируй стиль и термины).

## Выход
Один файл `docs/work/classic_theory_plain/<lang>/lesson_NN.json` (создай папку при необходимости). Формат:

```json
{
  "lang": "es", "lesson": 1,
  "title": {"ru": "…", "uk": "…", "en": "…"},
  "chapters": [
    {
      "id": "c1",
      "title": {"ru": "Я здесь", "uk": "Я тут", "en": "I am here"},
      "text": {"ru": "…", "uk": "…", "en": "…"},
      "examples": [
        {"phraseId": "es:01:01", "say": {"ru": "эстóй акý", "uk": "естóй акý"}}
      ],
      "practice": [
        {"command": {"ru": "Выберите, как сказать: «Я здесь»", "uk": "Виберіть, як сказати: «Я тут»", "en": "Choose how to say: “I am here”"},
         "sample": true, "promptPhraseId": "es:01:01", "options": ["es:01:01", "es:01:02", "es:01:07"], "answerId": "es:01:01"}
      ]
    }
  ]
}
```
- 3–5 глав на урок. Одна мысль на главу. Первая глава — самое простое, что есть в уроке.
- `text`: строки через `\n` (каждая строка — одна короткая мысль, до ~12 слов). Показывай ПО ПОРЯДКУ: фраза на изучаемом языке → её перевод → (как читается). Пример строк:
  `Estoy aquí. — Я здесь.` / `Читается: эстóй акý.` / `Слово aquí значит «здесь».`
- `examples`: 2–3 фразы курса этой главы (id из `phrases`). `say` — как читается русскими (ru) и украинскими (uk) буквами, с ударением (´) — для en-языка курса (английский) читается тоже русскими буквами, это обязательно для урока 1–3. Для `en` локали транскрипции нет.
- `practice`: 1–2 простых задания на главу: ОДНА команда + варианты из фраз курса, где `answerId` — верный. У первого задания раздела `sample: true` — образец (показываем ответ). Команда содержит перевод в «ёлочках» ТОЧНО как в `ru`/`uk` фразы `promptPhraseId`. Варианты (options) — 2–3 фразы курса, неправильные не должны быть тоже верными переводом.
- Локали: пиши `ru`, `uk`, `en` (остальные 6 локалей добавит переводчик). Обращение «вы» везде (в ru/uk: «вы», «посмотрите», «скажите»; en: «you»).

## Запрещено (проверяется скриптом `scripts/classic_plain_check.mjs`)
- Слова-термины: подлежащее, сказуемое, глагол, существительное, прилагательное, местоимение, наречие, предлог, артикль, падеж, склонение, спряжение, время (как грамм. термин), инфинитив, причастие, согласование, форма/формы, вспомогательный, суффикс, окончание, род (м/ж), число (ед./мн.), ударение — вместо них показывайте примеры. (en: verb, noun, article, tense, conjugation, pronoun, adjective…; uk: дієслово, іменник, займенник…)
- Блоки «что заучивать», «типичная ошибка», «нюансы», «стратегия», «выбор формы», «правило».
- «ты/тебе/тебя/твой» (кроме текста внутри «ёлочек», который является переводом фразы курса).
- Изучаемые слова, которых человек ещё не видел: в тексте можно использовать только слова из `phrases` урока (и прошлых уроков из `knownWords`/`newWords`). Любое другое слово изучаемого языка — нельзя.
- «Представь ситуацию», сценки, метафоры про «друга в куртке».

## Тон
Тёплый, короткий, как будто объясняете человеку, который стесняется. Не «запомните правило», а «смотрите: …». После каждого нового слова — перевод рядом. Если в главе несколько слов — только 2–3.

## Образец главы (es, урок 1, глава 1)
```
Смотрите, как сказать «Я здесь».
Estoy aquí. — Я здесь.
Читается: эстóй акý.
Слово estoy значит «я нахожусь». Слово aquí значит «здесь».
```
Переводы фраз курса в «ёлочках» берите ДОСЛОВНО из `ru`/`uk` пакета (там может стоять «Ты здесь» — это перевод конкретной фразы, его не меняют).

## Правила по итогам проверки новичками (урок 1, 05.11) — ОБЯЗАТЕЛЬНЫ
1. Каждое слово изучаемого языка в тексте — с переводом РЯДОМ при первом появлении, включая маленькие (the, la, il, die, das, y, e, de…). Если по-русски такого слова нет — скажите это одной строкой: «по-русски такого слова нет, запоминайте его вместе с названием вещи».
2. Не вводите слов и форм, которых нет в примерах главы (stanco, libre, Paolo…), и не оставляйте слов «из воздуха» без перевода (Lei, está, están, il…). Мужской и женский варианты («готов/готова») — только если в уроке есть обе фразы курса; иначе не упоминайте.
3. В ПЕРВОЙ главе урока 1 одной короткой строкой объясните две вещи: «Чёрточка над буквой в подсказке «Читается» показывает, какую часть слова говорить громче» и «Русские буквы передают звук приблизительно». Дальше не повторяйте.
4. Маленькие слова-связки (am/is/are, soy/estoy…, suis/es/est, bin/bist/ist, sono/sei/è) НЕ называйте «слово посередине / маленькое слово»: называйте по имени и говорите, что они значат («быть, находиться») и что по-русски их часто нет. Говорите «слово меняется, смотря о ком речь: я — …, вы — …, он — …».
5. Не пишите «когда говорит другой человек», «про одного человека» (двусмысленно). Пишите «когда речь о вас», «когда речь о нём/о ней», «когда речь о нас/о них».
6. Транскрипции одинаковых звуков пишите ОДИНАКОВО во всех главах (ll → «й» везде; носовые звуки, ü, r — единый способ). Не вводите непонятных значков; если звук сложный, скажите словами («как «ю», но губы трубочкой»).
7. В уроке 1 — не больше 4 глав и не больше 7–8 новых слов на главу. Лишнее (род у прилагательных, вежливое «вы», несколько мест) переносите в следующие уроки; после слов «Об этом позже» ничего не обещайте.
8. Задания: варианты ответа отличаются тем самым словом, которое разобрали в главе (например «I am ready / He is ready / We are ready» для «Он готов»), а не просто разными словами. Порядок вариантов не важен (его перемешивает скрипт). Одно задание на главу достаточно.
9. Перевод вводите так, как он стоит в `ru` фразы курса; не переводите «находится» там, где в русском просто нет глагола (напишите: «по-русски слово не говорят, но по-немецки оно нужно»).

## ДОПОЛНЕНИЕ 05.11 (Learning V2 / Координатор): покрытие слов и количество заданий
1. **Каждое новое слово урока** (список `newWords` во входе) должно быть ВВЕДЕНО: либо стоять в тексте главы с переводом, либо входить в одну из фраз-примеров главы (`examples`: карточка «фраза → перевод → читается»). Слово из `newWords` без такого введения — брак. Проверка: `node scripts/classic_plain_coverage.mjs <lang> <lesson>` (в строке «не введено» должно быть пусто или почти пусто; фразы с нужным словом ищи по `phrases` входа — берите ЛЮБЫЕ фразы урока, где слово есть).
2. Примеров на урок — столько, чтобы закрыть все новые слова: обычно 12–25 фраз на 4–5 глав (по 3–6 на главу, сгруппировано по теме). Для каждой — `say.ru` и `say.uk` («как читается»).
3. **Задания** (`practice`): на КАЖДУЮ главу — ровно 1 образец (`sample: true`) и 2 реальных задания (`sample: false`), всего не меньше 8–10 реальных на урок. Задания используют ТОЛЬКО слова, введённые в этой или прошлых главах/уроках (смотри, что уже показано в `examples` ДО этого задания). Каждое задание — `promptPhraseId` + 2–3 варианта (`options`) из фраз, уже показанных в примерах глав.
4. Не раздувайте текст: объяснение остаётся коротким; слова вводятся карточками-примерами, а не длинными абзацами.
