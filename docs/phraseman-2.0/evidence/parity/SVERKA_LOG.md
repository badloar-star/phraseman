3. Плашка энергии «⚡ 5» справа в шапке: в макете есть (стеклянная пилюля); в приложении её нет.
4. Под названием урока: макет — полоса прогресса + «17 / 50»; приложение — три звезды + «1/50».
5. Карточки-строки: макет — стекло: светлее сверху (градиент), светлая кромка по верхнему краю, мягкая тень под карточкой; приложение — плоская заливка одного тона, ровная тонкая обводка, тени нет.
6. Плитка значка в строке: макет — тёмный круг-подложка, едва заметный (утоплен); приложение — подложки не видно, значок висит на фоне карточки.
7. Набор строк: макет — «Продолжить · 17/50 фраз» (значок ▶), «Слова урока · 9/24 слов» (значок «карточка-текст»), «Теория · Правила и пояснения» (значок «список»); приложение — «Перепройти · 1/50 · 1/3★» (значок «круговая стрелка»), «Словарь · 0/37 слов» (значок «книга»), лишняя строка «Неправильные формы глаголов · 0/1 глаголов» (⚡), «Теория» со значком «книга» вместо «списка».

9. Фон экрана: макет — почти чёрный нейтральный с мягкой виньеткой; приложение (тема «Затмение») — сине-серый, заметно светлее.
