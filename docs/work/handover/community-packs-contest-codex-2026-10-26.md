## 3. Анимации (обязательны, тайминги — из приложения, KIT_MOTION)

- **Появление каталога.** Статус-бар и табы сразу. Герой-веер из масштаба 0.94. Тексты блока «Набор месяца» лесенкой. Пьедестал поднимается блоками 2-1-3: 240 / 320 / 400 мс. Монеты авторов падают сверху. Панель и плитки лесенкой по 60 мс. Все входы ease-out не дольше 520 мс.
- **1 место.** Мягкий блик по стеклу раз в 5 с, только `transform`.
- **«Топ / Новые».** Шайба в цвете темы скользит, пружина без отскока около 260 мс (как `V2SegmentedControl`). Плитки меняются коротким фейдом.
- **♥.** Срабатывает мгновенно: заливка и отскок 1→1.18→1 за 110+140 мс, как `likePop` в `CommunityPackSocialBar`. Счётчик прыгает (numup/numdn 650 мс, `cubic-bezier(.3,1.4,.5,1)`). Свой набор лайкнуть нельзя — покачивание.
  - На экране набора ♥ заблокирован до «Добавить себе». **Это решение Макетов, владелец не подтверждал** — уточнить или оставить как в макете.
- **«Добавить себе».** Мгновенно «✓ В твоих наборах», смена через размытие 160 мс, ♥ разблокируется с отскоком.
- **Проверка ИИ.** Старт 420 мс, по 320 мс на карточку, счётчик «2 из 12». У хороших карточек галочка с отскоком. Проблемные получают тонированный блок с «Исправить». «Исправить» меняет текст на месте. Кнопка публикации из серой становится основной с отскоком, до готовности покачивается.
- **Публикация.** Экран проверки уезжает, каталог въезжает на «Новых». Новый набор стоит первым с одним мягким кольцом в цвете темы. Сверху тост «Набор в конкурсе!» в формате `ActionToast 'top_line'`, уходит через 2.2 с.
- **Шторка.** Затемнение 260 мс, выезд 440 мс по `cubic-bezier(.2,1,.3,1)`. Закрывается «Понятно» или тапом по затемнению.
- **Победитель.** Окно из масштаба 0.94 за 340 мс. Конфетти в оттенках темы не дольше 1.2 с, как `ConfettiBurst`. Медаль влетает сверху с кольцом. ♥ считает 0→N за 900 мс. Приз и кнопка догоняют.
- **Переходы экранов.** Новый въезжает справа за 360 мс, прежний уходит на четверть с притемнением. «Назад» — обратный переход.
- `prefers-reduced-motion` / «Уменьшить движение» гасит всё.
- Анимации — на UI-треде (Reanimated), без setState в кадрах. Тяжёлые списки — FlatList/FlashList.

## 5. Конкурс «Набор месяца» — серверная часть (новая)

**Решения владельца (26.10):**
- голос = лайк;
- участвуют **все новые наборы месяца** (опубликованные в этом месяце);
- призы: **Plus и монеты**;
- наборы на любых языках.

**Что построить:**
1. **Дата публикации набора.** Нужен `createdAt`/`publishedAt` в проекции каталога. Сейчас в проекции фактически `updatedAt`, это заметил Дизайн. Месяц считать по UTC.
2. **Подсчёт голосов за месяц.** Лайки внутри месяца на наборах этого месяца. Свой набор лайкать нельзя. Голосуют только настоящие аккаунты: не анонимные, с возрастом аккаунта или минимумом активности — **анти-накрутка**.
3. **Таблица лидеров — Firebase-экономия.** Серверная функция по расписанию раз в N часов (предложение — 3 ч) пишет один документ `contest/{yyyy-mm}`: топ-3, число участников, срез мест. Телефон читает этот один документ при входе в раздел и кэширует. Никаких выкачиваний коллекции лайков с клиента. «Твоё место» — либо поле в том же срезе, либо одна точечная callable-функция с кэшем.
4. **Итоги месяца.** Расписание 1-го числа 00:05 UTC:
   - фиксирует топ-3 и пишет `contest/{yyyy-mm}.final`;
   - начисляет призы: Plus — через существующий механизм грантов Plus; монеты — через существующий серверный журнал монет;
   - идемпотентно, с журналом выдачи.
5. **Окно победителя** показывается один раз (флаг «показано») по данным `final`. «Забрать приз» срабатывает оптимистично: локально сразу «✓ Plus включён», сеть догоняет, при ошибке откат с понятным текстом.
6. Новые правила Firestore для `contest/*`: чтение всем вошедшим, запись только сервер.

**Выкладка сервера** — только с явного «да» владельца и точечно: `scripts/deploy_from_clean_head.sh --only ...`. Полного `firebase deploy` нет.
