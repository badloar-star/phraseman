# Урок 31 · Заняття 42 — Ключ і записка

**Ситуація.** Ви прибираєте запасний ключ і залишаєте Анні записку.

**Що ви опануєте:** пояснювати мету своїх дій і називати іншого учасника після so that.
**Нові слова:** —
**Повторюємо знайомі слова:** key, box, note, drawer

## Інтро 1

### Прибрав ключ, щоб зберегти його

Ви поклали запасний ключ у коробку, де він не загубиться: I put the key in the box to keep it safe — я поклав ключ у коробку, щоб зберегти його в безпеці. Складіть I put the key in the box + to + keep it safe. Після to називаємо мету: keep it safe. Кладете й хочете зберегти ключ ви.

**Виберіть фразу для цієї ситуації.**

- ✅ **I put the key in the box to keep it safe.**
- ❌ I put the key in the box to kept it safe. — *Після to потрібна початкова форма keep.*
- ❌ I put the key in the box for keep it safe. — *Перед keep для цієї мети потрібне to.*

---

## Інтро 2

### Записка допоможе Анні знайти ключ

Анна прийде пізніше. Ви написали їй записку про те, де лежить ключ: I wrote a note so that Anna could find the key — я написав записку, щоб Анна могла знайти ключ. Складіть I wrote a note + so that + Anna could find the key. Пишете ви, а знайти має Анна: після so that явно називаємо її.

**Виберіть фразу для цієї ситуації.**

- ✅ **I wrote a note so that Anna could find the key.**
- ❌ I wrote a note to Anna find the key. — *Для окремого учасника Anna потрібна ціла частина після so that.*
- ❌ I wrote a note so that Anna could found the key. — *Після could потрібна форма find.*

---

## Інтро 3

### Я знаю, де коробка

Друг шукає коробку з ключем. Ви пам’ятаєте її місце: I know where the box is — я знаю, де коробка. Складіть I know + where + the box + is. Після where зберігаємо порядок the box is, без питальної перестановки.

**Виберіть фразу для цієї ситуації.**

- ✅ **I know where the box is.**
- ❌ I know where is the box. — *Після where порядок the box is.*
- ❌ I know where the box are. — *Одна box потребує is.*
