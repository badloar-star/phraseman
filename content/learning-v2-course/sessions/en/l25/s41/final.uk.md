# Англійська · Урок 25 · Заняття 41 — Якими ми були раніше

**Ситуація.** Ви згадуєте колишні почуття й риси характеру.

**Що ви опануєте:** used to + base verb for past states
**Нові слова:** fearless, helpless, outgoing, carefree

## Інтро 1

### Яким я був у дитинстві

Fearless — безстрашний. I used to be fearless as a child — у дитинстві я був безстрашним. Used to be описує колишній стан і передбачає, що тепер усе інакше. Після used to ставимо початкову форму be, а не was. Це не розповідь про єдиний сміливий учинок: ідеться про те, яким я був у той період.

**Виберіть фразу для цієї ситуації.**

- ✅ **I used to be fearless as a child.**
- ❌ I use to be fearless as a child. — *Колишній стан: used to + початкова форма.*
- ❌ I using to be fearless as a child. — *У ствердженні про минуле потрібно used to.*

---

## Інтро 2

### Раніше почувався інакше

Helpless — безпорадний, той, хто не може впоратися без допомоги. He used to feel helpless in the kitchen — раніше він почувався безпорадним на кухні. Наприклад, не вмів готувати, а тепер навчився. Outgoing — товариський, той, хто легко знайомиться з людьми. She used to be outgoing at school — у школі вона була товариською. Used to підходить і для почуттів, і для рис характеру в минулому: used to feel, used to be.

**Виберіть фразу для цієї ситуації.**

- ✅ **He used to feel helpless in the kitchen.**
- ❌ He use to feel helpless in the kitchen. — *Колишній стан: used to + початкова форма.*
- ❌ He using to feel helpless in the kitchen. — *У ствердженні про минуле потрібно used to.*

---

## Інтро 3

### Без турбот, а не без уваги

Carefree — безтурботний. We used to be carefree during the holidays — раніше на канікулах ми були безтурботними. Carefree не дорівнює знайомому careless: carefree — без турбот, careless — неуважний чи необережний. Тут описуємо колишній стан, тому used to be. Звичне would з попередніх занять підходить для повторюваних дій, але в такому описі стану вибираємо used to.

**Виберіть фразу для цієї ситуації.**

- ✅ **We used to be carefree during the holidays.**
- ❌ We use to be carefree during the holidays. — *Колишній стан: used to + початкова форма.*
- ❌ We using to be carefree during the holidays. — *У ствердженні про минуле потрібно used to.*
