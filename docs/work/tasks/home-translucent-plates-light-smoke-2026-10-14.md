# Главная: плашки с фоном 50 %, «Сегодня» без фона; тёмные пятна на белом в светлых темах

Governance-ID: TG-F4DB144C0862

## Outcome
1) Главная во всех темах: у внешней карточки «Сегодня» нет фона (ни заливки, ни тени, ни блика), у остальных плашек Главной фон 50 % через альфу цвета фона (не opacity всего элемента); текст, значки, картинки — 100 %. 2) Тёмные пятна на белых плашках светлых тем исчезли: источник — «дымка» V2GlassSheen: в светлом «Максимуме» её цвет `solid(cardSmoke[0])`, а у градиентных тем cardSmoke = `#00000000`, `solid()` отбрасывает альфу и получается ЧЁРНАЯ дымка с усилением ×4. Правило светлых тем: внутри плашки ничего темнее самой плашки. 3) Лог `[HOME-PLATE]`, тесты.

## Scope
`components/home/v2/*`, `components/DailyPhraseCard.tsx` (ветка Главной), `components/NotificationCenterButton.tsx` (кнопка-колокольчик живёт только на Главной), `components/v2/V2Glass.tsx` (необязательный пропс прозрачности значка; useV2GlassStyle не меняется), `constants/v2StyleGlassVariant.ts` (дымка светлых тем — только белая). `app/(tabs)/home.tsx` (Ядро) не трогаю. Тёмные темы не меняются.

## Architecture
