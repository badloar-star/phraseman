# Проверка на телефоне перед выпуском 16.10 — 15 пунктов

Для владельца. Каждый пункт: **что нажать → что должно быть**. Сборка 132 (iPhone — TestFlight, Android — внутренний тест).

Если что-то не так: снимок экрана и время (часы:минуты) — координатору. Этого хватит, чтобы найти запись в журнале.

Удалять аккаунт для проверки НЕ нужно — удаление проверяем на эмуляторе.

---

### Вход и аккаунт

1. **Открыть приложение на новом месте, дойти до экрана входа** → тёмная плита. Кнопка «Войти через Apple» **белая с чёрным значком** и хорошо видна. Кнопка Google видна.
2. **iPhone: «Войти через Apple»** → системное окно Apple → Главная. Настройки → Аккаунт: вход через Apple.
3. **«Войти через Google» → выбрать аккаунт в списке** → Главная с вашим прогрессом. Настройки → Аккаунт: ваша почта.
4. **Настройки → Аккаунт → «Выйти и войти другим аккаунтом» → «Выйти»** → не дольше ~10 с, без бесконечной крутилки, снова экран входа.
5. **Войти другим Google-аккаунтом, на устройстве уже есть прогресс** → окно «Сменить аккаунт?», обе кнопки читаются целиком → «Сменить» → не дольше ~15 с Главная второго аккаунта; в Аккаунте его почта.
6. **Только если само появится окно «Восстановить аккаунт?»** → «Восстановить» → аккаунт и прогресс на месте. Не появилось — пункт пропустить.

### Plus

7. **Пейвол → «Месяц» → покупка в песочнице** → пейвол закрывается, Plus включён. Если магазин держит оплату — короткая плашка «Оплата обрабатывается — Plus включится сам». Окна «ждёт подтверждения родителя или банка» быть НЕ должно.
8. **Настройки → строка подписки** → экран «Подписка Plus» сразу с названием плана («Месячная подписка»), без серой заготовки. Закрыть и открыть ещё раз — так же сразу.

### Что нового

9. **Обновиться на 132 поверх старой установки (поставленной до 16.10)** → после входа один раз окно «Что нового». Закрыть, перезапустить приложение — больше не появляется. На новой установке его быть не должно.

### Пик

10. **Язык интерфейса русский или украинский** → в нижнем меню есть «Пик». Сменить язык интерфейса на английский → «Пик» пропадает сразу, без перезапуска. Пик включается ещё и флагом с сервера: если его нет и на ru — сказать координатору.
11. **Включить VoiceOver (iPhone) / TalkBack (Android), открыть Пик, вести пальцем по экрану** → каждый элемент озвучивается словами, у кнопок понятные названия, ничего не «молчит».

### Диалоги, карточки

12. **Новый аккаунт → вкладка с диалогами** → открыт ровно один первый диалог, остальные под замком ранга.
13. **Карточки → открыть карточку → нажать на звук** → слово или фраза озвучивается, звук не обрезан, не повторяется дважды.

### Крупный шрифт

14. **Настройки телефона → размер текста на максимум → вернуться в приложение** → Главная, Настройки, Аккаунт: текст не обрезан и не налезает. В окнах с двумя кнопками («Сменить аккаунт?», «Восстановить аккаунт?») кнопки стоят **столбиком** и слова не рвутся.
15. **Вернуть обычный размер текста** → всё как было, без перезапуска.
