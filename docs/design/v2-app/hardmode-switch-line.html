Урок: переход от клавиатуры к выбору слов

Жалоба №4: при включённом «Вводе с клавиатуры» новичок видит поле вместо плиток и не понимает почему. Решение координатора 25.10:

  • Строка видна всегда, пока включён ввод с клавиатуры: тихая, одной строкой, без обводки.
  • Тап сразу выключает настройку — на месте, без похода в настройки и без ожидания сети; плитки появляются мгновенно, набранное сбрасывается.
  • Внизу тост с «Вернуть» — одним тапом обратно в ввод с клавиатуры.
  • Только в одну сторону: в режиме плиток обратной строки нет, включить снова можно в «Настройках обучения».
