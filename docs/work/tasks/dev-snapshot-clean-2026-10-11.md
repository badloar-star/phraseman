# Dev-флаг «чистые кадры сверки» (без плашек LogBox)

Governance-ID: TG-FC8FAC3304B9

## Outcome
В dev-сборке эмулятора при `EXPO_PUBLIC_SNAPSHOT_CLEAN=1` LogBox (красные и жёлтые плашки, полноэкранный инспектор) отключён, чтобы кадры Сверки были чистыми. В обычном dev и в релизе поведение не меняется.

## Scope
`app/dev_snapshot_clean.ts` (новый крошечный модуль), одна строка в `app/_layout.tsx` под условием `__DEV__`, сторож `tests/dev_snapshot_clean_contract.test.mjs` и поведенческий тест `tests/dev_snapshot_clean_behavior.test.ts`.

## Architecture
Модуль сам проверяет `__DEV__` и значение переменной окружения; вызывает `LogBox.ignoreAllLogs(true)` только когда оба условия верны. В корневом layout подключается как `if (typeof __DEV__ !== 'undefined' && __DEV__) require('./dev_snapshot_clean')`: в релизном бандле Metro подставляет `__DEV__ = false`, ветка вырезается; в тестах голая ссылка не падает (`typeof`).

## Security and privacy
Переменная — публичный флаг без секретов, данных пользователя не касается. Консольные предупреждения по-прежнему идут в бандлер и журнал — скрываются только плашки на экране.

## Technical debt
Не добавляется. Флаг включает владелец Metro (сессия «Эмулятор») перезапуском с `EXPO_PUBLIC_SNAPSHOT_CLEAN=1`.

## Verification
Полная проверка типов в слоте светофора; поведенческий тест (флаг есть/нет, `__DEV__` есть/нет); сторож: `ignoreAllLogs` встречается только в этом модуле, `_layout` подключает его под защитой `__DEV__`, флаг не лежит в `eas.json`/`.env*`.

## Rollback
Откатить коммит: модуль, строка в layout и тесты исчезнут.
