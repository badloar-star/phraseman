## Architecture

- Единое правило для четырёх сессий: если вход упал с `pending_grant_*` или
  любой ошибкой инфраструктуры, а карточки уже загружены — раунд стартует
  локально из загруженного пула, без чека и без списания энергии; в лог —
  `entry:fail-open` с причиной. Экран-заглушка остаётся только для случая
  «карточек физически нет».
- Ошибка гранта несёт `reason`, чтобы аудит по логу закрывался одним grep.
- Кнопка старта в выборе наборов не ждёт `quotaPreview.status === 'allowed'`:
  блокирует только доказанный `exhausted`.
