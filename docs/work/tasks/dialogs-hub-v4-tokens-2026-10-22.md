# Токены хаба Диалогов v4: сверка с макетом и недостающее

## Outcome
Владелец одобрил `docs/design/v2-app/dialogs-hub-v4.html`; перенос делает 2 · ДИЗАЙН. Цвета под перенос готовит 4 · ТЕМЫ: сверить `dialogs_hub_tokens` (d2cf4c6f8) с макетом (сцена, «Свободный разговор», плитки 4 миров с дорожкой прогресса, переключатель вместо чипов, компактные строки темы с замком / ✓ / монетой ранга, экран темы), добавить недостающее, закрепить контраст сторожем по 23 темам × 2 оформлениям (текст ≥ 4,5, значки ≥ 3, дорожка различима). Дизайну — одна строка «какой токен куда».

## Scope
In scope: `components/dialogs/scene/dialogs_hub_tokens.ts` (добавление полей: дорожка плитки мира, рельс переключателя, компактная строка, шапка экрана темы, заметка, затухание), `tests/dialogs_hub_tokens.test.ts` (расширение), `docs/work/tasks/dialogs-hub-v4-token-map-2026-10-22.md`.
Out of scope: перенос экранов (2 · ДИЗАЙН), подключение sceneTop на экране (их шаг), существующие поля токенов (их читают DialogsHubThemes, DialogsHubWorldSwitch, DialogueV2ThemeScreen, DialogueV2PlusTools — не меняются).

## Architecture
Поля только добавляются в `DialogsHubTokens`; всё считается из токенов текущей темы (`opaqueCard`, `opaqueControl`, `accentGraphic`, `text`, `secondary`, `bg`) — как в макете `--card/--ctl/--acc/--tx/--sec/--bg/--hair`. Тонкая «hair» дорожка = цвет текста темы с прозрачностью 7 % (макет). Кеш по объекту токенов прежний.

## Security and privacy
Данных не касается.

## Technical debt
Тексты и раскладка в макете — задача Дизайна; если дорожка 7 % окажется неразличимой хотя бы в одной теме, пороги и значение уточняются с координатором, а не молча меняются.

## Verification

## Rollback
