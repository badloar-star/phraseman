# Отложенное — не запускать при текущем упрощении

Learning V2 сохраняет собственную разработку и документы. Его первый релиз не требуется для PhraseMan 2.0. Пробные 10 сессий — отдельное решение, не отмена трёх открытых уроков V1. При чистке веток сохранить неслитую V2-работу в проверенном архиве/канонической истории.

Облачное распознавание речи — исследование позднее. Перед заменой движка нужны сравнительные сценарии на реальных акцентах/языках, цена минуты/запроса и concurrency, разрешения/согласия, хранение/удаление голоса и fallback. Не покупать качество только по названию API. Transcription само по себе не измеряет артикуляцию и не обосновывает процент «правильного произношения».

Вторая голосовая линия на карте V2 должна разделять учебные цели и способ ответа, а не автоматически удваивать весь backend/контент/прогресс. До этого нужны модели session ID, skill progress и миграции.

Башня вместо арены — ранняя идея, которая не получает разрешение из факта удаления арены. Сохранённые генераторы/режимы можно использовать после отдельного продуктового решения. Не строить новую игру в release simplification.

Расширение V1 на новые языки — отдельные контентные задачи после стабильной платформы. Не создавать «тысячу сессий генерации» заранее; сначала один язык/пилот уроков с качественным рубрикатором.
