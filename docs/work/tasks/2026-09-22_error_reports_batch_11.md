## Outcome

Каждый из 11 открытых репортов разобран по коду, сгруппированы дубликаты,
подготовлены персональные ответы на языке автора и встроены в превью админки
(`PREPARED_REPORT_REPLIES`), чтобы администратор вручную отправил их из
рабочей админки. Успех = администратор видит все черновики в
https://phraseman-ea0b3.web.app/legacy.html#control-panel и может отправить
их одной кнопкой; ни один живой пользователь не получает рассылку из CLI.

## Scope

In scope:
- анализ `app/lesson_data_1_8_phrases_source.ts`, `app/lesson_data_17_24.ts`,
  `app/phrase_target_utils.ts`, `app/flashcards/deck_options.ts`;

Out of scope:

- пересборка мобильного приложения.

## Architecture

Без изменения архитектуры. `PREPARED_REPORT_REPLIES` — статическая карта
`reportId → {title, body, resolution, rewardBundle}` внутри единственной рабочей
админки `admin/v2/legacy.html`. Правки админки вне этого файла на боевую не
попадают (правило проекта). Инвариант: идемпотентность — репорт с уже
проставленным `replyMessageId` пропускается и не получает повторную награду.

## Security and privacy

Персональные данные: ответы адресованы конкретным uid, но **в текст ответа не
попадают** ни uid, ни чужие имена, ни внутренние id, ни имена файлов, ни куски
кода — только суть проблемы человеческим языком. Внешние каналы (Telegram) не
затрагиваются. Новых полей, сервисов и разрешений не добавляется, поэтому
privacy policy обновлять не требуется. Аутентификация админки не меняется
(`custom claim admin`, правила входа не трогаем). App Check не включается.

## Technical debt

- **Contain.** `words`/`wordsEn` — двойной набор токенов: русский в `words` и
  английский в `wordsEn` для уроков 20/22/23/24/25/27/28/29/30 (450 фраз).
  Это штатный режим (`phrase_target_utils.phraseWordRowsForStudyTarget` отдаёт
  приоритет `wordsEn`), но читается как порча данных и уже стоил этой сессии
  времени на проверку. Граница: `phrase_target_utils.ts` — единственная точка
  выбора слотов. Выход из долга: короткий комментарий-навигатор у `words`
  в файлах данных — отдельной задачей, не в этой.
- **Accept temporarily.** Нет автоматической сверки `dataText` из репорта с
  актуальным содержимым фразы: репорты #7 и #8 пришли с текстом, которого в
  текущем контенте нет (`He does not need money` / `She uses apps` живут только
  в `lesson_data_1_8_phrases_es.gen.ts`). Владелец: следующая сессия разбора
  репортов. Дата пересмотра: следующая пачка. Потолок影響: тратится время
  сессии на ручную сверку, пользователь не страдает.

## Rollback

`PREPARED_REPORT_REPLIES` — только черновики: они ничего не начисляют и никому
не уходят, пока администратор не нажмёт «Отправить готовые ответы». Откат =
удалить добавленные записи из `admin/v2/legacy.html` и повторить
`npm run hosting:admin`. Данные пользователей не затрагиваются, начисленные
награды не отзываются (их ещё нет). Необратимых миграций нет.
