- дни отсутствия — снимок прошлой активности;

- карточки — сохранённые карточки языка, N ≤ 5 (понятия «карточки по сроку» в приложении нет).

Части строки, которых нет (0 фраз, энергия не полная), не выдумываются — опускаются.
Карточек 0 → главной кнопки нет: в образце другого варианта нет, ничего не придумываем, остаётся «На Главную».
