# Звук и движение — каталог событий

Интерактивный макет: каждое звуковое событие приложения + анимация, построенная
по **реальной форме волны** его WAV-файла.

## Запуск

```
python -m http.server 8843
```

Открыть http://localhost:8843/docs/sound-motion/. Через `file://` не работает — браузер заблокирует
загрузку аудио.

## Откуда берутся данные

| Источник | Что даёт |
|---|---|
| `modules/audio/sound_events.ts` | список событий, громкость, семейство, платформа |
| `waveforms.json` | огибающая, атака, спад, пики, яркость тембра, форма |
| аудит `app/`, `components/`, `hooks/` | какой экран вызывает событие |

События в макете — те же самые, что в приложении. Ничего не выдумано.

## Как анимация следует за звуком

Анимация не назначена на глаз — её параметры вычислены из PCM каждого файла
(`scripts` анализа: RMS-огибающая по 64 окнам, поиск локальных пиков, оценка
спектральной яркости).

| Из звука | В анимацию |
|---|---|
| `effectiveMs` — реальное звучание без хвоста тишины | длительность анимации |
| `hits[]` — тайминги пиков огибающей | момент каждого импульса-кольца |
| `shape` = `perc` | один резкий поп |
| `shape` = `double` / `triple` | два-три импульса |
| `shape` = `multi` | каскад искр по таймингам ударов |
| `shape` = `swell` | плавное нарастание |
| `brightness` > 0.55 (яркий тембр) | золото `#FFC800` |
| `brightness` ≤ 0.55 (глухой тембр) | зелень `#47C870` |
| огибающая (64 значения) | покадровый масштаб и прозрачность орба |

Полоска под сценой — реальная огибающая файла; бегунок идёт по ней синхронно
со звуком.

## Что показал аудит

- **48** событий в каталоге, **39** со звуком, **9** ждут озвучки (арена + `vip_finale`).
- **7** событий имеют готовый WAV, но не вызываются ни одним экраном:
  `learn.hint_reveal`, `learn.timer_expired`, `system.warning`,
  `system.destructive_done`, `voice.turn_ready`, `voice.no_speech`,
  `social.friend_request`.
- `durationMs` в каталоге — длина **контейнера**, а не звука: в среднем
  **695 мс** в конце каждого файла это тишина. Худший случай —
  `social.quest_complete`: 1500 мс в каталоге против 234 мс реального звучания.

Пересобрать после изменения каталога или замены WAV: пересчитать `waveforms.json`
анализом PCM и перегенерировать `index.html`.
