## Outcome
1) Журнал `[THEMED-ART] tint=<hex> level=<уровень> theme=<id> brightness=<тон>` на каждой плитке/карточке со слоем accent — видно, какой цвет реально красит деталь. 2) Расчёт-превью: сравнение кандидатов (accent, accentBright, accentGradient[0], accentText, cta, и артовый токен «светлота зажата, chroma не ниже порога») для тем Закат (terracotta), Мята (sage), Графит × уровни 0 / 0,5 / 1 × тёмное и светлое оформление. Таблица и расчётные образцы цвета отправляются координатору БЕЗ правки токенов — правка только после его решения.

## Scope
components/theme/ThemedArtLayers.tsx — только dev-журнал (в боевой сборке молчит); отчёт и расчёт — вне кода приложения (скрипт во временной папке и документ docs/phraseman-2.0/CLAY_ACCENT_SATURATION_2026-10-12.md). Токены, картинки, экраны не меняются.

## Architecture
Журнал дедуплицируется по ключу «тема|тон|tint|уровень», чтобы не писать строку на каждый рендер плитки. Уровень берётся из насыщенности (liquidGlassLevelForIntensity). Расчёт — OKLCH: светлота L, насыщенность C, оттенок H для каждого кандидата.
