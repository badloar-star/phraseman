# Испанский · Урок 6 · Занятие 4 — Там есть стол

**Ситуация.** Показываете другу предметы в другой части комнаты.
**Что вы освоите:** уточнить место словом allí — там.
**Новые слова:** allí
**Повторяем знакомые слова:** haber, mesa, silla, libro, aquí.

## Интро 1

### Показать стол подальше

Вы стоите у входа, а стол заметили в дальнем углу. Скажите `Hay una mesa allí` — «Там есть стол». Соберите `Hay una mesa` + `allí`. Allí означает «там», не рядом с вами. В выбранном порядке поставьте его в конец: друг поймёт, в какую сторону идти, и не будет ждать стол у двери.

**Сообщите «Там есть стол». Начните с Hay, место поставьте в конце.**

- ✅ **Hay una mesa allí.** — *Hay una mesa + allí.*
- ❌ Hay una mesa aquí. — *Aquí — здесь; в этой ситуации нужен стол там: allí.*
- ❌ Hay un mesa allí. — *Mesa женского рода: una.*

## Интро 2

### Указать свободный стул

В другом конце комнаты вы заметили свободный стул. Скажите `Hay una silla allí` — «Там есть стул». Соберите `Hay una silla` + `allí`. Слово allí не меняется при замене предмета. Оно говорит о месте, а una silla — о том, что там есть.

**Сообщите «Там есть стул». Начните с Hay, место поставьте в конце.**

- ✅ **Hay una silla allí.** — *Hay una silla + allí.*
- ❌ Hay una silla aquí. — *Для места подальше в этой сцене нужно allí.*
- ❌ Hay un silla allí. — *Silla женского рода: una.*

## Интро 3

### Заметить книгу на дальнем столе

Друг ищет чтение, и вы показываете на книгу в другой части комнаты. Скажите `Hay un libro allí` — «Там есть книга». Соберите `Hay un libro` + `allí`. С libro используем un. Allí сохраняется: для книги и для стула слово «там» одно и то же.

**Сообщите «Там есть книга». Начните с Hay, место поставьте в конце.**

- ✅ **Hay un libro allí.** — *Hay un libro + allí.*
- ❌ Hay una libro allí. — *Libro мужского рода: un.*
- ❌ Hay un libro aquí. — *Aquí — здесь; по ситуации книга там: allí.*

## Практика · 13 заданий

**1 · Карточка слова — allí**
> **allí** — там, в месте на некотором расстоянии от говорящего.
🔊 *allí*

**2 · Послушайте и выберите слово**
🔊 *allí*
→ **allí** · aquí
- aquí — *Звучит allí — там, не aquí — здесь.*

**3 · Вставьте слово — там есть стол**
`Hay una mesa ___.`
→ **allí** · aquí · años
Полная фраза: **Hay una mesa allí.**
- aquí — *Нужно «там» — allí.*
- años — *Это годы; для места нужно allí.*

**4 · Соберите фразу — там есть стол; начните с Hay, слово «там» поставьте в конце**
Плитки: `allí` · `Hay` · `una` · `mesa` · `aquí`.
→ **Hay una mesa allí.**
*Плитка `aquí` лишняя: она означает «здесь», а нужно «там».*

**5 · Вставьте слово — там есть стул**
`Hay ___ silla allí.`
→ **una** · un · unos
Полная фраза: **Hay una silla allí.**
- un — *Silla женского рода: una.*
- unos — *Одна silla: una.*

**6 · Соберите фразу — там есть стул; начните с Hay, слово «там» поставьте в конце**
Плитки: `silla` · `allí` · `Hay` · `una` · `un`.
→ **Hay una silla allí.**
*Плитка `un` лишняя: с silla нужна una.*

**7 · Соберите фразу — там есть книга; начните с Hay, слово «там» поставьте в конце**
Плитки: `libro` · `allí` · `Hay` · `un` · `una`.
→ **Hay un libro allí.**
*Плитка `una` лишняя: с libro нужен un.*

**8 · Послушайте и соберите фразу**
🔊 *Hay una mesa allí.*
Плитки: `Hay` · `una` · `mesa` · `allí` · `aquí`.
→ **Hay una mesa allí.**
*Плитка `aquí` лишняя: звучит allí.*

**9 · Вставьте слово — здесь есть стул; теперь предмет рядом с вами**
`Hay una silla ___.`
→ **aquí** · allí · tiempo
Полная фраза: **Hay una silla aquí.**
- allí — *Теперь нужно «здесь» — aquí.*
- tiempo — *Это время; «здесь» — aquí.*
