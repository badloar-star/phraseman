## Общие причины (повторяются во всех курсах)
1. Грамматические слова без объяснения: подлежащее, форма, личная форма, спряжение, инфинитив, артикль, род, падеж, согласование, множественное число, «связка».
2. Слова из заданий не введены до задания: est/là/au/prêt (fr), è/pronto (it), müde/die Tasche/lerne (de), start/early/late/cold (en), la/él/sí (es).
3. Задание противоречит тексту: fr урок 2, задание 1 — «Меня здесь нет» собирается плиткой «là» («там»), хотя «здесь» = ici.
4. Мета-рассуждения («Не добавляй è перед уже готовой конструкцией, где глагол присутствует», «единственная обязательная мелодия…») — не действия человека.
5. Повтор: de урок 3 содержит дословный абзац из урока 1; en теория повторяет один абзац по несколько раз.
6. Заголовки без содержимого в en («Опишите время или температуру», «Порядок слов в этом ответе») — под ними только служебные коды; частично шум сборщика (исправлен), но пустые блоки проверить на экране.
