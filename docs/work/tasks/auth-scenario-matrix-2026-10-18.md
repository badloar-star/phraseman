# Матрица сценариев входа и выхода (18.10)

Составил «9 · САЙТ» по заданию координатора.

**Правило владельца (18.10).** НИ ОДИН сценарий входа или выхода не заканчивается ошибкой. Исключение одно — нет сети: тогда понятный текст. «Мягкая карточка» — не решение: сценарий должен заканчиваться **успехом**.

Как читать таблицу:
- **Ожидание** — что должен увидеть человек.
- **Журнал** — строка, которая это подтверждает. Метки настоящие, из кода (`identityTrace('[AUTH-LINK-GOOGLE]', '<шаг>')`, `[AUTH-LOGOUT] {stage}`, `logAuthEvent('auth_*')` и т. д.).
- **Эмулятор** — можно ли прогнать на Pixel_8 без паролей, аккаунтами №2 и №3. Аккаунт №1 не трогать.
- **Тест** — какая автоматическая проверка уже покрывает строку. «Мой» = `tests/account_switch_owner_rules_1018.test.ts` (прогон 18.10: 9 зелёных / 1 красный).
- **Сейчас** — расхождение кода с правилом. Источник — опись `a6d2e2812` и последние коммиты Авторизации и Дизайна (`ca5dc9235`, `fba1616e9`, `50effffc1`).

Кнопки Apple на Android нет (`[AUTH-MODAL] apple_hidden`). Поэтому все строки «Apple» — **только iOS**, на эмуляторе Android их не прогнать.

## D. Что ещё нарушает новое правило «только успех»

1. **B1 — отмена окна провайдера.** Убрать текст совсем: человек передумал, это не ошибка.
2. **A5 — двойной сбой очистки при выходе.** Вместо окна «Не удалось выйти» — выход всё равно до шторки входа, а очистку дочистить при следующем запуске.
3. **A9 — удаление.** Окна «Не получилось подготовить удаление» / «Выход не завершился» → доводить фоном.
4. **A11 — `identity_retired` не со «stable».** Вместо окна «Аккаунт удалён… войди другим способом» — свежий профиль.
5. **A12 — тост «Облако сейчас недоступно».** Повтор фоном, без текста.
6. **B5 и B8 для пути через Настройки.** Окна «Перезапусти приложение» и «Прогресс не сохранён… отменена». Решение то же, что и для правила 4: путь «Выйти и войти» (A5 + A2) вместо окна смены в Настройках.

## E. Как прогонять на эмуляторе (Сверке)

- **Аккаунты:** только №2 и №3, они уже добавлены в эмулятор. Паролей не вводить; №1 не трогать.
- **A9 (удаление):** только с №3 и сразу восстановить (A10).
- **Журнал:** `.expo/metro-console.log` или `adb logcat`, искать по меткам из колонки «Журнал».
- **Сеть:** `adb emu network delay gprs`, `adb emu network speed gsm`, авиарежим — `adb shell cmd connectivity airplane-mode enable`.
- **Убить приложение:** `adb shell am force-stop <пакет>` во время колечка на кнопке.
