## Анимационная библиотека (для макетов «Улучшено»)

Реализовать как переиспользуемые CSS-классы/keyframes (только transform/opacity/filter):
1. `spring-in` — вход карточки: translateY(18px)+scale(.96) → 1 с кривой cubic-bezier(.34,1.56,.64,1) (overshoot-пружина), 420мс.
2. `stagger` — каскад появления детей (задержки 40–70мс, fade+rise 10px).
3. `halo-pulse` — пульс двойного кольца/свечения (scale 1→1.08, opacity), 1400–1700мс, ease-in-out, infinite.
4. `float-y` — парение ±6–8px, 1600–2000мс.
5. `shine` — бегущий блик по CTA (градиентная полоса translateX), цикл ~2.8с с паузой (не непрерывно!).
6. `confetti` — 10–16 частиц (разные цвета акцента/золота/голубого), разлёт по дуге с rotate+fall, ~1.6–2.2с, сгорают в opacity 0. Генерить позиции CSS-переменными (--tx,--ty,--rot,--delay) через inline-стили на span.
7. `chest-open` — двухфазная анимация сундука: дрожь (keyframes shake 4 кадра) → крышка (rotateX/translateY) → орб награды spring-подъём + дыхание.
8. `count-up` — число награды «набегает» (JS, rAF, 800мс, easeOut).
9. `burst` — радиальная вспышка за иконкой (scale 0→1.4, fade), one-shot 700мс.
10. `ticket-glow` — мягкое дыхание золотого свечения.
11. `ring-rotate` — медленное вращение conic-gradient кольца (7–9с, linear).
12. `progress-drain` — тонкий прогресс-бар автозакрытия тоста (scaleX 1→0 за длительность).
13. `wiggle` — лёгкое покачивание ±4° для «живости» иконки.
Все бесконечные анимации — только на improved-макетах; у current-макетов статика (мы показываем «снимок»). Для каждого improved-телефона — кнопка «↻ Повторить» (JS снимает/возвращает класс `.play` на телефоне, перезапуская анимации; one-shot анимации должны проигрываться заново).
В шапке документа — глобальный тумблер «Анимации: вкл/выкл» (добавляет/снимает класс на <html>) + `@media (prefers-reduced-motion: reduce)` отключает всё по умолчанию.
Производительность: запретить animation по width/height/top/left — только transform/opacity/filter; частицы — will-change:transform; не больше ~20 одновременно анимируемых узлов на макет.

## Ключевые выводы для TL;DR (использовать)

1. Экосистема оверлеев зрелая архитектурно (OverlayArbiter, 37 ключей, сторож от залипания), но усталость от серий окон ничем не ограничена — на старте легальна очередь из 5+ модалов подряд.
2. Треть наградных модалов — «сиротские» (не подключены к проде): Shard/Throne/RankChange/SeasonResult/DialogVictory/DailyTasksFirstVisit + 2 выключены флагами. Решить судьбу каждого.
3. Три поколения дизайна сосуществуют (RewardCardV2 / лиговая рамка / кастом-тяжёлые) + непоследовательный фон (где-то = CTA, где-то = закрыть, где-то глухой) и крестики-обманщики у сундуков.
4. Доказанный индустрией рычаг — редкие большие праздники: у Duolingo milestone-анимация дала +1.7% D7. У Phraseman праздники частые и равноамплитудные → выгорают. Нужна ярусная модель.
5. Тёмные паттерны осознанные: онбординг-пейвол без крестика, 77-ч urgency с удвоением цены, NoEnergyModal без закрытия фоном при hapticWarning. Каждый — осознанный риск конверсии vs доверия.
6. Тосты: 9 разных компонентов с разной геометрией (низ/верх), разной длительностью (3–12с), разным интерактивом; error-тосты автоскрываются за 3.2с (индустрия: error = липкий).
7. Тексты: повсеместный разнобой ты/вы; a11y-лейблы «Close»/«Закрыть» хардкодом; склонения местами ломаются («2 дней подряд», «1 осколков будут»).
8. Motion-фундамент хороший (constants/motion.ts, springs, reduce-motion), но применяется непоследовательно: Reanimated только у 2 модалов, конфетти выведены, часть системы карточек отключена флагами.

## Технические требования к файлу

- Валидный HTML5, один файл, UTF-8, <html lang="ru">, адаптивная сетка (телефоны переносятся на узком экране).
- Никаких внешних ресурсов. Никаких огромных data-URI.
- JS: только переключатель анимаций, кнопки ↻ Повторить, count-up, аккордеоны TIER 2. Без фреймворков.
- Итоговый размер: ориентир 150–350 КБ. Не больше 500 КБ.
- После сборки: самопроверка — открыть файл, убедиться что нет синтаксических ошибок JS (можно node --check на извлечённый script), посчитать секции/карточки, доложить числа.
