# «Из видео» на pt-BR (18.10 00:16)
Путь: Настройки → Язык интерфейса → Português (Brasil) (через /settings_language), Карточки → плитка «De vídeos» → экран «Dos vídeos» (s19_from_videos.png).
Результат: названия наборов — просто человеческие («Собеседование», «В аэропорту», «Первое свидание…»), без кода и без `.docx` ✅; подписи «24 frases / 21 frases», кнопка «Adicionar +».
🟡 Заголовок экрана — «Dos vídeos» (в коде app/flashcards_video_packs.tsx:234, 'pt-BR': 'Dos vídeos'), а плитка хаба на том же языке — «De vídeos». Для «Из видео» по-португальски верно «De vídeos» («Dos» = «из этих/ из определённых»). Не критично, но разнобой заголовка и плитки.
Побочно: кнопки/плитки pt-BR на Главной читаются; раскладка Настроек и Главной после смены языка «залипает» в прокрутке вниз (мои тапы по верхним пунктам попадали ниже) — отдельное наблюдение для Дизайна. Случайный тестовый голос в опросе «Больше уроков» (локально) и один открытый «Про визитка» — покупок не нажимала.
