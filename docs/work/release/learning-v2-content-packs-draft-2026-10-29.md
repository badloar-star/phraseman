## 1. Зачем

| | JS-бандл Android (Hermes) |
|---|---|
| 04.10 (PM-066) | 34,2 МБ |
| 146 (в магазинах) | 101,4 МБ |
| 2.0.4 (HEAD 28.10) | 121,9 МБ |

Рост — курс Learning V2: каждый JSON `factory_native/generated_release/<lang>/lNN/sNN/*.json` подключён
**статическим `require`** из `factory_native_manifest_*_v1.generated.ts` («Metro static edges»). Итог: весь курс
(10 720 файлов, 189 МБ исходного JSON) лежит в каждой установке и в каждой OTA. Каждый новый урок или язык добавляет
≈3–4 МБ байт-кода.

Из чего состоит сессия (5 файлов) и сколько весит весь курс по типу файла:

| Файл | Весь курс | Кому нужен |
|---|---|---|
| `learner.json` (тексты для ru) | 79,9 МБ | только ru-интерфейсу |
| `learner.uk.json` (тексты для uk) | 79,7 МБ | только uk-интерфейсу |
| `intro.json` | 19,4 МБ | всем |
| `answers.json` | 6,1 МБ | всем (проверка ответов) |
| `auxiliary.json` | 3,9 МБ | всем |

**Главная находка:** ≈ 42 % контента — тексты на втором языке интерфейса, который этому человеку не нужен.
И 100 % — уроки, до которых человек ещё не дошёл: на старте курса из 32 уроков нужны 1–2.

## 2. Как предлагается (по образцу озвучки, b9773b2ca)

Озвучка уже доставляется так: неизменяемые пакеты по хэшу, каталог `current.json`, авторизованный GET через
воркер `phraseman-learning-audio.badloar.workers.dev` (R2), проверка sha256, хранение в `Paths.document`,
воспроизведение только с диска, окно подкачки по прогрессу (`modules/learning-v2/audio/progressive_audio_*`).
Для контента — тот же скелет:

1. **Пакет = (язык изучения, урок, язык интерфейса).** Внутри — 56 сессий: intro + learner.<locale> + answers +
   auxiliary одним сжатым JSON. Путь по хэшу содержимого: `learning-v2/content/v1/<target>/<locale>/lNN-<sha>.json.gz`.
   Оценка: один урок одного языка интерфейса ≈ 2,8 МБ JSON → ≈ 0,4–0,6 МБ gzip.
2. **Каталог** `learning-v2/content/v1/<target>/current.json`: урок → объект, sha256, размер, версия схемы.
   Правка текста урока = новый пакет + новый каталог. **Правки контента едут без сборки магазина и без OTA.**
3. **В бандле остаётся стартовый набор**: уроки 1–2 каждого опубликованного языка изучения на обоих языках
   интерфейса (≈ 6 % курса). Первый запуск и первые занятия идут офлайн и мгновенно, как сейчас.
4. **Окно подкачки** (как у озвучки, по `course_local_progress_v1`): текущий урок + следующий. Скачивание — фоном
   после первого кадра Главной (`runAfterHomeFirstFrame`) и сразу после завершения сессии; не с тапа по уроку.
5. **Офлайн-кэш:** пройденные и текущие уроки не вытесняются: повтор и экзамен главы нужны офлайн. Потолок
   ≈ 50 МБ; вытеснение — только уроков дальше окна. При смене языка интерфейса пакеты другой локали не удаляются
   сразу — только при нехватке места.
6. **Целостность:** sha256 всего пакета + схема перед установкой; атомарная установка (временный файл → перенос),
   битый или частичный файл никогда не виден плееру. Повторная загрузка — с ограниченными ретраями.

## 3. Путь «урок не скачан»

Правило владельца 04.10 — разделы открываются мгновенно, без полноэкранных загрузок. Поэтому:

- **Обычный случай:** пакет следующего урока уже скачан фоном (п.2.4) — человек ничего не замечает.
- **Онлайн, пакета нет** (прыжок через уроки, тест уровня, переустановка): карточка урока на карте курса сразу
  кликабельна; экран урока открывается со скелетоном на месте блока сессии и тихим индикатором загрузки
  (≈0,5 МБ — секунда-две на мобильной сети). Полноэкранного спиннера нет.
- **Офлайн, пакета нет:** на карте курса у урока тихий значок «нужен интернет»; вход показывает состояние D158
  «Сейчас недоступно» с понятной причиной и кнопкой «Повторить», плюс подсказку пройти скачанные уроки.
  Энергия и попытки не списываются до фактического старта сессии.
- **Каталог недоступен, пакеты в кэше:** работаем по кэшу, тихий признак обновления (правило «ошибка сети при
  наличии кэша не ломает экран»).
- **Логи (сперва логи):** префикс `[V2-PACK]` — вход (target, урок, локаль, источник: бандл / кэш / сеть), каждое
  ветвление со значением, сеть (код, байты, мс), каждый ранний выход и catch; итог — что увидел человек. Событие
  журнала обращений `v2pack:<target>:lNN:<outcome>`.

## 4. Стоимость

- **Firestore: 0 чтений** — всё через Storage/R2, как озвучка.
- **Трафик:** весь курс одного языка изучения одной локали ≈ 32 × 0,5 МБ ≈ 16 МБ на человека за всё время.
  Через воркер на R2 исходящий трафик бесплатный; платные только операции чтения (класс B, $0,36 за миллион):
  ≈ 1 GET каталога на холодный старт (кэш по ETag, раз в N часов) + 1 GET на урок. Это центы в месяц при
  нынешней аудитории.
- **Экономия:** установка и каждая будущая OTA легче на ≈ 80–100 МБ; правки текстов без выпуска.

## 5. Что сломается без особой осторожности (сторожа и связи)

- Цепочка «сессия открывается» (CLAUDE.md, чек-лист `docs/v2/КАК_ВЫПУСКАТЬ_СЕССИЮ_ЧЕКЛИСТ.ru.md`) и сторож
  `tests/learning_v2_es_bundle_reachability_guard.test.ts` проверяют, что сессия **в бандле**. Их нужно переписать
  на «в бандле или в каталоге + стартовый набор в бандле», иначе вернётся класс `stable_identity_unavailable`
  («сессия не нашлась локально → ушла в сеть»).
- `esAuthoredEpisode01ContiguousCeilingV1` (автопотолок) должен считать только то, что реально доступно.
- `app/learning_language_surface_readiness.ts` (D129/D130): «раздел включён» ≠ «пакет скачан»; таблица остаётся
  про включение, доступность — отдельный слой.
- Тест уровня и экзамен главы берут задания из нескольких уроков — им нужен пакет каждого задействованного урока.
- Озвучка уже знает урок и сессию; пакеты контента и звука скачиваются одной очередью, чтобы не удваивать окна.
- **`answers.json` сейчас в бандле**, то есть правильные ответы есть на устройстве. В CLAUDE.md (раздел App Check)
  записано «правильные ответы заданий физически не покидают сервер». Нужно сверить с решениями D-реестра:
  пакеты дают шанс держать ответы отдельно (или серверно), но это решение владельца, не побочный эффект.
- **Политика конфиденциальности:** новых данных нет. Загрузка с CDN раскрывает IP так же, как озвучка через
  Cloudflare (политика 9234036b0). Формулировку «аудио» стоит расширить до «аудио и учебные материалы».

## 6. Этапы (оценка)

| 0 | Решение владельца + сверка D-реестра про ответы | — |

| 3 | Резолвер контента: бандл → кэш → «не скачан»; переписать манифест на ленивую часть | 1–1,5 дня |
| 4 | Экраны: карта курса, вход в сессию, D158, логи `[V2-PACK]` | 1 день |
| 5 | Сторожа «сессия открывается», тест уровня, экзамен, автопотолок | 1 день |

но первая версия с пакетами всё равно должна прийти сборкой магазина (новый путь загрузки).

## 7. Вопросы (координатору / владельцу)

1. Стартовый набор в бандле: уроки 1–2 или 1–4 каждого языка? Больше — надёжнее офлайн, тяжелее бандл.
2. Офлайн без пакета: показывать урок закрытым на карте или открывать с D158 при входе?
3. Предварительная загрузка: только Wi-Fi или любая сеть (≈ 0,5 МБ на урок)?
4. `answers.json`: оставить на устройстве (как сейчас) или вынести? Это меняет безопасность, а не только размер.
5. Порядок: сразу после 2.0.4 или раньше 2.0.4, если замер холодного старта (п.7(а)) покажет регресс?
6. Промежуточный шаг: бандлить только ru-тексты, а uk — пакетом? Это −40 % бандла за ≈ 2 дня, но даёт два пути
   контента вместо одного; я бы делал сразу общий механизм.
