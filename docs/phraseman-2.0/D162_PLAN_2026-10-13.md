# D162 — переход между лигами Пика по монетам недели: план внедрения (Ядро, 13.10)

D162 (OWNER_FINAL 10.10): повышение/понижение решает ТОЛЬКО сумма монет, заработанных во всех режимах за неделю; счёт Пика
(ступени, этажи) на переход не влияет; сумма — одно поле-счётчик, растущее при начислении; начисления не меняются.

**Сейчас (находка Макетов, проверено):** место/повышение/понижение — по ступеням: `functions/src/spire_finalize_core.ts:131`
(`compareSpireStanding`, сорт по `steps`), клиент `components/spire/SpirePodium.tsx:30`, `modules/spire/room_rows.ts:103`.

## Что уже есть (код 13.10)

- **Счётчик недели уже существует и серверный:** `users/{uid}.stars.weekEarned` в журнале монет (`stars_ledger.ts:653–662`) растёт
  при каждой операции класса `earn` (практика/уроки/диалоги `practice_session`, Learning V2, ступени Пика `spire_step`, …), призы и
  выдачи (`grant`) — нет. Неделя переносится лениво при записи; `starsWeekEarned(stars, weekKey)` (`:368`) читает и прошлую неделю
  (`prevWeekEarned`) — финализация в понедельник видит закрытую неделю. Пересчёта истории нет.
- **Неделя совпадает:** журнал — `getWeekKey` (ISO-неделя по UTC, `progress_events.ts:225`), комната — `spireWeekId`
  (`spire_groups.ts:79`) — один алгоритм, формат `YYYY-Www`.
- **Вход в комнату и отчёт ступеней уже читают `users/{uid}`** (`spire_groups.ts:230`, `spire_progress.ts:186`; отчёт пишет
  `spire_step` в журнал в той же транзакции) → снимок монет недели в комнату = **0 лишних чтений**.
- Повышение/понижение и места 1–3 считаются **только по живым** (`liveRank`); боты влияют лишь на показанный `roomRank`.

## Риски

- 🔴 **Накрутка:** сумму практики (`practiceRuneGrant`) задаёт клиент (PM-291) — при ранжировании по монетам модифицированный
  клиент поднимет себя в комнате. Ступени проверяются сервером строже. Для R1: в финализации — потолок суммы недели (константа
  в `config/spire_v1`), либо принять риск до PM-291.
- 🟡 **Показ ≠ итог:** если клиент (п.4) не успеет в сборку 16.10, а сервер (п.2) включит монеты, человек видит место по ступеням,
  а итог недели — по монетам. Поэтому **п.2 без п.4 не включать**.
- 🟡 **Гейт макетов:** смена числа на подиуме/в списке — новое состояние экрана, нужен утверждённый образец.
