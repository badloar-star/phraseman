# Моменты v3 — сценарий проверки на эмуляторе (для Сверки)

**Дата:** 15.10 · **Автор:** МОМЕНТЫ · **Основа:** 4f8a07461 (флаг `moments_v3` включён по умолчанию; выключает только явный `false` в `remote_config/app.bools`)

## 0. Подготовка (один раз)

Ссылки открываются так (dev-сборка, эмулятор `emulator-5554`):

```bash
adb -s emulator-5554 shell am start -W -a android.intent.action.VIEW -d "phraseman://dev_state?moments=v3&next=/(tabs)/home" app.phraseman
```

- `moments=v3` — dev-переключатель (только `__DEV__`, ключ `dev_moments_v3_override`). С 4f8a07461 флаг и так включён, но переключатель
  убирает зависимость от кэша конфига. `moments=off` — проверка, что всё прячется; `moments=inherit` — снять подмену.
- Журнал: `.expo/metro-console.log` (или `adb logcat -s ReactNativeJS`). Ищем по префиксам из таблицы.
- Первая строка, которую надо увидеть после запуска:
  `[MOMENTS-V3-FLAG] {"source":"screens","remote":"absent","cache":"есть",...,"effective":true}`. Ворота окон Главной пишут то же
  со своим `source`: `spire_week`, `coin_rank_enough`, `welcome_back`.
- Если какого-то момента не видно, сначала ищите его префикс: каждый ранний выход называет причину (`не показываем: …`, `нет (…)`, `reason=…`).
- Окна Главной идут через арбитр по очереди, а не одновременно: D191 → монета → «С возвращением». Проверяйте их по одному и закрывайте предыдущее.

Все `dev_state`-параметры работают только в dev-сборке (`__DEV__ && !IS_STORE_RELEASE`). В стор-сборке они отклоняются или подменяются заглушками `store_release_stubs/dev_state/*`.

## 2. Что важно для Сверки

- **«Сначала журнал»**: если момент не появился, приложите строку его префикса. Причина в ней называется всегда.
- **Порядок на итоге урока**: рубеж серии → цепочка m10 → «ИДЕАЛ» m09 → оценка приложения. На итоге диалога: рубеж → m17.
- **Один раз**: D191 — раз в неделю на язык (dev-ветка спрашивает каждый раз — снимать подмену `spireWeek=off`); монета — раз на ранг;
  «С возвращением» — раз на возвращение; m17 — раз на изучаемый язык (сброс — `dialogsDone=reset`); m09 — раз на прохождение.
- **Без сервера 17.10**: ни один момент не зависит от выкладки 17.10. D191 в бою читает итог недели, который пишет уже работающий
  сервер; нет документа → окна нет, без падения.
- **Новое в этом коммите**: dev-ветка D191 (`spireWeek` теперь ведёт и окно на Главной, а не только карточку в Пике), журналы `[MOMENT-m09]` и `[MOMENT-m11]`.
  Сторож — `tests/moments_v3_emulator_hooks.test.ts`.
