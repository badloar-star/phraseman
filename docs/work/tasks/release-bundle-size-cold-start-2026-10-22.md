## Предложения (на решение координатора и Learning V2)

1. Сгенерированные данные вынести из `app/` в `modules/` (или `data/`): dev перестанет их выполнять на старте (OOM),
   а в релизе они будут в бандле только при реальном импорте. Владельцы — Learning V2 (их файлы).
2. Связка B «только TTS»: если записанное аудио больше нигде не нужно — убрать ленивые `require` аудио-индексов и
   production_audio_entries → ≈ 8,1 МБ из бандла. Только с согласия Learning V2.
3. Манифест factory_native: разрезать по уроку (шард на урок, `require` по уроку) — бандл тот же, но память и разбор
   только для открытого урока. Решает Learning V2.
4. Замер релизного экспорта — когда будет ≥ 8 ГБ свободной памяти и слот: экспорт с картой исходников, топ-20 по весу.
