## Outcome

Ролик, где видео идёт ПОДРЯД: прозвучала английская фраза — видео замирает,
показывается её русский перевод, идём дальше к следующей фразе. Каждая фраза,
без пропусков и без отбора «интересного».

Успех: на готовом ролике перевод на экране относится ИМЕННО к той фразе,
которая только что прозвучала; плашка с текстом видна только в момент паузы
и исчезает, когда видео продолжается.

## Scope

- `content/clipper/render_seq.py` — новая сборка: чередование видео/пауза.

## Architecture

Текущая граница: конвейер ОТБИРАЕТ 3-5 «интересных» моментов из всего видео
(модель + порог score), остальное пропускает; плашка с текстом присутствует
всю длительность паузы.

Целевая: отбора нет. Берём непрерывный отрезок видео и режем его на фразы
по границам речи из транскрипта. Каждая фраза -> пара (видео, пауза с
переводом). Пауза длится фиксированно, не по длине озвучки.

Инвариант: перевод в паузе N принадлежит фразе из отрезка N. Рассинхрон
физически невозможен, потому что текст и отрезок берутся из одной записи.

Решение: озвучки нет вовсе. Повод — рассинхрон «озвучивается не то, что на
экране» возник именно из-за того, что озвучка и видеоряд собирались из разных
источников. Убирая озвучку, убираем класс бага, а не конкретный случай.

## Security and privacy

Личных данных не обрабатывает: вход — видео на диске владельца, выход — файл
там же. Firestore, аккаунты, детские данные не затронуты. Privacy policy
обновления не требует.

Секреты: в этом режиме внешние API не вызываются вовсе (перевод делает модель
в диалоге, транскрипция локальная). ELEVENLABS_API_KEY не используется.

Копирайт: как и прежде, права на исходник — ответственность владельца.
input/work/output закрыты в .gitignore.

## Technical debt

- **Accept temporarily:** перевод фраз выполняет модель в диалоге, а не
  автоматический вызов. Владелец, пересмотр — когда режим устоится.
- **Contain:** два режима сборки (отбор моментов и пофразовый) живут рядом.
  Граница — отдельные файлы render.py / render_seq.py. Условие выхода: если
  пофразовый победит, старый удаляется.
- **Pay now:** убран рассинхрон озвучки и видеоряда — источник один.
