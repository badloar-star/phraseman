## Architecture

Страница не меняет движок: берёт SR.recolor с готовым растром неба (сопоставление строк: y < 340 → y, y ≥ 393 → y − 53), затем
хирургия строк на холсте кадра (полоса неба убрана, низ сцены на 1029, зазор, карточка и всё ниже сдвинуты на +3 px, таббар 2140+ не
трогается), перекраска угловых зон (r 28 dp внутри — цвет сцены, снаружи — фон страницы), тень (только на пикселях фона: зазор и поля),
герой заново по SA.heroHome(W, 1029). Инвариант: эталоны и parity не затронуты (движок без правок).
