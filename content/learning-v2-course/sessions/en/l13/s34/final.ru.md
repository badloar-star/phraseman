# Английский · Урок 13 · Занятие 34 — По дороге к друзьям

**Ситуация.** Уточните у друга порядок вчерашних событий в дороге.

**Что вы освоите:** review: past event sequence
**Новые слова:** set off, stop off, drop off, run into

## Интро 1

### Отправиться в путь

Set off — отправиться в путь. First of all, we set off at eight — первым делом мы отправились в восемь. Did you set off early? — Ты отправился рано? Выберите вопрос.

**Выберите фразу для этой ситуации.**

- ✅ **Did you set off early?**
- ❌ You set off early. — *Это сообщение, не вопрос.*
- ❌ Do you set off early every day? — *Это вопрос о привычке.*

---

## Интро 2

### Остановиться по пути

Stop off — ненадолго остановиться по пути. Then we stopped off at a café — затем мы ненадолго остановились в кафе. Выберите остановку по пути.

**Выберите фразу для этой ситуации.**

- ✅ **Then we stopped off at a café.**
- ❌ First of all, we set off at eight. — *Это отправление, а нужно остановиться по пути.*
- ❌ Then we stop off at a café yesterday. — *Для прошлого нужна stopped.*

---

## Интро 3

### Завезти и случайно встретить

Drop off здесь — завезти и оставить вещь или человека в нужном месте. Run into здесь — случайно встретить знакомого. Did you run into your neighbour? — Ты случайно встретил соседа? Выберите встречу.

**Выберите фразу для этой ситуации.**

- ✅ **Did you run into your neighbour?**
- ❌ Did you drop off the parcel? — *Это доставка посылки.*
- ❌ Did you ran into your neighbour? — *После did нужна run.*
