# Task packet: друзья без ложного «пусто» и урок без лишнего кадра-заготовки

Governance-ID: TG-04027487D047
Status: In progress
Owner: сессия аудита загрузок 11.11 (владелец: «Старт и вкладки» → «Правь сейчас»)

## Outcome

1. Вкладка «Друзья» на чистом кэше (первый запуск, смена аккаунта) больше не показывает
   «Учиться вместе приятнее / Добавить друга» до того, как список реально получен. Пустое
   состояние появляется только когда подписка ответила, упала, либо истёк потолок 2,5 с.
2. Урок без вступления (комби, урок без экранов вступления, dev-пропуск) не рисует
   кадр-заготовку `LessonFirstFrame` перед первым вопросом: готовность считается синхронно.

Мера успеха: в журнале `[FRIENDS-LIST] settled` с причиной; на холодном входе в «Друзья»
с друзьями пустое состояние не мелькает.

(ленивая инициализация `introGateReady`).

- каркасы для этих вкладок и снятие заставки — нужен макет и решение владельца.
