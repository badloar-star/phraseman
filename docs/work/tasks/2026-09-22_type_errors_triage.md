## Outcome

Владелец понимает, что скрывается за 417 ошибками типов: какие из них ломают
приложение пользователю, какие — только проверку, и что с каждым классом делать.
Критичные для пользователя — починены.

Успех измеряется не числом ошибок, а фактом: ни одна ошибка типов не соответствует
поломке, которую видит пользователь.

## Scope

In scope:
- классификация всех 417 ошибок по классам и корневым причинам;
- **сделано**: починка `ReferenceError` в [lessons.tsx](app/(tabs)/lessons.tsx) —
  экран уроков падал на каждом рендере (коммит `afaa9887f`);
- разведка по классу «языки es/de не поддержаны» (22 ошибки, 8 модулей);
- разведка по классу «контент Learning V2» (191 ошибка).

Out of scope (до отдельного решения владельца):
- массовая правка типов в 8 модулях под четыре языка — сначала разведка, потому
  что за типами может стоять отсутствующий контент: типы позеленеют, а функция
  останется пустой;
- правка генератора курса и перегенерация контента.

## Architecture

Изменение в `lessons.tsx` — **без изменения архитектуры и логики**: блок
«спокойного отказа» (49 строк: state, timers, progress, style, clearTimers,
showHint) перенесён целиком выше `launchSelectedLearningV2Session`. Ни одна
строка логики не менялась, только порядок объявления.

Инвариант, который был нарушен и теперь восстановлен: **объявление `const` обязано
стоять выше всех хуков, упоминающих его в массиве зависимостей**. Массив
зависимостей вычисляется в рендере немедленно — в отличие от тела колбэка,
которое выполняется по событию. Прежний комментарий утверждал, что «объявлена ниже
и это безопасно»: верно для вызова внутри `.catch()`, неверно для deps-массива.

## Security and privacy

Не применимо: перенос объявления в UI-компоненте. Персональных данных,
разрешений, сторонних сервисов, детских данных не затрагивает — Privacy Policy
не требует обновления.

Отмечено на будущее: разведка по es/de отдельно проверяет, не пишет ли выбор
испанского в ключи хранилища другого языка (риск порчи пользовательских данных).
Если подтвердится — это уже вопрос сохранности данных, не только типов.

- **Pay now** — `ReferenceError` в `lessons.tsx`: устранён.
- **Contain** — 22 ошибки «языки es/de»: граница на время разведки — знание, что
  испанский предлагается пользователю при неполной поддержке. Exit: отчёт
  разведки → решение владельца, чинить типы или закрыть выбор языка.
- **Contain** — 191 ошибка в контенте Learning V2: контур авторский (сборка курса),
  в рантайм-бандл предположительно не входит — это проверяет разведка. Exit: отчёт
  с числом уникальных дефектов за этими ошибками.
- **Accept temporarily** — оставшиеся 415 ошибок не блокируют сборку: Metro
  собирает через Babel и типы не проверяет, поэтому релиз 1.6.24 собрался успешно.
  Владелец: владелец проекта. Потолок ущерба: проверка типов бесполезна как
  сторож, пока красная. Exit: доведение до нуля по классам.

Ограничение метода, которое надо помнить: **зелёная проверка типов ≠ экран
открывается**. Именно этот баг тип-проверка поймала, но родственный класс
(`const` выше объявления внутри тела функции) она не ловит вовсе — память
`project_const_used_before_declared_killed_screen`.

## Rollback

`git revert afaa9887f` возвращает прежний порядок объявлений в `lessons.tsx`.
Пользовательских данных не затрагивает, миграций нет. Откат вернёт
`ReferenceError` на экране уроков, поэтому делать его стоит только вместе с
другим способом починки.
