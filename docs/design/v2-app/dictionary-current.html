Словарь — как сейчас по коду

В приложении два «словаря», и они не связаны друг с другом: словарь курса Learning V2 (кнопка-книжка в шапке карты уроков) и классический «Словарь урока N» (старый курс). Есть и третье, малое место — «Карман слов» внутри занятия Learning V2: слова текущего урока и колода карточек по нажатию (LearningV2WordPocketOverlayV1.tsx); отдельным макетом его не рисую. Ниже два словаря — один в один с экраном: размеры, тексты и состояния взяты из кода. Для словаря курса есть и прежний эталон — блок «Словарь» в learning-v2.html (экраны 2.7–2.9); этот файл показывает то же самое в обеих темах плюс вход и классический словарь.
