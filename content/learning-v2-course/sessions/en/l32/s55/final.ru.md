# Урок 32 · Занятие 55 — Разбираем вещи после поездки

**Ситуация.** Вы с Анной разбираете дорожную сумку дома.

**Что вы освоите:** объяснять предположение, отвергать невозможный вариант и уточнять предмет.
**Новые слова:** —
**Повторяем знакомые слова:** bag, shirt, book, towel

## Интро 1

### Наблюдение и возможность

Вы поднимаете закрытую сумку и по небольшому весу предполагаете, что Анна уже вынула вещи. The bag is light, so it might be empty. — Сумка лёгкая, поэтому она, возможно, пустая. Соберите The bag is light + so + it might be empty. До so назовите наблюдение, после so — возможный вывод с might. Перед состоянием empty нужна связка be.

**Выберите фразу для этой ситуации.**

- ✅ **The bag is light, so it might be empty.**
- ❌ The bag is light, so it might is empty. — *После might используем be.*
- ❌ The bag is light, so it might to be empty. — *После might не ставим to.*

---

## Интро 2

### Этот вариант исключён

Из рубашки капает вода. Анна считала, что она высохла после дождя. The shirt can't be dry. — Рубашка не может быть сухой. Соберите The shirt + can’t + be + dry. Наблюдение исключает названное состояние. Can’t выражает этот вывод; перед dry здесь нужна связка be.

**Выберите фразу для этой ситуации.**

- ✅ **The shirt can't be dry.**
- ❌ The shirt can't is dry. — *После can’t используем be.*
- ❌ The shirt can't to be dry. — *После can’t не ставим to.*

---

## Интро 3

### Уточняем предмет

Вы показываете Анне предмет и уточняете своё действие с ним: The book I read is short. — Книга, которую я прочитал, короткая. Соберите The book + I read + is short. Часть I read уточняет book. That можно опустить: I уже называет того, кто выполнил действие.

**Выберите фразу для этой ситуации.**

- ✅ **The book I read is short.**
- ❌ The book I read it is short. — *Не повторяем названный предмет словом it.*
- ❌ The book I reading is short. — *Нужна прошедшая форма read.*
