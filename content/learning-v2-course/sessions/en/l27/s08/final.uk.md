# Урок 27 · Заняття 08 — Облаштувати кімнату

**Ситуація.** Ви розміщуєте книжки й лампу, обговорюєте покупку ліжка та обираєте крісло.

**Що ви опануєте:** сказати, що було б, якби…, і не плутати «вже зроблено» з «було тоді»
**Нові слова:** bookshelf, nightstand, headboard, armrest

## Інтро 1

### Якби було більше місця

Ви хочете переставити книжкову полицю, але вільного місця бракує. Поясніть: I would move it if I had more room — я б переставив її, якби мав більше місця. It замінює полицю; room тут означає простір. Складаємо: I + would move + it + if I had more room — хто, що зробив би, що переставив би, за якої умови. Після would потрібна move без to. Had після if описує уявну умову зараз.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would move it if I had more room.**
- ❌ I would moved it if I had more room. — *Після would потрібно move.*
- ❌ I would move it if I would had more room. — *Після if тут had без would.*

---

## Інтро 2

### Коли купили ліжко

Друг помітив ваше нове ліжко й запитує, коли ви його купили. Дайте відповідь: We bought it last week — ми купили його минулого тижня. Складаємо: We + bought + it + last week — хто, дія в минулому, що купили, коли. Bought — минула форма buy, не buyed. Last week указує завершений час, тому використовуємо bought без have. It замінює вже назване ліжко.

**Виберіть фразу для цієї ситуації.**

- ✅ **We bought it last week.**
- ❌ We have bought it last week. — *Із last week тут past simple.*
- ❌ We buyed it last week. — *Минула форма buy — bought.*

---

## Інтро 3

### Якби крісло проходило у двері

У магазині вам сподобалося крісло, але воно зашироке для ваших дверей. Поясніть: I would buy it if it fitted through the door — я б купив його, якби воно проходило у двері. Складаємо: I + would buy + it + if it fitted through the door — хто, що зробив би, що купив би, за якої умови. Після would потрібна buy. Fitted після if позначає уявну умову зараз; would у цю частину не додаємо. В американській англійській замість fitted також уживають fit.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would buy it if it fitted through the door.**
- ❌ I would buying it if it fitted through the door. — *Після would потрібна початкова форма buy.*
- ❌ I would buy it if it would fitted through the door. — *В умові fitted без would.*
