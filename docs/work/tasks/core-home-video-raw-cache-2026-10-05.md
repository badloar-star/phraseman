## Outcome

Новый лёгкий модуль app/lingman_youtube_feed_disk.ts (только AsyncStorage + id канала из remote_flags) читает
сохранённый список канала. Главная вызывает его сразу при монтировании — не ждёт ни импорта ленты, ни
homeRuntimeActive — и показывает ролики из кэша. Дальше прежний путь: импорт модуля ленты → сеть раз за запуск →
пины «Пульта» подмешиваются. Для языков с лентой из каталога (es/fr/de/it) — без изменений.

## Scope

app/lingman_youtube_feed_disk.ts (новый), app/lingman_youtube.ts (ключ хранилища и id канала по умолчанию берутся из
лёгкого модуля — один источник), app/(tabs)/home.tsx (эффект чтения кэша при монтировании + лог).

## Architecture

Ключ хранилища и формат записи не меняются. Кэш привязан к id канала: если «Пульт» сменил канал — не показываем.

## Security and privacy

## Technical debt
