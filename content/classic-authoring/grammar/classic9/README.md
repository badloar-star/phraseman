# PhraseMan Classic · Испанский ES-01–09

Девять готовых для переноса банков по 50 переводов. 01–06 — принятая редакция `classic6`. 07 — наличие с **hay**; 08 — краткие притяжательные **mi / tu / su** и их множественное число; 09 — настоящее время правильных **-ar** на четырёх частотных глаголах. Следующая тема — ES-10, настоящее время правильных -er/-ir. В плане 32 темы, но уроки 10–32 здесь не объявляются готовыми.

**Просмотр.** `START.html` — автономный тренажёр. Вверху выбрать любой урок. `START.html#L7` — сразу к новой партии. `THEORY.html` — только вступления и подробные объяснения. `ALL-450.html` — поиск и сверка переводов и разборов; `ALL-450.tsv` — те же данные для редактора. У всех девяти уроков три блока вступления по образцу старого английского курса Сары: смысл, формула, разбор сборки. По нажатию следующая карточка добавляется под предыдущей. После третьего блока появляется «Начать тренировку». Семь глав теории доступны отдельно. Практика — только перевод по одной целой испанской словоформе, шесть вариантов на позицию, даже когда теория разбирает основу и окончание. Никаких встроенных вопросов Learning V2.

**Что переносить.** Файлы `lessons`, `classic-intro`, `classic-theory` и `classic-adapter` с одинаковым номером образуют один урок. Загружать ES как изучаемый язык, ru/uk как язык подсказок. Поле `english` — технический перевод для старого типа, это не целевая озвучка. Сохранять `context`, особенно если регион, число адресатов или форма обращения отличают один допустимый ответ от другого. Для интро использовать прежний `LessonIntroScreens`, для справки передавать `getSpanishClassicTheory` из приложенного адаптера, где зарегистрированы уроки 1–9. Для практики переносить ID, порядок, все словесные позиции и пояснения; пунктуация не является плиткой. Для словаря — `ledger.json`, список `vocabulary.new` текущего урока и `seenBefore`. Для справочников — `grammarTables` и `verbTables`. У безличного hay не надо дорисовывать ещё пять фиктивных форм. У su одна форма может относиться к разным владельцам: смотреть на подсказку, не угадывать за ученика. Нажатие на пример и возврат из теории должны сохранять позицию сборки.

**Независимость от старых блоков.** 300 прежних упражнений, их идентификаторы, вводные тексты и адаптеры данных предыдущих уроков не заменены. Лексические записи продолжают прежнюю систему идентификаторов; повтор формы не создаёт лишней карточки. Например, salidas остаётся формой старого salida; clase в значении учебной группы получает отдельный ключ с реальной фразой-основанием. Предложенные альтернативы в свободном переводе иллюстративны, а не исчерпывающи.

**Сборка из исходников.** В полном ZIP открыть `source`. В репозитории эта папка соответствует `content/classic-authoring/grammar/`. Python 3.10+ и стандартная библиотека: `python3 -B classic6/build.py /tmp/pm-six`; затем `python3 -B classic9/release.py /tmp/pm-six /tmp/pm-nine`; `python3 -B classic9/verify9.py /tmp/pm-six /tmp/pm-nine` (для проверки в браузере нужен локальный Chromium или Chrome). Каталоги результатов должны быть отдельными от исходников; каталог для новой сборки должен быть пустым. Для комплектации архива скопировать папку с авторскими исходниками в `source/`. Контрольные суммы и протокол проверки — `qa/`. Просмотр браузера не заменяет вычитку независимым преподавателем и испытание на iOS/Android. Нет изменений мобильного приложения, профиля, экономики, Firebase или публикации.

Методические источники для перепроверки: Instituto Cervantes, *Plan curricular, Gramática A1–A2* (https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/niveles/02_gramatica_inventario_a1-a2.htm); AVE, *Hay o está* (https://cvc.cervantes.es/ensenanza/actividades_ave/niveli/ficha_13.htm); AVE, *El presente de indicativo* (https://cvc.cervantes.es/ensenanza/actividades_ave/niveli/ficha_08.htm). Предложения и объяснения авторские.
