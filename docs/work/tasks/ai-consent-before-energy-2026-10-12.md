# Диалоги: энергия списывается только после согласия на ИИ

Governance-ID: TG-284436D1E9EE

## Outcome
Находка Макетов `d8b078e8e`:
- «Начать диалог» (`app/dialogue_v2_briefing.tsx`) списывал 1 энергию ДО согласия на ИИ.
- Шторка согласия жила в `AiDialogConsentGate` внутри сессии. Сессия смонтирована только после согласия, поэтому при отказе её механизм возврата энергии (`energyOp`, `settleEnergy`) не срабатывал — энергия терялась.
- То же у человека, который отказался раньше: списание, затем экран «AI-диалоги выключены».

Стало:
- Брифинг спрашивает согласие САМ, до списания. Это совпадает с макетом `dialogs.html` B3: шторка поверх брифинга.
- Списание только после согласия.
- Отказ — без списания, человек остаётся на брифинге.
- Страховка: если в сессию всё же пришли со списанной энергией (`energyOp`), а согласие там отклонено, энергия возвращается (`refundActivityStart`) с логом.

## Scope
- `app/dialogue_v2_briefing.tsx` — проверка согласия перед `confirmSpendOne`, шторка `AiDialogConsentModal`, логи.
- `app/ai_dialog_consent_gate.tsx` — необязательный колбэк `onDeclined`.
- `app/dialogue_v2_session.tsx` — передаёт `onDeclined`: возврат `energyOp` + лог.
- Тесты: `tests/dialogue_v2_briefing_route.test.ts` (оба пути), сторож источника по необходимости.
- `docs/phraseman-2.0/AUTH_RELEASE1_TEST_SCENARIO_2026-10-11.md` — шаги C1–C3, F6/G2: выход мгновенный, окна «Выйти из аккаунта?» нет.

## Architecture
- Состояние согласия — синхронно из памяти (`isAiDialogConsentHydrated` / `isAiDialogConsentGranted`).
- Если ещё не прочитано с диска — `hydrateAiDialogConsentFromStorage()` перед решением (0 сети).
- Согласие пишется как в gate: локально сразу, в облако фоном.
- Gate в сессии остаётся: страховка для прямых входов (`ai_dialog_session`, `ai_companion_session`) и отзыва согласия.

## Security and privacy
- Логика согласия та же: OpenAI только после «Принять».
- Ничего нового не собирается, политика не меняется.

## Technical debt
- Отказ на брифинге закрывает шторку без экрана «выключены». Повторный тап «Начать» снова покажет шторку — так в макете.

## Verification
- Логи `[AI-CONSENT-ENERGY]` на каждой ветке.
- Тесты:
  - согласие есть → списание и переход;
  - согласия нет → шторка, списания нет;
  - принять → списание и переход;
  - отказ → списания нет, перехода нет;
  - отказ в сессии со `energyOp` → возврат.
