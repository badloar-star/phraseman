## Architecture

**Прочитано перед правкой:**
- `video_phrase_sets/{videoId}` — корневой документ, поля `activeVersion`,
  `activePhraseCount`, `updatedAtMs` (см. `publishedRootPatch`);
- версии в подколлекции `versions/{versionId}`, у опубликованной
  `status === 'published'` и есть `sourceName` + `phrases`;
- `buildVideoPackDoc` уже вынесен чистой функцией — backfill переиспользует её,
  второй копии сборки документа не будет;
- языковой контур: `app/flashcards/pack_languages.ts` (`PackLanguage`,
  4 языка), готовый UI `PackLanguagePicker.tsx`, хранение выбора
  `pack_language_preferences.ts` (`getStoredPackLanguage`/`setStoredPackLanguage`).
  Именно его просил владелец — «языковой контур», а не цель обучения.

**Backfill:** админская callable, проходит по `video_phrase_sets` постранично
(`limit` + курсор по id), для каждого документа с непустым `activeVersion`
читает версию, берёт фразы и зовёт тот же `syncVideoPack`. Идемпотентна:
id набора детерминированный (`video_{videoId}`), повторный прогон обновляет,
а не плодит копии; `keepSocial` сохраняет лайки уже живущих наборов.

**Язык:** экран показывает `PackLanguagePicker` и фильтрует выдачу по
выбранному языку, а не по цели обучения. Выбор запоминается тем же хранилищем,
что и в каталоге наборов, — человек не переключает язык дважды.

**Риск, который снимается сознательно:** backfill трогает `community_packs` —
чужую коллекцию. Поэтому он только админский (`requireAdmin`), пишет строго
через `buildVideoPackDoc` и не удаляет ничего.

## Security and privacy

- `adminBackfillVideoPacks` требует `admin`-claim и разрешения `content.publish`
  — та же проверка, что у публикации. Обычный пользователь её не вызовет.
- Правила Firestore не меняются: клиенту `community_packs` по-прежнему
  read-only + три счётчика.
- Новых персональных данных не собирается; uid не показывается.
- Обращение к YouTube (превью/плеер) уже отмечено ранее: политику приватности
  обновить ДО релиза. Повторяю в 🔴-итоге.

## Technical debt

- **Pay now**: backfill переиспользует `buildVideoPackDoc` и `syncVideoPack` —
  ни одной второй копии сборки документа.
- **Pay now**: выбор языка берётся из существующего `PackLanguagePicker` и
  общего хранилища, а не заводится третий способ хранить язык.
- **Contain**: backfill читает коллекцию постранично с `limit`. Граница —
  страница 100 документов, курсор по id. Exit condition: если роликов станет
  тысячи, вынести в задачу по расписанию.

## Verification

Тяжёлые проверки ЗАПРЕЩЕНЫ владельцем на этом ПК. Ни прогонов тестов, ни
полной проверки типов, ни сборок. Слот не берётся.

Проверка чтением и логами:
1. Backfill логирует КАЖДЫЙ пропуск с причиной (нет activeVersion, версия не
   published, ноль фраз) — пустой результат обязан объяснять себя.
2. Возвращает счётчики: сколько просмотрено, создано, пропущено.
3. Экран языка: выбранный язык виден в заголовке фильтра, список меняется.
4. Ни одного немого `catch`, каждый ранний выход логирует причину.

## Rollback

Backfill ничего не удаляет и идемпотентен — повторный прогон безопасен.
Созданные наборы остаются рабочими наборами карточек даже при откате клиента.
Кнопка в админке — отдельный элемент, её удаление ничего не ломает.
