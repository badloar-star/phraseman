# Task packet: исключить корневую content/ из сканирования Metro

Governance-ID: TG-441DCCC0ACA3
Status: In progress

Related epic/enabler: none

## Outcome

Metro перестаёт сканировать корневую папку `content/` (сценарии курса, пайплайны MASON/LINGMAN/VIRAL, аватар-студия, ~2170+ файлов JSON и markdown). Меньше файлов в карте Metro — меньше памяти сервера и меньше поводов для его разрастания. Успех: память сервера через ~10 минут после старта ниже текущих ~6 ГБ, сборка приложения не ломается.

## Scope

In scope: `metro.config.js`, список `ignoredRootFolders`, одна строка `'content'` с комментарием.

Out of scope: `modules/learning-v2/content/` (это код приложения, он не исключается — регэксп привязан к корню проекта), лимит памяти сервера (отдельное решение владельца), переключение Watchman.

## Architecture

Текущая граница: `ignoredRootFolders` исключает служебные корневые папки из карты файлов Metro регэкспом `^<root>/<folder>[/\\].*`. Новая граница — то же правило для `content`. Поток данных сборки не меняется: импорты приложения на корневую `content/` не ссылаются (проверено поиском: совпадения только по `modules/learning-v2/content/…`, и тесты, которые в бандл не попадают).

## Security and privacy

Не касается: конфигурация сборщика, персональных данных и секретов нет.

## Technical debt

- Contain: память сервера всё равно растёт выше 5 ГБ за счёт самого приложения (~5000 модулей). Исключение `content/` снижает вклад, но не решает проблему. Exit condition — отдельный замер после перезапуска и решение владельца по лимиту памяти.

## Verification

1. `node --check metro.config.js` — синтаксис.
2. Поиск импортов на корневую `content/` в коде приложения: только тесты и сама папка `content/` — выполнено 10.10.
3. После перезапуска сервера: `curl 127.0.0.1:8081/status` = running, `Android Bundled … index.js` в журнале `C:\Temp\claude\metro_live.log`, приложение открывается на эмуляторе.
4. Замер памяти через ~10 минут после старта; сравнение с ~6 ГБ.

## Rollback

Удалить строку `'content',` из `ignoredRootFolders` в `metro.config.js` и перезапустить сервер. Данные не затрагиваются.
