# Feature intro asset system

The owner approved new DALL·E art for every user-facing explanation. The gallery currently contains thirteen explanations; the app has nine live themes, so the complete deliverable is 117 wired asset paths that all carry the same universal artwork.

Each explanation owns one stable motif: cards hub = curated card case; statistics = luminous progress chart; daily phrase = phrase card with speech spark; videos = cinematic play portal; friends = linked profile medallions; Arena = opposing speech crests; League = weekly trophy tower; swipe = two cards moving left/right; listening = headphones and soundwave card; speaking = microphone and phrase halo; blitz = lightning deck and timer; AI dialog = two conversational bubbles linked by a spark; mistake practice = repaired card with return ribbon.

All images share one calm, editorial 3D still-life system approved by the owner: a small, tactile central object with soft studio light, restrained botanical or material accents and generous negative space. They must feel like the supplied `hello` card reference, not like separate game worlds. Every image is readable at 190×190 logical pixels and contains no words, letters, logos or watermark.

The illustration has one fixed universal palette: deep forest green, warm cream paper and restrained brass. Themes affect the surrounding application surface only, never the artwork. This keeps the object crisp and recognisable instead of introducing a different colour cast, damaged-looking material edges or nine competing art directions. The transparent WebP lets the component place the same object cleanly on every app-colour background.

The thirteen original scenes are generated sequentially through the built-in image tool, one master scene per call. Every master is generated against a flat, neutral black background and converted to a clean, binary alpha silhouette at 256×256 WebP by tracing only the edge-connected dark background. Never use a chroma-key or remove foreground pixels by colour: pale paper, metal highlights and botanical details must keep their intact edges. Every master is visually checked and recorded in a resumable checkpoint. The eight additional paths for each scene are exact copies of that master so every theme loads the same universal artwork. The static require map is created before generation so no bundled image can be orphaned. Dialogue comic bubbles remain animated; only their central illustration becomes theme-specific.

No existing Home assets are replaced. No source/intermediate PNG enters the bundled asset tree. Production wiring is complete only after all 117 files exist, all literal requires resolve, dimensions/alpha/compression pass, focused tests pass, and a contact sheet is reviewed.
