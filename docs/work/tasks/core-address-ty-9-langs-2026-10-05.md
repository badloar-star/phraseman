## Outcome

Все тексты интерфейса обращаются к человеку на «ты»: ru «ты», uk «ти», es tú, pt-BR você, id kamu, tr sen, pl ty
(en без изменений). Источник — docs/phraseman-2.0/evidence/parity/ADDRESS_TY_LIST_2026-10-05.md: 246 строк ru/uk
в 89 файлах + id/tr. Скан даёт ложные совпадения — каждая строка решается по смыслу.
НЕ меняем:
- множественное обращение к нескольким людям: подписи для соцсетей к подписчикам («Завидуйте молча»,
  «Пожелайте мне удачи»), «вы друзья» / «Arkadaşsınız» / «Kalian berteman»;
- шутки, где «вы» — сам предмет шутки («Таймер теперь обращается к тебе на «вы»»);
- местоимение-подпись «Вы / You» как метка автора (это не обращение, а имя «вы» = «я» в комментариях —
  меняется на «Ты» только если рядом метки уже на «ты»);
- учебный контент (lesson_data, theory, idioms, error_traps, Learning V2 source, сценарии AI-диалогов);
- app/flashcards_training_setup.tsx (сторож хэширует логику; к тому же там чужие правки).
