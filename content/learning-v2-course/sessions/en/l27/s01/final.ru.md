# Урок 27 · Занятие 01 — Если бы было иначе

**Ситуация.** Вы обсуждаете поездку, представляете дом с садом и выбираете подходящее жильё.

**Что вы освоите:** сказать, что было бы, если бы…
**Новые слова:** possibly, naturally, obviously, frankly

## Интро 1

### Если бы было больше времени

Вы хотите путешествовать, но свободного времени мало. Представьте другое положение: If I had more time, I would travel — если бы у меня было больше времени, я бы путешествовал. Собираем две части: If + I + had + more time — условие; I + would + travel — результат. Had — форма past simple, но здесь она обозначает воображаемое условие сейчас или в будущем. В результате после would ставим travel без to. Между начальным условием и результатом нужна запятая.

**Выберите фразу для этой ситуации.**

- ✅ **If I had more time, I would travel.**
- ❌ If I would have more time, I would travel. — *В условии нужно had, без would.*
- ❌ If I had more time, I would travelled. — *После would нужна начальная форма travel.*

## Интро 2

### Если бы у нас был сад

У вас нет сада, но вы обсуждаете, что выращивали бы в нём. Скажите: We would grow vegetables if we had a garden — мы бы выращивали овощи, если бы у нас был сад. Собираем: We + would grow + vegetables + if we had a garden — кто, что делал бы, что выращивал бы, при каком условии. Результат стоит первым, поэтому перед if запятая не нужна. После would используем grow; в условии — had без would.

**Выберите фразу для этой ситуации.**

- ✅ **We would grow vegetables if we had a garden.**
- ❌ We would growing vegetables if we had a garden. — *После would нужно grow.*
- ❌ We would grow vegetables if we would had a garden. — *В условии нужно had без would.*

---

## Интро 3

### При каком условии переедете

Друг спрашивает, согласились бы вы переехать. Пока работы на новом месте нет. Ответьте: I would move if I found a job — я бы переехал, если бы нашёл работу. Собираем: I + would move + if I found a job — кто, что сделал бы, при каком условии. После would нужна move без to. Found — форма find, не finded; после if она представляет возможное условие, а не сообщает, что работа уже найдена.

**Выберите фразу для этой ситуации.**

- ✅ **I would move if I found a job.**
- ❌ I would to move if I found a job. — *После would не ставим to.*
- ❌ I would move if I finded a job. — *Прошедшая форма find — found.*
