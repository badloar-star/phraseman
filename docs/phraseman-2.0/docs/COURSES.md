# Learning V1 и учебные звёзды

Владелец настаивает: действующий английский курс хороший и его не нужно уничтожать ради V2. Сохранить engine, content и progress; интерфейс переработать полностью. Отдельное позиционирование «Тренировочный курс» — предложение, имя утверждается отдельно.

Первые три урока V1 открыты, остальное за Plus/соответствующим paywall. Исторические купленные права и текущие испытательные режимы сверить с реальным ledger/flags. Переход к трём открытым урокам не должен молча отнять навсегда приобретённый доступ. Жемчужный unlock снимается после миграционного решения.

## Звёзды
Владелец предлагает уйти от пятибалльной оценки к 1–3 звёздам и минимуму 2 для дальнейшего шага/раздела. Точные пороги НЕ заданы. Рабочий пример для обсуждения: 60/80/95%, ниже первого порога — завершённая попытка без звезды. Не публиковать эти числа без проверки difficulty и возможности повторить занятие. Не снижать старые подтверждённые unlocks при миграции best score.

Право пройти следующий урок состоит из двух независимых условий: учебный prerequisite и content entitlement. 2 звезды не обходят подписку; Plus не отменяет саму учебную последовательность автоматически. Экзамены/срезы знаний остаются, пересдача доступна по ясным правилам. Учебные проценты/звёзды — не опыт и не основание вернуть XP.

## Новые локали V1
Владелец предложил шаблон 32 урока × 50 фраз = 1600 фраз на язык. Сделать authoring plan: цели уроков, prerequisites, лексический реестр, grammatical forms, quality rubric и редакторская проверка. Нельзя выдать случайные 1600 фраз за курс. Повтор допустим как педагогическое решение, но не незаметный дубль нового материала. Проверить существующий engine Устно для каждой локали, не подключать облачный STT сейчас.

Новые V1 курсы планируются по готовности контента и спросу; они не блокируют первичную чистку/новый интерфейс. V2 имеет отдельный future plan, а предложение «10 сессий бесплатно» не переписывает V1.
