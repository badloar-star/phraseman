# Английский · Урок 26 · Занятие 33 — Сначала условие или решение

**Ситуация.** Вы выбираете транспорт и место для ужина, передаёте одну договорённость в разном порядке.

**Что вы освоите:** ставить условие с if в начало или в конец фразы: The subway is closed tonight.
**Новые слова:** subway, railroad, diner, takeout

## Интро 1

### Условие в начале или в конце

Subway — метро. If the subway is closed, we will take a bus — если метро закрыто, мы поедем на автобусе. То же условие можно поставить после решения: We will take a bus if the subway is closed. Смысл сохраняется. Когда часть с if стоит первой, после неё обычно пишут запятую; когда она идёт второй, запятая обычно не нужна. Перестановка не меняет времена: после if остаётся is, в результате — will take.

**Выберите фразу для этой ситуации.**

- ✅ **We will take a bus if the subway is closed.**
- ❌ We will take a bus if the subway will be closed. — *Порядок частей не разрешает will после if в этом условии.*
- ❌ We take a bus if the subway will be closed. — *В условии нужно is; обещанное решение здесь will take.*

## Интро 2

### Сначала просьба или сначала условие

Друг собирается сам разобраться с трудным делом. Предложите обратиться к вам: If you need help, call me — если нужна помощь, позвони мне. Можно начать с просьбы: Call me if you need help. Собираем две части: call + me — что сделать и кому позвонить; if + you + need + help — при каком условии. Переставляем целые части, не меняя их форм. Когда условие первое, после него нужна запятая; после просьбы перед if — нет. Call в начале фразы, без you, остаётся просьбой в обоих порядках.

**Выберите фразу для этой ситуации.**

- ✅ **Call me if you need help.**
- ❌ You will call me if you need help. — *You will call — сообщение о будущем; здесь нужна просьба call.*
- ❌ Call me if you will need help. — *После if в этом условии need без will.*

## Интро 3

### Если в кафе нет мест

Вы планируете ужин в кафе и обсуждаете запасной вариант: We will get takeout if the diner is full — мы возьмём еду навынос, если в кафе нет мест. Поставим условие первым: If the diner is full, we will get takeout. Собираем: If + the diner + is + full, + we + will get + takeout — условие, затем решение. Теперь после условия нужна запятая. Перестановка не меняет форм: в условии остаётся is, в решении — will get.

**Выберите фразу для этой ситуации.**

- ✅ **If the diner is full, we will get takeout.**
- ❌ If the diner will be full, we will get takeout. — *После if здесь is, независимо от порядка частей.*
- ❌ Unless the diner is full, we will get takeout. — *Unless меняет условие: еду навынос возьмём, если кафе не заполнено.*
