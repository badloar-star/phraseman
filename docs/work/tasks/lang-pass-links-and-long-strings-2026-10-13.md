# Шаблон ссылок lang_pass (15 экранов × 7 языков) и проверка длинных строк 9 языков в зонах Тем

Governance-ID: TG-CBADC096E75B
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора: пункты 1–3 после b7fa6eacf)

## Outcome
1. Контраст плашек и полей к подложке в тёмном по образцу: замер и вывод (подложка и поля нейтральны, `control/sheet` 1,00 → 1,18; плашки шторок 1,30), список строк manage-subscription для «после».
2. Скрипт `scripts/dev_links_lang_pass.py` и сгенерированный `docs/phraseman-2.0/DEV_LINKS_LANG_PASS.md`: шаблон ссылок 15 ключевых экранов с параметром `uiLang` для es, pt-BR, tr, pl, vi, id, uk (блок LANG). Явно отмечено, что `dev_state?uiLang` сейчас принимает только `en|off` — для остальных языков нужно расширение у Ядра.
3. Документ `docs/phraseman-2.0/LONG_STRINGS_ZONES_R1_2026-10-13.md`: строки зон (кампании, «Мои ошибки», монеты, онбординг — только тексты) в 9 языках, длина которых заметно превышает русскую/английскую, с оценкой риска переноса/обрезки.

## Scope
Только чтение кода и новые файлы: скрипт генерации, два документа. Код приложения не меняется; правки текстов или вёрстки — отдельным шагом по результатам.

## Architecture
Скрипт ссылок повторяет формат `dev_links_lang_switch.py` (Авторизация): таблица «id · экран · язык · ссылка · перед кадром»; ссылки берутся от тех же `dev_state`-хвостов, что и ru/en-проход, с `&uiLang=<язык>` перед `next=`. Анализ длин: сканирование объектов `{ ru, uk, en, es, 'pt-BR', vi, id, tr, pl }` в файлах зон и сравнение длин с `max(ru, en)`.

## Security and privacy
Только dev-ссылки сборки разработчика и чтение исходников; данных пользователей нет.

## Technical debt
Статический анализ не видит реальной ширины контейнеров: вывод — «кандидаты на переполнение», подтверждает только кадр на языке (lang_pass Сверки). Для es/pt-BR/tr/pl/vi/id/uk смена языка по ссылке заработает только после расширения `uiLang` в `app/dev_state_fixtures.ts`/`app/dev_ui_lang.ts` (Ядро).

## Verification
Скрипт генерации запускается без ошибок, таблица содержит 105 строк (15 × 7); отчёт по строкам считается скриптом с счётчиками (файлов, объектов, кандидатов).

## Rollback
Удалить скрипт и два документа.
