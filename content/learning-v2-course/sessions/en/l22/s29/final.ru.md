# Английский · Урок 22 · Занятие 29 — Выбрать обувь и одежду

**Ситуация.** Вы выбираете вещи для тепла и удобства.

**Что вы освоите:** determiner|adjective + one|ones
**Новые слова:** lace-up, slip-on, pull-on, fleece-lined

## Интро 1

### Обувь на шнурках

Lace-up описывает обувь на шнурках: lace-up boots. Выбираем ботинки, поэтому вместо boots говорим ones. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I prefer the lace-up ones.**
- ❌ I prefer the lace-up one. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I prefer the lace-up them. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 2

### Надеть без застёжек

Slip-on — обувь без шнурков и застёжек, которую легко надеть, вставив ногу. Pull-on описывает одежду, которую натягивают без расстёгивания: например брюки на резинке. Здесь выбираем туфли: shoes → ones. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

## Интро 3

### Флисовая подкладка

Fleece вам уже знакомо: флис. Fleece-lined означает, что внутри есть флисовая подкладка. Это не значит, что вся вещь сделана из флиса. Здесь выбираем одну куртку: jacket → one. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**
