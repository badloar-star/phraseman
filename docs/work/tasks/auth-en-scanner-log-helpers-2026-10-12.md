## Outcome

Сторож `scripts/scan_untranslated_ui.mjs` перестаёт считать «непереведённым интерфейсом» тексты журналов и русские формы слова внутри
русской ветки перевода. База опускается, и новая настоящая русская строка без перевода ловится сразу, а не тонет в ложных находках.
Мера: число находок падает ниже 124, настоящих (экранных) строк среди снятых нет; тесты сторожа зелёные.

## Scope

In scope:
- `scripts/scan_untranslated_ui.mjs`: локальный помощник журнала признаётся журналом, если в ЭТОМ файле он объявлен как
  `function имя(message: string…) { DebugLogger.*/console.*(…) }` — тело один вызов логгера (проверка по телу, не по маске имени);
  явный список дополнен `logTide`.
- `components/NoEnergyModal.tsx`: русские формы «минуту/минуты/минут» перенесены в русскую строку triLang через общий `pluralWord`
  (`constants/plural.ts`), отдельная функция `ruMinutes` убрана. Текст для человека не меняется.
- `components/survey/SurveySheetModal.tsx` НЕ правится: файл закреплён контрольной суммой (survey_unavailable_liquid_glass_source_contract); его журнал logTide снимается правилом сканера, две метки причины закрытия остаются находками.
- `tests/untranslated_ui_positional.test.mjs`: тест на распознавание помощника журнала по телу и на отказ, если тело не логгер.
- `config/untranslated-ui-baseline.json`: опустить отдельным коммитом.

Out of scope: `app/(tabs)/lessons.tsx` и прочие файлы Ядра, Codex-зона Learning V2 (handoff 2ed60f37c), изменение текстов для людей.

## Architecture

No architecture change: правило сторожа (скрипт разработки) и две локальные правки без изменения поведения экранов.
Инвариант: сторож не ослабляется — функция признаётся журналом только если её тело и есть вызов логгера.
