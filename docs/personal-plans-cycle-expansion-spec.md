# Personal Plans Cycle Expansion Spec

Status: chat draft planning artifact, not production-ready.

This document defines how the 28-day universal cycle expands to the full length of every Personal Plan. It does not authorize source/runtime import, live registration, audio readiness, pronunciation readiness, or production readiness.

Selected daily time does not change day selection. It does change the initial visible workload: each day keeps the full maximum task pool, and the selected time reveals the first slice before optional add-more tasks.

## Plan Lengths

- Voyazh: 84 days = 3 full cycles.
- Mitap: 112 days = 4 full cycles.
- Gavan: 126 days = 4 full cycles + 14-day partial cycle.
- Impuls: 140 days = 5 full cycles.
- Echo: 84 days = 3 full cycles.

## Cycle Growth

Cycle 1 uses the completed 28-day universal cycle as the foundation: first usable phrases, recall, stress, repair, weekly checks, and final handoff.

Cycle 2 repeats the same rhythm with new situations and fewer direct hints. It should not clone Cycle 1 copy. It should keep the same load roles while changing contexts, distractors, and recall targets.

Cycle 3 increases independence: more free answer prompts, more two-step responses, more context transfer, and fewer rescue options before the user attempts an answer.

Cycle 4 raises scenario density for longer plans: more mixed context, stronger error-driven review, and more production before options appear.

Cycle 5 is used only by Impuls as a full cycle and by Gavan as a 14-day partial extension. It should focus on stable spontaneous production, not more cards per day.

## Plan-Specific Expansion

### Voyazh

Voyazh runs 3 full cycles. Cycle 1 covers survival route and help. Cycle 2 moves into transport, ticket, receipt, check-in, and timing pressure. Cycle 3 combines airport, hotel, street, and emergency help with more free answers.

### Mitap

Mitap runs 4 full cycles. Cycle 1 covers short status and next steps. Cycle 2 adds blockers, ownership, and follow-up. Cycle 3 adds decision framing and disagreement repair. Cycle 4 rehearses meeting wrap-up with minimal prompts.

### Gavan

Gavan runs 4 full cycles + a 14-day partial cycle. Cycle 1 covers calm replies and clarification. Cycle 2 adds soft boundaries and simple choices. Cycle 3 adds pressure without over-explaining. Cycle 4 combines calm decision flow. The 14-day partial cycle reinforces the weakest review and stress roles from the previous cycles.

### Impuls

Impuls runs 5 full cycles. Cycle 1 covers simple story sequence. Cycle 2 adds problem, attempt, and result. Cycle 3 adds reason, opinion, and correction. Cycle 4 adds fast repair and alternative action. Cycle 5 focuses on short spontaneous monologue control.

### Echo

Echo runs 3 full cycles. Cycle 1 covers repeat and key-detail recognition. Cycle 2 adds time, place, number, and name repair. Cycle 3 adds short listening-memory dialogs and more repeat-back production.

## Expansion Rules

- Keep the 28-day rhythm: foundation, choice, recall, stress, repair, weekly check, handoff.
- Do not include every mode every day.
- Do not change which tasks exist by selected daily time; use it only to choose the initial visible count.
- Increase difficulty by reducing scaffolding, changing context, strengthening distractors, and requiring more production.
- Keep plan days separate from normal lessons.
- Do not clone text between cycles. Reuse skills, not exact copy.
- Keep generated content as chat draft until review approval and source-intake gates are complete.

## Non-Readiness

This spec is not production-ready. The 28-day content is chat draft, not reviewed source content. Full production still needs approval records, import validation, source/runtime registration, approved audio where used, and real pronunciation/scoring evidence.
