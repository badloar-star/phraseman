## Что одинаково у всех лиг

Башня = текущая `components/spire/SpireTowerSvg.tsx` + модель `components/spire/spire_tower_model.ts` без изменений: 15 этажей (Страж каждые 5), ширина `196 − (f−1)·5`, высота этажа 46 / Страж 60, кладка рядами 11 px с изгибом, окна по окружности (углы −.72 / 0 / .72, с 12-го — два), карнизы-кольца, зубцы и машикули Стражей, барабан + конус с черепицей + навершие; состояния этажей «пройден / мой / впереди / вершина недели», маркер игрока справа, соперники слева.

## Что задаёт лига (новые props SpireTowerSvg)

- `stone` — базовый цвет камня. Из него выводятся все градиенты теми же долями затемнения, что у эталона Оникса (`#5A5A62` → `#1F1F23 #3D3D44 #5A5A62 #46464D #2C2C31 #18181B`):
  - `cyl` = darken(stone, .64 / .31 / 0 / .21 / .50 / .72) по стопам 0 / .16 / .36 / .55 / .8 / 1;
  - `cylG` (Страж) = darken(.60 / .22) · lighten(.08) · darken(.10 / .45 / .69);
  - `cylCorn` = darken(.53) · lighten(.14) · darken(.05 / .62); `cone` = darken(.66 / .05 / .35 / .76);
  - окно «пройден» = mix(darken(stone, .35), lit, .12); «впереди» = darken(stone, .85); подоконник = mix(darken(stone, .1), #6B6B72, .5);
  - для светлого камня (средняя яркость > 140: Мрамор, Опал) швы кладки .22 вместо .34 и тень под карнизом .30 вместо .42.
- `lit` — свет окна моего этажа, свечение окон (blur 4) и навершия, маркер игрока.
- `sky` — оттенок неба (3 стопа: sky, mix(sky, stone, .06), darken(sky, .15)).
- `glow` — радиус свечения навершия (на вершине недели × 2.6) — растёт от 34 у Гранита до 52 у Алмаза.
- `details` — 1–4 маленькие детали, у высших лиг больше:
  - `pennant` (цвет) — вымпел 17 × 10 на удлинённом флагштоке навершия;
  - `rim` (цвет) — ободок 1.2–1.6 px по верху зубцов Стражей, низу карнизов, кольцу конуса и цоколю;
  - `gem` (цвет) — гранёный камень 6.5 / 8 вместо белого шара в навершии;
  - `crystals` (цвет) — четыре маленьких кристалла (12–22 px) по бокам цоколя;
  - `veins` (цвет) — две светящиеся прожилки на этаж (3 px с blur 1.6 + 1 px ядро), на этажах «впереди» приглушены;
  - `flame` (цвет) — огонёк 16 / 26 px над навершием;
  - `sheen` — перламутровый отлив (полоса мята / сирень / персик / небо, α ~.22) на каждом этаже.

## Перенос

Добавить в `SpireTowerSvg` проп `skin` (объект выше) с дефолтом = Оникс без деталей (текущий вид, ничего не меняется для существующих экранов). Градиенты — функции от `stone`; детали — небольшие условные группы. Узлов на башню ~430–470 (у эталона ~420): детали добавляют 5–40 узлов. Фильтры blur (прожилки, свечение окон) — те же, что уже есть у эталона.
