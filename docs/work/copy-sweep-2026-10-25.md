# Зачистка текстов интерфейса — 25.10 (Переводчик, приоритет владельца)

Правило для каждой строки: сообщает ли она что-то полезное — что случилось, что делать, что человек получит?
**Нет** (красота, мотивация, вода) → УДАЛИТЬ. **Да, но метафора / выдуманный термин** → прямо, коротко, с цифрами.
Образцы владельца: «До месяца — 23 дня», «Пропущенный день не сбросит серию».

Колонка «Чей файл»: 🆓 — файл свободен, правлю сам после одобрения; 🔒 — файл в чужой незакоммиченной работе, список уходит
владельцу зоны. «Удалить» в вёрстке согласуется с владельцем экрана, чтобы не осталось пустого места.
