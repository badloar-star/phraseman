🟠 Сквозная тема №1 — дыры в локализации (≈18)

Самая системная проблема релиза: десятки строк переведены только на ru/uk/es, остальным 5 языкам показывается русский.

  • settings_edu.tsx:61 — весь экран «Настройки обучения» (тумблеры) на 3 языках
  • profile_card_system.ts:45 — описания платной карточки профиля
  • collectibles_screen.tsx:241 — вся «Сокровищница» (заголовки секций, идиомы)
  • ai_dialog_scenarios.ts:169 — испанские сценарии диалогов падают в русский
  • lesson_lock_system.ts:213 — модалка «урок заблокирован» на русском для 5 языков
  • streak_stats.tsx:2008 — шеринг серии шлёт русский текст бразильцам/туркам/полякам
  • Мохибейк: daily_tasks_screen.tsx:2306 — вьетнамское «Забрать» = крякозябры; settings_notifications.tsx:29 — в русском расписании «Четвер» (укр. слово)

🟠 Сквозная тема №2 — обещание ≠ факт (деньги / мотивация)

  • settings_invite_friend.tsx:191 — кнопка «Пригласить друга» шарит ссылку без реф-кода; друг не привяжется → обещанные +7 дней не придут
  • shards_shop.tsx:1151 — карточка пакета показывает «30 осколков», а начисляется 35. Бонус скрыт → недопродажа
  • personal_plan.tsx:164 — «серия дней» в шапке плана = просто номер дня (фейк), не совпадает со статистикой
  • home.tsx:1663 — полоска «почини серию» считает /2, хотя нужен 1 урок → всегда максимум 50%

🟠 Тупики и застревания

  • quizzes.tsx:1607 — пустой квиз = тупик без кнопки выхода, энергия/лимит уже потрачены
  • ai_dialog_session.tsx:188 — ошибка ИИ показана как реплика собеседника, нет «Повторить»; единственная бесплатная попытка сгорает при сбое сети
  • MatchmakingContext.tsx:325 — поиск соперника до 10 минут; при выключенных ботах можно зависнуть без «никого не нашли»
  • personal_plan.tsx:511 — «Назад» на плане фолбэчит на сам себя → можно застрять
  • personal_plan_setup.tsx:301 — про премиум узнаёшь только в конце 4-шагового мастера (bait-and-switch)
