# Инструкция аудитору — пакет full3 (05.11): словарь, вступления, теории
Цель владельца: «сильная модель говорит: супер, чётко». Допуск: ≤1% единиц с ошибкой по каждому языку. Единица = лемма словаря / урок вступления / урок теории.
Не меняй файлы проекта; результат пиши ТОЛЬКО в results_<имя chunk-файла без chunk_>.json в этой папке (например chunk_glossary_en_03.json → results_glossary_en_03.json).
Формат результата: JSON-массив {"id": "<lemma | lesson-N>", "type": "G1|G2|G3|G4|I1|I2|I3|I4|T1|T2|T3", "field": "<путь/поле>", "problem": "коротко", "fix": "<полная новая строка или объект>"}.
В ответе (чате) — ОДНА строка: «<chunk>: проверено N, единиц с ошибкой F, замечаний M (по типам)».

## A. chunk_glossary_<lang>_NN.json — словарь (≈100 лемм)
Запись: {lemma, meaning:{ru,uk,en,es,pt-BR,vi,id,tr,pl}, firstLesson, phrasesCount, examples:[{id,target,ru,uk}], other}.
- G1: перевод ru/uk леммы неверен/неточен для значения в примерах курса (смотри examples), не та часть речи, не тот род/число, калька, неестественно; ru и uk расходятся по смыслу.
- G2: перевод на en/es/pt-BR/vi/id/tr/pl неверен или не соответствует ru (проверь выборочно по 2–3 локалям, но каждую запись хотя бы по en и es).
- G3: лемма в неверной форме (не начальная форма: «bin» вместо «sein», «am» вместо «be»), опечатка, неверный регистр/артикль/род, дубль леммы (две записи одного слова).
- G4: firstLesson неверен (слово встречается раньше в примерах), либо в meaning пусто/служебный мусор/«TODO».
fix: для meaning — {"locale":"ru","value":"..."} в поле field «meaning.<locale>».

## B. chunk_intro_<lang>_NN.json — вступления уроков (по 4 урока; в каждом 3 блока concept/formula/practice)
Каждый блок: titleXX/textXX (RU,UK,EN,ES,PtBr,Vi,Id,Tr,Pl), exampleIds + exampleResolved (фразы курса).
- I1: текст неверен по языку: неверное правило/пример/формула (проверь формулы и примеры слов по языку курса), пример не из курса или не соответствует правилу, противоречие между блоками урока.
- I2: ru/uk неестественны (калька, неграмматичность, «ты/вы» вразнобой), обрыв/пустой/обрезанный экран, разный смысл ru и uk, лишний служебный символ (обратные кавычки ` , **, markdown), шаблонное начало «Представь ситуацию…/Imagine…» (запрещено владельцем — предложи содержательный заголовок).
- I3: другие локали (en/es/pt-BR/vi/id/tr/pl) не передают смысл ru или с ошибками (проверь en, es, pt-BR полностью; остальные — выборочно по первому/последнему блоку).
- I4: пример (exampleResolved) не иллюстрирует правило урока или нарушает правило владельца (подсказка-расшифровка мелким шрифтом, обводки — это не про текст, пропусти).
fix: полная новая строка для поля (titleXX/textXX…), field = имя поля блока, id = "lesson-N/block-K".

## C. chunk_theory_<lang>_NN.json — теории уроков (по 2 урока; только локали ru/uk/en; exampleResolved — фразы курса, на которые ссылается теория). Типы: T1 — правило/формула неточны или неполны, неверный пример, пример не из курса или не иллюстрирует правило; T2 — ru/uk неестественны (калька, ты/вы вразнобой, обрыв, markdown-символы), ru и uk расходятся по смыслу, en не соответствует ru; T3 — противоречие между уроками или с фразами курса. id записи = "lesson-N/<раздел>", fix — полная новая строка поля.

Общие правила: придирайся только к РЕАЛЬНЫМ ошибкам; спорный стиль не записывай. Не придумывай замечаний. Одна единица может иметь несколько записей.
