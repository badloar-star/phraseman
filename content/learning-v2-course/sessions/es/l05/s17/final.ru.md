# Испанский · Урок 5 · Занятие 17 — У него есть брат

**Ситуация.** Рассказываете другу о Педро, его семье и вещах.
**Что вы освоите:** использовать él tiene, когда говорите о другом мужчине.
**Новые слова:** —
**Повторяем знакомые слова:** él, tener, hermano, libro, carro.

## Интро 1

### Семья Педро

Вы с другом обсуждаете Педро. Скажите `Él tiene un hermano` — «У него есть брат». Соберите `él` + `tiene` + `un hermano`. Él означает «он», здесь это Педро. Для «он» выбираем tiene: без конечного s, которое было в tienes для «ты».

**Речь о Педро. Скажите «У него есть брат». Начните с Él tiene.**

- ✅ **Él tiene un hermano.** — *Для él нужна форма tiene.*
- ❌ Él tienes un hermano. — *Tienes относится к «ты»; с él нужно tiene.*
- ❌ Él tengo un hermano. — *Tengo относится к «я»; с él нужно tiene.*

## Интро 2

### Книга Педро

Друг спрашивает, есть ли у Педро что почитать в дороге. Сообщите `Él tiene un libro` — «У него есть книга». Соберите `él` + `tiene` + `un libro`. Меняем только то, что есть у Педро: вместо брата называем книгу. Форма tiene остаётся, потому что по-прежнему говорим о нём.

**Речь о Педро. Скажите «У него есть книга». Начните с Él tiene.**

- ✅ **Él tiene un libro.** — *Él tiene сообщает о Педро.*
- ❌ Él tiene una libro. — *Libro мужского рода: un.*
- ❌ Él tengo un libro. — *С él нужна форма tiene.*

## Интро 3

### Машина Педро

Вы обсуждаете, кто может приехать на машине. Педро уже упомянут. Скажите `Él tiene un carro` — «У него есть машина». Соберите `él` + `tiene` + `un carro`. В начале стоит él со знаком ударения — «он». Не путайте его с артиклем el: здесь слово называет человека, о котором говорите.

**Речь о Педро. Скажите «У него есть машина». Начните с Él tiene и используйте carro.**

- ✅ **Él tiene un carro.** — *Él — «он», tiene — форма для него.*
- ❌ Él tienes un carro. — *Для «он» нужно tiene, без s.*
- ❌ Él tiene una carro. — *Carro мужского рода: un.*

## Практика · 12 заданий

**1 · Послушайте и выберите слово**
🔊 *tiene*
→ **tiene** · tengo
- tengo — *Звучит tiene, с конечным e.*

**2 · Вставьте слово — у него есть брат**
`Él ___ un hermano.`
→ **tiene** · tienes · tengo
Полная фраза: **Él tiene un hermano.**
- tienes — *Для él нужно tiene, без s.*
- tengo — *Tengo относится к «я»; здесь él tiene.*

**3 · Соберите фразу — у него есть брат; начните с Él**
Плитки: `un` · `él` · `hermano` · `tiene` · `tienes`.
→ **Él tiene un hermano.**
*Плитка `tienes` лишняя: для él нужна форма tiene.*
