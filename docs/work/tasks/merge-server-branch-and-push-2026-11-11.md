## Outcome

Владелец 11.11: «отправляй сервер» → после доклада о расхождении веток «Да, объединяй».
Локальная `feature/referral-roulette` опережает серверную на ~1560 коммитов и отстаёт на 24
(админка 29–30.10: шаблоны историй, комментарии YouTube, скрипты и тесты выкладки).

Мера успеха: на сервере одна вершина, в которой есть и 24 серверных коммита, и вся локальная работа;
`git rev-list --count origin/feature/referral-roulette..HEAD` после отправки = только коммиты, сделанные
другими сессиями уже после неё; ни одна несохранённая правка живых сессий не потеряна.

## Scope

In scope:
- один коммит объединения, собранный без изменения рабочих файлов и общего индекса
  (`git merge-tree --write-tree` + `git commit-tree`, затем `git update-ref` с проверкой прежней вершины);
- разбор пяти конфликтов (решения владельца «сам реши что лучше» + «не трогать занятые»):
  - `admin/v2/scripts/pages/story_announcements_v2.{js,css}`, `story_announcements_v2_preview.html`,
    `admin/v2/scripts/pages/youtube-comments.js` — серверная версия (30.10, выложена в прод, полнее);
  - `functions/src/jarvis/jarvis_data_contract_guard.test.ts` — обе проверки (локальная про истории, серверная про YouTube);
- появление на диске новых серверных файлов, у которых локально нет несохранённых правок;
- `git push origin feature/referral-roulette` (обычный, без принуждения).

Out of scope:
- файлы с чужими несохранёнными правками на диске (`story_announcements_v2.js` — удалён в рабочей копии,
  `jarvis_data_contract_guard.test.ts`, `tests/admin_story_announcements_v2_gallery_contract.test.ts`) — не перезаписываются;
- переписывание сторожа `tests/admin_story_announcements_v2_gallery_contract.test.ts` под серверную версию;
- выкладка админки, функций, сборок; принудительная отправка; новые ветки и worktree.

## Architecture

No architecture change. Меняется только история: у ветки появляется коммит с двумя родителями.
Инвариант: рабочее дерево и общий индекс других сессий не переписываются; вершина ветки двигается
только если она не изменилась с момента расчёта (иначе расчёт повторяется).

## Security and privacy

Данные пользователей, правила доступа, секреты не затрагиваются. 24 серверных коммита уже лежат на
GitHub; новых секретов объединение не добавляет. Отправка — в тот же частный репозиторий владельца.

## Verification

- `git merge-tree` даёт ровно пять ожидаемых конфликтов, иначе остановка;
- в объединённом дереве нет меток конфликта; сторож Джарвиса разбирается компилятором без ошибок синтаксиса;
- `git diff <серверная вершина> <коммит объединения>` не теряет ни одного серверного файла, кроме сведённых;
- после отправки: `git rev-list --count HEAD..origin/feature/referral-roulette` = 0;
- несохранённые правки занятых файлов на месте (`git status` по ним не изменился по смыслу).

## Rollback

До отправки: `git update-ref refs/heads/feature/referral-roulette <прежняя вершина> <коммит объединения>` —
рабочие файлы при этом не меняются. После отправки откат — новым коммитом (`git revert -m 1`), без
принудительной отправки. Серверная вершина до объединения: 7bf2258cdc5d2647bea7a6f9ed9115035ee2d581.
