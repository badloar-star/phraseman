## Outcome

Для каждого из 8 заданий вёрстка колонки «Предлагаем» перенесена в код буквально: те же отступы, размеры, веса, межстрочные, радиусы, цвета (через токены), тени, высоты, порядок блоков. Тексты — только правилом Learning V2 (splitLearningV2TaskPromptV1), без подстановок под макет. Мера успеха: Сверка снимает режим рядом с макетом той же ширины (наложение), расхождение ≤ 2 px и та же структура блоков (команда, ситуация, цель — отдельно). До подтверждения Сверки режим «не готов».

## Scope

In scope: тело заданий (components/learning-v2/LearningV2TaskBody.tsx, токены learning_v2_task_theme_tokens.ts, Lv2Chip/Lv2Cta-замена для заданий), режимы modules/learning-v2/modes/*, новое слово, интро; порядок работы: «Собери фразу» → «Послушай и выбери» → диктант → «Вставь слово» → «Скажи вслух» → новое слово → интро → «Найди пары».

Out of scope: оболочка (шапка, HUD, подвал, плитки ответов — 7e15fdc7e, 71a93e367, 4 · ТЕМЫ), верхний inset под статус-баром (общая правка 5 · ВХОД: фон идёт под него без полосы — своих фонов не добавляю), тексты и контент (Learning V2).

## Architecture

Цифры живут один раз: размеры — LV2_TASK_BODY / LV2_TASK_LAYOUT (learning_v2_task_layout_tokens.ts, LearningV2TaskBody.tsx), цвета и тени — токены темы + 9 недостающих (learning_v2_task_theme_tokens.ts, таблица 4 · ТЕМЫ п. 1–9). Режимы собираются из общих блоков: Lead (название + ситуация), Goal, Say, TaskCta. Где в React Native нет такого CSS — ближайший эквивалент, помечен в колонке «Отклонение».
