# Статистика и конкретные ошибки

Полной переделки логики статистики владелец не требует, но общий дизайн меняется. Полезные счётчики/время/учебные результаты сохраняются. «Закреплено фраз» удаляется как непонятная метрика — не как команда удалить карточки пользователя.

Общий summary допустим по аккаунту, при этом исходные learning events сохраняют locale/course/mode и session ID. Ошибки показываются с языком и фактической фразой/словом. Вариант просмотра по языку не должен случайно очищать ошибки другого языка.

Удалить тексты, которые заявляют слабое произношение без реального измерения. Ошибка выбора/ввода не доказывает голосовую проблему. Полезный разбор привязан к конкретному вопросу, ответу и критерию проверки. Личные тексты/аудио не отправлять в logging без необходимости и согласия.

Из выбранных ошибок доступна повторная практика. Правило «исправлено» определено по успешным попыткам, не просто открытию экрана. Удаление XP не удаляет нормальный учебный результат, но старые level/XP graphs и вычисления вычищаются. Исторический архив не должен активно синхронизировать ненужный опыт.
