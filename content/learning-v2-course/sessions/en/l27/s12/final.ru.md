# Урок 27 · Занятие 12 — Объяснить самочувствие

**Ситуация.** Вы называете ощущения, рассказываете о времени и договариваетесь о приёме.

**Что вы освоите:** сказать, что было бы, если бы…
**Новые слова:** nausea, heartburn, nosebleed, insomnia

## Интро 1

### Если бы была запись на сегодня

Вы можете прийти в клинику сегодня, но записи пока нет. Объясните: I would come today if I had an appointment — я бы пришёл сегодня, если бы у меня была запись на приём. Would come — воображаемый результат; if I had an appointment — условие сейчас. Собираем предложение: I + would come + today + if I had an appointment — кто, что сделал бы, когда, при каком условии. После would нужна come; в условии had без would.

**Выберите фразу для этой ситуации.**

- ✅ **I would come today if I had an appointment.**
- ❌ I would came today if I had an appointment. — *После would нужна начальная форма come.*
- ❌ I would come today if I would had an appointment. — *В условии had без would.*

---

## Интро 2

### Когда записали время

Вы записали время нескольких событий, и собеседник спрашивает, когда сделали эти заметки. Ответьте: I wrote them down yesterday — я записал их вчера. Wrote — прошедшая форма write. Them заменяет the times и стоит между wrote и down. Yesterday называет законченное время; have не нужен. Собираем предложение: I + wrote + them + down + yesterday — кто, wrote, что записал, down, когда.

**Выберите фразу для этой ситуации.**

- ✅ **I wrote them down yesterday.**
- ❌ I have written them down yesterday. — *С yesterday здесь форма прошлого.*
- ❌ I writed them down yesterday. — *Прошедшая форма write — wrote.*

---

## Интро 3

### Посоветовать поставить напоминание

Друг боится забыть время приёма. Посоветуйте: If I were you, I would set a reminder — на твоём месте я бы поставил напоминание. If I were you вводит совет; set a reminder — поставить напоминание. Собираем предложение: If I were you, + I would + set + a reminder — на твоём месте, я бы, действие, что поставить. После условия ставим запятую. После would нужна set без to и без -ing.

**Выберите фразу для этой ситуации.**

- ✅ **If I were you, I would set a reminder.**
- ❌ If I were you, I would setting a reminder. — *После would нужна начальная форма set.*
- ❌ If I were you, I would to set a reminder. — *После would не ставим to.*
