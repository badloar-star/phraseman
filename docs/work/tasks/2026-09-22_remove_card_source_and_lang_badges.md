# Убрать пометки на карточках: «ИСТОЧНИК: …» и код языка (EN/RU/…)

Governance-ID: TG-E69D0BA1C534
Дата: 2026-09-22

## Outcome

Владелец (скриншот экрана «Сохранённые») попросил: «удали вот эти пометки на
карточках навсегда en ru и другие». На карточке было два декоративных элемента,
которые ничему не учат и шумят:

1. Пилюля вверху слева — «ИСТОЧНИК: ВИДЕО · АНГЛИЙСКИЙ» (цветная плашка
   с обводкой, `textTransform: uppercase`).
2. Мелкая надпись по центру над фразой — код языка озвучки («EN», «RU», «UK»,
   «ES», «FR», «DE»).

Обе пометки удалены с ОБЕИХ сторон карточки (лицо и оборот) навсегда.

## Scope

Затронут ровно один файл отрисовки:

- `app/flashcards/FlashcardListItem.tsx` — удалены 4 JSX-блока (бейдж источника
  спереди/сзади, код языка спереди/сзади) и вычисления, питавшие только их.

НЕ затронуто намеренно:

- `app/flashcards/source_labels.ts` (`buildSourceLabel`) — функция остаётся,
  её используют ДВА других живых места:
  - `app/flashcards/CollectionListView.tsx:422` — подпись источника участвует
    в ПОИСКЕ по карточкам (ищется по тексту «видео», «урок» и т.п.);
  - `app/community_pack_create.tsx:1299` — подпись источника в конструкторе
    набора сообщества.
  Удаление функции сломало бы оба.
- `hooks/use-audio.ts` (`speechLocaleToShortLabel`) — остаётся, локаль озвучки
  по-прежнему вычисляется и нужна кнопке звука.
- Пропсы `sourceBadgeStyle` / `sourceBadgeTextStyle` и стили
  `CollectionListView.tsx:1021-1022` — оставлены как есть, чтобы не трогать
  публичный контракт компонента и его второго потребителя
  `components/learning-v2/LearningV2NewWordEncounterOverlay.tsx:385`.
  Удаление пропсов потребовало бы правки чужого экрана ради нуля пользы.

## Architecture

Правка чисто вычитающая: убраны узлы из дерева и мёртвые после этого константы.
Никакой новой логики, состояния, эффектов и сетевых вызовов не добавлено.

## Security and privacy

Сбор/хранение/передача данных НЕ затронуты. Новых полей, разрешений, сторонних
сервисов нет. Privacy Policy обновления не требует — наоборот, с экрана исчезла
подпись, раскрывавшая происхождение карточки.

## Technical debt

- Пропсы `sourceBadgeStyle` / `sourceBadgeTextStyle` стали неиспользуемыми
  внутри `FlashcardListItem`, но остаются в сигнатуре ради совместимости с двумя
  вызывающими. Зачистка — отдельной задачей вместе с их удалением у обоих
  потребителей.
- Стили `sourceBadge` / `sourceBadgeText` в `CollectionListView.tsx` тоже стали
  декоративно мёртвыми по той же причине.

## Verification

- Точечная проверка типов по затронутому файлу.
- `npx jest tests/saved_card_set_builder_domain.test.ts` — сторож
  `buildSourceLabel`, обязан остаться зелёным (функцию не трогали).
- Визуально: экран «Сохранённые» — на карточке ни плашки источника, ни кода
  языка; переворот карточки — то же самое на обороте.

## Rollback

`git revert` коммита этой задачи. Правка изолирована в одном файле, откат
безопасен — удалённые блоки не несли состояния.
