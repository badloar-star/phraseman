# Глобальная нормализация визуального размера аур

## Цель

Сделать ауры аватара визуально компактнее и одинаковее во всех местах приложения: в студии кастомизации, лиге, арене, профилях и других экранах, использующих общий `AvatarAura`/`AvatarView`. Размер самого аватара, геометрия строк и зоны нажатия не меняются.

## Наблюдаемая причина

Все одобренные ауры хранятся на холсте 320×320, однако видимая графика занимает разную долю холста. Проверка альфа-канала всех трёх слоёв каждой ауры выявила две устойчивые группы:

- крупная графика: взвешенный 95-й процентиль радиуса примерно 108–128 px;
- компактная графика: примерно 79–93 px.

Единый коэффициент 2,05× делает первую группу чрезмерно большой, но подходит второй. Простое глобальное уменьшение ухудшило бы уже компактные ауры и не выполнило требование одинакового воспринимаемого размера.

## Выбранное решение

В общем рендерере одобренных аур вводятся два профиля масштаба:

- `1.62×` для визуально крупных ассетов;
- существующий `2.05×` для уже компактных ассетов.

К компактному профилю относятся:

- `aura-neon-circuit`;
- `aura-obsidian-smoke`;
- `aura-phantom-chain`;
- `aura-pixel-party`;
- `aura-plasma-gear`;
- `aura-plus`;
- `aura-pro`;
- `aura-star-choir`;
- `aura-sunset`;
- `aura-violet`.

Остальные одобренные ауры используют новый компактный глобальный масштаб 1,62×. Сезонные ауры сохраняют собственный коэффициент 1,40×: это другой набор арта с собственной безопасной областью.

## Архитектура и поток данных

`AvatarView` продолжает передавать `auraId` и необязательный явный `auraVisualSize` в `AvatarAura`. `AvatarAura` определяет источник арта и выбирает профиль по `auraId`. Если вызывающий код явно передал `auraVisualSize`, явный размер сохраняет приоритет для специализированных поверхностей.

Студия кастомизации перестаёт передавать единый явный диаметр 91 pt для всех аур. Благодаря этому она использует ту же глобальную нормализацию, что лига, арена и профили. Размер превью-аватара 52 pt и размер плитки остаются прежними.

Никакие изображения не редактируются, не пережимаются и не перезаливаются. Версия CDN, SHA-256 и 320×320-контракты остаются без изменений.

## Совместимость и ограничения

- Действующие изменения общей анимации аур в грязном рабочем дереве сохраняются без перезаписи.
- Не меняются ID аур, права владения, цены, сохранённый выбор пользователя или облачная синхронизация.
- Не меняются аватары, премиальный статус, кликабельные области и доступность.
- Градиентный placeholder использует тот же вычисленный диаметр, поэтому загрузка удалённого слоя не вызывает скачка размера.
- Новая одобренная аура по умолчанию попадает в профиль 1,62×. Если её видимая графика относится к компактной семье, её ID должен быть явно добавлен в компактный набор вместе с тестом.

## Проверка

Сфокусированные контрактные тесты должны доказать:

1. общий рендерер содержит два профиля и выбирает 2,05× только для перечисленных компактных ID;
2. остальные одобренные ауры получают 1,62×;
3. сезонный коэффициент остаётся 1,40×;
4. явный `auraVisualSize` по-прежнему имеет приоритет;
5. студия больше не задаёт единый размер 91 pt и наследует глобальное правило;
6. существующие контракты слоёв, CDN и безопасной области остаются зелёными;
7. тесты клуба/лиги подтверждают, что ауры по-прежнему не обрезаются на подиуме и в строках.

## Критерии приёмки

- На одном и том же размере аватара крупные ауры становятся приблизительно на 21% меньше по диаметру холста: 2,05× → 1,62×.
- Уже компактные ауры визуально не уменьшаются.
- Разница воспринимаемого диаметра между двумя группами существенно сокращается.
- Результат одинаков на всех поверхностях, использующих общий рендерер, включая студию.
- Существующие функции и текущие параллельные изменения сохранены.
