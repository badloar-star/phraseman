# PM-066 A1 — размер бандла и недостижимость осиротевших ресурсов (замер 2026-10-04)

Метод: JS-экспорт Android (`NODE_ENV=production`, `EXPO_PUBLIC_STORE_RELEASE=1`, без минификации, с картой ассетов) на HEAD (дерево с коммита 7b27ddbf6 и выше); только JS-бандл и ассеты, нативная часть не собиралась.

| Показатель | Значение |
|---|---|
| JS-бандл (Hermes bytecode, `index-*.hbc`) | 35 808 409 байт ≈ 34,2 МБ |
| Ассеты, выгруженные в экспорт | 99 физических файлов, ≈ 2,8 МБ (в карте ассетов 481 запись) |
| Время экспорта | 53 с |

Недостижимость: в карте ассетов экспорта нет ни одного файла из `assets/images/level-spin-rewards` и `assets/images/league` (0 вхождений) — это каталоги, которые PM-009 пометил «в архиве EAS, но не в бандле» (0,28 + 0,24 МБ). Metro кладёт в бандл только ресурсы, достижимые статическим `require`, поэтому удаление таких файлов НЕ меняет бандл (разница по построению 0 байт); меняется только сборочный архив (≤ 1,37 МБ по PM-009).

Почему нет числа «до/после» по коммитам: нативная зависимость `expo-background-task` ушла из `package.json` внутри общего снимка efe19ae9d (30.09, десятки несвязанных изменений), поэтому разница бандлов между его родителем и HEAD измеряла бы не PM-066. Нативный пакет не входит в JS-бандл; его эффект виден только в размере APK/AAB (замер требует EAS-сборки).

Cold start (вторая половина A1): INBOX §138 — store-release на слабом профиле (2 ядра / 2 ГБ), fin6 ≈ 1,4 с, fin7 ≈ 1,6 с; baseline PM-010 — INBOX §141.

Решение за координатором: принять «0 байт по построению + замер HEAD» как закрытие A1, либо потребовать EAS-замер размера APK до/после снятия нативного пакета.
