# Task packet: автоопределение рабочего стола (ловушка OneDrive)

Governance-ID: TG-F5583440DE92
Status: In progress
Owner: сессия Claude Opus 5 (по запросу владельца)
Related epic/enabler: content/clipper (пакетная сборка)

## Outcome

Ключевое слово `desktop` в аргументе папки разворачивается в НАСТОЯЩИЙ рабочий
стол пользователя, даже если он перенесён в OneDrive. Владелец видит папку там,
где смотрит, а не в скрытом двойнике.

Успех: `batch.py <видео> desktop` создаёт папку в том каталоге, который система
считает рабочим столом; в логе печатается фактический путь.

## Scope

In scope:
- `content/clipper/batch.py` — разрешение пути назначения.
- `content/clipper/README.md` — упоминание ключевого слова.

Out of scope:
- Приложение Phraseman.
- Перенос уже созданных файлов (сделан вручную).
- Остальные шаги конвейера.

## Architecture

Текущая граница: путь назначения принимается буквально из argv. При
`C:\Users\badlo\Desktop` Windows молча создаёт скрытый каталог, если реальный
рабочий стол перенесён в OneDrive — инцидент 20.09.2026, владелец не нашёл
файлы.

Целевая: если аргумент равен `desktop` (без учёта регистра), путь берётся из
системы: реестр Windows (User Shell Folders, ключ Desktop) с откатом на
USERPROFILE/OneDrive/Desktop и USERPROFILE/Desktop — первый существующий.
Явно переданный абсолютный путь работает как раньше.

Инвариант: фактический путь назначения ВСЕГДА печатается в лог до начала
работы, чтобы расхождение было видно сразу, а не после сборки.

## Security and privacy

Личных данных нет. Читается только путь к папке текущего пользователя из его
же реестра; ничего не отправляется наружу. Firestore, аккаунты, детские данные
не затронуты; privacy policy без изменений.

Запись вне проекта остаётся явной: скрипт пишет туда, куда указал владелец.

## Technical debt

- **Pay now:** убирается класс ошибки «файлы не там, где пользователь смотрит».
- **Accept temporarily:** определение через реестр — только Windows. На другой
  ОС откат на переменные окружения. Владелец, пересмотр — если появится Mac.

## Rollback

не ломает. На приложение и сборку не влияет.
