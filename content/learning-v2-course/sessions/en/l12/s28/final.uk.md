# Англійська · Урок 12 · Заняття 28 — Догляд за одягом і взуттям

**Ситуація.** Згадайте, чим користувалися перед виходом із дому.

**Що ви опануєте:** changed /d/, used /d/, wanted /ɪd/, needed /ɪd/
**Нові слова:** shoehorn, shoe polish, clothes brush, lint roller

## Інтро 1

### Ложка для взуття

Shoehorn — «ложка для взуття». I used a shoehorn — я скористався ложкою для взуття. У used, коли це минуле від use «користуватися», закінчення /d/. Виберіть учорашню дію.

**Виберіть фразу для цієї ситуації.**

- ✅ **I used a shoehorn yesterday.**
- ❌ I use a shoehorn yesterday. — *Для минулого потрібна used.*
- ❌ I uses a shoehorn yesterday. — *Uses — не минуле й не форма з I.*

---

## Інтро 2

### Крем і щітка

Shoe polish — «крем для взуття», clothes brush — «щітка для одягу». We changed the clothes brush — ми замінили щітку для одягу. Change → changed: закінчення /d/, без окремого складу. Виберіть повідомлення про заміну щітки.

**Виберіть фразу для цієї ситуації.**

- ✅ **We changed the clothes brush.**
- ❌ We used shoe polish. — *Це використання крему, не заміна щітки.*
- ❌ We change the clothes brush yesterday. — *Для минулого потрібна changed.*

---

## Інтро 3

### Ролик для одягу

Lint roller — «липкий ролик для чищення одягу». I needed a lint roller — мені був потрібен ролик. У needed закінчення /ɪd/, як у wanted. Виберіть повідомлення про минулу потребу.

**Виберіть фразу для цієї ситуації.**

- ✅ **I needed a lint roller.**
- ❌ I need a lint roller yesterday. — *Для минулого потрібна needed.*
- ❌ I needs a lint roller yesterday. — *Needs — не минуле й не форма з I.*
