# Task packet: слияние оверрайдов интро по ключу экрана

Governance-ID: TG-D5F8257FB4C6
Status: In progress
Owner: сессия «Темы» (интро классики)
Related epic/enabler: TG-8A3674E816C9 (слой оверрайдов), TG-FD8D5C0A3024 (интро по стандарту)

## Outcome

Переписанные интро доходят до собранного `modules/classic-courses/<lang>/intro.json`. Причина поломки найдена: два файла оверрайдов (ru/прочие — Темы, uk — Переводчик) сливались целиком по ключу экрана, и запись uk затирала все русские поля того же экрана. Мерка: после пересборки en в `intro.json` урок 1 имеет заголовки из оверрайда.

## Scope

In scope: строка слияния `INTRO_OVERRIDES` в `scripts/classic_course_pack.mjs` — поля объединяются внутри каждого ключа экрана.
Out of scope: формат файлов оверрайдов; тексты интро; правки других хунков скрипта (Теория).

## Architecture

Граница: два файла оверрайдов → один словарь по screenId → `applyIntroOverrides`. Инвариант: поле одного файла не затирается полем другого файла того же экрана; при совпадении одного поля побеждает файл, идущий позже в списке (uk).

## Security and privacy

Не применимо: учебный текст, персональных данных и сети нет.

## Technical debt

- Pay now: слияние по ключу — исправлено здесь.
- Accept temporarily: уникальных полей в обоих файлах нет; при будущем конфликте одного поля — поведение задокументировано в комментарии.

## Verification

- `node --check scripts/classic_course_pack.mjs` — синтаксис.
- Слияние двух файлов на en:01:intro:1 даёт поля titleRU, textRU, linesRU, titleUK, textUK, linesUK — проверено.
- Пересборка en — titleRU урока 1 равен «Что учим сегодня» в `intro.json`.

## Rollback

Вернуть прежнюю строку слияния `Object.assign` — оверрайд uk снова затрёт русские поля; откат безопасен, данных не касается.
