# Известные расхождения к выпуску 05.11

## 1. Контраст кнопок на светлом низу тёмной сцены (экран «Онбординг „ага“» и «Приветствие нового языка»)

- Что: в тёмном оформлении низ сцены стал светлее (одобрено владельцем: ровный тон неба). Кнопка записи и подписи на нём читаются слабее порога.
- Цифры:
  - «Онбординг ага»: кнопка записи 2.29–2.48 при пороге 2.5 — графит, полярная, сланец, таупе, олива, шалфей, эвкалипт; «чисто» 2.84–2.99 при пороге 3 — полярная, шалфей, эвкалипт.
  - «Приветствие нового языка»: кнопка на фоне < 3 — rose, taupe, olive, sage, eucalyptus, grad_aurora.
- Решение координатора 05.11: вариант (б) — визуал к выпуску не меняем, порог не ослабляем молча.
- Тесты: помечены KNOWN-списками в tests/onboarding_aha_theme_palette.test.ts и tests/scene_theme_single_source_guard.test.ts; новые расхождения по этим же правилам всё так же падают.
- Снятие: следующая обнова — визуальное решение кнопки на светлом низу (тёмная кнопка из токена ink) по кадру владельца; после этого убрать KNOWN-списки.
- Владелец зоны: сессия «Темы».

Примечание к тестам: в «Приветствии» известное расхождение помечено для всех тёмных тем с сообщением «кнопка … на фоне < 3» (порог по числу в сообщении не разбирается); в «Онбординге ага» — пороги по замеру: кнопка записи ≥ 2,2 и «чисто» ≥ 2,8. Новые падения за этими порогами и в других оформлениях по-прежнему красные.
