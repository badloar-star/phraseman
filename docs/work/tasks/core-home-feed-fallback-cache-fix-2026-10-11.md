## Outcome

При 404 или сбое RSS лента собирается так:

| Состояние | Источник | Чтения | Ошибка |
|---|---|---|---|
| Сохранённый список канала свежее 6 ч | этот список (`source: feed_cache`) | 0 | нет |
| Список старше 6 ч или его нет | один запрос в серверный каталог за запуск (`source: catalog`), проверка `youtubeChannelId` | один запрос | нет |
| Каталог не ответил, есть старый список | старый список (`feed_cache_stale`) | — | нет |
| Ничего нет | встроенный запасной список (`builtin`) | — | нет |
| Переопределённый канал без кэша | пусто | — | есть |

Ошибка — только когда показать нечего.

Вердикт cold5: свежий кэш отдавался с `error=404`, поэтому лента выглядела как сбой без обновлений.

## Verification

Тесты на все ветки:
- свежий кэш + совпадение канала → лента из кэша, `error` нет, каталог не читается;
- старый кэш → каталог;
- старый кэш и каталог упал → старый кэш;
- пусто → встроенный список;
- чужой канал каталога не показывается.

Плюс прежние наборы ленты.
