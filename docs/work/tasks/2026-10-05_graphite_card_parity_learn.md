## Outcome

Два отличия Сверки на экранах Learn:
1. Заливка карточек в «Затмении» светлее макета. Причина: токен Графита `opaqueCard = #222429`, макет `learn.html` (kit.css) — `.card { background: var(--card) }`, `--card: #151517`. Починка: `opaqueCard` Графита → `#151517`.
2. Кнопка «Начать» лавандовая. По коду `PracticeCta` берёт `glass.cta`; у Графита `cta = #F2F1F6` на ЛЮБОЙ насыщенности (формулы уровней не меняют `cta`) — ровно как `--cta` макета. Лавандовый `cta` даёт тема `lavender` («Туманность»): на эмуляторе, по-видимому, выбрана не «Затмение». Не чиню наугад (правило «сперва логи»): в лог гидратации добавлен id темы `[THEME] hydrate`, Сверка подтверждает тему; если окажется «Затмение» — разбор по логу.

## Architecture

Нет изменений архитектуры: одно значение токена. Каскад рисков (69 файлов читают `.opaqueCard`):
- все непрозрачные карточки в «Затмении» темнеют `#222429 → #151517` (Главная через V2-палитру `card`, Learn, Карточки, Диалоги, Настройки, шторки-карточки) — это совпадает с макетом kit `--card` на всех экранах 2.0;
- контраст текста растёт (белый на #151517 выше), плашки `opaqueControl #222429` на карточке становятся заметнее — как `--tile/--control` макета;
- риск: места, где `opaqueCard` использован НЕ как карточка (фон чипа/кнопки) — станут темнее макетного `--control`; ловит пересъёмка Сверки;
- градиентные темы (тёмные) подмешивают акцент в `graphite.opaqueCard` → их карточки тоже темнее (формула макета градиентов: `rgba(24,24,27,.72)` ≈ та же тёмная база) — согласовано;
- уровни/ползунок: «Максимум» пересчитывает `opaqueCard` своей формулой (не затронут), 0…0.5 — смешивание от новой базы.
