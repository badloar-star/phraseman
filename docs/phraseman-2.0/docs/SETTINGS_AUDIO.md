# Настройки, уведомления и единый TTS

Реестр настроек: visible label, route/action, current owner, status, migration, accessibility. Удалить темы, Макса, голосовые разборы с ним, игровые уведомления и controls удалённых функций. Не удалять account/privacy/purchases/language по сходству с лишними настройками.

«Очистить кеш» проверяется до переименования/перестановки. Кеш — только восстанавливаемые данные: media previews/TTS caches, временные snapshots по согласованной политике. Не auth/session, не приватные наборы, не единственная копия progress, не purchases, не durable outbox. Проверить действие при офлайн и незавершённой синхронизации.

## Уведомления
Сначала типизация: социальные события → Активность; удалённые игровые сценарии → retired; важные сообщения об аккаунте/покупке/безопасности → оставить нужный канал; напоминания о практике → отдельно согласовать. Старые already-scheduled local notifications нужно отменить миграцией. На сервере снять producers/queues/cron, а не только клиентские switch. Не удалять системную возможность управлять разрешением пользователя.

## Озвучка
Цель — TTS по умолчанию везде, без лишней большой библиотеки предзаписанной речи. Фраза «либо наш голос» создаёт исключение: до удаления подготовить allowlist учебного аудио по V1/V2/другим разделам. Удаление звуков фанфар не должно снести video player, микрофон или speech recognition.

Один audio owner/arbiter: TTS, видео, запись не говорят одновременно. Отмена при смене карточки/экрана/аккаунта, обработка background/headphones/phone call и отсутствующего голоса. Переход к TTS может снизить объём медиа, но качество произношения/офлайн зависит от доступного движка и конкретной локали; нужна проверка на устройствах, не абстрактная гарантия.

После разрешения по allowlist убрать packs/manifests/seeds/prefetch/cache jobs/download links, ненужные effects/sounds и remote objects после compatibility period. Не запускать cloud TTS заново как «улучшение» без отдельной стоимости/решения.

## Проверки платформы до удаления старого аудио
Официальная Expo Speech документация latest указывает: speak при текущем воспроизведении добавляет фразу в очередь, stop очищает её; pause/resume не доступны на Android; на физическом iOS устройстве silent mode может означать отсутствие звука. Поэтому тестировать смену карточки, stop, повторное нажатие, iOS silent mode и доступные голоса, а не только эмулятор. Это сведения W11, а не подтверждение версии SDK проекта: сначала сверить установленную версию и фактический audio-session контракт.
