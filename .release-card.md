## Goal

Restore first-attempt friend lookup, responsive Friends navigation, correct Google sign-in visibility, accurate rapid lesson taps, honest dev purchase behavior, and admin-granted Plus access in AI dialogues.

## Allowed changes

- Narrow React Native fixes and focused regression tests for the reported user flows.
- Server-side friend lookup and Premium entitlement resolver fixes.
- Exact Firebase Functions deploy of `friendLookupUser` and `premiumDialogSend` only.
- Production OTA for iOS and Android on runtime 1.5.53.

## Forbidden changes

- No Firestore rules, indexes, Hosting, Remote Config, admin UI, or production-data mutation.
- No broad Functions deploy and no unrelated account-deletion/backend changes.
- No removal or replacement of existing app functionality.

## Risk level

medium — the release touches identity and paid-access reads, but writes no entitlement data and is isolated in a clean release worktree with focused tests and exact deploy targets.

## Manual tests

- Regression area: friend code search, friend live lists, normal paid/free paywall behavior, lesson word selection, and account-linked Premium.
- Upgrade from previous version: verify a TestFlight runtime 1.5.53 install downloads and applies the OTA after a complete restart.
- User type(s): existing admin-VIP, existing paid, existing free, and provider-linked accounts.
- Platform-specific checks: verify the OTA update group contains both iOS and Android manifests; iOS TestFlight is the primary reported path.
- Performance check: switch away from Friends immediately and confirm tabs remain responsive while auth/network work is pending.
