# Правила писателя v2 (по замечаниям независимых читателей-новичков, 05.11) — ОБЯЗАТЕЛЬНО для новых уроков

1. Каждое слово изучаемого языка, которого не было в предыдущих уроках, получает ОТДЕЛЬНУЮ строку-перевод сразу после фразы-примера: «Слово Tasche значит «сумка»». Перевода всей фразы недостаточно. Уже известные слова не переводи повторно.
2. Не больше 8 новых слов в одной главе. Дроби на главы (до 8 глав на урок; ≤30 примеров на урок).
3. Слова со сменой смысла (leave: «уйти»/«оставлять», sign: «подписать»/«надпись», open: «открыть»/«открыт», last: «последний»/«прошлый») — при первом появлении в уроке одной строкой скажи, что здесь такой смысл; смыслы одного слова в соседних уроках не должны противоречить.
4. Формы слов объясняй причиной (cancel → cancelled: «две l», try → tried: «y меняется на i + ed»), без грамматических терминов. Формы прошедшего: смысл перевода формы совпадает со смыслом основного слова (take → took «взял»); поясняй переносные значения («took the bus» — «поехали на автобусе»).
5. was/were, do/does/did и другие «слова-помощники» вводи явно ПЕРЕД первым использованием: что значат и что по-русски их не говорят.
6. Никаких «россыпей слов» («Слова: a, b, c…») — слово вводится только внутри фразы с переводом.
7. Никаких мета-фраз («образец — это…», «в примерах урока…», «запоминайте вместе с…», «курс переводит…»).
8. Задания (по 1 образцу + 2 реальных на главу, ≥8 реальных на урок) — только со словами, показанными ДО этого места.
9. P0: в en-тексте нельзя упоминать русский язык и кириллицу. Обращение «вы». Чтение русскими/украинскими буквами с ударением (´ над кириллической гласной).
10. После записи: fixmixed → check → coverage («замечаний: 0», «не введено 0») → render → независимый читатель-новичок (отдельный агент, читает только review/<lang>_lesson_NN_ru.md) → правка до «ПОНЯТНО 0 мест».
