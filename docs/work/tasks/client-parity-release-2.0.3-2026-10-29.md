## Outcome

Все клиентские файлы, которые релизная ветка `release/community-2026-10-26` (da0a435e3) изменила с развилки 82cfea233, есть в нашей ветке: либо побайтно равны релизу, либо (11 «ручных») — надмножество релиза плюс наше новое. После этого OTA из нашей ветки не откатывает людям Сообщество и конкурс. Мера успеха: сверка «релиз ⊆ наша версия» по каждому из 138 путей, полная проверка типов приложения и тесты Сообщества и конкурса зелёные, затем проверка Сверки на устройстве.

## Scope

In scope: клиентские пути из списка Ядра (127 — побайтно равные релизу в рабочем дереве, коммит как есть группами и только эти пути); 11 ручных: community_pack_create, packSocialLive, dev_community_scene_preview, CommunityPackPreview, FlashcardsCategoryHub, flashcards_collection, CommunityPackCheckScene, CommunityPackScene, CommunityScene, CommunityWinnerDialog (моя версия 68fa2660b новее — оставить), shared/community_month_contest (версия Ядра новее — оставить). Сверка по правилу: релиз должен быть подмножеством нашей версии; недостающее вношу из релиза.

Out of scope: ачивки и прочие сироты, серверные пути (functions*, admin, scripts, docs), любые изменения, не нужные для паритета.

## Architecture

Нет архитектурных изменений: это перенос уже выпущенного кода (Сообщество, конкурс) в нашу ветку. Инварианты: файл рабочего дерева == релизу побайтно (по нормализованным окончаниям строк) для группы A; для ручных — сравнение построчно «все содержательные строки релиза присутствуют», доведение руками, тесты. Коммиты группами по теме, только перечисленные пути через safe_commit (временный индекс, сверка numstat).

## Security and privacy

Код уже выпущен в релизе 2.0.3, новых данных и сервисов не добавляется; политика конфиденциальности не меняется этим переносом (конкурс и лесенка отражены в разделе 7, коммит 6aa721e13).

## Technical debt

Pay now: паритет с релизом. Contain: тест «релиз ⊆ ветка» по списку путей (скрипт сверки лежит рядом с отчётом) — иначе следующий OTA снова может откатить. Accept temporarily: 11 ручных путей, где наша версия новее, проверены вручную; сроки — сегодня вечером.

## Verification

Скрипт сверки по каждому пути (равен / надмножество / отличается), полная проверка типов приложения под светофором, тесты Сообщества и конкурса (`tests/community_*`, `tests/contest*`, `tests/story_contest*`), затем проверка Сверки на устройстве. Хэши коммитов и итог — координатору.

## Rollback

Каждая группа — отдельный коммит; откат — `git revert` группы. Данных пользователей перенос не трогает.
