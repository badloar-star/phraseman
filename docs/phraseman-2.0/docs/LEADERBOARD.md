# Недельный топ-3

Текущее направление — убрать длинный список 30 участников и оставить спокойный top-3/пьедестал. Предпочтение top-3 явнее раннего «top-5». Название одним словом утверждается; «Рейтинг» — рабочее предложение. Ранняя идея добавить игру к лиге не разрешает вернуть арену/построить башню.

Метрика требует точного решения. Рекомендация: eligible earned coins/week, не текущий wallet balance, иначе человек наказывается за повышение ранга. Не XP, поскольку он удалён. Переход недели, timezone, tie-break и защита от подмены событий фиксируются в контракте. Ранг игрока не равен месту в рейтинге.

Снимок top-3 можно читать одним компактным payload, но нельзя считать только это чтение. Записи событий и обновление агрегата, security rules/index reads, работа scheduler и стоимость повторов входят в budget. Не читать весь users collection каждые 3 часа лишь для трёх имён. Частота 3/6 часов — варианты владельца, а не обязательный cron. UI должен соответствовать реальной свежести.

Анимация изменения с последнего визита вычисляется из нового snapshot и локального lastSeen. Серверный cron для визуального движения не нужен. Снизить движение/отключить при reduce motion, не менять положение кнопок во время касания.

League boosts, сундук, modifiers энергии и остальные игровые привилегии удаляются. Если их покупали — отдельное рассмотрение в ledger; не удалять исторические права незаметно. При нуле участников/недоступной сети отображается честное состояние, не выдуманные лидеры.
