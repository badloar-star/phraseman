# Кнопка «Перевести на все языки» для набора

Governance-ID: TG-3316629FE833
Дата: 2026-09-21

Запрос владельца: «наборы должны переводиться автоматически на все языки
интерфейса — если включён украинский, будет перевод на укр», «при одобрении
набора надо добавить кнопку перевести на все языки», «и ИИ переводит на все
языки интерфейса которые у нас есть в приложении».

## Диагноз

Кнопки нет — не сделана. Автор пишет набор на ОДНОМ родном языке, и человек с
украинским интерфейсом видит русский текст.

## Outcome

В панели проверки появляется кнопка «Перевести на все языки». ИИ переводит
исходную (родную) сторону каждой карточки на остальные языки интерфейса;
изучаемая сторона (английский/французский) НЕ трогается.

Языки интерфейса (подтверждено по `app/source_locales.ts`,
`INTERFACE_SOURCE_LOCALE_STATUS`, все active): **ru, uk, es, pt-BR, vi, id,
tr, pl**.

## Scope

### Новое
- `functions/src/admin_community_pack_translate.ts` — callable
  `adminCommunityPackTranslateLocales` (admin-only, secret `OPENAI_API_KEY`).
- Тест-контракт рядом.

### Правится
- `functions/src/index.ts` — экспорт.
- `admin/v2/legacy.html` — кнопка в панели проверки.

### НЕ трогается
- `admin_translate.ts` — у него лимит 20 полей и профиль перевода писем;
  ломать работающую функцию ради другого сценария нельзя.

## Architecture

Почему отдельная функция, а не переиспользование `adminTranslateMessage`:
- `MAX_FIELDS = 20`, а в наборе до 50 карточек;
- у карточек свой контракт: переводим ТОЛЬКО исходную сторону, целевой язык
  обучения неприкосновенен;
- перевод пишется в `sourceLocales` карточки, а не в плоские поля письма.

Карточки режутся на пачки по 25, каждая — один запрос к OpenAI. Запись —
одной транзакцией после всех пачек, чтобы набор не остался переведённым
наполовину.

Целевые локали берутся из константы, зеркалящей `INTERFACE_SOURCE_LOCALE_STATUS`;
сторож сверяет список с `app/source_locales.ts`, чтобы новый язык интерфейса
не забыли добавить.

## Security and privacy

Admin-only (`request.auth.token.admin`), `enforceAppCheck: ENFORCE_APP_CHECK_OPENAI`,
ключ OpenAI только на сервере. В OpenAI уходит ТОЛЬКО текст карточек:
`authorStableId`, uid, email не отправляются — как и в проверке.

Privacy policy правок не требует: новых данных не собираем, новых получателей
нет, OpenAI уже обрабатывает этот же пользовательский контент при проверке.

## Technical debt

Перевод машинный и не проверяется человеком по каждой локали. Если качество
для какого-то языка окажется плохим, править придётся руками или повторным
прогоном.

- `npx tsc --noEmit` по functions.
- Живой прогон на стенде: кнопка зовёт функцию, набор не публикуется.

## Rollback

`git revert`. Функция новая, существующие не менялись; откат убирает кнопку
и оставляет уже записанные переводы (данные не теряются).
