# Английский · Урок 22 · Занятие 25 — Выбрать ту или те

**Ситуация.** Вы сравниваете вещи и выбираете подходящие.

**Что вы освоите:** determiner|adjective + one|ones
**Новые слова:** hooded, patterned, loose-fitting, tight-fitting

## Интро 1

### Куртка с капюшоном

Hooded — с капюшоном. Вы выбираете одну куртку и хотите именно куртку с капюшоном: the hooded one. One заменяет jacket. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I want the hooded one.**
- ❌ I want the hooded ones. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I want the hooded it. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 2

### Узор и свободный покрой

Patterned — с узором, не однотонный. Узор может быть разным; striped — полосатый — уже знакомый частный случай. Вы выбираете шторы, то есть несколько предметов: the patterned ones. Loose-fitting — свободного покроя: рубашка не облегает тело. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I like the patterned ones.**
- ❌ I like the patterned one. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
- ❌ I like the patterned them. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*

## Интро 3

### Облегающие джинсы

Tight-fitting — облегающий, плотно сидящий по фигуре. Это описание покроя, а не обязательно ошибка размера. Jeans — слово во множественном числе, поэтому говорим the tight-fitting ones, даже когда выбираем одну пару джинсов. One заменяет уже названное исчисляемое существительное в единственном числе, ones — во множественном: the red shirt → the red one; the red shirts → the red ones. Сохраняем описание вещи перед one / ones. Здесь one означает не счёт «один», а заменяет название вещи.

**Выберите фразу для этой ситуации.**

- ✅ **I do not want the tight-fitting ones.**
- ❌ I do not want the tight-fitting one. — *В этой ситуации название вещи заменяем one для единственного числа или ones для множественного.*
