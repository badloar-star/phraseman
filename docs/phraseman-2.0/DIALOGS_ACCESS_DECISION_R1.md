# Диалоги в R1: кто может открыть первый диалог — решение владельца (12.10, утро)

Источник цифр: Ядро, 12.10 ~01:30, только чтение кода (file:line у Ядра). Код экономики не менялся.

## Как сейчас
- Новичок стартует с ранга 0. На ранге 0 не открыт **ни один** диалог.
- Нужный ранг по уровню: A1 → 1, A2 → 6, B1 → 11, B2 → 14 (`app/ai_dialog_level_lock.ts:60–70`; каталог V2 — ранг = номер диалога в мире, 1…16).
- Монеты: ранг 1 = 1 000; ранг 6 = 21 000 суммарно.
- Обхода нет: ни Plus, ни покупка, ни пробный диалог (`FREE_DIALOGS_LIFETIME_DEFAULT = 0`). Комментарии о «трёх бесплатных» в `DialogsTabContent.tsx:417`, `ai_dialog_briefing.tsx:179` устарели.

## Сколько зарабатывает новичок (free)
| Источник | Монеты |
|---|---|
| Старый урок, первый проход (бесплатны уроки 3–8) | ≈150 + бонус серии до 105 |
| Повтор урока | ≈50 |
| Практика (словарь, глаголы, карточки, ошибки) | +3 за элемент, повтор +1 |
| Задания дня | 150 в день |
| Шпиль (только ru/uk) | первые 5 этажей ≈550, полное восхождение ≈3 050 в неделю |
| Learning V2 | сейчас 0 (в стор-сборке нет открытых сессий) |

Оценка: ранг 1 — через 2–3 дня (с Шпилём — 1–2), ранг 6 (A2) — через 1–3 месяца.

## Варианты
1. **Оставить как есть.** Диалоги — награда за прогресс. В первые 2–3 дня вкладка показывает только замки.
2. **Один пробный диалог на ранге 0** (`FREE_DIALOGS_LIFETIME_DEFAULT = 1`). Новичок сразу пробует фичу. Цена — вызовы ИИ на каждого нового пользователя.
3. **Первый диалог мира A1 открыт с ранга 0** (порог A1 = 0 для диалога №1). То же по цене, но без счётчика «пробных».

Координатор ничего не менял: варианты 2–3 добавляют расходы на ИИ, это решение владельца.
