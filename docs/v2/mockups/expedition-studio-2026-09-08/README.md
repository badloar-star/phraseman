## Критерии

1. Одна экспедиция от дневника и маршрута до итогов, с отдельным характером checkpoint.
2. Шесть настоящих механик: сборка, слушать/выбрать, диктант из слов, пропуск, четыре пары, удержание для речи. Ошибка не переставляет варианты; тексты слушания скрыты до попытки; голосовая неопределённость нейтральна.
3. Три различающихся словаря с одними данными и общим сохранением; накопление нескольких карточек справа без потери ответа/шага.
4. Повтор сцен, состояния ошибки/успеха/паузы/недоступного аудио, reduced motion, короткие и узкие экраны.
5. Автономный `standalone.html`, проверка браузером и focused native gates.

Нативная правка: словарь получает свой `Modal fullScreen` и safe-area; Horizons по умолчанию развёрнуты, меню возвращает все прежние controls. Это исправление геометрии, не интеграция новых вариантов словаря.

## Последние решения владельца и реализация

- Макет открывается в корпусе телефона шириной 390 px; доступен узкий 320 px. Раздел заполняет внутренний экран, системные отступы и навигация сохранены.
- Концепция «миров» снята в новом дизайн-предложении. Выбор — «Экспедиции», внутри понятный урок и маршрут. Сгенерированный дневник заменяет схематичную арку на входе и в подготовке. Новая иллюстрация пока используется только в макете.
- Девять палитр читаются сборщиком непосредственно из `constants/theme.ts`. Переключатель имитирует выбранную тему; отдельный HTML не имеет доступа к ThemeContext запущенного приложения. В нативных Horizons, artwork, результатах и фоновой оболочке используется активный ThemeContext, включая live preview темы.
- Словарь и карман сохраняют текущий ответ. Автоматическое появление находки не открывает модалку. Общие закладки между вариантами A/B/C. Таймер останавливается при модалках и каталоге, учтён режим без таймера.
- Данные обучения, распознавание голоса и награды в HTML — демонстрация; реальный баланс не меняется.
