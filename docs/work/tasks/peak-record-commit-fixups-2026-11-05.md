# Task packet: доводка коммита «Рекорд этажа» — журнал причины в catch, «Ты» с рангом из профиля

## Outcome
Коммит «Рекорд этажа» (спорная сцена Пика + сервер) отклонил pre-commit: сторож немых catch не видит журнал причины в четырёх catch (`spire_pack_build.ts` ×3 через локальный помощник `warn`, `spire_floor_record_readiness.ts`). Правка делает причину видимой в журнале и для сторожа. Затем — строка «Ты» и чужие монеты на экране Пика берут ранг из актуального источника (`useMyCoinRank`), а не из устаревшего документа комнаты.

## Scope
- `functions/src/spire_pack_build.ts`: помощник `logger` над существующим `warn` (поведение не меняется).
- `functions/src/spire_floor_record_readiness.ts`: `console.warn` с причиной в catch.
- `components/spire/peak/PeakScreenV2.tsx`: для строки «Ты» ранг монеты = ранг пользователя из `towerProps.myCoinRank` (источник — `useMyCoinRank` в `SpireHomeScreen`), 0 новых чтений.
- Вне объёма: серверная запись ранга из профиля при входе в комнату (отдельным шагом, если координатор подтвердит), раскатка функций.

## Architecture
No architecture change: клиент подменяет ранг только для собственной строки; сервер и формат комнаты не меняются.

## Security and privacy
Журнал содержит только текст ошибки, без личных данных. Ранг монеты уже публичное поле профиля и комнаты.

## Technical debt
Contain: серверный источник ранга в комнате остаётся прежним (клиент присылает при входе); устаревание чужих монет — отдельная задача.
