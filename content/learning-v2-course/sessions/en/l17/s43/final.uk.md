# Англійська · Урок 17 · Заняття 43 — Адреси для замовлень і листів

**Ситуація.** Ви перевіряєте адреси кількох замовлень і листів родини після переїзду.

**Що ви опануєте:** some / any + plural count noun or non-count noun
**Нові слова:** delivery address, billing address, return address, forwarding address

## Інтро 1

### Повідомити про наявність

delivery address — адреса доставки. Для замовлень родини збережено кілька адрес. Підтвердьте це. Delivery address → delivery addresses. Some ставимо перед злічуваним у множині або незлічуваним, коли повідомляємо про певну кількість.

**Виберіть фразу для цієї ситуації.**

- ✅ **We saved some delivery addresses.**
- ❌ We saved any delivery addresses. — *У стверджувальному повідомленні про певну кількість використовуємо some.*
- ❌ We saved a delivery addresses. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 2

### Повністю заперечити наявність

billing address — адреса, зазначена для виставлення рахунку. В отриманому списку немає таких адрес узагалі. Billing address → billing addresses. return address — адреса відправника для повернення листа або посилки. Some використовується з множиною злічуваних та з незлічуваними. У запереченні зі значенням «жодного» зазвичай вибираємо any.

**Виберіть фразу для цієї ситуації.**

- ✅ **We don't have any billing addresses.**
- ❌ We don't have some billing addresses. — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ We don't have a billing addresses. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 3

### Запитати без припущення

forwarding address — нова адреса, на яку пересилають пошту після переїзду. Кілька мешканців переїхали. Ви не знаєте їхніх нових адрес. Запитайте нейтрально, без очікування відповіді «так». Forwarding address → forwarding addresses. У нейтральному запитанні зазвичай any. Some теж трапляється в запитаннях: наприклад, у пропозиції Would you like some tea? або коли очікують «так». Тому враховуйте ситуацію, а не лише знак питання.

**Виберіть фразу для цієї ситуації.**

- ✅ **Do you have any forwarding addresses?**
- ❌ Do you have some forwarding addresses? — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ Do you have a forwarding addresses? — *A не ставиться перед незлічуваним або множиною.*
