# Цветная деталь «Глины» бледная: расчёт (Темы, 15.10) — БЕЗ правки токенов

Кадры: `docs/phraseman-2.0/evidence/clay_home/` (Закат = terracotta, Мята = sage, Графит). Расчёт — OKLCH токенов `liquidGlassTokens(id, { appearance, intensity })`; L — светлота, C — насыщенность (0 серый … 0,15 яркий).

## Причина: плитка красится токеном `accentBright`, а он в тёмных темах — пастель

| тема, оформление | уровень | accent | accentBright (сейчас красит деталь) |
|---|---|---|---|
| Закат (terracotta) dark | 0 «Спокойно» | #F6DFD7 L0,92 C0,03 | #F6DFD7 L0,92 C0,03 |
| Закат dark | 0,5 / 1 | **#FF9A84 L0,79 C0,13** | #FFC6B4 L0,87 C0,07 |
| Мята (sage) dark | 0 | #D8EADB L0,92 C0,03 | #D8EADB L0,92 C0,03 |
| Мята dark | 0,5 / 1 | **#5ED99E L0,80 C0,14** | #A1F3C7 L0,90 C0,10 |
| Графит dark | 0 | #F2F1F6 L0,96 C0,01 | #F2F1F6 L0,96 C0,01 |
| Графит dark | 0,5 / 1 | #ABC0D7 L0,80 C0,04 | #D0E0F1 L0,90 C0,03 |
| Закат light | 0 | #331610 L0,24 C0,05 | #47221A L0,30 C0,06 |
| Закат light | 0,5 / 1 | #B53621 L0,52 C0,17 | #B53621 (то же) |
| Мята light | 0,5 / 1 | #008445 L0,54 C0,14 | #008445 (то же) |
| Графит light | 0,5 / 1 | #4D6C8C L0,52 C0,06 | #4D6C8C (то же) |

Выводы:
1. **Уровень 0 («Спокойно») нейтрален по замыслу**: у всех тем accent почти белый/почти чёрный (C 0,01–0,06). Кадр, снятый на уровне 0, не может показать цвет темы — это не дефект токена, а само «Спокойно» (как белые кнопки Plus и серые плитки).
2. **На уровнях 0,5 и 1 в ТЁМНОМ оформлении `accentBright` бледнее `accent`**: Закат C 0,07 против 0,13, Мята C 0,10 против 0,14, светлота 0,87–0,90 против 0,79–0,80. Именно `accentBright` сейчас красит слой — отсюда «почти белое».
3. В светлом оформлении на 0,5 и 1 `accentBright` = `accent` — деталь насыщенная и тёмная, правка там не нужна.

## Предложение (на решение координатора)

**Вариант А (рекомендую, один токен, минимум кода):** красить слой `accent`, а не `accentBright` — в `ThemedArtLayers` (и, если нужно, в `ThemedArt`) `tint = tokens.accent`. Даёт Закат #FF9A84 и Мята #5ED99E (C 0,13–0,14) на 0,5/1 в тёмных, светлые не меняются, на уровне 0 остаётся нейтрально. Контраст к тёмной глине ≥ 6,0, к светлой ≥ 3,9 (страж `themed_art_clay_accent_contrast` остаётся зелёным).

**Вариант Б (если «Графит» тоже должен быть цветным):** артовый токен `artAccent` = оттенок `accent`, светлота зажата ([0,66…0,80] dark / [0,46…0,58] light), C не ниже 0,11 — но ТОЛЬКО при уровне > 0 (на уровне 0 оттенок серого произвольный: расчёт на Графите дал бы сиреневый #C3AFFD — это неверно). Графит dark 0,5/1 → #87C3FF (C 0,11, контраст 6,64), Графит light → #306CA6 (4,54). Меняет «личность» графитовой темы на плитках — решение владельца.

Расчётные образцы (hex) для проверки глазами: Закат dark 0,5 → `#FF9A84` (А) / `#FF9A84` (Б); Мята dark 0,5 → `#5ED99E` / `#5ED99E`; Графит dark 0,5 → `#ABC0D7` (А) / `#87C3FF` (Б).
