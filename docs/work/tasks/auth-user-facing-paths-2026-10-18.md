# Вход, выход, привязка и смена аккаунта: что видит человек (опись 18.10)

Только чтение, без правок кода. Составил «9 · САЙТ» по заданию координатора; файлы входа принадлежат «5 · АВТОРИЗАЦИЯ».

Эталон состояний: [docs/design/v2-app/auth-states.html](../../design/v2-app/auth-states.html) (af3c6e324).

Правила владельца, по которым ставится вердикт:
- **П1** — никаких системных и технических текстов на экране.
- **П2** — никаких полноэкранных ошибок.
- **П3** — вход из аккаунта A в аккаунт B сразу, без блокирующих окон и ожиданий.

Сокращения: RPM = `components/RegistrationPromptModal.tsx` (шторка входа «Всё в безопасности»), ST = `app/(tabs)/settings.tsx`, CO = `components/CleanOnboarding.tsx`, ALF = `components/account/AccountLogoutFlow.tsx`, AD = `app/account_details.tsx`.

## Главное

1. **П3 нарушено системно: прямого входа из A в B нет.**
   - Сейчас путь такой: шторка входа → красная строка «Телефон уже связан с другим аккаунтом» и кнопка «Сменить аккаунт» → переход в Настройки → окно «Сменить аккаунт?» → затемнение «Не закрывай приложение» на 3–45 с → повторный вход.
   - Подробности в разделе A5, пункты 38–51.
2. **Технических текстов в релизных путях входа почти нет.**
   - Все ошибки идут через словари (`app/auth_error_copy.ts`, `getAuthRecoveryErrorMessage`), а коды попадают только в журнал `[AUTH-…]`.
   - Исключения:
     - слово «Облако» в тосте (п. 58);
     - «Google-аккаунт» в окне, которое видят и пользователи Apple (п. 48);
     - английский заголовок «Something went wrong» вместо «Не получилось» (п. 60).
3. **Кнопки Google и Apple отзываются правильно.**
   - Индикатор появляется сразу, двойное нажатие заблокировано, индикатор держится весь вход.
   - Не хватает вибрации, а у смены аккаунта — крутилки (раздел B).
4. **С эталоном auth-states.html расходятся два места** (раздел C):
   - строка «Входим…» появляется только с 8 с вместо 3 с;
   - сбой показан красной строкой под кнопками, а должна быть мягкая карточка над ними.
