## Architecture

Наряд — замороженный объект строк и чисел, производные цвета считаются при загрузке модуля из камня (paletteOf образца). `SpireTowerSvg` рисует из него градиенты в `<Defs>`; у премиальных ещё Pattern, отлив и металл. Без пропа — прежний Оникс (наряд по умолчанию, значения перенесены без изменений). Peek недели Шпиля — по образцу `peekSpireRoom`: чтение из памяти процесса на первом кадре, обновление фоном.
