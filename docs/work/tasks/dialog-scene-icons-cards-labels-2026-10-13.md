# Task packet: значки сценок Диалогов и вёрстка подписей Карточек (очередь координатора 13.10)

Governance-ID: TG-904CE5EABC80
Status: In progress
Owner: сессия «2 · ДИЗАЙН» по очереди координатора 13.10 10:10 (владелец: «Да» значкам сценок)

## Outcome

1. У каждой сценки Диалогов свой значок (кафе — cafe, аэропорт — airplane, ресторан — restaurant, отель — bed, машина/такси — car, поезд — train, работа — briefcase, город — navigate/map, спорт — fitness…) — одна таблица «id сценария → значок» в одном месте, для неизвестного — текущий общий значок. Сторож на таблицу.
2. Кандидаты Макетов на дефект: «В моих наборах» в узкой кнопке переносится на 2 строки и порядок кнопок обратный («Тренировать» справа); подписи «Скажи по-английски / Повтори за диктором» на 2 строки; меню фильтра перекрывает шапку.

## Scope

In scope: таблица значков и её потребитель в списке/каталоге сценок (`components/dialogs/*`), `app/flashcards_*`/`components` кнопки набора и подписи режимов, меню фильтра, сторожа.

Out of scope: сами сценарии и их id (Ядро), тексты, начисления.

## Architecture

Таблица — чистый модуль без React (`id сценария → имя значка Ionicons`) с запасным значком; компонент плитки берёт значок из неё. Остальное — правки вёрстки (перенос / гибкая ширина / порядок), без сжатия шрифта.

## Security and privacy

Данные пользователя не затрагиваются.

## Technical debt

Contain: новые сценарии без записи в таблице получают общий значок, пока их не добавят.

## Verification

`npm run test:one` по сторожам под светофором; кадры Сверки по спискам сценок, кнопкам набора и меню фильтра.

## Rollback

git revert коммитов правок.
