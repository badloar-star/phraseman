# Task packet: полная проверка английских строк интерфейса перед открытием English (слово владельца 17.10)

Governance-ID: TG-200E3ABA8B49
Status: In progress
Owner: сессия «Специалист по переводам» (координатор 17.10; флаг открывает Ядро, local_2047b88f)
Related epic/enabler: R07 — английский как язык интерфейса (`ENGLISH_UI_LOCALE_ENABLED`)

## Outcome

С английским интерфейсом человек не видит:
- пустых строк;
- русского текста вместо английского;
- строк, которые не помещаются на ~360 dp.

Сегодняшние новые строки на английском вычитаны. Отчёт координатору и Ядру: сколько строк проверено, сколько исправлено, какие дыры остались.

## Scope

In scope:
- Словари интерфейса в `app/`, `components/`, `constants/`, `hooks/`, `modules/`:
  - `en` с кириллицей, пустой `en`, `en` совпадает с русским;
  - позиционные `tl()` и 9-элементные массивы, где на месте en стоит русский;
  - слишком длинный `en`.
- Правка только самих английских строк.

Out of scope:
- сам флаг (его включает Ядро);
- учебный контент на языках-источниках;
- русский текст;
- файлы, которые сейчас правят другие сессии (их обходить и сообщать).

## Architecture

No architecture change. Меняются только значения строк. Скрипт проверки лежит в scratchpad, в репозиторий он не входит.

## Security and privacy

Не применимо: меняются только тексты.

- Английских названий системных наборов карточек (`titleEn`) нет в данных — Accept temporarily: это данные Ядра/контента, а не словарь.

## Результат аудита (17.10, переводчик)

**Что проверено.** 5881 строковая запись интерфейса в `app/`, `components/`, `constants/`, `hooks/`, `modules/` (без тестов, dev-витрины и учебного контента):
- словари `{ ru, …, en }`;
- позиционные `tl()`;
- 9-элементные массивы.

| Проверка | Найдено |
|---|---|
| `en` с кириллицей | 0 |
| пустой `en` при непустом ru | 0 |
| `en` — ссылка на русский без своего текста | 0 (3 места `x.en ?? x.ru`, но `en` заполнен во всех данных: ugcCardThemePresets 6/6, vip_survey_content 32/32, DeleteAccountConfirmModal 16/16) |
| слишком длинный `en` (> ×1,35 русского и > 24 знаков) | 96 — просмотрены. Кнопок, которые вылезут за строку на 360 dp, нет: это заголовки и тексты в 2 строки, латиница уже кириллицы |
| сторожа `scan_missing_en_dictionaries` / `scan_direct_lang_index` / `scan_untranslated_ui` / `scan_narrowed_ui_lang` | 0 / OK / 0 моих / 4 как в базе |

**Дыры, найденные сверх сторожей.** Ветки `lang === 'uk' / 'es'`, где во всех остальных случаях стоял русский:

1. `app/celebration_share_messages.ts` — текст «Поделиться» медали, открытого урока, зачёта и экзамена Лингмана. en, pt-BR, vi, id, tr и pl отправляли друзьям РУССКИЙ текст. **Исправлено:** `app/share_messages_more_locales.ts`, по 3 варианта на вид и язык, без названия изучаемого языка и без рода (D188).
2. `app/achievement_share.ts` — текст «Поделиться» достижения, та же дыра. **Исправлено** тем же модулем.

**Не дыры, проверено.**
- `app/home_feature_tips.ts` — подсказки на Главной только ru/uk, но `HOME_FEATURE_TIPS_ON_HOME = false`: карточки не рисуются.
- `app/medal_utils.ts` `getNextMedalHint` — ru/uk/es, но вызовов нет (мёртвый код).
- `app/constants/bot_names.ts` — это имена, а не текст.
- `exam_share.ts`, `lesson_share.ts` — en есть. Сканер ловил массивы вариантов, а не языков.

**Остаётся (не словари — данные и решения Ядра).**
- Названия системных наборов карточек: в данных нет `titleEn`, en видит русское (`packTitleForInterface`).
- Сообщения из админки (`app/app_messages.ts`) приходят на 8 языках без en, en → ru по замыслу. Нужен английский текст в админке или скрытие для en.
- Учебный материал (объяснения, интро уроков) остаётся на языке-источнике: английского источника нет (`app/config.ts`, `app/source_locales.ts`). Английский интерфейс переводит только оболочку. Какой источник показывать человеку с английским интерфейсом — решение Ядра/координатора.
