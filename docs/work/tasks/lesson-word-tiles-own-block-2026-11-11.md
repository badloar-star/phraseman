# Task packet: плитки слов урока перерисовываются сами, а не вместе со всем блоком урока

Governance-ID: TG-2AFE53C8C4CE
Status: In progress
Owner: сессия «аудит микрофризов при сборке фраз» (владелец 11.11.2026)
Related epic/enabler: none

## Outcome

Владелец 11.11: «аудит и поиск причин, почему в приложении есть микрофризы при сборке фраз в уроках». Причина №2 аудита:
каждый тап по плитке слова перерисовывал большой блок урока (около 1400 строк разметки) трижды — сам тап, снятие
блокировки двойного тапа через 90 мс и гашение вспышки через 260 мс. После правки второй и третий раз перерисовываются
только сами плитки (до шести штук). Выигрывает ученик: при быстрой сборке фразы следующий тап не попадает в чужую
перерисовку. Мера успеха — на телефоне пропадает подтормаживание между тапами; поведение плиток не меняется.

## Scope

In scope:
- новый файл `components/LessonWordTiles.tsx` — сетка плиток со своим состоянием вспышки и блокировки двойного тапа;
- `app/lesson1.tsx` — блок плиток заменён на `<LessonWordTiles … />`, состояние вспышки и блокировки оттуда убрано;
- сторожа `tests/lesson_word_press_accuracy_contract.test.ts`, `tests/lesson_word_tile_lifecycle.test.tsx`,
  `tests/lesson1_dev_only_test_ids_2026_11_05.test.ts` — те же проверки, но читают новое место кода
  (решение владельца 11.11: «Да, после коммита» на вопрос о переписывании сторожей под вынос).

Out of scope:
- пересоздание нативной цели нажатия на каждом слове (`pressTargetKey`, причина №3) — это намеренная защита от
  «залипшего» жеста, не трогаю;
- тяжёлая обработка последнего слова фразы (причина №5) — нужен замер на телефоне;
- внешний вид плиток: цвета, отступы, тени, тексты — без изменений.

## Architecture

Было: состояние `flashWord` и `wordDispatchPending` жило в `LessonContent`, поэтому два таймера после тапа
перерисовывали весь `LessonContent`. Стало: оба состояния и оба таймера живут в `LessonWordTiles`; `LessonContent`
передаёт туда готовый список плиток, набор приглушённых «50 на 50» и стабильный обработчик выбора слова.
Инварианты сохранены: ответ применяется в том же кадре, что и вспышка; блокировка 90 мс от двойного тапа; ключ слота
(`presentationSlotKey`) и ключ цели нажатия (`optionKey`) раздельны; тестовые id плиток только в dev.
Убрана недостижимая ветка «вставить слово в поле ввода»: блок плиток рендерится только когда режим ввода с клавиатуры
выключен.

## Security and privacy

Не затрагивается: нет сети, хранения, персональных данных, прав доступа. Тестовые id плиток по-прежнему только в dev —
в релизе ничто не подсказывает верный ответ.
