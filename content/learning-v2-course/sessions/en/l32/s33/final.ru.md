# Урок 32 · Занятие 33 — Находим Бена по подсказкам

**Ситуация.** Вы с Анной ищете Бена в доме и объясняете свои выводы.

**Что вы освоите:** соединять наблюдение и вывод с so, выбирая must, might или can’t по смыслу.
**Новые слова:** —
**Повторяем знакомые слова:** coat, window, shoes, door

## Интро 1

### Признак и уверенный вывод

Вы ищете Бена в доме и видите его пальто, без которого он обычно далеко не уходит: His coat is here, so he must be nearby — его пальто здесь, значит, он, должно быть, поблизости. Соберите His coat is here + so + he must be nearby. До so назовите наблюдение, после so — свой уверенный вывод с must.

**Выберите фразу для этой ситуации.**

- ✅ **His coat is here, so he must be nearby.**
- ❌ His coat is here, so he must is nearby. — *После must нужна форма be.*
- ❌ His coat is here, so he must to be nearby. — *После must не ставим to.*

---

## Интро 2

### Признак и возможное объяснение

Вы замечаете открытое окно в комнате, где ещё не были: The window is open, so the room might be cold — окно открыто, поэтому в комнате может быть холодно. Соберите The window is open + so + the room might be cold. Вы видите окно, но температуру ещё не проверили. Поэтому после so называете только возможность с might.

**Выберите фразу для этой ситуации.**

- ✅ **The window is open, so the room might be cold.**
- ❌ The window is open, so the room might is cold. — *После might здесь нужна форма be.*
- ❌ The window is open, so the room might to be cold. — *После might не ставим to.*

---

## Интро 3

### Признак исключает вариант

Анна предполагает, что Бен наверху, но вы сейчас видите его во дворе: I can see him outside, so he can’t be upstairs — я вижу его снаружи, значит, он не может быть наверху. Соберите I can see him outside + so + he can’t be upstairs. Наблюдение исключает второй вариант, поэтому после so используем can’t.

**Выберите фразу для этой ситуации.**

- ✅ **I can see him outside, so he can't be upstairs.**
- ❌ I can see him outside, so he can't is upstairs. — *После can’t нужна форма be.*
- ❌ I can see him outside, so he can't to be upstairs. — *После can’t не ставим to.*
