## Outcome

«Сообществе», плитка и задание дня spire_steps на Главной, входы по ссылкам и пушам (ведут на Главную с логом),
тур и расход энергии (живут внутри экрана Шпиля — недоступны), упоминание Шпиля в dev-кампании слота сообщений.
Смена языка ru → es посреди недели — Шпиль пропадает сразу; запись в комнате на сервере не трогаем.
Сервер: пуши Шпиля только при pushTokenLang ru/uk, иначе пропуск с логом (выкладка после Codex).

## Scope
In: `app/spire/spire_ui_lang_gate.ts` (новый), `app/spire_tab_flag.ts`, `app/(tabs)/home.tsx` (плитка),

## Architecture
Один синхронный замок: `isSpireTabEnabled()` = флаг вкладки И язык интерфейса ∈ {ru, uk} (peek языка). Все
потребители (вкладка, ворота сети, задания дня) уже ходят через него; Главная получает его в плитке. Подписка на
событие `app_lang_changed` пересчитывает замок без перезапуска. Лог `[SPIRE-GATE]` при каждой смене решения.
