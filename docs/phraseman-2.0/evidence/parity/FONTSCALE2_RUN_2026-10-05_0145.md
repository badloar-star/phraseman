## 🟡 Смена шрифта перезапускает экран + ошибка навигации
После `font_scale 2.0` Activity пересоздалась, приложение вернулось на Главную, в логах **красная** ошибка:
`Looks like you have configured linking in multiple places … Only a single instance of the root component is rendered … android:launchMode=singleTask`.
То есть при смене системного шрифта корень приложения рендерится второй раз. У реального пользователя, меняющего размер шрифта, это сбросит экран и может задвоить навигацию.
