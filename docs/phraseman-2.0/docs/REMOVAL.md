# Карта удаления, сохранения и консервации

| Домен | Целевое действие | Что обязательно защитить |
|---|---|---|
| Спины / рулетка | Удалить UI, выдачу, расход, flows, собственные jobs/ассеты/строки | Старые платежи и pending events разобраны до purge |
| Подарки / welcome / comeback / день / неделя | Удалить механику, хосты и начисления | Auth, useful admin messages, consent, sync остаются |
| Сундуки друзей и лиги | Удалить обе системы | Друзья, полезная активность, независимый недельный топ |
| XP / уровни / множители | Удалить расчёт, запись, UI, награды, server jobs | Учебные оценки, V1 progress, история прав |
| Жемчуг | Отключить новые покупки/выдачу, мигрировать, затем удалить | Ledger 1:10 и права покупателей, callbacks старых покупок |
| Старые аватары / гексаэдры / ауры / студия | Удалить, заменить coin identity | Публичный профиль и purchased rights |
| Декоративные темы / рубашки / цвета колод | Удалить механики выбора/ассеты | Контент, базовые цветовые tokens и доступность |
| Арена | Удалить релизные routes/UI/эксклюзивные зависимости | Генераторы/режимы архивировать отдельно |
| Макс | Консервация вне релиза | Исходники/контракты; никаких активных jobs/секретов |
| Legacy «Планы» | Удалить после идентификации | Не перепутать с учебными планами V1/V2 |
| Идеи | Скрыть и убрать runtime/preload | Уничтожение данных не задано; приватный архив по необходимости |
| Озвучка/пакеты | TTS основа; убрать лишние packs по allowlist | Видео, STT и разрешённый авторский учебный голос |
| Рейтинг | Переделать в топ-3 | Метрика недели не зависит от текущего баланса/XP |

## Чек-лист каждого удаления
Входы и routes; вложенные exclusive screens; shared components; state owners; triggers/listeners/timers; queues/outbox; service clients; server functions/cron; data fields/security rules; notifications и уже запланированные local notifications; products/entitlements; assets/import maps/native deps; analytics/admin controls; tests/docs.

Нужны два доказательства: пользователь больше не видит удалённый сценарий и release/runtime/server больше не обслуживают его зря. Удалённая кнопка при активном cron — незавершённая задача. Отсутствие импорта по grep не гарантирует отсутствия динамического route discovery. Не удалять инфраструктуру целиком, если есть другие потребители.

## Порядок
Инвентаризировать → определить зависимые права/данные → backup/rollback → отключить producers → завершить/мигрировать pending work → убрать UI и consumers → снять deployed jobs → измерить bundle/runtime → удалить данные после согласованного срока совместимости. Составить retired ID map; случаи старого клиента покрыть тестами.

Установить release exclusion для архивов и проверить граф/артефакт сборки. Архив должен содержать README «что сохранено / как восстановить / какие контракты устарели», но не стартовать при импорте. Не сохранять огромные legacy assets «на всякий случай» в runtime-пакете.
