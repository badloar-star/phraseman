# Чек-лист «разделы урока» (Сверка, 06.11)

Governance-ID: TG-C8415E297D29

Копия для `docs/work/release/` (запись туда требует пакета задачи; перенести по решению координатора).

## Что снимать
Для каждого из 5 курсов (en, es, fr, de, it) × уроки 1, 2, 3 × разделы:
1. Список «Обучение» (строка урока: название, замок/«Открыт»).
2. Меню урока (пункты: «Начать», «Слова урока N слов», «Теория»; глаголы/аналог, если есть).
3. Интро урока (карточки до «Начать тренировку»).
4. Теория (заголовок, «Разделы n/m · задания k/N», аккордеон, примеры, задания).
5. Слова/«Vocabulary»: вкладки «Практика» и «Список слов» — ПОСЛЕ загрузки (не скелетон).
6. Первое упражнение (плитки, подсказки) и счётчик монет до/после.
Размеры: 720×1600 (fresh), 412×915, 360×800; тема светлая и тёмная для Главной и Пика.
Имя файла: `pending/<раздел>/<курс>-l<N>-<что>__<тема>-<размер>.png`; каждый кадр — открыть и посмотреть до сдачи.

## Признаки вердикта (✅ / 🔴 / 🟡)
- **Понятно новичку:** заголовок и пояснения короткие, первая фраза из интро реально есть в упражнении; термины не вводятся без пояснения; длинный абзац — не более ~8 строк на экран.
- **Нет чужих языков:** текст интерфейса — на языке интерфейса (en/ru/uk…), учебный материал — на изучаемом; в плитках-отвлекателях нет слов третьего языка (пример-дефект: английские плитки в итальянском задании); фразы про «русские буквы» не показываются в en.
- **Только новые слова:** слова упражнения 1 встречаются в интро/«Слова урока»; пример-дефект: «finestra/aperta» в упражнении, а интро учит «Sono qui».
- **Нет заглушек:** нет «скоро», «готовится», «скрыты», «часть N» вместо названия, «Проверяем доступ…» дольше нескольких секунд, пустых экранов дольше 1–2 с.
- **Скорость:** время открытия меню/интро/слов зафиксировать; >3 с — 🟡, >10 с — 🔴.
- **Монеты:** 1-й проход +3, повтор +2, третий +1; счётчик в шапке меняется сразу после «Check».
