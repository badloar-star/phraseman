# ИИ-генерация: ОФЛАЙН-ПОЛИТИКА (единый контракт для всех разделов)

> Общий обязательный контракт офлайн-поведения для всех шести спек ИИ-генерации.
> Закрывает сквозные находки адверсариального ревью **C3** (честность латентности),
> **C4** (мультиязычный фолбэк) и **C5** (размер резерва). Каждая спека раздела ССЫЛАЕТСЯ
> на этот файл и НЕ переопределяет эти правила — только уточняет числа под свой контент.
>
> Дата: 2026-07-05. Статус: DRAFT (обязателен к соблюдению во всех разделах).

---

## 0. Почему это отдельный документ

Ревью показало: во всех шести спеках офлайн-поведение **декларировано, но не выполнено** одинаково-небрежно — заниженный резерв, тихий фолбэк на русский, ключевание только по `StudyTarget`, несовместимая библиотека персистентности. Чтобы не чинить это шесть раз по-разному, правила вынесены в один канонический контракт.

---

## 1. Главный принцип — три уровня, генерация НИКОГДА не на критическом пути офлайна

```
1. Кеш сессии на устройстве   (что человек уже видел онлайн — лежит локально)
        ↓ пусто
2. Прошитый текстовый резерв   (маленький, гарантия ОДНОЙ полной сессии без повторов,
                                ключ = (StudyTarget × uiLang), цель ×2–3 сессии)
        ↓ нет для этой пары языков
3. Бандл-уроки (1600 фраз + словари) + device-TTS  ← ВСЕГДА работает полностью офлайн
        ↓ не применимо к секции
4. Честный экран «нужен интернет»   (НЕ спиннер, НЕ чужой язык)
```

**Правило одной строкой:** офлайн отдаёт готовый контент мгновенно ИЛИ честно говорит «нужен интернет» — но **НИКОГДА не крутит спиннер в ожидании генерации, которая офлайн не придёт**. Генерация — это про НОВИЗНУ поверх готового, а не про сам факт «есть что показать».

---

## 2. Ключевой инсайт: генеративный урок — САМАЯ устойчивая офлайн-секция

Раз 1600 фраз + словари остаются прошитыми ДАННЫМИ, движок генеративного урока (`app/smart_route/`, `specs/ai-gen-lessons.md`) работает **полностью офлайн** на бандле. Офлайн теряется РОВНО один слой — ИИ-новизна (свежепридуманные примеры). Грамматика, лексика, порядок шагов, объяснения (теория-через-задания) берутся из бандла и собираются локально без единого сетевого запроса.

Формулировка для спеки урока: **урок — не «сетевая фича, которая падает офлайн», а офлайн-фича, которая онлайн становится богаче.** Это гарантия, а не риск.

---

## 3. Голос офлайн — device-TTS ВЕЗДЕ

Приоритет источника аудио:
```
кешированное серверное TTS-аудио (человек уже слышал онлайн — лежит локально)
    ↓ нет
device-TTS (expo-speech, системный голос телефона)  ← мгновенно, офлайн, ноль сети, ноль бандла
    ↓ движка/голоса языка нет на устройстве
показать текст без принудительной тишины (НЕ блокировать поток)
```

- Для en/fr (StudyTarget) системные голоса iOS/Android — отличного качества. Device-TTS достаточно как штатный офлайн-голос.
- **130 МБ пре-рендер аудио — это про КАЧЕСТВО ОНЛАЙНА, а НЕ про выживание офлайна.** Тащить аудио в бандл ради офлайна НЕ надо.
- **НИКОГДА не блокировать поток урока/задания ожиданием сетевого аудио из Storage.**

---

## 4. Мультиязычный фолбэк — жёсткое правило (закрывает C4)

```
язык интерфейса пользователя есть офлайн?  → показываем на нём
    нет → фолбэк на АНГЛИЙСКИЙ (= studyTarget-язык), НЕ на русский
        английского тоже нет для этой секции → честный экран «нужен интернет»
```

- **Русский как фолбэк — ЗАПРЕЩЁН.** Подсунуть турку/индонезийцу/вьетнамцу русский — хуже, чем честно сказать «нужен интернет». Английский оправдан: это язык, который человек и так учит.
- Полностью мультиязычны офлайн (дёшево, текст): **фразы дня** (353 идиомы уже с 8 переводами), **правила квизов** (короткие строки, прошить перевод на 9 языков).
- Честно НЕ могут быть офлайн: свежий ИИ-разбор ошибок «Моей практики» на редком языке; генеративная новизна урока на 9 языках (сам урок офлайн работает — новизна нет).

## 5. Размер резерва — гарантия одной полной сессии без повторов (закрывает C5)

Сессия ≈ 10–15 заданий. Резерв берём **×2–3 от сессии**, чтобы вторая офлайн-сессия не была копией первой.

| Секция | Ключ резерва | Штук на ячейку | Обоснование |
|---|---|---|---|
| Арена/Тесты | (StudyTarget × уровень × тип) | **30** (не 10!) | 10 = ровно 1 матч, 0 запаса = провал C5 |
| Фразы дня | (StudyTarget × язык) | **30** + 353 бандл-идиомы как дно | текст, микроразмер |
| Моя практика | (StudyTarget × топ-8 кластеров ошибок) | **5 на кластер = 40** | глубина буфера 5, не 1.25 |
| Квизы | (StudyTarget × язык × уровень A1–B1) | **30** | C1–C2 честно офлайн-недоступны |
| Генеративный урок | — | **0 спец-резерва** | тянет из 1600 бандл-фраз |

- Прошиваем полностью для en/fr контента + EN как универсальный UI-фолбэк. Полные 9 языков UI — только для дешёвых текстовых секций (фразы дня, правила квизов).
- **Вес: только ТЕКСТ (аудио = device-TTS), порядка 1.5–3 МБ на весь резерв**, JSON gzip в бандле. Это честно выполняет решение владельца «маленький резерв, не 130 МБ».

## 6. Два обязательных кода-фикса в существующем приложении (найдено при аудите)

Без них даже кеш не переживёт закрытие приложения:

1. **Включить офлайн-персистентность Firestore.** Сейчас ВЫКЛЮЧЕНА (аудит: `@react-native-firebase/firestore v21.14.0`, `enablePersistence()` не вызван). Использовать ВСТРОЕННУЮ нативную персистентность `@react-native-firebase/firestore` (`settings({ persistence: true })` / дефолт кеша), **НЕ `nandorojo/expo-firestore-offline-persistence`** (это под web-SDK, несовместимо с нативным RN Firebase проекта — находка C6). Это чинит фолбэк-уровень 1 (кеш сессии) для всех разделов разом.
2. **device-TTS как офлайн-голос.** Фразовое аудио сейчас network-only (`app/phrase_audio_url_map.generated.ts` → Firebase Storage URLs; в бандле только UI-звуки ~312КБ). Добавить `expo-speech`-фолбэк на офлайн-путь озвучки (см. §3).

Переиспользовать уже существующее:
- `app/net_status.ts` (Google 204-проба, 10с офлайн / 60с онлайн) — детектор офлайна, НЕ отправлять сетевой запрос при `offline`, сразу резерв.
- `components/OfflineBanner.tsx` — баннер «📡 Офлайн-режим: базовый набор» (8 переводов уже есть).
- `app/ai_kill_switch_copy.ts` — человеческая копия для честного экрана «нужен интернет».

## 7. Офлайн-UX — честно, но не «сломано»

- **Баннер** (`OfflineBanner.tsx`): «📡 Офлайн-режим: базовый набор», спокойный тон, на языке интерфейса.
- **Внутри секции — микро-метка, не блокировка:** арена «Тренировка (без рейтинга)», урок «Офлайн-урок из твоего набора», практика «Базовый набор». Человек РАБОТАЕТ, а не смотрит в заглушку.
- **Против затхлости повторов:** резерв ×2–3 сессии + ротация порядка (перемешивать выборку) + сперва то, что человек ещё НЕ видел из кеша, потом резерв.
- **Честный экран «нужен интернет»** — только где реально нет контента (C1–C2 квизы, свежий ИИ-анализ). НИКОГДА не пустой batch.

---

## 8. Первая сессия офлайн (худший случай) — гарантия

Новый пользователь, никогда не был онлайн, кеша нет — только бандл:

| Секция | Работает офлайн? |
|---|---|
| Генеративный урок | **ДА** — 1600 бандл-фраз + device-TTS, полноценно (кроме ИИ-новизны) |
| Фразы дня | **ДА** — 353 бандл-идиомы + резерв |
| Арена/Тесты | **ДА (тренировка)** — прошитый резерв 30/уровень; рейтинговый матч нет |
| Моя практика | **ДА на базовый набор** — резерв 40 упр.; свежего анализа нет (честно) |
| Квизы | **ДА A1–B1** из резерва; C1–C2 — честно «нужен интернет» |

**Гарантия: каждая секция либо работает на бандле, либо ОДИН раз честно говорит «нужен интернет» — ни одна не показывает спиннер и не дед-эндит в середине сессии.**

---

## 9. 8 ЖЁСТКИХ ПРАВИЛ (обязательны во всех спеках)

1. **Резерв ключуется парой (StudyTarget, uiLang)** — не только StudyTarget. (C4)
2. **Фолбэк языка: uiLang → EN → честный «нужен интернет». Русский как фолбэк ЗАПРЕЩЁН.** (C4)
3. **Мин. размер резерва = гарантия одной полной сессии без повторов, цель ×2–3** (арена 30/уровень×тип, практика 5/кластер, квизы 30/уровень A1–B1). (C5)
4. **Kill-switch и офлайн-путь возвращают РЕЗЕРВ или честную заглушку, НИКОГДА пустой batch.** (C3)
5. **Генерация не на критическом пути офлайна:** при `net_status = offline` сетевой запрос не отправляется — сразу резерв. Никаких спиннеров ожидания. (C3)
6. **Голос офлайн = device-TTS, поток не блокируется ожиданием сетевого аудио.**
7. **Генеративный урок объявляется офлайн-полным на бандле** (1600 фраз + словари); офлайн теряется только ИИ-новизна — это ГАРАНТИЯ в спеке урока, не риск.
8. **Проверка глубины резерва на язык** в `reserve_manifest` (админка): каждая пара (section, StudyTarget, uiLang) имеет замеренную глубину «≥ одна сессия», иначе секция для этой пары честно офлайн-недоступна.

Плюс два кода-фикса из §6 (включить нативную персистентность Firestore; device-TTS-фолбэк) — обязательны как предусловие Фазы 0.

---

### Итог простыми словами

- Без интернета приложение сразу показывает готовое или честно говорит «нужен интернет» — но никогда не крутит бесконечную загрузку.
- Урок — самая надёжная часть офлайна: 1600 фраз зашиты внутрь, голос читает встроенный голос телефона бесплатно.
- Тренировки, квизы, фразы, практика работают на небольшом встроенном наборе — минимум на одно полное занятие; рейтинги ждут сети.
- Язык без сети падает на английский, НИКОГДА на русский; где и его нет — честно «нужен интернет».
- 130 МБ звука нужны только для качества онлайн, в приложение ради офлайна их тащить не надо.
- Два технических предусловия: включить сохранение кеша (сейчас выключено) и добавить встроенный голос телефона для офлайна.
