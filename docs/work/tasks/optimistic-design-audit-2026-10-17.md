# Task packet: [OPTIMISTIC-DESIGN] аудит Optimistic UI экранов Дизайна

Governance-ID: TG-EC0D542AD8E2
Status: In progress
Owner: сессия «2 · ДИЗАЙН» (поручение координатора 17.10)
Related epic/enabler: INBOX §139 (аудит Optimistic UI), ворота PM-220

## Outcome

По коду проверены действия на экранах Дизайна: вступление урока, плеер урока (ответ, «дальше», сердца), 4 плитки Главной, «Продолжить», итог урока.
Для каждого: мгновенный отклик, защита от двойного тапа, нет полноэкранного спиннера там, где хватает локального состояния.
Дешёвые дыры закрыты тут же, дорогие — списком в отчёте координатору. Успех: ни один тап не пропускает страницу, не вызывает завершение/открытие стора дважды.

## Scope

In scope: `app/learning_v2_session_intro.tsx` (замок «Дальше»), `app/lesson_complete.tsx` (окно оценки: «Да»), чтение без правок: `app/learning_v2_direct_session_player_v1.tsx`, `components/home/v2/HomeV2FeatureTiles.tsx`, `HomeV2ContinueCard.tsx`, `app/learning_v2_home_continue_route.ts`.

Out of scope: переписывание плеера, сервер, Firestore, внешний вид экранов.

## Architecture

No architecture change: локальные замки-ref внутри компонентов; существующая цепочка onComplete/openStoreReviewPage не меняется. Инвариант: действие выполняется один раз на тап-серию; замок снимается при смене страницы (вступление) или по таймеру 1,5 с (последняя страница, если родитель не ушёл с экрана).

## Security and privacy

Данные пользователя не затрагиваются, новых полей, сервисов и разрешений нет. Журнал `[OPTIMISTIC-DESIGN]` пишет только номер страницы и флаг.

## Technical debt

Contain: гонка «два тапа в один кадр» для `evaluate` плеера (ответ → сердца) не воспроизводится на дискретных событиях, ref-замок не добавляется — записано в отчёте; выход — если Сверка увидит двойное списание сердца.

## Verification

Точечные тесты: сторож вступления и итога урока (`npm run test:one -- tests/<файл>`), синтаксис через babel.parseSync, затем журнал `[OPTIMISTIC-DESIGN]` на эмуляторе (Сверка).

## Rollback

Откат коммита; замки локальные, данные не пишут.
