## Architecture

**Настоящая структура экрана, вычитанная из `app/flashcards/FlashcardsHubScreen.tsx`
(строки 460–600 — разметка, конец файла — `StyleSheet`):**

Порядок сверху вниз:
1. Шапка `styles.header`: `minHeight:60, paddingH:16, paddingTop:8, paddingBottom:8`,
   `flexDirection:row, justifyContent:space-between`;
   - кнопка назад: 48×48, `borderRadius:15`, фон `t.bgSurface`, иконка
     `arrow-back` 23px цвет `t.textPrimary`;
   - заголовок «Карточки»: `max(27, round(f.h1*1.2))` = **27px**,
     `lineHeight max(32, round(22*1.35))` = **32**, вес **900**, `letterSpacing:0.1`;
   - кнопка «+»: 48×48, `borderRadius:15`, фон `t.bgSurface`, иконка `add` 25px.
2. `ScrollView`, `contentContainer: paddingHorizontal:16, paddingBottom:32`.
3. `SavedTopCommunityPacks` — витрина, ПЕРВАЯ в скролле.
4. Заголовок «Ваши карточки» `styles.sectionTitle`: `marginTop:6, marginBottom:12`,
   `f.h2` = **18px**, `lineHeight round(18*1.25)` = **23**, вес **900**.
5. `styles.libraryList` с `gap:9`, три `LibraryRow`:
   `minHeight:72, borderRadius:18, paddingH:12, paddingV:11, gap:11`, фон `t.bgSurface`;
   - иконка в квадрате `44×44, borderRadius:14`, фон `${t.accent}18`, Ionicon 21px `t.accent`;
   - название: `f.bodyLg` = **16px**, `lineHeight round(16*1.2)` = **19**, вес **900**, `t.textPrimary`;
   - подпись: `marginTop:3`, `f.sub` = **14px**, `lineHeight round(14*1.25)` = **18**,
     вес **700**, цвет **`t.textSecond`** (зелёный #58CC89);
   - шеврон `chevron-forward` 20px `t.textMuted`.
   Тексты: «Сохранённые / Личная коллекция», «Мои наборы / Созданные и добавленные»,
   «Наборы пользователей / Открыть каталог».
6. Кнопка `styles.trainButton`: `minHeight:54, marginTop:16, borderRadius:17,
   paddingH:16, paddingV:12`, фон `t.accent`; подпись «Тренироваться с карточками»
   `f.bodyLg`=**16px**, вес **900**, цвет `t.correctText` (#042010);
   под подписью `SpeakingQuotaDots` (`marginTop:6`) — точки остатка тренировок,
   потраченные `${t.correctText}3D`, оставшиеся `t.correctText`.

**Важно про подписи под названиями.** Правило владельца запрещает
«подпись-расшифровку мелкими буквами под названием». Здесь подписи ЕСТЬ
(«Личная коллекция» и т.д.), но это существующий, уже одобренный владельцем
экран, и они 14px весом 700 — не «мелкие буквы». Макет ПОВТОРЯЕТ экран, а не
проектирует новый, поэтому воспроизводит их как есть. Новая четвёртая строка
получает подпись того же рода ради единообразия ряда.

**Витрина** (`SavedTopCommunityPacks.tsx`), для 390pt:
`tileW = floor((390−32−20)/3)` = **112**, квадрат, `TILE_RADIUS:18`,
фон `t.bgSurface`; обложка-веер `floor(112*0.92)` = **103px**;
`labelSize = max(11, min(f.caption=13, floor(112*0.13)=14))` = **13**;
название `labelSize+1`=**14**/`+4`=**17**, вес 800, по центру;
автор `max(10, labelSize−1)`=**12**, вес 700, `t.textSecond`, по центру;
соцбар `marginTop:5`, иконки 12, цифры 10 вес 700 `t.textSecond`;
бейдж числа карт `right:5,bottom:5, r:9, padH:6 padV:1`, фон `t.bgCard`,
шрифт `max(10, round(13*0.82))`=**11** вес 900;
галочка владения `right:5,top:5, r:999, padding:3`, фон `${t.accent}26`, 11px.
Заголовок витрины `f.h2`=18 вес 900 `marginBottom:12`; контейнер
`marginTop:10, marginBottom:18`; ряд горизонтальный, `gap:10`.

**Решения владельца этого хода (ответы на вопросы):**
1. Четвёртая строка «Из видео» — **сразу после «Сохранённые»**, то есть вторая

2. Стиль — **ноль отличий** от остального приложения.
3. Подача макета — **по одному экрану крупно**.
4. Полный список — сетка 3 в ряд, как каталог сообщества (следующий ход).

Единственное новое на ЭТОМ экране: одна `LibraryRow` с иконкой и значок ▶ на
плитках витрины у наборов из видео.

Архитектурное изменение: нет — статический HTML вне дерева приложения.
