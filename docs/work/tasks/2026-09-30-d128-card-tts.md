## Outcome

Карточки звучат голосом OpenAI на языке набора (en/es/fr/de/it), а не чужим голосом
устройства. Одобренный пользовательский набор озвучивается в фоне сразу после
одобрения. Официальные наборы — отдельным скриптом (dry-run по умолчанию, оценка цены).
Если клипа нет и на устройстве нет голоса ровно этого языка — спокойное «Голос недоступен».

## Architecture

Клип адресуется детерминированно: ключ = sha256(стиль + язык + голос + модель + текст),
путь `card-audio/v1/<lang>/<key>.mp3`, download-токен выводится из пути. Сервер пишет файл,
клиент вычисляет ту же ссылку сам — 0 чтений Firestore на карточку. Одобрение пишет
`card_tts_jobs/{packId}` (status queued) → триггер `cardTtsPackWorker` → проверка наличия в
Storage (глобальный дедуп) → суточный бюджет символов → OpenAI (≤4 параллельно, тайм-аут) →
Storage → `card_tts_billing` → сводка `cardTts` в документе набора.
Инварианты: наборы `none` и неопубликованные не озвучиваются; одобрение не ждёт OpenAI.

## Security and privacy

В OpenAI уходит только текст карточки и язык (инструкция). Без uid/почты/профиля.
Приватные наборы не отправляются (план требует listingStatus 'published').
Ключ OpenAI — `defineSecret('OPENAI_API_KEY')`. Коллекции очереди/бюджета/биллинга —
deny для клиента. Requeue — только custom claim admin. App Check не включается (пломба).
Политика: абзац D128 уже в `docs/phraseman-2.0/legal/LEGAL_2_0_DRAFT.md` — внести до релиза.
