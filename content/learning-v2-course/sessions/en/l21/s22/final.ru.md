# Английский · Урок 21 · Занятие 22 — Успеть на встречу

**Ситуация.** Вы готовитесь к встрече и планируете время на дорогу.

**Что вы освоите:** verb + to-infinitive
**Новые слова:** run late, lose track of time, set an alarm, allow time

## Интро 1

### Не опаздывать

Run late — отставать от графика, опаздывать. У вас назначена встреча, и вы не хотите задержаться. Часто можно услышать I am running late — «Я опаздываю»; здесь выражаем нежелание: I do not want to run late. После want и need здесь используем to + начальную форму. I do not want to… выражает нежелание, I need to… — необходимость. В сочетаниях to run и to set не удваиваем последнюю букву: удвоение есть только в running и setting.

**Выберите фразу для этой ситуации.**

- ✅ **I do not want to run late.**
- ❌ I do not want to running late. — *Здесь после to нужна начальная форма, без -ing.*
- ❌ I do not want to runs late. — *После to не добавляем -s к глаголу.*

---

## Интро 2

### Следить за временем

Lose track of time — потерять счёт времени, увлечься и не заметить, сколько времени прошло. Вы не хотите забыть о встрече за чтением. Set an alarm — поставить будильник, выбрать время сигнала. После want и need здесь используем to + начальную форму. I do not want to… выражает нежелание, I need to… — необходимость. В сочетаниях to run и to set не удваиваем последнюю букву: удвоение есть только в running и setting.

**Выберите фразу для этой ситуации.**

- ✅ **I do not want to lose track of time.**
- ❌ I do not want to losing track of time. — *Здесь после to нужна начальная форма, без -ing.*
- ❌ I do not want to loses track of time. — *После to не добавляем -s к глаголу.*

---

## Интро 3

### Учесть дорогу

Allow time — предусмотреть время на что-то. Вы планируете встречу и учитываете, сколько займёт дорога. Allow time for the journey означает оставить в плане достаточно времени на путь. После want и need здесь используем to + начальную форму. I do not want to… выражает нежелание, I need to… — необходимость. В сочетаниях to run и to set не удваиваем последнюю букву: удвоение есть только в running и setting.

**Выберите фразу для этой ситуации.**

- ✅ **I need to allow time for the journey.**
- ❌ I need to allowing time for the journey. — *Здесь после to нужна начальная форма, без -ing.*
- ❌ I need to allows time for the journey. — *После to не добавляем -s к глаголу.*
