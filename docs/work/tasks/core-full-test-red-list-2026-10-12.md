## Scope
In: чистый срез HEAD вне репозитория (`git archive` → C:/Temp/claude/jest_head, соединения на node_modules), скрипт прогона
частями в scratchpad, логи частей, документ статуса. Out: любые правки кода и тестов, рабочая копия других сессий.

## Architecture
Срез HEAD — чтобы чужие незакоммиченные правки рабочей копии не давали ложных красных. Список файлов — по правилам раннера
из package.json (testMatch/ignore). Части по ~80 файлов, один процесс, `--runInBand` (= maxWorkers 1), лимит кучи как у
`test:one`. Перед каждой частью: слот светофора, свободная память ≥ 3 ГБ, нет процесса проверки типов; после — слот отдаётся
(другие сессии не ждут часами). Отдельно — тесты `node --test` (*.test.mjs) тоже частями. Красные: файл, имя теста, первая
строка причины; зона — по путям (learning-v2/gustav/factory_native — Codex); «предсуществующий» — по истории файла теста и
предмета проверки (последний коммит, кто).

## Security and privacy
Срез копирует только отслеживаемые файлы; секреты (functions/.env*) в срез не копируются и не читаются.

## Technical debt
Срез без игнорируемых git файлов: тест, зависящий от сгенерированного неотслеживаемого файла, покажет «нет модуля» — такие
помечаются отдельно («зависит от неотслеживаемого файла»), а не как дефект кода. Прогон долгий (часы) — идёт в фоне.

## Verification
Сумма зелёных+красных = числу файлов списка; каждый красный подтверждён логом части; срез после прогона удаляется
(соединения снимаются до удаления папки).

## Rollback
Документ — `git revert`; срез и логи — удалить папки во временном каталоге.
