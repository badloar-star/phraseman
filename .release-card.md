# Release card

## Type

feature

## Goal

Ship Phraseman 1.6.15 (build 121) with the production Daily Journey: one automatic daily reward presentation after onboarding, durable daily grant/inbox behavior, animated delivery into the home statistics gift entry, and unread-gift presentation in the inventory. Learning V2 remains unavailable in the store build and its unfinished workspace changes are excluded from this release snapshot.

## Allowed changes

- Daily Journey production host, reward schedule, activation/inbox/inventory integration, motion, copy, sound trigger, onboarding gate, statistics unread state, developer preview, focused contracts, and the wired gift asset.
- Minimal production-closure fixes for imports and type contracts already referenced by the current canonical home/quest code.
- Exact metadata bump in `app.json`: app/runtime 1.6.14 to 1.6.15 and Android/iOS build 120 to 121.
- EAS production build for iOS with automatic App Store Connect submission, and EAS production build for Android without submission.

## Forbidden changes

- No Learning V2 authoring, unfinished V2 workspace files, V2 release enablement, or V2 route exposure.
- No Android automatic submission or Google Play rollout; Android upload remains manual.
- No Firebase Functions, Firestore rules/indexes, Hosting, admin, OTA deployment, App Check policy, purchase/access contract, branch, or worktree changes.
- No unrelated deletion, rollback, or restoration of retired functionality.

## Risk level

high — this is a two-platform native store build. Daily rewards touch durable local grants and account-scoped inventory; release metadata and iOS submission are externally visible operations.

## Manual tests

- Finish onboarding and confirm no Daily Journey modal appears before the home screen becomes eligible.
- Launch on two consecutive local days: confirm one grant per day, the current reward reveal, flight into the gift entry, unread indicator, and no duplicate grant after relaunch.
- Use Skip and confirm it advances directly to the reward delivery without a second action screen.
- Open Gifts and confirm every unseen gift pulses once with the unread tint; navigate back and confirm the gift shortcut clears and the statistics card returns to its normal size.
- Upgrade from 1.6.14 (120) on both platforms and confirm the active account, Plus/lifetime access, pearl/rune/spin/energy state, and existing gifts remain intact.
- Confirm App Store Connect receives iOS build 121 automatically; download the Android build artifact and upload it manually only after device smoke.
