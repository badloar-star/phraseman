# Испанский · Урок 5 · Занятие 28 — У подруг есть сумка

**Ситуация.** Рассказываете о вещах двух подруг перед поездкой.
**Что вы освоите:** использовать ellas tienen для группы женщин.
**Новые слова:** —
**Повторяем знакомые слова:** ellas, tener, bolsa, libro, llave.

## Интро 1

### Сумка подруг

Две подруги собирают вещи. Скажите о них `Ellas tienen una bolsa` — «У них есть сумка». Соберите `Ellas` + `tienen` + `una bolsa`. Ellas обозначает группу женщин. Форма tienen такая же, как с ellos: людей несколько. Выбираем ellas по людям, о которых говорим, а не по роду слова bolsa.

**Скажите о подругах «У них есть сумка». Начните с Ellas tienen, используйте bolsa.**

- ✅ **Ellas tienen una bolsa.** — *Ellas + tienen + una bolsa.*
- ❌ Ellas tiene una bolsa. — *Подруг несколько: tienen.*
- ❌ Ella tienen una bolsa. — *О нескольких подругах нужно ellas.*

## Интро 2

### Книга у подруг

Подруги берут книгу в дорогу. Сообщите `Ellas tienen un libro` — «У них есть книга». Соберите `Ellas` + `tienen` + `un libro`. Хотя libro мужского рода, начало остаётся ellas tienen: говорим о женщинах. Род книги влияет только на артикль перед libro — un.

**Скажите о подругах «У них есть книга». Начните с Ellas tienen.**

- ✅ **Ellas tienen un libro.** — *Ellas — подруги; un — по роду libro.*
- ❌ Ellas tienen una libro. — *Libro мужского рода: un.*
- ❌ Ellas tiene un libro. — *С ellas нужна форма tienen.*

## Интро 3

### Ключ у подруг

Сосед спрашивает, смогут ли подруги открыть дверь. Объясните `Ellas tienen una llave` — «У них есть ключ». Соберите `Ellas` + `tienen` + `una llave`. Начало ellas tienen сообщает о нескольких женщинах. Ключ один, поэтому una llave; число людей не требует нескольких ключей.

**Скажите о подругах «У них есть ключ». Начните с Ellas tienen.**

- ✅ **Ellas tienen una llave.** — *Ellas + tienen + una llave.*
- ❌ Ellas tenemos una llave. — *Tenemos — «у нас»; о них нужно tienen.*
- ❌ Ellas tienen un llave. — *Llave женского рода: una.*
