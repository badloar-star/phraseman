## Что одинаково у всех лиг

`components/spire/SpireTowerSvg.tsx` + `components/spire/spire_tower_model.ts` без изменений: 15 этажей (Страж каждые 5), ширина `196 − (f−1)·5`, этаж 46 / Страж 60, кладка 11 px с изгибом, окна по окружности, карнизы-кольца, зубцы и машикули Стражей, барабан + конус с черепицей + навершие; состояния «пройден / мой / впереди / вершина недели», маркер справа, соперники слева.

## Проп `skin` (новое в SpireTowerSvg)

| поле | что делает | как рисовать в react-native-svg |
|---|---|---|
| `stone` | средний тон камня | `cyl` = darken(stone, .70 / .38 / 0 / .24 / .55 / .78)·k по стопам 0 / .16 / .36 / .55 / .8 / 1 (k = .75 для светлого камня — яркость > 140, иначе 1); `cylG` (Страж) = darken(.64 / .28)·k · lighten(.06) · darken(.14 / .50 / .74)·k; `cylCorn` = darken(.60) · mix(lighten(stone, .2), metal, .25) · darken(.08 / .70); `cone` = darken(.72 / .10 / .40 / .80); окно «пройден» = mix(darken(stone, .35), lit, .14), «впереди» = darken(stone, .86), подоконник = mix(darken(stone, .1), metal, .35) |
| `spec` 0..1 | сила зеркального блика | градиент `gloss` (x1=0 → x2=1), ОДИН `<Rect>` поверх кладки на этаж + на барабан + `<Polygon>` на конус: #000 .45 @0 · #000 .12 @.10 · #FFF 0 @.20 · #FFF spec·.12 @.27 · #FFF spec·.48 @.31 · #FFF spec·.10 @.35 · #FFF 0 @.44 · #000 0 @.62 · #000 .20 @.84 · edge 0 @.93 · edge .12+spec·.12 @.955 · edge 0 @.975 · #000 .5 @1 |
| `edge` | цвет тонкой подсветки края | см. `gloss` |
| `tex` | материал поверх кладки | ОДИН `<Pattern patternUnits="userSpaceOnUse">` на лигу в `<Defs>` + один `<Rect fill="url(#tex)">` на этаж и `<Polygon>` на конус (текстура непрерывна через этажи). Содержимое паттернов — в `skins.js` образца (`texPattern`), 3–7 фигур на паттерн, только заливки/обводки с opacity |
| `metal` | металл ободков и навершия | градиент `metal` (darken .45 · lighten .45 @.3 · metal @.55 · darken .55); `rim: 'full'` — ОДИН `<Path>` на все карнизы (полоса 1.4 px под верхом карниза) и ОДИН `<Path>` на зубцы каждого Стража (шапки 1.8 px), кольцо конуса и полоса цоколя; `rim: 'ring'` — только кольцо конуса и цоколь |
| `finial` | навершие вместо белого шара | `ball` металлический шар · `gem` гранёный камень на подставке · `crystal` кристалл · `cabochon` кабошон с полосами · `cluster` друза из 3 кристаллов · `orb` опаловая сфера (радиальный градиент) · `crown` корона с камнем · `shard` осколок стекла с огнём (радиальный градиент, без фильтра) · `brilliant` бриллиант в короне; 2–9 узлов |
| `gem` | цвет камня навершия | — |
| `pennant` | вымпел (у части лиг) | флагшток удлиняется на 22 px, вымпел 18 × 11 + блик |
| `lit`, `sky`, `glow` | свет окон и навершия, небо, радиус свечения | радиус: обычный / ×2.6 на вершине недели |

**Перформанс:** эталон ≈ 400 узлов; облачение добавляет +43…+53 (15 текстур + 15 отливов + 3 на барабан/конус + 2–5 ободков + 2–9 навершие + 0–2 вымпел). Фильтров на кладке нет; blur остаётся только там, где он уже есть у эталона (свечение окон моего этажа, облака).
