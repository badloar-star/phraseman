# Английский · Урок 8 · Занятие 32 — Коротко и понятно

**Ситуация.** Подготовить именную карточку для встречи, защитить меню плёнкой и заклеить посылку для возврата.

**Что вы освоите:** повторить короткие указания и освоить четыре новых предмета
**Новые слова:** name tag, laminator, packing tape, cable tie

---

## Интро 1

### Имя для новых знакомых

На встрече книжного клуба люди видят друг друга впервые. У входа раздают карточки с именами. Name tag — «именная карточка, бейдж с именем». `Attach the name tag` — «Прикрепи именную карточку». Вы предлагаете другу прикрепить его карточку к одежде.

**Скажите другу прикрепить именную карточку.**

- ✅ **Attach the name tag.**
- ❌ Attaches the name tag. — *Для указания нужна начальная форма без s/es.*
- ❌ To attach the name tag. — *Для указания не нужно to.*

---

## Интро 2

### Меню, которое можно протирать

Вы помогаете в кафе: бумажное меню нужно покрыть защитной плёнкой. Для этого приготовлен ламинатор. Laminator — «ламинатор». Его вилка ещё не подключена. `Plug it in` — «Включи его в розетку». It стоит между Plug и in; здесь it заменяет laminator.

**Покажите на ламинатор и скажите «Включи его в розетку».**

- ✅ **Plug it in.**
- ❌ Plug in it. — *С it нужен порядок Plug it in.*
- ❌ Plugs it in. — *Для указания нужно Plug, без s.*

---

## Интро 3

### Коробка для возврата покупки

Вы возвращаете покупку по почте. Коробка закрыта, но её ещё нужно заклеить. Packing tape — «упаковочный скотч». `Use the packing tape` — «Используй упаковочный скотч». Вы показываете другу на приготовленный рулон.

**Скажите другу использовать упаковочный скотч.**

- ✅ **Use the packing tape.**
- ❌ Uses the packing tape. — *Для указания нужна начальная форма без s/es.*
- ❌ To use the packing tape. — *Для указания не нужно to.*
