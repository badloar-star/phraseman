Кнопка буста активируется только после второй честной блокировки — по закону 05 бесплатный путь предлагается первым минимум дважды, прежде чем появляется платный. «Полный флоу покупки» прогоняет подтверждение → processing 600 мс → успех: 4 контурные boost-звезды летят по дуге в полосу прогресса, полоса дозаполняется, замок расщёлкивается (поворот дужки + scale-поп), золотая волна.
