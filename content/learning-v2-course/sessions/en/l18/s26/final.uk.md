# Англійська · Урок 18 · Заняття 26 — Підібрати деталі для дому

**Ситуація.** Ви перевіряєте, чи підходить річ для конкретного завдання.

**Що ви опануєте:** too + adjective; adjective + enough
**Нові слова:** door lock, window lock, window handle, spare part

## Інтро 1

### Пояснити, чому замок не підходить

Ви принесли новий дверний замок, але його корпус не вміщується в підготовлений отвір. This door lock is too large — цей дверний замок завеликий. Після This door lock is поставте too large. Too стоїть перед large і показує, що розмір заважає встановленню. Ви говорите не просто про великий замок, а про перевищення відповідного розміру.

**Виберіть фразу для цієї ситуації.**

- ✅ **This door lock is too large.**
- ❌ This door lock is large too. — *Правильний порядок: too large.*
- ❌ This door lock is large enough. — *За ситуацією потрібне too large: умова або заважає, або виконана.*

---

## Інтро 2

### Передати оцінку майстра

Майстер перевірив віконний замок і сказав, що його міцності вистачає для передбаченого завдання. Ви переказуєте цю оцінку: This window lock is strong enough — цей віконний замок достатньо міцний. Спочатку This window lock is, потім strong enough. Enough після strong показує, що потрібного ступеня міцності досягнуто.

**Виберіть фразу для цієї ситуації.**

- ✅ **This window lock is strong enough.**
- ❌ This window lock is enough strong. — *Правильний порядок: strong enough.*
- ❌ This window lock is too strong. — *За ситуацією потрібне strong enough: умова або заважає, або виконана.*

---

## Інтро 3

### Вибрати зручну ручку

Ви беретеся за віконну ручку: долоня зручно вміщується, довжини ручки вистачає. This window handle is long enough — ця віконна ручка достатньо довга. Назвіть ручку: This window handle, потім поставте is. Наприкінці long enough: спочатку прикметник long, після нього enough. Так ви повідомляєте, що ручка підходить за довжиною.

**Виберіть фразу для цієї ситуації.**

- ✅ **This window handle is long enough.**
- ❌ This window handle is enough long. — *Правильний порядок: long enough.*
- ❌ This window handle is too long. — *За ситуацією потрібне long enough: умова або заважає, або виконана.*
