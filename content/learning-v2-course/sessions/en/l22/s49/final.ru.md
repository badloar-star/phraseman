# Английский · Урок 22 · Занятие 49 — Подготовиться к поездке

**Ситуация.** Вы объясняете приготовления к путешествию.

**Что вы освоите:** сказать, зачем вы что-то делаете: I went out to buy bread
**Новые слова:** book a flight, pack my bag, check my passport, print my ticket

## Интро 1

### Сайт для бронирования

Вы объясняете другу, зачем открыли сайт авиакомпании. I use this website to book a flight — я пользуюсь этим сайтом, чтобы забронировать перелёт. Сначала называем действие: I use this website. Затем добавляем цель: to book a flight. Здесь to означает «чтобы», а book стоит в начальной форме. Так объясняем цель использования сайта.

**Выберите фразу для этой ситуации.**

- ✅ **I use this website to book a flight.**
- ❌ I use this website for book a flight. — *Цель выражается через to + начальную форму глагола.*
- ❌ I use this website of book a flight. — *Цель выражается через to + начальную форму глагола.*

---

## Интро 2

### Список для сборов

Перед поездкой вы составляете список вещей, чтобы собрать сумку. I make a list to pack my bag — я составляю список, чтобы собрать сумку. Собираем: I make a list + to + pack my bag. Первая часть сообщает, что вы делаете; to pack my bag объясняет зачем. После to нужна начальная форма pack. My bag указывает на вашу сумку.

**Выберите фразу для этой ситуации.**

- ✅ **I make a list to pack my bag.**
- ❌ I make a list for pack my bag. — *Цель выражается через to + начальную форму глагола.*
- ❌ I make a list of pack my bag. — *Цель выражается через to + начальную форму глагола.*

---

## Интро 3

### Распечатать билет

Вы хотите взять бумажный билет и пользуетесь принтером. I use the printer to print my ticket — я пользуюсь принтером, чтобы распечатать билет. Собираем: I use the printer + to + print my ticket. To print my ticket называет цель, поэтому to переводится как «чтобы». После него используем print без окончаний. Вся фраза объясняет, зачем нужен принтер.

**Выберите фразу для этой ситуации.**

- ✅ **I use the printer to print my ticket.**
- ❌ I use the printer for print my ticket. — *Цель выражается через to + начальную форму глагола.*
- ❌ I use the printer of print my ticket. — *Цель выражается через to + начальную форму глагола.*
