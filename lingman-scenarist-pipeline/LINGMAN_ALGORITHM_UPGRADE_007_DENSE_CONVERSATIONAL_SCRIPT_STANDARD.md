# Lingman Algorithm Upgrade 007 - Dense Conversational Script Standard

Дата:

```text
2026-05-20
```

## Причина

```text
Пользователь подтвердил, что базовый сценарий получился хорошим, но потребовал более жирный поток текста:
- больше подробных объяснений;
- больше прямых примеров;
- меньше коротких сухих строк;
- меньше публичного перечисления источников;
- убрать палевный AI-юмор;
- сделать текст более разговорным, плотным и живым.
```

## Новое Правило

```text
Каждый сценарий должен звучать как насыщенный разговорный монолог, а не как учебная карточка.

Для каждой ключевой механики сценарист обязан раскрыть:
1. русскую ловушку;
2. английскую логику;
3. несколько прямых примеров;
4. объяснение, почему пример работает;
5. связку к следующему механизму.
```

## Источники

```text
Источники нужны для факт-чека, но не обязаны звучать в публичном сценарии.
Не называть малоизвестные или скучные источники внутри сценария, если это не добавляет зрителю интереса, доверия или интриги.
Факт-чек хранить в пакете выпуска.
```

## Юмор

```text
Юмор должен быть спокойным, острым и наблюдательным.
Запрещены случайные AI-метафоры, очевидные мемные вставки и шутки, которые выглядят как попытка "пошутить".
Если шутка не помогает объяснению или характеру ведущего, ее нужно убрать.
```

## Стиль Итогового Текста

```text
Текст должен быть жирнее:
- больше смыслового потока;
- длиннее объяснения;
- больше естественных речевых переходов;
- меньше рубленых мини-блоков;
- больше разжевывания без ощущения учебника;
- примеры должны объясняться, а не просто перечисляться.
```
