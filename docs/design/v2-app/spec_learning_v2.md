# Опись Learning V2 (LV2) — всё видимое в разделе, по коду на 25.09.2026

Источники: `app/learning-v2/**`, `components/learning-v2/**` (PulseCourse, PulseMapSessionRow, OutcomeSheet,
FounderPassModal, DictionaryOverlay, NewWordEncounterOverlay, WordPocketOverlay, horizons/*), `components/LearningV2*.tsx`,
`app/learning_v2_direct_session_player_v1.tsx`, `app/learning_v2_session_intro.tsx`, `modules/learning-v2/modes/*`,
`app/learning_v2_session_copy.ts`, `app/learning_v2_checkpoint_copy.ts`, `app/learning_v2_new_word_encounter_copy.ts`,
`app/session_attempts/session_attempts_copy.ts`, `components/NoEnergyModal.tsx`, `docs/phraseman-2.0/docs/COURSES.md`, `ENERGY.md`.

Структура курса (`course_topology_v1.ts`): 32 урока × 56 занятий = 1792; урок = 7 глав по 8 занятий; занятия 8/16/24/32/40/48 —
проверка главы (`chapter_checkpoint`), 56 — итоговый экзамен урока (`final_exam`). Интро сессии — 3 страницы с вопросом на каждой.
Практика — 14–22 задания. Попыток на задание — 3 (сердца). Энергия: Free 5, −1 при старте занятия, +1 за 10 минут, Plus не тратит.

Анимации — живые, с кнопкой «Повторить анимацию» под телефоном.

## 5. Практика — режимы (`modules/learning-v2/modes/*`, шапка/подвал из `learning_v2_direct_session_player_v1.tsx`)

Общая рамка каждого задания: ✕ · полоса прогресса · «3 / 16» · сердца (попытки) · энергия · монеты за занятие; подвал
«Назад · Слова (счётчик) · Дальше»; флажок репорта. Подсказки в релизном плеере нет как кнопки — после ВТОРОЙ ошибки приходит разбор
(`secondErrorExplanation`) и автосборка правильного ответа; это и есть «подсказка» (состояние 4 у каждого режима).

| № | Режим (`family`) | Состояния | Телефоны |
|---|---|---|---|
| 5.1 | Собери фразу (`phrase_builder`) — любимая механика: подпись задания, перевод крупно + звук, строка ответа, банк чипов, «Проверить» | вопрос · собрано (Проверить активна) · верно (волна по чипам) · неверно 1-й раз (чип подсвечен, вернётся) · неверно 2-й раз — разбор + правильный порядок | pb-1..pb-5 |
| 5.2 | Слушай и выбирай (`listen_choose`): кнопка play с кольцом, подпись «Нажми, чтобы послушать / Звучит… / Прослушать ещё раз», варианты строками | до прослушивания · звучит · верно (фраза раскрыта) · неверно + разбор | lc-1..lc-4 |
| 5.3 | Диктант-конструктор (`listen_build_dictation`): «Послушай и собери фразу», play с кольцом, текст скрыт, банк чипов | вопрос · верно (текст раскрыт) · неверно + разбор | ld-1..ld-3 |
