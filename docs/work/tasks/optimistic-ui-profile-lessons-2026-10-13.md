## Architecture

Откат лайка при сбое возвращает значения, снятые перед оптимистичным шагом, а не читает сервер: чтения лайков при сбое сети сами возвращали «нет лайка / 0» и затирали правду. Память отправленных заявок — модульный Set процесса (не durable, не показ «потом»), как у синтетических заявок. `deleteFriend` теперь бросает на ранних выходах, чтобы сработал существующий откат у всех трёх вызывающих.
