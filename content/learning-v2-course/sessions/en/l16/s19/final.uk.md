# Англійська · Урок 16 · Заняття 19 — Виконати обіцяні справи

**Ситуація.** Ви обіцяєте допомогти близькій людині або виконати спільну справу.

**Що ви опануєте:** I'll + base verb: promise
**Нові слова:** hand in, hand out, send back, set aside

## Інтро 1

### Обіцянка близькій людині

I'll — скорочення I will. Обіцянку теж можна передати через I'll + дієслово в початковій формі. Тут ви не просто припускаєте майбутнє: ви запевняєте людину, що зробите обіцяне. Значення обіцянки зрозуміле із ситуації. Після I'll не потрібне to. hand in — здати документ або роботу тому, хто їх збирає. Ви заповнили бланк для шкільної поїздки. Учитель нагадує про нього, і ви обіцяєте здати його завтра. I'll hand in the form tomorrow. — Я здам бланк завтра.

**Виберіть фразу для цієї ситуації.**

- ✅ **I'll hand in the form tomorrow.**
- ❌ I'll to hand in the form tomorrow. — *Після I'll не потрібне to.*
- ❌ I hand in the form tomorrow. — *Без will фраза не передає цю обіцянку на майбутнє. Тут потрібне I'll.*

## Інтро 2

### Запевняємо в підтримці

hand out — роздати по одному кільком людям. Друг готує свято й переживає, що гості не отримають запрошення. Ви обіцяєте їх роздати. I'll hand out the invitations. — Я роздам запрошення.

**Виберіть фразу для цієї ситуації.**

- ✅ **I'll hand out the invitations.**
- ❌ I'll to hand out the invitations. — *Після I'll не потрібне to.*
- ❌ I hand out the invitations. — *Без will фраза не передає цю обіцянку на майбутнє. Тут потрібне I'll.*

## Інтро 3

### Дотримуємо слова

send back — надіслати назад. set aside — відкласти й зберегти для певної мети. Ви з другом збираєтеся в поїздку. Він непокоїться про витрати, і ви обіцяєте відкласти свою частину грошей. I'll set aside some money for the trip. — Я відкладу трохи грошей на поїздку.

**Виберіть фразу для цієї ситуації.**

- ✅ **I'll set aside some money for the trip.**
- ❌ I'll to set aside some money for the trip. — *Після I'll не потрібне to.*
- ❌ I set aside some money for the trip. — *Без will фраза не передає цю обіцянку на майбутнє. Тут потрібне I'll.*
