## Outcome

Тап по «Выйти и войти под другим аккаунтом» на экране «Аккаунт» сразу меняет саму строку: вместо заголовка —
«Сохраняем прогресс…», вместо шеврона — маленький индикатор. Окна со спиннером поверх экрана нет. Второе нажатие и
уход с экрана, пока идёт выход, заблокированы (с причиной в логе). Окно появляется только при отказе («Не удалось
выйти»), как раньше.

## Scope

- components/account/AccountLogoutFlow.tsx: нативное окно видно только в стадиях confirm и failed; карточка
  «Выходим из аккаунта» со спиннером убрана. Логика выхода (две попытки, тексты отказа, повтор) не меняется.
- app/account_details.tsx: строка выхода в стадии wiping — заголовок «Сохраняем прогресс…» (9 языков), индикатор

  «Привязать аккаунт», «Удалить аккаунт» во время выхода не срабатывают — лог `[ACC-MUT] ui:account_action_ignored`.
- Поведение «выход без облака» НЕ меняю: сейчас (решение владельца 31.08 «выход мгновенный», вариант Б 12.10) после
  3 с ожидания пишется аварийная копия на телефоне и выход идёт дальше. Слова координатора «выходить без сохранения
  нельзя / Не удалось сохранить, попробуй ещё раз» противоречат этому решению — вопрос отправлен координатору.

## Architecture

Состояние берётся из уже существующей стадии logoutStage === 'wiping'; блокировка — ref + ранний выход с логом.
Нативный present/dismiss: confirm→wiping теперь закрывает окно (без нового present), idle→failed открывает его —
present-during-dismiss не возникает.
