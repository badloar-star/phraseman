## Общие правила на эти дни

- **Выкладка функций — только из среза HEAD** (`/c/Temp/phraseman_deploy/<хэш>`), не из рабочей папки: в ней чужая незакоммиченная
  правка с ошибкой типов. Готовая команда — `DEPLOY_MORNING_2026-10-13.md`, раздел «Команда».
- Выкладку, запись в рабочую базу, публикацию сайта и отправку в магазины выполняет **только владелец**. Сессии готовят и проверяют.
- Коммиты кода (`app/ components/ modules/`) — в окна :00–:05 и :30–:35 каждого часа (робот иначе стоит на пересборке).
  Документы — когда угодно.
- Тяжёлое (проверка типов, тесты, сборка) — через светофор: `bash .claude/semaphore/slot.sh acquire "…"`.

## 4. Что нельзя делать без владельца

- Любая выкладка функций, правил, индексов, админки и сайта; любая запись в рабочую базу (вопрос 2).
- Отправка в магазины, ввод ключей, изменение переменных EAS.
- Деньги и доступ: число бесплатных уроков (вопрос 11), апселл (вопрос 14), обход гейта сверки (`PARITY_GATE_WAIVER`).
- Включение английского интерфейса (вопрос 4) и тема по умолчанию (вопрос 3).
- Правка хуков `~/.claude/hooks/*` (вопрос 5).
- Функции «дня выхода» (§1.5) — до публикации 2.0 в магазинах.

## 6. Совместимость патчей (проверено 13.10 ~04:20, HEAD 39814d0ee)

Проверка — во временном индексе (`read-tree HEAD` → `git apply --cached` по очереди), рабочее дерево и общий индекс не тронуты.
Порядок — как в дне сборки: политика (13) → апселл (14) → тема (3) → «Что нового» (15) → английский интерфейс (4).

| Патч | Цепочка с темой L1 | Цепочка с темой L05 |
|---|---|---|
| `PRIVACY_R1_PATCH_2026-10-13.diff` (вопрос 13) | ✅ | ✅ |
| `patches/LESSON_SOFT_UPSELL_A_2026-10-13.diff` (вопрос 14, вариант А) | ✅ | ✅ |
| `patches/DEFAULT_THEME_AURORA_L1_2026-10-13.diff` / `…_L05_…` (вопрос 3, один из двух) | ✅ | ✅ |
| `patches/RELEASE_NOTES_V2_GATE_2026-10-13.diff` (вопрос 15) | ✅ | ✅ |
| `handoff/enable_english_ui.patch` (вопрос 4) | ✅ после перегенерации | ✅ после перегенерации |

- Конфликтов между патчами нет: они трогают разные файлы.
- **Английский интерфейс:** старый патч не ложился на `app/config.ts`. Перегенерирован от HEAD с тем же содержимым — флаг `true` и та же
  пометка «зачем». Новый ложится и на чистый HEAD, и в конце обеих цепочек.
- Темы L1 и L05 — взаимоисключающие: применять одну.
- **В день сборки повторить эту проверку перед применением** — HEAD сдвигается, патч может устареть снова. Устаревший патч
  перегенерировать тем же содержимым: правка во временном индексе, `git diff --cached HEAD`.
