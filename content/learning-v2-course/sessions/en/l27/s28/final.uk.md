# Урок 27 · Заняття 28 — Прогулянка у зручному темпі

**Ситуація.** Ви обираєте темп і маршрут, просите зробити фотографію й домовляєтеся про наступну прогулянку.

**Що ви опануєте:** сказати, чого вам хочеться інакше, і про те, що було б, якби…
**Нові слова:** brisk, leisurely, scenic, shoreline

## Інтро 1

### Хотілося б гуляти довше

Ви гуляєте біля води, але незабаром потрібно повертатися. Скажіть другові: I wish we had more time — шкода, що в нас немає більше часу. Had після wish виражає бажання щодо теперішнього: зараз часу мало. Складаємо речення: I wish + we + had + more time — бажання, хто, had, чого хочеться більше. Це не розповідь про те, скільки часу було вчора.

**Виберіть фразу для цієї ситуації.**

- ✅ **I wish we had more time.**
- ❌ I wish we have more time. — *У цьому побажанні про теперішнє потрібна форма had.*
- ❌ I wish we having more time. — *Тут ставимо had.*

---

## Інтро 2

### Якби стежка була коротшою

Ви бачите гарну стежку, але вона надто довга для сьогоднішньої прогулянки. Поясніть: We would take that path if it were shorter — ми б пішли тією стежкою, якби вона була коротшою. Would take — уявний вибір, if it were shorter — умова. Складаємо речення: We + would take + that path + if it were shorter — хто, що зробив би, який шлях вибрав би, за якої умови. Після would використовуємо take без to.

**Виберіть фразу для цієї ситуації.**

- ✅ **We would take that path if it were shorter.**
- ❌ We would took that path if it were shorter. — *Після would потрібна форма take.*
- ❌ We would to take that path if it were shorter. — *Після would не ставимо to.*

---

## Інтро 3

### Коли зробили фотографію

Друг запитує, коли ви зробили фотографію берега. Це було хвилину тому. Дайте відповідь: I took it a minute ago — я зробив її хвилину тому. It замінює the photo; took — минула форма take, не taked. A minute ago називає завершений момент, тому have не потрібне. Складаємо речення: I + took + it + a minute ago — хто, дія в минулому, що зробив, коли.

**Виберіть фразу для цієї ситуації.**

- ✅ **I took it a minute ago.**
- ❌ I have taken it a minute ago. — *Із a minute ago тут took без have.*
- ❌ I taked it a minute ago. — *Минула форма take — took.*
