# Task packet: «натискаю на класичні уроки — уроків немає» — логи [CLASSIC-LESSONS] и [FEATURE-INTRO]

Governance-ID: TG-882EB9B867C8
Status: In progress
Owner: Learning V2 session; координатор 28.10 (жалобы #3 uk 2.0.3, #1 ru 2.0.3, #11 ru 2.0.0)

## Outcome

Причину по логу с телефона можно назвать одним поиском:
- [CLASSIC-LESSONS] — при каждом показе классического списка: язык, цель изучения, страница, вход (tab/push), сколько уроков должно быть,
  сколько строк собрано, сколько осталось после поиска, сколько уроков открыто, есть ли Plus, сколько пройдено;
- [FEATURE-INTRO] — каждый немой выход из нажатия на кнопку с вводным окном (кнопка «Классический курс» неактивна, проверка уже идёт,
  окно уже открыто, экран ушёл, пока ждали ответа хранилища) и что в итоге: показ окна или переход сразу.

## Scope

app/(tabs)/lessons.tsx (один эффект с логом), hooks/use_requested_feature_intro.ts (логи на ранних выходах). Поведение не меняется.

## Architecture

Список строится из lessonNamesForStudyTarget → listData (пусто только на странице v2) → поиск. Кнопка «Классический курс» зовёт
useRequestedFeatureIntro.request: у него три немых return; если вход не активен (выбрано занятие, вкладка не на переднем плане),
нажатие ничего не делает.

## Security and privacy

В логе нет текста поиска (только длина), нет uid и имён.

## Technical debt

Временная трассировка [CLASSIC-LESSONS] убирается после диагноза; логи на ранних выходах [FEATURE-INTRO] остаются навсегда.

## Verification

Точечные тесты списка уроков и вводных окон; разбор синтаксиса; коммит в окно.

## Rollback
