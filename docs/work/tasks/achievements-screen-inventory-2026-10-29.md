## 2. Экран сверху вниз: элементы, состояния, тексты

### 2.1 Шапка
- Кнопка «назад»: общий `ScreenBackButton` 44 dp (закон «назад везде в одном месте»), a11y «Назад».
- Заголовок «Достижения» — f.h2, 700, одна строка; подпись-расшифровка под ним убрана по правилу владельца.
- DEV-кнопка (только `ENABLE_DEV_TOOLS`): «DEV» / «DEV: all» — показать весь каталог (закрытые и в процессе); в магазинной сборке нет.
- Пилюля счёта `ResultsGlassCountPill` справа: «N/M» = полученные / видимые активные (сейчас например «12/32»); a11y «N/M наград», при
  N = M — «N наград» (склонение через `pluralWord`: награда / награды / наград).

## 3. План: как +90 встают без потери существующего

### 3.1 Что меняется само, без правок интерфейса
- Пилюля шапки: знаменатель 32 → 122 (например «12/122»).
- Витрина: новые полученные награды встают в ту же карусель; порядок прежний; при > 9 полученных индикатор переходит на «i / N» —
  уже предусмотрено.
- Док: «Особые» вырастают с 15 до 105 наград; опция появляется, как и сейчас, когда в категории есть полученные.
- Досье: для наград активности прогресс считается (`activityAchievementProgress`), для вершин — статуэтка, метка и чип «Статуэтка
  улучшена»; «Поделиться» работает как сейчас.
- История (`StorySlides`): событие вершины различает «открыта» и «улучшена».
- Все существующие 32 награды, их арт, порядок и тексты не меняются.

### 3.2 Что код НЕ покрывает — решения для макета (цвета только из токенов темы, без плиток-цифр, без служебного текста в телефоне)
а) Арт 78 наград активности. Сейчас — зелёный щит «Особые» с ракетой у всех 78 (одинаковые). Минимум без нового арта: пять строк в
   `ACHIEVEMENT_ICON` по сериям (видео → videocam, ежедневные → leaf, репорты → eye, старый курс → book, уроки V2 → library) — щит в
   цвете категории, значок серии; максимум — статуэтки, как у 64 старых (Storage). В макете показываю оба («как в коде» / «значок серии»).
б) «Особые» = 105 наград одной опцией дока. Предложение: группировать док по `foundationGroup` без смены категорий — «Активность» (14),
   «Уроки V2» (64), «Вершины Пика» (12), «Особые» (15 прежних); плитки дока — те же токены accentBg / accentText; значки videocam /
   library / podium / rocket. Цвета щитов не меняются (#10B981 у special), у вершин щит не нужен — статуэтки.
в) 64 награды «урок N закрыт» — однородный ряд из 64 плиток и витрины, и дока. Альтернатива (меняет каталог — решение владельца и
   Дизайна): одна награда на язык с прогрессом «уроков закрыто 12 из 32», в досье — список закрытых уроков. В макете показываю ряд по
   каталогу и вариант «одна на язык» как сравнение.
г) Закрытые и «в процессе» не видны (только полученные). Для 90 новых, особенно вершин Пика, тизер «что впереди» был бы полезен —
   решение владельца; в макете состояния «закрыта / в процессе» показаны как вид DEV с честной подписью.
д) Вершины Пика: порядок лиг Гранит → … → Алмаз; у Алмаза улучшения нет (`upgradable: false`); при улучшении — та же статуэтка с меткой
   sparkles и чип «Статуэтка улучшена» в досье; отдельного окна-поздравления нет (история через StorySlides).

### 3.3 Что покажет макет (поверх кадров Сверки `now_achievements_{top,scroll,card}_graphite_dark.png`)
- Витрина: 12 статуэток (чипы выбора камня) и 8 типовых наград активности; состояния закрыта / в процессе / получена / улучшена.
- Док: капсула «Особые» и вариант с группами из §3.2 б.
- Досье: четыре состояния на кадре открытой карточки.
- Галерея всех 90 на странице (вне телефона), группами, с условиями.
- Чипы страницы: награда, высота/вариант значка, «как в коде» / «значок серии». Внутри телефонов — ни служебных слов, ни плиток с цифрами.

### 3.4 Риски и замечания
- Описание = условие у 78 наград активности (`descRu: condition`) — в досье текст повторяется дважды; Дизайну дать отдельные описания.

- Бандл: 12 статуэток ≈ 1,1 МБ уже в бандле (кластер); арт активности, если делать, — в Storage по образцу 64 старых.
- Секретных наград среди новых нет (`secret` не задан) — условия видны сразу.
