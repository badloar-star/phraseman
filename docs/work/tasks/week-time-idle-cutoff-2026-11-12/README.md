# «Твоя неделя 37 ч 45 мин» при серии 0 — разбор и готовая правка (ждёт решения владельца)

Обход экранов 12.11, экран «Серия и результаты» (`docs/phraseman-2.0/evidence/screen-walk/w1_streak_stats.png`).

## Факты (хранилище эмулятора emulator-5554, только чтение)

- `streak_count = 0`, `last_active_date = 2026-10-25` — практики с 25.10 не было.
- `phraseman_foreground_daily_ms_v1`: пн 09.11 — 2 ч 09 мин, **вт 10.11 — 23 ч 17 мин**, ср 11.11 — 9 ч 12 мин, чт 12.11 — 5 ч 59 мин (на момент чтения).
- Источник цифры блока — время, пока приложение открыто на экране (`app/foreground_usage_ms.ts`), по дням. Касания не учитываются:
  эмулятор, оставленный с открытым приложением, набирает почти сутки.
- Ошибки сложения нет: дни складываются верно, слияние с облаком берёт максимум за день, а не сумму (`app/restore_numeric_max_merge.ts`).
- Макет (`docs/design/v2-app/results.html`, экран серии): «Твоя неделя 42 мин», «Короткие занятия без больших пауз» — это время практики.

## Что решает владелец

Считать ли время без касаний. Готовая правка (не применена):

- `idle_cutoff.patch` — после 3 минут без касаний время не засчитывается; касание в корне приложения (`onTouchStart`)
  отмечает активность; простой не «догоняется» после возвращения.
- `foreground_idle_week_time_2026_11_12.test.ts.txt` — тест (час без касаний → 3 мин; 20 мин с касаниями → 20; простой 30 + работа 10 → 13).
  Положить в `tests/` без `.txt`. **Jest на нём ещё не прогонялся** — прогон остановлен, когда пришло решение подождать владельца.

Что заденет правка: достижение «50 часов в деле» и подсказки по времени будут копиться медленнее (честнее);
касания внутри нативных модальных окон до корня не доходят — там через 3 минуты счёт встанет.
Уже накопленные значения не меняются.

## Мелочь рядом (не чинилось)

Счётчик раскладывает время по UTC-дням, а экран серии ищет дни по местному календарю — у поясов UTC+N
время после полуночи попадает во «вчера». На 37 ч не влияет.
