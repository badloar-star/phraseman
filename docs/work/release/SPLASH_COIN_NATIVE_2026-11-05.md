# Заставка «Г · Монета»: нативная часть (проверяется при следующей сборке), 05.11

Слово владельца: «ДЕЛАЙ Г монета! Можно сделать так, чтобы она сразу была при запуске, без статичной картинки вначале?». Макет — `docs/work/release/mockups/splash_variants_2026-11-05.html`, вариант «Г · Монета» (1,8 с).

## Что изменено
- **Нативная заставка без картинки.** `app.json` → плагин `expo-splash-screen`: `image` и `dark.image` теперь `./assets/images/splash-empty.png` — полностью прозрачный лист 288×288 (401 Б) вместо знака `splash-icon.png`; `backgroundColor` и `dark.backgroundColor` — `#101214`.
  - Android 12+: плагин кладёт картинку в `windowSplashScreenAnimatedIcon` (drawable `splashscreen_logo`) — теперь это прозрачный лист, иконка приложения не показывается; фон окна заставки — `#101214`.
  - Android до 12 и iOS (LaunchScreen/storyboard): тёмный фон `#101214` и прозрачная картинка — виден только тёмный экран.
  - Плагин сам поддерживает отсутствие картинки, но прозрачный лист надёжнее: на Android 12 без картинки система подставила бы иконку приложения.
- **Экранная заставка** (`app/_layout.tsx` → `StartupSplashHold`, `components/startup/SplashCoin.tsx`): бесконечный пульс заменён конечной анимацией «Монета» на нативном драйвере (transform/opacity, UI-поток), старт с первого кадра JS; в финале стоит знак. Заставка держится до готовности Главной, но не короче 1,8 с; Reduce Motion — растворение 280 мс. Новая картинка одна: `assets/images/splash-coin.webp` (352×352, 20 КБ); знак и надпись — прежние `splash-glyph.webp`, `splash-wordmark.webp`.
- Журнал `[SPLASH-COIN]`: `start`, `end` (`ms`, `finished`, `reducedMotion`), `early hide ждёт конец анимации`, `min-hold done`.

## Что проверить при следующей сборке (нативное, из JS не проверить)
1. Холодный старт Android 12+ и ниже, iOS: до первого кадра JS — только тёмный экран, ни знака, ни иконки приложения, ни белой вспышки.
2. Переход нативная заставка → монета без мигания (фон одинаковый `#101214`).
3. Время `[THEME-BOOT] SplashScreen.hideAsync()` до/после (`waitedMs`, `jsSplashPaintedAt`): новой работы до первого кадра нет (одна локальная картинка 20 КБ, без сети и диска), ожидается без изменений.
4. Анимация идёт ровно один раз, без перезапуска при смене экрана заставка → онбординг (`isSplashCoinFinished`).

## Откат
`app.json`: вернуть `splash-icon.png` в `image`/`dark.image`; `StartupSplashHold` — `git revert` коммита с этой заставкой.
