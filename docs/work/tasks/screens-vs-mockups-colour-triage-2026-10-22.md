# Разбор 44 экранов «расходится с макетом» по цвету/тону/контрасту (4 · ТЕМЫ)

Governance-ID: TG-648D40914A81

## Outcome
Координатор: из 44 строк раздела 2 карты `screens-vs-mockups-2026-10-22.md` (08ae62098) взять те, где расхождение — цвет, тон, градиент или контраст (не вёрстка), и починить по закону «только оттенки текущей темы». Итог разбора: список «что взял / что отдал» ниже. Правок кода по итогам нет — цветовые расхождения оказались либо следствием другой темы на кадре образца, либо устаревшими, либо уже закрыты токенами; настоящие остатки отданы владельцам экранов с конкретной причиной.

## Scope
In scope: чтение кода и макетов по 44 строкам, этот отчёт.
Out of scope: вёрстка, структура, логика и флаги (Дизайн, Ядро), съёмка кадров (Сверка).

## Architecture
Критерий «цветовое»: в строке карты речь о цвете/оттенке/градиенте/контрасте. Для каждого такого случая проверено, откуда код берёт цвет: из токенов текущей темы (`liquidGlassTokens`, `accentGraphic`, `opaqueCard`…) или из литерала. Если цвет берётся из токена темы, а макет снят в другой теме, это не дефект кода — нужен кадр образца и приложения в ОДНОЙ теме.

## Security and privacy
Данных не касается.

## Technical debt
Для пяти строк нужен парный кадр «образец | приложение» в одной теме (Сверка), иначе спор про цвет нерешаем.

## Verification
Чтение кода: `components/mistakes-panel/PanelKit.tsx` (кольцо `g.accentGraphic`), `app/flashcards/VideoPackRow.tsx` и каталог наборов (кнопка «Добавить» — общий компонент, токены темы), `components/coin_rank_moments/CoinRankEnoughDialog.tsx` (плашка `useSpirePalette().card`), `components/energy/*` (обводки пилюли нет), `TodayRings.tsx` (кольца токенами темы).

## Rollback
Не применимо (документ).

## Что взял

Ничего не правил: в коде цвет у всех цветовых строк уже идёт из токенов темы.
