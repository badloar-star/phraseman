## Правила владельца (действуют всегда)

- Работать без остановки, пока есть хоть одна задача; простой сессий запрещён. Сессия закончила — сразу следующая задача.
- Вопросы владельцу — пачкой, кнопками, простым языком. Не ответил 5 минут — вопрос отложить, работу продолжать.
- Ночью и когда владелец спит — вопросов нет; решения принимает координатор и записывает «почему».
- Всё, что координатор говорит «надо сделать» — делает сам, а не перекладывает на владельца.
- Сборку и отправку в сторы — только после слова владельца «собирай» и доклада с доказательствами. Исключение — 90% недельного лимита: финальные проверки, лёгкие правки, релизные версии; к 95% обе версии готовы без багов.
- Визуальную правку в сборку — только после показа финального макета и явного «да». Ответ на кнопку варианта ≠ одобрение.
- Одобренный макет переносится «до бита»; принимается только по кадру с устройства рядом с макетом.
- Макеты — на реальных экранах приложения, интерактивной ссылкой, со всеми кнопками и состояниями из кода; минимум кнопок и мелких текстов, премиально, «как Сцена».
- При редизайне ничего не убирать без прямого слова владельца (лайки, комментарии, кнопки).
- Цвета — только оттенки текущей темы. Верх экрана цельный, без полосы под часами. Кнопка «назад» везде в одном месте.
- Таббар — только значки, без подписей. Вкладку Plus не добавлять.
- Тексты — живые, дружеские, с цифрами, без пафосных метафор; каждая строка полезна человеку.
- Заглушек «скоро / пока готовится» нет. В курсе не на английском — ни слова английского.
- Прогресс пользователей не теряется никогда — ни при замене курсов, ни при переносе.
- Телефон начисляет монеты и награды сразу; сервер только хранит для синхронизации.
- Платную озвучку не генерить; пока только системный голос телефона.
- Firebase — минимум затрат; Test Lab — только бесплатная квота.
- Всё в одной ветке, всё попадает в приложение; без отдельных веток и worktree.
- Каждая правка владельца закрепляется тестом-сторожем; ослабить его может только владелец.
- При ошибке — сначала подробные логи, потом починка; немых catch нет.
- Картинки для сторов не делать и не спрашивать.
- Поддержка: «как купить Plus / из России» — всегда бот @PhrasemanPremiumBot.
- Темы с условиями открытия сохраняют свои условия.
- Названия эпизодов — не больше 2 слов.
- Learning V2 заморожен на ~полгода: новые не видят, ошибки не в Telegram.
- Codex отключён — его работу не ждать, его незакоммиченное доводят сессии областей.
- Один эмулятор за раз, следить за нагрузкой на компьютер; больше ничего не генерировать картинками без нужды.
- Fable — только для макетов анимаций; дальше дешёвая модель.
