# Башни лиг Шпиля — параметры для переноса в код (Макеты, 13.10.2026)

Образец: `docs/design/v2-app/spire-leagues.html` (интерактивный; таблица и JSON внизу страницы генерируются из тех же параметров). Скрипт-источник параметров — блок `LEAGUES` в этом файле.

## Модель

Одна модель этажей на все лиги — `components/spire/spire_tower_model.ts`: 15 этажей, Страж каждые 5 (этажи 5, 10, 15), вершина — 15-й; состояния этажа `mine / passed / ahead`; маркер игрока справа от своего этажа, соперники слева. Лига (`spireTiers.<lang>`, 0 = Гранит … 11 = Алмаз, `modules/spire/tier_names.ts`) выбирает **параметры башни** — палитру и набор форм. Геометрия (высота этажа, сужение, ширина основания, высота навершия) — функция номера лиги.

Чёрная башня-эталон (текущая `SpireTowerSvg.tsx`) закреплена за лигой **Оникс** (6, чёрный камень); её параметры = текущие константы кода (ряд кладки 11, швы .34, окна-арки ×3, карниз-кольцо, зубцы-мерлоны, конус с навершием).

## Параметры лиги

- **geometry**: `w0` — ширина нижнего этажа, `taper` — потеря ширины на этаж, `floorH` / `guardH` — высота обычного этажа / Стража, `crownH` — высота навершия (всё в единицах viewBox 390 × H).
- **forms.body** — фактура корпуса: `ashlar` кладка рядами, `columns` шестигранные колонны, `marble` жилки + пилястры, `jade` лакированные пояса, `facet` грани-призмы (число граней `facets`), `bands` слоистые полосы агата, `veins` глянец + лавовые жилы, `iris` радужные эллипсы опала.
- **forms.window**: `slit` бойница, `arch` арка, `round`/`moon` круглое, `lancet` стрельчатое, `diamond` ромб, `star` звёздочка; `windowsPerRow` (2–4, на этажах ≥ 12 на одно меньше), `windowRows` (1–2).
- **forms.cornice** — карниз этажа: `ring`, `gold`, `eave` (загнутый карниз пагоды), `flare` (зубцы-кристаллы), `terrace`, `scallop` (жемчужины).
- **forms.guardTop** — парапет Стража: `merlon` зубцы, `column` обломки колонн, `balustrade` балюстрада (+ пинакли у топаза), `pagoda` карниз с фонариками, `crystals` кристаллы, `spikes` шипы, `pearls` жемчуг.
- **forms.crown** — навершие вершины: `cone`, `columns`, `dome`, `pagoda`, `crystals`, `geode`, `pearl`, `goldspire`, `shards`, `diamond`.
- **forms.plinth** — основание: `stone`, `steps`, `water`, `crystal`, `lava`, `mirror`. **numerals**: `arabic` / `roman` (римские — Мрамор, Аметист, Топаз).
- **atmosphere** — набор слоёв позади башни: `stars`, `cloud`, `warmcloud`, `dust`, `mist`, `rain`, `fireflies`, `glitter`, `frost`, `sparks`, `nebula`, `aurora`, `bubbles`, `rays`, `goldust`, `sunset`, `embers`, `smoke`, `beams`.
- **palette**: `sky[3]` небо, `star`, `stone[6]` цилиндрическая светотень (0, .16, .36, .55, .8, 1), `corn[4]` карниз, `roof[4]` кровля/шпиль, `win{lit,past,dark,glow}` цвета окон (мой этаж / пройден / впереди / свечение), `accent` (маркер, выделение, свечение навершия), `halo` свет мой-этажа, `num/numDim` номера, `gold` у мрамора/топаза, `vein` у обсидиана.

Состояния этажей: **мой** — окна светятся (`win.lit` + размытое свечение `win.glow`), эллипс-гало, номер цветом `accent`, маркер игрока; **пройден** — окна `win.past`; **впереди** — окна `win.dark` и вуаль цвета неба (прозрачность .26); **вершина недели** — все окна светятся, гало на 15-м этаже, подпись «ВЕРШИНА НЕДЕЛИ» цветом `accent`, навершие светится сильнее.
