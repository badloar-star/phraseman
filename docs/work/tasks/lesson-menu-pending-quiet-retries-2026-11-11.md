# Task packet: меню платного урока само перепроверяет подписку после потолка

## Outcome

Решение владельца 11.11 на вопрос «Добавить в меню платного урока тихие повторные проверки
подписки?» — дословно: «Да, добавь».

После 12-секундного потолка меню видно, запуск закрыт. Раньше повторная проверка шла только при
смене общего статуса подписки или при возврате на экран — человек мог смотреть на неактивную
кнопку, пока не выйдет и не зайдёт. Теперь после потолка меню само тихо перепроверяет доступ
через 1, 3 и 8 секунд (`LOAD_GATE_BACKOFF_MS`); как только доступ решён, повторы прекращаются.

Мера успеха: строки `[LESSON-MENU] lock:pending_retry` в журнале, затем обычная `lock:resolved`.

## Scope

In scope: `app/lesson_menu.tsx` — состояние «потолок сработал», счётчик повторов, один эффект-таймер.

Out of scope: правила платного доступа, сама проверка подписки (`premium_guard`), вид меню с
неактивным запуском (нужен макет).

## Architecture

No architecture change. Повтор — вызов существующего `loadLockState()`; после потолка он идёт
«тихо» (ключ подтверждён), поэтому скелет не возвращается. Поколение проверки (`lockGenerationRef`)
уже защищает от наложения результатов.

## Security and privacy

Доступ не расширяется: повторы только перезапускают ту же проверку; запуск остаётся закрытым,
пока она не решит. Не более трёх повторов на вход — нагрузка ограничена. Новых данных нет.

## Technical debt

- Accept temporarily: после трёх неудачных повторов меню остаётся с закрытым запуском до возврата
  на экран или смены статуса подписки. Владелец: владелец продукта; выход — макет состояния
  «проверяем подписку» с ручным повтором.
