# PM-216 — ленивая загрузка контента на старте ([CONTENT-LAZY], 2026-10-03)

Коротко: подробности и числа — в INBOX_COORDINATOR_FROM_CORE.md, раздел «PM-216 продолжение: ленивая загрузка контента».

- Причина: `asyncRoutes` выключен (sync-режим expo-router, babel-preset-expo/expo-router-plugin.js: `asyncRoutes ? 'lazy' : 'sync'`), `inlineRequires: false` (ExpoMetroConfig.js) — при запуске поднимаются все 145 маршрутов вместе со статическим замыканием импортов: 1353 файла / 21,26 МБ исходников.
- Сделано: `app/content_lazy.ts` (`lazyContent`, строка `[CONTENT-LAZY] loaded key=… ms=… sinceJsStartMs=…`), четыре модуля данных перестали исполняться при импорте: озвучка фабрики V2 (568 КБ), индекс озвучки уроков (515 КБ), карта фраз → mp3 (310 КБ, строилась при импорте), глоссы словаря (160 КБ). Замыкание: 21 258 475 → 19 723 741 Б (−7,2 %).
- Охрана: `tests/content_lazy_startup.test.ts` (10 проверок).
- Не сделано: манифест V2 1,25 МБ (`factory_native_course_v1.ts` с чужими несохранёнными правками), сценарии ИИ-диалога, тексты пейвола; рычаг уровня сборки (`asyncRoutes` / `inlineRequires`) — отдельное решение с замером на слабом профиле.
