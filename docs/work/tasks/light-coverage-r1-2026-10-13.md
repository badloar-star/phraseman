# Покрытие светлого оформления кадрами R1 и минимальный набор для «Аврора ＠1 светлая»

Governance-ID: TG-F088B6AF335A
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора к вопросу 3 владельца)

## Outcome
Файл `docs/phraseman-2.0/LIGHT_COVERAGE_R1_2026-10-13.md`: список экранов R1, снятых в светлом оформлении (по журналам прогонов и evidence), и, если ключевых экранов в светлом почти нет, предложение Сверке минимального набора из ~12 кадров со ссылками `theme=grad_aurora&level=1&appearance=light`.

## Scope
Только чтение реестра, журналов `_runs` и DEV_LINKS; временный скрипт вне репозитория; один новый документ. Код приложения, реестр и модули шагов не меняются.

## Architecture
Светлый кадр определяется по запросу в журнале прогона (`appearance=light` в ссылке и применённая тема без отказа); экран привязывается к макету через `visual_parity.json`. Ссылки набора берутся из DEV_LINKS_R1 с добавлением хвоста темы.

## Security and privacy
Только внутренние журналы тестовых прогонов; персональных данных нет.

## Technical debt
Признак «светлый» берётся из журналов, а не из пикселей кадра: журнал, переписанный более поздним прогоном, может не отражать картинку в evidence.

## Verification
Счётчики сверены двумя способами (журналы и имена файлов evidence); ссылки набора проверены на существование строк DEV_LINKS.

## Rollback
Удалить новый документ.
