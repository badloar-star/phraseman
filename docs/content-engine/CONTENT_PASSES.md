# Five-Pass Content Transformation System

Этот файл превращает пять полезных идей из типовых Instagram-промптов в нормальный редакционный процесс. Ролевые фразы вроде "действуй как вирусный копирайтер" сами по себе ничего не гарантируют. Качество появляется только тогда, когда у каждого прохода есть конкретная задача, входные данные, критерии и причина отклонить слабый результат.

## Общий порядок

Каждый материал проходит пять отдельных редактур:

1. Pattern Break - не повторяет заезженный контент конкурентов.
2. Hook Stress Test - останавливает скролл и создаёт точный долг.
3. Format Multiplication - превращается в три самостоятельных формата.
4. Retention Edit - каждая строка тянет к следующей.
5. Authority Edit - звучит дорого, ясно и уверенно без позы гуру.

Нельзя объединять все пять задач в один расплывчатый запрос. На каждом проходе меняется только одна группа свойств текста. Иначе модель одновременно усиливает громкость, сокращает, усложняет голос и начинает терять факты.

# Pass 1 - Pattern Break

## Цель

Создать идеи, которые не выглядят очередной копией языкового аккаунта, но остаются понятными алгоритму и аудитории.

## Вход

- тема;
- аудитория;
- цель;
- 15-30 свежих публикаций прямых конкурентов;
- повторяющиеся форматы;
- повторяющиеся обещания;
- повторяющиеся визуальные решения;
- реальные механики Phraseman, связанные с темой.

## Задача редактора

1. Назвать семь самых заезженных паттернов без общих слов.
2. Для каждого паттерна объяснить, почему он стал взаимозаменяемым.
3. Создать десять идей, которые ломают хотя бы один паттерн, но сохраняют узнаваемую боль аудитории.
4. Не выдавать смену шрифта или B-roll за новую концепцию.

## Формат каждой идеи

- Концепция.
- Центральный конфликт.
- Reel hook.
- Что пользователь должен почувствовать в первые две секунды.
- Оптимальный формат.
- Почему идея выглядит свежей.
- Почему её могут сохранить.
- Почему её могут отправить другому человеку.
- Какой конкретный ритуал Phraseman естественно продолжает мысль.
- Риск: почему идея может не сработать.

## Сильные виды pattern break

- Не дать урок, а устроить тест до объяснения.
- Не показать правильный ответ, а разобрать момент задержки.
- Не учить редкое слово, а разоблачить знакомую фразу, которая не приходит вовремя.
- Не обещать беглость, а показать один механизм, который её блокирует.
- Не перечислять функции приложения, а показать личный ритуал проверки.
- Не спорить с конкурентом, а сменить предмет разговора.

## Слабые виды pattern break

- "Сделаем минималистичнее".
- "Добавим провокацию".
- "Возьмём необычный звук".
- "Напишем более эмоционально".
- "Сделаем карусель вместо Reel".

Это оформление, а не новая идея.

# Pass 2 - Hook Stress Test

## Цель

Получить hooks, которые останавливают скролл не пустым кликбейтом, а конкретным конфликтом, личной угрозой или незакрытой проверкой.

## Пять обязательных категорий

1. Любопытство - читатель понимает, какой детали ему не хватает.
2. Контрарный взгляд - привычный инструмент или убеждение оказывается ненадёжным.
3. Эмоциональное напряжение - хук попадает в знакомую неловкость, потерю или страх.
4. Конкретика - число, точная фраза, сцена, срок или результат.
5. Скрытый авторитет - автор видит механизм глубже, но не заявляет о собственной экспертности.

## Задание

Создать 20 hooks:

- четыре на любопытстве;
- четыре контрарных;
- четыре эмоциональных;
- четыре конкретных;
- четыре со скрытым авторитетом.

Затем выбрать пять лучших не по вкусу, а по оценке.

## Оценка hook от 0 до 2

- Понятность без caption.
- Конкретность.
- Неожиданность.
- Личная применимость.
- Информационный долг.
- Правдивость.
- Возможность выполнить обещание в статье.
- Визуальная читаемость в две строки.

Максимум - 16. Публикационный минимум - 12. Hook с оценкой по правдивости ниже 2 не публикуется независимо от общего балла.

## Проверка первой секунды

Редактор видит hook отдельно от статьи и отвечает:

- Я понял тему за один взгляд?
- Я почувствовал потерю, конфликт или проверку?
- Я знаю, зачем открывать caption?
- Статья действительно отдаст обещанный ответ?
- Hook не звучит как универсальный шаблон для любой ниши?

## Что запрещено

- "Ты не поверишь".
- "Никто об этом не говорит" без доказательства.
- "Секрет, который скрывают учителя".
- Непроверяемые проценты.
- Слова "шок", "сенсация" и "революция" вместо самой сенсации.
- Вопрос, на который читатель легко отвечает "нет" и уходит.
- Hook, который уже сообщает весь вывод и не оставляет долга.

# Pass 3 - Format Multiplication

## Цель

Не копировать один текст в три контейнера, а заново спроектировать одну идею под три разных способа потребления.

## Ограничения

- без лица;
- без обязательного голоса;
- без трендового звука;
- без сложного монтажа;
- без зависимости от одного конкретного stock-клипа.

## Формат A - Text Reel

Дать:

- hook на экране;
- длительность;
- тип B-roll;
- движение в кадре;
- положение плашки;
- caption;
- незаметный CTA;
- вариант loop;
- одну метрику, которая покажет, что формат работает.

Text Reel создаёт сбой и отправляет в caption. Он не пытается вместить всю статью на экран.

## Формат B - Carousel

Дать:

- обложку;
- функцию каждого слайда;
- финальный слайд;
- caption;
- CTA;
- причину листать дальше;
- причину сохранить.

Карусель должна давать последовательность доказательств, а не разрезанный на семь карточек абзац.

## Формат C - Quiet Visual Post

Дать:

- один визуальный образ;
- короткую подпись на изображении или её отсутствие;
- caption;
- CTA;
- эмоциональную задачу;
- причину, по которой пост не выглядит пустым.

Тихий пост работает через узнавание и авторитет. Он не обязан быть слабой версией Reel.

## Правило самостоятельности

Каждый формат должен быть понятен человеку, который не видел два других. При этом все три должны выражать одну центральную мысль, а не три разных темы.

# Pass 4 - Retention Edit

## Цель

Увеличить вероятность того, что caption дочитают, сохранят и отправят, не превращая текст в нервную цепочку однострочников.

## Метод

Редактор проходит текст предложение за предложением и для каждого отмечает его функцию:

- новый факт;
- усиление конфликта;
- объяснение;
- сцена;
- поворот;
- доказательство;
- проверка;
- продуктовый мост;
- финальное действие.

Предложение без функции удаляется или объединяется с соседним.

## Правила удержания

- Первая строка не разогревает. Она начинает событие.
- Второе предложение не повторяет первое. Оно меняет значение первого.
- До 25 процентов текста читатель уже должен увидеть конкретное доказательство.
- До 50 процентов читатель должен узнать себя в сцене.
- Phraseman появляется после того, как проблема уже доказана.
- Каждый абзац заканчивается не итогом, а новым последствием.
- Сильнейший образ используется один раз, а не разжёвывается.
- Оговорка исследования не прячется в самом конце.
- Текст не должен постоянно кричать. Контраст громкого и спокойного удерживает лучше одинаковой истерики.

## Проверка цепи

После каждого предложения задать вопрос: что заставляет читать следующее?

Допустимые ответы:

- мне обещали объяснение;
- появился новый риск;
- я хочу проверить себя;
- факт изменил смысл предыдущей строки;
- сцена слишком знакома;
- я хочу увидеть, чем закончится эксперимент.

Недопустимый ответ:

- потому что автор продолжает говорить.

## Анти-ИИ монтаж

- Склеить необязательные микропараграфы.
- Удалить параллельные конструкции, которые повторяются три раза подряд.
- Сломать слишком ровную длину предложений.
- Убрать резюме того, что читатель только что прочитал.
- Убрать вводные слова, которые не меняют смысл.
- Заменить общий совет конкретным действием.
- Проверить, что длинных тире нет.

# Pass 5 - Authority Edit

## Цель

Сделать текст дорогим и экспертным без искусственной важности, цифр ради хвастовства и роли всезнающего гуру.

## Что создаёт авторитет

- точное различение двух похожих механизмов;
- корректная оговорка, которая не убивает вывод;
- конкретная деталь исследования;
- ясная причинная цепь;
- способность назвать ограничение собственного совета;
- спокойный глагол вместо рекламного эпитета;
- наблюдение, которое читатель может проверить сам;
- выбор одного сильного тезиса вместо семи безопасных.

## Что имитирует авторитет

- "как эксперт с многолетним опытом";
- громоздкие термины без необходимости;
- пассивный залог ради серьёзности;
- ссылка на исследование без описания дизайна;
- слова "эффективный", "инновационный", "уникальный";
- тонна цифр, не связанных с решением читателя;
- снисходительный тон;
- обещание результата для всех.

## Три версии одного текста

### Elegant

Спокойная точность. Меньше давления, больше наблюдения и подтекста. Подходит для бренда, которому не нужно доказывать статус вслух.

### Direct

Быстрый конфликт, простой язык, минимум украшений. Подходит для тестовых Reels и широкой холодной аудитории.

### Premium

Более плотная мысль, точнее лексика, один сильный образ, строгая логика. Не означает более длинный или более сложный текст.

## Проверка тихой уверенности

Перед публикацией удалить название автора, должность и любые заявления об экспертности. Если текст после этого не выглядит компетентным, позиционирование держалось на декорации.

# Master Prompt

Используй этот блок после подготовки source card и первого черновика.

```text
Проведи текст через пять независимых проходов.

Контекст:
Тема: [ТЕМА]
Аудитория: [АУДИТОРИЯ]
Цель: [ЦЕЛЬ]
Источник и дата: [ИСТОЧНИК]
Точный результат: [РЕЗУЛЬТАТ]
Ограничение: [ОГРАНИЧЕНИЕ]
Механика Phraseman: [МЕХАНИКА]
Черновик: [ТЕКСТ]

Pass 1 - Pattern Break
Назови семь заезженных паттернов по этой теме. Создай десять идей, которые ломают их содержательно, а не только визуально. Для каждой дай концепцию, конфликт, hook, формат, причину свежести, причину сохранения, причину отправки, продуктовый ритуал и риск.

Pass 2 - Hook Stress Test
Создай 20 hooks по пяти категориям: любопытство, контрарный взгляд, эмоциональное напряжение, конкретика, скрытый авторитет. Оцени каждый по восьми критериям от 0 до 2. Выбери пять лучших и объясни выбор.

Pass 3 - Format Multiplication
Преврати выбранную идею в Text Reel, carousel и quiet visual post. Для каждого дай структуру, экранный текст, визуальное направление, caption, CTA, причину удержания и основную метрику. Форматы должны быть самостоятельными.

Pass 4 - Retention Edit
Перепиши caption так, чтобы каждое предложение выполняло функцию и создавало долг перед следующим. Удали повторы, пустые вводные, лишние абзацы, рекламный тон и слишком ровные конструкции. Сохрани 3-5 плотных абзацев. После текста кратко перечисли, какие слабые места были удалены.

Pass 5 - Authority Edit
Дай три окончательные версии: Elegant, Direct, Premium. Каждая должна транслировать компетентность и авторитет через точность, ясность и спокойную уверенность, без образа гуру, высокомерия, хвастовства цифрами и искусственно сложной лексики.

Обязательные правила:
- Только короткий дефис.
- Никаких длинных тире.
- Не выдумывать факты, проценты, конкурентов и исследования.
- Не прятать важные ограничения источника.
- Не использовать прямой призыв скачать Phraseman.
- Не завершать универсальной моралью.
- Не разбивать каждое предложение на отдельный абзац.
- Не считать смену формата новой идеей.
```

# Финальный шлюз

Материал допускается к публикации, только если:

1. Он отличается от конкурентов содержанием, а не декором.
2. Hook набрал минимум 12 из 16.
3. Caption выполняет обещание hook.
4. В тексте нет предложения без функции.
5. Авторитет создаётся точностью, а не позой.
6. Phraseman появляется как действие, а не рекламная вставка.
7. Исследовательская оговорка находится там, где она влияет на понимание.
8. После закрытия caption читателю хочется проверить конкретную фразу, ошибку или привычку.
