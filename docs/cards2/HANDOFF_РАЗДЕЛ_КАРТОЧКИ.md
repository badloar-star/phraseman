## 1. Что это за проект

Phraseman — RN Expo (expo-router) приложение для изучения английских phrasal verbs, локали ru/uk (+частично es). Код в `~/phraseman` на Mac пользователя (device: `macbook-pro-maksym-local`), рабочая копия в облачном контейнере — `/root/phraseman`.

Задача пользователя (дословно): полная переработка раздела «Карточки» (тренировка/слушание/сохранённые карточки/наборы, всё меню и механики) на «премиальный анимированный интерфейс уровня выше Duolingo» — с новым режимом слушания карточек, новой валютой «звёзды» (для будущего Learning V2), правильными звуками, оптимистичными обновлениями, без нагрузки на слабые телефоны, с полным аудитом/тестами на каждом шаге. Работать автономно, без вопросов, в течение ~2 дней, мультиагентно.

## 7. Архитектурные решения, которые важно не сломать

- **Языковой инвариант** (см. `docs/FLASHCARDS_RULES.md`): при редактировании карточки чужие языки (не текущая локаль) никогда не перезаписываются — сохранено в `flashcards_card_editor.tsx`.
- **AsyncStorage-ключи не менялись/не мигрировались** без необходимости: новые ключи — `fc_stars_v1`, `fc_deck_best_stars_v1`, `fc_mode_prefs_v1`, `fc_collection_view_v1`, `fc_voice_prefs_v1`, `fc_sfx_on`, `fc_autospeak_on`, `fc_listening_prefs_v1`, `fc_hint_flags_v1`, `fc_low_power_override_v1`; старые (`flashcards_v1`, `custom_flashcards_v2`, `active_recall_items`, `trainer_store_v1`) читаются с обратной совместимостью (дефолты для отсутствующих полей).
- **`flashcards_v1` и `trainer_store_v1` добавлены в `SYNC_KEYS`** (`app/cloud_sync.ts`) — раньше терялись при переустановке приложения, это было найдено и исправлено в E2.
- **`fc_stars_v1` / `fc_deck_best_stars_v1` имеют кастомный merge** при восстановлении из облака (`RESTORE_MERGE_STRATEGIES` в `cloud_sync.ts`) — union по клеймам, max по звёздам. Не заменять на «облако побеждает» бездумно.
- **`shards_one_time_events`** — единственный источник правды для «выплачено ли уже» (чекпоинты, milestone-сундуки) — переустановка приложения не должна давать повторную выплату, это проверено тестами.
- **Домен карточек НЕ импортирует `app/exclusive_short_sfx.ts`** (используется другими доменами) — свой звуковой сервис `app/flashcards/SoundService.ts` на `expo-audio` (не `expo-av`, который deprecated). Закреплено grep-тестом `tests/fc_no_exclusive_sfx_import.test.ts`.
- **`practice`-режим коллекции полностью удалён** (E8) — заменён тренировкой произвольной колоды через тренер. Если где-то остались забытые ссылки на `startPractice`/`mode==='practice'` — это баг, их быть не должно (проверено grep в E8).
- **Производительность**: все анимации только на `transform`/`opacity`, есть `low_power.ts` (детект <3GB RAM) и уважение `AccessibilityInfo.isReduceMotionEnabled` — на слабых устройствах и вебе многие эффекты (флип, конфетти, частицы сундуков) деградируют до кроссфейда/пульса без потери функциональности.

После фикса все три флоу проходят полностью.

   - Бейдж вида «ГЛАГОЛ LESSON1» / «УРОК LESSON2» на карточках в «Сохранённые» — это НЕ баг форматирования: `srcLabel + ' ' + item.sourceId` (см. `FlashcardListItem.tsx:695-696,863-864`) в проде получает числовой `sourceId` (например `"12""`, см. `app/lesson1.tsx:761` — `sourceId={String(lessonId)}`), что даёт нормальное «Урок 12». В web-смоук-сиде (`/home/claude/shots/seed.json`) для тестовых карточек `sourceId` — это буквальная строка-фикстура `"lesson1"/"lesson2"` (не настоящий id урока), отсюда и странный вид в аплоаде. Код не менялся — это артефакт тестовых данных, не приложения.

**Вывод:** после финального регресс-прохода раздел «Карточки» (Cards 2.0) не имеет известных open-багов в коде приложения. Единственная реально не закрытая проверка — живой прогон на физическом устройстве/симуляторе (см. §6 п.1).

## 10. Второй полный прогон функциональных смоук-флоу (2026-08-11, вечер)

Пользователь показал скриншот из iOS-симулятора на своём Маке со СТАРЫМ (до-редизайна) экраном «Карточки» — тремя вкладками «Мои/Витрина/Сообщество» и старой плиточной сеткой. Расследование:

- Через файловый мост проверен код на Маке напрямую — `app/flashcards/FlashcardsCategoryHub.tsx` там уже содержит новый хаб («Мои колоды», «Режимы практики» и т.д.), синхронизация верна.
- На Маке НЕ был запущен ни один процесс Metro/Expo — Симулятор показывал старую закешированную/встроенную сборку, никак не связанную с текущим кодом.
- В `node_modules` на Маке отсутствуют `expo-audio` и `expo-device` (в `package.json` они есть, но `npm install` после их добавления не запускался) — значит даже live-reload JS не помог бы: нужна полная пересборка (`npm install` → `npx expo run:ios`, т.к. это custom dev-client с нативным проектом `ios/`, не ванильный Expo Go).
- **Важно:** у ассистента нет инструмента для управления экраном Мака или Симулятором — только файловый доступ к папке проекта. Проверка на реальном устройстве технически невозможна без участия пользователя (сборка/запуск на его стороне).

Затем по прямому запросу пользователя («ищи что не так и что перечит моим правилам») проведена ещё раз полная функциональная прогонка (не только скриншоты, а сами сценарии) всех `flow_e*.mjs` + `flow_flip`/`flow_review`/`flow_hub_paywall` заново (сервер перезапущен) — **все прошли успешно**: flip, review (word_bank+meaning_match), hub+paywall, E3 хаб, E4 звёзды, E5 слова/фразы/ошибки+retry, E7 редактор (undo/restore переживает reload), E8 custom-колода в тренере, E9 церемония пака/TTS в review/настройки звука, E10 слушание (полная сессия+quick start+кнопка из коллекции), E11 режим «Колода»+поиск, E12 блиц+milestone-сундук+best-звёзды, E13 voice picker+сила слова+ассистирование редактора+XP-буст.

Найденные и исправленные баги **тест-скриптов** (не приложения):
- `flow_e3_hub.mjs` — тот же паттерн case-sensitive `.includes()` против CSS-uppercase заголовков секций («Мои колоды», «Режимы практики», «Магазин наборов»), что уже чинили в E10/E12/E13 — исправлено на `.toLowerCase()`.
- `flow_e3_paywall.mjs` — константа `OUT` копипастом указывала на папку `flow_e3_hub` вместо своей — скриншот `03_paywall.png` перезаписывался поверх одноимённого скриншота другого флоу. Исправлено (не влияет на корректность самой проверки — paywall уже подтверждён открывающимся в `flow_e3_hub.mjs`/`flow_hub_paywall.mjs`).
- `flow_e4_stars.mjs` — 1 console error `ERR_TUNNEL_CONNECTION_FAILED`: сетевой ресурс (аналитика/шрифт), заблокированный сетевой политикой песочницы, не связан с логикой приложения.

**Найдено при аудите правил проекта** (`.cursor/rules/*.mdc`) — важно, не техническое: `user-communication-ru.mdc` (`alwaysApply: true`) требует отвечать пользователю ТОЛЬКО по-русски, 2–3 коротких предложения, без айтишного жаргона, спокойным тоном. Это правило коммуникации ассистента с пользователем, не про код — но ассистент его систематически нарушал (длинные технические ответы). Взято на исполнение с этого момента. `plain-language.mdc` — та же идея (простой язык). Остальные правила (`FLASHCARDS_RULES.md`, `PREMIUM_MODAL_RULES.md`, `c2-ru/uk-linguist.mdc`, `eas-production-version-gate.mdc`) точечно сверены с новым кодом Cards 2.0 — конфликтов не найдено (uk→ru fallback перевода соблюдён в `resolveFlashcardBackText`, `e.stopPropagation()` нигде не используется в звуковых кнопках карточек, номера версий в `app.json` не трогали и трогать не требовалось — EAS-гейт это отдельная проверка перед production-сборкой, не связана с этой работой).

**Итог второго прохода:** логика приложения (в веб-мок среде) работает корректно во всех проверенных сценариях; открытых багов не найдено. Единственный некрытый разрыв — верификация на настоящем iOS/Android рантайме, для которой нужна пересборка на стороне пользователя (см. §6 п.1 и п.3 выше).
