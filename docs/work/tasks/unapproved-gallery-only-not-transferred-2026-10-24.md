## Scope

## Architecture
По каждому из 79 пунктов: макет (docs/design/v2-app/<file>) против кода (пути из пункта, рабочее дерево). Перенесено → пункт
убирается. Не перенесено → в note пишется «Нет в коде: …». Сверку делают три агента (по трети, только чтение), правку страницы —
эта сессия. Ключ localStorage меняется на v2, чтобы старые отметки не путали счётчик.

## Security and privacy
Страница статическая, без сети; новых данных нет.

## Technical debt
Решение «перенесено» принимается по исходникам, без снимков, поэтому в спорных случаях пункт остаётся в галерее.

## Verification
