# Число заданий и эпизодов: одно правило для окна эпизода, обложки и Главной

## Outcome
Сверка 24.10 (координатор, экраны, которые завтра включаем): окно эпизода 1 пишет «0 заданий», а в сессии их 19; подзаголовок дублирует
заголовок «Первый пропуск»; на Главной «0 из 50» до входа в эпизод и «0 из 56» после. Нужны логи [SEASON-COUNT] (откуда каждое число)
и одно правило: число показывается, только если известно из данных курса; неизвестное — не рисуется (не «0»); старый курс (50 фраз)
не подставляется в карточку урока V2; подзаголовок не повторяет заголовок.

components/learning-v2/season/SeasonCourse.tsx (окно эпизода), components/learning-v2/season/SeasonCourseView.tsx (лог обложки),

## Architecture
Окно эпизода: tasksCount null → правой подписи нет; подзаголовок скрыт при совпадении с заголовком. Главная: homeSceneLessonCount —
V2 с прогрессом → эпизоды урока (локальный прогресс курса), V2 без прогресса → числа нет (ждём), старый урок → 50 фраз.
Каждое решение — одна строка [SEASON-COUNT] со значениями и источником.
