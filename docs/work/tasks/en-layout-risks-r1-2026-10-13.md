# Task packet: риски вёрстки при английском интерфейсе (зона Дизайна)

Governance-ID: TG-28AFCD5830A2
Status: In progress
Owner: сессия «2 · ДИЗАЙН» по команде координатора 13.10 (вопрос 4, EN-проход)

## Outcome

Список мест в зоне Дизайна (Карточки, Диалоги, Видео, Главная, Шпиль, Уроки), где английский текст рискует не влезть: кнопки, чипы, вкладки фиксированной ширины, `numberOfLines={1}` с обрезкой, заголовки в одну строку рядом с иконкой, тексты в пилюлях. Для каждого: файл:строка → строка en → риск. Явные случаи чинятся переносом или вёрсткой (не сжатием шрифта) в окна коммитов. Документ: `docs/phraseman-2.0/EN_LAYOUT_RISKS_R1_2026-10-13.md`.

## Scope

In scope: чтение кода зоны; сравнение длины en и ru строк (временный сценарий в scratchpad, в репозиторий не кладётся); документ; точечные правки вёрстки явных случаев.

Out of scope: сами тексты (за Ядром/переводом), `adjustsFontSizeToFit` и любое сжатие шрифта (запрещено владельцем), Learning V2.

## Architecture

Статический разбор: пары `ru/en` из `triLang`-объектов рядом с контекстом (`numberOfLines`, фиксированная ширина, `flexDirection: 'row'` без переноса). Исправления: `flexShrink`/`minWidth: 0`, перенос на вторую строку или `flexWrap`, `numberOfLines={2}` там, где высота позволяет, без смены кегля.

## Security and privacy

Данные не затрагиваются.

Contain: разбор статический, настоящую проверку делает Сверка по EN-кадрам; динамические строки (имена, числа) в оценку не входят.
