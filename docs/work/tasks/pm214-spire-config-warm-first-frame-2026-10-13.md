## Architecture

`warmSpireConfigFromDisk()` читает `spire_config_cache_v1` из хранилища и кладёт конфиг в `configMemory`, как это уже делает `loadSpireConfig`, но без сети и без проверки возраста: свежесть решает сам экран (`loadSpireConfig` при входе освежает фоном; «выключен» из старого кэша перепроверяется `refreshSpireConfigIfLocked`). Запуск — `runAfterHomeFirstFrame('spire_config_warm', …, { holdDuringOnboarding: true })` с динамическим импортом, чтобы не утяжелять первый кадр Главной.
