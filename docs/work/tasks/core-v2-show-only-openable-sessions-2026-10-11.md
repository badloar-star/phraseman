# Task packet: Learning V2 — показываем столько, сколько реально открывается

Governance-ID: TG-EB74F0894E32
Status: In progress

Вырез V2 не возвращаем; игрок видит только занятия, которые открываются, без тупиков «Сессия недоступна».

## Outcome
1. Сгенерированный артефакт `app/learning_v2_bundle_availability_v1.generated.ts` — сколько занятий с начала курса подряд
   собираются из бандла. Пишет его тот же проход, что проверяет сборку занятий (`tests/learning_v2_bundle_availability.test.ts`,
   режим обновления). После починки Codex множество растёт само — правка кода не нужна, только перегенерация.
2. Клиентский слой `app/learning_v2_session_availability_v1.ts`: «занятие выпущено» = его позиция в курсе меньше этого числа.
3. Карта (`LearningV2ChaptersCourse`) показывает только выпущенные занятия; главы, уроки без них — скрыты (не серые).
4. Нет ни одного выпущенного занятия → вход в курс (вкладка «V2», чип «Новые уроки») не показывается.
5. Ворота precheck «Озвучка встроенных занятий V2» — красные, только если занятие внутри выпущенного множества не
   собирается; остальные — справка со счётчиком.

## Scope
In: артефакт и его генератор/проверка, слой доступности, `app/(tabs)/lessons.tsx` (вход, предикат материала), компонент карты,
ворота озвучки, сторожа входа.
Out: контент, фабрика, клиент сессии v3 (Codex), схема прогресса.

## Architecture
Прогресс курса — строго непрерывная цепочка (`course_local_progress_v1.ts`: засчитанное = префикс порядка курса), а каталог
фабрики привязан к позиции. Поэтому «выпущенное множество» — НЕПРЕРЫВНЫЙ префикс собирающихся занятий от урока 1 занятия 1.
Внутри него дыр нет: «следующее» никогда не упирается в скрытое, схема прогресса и синхронизация не меняются. Занятие,
которое собирается, но стоит после первой дыры, — скрыто до починки дыры (справка в воротах).

## Technical debt

  отдельная задача после релиза.

озвучки в precheck.
