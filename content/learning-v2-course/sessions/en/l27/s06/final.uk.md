# Урок 27 · Заняття 06 — Що будемо їсти

**Ситуація.** Ви обираєте обід, пояснюєте свої смаки й обговорюєте вечерю з другом.

**Що ви опануєте:** if + past simple, would + base verb; past simple / present perfect
**Нові слова:** nutritious, appetizing, tasteless, sugary

## Інтро 1

### Обрати обід

Nutritious — поживний, що містить корисні для організму речовини. I want a nutritious lunch — я хочу поживний обід. Appetizing — апетитний, що викликає бажання поїсти: That looks appetizing — це має апетитний вигляд. У британському написанні трапляється appetising; це те саме слово. Ви готували б частіше, якби було більше часу: I would cook more often if I had more time. Had після if позначає уявну умову, would cook — результат.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would cook more often if I had more time.**
- ❌ I would cooked more often if I had more time. — *Після would потрібно cook.*
- ❌ I would cook more often if I would had more time. — *В умові had без would.*

---

## Інтро 2

### Розповісти про смак

Tasteless — несмачний у значенні «майже без смаку», коли йдеться про їжу. This soup is tasteless — цей суп майже без смаку. Це ваше враження про смак, а не повідомлення про безпечність їжі. Sugary — солодкий через цукор, із помітною кількістю цукру. This drink is too sugary for me — цей напій для мене надто солодкий. For me показує особисту перевагу. Друг пропонує лимон. I would add some lemon if I had one — я б додав трохи лимона, якби він у мене був. One тут замінює a lemon.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would add some lemon if I had one.**
- ❌ I would adding some lemon if I had one. — *Після would потрібна форма add.*
- ❌ I would add some lemon if I would had one. — *Після if тут had без would.*

---

## Інтро 3

### Хто сьогодні готує

I have made dinner — я приготував вечерю: повідомляємо про результат зараз. I made it yesterday — я приготував це вчора: називаємо завершений час, тому made без have. Ви обговорюєте допомогу на кухні: I would help you if I finished work earlier — я б допоміг тобі, якби закінчував роботу раніше. Finished тут — уявна умова, а не обіцянка. Друг уже накрив на стіл. Це його улюблена частина готування: їжа з’являється, а каструлі поки не його турбота.

**Виберіть фразу для цієї ситуації.**

- ✅ **I made it yesterday.**
- ❌ I have made it yesterday. — *Із yesterday тут past simple.*
- ❌ I maked it yesterday. — *Минула форма make — made.*
