# Качество переводов и объяснения устойчивых конструкций (Phraseman планы)

## Проблема
Переводы фраз персональных планов литературные/смысловые, не дословные. Юзер
собирает английскую фразу по словам и видит расхождение с русским переводом
(owner→ответственный, follow up→вернусь с ответом) → жалобы. Правило:
если конструкция устойчивая — ОБЯЗАТЕЛЬНО объяснение почему не дословно.

## Решение (одобрено пользователем)
Переводы оставляем естественными. Объяснение «почему не дословно» через:
**словарь устойчивых конструкций + авто-детекция расхождения** (100% покрытие).

## Компоненты
1. `personal_plan_idiom_dictionary.ts` — словарь фразовых глаголов и не-дословных
   слов (follow up, check in, sort out, run out, owner, there is, make sure,
   in charge, ...). Каждая запись: id, regex pattern, titleRu, explanationRu.
2. `personal_plan_phrase_explanation.ts` — приоритетная цепочка:
   1) idiom dictionary (точное объяснение конструкции)
   2) авто-детекция: literalCoverage(en, ru) < 0.5 → «перевод по смыслу»
   3) грамматический паттерн (вопрос/отрицание/need/there is/утверждение)
3. Объяснение крепится к ПЕРВОМУ слову фразы (видно сразу при сборке).

## Тесты
16 passing: словарь (детекция каждой конструкции), приоритеты (idiom > divergence
> grammar), прогон по 320 реальным фразам. tsc чистый.

## Что НЕ трогали
Сами переводы (english/russian пары) не менялись — только добавлены объяснения.
