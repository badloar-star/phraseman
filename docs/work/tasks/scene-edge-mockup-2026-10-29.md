# Task packet: нижний край сцены — плавный переход в фон экрана (макет вариантов на реальных кадрах Главной)

Governance-ID: TG-E47216C57454

Related epic/enabler: PhraseMan 2.0 — сцена (scene-approved.js, scene-final.html); исполнители — «Темы» на 4 экранах (Главная, Диалоги, Сезон, Пик)

## Outcome

Владелец: сцена (~46 % экрана, скругление 32 dp снизу) под «Продолжить» обрывается ровным краем — «так не должно быть нигде»; нижний
край должен плавно уходить в фон экрана. Светлая тема остаётся «А». Нужен интерактивный макет на реальных кадрах Главной (тёмное
«Глубокое небо» и светлое «А»): 2–3 варианта перехода — градиент последних N dp в цвет фона без скругления, мягкое растворение, свой
вариант; видно карточку «Сегодня» под сценой и где начинается текст; точные числа для Тем (высота перехода, кривая, цвета scenePalette).

## Scope

In scope: docs/design/v2-app/scene-edge.{app.js,css,make.cjs,html} (на движке scene-final: dark-themes.app.js + scene-approved.js +

Out of scope: код приложения (переход внедряют «Темы» по числам из доклада), другие экраны (Диалоги/Сезон/Пик — те же числа), вечер.

## Architecture

Сцена «как будет» = та же перекраска утверждённой формулы на реальном кадре; поверх — пост-обработка нижних N dp: смешение пикселя с
цветом фона экрана по кривой t → a(t) (вариант 1 линейно, вариант 2 smoothstep, вариант 3 — сцена продолжается под карточку «Сегодня»:
нижние строки под краем сцены, совпадающие с фоном страницы, получают хвост сцены с тем же растворением; пиксели карточки не трогаются).
Углы скругления (вне радиуса) закрашиваются формулой сцены (fillCorners), скругления нет. Цвет фона — токен темы `bg` (сверен с кадром
в строке под сценой на поле x 16). Числа варианта — в подписи страницы и в докладе, внутри телефонов служебного текста нет.
Инвариант: при `post`/`fillCorners` не заданных выход движка прежний (эталоны 124 PNG и parity не затронуты).
