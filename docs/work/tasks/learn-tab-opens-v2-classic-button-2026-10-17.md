# Task packet: вкладка «Обучение» открывает новые уроки, старые — кнопкой «Классический курс»

Governance-ID: TG-C36FA1695B33
Status: In progress
Owner: сессия «2 · ДИЗАЙН»
Related epic/enabler: R08 (карта V2, риск H1), R69 (полотно)

## Outcome
Слово владельца 17.10 (передал координатор): «вкладка Обучения будет открывать конкретно именно новые уроки, а не старые, а старые уроки будут открываться отдельной кнопочкой там, где сейчас Новые уроки».
Результат: корневая вкладка «Обучение» при каждом входе открывает карту V2; на карте есть кнопка «Классический курс» (9 языков), открывающая прежний список уроков; из старого списка «назад» возвращает на карту; с карты «назад» — на Главную. Это отменяет решения 13.09 («вход открывает старые уроки») и 13.10 («вкладки Уроки | V2 с памятью выбора»).

## Scope
In scope: `app/(tabs)/lessons.tsx` (стартовая страница вкладки, «назад», шапка старого списка, подпись кнопки), `components/learning-v2/LearningV2ChaptersCourse.tsx` (кнопка в строке «Урок N»), сторожа: `lessons_entry_opens_legacy_guard`, `lessons_tabs_memory`, `learning_v2_visibility_switch_contract`, `learning_v2_legacy_lessons_entry_2026_09_12_gate`, новый `learn_tab_opens_v2_contract`.
Out of scope: плитка «Уроки» на Главной и выходы из старых уроков (маршрут `/lessons_list`) — остаются на старом списке; рубильник «V2 скрыт»; таббар (`_layout.tsx`); тексты вводного окна «legacy_lessons_first_visit».

## Architecture
Выбор стартовой страницы — `startLessonsPage(initial, presentation)`: вкладка (`presentation="tab"`) + курс доступен → `v2`; маршрут `/lessons_list` и `/learning-v2/course` — как раньше. Память выбранной вкладки (`lessons_tab_page_v1`) удалена целиком: иначе у людей со старой записью `v2` отдельный маршрут старого списка молча прыгал бы на карту. Если курс недоступен (рубильник/нет выпущенных занятий) — вкладка открывает старый список, как раньше. Кнопка живёт в карте V2 в строке «Урок N · Классический курс» — в шапке с «назад» и HUD (словарь, монеты, энергия) на 360 dp места нет; через тот же `onLegacyLessons` (вводное окно при первом входе → `openLegacyLessons`). Чип «Новые уроки» убран из старого списка вкладки (там же появилась стрелка «назад» к карте); в push-маршруте старого списка он остался.

## Security and privacy
Данные не затрагиваются: ни новых полей, ни сервисов, ни разрешений; удалена локальная запись выбора вкладки.

## Technical debt
Contain: кнопки нет в макетах (`learn.html`, макет шапки карты) — нужен макет/одобрение Макетов; название «Классический курс» предложено координатором, тексты на 8 языках — черновик, сверить с Переводчиком. Плитка «Уроки» на Главной ведёт в старый список — решение координатора.

## Verification
Сторожа по исходникам + прогон смежных; кадры Сверки (эмулятор, очередь emu_lock): холодный вход во вкладку → карта, таббар скрыт и возвращается при «назад», «Классический курс» → старый список, «назад» → карта, узкий экран 360 dp, длинная подпись (pt-BR/vi), крупный шрифт.

## Rollback
Откат коммита возвращает прежнее поведение (кроме удалённой локальной записи выбора — она необязательна).
