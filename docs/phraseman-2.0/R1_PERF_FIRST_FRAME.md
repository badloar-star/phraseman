## 1. Замер: что поставлено и как снять

Хук `usePerfR1Probe(screen)` (`app/perf_r1_probe.ts`) стоит в корне **Главной** (`home`), **списка Уроков** (`lessons`), **хаба Карточек** (`cards_hub`). В релизе и стор-сборке это пустая функция без единого React-хука (владелец 22.09: тело горячего экрана — чистое); в dev пишет в Metro три возможные строки на заход:

```
[PERF-R1] {"screen":"home","stage":"first_frame","ms":…,"commits":…}   — от первого рендера корня до первого кадра после коммита
[PERF-R1] {"screen":"home","stage":"commits_3s","commits":…,"ms":…}   — сколько раз корень перерисовался за первые 3 с
[PERF-R1] {"screen":"home","stage":"left_early","commits":…,"ms":…}    — экран закрыли раньше 3 с
```

Считаются **коммиты** (`useEffect` без зависимостей), а не вызовы `render`: в dev-StrictMode render зовётся дважды, коммит — один раз. Для Главной уже есть собственные метки `[HOME-RENDER]` (`homeFirstRenderStartedAt` / `homeFirstPassiveStartedAt`, сторож `home_render_timing_log_contract`) — они остаются и читаются вместе.

**Просьба Сверке (очередь):** холодный старт, гость, Главная → Уроки → Карточки; по 3 захода на экран; в Metro-журнале выбрать `[PERF-R1]` и `[HOME-RENDER]`; приложить строки в `INBOX`. Ориентиры для решения: `first_frame` ≲ 300 мс, `commits_3s` ≲ 6 для Главной / Уроков и ≲ 4 для хаба. Что выше — берём из таблицы M/L ниже в порядке цены/эффекта.
