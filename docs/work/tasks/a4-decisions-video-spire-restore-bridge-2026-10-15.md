# А4: решения координатора по «не чиню» — видеорейка, Пик без сети, потолок «Восстановить», журнал моста курса (15.10)

Governance-ID: TG-909B2FF730EC

## Outcome
По решению координатора ~14:05, окнами до 15:00: (1) видеорейка Главной без данных тихо скрывается через ~10 с и возвращается сама, когда видео появились; лог `[HOME-VIDEO]`; (2) Пик без конфига и без кэша при отсутствии сети показывает «Нет интернета» (уже переведённая строка OfflineBanner), а не «откроется чуть позже»; (3) «Восстановить» в управлении Plus: потолок 8 с → тост «Не удалось связаться с магазином»; (5) потеря «моста» карта→занятие курса — лог `[V2-BRIDGE]` с причиной, поведение не меняется.

## Scope
`components/home/v2/HomeV2VideoRail.tsx`; `components/OfflineBanner.tsx` (экспорт `offlineBannerText`), `components/spire/SpireLockedState.tsx`, `components/spire/SpireHomeScreen.tsx` (потолок файла 400 строк — правка в пределах уже существующих строк), новый `components/spire/spire_config_offline.ts`; `app/manage_subscription.tsx`; `app/learning_v2_direct_session_player_v1.tsx`. Не делаю (решение координатора): таймаут хода диалога (серверный, после выпуска).

## Architecture
Видеорейка: таймер 10 с в эффекте, `animateNextLayoutTransition` на скрытие/возврат (правило стабильной раскладки). Пик: помощник читает NetInfo (тот же вердикт, что у каталога Карточек) и возвращает отдельный объект `SPIRE_CONFIG_OFFLINE` — экран по идентичности объекта выбирает текст. «Восстановить»: сторож по времени с номером запуска (поздний `finally` старого запуска не снимает замок нового); поздний успех всё равно применяется.

## Security and privacy
Данные не затрагиваются; денежный путь «Восстановить» не меняется — только момент снятия спиннера и тост.

## Technical debt
Потолок на экран загрузки цен при пустом плане (платный пользователь без кэша) — не трогаю: без плана экран нечем рисовать. Старые `[V2-HANDOFF]`/`[V2-SESSION]` остаются, `[V2-BRIDGE]` — единый префикс для поиска.

## Verification
Сторож по исходникам + тесты помощника Пика (вердикт офлайн/онлайн) и логики скрытия рейки; контрактные тесты экрана Пика (≤ 400 строк).
