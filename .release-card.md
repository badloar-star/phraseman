# Release card

## Type

polish

## Goal

Deliver the current app experience to existing compatible installations through a production OTA before the official 1.5.60 store builds.

## Allowed changes

- Current mobile app JavaScript/TypeScript and bundled assets.
- App release metadata for version 1.5.60 and build 100.
- Production OTA publication for iOS and Android on runtime 1.5.53.

## Forbidden changes

- No Firebase Functions, Firestore rules, indexes, Hosting, or admin deployment.
- No completion or reconciliation of unfinished admin/backend work.
- No removal of existing app functionality as release cleanup.

## Risk level

high — this publishes the current dirty mobile workspace directly to production; the scope is intentionally broad but excludes backend/admin deployment.

## Manual tests

- Smoke: current Android dev-client was rebuilt and opened against the current LAN Metro source.
- Regression area: home/today navigation, lessons, weekly review, trainer, explanations, avatars, clubs, purchases, auth, and offline behavior.
- Upgrade from previous version: verify an installed runtime 1.5.53 client receives the OTA after publication.
- User type(s): existing free and existing paid users are the primary OTA audience.
- Platform-specific checks: verify the published update group contains both Android and iOS manifests.
- Performance check: confirm startup and tab navigation remain responsive after OTA application.

## Diff review

- Existing mobile changes are user/session work explicitly requested for the current release.
- Main risk is the breadth of the dirty mobile workspace; admin/functions are excluded from the EAS archive and deployment scope.
- The full release gate was intentionally skipped by explicit user instruction; focused mobile tests and TypeScript diagnostics were checked instead.
