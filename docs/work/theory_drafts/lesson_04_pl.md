# Teoria · Lekcja 4 nowego kursu — «There is, there are, some, any, in, on, under» (PL)

> Sesja «12 · ТЕОРИЯ», 21.10.2026. Sekcje 01–14, angielskie zdania i ćwiczenia jak w
> `lesson_04_ru.md`. Oparcia polskie: «Jest apteka» / «Są banki» są bliskie angielskiemu, ale
> miejsce stawiamy na początku («Za budynkiem jest ogród»), a po angielsku idzie na koniec;
> «Nie ma soku» łatwo zamienić w There is not juice / There no juice; «na parapecie» = on, «w» = in.
> Zwracamy się na «ty». Potrzebna korekta native speakera.

**Tytuł ekranu:** Teoria · Co gdzie jest

---

## 01 · Czego się nauczysz *(otwarta od razu)*

**body**
W tej lekcji uczysz się opowiadać, co gdzie jest: «w pobliżu jest apteka», «w lodówce jest mleko», «nie ma dzwonka», «klucz leży pod wycieraczką». Najważniejsza nowa fraza to There is: po polsku to po prostu «jest».

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There is a pharmacy here. | Tutaj jest apteka. | There is |
| There is some milk here. | Tutaj jest mleko. | some |
| Is there a toilet here? | Czy jest tu toaleta? | Is there |
| There isn't a doorbell. | Nie ma dzwonka. | isn't |
| The key is under the doormat. | Klucz jest pod wycieraczką. | under |

---

## 02 · There is — «tutaj jest» *(otwarta od razu)*

**body**
Kiedy mówisz, że gdzieś coś jest, zacznij od There is. Po polsku «Tutaj jest apteka», a po angielsku kolejność jest inna: There is a pharmacy here. Miejsce idzie na koniec. Here is znaczy «oto», a nie «tu jest».

**formula**
`There is` · `a + rzecz` · `gdzie`

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There is a pharmacy here. | Tutaj jest apteka. | There is |
| There is a library nearby. | W pobliżu jest biblioteka. | There is |
| There is a bakery here. | Tutaj jest piekarnia. | There is |
| There is an office upstairs. | Na górze jest biuro. | There is |
| There is a clinic inside the building. | W budynku jest przychodnia. | There is |

**fix**
- ~~Here is a pharmacy.~~ *(w znaczeniu «tu jest»)* → There is a pharmacy here.
- ~~There is pharmacy here.~~ → There is a pharmacy here.

**tip**
There tu nie znaczy «tam». To tylko początek frazy «jest». Dlatego There is a pharmacy here to «tutaj jest apteka», a there i here się nie kłócą.

---

## 03 · There are — kiedy jest ich kilka

**body**
Gdy rzeczy jest kilka, zamiast is stawiamy are, a słowo dostaje s: There are banks here. Tak samo jak w lekcji 3, przed kilkoma rzeczami nie ma a.

**formula**
`There are` · `rzeczy + s` · `gdzie`

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There are banks here. | Tutaj są banki. | There are |
| There are museums nearby. | W pobliżu są muzea. | There are |
| There are bridges nearby. | W pobliżu są mosty. | There are |
| There are quiet streets here. | Tutaj są spokojne ulice. | There are |
| There are parks nearby. | W pobliżu są parki. | There are |

**fix**
- ~~There is banks here.~~ → There are banks here.
- ~~There are a bank here.~~ → There is a bank here.

**drill · choice**
- zdanie: `There ___ museums nearby.`
- opcje: `is` · `are` · `am`
- odpowiedź: `are`
- dlaczego: Muzeów jest kilka, więc There are.

## 04 · Miejsce — na końcu

**body**
Po polsku miejsce często stoi na początku: «Za budynkiem jest ogród». Po angielsku najpierw There is i rzecz, a gdzie — na samym końcu: There is a garden behind the building. Tak łatwiej: najpierw mówisz, co jest, potem doprecyzowujesz gdzie.

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There is a garden behind the building. | Za budynkiem jest ogród. | behind |
| There is a bench near the garden. | Obok ogrodu jest ławka. | near |
| There is a church behind the bank. | Za bankiem jest kościół. | behind |
| There is a market near the bridge. | Przy moście jest targ. | near |
| There is a lake behind the park. | Za parkiem jest jezioro. | behind |

**drill · word_bank**
- zadanie: Powiedz koledze: «Za parkiem jest jezioro».
- odpowiedź: `There` · `is` · `a` · `lake` · `behind` · `the` · `park`
- podpisy: brak (zdanie jest długie, podpisy przy kafelkach tylko przeszkadzają)
- zbędne kafelki: `are` · `in`

## 05 · Zapytać «czy jest?» i odpowiedzieć krótko

**body**
Żeby zapytać, czy coś jest, zamień miejscami dwa pierwsze słowa: There is → Is there…? There are → Are there…? Krótka odpowiedź: Yes, there is. No, there isn't. Yes, there are. No, there aren't.

**formula**
`Is there` · `a + rzecz` · `gdzie` · `?` — `Are there` · `rzeczy + s` · `gdzie` · `?`

**examples** 🔊
| en | pl | hi |
|---|---|---|
| Is there a dentist near here? | Czy jest tu w pobliżu dentysta? | Is there |
| Is there a toilet here? | Czy jest tu toaleta? | Is there |
| Yes, there is. | Tak, jest. | there is |
| No, there isn't. | Nie, nie ma. | isn't |
| Are there trams near the bank? | Czy przy banku jeżdżą tramwaje? | Are there |
| Yes, there are. | Tak, są. | there are |
| No, there aren't. | Nie, nie ma. | aren't |

**fix**
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~Yes, there's.~~ → Yes, there is.
- ~~Is there trams here?~~ → Are there trams here?

## 06 · Mleko, chleb, masło — nie liczy się ich na sztuki

**body**
Jedne rzeczy się liczy: banan, dwa banany. Innych nie: mleko, chleb, masło, cukier. Przed takimi słowami nie ma a, a na końcu nie ma s. Żeby powiedzieć «jest trochę», dajemy some: There is some milk.

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There is some milk here. | Tutaj jest mleko. | some |
| There is some bread near the basket. | Przy koszyku jest chleb. | some |
| There is some butter near the bowl. | Przy misce jest masło. | some |
| There is some cheese here. | Tutaj jest ser. | some |
| There are some berries here. | Tutaj są jagody. | some |

**fix**
- ~~There is a milk here.~~ → There is some milk here.
- ~~There are some milk here.~~ → There is some milk here.
- ~~There is some breads.~~ → There is some bread.

**tip**
Przy tym, czego nie liczy się na sztuki, zawsze is, a nie are: There is some milk, choć po polsku wydaje się, że mleka jest «dużo».

---

## 07 · some czy any

**body**
some dajemy, gdy mówisz, że coś jest. any — gdy pytasz, czy w ogóle jest, albo mówisz, że nie ma. Po polsku oba często się nie tłumaczą: «Jest zupa?» — Is there any soup?

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There is some milk here. | Tutaj jest mleko. | some |
| Is there any soup here? | Czy jest tu zupa? | any |
| Are there any mushrooms here? | Czy są tu grzyby? | any |
| There isn't any juice here. | Nie ma tu soku. | any |
| There aren't any carrots here. | Nie ma tu marchewek. | any |

**fix**
- ~~There is any milk here.~~ → There is some milk here.
- ~~There isn't some juice here.~~ → There isn't any juice here.

**drill · choice**
- zdanie: `Is there ___ rice near the pot?`
- opcje: `a` · `some` · `any`
- odpowiedź: `any`
- dlaczego: Pytasz, czy ryż w ogóle jest, więc any.

---

## 08 · «Nie ma»: There isn't, there aren't

**body**
Żeby powiedzieć, że czegoś nie ma, dodaj not: There is not → There isn't, There are not → There aren't. O jednej rzeczy — isn't a, o kilku — aren't any. Polskie «nie ma» nie ma osobnego odpowiednika: There no juice jest błędem.

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There isn't a doorbell. | Nie ma dzwonka. | isn't |
| There isn't an intercom. | Nie ma domofonu. | isn't |
| There aren't any handrails. | Nie ma poręczy. | aren't |
| There aren't any steps. | Nie ma stopni. | aren't |
| There isn't a lawn behind the building. | Za budynkiem nie ma trawnika. | isn't |

**fix**
- ~~There isn't doorbell.~~ → There isn't a doorbell.
- ~~There aren't any handrail.~~ → There aren't any handrails.
- ~~There no juice here.~~ → There isn't any juice here.

**drill · binary**
- pytanie: Przy drzwiach nie ma dzwonka. Jak to powiesz?
- A: `There isn't a doorbell.`
- B: `There aren't a doorbell.`
- poprawne: A
- wyjaśnienie: Dzwonek jest jeden, więc isn't.

## 09 · in, on, under — w, na, pod

**body**
in — wewnątrz: in the sink, in the basement. on — na wierzchu, na powierzchni: on the worktop, on the windowsill. under — pod: under the doormat. Polskie «na» to zwykle on, «w» — in.

**examples** 🔊
| en | pl | hi |
|---|---|---|
| The lemon is in the sink. | Cytryna jest w zlewie. | in |
| The bicycle is in the basement. | Rower jest w piwnicy. | in |
| The cups are on the worktop. | Kubki są na blacie. | on |
| The plant is on the windowsill. | Roślina stoi na parapecie. | on |
| The key is under the doormat. | Klucz jest pod wycieraczką. | under |

**fix**
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~The key is on under the doormat.~~ → The key is under the doormat.

---

## 10 · next to, between … and, near, behind

**body**
next to — tuż obok, «przy». near — niedaleko, «w pobliżu». behind — «za», z tyłu. between … and — «między … a …», to dwa słowa na dwa punkty odniesienia. Po polsku jest «a», po angielsku and.

**examples** 🔊
| en | pl | hi |
|---|---|---|
| The bench is next to the lamppost. | Ławka stoi przy latarni. | next to |
| The signpost is near the bridge. | Drogowskaz jest w pobliżu mostu. | near |
| The ladder is behind the shed. | Drabina stoi za szopą. | behind |
| The bus stop is between the bank and the library. | Przystanek jest między bankiem a biblioteką. | between |

**fix**
- ~~The bench is next the lamppost.~~ → The bench is next to the lamppost.
- ~~The bus stop is between the bank, the library.~~ → The bus stop is between the bank and the library.

**drill · choice**
- zdanie: `The bus stop is ___ the bank and the library.`
- opcje: `next to` · `behind` · `between`
- odpowiedź: `between`
- dlaczego: Są dwa punkty odniesienia — bank i biblioteka — a przystanek jest pośrodku: between … and.

## 11 · There is czy The … is

**body**
There is — gdy mówisz, że coś jest: rozmówca jeszcze o tym nie wie. The … is — gdy rzecz jest już znana, a ty mówisz, gdzie jest: The lemon is in the sink. Po polsku: «W zlewie jest cytryna» a «Cytryna jest w zlewie».

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There is a car park near the hotel. | Przy hotelu jest parking. | There is |
| The barrier is near the gate. | Szlaban jest przy bramie. | The |
| There is a storeroom between the kitchen and the hall. | Między kuchnią a przedpokojem jest spiżarnia. | There is |
| The coat rack is behind the door. | Wieszak stoi za drzwiami. | The |

**fix**
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.
- ~~A pharmacy is here.~~ → There is a pharmacy here.

**drill · binary**
- pytanie: Siostra szuka cytryny, o której obie wiecie. Jest w zlewie. Co powiesz?
- A: `There is a lemon in the sink.`
- B: `The lemon is in the sink.`
- poprawne: B
- wyjaśnienie: Cytryna jest już znana, mówisz, gdzie jest: The lemon is in the sink.

---

## 12 · Krótka forma: There's

**body**
W rozmowie There is prawie zawsze skraca się do There's: There's a cashpoint near the bank. Z There are tak się nie robi, a «nie ma» skraca się jak zwykle: isn't, aren't.

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There's a cashpoint near the bank. | Przy banku jest bankomat. | There's |
| There's a postbox next to the gate. | Przy bramie jest skrzynka pocztowa. | There's |
| There's a vending machine in the hall. | W holu jest automat z napojami. | There's |

**tip**
Krótkiego «tak» się nie skraca: Yes, there is, a nie Yes, there's.

---

## 13 · Błędy, które robi prawie każdy

**fix**
- ~~Here is a pharmacy.~~ *(«tu jest»)* → There is a pharmacy here.
- ~~There is banks here.~~ → There are banks here.
- ~~There is a toilet here?~~ → Is there a toilet here?
- ~~There are some milk.~~ → There is some milk.
- ~~There isn't some juice.~~ → There isn't any juice.
- ~~The plant is in the windowsill.~~ → The plant is on the windowsill.
- ~~There is the lemon in the sink.~~ → The lemon is in the sink.

**tip**
Dwa sprawdziany. Mówisz, że coś jest, czy gdzie stoi znana rzecz? «Jest» — There is / There are. «Gdzie» — The … is. I drugi: jedna rzecz, kilka, czy coś, czego nie liczy się na sztuki?

## 14 · Co zabrać do ćwiczeń

**body**
«Jest» — There is a… / There are… / There is some… «Czy jest?» — Is there…? Are there any…? «Nie ma» — There isn't a… / There aren't any… Miejsce — na końcu: in, on, under, next to, near, behind, between … and.

**examples** 🔊
| en | pl | hi |
|---|---|---|
| There is a library nearby. | W pobliżu jest biblioteka. | There is |
| Are there any mushrooms here? | Czy są tu grzyby? | any |
| There aren't any steps. | Nie ma stopni. | aren't |
| The cups are on the worktop. | Kubki są na blacie. | on |
