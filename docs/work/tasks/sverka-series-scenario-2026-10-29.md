## Architecture

Каждый кадр: фокус `app.phraseman` + проверка `frame_check.py` (1080×2400, не чёрный, не красный экран сборщика, не плоская заставка, не рабочий стол); брак — одно повторение, затем FAIL в `series/series.log`. В metro-логе виден только факт сброса: `[SUPPORT-DIAG] сброс журнала reason=… записано=N отброшено=M …` (N>0 = доехало на диск). Содержимое — через экран отчёта («Пожаловаться») или `adb shell run-as app.phraseman cat databases/RKStorage` (в dev-сборке без run-as — не читаем). РЕШЕНИЕ: обязательны только строки `[HOME-LESSONS-BTN]` и `lessons_tab:` (дублируют те же тайминги); события `lessons:*` — бонус, результат сценария без них не блокируется; `lessons:stage:*` и `:cold` ещё не закоммичены (Дизайн пришлёт хэш). В отчёт серии добавляется строка `[SUPPORT-DIAG]` из лога, если она есть.
  Холодный и тёплый — отдельно: холодный = после перезапуска, первый тап в течение 45 с (в событиях суффикс `:cold`).

## Прошлые дефекты, учтённые в сценарии
1. Объявление «Больше практики» перекрывало кадры → закрывается один раз; кадр с ним — брак.
2. Чёрные кадры / «Unable to load script» после перезапусков → проверка кадра + холодный запуск вместо перезапусков «поверх»; `adb reverse tcp:8081 tcp:8081` перед каждым холодным стартом.
3. Параллельные заходы на эмулятор → оба замка на всю серию.
4. ANR «Phraseman isn't responding» после ~20 мин → холодный перезапуск каждые 60 кадров; при FAIL — строки ANR из logcat в `series.log`.
5. Подмена `lv2progress` ломала открытие «Уроков» → применяется только в блоке A и снимается следующей ссылкой `dev_state`.
6. Мусорный файл `nul` в `placement_entry` → скрипты не используют перенаправление в `nul`.
