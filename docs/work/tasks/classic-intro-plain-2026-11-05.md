# Task packet: вступления классики по стандарту «объясняем как ребёнку»

Governance-ID: TG-FD8D5C0A3024
Status: In progress
Owner: сессия «Темы» (вступления классики)
Related epic/enabler: docs/work/classic_plain_explanation_standard_2026-11-05.md; TG-D01D9A1F84C3

## Outcome

Вступления перед уроками классики (intro) переписаны по стандарту владельца: 3–5 коротких строк «что учим сегодня» обычными словами и 3 примера «фраза → перевод (как читается)», без терминов и без «Представь ситуацию». Пользователь, который не знает языка, с первого урока понимает, что делать. Мерка: independent-проверка «пятилетнего читателя» (агент получает только текст) не находит непонятных терминов в уроке 1 каждого языка; сборка проходит, сторож Ревизора зелёный по затронутым урокам.

## Scope

In scope: `docs/work/classic_intro_overrides.json` (ru-поля titleRU/textRU/linesRU) для уроков 1 каждого языка (en, es, fr, de, it), затем остальных уроков — по приоритету владельца; пересборка; коммиты пачками; пересмотр en 1–4 под стандарт.
Out of scope: uk-поля (Переводчик); теория (отдельная задача); Learning V2; сцены и «Наборы» (параллельно, отдельные пакеты).

## Architecture

Граница: слой оверрайдов интро → пакет → `modules/classic-courses/<lang>/intro.json`. Формат карточки не меняется: concept / formula / practice, поля titleRU/textRU/linesRU. Меняется только содержание.

## Security and privacy

Не применимо: учебный текст, персональных данных и сети нет.

## Technical debt

- Accept temporarily: uk-поля интро остаются старыми до правки Переводчика — владелец Переводчик, выход — его файл.
- Accept temporarily: уроки 2–32 и языки — следующие пачки этой задачи, по приоритету владельца (урок 1 каждого языка первым).

## Verification

- Проверка пятилетнего читателя: независимый агент получает только текст карточек урока и отвечает (а) что узнал, (б) что делать, (в) непонятные слова. Брак — любой термин или «слово из воздуха».
- Сборка языка проходит; предупреждений «не применено ключ» по затронутым ключам нет.
- Сторож Ревизора по затронутым урокам — итог по `Tests:`.
- Коммит пачкой через safe_commit с `--expect`.

## Rollback

Удалить ключи из оверрайдов и пересобрать — пакет вернёт прежние тексты.
