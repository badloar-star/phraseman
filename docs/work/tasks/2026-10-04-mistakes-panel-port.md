# Task packet: «Мои ошибки» в приложении 1 в 1 с макетом «Панель»

Governance-ID: TG-30510D7EB55F
Status: In progress

Related epic/enabler: PhraseMan 2.0, паритет макет↔приложение (visual_parity.json, строки mistakes-panel-*)

## Outcome

Раздел «Мои ошибки» в приложении выглядит и ведёт себя как утверждённый владельцем макет docs/design/v2-app/mistakes-panel.html (вариант Б «Панель», 20 экранов): кольцо прогресса, ленты-фильтры, панель-список, ответы в «стакане». Меряем снимком эмулятора рядом с макетом (гейт scripts/port_ready_gate.mjs); слово «готово» — только после «принято» координатора.

## Scope

In scope: app/mistakes_hub.tsx, app/mistakes_list.tsx, app/mistake_detail.tsx, app/mistake_practice_session.tsx (отображение, не логика журнала), новые общие элементы в components/mistakes-panel/, строки реестра паритета.

Out of scope: ядро журнала modules/mistake-practice/*, подсказки хаба (mistake_hub_advice.ts), «Карточки», «Видео», «Наборы», тексты на других языках сверх существующих.

## Architecture

Данные не меняются: хаб и список читают тот же loadMistakePracticeHubSnapshot (локальный журнал, 0 чтений Firestore). Меняется только слой отображения и общие элементы (кольцо, ленты, панель, «стакан»). Размеры берутся замером макета, кромки — внутренние тени boxShadow inset (новая архитектура включена).

## Security and privacy

Новых данных, сервисов и разрешений нет; аналитика прежняя. Политика конфиденциальности не затрагивается.

## Technical debt

Contain: старые экраны не копируем «на всякий случай» — заменяем целиком; устаревшие контрактные тесты обновляем коротко и осознанно (как у хаба «Карточек»). Фильтр по типу в окне «Отработка» требует поддержки в построении сессии — отдельным шагом; до тех пор рабочий чип «Все».

## Verification

Типы по изменённым файлам, тесты mistake*/mistakes*, сторож perf_freeze_contract, снимок эмулятора рядом с макетом через parity_shot.mjs (делает сессия 6), гейт port_ready_gate.mjs.

## Rollback

Каждый экран — отдельным коммитом; откат git revert коммита экрана возвращает прежний вид, данные журнала не затрагиваются.
