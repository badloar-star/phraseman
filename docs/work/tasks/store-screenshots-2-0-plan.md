## Outcome

Готовый план, чтобы снять и собрать новые скриншоты магазинов в стиле 2.0. В нём: какие экраны, в каком порядке, какие размеры нужны каждому стору, где лежат старые картинки, как снять кадры с эмулятора в тёмной и светлой теме. Загрузка в сторы — отдельный шаг, только с «да» владельца.

## Scope

In scope: этот документ; список кадров, ссылки dev_state, правила сборки.
Out of scope: съёмка, правка кода приложения, загрузка в App Store Connect / Play Console, тексты описания стора (они в `content/marketing/ASO_STORE_LISTING.md`).

## Architecture

No architecture change. Кадры снимаются с dev-клиента на эмуляторе Pixel_8 по ссылкам `phraseman://dev_state?...` (источник правды параметров — `parseDevStateParams` в `app/dev_state_fixtures.ts`). Подпись и фон дорисовываются при сборке, вне приложения.

## Security and privacy

Только тестовый аккаунт эмулятора; аккаунт №1 не используем. В кадрах не должно быть настоящих имён, почты, uid. Друзья и лента — только демо-данные (`friends=demo`). Покупки не нажимаем, пароли не вводим.

## Technical debt

## 2. Требования сторов (сверить в консоли перед загрузкой — правила меняются)

| Стор | Слот | Размер | Количество | Примечания |
|---|---|---|---|---|
| App Store | iPhone 6.9" | **1320×2868** (или 1290×2796) | 1–10 на язык | PNG/JPEG без прозрачности. Меньшие iPhone Apple масштабирует сам. |
| App Store | iPad 13" | **2064×2752** (или 2048×2732) | 1–10 | Обязателен: в `app.json` `supportsTablet: true`. |
| Google Play | Телефон | **1080×1920** (9:16) | 2–8, лучше 6–8 | PNG/JPEG ≤ 8 МБ, стороны 320–3840, длинная сторона ≤ 2× короткой. |
| Google Play | Feature graphic | **1024×500** | 1, обязательна | Без важного текста по краям. |
| Google Play | Планшеты 7"/10" | 9:16 или 16:9, ≥ 1080 | по желанию | Помогает показу на планшетах. |

Важное следствие: **сырой кадр Pixel_8 — 1080×2400 (20:9), это 2,22:1 — Play такой не примет.** Поэтому кадр всегда кладётся на холст 9:16 с подписью сверху (как в ASO-плане), а не загружается как есть.

## 3. Список кадров (порядок = порядок в сторе)

Правило из ASO-плана: первые 2–3 кадра видны без свайпа и решают; сначала бесплатное, платное дальше с тихой пометкой «Plus»; пейвол не показываем.

| № | Экран | Что в кадре | Плата | Подпись (черновик, RU) |
|---|---|---|---|---|
| 1 | Главная-сцена | герой «урок дня», «Сегодня», разделы, фраза дня — как на утверждённом макете scenes-compact в.2 | бесплатно | Говорите готовыми фразами, а не отдельными словами |
| 2 | Занятие (урок) | сбор фразы из слов, середина урока, видна прогресс-полоса | бесплатно | 15 минут в день — и первая фраза уже ваша |
| 3 | Хаб урока | обложка сезона / главы и эпизоды (кадры `hub/cover`, `hub/chapters_list` у Сверки) | бесплатно | Путь от первых фраз до свободного разговора |
| 4 | Диалоги | хаб диалогов со сценами | Plus | Тренируйте живой разговор без стеснения |
| 5 | Пик | неделя Пика с соперниками | бесплатно | Поднимайтесь выше каждую неделю |
| 6 | Друзья | список друзей с демо-данными | бесплатно | Учитесь вместе с друзьями |

Подписи — черновик; финал утверждает владелец, переводы делает 10 · ПЕРЕВОДЧИК. Никаких выдуманных цифр (число уроков/фраз пересчитать перед сборкой).

Feature graphic (Play): Главная-сцена на фоне темы + логотип и одна фраза, без мелкого текста.

## 4. Как снять на эмуляторе (Сверка)

Порядок — по правилам Сверки (`docs/work/tasks/sverka-safe-screencap-rule-2026-10-18.md`): строго по одному кадру, `timeout 20`, проверка `pidof screencap`, холодный перезапуск между состояниями.

1. Эмулятор Pixel_8 поднят по `docs/phraseman-2.0/ЗАПУСК_ЭМУЛЯТОРА.md`.
2. **Чистая строка состояния** (обязательно для iOS-набора и красиво для Play):
   ```
   adb shell settings put global sysui_demo_allowed 1
   adb shell am broadcast -a com.android.systemui.demo -e command enter
   adb shell am broadcast -a com.android.systemui.demo -e command clock -e hhmm 0941
   adb shell am broadcast -a com.android.systemui.demo -e command battery -e level 100 -e plugged false
   adb shell am broadcast -a com.android.systemui.demo -e command network -e wifi show -e level 4 -e mobile hide
   adb shell am broadcast -a com.android.systemui.demo -e command notifications -e visible false
   ```
   После съёмки — `-e command exit`.
3. Холодный старт, дождаться «DEV-STATE OK», открыть ссылку, **подождать 3 с, пока уйдёт тост dev_state**, снять `adb exec-out screencap -p`.
4. Тема — параметр `appearance=dark|light`; оттенок — `theme=<id>` из `LIQUID_GLASS_THEME_IDS` (один и тот же на весь набор).

Базовая часть ссылки: `phraseman://dev_state?onboarding=done&intros=seen&overlays=off&plus=on&studyTarget=en&appearance=<dark|light>&theme=<id>`

| № | Добавить к базовой | Проверено у Сверки |
|---|---|---|
| 1 Главная | `&friends=demo&spire=open&cards=demo&next=/` | да (вариант с `plus=off`) |
| 2 Урок | `&lessonintro=skip&mode=a&energy=5&next=/lesson1?id=1` → пройти 2–3 шага до середины | да |
| 3 Хаб урока | превью `dev_season_preview?state=…&theme=dark|light` (как в отчёте Сверки 22.10, раздел hub) | да, кадры есть |
| 4 Диалоги | `&dquota=reset&energy=5&aiConsent=granted&next=/ai_dialog_home` | да |
| 5 Пик | `&spire=open&next=/(tabs)/arena` | уточнить маршрут вкладки Пика |
| 6 Друзья | `&friends=demo&next=/(tabs)/friends` | уточнить |

Для каждого языка интерфейса — тот же набор с `uiLang=<код>` (как в ссылках `uiLang=en&enStudyPrompt=off`).

## 5. Сборка картинок

- Скрипт сборки (вне репозитория, `C:/Temp/claude/store-shots/`): холст нужного размера → фон из тона темы (глубокий градиент, без рамок) → подпись сверху (Inter, крупно, 1–2 строки) → кадр телефона снизу со скруглением; для «Plus» — тихая метка в углу подписи.
- iOS-набор: срезать навигационную полосу Android снизу; строка состояния — только демо-режим (Apple отклоняет кадры с интерфейсом чужой платформы). Отдельно проверить, что в кадре нет Android-специфичных элементов (системные тосты, кнопка «назад» Android).
- iPad 13": та же композиция с кадром, снятым на эмуляторе-планшете (Pixel Tablet, 2560×1600) — если такого эмулятора нет, это отдельное решение (раздел 7).
- Экспорт PNG без альфа-канала; проверка размеров скриптом.
