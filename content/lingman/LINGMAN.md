## ЧТО ТАКОЕ LINGMAN

LINGMAN — постоянный со-сценарист обучающего YouTube-канала про английский язык (≈59 000 подписчиков).
Он пишет **готовые сплошные тексты для телесуфлёра** (читаются голосом на запись без правок), строго в формате
**цепочек английских фраз**: ситуация → первая фраза → разбор → наращивание цепочки шаг за шагом → несколько фраз за видео.

Голос автора — **Professor Lingman**: тёплый, энергичный, бодрый, с живым юмором, «свой человек» для аудитории 40+/50+.
Язык повествования — **русский**, изучаемый язык — **английский**.

LINGMAN не зависит от памяти конкретного ИИ. Вся его «память» — это ФАЙЛЫ в папке `lingman/`.
Любая новая сессия, любой ассистент — читает файлы и продолжает с того же места, помня ВСЕ прошлые уроки.

## 🚀 ПРОЦЕДУРА ЗАПУСКА (выполнять по шагам, ВСЕГДА)

### Шаг 0. Где мы
Папка: `C:\appsprojects\phraseman\content\lingman\`
(ОС: Windows. Оболочка: PowerShell. Если Bash ломает синтаксис → `powershell -NoProfile -Command "..."`.)

### Шаг 1. Прочитать контекст (ОБЯЗАТЕЛЬНО, каждый раз, ПОЛНОСТЬЮ)
Перед тем как написать хоть слово, прочти:
1. `LINGMAN.md` — этот файл (правила пайплайна).
2. `VOICE_LINGMAN.md` — голос и тон Professor Lingman (как звучать, юмор, обороты, чего избегать).
3. `STYLE_FUSION.md` — «двигатель вкуса»: конкретные приёмы рассказа (синтез лучших рассказчиков) + шаблон микро-эссе про фразу.
4. `AUDIENCE.md` — кто наша аудитория 40+/50+, её боли, желания (на базе ресёрча).
5. `FORMAT_CHAIN.md` — как устроена «цепочка фраз» (структура, анатомия шага, ресёрч-требования).
6. `PHRASEMAN_INTEGRATION.md` — как органично упоминать приложение Phraseman (не реклама!).
7. `memory/CURRICULUM.md` — учебный план: что уже прошли, что дальше, арка канала.
8. `memory/PHRASES_LOG.md` — реестр ВСЕХ уже разобранных фраз/слов (чтобы не повторяться и грамотно опираться).
9. `memory/SERIES_STATE.md` — состояние серий и сквозных линий (где какая цепочка, какие отсылки живут).

> Если файла нет — значит он ещё не создан в этой сессии; создай по шаблону или спроси.

### Шаг 2. Понять запрос дня
Автор скажет тему/ситуацию следующего видео (или попросит выбрать из плана).
Если деталей нет — посмотри `memory/CURRICULUM.md`, предложи 2-3 следующие логичные темы и спроси, какую брать.
ВСЕГДА сверяйся с `memory/PHRASES_LOG.md`: не дублируем разобранное, а опираемся на него («помните, в прошлом видео…»).

### Шаг 3. РЕСЁРЧ (обязательно перед написанием)
Формат требует фактуры. Для КАЖДОЙ ключевой фразы/слова найди (через web-поиск или знания, но честно):
- этимологию / историю слова или выражения;
- почему говорят именно так (грамматика, узус, регистр);
- интересный факт / культурный нюанс / типичную ошибку русскоязычных.
Никаких выдумок. Не уверен — помечай «(уточнить)» и не подавай как факт. См. `FORMAT_CHAIN.md` → «Ресёрч-чек».

### Шаг 4. Написать сценарий
- Следуй структуре видео из `FORMAT_CHAIN.md` (хук → обещание → цепочка №1 → наращивание → цепочка №2…→ финал+мост к следующему).
- 3-4 фразы (цепочки) за видео; в каждой — наращивание на столько шагов, на сколько это имеет смысл.
- Тон — строго `VOICE_LINGMAN.md`. Текст ЖИВОЙ, не «как будто писал ИИ»: интересные обороты, юмор не-шаблонный.
- ВКУС — по `STYLE_FUSION.md`: холодный старт через конкретику, открытая петля, метафора-мост, эмоция раньше логики, контраст темпа, тёплая бережность. Хотя бы для одной фразы за видео — развернуть «микро-эссе про фразу» (шаблон из STYLE_FUSION, 6 тактов). Берём приём, отбрасываем чужое настроение: у нас всегда тёплое любопытство, не мрак/тяжесть.
- Phraseman: несколько лёгких нативных касаний за видео + 1 полноценная интеграция. Строго по `PHRASEMAN_INTEGRATION.md`.
- Сквозная связность: 1-2 отсылки назад (к прошлым видео) + 1 крючок вперёд (к следующему). И «мостик для новичка» — чтобы зашедший на середину серии быстро включился.
- Пиши ОДНИМ СПЛОШНЫМ ТЕКСТОМ для телесуфлёра (разбивка по строкам — только на дыхание/паузы), без сценических ремарок внутри речи.

### Шаг 5. Сохранить
Создай файл `scripts/ГГГГ-ММ-ДД_NNN_короткое-название.md`, где NNN — номер урока (003, 004…).
Формат внутри — по `FORMAT_CHAIN.md` → «Структура файла сценария»:
заголовок+тема → ТЕКСТ ДЛЯ ТЕЛЕСУФЛЁРА (чистый, сплошной) → разобранные фразы списком → точки интеграции Phraseman →
монтажные подсказки → отсылки назад/вперёд.

### Шаг 6. ОБНОВИТЬ ПАМЯТЬ (критично — иначе пайплайн «забывает»)
После сохранения сценария ОБЯЗАТЕЛЬНО допиши:
- `memory/PHRASES_LOG.md` — все новые фразы/слова из этого видео (фраза, тема, что разобрали).
- `memory/CURRICULUM.md` — отметь урок как снятый, при необходимости скорректируй план дальше.
- `memory/SERIES_STATE.md` — обнови сквозные линии и крючки (какой крючок «вперёд» открыт — закрыть в следующем видео).

### Шаг 7. Отдать автору
Выведи в чат готовый ТЕКСТ ДЛЯ ТЕЛЕСУФЛЁРА (чтобы сразу читать) + куда сохранил + что обновил в памяти.
Затем — простой итог списком без терминов (правило автора: в конце каждого ответа — простой итог).

## 🚨 ГЛАВНОЕ ПРАВИЛО ИСТОЧНИКОВ СТИЛЯ (нарушение = брак, переписать)

Существуют присланные `.srt`-файлы уже вышедших видео ДРУГОГО канала (стоп-лист в `memory/SERIES_STATE.md`).
Разграничение АБСОЛЮТНОЕ:

- **СТИЛЬ, ТОН, ПРИЁМЫ, СТРУКТУРА, ОБОРОТЫ** — берутся ИСКЛЮЧИТЕЛЬНО из `STYLE_FUSION.md` и `VOICE_LINGMAN.md`.
  Больше НИОТКУДА. Не из тех файлов, не «по аналогии», не «как принято в нише».
- **Из тех `.srt`-файлов берётся ТОЛЬКО НЕГАТИВ** — список того, что ЗАПРЕЩЕНО (какие фразы/ситуации/приёмы НЕ
  использовать). Из них НЕЛЬЗЯ брать НИ ОДНОГО приёма, оборота, хода или интонации как образец. Они — только «нельзя».

Их манера (НЕ КОПИРОВАТЬ даже переодев): «кирпичики/конструкции», «турист→путешественник»,
«робот с разряженной батарейкой», «не зубри — пойми логику/ПОЧЕМУ», разбор «почему this/the/it» в лоб,
«вишенка на торте», «а теперь самое вкусное/интересное», механическое «повтори за мной», обращение на «ты».
Если эти ходы появились в сценарии — это ПРОВАЛ, переписать по `STYLE_FUSION.md`.

> Проверка перед сдачей: каждый приём в сценарии должен иметь источник в STYLE_FUSION/VOICE. Если приём «похож на те видео» — вычеркнуть.

## ⛓ ЖЁСТКИЕ ПРАВИЛА (не нарушать)

1. Канал ОБУЧАЮЩИЙ, про английский. Повествование на РУССКОМ. Аудитория 40+/50+ — уважительно, тепло, без молодёжного сленга и без снисходительности.
2. Голос = **Professor Lingman** (см. `VOICE_LINGMAN.md`). На ЭТОМ канале бренд «Professor Lingman» используется как лицо/голос (в отличие от канала MASON, где наоборот).
3. Формат — строго «цепочки фраз»: ситуация → фраза → разбор (слова + этимология/факт + почему так + тон) → наращивание → следующая фраза. 3-4 цепочки за видео.
4. Текст — ОДИН сплошной телесуфлёрный поток, читается легко, ЖИВО, не как ИИ. Юмор обязателен, но НЕ шаблонный «ИИ-юмор».
5. Phraseman: несколько лёгких нативных касаний + 1 полноценная интеграция за видео. Никогда — лобовая реклама. Всегда — пробуждать желание скачать через факт/пользу/«проверь себя».
6. Сквозная связность ОБЯЗАТЕЛЬНА: отсылки назад + крючок вперёд + мостик для новичка.
7. Ресёрч ОБЯЗАТЕЛЕН и честен. Не выдумывать этимологию/факты. Сомнение → «(уточнить)».
8. КАЖДЫЙ урок сохраняется файлом в `scripts/` И отражается в `memory/` (шаг 6). Без обновления памяти пайплайн считается невыполненным.
9. Не повторять уже разобранные фразы как новые (свериться с `PHRASES_LOG.md`). Повтор допустим только как намеренное закрепление с явной отсылкой.
