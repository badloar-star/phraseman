## Вывод по коду (26.10)
`app/lessons_list.tsx` — повторный экспорт вкладки `(tabs)/lessons`. «К урокам», «Следующий урок» и автопереход у
французского делают `replace` итога на `/lessons_list`. Если урок открыт с вкладки «Уроки», в стеке две копии списка:
`[вкладки(Уроки), lessons_list]`.
- Кнопка «назад» и Android на `lessons_list` идут через `safeRouterBack`: корень раздела → `dismissTo('/(tabs)/home')`
  снимает обе копии, петли нет.
- Свайп iOS (у `lessons_list` своих настроек нет, свайп включён) снимает только верхнюю копию и показывает вкладку
  «Уроки» — тот же список второй раз. Петля подтверждена.

Параметр `id` вкладка не читает (маршрутных параметров у неё нет, к текущему уроку она прокручивает сама). Починка —
`dismissToTabRoute(router, '/(tabs)/lessons')` во всех трёх местах: стек сворачивается до вкладки, копии нет.

## Outcome
1. Проверено по коду (и тестом навигации, без эмулятора), задваивается ли список уроков в стеке. Путь: Главная → Уроки
   → урок → итог → «К урокам» → назад; на итоге `goBackFromComplete` делает replace на /lessons_list. Подтвердится —
   починить: петли «назад» запрещены владельцем.
2. Скрипт отчёта (`scripts/back_button_audit.ts`) при пересборке переносит чужие разделы ниже маркера «## Разделы других
   сессий» и не стирает их.

`dismissTo` (`safeRouterBack` с fallback `/lessons_list`), а не `replace` поверх стека.
