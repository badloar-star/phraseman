# Task packet: U10 «Один подходящий ответ» — в пропуск подходит ровно один вариант

Governance-ID: TG-D4B722FFEF62
Status: In progress
Owner: сессия Claude (U10), по списку правок владельца
Related epic/enabler: список правок контента владельца, пункт U10

## Outcome

Ученик не получает «ошибку» за верный ответ в заданиях «пропуск + выбор варианта». Примеры владельца:
«Are you ___?» (free / okay / tired), «We buy ___» (food / coffee). Эталон корректного задания, который
обязан остаться: «They walk ___ the evening» → `in`.

Мера успеха: в каждом задании с пропуском, которое приложение может показать, в пропуск подходит ровно один
из предложенных вариантов — грамматически и по смыслу.

## Scope

In scope:
- генератор заданий «пропуск» экзамена уровня — `app/level_exam_blueprint.ts` (`safeGapCandidate`): именно он
  собирает примеры владельца из фраз курса и добирает варианты «словами того же класса»;
- авторские банки заданий с пропуском: `app/exam.tsx` (зачёт урока), `app/diagnostic_test.tsx` (входной тест) —
  полный просмотр, точечные правки вариантов;
- сторож-тест на новое правило.

Out of scope:
- курс Learning V2 — удаляется по решению владельца D203 (11.11), не трогаем;
- плитки классических курсов `modules/classic-courses/**` — это сборка фразы по показанному переводу, их уже
  ведёт аудит «Ревизора» (сторожа `classic_courses_pack`, `classic_distractor_pairs_guard`), а файлы сейчас
  с чужими незакоммиченными правками;
- смена версии экзамена, формата попытки, очков и порога — не меняются.

## Architecture

Current boundary: `buildLevelExamBlueprint` берёт фразы уроков уровня, для формата `fill_gap` вызывает
`safeGapCandidate`: первый подходящий по правилам токен фразы становится пропуском, варианты = соблазны плитки
из пройденных уроков + добор словами той же категории (`backfillByCategory`). Для лексических категорий
(существительное, прилагательное, наречие…) добор тем же классом по построению даёт слова, которые
грамматически встают в пропуск («Are you free/okay/tired?»).

Intended boundary: правило однозначности живёт в отдельном чистом модуле; генератор только спрашивает его.
Пропуск выдаётся, только если однозначность доказуема: грамматические категории (уже проверяются правилом
согласования) и предлоги с авторскими соблазнами. Лексические пропуски с добором «тем же классом» не выдаются.

Invariants: число заданий экзамена, форматы, id заданий (`level:fill_gap:lesson:phrase`), scoreUnitId, порог
и длительность не меняются; детерминированность по seed сохраняется; сохранённые активные попытки читаются
как раньше (blueprint хранится в попытке целиком).

## Security and privacy

Не затрагивается: нет новых данных, полей, сети, разрешений и сторонних сервисов. Правка — чистая функция
отбора заданий на устройстве и тексты вариантов ответа.

## Technical debt

- Contain: экзамен уровня читает СТАРЫЙ английский курс (`getLessonData(lessonId)` без языка), хотя в уроках
  уже классический курс. Это отдельное решение владельца (какой курс проверяет экзамен) — в отчёте отмечено
  как вопрос, здесь не меняется. Выход: решение владельца.
- Contain: в `app/level_exam_blueprint.ts` лежит чужая незакоммиченная правка v4 (перевод в подсказке пропуска,
  10.11). Мои изменения коммитятся только своими хунками; чужая правка остаётся как есть.

## Rollback

`git revert` коммитов задачи. Данные пользователей не мигрируются: формат попытки и id заданий не меняются,
уже начатые попытки доигрываются со своим сохранённым набором заданий.
