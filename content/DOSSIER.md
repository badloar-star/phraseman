## 3. ПРОЕКТ — PHRASEMAN

- **Что это:** приложение для тех, кто учит английский по фразам (уровни A1–A2 и выше). Перевод + озвучка фраз, упражнения. Выросло из его же ютуб-курса.
- **Зачем начал:** вёл ютуб-канал про английский (~год), делал часовые/двухчасовые видео «фраза → перевод → озвучка» — людям заходило. Потом ютуб снял монетизацию → мотивация просела, деньги надо где-то брать. Решил написать курс для подписчиков (A1–A2). Написал ~15 страниц / 3 урока — понял: курс выйдет дорогой, долгий, и вряд ли купят.
- **Момент рождения приложения:** вёз сына из школы, сын рассказал, что за час накидал простенькое приложение. Максим перестал слушать — в голове уже зрел план: «так я ж тоже могу сделать приложение для тех, кто учит английский».
- **Путь (драма для сериала):**
  - Пилот за ~2 недели вслепую: не знал ни про Visual Studio, ни про Codex, ни про Claude-десктоп (его тогда и не было). В браузере открывал ChatGPT и Claude, копировал код, пытался запускать через Expo. Куча падений и ошибок, файлы перекидывал вручную. → пилот снёс полностью.
  - Перешёл в Visual Studio, начал заново — родилось имя **Phraseman**. На Android вышел через ~2 недели.
  - Бета-тест: позвал подписчиков, предложил **премиум навсегда бесплатно** бета-тестерам → за 1 день 45+ желающих. Через ~2 недели после беты — MVP в Google Play, одобрили. Очень этим гордился.
- **Где сейчас (на момент 2026-06-20):**
  - ~3400 подписчиков приложения.
  - Заработано ~€700–800.
  - ~44 платящих.
  - Каждый день приходит ~30–50 новых — НО без рекламы на его ютубе платящие почти не появляются. Реклама = кислород.
- **Тех-стек/деньги на разработку (для шуток про «сколько это сожрало»):** работает в основном на Opus. Сейчас: Claude за $200 + Codex за $200. Раньше был зоопарк из 6 подписок Claude по ~€23–28 (добавлял +1 каждый раз, как кончались лимиты, вместо одной большой). Пробовал Cursor (~$200), Codex (~$103). Успел поюзать «Fable 5 / clone skate 14» (его формулировка) до блокировки — хвалит, много помог. Есть админка: может выдать premium/VIP вручную без оплаты.
