## Outcome

Человек, изучающий испанский или немецкий, получает работающие «Мои ошибки» и
видит свои локальные наборы карточек.

Сегодня для него:
- ошибки либо **не записываются вовсе**, либо **пишутся в АНГЛИЙСКИЙ журнал**
  (12+ мест с принудительным фолбэком `studyTarget === 'fr' ? 'fr' : 'en'`),
  то есть смешиваются с чужими данными;
- локальные наборы карточек **сохраняются, но не видны ни на одном экране**
  (`loadLocalAuthorPacks` перебирает только `['en','fr']`).

Успех измеряется поведением, а не зелёным tsc: запись ошибки на испанском
попадает в испанский журнал; созданный на испанском набор появляется в списке.

## Architecture

Изменение границы: `MistakeStudyTarget` перестаёт быть снимком двухъязычной
эпохи и ссылается на канонический список языков курса, как уже сделано для
`LocalAuthorPack.studyTarget`. Инвариант: **список языков объявляется в одном
месте** (`LEARNING_LANGUAGE_TARGETS`), остальные типы ссылаются на него, чтобы
пятый язык не требовал правки 30 файлов снова.

Ключевое: у сервера собственная копия ограничения, не связанная типами с
клиентом. Расширение клиента без деплоя функции даст отказ
`mistake_practice_event_sync_invalid` при синхронизации — поэтому клиент и
сервер правятся в одном заходе.

Порядок правок выбран от данных к экранам: тип → валидаторы → фолбэки. Обратный
порядок оставил бы фолбэки, которые продолжают сливать es/de в английский уже
после починки типа.

## Security and privacy

Персональных данных не добавляется: журнал ошибок и наборы уже принадлежат
пользователю и уже хранятся локально и в облаке. Меняется только то, под каким
языковым ключом они лежат, — объём и состав собираемого не растёт, новых
разрешений и сторонних сервисов нет. **Privacy Policy обновления не требует.**

Отдельно отмечено: правка НЕ переносит и НЕ сливает существующие журналы.
Английский журнал, куда по ошибке попадали испанские записи, остаётся как есть —
переписывать чужие данные в рамках этой задачи опаснее, чем оставить.

## Verification

Обязательно (иначе отчёт о готовности недействителен):
- `npm run typecheck` до и после — счётчик ошибок должен падать, а не расти;
  базовая линия на момент старта: **168**;
- точечные тесты модуля ошибок через `npm run test:one` (НЕ `npx jest` — падает
  по памяти на любом файле);
- `npx tsc --noEmit -p functions/tsconfig.json` — сборка функций обязана
  остаться зелёной (EXIT=0), иначе деплой сломан;
- чтение кода: ни один фолбэк `? 'fr' : 'en'` не остался в местах записи журнала.

Ограничение честности: подтвердить «испанская ошибка легла в испанский журнал»
можно только на устройстве. До такой проверки заявляю починку кода записи и
чтения, а не наблюдаемый результат у пользователя.

## Rollback

`git revert <commit>` возвращает узкий тип и прежние валидаторы. Пользовательские
данные не затрагиваются: правка не переписывает и не удаляет журналы, только
расширяет множество принимаемых языков. Откат безопасен — записи, созданные под
ключами es/de за время работы новой версии, останутся лежать нетронутыми (и снова
станут нечитаемыми, но не пропадут).

Серверная часть откатывается отдельным деплоем предыдущей версии функции.
