## Outcome

Раздел «Диалоги» в приложении соответствует утверждённому макету:
1. Экран разговора: цель одной строкой под шапкой; у каждой реплики собеседника
   три круглые кнопки (озвучить, перевести, «почему так»); «почему так» открывает
   шторку снизу с объяснением, переводом и рекомендациями мгновенно (данные
   приходят вместе с репликой); своя ошибка видна сразу одной строкой под своим
   пузырём; помощник (строка над полем) появляется только после трёх
   неадекватных реплик подряд; микрофон слева, поле в центре, отправить справа.
2. Разбор после разговора: оценка диалога числом из 100, полный разбор каждой
   фразы ученика (Plus), Free видит одну фразу и вуаль; руны за первый успех в
   сцене; оценка разговора звёздами.
3. Хаб: афиша «Начать урок» с орбом Макса, кольцо звания в углу, список групп
   раскрывается вниз без стрелок.
4. Урок с Максом: текстовый чат на каркасе MAX (цели can-do, доска, отметка
   фразы, шаг мастерства, домашка в карточки, память, разбор) без голоса и
   realtime; Макс пишет первым и предлагает темы из каталога.

Мера успеха: владелец проходит хаб → урок с Максом → диалог → разбор на
дев-сборке; все действия отвечают мгновенно; стоимость хода не выросла более
чем на один вызов модели.

## Architecture

Граница сейчас: клиент → `premiumDialogStream` (SSE) → OpenAI; разбор отдельным
callable. Намеченная: тот же путь, конверт хода расширяется полями, которые
модель отдаёт в том же вызове (лимит вывода 200 → 360 токенов); разбор
возвращает построчный список; Макс: новые callable `tutorTextTurn` /
`tutorTextFinalize` в основной кодбазе, импортируют чистые модули MAX
(`max_voice_can_do_goals*`, `max_voice_tutor_memory`, промпт-префикс без
голосовых абзацев). Инварианты: 0 realtime; награды считает сервер
идемпотентно; клиент показывает по факту; никаких новых фоновых таймеров.

## Security and privacy

Память Макса хранит учебные факты об ученике (уже покрыто политикой для MAX:
та же коллекция `voice_tutor_memory`); новые поля конверта не содержат PII;
безопасность реплик: существующие `flag_safety`/moderation MAX переиспользуются
в тексте. Детских данных нет. Секреты не затрагиваются.

## Technical debt

- Pay now: конверт хода становится единственным источником объяснений
  (отдельный вызов перевода остаётся только как фолбэк).
- Contain: старый брифинг/консент не трогаем; гейт разбора Free «1 фраза»
  покрыт тестом.
- Accept temporarily: голосовой MAX остаётся запломбирован, текстовый Макс
  живёт отдельным флагом; пересмотр при возврате голоса.
