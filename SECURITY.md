# Security reporting

Please do not publish suspected vulnerabilities, credentials or personal data in a public issue. Use the repository's private security advisory channel or contact the repository owner through the private maintainer channel. Include a minimal reproduction, affected surface, impact and a safe contact route; redact secrets and user data.

We will acknowledge a private report, triage severity and preserve evidence. Public disclosure timing, credits and remediation details are decided case-by-case after a fix or mitigation is available. This file is a reporting route, not a SOC 2 certification or a guarantee of a response-time SLA.

Never test against production accounts, attempt privilege escalation against live users, or exfiltrate data. Stop at the smallest proof needed to establish impact.
