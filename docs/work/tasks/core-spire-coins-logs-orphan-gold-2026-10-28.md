# Ядро · монеты Пика: журнал [SPIRE-COINS] по всей цепочке + золото не снимается как «сирота» (координатор 28.10)

Governance-ID: TG-9D55B2D69765
Status: In progress
Owner: 1 · ЯДРО

## Outcome
Жалобы после 2.0.3: «дошла до вершины — монеты не изменились»; «на некоторые ответы двойные очки, потом с общего счёта
сняли 50, прошла ступени — очки не изменились, потом уменьшились». 1) Журнал [SPIRE-COINS] (console.log — виден в релизе; прежний
[PEAK-COINS] шёл через DebugLogger.info/warn, которые в релизной сборке молчат): каждое изменение «ожидающих» монет с причиной и
суммами до/после, решение «монеты ступени сразу» с каждым ранним выходом, каждая смена показанного числа с разбивкой
кошелёк/ожидающие, каждое снятие «сироты». 2) Найдено кодом: строка золота `spire_gold:{reportId}` всегда считалась сиротой —
чистка сверяла id с очередью, где лежит `{reportId}` без приставки, и через 2 мин снимала ×2 (число падало, потом сервер
засчитывал золото и оно возвращалось). Починка: для золота сверяем id ступени.

## Scope
In scope: `app/spire/spire_pending_coins.ts`, `app/spire/spire_pending_orphans.ts`, `app/spire/spire_step_close.ts`,
`app/runes_system.ts` (только журнал смены показанного числа), тесты.
Out of scope (правят другие сессии — не трогаю): `app/spire_report_client.ts`, `modules/spire/report_store.ts`,
`app/spire/spire_week_result_client.ts`, `components/spire/SpireHomeScreen.tsx`; сервер.

## Architecture
Без изменений поведения, кроме одного: сирота-золото определяется по id ступени (`spire_gold:` снимается с id перед сверкой).
Журнал — строки JSON с префиксом [SPIRE-COINS], без uid целиком (6 символов) и без текстов.

## Security and privacy
Только суммы, id отчётов и укороченный владелец.

## Technical debt
Вершина: бонус сервер даёт раз на неделю и язык (`spire_summit:{scope}`) — повторная вершина в ту же неделю монет не даёт; это
правило, не баг. Причина конкретной жалобы — по журналу после воспроизведения.

## Verification
Тесты Пика (ожидающие, сироты — новый случай золота, золото, закрытие ступени) и проверка типов затронутых файлов.
