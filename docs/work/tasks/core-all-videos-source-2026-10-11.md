## Outcome
Источник данных `app/all_channel_videos_source.ts` для вкладки «Все видео»: полный список роликов канала (до 100 —
потолок каталога `YOUTUBE_CATALOG_LIMITS.videosPerChannel`), сортировка «новые / популярные», поиск по названию,
фильтр по плейлисту, порции по 20 для отрисовки. Первый кадр — из памяти или с диска без сети; обновление фоном.

## Scope
In: новый модуль + чистый селектор + хук, тест. Out: сам экран и навигация (Дизайн), серверный каталог (без изменений).

## Architecture
Снимки экрана видео (`youtube_catalog_cache`, `youtube_channel_memory_cache`) обрезают список до 20 роликов, поэтому
полный список хранится отдельно и компактно (без описаний, ~150 байт на ролик): память + AsyncStorage на канал и
аккаунт. Сеть: не чаще раза в 6 ч на канал; сначала одно чтение манифеста — если версия каталога та же, всё;
полное перечитывание (корень, канал, ролики, плейлисты) — только при новой версии (сервер не меняет версию без
изменения содержимого, пакет K). Пока полного списка нет — показываем 20 из снимка экрана видео с признаком `partial`.

## Security and privacy
Публичные данные каталога YouTube; новых персональных данных нет. Кэш привязан к области аккаунта.

## Technical debt
- Pay now: снимки экрана видео не годятся для полного списка (потолок 20).
- Contain: каталог сервера ограничен 100 роликами на канал — «все» = все из каталога.

## Verification
Тест селектора (сортировки, поиск, плейлист, порции) и загрузчика (кэш свежий — 0 чтений; версия та же — 1 чтение;
новая версия — полное чтение; смена аккаунта — ответ отброшен; ошибка сети при кэше — кэш остаётся). Точечный typecheck.
