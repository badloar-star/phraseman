# Как включить аварийный выключатель по бюджету Google Cloud (для владельца, ~5 минут)

Зачем: приложение само считает расходы на ИИ и останавливает платные функции на 15 $ в сутки (слой 2). Этот шаг добавляет
страховку от Google: если ФАКТИЧЕСКИЕ расходы проекта дойдут до бюджета, Google пришлёт сигнал, и функция `spendCapBillingKillSwitch`
выключит все платные функции. Людям в приложении это покажется как «на сегодня всё».

Важно: выключатель срабатывает только после полной выкладки функций. Ключи и пароли нигде вводить не нужно.

## Шаг 1. Тема для сигнала

1. Откройте https://console.cloud.google.com/cloudpubsub/topic/list?project=phraseman-ea0b3
2. Нажмите **Create topic**.
3. Topic ID: `billing-budget-alerts` — ровно так, маленькими буквами, через дефис.
4. Галочку «Add a default subscription» можно оставить. Нажмите **Create**.

## Шаг 2. Бюджет

1. Откройте https://console.cloud.google.com/billing и выберите платёжный аккаунт проекта Phraseman.
2. Слева **Budgets & alerts** → **Create budget**.
3. **Name:** `phraseman-daily-guard`.
4. **Time range:** Monthly. Дневного периода у Google нет, поэтому сумма ниже — месячная.
5. **Projects:** только `phraseman-ea0b3`. **Services:** все.
6. Галочку «Include credits…» снимите: считаем полную стоимость.
7. **Budget amount:** Specified amount → `600` USD. Это 20 $ × 30 дней. Если хотите строже, поставьте меньше.
8. **Thresholds:** 50 %, 90 %, 100 % — по «Actual».
9. **Notifications:** галочка **Connect a Pub/Sub topic to this budget** → выберите `projects/phraseman-ea0b3/topics/billing-budget-alerts`.
10. Почтовые уведомления владельцу оставьте включёнными. Нажмите **Finish**.

Google присылает сигнал о бюджете несколько раз в день, с задержкой до нескольких часов. Поэтому главный дневной потолок — слой 2 в самом приложении. Этот бюджет — второй замок.

## Как снова включить платное после срабатывания

Выключатель НЕ включает платное обратно сам: иначе перерасход повторился бы.

1. Откройте https://console.firebase.google.com/project/phraseman-ea0b3/firestore/data/~2Fspend_cap_config~2Fglobal
2. Поле `paidDisabled` → `false`, сохраните. В течение минуты функции снова отвечают.

## Где менять дневной порог приложения (слой 2)

Тот же документ `spend_cap_config/global`:

| Поле | Что делает |
|---|---|
| `dailyLimitCents` | Порог в центах за сутки UTC. По умолчанию 1500 (= 15 $). |
| `enabled` | `false` — отключить дневной потолок без выкладки (только в крайнем случае). |
| `estimateCentsByFn` | Оценка одного вызова по имени функции, например `{ "dialogueV2TextTurn": 0.3 }`, если оценки окажутся завышены. |

Посмотреть сегодняшние траты — коллекция `spend_daily_shards`: документы `<дата>_0` … `<дата>_9`, сумма поля `cents`.
