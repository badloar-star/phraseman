# Heisenberg: конвейер Клод-переводов — RUNBOOK

Самодостаточная инструкция: любая сессия (включая дешёвую модель-исполнителя)
продолжает массовый перевод с места остановки. Качество обеспечивает НЕ
переводчик, а конвейер: детерминированные проверки + строгие судьи. Переводить
может дешёвая модель; **судить — только сильная**.

Решение владельца (2026-07-04): переводим силами Клода/агентов, БЕЗ OpenAI API.

## Состояние и цифры

- Пилот pt-BR: 1000/1000 GO — `docs/heisenberg/claude-translations/pt-BR/pilot-2026-07-04/accepted_rows.jsonl`.
- Бэклог pt-BR ≈ 126 500 продуктовых строк; vi/id/tr/pl — примерно столько же каждый.
- Apply-этап (запись GO-строк в исходники приложения) — ОТДЕЛЬНЫЙ шаг, см. конец.

## Цикл одной волны (повторять до исчерпания бэклога)

Все команды из корня `C:\appsprojects\phraseman`.

### 0. Блоки перевода (один раз на локаль, переиспользуются)

```bash
npm run heisenberg -- --lang pt-BR
# выход: docs/heisenberg/<locale>/<run-id>/translation_blocks/
```

### 1. Эмит пакетов (с пропуском уже сделанного)

```bash
node scripts/heisenberg_claude_translation_packets.mjs --emit \
  --blocks docs/heisenberg/pt-br/<run-id>/translation_blocks \
  --locale pt-BR \
  --limit 800 --packet-size 200 \
  --exclude-done docs/heisenberg/claude-translations/pt-BR/pilot-2026-07-04/accepted_rows.jsonl \
  --exclude-done <accepted_rows.jsonl каждой предыдущей волны> \
  --out-dir docs/heisenberg/claude-translations/pt-BR/wave-<NNN>
```

Мусор отфильтрован автоматически (admin/, qa-artifacts/, `__cp_preview`,
`app/_admin*`, `*_dev.tsx`, `.superpowers/`, код-шум `typeof/===`).

### 2. Агенты-переводчики (дешёвая модель — ок)

По одному агенту на пакет, **волнами по 3–4** (больше — рейт-лимит).
В промпте агента ОБЯЗАТЕЛЬНО:

- «Работай САМ, запускать суб-агентов ЗАПРЕЩЕНО» (иначе делегируют и дохнут);
- вход `packets/packet_NNNN.jsonl`, выход `filled/packet_NNNN.filled.jsonl`,
  формат строки `{"id","targetText","translatorNotes"}` — каждый входной id ровно один раз;
- правила: смысл 1:1 без выдумок; английское в кавычках = учебный материал,
  ДОСЛОВНО; плейсхолдеры `${x}`/`{x}`/`%s`, URL, ID, «Phraseman» — дословно;
  английские примеры-предложения остаются английскими; **русские/украинские
  слова-цитаты вопросов (`«кружка»`) — тоже дословно, их НЕ переводить**;
  испанский исходник ≠ готовый португальский — ПЕРЕВОДИТЬ (когнаты совпадут сами);
  короткие UI-подписи — короткими; тон «você» (pt-BR) / аналог для локали;
- самопроверка node-скриптом: число строк, JSON.parse, покрытие id.

### 3. Инжест (детерминированные проверки)

```bash
node scripts/heisenberg_claude_translation_packets.mjs --ingest \
  --locale pt-BR --out-dir docs/heisenberg/claude-translations/pt-BR/wave-<NNN>
```

Hard-проверки (mojibake, плейсхолдеры, кириллица-утечка, пусто) валят строку
сразу; soft-флаги (identical-to-source, protected-english-missing,
weak-language-signal) отдаются судье. Без судьи максимум `PENDING_JUDGE`.

### 4. Агенты-судьи (ТОЛЬКО сильная модель)

По одному на пакет, волнами по 3–4. Вердикт по 3 линзам на каждую пару
(GO/HOLD + note): accuracy (ничего не добавлено/потеряно), naturalness
(естественный целевой язык, испанизмы в pt-BR = HOLD), integrity (учебный
английский/цитаты/плейсхолдеры целы). Выход
`judged/packet_NNNN.judged.jsonl`: `{"id","judge":{accuracy,naturalness,integrity}}`.
Судье говорить: «сомневаешься — HOLD», «когнат es→pt идентичный — GO, если
слово реально такое в pt-BR», «русские цитаты вопросов должны остаться».

### 5. Финальный инжест → GO/HOLD

Повторить команду шага 3. `accepted_rows.jsonl` = GO-леджер волны,
`held_rows.jsonl` = брак с причинами судей.

### 6. Цикл исправлений (если held > 0)

Исправить targetText прямо в `filled/*.jsonl` по судейским note (маленький
node-скрипт с map id→текст), затем пере-суд ТОЛЬКО исправленных id новым
judged-файлом с БОЛЬШИМ номером (`packet_0008.judged.jsonl`, `0009`, ...) —
поздние файлы перекрывают вердикты по id. Снова шаг 5. Повторять до 0 held.

## Дисциплина

- Волны агентов по 3–4, не 7+ (рейт-лимит убивает молча).
- Пакет 150–200 строк (300+ рискует контекстом агента).
- Никогда не редактировать judged-файлы руками — только новые файлы поверх.
- Леджеры волн НЕ удалять: они же — вход `--exclude-done` следующих волн.
- Конвейер ничего не пишет в исходники приложения и не создаёт аппрувов:
  `reviewerImportAllowed=false` навсегда, GO-строки ждут apply-этапа.
