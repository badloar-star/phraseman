# Task packet: бета-тест А3 — ни одного сырого ключа или пустой строки в 9 языках, длинные языки не ломают кнопки

Governance-ID: TG-A171DC461388
Status: In progress
Owner: сессия «Специалист по переводам» (план docs/work/tasks/beta-test-2026-10-15.md, часть А3)
Related epic/enabler: бета-тест перед сборкой 16.10

## Outcome

На любом из 9 языков интерфейса человек не видит ни сырого ключа (`settings.title`, `cta_buy`), ни пустой строки, ни русского/
английского текста в чужом языке; кнопки и плашки на длинных языках (pl/id/vi/pt-BR/de) не выходят за одну строку.

## Scope

In scope: сканер по таблицам строк (9-элементные массивы, объекты `{ru, uk, en, …}`, вызовы `L/LP/triLang`) в app/, components/,
modules/, constants/, hooks/; правки найденных строк (чистые замены текста). Out of scope: вёрстка, логика выбора языка, тексты курса
Learning V2 (у них свои гейты), магазины.

## Architecture

No architecture change: сканер — разовый скрипт вне репозитория; правки — значения строк.

## Security and privacy

Не применимо: только видимые тексты.

## Technical debt

Сторожа на «сырой ключ / пустая строка / длинная кнопка» в репозитории частично есть (i18n_missing_en_fallback, untranslated_ui_positional);
пробелы, если найдутся, — предложение сторожа в отчёте.

## Verification

Сканер + ручной разбор каждой находки; сторожа i18n через slot.sh после правок.

## Rollback

`git revert` коммита правок.
