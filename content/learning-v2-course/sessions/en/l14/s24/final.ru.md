## Интро 1

### Коричневый сахар

Brown sugar — коричневый сахар. I was adding brown sugar. — Я добавлял коричневый сахар. Описываем действие, которое шло в тот момент.

**Выберите фразу для этой ситуации.**

- ✅ **I was adding brown sugar.**
- ❌ I am adding brown sugar. — *Am adding — сейчас.*
- ❌ I was add brown sugar. — *Нужна форма adding.*

## Интро 2

### Мелкий сахар и пудра

Caster sugar — мелкий сахарный песок; icing sugar — сахарная пудра. Это разные продукты. She was using icing sugar. — Она использовала сахарную пудру. Выберите пудру.

**Выберите фразу для этой ситуации.**

- ✅ **She was using icing sugar.**
- ❌ She was using caster sugar. — *Caster sugar — мелкий сахарный песок, не пудра.*
- ❌ She were using icing sugar. — *С she нужна was.*

## Интро 3

### Панировочные сухари

Breadcrumbs — хлебные крошки; здесь панировочные сухари для готовки. We were using breadcrumbs. — Мы использовали панировочные сухари. Выберите прошлый процесс.

**Выберите фразу для этой ситуации.**

- ✅ **We were using breadcrumbs.**
- ❌ We are using breadcrumbs. — *Are using — сейчас.*
- ❌ We was using breadcrumbs. — *С we нужна were.*
