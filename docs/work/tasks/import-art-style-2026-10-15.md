# Приёмка выбранного стиля арта одной командой: scripts/import_art_style.mjs

## Outcome
`node scripts/import_art_style.mjs <код стиля> [--dry-run]` берёт ART_STYLE_FOR_CODEX/trials/<код>/{dark,light}/*.webp и *.accent.webp, сжимает до ≤ 400 КБ (webp q≈85 и ниже), проверяет настоящую альфу сторожем, копирует в assets/images/v2art/{dark,light}/ и запускает gen_themed_art_assets.mjs. `--dry-run` только печатает, что заменится/добавится и какой будет размер. Ничего не применяется само: владелец ещё выбирает стиль.

## Scope
scripts/import_art_style.mjs (новый), tests/import_art_style.test.ts (на синтетической папке во временной директории). В assets ничего не кладётся.

## Architecture
Использует knownNames/checkArtFile из gen_themed_art_assets.mjs. Имена вне реестра пропускаются с предупреждением. Любой файл, не прошедший сторож после сжатия (непрозрачные углы), отвергается, и вся приёмка завершается ошибкой ДО записи (применяется только «всё или ничего»). Заменяемые файлы сохраняются в ART_STYLE_FOR_CODEX/_backup/<код>-<время>/ для отката. Скрытые опции --src-root/--dest-root/--no-gen — для теста.

## Security and privacy
Локальный скрипт, картинки.

## Technical debt
Нет: применять только по решению владельца.

## Verification
Тест: dry-run ничего не пишет; применение сжимает тяжёлый файл ≤ 400 КБ и заменяет; шахматка отвергается без записи; незнакомое имя пропускается.

## Rollback
git revert; файлы, заменённые при реальной приёмке, лежат в _backup.
