## Outcome

Экран «Обучение» Learning V2 выглядит и двигается как способ 2 эталона: обложка главы-сезона с «Продолжить эпизод N», выбор главы, карусель карт эпизодов с глубиной (центральная крупнее, соседние уходят в глубину, свайп листает, тап раскрывает карту), экзамен — последняя карта, за ней карты следующей главы; нижний ряд «Вся глава · Слова · Теория»; все пять состояний (в процессе, новичок с «Не хочу с начала», тап по закрытому эпизоду, вся глава, экзамен); обе темы. Данные — из текущего прогресса курса без новых чтений Firebase. Успех: склейка «макет | эмулятор» без расхождений для каждого из пяти экранов, ровные 60 кадров карусели на слабом Android.

## Scope

In scope: `components/learning-v2/LearningV2ChaptersCourse.tsx` и новые соседние компоненты карусели/обложки/раскрытой карты, тексты (слово «Эпизод» — формы от «Переводчика»), тесты, обновление реестра паритета. Вход из `app/(tabs)/lessons.tsx` — только после согласования с сессией Learning V2, которая сейчас правит этот файл (вход «Эпизод»).

Out of scope: файлы Codex (`content/learning-v2-course/**`, `modules/learning-v2/content/**`), содержимое курса, сервер, логика прогресса и начисления, экран самого занятия.

## Architecture

Данные берутся из существующего снимка прогресса курса (то же, что питает нынешний экран); новая раскладка — чисто представление. Анимации карусели на UI-треде (Reanimated, shared values, worklets), список карт виртуализирован (рисуются соседние карты, остальные — по требованию), без `setState` на кадр. Первый кадр = итоговая геометрия, без полноэкранных спиннеров (правило «каждый раздел открывается мгновенно»).

## Security and privacy

Новых данных не собираем, сторонних сервисов и разрешений не добавляем; Privacy Policy не затрагивается. Тап по закрытому эпизоду «Открыть экзаменом главы» использует существующую логику доступа, а не обходит её.

## Technical debt

Pay now: единая карусель вместо двух параллельных вариантов; старая раскладка удаляется после перехода, а не остаётся мёртвым кодом. Contain: перевод слова «Эпизод» ждёт «Переводчика» — до его форм используется текущий словарь, место подмены помечено комментарием с условием выхода.

## Verification

Тесты формы данных и состояний (пять экранов), контракт производительности (`perf_freeze_contract`, `layout_stability_contract`), `tsc` под светофором; склейка «макет | эмулятор» по каждому из пяти экранов в обеих темах и запись экрана для анимаций («Сверка»).

## Rollback
