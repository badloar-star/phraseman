Прогон состояний

Или руками: тап по карточке слева/справа выделяет её (тон + подъём, без рамки). Тап по карточке из другой колонки: совпало, обе замыкаются и гаснут через opacity, место остаётся зарезервированным (сетка не прыгает); не совпало, мягкая тонировка 300 мс без тряски, серия сбрасывается, счётчик ошибок +1. Speed Match: optional practice, НЕ mastery gate (04 · SB-03).
