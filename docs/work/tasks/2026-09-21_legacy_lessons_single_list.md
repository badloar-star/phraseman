# Старые уроки — один сплошной список без чипов уровней

Governance-ID: TG-4B7C7478AB3D

## Outcome
В разделе «Старые уроки» больше нет кнопок A1 / A2 / B1 / B2 вверху. Все
32 урока идут одним списком, как было раньше: внутри потока остаются
заголовки уровней, экзамены после 8/18/28 урока и аттестация после 32-го.

Владелец 21.09: «в раздел старые уроки убери A1 A2 B1 B2 кнопочки вверху,
пусть всё будет списком как было когда-то».

## Scope
- `app/(tabs)/lessons.tsx` — фильтр по уровню, рельса чипов, состояние
  выбранного уровня и связанная с ним подкрутка рельсы.

## Architecture
Данные УЖЕ построены под сплошной список: `listData` кладёт заголовок
уровня перед уроками 1/9/19/29, экзамен после 8/18/28 и аттестацию после
32. Фильтр `legacyFilteredListData` это резал по выбранному уровню.

Удаляется:
- состояние `legacySelectedLevel` и его сеттер;
- фильтрация по уровню в `legacyFilteredListData` (поиск по тексту
  остаётся — он работает поверх всего списка);
- чипы A1–B2 в рельсе;
- `revealSelectedLegacyLevel` и `legacyLevelRailRef` — подкрутка рельсы к
  выбранному уровню теряет смысл без чипов.

Остаётся в ряду: кнопка поиска, COMBO и «Новые уроки» — владелец просил
убрать только уровни.

Вызовы `setLegacySelectedLevel` из других мест (переход к текущему уроку)
удаляются вместе с состоянием; прокрутка к текущему уроку работает по
индексу строки и уровня не требует.
