### Пункт 7 — «Почему очки не показываются ни мои ни оппонента?»

**Статус: НАЙДЕН ТОЧНЫЙ БАГ, готов к правке.**

**Файл:** `app/arena_match.tsx`, строки 349-365, функция построения
`players`:
```tsx
const players: readonly ArenaPlayer[] = useMemo(() => {
  if (!plan) return [];
  const you: ArenaPlayer = {
    uid: plan.viewerSeat, name: arenaText(lang, 'you'), rank: 0, rating: 0,
    score: 0, correct: 0,        // ← ЖЁСТКО НОЛЬ, ВСЕГДА
  };
  const rival: ArenaPlayer = {
    ...
    score: 0, correct: 0,        // ← ЖЁСТКО НОЛЬ, ВСЕГДА
  };
  return plan.viewerSeat === 'a' ? [you, rival] : [rival, you];
}, [lang, plan]);   // ← зависит только от plan, НЕ от live match.state!
```
`useMemo` пересчитывается только при смене `lang`/`plan` — план матча
(состав игроков/задания) не меняется по ходу игры, поэтому `score` навечно
остаётся `0` для обоих, независимо от реальных ответов.

**Сервер это делает ПРАВИЛЬНО** — `functions/src/arena_v2.ts`, функция
`refreshPublicTotals` (строка 667-678), вызывается после каждого ответа,
пишет актуальный счёт в публичное поле `match.players[].score` и
`match.scores`. То есть **реальные данные уже приходят на клиент** через
живую подписку на матч (`useArenaMatch`/`match.players`), просто экран их
игнорирует и рисует свой захардкоженный локальный массив вместо них.

**Что нужно сделать:** в `arena_match.tsx` заменить локальный
`useMemo`-массив `players` на чтение из `match.players` (живого документа
матча, который уже приходит через realtime-подписку и уже обновляется
сервером после каждого ответа). Нужно аккуратно смёрджить: `match.players`
может не содержать `name`/`avatar`/`aura` (косметику) — эти поля берутся
из `plan.opponent`, а `score`/`correct` — из `match.players`. Проверить
структуру `match.players` (`ArenaPublicMatch` тип в
`modules/arena/contract.ts`) и `ArenaPlayer` тип, используемый
`ArenaPlayers`-компонентом — они должны совпасть по форме.
