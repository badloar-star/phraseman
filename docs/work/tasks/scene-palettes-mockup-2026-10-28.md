## Outcome

Один живой HTML-макет `docs/design/v2-app/scene-palettes.html` (+ `scene-palettes.css`, `scene-palettes.app.js`, `scene-palettes.make.cjs` рядом),
в котором владелец видит для каждой из 23 тем в светлом и тёмном виде новую палитру «Сцены» (небо/фон, свет, акценты) по теории цвета
(комплементарная / сплит-комплементарная / аналоговая схема, подписана в макете для координатора), применённую ко всем экранам со сценой
(Главная, Пик, обложка Сезона в уроках, Диалоги, Наборы), с режимами «сейчас» (реальный кадр, если есть; иначе формула приложения) и
«новый», живым переключателем тем и сеткой «тема × экран». Второй раздел — герои на сцене Главной крупнее и объёмнее (2–3 варианта:
размер, свет/тень/глубина, появление и нажатие) во всех темах. Мера успеха: владелец выбирает схему и вариант героя; все кадры сняты
headless без JS-ошибок, 404 и битых значков; белый текст на сцене ≥ 4,5:1, шов сцены с карточкой ≥ 1,34 в тёмном.

## Scope

In scope: только файлы макета в `docs/design/v2-app/`: `scene-palettes.{html,css,app.js,make.cjs}`; движок — дословно из эталонов
`peak-scene-v2.html` (CSS по диапазонам строк, снимок тем `window.__THEMES`, коды значков `window.__ICODE`) и `kit.css/kit.js`;
расчёт палитр — чистая функция в `scene-palettes.app.js` (вход: токены темы уровня «Максимум», выход: цвета сцены и подпись схемы),
пригодная к переносу в `components/home/v2/scene/home_scene_tokens.ts` после одобрения. Снимки — playwright headless в Temp, склейки для отчёта.

Out of scope: любой код приложения (`components/`, `app/`, `constants/`) — до одобрения владельца; премиум-темы со своими шейдерами
(olive, lime, amethyst, titanium, horizon, singularity); новая графика героев (используются существующие `assets/v2art/*`); чужие
незакоммиченные файлы (Codex в том же дереве — перед правкой `git status --short -- <файл>`).

## Architecture

Текущая граница: цвета сцены считает `homeSceneThemeTokens` (тёмное — 30 % градиента акцента над фоном; светлое — OKLCH L .47→.28 от
оттенка акцента; «Сумерки» светлое — числа эталона), Пик берёт те же токены, Диалоги — свою формулу (`dialogsSceneColors`), обложка
Сезона — `seasonThemedArt` по главе. Предлагаемая граница: одна функция палитры сцены `scenePalette(themeId, appearance)` →
{ top, bottom, light, lightHue, horizon, scheme } — один источник для всех экранов со сценой; в макете она живёт в JS и показана на
всех экранах. Инварианты: сцена всегда тёмная под белыми чернилами (белый ≥ 4,5:1 на верхе и зоне текста), шов с карточкой ≥ 1,34 в
тёмном и ≥ 1,12 в светлом, оттенок света = оттенок темы (сцена остаётся «своей»), prefers-reduced-motion гасит движение. Решение:
архитектура приложения не меняется (макет), перенос — отдельной задачей по слову владельца.

## Security and privacy

Нет: статический макет без сети, без данных пользователя, без аналитики; картинки героев и монет — из репозитория. Детские данные,
секреты, авторизация — не затрагиваются.

## Technical debt

- Pay now: своё — только в cs-классах/файлах рядом, движок режется по диапазонам строк эталона с проверкой первой строки (сборщик падает,
  а не собирает кривую страницу); формула «сейчас» дублирует код приложения осознанно (чистая копия, как у Наборов).
- Contain: реальные кадры «сейчас» подхватываются по шаблону пути `assets/real/scene_{screen}_{themeId}_{appearance}.png`; пока кадров
  нет — подпись «по формуле приложения». Выход: Сверка присылает кадры, макет их показывает без правок кода.
- Accept temporarily: обложка Сезона в макете — в компактной верстке `scenes-compact.html` (вариант 2 владельца 22.10), не полный экран
  уроков; владелец — координатор, пересмотр при одобрении палитры (перенос в код). Потолок: только макет.
