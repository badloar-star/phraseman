# Урок 32 · Занятие 04 — Не тот адрес

**Ситуация.** Вы с Беном ищете дом Анны и замечаете ошибку в записанном адресе.

**Что вы освоите:** делать вывод по несоответствию и уточнять адрес знакомой частью без that.
**Новые слова:** —
**Повторяем знакомые слова:** address, door, street, number

## Интро 1

### Должно быть, не тот дом

Номер на двери не совпадает с адресом Анны. Вы делаете вывод: This must be the wrong house — это, должно быть, не тот дом. Соберите This + must + be + the wrong house. Must выражает уверенный вывод по найденному несоответствию; перед названием предмета the wrong house нужна связка be.

**Выберите фразу для этой ситуации.**

- ✅ **This must be the wrong house.**
- ❌ This must the wrong house. — *Перед the wrong house нужна связка be.*
- ❌ This must is the wrong house. — *После must здесь нужна форма be, не is.*

---

## Интро 2

### Адрес, который написал Бен

У вас две записки. Уточните адрес на записке Бена: The address Ben wrote is wrong — адрес, который написал Бен, неверный. Соберите The address + Ben wrote + is wrong. Часть Ben wrote уточняет address. That можно опустить: Бен написал адрес, и Ben уже назван внутри уточнения.

**Выберите фразу для этой ситуации.**

- ✅ **The address Ben wrote is wrong.**
- ❌ The address Ben wrote it is wrong. — *Address уже названо: it после wrote не нужно.*
- ❌ The address Ben written is wrong. — *Нужна прошедшая форма wrote.*

---

## Интро 3

### Дверь заперта — подождали

Вы с Беном дошли до нужного дома, но дверь была заперта: The door was locked, so we waited — дверь была заперта, поэтому мы подождали. Соберите The door was locked + so + we waited. Перед so — причина, после него — результат вашего решения.

**Выберите фразу для этой ситуации.**

- ✅ **The door was locked, so we waited.**
- ❌ The door was locked, so we waiting. — *Нужна полная часть we waited.*
- ❌ The door was locked, so we waits. — *Для прошлого действия используем waited.*
