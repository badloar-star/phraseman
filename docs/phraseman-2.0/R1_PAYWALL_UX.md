## 5. Что НЕ тронуто — находки по логике покупки (для координатора)

1. 🔴/🟡 **Любой сбой покупки (кроме отмены и «ожидает подтверждения») в окне Plus показывает тяжёлый блокирующий диалог «Статус покупки не подтверждён. Неизвестно, прошла ли оплата… не покупай снова»** (`app/paywall_purchase.ts` ~1369, `showUnverifiedPurchaseAlert`). Это верно для сбоя *после* оплаты, но срабатывает и на обычную потерю сети / недоступный товар, когда оплата даже не начиналась (`purchaseErrorCategory` уже различает `network_error` / `store_error`). Предложение: для этих двух категорий — мягкий тост `storeUnreachableToast()` вместо диалога; диалог оставить для `sdk_other` / `unknown`.
2. 🟡 **Окно покупки набора открывается для набора без `priceRunes`** (кнопка «за 0»): цена `Math.max(0, floor(Number(pack.priceRunes ?? 0)))`. Нужен вход-гейт в хозяине: набор без цены не должен доходить до окна покупки (или должен быть бесплатным путём).
3. 🟡 **`handleRestore` в режиме `DEV_IAP_BYPASS` молча выходит** после хаптика — для разработчика без обратной связи (в стор-сборке не встречается).
4. 🟡 **«Привязка» восстановления к экрану**: если во время восстановления сменился аккаунт, результат отбрасывается молча (`restoreResult.status !== 'ok'`) — крутилка снимается, а ни тоста, ни пояснения нет. Редко, но стоит одного журнального слова/тоста.
