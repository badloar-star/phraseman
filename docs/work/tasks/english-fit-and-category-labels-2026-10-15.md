# Английский интерфейс (п.76): помещаются ли подписи; русские названия категорий карточек при en

## Outcome
Аудит по коду: английские подписи не обрезаются в кнопках, чипах, вкладках, плитках, сегментах. Найден реальный дефект — названия категорий карточек (чипы хаба, плитки, шапка набора, экран набора) при английском интерфейсе брали РУССКИЕ подписи (`en: cat.labelRU`). Чиним данными: у категории появляются английские подписи.

## Scope
app/flashcards/types.ts (поля labelEn, fullLabelEn), app/flashcards/constants.ts (значения для 9 категорий), потребители: CollectionHeader.tsx, FlashcardsCategoryBar.tsx, FlashcardsCategoryTiles.tsx, app/flashcards_collection.tsx — по одной строке `en:`. Вид, ширины (чип 68) и логика не меняются.

## Architecture
Расширение модели Category двумя обязательными строковыми полями; все четыре места, где en брал RU, читают новые поля. Сокращённые подписи для чипа шириной 68: Saved, Emotions, Fillers, Reactions, Traps, Verbs, Scenes, Links, Create — каждая ≤ 9 знаков, чтобы поместиться в одну строку на 13 px без сжатия шрифта.

## Security and privacy
Данные пользователя не затрагиваются, статические строки интерфейса.

## Technical debt
«Scenes» вместо «Situations» и «Links» вместо «Connectors» — сознательное укорочение под чип 68 (полные названия остаются в fullLabelEn); окончательные формулировки подтверждает владелец/копирайт.

## Verification
Срез типов по затронутым файлам, тесты flashcards, прицельный поиск `en: cat.*RU` (должно быть 0).
