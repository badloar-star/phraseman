# Экзамен главы v2 и «Мастерская фраз»: карта цветов на токенах тем

Для: Learning V2 (перенос экрана экзамена в приложение) и 2 · ДИЗАЙН. Подготовил: 4 · ТЕМЫ, 25.10.2026.
Прототипы: экзамен главы v2 — https://claude.ai/artifact/PYJfpbH1Upz9KCLngxVyG9, «Мастерская фраз» — https://claude.ai/artifact/Mgiat3h327LrNzinagLX87.

**Правило (замок theme-colors-only):** каждый цвет экрана — токен текущей темы из `liquidGlassTokens(themeId, { level, appearance })`. Цвета из прототипа (`#5F5CB1`, `#006F30`, `#A73533`, `#D5D6EA` и т. д.) — это снимок одной темы («Сумерки», светлая) и в код не переносятся.

**Как проверено:** 29 тем × светлая/тёмная × уровни Спокойно/Акцент/Максимум = 174 сочетания; на каждое — 38 пар «цвет / фон», всего 6612 пар. Полупрозрачные токены (`accentSoft`, `goodSoft`, `badSoft`, `accentTile`) сведены на свою подложку (`flattenOver`), как их видит человек. Порог: текст ≥ 4,5, значки и полосы (графика) ≥ 3,0. **Итог по карте ниже: 0 нарушений.** Скрипт замера: `scripts/theme_contrast_measure.ts` (`npx tsx scripts/theme_contrast_measure.ts`), после правки палитры — перезапустить.

## Заметки для переноса

- **Кнопки с замком и часами.** Вход «Мастерская фраз» без Plus — та же кнопка, что с Plus (`accentText` на `accentSoft`), замок того же цвета: не приглушать, человек должен видеть, куда нажать за Plus. «Фраз пока мало» и «Пересдать через 59 мин» — приглушённые, но с информацией: подпись `secondary`, часы `iconMuted` на `opaqueControl`.
- **Неактивная кнопка.** Прозрачность 35 % из прототипа не использовать — она роняет текст ниже 4,5. Неактивная «Проверить» — `buttonFillDisabled` + `buttonInkDisabled`.
- **Нижняя панель с кнопкой** — `opaqueSheet`; кнопка `ctaFill` / `ctaFillInk`.
- **Верно / неверно в поле после проверки** — цвет букв `good` / `bad` на `opaqueCard` проходит (минимум 5,48 / 5,58), можно оставить.
- **Без обводок:** поле ввода и карточки отделяются фоном `opaqueCard` и тенью темы (`plateShadow`), не рамкой.
- **Сторож.** При переносе стоит закрепить пары этой карты тестом (по образцу `tests/intro_text_roles_contrast.test.ts`): если палитра темы сдвинется, тест покажет, какая роль упала.
