# Какие экраны релиза остались без макета — список для владельца

Составлено сессией «2 · Дизайн» 10.10.2026 по реестру визуального паритета (`registries/visual_parity.json`, строки `no_mockup`) и коду. Макеты я не рисую — это только перечень «что, где, в каком состоянии, как найти на телефоне».

**Итог.** В реестре 109 строк без макета. Из них **91 состояние реально видно пользователю релиза** и требует макета; ещё **18 закрываются без макета** (см. конец). Все 91 уже сделаны в приложении на токенах «Liquid Glass» (по матрице паритета 30.09–04.10), но **ни одно не сверено с макетом глазами** — сверять не с чем.

Легенда приоритета: **A** — видно всем и часто / деньги; **B** — видно многим, но не постоянно; **C** — редкое событие.

## 1. Пейвол Plus — цена и покупка (7 состояний, A)

- **Код:** `components/paywall/PaywallPlusScreen.tsx` (+ общий `components/paywall/paywallShared.tsx`), логика покупки `app/paywall_purchase.ts`. Маршрут `/premium_modal` (диспетчер единственного пейвола Plus).
- **Как выглядит сейчас:** единый пейвол Plus на токенах стекла выбранной темы; старые варианты A–G удалены (30.09). Прошлые тёмные «золотые» палитры остались только как запасные.
- **Состояния без макета (реестр `paywalls-011…018`, кроме 017):** загрузка условий · ошибка до checkout · «проверяем покупку» · ожидание банка/родителя (отдельный диалог) · результат покупки неизвестен (отдельный диалог) · статус неизвестен · промо магазина.
- **Как найти на телефоне:** Настройки → «Plus» (или любой лимит: энергия кончилась, лимит ИИ-диалогов, закрытый урок 4+). Ошибку и «проверку» — режимом полёта и тестовой покупкой Google Play (тестовые карты: «ожидание»/«отклонена»). Требуется Free-аккаунт без dev-Plus.
- **Не рисовать:** «Уход с пейволла» (`paywalls-017`) — перехвата на выходе нет (D115).

## 2. Визитка игрока (7 состояний, A)

- **Код:** `components/PlayerProfileModal.tsx` + арт-карточка `components/profile-card/*` (фон-«look», монета ранга, шторки био и Pro-вида за монеты), жалоба — `ReportUserModal`.
- **Как выглядит сейчас:** отдельный арт-стиль карточки (не стеклянные токены экрана): фон из набора «looks», монета ранга, плашка ранга; футер своей и чужой визитки разный.
- **Состояния:** своя визитка · чужая без ID · незнакомый игрок · заявка отправляется · заявка отправлена · уже друг · лайк поставлен/отправка лайка.
- **Как найти:** вкладка «Сообщество» → «Друзья» → тап по другу или по себе; Главная → аватар. «Незнакомый игрок» и «без ID» — из результата поиска по коду/нику.
- **Заметка:** внутри есть покупка Pro-вида за монеты — состояние оплаты тоже нужно нарисовать (шторка `ProfileCardProSheet`).

## 3. «Сообщить об ошибке» (6 состояний, A)

- **Код:** `components/ReportErrorButton.tsx` (кнопка «Нашёл ошибку?» стоит в уроках, диалогах, друзьях, достижениях и др.).
- **Как выглядит сейчас:** шторка/окно на токенах стекла; форма с полем (минимум 10 символов), оптимистичная отправка.
- **Состояния:** форма · «минимум 10 символов» · оптимистичная отправка · сервер подтвердил · не отправилось · лимит «раз в минуту».
- **Как найти:** любой экран с кнопкой «Нашёл ошибку?» (например, итог урока, Достижения) → тап. Ошибку отправки — режим полёта; лимит — отправить дважды подряд.

## 4. Промокод (12 состояний, B)

- **Код:** `app/promo_code_entry.tsx`; при VIP-коде открывается `VipCelebrationModal`.
- **Как выглядит сейчас:** стеклянная карточка, поле ввода, кнопка в цвете `cta`, итог — плашка со значком.
- **Состояния:** пусто · можно применить · проверка · срок подтверждён · бессрочный результат · не найден · истёк · лимит исчерпан · уже использован · неверный формат · отключён · ошибка проверки.
- **Как найти:** Настройки → «Ввести промокод». Состояния ошибок нужны тестовые коды на сервере (истёкший, исчерпанный, использованный, отключённый) — их готовит Ядро.

## 5. Код друга — реферальный лист (11 состояний, B)

- **Код:** `components/referral_code_sheet.tsx` (открывается из `app/referrals.tsx`).
- **Как выглядит сейчас:** шторка на токенах стекла; итог проверки — плашка со значком (прежние цветные тексты убраны).
- **Состояния:** пусто · можно применить · проверка · принят · уже привязан · неверный формат · не найден · собственный код · аккаунт не новый · отключён · ошибка проверки.
- **Как найти:** Настройки → «Пригласить друга» (экран рефералов) → «Ввести код друга». Часть состояний («аккаунт не новый», «собственный код») воспроизводится любым аккаунтом; остальные — тестовыми кодами.
- **Заметка:** название реестра «в онбординге» неточно — из онбординга лист не открывается, только из экрана рефералов.
