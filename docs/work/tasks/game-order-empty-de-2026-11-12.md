# Task packet: «Собери диалог» на немецком открывается пустым «0 / 0» с активной «Готово»

Governance-ID: TG-607ECBE82EAC
Status: In progress
Owner: сессия «банк заданий игр de/fr» по задаче координатора (обход экранов `docs/work/tasks/screen-walk-2026-11-12.md`)
Related epic/enabler: D207

## Outcome

Если у урока нет ни одного диалога, экран «Собери диалог» не притворяется сыгранной игрой: нет счётчика «0 / 0» и
кнопки «Готово», вместо них — понятная строка, с какого урока появятся диалоги, и кнопка «Закрыть». Причина видна в
журнале `[GAME-ORDER]` (язык, урок, сколько диалогов нашёл подбор, с какого урока они есть в банке).

## Причина (по коду и данным банка)

Диалоги в банках начинаются не с урока 1: de — с урока 4, fr / es / it — с 3, en — с 2 (решение владельца
11.11 оставить: в ранних уроках одни утверждения, однозначный порядок реплик не собрать). Разминка такую игру
не предлагает (`isGameAvailable`), но экран, открытый напрямую (обход экранов, прямая ссылка), подбирал 0 диалогов и
по правке 11.11 сразу показывал «Готово» при «0 / 0». Подбор работает верно, банк не пустой — пробел намеренный.

## Scope

In scope: `app/game_order.tsx` (журнал и пустое состояние), `modules/games/order_entry.ts` (новый, правило без React),
`tests/game_order_entry.test.ts` (новый).

Out of scope: банки (`order_de.ts` сейчас с несохранёнными правками другой сессии — уроки 17–20), `task_source.ts`,
разминка, другие игры.

## Architecture

`order_entry.ts` отвечает на вопрос «что показать»: диалог дня или пустое состояние с первым уроком, где диалоги есть.
Экран только рисует. Подбор заданий не меняется.
