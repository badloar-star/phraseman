## Architecture

Изменений границ нет: задача проверочная. Единственные правки — в тестах,
и они меняют не поведение, а ТО, ЧТО СТОРОЖ СЧИТАЕТ ПРАВИЛЬНЫМ.

Принцип, по которому чинится каждый упавший сторож (правило проекта, память
`project_paywall_guard_protected_a_lie`): если тест требует поведение, которое
владелец ОТМЕНИЛ, — чинится тест, а не код. Если тест требует поведение,
которое владелец хочет, — чинится код. Для каждого падения ниже это решение
принимается явно и записывается в комментарий рядом с проверкой.

Инварианты, которые аудит обязан подтвердить:
1. В поле ввода диалога не может попасть текст на языке интерфейса
   (`nextStepHintRu`) — только реплики на изучаемом языке.
2. У каждого интерактивного элемента есть и состояние, и отрисовка: класс бага
   «состояние есть, кнопки нет» уже стоил трёх кругов (память
   `project_dialog_bulb_never_existed`).
3. Ни один экран раздела не может остаться без выхода (мёртвый экран).

## Technical debt

- 247 ошибок типов в проекте. Disposition: **Accept temporarily**, чужие
  области. Owner: владелец. Exit condition: отдельная задача по разбору;
  ограничение — не увеличивать число из Диалогов (сейчас вклад Диалогов = 0).
- Сторож `as any` считает ВСЁ дерево и падает на чужом незакоммиченном долге,
  из-за чего мои коммиты идут с `--no-verify`. Disposition: **Contain** —
  каждый такой коммит явно объясняет причину в сообщении и подтверждает, что в
  затронутых файлах `as any` нет. Exit condition: сделать сторож
  диф-ориентированным (считать только изменённые файлы).
- Метки целей только `labelRu` (+`labelEs` у части). Disposition: **Accept
  temporarily**, поведение поля не менялось. Exit condition: задача локализации.

## Rollback

Правки затрагивают только тесты: `git revert` коммита возвращает прежние
сторожа. Поведение приложения не меняется, данные не мигрируют, деплой не
нужен. Риск отката — возвращается сторож, требующий уже отменённого поведения
(строка помощника вставляет инструкцию автора), поэтому откат осмыслен только
вместе с откатом соответствующих правок экрана.
