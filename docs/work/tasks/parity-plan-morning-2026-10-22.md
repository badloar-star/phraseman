## Перед началом (5 минут)
1. Проверить память ПК (≥ 4 ГБ свободно) — эмулятор падал при 1,3 ГБ; без слова координатора не поднимать.
2. `bash /c/Temp/claude/emu_lock.sh acquire "6 СВЕРКА: утренняя сверка"`; `adb devices` → emulator-5554.
3. Убедиться, что Metro подхватил HEAD (после перезагрузки бандла); закрыть системные окна (например «System UI isn't responding» → Wait).
4. Ссылки открывать так: `adb -s emulator-5554 shell am start -a android.intent.action.VIEW -d "<ссылка>"`. Осторожно: раньше открытие ссылок на работающее приложение роняло его — при `error: closed` не повторять подряд, снять экран и сообщить.
