# Спецификация для фабрики курса (Codex): банк экзамена главы и цели занятий «умение + пример»

Governance-ID: TG-AC77BD18ED77
Status: Spec — передаёт владелец; файлы фабрики (content/learning-v2-course) Learning V2 не трогает
Owner: фабрика курса (Codex); заказчик — Learning V2 (приложение) по решениям владельца 25.10

## Outcome

1. Банк экзамена главы v2 (`exam_bank`) — по выбору владельца 25.10: 10 заданий трёх типов, новые жизненные фразы, без подсказок,
   пересдача сразу после «Повторить эти темы». Пилот — уроки 1–3 (21 глава); владелец читает 2 главы до массовой генерации.
2. Цели занятий (`learningOutcomeByLocale`) — переписать для ученика: «умение + пример» вместо служебных ярлыков
   («present perfect…», «verb +…», «как сказать, … используя `he/she/it + is`»).

## Scope

In scope: шаблоны и проверки фабрики, формат выхода. Out of scope: код приложения (движок экзамена, показ — Learning V2).

## Architecture

### A. exam_bank — вход

- План главы: урок, глава (8 эпизодов), пункты грамматики главы (из цели/вступлений эпизодов), лексика глав уже пройденных.
- Частотный список и стоп-лист (редкие/«смешные» слова: pouffe, ceramics, mole…), список пройденной грамматики к главе.

### A. exam_bank — выход (на главу; файл рядом с выпуском, путь согласовать: `release/en/lXX/exam/chapter-C.json`)

```json
{
  "schemaVersion": "learning-v2-exam-bank.v1",
  "lessonOrdinal": 1, "chapterOrdinal": 2,
  "grammarPoints": [{ "id": "be_he_she_it", "label": { "ru": "he/she/it + is", "uk": "…" }, "episodeOrdinals": [9, 10] }],
  "items": [
    { "id": "l01c2-001", "type": "situation_to_phrase", "grammarPoint": "be_he_she_it",
      "situation": { "ru": "Коллега спрашивает про нового начальника. Скажите, что он спокойный.", "uk": "…" },
      "accepted": ["He is calm.", "He's calm."], "core": ["he", "calm"] },
    { "id": "l01c2-002", "type": "dialogue_reply", "grammarPoint": "be_he_she_it",
      "partnerLine": "Is your sister at home?", "situation": { "ru": "Ответьте, что да, она дома.", "uk": "…" },
      "accepted": ["Yes, she is at home.", "Yes, she's at home.", "Yes, she is."] },
    { "id": "l01c2-003", "type": "fix_the_error", "grammarPoint": "be_he_she_it",
      "wrong": "She are tired.", "errorKind": "be_agreement",
      "accepted": ["She is tired.", "She's tired."] }
  ]
}
```

- ≈30 заданий на главу (3 попытки по 10 без повторов), доли: ~40 % situation_to_phrase, ~30 % dialogue_reply, ~30 % fix_the_error;
  каждый пункт грамматики главы — не меньше 3 заданий.
- Тексты ситуаций — ru и uk (остальные языки показывают ru/uk, как вступления).

### A. exam_bank — правило смысла (владелец 25.10)

Ситуация, реплика собеседника и ожидаемый ответ сходятся по смыслу, как в живом разговоре. Пример ошибки владельца: «Коллега
спрашивает, готов ли отчёт» → ответ «I'm not ready» (спросили про отчёт — отвечаешь про себя). Верно: «It isn't ready yet.» или
«The report isn't ready yet.» Несколько верных вариантов ответа обязательны. Грамматика — только пройденная к концу главы (по урокам
и эпизодам), даже если фраза «простая»: «we / they» и вопросы не появляются в банке раньше эпизода, где их вводят.

### A. exam_bank — автопроверки (сторож фабрики, блокирует выпуск банка)

1. `accepted` не пуст, первый вариант — эталон; все варианты — одна и та же мысль (суд).
2. `fix_the_error`: `wrong` отличается от эталона ровно одной правкой по `errorKind`; `wrong` ∉ `accepted` после нормализации.
3. Нормализация приложения (регистр, пунктуация, ’/', пробелы, I'm/I am, don't/do not, it's/it is) не делает `wrong` верным и не
   склеивает разные смыслы — тест на контрпримерах из самого банка.
4. Лексика: все слова — из частотного списка или пройденной лексики; стоп-лист пуст; фраз из эпизодов главы нет (сравнение с
   выпуском, точное и почти точное совпадение).
5. Грамматика — только пройденная к этой главе; каждый `grammarPoint` есть в плане главы и указывает эпизоды для «Повторить эти темы».
6. Судьи фабрики «дважды» (как у вступлений): понятность ситуации, естественность фраз, однозначность ответа.

### B. Цели занятий «умение + пример»

- Выбор владельца 25.10 — вариант A «умение + пример». Переписать ВСЕ 1540 целей; 9 языков интерфейса (ru, uk, en, es, pt-BR, vi, id, tr, pl).
- Формат: `learningOutcomeByLocale.<язык>` = короткое умение от лица ученика, глаголом (Говорить / Спрашивать / Рассказывать / Описывать / Сравнивать…), без терминов и формул, ≤ 40 знаков («Говорить, какой человек»,
  «Сравнивать цены», «Рассказывать, что шло одновременно»); новое поле `outcomeExample` = английская фраза ЭТОГО занятия
  (из вступления, ≤ 60 знаков) + её перевод ru/uk.
- Стоп-слова и запреты: «как сказать», «используя», обратные кавычки, «+», английские ярлыки грамматики, «review:».
- Автопроверки: длина; нет латиницы в умении; `outcomeExample.en` встречается во вступлении или заданиях занятия; суд «понятно ли
  ученику без терминов» дважды.

## Security and privacy

Нет: контент курса, без данных пользователей.

## Technical debt

Contain: до выпуска новых целей приложение прячет цели из одних латинских ярлыков (показ — Learning V2).

## Verification

Сторожа фабрики выше + пилот exam_bank на уроках 1–3 → вычитка владельцем 2 глав → массовая генерация; цели — выборка 50 занятий
на суд и показ владельцу.

## Rollback

Банк главы не выпущен — приложение показывает прежний экзамен (флаг по главам); старые цели остаются в выпуске до замены.
