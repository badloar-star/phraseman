## 4. Результат: что пишется и где используется
- Пишет ровно одно: `AsyncStorage` ключ `diagnostic_last` (по языку курса, `diagnosticLastKey`) = `{score, level, date}` (стр. 1259–1264). Никакого «пройден / открыть уровни».
- Уровень: A1…C1 — высший подряд уровень, где верно ≥3 из 4; C2 — только при 20/20 (стр. 730–744).
- Побочные эффекты: достижение `diagnosis` (`checkAchievements`), события аналитики `trackFeatureStart/Success`, «Мои ошибки» (`captureCurrentAccountObjectiveAttempt` на неверные ответы; ручной пропуск не пишется), 1 энергия за старт.
- Сервер: прямых вызовов Firestore/функций нет. Косвенно: ключ `diagnostic_last` входит в `SYNC_KEYS` (`cloud_sync.ts:665`) и уезжает общей синхронизацией прогресса (облако только хранит). Для французского — чтение банка вопросов (`french_diagnostic_remote_runtime`).
- Где используется потом: только в самом intro («Твой текущий уровень», «Твой последний результат · N / 20 · дата»). Уровень НЕ открывает уроки, НЕ меняет прогресс классики и НЕ связан с Learning V2. Выход посреди теста ничего не сохраняет. «Готовность к экзамену» считается из прогресса 32 уроков (`exam_readiness.ts`, порог урока 45 из 50), а не из теста.

## 7. Пересечение с Q61
Q61 (`MORNING_QUESTIONS_2026-10-22.md:182`): «Ученица прошла весь классический курс и просит открыть ситуации B1/B2 в новом курсе… да/нет/частично (через тест „Не хочу с начала“)?» Строка брифа 25.10: «Да / нет / через тест».
Что общего: оба — «тест уровня», но продукты разные. Классический: 20 вопросов по грамматике, 1 энергия, пишет только подпись уровня. V2 «Не хочу с начала» (`app/learning_v2_placement*.ts`, `components/learning-v2/placement/**`): бесплатный, по 1 вопросу на тему урока (при ошибке ещё 2, засчитано 2 из 3), итог — «открыть» уроки 1…N−1 в прогрессе V2 без зачёта и звёзд (`…ProgressStore.open(…, 'placement_test')`); один раз на аккаунт (`learning_v2_not_from_start_used_v1`); экран за флагом `LEARNING_V2_PLACEMENT_UI_ENABLED = false` (кнопка пока ведёт в «Все уроки»); берутся только уроки до 22 и только выпущенные занятия.
Как каждый ответ влияет на этот экран:
- «Нет»: диагностика не меняется. Перенос вида идёт как обычно.
- «Да» (автозачёт): диагностика остаётся отдельной и не служит доказательством — доказательство это прогресс 32 классических уроков (порог 45 из 50, как в `exam_readiness.ts`). Экран почти не затронут: нужен новый код «классика → открыть уроки V2» (тот же `open`), возможно кнопка «Открыть новый курс» на итоге или в интро.
- «Через тест»: диагностика тоже остаётся отдельной (слияние нецелесообразно: другие вопросы, цена, смысл). Включается и доделывается V2-тест; со стороны диагностики максимум CTA на итоге. Проверить: кнопка «Не хочу с начала» показывается новичку (`newcomer`) и один раз — закончившая классику ученица может её не увидеть; и достигает ли тест (потолок 22 урока) ситуаций B1/B2 — это вопрос к команде V2, здесь не проверялось.
Ждёт ответа Q61: любые кнопки/ссылки из диагностики в V2, перенос данных классики в V2, слияние или удаление экрана. НЕ ждёт: всё из раздела 6 (шапки, интро, итог, пропуски, подписи, тексты).
