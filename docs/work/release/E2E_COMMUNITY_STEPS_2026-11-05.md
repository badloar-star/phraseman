# E2E «Сообщество» — сценарий для Сверки, 05.11

Кто пишет: Сайт. Билд: HEAD с `e40968d0b` и новее. Язык интерфейса — русский (проверка 9 языков — отдельным прогоном на «Оставить отклик» и «Понял»). Темы: каждый шаг в светлой и в тёмной.
Журнал для сверки цепочки: `[COMMUNITY-NOTICE]`, `[PACK-LIKE]`, `[OPT-UI] pack_like`, `[FC-SETUP-PREFS]` (поиск по префиксу).

## 0. Подготовка
- Аккаунт с интернетом, вкладка «Сообщество» → раздел «Наборы».
- Нужны наборы: A — чужой, с лайками > 0 и комментариями > 0; B — чужой, лайков > 0, комментариев 0; C — чужой, с тремя словами в `previewWords`; D — свой.
- Чистое состояние плашки: ключ `story_events_v1:community_notice_closed:<владелец>` отсутствует (новый профиль или сброс через dev-экран).

## 9. Критичные «НЕ»
- Плашка не возвращается после ✕ ни в этот день, ни через неделю, ни после перезапуска.
- Вибрации нет на открытии и долгом нажатии строк и плиток.
- В строке нет обводки-контейнера и мелких расшифровок под названием.
- Число лайков/комментариев не прыгает после ответа сервера (оптимистичное значение совпадает с серверным).
- Ни одного нового чтения Firebase на строку (проверка по счётчикам [CARDS-PERF] / журналу сети: строки каталога без запросов членства).
