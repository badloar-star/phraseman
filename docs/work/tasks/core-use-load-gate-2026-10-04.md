## Outcome
Одна реализация правила D158 вместо пяти копий «тихий повтор 5×20 с»: потолок одной загрузки 12 с, тихие повторы ~1/3/8 с (app/load_gate_config.ts), затем `exhausted` — экран показывает «Сейчас недоступно» + тихую «Попробовать снова»; при возврате в приложение повтор идёт сам. Успех сбрасывает счётчик.

## Architecture
Контракт хука: потребитель передаёт `status: 'loading' | 'ready' | 'error'` и `retry()`; `retry` обязан перевести статус в `'loading'` (иначе следующий таймер обгонит запрос). Хук: `error` → пауза бэкоффа → `retry`; `loading` дольше потолка → считается попыткой; повторы кончились → `exhausted: true`. `retryNow(source)` сбрасывает счётчик. Лог `[LOAD-GATE:<id>]` на каждую ветку.
