## Как читать

- **Сценарий:** вошедший (Google/Apple) человек возвращается раз в сутки, холодный старт до Главной и первые ~60 с.
  Все TTL ≤ 24 ч при таком ритме истекают — значит, считаем их как «сеть каждый старт».
- **Это оценка по коду, не замер.** Факт снимается dev-счётчиком `[FS-READS]` (`app/dev_firestore_read_counter.ts`,
  сводки в 10/30/60 с) на эмуляторе аккаунтом №2 — см. «Как подтвердить» внизу.
- «Чтения» — документы Firestore, включая чтения ВНУТРИ вызываемых функций (они тоже оплачиваются).
- Источник: **сеть** (get), **слушатель** (onSnapshot), **кэш** (диск/память, 0 чтений), **функция** (callable, чтения
  на сервере).
- «Отложено?» — уже ли идёт после первого кадра Главной.

## Как подтвердить фактом (утром, на эмуляторе, по слоту)

1. Сборка dev, аккаунт №2 (не №1), холодный старт, ничего не трогать 60 с.
2. В журнале — сводки `[FS-READS]` на 10/30/60 с: по коллекциям, по вызывающим функциям, живые слушатели.
3. Сверить с таблицей: строки, где факт расходится с оценкой больше чем вдвое, — первыми в разбор.
4. Чтения внутри функций `[FS-READS]` не видит (это сервер) — их брать из журнала функций/оценки выше.
