## Outcome

Человек, который учит немецкий или французский, получает в играх задания на своём языке, собранные из
фраз своих уроков 1–8 (владелец 11.11.2026: «оно должно работать на всех языках», «фразы должны корректно
подбираться для режимов игры, без багов»). Мера успеха: у каждого задания ровно один верный ответ, слова —
только из пройденных уроков, сторож `tests/game_task_bank_de_fr.test.ts` зелёный по тексту вывода.

## Scope

In scope (новые файлы и две записи в реестре):
- `modules/games/bank/make_de_fr.ts` — сборщики заданий (индексы считает код, а не автор);
- `modules/games/bank/{odd_word,sort,exact,listen,memory,hunt,order}_{de,fr}.ts`, `forms_de.ts`;
- `modules/games/bank/index.ts` — только свои импорты и записи `de`, `fr`;
- `tests/game_task_bank_de_fr.test.ts` — программная проверка банка по данным уроков.

Out of scope: файлы правил `modules/games/*_core.ts`, `task_source.ts`, `warmup_state.ts`, экраны
`app/game_*.tsx`, банки других языков (`*_en.ts`, `*_es.ts`, `*_it.ts`, `make_es_it.ts`), уроки 9+,
переводы пояснений на другие языки интерфейса, `forms_fr.ts` (см. ниже «Что не сделано»).

## Architecture

No architecture change: банк — чистые данные с типами из файлов правил. Язык подключается одной записью
в реестре `GAME_BANKS`; подбор заданий и экраны не меняются. Инвариант: задание урока N использует только
слова уроков 1..N; произносимая фраза «На слух» — дословная фраза урока N.

## Security and privacy

Не применимо: статические учебные тексты, нет ввода пользователя, сети, хранения и личных данных.

## Technical debt

- Contain: пояснения только на русском. Выход — решение владельца о переводе, когда игры откроют для
  других языков интерфейса (ведёт сессия игр).
- Contain: «ровно один верный ответ» и «порядок реплик однозначен» машина проверяет только по совпадению
  с фразами уроков; смысловая вычитка ручная, сомнения — в разделе ниже.
- Contain: сборщики `make_de_fr.ts` повторяют часть `make_es_it.ts` соседней сессии (её файл не трогаю).
  Выход — после слияния обеих работ свести в один сборщик (ведёт сессия игр).

## Что не сделано и почему

- «Собери диалог»: немецкий уроки 1–3 и французский уроки 1–2 — заданий нет. В этих уроках одни утверждения
  (вопросы появляются в немецком с урока 5, во французском с урока 3), слов «да / нет / тоже / он / она» ещё
  нет — порядок реплик не получается однозначным. До этих уроков игра у языка просто не показывается.
- `forms_fr.ts` не делался. У французского нет привычной тройки «три формы»: ближайший аналог — пара
  «начальная форма — форма прошедшего» (prendre — pris), но это уже другая игра (две ячейки, не три), а
  подписать ячейки без терминов нельзя. Нужно отдельное решение владельца, делать ли такую игру.

## Вне рамок задачи, но мешает (экран не мой)

- 🔴 «На слух» для немецкого и французского прочитает фразу АНГЛИЙСКИМ голосом. `app/game_quiz.tsx:134`
  вызывает `inferExpoSpeechLanguage(round.prompt.text)` без языка обучения, а для латиницы без подсказки
  функция возвращает английский (`hooks/use-audio.ts:148`). Нужно передать `studyTarget` вторым аргументом.
  То же касается испанского и итальянского. Экран `app/game_quiz.tsx` по условию задачи не трогал.
- Французский «?» стоит через пробел. В словах заданий он приклеен к последнему слову неразрывным пробелом
  (`gare ?`), чтобы не стать отдельной кнопкой. В тексте карт, вариантов и реплик «Собери диалог» пробел
  обычный — если экран переносит строку перед «?», заменить там на неразрывный.
