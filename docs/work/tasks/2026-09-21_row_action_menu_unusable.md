# Меню «•••» в строках не раскрывается — действия недоступны

Governance-ID: TG-880C4B636BA1
Дата: 2026-09-21

Запрос владельца: «ПОЧЕМУ НЕТ КНОПКИ УДАЛИТЬ СООБЩЕНИЕ», ранее — «это
выпадающее не раскрывается, оно обрезано».

## Диагноз

Кнопка удаления ЕСТЬ в коде (`legacy.html:34246`, `data-am-act="delete"`, 🗑).
В строке сообщения четыре кнопки: Отклик, Изменить, Вкл/Выкл, Удалить.

`collapseActionGroup` (`legacy.html:54338`) сворачивает группу действий, если
кнопок больше двух: одна остаётся снаружи, остальные уходят в `<details>` с
меткой «•••». На скриншоте владельца видно ровно это: «Отклик» + «•••».

Кнопка не пропала — она внутри меню, а меню не раскрывается и обрезается.
Проблема общая для всех списков админки (сообщения, наборы, заявки,
сертификаты, рефералы), а не только для сообщений.

## Что уже пробовали и почему это не сработало

В коммите `30b341567` я поднял меню через
`.report-card:has(.pm-v4-action-menu[open]) { position:relative; z-index:2999 }`.
Смена `position` у карточек СЛОМАЛА раскладку списка («СЛОМАЛСЯ СПИСОК, ОН НЕ
ВИДЕН ПОЛНОСТЬЮ»), правило откачено в `d21bee3f4`.

Вывод: `position` элементов раскладки трогать нельзя.

## Outcome

Меню «•••» раскрывается и полностью видно во всех списках админки; удаление,
изменение и вкл/выкл доступны в один клик по меню.

## Scope

### Правится
- `admin/v2/legacy.html` — CSS контейнеров списков и меню.

### НЕ трогается
- `position` карточек списка — именно это сломало раскладку.
- Разметка строк и обработчики действий: они исправны.

## Architecture

Меню обрезается, потому что у контейнера списка (или его предка) стоит
`overflow`, отсекающий абсолютно позиционированный попап.

Решение — снять отсечение у контейнеров списков (`overflow: visible`), не
трогая `position` строк. Если отсечение нужно для горизонтальной прокрутки,
применяется `overflow-x: auto; overflow-y: visible`.

Почему не портал: перенос узла в `body` потребовал бы ручного позиционирования
и синхронизации при прокрутке — больше кода и больше мест, где ломаться.
Сначала пробуем минимальное CSS-решение и проверяем живым прогоном.
