# Примеры, не установленная конфигурация
Сверить существующие project/user config и актуальную документацию W1–W4. Слить нужные поля вручную; не перезаписывать конфиг проекта. `.codex/agents/` поддерживается соответствующими локальными клиентами. Доступность модели проверяется в аккаунте.

Пути в этом архиве `codex_examples/` специально не названы `.codex/`: автоматической активации нет. Для маленькой задачи не запускать всех reviewers. Основной поток — единственный writer; до двух подагентов — только чтение. В каждом отчёте записывать фактическую модель/effort, не только рекомендованные.
