## Outcome
Список добавленных после коммита 7f569e653 литералов цвета (#hex, rgb/rgba, white/black/named) и обводок контейнеров в app/components/hooks. Каждое место: осознанное (скрим, тень, dev) получает пометку theme-exempt с причиной, остальное в своих файлах переводится на токены темы, в чужих уходит списком владельцу и координатору.

## Scope
Скрипт разбора diff (временный, вне репозитория), правки только в файлах, где нет чужих незакоммиченных правок и где место моё (components общие); отчёт в docs/phraseman-2.0. Экраны Дизайна, Codex и Авторизации — только список.

## Architecture
`git diff -U0 7f569e653..HEAD -- app components hooks`; строки с добавленным цветом или border-свойством, без комментариев, тестов, dev-файлов и уже помеченных исключений. Замена идёт на токены `g`/`t` (text, secondary, opaqueControl, accentGraphic и т. д.), а не на новые литералы.

## Security and privacy
Только цвета и стили; данные не затрагиваются.

## Technical debt
Часть литералов может быть законной (скрим, тень, градиенты арта); их помечаем, а не переписываем. Существующие ратчеты theme_hardcoded_colors_ratchet и shadow_style_no_container_borders прогоняются при свободной памяти.

## Verification
Повторный разбор diff после правок; точечный прогон двух ратчетов по слоту светофора при памяти не ниже 3 ГБ.

## Rollback
git revert коммитов зачистки по отдельности.
