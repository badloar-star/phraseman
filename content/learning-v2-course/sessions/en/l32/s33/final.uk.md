# Урок 32 · Заняття 33 — Знаходимо Бена за підказками

**Ситуація.** Ви з Анною шукаєте Бена в будинку й пояснюєте свої висновки.

**Що ви опануєте:** поєднувати спостереження й висновок із so, обираючи must, might або can’t за змістом.
**Нові слова:** —
**Повторюємо знайомі слова:** coat, window, shoes, door

## Інтро 1

### Ознака й упевнений висновок

Ви шукаєте Бена в будинку й бачите його пальто, без якого він зазвичай далеко не йде: His coat is here, so he must be nearby — його пальто тут, отже, він, напевно, поблизу. Складіть His coat is here + so + he must be nearby. До so назвіть спостереження, після so — свій упевнений висновок із must.

**Виберіть фразу для цієї ситуації.**

- ✅ **His coat is here, so he must be nearby.**
- ❌ His coat is here, so he must is nearby. — *Після must потрібна форма be.*
- ❌ His coat is here, so he must to be nearby. — *Після must не ставимо to.*

---

## Інтро 2

### Ознака й можливе пояснення

Ви помічаєте відчинене вікно в кімнаті, де ще не були: The window is open, so the room might be cold — вікно відчинене, тому в кімнаті може бути холодно. Складіть The window is open + so + the room might be cold. Ви бачите вікно, але температуру ще не перевірили. Тому після so називаєте лише можливість із might.

**Виберіть фразу для цієї ситуації.**

- ✅ **The window is open, so the room might be cold.**
- ❌ The window is open, so the room might is cold. — *Після might тут потрібна форма be.*
- ❌ The window is open, so the room might to be cold. — *Після might не ставимо to.*

---

## Інтро 3

### Ознака виключає варіант

Анна припускає, що Бен нагорі, але ви зараз бачите його у дворі: I can see him outside, so he can’t be upstairs — я бачу його надворі, отже, він не може бути нагорі. Складіть I can see him outside + so + he can’t be upstairs. Спостереження виключає другий варіант, тому після so використовуємо can’t.

**Виберіть фразу для цієї ситуації.**

- ✅ **I can see him outside, so he can't be upstairs.**
- ❌ I can see him outside, so he can't is upstairs. — *Після can’t потрібна форма be.*
- ❌ I can see him outside, so he can't to be upstairs. — *Після can’t не ставимо to.*
