Прогон состояний

Или руками: A/B-кнопки на карточках прослушивают каждое слово отдельно (не участвуют в ответе); центральная play-кнопка проигрывает раунд по фиксированной последовательности sheep → ship → sheep; тап по карточке выбирает ответ; «Проверить» завершает раунд. После третьего раунда — итоговая полоса «Пары различены: N из 3» вместо обычного фидбека.

Спецификация для RN (Reanimated 4)

Прогресс-кольцо play (раунд)1400 мс · stroke-dashoffset linear
A/B прослушивание карточки900 мс · пульс кнопки, взаимоисключает play
Пульс play пока звучит раунд1100 мс loop · останов на audioend/blur
Выбор карточки140 мс · подъём + акцент-кольцо
«Проверить»: лок160 мс · клик-звук (кнопка)
Success: заливка карточки220 мс · background-crossfade
Полёт звезды за раунд700 мс · slide · тик-хаптик
Бамп счётчикаspring micro · scale 1.28
Пилюля серии: ярусы 2/4/6+накал градиента + искры
Золотая волна (серия 3/5/7)700 мс · перелив по экрану
Ошибка: тонировка карточки180 мс · без тряски/вибро
A/B replay в фидбеке900 мс каждое, без лимита повторов
Итог «N из 3»появление 240 мс, звёзды по одной ≤700 мс
Авто-«Дальше» (раунд 1-2)1400 мс · тап = сразу
Переход раундов240 мс · сдвиг + поворот 2.5°
Только transform / opacity / (кольцо: stroke-dashoffset, UI-тред через Reanimated). Полоса счёта раунда и полоса фидбека с зарезервированной высотой: первый кадр = финальная геометрия. В RN аудио: phrase_audio_player / TTS с раздельными clip id для A, B и раунда. Reduced motion: пульсации и волна выключены, заливка вместо wipe.
