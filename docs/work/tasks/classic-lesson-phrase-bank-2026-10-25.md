## Outcome

Пока человек проходит занятия Learning V2, на устройстве копится банк «Сборка фразы» этого урока: фраза, перевод по локалям, слова по порядку и лишние слова. Копится уже с этого обновления, даже если сам режим выйдет позже. Банк не меняет ни одно существующее поведение занятия, не читает сеть и Firestore.

## Scope

In scope:
- новое чистое ядро `app/learning_v2_lesson_phrase_bank_core_v1.ts` (проверка, проекция из задания «Сборка фразы», слияние, разбор, ключ);
- новое хранилище `app/learning_v2_lesson_phrase_bank_v1.ts` (AsyncStorage, ключ с хэшем аккаунта, блокировка перехода аккаунта — по образцу `learning_v2_unlocked_lesson_words_v1.ts`);
- одна точка записи в плеере `app/learning_v2_direct_session_player_v1.tsx` (эффект на показ задания «Сборка фразы», без изменения остальной логики);
- тесты: ядро (node) и сторож «плеер пишет в банк только для phrase_builder, не в предпросмотре».

Out of scope: сам режим, экран, кнопка, Plus-замок, награды, макет (идут отдельными шагами после макета), правки сервера и Firestore.

## Architecture

- Источник данных — learner-версия `modePayload` задания `phrase_builder` (`targetPhrase`, `localizedMeaning`, `orderedTokens`, `authoredDistractorTokens`); ничего нового с сервера не берётся, 0 чтений.
- Запись при ПОКАЗЕ задания (не при ответе): фраза в банке означает «ученик её встретил». Дедуп в памяти на занятие + дедуп по нормализованной фразе в хранилище.
- Ключ `learning-v2:phrase-bank:v1:<хэш аккаунта>:<язык>:lesson:<N>`; лимит 480 фраз на урок (~100 КБ), записи с невалидной формой отбрасываются при чтении.
- Запись не блокирует кадр: fire-and-forget после показа, ошибка уходит в журнал `[CLASSIC-BANK]`, занятие не страдает.
- Предпросмотр автора (`isAuthoringPreview`) в банк не пишет.

## Security and privacy

В банк идёт только учебный контент, который ученик уже видел; данных об ученике нет. Ключ изолирован хэшем аккаунта (как слова урока). Политика приватности не меняется. Облачной синхронизации нет.

## Technical debt

Уже пройденные до релиза занятия в банк не попадут (кэш V2 их не хранит) — решение по ним (фразы старого урока той же темы / подкачка) за владельцем, см. отчёт. Очистка при удалении аккаунта — как у слов урока (ключ с хэшем аккаунта); если нужен явный стёрт при выходе, это отдельный шаг с координатором.

## Verification

Тесты ядра (проекция, слияние, дубликат, лимит, битая запись, ключ); сторож-тест по источнику плеера; `npm run typecheck` на затронутых файлах; в эмуляторе: пройти занятие с «Сборкой фразы» и увидеть `[CLASSIC-BANK] added` в журнале.

## Rollback

Откат одного коммита; ключи в AsyncStorage безвредны (никто их не читает).
