# Испанский · Урок 5 · Занятие 19 — У Аны есть коробка

**Ситуация.** Собираетесь в поездку и называете, у кого есть нужные вещи.
**Что вы освоите:** поставить имя человека перед tiene вместо él или ella.
**Новые слова:** —
**Повторяем знакомые слова:** tener, caja, libro, llave.

## Интро 1

### Коробка Аны

Друзья ищут коробку для вещей. Скажите `Ana tiene una caja` — «У Аны есть коробка». Соберите `Ana` + `tiene` + `una caja`. Вместо ella называем Ану по имени. Форма tiene остаётся: говорим об одном другом человеке. Перед именем в этой фразе ничего добавлять не нужно.

**Скажите «У Аны есть коробка». Начните с Ana tiene.**

- ✅ **Ana tiene una caja.** — *Имя Ana заменяет ella, форма tiene сохраняется.*
- ❌ Ana tengo una caja. — *Tengo — для «я»; об Ане нужно tiene.*
- ❌ Ana tienes una caja. — *Здесь рассказываете об Ане, не обращаетесь к ней: tiene.*

## Интро 2

### Книга Педро

Друг спрашивает, у кого есть книга для дороги. Сообщите `Pedro tiene un libro` — «У Педро есть книга». Соберите `Pedro` + `tiene` + `un libro`. Имя Pedro занимает место él. Tiene подходит и к имени мужчины, и к имени женщины: форма относится к одному человеку, о котором рассказываем.

**Скажите «У Педро есть книга». Начните с Pedro tiene.**

- ✅ **Pedro tiene un libro.** — *Pedro + tiene + un libro.*
- ❌ Pedro tengo un libro. — *О другом человеке говорим tiene.*
- ❌ Pedro tiene una libro. — *Libro мужского рода: un.*

## Интро 3

### Ключ Аны

У двери друзья выясняют, у кого есть ключ. Скажите `Ana tiene una llave` — «У Аны есть ключ». Соберите `Ana` + `tiene` + `una llave`. Назвав имя, не добавляем следом ella: для этой простой фразы достаточно Ana. Перед llave ставим una по женскому роду испанского слова.

**Скажите «У Аны есть ключ». Начните с Ana tiene.**

- ✅ **Ana tiene una llave.** — *Имя уже называет человека; дальше tiene.*
- ❌ Ana tiene un llave. — *Llave женского рода: una.*
- ❌ Ana tengo una llave. — *С именем другого человека здесь нужна форма tiene.*
