Курс V2 — сколько голосовых осталось сегодня (D194)

Решение владельца D194, 15.10 · в код — когда курс V2 откроют после R1. Free — 3 голосовые попытки в день, один общий счётчик с голосом Диалогов (D165); Plus — без лимита и без цифры. Цифра остатка — на кнопке микрофона у всех голосовых заданий курса; попытка списывается в начале записи (как D165). Остаток 0 — на микрофоне бейдж PLUS, тап открывает пейвол Plus; остальные задания занятия проходятся без голоса. Экран — «Повтори и сравни» из learning-v2.html (тот же код и стиль), меняется только микрофон.
