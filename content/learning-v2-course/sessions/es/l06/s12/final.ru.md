# Испанский · Урок 6 · Занятие 12 — Здесь есть стулья?

**Ситуация.** Перед встречей уточняете, есть ли в комнате мебель для гостей.
**Что вы освоите:** спросить о наличии нескольких предметов с помощью ¿Hay...?
**Новые слова:** —
**Повторяем знакомые слова:** haber, silla, mesa, libro, aquí, allí.

## Интро 1

### Узнать о местах для гостей

Вы ещё не видели комнату и спрашиваете организатора `¿Hay sillas aquí?` — «Здесь есть стулья?» Соберите `¿Hay` + `sillas` + `aquí?`. Для нескольких предметов hay остаётся тем же. В этой общей фразе sillas стоит без артикля. Стульев может быть много, но дополнительная s к hay всё равно не нужна.

**Спросите «Здесь есть стулья?» без артикля. Начните с ¿Hay, место поставьте в конце.**

- ✅ **¿Hay sillas aquí?** — *¿Hay + sillas + aquí?*
- ❌ ¿Hay una sillas aquí? — *Una не подходит к sillas; здесь артикль не используем.*
- ❌ ¿Hay sillas allí? — *Спрашиваем «здесь» — aquí.*

## Интро 2

### Спросить о столах в другой комнате

Вы показываете на соседнюю комнату и спрашиваете `¿Hay mesas allí?` — «Там есть столы?» Соберите `¿Hay` + `mesas` + `allí?`. Allí означает «там». Вопрос сообщает, какие предметы и какое место вас интересуют; точное количество сейчас не требуется.

**Спросите «Там есть столы?» без артикля. Начните с ¿Hay, место поставьте в конце.**

- ✅ **¿Hay mesas allí?** — *¿Hay + mesas + allí?*
- ❌ ¿Hay una mesas allí? — *Перед mesas в этой фразе артикля нет.*
- ❌ ¿Hay mesas aquí? — *По ситуации спрашиваем «там» — allí.*

## Интро 3

### Узнать о книгах

Вы ищете, что почитать, и спрашиваете сотрудника комнаты отдыха `¿Hay libros aquí?` — «Здесь есть книги?» Соберите `¿Hay` + `libros` + `aquí?`. Сначала hay, затем название нескольких предметов, в конце место. Для вопроса нужны интонация и знаки ¿ ... ?, но сам порядок слов не меняется.

**Спросите «Здесь есть книги?» без артикля. Начните с ¿Hay, место поставьте в конце.**

- ✅ **¿Hay libros aquí?** — *¿Hay + libros + aquí?*
- ❌ ¿Hay un libros aquí? — *Un не подходит к libros; здесь артикля нет.*
- ❌ ¿Hay libros allí? — *Нужно «здесь» — aquí.*
