# Эффекты первого кадра Главной («Сцена»): что создаёт шейдеры и дешёвая замена (22.10.2026)

Источник: исходники (без запуска). Платформа — Android. Цена «относительная»: по типу эффекта и площади; точные доли даст трасса Perfetto (срезы компиляции шейдеров).

## Опись (по убыванию ожидаемой цены)

## Итого по первому кадру
~12 слоёв размытия теней (пп. 1; светлая тема) + 2–3 радиальных SVG (п. 3) + 4–6 линейных градиентов (пп. 2, 4, 5, 7, 8) + 2 больших растра героя (п. 6).
Главная доля, по типу эффекта, — тени с размытием (п. 1) и SVG-радиалы (п. 3); овердро фона (п. 5) и размер растров (п. 6) — на память и заполнение, не на компиляцию.

## Рекомендуемый порядок (меньше риска → больше выигрыша)
1. Авто-Lite для слабых устройств (RAM ≤ 3 ГБ или эмулятор): тени выключаются существующим переключателем; ноль новой графики.
2. Тени-картинки вместо размытия для 6 плит Главной (9-patch, один размер) — выигрыш самый большой, вид тот же.
3. Запечённый фон сцены (п. 3 + 4) — убирает SVG-холст и 3 слоя; 92 мелких файла генерируются скриптом из токенов.
4. Фон под сценой только ниже сцены (п. 5) и героя 512 px (п. 6).
5. Отложить на 2-й кадр: появление героя, плашка таб-бара `CapFill`, `sceneHalo`/`sceneEmber` — если п. 3 не делаем.

## Как измерить до/после (без эмулятора владельца)
Perfetto/`adb shell dumpsys gfxinfo <пакет> framestats`: время первого кадра Главной и срезы «shader compile» (`Skia`/`HWUI`); считать на слабом реальном устройстве (RAM 3 ГБ, API 29–30) и на API 31+. Выполняет Сверка/7 · ЭМУЛЯТОР по разрешению владельца.
