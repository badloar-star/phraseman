# Task packet: плитка «Мои ошибки» на Главной — текст по центру, иконка меньше, шрифт жирнее

Governance-ID: TG-9244AAF8FEB9
Status: Planned
Owner: сессия c6f9f576 (Claude Opus 5), по прямому заданию владельца
Related epic/enabler: none — косметическая правка по замечанию владельца

## Outcome

Владелец видит на Главной плитку, где:

- название («Мои ошибки» / имя последнего урока) стоит **по центру своего блока**,
  а не прижато к левому краю;
- картинка **не упирается в край слота** — размер уменьшен на 3 % (124 → 120),
  появляется воздух по краям;
- название набрано **жирнее** (вес 700 → 800), заметнее в иерархии плитки.

Мера успеха: на скриншоте Главной название визуально по центру между картинкой и
счётчиком, картинка не касается границ слота, вес текста заметно выше прежнего.
Геометрия плитки при этом не меняется — соседи не сдвигаются.

## Scope

In scope:

- `app/(tabs)/home.tsx` — «приоритетная карточка» Главной (один компонент на два
  состояния: «Мои ошибки» и «Последний урок», переключаются долгим нажатием):
  - `homeLastLessonArtSize` 124 → 120;
  - выравнивание блока названия (`FlowText` в контейнере `flex: 1`);
  - `fontWeight` названия 700 → 800.

Out of scope:

- размеры слота (`homeLastLessonArtSlotWidth/Height` 92×72) — не трогаем, иначе
  поедет высота плитки и сдвинутся соседние секции (layout stability);
- счётчик справа, значок и логика долгого нажатия;
- прочие плитки Главной и экран «Мои ошибки»;
- правка самих картинок-ассетов.

Решение владельца (подтверждено вопросом в сессии): правки применяются **к обоим
состояниям** плитки, чтобы переворот оставался бесшовным.

## Architecture

No architecture change — и вот почему: меняются только значения стилей внутри уже
существующей разметки. Не добавляется ни компонент, ни состояние, ни проп, ни
зависимость; границы модулей и поток данных прежние.

Инвариант, который обязан сохраниться: **плитка держит свой размер при перевороте.**
Высота задана `minHeight: 72` на внутреннем слое и слотом 92×72; размер картинки
на неё не влияет, потому что 120 > 72 и при `contentFit="contain"` картинка
по-прежнему вписывается по высоте слота. Поэтому уменьшение картинки не двигает
соседей — это и есть причина не трогать слот.

## Security and privacy

Не применяется: правка не касается данных. Не добавляется и не меняется ни одно
поле, ни сбор, ни хранение, ни передача; нет новых сервисов, разрешений, сетевых
вызовов и персональных данных. Privacy policy обновления не требует.

## Technical debt

- **Pay now.** `homeLastLessonArtSize = 124` при слоте 92×72 — картинка намеренно
  крупнее слота, из-за чего и упиралась в край. Значение приводится к 120 и
  снабжается комментарием «зачем», чтобы следующая сессия не вернула 124 как
  «круглое число».
- **Accept temporarily.** Размер картинки остаётся связанным для обоих состояний
  плитки (одна константа). Владелец 2026-09-21 сознательно выбрал общий размер
  ради бесшовного переворота. Владелец: он же; пересмотр — если состояния начнут
  расходиться визуально; потолок влияния: одна плитка на Главной.

Силентного долга не создаётся.

## Verification

Детерминированные проверки:

1. `npx tsc` точечно по затронутому файлу — ошибок в `app/(tabs)/home.tsx` нет.
   (Полный прогон сейчас недоступен: чужая синтаксическая ошибка в
   `app/lesson_menu.tsx` из параллельной сессии и нехватка памяти на машине.)
2. Сторож стабильности вёрстки:
   `npx jest tests/layout_stability_contract.test.ts --runInBand --watchman=false`
   — плитка не должна попасть в baseline как новая нестабильность.
3. Запрет владельца: в правке нет `adjustsFontSizeToFit`, нет `borderWidth`/
   `borderColor`, нет подписи-расшифровки мелкими буквами.

Ручная проверка (владелец, на устройстве): открыть Главную → название по центру,
картинка с воздухом по краям, шрифт жирнее; долгим нажатием переключить состояние
— плитка не меняет размер, соседи не прыгают.

Артефакт: скриншот Главной до/после.

Доступность: `accessibilityLabel` и `accessibilityHint` плитки не меняются;
кегль названия (`Math.max(15, f.body)`) не уменьшается, поэтому читаемость и
поддержка крупного системного шрифта не страдают.

## Rollback

Полностью обратимо, миграций и данных нет: вернуть три значения в
`app/(tabs)/home.tsx` — `homeLastLessonArtSize` 120 → 124, выравнивание блока
названия убрать, `fontWeight` 800 → 700. Пользовательские данные и права не
затрагиваются, откат не может ничего потерять.
