# Англійська · Урок 18 · Заняття 18 — Порівняти засоби для дому

**Ситуація.** Ви порівнюєте вибрані речі й помічаєте однакові якості.

**Що ви опануєте:** as + adjective + as
**Нові слова:** fabric softener, stain remover, laundry detergent, cleaning spray

## Інтро 1

### Однакова якість 1

fabric softener — кондиціонер для білизни. stain remover — плямовивідник. Вибрана пара має однакову якість або ціну. Використовуємо as + звичайний прикметник + as: as cheap as.

**Виберіть фразу для цієї ситуації.**

- ✅ **This fabric softener is as cheap as yours.**
- ❌ This fabric softener is as cheaper as yours. — *У конструкції рівності потрібна звичайна форма cheap.*
- ❌ This fabric softener is as cheap than yours. — *Потрібні два as: as … as.*
