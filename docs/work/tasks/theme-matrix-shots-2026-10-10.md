## 3. Как переключать тему (одинаково для всех состояний)

1. Открыть экран «Темы»: `adb shell am start -W -a android.intent.action.VIEW -d "phraseman://settings_themes" app.phraseman`
2. Оформление (тёмное/светлое): кнопки `testID=theme-appearance-dark` / `theme-appearance-light` (справа сверху).
3. Тема: тап по строке `testID=theme-tile-<id темы>` (например `theme-tile-grad_aurora`, `theme-tile-rose`). Применяется сразу, мерцания быть не должно (если есть — снимок и в INBOX).
4. Насыщенность: ползунок `testID=theme-intensity-slider`; перетащить до нужного положения (левый край = 0 %, правый = 100 %, шаг 5 %). Точное значение видно в логе бандлера: строка `[THEME-INTENSITY] commit { saved: … }` — сверять с таблицей.
5. Выйти кнопкой «Назад» (`themes-back`) и открыть первый экран из таблицы.
Состояние сохраняется между запусками (хранилище `liquid_glass_theme`, `liquid_glass_intensity`, `liquid_glass_appearance`), перезапуск приложения тему не сбрасывает.
