## Дыры — что нужно Learning V2

1. **Урок 14** — нет вопроса на главную тему. Нужны пропуски, где выбор между процессом и событием, например
   «I ___ my boots when you called.» → `was cleaning` / `cleaned` / `am cleaning`, и «She was cooking ___ I was talking.» → `while` / `when`.
   Минимум 3 (лучше по 1 на «was + -ing», «when + прошлое», «while»). Пока их нет — для урока 14 брать вопросы-вопросы
   «Were / Are / Did …ing?» (их 16, проверяют was / were в процессе), но это слабее.
2. **Урок 15** — нужны пропуски на выбор формы по смыслу: «Решили сами» → `am going to renew` / `am renewing`,
   «Договорились на пятницу» → `are paying` / `are going to pay`. Сейчас все 96 — скрепка am / is / are.
3. **Урок 2** — вопросительное слово (Who / What / Where) есть в одном задании (l02/s25 i08). Если тест должен проверять и его — нужно ещё 2.
4. **Урок 3** — в отбор не брать «Is / Am / Are» из занятий 1–8 (тема урока 2); годные — a / an / the (l03/s09–s16, s41–s48).
5. **Урок 9** — не брать «Завершите просьбу не открывать / не трогать…» (ответ open / touch — тема урока 8).
