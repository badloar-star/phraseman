## Как читать

- **Dev-способ** = параметр `phraseman://dev_state?...&next=<путь>` (app/dev_state_fixtures.ts), либо dev-маршрут `phraseman://dev_moments_preview?state=...` (app/dev_moments_preview.tsx), либо Dev Hub / motion_showcase. Все только в dev-сборке (`__DEV__ && !IS_STORE_RELEASE`), в стор-сборке их нет.
- **Моменты v3** (m01–m21) показываются только при `moments=v3` (удалённый флаг `moments_v3` или `dev_state?moments=v3`).
- **Тест** = файл в tests/, который реально проверяет это окно (не просто упоминает имя). «Зонтичный» помечен отдельно.
- **RM** = Reduce Motion: «да» — обработка есть в самом файле или в общем слое (HybridAlertShell, HybridSheetShell, use_reward_impact_hybrid), «нет» — не найдена.
- Арбитр окон = `useOverlayVisible('<ключ>')` (components/OverlayArbiter.tsx): окна ждут очереди и не накладываются.
