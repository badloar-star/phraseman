Jesse rewrite for `conjunction_logic`.

## Scope

- Category: `conjunction`
- Status: `active`
- Priority: `16`
- Locales: `ru`, `uk`, `es`
- Main contrast: `and`, `but`, `because`, `so`, `if`, `when`, `although`

## Learner problem

The learner chooses connectors by dictionary translation instead of the relationship between two sentence parts. The rewrite teaches the connector as a logic signal:

- `and` adds
- `but` turns against expectation
- `because` gives the reason
- `so` gives the result
- `if` sets a condition
- `when` points to time
- `although` keeps the action despite an obstacle

## Contract anchors

- `conj_contrast_001`: wrong `so` feedback contains `because`.
- `conj_contrast_002`: wrong `because` feedback contains `so`.
- `conj_contrast_005`: wrong `If` feedback contains `when`.
