# Рекорды этажей — утверждено владельцем 28 октября 2026

Рекорд заменяет личное место в левой колонке. Размер башни и тройки участников
сохраняется. Номера этажей на башню не добавляются. Подробности и запуск — в шторке.

Правила: одна одинаковая специальная попытка выбранного этажа для всех участников
комнаты текущей недели. Только 10/10; меньшее время выигрывает, равенство сохраняет
владельца. Личный лучший результат хранится отдельно. Никаких изменений обычного
прогресса, недельных очков или наград.

План и критерии приёмки:
1. Общий чистый контракт: фиксированный набор, проверка всех ответов, строгое сравнение.
2. Сервер: каноническая личность и членство, текущая неделя, атомарное обновление,
   повтор отправки безопасен, прямые клиентские записи закрыты.
3. Клиент: отдельная попытка без вызова обычного игрового раннера, состояния загрузки
   и недоступности не трактуются как отсутствие рекорда; смена аккаунта сбрасывает данные.
4. Компактный блок и шторка, локальные проверки типов и целевые тесты.

Публикация Firebase и выпуск приложения не входят в локальную реализацию.

Реализация:
- `SpireFloorRecord` занимает прежнюю строку личного места: 58 dp, либо 52 dp в
  существующем компактном режиме. Башня, тройка участников и расчёт компоновки сохранены.
  Длинные подписи раскрываются полностью в шторке и accessibility label; используется
  явный семантический ClampedText, список разрешённых потребителей дополнен этой строкой.
- Отдельный `SpireRecordAttempt` использует только отображение заданий, без обычного
  раннера, энергии, прогресса, золотых заданий, недельных очков и наград.
- У всех один фиксированный набор: первый набор первой ступени выбранного физического
  этажа (1–15). Отпечаток пакета закрепляется для комнаты на неделю. Пересборка пакета
  с другим отпечатком закрывает новые попытки вместо сравнения разных заданий.
- Время: после отсчёта, с появления первого задания до последнего ответа, без пауз;
  фон входит во время. Это явно указано перед запуском. Неверный ответ завершает попытку.
- Callable проверяет каноническую личность, членство, неделю, набор и все ответы.
  Личные лучшие и общий рекорд обновляются в транзакции. Подтверждённая попытка получает
  неизменяемый результат; повторная отправка не создаёт повторного результата.
- Три коллекции закрыты прямым клиентским чтениям/записям. Личные данные и владение
  рекордом очищаются при удалении аккаунта. Джарвис эти коллекции не читает; guard обновлён.

Граница проверки: ответы сервер перепроверяет, но длительность измеряет клиент
  с серверным ограничением по времени жизни попытки. Это не защита от модифицированного
  клиента. На реальном устройстве и в опубликованном Firebase новый сценарий ещё не проверен.
