# Task packet: отдельный ключ для новой части «Лесенки приглашений» (150)

## Outcome
Старый ключ `referral_ladder_enabled` в бою включён с 146 и остаётся как есть (экран лесенки). Новая часть 150 — истории лесенки у кольца аватарки и текст приглашения с обещанием «500 монет каждому» — переезжает на новый ключ `referral_ladder_v2_enabled` с дефолтом ВЫКЛ, чтобы сборка 150 не показала сырое.

## Scope
`app/remote_flags.ts` (имя и дефолт ключа), `app/referral_ladder_flag.ts` (чтение и хук v2), `app/referral_invite_share.ts` (программа приглашения), `modules/story_events/use_referral_ladder_story.ts` (история). Экраны `referrals.tsx` и `friends.tsx` остаются на старом ключе. Боевой remote config не трогается.

## Architecture
`isReferralLadderV2Enabled()` читает `getRemoteBool('referral_ladder_v2_enabled')` (нет ключа = выключено). Без v2 текст приглашения остаётся прежним («roulette») и история не показывается. Включение — только владельцем через Пульт, после проверки сервера и устройства.

## Security and privacy
Данные не добавляются. Обещание монет в тексте не уходит наружу без включённого ключа.

## Technical debt
Два ключа одной фичи; когда лесенка станет окончательной, ключи нужно слить и удалить v2.

## Verification
Тест: дефолт v2 выключен; без v2 приглашение «roulette» и история отключена; старый ключ экран лесенки не затрагивает.
