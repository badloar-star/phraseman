## Outcome

1. На экране «Сохранённые» текст карточки (фраза и перевод) ВСЕГДА помещается целиком на любой позиции ползунка размера: кегль считается от ширины карточки пропорционально шагу, перенос по словам без многоточия, карточка растёт по высоте под текст. `adjustsFontSizeToFit` не используется. Длинные фразы из реального набора проверены на всех шагах.
2. При первом открытии (и после сброса) экран показывает ГОРИЗОНТАЛЬНЫЕ карточки на всю ширину (крайнее положение ползунка: «EN · фраза · перевод · звук · ⋯»). Если человек сам сменил размер — его выбор запоминается.
3. Карточки «как на макете»: диагональный градиент цвета темы внутри карточки через почти чёрный, стекло, блик по кромке, свечение в углу, точки силы слова слева снизу, радиус по масштабу.
4. Журнал `[SAVED-CARDS-SIZE]`: шаг, ширина, кегль, высота, обрезка да/нет.

## Scope

In scope: `components/cards-grid/*` (раскладка, галерея, шаг по умолчанию, запоминание), `app/flashcards/CollectionGalleryView.tsx` (данные точек, шаг поиска), тесты галереи, снимки эмулятора и макета на трёх шагах.
Out of scope: серверная часть, содержимое наборов, сами макеты (эталон только читаем), хаб «Карточки», экран набора вне галереи.

## Architecture

Плитка получает геометрию по каждому из четырёх шагов (x, y, w, h), посчитанную на JS из карточек и ширины: высота ряда — максимум оценённых высот его карточек (оценка строк — консервативная, по таблице ширин символов), поэтому плитка всегда с запасом, а не обрезается. Кегль шага — пропорционален ширине плитки. Морф между шагами использует те же геометрии. Окно отрисовки и опора щипка считаются по верхам рядов. Градиент и блик — SVG/LinearGradient внутри плитки на токенах темы; точки — из силы слова карточки.

## Security and privacy

Данных не собираем и не передаём; шаг масштаба уже хранится локально в AsyncStorage (ключ `fc_gallery_step_v1`), новых хранилищ нет. Политика конфиденциальности не затрагивается.

## Technical debt

Оценка высоты текста — эвристика (таблица ширин символов), а не точное измерение: она намеренно с запасом, чтобы никогда не резать; точное измерение для сотен плиток дороже. Если на каких-то языках окажется заметный лишний запас — подкрутить коэффициент.
