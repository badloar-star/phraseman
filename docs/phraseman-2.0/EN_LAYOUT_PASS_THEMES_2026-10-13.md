# Английский интерфейс 16.10 — проход по рискам раскладки (Темы, 13.10)

Исполнитель: сессия «4 · ТЕМЫ 2.0». Источники: `EN_LAYOUT_RISKS_R1_2026-10-13.md` (Дизайн, статический разбор ≈2 900 пар ru/en), `EN_PASS_RESULT_R1_2026-10-13.md` и `EN_PASS_RESULT_R1_AUTH_2026-10-13.md` (45 кадров Сверки/Авторизации). Метод: пройден каждый риск из обоих документов, сверен с кодом и с моими правками дня (minHeight, рельсы, «Пик»).

## Итог
Правки раскладки для английского **не требуются**: ни один английский текст не обрезается, длинные строки переносятся в контейнерах с `flex`/`minWidth: 0`/`minHeight`. Все кнопки и пилюли с переводимой подписью уже на `minHeight`, а не на фиксированной высоте (7909da4b8, e26ca9047, 992d2b732; см. R1_LARGE_FONT_360_AUDIT) — это запас и для английского.
