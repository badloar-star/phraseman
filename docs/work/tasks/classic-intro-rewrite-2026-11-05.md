## Outcome

Владелец запретил во всех интро уроков сценки «Представь ситуацию». Интро классики переписываются в стиле старого курса: подробный разбор по шагам — правило, когда применяется, типичные ошибки, 3–5 примеров с переводом, без сценок. Пользователь выигрывает: интро понятны без сценария, без сюжетных вставок. Мерка: в `modules/classic-courses/{en,es,fr,de,it}/intro.json` ни одного заголовка и текста «Представь ситуацию» (и аналогов в других языках), сторож запрещённых начал Теории зелёный, пачками по 3–4 урока с коммитом на пачку.

## Scope

In scope: файлы `modules/classic-courses/<lang>/intro.json` (карточки concept/formula/practice в 32 уроках × 5 языков); русские тексты (titleRU/textRU/linesRU) пишет эта сессия, украинские (titleUK/textUK/linesUK) — Переводчик.
Out of scope: слой правок `docs/work/classic_translation_fixes_*.json` (правит только Переводчик); курсы Learning V2 (сессия Теории); код приложения; сторож Теории (его правит Теория).

## Architecture

Граница: данные интро → рантайм классики (`modules/classic-courses`). Формат карточки сохраняется: `kind`, `lessonId`, `order`, `screenId`, `examplesById`, `titleRU`, `textRU`, `linesRU`, и украинская пара. Меняется только текст; структура, id и порядок не трогаются. Инвариант: число карточек на урок не меняется (3).

## Security and privacy

Не применимо: только учебный текст, персональных данных и сетевых вызовов нет.
