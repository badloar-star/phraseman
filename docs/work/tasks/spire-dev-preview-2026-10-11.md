# Шпиль — DEV-превью экранов на моках (без серверного config.enabled)

Governance-ID: TG-59DCF2A6C246

## Outcome
Эмулятор и Сверка снимают все состояния экранов Шпиля (хаб, комната, ступень, итоги, пустое, ошибка) рядом с `spire.html`, не дожидаясь серверного включения. В релизе маршрута нет.

## Scope
Новый маршрут `app/dev_spire_preview.tsx` (только `__DEV__ && !IS_STORE_RELEASE`), моки состояний `components/spire/spire_preview_fixtures.ts`, запись в Dev Hub, сторож «в релизе роута нет».

## Architecture
Экраны Шпиля берут данные из хука игры за серверным замком. Превью рисует те же компоненты на готовых моках через пропсы / локальную подмену источника, не трогая боевой путь.

## Security and privacy
Моки не содержат реальных данных; сети и записей нет; в релизной сборке маршрут отсутствует.

## Technical debt
Не добавляется: файлы превью изолированы и охраняются сторожем.

## Verification
Типы, сторож релиза, точечные тесты Шпиля, снимки Сверки.

## Rollback
Удалить маршрут и фикстуры.
