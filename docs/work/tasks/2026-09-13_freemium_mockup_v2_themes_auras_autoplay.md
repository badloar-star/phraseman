## Architecture

- Темы: цена в жемчужинах уходит из каталога/экрана; доступ = Indigo для всех,
  остальные — по Plus (через существующий `useFeatureAccess`/gate тем), без
  нового флага. Купленные ранее темы остаются у владельцев (грандфазер по
  инвентарю, ничего не отбираем).
- Ауры: одна аура помечается `plusOnly`, остальные получают цену в жемчужинах
  и покупаются через существующую композитную операцию (debit+grant),
  идемпотентно, по Economy Constitution.
- Автовоспроизведение: удаление контекста из union-типа заставит TS показать
  все Record-ы, где он обязателен — правим их все в одном коммите.
