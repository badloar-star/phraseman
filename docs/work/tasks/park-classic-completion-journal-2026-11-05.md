# Task packet: парковка «журнала завершения урока» (classic_completion_*)

## Outcome
Решение координатора (06.11, «вариант Б»): сирота «журнал завершения урока» (правки `app/lesson1.tsx` +140/−34 и untracked `classic_completion_*`) не заказана владельцем, требует 6–9 часов с E2E и рискованна для сборки 150. Нужно, чтобы Metro Эмулятора, собирающий из рабочего дерева, показывал кадры ровно с HEAD.

## Scope
- Сохранить: патч девяти изменённых файлов (`lesson1`, `lesson_complete`, `lesson_lock_system`, `lesson_screen_bootstrap`, `medal_utils`, `progress_events_client`, три теста), вырезанные блоки журнала из смешанных файлов (`cloud_sync.ts` — ключи очереди, `_layout.tsx` — эффект восстановления), копии 21 untracked файла.
- Вернуть к HEAD / удалить из дерева только перечисленное; чужие правки в смешанных файлах не трогать.
- Не затрагиваются: другие сироты (витрина визитки, атрибуция покупок, коллекционные предметы Пика — уже отдельно).

## Architecture
Парковка = копия файлов + патч в репозитории; дерево приводится к HEAD. Возврат — `git apply` патча и копирование untracked обратно (в README).
