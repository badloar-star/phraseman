# PM-134 — кнопка → назначение во всех режимах тренировки

Задача: PM-134 «Удалить неиспользуемые controls во всех режимах», критерий A1 «по каждому control
указано назначение». Составлено 2026-10-04 сессией «Дизайн-QA и реестр» **по коду, HEAD `e47c1c04c`** (строка §5 про «Настройки» и итог обновлены 04.10 после abac0c627, HEAD `feada959a`),
без запуска приложения (кадры режимов уже есть в `design_gate/`, см. A2 в реестре).

Охват: четыре режима из шторки выбора тренировки (`app/flashcards/FlashcardsTrainingModeSheet.tsx`:
blitz, speaking, truefalse, recall), основной свайп-режим «Тренировка» (`/flashcards_swipe`) и
отработка ошибок (`app/mistake_practice_session.tsx`) — рецензент считал её четвёртым режимом.

Обозначения столбца «Нужна?»: **да** — у кнопки есть своё действие, которого нет у других;
**дубль** — то же действие, что у другой кнопки на экране; **a11y** — кнопка нужна, но описание
для экранного диктора неполное.

Общее для всех режимов (кроме ошибок): итог — общий экран завершения 2.0
(`app/flashcards/SessionResultScreen.tsx` → `components/completion/V2DoneScreen.tsx`).

| Кнопка итога | testID | Назначение | Нужна? |
|---|---|---|---|
| Крестик | — (`V2DoneScreen` close) | Закрыть итог = то же, что «Готово» (`onClose = onDone`) | да (стандартный выход сверху; системный жест тоже ведёт сюда) |
| «Готово» | `v2-done-primary` | Выйти из режима (`onDone`) | да |

## Итог для PM-134

- Назначение указано для каждой кнопки во всех 6 экранах режимов → **A1 закрывается этим документом**.
- **Лишняя кнопка найдена одна:** «Настройки» в шапке свайп-режима дублировала «Выйти из тренировки» —
  **снята в abac0c627** (04.10, сессия «Дизайн»; независимое ревью подтвердило по коду). Обработчик выхода из итога
  переименован `openSettings` → `exitFromResult`.
- Недочёты описаний для диктора (не лишние кнопки, но мешают A2 «настройки доступности не пропали»):
  метки `qa-fc-blitz-opt-N` и `qa-fc-blitz-pick-decks` в блице, кнопка сброса сборки и крестик без роли
  в отработке ошибок.
- Расхождение между режимами: «Выбрать наборы» в шапке «Вспомни» осталась, в блице и «Устно» убрана (D152).
- Текст «Скажи по-английски» в «Устно» зашит под английский язык изучения.
