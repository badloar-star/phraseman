## Architecture

**Геометрия взята ИЗ КОДА, а не придумана.** Вычитанные константы и расчёт для
экрана 390pt (iPhone 14/15):

Витрина — `app/flashcards/SavedTopCommunityPacks.tsx`:
- `COLS = 3`, `GAP = 10`, `TILE_RADIUS = 18`, `SHOWN = 10`;
- `tileW = floor((contentWidth - GAP*(COLS-1)) / COLS)` = `(358-20)/3` = **112px**;
- плитка **КВАДРАТНАЯ**: `height: width` (строка ~156) — не 16:9, как я рисовал;
- фон плитки `t.bgSurface` = **#17241A**, не bgCard;
- обложка — PNG-«веер» `iconSize = floor(width*0.92)` = **103px**, `contentFit: contain`,
  пропорция `PACK_FAN_ASPECT = 329/268`;
- бейдж числа карточек: `right:5, bottom:5`, `borderRadius:9`,
  `paddingH:6 paddingV:1`, фон `t.bgCard`, шрифт `max(10, round(labelSize*0.82))`
  = **11px вес 900**, цвет `t.textSecond`;
- галочка «в моих»: `right:5, top:5`, `borderRadius:999`, `padding:3`,
  фон `${t.accent}26`, иконка checkmark **11px**;
- `labelSize = max(11, min(f.caption=13, floor(112*0.13)=14))` = **13**;
- название: `marginTop:8`, `fontSize: labelSize+1` = **14px**, `lineHeight: labelSize+4` = **17**,
  вес **800**, по центру, `t.textPrimary`;
- автор: `marginTop:2`, `fontSize: max(10, labelSize-1)` = **12px**, вес 700,
  `t.textSecond` (#58CC89), по центру;
- соцбар: `marginTop:5`;
- заголовок витрины: `f.h2` = **18px**, вес **900**, `letterSpacing:0.1`,
  `lineHeight: round(18*1.25)` = **23**, `marginBottom:12`;
- контейнер витрины: `marginTop:10`, `marginBottom:18`;
- горизонтальный `ScrollView`, `marginHorizontal:-5`, `paddingHorizontal:5`, `gap:10`.

Соцбар плитки — `CommunityPackSocialBar.tsx`, ветка `isTile` (строка ~365):
- `flexDirection:row`, `justifyContent:center`, `gap:8`;
- внутри пары: `gap:3`; иконка **12px**; цифра **10px вес 700** цвет `t.textSecond`;
- сердце: `heart` при лайке (цвет `t.accent`), иначе `heart-outline` (`t.textMuted`);
- вторая пара — `people-outline` + число добавлений.

Полоса категорий — `FlashcardsCategoryBar.tsx`:

- пункт: `width:68`, `gap:2`; иконка **33px**; подпись **10px**,
  вес 600 активная / 400 обычная, `letterSpacing:0.1`;
- активный: цвет `t.textPrimary` + подчёркивание `bottom:-4, left:25%, right:25%,
  height:2, borderRadius:1`;
- `paddingTop:6, paddingBottom:4`.

Тема — `constants/theme.ts` → `DARK`:
`bgPrimary #030604`, `bgCard #101710`, `bgSurface #17241A`, `bgSurface2 #203028`,

## Security and privacy

Не применяется:
- статический HTML, без скриптов, сети и полей ввода;
- данные вымышленные, uid не показывается;
- обложки не грузятся с YouTube — CSS-фигуры; обращений к стороннему домену нет;
- нового сбора данных нет → политику приватности трогать не нужно.

Отметка на будущее: при реализации превью кадра пойдёт с `i.ytimg.com` (IP
пользователя уходит к Google) — тогда сверяться с политикой. Лайк пишет userId
в `pack_likes` — механизм уже существует и покрыт правилами Firestore.
