## Outcome

Держатели замка аккаунта в дев-сборке печатаются безымянными кадрами («?anon_0_»). Нужен скрипт, который берёт
файл пакета логов и через Metro /symbolicate превращает кадры бандла в «файл:строка». Для этого кадр должен
нести полный URL бандла (у lazy-бандлов чанков URL разный) — lockCallerTag печатает его целиком.
Плюс план (без правок) разбивки синхронной работы первого рендера Главной: home.tsx и (tabs)/_layout.tsx.

## Scope

- scripts/diag/symbolicate_pack.mjs (новый; только чтение файла пакета + POST на локальный Metro);
- app/account_generation.ts: сырые кадры — полный URL кадра со строкой:колонкой (без обрезки до 120 символов);
- docs/work/tasks/core-home-first-render-plan-2026-10-05.md — список синхронной работы со ссылками на строки.

## Architecture

Скрипт: node scripts/diag/symbolicate_pack.mjs <файл пакета> [--metro http://localhost:8081]; уникальные кадры
одним запросом; печать «кадр -> файл:строка (функция)» и копия пакета <файл>.symbolicated.txt с подстановкой.

## Security and privacy

Только локальный Metro; в кадрах нет данных пользователя.
