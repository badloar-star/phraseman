## Architecture

No architecture change. Удаляются только точки входа в две клиентские шторки; хук `useMistakeExplain` по-прежнему
возвращает `eli5`, но его никто не читает (мёртвая ветка до этапа B). Счётчик подсказок 50/50 не меняется:
`onConsumeExplainCredit` больше не вызывается из урока, потому что шторка «Объяснить» не открывается.

## Security and privacy

Сбор и передача данных только уменьшаются: два вида запросов к ИИ (упрощённый разбор и разбор фразы) клиент больше
не отправляет. Новых данных, прав, секретов нет. Текст согласия на ИИ упоминает обе функции — править вместе с этапом B.
