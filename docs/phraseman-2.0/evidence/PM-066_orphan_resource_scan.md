Модель: Sonnet 5. Разведочная задача (без правок кода, кроме отмеченного ниже).
Проверено: `git grep` по именам модулей, удалённых этой программой (avatar_select,
avatar_dna_studio, level_reward_spin*) в НЕ-код файлах, которые обычный скан по

## Найдено

1. **`package.json`: `expo-background-task: ~1.0.10` — осиротевшая native-зависимость.**
   Код, который её использовал, уже удалён (D47, комментарий в `app/_layout.tsx:1099`
   говорит «удалён целиком»). Проверено: ноль вызовов `BackgroundTask.*` где-либо в
   `app/**`/`hooks/**`/`modules/**`/`components/**`, пакет не зарегистрирован как
   Expo config-plugin в `app.json`. Кандидат на PM-066-A2 («native package удаляется
   только после проверки общих потребителей»).
   **Не удалено в этой сессии**: снятие native-зависимости требует `npm install`
   (обновление `package-lock.json`) и потенциально native-ребилда (EAS) — в
   экономном режиме без сборок это осознанно не делалось, чтобы не создать
   рассинхрон лока в общем git-дереве, где параллельно пишут другие сессии.
   Следующий шаг: одна сессия с правом на `npm install` убирает строку и коммитит
   обновлённый lock отдельно.

2. **`docs/phraseman-2.0/registries/screen_inventory.json`** всё ещё содержит
   записи/evidence-пути на удалённые `app/avatar_select.tsx` и
   `app/avatar_dna_studio.tsx` (маршруты `/avatar_select`, `/avatar_dna_studio`,
   строки evidence вида `app/avatar_select.tsx:1552`). Это данные аудита реестра
   2.0, не код и не билд-конфиг — не влияет на сборку/рантайм. Не тронуто:
   правка реестров требует `tools/render_views.py`/`tools/validate.py`
   (вне поручения «PROGRESS.md и tasks.json не редактировать», но тот же
   инструментарий регистров) — оставлено на усмотрение владельца/следующей сессии.
