Полноэкранных спиннеров и ранних `return` по загрузке нет. Крутилки только локальные: строка открываемого набора (FlashcardsCategoryHub), карточка ожидания на экране ранга (coin_rank). Заготовки (Skeleton) — Сохранённые, Мои наборы, «Из видео», хаб ошибок, отработка, лента видео, серия, достижения.
- ⚠ **Ядру:** деталь ошибки (app/mistake_detail.tsx) в первый кадр показывает только «‹», потом контент появляется разом (данные локальные, но это скачок геометрии). Лучше: брать черновик из строки списка, откуда пришли (мгновенно), а не заготовку.
