# Пакетная озвучка фраз для роликов

Локальная замена ElevenLabs на машине владельца. Список фраз на входе →
пронумерованные аудиофайлы в одной папке, одним и тем же голосом.

Зачем: для роликов MASON / LINGMAN / VIRAL нужно озвучивать по 300–500 фраз
за раз. Вручную в интерфейсе ComfyUI это часы кликов, и голос между запусками
«плывёт».

## Что нужно один раз

1. **Запустить ComfyUI** — `C:\ComfyUI\run_nvidia_gpu.bat`. Дождаться строки
   `To see the GUI go to: http://127.0.0.1:8188`.

2. **Положить образец голоса** в `C:\ComfyUI\ComfyUI\models\voices\`:

   ```
   Мой_голос.wav              — 10–30 секунд чистой речи, без музыки и шума
   Мой_голос.reference.txt    — текст, который в этой записи произнесён, слово в слово
   ```

   Имя файла (без расширения) и есть значение `--voice`.

   Расшифровка обязательна: движок сверяет звук с текстом, и без неё голос
   воспроизводится заметно хуже.

## Запуск

```bash
python tts_batch.py --phrases phrases.txt --out ./out --voice "Мой_голос" --language ru
```

Формат `phrases.txt` — одна фраза на строку. Пустые строки и строки с `#`
пропускаются и номер не занимают.

Результат: `out/001.wav`, `out/002.wav`, … в порядке строк файла.

## Ключи

| Ключ | Зачем |
|---|---|
| `--voice` | имя образца голоса (файл в `models/voices` без расширения) |
| `--engine` | движок: `chatterbox_23lang` (по умолчанию), `omnivoice`, `higgs_v3`, `moss` |
| `--language` | `ru`, `en`, `de`, `es`, `fr`, `it` |
| `--seed` | фиксирует голос между запусками; менять без нужды не стоит |
| `--resume` | продолжить прерванный батч: уже готовые файлы пропускаются |
| `--timeout` | секунд на одну фразу (по умолчанию 600) |

## Если что-то пошло не так

Упавшие фразы попадают в `out/_errors.txt` — номер, текст, причина. Повторить
только их: тот же запуск с `--resume`, готовые файлы он не тронет.

## Выбор движка

Все шесть языков владельца (RU/EN/DE/ES/FR/IT) закрывают четыре движка:

| Движок | Вес | Лицензия |
|---|---|---|
| **ChatterBox 23L** | 4,3 ГБ | MIT — без ограничений |
| **OmniVoice** | 3,7 ГБ | Apache-2.0 — без ограничений |
| Higgs Audio v3 | 8 ГБ | **Research and Non-Commercial** |
| MOSS-TTS | 8,5 + 6 ГБ | Apache-2.0 |

**Higgs Audio v3 нельзя применять для роликов, продвигающих платный продукт** —
лицензия запрещает коммерческое использование.

CosyVoice3 (нет немецкого и испанского) и Qwen3-TTS (нет русского и
итальянского) под эту задачу не подходят, хотя в обзорах их советуют часто.

## Про акцент

Публичных замеров «голос снят с русского — насколько чисто он звучит по-немецки»
не существует ни для одной модели. Выбор делается на слух: прогнать одну фразу
на всех шести языках через ChatterBox 23L и OmniVoice с одним образцом и
сравнить.

## Приватность

Образец голоса — биометрия. Хранится только локально, никуда не отправляется.
Клонировать допустимо свой голос или чужой с явного согласия его носителя.
