# Английский · Урок 17 · Занятие 48 — Покупки и возврат товара

**Ситуация.** Вы сравниваете условия магазинов, документы доставки и курсы валют перед покупкой за границей.

**Что вы освоите:** some / any + plural count noun or non-count noun
**Новые слова:** refund policy, return label, exchange rate, delivery note

## Интро 1

### Сообщить о наличии

refund policy — правила возврата денег. Вы сравнили условия возврата у нескольких магазинов. Refund policy → refund policies. Some ставим перед исчисляемым во множественном числе или неисчисляемым, когда сообщаем о некотором количестве.

**Выберите фразу для этой ситуации.**

- ✅ **We compared some refund policies.**
- ❌ We compared any refund policies. — *В утвердительном сообщении о некотором количестве используем some.*
- ❌ We compared a refund policies. — *A не ставится перед неисчисляемым или множественным числом.*

---

## Интро 2

### Полностью отрицать наличие

return label — почтовая этикетка для обратной отправки товара. Ни для одной посылки этикетки нет. Отрицайте наличие полностью. Return label → return labels. exchange rate — обменный курс валюты. Some используется с множественным числом исчисляемых и с неисчисляемыми. В отрицании со значением «никакого» обычно выбираем any.

**Выберите фразу для этой ситуации.**

- ✅ **We don't have any return labels.**
- ❌ We don't have some return labels. — *Здесь требуется полное отрицание или нейтральный вопрос о наличии: any. Some в вопросе возможно при другом ожидании говорящего, но здесь этого смысла нет.*
- ❌ We don't have a return labels. — *A не ставится перед неисчисляемым или множественным числом.*

---

## Интро 3

### Спросить без предположения

delivery note — документ со списком доставленных товаров. Вы не знаете, сохранились ли документы из посылок. Спросите нейтрально. Delivery note → delivery notes. В нейтральном вопросе обычно any. Some тоже встречается в вопросах: например, в предложении Would you like some tea? или когда ожидают «да». Поэтому учитывайте ситуацию, а не только вопросительный знак.

**Выберите фразу для этой ситуации.**

- ✅ **Do you have any delivery notes?**
- ❌ Do you have some delivery notes? — *Здесь требуется полное отрицание или нейтральный вопрос о наличии: any. Some в вопросе возможно при другом ожидании говорящего, но здесь этого смысла нет.*
- ❌ Do you have a delivery notes? — *A не ставится перед неисчисляемым или множественным числом.*
