## Architecture
Намерение = `{ owner, sessionId, amount, endedBy, mistakes, atMs }` в одном ключе AsyncStorage, уникально по
`owner + sessionId`.
- **Хост:** по одному намерению; ждёт чтения копилки → отметка «начислено» (как сейчас, до начисления) → начисление →
  намерение удаляется → `settle()` в фоне (сеть догоняет через долговечную очередь копилки).
- **Один id операции:** вход копилки берётся из одной функции `dialogueV2CoinPracticeRunesInput(sessionId)` и для экрана,
  и для хоста.
- **Сторож в корне:** модуль без тяжёлых импортов. При ВЫКЛ рендерит null и не читает диск. Хост грузится лениво внутри
  тихой ловушки ошибок — сбой хоста не уронит корень (урок 04ec8cd30).

## Security and privacy
Данных не добавляет: локальные записи на телефоне, те же монеты, тот же серверный зачёт. Firestore не трогается.

## Technical debt
- Выключение флага при лежащих намерениях их замораживает (не теряет): начислятся после повторного включения.
- Падение между отметкой и начислением теряет монеты, как и сейчас (сторона «не начислить дважды»).

## Verification
