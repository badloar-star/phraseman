# Языки интерфейса — зона Ядра (R1), 13.10

**Повод.** Слово владельца 13.10, переданное координатором: «исправить и починить интерфейс на других языках».

**Зона.** 19 файлов с находками из ~120 файлов зоны:
- старые уроки (`app/(tabs)/lessons.tsx`, `app/lesson*`, `components/lessons/`);
- теория (`components/theory/`);
- экзамен уровня (`components/level-exam/`);
- энергия (`components/energy/`, `EnergyBar`, `NoEnergyModal`);
- Шпиль (`app/spire/`, `components/spire/`);
- «Мои ошибки» (`app/mistake*`, `components/mistake-practice/`, `components/mistakes-panel/`);
- заметки о выпуске (`components/release_notes_copy.ts`).

Learning V2 (зона Codex) и чужие зоны не входят.

## Как проверял

1. **Сканер переводов** `scripts/scan_i18n_design_zone.mjs --json` по всему приложению, затем фильтр по файлам зоны. Он ищет два вида находок:
   - неполные языковые объекты (есть `ru`, но не все 9 языков);
   - кириллицу вне переводчика.
2. **Каждая найденная кириллица просмотрена глазами.** Сканер не узнаёт таблицы языков в виде кортежей и отдельных констант, поэтому большая часть находок — ложные.
3. **Английские слова в разметке.** Отдельный поиск по `JSX`, `label`, `title` и `accessibilityLabel` — сканер видит только кириллицу.
4. **Рантайм.** Строки `[I18N-FALLBACK]` во всех журналах прогонов `docs/phraseman-2.0/evidence/**` — экран попросил перевод, а его нет.

- **Чужая незакоммиченная правка.** В `app/lesson_menu.tsx` другая сессия поменяла `uk` подписи кнопки настроек: «Налаштування» → «Параметри». После этого храповик сканера показывает `lesson_menu.tsx: литералов 2 > 1`. Правка не моя, файл я не трогал — пусть автор зафиксирует базу или поправит.

  - `app/lesson_teaching_notes.ts`: не подключён; в нём `pickLang` без `en` с откатом на русский и немой `catch {}` в разборе списка просмотренных;
