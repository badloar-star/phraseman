## Technical debt

- Правила банков запрещают «?» во всех банках (задумано для урока 1). В главах про вопросы (l24 c2 «How long…?», l26 c2 «Have you…
  yet?») проверяется ответ на вопрос, а не сам вопрос. Снять запрет для уроков после введения вопросов — решение Learning V2.
- Сторож слов проверяет запасные ответы после нормализации, где однобуквенное «a» не отфильтровано, а в словаре его нет никогда:
  запасной ответ со словом «a» всегда красный. Поэтому у части заданий один эталон (сокращения движок раскрывает сам — I've, haven't
  засчитываются). Починка — в chapter_exam_v2_vocabulary.ts (фильтр однобуквенных и для запасных), решение Learning V2.
