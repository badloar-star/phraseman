## Подробно

### 1. Сохранить / убрать карточку
`components/AddToFlashcard.tsx` `handlePress`: закладка и анимация меняются на тапе (а); `inFlightRef` + `blockStaleStorageHydrationRef` — один проход и поздний ответ не затирает свежее (в); при отказе `[OPT-UI] card_save|card_remove rollback reason=…` + тост (б); после записи сверка с хранилищем без прыжка (д). Из раскрытой карточки: `flashcards_collection.tsx` `onToggleOpenedSave` — галочка сразу, `openedSaveInFlightRef`, откат + тост, пейвол при лимите. Из видео: `YoutubeVideoPhrases.save` — `savingIdsRef`, лог `[VIDEO-PHRASE-SAVE]`.

### 2. Добавить карточку в набор
`app/flashcards/ExpandedCardV2.tsx` `addTo` → `community_packs/localPackCardAdd.ts` `addCardToLocalPack`: запись только в локальный набор автора (хранилище устройства, без сервера, десятки мс); шторка закрывается после записи с тостом «Добавлено» (а — не сеть, ожидание незаметно); исходы `duplicate` / `failed` / исключение — разные тосты, кнопка снова свободна (б); список наборов в шторке грузится локально со скелетом строки, не на весь экран (г).
**Чего не было 🔧.** (в) замок был только состоянием `adding`: два тапа в одном кадре оба видели «свободно» и дважды писали карточку (спасал лишь дубль-чек по тексту). Теперь синхронный `addingRef`, снимается на всех исходах; лог `[OPT-UI] card_to_pack ignored reason=double_tap`.

### 3. Удалить карточку и «Вернуть»
`app/flashcards/useCollectionData.ts` `deleteCardById`: карточка исчезает до записи (а); `deletingCardIdsRef` — один проход на карточку (в); сбой возвращает только её на место + тост (б); «Вернуть» (в том числе для своих карточек) возвращает в тот же кадр, запись догоняет, при сбое перечитывает факт и говорит тостом (`[OPT-UI] undo_delete …`). Счётчик «Сохранённые N» считается из локального списка — прыжка нет (д).

### 4. Создать набор из выбранных
`flashcards_collection.tsx` `openCreatePackFromSelection`: выбор → локальная подготовка набора (`stageSavedCardSet`, без сети) → переход в редактор. Выбор не теряется при ошибке (тост «Выбор сохранён»).
**Чего не было 🔧.** (б) `catch {}` без причины в журнале — тост был, следа нет (запрет немого catch); (в) замок `selectionCreateBusy` — состояние. Теперь `selectionCreateLockRef` (снимается в `finally`), логи `[OPT-UI] pack_from_selection ignored reason=double_tap` и `… rollback reason=stage_failed`.

### 5–6. Создать набор / переименовать набор
`app/community_pack_create.tsx` `onSubmit` — один и тот же путь и для нового набора, и для правки названия (отдельного «переименовать» нет). Локальный набор (не для сообщества) пишется на устройство и экран закрывается сразу — мгновенно (а ✅). Набор «для сообщества» ждёт всю цепочку «сохранить → отправить на публикацию» (сеть, таймауты) и только потом закрывается — (а) ❌, это E1 ниже. Замок — `submitInFlightRef` (в ✅). Спиннер только на кнопке (`busy`), форма остаётся (г ✅). Статусы `daily_limit` / не отправлено — отдельные тосты, набор уже на устройстве.
**Чего не было 🔧.** (б) в тост ошибки шёл **текст исключения** («Account changed», «Local pack not found») — английский текст в русском интерфейсе. Теперь человеку — локализованное «Не удалось сохранить набор», причина — `[OPT-UI] pack_save rollback reason=exception …` в журнал. Ветки `free_author_pack_limit_reached` (пейвол) и немых нет.

### 7–10. Оценка в тренировке
- **«Правда/ложь»** (`flashcards_swipe.tsx` `applyAnswer`): вердикт, вибрация, звук, счётчики и следующая карточка — на тот же свайп; `memoryRef` обновляется мгновенно, запись памяти карточек — отложенная пачка (`scheduleSwipeMemorySave`, flush при уходе/сворачивании), `catch` пишет причину. Руна — локальный счётчик с полётом. Образец.
- **«Блиц»** (`flashcards_blitz_session.tsx` `pick`): подсветка верного/неверного, события, счётчики — сразу; следующий вопрос по таймеру. **🔧** замок `locked` — состояние: два тапа в одном кадре писали ответ дважды (двойной `eventsRef`, двойной `applyBlitzAnswer`). Добавлен `pickLockRef` (снимается, когда `locked` вернулся в «свободно»), лог `[OPT-UI] blitz_pick ignored reason=double_tap`.
- **«Вспомни и напиши»** (`flashcards_recall_session.tsx` `checkAnswer` → `recordVerdict`): проверка локальная, замок `answerLockedRef` — ref (в ✅), без сети.
- **«Устно»** (`flashcards_speaking_session.tsx`): фазы `idle → live → scored`; оценка — по распознаванию на устройстве, ожидания сети нет; результат попытки пишется в события сразу (`scoreSpeakingAttempt`).
- (д) Руны за верный ответ — локальный счётчик с полётом, итог сессии сверяется при завершении; «прыжка» цифры на самом ответе нет. Сверку итоговой суммы с сервером на эмуляторе не проверял.

### 11. Лайк набора
`CommunityPackSocialBar.tsx` `onLikePress`: сердце и цифра сразу, при исключении откат + тост; после ответа сверка с фактом (`res.liked`) — расхождение приводится к правде. (в) ⚠️ замка нет — два быстрых тапа дают два переключения; итог верный. Не чиним (E5).

### 12. Добавить чужой набор
Хаб (`FlashcardsCategoryHub.tsx` «+»): «✓» и «+1» сразу, `addingPackIdsRef`, при отказе откат и тост. Экран набора (`CommunityPackSocialBar.tsx` `onAddPress`): `try/catch` вокруг записи, откат и тост, лог `[OPT-UI] pack_add threw …`. Спиннера на весь экран нет.
