## Проблема

```text
Для курса из 32 уроков недостаточно иметь порядок уроков и рабочие названия.
Каждый выпуск должен быть готовым YouTube-активом, который можно производить, публиковать и вести в Фрейзмен.
```

## Новое Правило

```text
В формате "Сборка Английского: 32 урока Фрейзмена" каждый урок выпускается полным пакетом.

Запрещено сдавать только тему, черновой план или таблицу.
Минимальный готовый результат для одного урока:
1. финальное кликабельное название;
2. 10 запасных названий;
3. идея превью;
4. одностраничный бриф;
5. полный сценарий на 10 минут;
6. нативная реклама Фрейзмена до 90 секунд;
7. точная миссия в приложении;
8. описание YouTube без таймкодов;
9. закрепленный комментарий;
10. 3 идеи Shorts/Reels;
11. факт-чек;
12. QA-проверка.
```

## Конверсионное Правило

```text
Каждый сценарий должен прямо связывать выпуск с конкретным уроком приложения:
"Это урок N из 32 в Фрейзмене."

Фрейзмен не должен появляться как случайная реклама.
Он должен быть второй половиной урока: видео объясняет, приложение тренирует.
```
