# Англійська · Урок 17 · Заняття 45 — Перевірити папку з документами

**Ситуація.** Ви перевіряєте документи в папці й запитуєте про підтвердження адреси та особи.

**Що ви опануєте:** some / any + plural count noun or non-count noun
**Нові слова:** work permit, residence permit, proof of address, photo ID

## Інтро 1

### Повідомити про наявність

work permit — дозвіл на роботу. Ви повідомляєте про кілька перевірених документів. Work permit → work permits. Some ставимо перед злічуваним у множині або незлічуваним, коли повідомляємо про певну кількість.

**Виберіть фразу для цієї ситуації.**

- ✅ **We checked some work permits.**
- ❌ We checked any work permits. — *У стверджувальному повідомленні про певну кількість використовуємо some.*
- ❌ We checked a work permits. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 2

### Повністю заперечити наявність

residence permit — дозвіл на проживання, посвідка на проживання. В обговорюваній папці немає жодного документа цього типу. Residence permit → residence permits. proof of address — підтвердження адреси проживання. Some використовується з множиною злічуваних та з незлічуваними. У запереченні зі значенням «жодного» зазвичай вибираємо any.

**Виберіть фразу для цієї ситуації.**

- ✅ **We don't have any residence permits.**
- ❌ We don't have some residence permits. — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ We don't have a residence permits. — *A не ставиться перед незлічуваним або множиною.*

---

## Інтро 3

### Запитати без припущення

photo ID — документ із фотографією, що посвідчує особу. Запитайте нейтрально про наявність підтвердження особи, не припускаючи відповіді «так». Тут photo ID — загальна назва, без підрахунку окремих карток. У нейтральному запитанні зазвичай any. Some теж трапляється в запитаннях: наприклад, у пропозиції Would you like some tea? або коли очікують «так». Тому враховуйте ситуацію, а не лише знак питання.

**Виберіть фразу для цієї ситуації.**

- ✅ **Do you have any photo ID?**
- ❌ Do you have some photo ID? — *Тут потрібне повне заперечення або нейтральне запитання про наявність: any. Some у запитанні можливе за іншого очікування мовця, але тут такого змісту немає.*
- ❌ Do you have many photo ID? — *Many потребує злічуваного іменника у множині; тут загальна назва.*
