# Аудит генератора фраз и инфраструктуры генерации контента планов

> Дата: 2026-06-10. Контекст: перестройка планов (Ф0–Ф3, Ф5 выполнены; Ф4 — контент — впереди).
> Вопрос аудита: идеально ли всё для генерации ~546 дней под новые темы, и что улучшить.

## Вердикт коротко

**Конвейер генерации (tools/plan_gen) — рабочий и почти готов к Ф4.** Писатель + 3 критика,
параметризация по planId/теме/арке, валидатор и gate-проверка на месте, грабли задокументированы.

**Главные проблемы НЕ в конвейере, а в двух местах:**
1. **Рантайм-генератор фраз** (`app/personal_plan_phrase_lessons.ts`) — фолбэк для неавторских
   дней слабый: одни и те же 6 фраз на все дни, шаблонные дистракторы.
2. **Рассинхрон старых тем с новой концепцией** — scaffold-темы дней, per-plan шаблоны и
   authored-контент mitap до сих пор живут в старых темах (созвоны/переезд).

---

## Часть 1 — рантайм-генератор фраз (что видит юзер СЕЙЧАС)

Резолв фраз дня: `getPersonalPlanPhraseLesson(id)` →
`PERSONAL_PLAN_PHRASE_LESSONS[id]` (рукописная карта) → gavan-canonical (week1 media) →
`buildGeneratedPlanPhraseLesson`: **authored из реестра** (если есть) → **шаблоны**.

### Находки (по серьёзности)

**К1. Шаблонный фолбэк = одни и те же 6 фраз на ВСЕ дни плана.**
`GENERATED_DAY1_PHRASE_TEMPLATES[полный id]` есть только у дня 1; все остальные дни без
authored-контента получают `GENERATED_PLAN_PHRASE_TEMPLATES[planId]` — статичные 6 фраз.
День 2 = день 50 = день 126. Для gavan/impuls/echo (authored нет вообще) это весь контент
после дня 1. Лечится только Ф4 (генерацией), полировать шаблоны бессмысленно.

**К2. Дистракторы шаблонного пути слабые и в старой лексике.**
`generatedWordsForPhrase`: дефолтный пул `phrase: ['please','again','briefly','slowly',
'carefully','clearly']` — слова не того класса, угадайка; пул `noun: ['owner','task','result',
'summary','deadline','update','blocker']` — **лексика созвонов (старый mitap)**, она будет
всплывать плитками в любых новых темах. Категоризация — англ. regex-списки на ~30 слов.

**К3. Мёртвый рукописный контент + баг внутри.**
`PERSONAL_PLAN_PHRASE_LESSONS['gavan_day1_short_replies']` — богатый день (правильные
дистракторы here←hear/there/her, авторские notes), но рантайм запрашивает
`gavan_d001_content_unit` → этот блок НИКОГДА не используется. Внутри баг:
`spanish: 'Я здесь.'` (русский текст в испанском поле). Решение: удалить блок в Ф6-cleanup
(Ф4 закроет день authored-контентом) — не чинить мёртвое.

**К4. uk = ru в шаблонном пути.** `ukrainian: template.ukrainian ?? template.russian` —
помечено как заглушка; украинцы на шаблонных днях видят русский. Закрывается Ф4.

**К5. canonicalWordDistractors (gavan week1 canonical-media) опасен.**
Дистракторы = слова ИЗ ДРУГИХ ФРАЗ ТОГО ЖЕ ДНЯ + дефолты ('please','now','again','here',...)
— высокий риск «второго правильного ответа» (нарушение контракта «ровно 1 правильный»).
Путь живёт только для `gavan_week1_dayN_canonical_media`.

## Часть 2 — рассинхрон тем с новой концепцией (Ф5 переименовала, контент не переехал)

| Слой | voyazh→Компас | mitap→Фокус | gavan→Запас | impuls→Реплика | echo→Эфир |
|---|---|---|---|---|---|
| Темы scaffold-дней (catalog topics) | ✓ поездки | ✗ **созвоны/standup** | ✗ **переезд/документы** | ~ ок (речь) | ~ ок (слух) |
| Per-plan шаблон 6 фраз | ✓ | ✗ **summary/deadline/owner** | ✗ **формы/адрес** | ✓ | ✓ |
| Authored-контент | ✓ **84/84 совместим** (вычитать тон 50+) | ✗ 56 дней про созвоны — **в перепись** | нет (0/126) | нет (0/140) | нет (0/84) |

**Следствие:** юзер, выбравший «Заниматься для себя» (Фокус), с 12-го дня видит заголовки
«Сказать про blocker», «Follow-up после meeting» — прямое противоречие обещанию онбординга.
То же у Запаса (заголовки про аренду/клиники вместо «нужных слов»).

**Объём Ф4 (уточнён аудитом):** gavan 126 + impuls 140 + echo 84 + mitap 112 (перепись) =
**462 дня генерации** + voyazh 84 — только вычитка тона (актив сохранён). Это меньше «всех 546».

## Часть 3 — конвейер tools/plan_gen (оценка по файлам)

- **make_batch.py** ✓ — ROWS редактируются под батч; gate-формула продублирована из
  `plan_lesson_gate.ts` (риск рассинхрона — мелкий, формула стабильна).
- **write_gen_wf.py** ✓✓ — ядро. Писатель + 3 критика (смысл/i18n/gate), CLI-параметры
  planId/тема/арка, POS-набор и карта уроков вшиты, контракт «6 фраз / 5 дистракторов /
  6 vocab / 3 intro / prereq в gate» прописан жёстко, грабли дистракторов-синонимов учтены.
  **Улучшение И1:** STYLE не знает новой аудитории — добавить строку «аудитория 50+,
  спокойный серьёзный тон, простые понятные названия (НЕ хуки), без сленга и мемов»
  (требование концепции; сейчас только «дружелюбный тренер на ты»).
- **parse_batch.py** ✓ — фильтр POS-шума со strong-списком, рабочая эвристика.
- **val_batch.ts** ✓ — реальный validatePlanContentDay + gate + suma. **Улучшение И2:**
  не ловит дубли фраз между днями (дедуп — отдельный скрипт по памяти, гонять каждые
  3-4 недели); можно встроить флажком `--dedup <plan_content.ts>`.
- **emit_and_splice.py** ✓ — contiguous-append, грабли «не для патчей» задокументированы
  в шапке и в памяти.

Схема/валидатор (`plan_content_schema.ts`) — здоровы (intro-kind проверка добавлена ранее,
prereq>=1, 16 валидных POS). Реестр (`plan_content_registry.ts`) — чистый, регистрация
нового плана = 1 импорт + 1 строка в ALL_CONTENT_DAYS.

## Рекомендации (приоритет)

**Перед стартом Ф4 (быстрые, дешёвые):**
1. (И1) Дописать в STYLE write_gen_wf.py строку про 50+/спокойный тон/простые названия.
2. Спроектировать 5 арок под новые темы (это и есть вход Ф4; старые docs/plan_arcs/* устарели)
   — и в рамках арок заменить mitapTopics/gavanTopics + 2 шаблонных набора (mitap/gavan)
   на новые темы. Это контент-решения — утверждаются владельцем вместе с арками.
3. Очерёдность генерации (предложение): **gavan (Запас)** первым — самый простой формат
   (слова дня), уровень A1→A2, 126 дней; затем impuls 140, echo 84, перепись mitap 112.
   voyazh — параллельная вычитка тона. (Память: «план целиком, потом следующий».)

**В Ф4 по ходу:**
4. (И2) Дедуп-проверку в val_batch (или гонять существующий скрипт каждые 3-4 недели — как mitap).
5. Не улучшать шаблонный фолбэк и canonical-путь — они умирают по мере авторизации дней.

**В Ф6 (cleanup):**
6. Удалить мёртвый `gavan_day1_short_replies` (с багом ru-в-es) и gavan-canonical путь,
   когда gavan будет authored; убрать заглушку uk=ru.

## Что НЕ нужно менять

- Контракт PlanContentDay, валидатор, gate-кривую — стабильны, протестированы.
- Реестр и re-key адаптер (`${lessonId}_phrase_${N}`) — контракт залочен тестом.
- makeGeneratedDay/профили Ф3 — не пересекаются с генерацией контента.
- Воркфлоу писатель+3критика — доказал себя на voyazh 84/84 и mitap 56.
