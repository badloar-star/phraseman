# Урок 27 · Заняття 04 — Кімната для гостей

**Ситуація.** Ви обираєте ліжко, обговорюєте візит близьких і завершуєте підготовку кімнати.

**Що ви опануєте:** if + past simple, would + base verb; past simple / present perfect
**Нові слова:** wisely, eagerly, deeply, practically

## Інтро 1

### Якби вистачало грошей

Ви вибираєте ліжко для гостей, але грошей на модель, яка сподобалася, бракує. Поясніть: I would buy a better bed if I had enough money — я б купив краще ліжко, якби мав достатньо грошей. Складаємо: I + would buy + a better bed + if I had enough money — хто, що зробив би, що купив би, за якої умови. Після would потрібна buy, не bought. В умові використовуємо had без would: потрібної суми зараз немає.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would buy a better bed if I had enough money.**
- ❌ I would bought a better bed if I had enough money. — *Після would потрібна форма buy.*
- ❌ I would buy a better bed if I would had enough money. — *В умові had без would.*

---

## Інтро 2

### Якби працювали поруч

Ви рідко бачитеся з близькими, бо працюєте далеко від них. Поясніть: I would see them more often if I worked nearby — я б частіше з ними бачився, якби працював поруч. Складаємо: I + would see + them + more often + if I worked nearby — хто, що робив би, з ким, як часто, за якої умови. Them замінює близьких. Після would потрібна see; worked після if представляє інше становище зараз.

**Виберіть фразу для цієї ситуації.**

- ✅ **I would see them more often if I worked nearby.**
- ❌ I would seeing them more often if I worked nearby. — *Після would потрібно see.*
- ❌ I would see them more often if I would worked nearby. — *В умові worked без would.*

---

## Інтро 3

### Коли зібрали ліжко

Гість помічає нове ліжко й запитує, коли ви його зібрали. Дайте відповідь: We built it yesterday — ми зібрали його вчора. Складаємо: We + built + it + yesterday — хто, дія в минулому, що зібрали, коли. Built — минула форма build, не builded. It замінює ліжко. Yesterday указує завершений час, тому тут built без have.

**Виберіть фразу для цієї ситуації.**

- ✅ **We built it yesterday.**
- ❌ We have built it yesterday. — *Із завершеним yesterday тут past simple.*
- ❌ We builded it yesterday. — *Минула форма build — built.*
