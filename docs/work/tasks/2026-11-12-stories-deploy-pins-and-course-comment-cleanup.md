## Architecture

Код поведения не меняется: правятся только комментарии, константы закрепления в скрипте выкладки и удаляется файл без
единого импортёра. Скрипт выкладки по-прежнему отказывает, если живая версия на хостинге — не одна из проверенных.

## Security and privacy

Скрипт выкладки остаётся с теми же проверками (сайт, состав файлов, адрес загрузки, гонка выпусков); меняются только
отпечатки допустимых файлов. Секретов и персональных данных правка не касается.
