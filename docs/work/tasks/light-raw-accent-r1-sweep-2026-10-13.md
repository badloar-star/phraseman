## Outcome
Файл `docs/phraseman-2.0/LIGHT_RAW_ACCENT_R1_2026-10-13.md`: по каждому из 56 мест сканера — файл:строка, что за элемент (график без текста / заливка кнопки с текстом / вуаль / картинка / dev), контраст на светлой ＠1 (сырой accent #7EF0C8 даёт 1,0:1, accentGraphic #48816E — 3,27:1). Места, где реально график или текст/значок без заливки, в файлах без чужих незакоммиченных правок переведены на accentGraphic / accentTextSafe; остальное помечено light-accent-ok с причиной или передано владельцу.

## Scope
Новый отчёт; правки только в `components/*` (общие, мои) и в файлах `app/*` без чужих правок — минимальные замены одного токена. Онбординг (заморожен) только отмечается, не правится. Файлы Авторизации, Codex и Дизайна с чужими незакоммиченными правками не трогаются — им список.

## Architecture
Тот же сканер `scripts/light_accent_graphics_scan.mjs` и токены accentGraphic/accentTextSafe (c62e8fc70); тёмный вид не меняется (оба токена равны accent). База храповика `config/light-accent-graphics-baseline.json` подтягивается за каждую исправленную строку.

## Security and privacy
Только цвета.

## Technical debt
Часть мест — заливки кнопок с текстом: там важен контраст текста на заливке (accentInk), а не заливки на фоне; их не меняем.
