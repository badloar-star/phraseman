# Англійська · Урок 26 · Заняття 33 — Спочатку умова чи рішення

**Ситуація.** Ви вибираєте транспорт і місце для вечері, передаєте одну домовленість у різному порядку.

**Що ви опануєте:** ставити умову з if на початок чи в кінець фрази: The subway is closed tonight.
**Нові слова:** subway, railroad, diner, takeout

## Інтро 1

### Умова на початку або в кінці

Subway — метро. If the subway is closed, we will take a bus — якщо метро закрито, ми поїдемо автобусом. Ту саму умову можна поставити після рішення: We will take a bus if the subway is closed. Зміст зберігається. Коли частина з if стоїть першою, після неї зазвичай пишуть кому; коли вона йде другою, кома зазвичай не потрібна. Перестановка не змінює часів: після if залишається is, у результаті — will take.

**Виберіть фразу для цієї ситуації.**

- ✅ **We will take a bus if the subway is closed.**
- ❌ We will take a bus if the subway will be closed. — *Порядок частин не дозволяє will після if у цій умові.*
- ❌ We take a bus if the subway will be closed. — *В умові потрібно is; обіцяне рішення тут will take.*

## Інтро 2

### Спочатку прохання чи спочатку умова

Друг збирається сам розібратися зі складною справою. Запропонуйте звернутися до вас: If you need help, call me — якщо потрібна допомога, зателефонуй мені. Можна почати з прохання: Call me if you need help. Складаємо дві частини: call + me — що зробити й кому зателефонувати; if + you + need + help — за якої умови. Переставляємо цілі частини, не змінюючи їхніх форм. Коли умова перша, після неї потрібна кома; після прохання перед if — ні. Call на початку фрази, без you, залишається проханням в обох порядках.

**Виберіть фразу для цієї ситуації.**

- ✅ **Call me if you need help.**
- ❌ You will call me if you need help. — *You will call — повідомлення про майбутнє; тут потрібне прохання call.*
- ❌ Call me if you will need help. — *Після if у цій умові need без will.*

---

## Інтро 3

### Якщо в кафе немає місць

Ви плануєте вечерю в кафе й обговорюєте запасний варіант: We will get takeout if the diner is full — ми візьмемо їжу навинос, якщо в кафе немає місць. Поставмо умову першою: If the diner is full, we will get takeout. Складаємо: If + the diner + is + full, + we + will get + takeout — умова, потім рішення. Тепер після умови потрібна кома. Перестановка не змінює форм: в умові залишається is, у рішенні — will get.

**Виберіть фразу для цієї ситуації.**

- ✅ **If the diner is full, we will get takeout.**
- ❌ If the diner will be full, we will get takeout. — *Після if тут is, незалежно від порядку частин.*
- ❌ Unless the diner is full, we will get takeout. — *Unless змінює умову: їжу навинос візьмемо, якщо кафе не заповнене.*
