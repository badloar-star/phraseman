## План прогона трёх правил смены аккаунта (для эмулятора, после/вместе с Авторизацией)
Безопасность: вход выполняет человек или Авторизация по своим допустимым путям; Сверка пароли НЕ вводит, аккаунт №1 не трогает, аккаунты №2/№3 только по явному слову человека, ничего не стирает, выход/смена — только с явного разрешения. Сверка снимает кадры и журнал. Точные строки журнала [AUTH-SWITCH] новых правил в HEAD ещё не напечатаны под этим именем — ниже ожидаемые из существующего кода + место для строки Авторизации («строка Авторизации: …», уточнить у неё).
Подготовка перед каждым сценарием: свежий запуск, `logcat -c`, кадры серией на устройстве (cap.sh), после — выписать строки [AUTH-LINK-GOOGLE], [AUTH-SWITCH*], [PROFILE-FLIP], [CONSENT-REGATE], [AUTH-MODAL], [AUTH-ONB].
