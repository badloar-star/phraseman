## Пункт 2 (повтор): путь через эмулятор Firebase С ФУНКЦИЯМИ — остановлен на подготовке, причины точные
Боевой аккаунт не трогается. Подготовка показала четыре препятствия, ни одно не снять без чужих процессов или времени:
1. **Порты заняты чужим набором.** Эмуляторы Auth (9099) и Firestore (8085) уже запущены сессией Входа (`firebase emulators:start --config firebase.e2e.json --only auth,firestore ... --export-on-exit .e2e-emulator-data`, PID 25228, Firestore-java PID 32744). Второй запуск `--only auth,firestore,functions` упрётся в эти порты; чтобы добавить Functions, набор надо перезапустить (останавливать чужой процесс я не стал).
2. **В `firebase.e2e.json` нет секции `functions`** (только auth 9099, firestore 8085, ui off): Functions-эмулятор из этого конфига не поднимется; нужно добавить `"functions": {"port": 5001, "host": "127.0.0.1"}` и `functions.source`.
3. **Сборка функций из чистого HEAD.** В рабочем дереве у `functions/src` чужие незакоммиченные правки (`account_delete.ts`, `admin_spire_config.ts`, `index.ts`, `spire_config_contract.ts`, …), а README (`docs/work/e2e/README.md`) требует собирать `functions/lib` из чистого HEAD; у `functions/tsconfig.json` `rootDir: ".."` — компилируется весь репозиторий, `git archive HEAD` не уложился в 2 минуты даже на подсчёт размера. Сборка + выгрузка за 20 минут не реалистична на этом ПК (свободно ~1–5 ГБ при трёх Metro/эмуляторах).
4. **Клиент:** `app/firebase_emulator_dev.ts` ждёт эмуляторы на жёстко заданных портах auth 9099 / firestore **8080** / functions 5001, а в `firebase.e2e.json` Firestore на **8085** (порт передаётся через `EXPO_PUBLIC_FIREBASE_EMULATOR_FIRESTORE_PORT`, а для functions переменной нет) — адрес эмулятора Functions надо проверить отдельно.
Предложение: Вход (владелец набора эмуляторов) собирает `functions/lib` из чистого HEAD в `C:/Temp/...` и перезапускает набор с Functions; после его хэша/сообщения я запускаю Metro :8082 (`scripts/e2e/metro_emulator.sh`) и прогоняю вход → удаление → повторный вход на `accounts-v2-e2e-a@phraseman.test`.
