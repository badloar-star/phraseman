Составлен по запросу владельца для макета объединённого экрана «Этот урок / Весь курс». Всё взято из кода; номера строк проверены по файлам на 22.10. Если элемента в коде нет, написано «отсутствует». Ничего не выдумано.

**Важная оговорка про состояние дерева.** Переключатель «Этот урок / Весь курс» на экране «Слова» (`app/learning_v2_lesson_words.tsx`) на момент составления лежит в рабочем дереве **незакоммиченным** (`git status`: файл `M`; в HEAD переключателя нет, он добавлен правкой другой сессии). Коммит `45cf9fbdc` убрал книжку из шапки хаба и сослался на «слова — плитка „Слова“». Все строки раздела A ниже взяты из рабочего дерева.

## Главное для макета (выжимка)

1. **Плитка «Слова» живёт на обложке урока** рядом с «Продолжить» и «Теория» (стекло 70×50, значок «albums» + подпись «Слова»); она открывает **экран `/learning_v2_lesson_words?lesson=N`** целиком (push, не шторка). Книжки со счётчиком слов в шапке хаба **больше нет**.
2. **Экран один, внутри переключатель-таблетка** из двух ячеек: **«Этот урок» | «Весь курс»** (ru). Заголовок над ним: для «Этого урока» — **«N. Словарь»** (где N — номер урока, строка `words.title` из `LangContext`), для «Всего курса» — **«Слова курса»**. Слева общая круглая кнопка «назад».
3. **Строка слова** = карточка 58+ dp: слева значок статуса (кружок с тремя точками; галочка у «выученного», но у слов Learning V2 «выучено» не считается, значит всегда три точки), крупно слово (16/21, 600), под ним перевод (13/17, вторичный цвет), справа закладка «в карточки». Тап по слову = озвучка + подсветка плашки до 2,5 с.
4. **Нет у слова** на этом экране: транскрипции, отдельной кнопки-динамика, метки урока, части речи, примера. Всё это есть **только** в убранном старом словаре (транскрипция + динамик 38 + заголовки «УРОК N»).
5. **Пустые состояния (ru, дословно):** этот урок — «Слова появятся здесь, когда вы встретите их в занятиях этого урока»; весь курс — «Слова появятся здесь, когда вы встретите их в занятиях курса». Спиннера нет: пока чтение не завершилось — пустое место.
6. **Хвост «этого урока»:** строка под списком «Ещё N слов откроются в эпизодах урока» (ru; формы слово/слова/слов), N = все новые слова урока минус открытые. Закрытые слова числом, без названий. Во вкладке «Весь курс» этой строки нет.
7. **Free и Plus на этом экране не различаются.** Единственная граница — закладка «в карточки»: у Free лимит 50 сохранённых карточек, после него открывается окно Plus (`flashcard_limit`, source `add_to_flashcard`).
8. **Поиска, фильтров, сортировки, группировки по урокам, счётчика «выучено» на экране «Слова» нет.** Они были только в убранном словаре (поиск при ≥ 12 слов, заголовки «УРОК N» + число слов, счётчик «Открыто: N») и в dev-словаре V2 (чипы уроков, лист «Уроки», режим выбора, «Тренировать · N»).
9. **Источник слов:** локальная память телефона (AsyncStorage), ключ на урок; слово попадает туда, когда человек **увидел его в занятии** (экран «новое слово»). Сеть и Firestore не трогаются. Для «всего курса» читаются 32 ключа одним `multiGet`, и только при переходе на вкладку «Весь курс».

# Чего в приложении НЕТ (чтобы макет не рисовал лишнего)

- **Книжки со счётчиком слов в шапке хаба урока** и окна «Словарь» из хаба (убраны `45cf9fbdc`, сторож в тестах запрещает вернуть).
- На экране «Слова»: **поиска, фильтров, сортировки, чипов уроков, режима выбора, кнопки «Тренировать», транскрипции, кнопки-динамика, счётчика слов в шапке, меток «выучено», полосы прогресса «N / M выучено», заголовков частей речи, заголовков «УРОК N» во вкладке «Весь курс», скелета/спиннера загрузки, экрана ошибки, офлайн-плашки, пейвола, замков, значка Plus, лимита слов, кнопки «сообщить об ошибке», кнопки «Начать тренировку»**.
- Отдельного счётчика «слова курса: N» нигде нет (число слов видно только косвенно: в строке «Ещё N слов откроются…» и в журнале).
- Закрытых слов **без названий** в списке нет вообще: закрытые показываются только числом внизу вкладки «Этот урок».
- Различий Free и Plus по самим словам нет.
- Словарь V2 (чипы, лист «Уроки», тренировка) **в сторе не доступен** и ни из какого экрана не открывается.

# Неочевидное / спорное

1. **Переключатель «Этот урок / Весь курс» не закоммичен** (рабочее дерево, правка другой сессии). Если её откатят, на экране останется только «этот урок». Макет надо сверять с владельцем и с автором этой правки.
2. **Озвучка на экране «Слова» жёстко `en-US`** (`lesson_words.tsx:3452`), а в старом окне и в словаре V2 — язык изучаемого слова через системный TTS (`ttsLocaleForStudyTarget`). Для курса с не-английской целью слова на экране «Слова» озвучатся не тем языком. Не проверено запуском.
3. **Ключ строки = английский текст слова** (`lesson_words.tsx:3462`), а дедупликация во «Всём курсе» идёт по (язык, урок, id слова). Если одно и то же слово встречается в двух уроках, во вкладке «Весь курс» будут одинаковые ключи (ожидаемо предупреждение React, возможна путаница строк). Не проверено запуском.
4. **В режиме `en` (интерфейс на английском)** перевод строки берётся из поля `en`, а в `learningV2LessonWordToListWord` в это поле кладётся **само слово** (`learning_v2_lesson_words.tsx:44`; `lesson_words_spanish_gloss.ts:141-143`). Значит под словом может показаться то же слово вместо перевода. Не проверено запуском.
5. **«Закладка» передаёт не все переводы:** `AddToFlashcard` на экране «Слова» получает только ru/uk/es, переводы pt-BR/vi/id/tr/pl теряются (`lesson_words.tsx:3554`), в старом окне передавались все девять.
6. **Нет «выучено»**: значки статуса на экране «Слова» формально есть, но всегда «не выучено». Чтобы показать прогресс, нужен новый источник данных (сейчас у слов Learning V2 нет счётчика).
7. **«Открытое слово» ≠ «пройденное».** Слово попадает в список, как только показано на карточке «новое слово» в занятии, даже если занятие не завершено.
8. **Заголовок «N. Словарь»** (формат «5. Словарь» с точкой) общий с основным курсом, а не «Слова урока 5», как сказано в комментарии файла (`learning_v2_lesson_words.tsx:4-5`). Фактически берётся `s.words.title(N)`.
9. **Старое окно читало слова курса при каждом показе хаба**, даже без нажатия на книжку (расчёт удалён коммитом). Новый путь экономнее: читает только по переключению на «Весь курс».
10. **Порог поиска «≥ 12 слов»** есть только в старом окне; в V2 поиск виден всегда. Если в объединённом экране будет поиск, порог надо решить отдельно.
11. **Счётчик «Открыто: N» в старом окне не менялся от поиска** (всегда `words.length`).
12. **Перевод ещё не принят Переводчиком** на 7 языках для подписей переключателя и заголовка «Слова курса» (комментарий в коде), а формы числа в «Ещё N слов…» «вычитаны Переводчиком 22.10» (`learning_v2_lesson_words_closed_v1.ts:14`).
13. **Дубль по теме «Классический курс»:** в хабе под обложкой есть три плитки «Все главы / Все уроки / Старый курс» (`SeasonNavTiles.tsx:35-37`), «Слова» — не в их числе, а на обложке. В макете не путать два ряда плиток.
