## Outcome

Человек может собрать отработку из УЖЕ исправленных ошибок для закрепления. Верный ответ
в повторе не меняет статус «исправлена»; ошибка в повторе возвращает её в активные по
обычным правилам. Без нового параметра отработка ведёт себя байт в байт как раньше.

## Scope

In scope: modules/mistake-practice/session.ts (параметр pool), scheduler.ts (выборка
исправленных), projection.ts (правило для событий с payload.review), счётчик доступных
исправленных, тесты. Затем — runtime prepare (параметр, возобновление) после ответов.

Out of scope: кнопка и окно (сессия 3), награды/энергия до решения владельца, сервер.

## Architecture

Журнал событий — источник правды, проекция пересобирается из всего журнала. Новое
правило срабатывает ТОЛЬКО на practice_answered с payload.review === true, поэтому
история без пометки читается как раньше. Выборка 'corrected' не смотрит на срок.

## Security and privacy

Новых данных нет: та же запись журнала с одним булевым полем review. Политика не меняется.

## Technical debt

- Contain: экономика повтора (монеты/энергия/звёзды) — ждёт решения владельца; до него
  экран не передаёт pool, поэтому новый режим недостижим из интерфейса.

ответами по исправленной ошибке (как сейчас) — откат безопасен для данных.
