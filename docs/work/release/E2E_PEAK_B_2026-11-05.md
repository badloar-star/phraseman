# E2E: Пик B в боевом режиме «по ступеням» — сценарий для Сверки (Моменты, 05.11)

Составлен по коду HEAD. На устройстве сценарий не гонялся — каждый шаг даёт ожидаемое и способ увидеть; расхождение с ожидаемым = находка.

## 0. Подготовка

- **Что проверяем.** Сборка с `PEAK_SCREEN_V2_ENABLED=true` (`components/spire/peak/peak_screen_flag.ts:4`), серверный конфиг остаётся `rankBy=steps`, `promotionBonus=100`. Это живое приложение, не превью.
- **Без пересборки (только dev-сборка).** Живой экран Пика в варианте B: `phraseman://dev_spire_preview?peakB=1` (+ `&tour=off` — убрать тур; без `tour=off` тур идёт по флагу аккаунта). Принудительно ступени: `phraseman://dev_state?spireRankBy=steps`. В стор-сборке этих маршрутов нет.
- **Журнал (одним поиском).** `[PEAK-B]` — решение экрана (`screen: PeakScreenV2 (B)`), загрузка слота; `[PEAK-TOUR]` — `done {via:'start'|'skip'}` и `card_overlap {page, screen, card}`. Любая красная ошибка рядом = находка.
- **Размеры экрана (эмулятор).** `adb shell wm size 360x640`, затем `375x667`; вернуть: `adb shell wm size reset`.
- **Сброс «тур показан».** Свежая установка или новый аккаунт; либо стереть ключ `story_events_v1:peak_tour:<uid>` (AsyncStorage) и перезапустить приложение. Флаг «видел СТАРЫЙ тур» — ключ `spire_tour_seen_v1`=`1`.

## 1. Первый вход на вкладку Пика → тур B (аккаунт без `story_events_v1:peak_tour:<uid>`)

1. Открыть вкладку Пика. **Должно быть:** на экране сразу рельса/этаж, поверх затемнение с «дырами» и карточка тура внизу; старого тура (`SpireTour`) нет. Журнал: `[PEAK-B] решение экрана ... on:true`.
2. Страница 1 из 3. **Должно быть:** заголовок «Поднимайся выше всех за неделю» (`tour1Title`) и текст про 15 этажей и «место считается по ступеням» (`tour1Text`; слова «монеты недели» быть НЕ должно); подсвечены окна по прежней раскладке (legacy: шапка/башня/счётчик), кнопки «Пропустить» и «Далее» одной строкой, не схлопнуты, текст кнопок целиком.
3. «Далее» → страница 2: «10 заданий, общее время, 3 сердца» + текст про таймер и сердце. **Должно быть:** другое окно подсветки, кнопки на месте.
4. «Далее» → страница 3: «Верхние 15% переходят на пик выше» + текст «{Лига1}, {Лига2}… до {Вершина}. Нижние 15% и все без ступеней спускаются…» (названия лиг подставлены, не `{a}`). **Должно быть:** стрелки «поднимаются» слева от строк топ-5 с зоной «вверх», кнопка «Начать» (вместо «Далее»).
5. «Начать». **Должно быть:** тур исчез в тот же кадр (без паузы на сеть), журнал `[PEAK-TOUR] done {"via":"start"}`.
6. Проверка «Пропустить»: повторить пп.1–2 на другом новом аккаунте, нажать «Пропустить» на любой странице. **Должно быть:** тур закрыт сразу, `done {"via":"skip","page":N}`, дальше как после п.5.
7. Нигде в туре нет «5 лучших по монетам», «+1000 монет» (это только режим монет).

## 2. Экран B после тура (режим ступеней)

1. **Рельса и этаж:** башня-рельса слева, номер этажа, плашка лиги и времени до конца недели справа/сверху (`pill`). Номера этажей читаемы.
2. **Счётчик:** крупное «N ступеней» (форма слова под число; НЕ «N монет») и «N место». Пока комната грузится — «—», без скачка вёрстки.
3. **Топ-5:** 5 строк (если людей меньше — столько, сколько есть), место, монета-ранг, имя, справа число СТУПЕНЬ (не тысячи монет); у строк в зоне повышения стрелка вверх. Группа «Дошёл до вершины» — только если такие есть вне топ-5.
4. **Кнопка «Все участники»** внизу.

## 3. «Все участники» → назад

1. Нажать «Все участники». **Должно быть:** окно поверх экрана с подписью «<Лига> · N человек · по ступеням» (не «по монетам»), 30 строк с разделителями «Зона повышения / Остаются / Зона понижения»; зоны по ступеням (верхние 15 %), числа — ступени.
2. «Назад». **Должно быть:** возврат на экран B на то же место прокрутки, тур не появляется.

## 4. Повторный вход

Выйти из вкладки (на Главную) и вернуться; затем убить приложение и открыть заново. **Должно быть:** тура нет (флаг `story_events_v1:peak_tour:<uid>`), экран B сразу. Журнал не содержит `[PEAK-TOUR]`. Смена аккаунта (если есть второй): тур B один раз у каждого аккаунта.

## 5. Игрок, видевший СТАРЫЙ тур

Аккаунт со старой сборки (2.0.3), где `spire_tour_seen_v1=1`, но нет `story_events_v1:peak_tour:<uid>` (обновление поверх). **Должно быть:** тур B показывается ОДИН раз на первом входе (старый флаг его не гасит и старый `SpireTour` не показывается), после — как п.4.

## 6. Малые экраны: 360×640 и 375×667

Для каждого размера пройти пп.1–3 (тур, страницы 1–3, экран B, «Все участники»). **Должно быть:** карточка тура не уезжает за экран, обе кнопки видны и нажимаются; нижние строки топ-5 либо не закрыты, либо карточка встала НАД подсвеченным окном. Если карточка перекрывает подсвеченные строки топ-5 — журнал `[PEAK-TOUR] card_overlap {page,screen,card}` (известное, см. KNOWN_ISSUES: записать страницу и размер). Экран B без тура: ничего не обрезается, прокрутка работает, кнопка «Все участники» достижима.
Дополнительно: системный крупный шрифт (Настройки → Размер шрифта максимум) на 375×667 — текст тура уменьшается не более чем до потолка, кнопки целы.

## 7. Окно повышения и «+1 к запасу энергии»

Сервера не нужно: `phraseman://dev_moments_preview?state=promo` (полное) и `state=promoshort` (короткое, `&tier=2`).
1. Запас энергии меньше 11 (по умолчанию в dev 0). **Должно быть:** в финале окна под лигой строка «+1 к запасу энергии» (в коротком — отдельной строкой под итогом); при `&coins=100` ещё «+100 монет за повышение».
2. Запас 11: строки быть НЕ должно (правило `promotionEnergyLine`, коммит d18f26e89). На устройстве запас 11 выставляется только записью `spire_energy_bonus_v1`=`11` в AsyncStorage + перезапуск (в dev нет переключателя); если так не получается — достаточно теста `tests/promotion_energy_line_2026_11_05.test.ts` (0/10 → строка, 11 → null).
3. В обоих окнах кнопка «Играть» работает, никакой другой текст не изменился.

## 8. Откатов и крэшей нет

Пройти пп.1–7 и убедиться: нет красного экрана, нет `ERROR`/`FATAL` в журнале приложения, нет возврата на старый экран Пика (`screen: старый экран Пика` в `[PEAK-B] решение экрана` — находка), нет зависшего затемнения тура после «Начать»/«Пропустить», нет повторного показа тура без причины.
