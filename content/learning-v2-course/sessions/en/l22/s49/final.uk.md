# Англійська · Урок 22 · Заняття 49 — Підготуватися до поїздки

**Ситуація.** Ви пояснюєте приготування до подорожі.

**Що ви опануєте:** сказати, навіщо ви щось робите: I went out to buy bread
**Нові слова:** book a flight, pack my bag, check my passport, print my ticket

## Інтро 1

### Сайт для бронювання

Ви пояснюєте другу, навіщо відкрили сайт авіакомпанії. I use this website to book a flight — я користуюся цим сайтом, щоб забронювати переліт. Спочатку називаємо дію: I use this website. Потім додаємо мету: to book a flight. Тут to означає «щоб», а book стоїть у початковій формі. Так пояснюємо мету використання сайту.

**Виберіть фразу для цієї ситуації.**

- ✅ **I use this website to book a flight.**
- ❌ I use this website for book a flight. — *Мета виражається через to + початкову форму дієслова.*
- ❌ I use this website of book a flight. — *Мета виражається через to + початкову форму дієслова.*

---

## Інтро 2

### Список для зборів

Перед поїздкою ви складаєте список речей, щоб зібрати сумку. I make a list to pack my bag — я складаю список, щоб зібрати сумку. Складаємо: I make a list + to + pack my bag. Перша частина повідомляє, що ви робите; to pack my bag пояснює навіщо. Після to потрібна початкова форма pack. My bag указує на вашу сумку.

**Виберіть фразу для цієї ситуації.**

- ✅ **I make a list to pack my bag.**
- ❌ I make a list for pack my bag. — *Мета виражається через to + початкову форму дієслова.*
- ❌ I make a list of pack my bag. — *Мета виражається через to + початкову форму дієслова.*

---

## Інтро 3

### Роздрукувати квиток

Ви хочете взяти паперовий квиток і користуєтеся принтером. I use the printer to print my ticket — я користуюся принтером, щоб роздрукувати квиток. Складаємо: I use the printer + to + print my ticket. To print my ticket називає мету, тому to перекладається як «щоб». Після нього використовуємо print без закінчень. Уся фраза пояснює, навіщо потрібен принтер.

**Виберіть фразу для цієї ситуації.**

- ✅ **I use the printer to print my ticket.**
- ❌ I use the printer for print my ticket. — *Мета виражається через to + початкову форму дієслова.*
- ❌ I use the printer of print my ticket. — *Мета виражається через to + початкову форму дієслова.*
