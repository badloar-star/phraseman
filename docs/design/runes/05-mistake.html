Правила, общие для всех трёх дизайнов

Со второй ошибки объяснение остаётся бесплатным — это работает сегодня и менять не планируется. Платный разбор нужен только на первой ошибке, где сейчас пусто.

Списание в кадре 0. Баланс меняется до ответа сервера, руна летит к счётчику, счётчик делает bump 420 мс — та же кривая, что и везде в рунных экранах.

Разбор без школьных терминов. Никаких «инфинитив», «спряжение», «форма 3-го лица» — только простыми словами, как объясняет живой человек.

Личная статистика — по факту, не выдумка. «4 раза за месяц» должно быть настоящим числом из истории ошибок ученика, а не декоративным текстом.

Сердечки за руны — под вопросом. Ни один из трёх дизайнов не решает этот вопрос сам, состояние показано как есть — для обсуждения с владельцем.
