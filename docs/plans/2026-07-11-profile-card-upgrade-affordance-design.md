# Profile Card Upgrade Affordance Design

## Goal

Make the upgrade action on the current user's profile card immediately understandable without changing the existing preview or purchase flow.

## Approved Design

- Keep the compact 42 px circular control, but move it directly below the close button.
- Show only an upward arrow so the action stays visually quiet and unambiguous.
- Keep the next-level gradient, glow, haptic feedback, and in-place preview behavior.
- Keep the shard diamond only in the purchase CTA, where it represents currency.
- Continue showing the control only on the current user's card and only when another level is available.
- Use dark foreground on the bright gradient and preserve the existing accessibility label and enlarged touch area.
