# Классика: испанская грамматика по одной теме

Откройте **ES-01.html** из собранного архива в браузере: «Все 50 фраз» показывает оригинал, перевод и каждое слово; «Собрать» рядом с фразой запускает задание с шестью вариантами на каждом шаге. Кнопки RU/UA меняют язык ученика, таблица программы для редактора пока на русском. Это офлайн-предпросмотр, не мобильное приложение. Пунктуация выводится автоматически, попытки, подписка, монеты и звук здесь не моделируются. Выбор заданных плиток — отработка образца, а не оценка произвольного перевода.

## Источник методики

В английском банке `lesson1_phrase_1` = `I am here`, его `wordsEn` = `I / am / here`; варианты для `am`: `is, are, be, been, being`. Следом идут `You are ready`, `He is busy`, `She is calm`, `We are together`. В теории первого урока сравниваются английская фраза без связки и корректная с am/is/are. Урок 2 опирается на эту основу; уроки 3–5 отдельно разбирают утверждение, отрицание и вопросы Present Simple. Проверено по оригинальному классическому пути, не по Learning V2. Эталон: `badloar-star/phraseman@7bf2258c`, `constants/lessons.ts`, `app/lesson_data_1_8.ts`, `app/lesson_data_1_8_phrases_es.gen.ts`, `app/lesson_intro_screens_lesson1_v2.ts`, `lesson_intro_screens_lesson2_v2.ts`, `lesson_intro_screens_lesson3_v2.ts`. Это авторский перенос метода, не построчный перевод английского плана.

## Формат UTF-8

`es/programme.psv`: номер | одна операция | образец | предыдущие темы.

`es/lexicon.psv`: неизменный ключ значения | лемма | формы через пробел | RU | UK | тип | группа вариантов. Составные выражения en casa / en clase объясняются в теории, технически разбираются по словам. Совпавшее неоднозначное написание без ручного разбора блокирует сборку. Леммы для узнавания не следует заставлять учить все сразу.

`es/NN.lesson` содержит разделы: `title`: RU|UK; `grammar`: идентификатор конструкции|язык синтеза в приложении|рабочий уровень; `forms`: лицо|местоимения|форма|RU|UK; `steps`: первый номер из десяти|название RU|название UK|объяснение RU|объяснение UK; `rules`: заголовки RU, UK|тексты RU, UK|ссылки на фразы (всего пять полей); `phrases`: номер|лицо|естественный перевод RU|перевод UK|испанская фраза. Уточнение адресата в скобках применяется только в подсказке, не входит в испанский ответ.

## Первое продолжение

ES-02 — **no + форма estar**. Взять лексику ES-01; создать свои 50 фраз и объяснения. Первое новое слово — no, а не повторный ввод estoy/estás/está. Дополнительные формы, которые раньше были лишь справочной записью, привязывать к первому реально показанному примеру. Когда добавляется урок, реализовать его явный валидатор по грамматической цели (сейчас предусмотрен ES-01); не заменять заглушкой, автоматически принимающей все фразы. Вопросы и новые времена здесь не вводить. Пример решения ошибки: `Ana está no en casa` → `Ana no está en casa`.

## Проверка

Из этой папки: `python3 -B -m unittest -v test_grammar`, затем `python3 -B build.py --out /tmp/phraseman-es-grammar`. Выход — HTML, пакет, словарь с первым появлением и формами, следующее задание, отчёт. Сверка каждой плитки с канонической строкой и грамматические тесты не замещают независимую вычитку переводов или тест на телефоне. Ориентиры по объёму грамматики — инвентари Instituto Cervantes A1–A2 / B1–B2; авторский порядок из 32 тем не означает автоматического достижения уровня. Экспорт не публикует в рабочее приложение.
