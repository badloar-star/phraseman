## Outcome

Разбор по фактам:
- dialogs-036: при выходе разговор НЕ сохраняется. resumeDialogueV2Memory никто не вызывает; в экране сессии нет
  ни хранения, ни восстановления. Текст «Переписка не сохранится» правдив — оставлен, макет обещает несуществующее.
- Первая реплика без перевода и разбора — это ДАННЫЕ. Выпуск хранит opening только как {personaId, text};
  перевод и разбор приходят из серверного разбора хода и только для реплик-ответов. Кнопка перевода
  показывается только при наличии перевода, так что пустого места нет. Закрыть можно только контентом
  (поле перевода в выпуске) или новым серверным вызовом — после релиза.
- Подсказка повторяет цель — это ЛОГИКА: `hintText = coaching.hint ?? currentObjective.label`. До первого
  разбора хода «подсказка» = текст цели. Кнопка подсказки в карточке цели видна всегда; без текста она не
  открывает ничего.
Фикс: подсказка — только из разбора хода (без подмены целью). Карточка цели показывает кнопку «Подсказка»
только когда подсказка есть. Дублей и мёртвой кнопки нет.
