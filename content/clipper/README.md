# CLIPPER — конвейер автомонтажа клипов «фраза → пауза → разбор»

> Модуль самодостаточен, как `content/marketing` и `content/lingman`.
> Любая сессия любого ИИ читает этот файл и продолжает с того же места.
> Приложение Phraseman этот модуль НЕ импортирует и не видит.

## Что он делает

На входе — папка с видео, где говорят по-английски.
На выходе — вертикальные ролики 1080×1920 такого устройства:

```
[A] оригинал: 3 секунды контекста + сама английская фраза   (звук оригинала)
[B] СТОП-КАДР ровно на конце фразы: кадр обесцвечен,
    поверх — фраза, дословный (неправильный) перевод,
    настоящий смысл; звучит русская озвучка разбора        (голос ElevenLabs)
[C] оригинал дальше: короткий хвост                         (звук оригинала)
```

## Быстрый старт

```bash
python content/clipper/run.py --prepare
```
Берёт все видео из `input/`, распознаёт речь, готовит `work/<имя>/prompt.txt`.

Дальше нужен один шаг с моделью: содержимое `prompt.txt` отдать Claude,
ответ (JSON-массив) положить в `work/<имя>/answer.json`. Затем:

```bash
python content/clipper/run.py --finish <имя_видео_без_расширения>
```
Проставит таймкоды, озвучит и соберёт ролики в `output/`.

Один файл, только подготовка:
```bash
python content/clipper/run.py --one content/clipper/input/test.mp4
```

## Из чего собран

| Файл | Шаг | Чем работает |
|---|---|---|
| `transcribe.py` | видео → транскрипт с таймкодами **по словам** | faster-whisper, локально |
| `select_moments.py` | транскрипт → запрос модели → моменты с таймкодами | модель + поиск по словам |
| `tts.py` | текст разбора → mp3 | ElevenLabs (сменный адаптер) |
| `render.py` | момент + озвучка → готовый ролик | ffmpeg |
| `run.py` | связывает шаги | — |

Между шагами лежат файлы в `work/<имя>/`. Поэтому падение на шаге N не
заставляет переделывать предыдущие, а транскрипция (самый долгий шаг)
кэшируется навсегда — удали `transcript.json`, если нужен пересчёт.

## Настройки — `config/config.json`

Главное, что стоит трогать:

- **`min_score`** (сейчас 6) — порог качества фразы 0–10. Момент ниже порога
  выкидывается **до** платной озвучки. Это главный предохранитель: владелец
  выбрал режим «рендерить всё подряд без ручной проверки», и порог — то, что
  не даёт платить за мусор. `0` = действительно всё подряд.
- **`clips_per_video`** — сколько клипов резать из одного исходника.
- **`lead_in_sec` / `tail_sec`** — сколько оригинала показать до и после.
- **`tts_provider`** — `elevenlabs` или `none` (немая пауза, ноль затрат).
- **`whisper_model`** — `tiny`/`base`/`small`/`medium`. Больше = точнее и дольше.

## Важное про деньги и сроки

**Квота ElevenLabs.** На 20.09.2026 израсходовано 112 037 из 122 114 символов
(92%). Одно объяснение ≈ 200–300 знаков. Этот же аккаунт озвучивает уроки
приложения — клипы не должны съесть квоту целиком.

**Подписка стоит на отмене.** `pending_change: cancellation` на 27.09.2026.
После этой даты озвучка через ElevenLabs перестанет работать. Именно поэтому
провайдер вынесен в адаптер `tts.py`: переключение — одна строка в конфиге,
переписывать конвейер не придётся.

## Про права на исходники

Конвейер добавляет поверх фрагмента собственный разбор — это работает в пользу
transformative use, но **не делает законным** любой исходник. Ответственность за
права на видео из `input/` остаётся на владельце. Безопасные пути:
официальная clipping-программа автора либо короткий фрагмент с собственным
разбором. Массовый реаплоад чужого = страйки и снос аккаунта.

`input/`, `work/`, `output/` закрыты в `.gitignore`: чужие видео не должны
попадать в репозиторий ни по весу, ни по копирайту.

## Логи

Единый префикс `[CLIPPER]` с указанием шага: `[CLIPPER][transcribe]`,
`[CLIPPER][render]` и так далее. По правилу владельца лог показывает вход,
каждое ветвление вместе со значением, которое его решило, длительности вызовов,
каждый ранний выход и каждую пойманную ошибку с причиной. Немых `catch` нет.

Вытащить всю цепочку одним поиском:
```bash
grep "\[CLIPPER\]" content/clipper/work_prepare.log
```

## Известные ограничения

- **Автовыбор фразы ошибается.** Примерно 1 из 5 моментов — слабый. Порог
  `min_score` отсекает часть, но не всё. Если качество важнее скорости —
  просмотреть `work/<имя>/moments.json` перед `--finish`.
- **Шрифт.** `drawtext` берёт системный шрифт; кириллица на Windows может
  отрисоваться не идеально. Если текст в ролике выглядит плохо — прописать
  конкретный `fontfile=` в `render.py` → `build_pause_filter`.
- **Windows и кодировка.** Все шаги запускаются с `PYTHONIOENCODING=utf-8`
  (это делает `run.py`). Без него русские логи роняют скрипт на cp1252.
- **yt-dlp.** Команда `yt-dlp` на PATH может быть устаревшим шимом; рабочий
  вызов — `python -m yt_dlp`.
