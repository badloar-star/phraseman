# Светлая «Аврора»: нетекстовая графика ≥ 3:1 на всех уровнях ползунка (WCAG 1.4.11)

Governance-ID: TG-452D1E410E61
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора к утреннему вопросу 3 «тема по умолчанию»: светлая «Аврора» ＠1 без замечаний)

## Outcome
Замерены accent и accentGraphic светлой (и тёмной) «Авроры» на уровнях 0 / 0,25 / 0,5 / 0,6 / 0,75 / 1 против всех поверхностей (фон, верх и низ фона, карточка, контрол, шторка). Графика темы (кольца, полосы, точки, кромки) держит ≥ 3:1 при сохранении оттенка; тёмный вид байт-в-байт прежний. Если токен уже даёт норму — вывод: остаются места, красящиеся сырым accent, они переводятся на accentGraphic.

## Scope
Замер скриптом вне репозитория; правки токенов в `constants/liquidGlassThemePalette.ts` — только если замер покажет провал; места-потребители — отдельными минимальными правками в моих файлах `components/*` и `constants/*`. Экраны `app/*` Дизайна не трогаются, список им.

## Architecture
`accentGraphic = legibleOn(accent, text, [bg, bgTop, bgBottom, opaqueCard, opaqueControl, opaqueSheet], 3.2)` (c62e8fc70): равен accent там, где он уже держит ≥ 3,2:1; иначе тот же оттенок, углублённый в сторону текста темы. Тест `accent_graphic_token` проверяет ≥ 3:1 для 23 тем × 2 оформления × 5 уровней и равенство accent в тёмном.

## Security and privacy
Только цвета.

## Technical debt
Сырые обращения к accent для графики в экранах и общих местах остаются предметом храповиков `light_accent_graphics_ratchet` (основной счёт и счёт accentBorder/accentText).

## Verification
Таблица замера по уровням; `accent_graphic_token`, `light_accent_graphics_ratchet`, `v2_palette_theme_levels` по слоту светофора; кадры до/после Главной и Уроков (светлая ＠1 и ＠0,5) — у Сверки в её пачке.
