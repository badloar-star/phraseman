## Почему функции выкладываются всем набором, а не по одной

Изменились общие модули, которые подключает большинство функций:
- `auth_identity.ts` — его подключают около 160 функций;
- `account_delete_job.ts` — около 180;
- политика моделей OpenAI — около 80.

Всего затронуто **263 функции**. Точечный список по сути совпадает с полным набором, а выкладка части функций оставила бы остальные на старом коде общих модулей. Поэтому — **весь набор `default` одной командой**. Старые функции **не удалять**.
