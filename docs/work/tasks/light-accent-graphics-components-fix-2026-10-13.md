# Исправление графики на сыром accent в общих компонентах (светлые градиентные темы)

Governance-ID: TG-9FE4BB3FC9DE
Status: в работе
Owner: сессия «4 · ТЕМЫ 2.0» (поручение координатора 12.10: общие компоненты `components/*` из раздела 1 аудита LIGHT_ACCENT_GRAPHICS_AUDIT_2026-10-13.md; экраны `app/*` и разделы 2–3 — у Дизайна)

## Outcome
Кольца, полосы, точки, кромки, значки и текст, красящиеся сырым `accent`, в общих компонентах (`components/*`) берут новый токен `accentGraphic` (графика) или `accentText` (текст) и видны на светлых градиентных темах (раньше 1,0–1,8:1 на фоне). Тёмный вид и светлые тонированные темы не меняются. Каждая починка уменьшает базовую линию сторожа.

## Scope
Новый токен `accentGraphic` в `liquidGlassTokens` (+ необязательное поле `Theme.accentGraphic`, заполняется `makeLiquidGlassTheme`), правка ролей цвета в ~25 компонентах `components/*` из аудита, обновление `config/light-accent-graphics-baseline.json`, тест токена. Экраны `app/*`, Learning V2 и раскладка/размеры/анимации не затрагиваются; список Codex — строкой в handoff.

## Architecture
`accentGraphic = legibleOn(accent, text, [bg, bgTop, bgBottom, opaqueCard, opaqueControl, opaqueSheet], 3.2)`: равен `accent`, пока тот держит ≥ 3:1 на всех поверхностях, иначе тот же оттенок углубляется в сторону текста темы. В тёмном оформлении и на светлых тонированных темах совпадает с `accent` (проверяет тест). Компоненты читают `glass.accentGraphic` (GlassTokens) или `t.accentGraphic ?? t.accent` (Theme).

## Security and privacy
Только цвета; данные, права и сеть не затрагиваются.

## Technical debt
Часть мест (компоненты, получающие цвет пропом) остаётся на стороне экранов `app/*` — у Дизайна; места с текстом внутри заливки (кнопки) намеренно не меняются.

## Verification
Тест токена `tests/accent_graphic_token.test.ts` (23 темы × 2 оформления × 5 уровней: ≥ 3:1; тёмный = accent); существующие контрастные тесты тем; ратчет `light_accent_graphics_ratchet` (число уменьшилось); срез типов по правленым файлам; контракты соответствующих компонентов. Тесты — по слоту светофора.

## Rollback
`git revert` коммитов по отдельности: токен и каждый блок компонентов независимы; при откате поведение возвращается к сырому `accent`.
