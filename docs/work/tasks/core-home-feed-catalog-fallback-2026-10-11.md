## Outcome

Если RSS канала (`youtube.com/feeds/videos.xml`) отвечает ошибкой, Главная берёт свежие ролики ТОГО ЖЕ канала из
серверного каталога `youtube_catalog`. Сервер синхронизирует его через YouTube Data API, и он не зависит от RSS.

Вместо этого приложение больше не делает так:
- показывает кэш без обновлений;
- при переопределённом канале и пустом кэше показывает пустую ленту.

Факты 11.10:
- RSS `UCIr8fwZjbDtcUlQ-IKIbndg` (канал Professor Lingman, id подтверждён страницей канала: `externalId`/`rssUrl`)
  отвечает 404.
- Контрольный канал Google Developers тоже отвечает 404, то есть сбой RSS на стороне YouTube.
- Переопределение `youtube_channel_id` в `remote_config` («Пульт» → «📺 YouTube-канал») равно каналу по умолчанию.

## Scope

In scope:
- `app/lingman_youtube.ts`: фолбэк в ветке сбоя сети;
- тест;
- инструкция владельцу.

Out of scope:
- серверные правки;
- запись в прод: сброс переопределения делает владелец;
- переключение на «канал по умолчанию» — переопределение и есть он.

## Architecture

В ветке сбоя RSS:
- если сохранённый список свежее 6 ч, берём его без чтений;
- иначе делаем один запрос к каталогу за запуск (манифест → канал с тегом `en` / `localeDefaults.en` → до 12 роликов).
  Принимается, только если `channel.youtubeChannelId` совпадает с активным каналом — чужие ролики не показываем.
  Удачный итог сохраняется как обычный список.

## Verification

Тесты:
- RSS 404 и каталог отдал этот канал → ролики каталога, без ошибки, сохранены;
- каталог отдал другой канал → не показываем, прежний фолбэк;
- свежий кэш → каталог не читаем;
- каталог упал → прежний фолбэк.

Плюс точечная проверка типов.
