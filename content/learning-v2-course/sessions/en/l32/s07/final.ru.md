# Урок 32 · Занятие 07 — Ищем выход

**Ситуация.** Вы с Беном ищете выход из большого здания по плану.

**Что вы освоите:** делать вывод по поведению человека и уточнять найденные подсказки.
**Новые слова:** —
**Повторяем знакомые слова:** map, exit, stairs, floor

## Интро 1

### Должно быть, нужна помощь

Бен несколько раз смотрит на план здания и возвращается к той же двери. Вы предполагаете: He must need help — ему, должно быть, нужна помощь. Соберите He + must + need + help. После must сразу ставим начальную форму need без s. Must здесь выражает вывод по поведению Бена.

**Выберите фразу для этой ситуации.**

- ✅ **He must need help.**
- ❌ He must needs help. — *После must используем need без s.*
- ❌ He must be need help. — *Перед глаголом need дополнительное be не нужно.*

---

## Интро 2

### План, который вы нашли

Вы нашли план здания возле входа и показываете его Бену: The map I found is useful — план, который вы нашли, полезный. Соберите The map + I found + is useful. Часть I found уточняет map. That можно опустить: внутри уточнения уже есть I, тот, кто нашёл план.

**Выберите фразу для этой ситуации.**

- ✅ **The map I found is useful.**
- ❌ The map I found it is useful. — *Map уже названо: it после found не нужно.*
- ❌ The map I find yesterday is useful. — *Для завершённого прошлого действия нужна форма found.*

---

## Интро 3

### Выход закрыт — вернулись

Вы с Беном дошли до закрытого выхода: The exit was closed, so we went back — выход был закрыт, поэтому мы вернулись. Соберите The exit was closed + so + we went back. После so называем результат. Went back значит «вернулись».

**Выберите фразу для этой ситуации.**

- ✅ **The exit was closed, so we went back.**
- ❌ The exit was closed, so we gone back. — *Нужна прошедшая форма went.*
- ❌ The exit was closed, so we going back. — *Нужна полная часть we went back.*
